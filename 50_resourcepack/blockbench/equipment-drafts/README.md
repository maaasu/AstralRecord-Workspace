# 装備の設計原稿

新規3D装備124点の個別原稿です。各JSONは実マスターID、意匠、持ち点、8×8素材swatch、cuboid形状を保持します。完成形を編集する場合は、隣の `../items/` のnative Blockbench原稿を使ってください。弓の弦の分割やdrawモデル、着用用の標準リグは別原稿です。

素材や輪郭の変更後は、Java/Bedrock出力、32pxアイコン、着用原画を合わせて更新し、握り位置と全周UVを再確認します。防具着用は標準体型へ専用原画を貼る方式です。ゲームクライアント内の確認はnativeエディタの確認と分けて記録してください。

このフォルダーとsource manifestは編集・保守用で、配布パックには含めません。
