The Java container atlases adapt Minecraft: Java Edition GUI textures by Mojang
Studios from the 1.21.11, 26.1, 26.2 and 26.3 clients. AstralRecord supplies
the Celestial palette, frame, slot styling and ornaments. Asset sources and
regeneration instructions are documented in gui-source/README.md.
