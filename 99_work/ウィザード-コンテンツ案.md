# ウィザード — コンテンツ案

## 実装メモ（2026-10-01）

この文書の表は比較用の原案であり、以下は今回実装した装備マスタとの差分である。武器・補助・アクセサリはLv40以上、防具はLv15以上を採用した。Lv40未満の武器・アクセサリは既存装備を使う。希少スキルブック、専用パッシブ、固有発動効果、新規敵・ダンジョンは今回のマスタには含めていない。

- 防具の各講座・各更新帯に2点/4点の累積セット効果を付けた。Lv40以降は火と無属性の杖・補助にも2点の小補正を付けた。異なる講座の装備を混ぜる選択は残る。
- 一律のウィザード職業制限は採用しなかった。通常装備にはプレイヤーLv要件だけを設定した。将来の希少本や固有効果は、実装とバランスを確認して個別に制限する。
- プレイヤーLv100を超える新しい装備要件は作らず、Lv100原装備をrank0/+20→rank1/+40→rank2/+60で育てる。状態変化後の強化値は保持する。Lv110/120の行は別の原装備マスタとして作らない。
- 完成値は同帯の共通試作予算に合わせて再配分した。主武器魔攻・防具4部位のHP/防御/魔防は5講座中の最大構成を予算へ合わせ、他の系列と部位は原案の比率・方向を維持した。+40/+60の固定値は+20の約1.167/1.333倍で、割合値と移動速度は強化で増やさない。TTK・DPSを実測して確定した値ではない。
- 公開交換所 `wizard_equipment_exchange` で通常装備と状態変化素材を販売する。対価は既存のスキルジェム原石(無印)とGold。提案中の新規地域やボスを入手条件にはしていない。

作成日: 2026-10-01。これは追加候補を比較するための企画案。装備・スキル・敵・素材・物語の新規名称と数値は提案であり、採用済み仕様ではない。

**5つのビルドを、同じ更新帯の武器・防具・アクセサリと、選択式の超希少スキルブックで成立させる。最終装備は強化上限60、状態変化2回で完成する。**

- 武器は攻撃の得意分野、防具は戦い続ける方法、アクセサリは数値配分、スキルブックは主力スキルの使い方を変える。
- ブックを引けなくても各ビルドは成立する。希少品は「その技を大幅に強化するご褒美」とし、標準攻略の必須品にしない。
- 一式を強制しない。火の杖に氷の防具、雷のアクセサリにアーケインのMP装備、といった組み合わせも選べる。原案では強制セット効果を設けない方針だった。今回の実装は上記メモの2点/4点効果に従う。
- 以下のLvは**プレイヤーレベル**。ウィザードの職業レベル、装備の強化レベル、スキルレベルと区別する。

- iconは部位共通ではなく講座と品名に合わせ、時計=CLOCK、導火石=FIRE_CHARGE、氷鍵=TRIAL_KEY、銅鈴=BELL、割れた窓=GLASS_PANEなどを選んだ。同じ講座の同じアクセサリはLv40～100で図柄を引き継ぎ、段階更新と分かるようにした。既存使用済iconの再利用は、時計、針、研究頁、定規、炉核、氷片、栞・札、銅、封蝋、結晶種など名前がその形・素材を直接指す場合に限る。

Lv15〜85品は今回の標準案では状態変化を持たない。Lv100系列の**武器・補助・防具4部位・アクセサリ5種類の全て**と、10種の希少スキルブックにrank1/2を用意する。Lv120で表の一式を完成させた場合、重複装着するアクセサリ個体も含めて全装備が強化+60・rank2になる。

Lv100原装備は1マスタにつき3状態。Lv110/120の行は新しいドロップ品ではなく同じ個体の変化後を表す。変化直後の強化はそれぞれ+20/+40のままで、表の+40/+60の能力へは追加強化が必要。

### 3.2 能力表の読み方

- 「入手時」はrank0/+0の固定能力。「完成時」はその行のrank・強化上限へ達した能力。Lv110/120行の「原装備」は共通のLv100/rank0/+0を示す。
- 表のHP/MPは**最大値の加算**。既存の職業・スキルツリー・他装備を含んだ最終値ではない。防御と魔防もそれぞれ独立した加算。
- `pt`は割合ステータスへの加算ポイント。火増+8ptは火属性ダメージ増加へ8を加える提案であり、最終ダメージ全体を別枠で1.08倍にする意味ではない。
- 魔攻・知力・HP・MP・防御・魔防・MP回復力は、**1強化ごとにその装備の入手時値の1%を固定加算**。割合ステータスと移動速度は強化で増やさない。強化しても装備の用途は変わらない。
- 例: Lv100のアステリオンの星炉杖は魔攻787.5。+20は945、+40は1102.5、+60は1260。rank自体による数値の二重加算はない。
- 入手時値を小数第1位で確定し、その値の1%を各段階へ累積する。完成時の表示は小数第1位へ四捨五入。YAML化では各段階の差分と累積値を照合する。
- 武器は全て片手杖。補助装備を1個併用できる。補助装備の本型アイコンもスキルブック枠とは別。
- 店舗・素材交換の標準品は固定能力。レアリティはLv15〜25がRARE、Lv40〜85がEPIC、Lv100系列はLEGENDARY案。希少性だけで二つ先の更新帯の能力を与えない。

### 3.4 数値予算の位置づけ

低Lvの既存杖・防具を起点に、ビルド同士の比率を比較できる仮予算を置いた。各更新の間隔が異なるため、Lv25→40などの装備単体増加を「15〜25%の総合戦闘性能向上を満たした」と解釈しない。Lv100/+20→Lv110/+40→Lv120/+60では、強化対象の固定能力は16.7%、14.3%ずつ増加するが、実DPSは知力・属性・防御・MP収支・スキル回転を含めて別途測る。

Lv40以上の同格MobのHP・防御が未定なので、以下の絶対値は試作開始値。実際のTTKを保証するものではない。高Lv曲線を決めた後は、系統間の強弱と部位ごとの役割を保ったまま実数予算をまとめて合わせる。

## 4. 武器・補助・防具・アクセサリの個別案

各系統の装備表は同じ9更新段階を掲載する。アクセサリの種類数は5、装備可能数は9。タリスマン・チャーム・レリックは同名品をそれぞれ2/3/2個使った場合まで予算に含める。重複品を揃えることも、別系統の品へ差し替えることも可能。

### 4.1 落星の継承者

**モチーフ:** 天文学・星炉・帰還を待つ灯火。登場人物名・物語は新規案。

天文学者アステリオンは落ちた星を炉に閉じ込め、海の向こうへ旅立った弟の帰還灯にした。灯りを強めるほど星は町を焦がす。最後の装備は、破壊の炎を自分で選んだ一点へ収めるための道具になる。

**コンセプト:** メテオの着弾を作り、燃焼と小型メテオで範囲を焼く。大きな一撃とMP消費を引き受ける攻撃型。

**得意:** 密集した敵、予告を読める固定ボス、短い攻撃可能時間。**弱点:** 着弾前の移動、火耐性、MP枯渇、接近される場面。

**基本連携:** シンダーランスで燃焼 → メテオの予告位置へ誘導 → バーンメテオストライク。氷を1枠採りライムノヴァの熱衝撃を挟む型も成立。

### 4.2 冬の記録者

**モチーフ:** 氷の図書館・封じた記憶・解ける時間。登場人物名・物語は新規案。

司書ネーヴァは失われる記憶を氷の本へ保存した。しかし保存した時間は二度と先へ進まない。装備の成長は、守ることから、記憶を解放して仲間を未来へ送り出すことへの変化を描く。

**得意:** 接近する群れ、被弾しながら戦う探索、MPを温存した長期戦。**弱点:** 拘束が効きにくいボス、純単体火力、遠方からの高速攻撃。

**基本連携:** シンダーランス → ライムノヴァ（燃焼相手1.4倍） → 状態異常相手のエレメンタルボール。火を抜き、冷気付与とセルフヒールで生存する純氷型も可能。

### 4.3 雷路の郵便屋

**モチーフ:** 嵐の送電網・銅線・届ける手紙。登場人物名・物語は新規案。

郵便屋ヴォルタは嵐で途絶えた橋を銅線でつなぎ、一通だけ残った手紙を届けようとした。雷を武器にするのは速く殺すためだけではない。成長の終点は、途切れた道のすべてを結び直すこと。

**コンセプト:** ストームチェインとイミュレートスパークで敵の分散に対応し、移動と短い回転で隙を拾う。MP不足ならライトニングストライクを外す判断が強み。

**得意:** 散開した群れ、短い隙が多い戦闘、移動しながら再照準する場面。**弱点:** 高額MP追撃の連発、薄い防御、単一目標しかいない場面。

**基本連携:** ストームチェイン → イミュレートスパーク → マナサイフォン。敵が密集するときは追撃パッシブを採り、長期戦は追撃を外してMPを残す。

### 4.4 沈黙時計の研究者

**モチーフ:** 無音の時計・蓄えた魔力・決断の一秒。登場人物名・物語は新規案。

時計師セプティマは決められなかった一秒を魔力に換えて保存した。時計は動かず、研究だけが増えた。最終装備は、永久に蓄えるためでなく、必要な瞬間に蓄積を使い切るための時計になる。

**コンセプト:** MPを高く保ってアーケインオーバーロードを増幅し、アーケインランスを長い射程から通す。攻撃する前のMP残量を自分で作る単体寄りの型。

**得意:** 状態異常が効きにくい敵、硬い単体、長い直線の射撃機会。**弱点:** MP60%未満での連打、長い詠唱、継続被弾、広く散った敵。

**基本連携:** マナサイフォン → MP比率を確認 → アーケインオーバーロード → アーケインランス。サイフォンの空振り回復はない。

### 4.5 割れた虹の庭師

**モチーフ:** 光学・割れたステンドグラス・虹を育てる庭。登場人物名・物語は新規案。

庭師イリスは割れた聖堂の窓を拾い、破片を花のように並べた。虹を一本の光へ戻すことを求められても、彼女は違う色が残る庭を選ぶ。最後の装備は、割れたものを同じ形へ戻さず、違いを組み合わせる思想そのもの。

**コンセプト:** エレメンタルプリズムへ安価な対応弾を入力し、敵数に応じた屈折を使う。プリズムコンディションとMP軽減を合わせる設置型。

**得意:** 位置を選べる長期戦、敵の集団と単体を交互に相手にする場面、低消費の運用。**弱点:** 頻繁な移動、壁で入力が遮られる場所、プリズム照準の失敗、属性を一つに固定する戦闘。

**基本連携:** プリズム設置 → ダートをプリズムへ入力 → 必要な状態異常は敵へ直接当てる → コンディションの陣へ移動。ボールはプリズムに吸わせるか、状態異常敵へ直接当てるかを選ぶ。

## 5. 超希少スキルブック10案

### 5.1 共通ルール案

1. 1冊につき専用パッシブを1種内包する。最大スキルLvは1。職業やツリーで覚えた主力技を別に必要とし、ブックは主力技を自動習得させない。
2. 第1候補はプレイヤーLv40以上、第2候補はLv70以上。現在職業ウィザード・職業Lv1以上。ブックは最初rank0/+0で入手し、強化上限20。Lv110帯の素材でrank1/上限40、Lv120帯の素材でrank2/上限60へ進む。
3. 専用パッシブの習得素材は、第1候補が「星暦院の研磨原石」5個、第2候補が8個。この素材名・供給先も新規案。能力段階はスキルLvではなく、装備中のブックのrank0/1/2から解決する**新規挙動**。
4. 専用パッシブはバインド必須で1枠を使う。ブックを外したら使用許可・連動効果を失う。習得済みスキル個体は残り、再装備時に使える。
5. 表の火力例は対応する既存スキルが最大Lvの場合。低スキルLvでも主力の現在倍率を使い、最大Lvへ勝手に置換しない。`R`はその攻撃の解決魔法攻撃力。追加倍率は防御等の計算前のスキル倍率で、実ダメージの固定値ではない。
6. 追加攻撃は管理対象MobへのPvEのみ。壁・射程・同一敵上限を守る。追加攻撃自体は燃焼/冷気/感電を付けず、燃焼/感電追撃、ブック蓄積、MP回復陣、別のブック効果を起動しない。会心等の通常攻撃補正は採用時に個別監査し、追加攻撃の無限連鎖を作らない。
7. ブック独自のMP追加消費は既存の主力消費と別に明示する。主力消費後に不足したら主力だけが通常発動し、追加効果を起こさない。既存の燃焼MP28・感電MP56の追撃はそれぞれ別に支払う。MP軽減を適用する場合も、各支払いの時点を揃える。
8. ブックの取り外し・死亡・退出・ロードアウト切替で専用の蓄積と未発生の追加攻撃を解除する。装備変更で内部CDをリセットしない。支払済みMPは返還しない。主力技そのものの既存処理と、ブック由来の追加処理を区別する。
9. 1枠なので同じ系統の2冊も同時に使えない。「主力を二つとも全面強化」ではなく、どちらを主役にするかを選ぶ。

### 5.12 三色を残す庭師の日記

### 5.13 ドロップ設計

- 超低確率は**1冊ごとに、指定ボスの有効報酬1回につき基礎0.02%（1/5,000）**。10冊合計の確率ではない。一つの抽選に10冊を同時に載せない。
- 確率は独立抽選。ドロップ補正なしでは5,000回でも1冊以上を得る確率は約63.2%で、保証はない。ドロップ増加・幸運を使う現行経路へ載せる場合の実効確率は補正後の値を別に表示する。
- ブックがない状態を標準の戦闘難度にする。対象技の係数は大幅に伸ばす一方、内部CD・追加MP・準備条件によって全体ローテーションの伸びを制限する。
- 初期試作の受入目標は、条件を揃えた60秒単体戦でブックなし同等装備比の実DPS+20〜35%以内。群れ専用の七路便覧は同数の敵に対する総ダメージで別評価する。これらは目標で、達成済みの数値ではない。
- 10冊とも取引可能の原装備として供給する案。個体を強化・状態変化でき、技能の習得は所有者ごと。完成品取引の可否は既存経済に照らして採用時に決める。
- 同じブックをもう一度引くことを状態変化素材に要求しない。超希少品を得た後の育成は通常の攻略で進められるようにする。

### 6.2 強化確率案

rank0の武器・防具は現行の標準成功率を使う: +1は100%、+2〜4は75%、+5〜6は50%、+7〜8は35%、+9は20%、+10〜20は5%。失敗時は`NONE`、強化値を失わない案。補助・アクセサリ・ブックは今回も同じ確率へ合わせる。

状態変化後に新たに開く+21〜40、+41〜60は、各段階の成功率を20%とする案。高い強化値ほど永久に難しくし続けず、状態変化を攻略の節目として扱う。すでに通った+1〜20の率は上書きしない。第一変化で+0へ戻ることも、第二変化で+20へ戻ることもない。

失敗時に値を失わない前提では、最終原装備1個を+0→20にする期待試行数は約239.7回（1＋3÷0.75＋2÷0.5＋2÷0.35＋1÷0.2＋11÷0.05）、+20→40と+40→60は各100回。計約439.7個の強化オーブ／1個、16個なら約7,035個。ブックを早期に+20にした分は引き継ぐ。この供給量を支えられない場合はrank0後半の確率を調整する設計判断が必要で、完成済みバランスと呼ばない。

## 9. 採用前に行う調整・実装の範囲

### 9.1 今回具体化した内容

- 5系統×7原装備帯×11種類＝**385種の通常装備原案**。Lv110/120の変化名と完成能力を別途記載した。変化後を別原装備として数えない。
- 10冊の超希少ブック、10種の専用パッシブ、rank別の能力・追加MP・内部CD・状態変化名。
- プレイヤーLv15/25/40/55/70/85/100と、110/120での2回の状態変化。Lv120一式は全16個がrank2/+60。
- 各部位の入手時能力と完成時能力、装着可能数を含む一式比較、4つの混成例。
- 新規モチーフ・登場人物・9段階の物語、入手場所・素材・超希少確率・強化育成費用の案。

### 9.2 マスタ定義で表現する部分

既存statusによる固定能力、片手杖と補助、アクセサリタグ、必要Lvと職業条件、段階別強化差分、rank1/2の名称と上限、状態変化の素材・通貨、ブックの`usableSkills`は既存の仕組みに沿って定義する。実際のIDは今回割り当てない。

### 9.3 新しいスキル実装が必要な部分

ブックrankに連動したパッシブ性能、特定技への追加攻撃、発動単位の蓄積、ブック独自の支払い、内部CDの装備変更越し保持、凍結上限とボス除外、追加攻撃からの再帰トリガー除外はPlugin実装が必要。`usableSkills`だけ書けば実現する能力とはしない。特定技の強化を武器やアクセサリの未定義パラメータへ紛れ込ませない。

### 9.4 未確認・調整対象

1. Lv40〜120の同格Enemy/BossのHP・有効防御・属性耐性・必要MP継続時間は未確定。ここを定め、標準装備とブックなしでTTK・耐久時間を確認する。
2. 表の装備加算を職業・ツリーの成長へ重ね、知力と魔攻の積による過剰成長、移動速度上限、詠唱/CD/消費軽減の合計を確認する。装備表だけで最終強さを確定しない。
3. ブックは対象技の係数と、60秒ローテーションの実DPSを分けて測る。単体・5体・7体、付与耐性あり、MP不足、遮蔽、敵移動、詠唱中断を試す。
4. 追加攻撃の発動処理、追加MP、内部CD、装備解除・死亡・退出を実装した後に検証する。特に返雷と三彩の再帰、プリズムの元弾置換、状態異常付与パッシブの二重発火を確認する。
5. 0.02%の希少率、通常装備の交換量、強化オーブ約7,035個という完成負荷、状態変化費用は経済の供給量に照らす。引けない人にも装備更新が進むことを確認する。
6. Lv110/120素材の取引可否とコンテンツ参加Lvを決める。現行の状態変化で必要Lvが変わらない以上、素材取引を許すと早期完成の可能性がある。この案では進行時期を保証済みとはしない。
