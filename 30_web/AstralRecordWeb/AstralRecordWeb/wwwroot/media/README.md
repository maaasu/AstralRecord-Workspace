`astral-nebula-1280.mp4` / `astral-nebula-640.mp4`

- 元作品: [The Horsehead Nebula in Infrared Light](https://svs.gsfc.nasa.gov/30679), NASA Scientific Visualization Studio, 2015-09-25。
- 元ファイル: https://svs.gsfc.nasa.gov/vis/a030000/a030600/a030679/horsehead_ir-b-1920x1080p30.webm
- クレジット: NASA, ESA, and G. Bacon, T. Davis, L. Frattare, Z. Levay, and F. Summers (Viz 3D Team, STScI)。サイトのフッターにも表示する。
- 利用条件: [SVS FAQ](https://svs.gsfc.nasa.gov/help/) は特記のないコンテンツを public domain とし、利用・再配布を認めている。元作品に別条件の記載なし。確認日: 2026-10-26。
- 加工: 元映像の4〜20秒を切り出し、終端1秒を先頭1秒へクロスフェードし、先頭1秒を除いて15秒のループにした。音声なし。H.264/yuv420p、24fps、faststart MP4。PC用1280×720、モバイル用640×360。サイト上では色調と合成を調整する。
- 制作チームによる星雲の3D可視化映像であり、ゲーム内映像ではない。NASA等による当サイトの推奨を示すものではない。

`astral-galaxy-1280.mp4` / `astral-galaxy-640.mp4`

- 元作品: [Active Galaxy Hercules A: Visible & Radio Comparison](https://svs.gsfc.nasa.gov/30680/), NASA Scientific Visualization Studio, 2015-09-25。
- 元ファイル: https://svs.gsfc.nasa.gov/vis/a030000/a030600/a030680/hercules_a-b-1920x1080p30.webm
- クレジット: NASA, ESA, and Z. Levay, F. Summers, G. Bacon, T. Davis, and L. Frattare (Viz 3D Team/STScI)。
- 利用条件: [SVS FAQ](https://svs.gsfc.nasa.gov/help/) の public domain の案内と元作品のクレジットを確認。確認日: 2026-11-05。
- 加工: 元映像の16〜32秒を切り出し、終端2秒を先頭2秒へクロスフェードし、先頭2秒を除いて14秒の無音ループにした。H.264/yuv420p、24fps、faststart MP4。PC用1280×720、モバイル用640×360。
- スキルツリー編集の見出しで使用する。可視光と電波観測をもとにした可視化で、ゲーム内映像ではない。

元の高解像度動画や加工ツールはリポジトリに含めない。配信時は同一オリジンの上記MP4だけを使用し、外部サイトへ動画の再生リクエストを送らない。
