# Web Pages Prompt

## 読むタイミング

- Razor Page を追加するとき
- 既存ページの UI / 導線 / データ取得を変えるとき
- ページ配置や責務分割に迷うとき

## 必須ルール

- `.cshtml` と `.cshtml.cs` をセットで扱う。
- ページ固有の責務はそのページに閉じる。
- 既存のレイアウト、命名、導線と大きくずらさない。

## 更新チェックリスト

1. ページの責務が明確か確認する。
2. API 呼び出しがあるなら契約・認証の影響を確認する。
3. 導線変更があるならメニューや遷移元も見直す。
4. README や運用資料の更新が必要か確認する。

## 非推奨

- 他ページのロジックを直接流用して責務を曖昧にすること
- API 契約変更を前提にした画面変更を片側だけで進めること
