# エリヴァ南西街道の野外Mobマスタ

## 対象と配置境界

`eriva_supercontinent` の南西街道に、Lv.15からLv.45まで3レベル刻みで草原・森林の2環境を用意する。各段階に2種の既存Enemyを混ぜたスポナーマスタを1件ずつ、計22件定義する。スポナーの座標は静的マスタに含めない。北東の将来Lv.100以上の領域には登録しない。

| Lv | 草原（weight） | 森林（weight） |
|--:|:--|:--|
| 15 | グラスボア70 / 疾風の草狼30 | 下草の狩人60 / 星角の森守40 |
| 18 | グラスボア65 / 迷彩ゾンビ35 | 下草の狩人60 / 星角の森守40 |
| 21 | グラスボア55 / 迷彩ゾンビ45 | 下草の狩人60 / 星角の森守40 |
| 24, 27, 30 | クサハウンド60 / 迷彩ゾンビ40 | コケギツネ60 / ネッコガメ40 |
| 33 | ハラノヒツジ55 / カゼトカゲ45 | コケギツネ60 / ネッコガメ40 |
| 36, 39 | ハラノヒツジ55 / カゼトカゲ45 | コノハフクロウ55 / コカゲハリネズミ45 |
| 42, 45 | カマキリソード75 / イワセバイソン25 | トゲシカ55 / コカゲハリネズミ45 |

スポナーIDは `eriva_westroad_<grass|forest>_lv<level>_spawner`。全件の `radiusMeters: 64`、終日、`spawnIntervalTicks: 100`、`spawnChancePercent: 100.0`、`maxAlivePerSpawner: 6`、`maxNearbyMobs: 12`、`spawnPerPlayer: 1` を共通にする。`maxAlivePerMob` は指定せず、既定の0（Mob ID単位の上限なし）とする。地域表示は全レベル・両環境で `エリヴァ南西街道` とする。レベルはモブや配置計画のレベル欄に表示し、エリア名には含めない。実配置は道路距離300mごとに3レベル上げる。現行の開始接続道路は最大1,488mのためLv.15～27を使い、Lv.30～45のマスタは後続用として保持する。

半径64mはPlayer検出・周辺Mob計数・出現位置探索にも使われる。探索には道路やバイオームの除外条件がない。配置時は街道・安全地帯・隣接環境・北東側へ円が掛からないか地図と現地で確かめる。近接する複数スポナーの目標数は独立で、周辺上限は発生地点の円内で判定される。静的定義だけでは街道上の遭遇密度を保証しない。

## レベル別値の作り方

既存の親 `baseStats`、既存 `levels[]`、報酬参照を保持する。スポナーから必要なレベルが未登録の場合に限り、同一Mobの既存プロファイルを補う。

- 両側に既存プロファイルがあるレベルは各実数statusと `drops.exp` を線形補間し、整数へ丸める。例: Lv.44と46のカマキリソードからLv.45のHP `33,300`、ATTACK `7,038`、DEFENSE `6,156`、EXP `740`。
- 既存範囲の上側は最後の2プロファイルの1レベルあたりの差分を延長する。例: Lv.26と28のクサハウンドからLv.30を作る。Lv.45までの延長は同一Mobの既存Lv.40/42など近い値から行う。
- 既存レベルが1つだけの星角の森守・下草の狩人は、Lv.15/20/25/30のMob基準値を区間内で直線補間した比率を親値へ掛ける。`MAX_HEALTH`はHP、攻撃系はR、`DEFENSE`はDの比率を使い、EXPは1レベルにつき20増やす。Lv.30超の正式アンカーは設計されていないため、必要な局所比較ではLv.30基準から1レベルにつき1.052倍を仮置きする。割合系・移動速度・SHIELD_BREAKは固定する。
- `levels[].baseStats` はリストごと上書きされるため全statusを記載する。`levels[].drops.exp` は親の `items` と `lootTable` を継承する。新たな報酬参照は作らない。Mobの `progression` は標準遭遇順でありPlayer Lvではないため、レベル範囲の延長だけで変更しない。新スポナーの `progression` は出現Mobの最大値とする。

## 理論値の事前確認

Lv.15～30のPlayer/Mobアンカーは `00_docs/60_戦闘バランス設計書/02-成長曲線.md` に従う。Lv.30超のPlayer HP・R・Dだけは比較用にLv.30値から1レベルごと1.052倍を仮置きする。無属性・会心/Shieldなし、Player命中92%、最終倍率130%、skill込みDPSは通常攻撃の1.6倍とし、共通防御式 `max(0, 1 - D / R / 2.5)^(log(0.5)/log(0.6))` で試算した。耐久時間はMobの通常攻撃のみ、命中91.5%で算出する。通常攻撃Rは攻撃種別に合う補正だけを含める。星角の森守は近接型なので `MAGIC_ATTACK` を通常攻撃へ加算しない。

| 対象 | Lv | HP / 攻撃R / 防御D | 理論TTK | Player理論耐久 |
|:--|--:|:--|--:|--:|
| 星角の森守 | 15 | 4,400 / 760 / 767 | 6.0秒 | 9.9秒 |
| 星角の森守 | 21 | 9,000 / 1,555 / 1,568 | 6.0秒 | 9.9秒 |
| クサハウンド | 30 | 18,050 / 3,613 / 2,984 | 5.2秒 | 9.9秒 |
| ネッコガメ（耐久役） | 30 | 21,850 / 2,755 / 3,650 | 7.6秒 | 17.4秒 |
| カマキリソード | 42 / 45 | 30,060 / 6,353 / 5,555 → 33,300 / 7,038 / 6,156 | 4.8 / 4.4秒 | 9.0 / 9.9秒 |
| イワセバイソン（少数耐久役） | 42 / 45 | 81,928 / 7,758 / 7,153 → 94,096 / 8,911 / 8,216 | 16.6 / 16.1秒 | 10.1 / 10.3秒 |

Lv.42/45の試算は正式な成長アンカーではない。専用技、移動、複数同時接敵、地形、装備更新を含まない。Devでの配置後の実戦確認では同格装備でTTK・耐久と円内の同時接敵数を測り、共有公開前に必要なら配置数・weight・密度を調整する。

## 運用への受け渡し

このパッケージはMob/スポナーマスタのみを追加・補完する。`mob_spawners.yml` の実座標登録、DevへのFilebase公開・seed・API再読込は別工程とする。既存スポナーIDは変更しない。
