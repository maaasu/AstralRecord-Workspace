# エリヴァ南西街道の野外Mobマスタ

## 対象と配置境界

`eriva_supercontinent` の南西街道に、Lv.15からLv.45まで3レベル刻みで草原・森林の2環境を用意する。各段階に2種の既存Enemyを混ぜたスポナーマスタを1件ずつ、計22件定義する。スポナーの座標は静的マスタに含めない。北東の将来Lv.100以上の領域には登録しない。

| Lv | 草原（weight） | 森林（weight） |
|--:|:--|:--|
| 15 | グラスボア70 / 疾風の草狼30 | 下草の狩人60 / 星角の森守40 |
| 18 | グラスボア65 / 迷彩ゾンビ35 | 下草の狩人60 / 星角の森守40 |
| 21 | グラスボア55 / 迷彩ゾンビ45 | 下草の狩人60 / 星角の森守40 |
| 24, 27, 30 | クサハウンド60 / 迷彩ゾンビ40 | コケギツネ60 / ネッコガメ40 |
| 33 | ハラノヒツジ55 / カゼトカゲ45 | コケギツネ60 / ネッコガメ40 |
| 36, 39 | ハラノヒツジ55 / カゼトカゲ45 | コノハフクロウ55 / コカゲハリネズミ45 |
| 42, 45 | カマキリソード75 / イワセバイソン25 | トゲシカ55 / コカゲハリネズミ45 |

スポナーIDは `eriva_westroad_<grass|forest>_lv<level>_spawner`。全件の `radiusMeters: 64`、終日、`spawnIntervalTicks: 80`、`spawnChancePercent: 100.0`、`maxAlivePerSpawner: 12`、`maxNearbyMobs: 24`、`spawnPerPlayer: 2` を共通にする。1人あたりの維持目標を1体から2体へ増やし、最大6人分を12体まで維持する。周辺上限も24体に増やし、重なったスポナーの目標を過度に抑えない。補充判定を5秒から4秒へ短縮する。`maxAlivePerMob` は指定せず、既定の0（Mob ID単位の上限なし）とする。地域表示は全レベル・両環境で `エリヴァ南西街道` とする。レベルはモブや配置計画のレベル欄に表示し、エリア名には含めない。実配置は道路距離300mごとに3レベル上げる。現行の開始接続道路は最大1,488mのためLv.15～27を使い、Lv.30～45のマスタは後続用として保持する。

半径64mはPlayer検出・周辺Mob計数・出現位置探索にも使われる。探索には道路やバイオームの除外条件がない。配置時は街道・安全地帯・隣接環境・北東側へ円が掛からないか地図と現地で確かめる。近接する複数スポナーの目標数は独立で、周辺上限は発生地点の円内で判定される。静的定義だけでは街道上の遭遇密度を保証しない。密度を増やした分、Devで円内総数と同時接敵数を確認する。

## レベル別値の作り方

既存の親 `baseStats`、既存 `levels[]`、報酬参照を保持する。スポナーから必要なレベルが未登録の場合に限り、同一Mobの既存プロファイルを補う。

- 両側に既存プロファイルがあるレベルは各実数statusと `drops.exp` を線形補間し、整数へ丸める。例: Lv.44と46のカマキリソードからLv.45のHP `33,300`、ATTACK `7,038`、DEFENSE `6,156`、EXP `740`。
- 既存範囲の上側は最後の2プロファイルの1レベルあたりの差分を延長する。例: Lv.26と28のクサハウンドからLv.30を作る。Lv.45までの延長は同一Mobの既存Lv.40/42など近い値から行う。
- 既存レベルが1つだけの星角の森守・下草の狩人は、Lv.15/20/25/30のMob基準値を区間内で直線補間した比率を親値へ掛ける。`MAX_HEALTH`はHP、攻撃系はR、`DEFENSE`はDの比率を使い、EXPは1レベルにつき20増やす。Lv.30超の正式アンカーは設計されていないため、必要な局所比較ではLv.30基準から1レベルにつき1.052倍を仮置きする。割合系・移動速度・SHIELD_BREAKは固定する。
- `levels[].baseStats` はリストごと上書きされるため全statusを記載する。`levels[].drops.exp` は親の `items` と `lootTable` を継承する。新たな報酬参照は作らない。Mobの `progression` は標準遭遇順でありPlayer Lvではないため、レベル範囲の延長だけで変更しない。新スポナーの `progression` は出現Mobの最大値とする。

## 戦闘値の調整と事前確認

西街道スポナーが参照する通常Enemy 15種のLv.15～45の `ATTACK` を約半分（端数は切り上げ）にする。親 `baseStats` がこの範囲のレベルに使われる場合も同様に調整し、Lv.46以上のプロファイルとHP・防御・報酬・技設定は維持する。解決攻撃力は `ATTACK` と攻撃種別の加算値を足すため、星角の森守の `MAGIC_ATTACK` と下草の狩人の `RANGED_ATTACK` も半減して、それぞれの技の攻撃力も概ね半分にする。通常攻撃と技の被ダメージは実戦で別々に確認する。

| 対象 | Lv | ATTACK 変更前 → 変更後 |
|:--|--:|--:|
| 星角の森守 | 15 / 21 | 760 → 380 / 1,555 → 778 |
| クサハウンド | 30 | 3,613 → 1,807 |
| ネッコガメ | 30 | 2,755 → 1,378 |
| カマキリソード | 42 / 45 | 6,353 → 3,177 / 7,038 → 3,519 |
| イワセバイソン | 42 / 45 | 7,758 → 3,879 / 8,911 → 4,456 |

従来のPlayer理論耐久時間は攻撃力と同時接敵数の変更後に使えないため、再計算前の値を掲載しない。Lv.30超のPlayer成長アンカーも未確定である。Dev配置後、同格装備で通常攻撃・技の被ダメージ、TTK、円内の総Mob数と同時接敵数を測り、共有公開前に必要なら配置数・weight・密度を調整する。

## 運用への受け渡し

このパッケージはMob/スポナーマスタのみを追加・補完する。`mob_spawners.yml` の実座標登録、DevへのFilebase公開・seed・API再読込は別工程とする。既存スポナーIDは変更しない。
