# AstralRecord マスタデータエディタ

## 起動

1. ZIP 内の `AstralRecordMasterEditor-win-x64` をワークスペースの `60_tool/05-master-data-editor/dist/desktop/` に展開します。更新時はエディタを閉じ、同じ場所のアプリフォルダーごと差し替えます。
2. `AstralRecordMasterEditor.exe` を起動します。
3. 初回は `40_filebase`・`10_plugin`・`60_tool` のある AstralRecord ワークスペースを選びます。

次回からは前回のワークスペースを開きます。Windows 標準のタイトルバーにアプリ名とワークスペースを表示します。その下の操作ヘッダにある「ワークスペース」から選び直せます。

操作ヘッダ中央の検索窓は Ctrl+P でも開けます。Filebase全体を名前・ID・ファイル名・パスで検索し、上下キーとEnter、またはクリックで対象を開きます。空白区切りで複数語検索、Escで閉じます。開くたびに候補を更新し、フォルダや詳細フィルターの設定は保持します。
EXE と同じフォルダーの DLL・`wwwroot`・`tool-host` も必要です。EXE だけを移動しないでください。
ZIP にマスターデータや接続先設定は含まれていません。選んだワークスペース内のファイルを編集します。

日本語フォームの名前や説明文の欄をクリックするか文字を入力すると、既存マスターと入力履歴から予測候補が表示されます。候補をTabで採用すると、入力済みの文字を残したまま末尾に追記します。Escで候補を閉じ、Ctrl+Zで追記を取り消せます。Ctrl+Spaceでもローカル候補を開けます。

「AIアシスト」の「入力補完」で「候補がないときにLunaで補完」をオンにすると、文字を変更してローカル候補がない場合に、対象欄のテキストと項目情報をOpenAIへ送り、推論なしの`gpt-6-luna`で続きを提案します。作成・一括編集では、対象や参考の原稿と関連する定義もOpenAIへ送ります。採用した候補は下書きに入り、通常の検証・保存操作で反映します。予測変換の設定と入力履歴、画面で入力したAPIキーは起動中だけ有効です。

再起動後もAI接続を使う場合は、起動環境の`OPENAI_API_KEY`、または選択ワークスペースの`60_tool/05-master-data-editor/src/SkillTreeEditor.Server/appsettings.local.json`に`SkillTreeEditor:Ai:ApiKey`を設定します。キーをGitへ登録しないでください。作成・一括編集の既定モデルは`gpt-6.1-terra`で、画面の設定または`SkillTreeEditor:Ai:Model`で変更できます。

Windows x64 向けで、.NET は同梱しています。`webview2` フォルダーのある配布物は画面用ランタイムも同梱し、アプリ起動のための追加インストールは不要です。Node.js や .NET SDK もマスタ編集には不要です。ローカルディスクへ展開してください。
`webview2` を省いた軽量ビルドは、PC に Microsoft Edge WebView2 Runtime が必要です。未導入の場合は [Microsoft の配布ページ](https://developer.microsoft.com/microsoft-edge/webview2/)を参照してください。
同梱ランタイムは ZIP の更新時に更新します。Windows 10 では起動時に同梱ランタイムのフォルダーへ、Microsoft が要求するアプリパッケージ向け読み取り権限を設定します。

## マスタ編集

固定のグレー配色です。ボタン・入力欄・タブ・パネルは角の丸みと余白を統一し、保存・実行などの主要操作を青で示します。表示名・レアリティなど意味のある色とアイコンは保持し、カラーコードは同じ入力欄で確認できます。
「データ・配置編集」からマスターデータ・スキルツリー・ワールド配置を編集し、「設計・分析」から装備・入手経路と比較・成長グラフを利用できます。装備・入手経路はビルド構成の編集、比較・成長グラフは保存済みマスターの分析を担当します。

ダンジョンは主要設定を全体表示し、モブ・報酬アイテムを名前とアイコン付きの一覧から追加できます。ビルド装備は「強化・付与」で＋値・エンチャントを設定し、下書きへ反映してから保存します。エンチャント付きプリセットのゲーム側適用には対応版Pluginが必要です。Devでは「01 Dev更新」で更新してください。
モブの一覧と参照には討伐記録と同じ頭アイコンを表示します。設定済みの項目は入れ子も展開して編集でき、名前や説明の入力欄も常に表示します。変更を破棄するときは共通デザインの確認画面を表示します。
「設計・分析」の「ゲーム進行フロー」では、ダンジョン・ショップ・アイテム・モブなどのマスター参照をノードとして置き、矢印でつないで進行を設計します。ショップのノードからは商品を購入アイテムとしてまとめて追加でき、ノードや矢印に対象職業を設定して職業フィルタで職業別の流れを確認できます。ノードを選ぶと、ドロップ品・出現モブ・ボス・クリア報酬・商品・入場ワールド・素材の使い道など、マスターのつながりから次（右）と前（左）に置く候補が点線で表示されます。Tab で次の候補、Shift+Tab で前の候補をまとめて配置し、候補をクリックすると1件ずつ配置します。Esc で隠し、上部の「候補」で表示を切り替えます。ノードは標準で種類ごとの形（ダンジョン=門形、ショップ=六角形、アイテム=角丸の四角、モブ=円、職業=ひし形、ワールド=八角形など）のアイコンと、その上の名前で表示し、上部の「カード」で補足まで見えるカード表示に切り替えます。図・ノード・矢印の右クリックで、その位置へのマスター追加、候補の配置、参照の変更、矢印のラベル変更・向きの反転・削除などを選べます。「テキスト」表示は参照先の名前を解決した一覧で、AI への受け渡しに使えます。保存先はワークスペースの `40_filebase/95.design.game_flow/` です。
保存前の検証とバックアップは従来と同じです。未保存の変更がある場合、アプリ終了・ワークスペース変更時に確認します。

ファイル一覧のシングルクリックはプレビューで開き、次のファイル選択で差し替えます。ダブルクリックまたは編集開始でタブを保持します。プレビューは斜体の名前と「プレビュー」表示で確認できます。アカウント進行プリセットの習得ノードは「スキルツリーで選択」から、その職業とプレイヤーレベルに対応する配置図で選びます。

## ビューの配置

各ビューのタブをドラッグして、左右・上下に分割したり、別のタブグループへ移動したりできます。マスタのフォルダ・ファイル・編集・検証も個別に配置できます。
操作ヘッダの「別ウィンドウで開く」、または各タブ列の窓アイコンから別ウィンドウ化できます。各パネルの「⋯」はそのパネルの分割・フロート・メイン画面への復帰・閉じる操作です。別ウィンドウを閉じるとビューはメイン画面へ戻り、入力内容を保持します。別ウィンドウも Windows 標準の枠で移動・最大化・サイズ変更できます。
操作ヘッダのサイドバーアイコン「編集ナビ」で編集ナビゲーションの表示を切り替えます。「パネル」メニューはデータ・配置編集、設計・分析、マスターの一覧・検証、ビルド・反映を分けて並べ、閉じたビューの再表示やレイアウトの初期化に使います。配置はワークスペースごとに保存します。
未保存の内容はビューを隠したり移動したりしても保持します。アプリ終了時には保存または破棄を選んでください。

## 計画・実行・結果

03・01・12は条件を指定して「実行」を押すと開始します。事前の計画作成や確認チェックは不要です。「実行計画を表示」で反映元・反映先を任意に確認できます。
16は計画を作成し、対象と運用条件を確認してから実行します。

| ツール | 処理 |
| --- | --- |
| 03 マスタ反映 | 既存の MasterDataOnly フローでマスタを反映 |
| 01 開発環境更新 | ビルド・テスト・配備・既存の更新フロー |
| 12 ネットワークプラグイン | Lobby・Proxy・Extension のビルドと JAR の収集 |
| 16 メンテナンス | ワールド・ネットワークプラグインの選択と既存のメンテナンスフロー |

計画の作成だけではサーバー停止、コピー、DB 更新を実行しません。
12 はビルドと出力先の確認で、サーバーへの配布は 16 で扱います。
実行ログと結果はアプリ内の実行履歴に保存されます。アプリを閉じても開始済みの処理は継続し、再起動して履歴から確認できます。
異なるツールは同時に開始でき、実行履歴では処理ごとに状態・ログ・入力待ちを確認できます。同じツールを再実行する場合は、先に開始した実行の終了を待ちます。Dev や配布先などの共有リソースを使う処理は、従来の BAT と同じワークフローのロックと Control の予約に従います。
サーバーの手動停止・起動など、既存のツールが要求する運用手順は実行画面の計画とログに従ってください。
失敗時は結果と既存の復旧状態を確認し、復旧方式を指定して再実行します。16は新しい計画の確認が必要です。

実行には、従来の BAT と同じ PowerShell 7、Java/Maven、.NET SDK、接続先設定、サーバー権限などが必要です。
ワークスペースの `60_tool/CONFIGURATION.md` と各ツールの README を参照してください。
ワークスペースの `*.local.json` を引き継ぎます。計画では設定元と反映元・反映先を確認してください。

## 設定とデータ

- アプリ設定・WebView2 キャッシュ・起動エラー: `%LOCALAPPDATA%/AstralRecord/MasterEditor/`
- 保存前バックアップ: ワークスペースの `60_tool/05-master-data-editor/.backups/`
- ツール実行履歴: ワークスペースの `60_tool/05-master-data-editor/.cache/tool-jobs/`
- 引数: `AstralRecordMasterEditor.exe --workspace "C:\AstralRecord-Workspace"`
- ワークスペースを選び直して起動: `AstralRecordMasterEditor.exe --select-workspace`

アプリ削除は展開フォルダーを削除します。ワークスペースのマスターデータ・バックアップ・実行履歴は別に保持されます。
