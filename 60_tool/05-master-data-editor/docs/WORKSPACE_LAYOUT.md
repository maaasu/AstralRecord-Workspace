# 作業領域の配置とサイズ調整

各編集ビュー、実行ツール、履歴に加え、編集ナビゲーション、マスターのフォルダ、ファイル・検索結果、エディタ、検証結果をパネルとして配置できます。タブをドラッグし、別のタブ列や領域の中央に重ねると同じグループに入ります。領域の端に重ねると上下左右に分割できます。分割したパネルのサイズは境界線をドラッグして調整します。

タブ列の「↗」は現在のパネルを別ウィンドウに移します。別ウィンドウの「↙」またはウィンドウを閉じる操作でメイン画面に戻ります。「⋯」には分割、画面内でのフロート、パネルの再表示、配置の初期化があります。Windows 版はタイトルバーの「表示」からも編集ナビゲーションの表示と初期配置への復帰を操作できます。ブラウザー版の「☰」は編集ナビゲーションの表示を切り替えます。

移動、タブの切替、非表示、再表示で編集中の内容を保持します。パネルの配置とサイズはワークスペースごとに保存し、次回起動時に復元します。ブラウザーが別ウィンドウの自動表示を制限する場合、そのパネルはメイン画面に戻ります。

編集ビュー内の一覧などには専用の境界線があります。境界線はドラッグ、Tabで選択したあとの左右または上下キーで調整できます。Shift併用で大きく動かし、ダブルクリックまたはEnterで初期サイズへ戻します。保存先が利用できない場合も調整できます。

参照元一覧、装備比較、クラス成長、戦闘分析、配置の前後比較、テレポーター一覧の表では、列見出しの右端を同じ操作で調整できます。見えていない列は表の中を横にスクロールすると表示できます。列幅は表の種類ごとに保存します。
テレポーター一覧では、広い画面で列幅を調整できます。「列幅をリセット」を押すと、保存された列幅を消去し、すべての列を初期の幅に戻します。狭い画面ではカードに切り替わり、表に戻ると調整済みの列幅を使います。

| 画面・領域 | 調整できる境界と表示の修正 |
| --- | --- |
| スキルツリー | 一覧・キャンバス・詳細の幅。左右のペインを広げてもキャンバスの最小幅を確保します。 |
| ノード一覧 | 未配置・配置済みの高さ。空の区分は最小限の高さとし、もう一方の一覧が残りの高さを使います。 |
| 比較・成長グラフ | 条件と結果の幅。それぞれ独立してスクロールでき、狭くした条件欄は項目を折り返します。 |
| ワールド配置編集 | 地図と配置一覧の幅。ウィンドウの残り高さを使い、一覧の固定された高さ上限を解消します。地図の表示設定・座標移動と反映手順は開閉し、地図を最初から表示します。 |
| 配置一覧 | 操作欄と一覧の高さ。長い検索説明は開閉でき、検索・詳細・一括操作と結果を別々にスクロールできます。 |
| AI配置案 | 地図と配置案の幅。固定幅の詳細欄を調整できます。 |

スキルツリーの横境界は980px以下、分析画面の境界は950px以下では一覧の開閉・ペイン切替・縦並びに切り替わります。ワールドは領域の幅が800px以下なら縦並びになります。非表示になった境界線の幅は、広い画面に戻したときに再利用します。
