# Android版の接続と操作

自分のAndroidスマートフォン・タブレットから、Windowsのエディタで開いているワークスペースを編集できます。「保存」でPCのファイルを更新し、コミットやプッシュはPCで行います。

## 初めて使うとき

1. PCとAndroid端末でTailscaleにログインし、同じプライベートネットワークに接続します。接続ルールを設定している場合は自分の端末からPCへのTCP 8443を許可してください。[Tailscaleのダウンロード](https://tailscale.com/download)
2. ワークスペース内の `60_tool/05-master-data-editor/dist/android/AstralRecordMasterEditor.apk` をUSBなどで端末にコピーし、端末で開いてインストールします。Androidが確認した場合は、このAPKを開いたファイル管理アプリにインストールを許可してください。更新も同じ署名のAPKを上書きインストールします。
3. PCでいつものエディタを起動し、上部の「Android接続」→「接続を開始」を押します。初回にTailscaleがHTTPSの有効化を求めた場合は「初回の設定」の案内に従います。
4. AndroidのカメラでPC画面のQRコードを読み取り、エディタアプリを開きます。接続先は手入力もできます。PCで「登録コードを発行」を押し、8桁の数字をアプリに入力してください。コードは5分間、1回だけ使えます。
5. 次回からはAndroid版のアイコンをタップします。登録時に端末内で生成した専用鍵で自動接続します。PCをスリープさせず、対象のワークスペースをエディタで開いておいてください。

## 端末で編集する

- スマホでは一覧で目的のファイルをタップして開きます。タブを保持すると別の原稿と行き来できます。編集したプレビューは自動で保持されます。タブレットは幅に応じて一覧と編集を並べて表示します。
- アカウント進行プリセットでは、対象レベルの「スキルツリーで選択」を開きます。職業とレベルに合うツリーを指で移動・拡大し、ノードをタップして「選択を反映」を押します。ファイルへ保存する前に変更を確認できます。
- Androidの「戻る」で開いているダイアログを閉じたり、編集画面から一覧に戻ったりできます。保存競合が表示された場合は端末の下書きとPCの最新原稿を比較してください。

## 接続を管理する

- 「接続を停止」はこのワークスペースのAndroid受付と、エディタ用のTailscale転送を止めます。PCのエディタを閉じるときもこの転送を止め、次回同じワークスペースを開いたときに受付を再開します。「登録済みの端末」で端末を選んで登録を解除すると、その端末は再登録が必要になります。機種変更や紛失の際に使います。
- 接続先はPCのTailscale HTTPSアドレスの8443番です。Tailscale Serveがローカルの `127.0.0.1:5285` に転送します。HTTPS・MagicDNS・端末側のTailscale接続・PC側の受付状態を確認してください。Serveの設定を手動で取り除くときは、そのポートがエディタ専用であることを確認し、`tailscale serve --https=8443 off` を実行します。[Tailscale Serve](https://tailscale.com/docs/reference/tailscale-cli/serve)
- アプリの秘密鍵はAndroid Keystoreに保存します。QRコードには接続先だけが入っています。端末登録とマスタの版確認はワークスペースごとです。PCの配布・更新ツールはWindows版から操作します。
