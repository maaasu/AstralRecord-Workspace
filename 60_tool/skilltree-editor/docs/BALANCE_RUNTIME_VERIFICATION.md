## 起動環境

起動時のnpm未検出・runtime専用dotnet選択を修正しました。既存のportable Node.js 24.18.0と.NET SDK 10.0.402をユーザーの `AppData/Local/AstralRecord/tools` へ配置し、起動バッチで環境変数・標準配置・ユーザー配置を検出します。ダウンロードや永続PATH変更はしていません。

Nodeは通常起動、PATHなしのユーザー配置fallback、明示HOME優先、不正な優先HOMEから後続HOMEへのfallbackを実cmdで検査しました。.NETはエディタの `global.json` を使った実SDK解決を確認します。runtimeのみ・SDK10.0.100を採用せず、互換SDK10.0.402へ切り替え、互換SDKがない場合は明示的なエラーにします。SDKの配置数や `--list-sdks` の10.x表示だけでは判定しません。

## 未検証・残課題

- 全120件の実executorによるcast通し照合、全パッシブ組合せ、実サーバーの戦闘・イベントバス・実測DPSは未検証です。
- スキルはLv1・シジルなし。地形・複数敵・敵AI・プレイヤー判断・Bukkitの物理とtick揺れは対象外です。速度変更は明示した軌跡の再生です。
- Astral Edgeは静止条件のみ。6フレームの軌道と命中相対tickを動的経路へ移植する作業が残っています。必要軌跡のない技や未知の効果を厳密モードで無効化して続行しません。
- 元マスター、実サーバー、実DB、プレイヤーデータへの書き込み、デプロイ、Pushは行っていません。

起動は [README](../README.md)、条件指定と追加効果への対応方法は [BALANCE_RUNTIME.md](BALANCE_RUNTIME.md) を参照してください。
