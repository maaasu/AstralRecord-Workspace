# ワールド配置計画

マスタデータエディタ上部の「ワールド配置・編集」で、エリヴァ超大陸の保存済み Dev 配置を編集します。初期表示は「配置編集」です。「AI 配置案」に切り替えると、コピーしたワールドの保存済みブロックを解析して作った全域の案を確認できます。案は現在の Enemy マスタに存在するモブと実レベルを選び、既存の設置場所は使用しません。地域名と距離による進行レベルは計画用の提案です。

## 操作

- 「表示レイヤー」で地形、地域・推奨レベル、配置・未配置の理由を切り替えます。
- 地図はドラッグで移動、ホイールまたは `+` / `−` で拡大縮小できます。「全大陸」で表示を戻し、「開始地点」でワールドマスタのスポーン位置へ移動します。
- 地形レイヤーは `terrain-detail.json` と `terrain-detail.png` が揃うと1ブロック/画素で描画し、最大16px/mまで拡大できます。座標と表示倍率を地図左下で確認できます。詳細画像がない場合や版が一致しない場合は16m区画地図を使います。地域・レベル・未配置理由、地点選択は従来の16m区画の解析結果です。
- 地形の未解析・解析失敗区画は青灰色、未保存区画は濃灰色で表示し、水域とは区別します。「配置・未配置の理由」レイヤーの警告色・区画詳細は保持します。未知の区画を海や配置可能な地形とは扱いません。
- 地図の区画を押すと、座標、バイオーム、安全な列数、配置できない理由を表示します。拡大するとスポナーの点も選択できます。一覧からも選べます。
- Dev スポナーの円または AI 配置案の三角にマウスを合わせると、出現モブの日本語名とそれぞれの実レベルを地図枠内に表示します。Dev はカタログのモブ名・レベルの組合せを使用し、未解決のマスターは ID と不明表示で区別します。無効な Dev 配置は「無効」と表示します。ドラッグ中、追加・移動地点の指定中、地図からマウスを離したときは閉じます。長文で枠内に収まらない場合は全文確認の操作を案内します。Dev は選択後の地図下、AI はクリック・一覧から開く詳細に全モブを表示します。
- ホバー中は対象1件の出現範囲を水色の円で重ね、情報欄に半径を表示します。Dev はそのマスター、AI はその配置案の `radiusMeters` を使用し、拡大縮小に合わせて円の大きさも変わります。半径が不明・不正なら円を描かず「不明」と表示します。既に選択中または「出現範囲を重ねる」で表示している円は重複して描きません。ホバーを終えても選択中・一括表示の円は保持します。
- 地域と配置状況で絞り込み、モブ名・地域名・ID・座標で配置案を検索できます。
- 出現半径は32/48/64mを比較できます。半径を切り替えている間は前の配置案とダウンロードを無効化します。「出現範囲を重ねる」で円を表示します。
- 「案をJSON保存」は選択中の半径の提案をダウンロードします。`previewOnly: true` の比較資料であり、適用ファイルではありません。

既存スポナーマスタを流用する案と、Enemyマスタから作った「未登録のスポナーマスタ案」を区別します。未登録案には生成間隔や同時存在上限など未設計の項目があります。配置案を Dev の保存済み配置に自動適用せず、未登録マスタを登録する機能もありません。

## 保存済み Dev 配置

保存済み Dev 配置は専用の配置 API から読み、地図上に円のスポナー、紫色のひし形の NPC、黄色の四角の道標として重ねます。AI 配置案は三角で区別します。スポナーの色はマスター別が既定で、出現する実レベルの帯別にも切り替えられます。複数レベルを持つマスターとレベル不明は灰色です。単一レベルへ丸めません。全カタログのマスター ID 順で採番した `#番号` を一覧・凡例・拡大時の地図ラベルに共通表示し、同レベル・似た色のマスターも番号と名前で確認できます。番号は表示フィルタで変わりませんが、カタログへマスターを追加・削除すると変わる場合があります。カタログにないマスターは `#?` と ID で表示します。折りたたみ式の凡例は地図に表示中のマスターだけを列挙し、多い場合はスクロールします。拡大時のラベルは密集した場所で重複を省略し、選択した配置は最後に描画して白い輪郭・名前・実レベル・有効状態を表示します。無効な配置は中抜きと斜線で区別します。

「配置編集」では AI 案の点を隠し、地形レイヤーで全大陸表示のまま保存済みの点を選択できます。一覧から選択するとその地点へ地図が移動し、広い画面では地図の横に編集フォームが出ます。一覧・地図から配置を選択すると、同じ配置の再選択でも右ペインのスクロールを先頭へ戻し、編集フォームを表示します。フィルターと未保存の編集は保持します。通常ラベルは2px/m以上に拡大したときだけ表示し、それより低い倍率では選択中のラベルだけを表示します。選択したスポナーの出現半径は Filebase マスターの `radiusMeters` を使用します。追加するスポナーまたは NPC のマスターを先に選び、「地図で追加」から安全な地点をクリックします。「地図で移動」も選択した配置の X/Y/Z を同じ地点の安全な立ち位置へそろえます。解析できない地点は座標入力で指定します。操作はキャンセルできます。「AI 配置案」への切替や案の半径・検索は未保存の編集を保持します。AI 配置案では編集画面の絞り込みにかかわらず、現ワールドの保存済み・編集中の Dev 配置をすべて表示します。

スポナー・NPC は日本語名付きの既存マスターから選択します。配置一覧と地図は名前・ID・座標、種類、有効状態、地域、スポナーマスター、出現モブのレベル範囲で同時に絞り込めます。AI 配置案で選んだ Dev 配置が編集画面の条件から外れる場合、地図には選択中の1件を追加表示し、一覧件数と複数選択削除には含めません。座標・向き・有効状態を編集し、複製と複数選択削除もできます。道標は ID、表示名、アイコン、解放費用・ロック状態をフォームで指定します。保存済み道標の ID は既存の解放履歴と結び付くため変更できません。削除は対象件数を確認してから編集内容に加え、保存時に反映します。

新規配置の物理ワールド名は同じワールド ID の保存済み Dev 配置から選びます。複数の旧名がある場合は追加先を明示的に選択します。既存配置がない場合だけワールドマスターの `baseWorldPath` を使用します。画面見出しの日本語表示名は配置データのワールド名として保存しません。

保存は `expectedRevision` を付けた Dev 配置 API の一括更新です。保存・再読込中は配置を変更できません。競合（409）や接続失敗のときは画面の未保存内容を保持します。解析結果の再読込や画面切替でも編集内容を保持し、Dev配置の再読込やページ離脱時には未保存内容を確認します。別ワールドの配置は編集画面に表示されませんが、保存データから除去しません。Dev に保存した配置をゲーム内へ反映するには `/worldplacements reload` が必要です。共有チャンネルへの同期操作はこの画面にありません。

エディタの ASP.NET サーバーに `SkillTreeEditor__WorldPlacementApiBaseUrl`（専用 Dev API の基底 URL）、`SkillTreeEditor__WorldPlacementApiKey`（API 読取キー）、`SkillTreeEditor__WorldPlacementWriteKey`（配置書込キー）を環境変数または Git 管理外のローカル設定で渡します。ブラウザにはキーを渡さず、エディタの `/api/world-placements/dev` が代理で転送します。接続設定がない場合は 503 で保存を拒否します。

## 解析結果の準備

道路進行の計画は `continent.py --policy 60_tool/spawner-planner/policies/eriva-westroad.json` を指定します。道路が途切れた先を、水面・足場の数・高低差から推定した経路で北側、火山北西側、南東、南岸へ延ばします。300mごとに3レベル上がる設定を維持してLv.15〜45を配置し、周辺も地形をたどる距離でレベルを決めます。経路終点の累計距離は北側3,424m、火山北西側1,584m、南東2,048m、南岸1,904mです。短い枝をLv.45に引き上げず、距離相応のレベルにします。対象は道路・推定経路から384m以内、中心は320m以内、地表探索上限は3,808mです。X=64〜272、Z=1,440〜1,664では経路探索の局所高低差上限だけを11に緩めますが、配置候補の上限は4のままです。地域名は全レベルで「エリヴァ南西街道」です。出現円が溶岩・マグマブロックを検出した16m区画に触れる配置候補は除外します。

金色実線は検出した道路、水色点線は地形から推定した経路です。詳細に地形経路距離と経路からの距離を表示します。範囲内でも地表接続を確認できない区画には未配置理由を示し、後続地域は `reserved_future` として保持します。北東のLv.100超予定地は対象外です。16m集計による推定で、実際の歩行可能性は未検証です。閾値は[提案器の仕様](../../spawner-planner/docs/CONTINENT.md)を参照してください。

登録用ファイルを準備する場合は `prepare_registration.py` に出力一式、Filebase、明示したBukkitワールド名、新しい出力ディレクトリを渡します。半径64m、Lv.15〜45の許可レベル、配置座標・実測候補区画・再計算した地形距離と各配置のレベルの一致、既存マスタと実在プロファイル、道路範囲・保護範囲の条件を検証して配置YAMLと必要マスタをまとめます。未登録マスタ案のままでは受け付けません。この準備ツールはサーバーを変更せず、登録記録の `runtimeApplied` はfalseです。道路のみの案は未到達のレベル帯を必須にしませんが、地形延長案は実際のLv.45配置を必須にします。登録記録の `maxLevel` は実際の配置の最大値、`levelCap` は許可上限45です。実際のDevへの反映と稼働確認は、絶対パスを指定した別の作業で行います。

`--world-name` は既定で提案のworldと一致する必要があります。共有マスタ公開の保留によりruntime側の旧名を維持する場合だけ、`--source-world-name` で解析側の名前を明示します。対応は登録記録へ保存されます。配備前にコピー元の記録、`uid.dat`、共有APIのworldパスを照合し、同じ地形であることを確認してください。出力の `filebase/manifest.yml` はDevローカルoverlay用の許可ファイル一覧とSHA-256を含みます。

1. [スキャナー](../../spawner-planner/scanner/README.md) の全大陸モードで、隔離したワールドのコピーを解析します。
2. [全大陸の提案器](../../spawner-planner/docs/CONTINENT.md) で解析JSONと対象Filebaseから出力一式を生成します。
3. 生成物を既定の `60_tool/skilltree-editor/.cache/spawner-planning/` に配置して、`05-master-data-editor.bat` でエディタを開きます。生成途中のファイルを混在させないでください。提案器は各ファイルを一時ファイル経由で置換し、最後にmanifestを更新します。
4. エディタの「解析結果を再読込」を押します。

```powershell
python 60_tool/spawner-planner/continent.py --terrain C:/server/AstralRecord-CodexDev/analysis/continent-terrain.json --filebase 40_filebase --output 60_tool/skilltree-editor/.cache/spawner-planning
```

別の出力先を読む場合は、ASP.NETの `SkillTreeEditor:SpawnerPlanningDataDirectory` に絶対パスまたはワークスペース相対パスを設定します。環境変数なら `SkillTreeEditor__SpawnerPlanningDataDirectory` です。実行例のワールド位置や認証情報をソースの設定に埋め込みません。

## 読み取りAPIと世代管理

`/api/spawner-planning/manifest` を取得してから、同じ `exportRevision` を `revision` クエリへ付けて `/cells`、`/regions`、manifestの `radiusOptions` に含まれる `/proposals/{radius}` を取得します。半径は32/48/64mの非空・重複なし部分集合を許可し、64m単独案にも対応します。未選択の半径は404です。すべてGET専用です。スキーマ、ワールドID、地形指紋、出力世代の一致を確認し、再計算途中で世代が混ざった場合は409を返します。出力がない場合は404となり、画面に準備方法を案内します。

詳細地図は任意の `/terrain-detail` と `/terrain-detail/image` から読みます。両方に `revision` が必要です。固定名のメタデータは schemaVersion 1、元地形の SHA-256 `terrainFingerprint`、`minX` / `minZ` / `width` / `height`、`blocksPerPixel: 1`、`image: "terrain-detail.png"`、PNGの SHA-256 `imageSha256` を持ちます。APIはmanifestとの一致、PNGのハッシュ・寸法・最大8192画素/辺・最大128MiBを確認します。詳細地図が未生成なら404、不整合なら409で、配置案本体の利用は継続できます。

ファイル名は固定の許可リストです。任意ファイルの読込、パストラバーサル、シンボリックリンク・ジャンクション経由の読込を拒否します。APIは解析プロセスの実行やFilebase・ワールドの書換えを行いません。地形と配置JSONはローカルに保持し、外部地図サービスへ送信しません。

## 数字の読み方と限界

地表の16m区画を全256列測定します。カバー率の分母は、足場・地形・生息環境・モブ条件を満たす配置対象です。全陸地のカバー率ではありません。未保存、読込・解析失敗、水域、足場不適、急斜面、開始地点の保護範囲、対応モブなし、配置対象内の未カバーを区別します。未配置理由の色と件数から除外地域も確認してください。

地域・レベルの地図は距離帯と方角、生息環境に基づく提案です。洞窟、屋内、クエスト導線、すべての人工建築、実移動経路を解析したものではありません。32/48/64mは出現半径の比較で、稼働範囲・アグロ・負荷を保証する値ではありません。未登録案の同時存在上限は不明として扱い、ゼロと見なしません。配置ルールの詳細と制約は提案器の文書と画面の「解析と適用範囲」に記録します。
