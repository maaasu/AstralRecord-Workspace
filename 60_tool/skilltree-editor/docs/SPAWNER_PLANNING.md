# ワールド配置計画

マスタデータエディタ上部の「ワールド配置・編集」で、エリヴァ超大陸の保存済み Dev 配置を編集します。初期表示は「配置編集」です。「AI 配置案」に切り替えると、コピーしたワールドの保存済みブロックを解析して作った全域の案を確認できます。案は現在の Enemy マスタに存在するモブと実レベルを選び、既存の設置場所は使用しません。地域名と距離による進行レベルは計画用の提案です。

## 操作

- 保存済み配置とAI配置案の検索は、空白区切りのすべての語を含むものに絞り込みます。例: `オオカミ 草原`、`wolf -1150`。名前・地域名・ID・座標を組み合わせて探せます。Minecraftの色・装飾コードは検索から除き、英字の大文字・小文字は区別しません。空白だけなら検索による絞り込みを解除します。他の種類・地域などの表示条件は維持します。
- 保存済み配置の検索は地図の対象にも反映します（条件外の選択中配置は従来どおり残します）。AI配置案の検索は一覧だけに反映し、地域内の地図・カバー率・JSON保存対象は減らしません。AI案は配置案IDとX/Y/Z座標でも検索できます。検索だけで原稿・選択・配置データを変更しません。
- AI案の検索用文字列は案の取得時に作り、入力・地域変更では再利用します。案の半径や再読込で内容が変われば作り直します。各検索語と候補の一致判定は引き続き必要です。
- 「表示レイヤー」で地形、地域・推奨レベル、配置・未配置の理由を切り替えます。
- 地図はドラッグで移動、ホイールまたは `+` / `−` で拡大縮小できます。「全大陸」で表示を戻し、「開始地点」でワールドマスタのスポーン位置へ移動します。
- 地形レイヤーは `terrain-detail.json` と `terrain-detail.png` が揃うと1ブロック/画素で描画し、最大16px/mまで拡大できます。座標と表示倍率を地図左下で確認できます。詳細画像がない場合や版が一致しない場合は16m区画地図を使います。地域・レベル・未配置理由、地点選択は従来の16m区画の解析結果です。
- 地形の未解析・解析失敗区画は青灰色、未保存区画は濃灰色で表示し、水域とは区別します。「配置・未配置の理由」レイヤーの警告色・区画詳細は保持します。未知の区画を海や配置可能な地形とは扱いません。
- 地図の区画を押すと、座標、バイオーム、安全な列数、配置できない理由を表示します。拡大するとスポナーの点も選択できます。一覧からも選べます。
- Dev スポナーの円または AI 配置案の三角にマウスを合わせると、出現モブの日本語名とそれぞれの実レベルを地図枠内に表示します。Dev はカタログのモブ名・レベルの組合せを使用し、未解決のマスターは ID と不明表示で区別します。無効な Dev 配置は「無効」と表示します。ドラッグ中、追加・移動地点の指定中、地図からマウスを離したときは閉じます。長文で枠内に収まらない場合は全文確認の操作を案内します。Dev は選択後の地図下、AI はクリック・一覧から開く詳細に全モブを表示します。
- 出現範囲は初期表示から一括表示します。「配置編集」の「すべての出現範囲を表示」と「AI 配置案」の既存の「出現範囲を重ねる」は同じ表示設定で、モードを往復しても切替状態を保持します。Dev は現在の地図の表示条件に合うスポナーと追加表示される選択中のスポナー、AI は地域で絞り込んだ全配置案と地図上の Dev スポナーが対象です。配置案一覧の検索・一覧の表示件数は地図の対象を減らしません。NPC・道標の出現円は描きません。
- 「重複・未カバーを色で確認」は既定ONです。出現円とは独立して切り替え、モードを往復しても設定を保持します。橙は0件、緑は1件、紫は2件以上の水平円に中心点が含まれる区画です。凡例に各件数と対象を表示します。Dev では地図に表示中の有効なスポナー（条件外でも選択中のため残る配置を含む）、AI では地域で絞り込んだ全AI案のみを数え、併記されるDevは加算しません。未保存の編集を反映し、無効・NPC・道標は計数しません。地域・配置状況で区画を絞り込み、一覧検索と一覧件数制限はAIの計数対象を減らしません。件数は画面外を含む表示条件内の区画数です。
- ホバー中は対象1件の出現範囲を水色で強調し、情報欄に半径を表示します。選択中は選択色を優先します。Dev はそのマスター、AI はその配置案の `radiusMeters` を使用し、拡大縮小に合わせて円の大きさも変わります。半径が不明・不正なら円を描かず「不明」と表示します。一括表示をOFFにしても選択中・ホバー中の範囲は表示し、ホバーを終えると選択中・一括表示の状態に戻ります。
- 地域と配置状況で絞り込み、モブ名・地域名・ID・座標で配置案を検索できます。
- AI案の出現半径は32/48/64mを比較できます。半径を切り替えている間は前の配置案とダウンロードを無効化します。「出現範囲を重ねる」で全範囲の表示を切り替えます。
- 「案をJSON保存」は選択中の半径の提案をダウンロードします。`previewOnly: true` の比較資料であり、適用ファイルではありません。

既存スポナーマスタを流用する案と、Enemyマスタから作った「未登録のスポナーマスタ案」を区別します。未登録案には生成間隔や同時存在上限など未設計の項目があります。配置案を Dev の保存済み配置に自動適用せず、未登録マスタを登録する機能もありません。

### 重複・未カバーの読み方

着色するのは `status: ok`、`safeCount > 0`、候補X/Y/Zが有限数として測定済みで、水域ではなく地表が水・溶岩ではない陸地区画です。安全な足場を一部含むという条件であり、区画中心そのものの足場は保証しません。未解析・解析失敗・未保存・地表/生息環境不明・安全足場なし・候補不明の区画は着色しません。保護範囲や将来地域も含む地形の確認で、全陸地のスポーン可否の判定ではありません。

16m区画の中心点と、スポナー座標X/Zに0.5を加えた水平円との距離を判定します。円周を含み、画面外中心の円も計算します。1mの詳細地形の上でも判定は16m区画です。区画全体の被覆、高度差・地形の接続・区画四隅・生息環境・モブ条件は判定しないため、AI計画のカバー率や未配置理由とは一致しません。AI案の `coveredCellIndices` は新規被覆の記録なので、重複件数には使用しません。

半径・座標不明の有効な対象がある場合は、その件数を表示し、0/1件を「既知範囲」の件数へ切り替えます。色は既知の件数の下限で、橙の地点も未カバーとは断定できません。Dev配置・カタログの初回取得前または初回取得失敗、AI案取得前・半径切替中・取得失敗は着色と区画数を表示しません。正常に取得した空の配置とは区別します。「Dev を再読込」は配置とカタログを両方再取得し、両方成功した時点で反映するため、初回カタログ取得失敗後も回復できます。Devの半径はマスターAPIの値で、小数を保持し、未指定/nullはPluginと同じ16m、有限数値は最低1mです。明示的不正値や非有限値は不明（null）を返します。

### 区画から出現範囲を調べる

「確認する区画」で未カバーまたは重複を選び、「前の区画」「次の区画」で解析データ順に巡回します。現在の地域・配置状況に合う判定対象だけが候補となり、最後から最初へ循環します。選択区画が候補外なら、次は先頭、前は末尾へ移動します。中心へ地図を移動して区画を枠で示します。地図への追加・移動操作中は巡回を停止し、色表示OFF・データ未取得時は巡回を表示しません。

Dev編集でも地図の点のない場所を押すと区画を選択できます。「選択区画の出現範囲」は同じ区画中心に届く既知の対象をすべて数え、3件以上も実件数を表示します。出現モブの日本語名・実レベル・半径・座標から対象を選ぶとDev配置の編集またはAI案の詳細へ移動します。AIの新規被覆記録とは独立して幾何計算するため、2つ目以降の重複元も含みます。地形判定対象外・表示条件外は0件とせず、半径不明の対象がある場合は既知の件数と区別します。この確認や巡回だけで配置データを書き換えることはありません。

巡回用の区画索引は既存の件数集計と同じ走査で生成します。全区画と全スポナーの組合せは調べず、詳細は選択区画1件だけを照合して保持します。パン・ズーム・ホバーで詳細を再計算しません。密集地の詳細は50件ずつ表示し、全件数と地図の円は省略しません。

### 地図描画と大量配置の検証

2px/m以上で表示するスポナーの番号・レベルは、画面上のラベル位置を22pxごとの行に分け、近い3行だけで重なりを調べます。横4pxの余白・縦22px未満の重なり条件、表示順、選択中ラベルの優先表示は従来と同じです。上下端で補正した後の位置を使い、パン・ズーム・画面サイズ・配置などによるシーン再描画ごとに索引を作り直します。

2,500候補の比較検証では、同じ250ラベルを表示し、矩形の比較回数は313,500回から24,000回になりました。実際の地図でも2,500配置を拡大し、再拡大・選択変更後の表示内容と位置が従来判定と一致することを検証します。これは比較回数の改善で、Canvas全体の描画時間を測定したものではありません。同じ行に偏る場合の比較や、名前の幅測定・点の描画は残ります。

重複・未カバー判定は地図ごとに直前1件の地形と出現円（X/Z・半径・個数・配列順）を保持します。道標・NPC・向き・高さ・表示名・レベル・配置IDだけの変更では、同じ出現円の全区画計算と着色を再利用します。詳細欄の名前・ID・不明半径の警告は最新の入力を使います。スポナーの移動・半径・有効状態・対象ワールドや地域などで円が変わる場合、または地形更新時は再計算します。色表示OFF・未取得時は保持内容を解放し、再表示時に計算します。

これは全区画用の配列作成と着色を抑える改善です。入力更新時の円の比較は対象円数に比例し、表示情報の生成と地図のシーン描画は引き続き必要です。並び順だけの変更でも再計算します。地域・理由による区画の集計・着色は各表示条件で更新します。AI案の表示情報だけの変更では、地形レイヤーの着色を再作成しませんが、理由データの変更は理由表示や絞り込みへ反映します。

pointermove の最新座標とパンの差分を保持し、ホバー判定・座標表示・ドラッグの地図再構築を次の animation frame にまとめます。ツールチップの寸法測定だけでは全配置を再走査しません。ポインターを静止していても、表示位置・倍率、配置、マスター、AI案の地域条件を変えるとホバーを再判定します。

クリック抑止は各入力の水平・垂直移動量の絶対値を合計し、5pxを超えた場合だけ行います。フレーム内の往復でも移動距離を保持し、pointerup の終点までの差分を確定してから選択・地点指定を判定します。キャンセル・capture喪失・フォーカス喪失で受信済みのパンを確定して操作を終了し、その後のpointerupでは選択しません。地図外への離脱はホバーを閉じ、capture中のドラッグは継続します。非表示・解析結果更新・追加移動モード変更・画面破棄では保留入力を破棄します。「全大陸」・地点への移動・区画巡回は保留パンを破棄して移動先を優先し、拡大縮小・矢印キーのパンは保留パンの後へ適用します。

`SpawnerPlanningMap.test.tsx` は制御可能な animation frame で、2,500配置に対する30回のpointermoveをまとめて確認します。同じ入力の改修前後では、ホバーの距離計算呼出数が77,500回から2,500回（1走査）、ドラッグの地図シーン構築が30回から1回になりました。改修前のホバーには初回ツールチップ寸法測定の再走査1回も含みます。最終座標、5px境界・往復・pointerup終点、各終了条件と前提更新後の古いフレームの無効化、拡大縮小・地点移動との順序も検証します。これらは処理・Canvas呼出回数の検証であり、実ブラウザーの処理時間やゲームサーバー負荷の測定ではありません。

詳細地形は、地図が表示中・地形レイヤー・0.4px/m以上の拡大になったときに取得します。全大陸表示や他の画面では取得を始めません。同じ解析結果で取得できた画像は縮小・画面往復で再利用し、解析結果の更新時には古い画像を破棄します。取得できない間も16m区画の地図を使えます。

AI配置案は、現在読み込んでいる解析結果について検証済みの成功応答だけを半径ごとに最大3件保持します。配置編集とAI案の往復、同じ半径の再選択では再取得しません。「解析結果を再読込」で保持内容を破棄します。失敗・中断した応答は保持しません。

出現円は同じ色ごとに独立した円のパスをまとめて描きます。各円の前に開始位置を移すため、別の円へ線で接続しません。同色の交差部分は1つの描画で合成するため、重なり件数に応じて濃くする表示ではありません。件数による円の省略・上限はありません。画面外中心の円も半径が画面に届けば描き、画面から完全に離れた円と遠い点・ラベルだけを除外します。選択中の円・点は通常の円より後に描きます。

地形・道路・全出現円・点・選択表示を、現在の表示領域サイズのキャンバスへキャッシュします。ホバー対象の変更ではこの画像を復元し、未選択の対象1件の円だけを不透明の太い水色線で強調します。同じ点の中でポインターが移動してもキャンバスを再描画しません。表示倍率・移動・寸法・画素密度・地形画像・レイヤー・地域と配置状況・配置とマスターの編集・色分け・一括表示・選択の変更時はキャッシュを更新します。画面復帰時も再構築します。キャッシュはワールド全域の巨大な画像ではなく表示領域1枚分です。

重複計数は、円が交差する各行の区間へ差分を加算し、地形の各セルを1回走査します。全セルと全スポナーの組合せ走査は行いません。地形索引・計数・区画解像度の着色画像をキャッシュし、パン・ズーム・ホバーで計数し直しません。着色画像は詳細地形の後、道路・円・点の前に重ねます。`spawnerCoverage.test.ts` で境界・負座標・画面外中心・不明地形・重複と幾何判定の一致、90,000セル/10,000円で90,000以下の行区間加算を検証します。これは計算量・Canvas呼出数の確認で、実ブラウザーの時間測定ではありません。

`spawnerRangeDrawing.test.ts` は10,000件・3色をすべて描いて `arc=10,000`、`stroke=3` を確認します（従来は出現円ごとに `stroke` を1回）。`SpawnerPlanningMap.test.tsx` は2,500件がすべて画面内にある地図で全2,500円の追加 `stroke` が1回、ホバーで地形・点・全円の再構築が0、強調円だけが1回、離脱時の円パス作成が0であることを検証します。画面外中心、パン・ズーム、配置座標と半径の編集、色分け、画素密度変更も検証します。これは Canvas API 呼出数の検査であり、実ブラウザーの描画時間やゲームサーバーの負荷の測定ではありません。

## 保存済み Dev 配置

保存済み Dev 配置は専用の配置 API から読み、地図上に円のスポナー、紫色のひし形の NPC、黄色の四角の道標として重ねます。AI 配置案は三角で区別します。スポナーの色はマスター別が既定で、出現する実レベルの帯別にも切り替えられます。複数レベルを持つマスターとレベル不明は灰色です。単一レベルへ丸めません。全カタログのマスター ID 順で採番した `#番号` を一覧・凡例・拡大時の地図ラベルに共通表示し、同レベル・似た色のマスターも番号と名前で確認できます。番号は表示フィルタで変わりませんが、カタログへマスターを追加・削除すると変わる場合があります。カタログにないマスターは `#?` と ID で表示します。折りたたみ式の凡例は地図に表示中のマスターだけを列挙し、多い場合はスクロールします。拡大時のラベルは密集した場所で重複を省略し、選択した配置は最後に描画して白い輪郭・名前・実レベル・有効状態を表示します。無効な配置は中抜きと斜線で区別します。

「配置編集」では AI 案の点を隠し、地形レイヤーで全大陸表示のまま保存済みの点を選択できます。一覧から選択するとその地点へ地図が移動し、広い画面では地図の横に編集フォームが出ます。一覧・地図から配置を選択すると、同じ配置の再選択でも右ペインのスクロールを先頭へ戻し、編集フォームを表示します。フィルターと未保存の編集は保持します。通常ラベルは2px/m以上に拡大したときだけ表示し、それより低い倍率では選択中のラベルだけを表示します。選択したスポナーの出現半径は Filebase マスターの `radiusMeters` を使用します。追加するスポナーまたは NPC のマスターを先に選び、「地図で追加」から安全な地点をクリックします。「地図で移動」も選択した配置の X/Y/Z を同じ地点の安全な立ち位置へそろえます。解析できない地点は座標入力で指定します。操作はキャンセルできます。「AI 配置案」への切替や案の半径・検索は未保存の編集を保持します。AI 配置案では編集画面の絞り込みにかかわらず、現ワールドの保存済み・編集中の Dev 配置をすべて表示します。

スポナー・NPC は日本語名付きの既存マスターから選択します。配置一覧と地図は名前・ID・座標、種類、有効状態、地域、スポナーマスター、出現モブのレベル範囲で同時に絞り込めます。AI 配置案で選んだ Dev 配置が編集画面の条件から外れる場合、地図には選択中の1件を追加表示し、表示条件の一覧件数には含めず、一括選択にも自動追加しません。座標・向き・有効状態を編集し、複製と複数選択の操作もできます。道標は ID、表示名、アイコン、解放費用・ロック状態をフォームで指定します。保存済み道標の ID は既存の解放履歴と結び付くため変更できません。削除は対象一覧を確認してから編集内容に加え、保存時に反映します。

編集画面では検索・並び順・条件解除・表示件数を常時確認できます。種類・有効状態・地域・スポナーマスター・レベル上下限は初期状態で閉じた「詳細条件」で設定し、閉じても有効条件の件数と値を表示します。ワールド ID と保存先の詳細もこの中で確認できます。一括操作と選択中の編集フォームも開閉でき、選択中の配置を再選択するとフォームを開いて編集ペインを先頭へ戻します。開閉だけでは検索条件・一括選択・不正な数値の入力途中・履歴を消さず、配置一覧は編集ペインと一緒にスクロールします。有効な数値の入力途中でフォームを閉じると、従来どおりフォーカス移動で値を確定します。

新規配置の物理ワールド名は同じワールド ID の保存済み Dev 配置から選びます。複数の旧名がある場合は追加先を明示的に選択します。既存配置がない場合だけワールドマスターの `baseWorldPath` を使用します。画面見出しの日本語表示名は配置データのワールド名として保存しません。

保存は `expectedRevision` を付けた Dev 配置 API の一括更新です。保存・再読込中は配置を変更できません。競合（409）や接続失敗のときは画面の未保存内容を保持します。解析結果の再読込や画面切替でも編集内容を保持し、Dev配置の再読込やページ離脱時には未保存内容を確認します。別ワールドの配置は編集画面に表示されませんが、保存データから除去しません。Dev に保存した配置をゲーム内へ反映するには `/worldplacements reload` が必要です。共有チャンネルへの同期操作はこの画面にありません。

エディタの ASP.NET サーバーに `SkillTreeEditor__WorldPlacementApiBaseUrl`（専用 Dev API の基底 URL）、`SkillTreeEditor__WorldPlacementApiKey`（API 読取キー）、`SkillTreeEditor__WorldPlacementWriteKey`（配置書込キー）を環境変数または Git 管理外のローカル設定で渡します。ブラウザにはキーを渡さず、エディタの `/api/world-placements/dev` が代理で転送します。接続設定がない場合は 503 で保存を拒否します。

### 編集原稿と履歴

X/Y/Z・向き・道標の解放費用は、入力途中の文字を配置IDごとに保持します。空欄や符号だけの値を0へ変換せず、不正な値が残る間は保存を停止します。有効な数値はEnter・フォーカス移動で確定し、保存時にも確認します。Escapeでその欄の入力を取り消します。配置選択やAI案への切替をしても入力を保持し、「数値の入力中」から対象へ戻れます。入力中は地図での追加・移動、複製・削除、一括選択・有効状態の一括変更、履歴操作を停止します。

「元に戻す」「やり直す」で、追加・移動・複製・削除・有効状態の一括変更・フォーム編集を最大100操作まで戻せます。入力欄の数値を確定してから使用してください。配置エディタ内のCtrl/Cmd+Zで戻し、Ctrl/Cmd+YまたはShift+Ctrl/Cmd+Zでやり直します。入力欄の中ではブラウザー標準の文字編集を維持します。保存前に追加・変更・削除の件数を確認できます。保存またはDev再読込に成功すると履歴を初期化し、失敗時は編集内容を保持します。ページを閉じた後の履歴復元は対象外です。

「変更内容を確認」では、地図の検索・種類・地域などの表示条件にかかわらず、読み込んだ全配置の確定済み変更を追加・変更・削除で確認できます。日本語名と配置ID、座標・向き・マスター・有効状態・道標情報の保存前と編集後を表示し、変更種別でも絞り込めます。削除した配置も保存前の値を保持します。閉じている間は詳細を生成せず、開くと最大50件の比較表をページで切り替えます。ページ変更時は比較一覧の先頭へ戻り、取消などで件数が減った場合は存在する最後のページへ戻ります。

変更確認内の「変更を検索」では、保存前・編集後の名前、配置ID、マスターID、道標ID、ワールドID・名、X/Y/Zを空白区切りのAND条件で探せます。Minecraft装飾と英字の大文字小文字を無視します。例: `森林狼 -1150`。各語は前後どちらかの値に一致すればよく、変更前後の座標を組み合わせることもできます。検索・変更種別を変えると先頭ページへ戻ります。変更確認だけの絞り込みなので、地図・選択・原稿・保存対象には影響しません。検索用文字列は検索中だけ作成・保持し、変更またはカタログの更新時に作り直します。比較表のDOMは50件までですが、一致判定は全変更を対象にします。

「この配置へ移動」は追加・変更後の配置を選択して編集フォームと地図へ移動します。絞り込み条件外の配置も選択中の1件として地図に表示し、フィルターは保持します。「この配置の変更を取り消す」は、その配置だけを読込時の保存前へ戻します。追加は取消、変更は復元、削除は復元となり、他の配置の編集は保持します。この操作もUndo/Redoの対象で、Devへの書込みには保存が必要です。保存・再読込中と地図での追加・移動操作中は、変更一覧からの移動と個別取消を停止します。

未確定の数値入力は変更比較に含めず、注記を表示します。いずれかの配置に数値入力が残る間は、個別取消を停止して入力内容を保持します。Enter・フォーカス移動で確定するか、Escapeでその欄を取り消してから使用します。変更一覧からの配置選択だけでは入力を確定・破棄しません。

一括操作のチェックでスポナー・NPC・道標を選択し、「現在の表示条件に合う全 N 件を選択」で先頭50件より先も含む全結果を追加選択できます。「一括選択をすべて解除」で全選択を解除します。検索・条件を変えても選択を保持し、合計・現在の表示条件内・条件外の件数を表示します。「一括選択だけを一覧で確認」は表示条件外も含めた選択済み配置を50件ずつ表示し、名前・座標・配置IDから個別に確認・解除できます。この確認だけでは地図の表示条件は変わりません。

「有効にする」「無効にする」は全選択の有効状態だけを一度に変更します。条件外を含む場合とすべての削除（個別削除を含む）は専用の確認画面を開きます。合計・条件内外の件数、日本語名・実レベル・座標・配置ID・マスターID・ワールド・有効状態の前後（削除は削除対象）を50件ずつ表示し、条件外だけの確認もできます。最初はキャンセルへフォーカスし、キャンセル・Escapeでは原稿・履歴・選択を保持します。確認中は背景の操作を停止し、ワールド・原稿・マスター・表示条件・選択などの前提が変わると確定を停止して確認し直すよう案内します。確定は編集中の内容だけを変更し、APIへ保存しません。操作対象は現在のワールドの作業原稿に残る選択だけで、条件外を暗黙に除外しません。有効状態が同じ場合は履歴を追加せず、一括変更は1回のUndo/Redoで戻せます。地図での追加・移動中と保存・再読込中は一括選択・一括操作を停止します。保存・Dev再読込の成功、Undo/Redo、表示ワールド変更、一括削除で選択を解除し、個別取消では対象の選択を解除します。保存・再読込の失敗では選択を保持します。

Dev配置一覧は50件ずつ表示し、「さらに50件表示」で続きを開きます。検索・条件変更時は先頭50件へ戻ります。標準（現在の順序）、開始地点からの水平直線距離が近い順、出現実レベルの低い順・高い順、日本語名順に一覧だけを並び替えられます。低い順は最小実レベル、高い順は最大実レベルを使い、NPC・道標・レベル不明は末尾です。同順位は元の順序を保ち、並び順の変更でも先頭50件に戻ります。距離は道路に沿った距離ではありません。検索条件の一括解除は検索語・種類・有効状態・地域・スポナーマスター・レベル上下限のみを解除し、一括選択、編集中の原稿、並び順を保持します。名前・地域・レベル・検索用文字列を索引化し、入力ごとのマスター・地域の繰り返し検索を抑えます。地図の点・出現範囲・重複判定には、一覧の表示件数に関係なく絞り込み結果の全件を使用します。

## 解析結果の準備

道路進行の計画は `continent.py --policy 60_tool/spawner-planner/policies/eriva-westroad.json` を指定します。道路が途切れた先を、水面・足場の数・高低差から推定した経路で北側、火山北西側、南東、南岸へ延ばします。300mごとに3レベル上がる設定を維持してLv.15〜45を配置し、周辺も地形をたどる距離でレベルを決めます。経路終点の累計距離は北側3,424m、火山北西側1,584m、南東2,048m、南岸1,904mです。短い枝をLv.45に引き上げず、距離相応のレベルにします。対象は道路・推定経路から384m以内、中心は320m以内、地表探索上限は3,808mです。X=64〜272、Z=1,440〜1,664では経路探索の局所高低差上限だけを11に緩めますが、配置候補の上限は4のままです。地域名は全レベルで「エリヴァ南西街道」です。出現円が溶岩・マグマブロックを検出した16m区画に触れる配置候補は除外します。

金色実線は検出した道路、水色点線は地形から推定した経路です。詳細に地形経路距離と経路からの距離を表示します。範囲内でも地表接続を確認できない区画には未配置理由を示し、後続地域は `reserved_future` として保持します。北東のLv.100超予定地は対象外です。16m集計による推定で、実際の歩行可能性は未検証です。閾値は[提案器の仕様](../../spawner-planner/docs/CONTINENT.md)を参照してください。

登録用ファイルを準備する場合は `prepare_registration.py` に出力一式、Filebase、明示したBukkitワールド名、新しい出力ディレクトリを渡します。半径64m、Lv.15〜45の許可レベル、配置座標・実測候補区画・再計算した地形距離と各配置のレベルの一致、既存マスタと実在プロファイル、道路範囲・保護範囲の条件を検証して配置YAMLと必要マスタをまとめます。未登録マスタ案のままでは受け付けません。この準備ツールはサーバーを変更せず、登録記録の `runtimeApplied` はfalseです。道路のみの案は未到達のレベル帯を必須にしませんが、地形延長案は実際のLv.45配置を必須にします。登録記録の `maxLevel` は実際の配置の最大値、`levelCap` は許可上限45です。実際のDevへの反映と稼働確認は、絶対パスを指定した別の作業で行います。

`--world-name` は既定で提案のworldと一致する必要があります。共有マスタ公開の保留によりruntime側の旧名を維持する場合だけ、`--source-world-name` で解析側の名前を明示します。対応は登録記録へ保存されます。配備前にコピー元の記録、`uid.dat`、共有APIのworldパスを照合し、同じ地形であることを確認してください。出力の `filebase/manifest.yml` はDevローカルoverlay用の許可ファイル一覧とSHA-256を含みます。

1. [スキャナー](../../spawner-planner/scanner/README.md) の全大陸モードで、隔離したワールドのコピーを解析します。
2. [全大陸の提案器](../../spawner-planner/docs/CONTINENT.md) で解析JSONと対象Filebaseから出力一式を生成します。
3. 生成物を既定の `60_tool/skilltree-editor/.cache/spawner-planning/` に配置して、`05-master-data-editor.bat` でエディタを開きます。生成途中のファイルを混在させないでください。提案器は各ファイルを一時ファイル経由で置換し、最後にmanifestを更新します。
4. エディタの「解析結果を再読込」を押します。

```powershell
python 60_tool/spawner-planner/continent.py --terrain C:/server/AstralRecord-CodexDev/analysis/continent-terrain.json --filebase 40_filebase --output 60_tool/skilltree-editor/.cache/spawner-planning
```

別の出力先を読む場合は、ASP.NETの `SkillTreeEditor:SpawnerPlanningDataDirectory` に絶対パスまたはワークスペース相対パスを設定します。環境変数なら `SkillTreeEditor__SpawnerPlanningDataDirectory` です。実行例のワールド位置や認証情報をソースの設定に埋め込みません。

## 読み取りAPIと世代管理

`/api/spawner-planning/manifest` を取得してから、同じ `exportRevision` を `revision` クエリへ付けて `/cells`、`/regions`、manifestの `radiusOptions` に含まれる `/proposals/{radius}` を取得します。半径は32/48/64mの非空・重複なし部分集合を許可し、64m単独案にも対応します。未選択の半径は404です。すべてGET専用です。スキーマ、ワールドID、地形指紋、出力世代の一致を確認し、再計算途中で世代が混ざった場合は409を返します。出力がない場合は404となり、画面に準備方法を案内します。

詳細地図は任意の `/terrain-detail` と `/terrain-detail/image` から読みます。両方に `revision` が必要です。固定名のメタデータは schemaVersion 1、元地形の SHA-256 `terrainFingerprint`、`minX` / `minZ` / `width` / `height`、`blocksPerPixel: 1`、`image: "terrain-detail.png"`、PNGの SHA-256 `imageSha256` を持ちます。APIはmanifestとの一致、PNGのハッシュ・寸法・最大8192画素/辺・最大128MiBを確認します。詳細地図が未生成なら404、不整合なら409で、配置案本体の利用は継続できます。

ファイル名は固定の許可リストです。任意ファイルの読込、パストラバーサル、シンボリックリンク・ジャンクション経由の読込を拒否します。APIは解析プロセスの実行やFilebase・ワールドの書換えを行いません。地形と配置JSONはローカルに保持し、外部地図サービスへ送信しません。

## 数字の読み方と限界

地表の16m区画を全256列測定します。カバー率の分母は、足場・地形・生息環境・モブ条件を満たす配置対象です。全陸地のカバー率ではありません。未保存、読込・解析失敗、水域、足場不適、急斜面、開始地点の保護範囲、対応モブなし、配置対象内の未カバーを区別します。未配置理由の色と件数から除外地域も確認してください。

地域・レベルの地図は距離帯と方角、生息環境に基づく提案です。洞窟、屋内、クエスト導線、すべての人工建築、実移動経路を解析したものではありません。32/48/64mは出現半径の比較で、稼働範囲・アグロ・負荷を保証する値ではありません。未登録案の同時存在上限は不明として扱い、ゼロと見なしません。配置ルールの詳細と制約は提案器の文書と画面の「解析と適用範囲」に記録します。
