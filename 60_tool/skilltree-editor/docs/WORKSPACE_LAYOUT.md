# 作業領域のサイズ調整

画面上部はタイトルと画面切替を1行にまとめます。900px以下では「☰」から画面を切り替えます。Escapeまたはメニュー外のクリックで閉じられ、画面を切り替えても編集中の内容は保持します。

境界線にポインターを合わせてドラッグするとサイズを変更できます。境界線をTabで選び、左右または上下キーでも調整できます。Shift併用で大きく動かし、ダブルクリックまたはEnterで初期サイズへ戻します。サイズはブラウザー内に保存し、再読込後も使います。保存先が利用できない場合も調整できます。

| 画面・領域 | 調整できる境界と表示の修正 |
| --- | --- |
| マスターデータ | ファイル一覧と編集領域の幅。固定幅を解消し、編集領域の幅を確保します。 |
| ファイル一覧 | フォルダと検索結果の幅。検索説明の文字サイズ、操作欄の折返しを整理し、結果を下端までスクロールできます。 |
| スキルツリー | 一覧・キャンバス・詳細の幅。左右のペインを広げてもキャンバスの最小幅を確保します。 |
| ノード一覧 | 未配置・配置済みの高さ。空の区分は最小限の高さとし、もう一方の一覧が残りの高さを使います。 |
| 比較・成長グラフ | 条件と結果の幅。それぞれ独立してスクロールでき、狭くした条件欄は項目を折り返します。 |
| ワールド配置編集 | 地図と配置一覧の幅。ウィンドウの残り高さを使い、一覧の固定された高さ上限を解消します。地図の表示設定・座標移動と反映手順は開閉し、地図を最初から表示します。 |
| 配置一覧 | 操作欄と一覧の高さ。長い検索説明は開閉でき、検索・詳細・一括操作と結果を別々にスクロールできます。 |
| AI配置案 | 地図と配置案の幅。固定幅の詳細欄を調整できます。 |

マスターの外側の境界は1100px以下、スキルツリーの横境界は980px以下、分析画面の境界は950px以下では表示せず、一覧の開閉・ペイン切替・縦並びを使います。マスターのフォルダと検索結果は680px以下で切り替えます。ワールドは領域の幅が800px以下なら縦並びになります。非表示の境界の設定は、広い画面に戻したときに再利用します。
