# 作業ライブ

Claude と Codex のローカル記録を読み、誰が誰に何を依頼したかをブラウザーに表示します。依頼文、実行したコマンド、出力は、流れごとの図と一覧から確認できます。

## 起動と停止

Windows PowerShell 5.1 と、PATH から実行できる Node.js 24 以上を使います。リポジトリのルートから起動します。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\60_tool\agent-config\work-live\start.ps1
```

- 既定ではバックグラウンドで起動し、`http://127.0.0.1:5490` を表示します。同じ PC のブラウザーのアドレス欄に貼り付けて開きます。
- Codex デスクトップアプリでは、ツールバーのブラウザーボタンか `Ctrl+Shift+B`（Windows）で内蔵ブラウザーを開き、アドレス欄に起動時の URL を貼り付けます。[OpenAI の内蔵ブラウザー案内](https://help.openai.com/en/articles/20001277-using-the-built-in-browser-in-the-chatgpt-desktop-app)
- `-Open` を付けると、新しく起動したときだけ既定のブラウザーで 1 回開きます。起動済みの場合は URL が表示されます。
- `-Foreground` を付けると、同じコンソールで実行できます。`Ctrl+C` で停止できます。
- `-Stop` を付けると、起動スクリプトが登録した作業ライブを確認して停止します。

バックグラウンド起動のログは `%LOCALAPPDATA%\work-live\server.log` と `server-error.log` に保存します。同じフォルダの `server.pid` に PID、ポート、起動時刻を記録します。

### ポートを変える

`-Port 5491` または環境変数 `WORK_LIVE_PORT` でポートを指定します。両方ある場合は `-Port` が優先です。起動中の作業ライブがある場合は停止してから新しいポートで起動します。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\60_tool\agent-config\work-live\start.ps1 -Stop
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\60_tool\agent-config\work-live\start.ps1 -Port 5491
```

マスタデータエディタ、スポナー配置プレビュー、Control Web とは別のポートで使います。指定したポートに作業ライブが起動済みなら、その URL を再利用します。ほかのプログラムが使用中なら、ポート番号を表示して終了します。接続先は `127.0.0.1` に限定し、起動はこのスクリプトで管理します。

## 画面の読み方

- 上部のタブは実行中のセッションを先頭に、最後の動きが新しい順に並びます。タブの帯にポインターがある間や、ボタンにフォーカスがある間は並びを保ちます。通常は選択中のセッションを含めて最大 8 件を表示し、「ほか n 件」で残りを開きます。「すべて」で全セッションの流れを表示します。
- 画面幅が 600 px 以下のときは帯の中を横にスクロールできます。帯の端のグラデーションは、その先にもタブがあることを示します。選択したタブまで自動でスクロールします。
- 期間は「実行中」「直近 1 時間」「すべて（2 時間）」から選びます。LIVE は選択中のセッションが関わる実行中の依頼数です。タブと期間の選択は URL とブラウザーに保存します。
- 矢印は左の依頼元から右の依頼先へ向かいます。番号は同じ流れの依頼一覧に対応します。選択中のセッションは太枠になり、直接関わるカードと行が強調されます。
- カードでは主体、状態、進行中の操作または終了時の報告、経過時間、作業種別ごとの件数を確認できます。動きを減らす設定を使うと、図を静止表示します。
- 依頼の行を押すと、依頼文、出どころ、開始・終了時刻、実行内容が開きます。依頼文は先頭 20 行、実行内容は新しい 15 件を表示します。カードの見出しは冒頭のタグを飛ばして要約し、スキルの情報だけがあるときは名前か本文の先頭を使います。全文や過去の操作を開くボタンもあり、操作の行を押すとコマンドと出力が見られます。URL やパスを含む依頼文と出力は、折り返し付きのテキストで表示します。
- ページは 2 秒ごとに更新します。最後の動きから 3 分たった未終了の依頼は「応答なし」、結果を確認できず停止した依頼は「停止」と表示します。

## 情報源と表示範囲

| 情報源 | 読み取る内容 |
| --- | --- |
| `~/.codex/sessions/YYYY/MM/DD/rollout-*.jsonl`、`~/.codex/session_index.jsonl` | 今日と昨日の依頼・操作、スレッド名 |
| `~/.claude/projects/<プロジェクト>/<sessionId>.jsonl`、同名フォルダの `custom-title.json` | 入力、Claude のツール呼び出しと結果、セッション名 |
| Claude セッションの `subagents/agent-*.jsonl` と `.meta.json` | Agent の依頼先と実行内容 |
| `~/.claude/sessions/<pid>.json` | ローカルセッションの起動状態、作業フォルダ、セッション ID の対応 |

Claude は 4 秒、Codex は 2 秒ごとに確認します。直近 2 時間に更新された会話記録の末尾をまず 64 KiB 読み、依頼やターンの開始が見つからなければ最大 1 MiB まで戻ります。以後は追記を読みます。名前の取得にはタイトル記録と必要に応じて会話記録の先頭を使います。Codex の最初のターンが長く、先頭と末尾で同じターン ID を確認できる場合は、開始時刻と依頼文を先頭から補います。Claude の開始行が末尾の範囲外にあり、保存された依頼文が見つかる場合は、最初に観測した動きの時刻を表示します。

依頼は開始時刻が新しい順に最大 30 件、依頼文は 20,000 字、実行内容は 60 件・各 4,000 字まで保持します。長い会話記録では 256 KiB を超える行を省略します。Codex のファイル差分は各ファイル 1,500 字、Agent の呼び出し結果は 2,000 字まで表示します。

Codex アプリの起動元は「あなた」、サブエージェントの起動元は親の Codex です。`codex exec` や `codex review` は、取得済みの依頼文、作業フォルダ、時刻から Claude の Bash や PowerShell の呼び出しと照合します。`-C` にシェルの展開を含む場合は、呼び出し時点の作業フォルダを使います。照合できた依頼は矢印 1 本で表示し、状態・実行内容・結果を Codex の記録から取得します。指示書を渡す起動では依頼文も同じ記録から補います。バックグラウンド実行で Codex の記録がまだ見つからない場合は、Claude が受け取った終了通知で状態を更新します。起動元を特定できない CLI は「不明な呼び出し元（codex exec）」と表示します。

クラウドのセッションはローカルに記録がないため対象外です。表示と監視はこの PC 内で完結し、モデルの API を呼ばないためクレジットを消費しません。
