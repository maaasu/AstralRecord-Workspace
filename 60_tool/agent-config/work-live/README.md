# 作業ライブ

Claude Code のペインで、誰が誰に何を依頼したかを矢印で表示します。依頼を選ぶと、渡されたプロンプトや指示書と、実行したコマンドやファイル変更などを確認できます。

## 有効化

Claude Code 2.1.326 の function hooks API 向けです。ユーザー設定の ~/.claude/settings.json にある env に、プラグインのあるフォルダの絶対パスを追加します。このリポジトリの配置例は次のとおりです。

```json
{
  "env": {
    "CLAUDE_CODE_PLUGIN_DIRS": "C:/AstralRecord-Workspace/60_tool/agent-config/work-live"
  }
}
```

既存の設定はそのまま残し、CLAUDE_CODE_PLUGIN_DIRS にすでに別のフォルダがあれば、Windows ではセミコロン、macOS と Linux ではコロンでパスを区切って追記します。設定を保存したらデスクトップアプリを再起動し、Claude Code セッションを開きます。

## 使い方

- /work-live でペインを開きます。既定では Codex、別の Claude セッション、サブエージェントへの依頼が始まると自動で開きます。自動配置できない場合は、手動で開く操作をトーストで一度案内します。
- 一番上のタブで Claude、クラウド、Codex のセッションを切り替えます。このセッションが最初に選ばれます。依頼がなく、ほかで実行中のセッションがあれば、最後の動きが最も新しいものを選びます。タブはこのセッションを先頭に、実行中、その他の順で並び、それぞれ最後の動きが新しい順です。最初の 8 件より後ろは「ほか n 件」で表示できます。「すべて」を選ぶと、全セッションの流れを表示します。
- タブの下の「実行中」「直近 1 時間」「すべて（2 時間）」で期間を切り替えます。既定は「直近 1 時間」です。LIVE は選択中のセッションが関わる実行中の依頼数です。見出しには開始時刻、依頼元ごとに受けた件数、自分から出した件数が表示されます。最後の動きから 3 分たった未終了の依頼は「応答なし」になり、次の動きで実行中に戻ります。
- 依頼先が次の依頼を出したとき、親の開始から終了後 5 分までのものを同じ流れにまとめます。このセッションで委任元のターンを記録できた場合は、その依頼を親にします。選択中のセッションが依頼元か依頼先に含まれる流れを表示します。図では選択中のセッションを太枠で示し、直接つながらないカードと、一覧内で選択中のセッションが関わらない依頼を薄く表示します。
- 依頼の行を押すと、直下に全名、開始・終了時刻、依頼文と出どころ、実行内容が開きます。依頼文は Markdown で先頭 20 行を表示します。「全文を表示」で残りを開けます。URL、パス、リンク先、画像の参照先はコード表記に変わり、依頼文からは開けません。依頼文が空の場合も一覧から詳細を開けます。実行内容は新しい 15 件を古い順に並べ、見出しに操作の要約を表示します。各行を押すと取得したコマンドや出力などが折り返し付きで開きます。依頼と実行内容は、同じ行をもう一度押すと閉じます。
- ターミナルでは選んだタブに「[選択中]」が付き、文字のツリーで最新の作業または結果と経過時間を確認できます。最小化したウィジェットには、選択中のセッションが関わる最新の実行中の依頼を 1 行で表示します。フッターで Codex と Claude の監視状態を確認できます。

## フロー図の読み方

- 矢印は左の依頼元から右の依頼先に向かいます。矢印の番号は同じ流れの依頼一覧と対応します。同じ親から同じ相手への依頼は矢印をまとめ、番号を 3 件まで表示します。
- カードには主体の種類、状態、名前が並びます。その下で実行中の作業、終了時の報告、または依頼の要約を確認できます。末尾には経過時間と、保持している実行内容のうち最大 4 種類の作業件数が並びます。
- 実行中は、破線と光の粒が依頼先へ進み、到着に合わせて矢じりが光ります。カードの外枠が広がり、上の帯に光が流れます。「いま」の行に並ぶ 3 点と作業アイコンの動きで、編集中の鉛筆、端末のカーソル、検索中の虫眼鏡など、進行中の操作が分かります。実行中の矢印が 6 本を超えると、古い依頼は流れる破線と静止したカードで表示します。
- 新しい依頼ではカードが左から現れ、矢印が伸びてから番号と依頼の札が出ます。新しい操作が記録されると「いま」の行がせり上がり、対応する内訳の件数が光ります。
- 完了時は枠が緑に光り、完了の札とチェックが弾み、緑の光が依頼元へ戻ります。その後は灰色の実線と緑のチェックが残ります。失敗時はカードが震え、枠と矢印が赤く 2 回光り、赤い実線とバツが残ります。開始、操作更新、完了、失敗の演出は、それぞれの発生から 6 秒以内の描画で再生します。
- 「応答なし」のカードは色が薄くなり、点線の枠がゆっくり流れます。結果を確認できないまま止まった Claude の依頼は、同じ灰色で「停止」と表示します。詳細では「停止（結果不明）」と出ます。図とペインの LIVE、実行中のセッションタブ最大 8 個では、赤い点から二重の波紋が広がります。「あなた」のカードは静止します。
- OS やブラウザーで動きを減らす設定を有効にすると、状態の色とアイコンを静止表示します。SVG が 131,072 字に収まらない場合は演出を簡略化し、静止した図でも収まらない場合は文字のツリーで依頼を表示します。
- 吹き出しに対応する画面では、カードや矢印にポインターを置くと名前、依頼の要約、状態、経過時間を確認できます。

## アイコン

デスクトップ、モバイル、VS Code では、作業種別、依頼の主体、状態を SVG で表示します。フロー図の矢印上には円で囲んだ通し番号があり、依頼一覧にも同じ番号が並びます。ターミナルでは作業種別と依頼の状態を角括弧の札で表示します。

| アイコンの形 | 作業の意味 | ターミナル |
| --- | --- | --- |
| 折り目のある紙、虫眼鏡、フォルダ | ファイルを読む、検索、一覧 | `[読む]` `[検索]` `[一覧]` |
| 鉛筆 | ファイル変更 | `[編集]` |
| 端末、再生ボタン | シェルコマンド、Python や npm などの実行 | `[実行]` |
| 3 点の分岐 | Git 操作 | `[git]` |
| 地球、吹き出し | Web 操作、メッセージ | `[Web]` `[発言]` |
| 2 人の人影、四角から出る矢印 | サブエージェントへの委任、Codex や別セッションへの依頼 | `[委任]` `[依頼]` |
| ベル、スパナ | バックグラウンド作業の完了通知、その他のツール | `[通知]` `[道具]` |
| 丸にチェック、丸にバツ | 完了、エラーやコマンドの失敗 | `[完了]` `[失敗]` |

主体は、人影があなた、交差する光が Claude、雲がクラウドの Claude、山括弧と斜線が Codex、2 人の人影がサブエージェント、丸に疑問符が不明な相手を表します。

| アイコンの形 | 状態 | ターミナル |
| --- | --- | --- |
| 輪が広がる赤い点 | 実行中 | `[実行中]` |
| 緑の丸にチェック、赤い丸にバツ | 完了、エラーあり | `[完了]` `[失敗]` |
| 灰色の点線の丸 | 応答なし、停止（結果不明） | `[応答なし]` `[停止]` |
| 灰色の塗りつぶしの点 | 待機中 | `[待機中]` |

監視欄では、丸にチェックが動作中、丸にバツが使用不可、点線の丸が停止を表します。

## 設定

4 項目すべて既定で有効です。/config、またはユーザー設定の pluginConfigs で変更できます。

| 項目 | 動作 |
| --- | --- |
| autoOpen | Codex、別の Claude セッション、サブエージェントへの依頼が始まるとペインを開く |
| watchCodex | Codex のローカル作業記録を監視する |
| watchSessions | デスクトップアプリから取得できる別の Claude セッションを、クラウドを含めて監視する |
| showSelf | あなたからこのセッションへの依頼と、そのツール利用・完了状態を表示する |

Codex の記録の監視を無効にする設定例です。

```json
{
  "pluginConfigs": {
    "work-live": {
      "watchCodex": false
    }
  }
}
```

## 依頼元を判定する仕組み

| 情報源 | 判定方法 |
| --- | --- |
| あなたからこの Claude へ | 入力したプロンプトを起点に、このターンのツール呼び出しを記録します。空の入力、メタ入力、スラッシュコマンドは一覧から除きます。バックグラウンド作業などの自動通知は、直近の依頼の実行内容に記録します。 |
| この Claude から Codex へ | Bash または PowerShell の codex exec / review を起点にします。リダイレクトした指示書、echo / printf の引用符内、または引用符付きの直接引数から依頼文を取り出します。取得できなければ Codex の記録から補います。 |
| Codex のローカル記録 | 依頼文のあるターンを 1 件として扱います。表示名はスレッド名を使い、名前がなければ最初の依頼の要約を使います。親スレッドのあるターンは親 Codex からの依頼です。このセッションの CLI 起動は、作業フォルダ、時刻、取得済みの依頼文で照合します。依頼文を取得できず、フォルダと時刻で結び付けた場合は詳細の見出しに「（推定）」と表示します。起動記録で特定できない場合は作業フォルダが一致する Claude セッションを探します。候補が複数ある場合は起動時刻に最も近く活動したセッションを選びます。候補がなければ「不明な呼び出し元（codex exec）」、アプリのターンは「あなた」と表示します。 |
| 別の Claude セッション | セッション一覧のタイトルを表示名に使います。開始ツールの応答にあるセッション ID を使い、監視で見つけた最初の依頼と結び付けます。宛先を指定した送信は追加の指示として表示します。監視で初めて見つけた依頼は、一覧の startedBy がこのセッションなら「Claude（このセッション）」、別セッションならその Claude、空なら「あなた」を依頼元にします。 |
| サブエージェント | Agent 呼び出しの入力を依頼として表示し、ツール結果を実行内容に記録します。 |

## 記録の範囲とクレジット

- この mod が行うのはフックの観測、既存記録の読み取り、文字列処理、ペイン描画です。入力と結果はそのまま通過し、会話やプロンプトへの追記も行いません。セッション一覧とログは MCP から直接読み取るため、**表示・監視・開閉でモデルのクレジットを消費しません**。
- 表示対象は最後の動きから 2 時間以内の流れです。依頼は開始時刻が新しい順に最大 30 件保持します。依頼文は 1 件につき 20,000 文字、実行内容は新しい順に 60 件、各実行内容は 4,000 文字まで保持します。通知にも同じ上限を適用します。ファイル差分は各ファイル 1,500 文字、Agent の結果は 2,000 文字までです。
- Codex は 2 秒ごとにホーム配下の .codex/sessions/ の今日と昨日を調べ、直近 2 時間に更新された rollout JSONL を監視します。実行内容は初回に末尾 64 KiB から読み、ターン開始が見つからなければ最大 1 MiB までさかのぼります。256 KiB を超える行は省略したサイズを実行内容に記録します。最初の依頼の要約は必要に応じてファイルの先頭から探します。変数を含む指示書パスやシェル固有の展開は Codex の記録で補います。
- Claude は 4 秒ごとに ccd_session_mgmt を確認し、各周期で最大 3 セッションの直近ログを取得します。停止したセッションは最後にもう一度取得し、その後も活動時刻の更新を検出すると取り直します。最後の活動から 30 分以内は依頼元の照合に使います。MCP エラー時は 60 秒後に再試行します。平文ログに個別の時刻や ID がないため、セッションの時刻、取得時刻、前回からの重なりを使って表示します。
- VS Code の SVG は画像として表示されるため、矢印やノードの吹き出しを使えません。一覧のボタンから詳細を確認できます。
- 依頼文、コマンドと出力などがペインに表示されます。画面共有では表示する情報源を設定で調整できます。
