# Minecraft スキル追加の依頼テンプレート

数値が未定なら「既存スキルを基準に提案可」と書く。不要な項目は省略してよいが、発動対象と主効果は必須。

```text
$astralrecord-skill-author を使って、<職業> に <スキル名> を追加してください。

役割: <単体火力 / 範囲攻撃 / 回復 / 補助 / 移動 など>
発動・対象: <発動方法、敵/味方、自身、対象数、射程・角度・半径>
主効果: <ダメージ倍率または回復量、属性・状態異常など>
副効果: <範囲追加効果、ノックバック、持続など。なければ「なし」>
数値方針: <EN、CT、詠唱、レベル成長。未定なら比較対象と「提案可」>
演出: <発動から着弾までの見た目・音。参考にしたい既存スキルやバニラ要素>
入手・利用: <初期習得 / ジェム / ショップ / 管理者。不要なら「既存方針」>
設計書: <更新する絶対パス。未指定なら対象職業の戦闘バランス設計書を探索>
```

例:

```text
$astralrecord-skill-author を使って、冒険者にスマッシュを追加してください。

役割: 2体条件の高火力単体攻撃
発動・対象: 前方の敵1体へ、上から右下へ叩き落とす。命中地点の半径2mに追加効果
主効果: 主対象へ高い物理ダメージ
副効果: 周囲の敵へ主ダメージの20%とノックバック
数値方針: EN・CT・詠唱・レベル成長は冒険者の既存スキルを基準に提案可
演出: メイスの着地のような地面の粉、中心から外へ広がる衝撃波
入手・利用: 管理者でも使用可能。スキルジェムをショップで販売
設計書: E:\AstralRecord-Workspace\00_docs\60_戦闘バランス設計書\03-クラス別戦闘バランス\01-冒険者.md
```
