
# 武器と防具の質感を設計する

## 参考パックを読む

- モデル、参照 PNG、UV、GUI 表示の向きをたどり、完成表示を確認する。アトラスだけで武器の外見を評価しない。アイコン、手持ちモデル、着用テクスチャのどれが参考元に実在するかを区別する。参照切れや不足素材は確認できた範囲に含めない。
- 良い点を、どの素材、部品、表示サイズに効くかまで分解する。例えば Sword of Magic 5 の ARK 剣は刃の面と柄の素材差、ARK 弓は木部と握り・端部の重なり、ARK 杖は石と受け座の分離が参考になる。inpu と meisasu の防具アイコンでは、16px で読める縁・開口と硬質部・革の明度差を参考にできる。着用データが見つからない場合は、これをアイコンから着用 UV に応用する設計判断として扱う。
- 色・形・画素・UV を流用せず、観察した原則を対象装備のモチーフと進行度へ翻訳する。既存品の改修では、元の輪郭、色系統、素材、象徴的なパーツ、握り点を先に控える。「刀の鋼の質感」を直剣に取り入れても、反りや片刃は形状変更として扱う。

## 質感を作る

- 武器の立体改修では、刃の稜線と研ぎ面、弓身の積層と弦受け、杖の石と金具を実際の面・段差にできるか先に検討する。テクスチャ改修の範囲では既存 UV の面と部品を使い、帯状の白線で立体を足す代わりに、面ごとに同じ素材の明度と色を整理する。
- 金属は狭い縁や研ぎ面の光と広い面の抑えた濃淡を分ける。木目は材の長手方向、革や布は巻き・縫い目・織りの方向に合わせる。石は小さな光沢を実際の面に置く。接触部や継ぎ目に陰を集め、全面に同じ粒度の模様を散らさない。
- 防具のアイコン・手持ちと着用面は別に設計する。着用では額・頬の開口、肩と胴の境、腰と脚、靴口など、装着時に読める位置で素材を分ける。頭・胴・四肢の UV 面を特定し、正面だけでなく側面・背面へ装飾や素材の境界がつながるか確認する。同じセットは縁、留め具、金属や布の色域を揃える。異なるセットや素材はそれぞれの持ち味を残す。

## 配布と品質の確認

- テクスチャの一括改修は `item-models.json`、`armor-assets.json`、`blockbench/equipment-source-manifest.json` を突き合わせて対象と除外を確定する。武器と防具のみの依頼では `render_mode: generated` の2Dアクセサリー等を編集対象に混ぜない。全点依頼では ID ごとに、実際に描画される UV 面と変更画素が重なることを確かめる。共有着用 PNG が変わっていても、頭・胴・脚・足の各 ID について使用面を個別に照合する。
- UV と形状を維持する作業では、PNG の寸法と透過の境界を保つ。JE 配布 PNG、BE 手持ち PNG、BE アイコン、両版の native Blockbench 原稿の埋め込み画像を確認する。弓の引き原稿が同じアトラスを使う場合は引き3段階にも同期する。アイコンはモデルを投影するか、モデルに合わせて手で描き分ける。小さな表示でも材質と部位に応じた変化が読めるかを比べる。着用防具は着用原画、JE の humanoid と humanoid_leggings、BE の部位別着用 PNG と着用原稿を台帳で解決し、共有レイヤーの参照先も漏れなく確認する。
- 旧版と新版を同じ表示サイズ・向き・照明で比較する。各アイテムの小さなスロット表示で種類と主要部品を読めることを確認し、代表品は拡大した斜め視点で面の見え方、UV の伸び、部品の継ぎ目を調べる。着用は人体に割り当てた状態で前後を見て、顔や関節の開口とセットのつながりを確認する。アトラスや拡大画だけで完成と判定しない。
- 対象ファイルの台帳 SHA-256 を更新する。`.json` と `.bbmodel` は CRLF を LF に正規化してから計算する。PNG は元のバイト列を使う。配布アーカイブを両版とも検査し、同一入力で再生成したハッシュを比較する。静止プレビュー、静的なパック検査、実クライアントで確認した表示状態を区別して報告する。
