# Blockbench で着用防具を設計する

## 着用時の輪郭を決める

既存品を作り直すときは、マスターのモチーフ・進行度と着用原稿を確認する。ノクス旅装では、紺布と旅革を下地に、武器と共通する青灰の鋼・細い銀の縁・青銅の留め具を重ねた。前面の硬質部、側面の厚み、背面の革の支持を同じ意匠でつなぎ、初期装備らしい軽さを保つ。現行の色や形は [ノクスの着用原稿](../../../../50_resourcepack/blockbench/items/nox_armor_chest_worn.bedrock.bbmodel) と [装備アート台帳](../../../../50_resourcepack/blockbench/equipment-source-manifest.json) で確認する。

| 部位 | ノクス試作の構成と判定点 |
|:--|:--|
| 兜 | 布の外殻に額当て・側頭部・頬当てを重ねる。額の縁と背面の縫い目がつながり、正面から両目と口元が読める。頭を回したときに頬当てや首の後ろが肩甲に入らない。 |
| 胴 | 左右に面を分けた胸当て、二段の肩甲、帯で支える前腕当てを作る。背面の交差革帯は腰帯へつなぐ。首と肘に隙間を設け、腕が下がった姿勢で腰帯の端が前腕に入り込まない。 |
| 脚 | 腰帯、外腿の短い腰当て、面取りした膝当てを分ける。膝当てと靴口の間を紺布でつなぎ、布は脚と同じ骨で靴口の内側へ重ねる。 |
| 足 | 返し革の靴口、つま先の鋼の先芯、積層した底と踵を別の厚みにする。留め具は革帯に接続させ、脚を前後へ動かしても左右の硬い先芯や底が交差しない。 |

## 素体と一緒に造形する

1. **標準リグを読み込む。** Bedrock の既存着用原稿を土台に、`waist` → `body` と、その子の `head`・`rightArm`・`leftArm`・`rightLeg`・`leftLeg` の骨名、親子関係、ピボットを引き継ぐ。ノクス原稿の座標では前面が −Z、足裏が Y=0、腰のピボットが Y=12、頭の付け根が Y=24。先に素体、顔の開口、関節の隙間を置く。
2. **下地から外側へ重ねる。** 布・革の下地を作り、傾けた硬質板、折り返しの縁、留め具の順に付ける。胸板や肩甲の境目が側面でも読めるように、部品の角度と重なりを変える。共有する骨に載る腰帯なども、どの装備スロットに属するかを部品名や原稿で管理する。
3. **面ごとにUVを割り当てる。** 鋼の広い面と光る縁、革帯の折り返し、布の襞、接触部の影を分ける。部品の裏側も割り当て、狭い金具は周囲の布から分かる明度を確保する。UV島の境界を見て、隣の色や透過がにじまないようにする。
4. **静止と可動で検収する。** 同じ素体・倍率・照明で現行と試作を正面・斜め・側面・背面から描画する。4部位の一式、各部位単体、混成装備を見比べ、素体の第2スキンレイヤーも表示したまま頭・腕・脚を動かす。顔の開口、兜と肩、腰帯と腕、膝と靴口を確認する。靴口から素体の服がのぞく場合は、脚と同じ骨に置いた裏布や靴革を外側スキンより手前に出し、硬質部の隙間を再確認する。
5. **原稿を再読込する。** テクスチャを含む `.bbmodel` をBlockbenchで保存し、開き直して骨・ピボット、部品の回転、面UV、テクスチャが保たれることを確認する。回転と骨階層を適用できる描画器で、実際の原稿または書き出しデータを使う。静止画や関節を曲げた比較と、実クライアントで確認した内容を区別する。

## 試作と配布を分ける

- 全身の統合原稿と着用比較は試作として使える。ノクス試作の 512×512 統合アトラスは試作用。配布する場合はスロットごとに着用モデルを切り出し、パックの着用PNG規格である 64×32・128×64・256×128 のいずれかにUVを割り当て直す。
- 統合版は頭に `head`、胴に `body` と両腕、脚に `body` と両脚、足に両脚の形状を割り当てる。着用骨に明示的な `binding` は付けない。着用用の `geometry.worn` と `textures.armor`、部位別オフセットを確認する。
- Java 版の現行経路では、対応する革兜の頭装備に着用専用の立体モデルを使う。胴・脚・足は `humanoid` と `humanoid_leggings` の標準形状で素材、縁、留め具を描き分ける。各版の着用・手持ち・スロット表示、防具表示ON/OFFは個別に確認する。 [着用防具のパック契約](../../../../50_resourcepack/README.md#着用防具)
