# Blockbench で武器を設計する

## ノクスの原稿で完成度を測る

新規造形や作り直しでは、最も近い武器種のノクス原稿を Blockbench で開く。Java と統合版の原稿は [blockbench/items](../../../../50_resourcepack/blockbench/items/) にあり、配布先と使用段階は [編集元台帳](../../../../50_resourcepack/blockbench/equipment-source-manifest.json) で確認できる。

| 参考原稿 | 比較するときに見る部位 |
|:--|:--|
| [ノクスソード](../../../../50_resourcepack/blockbench/items/nox_sword.java.bbmodel) | 細身のシルエット、両面の稜線・研ぎ面・沈んだ谷、刃元と翼形の鍔の接合。斜めからも鋼、青銅、革巻きが分かれる。 |
| [ノクスボウ](../../../../50_resourcepack/blockbench/items/nox_bow.java.bbmodel) | 上下へ滑らかに細る弓身、頬・背・腹の積層、弦受けと矢台、弓身と弦の開口。[引き始め](../../../../50_resourcepack/blockbench/items/nox_bow_pull_0.java.bbmodel)から[引き切り](../../../../50_resourcepack/blockbench/items/nox_bow_pull_2.java.bbmodel)まで同じ握りを軸にしなる。 |
| [ノクススタッフ](../../../../50_resourcepack/blockbench/items/nox_staff.java.bbmodel) | 木の長軸、段付きの受け金具、三日月の内外の面取り、結晶の冠面と側面。三日月の開口と石を支える接合が見える。 |

ノクスと同等以上の完成度を、**輪郭、材質の面、接合部、実際に持ったときの見え方**で判定する。同条件の画像を並べ、どこが同等で、どの意匠や読みやすさが向上したかを部位で説明できるようにする。原稿のキューブ数、アトラス寸法、装飾量は造形に応じて決める。

## 造形から書き出しまで

1. **設計を絞る。** 武器種、進行度、主材、握り、遠目で残す識別点を先に決める。同じシリーズは素材と接合の意匠をそろえ、武器種や個体は輪郭でも区別する。既存品を作り直す場合は、元の用途・色系統・代表的な部品を控える。
2. **立体の骨格を作る。** Java Block/Item と統合版の対応形式で、握り、柄軸、先端、大きい部品を配置する。正面・斜め・側面・背面で輪郭を確認してから主要断面と接合を作る。刃の厚みと研ぎ面、弓身の曲がりと弦受け、杖の受け座と開口など、視点を変えると読み方が変わる部位を立体で作る。細分化するたびに正面以外から隙間、部品の浮き、同面のちらつきを確認する。
3. **材質を描く。** Blockbench の UV と Paint で部品ごとに面とテクスチャの対応を確認する。金属は広い地の面と狭い光の縁、木は長手方向の木目、革は巻きの段と接触影、石は面ごとの明度で分ける。握り、継ぎ目、留め具の付近に陰と光を置き、手持ちの大きさで材の境界が読めるか確かめる。詳しい質感の判断は [武器と防具の質感設計](equipment-surface-quality.md) を使う。
4. **握りと可動部を分ける。** モデル上の握りを共通にし、曲がる弓身、弦、矢などを別の要素に分ける。Java の通常弓は待機と引き3段階の編集元をそろえる。統合版は握りを手に固定し、子ボーンを動かして弦の端を弦受けへ追従させる。引き始め・中間・最大・復帰で、弦や矢の接続と握りを確認する。矢の照準を検証する場合は、投影上の延長線に加え、3Dで矢が前方を向くことも確かめる。
5. **実際の表示で比較する。** [握りと視界の手順](held-equipment.md)に従い、左右の一人称で柄から先端が伸びる向きと装飾面、三人称で腕と柄の接点を見る。同じ画角・解像度・照明・背景でバニラとノクスを並べ、既存品は変更前も置く。武器のスロットは[専用ピクセル原画](weapon-slot-icons.md)を用意し、実寸で区別できるか別に判定する。
6. **配布元を同期する。** Blockbench の両版原稿と書き出しを保存し、実際の配布モデル・参照テクスチャ・使用段階を確認する。直接操作できない場合は接続済み MCP、または独立した Blockbench Web のプロジェクト／書き出し codec を使う。書き出し後の再読込とパックビルドで姿勢、参照、台帳 SHA-256 を照合する。静止プレビューと隔離した実クライアントで確認した状態を区別して記録する。
