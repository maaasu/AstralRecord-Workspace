# 手持ち装備の握り方と視界

## 握り、向き、縮尺を決める

- 手持ち用の立体モデルでは、装備種別ごとに柄、持ち手、留め具などの握り点を形状上で特定し、`item-models.json` の `grip` に登録する。握り位置、先端や上端が向く方向、装飾面が向く方向を別々に決める。盾は待機時に盾面が胴体側へ回り込まず、防御時は手に追従して構えられることを確認する。魔導書の表紙や矢筒の矢口も装備の用途に合う向きで持たせる。
- 副手装備は一人称の待機中に照準や進行方向を大きく遮らない縮尺と配置にする。主手に武器を持った状態で見比べ、三人称では種類と持ち方が読める大きさにする。縮尺を変えたら握り点を支点として保つように平行移動も調整する。既存装備の縮尺は同種装備の参考値として使う。 [現在のパックの基準](../../../../50_resourcepack/README.md#武器の握り位置)
- 手持ちだけの調整では、Java 版は左右の手の `display` を変更して `gui`、`ground`、`fixed` の表示を保つ。統合版は attachable の手持ち姿勢で調整し、インベントリ用 PNG を保つ。

## 版ごとに姿勢を組む

- Java 版は左右の一・三人称の4姿勢を対象とする。左手の描画では X 平行移動と Y・Z 回転の符号がクライアントで反転する。描画時に各手の握り点と装飾面が意図した位置と方向に合うか確認する。正面を検査するモデルでは、装飾面の正面をモデルのローカル −Z に向ける。手持ち変換後にその面が向くべき方向を、姿勢ごとに `item-model-grip-targets.json` の `front` に登録する。
- Java 版で盾の使用姿勢を定義する場合は `minecraft:using_item` で切り替える。姿勢だけを変える場合は既存形状を継承し、両方のモデルで握り点を保つ。通常の盾へのフォールバックと対象パック形式のオーバーレイを確認する。弓の引き段階は待機と同じ握り点を使う。
- 統合版は `grip` の原点を握り点にし、現在の装備スロットの手にバインドする。立体の補助装備は一人称の主手 `first_person` と副手 `first_person_off` を別々の発動条件で定義し、それぞれの腕を基準に調整する。バニラの盾などを基準にする場合は、そのモデルのピボット、握り点、座標軸を調べ、専用モデルの原点に換算する。面を見せる装備は面の向きと胴体との重なりを確認する。
- 統合版の待機・攻撃・使用は、対象の手と視点で該当する姿勢が選ばれ、握りが腕から離れないことを確認する。Geyser 経由の盾は、カスタム装備の識別子と使用状態を attachable とプレイヤー側のアニメーション条件で別々に照合する。盾のモデルが防御姿勢を持つことと、クライアントが防御時に腕を上げることは別に検証する。
- 主武器の姿勢や切替条件を変更する場合は、通常表示に加え、長押し用に生成された統合版のトライデント attachable を確認する。生成時に引き継ぐ `first_person`、`third_person`、`attack` の参照と発動条件を照合する。切替を変えた場合は、副手や未登録番号でバニラのトライデントに戻ることも確認する。

## 表示を比較する

- [描画の共通ルール](../../../../50_resourcepack/AGENTS.md#描画の確認) に従い、両版でプレイヤーの腕と胴体を含めた画像を出す。対応する手と一・三人称の待機を比較し、防御や弓の引き、攻撃のアニメーションは該当する装備で代表フレームも確認する。三人称は正面と斜めまたは背面から握りの浮き、面の反転、体へのめり込みを確認する。一人称の画面内配置や視界は、画角を再現したシーンまたは隔離した実クライアントで確認する。
- 握りの不具合では、同じ姿勢や生成処理を使う装備も調べる。共通の原因で影響する装備を特定し、同系統の修正対象と主武器の回帰確認を分ける。比較には同じカメラ、腕の姿勢、画角を使う。
- Blockbench 編集元と配布用の姿勢・アニメーションを同期し、対象の編集元台帳の SHA-256 を更新する。生成した両版のパックで握り、姿勢の切り替え、GUI 用の表示とアイコンを照合する。静的検査、オフスクリーン描画、実クライアントで確認できた状態を分けて記録する。
