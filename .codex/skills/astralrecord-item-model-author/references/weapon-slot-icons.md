# 武器の専用スロットアイコンを描く

スロット用の武器は、手持ち原稿の材質と固有の意匠を読み取り、透明なピクセル原画へ描き起こす。インベントリとホットバーでは小さな表示で武器種と個体が伝わることを優先する。

## 実寸から設計する

1. **16 px で輪郭を決める。** 先端、柄、鍔や頭部を読み取れる面積に広げ、四辺に透明な余白を設ける。剣は刃と鍔、槍は長い柄と穂先、槌は打面、弓は開口と弦、弩は横に張る弓身、長杖は長い軸、短杖は大きめの頭部を優先する。
2. **同種を隣に並べて描く。** 武器種が同じでも、刃幅と切先、鍔の輪郭、弓端の曲がり、杖頭の形などから各 ID の見分け所を一つ以上決める。シリーズの色は補助に使い、近い色の武器も形や明暗で見分ける。参考は [ノクスソード](../../../../50_resourcepack/blockbench/pixel-art/nox_sword.pixel.json)の銀刃・翼形の鍔、[ノクスボウ](../../../../50_resourcepack/blockbench/pixel-art/nox_bow.pixel.json)の暖色の積層・紫の握り・淡い弦、[ノクススタッフ](../../../../50_resourcepack/blockbench/pixel-art/nox_staff.pixel.json)の三日月と独立した石。
3. **32 px の配布原画で仕上げる。** 論理16 pxの形を保ち、広い明暗面、短いハイライト、接合部の色で材質を分ける。淡い弦、刃先、石などの識別点は縮小しても残る幅を確保する。追加の細部は木目、縁、帯金などに絞り、暗い輪郭の内側にも背景と分離できる明度を置く。
4. **実背景で合否を決める。** 配布パックの通常・選択中のホットバーとインベントリの背景に重ね、Java の論理16 pxと統合版の実表示寸法で確認する。明暗の違う背景でも、まず武器種、次に個体の識別点、最後に素材の面を読み取れること。大きな原画では見えても、実寸で弦・開口・鍔・杖頭などが消える場合はピクセルのまとまりを直す。

## 配布する

- [ピクセル原画の形式](../../../../50_resourcepack/blockbench/pixel-art/README.md) に従って `blockbench/pixel-art/<id>.pixel.json` を保存する。立体武器は **生成前**に `item-models.json` の `java_gui_sprite` を `true` に設定する。既存生成器はこの指定で `bedrock/textures/items/<id>.png` だけを更新し、ビルドが同じ PNG から Java 用 GUI アセットを生成する。
- `python scripts/generate-pixel-item-assets.py <id> ...` で対象の PNG を生成し、同じ ID を `--check` 付きで検証する。編集元台帳に両方の SHA-256 を記録する。Java の通常アイテム・仮想トライデントで同じスプライトが選ばれ、手持ち・投棄・額縁は立体を選ぶことを確認する。統合版はカタログのアイコン参照、スロット PNG、手持ちアトラスの参照を別々に照合する。
- 全体改修では本番の武器台帳から対象 ID を確定し、同種の実寸一覧を作る。実クライアントで撮影できる場合は実際のスロットを確認し、配布素材を使った合成比較と区別して記録する。
