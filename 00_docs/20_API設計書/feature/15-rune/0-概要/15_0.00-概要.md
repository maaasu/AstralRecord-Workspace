# 15_0.00-概要

## 1. 目的

YAML ルーン定義（[[04_README]] の `category: rune`）を通常スタック item として所持する。
効果は `rune.stats` の固定値であり、乱数値・ルーン個体 ID・専用生成 API は持たない。
装備への装着・脱着はオーブを使用する `POST /api/equipment/orb-operations` の単一トランザクションで行う。

## 2. 構成要素

- `Repositories/EquipmentOrbOperationRepository`
- `Models/EquipmentOrbOperationModels.cs`
