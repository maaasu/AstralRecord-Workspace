# 15_0.00-概要

## 1. 目的

YAML ルーン定義（[[04_README]] の `category: rune`）からルーン個体を生成し、
ランダム値を持つ stat を `dbo.rune_instance_stat_roll` に保存する。
ルーン個体は装備への装着（[[14_3.02-操作系]].ルーン装着）で参照される。

## 2. 構成要素

- `Controllers/RuneController`
- `Repositories/RuneRepository`
- `Models/RuneInstanceModels.cs` 内の各 DTO
