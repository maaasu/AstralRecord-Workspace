# 15_1.00-モデル定義

## 1. ルーンインスタンスレスポンス

物理名: `RuneInstanceResponse`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `runeInstanceId` | GUID | ✗ | ルーン個体UUID |
| `accountId` | GUID | ✗ | 所有アカウントUUID |
| `itemId` | string | ✗ | YAML 上のルーンアイテム ID |
| `createdAt` | DateTime | ✗ | 作成日時 |
| `updatedAt` | DateTime | ✗ | 更新日時 |
| `statRolls` | object[] | ✗ | ステータスロール |
| `statRolls[].statRollId` | GUID | ✗ | ロールUUID |
| `statRolls[].status` | string | ✗ | ステータス名 |
| `statRolls[].type` | string | ✗ | `FLAT` / `SCALAR` |
| `statRolls[].value` | string | ✗ | 確定値（または固定値） |
| `statRolls[].sortOrder` | int | ✗ | 表示順 |

## 2. ルーンインスタンス作成リクエスト

物理名: `RuneInstanceCreateRequest`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `runeId` | string | ✗ | YAML 上のルーン itemId |
| `accountId` | GUID | ✗ | 所有アカウントUUID |
| `source` | string | ✓ | 生成元の識別子（例: `loot_drop`） |
| `createdBy` | GUID | ✗ | 作成者UUID |
