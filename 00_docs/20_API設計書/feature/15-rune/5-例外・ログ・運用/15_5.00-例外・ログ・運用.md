# 15_5.00-例外・ログ・運用

ログ・メッセージはハードコーディング。LogId は使用しない。

## 1. 共通エラーレスポンス

| ステータス | 発生条件 | ボディ |
|---|---|---|
| 401 Unauthorized | API キー未指定/無効 | なし |
| 400 Bad Request | バリデーション失敗 | `ProblemDetails` 互換 |
| 404 Not Found | `accountId` / `runeId` / 個体未存在 | なし |
| 500 Internal Server Error | 上記以外の例外 | `ProblemDetails` 互換 |

## 2. ログ一覧

| 項目 | 内容 |
|---|---|
| レベル | Error |
| テンプレート | `Failed to create rune instance for account {AccountId} rune {RuneId}` |
| 出力条件 | ルーン個体生成で例外発生時 |
| 引数 | `{AccountId}` / `{RuneId}` |
| 出力例外 | `_logger.LogError(ex, ...)` で添付 |

| 項目 | 内容 |
|---|---|
| レベル | Error |
| テンプレート | `Failed to get rune instance {InstanceId}` |
| 出力条件 | ルーン個体取得で例外発生時 |
| 引数 | `{InstanceId}` |
| 出力例外 | `_logger.LogError(ex, ...)` で添付 |
