# player-state snapshot モデル

## Request root

| フィールド | 型 | 必須 | 説明 |
|:--|:--|:--:|:--|
| `snapshotId` | UUID | ○ | retry でも同じ値を使う冪等キー |
| `accountId` | UUID | ○ | 所有アカウント |
| `updatedBy` | UUID | ○ | 更新者 |
| `inventories` | array | ○ | 保存対象 inventory。空配列可 |
| `loadouts` | array | ○ | dirty loadout の完全 state。空配列可 |
| `equipment` | array | ○ | dirty equipment の完全 state（enchants/runes 含む）。空配列可 |
| `learnedSkills` / `skillBindPresets` / `skillTree` / `accountProgress` | object | × | dirty section だけ送る。ACK は同名 property に metadata を返す |

## Core state

`inventories[]` は `inventoryId`, `metadataDirty`, `expectedUpdatedAt`（metadata dirty 時必須）, `metadataJson`, `expectedEntryIds`（必須・ロード時の有効 entry ID 全集合）, `entries[]` を持つ。entry は `inventoryEntryId`, item/instance 情報、quantity、metadataJson、既存 entry の `expectedUpdatedAt` を持つ。quantity は 1 以上、ID は snapshot 全体で重複不可。

`loadouts[]` は `equipmentLoadoutId`, `expectedUpdatedAt`, `slots[]` の完全 state。`equipment[]` は `equipmentInstanceId`, `expectedUpdatedAt`, enhancement/durability/rune state、`enchants[]`、`runes[]` の完全 state。equipment に独立 version は追加せず、child 更新時にも親 `updatedAt` を更新する。

## Optional section

- `learnedSkills`: `{ accountId, clientRevision, skills, deletedSkills }`。`skills[]` は既存行に `expectedVersion`、新規行には未指定を使う。削除は省略だけで表さず、`deletedSkills:[{learnedSkillId,expectedVersion}]` で明示する。これにより並行更新された skill を誤って削除しない。
- `skillBindPresets`: `{ accountId, clientRevision, selectedPresetIndex, presets[] }`。各 preset は `expectedVersion` を持つ完全 state。
- `skillTree`: `{ accountId, clientRevision, expectedVersion, unlockedNodes[] }`。
- `accountProgress`: `{ accountId, clientRevision, expectedProgressVersion, level, totalExperience, classId, classLevel, classExperience, classProgresses, mode? }`。`mode` が absent/null のとき API は mode を変更しない。

## ACK

Core ACK の ID 名は固定する。

```json
{
  "snapshotId": "UUID",
  "accountId": "UUID",
  "entries": [{ "inventoryEntryId": "UUID", "updatedAt": "UTC", "isDeleted": false }],
  "inventories": [{ "inventoryId": "UUID", "updatedAt": "UTC" }],
  "loadouts": [{ "equipmentLoadoutId": "UUID", "updatedAt": "UTC" }],
  "equipment": [{ "equipmentInstanceId": "UUID", "updatedAt": "UTC" }],
  "learnedSkills": { "clientRevision": 12, "entries": [], "deletedIds": [] },
  "skillBindPresets": { "clientRevision": 12, "entries": [] },
  "skillTree": { "clientRevision": 12, "version": 4, "updatedAt": "UTC" },
  "accountProgress": { "clientRevision": 12, "progressVersion": 8, "updatedAt": "UTC" }
}
```

ACK は state 本文を返さない。Plugin は snapshot ID と自身の revision が一致する pending state にだけ metadata を merge し、古い local state を ACK で置換しない。
