# player-state endpoint 索引

| HTTPメソッド | パス | 論理名 |
|:--|:--|:--|
| POST | `/api/player-state/snapshots` | ローカル確定 player-state snapshot の原子的保存・冪等 ACK |

## POST `/api/player-state/snapshots`

成功時は `200 OK` と ACK を返す。新規 apply と同一 `snapshotId` の retry は同じ ACK payload を返す。

| status | 条件 |
|:--|:--|
| `400` | UUID、負数、duplicate ID、JSON metadata、section payload が不正 |
| `404` | `accountId` が存在しない、または論理削除済み |
| `409` | snapshot ID の hash 不一致、所有権不一致、entry 集合/expected timestamp/version の競合、market listing 中の equipment |

transaction の適用順は、全 parent の ownership と base state 検証、equipment/loadout 検証、対象 inventory entry の一括無効化、最終配置、optional section 更新、ACK ledger 記録である。親 inventory を逐次 replace して entry 移動を削除扱いにしない。
