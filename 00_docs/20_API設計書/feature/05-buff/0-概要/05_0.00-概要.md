# 05_0.00-概要

## 1. 目的

MasterDataDB に投入済みの `buff` マスタから、バフ定義を取得する読み取り専用 API。

## 2. コンテキスト

- 通常リクエスト時に filebase を直接読まず、MasterDataDB を参照する。
- 全件常時メモリ保持は行わず、必要に応じて ID 単位の短時間キャッシュのみ許容する。
- 一覧取得は主要項目のみ返却し、詳細は ID 指定で取得する設計。

## 3. 構成要素

- `Controllers/BuffController`
- `Repositories/BuffRepository`（MasterDataDB 参照）
- `Models/BuffResponse`
