# 05_1.00-モデル定義

## 1. バフ一覧レスポンス要素

物理名: `BuffListItem`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `id` | string | ✗ | バフ ID |
| `type` | string | ✗ | `BUFF` / `DEBUFF` |
| `name` | string | ✗ | 表示名（Minecraft カラーコード含む） |
| `icon` | string | ✓ | アイコン（Minecraft マテリアル名） |
| `durationTicks` | int | ✗ | 効果時間（tick） |
| `isDebuff` | bool | ✗ | デバフフラグ |
| `stackGroup` | string | ✓ | 同じ値のバフを排他的に扱う重複グループ |

## 2. バフ詳細レスポンス

物理名: `BuffResponse`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `schemaVersion` | int | ✗ | YAML スキーマバージョン |
| `id` | string | ✗ | バフ ID |
| `type` | string | ✗ | `BUFF` / `DEBUFF` |
| `name` | string | ✗ | 表示名 |
| `icon` | string | ✓ | アイコン |
| `lore` | string[] | ✗ | 説明文 |
| `durationTicks` | int | ✗ | 効果時間（tick） |
| `isDebuff` | bool | ✗ | デバフフラグ |
| `stackGroup` | string | ✓ | 同じ値のバフを排他的に扱う重複グループ。未指定時は `id` 単位 |
| `modifiers` | object[] | ✗ | ステータス変動リスト |
| `modifiers[].status` | string | ✗ | 対象ステータス |
| `modifiers[].type` | string | ✗ | `SCALAR` / `FLAT` |
| `modifiers[].value` | number | ✗ | 変動量 |
