# 05_3.01-取得系

## 1. 取得系エンドポイント仕様

### バフ一覧取得

HTTPメソッド: `GET`
パス: `/api/buff`
コントローラ: `BuffController`
アクション物理名: `GetAll`

責務:

MasterDataDB の `dbo.master_data_entry`（`master_type = 'buff'`）から有効レコードを取得し、主要項目のみ返却する。

リクエスト:

| 種別 | 名前 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| Header | `X-Api-Key` | string | ✓ | API キー |

レスポンス:

| ステータス | 内容 | ボディ |
|---|---|---|
| 200 OK | 取得成功 | [[05_1.00-モデル定義]].バフ一覧レスポンス要素 の配列 |
| 401 Unauthorized | API キー未指定/無効 | なし |

処理内容:

1. 認証パイプラインで `X-Api-Key` を検証する
2. MasterDataDB から有効 buff を取得し、`payload_json` を [[05_1.00-モデル定義]].バフ詳細レスポンス へデシリアライズしてから主要項目へ射影する

    | 項目 | 内容 |
    |---|---|
    | 取得対象 | `master_type = 'buff'` かつ `is_deleted = 0` |
    | デシリアライザ | `System.Text.Json`（CamelCase / 大小区別なし） |

3. 200 で配列を返す
4. 例外時は [[05_5.00-例外・ログ・運用]] のログを記録し 500 を返す

### バフ詳細取得

HTTPメソッド: `GET`
パス: `/api/buff/{buffId}`
コントローラ: `BuffController`
アクション物理名: `GetById`

責務:

`buffId` をキーに MasterDataDB から有効レコードを取得し、`payload_json` をデシリアライズした [[05_1.00-モデル定義]].バフ詳細レスポンス を返す。

リクエスト:

| 種別 | 名前 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| Header | `X-Api-Key` | string | ✓ | API キー |
| Path | `buffId` | string | ✓ | バフ ID |

レスポンス:

| ステータス | 内容 | ボディ |
|---|---|---|
| 200 OK | 取得成功 | [[05_1.00-モデル定義]].バフ詳細レスポンス |
| 401 Unauthorized | API キー未指定/無効 | なし |
| 404 Not Found | 未定義 buffId | なし |

処理内容:

1. 認証パイプラインで `X-Api-Key` を検証する
2. MasterDataDB から `master_type = 'buff'` かつ `master_id = buffId` で検索する

    | 項目 | 内容 |
    |---|---|
    | 取得対象 | `payload_json`（`is_deleted = 0` のみ） |
    | 取得失敗 | 404 を返す |

3. `payload_json` を [[05_1.00-モデル定義]].バフ詳細レスポンス へデシリアライズし 200 を返す
4. 例外時は [[05_5.00-例外・ログ・運用]] のログを記録し 500 を返す
