# 05_5.00-例外・ログ・運用

ログ・メッセージはハードコーディング。LogId は使用しない。

## 1. 共通エラーレスポンス

| ステータス | 発生条件 | ボディ |
|---|---|---|
| 401 Unauthorized | API キー未指定/無効 | なし |
| 404 Not Found | buffId 未定義 | なし |
| 500 Internal Server Error | 上記以外の例外 | `ProblemDetails` 互換 |

## 2. ログ一覧

### 2.1 起動時 YAML ロード

| 項目 | 内容 |
|---|---|
| レベル | Information |
| テンプレート | `Loaded {Count} buffs from filebase` |
| 出力条件 | アプリ起動時に YAML ロード完了 |
| 引数 | `{Count}` = 読み込まれたバフ数 |

| 項目 | 内容 |
|---|---|
| レベル | Error |
| テンプレート | `Failed to load buff YAML: {Path}` |
| 出力条件 | YAML パース失敗時 |
| 引数 | `{Path}` = 該当ファイルパス |
| 出力例外 | `_logger.LogError(ex, ...)` で添付 |

### 2.2 取得系

| 項目 | 内容 |
|---|---|
| レベル | Error |
| テンプレート | `Failed to get buff {BuffId}` |
| 出力条件 | 例外発生時 |
| 引数 | `{BuffId}` = バフ ID |
| 出力例外 | `_logger.LogError(ex, ...)` で添付 |

## 3. 運用上の注意

- YAML はアプリ起動時のみロード。ホットリロード未対応。
