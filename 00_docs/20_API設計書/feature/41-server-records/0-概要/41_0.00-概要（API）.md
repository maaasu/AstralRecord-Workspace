# サーバーレコード概要

## 対象と除外

未削除ユーザーの未削除PLAYERモード（`account.mode=0`）アカウントを集計する。現在選択中かどうか、オンラインかどうかは条件にしない。`user.permission!=0`、ManagementDBのネットワーク設定`authorityUsers`に含まれるUUIDを除外する。設定が未bootstrapの場合のみ既存Proxy同期runtime運営UUIDを使う。設定が存在する場合はruntime一覧を合併せず永続設定を正本とする。現行permissionは0/99のみだが、旧・不正な非0値も除外する。ネットワークdebug/whitelist登録とWeb管理権限はサーバー運営権限を与える条件ではないため、それだけでは除外しない。

1ユーザーUUIDを1行とし、表示名は現在のMCIDを使用する。別ユーザーUUIDが同じ実在人物かどうかは識別できない。IPの共有を同一人物とは扱わない。

## ランキング

| 種類 | 単位 | 保存元・集計 |
|:--|:--|:--|
| `level` | `level` | 通常アカウントの現在`account.level`最大値。過去最高レベルとは別 |
| `gold` | `gold` | 有効・未削除GAME/CURRENCY inventoryの未削除・正数量entryを共通Gold額面表で換算して合算。旧Gold IDも対象。他通貨は対象外 |
| `play_time` | `seconds` | 通常アカウントの`play_time_seconds`合算。導入後のPLAYERモード累計のみ |
| `dungeon_clears` | `count` | 未削除ダンジョン記録の正`clear_count`合算 |
| `boss_defeats` | `count` | 未削除Mob記録のBOSSカテゴリの正`defeat_count`合算。攻略参加履歴とは別 |
| `mob_defeats` | `count` | 未削除Mob記録のENEMY/BOSSカテゴリの正`defeat_count`合算 |
| `dungeon_types` | `count` | 正`clear_count`を持つ未削除記録のDungeon ID種類数。アカウント間で重複を除去 |
| `quest_types` | `count` | 未削除クエスト状態の完了Quest ID種類数。アカウント間で重複を除去。反復クエスト完了回数ではない |

Goldの額面換算・所持金・時間・攻略/討伐回数の合算がInt64上限を超える場合は上限値へ丸める。既存アカウントcloneは所持金・冒険記録・クエスト完了集合も複製する。複製元識別情報がないため、過去のclone由来数量を自動除去できない。新しいプレイ時間列はcloneで複製せず0開始する。

## 保存と更新

プレイ時間はBukkitのserver別統計を取り込まない。APIキー認証済みPluginがPLAYER区間の測定の正本となり、経過秒差分を`playTime`sectionへ含め、既存player-state保存transaction内でアカウント累計へ加算する。同じsnapshot IDの再送・ACK照会では再加算しない。導入前時間は0であり、履歴のlogin/logout差分から復元しない。

Pluginは30秒ごとに非同期で全種類を1回取得する。同種パネルが複数あっても追加要求しない。API側は要求ごとにManagementDB権限と保存済み値を読み、各種類の集計・ソート・上位件数制限をDBで処理する。最大8×100行しか読み出さない。短期キャッシュは使用しない。生成中の保存を全種類で単一時点に固定するtransactionは使用せず、`generatedAt`は集計完了時刻を表す。

## 配置

API/Plugin更新前に`AstralRecord`へ`20261012_account_play_time.sql`を適用する。新規DBは`init.sql`に列と非負制約を含む。アカウント削除では他のアカウント進行同様に累計も削除される。
