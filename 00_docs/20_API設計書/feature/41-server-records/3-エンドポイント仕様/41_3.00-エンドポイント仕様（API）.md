# サーバーレコードエンドポイント

## GET `/api/server-records`

全8種類の[[41_1.00-モデル定義（API）]].サーバーレコード応答を一括取得する。

| 種別 | 名前 | 型 | 必須 | 説明 |
|:--|:--|:--|:--|:--|
| Header | `X-Api-Key` | string | ○ | 既存APIキー認証 |
| Query | `limit` | int | | 種類ごとの件数。省略10、1～100 |

| ステータス | 内容 | ボディ |
|:--|:--|:--|
| 200 | 取得成功 | [[41_1.00-モデル定義（API）]].サーバーレコード応答 |
| 400 | limitが1～100の範囲外、または整数でない | エラー説明 |
| 401 | APIキーなし・無効 | 既存認証応答 |
| 500 | DB/権限読み取り失敗 | 既存サーバーエラー応答。失敗を空順位へ置換しない |

1. 件数を検証し、保存済みネットワーク運営UUIDとユーザーpermissionから対象者を絞る。
2. [[41_0.00-概要（API）]]に従って通常アカウントのみをユーザー単位で集計し、DBで並べ替えて各種類の上位100行まで取得する。
3. 全8種類の集計結果を単一APIプロセス内で10秒間共有する。異なるlimit・チャンネルからの同時要求でも集計を重複実行せず、各種類の先頭limit行を返す。保持する集計結果は1組（最大800行）だけとする。
4. 0値を除外し、1始まりの連番と実際の集計完了時刻`generatedAt`を返す。キャッシュ応答でも時刻を更新しない。保存済み運営UUID一覧の変更は次回要求で検出して再集計する。permission・削除状態・スコアの変更は最大10秒後に反映する。集計失敗やキャンセルはキャッシュしない。

```json
{"generatedAt":"2026-10-12T00:00:00Z","rankings":[{"type":"level","unit":"level","available":true,"entries":[{"rank":1,"userUuid":"00000000-0000-0000-0000-000000000001","playerName":"Player","value":50}]}]}
```

上記は説明用に1種類へ省略した例であり、実際は空配列の種類も含めて全8種類を返す。
