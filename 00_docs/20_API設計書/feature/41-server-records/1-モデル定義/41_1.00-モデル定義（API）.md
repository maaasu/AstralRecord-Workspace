# サーバーレコードモデル定義

## サーバーレコード応答

| 項目 | 型 | 内容 |
|:--|:--|:--|
| `generatedAt` | UTC日時 | 全種類の集計完了時刻 |
| `rankings` | ランキング配列 | 全8種類。記録なしでも種類を省略しない |

## ランキング

| 項目 | 型 | 内容 |
|:--|:--|:--|
| `type` | string | [[41_0.00-概要（API）]]の種類ID |
| `unit` | string | `level` / `gold` / `seconds` / `count` |
| `available` | bool | 現行8種類はいずれもtrue |
| `entries` | 順位配列 | 値が正のプレイヤーのみ、上位limit行 |

## 順位

| 項目 | 型 | 内容 |
|:--|:--|:--|
| `rank` | int | 1からの連番。同値でも別の連番 |
| `userUuid` | UUID | ユーザー単位の識別子 |
| `playerName` | string | 現在のMCID |
| `value` | long | 種類の単位に対応した整数値 |

順位は値降順、MCID昇順、UUID昇順。文字列・UUIDの比較順はDBの比較規則に従う。
