# 06_1.00-モデル定義

## 1. ルートプール

物理名: `LootPoolResponse`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `schemaVersion` | int | ✗ | スキーマバージョン |
| `id` | string | ✗ | プール ID |
| `type` | string | ✗ | `LOOT_POOL` |
| `pick` | string | ✓ | 1 roll 内の最大採用件数。固定値 `"1"` または範囲 `"1~4"`、null は contents 数。範囲は Plugin が実行ごとに閉区間で抽選 |
| `contents` | object[] | ✗ | コンテンツ |
| `contents[].itemId` | string | ✗ | アイテム ID |
| `contents[].rate` | number | ✗ | content ごとの独立ドロップ率（0〜100%）。0%は必ず失敗、100%は必ず成功 |
| `contents[].amount` | string | ✓ | ドロップ数（固定値または範囲、null は 1） |

## 2. ルートテーブル

物理名: `LootTableResponse`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `schemaVersion` | int | ✗ | スキーマバージョン |
| `id` | string | ✗ | テーブル ID |
| `type` | string | ✗ | `LOOT_TABLE` |
| `rolls` | string | ✓ | 抽選回数（固定値または範囲、null は 1）。範囲は Plugin が実行ごとに閉区間で抽選 |
| `pools` | string[] | ✗ | 参照する LootPool の ID リスト |
