# 06_3.01-取得系

## 1. 取得系エンドポイント仕様

### ルートプール一覧取得

HTTPメソッド: `GET`
パス: `/api/loot/pool`
コントローラ: `LootController`
アクション物理名: `GetAllPools`

責務:

MasterDataDB の `dbo.master_data_entry`（`master_type = 'loot.pool'`）から有効レコードを取得し、各 `payload_json` をデシリアライズした [[06_1.00-モデル定義]].ルートプール の配列を返す。

リクエスト:

| 種別 | 名前 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| Header | `X-Api-Key` | string | ✓ | API キー |

レスポンス:

| ステータス | 内容 | ボディ |
|---|---|---|
| 200 OK | 取得成功 | [[06_1.00-モデル定義]].ルートプール の配列 |
| 401 Unauthorized | API キー未指定/無効 | なし |

処理内容:

1. 認証パイプラインで `X-Api-Key` を検証する
2. MasterDataDB から `master_type = 'loot.pool'` かつ `is_deleted = 0` の `payload_json` を取得する
3. 各 `payload_json` を [[06_1.00-モデル定義]].ルートプール へデシリアライズし 200 で配列を返す
4. 例外時は [[06_5.00-例外・ログ・運用]] のログを記録し 500 を返す

---

### ルートプール詳細取得

HTTPメソッド: `GET`
パス: `/api/loot/pool/{poolId}`
コントローラ: `LootController`
アクション物理名: `GetPoolById`

リクエスト:

| 種別 | 名前 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| Header | `X-Api-Key` | string | ✓ | API キー |
| Path | `poolId` | string | ✓ | プール ID |

レスポンス:

| ステータス | 内容 | ボディ |
|---|---|---|
| 200 OK | 取得成功 | [[06_1.00-モデル定義]].ルートプール |
| 401 Unauthorized | API キー未指定/無効 | なし |
| 404 Not Found | 未定義 poolId | なし |

処理内容:

1. 認証パイプラインで `X-Api-Key` を検証する
2. MasterDataDB から `master_type = 'loot.pool'` かつ `master_id = poolId` で検索する（取得失敗時は 404）
3. `payload_json` をデシリアライズし 200 で詳細を返す
4. 例外時は [[06_5.00-例外・ログ・運用]] のログを記録し 500 を返す
