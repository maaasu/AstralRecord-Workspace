# 06_5.00-例外・ログ・運用

ログ・メッセージはハードコーディング。LogId は使用しない。

## 1. 共通エラーレスポンス

| ステータス | 発生条件 | ボディ |
|---|---|---|
| 401 Unauthorized | API キー未指定/無効 | なし |
| 404 Not Found | poolId / tableId 未定義 | なし |
| 500 Internal Server Error | 上記以外の例外 | `ProblemDetails` 互換 |

## 2. ログ一覧

### 2.1 起動時 YAML ロード

| 項目 | 内容 |
|---|---|
| レベル | Information |
| テンプレート | `Loaded {PoolCount} loot pools and {TableCount} loot tables from filebase` |
| 出力条件 | アプリ起動時に YAML ロード完了 |
| 引数 | `{PoolCount}` / `{TableCount}` = 読み込まれた件数 |

| 項目 | 内容 |
|---|---|
| レベル | Error |
| テンプレート | `Failed to load loot YAML: {Path}` |
| 出力条件 | YAML パース失敗時 |
| 引数 | `{Path}` = 該当ファイルパス |
| 出力例外 | `_logger.LogError(ex, ...)` で添付 |

### 2.2 取得系

| 項目 | 内容 |
|---|---|
| レベル | Error |
| テンプレート | `Failed to get loot pool {PoolId}` |
| 出力条件 | プール取得で例外発生時 |
| 引数 | `{PoolId}` = プール ID |
| 出力例外 | `_logger.LogError(ex, ...)` で添付 |

| 項目 | 内容 |
|---|---|
| レベル | Error |
| テンプレート | `Failed to get loot table {TableId}` |
| 出力条件 | テーブル取得で例外発生時 |
| 引数 | `{TableId}` = テーブル ID |
| 出力例外 | `_logger.LogError(ex, ...)` で添付 |

## 3. 運用上の注意

- LootTable が参照する `pools[]` の ID 整合性は API 単体では検証しない。
  起動時ロードでの警告ログ追加は今後検討（[[06_9.00-未決事項]] 化候補）。
