# 06_0.00-概要

## 1. 目的

MasterDataDB に投入済みの `loot.pool` / `loot.table` マスタから、LootPool / LootTable 定義を取得する読み取り専用 API。

## 2. リソース

- LootPool: content ごとの独立ドロップ率と、1 roll 内の最大採用件数を定義するプール
- LootTable: 複数の LootPool と実行時抽選する roll 回数を組み合わせるテーブル

API は `pick` / `rolls` の固定値・範囲文字列を加工せず返す。抽選主体は Plugin であり、各 content を `rate`% で独立判定して空振りを許容し、成功候補が `pick` を超えた場合だけ無作為に絞る。

## 3. 構成要素

- `Controllers/LootController`
- `Repositories/LootRepository`（MasterDataDB 参照）
- `Models/LootResponse`
