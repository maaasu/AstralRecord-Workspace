# World API データモデル

## WorldType

| Value | Description |
|---|---|
| `HUB` | ハブ・ロビー用途ワールド。 |
| `BASE` | 拠点ワールド。 |
| `OVERWORLD` | 冒険用の通常フィールド。 |
| `DUNGEON` | ダンジョン用途ワールド。 |
| `BOSS_FIELD` | ボス戦用途ワールド。 |

## WorldResponse

| Field | Type | Description |
|---|---|---|
| `schemaVersion` | integer | スキーマバージョン。 |
| `id` | string | ワールドマスタ ID。 |
| `displayName` | string | 表示名。 |
| `worldType` | string | `WorldType`。 |
| `baseWorldPath` | string | 元ワールドフォルダのパス。 |
| `instanceRootPath` | string | インスタンス生成先ルート。 |
| `autoLoad` | boolean | 起動時 / `/world reload` 時の自動ロード対象か。 |
| `instanceEnabled` | boolean | インスタンス対応フラグ。 |
| `maxPlayers` | integer | 最大プレイヤー数。 |
| `allowBlockBreak` | boolean | ブロック破壊許可。 |
| `allowBlockPlace` | boolean | ブロック設置許可。 |
| `allowMobSpawn` | boolean | Mob スポーン許可。 |
| `showSpawnParticle` | boolean | スポーン地点の常時リングパーティクルとスニーク導線 TextDisplay の表示有無。 |
| `spawnLocation` | object | ワールド既定スポーン地点。 |
| `description` | string | 説明。 |
| `requiredItemId` | string? | 拠点から OVERWORLD へ転送する際に必要な Currency の参照値。`item:<id>` 形式。未指定時は入場条件なし。 |
| `guiIconMaterial` | string? | オーバーワールド転送 GUI に表示する `Material` 名。 |
| `adventureGuide` | object? | ワールド選択 GUI の補助情報。 |
| `overworldTeleportGui` | object? | オーバーワールド転送 GUI の画面固有配置設定。未指定時は非表示。 |

## WorldSummaryResponse

`GET /api/world` の一覧要素。ワールドフォルダやスポーン座標などの詳細は含めず、完全な `WorldResponse` は `GET /api/world/{worldId}` で取得する。

| Field | Type | Description |
|---|---|---|
| `id` | string | ワールドマスタ ID。 |
| `displayName` | string | 表示名。 |
| `worldType` | string | `WorldType`。 |
| `autoLoad` | boolean | 起動時 / `/world reload` 時の自動ロード対象か。 |
| `instanceEnabled` | boolean | インスタンス対応フラグ。 |
| `maxPlayers` | integer | 最大プレイヤー数。 |

## WorldAdventureGuideResponse

| Field | Type | Description |
|---|---|---|
| `recommendedLevelMin` | integer? | 推奨レベル下限。 |
| `recommendedLevelMax` | integer? | 推奨レベル上限。 |
| `recommendedPartySizeMin` | integer? | 推奨人数下限。 |
| `recommendedPartySizeMax` | integer? | 推奨人数上限。 |
| `notes` | string[]? | 補足メモ。 |

## OverworldTeleportGuiResponse

| Field | Type | Description |
|---|---|---|
| `slot` | integer? | GUI の配置先となる 0 以上 44 以下の Bukkit スロット番号。未指定時は非表示。 |
