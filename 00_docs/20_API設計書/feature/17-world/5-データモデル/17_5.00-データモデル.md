# World API データモデル

## WorldType

| Value | Description |
|---|---|
| `HUB` | ダンジョンやボス挑戦前の待機所、マイスペース。プレイヤー単位またはパーティー単位でインスタンス化予定。 |
| `BASE` | NPC や他プレイヤーと交流する拠点。複製なし。 |
| `OVERWORLD` | 敵が湧く通常探索ワールド。チャンネル単位でインスタンス化予定。 |
| `DUNGEON` | 特定の敵が特定数湧くダンジョン。パーティー単位でインスタンス化予定。 |
| `BOSS_FIELD` | 特定ボスが湧くボス戦フィールド。パーティー単位でインスタンス化予定。ブロック破壊・設置を許可する場合があり、ボス討伐後にインスタンスワールド削除予定。 |

## WorldResponse

| Field | Type | Description |
|---|---|---|
| `schemaVersion` | integer | スキーマバージョン。 |
| `id` | string | ワールド定義 ID。 |
| `displayName` | string | 表示名。 |
| `worldType` | string | WorldType。 |
| `baseWorldPath` | string | 複製元ワールドのパス。 |
| `instanceRootPath` | string | インスタンスワールド生成先ルート。 |
| `autoLoad` | boolean | 起動時自動ロード対象か。 |
| `instanceEnabled` | boolean | インスタンス化対象か。 |
| `maxPlayers` | integer | 最大参加人数。 |
| `allowBlockBreak` | boolean | ブロック破壊を許可するか。 |
| `allowBlockPlace` | boolean | ブロック設置を許可するか。 |
| `allowMobSpawn` | boolean | Mob スポーンを許可するか。 |
| `description` | string | 説明。 |
