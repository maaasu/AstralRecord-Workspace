# World API 概要

World API は、filebase の `50.features.world` に定義された WorldMasterData を MasterDataDB 経由で参照する。

今回はワールド複製、動的ロード、インスタンス削除は実装対象外とし、管理者用 Plugin コマンドがワールド定義の一覧・詳細・ロード済み Bukkit ワールドとの照合に使う読み取り API のみを提供する。

## 対象

- `GET /api/world`
- `GET /api/world/{worldId}`

## インスタンス生成方針

将来のインスタンス生成時は、`baseWorldPath` を複製元、`instanceRootPath` を複製先ルートとして扱う。生成ワールド名は Plugin 側で `{worldId}_{instanceType}_{ownerId}_{shortHash}` の形式で一意に生成する。

例: `boss_dragon_party_550e8400_a91f3c`

生成先例: `world_instances/boss/boss_dragon_party_550e8400_a91f3c`
