# World API 概要

World API は、filebase の `60.features.world` に定義された `WorldMasterData` を MasterDataDB 経由で提供する。

## 対象

- `GET /api/world`
- `GET /api/world/{worldId}`

## 提供する情報

- ワールド ID、表示名、種別
- `baseWorldPath` / `instanceRootPath`
- `autoLoad` / `instanceEnabled` / `maxPlayers`
- `allowBlockBreak` / `allowBlockPlace` / `allowMobSpawn`
- `showSpawnParticle`
- `spawnLocation`
- `description`
- `guiIconMaterial`
- `adventureGuide`
- `overworldTeleportGui`

`spawnLocation` は Plugin の参加時スポーンと `/world tp` の移動先に利用する。`guiIconMaterial` と `adventureGuide` は、拠点ワールドからオーバーワールドへ移動する GUI の表示情報として利用する。`overworldTeleportGui.slot` は同 GUI の絶対スロット配置に利用し、未指定のワールドは GUI に表示しない。
