# World API エンドポイント仕様

## GET `/api/world`

World マスタ一覧を返す。

### Response `200`

```json
[
  {
    "id": "world",
    "displayName": "Central Base",
    "worldType": "BASE",
    "autoLoad": true,
    "instanceEnabled": false,
    "maxPlayers": 100
  }
]
```

## GET `/api/world/{worldId}`

指定した `WorldMasterData` の詳細を返す。

### Response `200`

```json
{
  "schemaVersion": 1,
  "id": "boss_dragon",
  "displayName": "Dragon Boss Field",
  "worldType": "BOSS_FIELD",
  "baseWorldPath": "worlds/world_templates/boss/dragon",
  "instanceRootPath": "worlds/world_instances/boss",
  "autoLoad": false,
  "instanceEnabled": true,
  "maxPlayers": 8,
  "allowBlockBreak": true,
  "allowBlockPlace": true,
  "allowMobSpawn": true,
  "showSpawnParticle": true,
  "spawnLocation": {
    "x": 0.5,
    "y": 64.0,
    "z": 0.5,
    "yaw": 0.0,
    "pitch": 0.0
  },
  "description": "Party boss field for the dragon encounter. Instance worlds are expected to be deleted after victory."
}
```

### Response `404`

指定した `worldId` が MasterDataDB に存在しない。
