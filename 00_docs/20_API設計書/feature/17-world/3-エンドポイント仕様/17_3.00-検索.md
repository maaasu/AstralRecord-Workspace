# World API エンドポイント仕様

## GET `/api/world`

World 一覧を返す。

### Response `200`

```json
[
  {
    "id": "starlit_nox",
    "displayName": "Central Base",
    "worldType": "BASE",
    "autoLoad": true,
    "instanceEnabled": false,
    "maxPlayers": 100
  }
]
```
