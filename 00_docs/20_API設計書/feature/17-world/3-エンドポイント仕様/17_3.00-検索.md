# World API エンドポイント仕様

## GET `/api/world`

World マスタ一覧を取得する。

### Response `200`

```json
[
  {
    "id": "world",
    "displayName": "Central Base",
    "worldType": "BASE",
    "autoLoad": true,
    "instanceEnabled": false,
    "maxPlayers": 100
  }
]
```

## GET `/api/world/{worldId}`

World マスタ詳細を取得する。

### Response `200`

```json
{
  "schemaVersion": 1,
  "id": "boss_dragon",
  "displayName": "Dragon Boss Field",
  "worldType": "BOSS_FIELD",
  "baseWorldPath": "world_templates/boss/dragon",
  "instanceRootPath": "world_instances/boss",
  "autoLoad": false,
  "instanceEnabled": true,
  "maxPlayers": 8,
  "allowBlockBreak": true,
  "allowBlockPlace": true,
  "allowMobSpawn": true,
  "description": "Party boss field for the dragon encounter. Instance worlds are expected to be deleted after victory."
}
```

### Response `404`

指定した `worldId` が MasterDataDB に存在しない。
