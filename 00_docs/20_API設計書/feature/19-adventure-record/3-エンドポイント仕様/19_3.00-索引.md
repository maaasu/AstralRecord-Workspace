# 19_3.00-冒険記録 API

## エンドポイント一覧

| メソッド | パス | 用途 |
|:--|:--|:--|
| GET | `/api/adventure-record/mob?account_id={account_id}&category={category}` | アカウント単位の Mob 討伐記録一覧取得 |
| POST | `/api/adventure-record/mob/defeat` | Mob 討伐記録の登録・更新 |
| GET | `/api/adventure-record/dungeon?account_id={account_id}` | アカウント単位のダンジョン踏破記録一覧取得 |
| POST | `/api/adventure-record/dungeon/clear` | ダンジョン踏破記録の登録・回数加算 |

## GET `/api/adventure-record/mob`

アカウント単位で、討伐済み Mob の記録を `lastDefeatedAt` 降順で返す。`category` は省略可能で、指定時は `ENEMY` / `BOSS` のいずれかで絞り込む。

### Query

| 名前 | 必須 | 内容 |
|:--|:--:|:--|
| `account_id` | ✓ | アカウント UUID |
| `category` |  | `ENEMY` / `BOSS` |

### Response `200`

```json
[
  {
    "accountMobRecordId": "00000000-0000-0000-0000-000000000000",
    "accountId": "00000000-0000-0000-0000-000000000000",
    "mobId": "slime",
    "mobCategory": "ENEMY",
    "defeatCount": 3,
    "firstDefeatedAt": "2026-06-01T00:00:00Z",
    "lastDefeatedAt": "2026-06-01T00:10:00Z",
    "createdAt": "2026-06-01T00:00:00Z",
    "updatedAt": "2026-06-01T00:10:00Z",
    "createdBy": "00000000-0000-0000-0000-000000000000",
    "updatedBy": "00000000-0000-0000-0000-000000000000"
  }
]
```

## POST `/api/adventure-record/mob/defeat`

同一 `accountId` + `mobId` の記録があれば `defeatCount` を加算し、`lastDefeatedAt` を更新する。未登録の場合は新規作成する。

### Request

```json
{
  "accountId": "00000000-0000-0000-0000-000000000000",
  "mobId": "slime",
  "mobCategory": "ENEMY",
  "updatedBy": "00000000-0000-0000-0000-000000000000"
}
```

### Response `200`

`GET /api/adventure-record/mob` の要素と同じ形式の単一オブジェクトを返す。

## GET `/api/adventure-record/dungeon`

アカウント単位で、論理削除されていない踏破済みダンジョンを `lastClearedAt` 降順、同時刻は `dungeonId` 昇順で返す。Pluginのカルトグラフarchiveがメインスレッド外でlazy loadする。

### Query

| 名前 | 必須 | 内容 |
|:--|:--:|:--|
| `account_id` | ✓ | 空でないアカウント UUID |

### Response `200`

```json
[
  {
    "accountDungeonRecordId": "00000000-0000-0000-0000-000000000000",
    "accountId": "00000000-0000-0000-0000-000000000000",
    "dungeonId": "twilight_mine",
    "clearCount": 3,
    "firstClearedAt": "2026-08-01T00:00:00Z",
    "lastClearedAt": "2026-08-12T00:10:00Z",
    "createdAt": "2026-08-01T00:00:00Z",
    "updatedAt": "2026-08-12T00:10:00Z",
    "createdBy": "00000000-0000-0000-0000-000000000000",
    "updatedBy": "00000000-0000-0000-0000-000000000000"
  }
]
```

空UUIDは `400 Bad Request` とする。

## POST `/api/adventure-record/dungeon/clear`

`accountId` + trim済み`dungeonId`を一意キーとして、serializable transaction内でupsertする。未登録は `clearCount=1` として初回／最終踏破日時と監査列を作成する。既存レコードは同じIDのまま `clearCount` を1加算して `lastClearedAt`／更新監査列を更新し、論理削除済みなら再有効化する。

### Request

```json
{
  "accountId": "00000000-0000-0000-0000-000000000000",
  "dungeonId": "twilight_mine",
  "updatedBy": "00000000-0000-0000-0000-000000000000"
}
```

- `accountId` と `updatedBy` は空UUID不可。
- `dungeonId` はtrim後1〜100文字。

### Response `200`

`GET /api/adventure-record/dungeon` の要素と同じ形式の単一オブジェクトを返す。不正入力は `400 Bad Request` とする。
