# 14_5.00-例外・ログ・運用

ログ・メッセージはハードコーディング。LogId は使用しない。

## 1. 共通エラーレスポンス

| ステータス | 発生条件 | ボディ |
|---|---|---|
| 401 Unauthorized | API キー未指定/無効 | なし |
| 400 Bad Request | バリデーション失敗 / ペイロードルール違反 | `ProblemDetails` 互換 |
| 404 Not Found | 装備個体 / プリセット / 関連リソース未存在 | なし |
| 500 Internal Server Error | 上記以外の例外 | `ProblemDetails` 互換 |

## 3. 運用上の注意

- 状態変化・強化・エンチャント・ルーン装着はそれぞれ DB と YAML マスタの整合性に依存する。
  YAML 改修時は装備個体の整合性検証（既存個体への影響）も検討する。
- 強化失敗時の `failAction`（`NONE` / `DOWNGRADE` / `DESTROY`）の実装責務は本機能。詳細仕様は今後 [[14_9.00-未決事項]] で扱う候補。
