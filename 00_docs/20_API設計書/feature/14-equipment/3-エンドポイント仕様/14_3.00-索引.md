# 14_3.00-索引

API `equipment` 機能はエンドポイント数が多いため、3 ファイルに分割する。

## 一覧

1. [[14_3.01-インスタンス系]] — 装備個体の生成・取得
2. [[14_3.02-操作系]] — 強化・状態変化・エンチャント・ルーン装着
3. [[14_3.03-ロードアウト系]] — 装備プリセット管理

## エンドポイント横断索引

### インスタンス系

| HTTPメソッド | パス | 論理名 | 定義ファイル |
|---|---|---|---|
| POST | `/api/equipment/instances` | 装備インスタンス作成 | [[14_3.01-インスタンス系]] |
| GET | `/api/equipment/instances/{instanceId}` | 装備インスタンス取得 | [[14_3.01-インスタンス系]] |
