# 14_3.00-索引

このディレクトリは API `equipment` 機能のエンドポイント仕様を HTTP メソッド区分別に定義する。

## 一覧

1. [[14_3.01-取得系]]
2. [[14_3.02-登録系]]
3. [[14_3.03-更新系]]
4. [[14_3.04-削除系]]

## エンドポイント一覧（横断索引）

### 装備インスタンス

| HTTPメソッド | パス | 論理名 | 定義ファイル |
|---|---|---|---|
| GET | `/api/equipment/instances/{instanceId}` | 装備インスタンス取得 | [[14_3.01-取得系]] |
| POST | `/api/equipment/instances` | 装備インスタンス作成 | [[14_3.02-登録系]] |

### 装備操作

| HTTPメソッド | パス | 論理名 | 定義ファイル |
|---|---|---|---|
| POST | `/api/equipment/orb-operations` | オーブ支払い・抽選・装備更新を冪等かつ原子的に確定 | [[14_3.02-登録系]] |
| GET | `/api/equipment/orb-operations/{operationId}` | `account_id` 所有者の確定結果を台帳から照会 | [[14_3.01-取得系]] |
| DELETE | `/api/equipment/enchant` | エンチャント削除 | [[14_3.04-削除系]] |

### ロードアウト

| HTTPメソッド | パス | 論理名 | 定義ファイル |
|---|---|---|---|
| GET | `/api/equipment/loadouts?account_id={accountId}&loadout_profile={profile}` | プリセット一覧取得 | [[14_3.01-取得系]] |
| GET | `/api/equipment/loadouts/{loadoutId}` | プリセット取得 | [[14_3.01-取得系]] |
| GET | `/api/equipment/loadouts/{loadoutId}/slots` | スロット一覧取得 | [[14_3.01-取得系]] |
| POST | `/api/equipment/loadouts` | プリセット作成 | [[14_3.02-登録系]] |
| POST | `/api/equipment/loadouts/{loadoutId}/activate` | プリセット有効化 | [[14_3.02-登録系]] |
| PUT | `/api/equipment/loadouts/{loadoutId}` | プリセット更新 | [[14_3.03-更新系]] |
| PUT | `/api/equipment/loadouts/{loadoutId}/slots` | スロット登録/更新 | [[14_3.03-更新系]] |
| DELETE | `/api/equipment/loadouts/{loadoutId}?updated_by={updatedBy}` | プリセット削除 | [[14_3.04-削除系]] |
| DELETE | `/api/equipment/loadouts/{loadoutId}/slots/{slotType}/{slotIndex}?updated_by={updatedBy}` | スロット解除 | [[14_3.04-削除系]] |
