# 14_3.01-取得系

## 1. 取得系エンドポイント仕様

### 装備インスタンス取得

HTTPメソッド: `GET`
パス: `/api/equipment/instances/{instanceId}`
コントローラ: `EquipmentController`
アクション物理名: `GetInstance`

リクエスト:

| 種別 | 名前 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| Header | `X-Api-Key` | string | ✓ | API キー |
| Path | `instanceId` | GUID | ✓ | 装備個体UUID |

レスポンス:

| ステータス | 内容 | ボディ |
|---|---|---|
| 200 OK | 取得成功 | [[14_1.00-モデル定義]].装備インスタンスレスポンス |
| 401 Unauthorized | API キー未指定/無効 | なし |
| 404 Not Found | 未登録/論理削除済み | なし |

処理内容:

1. 認証パイプラインで `X-Api-Key` を検証する
2. リポジトリから装備個体を取得（関連 `statRolls`, `enchants`, `runes` を含む）

    | 項目 | 内容 |
    |---|---|
    | 検索キー | `equipmentInstanceId` |
    | 取得対象 | `is_deleted = 0` |
    | 未存在 | 404 を返す |

3. `enchants` は `slotIndex` 順で返し、各要素に `enchantMasterId` と `effectId` を含める。装備個別の抽選プールは付加しない
4. 200 で返す

### オーブ操作結果取得

HTTPメソッド: `GET`

パス: `/api/equipment/orb-operations/{operationId}?account_id={accountId}`

コントローラ: `EquipmentController`

アクション物理名: `GetOrbOperation`

| ステータス | 内容 | ボディ |
|---|---|---|
| 200 OK | 指定アカウントの確定済み結果 | `EquipmentOrbOperationResponse` |
| 400 Bad Request | `operationId` または `account_id` が空GUID | なし |
| 401 Unauthorized | API キー未指定/無効 | なし |
| 404 Not Found | 台帳未確定または所有アカウント不一致 | なし |

台帳は抽選・支払い・影響entry IDsを固定し、同じoperationの再照会では再抽選・再消費しない。台帳accountが対象を継続所有しGAME BAG/HOTBARまたはactive loadoutに保持する場合は `targetAvailable=true` と現在の `equipment`、譲渡・削除・membership欠落時はfalseと `equipment=null` を返す。

### プリセット一覧取得

HTTPメソッド: `GET`
パス: `/api/equipment/loadouts?account_id={accountId}&loadout_profile={profile}`
コントローラ: `EquipmentLoadoutController`
アクション物理名: `ListLoadouts`

リクエスト:

| 種別 | 名前 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| Header | `X-Api-Key` | string | ✓ | API キー |
| Query | `account_id` | GUID | ✓ | アカウントUUID |
| Query | `loadout_profile` | string | ✓ | `GAME` / `ADMIN` |

レスポンス:

| ステータス | 内容 | ボディ |
|---|---|---|
| 200 OK | 取得成功 | [[14_1.00-モデル定義]].ロードアウトレスポンス の配列 |
| 400 Bad Request | クエリ欠落/不正 | エラーオブジェクト |
| 401 Unauthorized | API キー未指定/無効 | なし |
