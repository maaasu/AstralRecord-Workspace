# 14_3.01-取得系

## 1. 取得系エンドポイント仕様

### 装備インスタンス取得

HTTPメソッド: `GET`
パス: `/api/equipment/instances/{instanceId}`
コントローラ: `EquipmentController`
アクション物理名: `GetInstance`

リクエスト:

| 種別 | 名前 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| Header | `X-Api-Key` | string | ✓ | API キー |
| Path | `instanceId` | GUID | ✓ | 装備個体UUID |

レスポンス:

| ステータス | 内容 | ボディ |
|---|---|---|
| 200 OK | 取得成功 | [[14_1.00-モデル定義]].装備インスタンスレスポンス |
| 401 Unauthorized | API キー未指定/無効 | なし |
| 404 Not Found | 未登録/論理削除済み | なし |

処理内容:

1. 認証パイプラインで `X-Api-Key` を検証する
2. リポジトリから装備個体を取得（関連 `statRolls`, `enchants`, `runes` を含む）

    | 項目 | 内容 |
    |---|---|
    | 検索キー | `equipmentInstanceId` |
    | 取得対象 | `is_deleted = 0` |
    | 未存在 | 404 を返す |

3. `enchantPools` は MasterDataDB の `item` マスタから解決して付加
4. 200 で返す

### プリセット一覧取得

HTTPメソッド: `GET`
パス: `/api/equipment/loadouts?account_id={accountId}&loadout_profile={profile}`
コントローラ: `EquipmentLoadoutController`
アクション物理名: `ListLoadouts`

リクエスト:

| 種別 | 名前 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| Header | `X-Api-Key` | string | ✓ | API キー |
| Query | `account_id` | GUID | ✓ | アカウントUUID |
| Query | `loadout_profile` | string | ✓ | `GAME` / `BUILDER` |

レスポンス:

| ステータス | 内容 | ボディ |
|---|---|---|
| 200 OK | 取得成功 | [[14_1.00-モデル定義]].ロードアウトレスポンス の配列 |
| 400 Bad Request | クエリ欠落/不正 | エラーオブジェクト |
| 401 Unauthorized | API キー未指定/無効 | なし |
