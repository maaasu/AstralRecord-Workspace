# 14_3.04-削除系

## 1. 削除系エンドポイント仕様

### エンチャント削除

HTTPメソッド: `DELETE`
パス: `/api/equipment/enchant`
コントローラ: `EquipmentController`
アクション物理名: `DeleteEnchant`

責務:

指定した `poolIndex` の現在エンチャントを物理削除する。

リクエスト:

| 種別 | 名前 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| Header | `X-Api-Key` | string | ✓ | API キー |
| Header | `Content-Type` | string | ✓ | `application/json` |
| Body | (全体) | [[14_1.00-モデル定義]].3.2 エンチャント削除 | ✓ | 削除対象 |

レスポンス:

| ステータス | 内容 | ボディ |
|---|---|---|
| 200 OK | 削除成功 | [[14_1.00-モデル定義]].装備インスタンスレスポンス（更新後） |
| 401 Unauthorized | API キー未指定/無効 | なし |
| 404 Not Found | 装備個体未存在 / 該当 `poolIndex` にエンチャント無し | なし |

処理内容:

1. 認証検証
2. 装備個体取得（未存在は 404）
3. 該当 `poolIndex` のエンチャントレコードを物理削除（無ければ 404）
4. 更新後レスポンスを 200 で返す

### プリセット削除

HTTPメソッド: `DELETE`
パス: `/api/equipment/loadouts/{loadoutId}?updated_by={updatedBy}`
コントローラ: `EquipmentLoadoutController`
アクション物理名: `DeleteLoadout`

リクエスト:

| 種別 | 名前 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| Header | `X-Api-Key` | string | ✓ | API キー |
| Path | `loadoutId` | GUID | ✓ | 削除対象UUID |
| Query | `updated_by` | GUID | ✓ | 削除実行者UUID |

レスポンス:

| ステータス | 内容 | ボディ |
|---|---|---|
| 204 No Content | 削除成功（論理削除） | なし |
| 400 Bad Request | クエリ欠落/不正 | エラーオブジェクト |
| 401 Unauthorized | API キー未指定/無効 | なし |
| 404 Not Found | 未登録/論理削除済み | なし |

### スロット解除

コントローラ: `EquipmentLoadoutController`
アクション物理名: `RemoveSlot`

リクエスト:

| 種別 | 名前 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| Header | `X-Api-Key` | string | ✓ | API キー |
| Path | `loadoutId` | GUID | ✓ | プリセットUUID |
| Path | `slotType` | string | ✓ | スロット種別 |
| Path | `slotIndex` | int | ✓ | スロット内番号 |
| Query | `updated_by` | GUID | ✓ | 更新実行者UUID |

レスポンス:

| ステータス | 内容 | ボディ |
|---|---|---|
| 204 No Content | 解除成功 | なし |
| 400 Bad Request | クエリ欠落/不正 | エラーオブジェクト |

| 404 Not Found | プリセット or 該当スロット未存在 | なし |
