# 14_3.04-削除系

## 1. 削除系エンドポイント仕様

### エンチャント削除

HTTPメソッド: `DELETE`
パス: `/api/equipment/enchant`
コントローラ: `EquipmentController`
アクション物理名: `DeleteEnchant`

責務:

指定した `slotIndex` の現在エンチャントを物理削除する。

リクエスト:

| 種別 | 名前 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| Header | `X-Api-Key` | string | ✓ | API キー |
| Header | `Content-Type` | string | ✓ | `application/json` |
| Body | (全体) | [[14_1.00-モデル定義]].3.2 エンチャント削除 | ✓ | 削除対象 |

レスポンス:

| ステータス | 内容 | ボディ |
|---|---|---|
| 200 OK | 削除成功 | [[14_1.00-モデル定義]].装備インスタンスレスポンス（更新後） |
| 401 Unauthorized | API キー未指定/無効 | なし |
| 404 Not Found | 装備個体未存在、所有不一致、該当 `slotIndex` にエンチャント無し | なし |

処理内容:

1. 認証検証
2. 装備個体取得後、`updatedBy == equipment.accountId` を検証（未存在・所有不一致は404）
3. 該当 `slotIndex` のエンチャントレコードを物理削除（無ければ404）
4. 更新後レスポンスを 200 で返す

### ルーン脱着

HTTPメソッド: `POST`
パス: `POST /api/equipment/orb-operations`（`RUNE_DETACH` オーブ）
コントローラ: `EquipmentController`
アクション物理名: `UnequipRune`

責務:

指定スロットのルーンを取り外し、オーブ1個の消費とルーン1個の通常インベントリ返却を同一トランザクションで行う。

リクエスト:

| 種別 | 名前 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| Header | `X-Api-Key` | string | ✓ | API キー |
| Header | `Content-Type` | string | ✓ | `application/json` |
| Body | (全体) | [[14_1.00-モデル定義]].3.1 オーブ装備操作 | ✓ | `runeSlotIndex` を指定した脱着対象 |

レスポンス:

| ステータス | 内容 | ボディ |
|---|---|---|
| 200 OK | 台帳へ確定した脱着の業務結果（成功・失敗を含む） | `EquipmentOrbOperationResponse` |
| 400 Bad Request | `runeSlotIndex` の形式不正 | エラーオブジェクト |
| 401 Unauthorized | API キー未指定/無効 | なし |

### プリセット削除

HTTPメソッド: `DELETE`
パス: `/api/equipment/loadouts/{loadoutId}?updated_by={updatedBy}`
コントローラ: `EquipmentLoadoutController`
アクション物理名: `DeleteLoadout`

リクエスト:

| 種別 | 名前 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| Header | `X-Api-Key` | string | ✓ | API キー |
| Path | `loadoutId` | GUID | ✓ | 削除対象UUID |
| Query | `updated_by` | GUID | ✓ | 削除実行者UUID |

レスポンス:

| ステータス | 内容 | ボディ |
|---|---|---|
| 204 No Content | 削除成功（論理削除） | なし |
| 400 Bad Request | クエリ欠落/不正 | エラーオブジェクト |
| 401 Unauthorized | API キー未指定/無効 | なし |
| 404 Not Found | 未登録/論理削除済み | なし |

---

### スロット解除

HTTPメソッド: `DELETE`
パス: `/api/equipment/loadouts/{loadoutId}/slots/{slotType}/{slotIndex}?updated_by={updatedBy}`
コントローラ: `EquipmentLoadoutController`
アクション物理名: `RemoveSlot`

リクエスト:

| 種別 | 名前 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| Header | `X-Api-Key` | string | ✓ | API キー |
| Path | `loadoutId` | GUID | ✓ | プリセットUUID |
| Path | `slotType` | string | ✓ | スロット種別 |
| Path | `slotIndex` | int | ✓ | スロット内番号 |
| Query | `updated_by` | GUID | ✓ | 更新実行者UUID |

レスポンス:

| ステータス | 内容 | ボディ |
|---|---|---|
| 204 No Content | 解除成功 | なし |
| 400 Bad Request | クエリ欠落/不正 | エラーオブジェクト |
| 401 Unauthorized | API キー未指定/無効 | なし |
| 404 Not Found | プリセット or 該当スロット未存在 | なし |
