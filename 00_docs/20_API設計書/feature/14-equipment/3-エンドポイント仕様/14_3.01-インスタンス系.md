# 14_3.01-インスタンス系

## 1. 装備インスタンス作成

HTTPメソッド: `POST`
パス: `/api/equipment/instances`
コントローラ: `EquipmentController`
アクション物理名: `CreateInstance`

責務:

YAML マスタ（[[04_README]]）の装備定義をもとに装備個体を生成して保存する。
ステータス乱数ロールは作成時に実値へ解決され、レスポンスには現在のエンチャント一覧も含まれる。

リクエスト:

| 種別 | 名前 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| Header | `X-Api-Key` | string | ✓ | API キー |
| Header | `Content-Type` | string | ✓ | `application/json` |
| Body | (全体) | [[14_1.00-モデル定義]].装備インスタンス作成リクエスト | ✓ | 生成内容 |

レスポンス:

| ステータス | 内容 | ボディ |
|---|---|---|
| 201 Created | 作成成功 | [[14_1.00-モデル定義]].装備インスタンスレスポンス |
| 400 Bad Request | バリデーション失敗 | エラーオブジェクト |
| 401 Unauthorized | API キー未指定/無効 | なし |
| 404 Not Found | `accountId` または `equipmentId` が未存在 | なし |

処理内容:

1. 認証パイプラインで `X-Api-Key` を検証する
2. リクエストのバリデーション（必須項目）
3. `accountId` の存在確認

    | 項目 | 内容 |
    |---|---|
    | 検索対象 | `dbo.account`（`is_deleted = 0`） |
    | 未存在 | 404 を返す |

4. `equipmentId` の存在確認（YAML マスタ）

    | 項目 | 内容 |
    |---|---|
    | 検索対象 | MasterDataDB 上の `item` マスタ |
    | 未存在 | 404 を返す |

5. 装備個体を生成

    | 項目 | 内容 |
    |---|---|
    | `equipmentInstanceId` | `Guid.NewGuid()` |
    | `enhanceLevel` | 0 |
    | `transcendenceRank` | 0 |
    | `runeMaxSlots` | YAML の `equipment.rune.maxSlots` を解決した値 |
    | `durabilityMax` / `durabilityValue` | YAML の `durability.max` |
    | `statRolls` | YAML の `stats[]` の `value` を範囲指定なら乱数解決、固定なら固定値で確定 |

6. 生成結果を 201 で返す
7. 例外時は [[14_5.00-例外・ログ・運用]].インスタンス系 のログを記録し 500 を返す

---

## 2. 装備インスタンス取得

HTTPメソッド: `GET`
パス: `/api/equipment/instances/{instanceId}`
コントローラ: `EquipmentController`
アクション物理名: `GetInstance`

リクエスト:

| 種別 | 名前 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| Header | `X-Api-Key` | string | ✓ | API キー |
| Path | `instanceId` | GUID | ✓ | 装備個体UUID |

レスポンス:

| ステータス | 内容 | ボディ |
|---|---|---|
| 200 OK | 取得成功 | [[14_1.00-モデル定義]].装備インスタンスレスポンス |
| 401 Unauthorized | API キー未指定/無効 | なし |
| 404 Not Found | 未登録/論理削除済み | なし |

処理内容:

1. 認証パイプラインで `X-Api-Key` を検証する
2. リポジトリから装備個体を取得（関連 `statRolls`, `enchants`, `runes` を含む）

    | 項目 | 内容 |
    |---|---|
    | 検索キー | `equipmentInstanceId` |
    | 取得対象 | `is_deleted = 0` |
    | 未存在 | 404 を返す |

3. `enchantPools` は YAML マスタ（[[04_README]]）から解決して付加
4. 200 で返す
