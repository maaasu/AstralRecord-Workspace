## 3. 操作系リクエスト（EquipmentOperationRequests）

### 3.1 オーブ装備操作

物理名: `EquipmentOrbOperationRequest`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `operationId` | GUID | ✗ | Pluginが操作開始時に発行し再送でも維持する冪等ID |
| `accountId` | GUID | ✗ | 所有アカウントUUID |
| `equipmentInstanceId` | GUID | ✗ | 対象装備個体UUID |
| `orbInventoryEntryId` | GUID | ✗ | クリック起点のオーブentry UUID |
| `orbItemId` | string | ✗ | 起点オーブitem ID。trim正規化後1～128 UTF-16 code unit |

物理名: `EquipmentOrbOperationResponse`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `operationId` | GUID | ✗ | 確定した冪等ID |
| `result` | string | ✗ | `APPLIED` / `NOT_ELIGIBLE` / `PAYMENT_UNAVAILABLE` / `NO_SLOT` / `NO_CANDIDATE` / `OPERATION_CONFLICT` |
| `operationType` | string | ✗ | `ENHANCE` / `REPAIR` / `TRANSCENDENCE` / `ENCHANT` |
| `equipment` | EquipmentInstanceResponse | ✓ | commit後およびreplay/GET時点で `targetAvailable=true` の対象現在値。業務失敗でも対象が利用可能なら返し、利用不能時はnull |
| `targetAvailable` | bool | ✗ | 台帳accountが対象を現在も所有し、GAME BAG/HOTBARまたはactive loadoutに保持する場合true。譲渡・削除・membership欠落時false |
| `affectedInventoryEntryIds` | GUID[] | ✗ | PluginがAPI正本へ照合するentry IDs。業務失敗時も起点オーブentryを含み、別serverでの消失を反映する |
| `paymentConsumed` | bool | ✗ | 支払いがcommit済みならtrue |
| `enhancementSucceeded` | bool | ✗ | 強化抽選の成否 |
| `failAction` | string | ✓ | 強化失敗動作 |
| `successRate` | double | ✓ | 台帳へ固定した成功率 |
| `repairedAmount` | int | ✓ | 修理回復量 |
| `transitionName` | string | ✓ | 状態変化先表示名 |

### 4.5 ACCESSORY の slotIndex

API と DB のロードアウトではオフハンドを含む10枠を `slotType=ACCESSORY` として保持する。プラグインの `ACCESSORY_SLOT.slotIndex` は次の値へ1引いて変換する。

| `slotIndex` | 用途 | item master tag |
|---:|---|---|
| 0 | オフハンド | `equipment.slot=SUBWEAPON` |
| 1 | アミュレット | `AMULET` |
| 2, 3 | タリスマン | `TALISMAN` |
| 4, 5, 6 | チャーム | `CHARM` |
| 7 | コア | `CORE` |
| 8, 9 | レリック | `RELIC` |
