# 14_1.00-モデル定義

## 1. 装備インスタンスレスポンス

物理名: `EquipmentInstanceResponse`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `equipmentInstanceId` | GUID | ✗ | 装備個体UUID |
| `accountId` | GUID | ✗ | 所有アカウントUUID |
| `itemId` | string | ✗ | YAML 上の装備 ID |
| `enhanceLevel` | int | ✗ | 現在の強化レベル |
| `runeMaxSlots` | int | ✗ | 現在の最大ルーンスロット数 |
| `transcendenceRank` | int | ✗ | 状態変化ランク（0 は未状態変化） |
| `durabilityMax` | int | ✗ | 現在の最大耐久値 |
| `durabilityValue` | int | ✗ | 現在の耐久値 |
| `createdAt` | DateTime | ✗ | 作成日時 |
| `updatedAt` | DateTime | ✗ | 更新日時 |
| `statRolls` | object[] | ✗ | ステータスロール |
| `statRolls[].statRollId` | GUID | ✗ | ロール UUID |
| `statRolls[].status` | string | ✗ | ステータス名 |
| `statRolls[].min` | string | ✗ | 確定下限値（または固定値） |
| `statRolls[].max` | string | ✗ | 確定上限値（または固定値） |
| `statRolls[].sortOrder` | int | ✗ | 表示順 |
| `enchants` | object[] | ✗ | 付与エンチャント一覧 |
| `enchants[].enchantId` | GUID | ✗ | エンチャントレコード UUID |
| `enchants[].slotIndex` | int | ✗ | スロット番号 |
| `enchants[].poolIndex` | int | ✗ | プール番号 |
| `enchants[].status` | string | ✗ | 付与ステータス |
| `enchants[].type` | string | ✗ | `FLAT` / `SCALAR` |
| `enchants[].value` | decimal | ✗ | 付与値 |
| `runes` | object[] | ✗ | 装着ルーン一覧 |
| `runes[].runeId` | GUID | ✗ | 装着レコード UUID |
| `runes[].runeInstanceId` | GUID | ✓ | 紐づくルーン個体 UUID |
| `runes[].slotIndex` | int | ✗ | ルーンスロット番号 |
| `runes[].itemId` | string | ✗ | 装着中ルーン itemId |
| `enchantPools` | object[] | ✗ | 参照用プール構成 |
| `enchantPools[].poolIndex` | int | ✗ | プール番号 |
| `enchantPools[].recipeId` | string | ✓ | レシピ ID |
| `enchantPools[].requiredMaterialItemId` | string | ✗ | 必要素材アイテム ID |
| `enchantPools[].requiredMaterialAmount` | int | ✗ | 必要素材数 |
| `enchantPools[].requiredCurrency` | int | ✗ | 必要通貨 |

## 2. 装備インスタンス作成リクエスト

物理名: `EquipmentCreateRequest`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `equipmentId` | string | ✗ | YAML 上の装備 ID |
| `accountId` | GUID | ✗ | 所有アカウントUUID |
| `source` | string | ✓ | 生成元の識別子（例: `loot_drop`） |
| `createdBy` | GUID | ✗ | 作成者UUID |

## 3. 操作系リクエスト（EquipmentOperationRequests）

### 3.1 エンチャント実施

物理名: `EquipmentEnchantRequest`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `equipmentInstanceId` | GUID | ✗ | 対象装備個体UUID |
| `poolIndex` | int | ✗ | 使用プール番号 |
| `updatedBy` | GUID | ✗ | 更新者UUID |

### 3.2 エンチャント削除

物理名: `EquipmentEnchantDeleteRequest`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `equipmentInstanceId` | GUID | ✗ | 対象装備個体UUID |
| `poolIndex` | int | ✗ | 対象プール番号 |

### 3.3 強化実施

物理名: `EquipmentEnhanceRequest`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `equipmentInstanceId` | GUID | ✗ | 対象装備個体UUID |
| `targetLevel` | int | ✗ | 目標強化レベル |
| `updatedBy` | GUID | ✗ | 更新者UUID |

### 3.4 状態変化実施

物理名: `EquipmentTranscendenceRequest`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `equipmentInstanceId` | GUID | ✗ | 対象装備個体UUID |
| `targetRank` | int | ✗ | 目標 transcendenceRank（現在値より大きい値） |
| `updatedBy` | GUID | ✗ | 更新者UUID |

### 3.5 ルーン装着

物理名: `EquipmentRuneEquipRequest`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `equipmentInstanceId` | GUID | ✗ | 対象装備個体UUID |
| `runeInstanceId` | GUID | ✗ | ルーン個体UUID |
| `runeItemId` | string | ✗ | ルーンの itemId |
| `slotIndex` | int | ✓ | スロット番号（未指定で空きへ自動装着） |
| `updatedBy` | GUID | ✗ | 更新者UUID |

### 3.6 ルーン脱着

物理名: `EquipmentRuneUnequipRequest`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `equipmentInstanceId` | GUID | ✗ | 対象装備個体UUID |
| `slotIndex` | int | ✗ | スロット番号 |

## 4. ロードアウト（EquipmentLoadoutModels）

### 4.1 ロードアウトレスポンス

物理名: `EquipmentLoadoutResponse`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `equipmentLoadoutId` | GUID | ✗ | プリセットUUID |
| `accountId` | GUID | ✗ | 所有アカウントUUID |
| `loadoutProfile` | string | ✗ | `GAME` / `BUILDER` |
| `loadoutName` | string | ✗ | プリセット名 |
| `sortOrder` | int | ✗ | 並び順 |
| `isActive` | bool | ✗ | 選択中フラグ |
| `metadataJson` | string | ✓ | 拡張メタデータ |
| `slots` | object[] | ✗ | スロット一覧 |
| `slots[].equipmentLoadoutSlotId` | GUID | ✗ | スロットUUID |
| `slots[].slotType` | string | ✗ | `WEAPON` / `SUBWEAPON` / `HEAD` / `CHEST` / `LEGS` / `FEET` / `ACCESSORY` / `TOOL` 等 |
| `slots[].slotIndex` | int | ✗ | スロット内番号 |
| `slots[].equipmentInstanceId` | GUID | ✗ | 装備個体UUID |

| `updatedBy` | GUID | ✗ | 更新者UUID（必須） |
