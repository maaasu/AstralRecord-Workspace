# 23_5.00-例外・ログ・運用

ログ・メッセージはハードコーディング。LogId は使用しない。

## 1. 共通エラーレスポンス

| ステータス | 発生条件 | ボディ |
|---|---|---|
| 400 Bad Request | 入力不正、価格ガード不合格、出品数上限超過、残高不足 | `ProblemDetails` 互換 |
| 401 Unauthorized | API キー未指定/無効 | なし |
| 403 Forbidden | 他アカウントの出品キャンセルなど権限不正 | `ProblemDetails` 互換 |
| 404 Not Found | 出品、アカウント、item、個体が存在しない | なし |
| 409 Conflict | 既に購入済み、出品状態競合、所有権競合、二重購入 | `ProblemDetails` 互換 |
| 500 Internal Server Error | 上記以外の例外 | `ProblemDetails` 互換 |

## 2. 価格ガードエラー

| コード | 条件 | HTTP |
|---|---|---|
| `market.price_below_sell_price` | `unitPrice < sellPrice` | 400 |
| `market.price_out_of_range` | 信頼度 `HIGH` / `MEDIUM` の相場許容範囲外 | 400 |
| `market.low_confidence_price_too_high` | 信頼度 `LOW` の低信頼時上限超過 | 400 |
| `market.sell_price_missing` | item マスタに店売り価格がなく出品不可 | 400 |
| `market.listing_slot_limit_exceeded` | `ACTIVE` / `SUSPENDED` / `CANCELED` を含む出品枠上限超過 | 400 |
| `market.unsupported_currency` | `currencyId` が Gold 以外 | 400 / 409 |
| `market.insufficient_gold` | 購入者の Plugin Gold 不足 | 400 |

## 4. 運用上の注意

- 相場許容範囲は経済バランスに強く影響するため、初期値を設定ファイル化できる実装にする。
- `market_price_snapshot` は監査・Web 表示・調査用に保持し、約定価格の正本は `market_transaction` とする。
- 異常価格の出品が既に `ACTIVE` の場合は、運用または定期処理で `SUSPENDED` に変更できるようにする。
- 出品数 Tier は成立取引数から計算し、手動で上限を書き換えない。
