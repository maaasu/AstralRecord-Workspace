# 23_5.00-例外・ログ・運用

ログ・メッセージはハードコーディング。LogId は使用しない。

## 1. 共通エラーレスポンス

| ステータス | 発生条件 | ボディ |
|---|---|---|
| 400 Bad Request | 入力不正、価格ガード不合格、出品数上限超過、残高不足 | `ProblemDetails` 互換 |
| 401 Unauthorized | API キー未指定/無効 | なし |
| 403 Forbidden | 他アカウントの出品キャンセルなど権限不正 | `ProblemDetails` 互換 |
| 404 Not Found | 出品、アカウント、item、個体が存在しない | なし |
| 409 Conflict | 既に購入済み、出品状態競合、所有権競合、二重購入 | `ProblemDetails` 互換 |
| 500 Internal Server Error | 上記以外の例外 | `ProblemDetails` 互換 |

## 2. 価格ガードエラー

| コード | 条件 | HTTP |
|---|---|---|
| `market.price_guard_rejected` | `unitPrice <= sellPrice`、または相場許容範囲外 | 400 |
| `market.price_out_of_range` | 信頼度 `HIGH` / `MEDIUM` の相場許容範囲外 | 400 |

| `market.listing_slot_limit_exceeded` | `ACTIVE` / `SUSPENDED` / 売上未受取 `SOLD` を含む出品枠上限超過 | 400 |
| `market.unsupported_currency` | `currencyId` が Gold 以外 | 400 / 409 |
| `market.insufficient_gold` | 購入者の Plugin Gold 不足 | 400 |
| `market.self_purchase` | buyer と seller が同一 | 400 |
| `market.insufficient_listing_quantity` | 購入数量が出品残数を超過 | 409 |
| `market.invalid_purchase_request` | 購入数量または冪等キーが未指定・範囲外 | 400 |
| `market.idempotency_conflict` | 購入済み冪等キーを別出品または別数量で再利用 | 409 |
| `market.purchase_receipt_invalid` | 保存済み購入 receipt が欠損または破損している | 409 |
| `market.destination_quantity_overflow` | 購入品の既存スタックへ数量を加算すると `bigint` 上限を超える | 409 |
| `market.claim_invalid_status` | `SOLD` 以外の出品で売上受取を試行 | 400 |
| `market.invalid_claim_request` | 売上受取の冪等キーが未指定または長すぎる | 400 |
| `market.claim_already_completed` | 別の冪等キーで受取済み出品を再受取しようとした | 409 |
| `market.claim_receipt_invalid` | 保存済み受取 receipt が破損している | 409 |

## 4. 運用上の注意

- 相場許容範囲は経済バランスに強く影響するため、初期値を設定ファイル化できる実装にする。
- `market_price_snapshot` は監査・Web 表示・調査用に保持し、約定価格の正本は `market_transaction` とする。
- 異常価格の出品が既に `ACTIVE` の場合は、運用または定期処理で `SUSPENDED` に変更できるようにする。
- 出品数 Tier の基本枠は成立取引数から計算し、手動で上限を書き換えない。マーケット拡張トークンの有効枠は GAME/CURRENCY inventory の所持数から API が算出し、種類ごとの上限を超えた所持数は枠へ加算しない。
- 売上は購入時ではなく `claim-proceeds` 成功時に seller Gold へ加算する。`SOLD` は受取完了まで出品枠を消費する。同じ `idempotencyKey` の再送は receipt を再生するため、HTTP 応答喪失後も Gold を二重加算しない。
