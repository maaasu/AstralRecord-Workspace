# 23_1.00-モデル定義

## 1. マーケット出品レスポンス

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `listingId` | GUID | ✗ | 出品 UUID |
| `sellerAccountId` | GUID | ✗ | 出品アカウント UUID |
| `sellerAccountName` | string | ✗ | 出品アカウントの表示名。公開中の出品画面で出品者を確認するために使用する |
| `buyerAccountId` | GUID | ✓ | 購入アカウント UUID。未購入時は null |
| `sourceInventoryEntryId` | GUID | ✓ | 互換用の先頭 escrow 元 inventory entry。複数 source の正本は `sourceInventoryEntryIds` |
| `itemCategory` | string | ✗ | `material` / `consumable` / `equipment` / `rune` 等 |
| `itemId` | string | ✗ | item マスタ ID |
| `instanceType` | string | ✓ | `EQUIPMENT`。スタック品は null |
| `instanceId` | GUID | ✓ | 個体 UUID。スタック品は null |
| `sourceInventoryEntryIds` | GUID[] | ✗ | 出品作成・キャンセル応答だけで返す escrow 元 inventory entry の一覧。Plugin の正本再同期に使用する |
| `quantity` | int | ✗ | 出品時の総数量 |
| `remainingQuantity` | int | ✗ | 現在 escrow に残る購入可能数量。`SOLD` と取り下げ済みは 0 |
| `currencyId` | string | ✗ | 支払い通貨 ID。既定は `gold` |
| `unitPrice` | long | ✗ | 1 個あたりの出品価格 |
| `totalPrice` | long | ✗ | `unitPrice * quantity` |
| `priceFloor` | long | ✗ | 店売り価格下限 |
| `referenceUnitPrice` | long | ✓ | 相場参照単価 |
| `priceDeviationRate` | decimal | ✓ | `unitPrice / referenceUnitPrice` |
| `priceConfidence` | string | ✗ | `HIGH` / `MEDIUM` / `LOW` |
| `valuationSignature` | string | ✓ | 相場評価シグネチャ |
| `valuationSnapshot` | object | ✓ | 出品時の評価詳細 |
| `status` | string | ✗ | `ACTIVE` / `SOLD` / `CANCELED` / `EXPIRED` / `SUSPENDED` |
| `statusReason` | string | ✓ | 停止・キャンセル理由 |
| `listedAt` | DateTime | ✗ | 出品日時 |
| `expiresAt` | DateTime | ✗ | 掲載期限 |
| `soldAt` | DateTime | ✓ | 購入成立日時 |
| `canceledAt` | DateTime | ✓ | キャンセル日時 |
| `version` | int | ✗ | 楽観ロック用バージョン |
| `createdAt` | DateTime | ✗ | 作成日時 |
| `updatedAt` | DateTime | ✗ | 更新日時 |
| `pendingProceeds` | long | ✗ | 売上受取前の約定売上合計。`ACTIVE` 中は受取不可 |

## 2. マーケット出品作成リクエスト

物理名: `MarketListingCreateRequest`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `sellerAccountId` | GUID | ✗ | 出品アカウント UUID |
| `sourceEntries` | object[] | ✗ | `inventoryEntryId` と `quantity` を持つ escrow 元一覧。合計は `quantity` と一致させる |
| `itemCategory` | string | ✗ | item カテゴリ |
| `itemId` | string | ✗ | item マスタ ID |
| `instanceType` | string | ✓ | 個体品の種別 |
| `instanceId` | GUID | ✓ | 個体 UUID |
| `quantity` | int | ✗ | 出品数量。個体品は 1 |
| `currencyId` | string | ✗ | 支払い通貨 ID |
| `unitPrice` | long | ✗ | 1 個あたりの出品価格 |
| `expiresAt` | DateTime | ✓ | 掲載期限。未指定時は API 既定値 |
| `createdBy` | GUID | ✗ | 作成者 UUID |

ルール:

- スタック品は `sourceEntries` を 1 件以上指定し、`instanceType` / `instanceId` は null。
- 個体品は `instanceType` / `instanceId` 必須で、`sourceEntries` は数量 1 の 1 件だけ指定する。
- `quantity` は 1 以上。個体品は必ず 1。
- `unitPrice` は 1 以上かつ `saleValue` より大きい。

## 7. 売上受取リクエスト・レスポンス

物理名: `MarketProceedsClaimRequest` / `MarketProceedsClaimResponse`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| request.`sellerAccountId` | GUID | ✗ | 出品アカウント UUID |
| request.`idempotencyKey` | string | ✗ | 同一出品の受取再送で固定する冪等キー |
| request.`updatedBy` | GUID | ✗ | 更新者 UUID |
| response.`listingId` | GUID | ✗ | 売上受取済み出品 UUID |
| response.`amount` | long | ✗ | 出品者へ加算した売上金額 |
| response.`affectedInventoryEntryIds` | GUID[] | ✗ | Plugin が出品者の通貨正本を再同期する対象 |

`idempotencyKey` が同じ再送では、受取済みで論理削除済みの出品であっても、永続化した receipt の `amount` と `affectedInventoryEntryIds` を 200 で再生する。異なるキーでの二重受取は拒否する。

## 8. マーケット取引レスポンス

物理名: `MarketTransactionResponse`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `transactionId` | GUID | ✗ | 取引 UUID |
| `listingId` | GUID | ✗ | 出品 UUID |
| `sellerAccountId` | GUID | ✗ | 出品者アカウント UUID |
| `buyerAccountId` | GUID | ✗ | 購入者アカウント UUID |
| `itemCategory` | string | ✗ | item カテゴリ |
| `itemId` | string | ✗ | item マスタ ID |
| `instanceType` | string | ✓ | 個体品の種別 |
| `instanceId` | GUID | ✓ | 個体 UUID |
| `quantity` | int | ✗ | 購入数量 |
| `currencyId` | string | ✗ | 支払い通貨 ID |
| `unitPrice` | long | ✗ | 単価 |
| `totalPrice` | long | ✗ | 総額 |
| `feeAmount` | long | ✗ | 手数料 |
| `sellerProceeds` | long | ✗ | 売主受取額 |
| `affectedInventoryEntryIds` | GUID[] | ✗ | 購入者が Plugin inventory を API 正本へ再同期するための更新 entry ID |
| `completedAt` | DateTime | ✗ | 成立日時 |

`idempotencyKey` が同じ購入要求の再送では、決済時に永続化した `affectedInventoryEntryIds` を含む receipt を 200 で再生する。同じキーを別の出品 ID または購入数で再利用した場合は `market.idempotency_conflict` で拒否する。
