# 23_2.00-ユースケース

## 1. 相場確認

1. Plugin または Web が、対象アイテムと任意の出品予定価格を指定して相場見積を要求する。
2. API は item マスタ、個体状態、約定履歴、出品中価格を参照して相場を算出する。
3. API は許容価格帯、信頼度、出品可否判定を返す。
4. Plugin または Web は判定結果を表示する。

## 2. 出品

1. 出品者が Plugin または Web で出品価格と数量を入力する。
2. 呼び出し元は [[23_3.02-登録系]].マーケット出品作成 を呼び出す。
3. API は所有権、出品数制限、店売り価格下限、相場乖離を検証する。
4. API は対象アイテムを escrow として確保し、出品を `ACTIVE` にする。
5. 呼び出し元は作成された出品情報を表示する。

## 3. 購入

1. 購入者が Plugin または Web で `ACTIVE` 出品を選択する。
2. 呼び出し元は [[23_3.02-登録系]].マーケット購入確定 を呼び出す。
3. API は出品状態、購入者残高、購入者インベントリ受取可否を検証する。
4. API はアイテム所有権を購入者へ移転し、出品を `SOLD` にする。
5. API は約定履歴を作成し、双方の成立取引数を更新する。
6. 通貨残高の減算・加算は `Q-MARKET-001` の API 正本化完了後に有効化する。初期実装では約定履歴に価格を記録する。

## 4. キャンセル

1. 出品者が自分の `ACTIVE` 出品をキャンセルする。
2. 呼び出し元は [[23_3.03-更新系]].マーケット出品キャンセル を呼び出す。
3. API は出品者本人であることと状態を検証する。
4. API は escrow 中のアイテムを出品者へ返却し、出品を `CANCELED` にする。

## 5. Web 参照

1. Web は [[23_3.01-取得系]].マーケット出品一覧取得 と [[23_3.01-取得系]].アカウントマーケット概要取得 を呼び出す。
2. Web は API から返る `status`、`priceConfidence`、`allowedMinUnitPrice`、`allowedMaxUnitPrice` を表示補助に使う。
3. Web は独自の価格判定・制限判定を持たない。

## 6. 期限切れ処理

1. API の定期処理または一覧取得時の補正処理が `expiresAt < now` の `ACTIVE` 出品を検出する。
2. API は該当出品を `EXPIRED` に更新する。
3. API は escrow 中のアイテムを出品者へ返却する。
4. 期限切れ出品は出品数制限のカウント対象外になる。
