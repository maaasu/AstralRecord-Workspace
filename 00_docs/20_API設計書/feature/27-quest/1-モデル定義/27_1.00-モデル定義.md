# account-quest モデル定義

## AccountQuestStateResponse

| フィールド | 型 | 説明 |
|:--|:--|:--|
| `accountQuestStateId` | UUID または null | 保存済み親行 ID |
| `accountId` | UUID | アカウント ID |
| `activeQuests` | 配列 | 受領中クエストと目標進行 |
| `completions` | 配列 | クエスト完了日時 |
| `cooldowns` | 配列 | クールダウン終了日時 |
| `isSaved` | bool | 親行が保存済みか |
| `version` | int | 保存世代 |

時刻は Unix epoch milliseconds で送受信し、DB では `DATETIME2(3)` として保存します。

## ActiveQuest

`questId`、`acceptedAtEpochMillis`、`acceptedNpcId`、`readyToTurnIn`、`objectiveProgress` を持ちます。`objectiveProgress` は `objectiveId` と 0 以上の `progress` の配列です。

## Completion / Cooldown

`Completion` は `questId` と `completedAtEpochMillis`、`Cooldown` は `questId` と `cooldownUntilEpochMillis` を持ちます。
