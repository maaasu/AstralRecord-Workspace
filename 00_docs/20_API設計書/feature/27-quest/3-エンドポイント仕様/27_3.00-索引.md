# account-quest API エンドポイント仕様

| メソッド | パス | 概要 |
|:--|:--|:--|
| GET | `/api/account-quest/{accountId}` | アカウント単位のクエスト進行取得 |
| PUT | `/api/account-quest/{accountId}` | アカウント単位のクエスト進行置換保存 |

## GET `/api/account-quest/{accountId}`

アカウントが存在しない場合は `404 Not Found`、状態が未保存の場合は空配列と `isSaved=false` を返します。

## PUT `/api/account-quest/{accountId}`

リクエストには `activeQuests`、`completions`、`cooldowns`、`updatedBy` を指定します。保存は状態全体の置換です。同一アカウントの置換保存はSQL Serverの更新ロックで直列化し、子状態の全置換中に並行リクエストが古い行を削除して`500`となることを防ぎます。トランザクション全体は SQL Server の再試行実行戦略内で実行し、接続再試行の設定とユーザー開始トランザクションの組み合わせによる `500` を防ぎます。アカウントが存在しない場合は `404 Not Found` を返します。

各quest ID・objective ID・accepted NPC IDは空白を除き100文字以内で、同じ配列内のquest IDまたは同一quest内のobjective IDは大文字小文字を区別せず一意でなければなりません。`updatedBy`、必須配列、ID、epoch millisecondsが不正な場合は `400 Bad Request` を返します。

### SQL Server 並行置換の統合テスト

`AccountQuestStateSqlServerIntegrationTests` は Windows 認証で `localhost\SQLEXPRESS` にだけ接続し、実行ごとに `AstralRecordQuestIntegration_` 接頭辞付きのランダムな一時DBを作成します。実接続情報・パスワードは設定ファイルやソース管理へ保存しません。テストは同一アカウントへのPUTを2本同時に実行して両方の成功と最終スナップショットの完全性を確認し、`finally` で作成した接頭辞付きDBだけを削除します。

```powershell
dotnet test .\AstralRecordApi.Tests\AstralRecordApi.Tests.csproj --filter 'Category=SqlServerIntegration'
```
