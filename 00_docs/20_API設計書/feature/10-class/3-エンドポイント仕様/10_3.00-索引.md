# 10_3.00-索引

## エンドポイント一覧

| HTTPメソッド | パス | 論理名 |
|---|---|---|
| GET | `/api/class` | クラス一覧取得 |
| GET | `/api/class/{classId}` | クラス詳細取得 |

---

## 1. クラス一覧取得

HTTPメソッド: `GET`
パス: `/api/class`
コントローラ: `ClassController`
アクション物理名: `ListClasses`

リクエスト:

| 種別 | 名前 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| Header | `X-Api-Key` | string | ✓ | API キー |

レスポンス:

| ステータス | 内容 | ボディ |
|---|---|---|
| 200 OK | 取得成功 | [[10_1.00-モデル定義]].クラス一覧レスポンス要素 の配列 |
| 401 Unauthorized | API キー未指定/無効 | なし |

---

## 2. クラス詳細取得

HTTPメソッド: `GET`
パス: `/api/class/{classId}`
コントローラ: `ClassController`
アクション物理名: `GetClass`

リクエスト:

| 種別 | 名前 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| Header | `X-Api-Key` | string | ✓ | API キー |
| Path | `classId` | string | ✓ | クラス ID |

レスポンス:

| ステータス | 内容 | ボディ |
|---|---|---|
| 200 OK | 取得成功 | [[10_1.00-モデル定義]].クラス詳細レスポンス |
| 401 Unauthorized | API キー未指定/無効 | なし |
| 404 Not Found | 未定義 classId | なし |

処理内容:

1. 認証パイプラインで `X-Api-Key` を検証する
2. MasterDataDB から `master_type = class` かつ `master_id = classId` で検索する（取得失敗時は 404）
3. 200 で詳細を返す
4. 例外時は [[10_5.00-例外・ログ・運用]] のログを記録し 500 を返す
