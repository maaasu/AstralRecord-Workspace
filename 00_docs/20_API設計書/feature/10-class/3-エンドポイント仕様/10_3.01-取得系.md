# 10_3.01-取得系

## 1. 取得系エンドポイント仕様

### クラス一覧取得

HTTPメソッド: `GET`
パス: `/api/class`
コントローラ: `ClassController`
アクション物理名: `GetAll`

責務:

MasterDataDB の `dbo.master_data_entry`（`master_type = 'class'`）から有効レコードを取得し、各 `payload_json` をデシリアライズして主要項目を返す。

リクエスト:

| 種別 | 名前 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| Header | `X-Api-Key` | string | ✓ | API キー |

レスポンス:

| ステータス | 内容 | ボディ |
|---|---|---|
| 200 OK | 取得成功 | [[10_1.00-モデル定義]].クラス一覧レスポンス要素 の配列 |
| 401 Unauthorized | API キー未指定/無効 | なし |

処理内容:

1. 認証パイプラインで `X-Api-Key` を検証する
2. MasterDataDB から `master_type = 'class'` かつ `is_deleted = 0` の `payload_json` を取得する
3. 各 `payload_json` を [[10_1.00-モデル定義]].クラス詳細レスポンス へデシリアライズし、主要項目（`id` / `name` / `shortName` / `role`）に射影して 200 で配列を返す
4. 例外時は [[10_5.00-例外・ログ・運用]] のログを記録し 500 を返す

### クラス詳細取得

HTTPメソッド: `GET`
パス: `/api/class/{classId}`
コントローラ: `ClassController`
アクション物理名: `GetById`

リクエスト:

| 種別 | 名前 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| Header | `X-Api-Key` | string | ✓ | API キー |
| Path | `classId` | string | ✓ | クラス ID |

レスポンス:

| ステータス | 内容 | ボディ |
|---|---|---|
| 200 OK | 取得成功 | [[10_1.00-モデル定義]].クラス詳細レスポンス |
| 401 Unauthorized | API キー未指定/無効 | なし |
| 404 Not Found | 未定義 classId | なし |

処理内容:

1. 認証パイプラインで `X-Api-Key` を検証する
2. MasterDataDB から `master_type = 'class'` かつ `master_id = classId` で検索する（取得失敗時は 404）
3. `payload_json` を [[10_1.00-モデル定義]].クラス詳細レスポンス へデシリアライズし 200 で返す
4. 例外時は [[10_5.00-例外・ログ・運用]] のログを記録し 500 を返す
