# 10_1.00-モデル定義

## 1. クラス一覧レスポンス要素

物理名: `ClassListItem`

| フィールド | 型 | 説明 |
|---|---|---|
| `id` | string | クラス ID |
| `name` | string | クラス名 |
| `order` | number | クラス一覧で表示する順序。値が小さいクラスから表示する |
| `shortName` | string | 色・装飾コードと前後空白を除いてASCII英大文字3文字（`^[A-Z]{3}$`）かつクラス間で一意なクラス短縮名 |
| `role` | string | ロール |

## 2. クラス詳細レスポンス

物理名: `ClassResponse`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `schemaVersion` | int | ✗ | YAML スキーマバージョン |
| `id` | string | ✗ | クラス ID |
| `type` | string | ✗ | `CLASS` |
| `name` | string | ✗ | クラス名 |
| `order` | number | ✗ | クラス一覧で表示する順序。値が小さいクラスから表示する |
| `shortName` | string | ✗ | クラスの短縮表示用ASCII英大文字3文字クラス短縮名（`^[A-Z]{3}$`） |
| `description` | string | ✓ | 説明文 |
| `icon` | string | ✓ | 表示アイコン |
| `role` | string | ✗ | `TANK` / `DEALER` / `HEALER` / `SUPPORT` |
| `maxLevel` | int | ✗ | クラスレベル上限。省略時は `100` |
| `commandOnly` | bool | ✗ | `true` の場合、職業 GUI では選択できず管理コマンドのみで選択可能 |
| `unlockLevel` | int | ✗ | 解放に必要な最低プレイヤーレベル |
| `unlockClassLevel` | object[] | ✗ | 解放条件（素材クラス × レベル） |
| `unlockClassLevel[].class` | string | ✗ | 素材クラス ID |
| `unlockClassLevel[].level` | int | ✗ | 素材クラスの必要レベル |
| `baseStats` | object[] | ✗ | 初期ステータス |
| `baseStats[].status` | string | ✗ | 共有ステータスカタログのID |
| `baseStats[].value` | double | ✗ | 初期値 |
| `growthPerLevel` | object[] | ✗ | 1 レベルあたりの増加量 |
| `growthPerLevel[].status` | string | ✗ | ステータス名 |
| `growthPerLevel[].value` | double | ✗ | 増加量 |
| `expRate` | int | ✗ | 必要経験値の倍率指標（基準値 100） |
| `usableSkills` | string[] | ✗ | 現在クラスで使用を許可するスキル ID。習得・所持は付与しない |
| `tags` | string[] | ✗ | 検索・分類用タグ |
