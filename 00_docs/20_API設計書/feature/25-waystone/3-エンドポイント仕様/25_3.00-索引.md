# account-waystone API エンドポイント仕様

## エンドポイント一覧

| メソッド | パス | 概要 |
|:--|:--|:--|
| GET | `/api/account-waystone/{accountId}` | アカウント単位の開放済みウェイストーンID一覧取得 |
| POST | `/api/account-waystone/{accountId}/unlock` | ウェイストーン開放登録 |

## GET `/api/account-waystone/{accountId}`

### 目的

指定アカウントが開放済みのウェイストーンID一覧を取得する。

### リクエスト

パスパラメータ:

| 名前 | 型 | 必須 | 説明 |
|:--|:--|:--|:--|
| `accountId` | UUID | 必須 | アカウントID |

### レスポンス

- `200 OK`: [[25_1.00-モデル定義]].AccountWaystoneStateResponse
- `404 Not Found`: アカウントが存在しない

## POST `/api/account-waystone/{accountId}/unlock`

### 目的

指定アカウントが指定ウェイストーンを開放済みであることを登録する。すでに開放済みの場合は既存行を返す。

### リクエスト

パスパラメータ:

| 名前 | 型 | 必須 | 説明 |
|:--|:--|:--|:--|
| `accountId` | UUID | 必須 | アカウントID |

Body: [[25_1.00-モデル定義]].AccountWaystoneUnlockRequest

### レスポンス

- `200 OK`: [[25_1.00-モデル定義]].AccountWaystoneUnlockResponse
- `404 Not Found`: アカウントが存在しない
