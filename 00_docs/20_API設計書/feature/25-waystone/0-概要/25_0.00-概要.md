# account-waystone API 概要

`account-waystone` は、アカウント単位のウェイストーン開放状態を扱う API。

ウェイストーンの位置、表示名、常時開放フラグ、開放コストは plugin data folder の `waystones.yml` を正本とし、API はプレイヤーごとの開放済み ID のみを `dbo.account_waystone_unlock` に保存する。
