# account-waystone モデル定義

## AccountWaystoneStateResponse

| フィールド | 型 | 説明 |
|:--|:--|:--|
| `accountId` | UUID | アカウントID |
| `unlockedWaystoneIds` | string[] | 開放済みウェイストーンID一覧 |

## AccountWaystoneUnlockRequest

| フィールド | 型 | 必須 | 説明 |
|:--|:--|:--|:--|
| `waystoneId` | string | 必須 | 開放するウェイストーンID |
| `updatedBy` | UUID | 必須 | 更新者 user ID |

## AccountWaystoneUnlockResponse

| フィールド | 型 | 説明 |
|:--|:--|:--|
| `accountWaystoneUnlockId` | UUID | 開放行ID |
| `accountId` | UUID | アカウントID |
| `waystoneId` | string | 開放済みウェイストーンID |
| `unlockedAt` | datetime | 初回開放日時 |
| `createdAt` | datetime | 作成日時 |
| `updatedAt` | datetime | 更新日時 |
| `createdBy` | UUID | 作成者 |
| `updatedBy` | UUID | 更新者 |
| `isDeleted` | boolean | 論理削除フラグ |
