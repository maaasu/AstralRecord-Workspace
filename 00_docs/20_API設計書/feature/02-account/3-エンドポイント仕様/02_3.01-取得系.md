# 02_3.01-取得系

## 1. 取得系エンドポイント仕様

### ユーザー別アカウント一覧取得

HTTPメソッド: `GET`
パス: `/api/account?user_id={userId}`
コントローラ: `AccountController`
アクション物理名: `GetByUserId`

責務:

`user_id` をキーに、対象ユーザーに紐づく未削除アカウント一覧をスロット番号昇順で取得する。

リクエスト:

| 種別 | 名前 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| Header | `X-Api-Key` | string | ✓ | API キー |
| Query | `user_id` | GUID | ✓ | 所有プレイヤーUUID |

レスポンス:

| ステータス | 内容 | ボディ |
|---|---|---|
| 200 OK | 取得成功 | [[02_1.00-モデル定義]].アカウントレスポンス の配列 |
| 401 Unauthorized | API キー未指定/無効 | なし |

処理内容:

1. 認証パイプラインで `X-Api-Key` を検証する
2. リポジトリで `dbo.account` と `dbo.account_class_progress` を取得する

    | 項目 | 内容 |
    |---|---|
    | 検索キー | `user_id` |
    | 取得対象 | `is_deleted = 0` のみ |
    | 並び順 | `slot_index` 昇順 |
    | 該当なし | 空配列を返す |
    | クラス進行度 | アカウントごとの全行を `classId` 昇順で `classProgresses` に格納する |

3. 例外時は [[02_5.00-例外・ログ・運用]].取得系 のログを記録し 500 を返す

### アカウント取得

HTTPメソッド: `GET`
パス: `/api/account/{uuid}`
コントローラ: `AccountController`
アクション物理名: `GetByUuid`

責務:

UUID をキーに `dbo.account` を取得する。論理削除済みは取得対象外。

リクエスト:

| 種別 | 名前 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| Header | `X-Api-Key` | string | ✓ | API キー |
| Path | `uuid` | GUID | ✓ | アカウントUUID |

レスポンス:

| ステータス | 内容 | ボディ |
|---|---|---|
| 200 OK | 取得成功 | [[02_1.00-モデル定義]].アカウントレスポンス |
| 401 Unauthorized | API キー未指定/無効 | なし |
| 404 Not Found | 未登録または論理削除済み | なし |

処理内容:

1. 認証パイプラインで `X-Api-Key` を検証する
2. リポジトリで `dbo.account` と `dbo.account_class_progress` を取得する

    | 項目 | 内容 |
    |---|---|
    | 検索キー | `uuid` |
    | 取得対象 | `is_deleted = 0` のみ |
    | 取得失敗 | 404 を返す |
    | クラス進行度 | 全行を `classId` 昇順で `classProgresses` に格納する。行がない旧データは account の現在クラス値で 1 件補完する |

3. 例外時は [[02_5.00-例外・ログ・運用]].取得系 のログを記録し 500 を返す

### アカウント解決

HTTPメソッド: `GET`
パス: `/api/account/resolve?selector={selector}&user_mcid={mcid}`
コントローラ: `AccountController`
アクション物理名: `Resolve`

`selector` は GUID、1〜2桁のスロット番号、または3文字以上のアカウント名を受理する。スロット番号には `user_mcid` が必須で、名前は未削除アカウント全体で一意に解決する。`selector` 省略時は `user_mcid` の現在選択アカウントを返す。GUIDまたは名前に `user_mcid` を併記した場合は所属が一致する場合だけ返す。Minecraft ID 自体の文字種はこの API で制限しない。

| ステータス | 内容 |
|---|---|
| 200 OK | 一意に解決した `AccountResponse` |
| 400 Bad Request | selector と user_mcid の指定不足、またはユーザー指定なしのスロット番号 |
| 404 Not Found | 未登録、論理削除済み、または指定ユーザーに未所属 |
