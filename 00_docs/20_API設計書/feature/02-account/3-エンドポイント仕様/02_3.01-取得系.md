# 02_3.01-取得系

## 1. 取得系エンドポイント仕様

### アカウント取得

HTTPメソッド: `GET`
パス: `/api/account/{uuid}`
コントローラ: `AccountController`
アクション物理名: `GetAccount`

責務:

UUID をキーに `dbo.account` を取得する。論理削除済みは取得対象外。

リクエスト:

| 種別 | 名前 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| Header | `X-Api-Key` | string | ✓ | API キー |
| Path | `uuid` | GUID | ✓ | アカウントUUID |

レスポンス:

| ステータス | 内容 | ボディ |
|---|---|---|
| 200 OK | 取得成功 | [[02_1.00-モデル定義]].アカウントレスポンス |
| 401 Unauthorized | API キー未指定/無効 | なし |
| 404 Not Found | 未登録または論理削除済み | なし |

処理内容:

1. 認証パイプラインで `X-Api-Key` を検証する
2. リポジトリで `dbo.account` を取得する

    | 項目 | 内容 |
    |---|---|
    | 検索キー | `uuid` |
    | 取得対象 | `is_deleted = 0` のみ |
    | 取得失敗 | 404 を返す |

3. 例外時は [[02_5.00-例外・ログ・運用]].取得系 のログを記録し 500 を返す
