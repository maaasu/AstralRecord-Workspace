# 02_3.02-登録系

## 1. 登録系エンドポイント仕様

### アカウント登録

HTTPメソッド: `POST`
パス: `/api/account`
コントローラ: `AccountController`
アクション物理名: `CreateAccount`

責務:

[[02_1.00-モデル定義]].アカウント登録リクエスト を受け取り、新規 account を作成する。
account UUID はサーバ側で `Guid.NewGuid()` により生成する。

リクエスト:

| 種別 | 名前 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| Header | `X-Api-Key` | string | ✓ | API キー |
| Header | `Content-Type` | string | ✓ | `application/json` |
| Body | (全体) | [[02_1.00-モデル定義]].アカウント登録リクエスト | ✓ | 登録対象 |

レスポンス:

| ステータス | 内容 | ボディ |
|---|---|---|
| 201 Created | 登録成功 | [[02_1.00-モデル定義]].アカウントレスポンス |
| 400 Bad Request | バリデーション失敗 | エラーオブジェクト |
| 401 Unauthorized | API キー未指定/無効 | なし |

処理内容:

1. 認証パイプラインで `X-Api-Key` を検証する
2. リクエストのバリデーションを行う

    | 項目 | 内容 |
    |---|---|
| 必須項目 | `userId`, `accountName`, `mode`, `createdBy`。`slotIndex` は null 可 |
    | 失敗時 | 400 を返す |

3. 新規 account を登録する

    | 項目 | 内容 |
    |---|---|
    | `uuid` | `Guid.NewGuid()` でサーバ生成 |
    | `isActive` | 既存の未削除アカウントがある場合は `false`、初回アカウントの場合は `true` |
    | `menuShortcutsJson` | 既定値（実装依存） |
    | `level` | 既定 `1` |
    | `totalExperience` | 既定 `0` |
    | 現在クラス | `adventurer` / Lv.1 / EXP 0 |
    | クラス別進行度 | `dbo.account_class_progress` に `adventurer` Lv.1 / EXP 0 を 1 件作成 |
    | `createdAt` / `updatedAt` | サーバ現在日時 |
| `updatedBy` | リクエストの `createdBy` と同値 |

    `slotIndex` が null の場合、`SERIALIZABLE` transaction 内で未削除アカウントの `0`〜`99` の最小空き番号を採番する。明示値も同じ範囲外は 400 とする。既存スロットの作成は 409 とする。

    同一リクエストの commit 結果が不明となって実行戦略が再試行した場合は、同一 user・slot・作成属性の既存行を作成済み結果として返し、重複作成しない。

4. 登録結果を [[02_1.00-モデル定義]].アカウントレスポンス へマッピングし 201 を返す
5. 例外時は [[02_5.00-例外・ログ・運用]].登録系 のログを記録し 500 を返す

### アカウント複製

HTTPメソッド: `POST`
パス: `/api/account/{sourceUuid}/clone`
コントローラ: `AccountController`
アクション物理名: `Clone`

複製元 UUID の保存済みプレイヤー進行を、指定ユーザーのスロットへ新 UUID と新しい一意なアカウント名で複製する。新アカウントの mode は常にプレイヤー (`0`) とし、所有ユーザー、スロット、監査値も複製先で新規に設定する。

作成済み先は `overwrite=false` で 409 `TARGET_ACCOUNT_EXISTS` と先 UUID を返し、呼出し側は確認後に `overwrite=true` と同じ `expectedTargetAccountId` を送る。再実行時の先 UUID 不一致は 409 `TARGET_CHANGED` であり、上書きを行わない。複製元または先に有効な skilltree runtime session がある場合も、変更せずに 409 `SOURCE_ACCOUNT_SESSION_ACTIVE` または `TARGET_ACCOUNT_SESSION_ACTIVE` を返す。

コピー対象は account進行、クラス進行、習得skill/sigil、skill bind preset、inventory/entry、equipment/stat roll/enchant/rune/loadout/slot、skilltree状態/解除ノード、quest、waystone、guide、mob/dungeon記録、login bonus受取済み状態、market account state とする。アカウント・子行の UUID は再採番し、inventory entry と loadout slot の装備参照、および skill bind preset 内の有効な `learnedSkillId` 参照も新 UUID へ変換する。複製対象外の忘却済みまたは未所有 `learnedSkillId` はバインドから null へ置換する。複製先に既存アカウントがなければ、新アカウントを active とし `dbo.user.account_id` も新 UUID へ設定する。

`dbo.user`/user_setting、メール配信状態、snapshot、skilltree session/view/operation、各種操作台帳、マーケット出品・取引・価格履歴、trade commit、削除台帳はコピーしない。先の上書きでは既存削除処理と同じく専用データを論理削除し、ACTIVE 出品は取消すが、共有または監査履歴は旧 UUID のまま残す。
