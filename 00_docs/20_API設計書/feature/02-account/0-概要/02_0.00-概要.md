# 02_0.00-概要

## 1. 目的

API `account` 機能は `dbo.account` への CRUD 契約を提供する。  
1 ユーザが複数のキャラクター（アカウント）を持つ前提で、スロット番号・選択中フラグ・権限モード等を管理する。

## 2. コンテキスト

- 呼び出し元: プラグインの `AccountService` / `AccountRepository`
- account UUID はサーバ側で自動生成する（クライアントから指定しない）
- ユーザ作成直後に最初の account が生成される運用

## 3. 構成要素

- `Controllers/AccountController`
- `Repositories/AccountRepository`
- `Models/AccountCreateRequest`, `AccountUpdateRequest`, `AccountResponse`
- `Data/Entities/Account`

## 4. 依存関係

- `IAccountRepository` -> `AppDbContext`（`dbo.account`）
- 外部キー: `dbo.account.user_id` -> `dbo.user.uuid`
