# 02_1.00-モデル定義

## 1. アカウント登録リクエスト

物理名: `AccountCreateRequest`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `userId` | GUID | ✗ | 所有プレイヤーUUID（FK → `dbo.user.uuid`） |
| `accountName` | string | ✗ | キャラクター名 |
| `slotIndex` | int | ✗ | スロット番号（0 始まり） |
| `mode` | int | ✗ | 権限モード（0:プレイヤー / 2:管理者）。API はこの 2 値以外を受理しない。 |
| `createdBy` | GUID | ✗ | 作成者UUID |

## 2. アカウント更新リクエスト

物理名: `AccountUpdateRequest`

`null` フィールドは「更新しない」。

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `accountName` | string | ✓ | キャラクター名 |
| `isActive` | bool | ✓ | 選択中フラグ |
| `mode` | int | ✓ | 権限モード（0:プレイヤー / 2:管理者）。指定時、API はこの 2 値以外を受理しない。 |
| `menuShortcutsJson` | string | ✓ | 2x2 craft shortcut 設定 JSON |
| `level` | int | ✓ | プレイヤーレベル。`totalExperience` を同時指定する場合のみ更新可 |
| `totalExperience` | long | ✓ | 累計経験値。`level` を同時指定する場合のみ更新可 |
| `classId` | string | ✓ | 現在クラス ID |
| `classLevel` | int | ✓ | 互換更新用。`classId`（省略時は現在クラス）のレベル。`classExperience` と同時指定する場合のみ更新可 |
| `classExperience` | long | ✓ | 互換更新用。`classId`（省略時は現在クラス）の累計経験値。`classLevel` と同時指定する場合のみ更新可 |
| `classProgresses` | object[] | ✓ | クラス別進行度の一括 upsert。各要素の `classId` は重複不可 |
| `classProgresses[].classId` | string | ✗ | クラス ID。空文字不可 |
| `classProgresses[].level` | int | ✗ | 当該クラスのレベル。`1` 未満は `1` に補正 |
| `classProgresses[].experience` | long | ✗ | 当該クラスの累計経験値。負数は `0` に補正 |
| `updatedBy` | GUID | ✗ | 更新者UUID（必須） |

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `uuid` | GUID | ✗ | アカウントUUID（サーバ生成） |
| `userId` | GUID | ✗ | 所有プレイヤーUUID |
| `accountName` | string | ✗ | キャラクター名 |
| `slotIndex` | int | ✗ | スロット番号 |
| `isActive` | bool | ✗ | 選択中フラグ |
| `mode` | int | ✗ | 権限モード（0:プレイヤー / 2:管理者） |
| `menuShortcutsJson` | string | ✗ | 2x2 craft shortcut 設定 JSON |
| `level` | int | ✗ | プレイヤーレベル |
| `totalExperience` | long | ✗ | 累計経験値 |
| `classId` | string | ✗ | 現在クラス ID |
| `classLevel` | int | ✗ | 現在クラスレベルの互換ミラー |
| `classExperience` | long | ✗ | 現在クラス累計経験値の互換ミラー |
| `classProgresses` | object[] | ✗ | アカウントが保持する全クラス進行度。`classId` 昇順 |

| `updatedBy` | GUID | ✗ | 更新者UUID |
| `isDeleted` | bool | ✗ | 論理削除フラグ |

## 4. クラス進行度

物理名: `AccountClassProgressUpdateRequest` / `AccountClassProgressResponse`

- クラス進行度の永続化正本は `dbo.account_class_progress` とする。
- `classId` 変更時は転職先クラスの保存済み進行度を現在値へ復元する。未経験クラスは Lv.1 / EXP 0 で作成する。
- `AccountResponse.classLevel` / `classExperience` は現在クラスの行を反映する互換フィールドとする。
- 既存データでクラス別行がない場合は、`dbo.account` に残る現在クラス進行度を 1 件の応答として補完する。

## 5. 関連 feature

- `user` のユーザレスポンスの `accountId` は本機能で発行する `uuid` を指す。
- プラグイン側 `account` モデルへのマッピングは `02-account` プラグイン設計書を参照。

## 6. アカウント削除リクエスト

物理名: `AccountDeleteRequest`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `deletedBy` | GUID | ✗ | 削除実行者 UUID。空 UUID は受理しない。 |

## 7. アカウント削除レスポンス

物理名: `AccountDeleteResponse`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `deletedAccountId` | GUID | ✗ | 論理削除したアカウント UUID |
| `userId` | GUID | ✗ | 所有ユーザー UUID |
| `deletedSlotIndex` | int | ✗ | 削除したスロット番号 |
| `selectedAccountId` | GUID | ✗ | 削除後に `dbo.user.account_id` へ設定したアカウント UUID |
| `createdReplacement` | bool | ✗ | 最後のアカウント削除により同一スロットの初期アカウントを作成した場合は `true` |
