# 02_1.00-モデル定義

## 1. アカウント登録リクエスト

物理名: `AccountCreateRequest`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `userId` | GUID | ✗ | 所有プレイヤーUUID（FK → `dbo.user.uuid`） |
| `accountName` | string | ✗ | キャラクター名 |
| `slotIndex` | int | ✗ | スロット番号（0 始まり） |
| `mode` | int | ✗ | 権限モード（0:プレイヤー / 1:ビルダー / 2:管理者） |
| `createdBy` | GUID | ✗ | 作成者UUID |

## 2. アカウント更新リクエスト

物理名: `AccountUpdateRequest`

`null` フィールドは「更新しない」。

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `accountName` | string | ✓ | キャラクター名 |
| `isActive` | bool | ✓ | 選択中フラグ |
| `mode` | int | ✓ | 権限モード |
| `menuShortcutsJson` | string | ✓ | 2x2 craft shortcut 設定 JSON |
| `updatedBy` | GUID | ✗ | 更新者UUID（必須） |

## 3. アカウントレスポンス

物理名: `AccountResponse`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `uuid` | GUID | ✗ | アカウントUUID（サーバ生成） |
| `userId` | GUID | ✗ | 所有プレイヤーUUID |
| `accountName` | string | ✗ | キャラクター名 |
| `slotIndex` | int | ✗ | スロット番号 |
| `isActive` | bool | ✗ | 選択中フラグ |
| `mode` | int | ✗ | 権限モード |
| `menuShortcutsJson` | string | ✗ | 2x2 craft shortcut 設定 JSON |
| `createdAt` | DateTime (ISO 8601) | ✗ | 作成日時 |
| `updatedAt` | DateTime (ISO 8601) | ✗ | 更新日時 |
| `createdBy` | GUID | ✗ | 作成者UUID |
| `updatedBy` | GUID | ✗ | 更新者UUID |
| `isDeleted` | bool | ✗ | 論理削除フラグ |

## 4. 関連 feature

- `user` のユーザレスポンスの `accountId` は本機能で発行する `uuid` を指す。
- プラグイン側 `account` モデルへのマッピングは `02-account` プラグイン設計書を参照。
