# 02_5.00-例外・ログ・運用

API `account` 機能の例外応答、ログ、運用上の注意点を集約する。  
本機能のログ・メッセージはコード上にハードコーディングする。LogId は使用しない。

## 1. 共通エラーレスポンス

| ステータス | 発生条件 | ボディ |
|---|---|---|
| 401 Unauthorized | `X-Api-Key` 欠落 / 不一致 | なし |
| 400 Bad Request | Body のバリデーション失敗 | `ProblemDetails` 互換 |
| 500 Internal Server Error | 上記以外の例外 | `ProblemDetails` 互換 |

## 3. 運用上の注意

- account UUID はサーバ側で生成する。クライアント側の値は無視する。
- `userId` の存在検証は API 単体では行わない。プラグイン側で先に `01-user` API のユーザ登録を完了させる前提。
- 論理削除済みレコードへの操作は常に 404。
- アカウント削除は履歴参照を維持する論理削除であり、履歴または共有データの物理削除を行わない。
