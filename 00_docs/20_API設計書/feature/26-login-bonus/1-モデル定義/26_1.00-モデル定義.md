# login-bonus API モデル定義

## LoginBonusClaimRequest

| フィールド | 型 | 必須 | 説明 |
|:--|:--|:--|:--|
| `claimDate` | date | 必須 | 受取対象日。`YYYY-MM-DD` |
| `updatedBy` | UUID | 必須 | 更新者。Plugin からは account ID |

## LoginBonusClaimResponse

| フィールド | 型 | 説明 |
|:--|:--|:--|
| `loginBonusClaimId` | UUID | 受取ID |
| `accountId` | UUID | アカウントID |
| `claimDate` | date | 受取対象日 |
| `claimedAt` | datetime | 実際に受取登録した日時 |
| `createdAt` | datetime | 作成日時 |
| `updatedAt` | datetime | 更新日時 |
| `createdBy` | UUID | 作成者 |
| `updatedBy` | UUID | 更新者 |
| `isDeleted` | boolean | 論理削除 |
| `wasCreated` | boolean | このリクエストで新規登録された場合は `true`。既に受取済みの場合は `false` |
