# login-bonus API エンドポイント仕様

## エンドポイント一覧

| メソッド | パス | 概要 |
|:--|:--|:--|
| GET | `/api/login-bonus/claims?account_id={accountId}&from={from}&to={to}` | アカウント単位のログインボーナス受取履歴を取得 |
| POST | `/api/login-bonus/accounts/{accountId}/claims` | ログインボーナス受取済み日を登録 |

## GET `/api/login-bonus/claims`

### 目的

指定アカウントのログインボーナス受取履歴を取得する。Plugin の月間 GUI 表示では `from` と `to` に表示月の初日・末日を指定する。

### リクエスト

Query:

| 名前 | 型 | 必須 | 説明 |
|:--|:--|:--|:--|
| `account_id` | UUID | 必須 | アカウントID |
| `from` | date | 任意 | 取得開始日 |
| `to` | date | 任意 | 取得終了日 |

### レスポンス

- `200 OK`: [[26_1.00-モデル定義]].LoginBonusClaimResponse の配列
- `404 Not Found`: アカウントが存在しない

## POST `/api/login-bonus/accounts/{accountId}/claims`

### 目的

指定アカウントが指定日付のログインボーナスを受け取ったことを登録する。
`account_id + claim_date` の一意制約により、サーバー再起動後も二重受取を防ぐ。

### リクエスト

Path:

| 名前 | 型 | 必須 | 説明 |
|:--|:--|:--|:--|
| `accountId` | UUID | 必須 | アカウントID |

Body: [[26_1.00-モデル定義]].LoginBonusClaimRequest

### レスポンス

- `200 OK`: [[26_1.00-モデル定義]].LoginBonusClaimResponse
- `400 Bad Request`: `claimDate` または `updatedBy` が不正
- `404 Not Found`: アカウントが存在しない

### 二重受取時

既に同じ `accountId` / `claimDate` の有効行が存在する場合、既存行を返し、`wasCreated=false` とする。
