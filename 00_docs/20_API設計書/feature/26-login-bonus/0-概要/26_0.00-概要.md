# login-bonus API 概要

ログインボーナスの受取済み日付を、アカウント単位で永続化する API。

## 目的

- サーバー再起動後も、同じアカウントが同じ日付のログインボーナスを再受取できないようにする。
- GUI 表示時に、指定月の受取済み日付を参照できるようにする。
- 保守時に、いつ受け取ったかを `claimedAt` で追跡できるようにする。

## 保存先

- DB: `AstralRecord`
- テーブル: `dbo.login_bonus_claim`
- 日付: `claimDate` は Plugin 側で Asia/Tokyo の日付として算出する。
