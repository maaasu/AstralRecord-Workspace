# 04_1.00-モデル定義

## 1. アイテム一覧レスポンス要素

物理名: `ItemListItem`（`ItemResponse` 縮約）

| フィールド | 型 | 説明 |
|---|---|---|
| `id` | string | アイテムID |
| `category` | string | カテゴリ |

## 2. アイテム詳細レスポンス

物理名: `ItemResponse`

### 2.1 共通フィールド

| フィールド | 型 | 説明 |
|---|---|---|
| `schemaVersion` | int | YAML スキーマバージョン |
| `id` | string | アイテムID |
| `category` | string | `material` / `consumable` / `equipment` / `currency` / `bundle` / `rune` |
| `name` | string | アイテム名 |
| `icon` | string | Minecraft マテリアル名 |
| `rarity` | string | `COMMON` / `UNCOMMON` / `RARE` / `EPIC` / `LEGENDARY` 等 |
| `saleValue` | int | 売却価格 |
| `customModelData` | int? | カスタムモデルデータ |
| `maxStack` | int | 最大スタック数 |
| `lore` | string[] | 説明文 |
| `unTradeable` | bool | 取引不可フラグ |
| `unSellable` | bool | 売却不可フラグ |

### 2.2 カテゴリ別拡張

カテゴリに応じて以下のいずれかのオブジェクトが含まれる（他は `null` または欠落）。

- `consumable`: `consumable.onUse.{sound, effect, amount}`, `consumable.effects[]`
- `equipment`: `equipment` オブジェクト（[[04_3.00-索引]] equipment フィールド表参照）
- `currency`: `currency.{type, group, expiresAt}`
- `bundle`: `bundle.{lootTableId, items[], onUse}`
- `rune`: `rune.{targetSlots, requiredEnhanceLevel, stats[], skills[]}`

詳細フィールドは本 API 設計書の item モデル定義を正本として扱う。
将来的にここへ転記する場合は YAML スキーマ（`50_filebase/10.features.item/`）と同期させること。

equipment の装備条件と状態変化条件は次の構造で返す。

| フィールド | 型 | 説明 |
|---|---|---|
| `equipment.requiredLevel` | int | 必要プレイヤーレベル。`0` は制限なし |
| `equipment.requiredClasses` | object[] | 装備可能な現在クラスと必要クラスレベル。空配列はクラス制限なし |
| `equipment.requiredClasses[].classId` | string | 現在選択中クラスと照合するクラス ID |
| `equipment.requiredClasses[].level` | int | 必要クラスレベル |
| `equipment.transcendence[].requiredEnhanceLevel` | int | 状態変化に必要な最小強化値 |

## 3. セット効果レスポンス

物理名: `SetEffectResponse`

対象: `GET /api/seteffect`, `GET /api/seteffect/{setId}`

| フィールド | 型 | 説明 |
|---|---|---|
| `id` | string | セット効果 ID |
| `name` | string | セット効果名 |
| `pieces` | セット効果ピース[] | 装着数ごとの発動効果 |

### 3.1 セット効果ピース

物理名: `SetEffectPieceResponse`

| フィールド | 型 | 説明 |
|---|---|---|
| `count` | int | 効果発動に必要な同セット装備数 |
| `stats` | セット効果ステータス[] | 付与ステータス |
| `skills` | string[] | 付与スキル ID |

### 3.2 セット効果ステータス

物理名: `SetEffectStatResponse`

| フィールド | 型 | 説明 |
|---|---|---|
| `status` | string | ステータス種別 |
| `type` | string | 加算・乗算などの適用方式 |
| `value` | string | 適用値 |
