### 2.2 カテゴリ別拡張

カテゴリに応じて以下のいずれかのオブジェクトが含まれる（他は `null` または欠落）。

- `consumable`: `consumable.onUse.{usingSound, sound, effect, amount, useTimeTicks, cooldownTicks}`, `consumable.effects[]`
- `equipment`: `equipment` オブジェクト（[[04_3.00-索引]] equipment フィールド表参照）
- `currency`: `currency.{type, group, expiresAt}`
- `bundle`: `bundle.{lootTableId, items[], openTimeTicks, onUse}`
- `rune`: `rune.{targetSlots, targetTags, requiredEnhanceLevel, stats[]}`。`targetSlots` は装備slot、`targetTags` は装備tagの追加条件で、両方を指定した場合はAND条件。スキル付与は行わない
- `orb`: `orb.effect`。`type` ごとに強化・修理・状態変化・エンチャントの対象条件と動作を持つ
- `sigil`: `sigil.{equipGroupId, modifiers[]}`

`bundle.onUse` は filebase の inline 演出定義を返す。`sound` は `{sound, volume, pitch}`、`particle` は `{particle, count, originOffsetX, originOffsetY, originOffsetZ, offsetX, offsetY, offsetZ, extra}` のオブジェクトである。

`bundle.openTimeTicks` は開封完了までの待機時間を表す（20 tick = 1 秒）。省略時は `20` です。

`consumable.onUse.usingSound` は使用開始時・待機中、`sound` は効果適用後に再生する sound key を表す。`useTimeTicks` は使用完了までの待機時間、`cooldownTicks` は使用成功後のクールダウンを表す（20 tick = 1 秒）。省略時はサウンドが `null`、待機時間とクールダウンが `40`。

スキルジェム用の item category・仮想 item 生成・response は廃止する。スキルの習得とレベルアップに必要な素材は skill master の `learnRequiredItems` / `levelUpRequiredItems` で定義する。

詳細フィールドは本 API 設計書の item モデル定義を正本として扱う。
将来的にここへ転記する場合は YAML スキーマ（`40_filebase/10.features.item/`）と同期させること。

equipment の装備条件と状態変化条件は次の構造で返す。

`equipment.stats[]` の基礎ステータスは次の契約で返す。既存の固定値・範囲値は従来どおり `value: {min, max}` に正規化する。

| フィールド | 型 | 説明 |
|---|---|---|
| `equipment.stats[].value.min/max` | string | 基礎値。`random` がある場合は、生入力の検証済みスカラー基準値を小数4桁以内の十進文字列に正規化し、両方に同値を保持する |
| `equipment.stats[].random.offsetMin/offsetMax` | number | 基準値へ加算する下限・上限。両方必須 |
| `equipment.stats[].random.step` | number | `offsetMin` 起点の離散抽選刻み。必須 |
| `equipment.stats[].random.zeroChance` | number | 0 の独立抽選確率。省略時0 |

`random` はスカラー `value` とだけ併用でき、範囲形式（`min/max` オブジェクトまたは `~` 文字列）、同じ stat 行直下の `min/max` との併記は拒否する。基準値・両 offset・step は有限で小数4桁以内、API の decimal で表現可能な値に限り、各値が double 往復で元の decimal 値へ戻ること。offset 下限は上限以下、step は正、区間差は step の整数倍、候補数は100万以下とする。基準値と offset の加算結果も有限かつ double 往復で元の decimal 値へ戻り、候補が複数ある場合は step が両端の最大絶対値における double の ULP 以上であること。`zeroChance` は有限の0～1で、正のときは通常抽選区間に0を含めない。装備インスタンスの応答は確定済み保存値だけを返し、このマスター抽選定義を混ぜない。

| フィールド | 型 | 説明 |
|---|---|---|
| `equipment.requiredLevel` | int | 必要プレイヤーレベル。`0` は制限なし |
| `equipment.requiredClasses` | object[] | 装備可能な現在クラスと必要クラスレベル。空配列はクラス制限なし |
| `equipment.requiredClasses[].classId` | string | 現在選択中クラスと照合するクラス ID |
| `equipment.requiredClasses[].level` | int | 必要クラスレベル |
| `equipment.usableSkills` | string[] | `SKILLBOOK` 専用の `skill:<id>` 参照一覧。省略時は空配列。装備中のみ使用許可に加算する |
| `equipment.transcendence[].name` | string? | 状態変化後の表示名。候補一覧ではrank数値の代わりに使用する |
| `equipment.transcendence[].rank` | int | 状態変化後の目標rank |
| `equipment.transcendence[].requiredEnhanceLevel` | int | 状態変化に必要な最小強化値 |
| `equipment.transcendence[].requiredMaterials` | object[] | 状態変化確認画面で検証・消費する素材IDと数量 |
| `equipment.transcendence[].requiredCurrency` | int | 状態変化確認画面で検証・消費するgold |

状態変化の必要素材・通貨は装備マスタから直接返し、`recipeId` は持たない。

装備強化とエンチャントは次の縮約契約を返す。

| フィールド | 型 | 説明 |
|---|---|---|
| `equipment.enhance.levels[].successRate` | float | 当該レベルへの強化成功率 |
| `equipment.enhance.levels[].failAction` | string | `NONE` / `SET_LEVEL` / `DECREASE_ONE` |
| `equipment.enhance.levels[].failTargetLevel` | int? | `SET_LEVEL` の失敗後レベル |
| `equipment.enchant.maxSlots` | int | エンチャント最大枠数。装備個別の抽選候補は持たない |

`equipment.enhance.levels[]` に強化用素材・通貨・recipeは返さない。強化はオーブ1個で試行し、`orb.effect.chargeSaleValue=true` のときはオーブの売値に応じたGoldも必要となる。

### 2.3 オーブ効果

| フィールド | 型 | 説明 |
|---|---|---|
| `orb.effect.type` | string | `ENHANCE` / `REPAIR` / `TRANSCENDENCE` / `ENCHANT` |
| `orb.effect.targetSlots` | string[] | 強化対象の装備slot |
| `orb.effect.rank` | int? | 強化の現在状態rank、または状態変化の `rankBasis` で選ぶrank条件 |
| `orb.effect.rankMode` | string | `EXACT` / `AT_MOST` |
| `orb.effect.rankBasis` | string | 状態変化ランク条件の照合先。`TARGET`（既定、到達先rank）/ `CURRENT`（現在rank） |
| `orb.effect.chargeSaleValue` | bool | `ENHANCE` / `REPAIR` / `TRANSCENDENCE` のオーブ使用1回につき、オーブの `saleValue` の非負分をGoldで消費するか。省略時は `false`。状態変化時は装備の `requiredCurrency` に加算。これら以外のtypeに指定されても課金しない |
| `orb.effect.repairAmount` | int? | 固定耐久回復量 |
| `orb.effect.repairFull` | bool | 最大耐久まで回復するか |
| `orb.effect.enchantMasterId` | string? | 共通エンチャントマスタ参照（`enchant:<id>`）。`REMOVE_RANDOM` / `LOCK_FIRST` では不要、他のエンチャント操作では必須 |
| `orb.effect.enchantOperation` | string? | `OVERWRITE_RANDOM` / `FILL_ONE_EMPTY` / `FILL_ALL_EMPTY` / `REROLL_VALUE_RANDOM` / `REMOVE_RANDOM` / `LOCK_FIRST` |
