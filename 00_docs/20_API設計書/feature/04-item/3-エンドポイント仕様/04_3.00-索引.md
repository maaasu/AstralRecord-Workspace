## 記載ルール

- 論理名（日本語）を主表記とする
- HTTP メソッド・パス・コントローラ・アクション物理名を併記する
- リクエストは `種別 / 名前 / 型 / 必須 / 説明` の 5 列で 1 表にまとめる
- レスポンスは HTTP ステータスごとに行を持つ表で記載する
- 処理内容は番号付き手順 + 補足表で記載する

詳細ルールは [[README]] を参照する。
