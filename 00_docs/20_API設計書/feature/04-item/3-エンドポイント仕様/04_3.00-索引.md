# 04_3.00-索引

## エンドポイント一覧

| HTTPメソッド | パス | 論理名 |
|---|---|---|
| GET | `/api/item` | アイテム一覧取得 |
| GET | `/api/item/{itemId}` | アイテム詳細取得 |

---

## 1. アイテム一覧取得

HTTPメソッド: `GET`
パス: `/api/item`
コントローラ: `ItemController`
アクション物理名: `ListItems`

責務:

MasterDataDB 上の有効 item を最小項目（`id` / `category`）で返す。レスポンス肥大化を避ける。

リクエスト:

| 種別 | 名前 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| Header | `X-Api-Key` | string | ✓ | API キー |

レスポンス:

| ステータス | 内容 | ボディ |
|---|---|---|
| 200 OK | 取得成功 | [[04_1.00-モデル定義]].アイテム一覧レスポンス要素 の配列 |
| 401 Unauthorized | API キー未指定/無効 | なし |

処理内容:

1. 認証パイプラインで `X-Api-Key` を検証する
2. MasterDataDB から有効 item の `id` と `category` のみを取得する
3. 200 で配列を返す

---

## 2. アイテム詳細取得

HTTPメソッド: `GET`
パス: `/api/item/{itemId}`
コントローラ: `ItemController`
アクション物理名: `GetItem`

責務:

`itemId` をキーに、カテゴリ別フィールドを含む完全な [[04_1.00-モデル定義]].アイテム詳細レスポンス を返す。

リクエスト:

| 種別 | 名前 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| Header | `X-Api-Key` | string | ✓ | API キー |
| Path | `itemId` | string | ✓ | アイテム ID |

レスポンス:

| ステータス | 内容 | ボディ |
|---|---|---|
| 200 OK | 取得成功 | [[04_1.00-モデル定義]].アイテム詳細レスポンス |
| 401 Unauthorized | API キー未指定/無効 | なし |
| 404 Not Found | 未定義 itemId | なし |

処理内容:

1. 認証パイプラインで `X-Api-Key` を検証する
2. MasterDataDB から `master_type = item` かつ `master_id = itemId` で検索する

    | 項目 | 内容 |
    |---|---|
    | 検索キー | `itemId` |
    | 取得失敗 | 404 を返す |

3. カテゴリに応じたペイロードを構築し 200 で返す
4. 例外時は [[04_5.00-例外・ログ・運用]] のログを記録し 500 を返す
