# 04_3.01-取得系

## 1. 取得系エンドポイント仕様

### アイテム一覧取得

HTTPメソッド: `GET`
パス: `/api/item`
コントローラ: `ItemController`
アクション物理名: `GetAll`

責務:

MasterDataDB の `dbo.master_data_entry`（`master_type = 'item'`）から有効レコードを取得し、`id` / `category` のみの最小項目で返す。レスポンス肥大化を避ける。

リクエスト:

| 種別 | 名前 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| Header | `X-Api-Key` | string | ✓ | API キー |

レスポンス:

| ステータス | 内容 | ボディ |
|---|---|---|
| 200 OK | 取得成功 | [[04_1.00-モデル定義]].アイテム一覧レスポンス要素 の配列 |
| 401 Unauthorized | API キー未指定/無効 | なし（[[04_5.00-例外・ログ・運用]] 共通エラー参照） |

処理内容:

1. 認証パイプラインで `X-Api-Key` を検証する

    | 項目 | 内容 |
    |---|---|
    | 検証主体 | `ApiKeyAuthenticationHandler` |
    | 失敗時 | 401 を返し、本処理は実行しない |

2. リポジトリで有効 item の最小項目を取得する

    | 項目 | 内容 |
    |---|---|
    | 取得対象 | `dbo.master_data_entry` のうち `master_type = 'item'` かつ `is_deleted = 0` |
    | 取得項目 | `master_id`（→`id`）, `category` |
    | 並び順 | `category` 昇順 → `master_id` 昇順 |

3. 200 で配列を返す

4. 例外発生時は以下ログを記録して 500 を返す

    | 項目 | 内容 |
    |---|---|
    | レベル | Error |
    | テンプレート | `Failed to list items` |
    | 出力条件 | リポジトリ呼び出しで例外発生時 |
    | 出力例外 | キャッチした例外を `_logger.LogError(ex, ...)` で添付 |

入力:

- なし

出力:

- [[04_1.00-モデル定義]].アイテム一覧レスポンス要素 の配列

例外時挙動:

- 認証失敗時は 401 のみ返す
- それ以外の例外は Error ログを記録し 500 を返す

### アイテム詳細取得

HTTPメソッド: `GET`
パス: `/api/item/{itemId}`
コントローラ: `ItemController`
アクション物理名: `GetById`

責務:

`itemId` をキーに MasterDataDB の `dbo.master_data_entry`（`master_type = 'item'`）から有効レコードを取得し、`payload_json` をデシリアライズした [[04_1.00-モデル定義]].アイテム詳細レスポンス を返す。

リクエスト:

| 種別 | 名前 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| Header | `X-Api-Key` | string | ✓ | API キー |
| Path | `itemId` | string | ✓ | アイテム ID |

レスポンス:

| ステータス | 内容 | ボディ |
|---|---|---|
| 200 OK | 取得成功 | [[04_1.00-モデル定義]].アイテム詳細レスポンス |
| 401 Unauthorized | API キー未指定/無効 | なし |
| 404 Not Found | 未定義 itemId | なし |

処理内容:

1. 認証パイプラインで `X-Api-Key` を検証する

    | 項目 | 内容 |
    |---|---|
    | 検証主体 | `ApiKeyAuthenticationHandler` |
    | 失敗時 | 401 を返し、本処理は実行しない |

2. リポジトリで対象アイテムを取得する

    | 項目 | 内容 |
    |---|---|
    | 検索キー | `master_type = 'item'` かつ `master_id = itemId` かつ `is_deleted = 0` |
    | 取得対象 | `payload_json` |
    | 取得失敗（該当なし / 論理削除済み） | 404 を返す |

3. `payload_json` を [[04_1.00-モデル定義]].アイテム詳細レスポンス へデシリアライズし 200 を返す

    | 項目 | 内容 |
    |---|---|
    | デシリアライザ | `System.Text.Json`（CamelCase / 大小区別なし） |
    | カテゴリ別フィールド | `consumable` / `equipment` / `currency` / `bundle` / `rune` のうち存在するものをそのまま展開 |

4. 例外発生時は以下ログを記録して 500 を返す

    | 項目 | 内容 |
    |---|---|
    | レベル | Error |
    | テンプレート | `Failed to get item {ItemId}` |
    | 出力条件 | リポジトリ呼び出し / デシリアライズで例外発生時 |
    | 引数 | `{ItemId}` = 対象アイテムID |
    | 出力例外 | キャッチした例外を `_logger.LogError(ex, ...)` で添付 |

入力:

- `itemId`: 対象アイテム ID

出力:

- [[04_1.00-モデル定義]].アイテム詳細レスポンス（取得成功時）

例外時挙動:

- 認証失敗時は 401 のみ返す
- 該当レコードなし / 論理削除時は 404 のみ返す
- それ以外の例外は Error ログを記録し 500 を返す
