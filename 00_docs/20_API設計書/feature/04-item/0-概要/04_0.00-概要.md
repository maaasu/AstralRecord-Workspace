# 04_0.00-概要

## 1. 目的

API `item` 機能は、MasterDataDB に投入済みの `item` マスタを、
プラグイン・Web からの照会に応じて必要な単位で返す。
装備セット効果は `set_effect` マスタとして扱い、同じ item 領域の読み取り API で返す。

カテゴリ:

- `material`: 素材
- `consumable`: 消費アイテム
- `equipment`: 装備
- `currency`: 通貨
- `bundle`: パケット
- `rune`: ルーン
- `orb`: 装備操作オーブ

共通エンチャントは装備 item 個別ではなく `master_type = 'enchant'` の独立マスタとして扱い、装備種別ごとの重み付き候補を `GET /api/enchant/{enchantMasterId}` で返す。

## 2. コンテキスト

- 通常リクエスト時に `50_filebase` の YAML を直接読まない。
- API 起動時または Seeder API 実行時に MasterDataDB へ投入された JSON ペイロードを参照する。
- 全 item の常時メモリ保持は行わず、必要に応じて ID 単位の短時間キャッシュのみ許容する。
- MasterDataDB の整形済みレスポンスを返す（`schemaVersion` を含む）。
