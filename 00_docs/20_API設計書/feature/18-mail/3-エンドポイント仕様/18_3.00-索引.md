# 18_3.00 メール API

通常メールの本文・題名・アイコン・報酬・公開期間は filebase `mail` マスタを MasterDataDB へ同期して参照する。
ロード時のマスタ不整合などプレイヤー固有の補償メールは `dbo.player_mail_delivery` にpayloadを保存し、通常メールと同じ一覧へ統合する。
通常メール・動的配信とも、アカウント別の既読・削除状態は `dbo.player_mail_state` で管理する。`dbo.player_mail_delivery.is_deleted` は配信レコード自体の運用無効化に使用する。`firstLoginOnly: true` の通常メールは、アカウント作成日時が公開開始以後のアカウントへだけ配信する。

スキルツリー構造不整合の補償は `skilltree_structure_reset_compensation` mailマスタをテンプレートにする。`account-skilltree` 補修APIが状態リセットと同じトランザクションでアカウント限定deliveryを作成し、同一構造キーの再試行では既存deliveryを再利用する。後の構造変更で別の不整合が発生した場合は別キーのdeliveryとして再配信できる。

## エンドポイント

| Method | Path | 説明 |
|:--|:--|:--|
| GET | `/api/mail?account_id={account_id}&filter={filter}` | 期限内かつアカウントが削除していないメール一覧を取得する。`filter` は `all` / `unread` / `read`。 |
| PUT | `/api/mail/{mailId}/read` | 指定メールをアカウント単位で既読にする。状態が存在しない場合は作成する。 |
| PUT | `/api/mail/{mailId}/delete` | 指定メールをアカウント単位で削除状態にする。メールマスタ自体は削除しない。 |

## 一覧レスポンス

```json
[
  {
    "schemaVersion": 1,
    "id": "welcome_mail",
    "icon": "CHEST",
    "title": "初ログイン記念の贈り物",
    "body": "AstralRecord へようこそ。\nノクスでの冒険の始まりを記念して、初ログインバンドルをお届けします。",
    "publishFrom": "2026-06-01T00:00:00",
    "publishTo": null,
    "firstLoginOnly": true,
    "receiveOnRead": true,
    "rewards": [
      {
        "itemId": "initial_login_bundle",
        "category": "bundle",
        "amount": 1
      }
    ],
    "isRead": false,
    "readAt": null,
    "isDeleted": false
  }
]
```

## 並び順

1. 未読を既読より上位にする。
2. 同じ既読状態の中では `publishFrom` が新しいものを上位にする。
3. 同一日時の場合は `id` 昇順にする。

## 既読・削除リクエスト

```json
{
  "accountId": "00000000-0000-0000-0000-000000000000",
  "updatedBy": "00000000-0000-0000-0000-000000000000"
}
```

## ステータスコード

| Method | Status | 説明 |
|:--|:--|:--|
| GET | 200 | 一覧取得成功 |
| PUT read | 200 | 既読更新成功 |
| PUT read | 404 | 指定アカウントに表示可能なメールが存在しない |
| PUT delete | 204 | 削除状態更新成功 |
| PUT delete | 404 | 指定アカウントに表示可能なメールが存在しない |
