# 18_3.00 メール API

メール本文・題名・アイコン・報酬・公開期間は filebase `mail` マスタを MasterDataDB へ同期して参照する。
プレイヤー別の既読・削除状態は AstralRecord DB `dbo.player_mail_state` で管理する。

## エンドポイント

| Method | Path | 説明 |
|:--|:--|:--|
| GET | `/api/mail?user_id={user_id}&filter={filter}` | 期限内かつプレイヤーが削除していないメール一覧を取得する。`filter` は `all` / `unread` / `read`。 |
| PUT | `/api/mail/{mailId}/read` | 指定メールをプレイヤー単位で既読にする。状態が存在しない場合は作成する。 |
| PUT | `/api/mail/{mailId}/delete` | 指定メールをプレイヤー単位で削除状態にする。メールマスタ自体は削除しない。 |

## 一覧レスポンス

```json
[
  {
    "schemaVersion": 1,
    "id": "welcome_mail",
    "icon": "WRITABLE_BOOK",
    "title": "サーバ参加ありがとうございます",
    "body": "AstralRecord サーバへ参加してくださりありがとうございます。\n冒険の始まりを記念して、100 アストラルドをお届けします。",
    "publishFrom": "2026-06-01T00:00:00",
    "publishTo": null,
    "receiveOnRead": true,
    "rewards": [
      {
        "itemId": "astrald",
        "category": "currency",
        "amount": 100
      }
    ],
    "isRead": false,
    "readAt": null,
    "isDeleted": false
  }
]
```

## 並び順

1. 未読を既読より上位にする。
2. 同じ既読状態の中では `publishFrom` が新しいものを上位にする。
3. 同一日時の場合は `id` 昇順にする。

## 既読・削除リクエスト

```json
{
  "userId": "00000000-0000-0000-0000-000000000000",
  "updatedBy": "00000000-0000-0000-0000-000000000000"
}
```

## ステータスコード

| Method | Status | 説明 |
|:--|:--|:--|
| GET | 200 | 一覧取得成功 |
| PUT read | 200 | 既読更新成功 |
| PUT read | 404 | メールマスタが存在しない |
| PUT delete | 204 | 削除状態更新成功 |
| PUT delete | 404 | メールマスタが存在しない |
