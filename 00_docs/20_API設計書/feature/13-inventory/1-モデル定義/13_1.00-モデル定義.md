| `isDeleted` | bool | ✗ | 論理削除フラグ |

## 5. インベントリエントリ登録リクエスト

物理名: `InventoryEntryCreateRequest`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `slotIndex` | int | ✗ | スロット番号 |
| `itemCategory` | string | ✗ | アイテムカテゴリ |
| `itemId` | string | ✓ | スタックアイテム ID。個体 entry では参照先個体の item ID を併記する |
| `instanceType` | string | ✓ | インスタンス系種別 |
| `instanceId` | GUID | ✓ | インスタンス UUID |
| `quantity` | int | ✗ | 個数（1 以上） |
| `metadataJson` | string | ✓ | 拡張メタデータ JSON |
| `createdBy` | GUID | ✗ | 作成者UUID |

ルール: `instanceType` と `instanceId` は必ず対で指定する。スタック entry は `itemId` を必須とし、個体 entry は `itemId` を併記できる。個体 entry に併記する `itemId` は同一 account 所有の参照個体（`EQUIPMENT` / `RUNE`）の item ID と API 正本で一致しなければならず、未指定時も API が正本の item ID を保存する。

## 6. インベントリエントリ更新リクエスト

物理名: `InventoryEntryUpdateRequest`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `inventoryEntryId` | GUID | ✓ | 既存entryを維持・移動する場合のUUID。新規の場合もclient採番値を指定可 |
| `slotIndex` | int | ✓ | スロット番号 |
| `quantity` | int | ✓ | 個数 |
| `metadataJson` | string | ✓ | 拡張メタデータ JSON |

`inventoryEntryId` はジェム・シジルmutationの素材指定に使うため、一括置換でも同一entryを再採番しない。別accountのentry UUID、同一request内の重複UUIDは拒否する。
| `updatedBy` | GUID | ✗ | 更新者UUID（必須） |

## 7. インベントリエントリ一括置換リクエスト

物理名: `InventoryEntryReplaceRequest`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `updatedBy` | GUID | ✗ | 更新者UUID（必須）。新規作成される entry の `createdBy` にも使用する |
| `entries` | InventoryEntryReplaceItemRequest[] | ✗ | 置換後に有効として残す entry 一覧 |

## 8. インベントリエントリ一括置換要素

物理名: `InventoryEntryReplaceItemRequest`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `inventoryEntryId` | GUID | ✓ | 既存UUIDまたはclient採番の新規UUID。未指定時はAPI採番 |
| `expectedUpdatedAt` | datetime | ✓ | 既存UUIDでは必須。取得時の `updatedAt` を指定する楽観ロック版 |
| `slotIndex` | int | ✓ | スロット番号 |
| `itemCategory` | string | ✗ | アイテムカテゴリ |
| `itemId` | string | ✓ | スタックアイテム ID。個体 entry では参照先個体の item ID を併記する |
| `instanceType` | string | ✓ | インスタンス系種別 |
| `instanceId` | GUID | ✓ | インスタンス UUID |
| `quantity` | int | ✗ | 個数（1 以上） |
| `metadataJson` | string | ✓ | 拡張メタデータ JSON |

既存UUIDの `expectedUpdatedAt` がDB正本と一致しない場合、一括置換全体を拒否する。これにより、ジェム・シジル消費後に到着した古いインベントリ保存が数量を復元することを防ぐ。client採番の未登録UUIDでは `expectedUpdatedAt` を指定しない。
