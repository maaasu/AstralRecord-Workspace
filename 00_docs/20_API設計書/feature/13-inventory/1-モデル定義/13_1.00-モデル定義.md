# 13_1.00-モデル定義

## 1. インベントリレスポンス

物理名: `InventoryResponse`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `inventoryId` | GUID | ✗ | インベントリUUID |
| `accountId` | GUID | ✗ | 所有アカウントUUID（FK → `dbo.account.uuid`） |
| `inventoryType` | string | ✗ | インベントリ種別（マスタ参照は呼出元責任） |
| `inventoryProfile` | string | ✗ | `GAME` / `BUILDER` |
| `slotCapacity` | int | ✗ | スロット容量 |
| `isEnabled` | bool | ✗ | 有効フラグ |
| `metadataJson` | string | ✓ | 拡張メタデータ JSON |

## 2. インベントリ登録リクエスト

物理名: `InventoryCreateRequest`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `accountId` | GUID | ✗ | 所有アカウントUUID |
| `inventoryType` | string | ✗ | インベントリ種別 |
| `inventoryProfile` | string | ✗ | `GAME` / `BUILDER` |
| `slotCapacity` | int | ✗ | スロット容量 |
| `isEnabled` | bool | ✗ | 有効フラグ |
| `metadataJson` | string | ✓ | 拡張メタデータ JSON |
| `createdBy` | GUID | ✗ | 作成者UUID |

## 3. インベントリ更新リクエスト

物理名: `InventoryUpdateRequest`

`null` は無更新。

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `slotCapacity` | int | ✓ | スロット容量 |
| `isEnabled` | bool | ✓ | 有効フラグ |
| `metadataJson` | string | ✓ | 拡張メタデータ JSON |
| `updatedBy` | GUID | ✗ | 更新者UUID（必須） |

## 4. インベントリエントリレスポンス

物理名: `InventoryEntryResponse`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `inventoryEntryId` | GUID | ✗ | エントリUUID |
| `inventoryId` | GUID | ✗ | 所属インベントリUUID |
| `slotIndex` | int | ✗ | スロット番号 |
| `itemCategory` | string | ✗ | アイテムカテゴリ |
| `itemId` | string | ✓ | スタックアイテム ID（スタック系のみ） |
| `instanceType` | string | ✓ | インスタンス系種別（`EQUIPMENT` / `RUNE` 等） |
| `instanceId` | GUID | ✓ | インスタンス UUID |
| `quantity` | int | ✗ | 個数（1 以上） |
| `metadataJson` | string | ✓ | 拡張メタデータ JSON |

## 5. インベントリエントリ登録リクエスト

物理名: `InventoryEntryCreateRequest`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `slotIndex` | int | ✗ | スロット番号 |
| `itemCategory` | string | ✗ | アイテムカテゴリ |
| `itemId` | string | ✓ | スタックアイテム ID（スタック系のみ） |
| `instanceType` | string | ✓ | インスタンス系種別 |
| `instanceId` | GUID | ✓ | インスタンス UUID |
| `quantity` | int | ✗ | 個数（1 以上） |
| `metadataJson` | string | ✓ | 拡張メタデータ JSON |
| `createdBy` | GUID | ✗ | 作成者UUID |

ルール: `itemId` と `instanceType`/`instanceId` は同時に指定しない。

## 6. インベントリエントリ更新リクエスト

物理名: `InventoryEntryUpdateRequest`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `slotIndex` | int | ✓ | スロット番号 |
| `quantity` | int | ✓ | 個数 |
| `metadataJson` | string | ✓ | 拡張メタデータ JSON |
| `updatedBy` | GUID | ✗ | 更新者UUID（必須） |

## 7. インベントリエントリ一括置換リクエスト

物理名: `InventoryEntryReplaceRequest`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `updatedBy` | GUID | ✗ | 更新者UUID（必須）。新規作成される entry の `createdBy` にも使用する |
| `entries` | InventoryEntryReplaceItemRequest[] | ✗ | 置換後に有効として残す entry 一覧 |

## 8. インベントリエントリ一括置換要素

物理名: `InventoryEntryReplaceItemRequest`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `slotIndex` | int | ✓ | スロット番号 |
| `itemCategory` | string | ✗ | アイテムカテゴリ |
| `itemId` | string | ✓ | スタックアイテム ID（スタック系のみ） |
| `instanceType` | string | ✓ | インスタンス系種別 |
| `instanceId` | GUID | ✓ | インスタンス UUID |
| `quantity` | int | ✗ | 個数（1 以上） |
| `metadataJson` | string | ✓ | 拡張メタデータ JSON |
