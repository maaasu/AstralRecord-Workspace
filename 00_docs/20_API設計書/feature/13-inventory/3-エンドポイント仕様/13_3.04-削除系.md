# 13_3.04-削除系

## 1. 削除系エンドポイント仕様

### エントリ論理削除

HTTPメソッド: `DELETE`
パス: `/api/inventory/entries/{inventoryEntryId}?updated_by={updatedBy}`
コントローラ: `InventoryController`
アクション物理名: `DeleteEntry`

リクエスト:

| 種別 | 名前 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| Header | `X-Api-Key` | string | ✓ | API キー |
| Path | `inventoryEntryId` | GUID | ✓ | 対象エントリUUID |
| Query | `updated_by` | GUID | ✓ | 削除実行者UUID |

レスポンス:

| ステータス | 内容 | ボディ |
|---|---|---|
| 204 No Content | 削除成功 | なし |
| 400 Bad Request | クエリ欠落/不正 | エラーオブジェクト |
| 401 Unauthorized | API キー未指定/無効 | なし |
| 404 Not Found | 未登録/論理削除済み | なし |

処理内容:

1. 認証パイプラインで `X-Api-Key` を検証する
2. `updated_by` の必須チェック
3. 対象エントリを取得（`is_deleted = 0`）。なければ 404
4. `is_deleted = true`, `updatedBy`, `updatedAt` を更新
5. 204 を返す
6. 例外時は [[13_5.00-例外・ログ・運用]].削除系 のログを記録し 500 を返す
