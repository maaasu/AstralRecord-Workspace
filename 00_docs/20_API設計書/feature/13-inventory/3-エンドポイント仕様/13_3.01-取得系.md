# 13_3.01-取得系

## 1. 取得系エンドポイント仕様

### アカウントインベントリ一覧取得

HTTPメソッド: `GET`
パス: `/api/inventory?account_id={accountId}`
コントローラ: `InventoryController`
アクション物理名: `ListInventoriesByAccount`

リクエスト:

| 種別 | 名前 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| Header | `X-Api-Key` | string | ✓ | API キー |
| Query | `account_id` | GUID | ✓ | アカウントUUID |

レスポンス:

| ステータス | 内容 | ボディ |
|---|---|---|
| 200 OK | 取得成功 | [[13_1.00-モデル定義]].インベントリレスポンス の配列 |
| 400 Bad Request | クエリ欠落/不正 | エラーオブジェクト |
| 401 Unauthorized | API キー未指定/無効 | なし |

処理内容:

1. 認証パイプラインで `X-Api-Key` を検証する
2. `account_id` の必須・型チェック（失敗時 400）
3. リポジトリで該当 account 配下の `dbo.inventory`（`is_deleted = 0`）を取得し配列で 200 を返す
4. 例外時は [[13_5.00-例外・ログ・運用]].取得系 のログを記録し 500 を返す

---
