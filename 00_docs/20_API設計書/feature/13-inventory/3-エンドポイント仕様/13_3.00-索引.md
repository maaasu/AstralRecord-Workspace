## 7. エントリ登録

HTTPメソッド: `POST`
パス: `/api/inventory/{inventoryId}/entries`
コントローラ: `InventoryController`
アクション物理名: `CreateEntry`

リクエスト:

| 種別 | 名前 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| Header | `X-Api-Key` | string | ✓ | API キー |
| Header | `Content-Type` | string | ✓ | `application/json` |
| Path | `inventoryId` | GUID | ✓ | 親インベントリUUID |
| Body | (全体) | [[13_1.00-モデル定義]].インベントリエントリ登録リクエスト | ✓ | 登録対象 |

処理内容:

1. 認証パイプラインで `X-Api-Key` を検証する
2. バリデーション

    | 項目 | 内容 |
    |---|---|
    | 必須項目 | `slotIndex`, `itemCategory`, `quantity`, `createdBy` |
    | 排他チェック | `itemId` と `instanceType`/`instanceId` の同時指定不可 |
    | `quantity` | `>= 1` |
    | 失敗時 | 400 を返す |

3. 親インベントリ存在確認（`is_deleted = 0`）。なければ 404
4. エントリを登録し 201 で返す
5. 例外時は [[13_5.00-例外・ログ・運用]].登録系 のログを記録し 500 を返す

レスポンス:

| ステータス | 内容 | ボディ |
|---|---|---|
| 201 Created | 登録成功 | [[13_1.00-モデル定義]].インベントリエントリレスポンス |
| 400 Bad Request | バリデーション失敗 | エラーオブジェクト |
| 401 Unauthorized | API キー未指定/無効 | なし |
| 404 Not Found | 親インベントリ未登録/論理削除済み | なし |

## 9. エントリ論理削除

HTTPメソッド: `DELETE`
パス: `/api/inventory/entries/{inventoryEntryId}?updated_by={updatedBy}`
コントローラ: `InventoryController`
アクション物理名: `DeleteEntry`

リクエスト:

| 種別 | 名前 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| Header | `X-Api-Key` | string | ✓ | API キー |
| Path | `inventoryEntryId` | GUID | ✓ | 対象エントリUUID |
| Query | `updated_by` | GUID | ✓ | 削除実行者UUID |

レスポンス:

| ステータス | 内容 | ボディ |
|---|---|---|
| 204 No Content | 削除成功 | なし |
| 400 Bad Request | クエリ欠落/不正 | エラーオブジェクト |
| 401 Unauthorized | API キー未指定/無効 | なし |
| 404 Not Found | 未登録/論理削除済み | なし |

処理内容:

1. 認証パイプラインで `X-Api-Key` を検証する
2. `updated_by` の必須チェック
3. 対象エントリを取得（`is_deleted = 0`）。なければ 404
4. `is_deleted = true`, `updatedBy`, `updatedAt` を更新
5. 204 を返す
