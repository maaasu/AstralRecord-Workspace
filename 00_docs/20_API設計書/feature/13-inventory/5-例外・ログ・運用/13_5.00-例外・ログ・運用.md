# 13_5.00-例外・ログ・運用

ログ・メッセージはハードコーディング。LogId は使用しない。

## 1. 共通エラーレスポンス

| ステータス | 発生条件 | ボディ |
|---|---|---|
| 401 Unauthorized | API キー未指定/無効 | なし |
| 400 Bad Request | バリデーション失敗 | `ProblemDetails` 互換 |
| 404 Not Found | 未登録/論理削除済み | なし |
| 409 Conflict | 一括置換対象の snapshot が古い、または既存 entry UUID を再利用できない | `ProblemDetails` 互換 |
| 500 Internal Server Error | 上記以外の例外 | `ProblemDetails` 互換 |

## 3. 運用上の注意

- インベントリ本体の削除（論理）は現状未提供。必要が出たら追加検討。
- `itemId` / `instanceId` 整合性は API では検証しない。プラグイン側で発行・参照する責務。
- `inventoryType` のマスタ参照は API では行わない。
