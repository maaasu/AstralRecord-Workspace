# 釣りマスタ取得 API

`GET /api/fishing/fish`、`GET /api/fishing/areas`、`GET /api/fishing/rules` は MasterDataDB の有効なエントリを ID 順に全件返す。各末尾に `/{id}` を付けると 1 件を返し、存在しなければ 404。Seeder 前または対象マスタがない場合、一覧は空配列となる。

魚の応答は YAML の数値・ID・名前・entityType・釣果項目を camelCase で返す。釣り場は `worldId`、`rulesId`、`levelRanges[].fish[].fishId` を含む。参照フィールドは `ref` オブジェクトから `"world:verdia"` などの文字列に展開する。追加報酬のない魚の `lootTableId` は null。

例: `GET /api/fishing/areas/verdia` の最初のレベル帯の抜粋（実際の応答は10以上の帯も含む）:

```json
{"id":"verdia","worldId":"world:verdia","rulesId":"fishing_rules:default","enabled":true,"levelRanges":[{"minLevel":0,"maxLevel":9,"fish":[{"fishId":"fishing_fish:river_cod","chancePercent":70},{"fishId":"fishing_fish:river_salmon","chancePercent":25},{"fishId":"fishing_fish:tropical_fish","chancePercent":5}]}]}
```

編集保存は既存の `PUT /api/master-data/files/{path}`、削除は既存の file API を使う。Seeder (`POST /api/master-data/seed`) は釣りマスタの構造、数値範囲、参照、レベル帯重複、確率合計、同一ワールド有効釣り場重複をトランザクション内で検証し、失敗するとマスタ同期をロールバックして FAILED を記録する。
