# 40_player-admin-edit モデル定義

JSONの物理名はcamelCaseとする。UTC日時はISO 8601で返す。GUIDは空GUIDを許可しない。

### 編集開始要求

物理名: `PlayerAdminEditStartRequest`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `editSessionId` | GUID | ✗ | 結果不明でも維持する開始ID |
| `reason` | string | ✗ | 訂正理由。空白不可、500文字以内 |

### 編集セッション

物理名: `PlayerAdminEditSessionResponse`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `editSessionId / accountId / userUuid / actorUserUuid` | GUID | ✗ | 編集・対象アカウント・対象ユーザー・操作者 |
| `reason` | string | ✗ | 開始理由 |
| `status` | string | ✗ | DRAINING / READY / APPLYING / COMPLETED / CANCELED / RECOVERY_REQUIRED |
| `revision` | int64 | ✗ | 確認・状態変更で増加する期待版 |
| `createdAtUtc / updatedAtUtc / expiresAtUtc` | UTC日時 | ✗ | 作成・更新・編集期限 |
| `completedAtUtc` | UTC日時 | ✓ | 反映または取消の確定時刻 |
| `expectedServerCount / acknowledgedServerCount` | int | ✗ | 必須退避確認数と確認済み数 |

### 反映要求

物理名: `PlayerAdminEditOperationRequest`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `operationId` | GUID | ✗ | 同一payload再送で維持する操作ID |
| `expectedRevision` | int64 | ✗ | 編集セッションの確認版 |
| `expectedStateHash` | SHA256 hex | ✗ | 確認したaccount/class progress/inventoryと参照装備・装備構成の状態 |
| `expectedCatalogVersion` | SHA256 hex | ✗ | 確認したitem詳細マスタ版。class詳細版も編集セッションの固定値と照合 |
| `level` | int | ✓ | 変更するレベル。1～100 |
| `classId` | string | ✓ | 変更する現在クラス |
| `inventoryChanges` | inventory変更[] | ✗ | 空配列可。最大256件 |

### 取消要求

物理名: `PlayerAdminEditCancelRequest`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `operationId` | GUID | ✗ | 同一取消再送で維持する操作ID |
| `expectedRevision` | int64 | ✗ | 取消対象の確認版 |

### inventory変更

物理名: `PlayerAdminInventoryChange`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `action` | string | ✗ | GRANT / SET_QUANTITY / DELETE |
| `itemId` | string | ✓ | GRANT時のマスタID |
| `inventoryEntryId` | GUID | ✓ | SET_QUANTITY / DELETE時の既存entry ID |
| `quantity` | int64 | ✓ | 付与・設定数量。DELETEでは指定しない |
| `expectedUpdatedAt` | UTC日時 | ✓ | 既存entryの確認した版 |

### 編集表示

物理名: `PlayerAdminEditorResponse`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `session` | 編集セッション | ✗ | 所有セッション |
| `account` | アカウント状態 | ✗ | 確定済み進行度 |
| `inventories` | inventory状態[] | ✗ | entryを含む表示用inventory |
| `availableItems` | 付与候補[] | ✗ | 現在のアイテム定義 |
| `availableClasses` | クラス候補[] | ✗ | 現在のクラス定義 |
| `expectedStateHash / catalogVersion` | SHA256 hex | ✗ | 反映要求へ戻す確認値 |

### アカウント状態

物理名: `PlayerAdminAccountResponse`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `accountId / userUuid` | GUID | ✗ | アカウントと所有者 |
| `level / highestLevel` | int | ✗ | 現在・最高到達レベル |
| `totalExperience` | int64 | ✗ | UUID依存の累計EXP |
| `classId` | string | ✗ | 現在クラス |
| `classLevel` | int | ✗ | 現在クラスのレベル |
| `classExperience` | int64 | ✗ | 現在クラスのEXP |
| `progressVersion` | int | ✗ | 通常進行度の保存版 |

### inventory状態

物理名: `PlayerAdminInventoryResponse`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `inventoryId` | GUID | ✗ | inventory ID |
| `inventoryType / inventoryProfile` | string | ✗ | 種類とGAME等のprofile |
| `slotCapacity` | int | ✓ | 収納容量 |
| `isEnabled` | bool | ✗ | 利用可否 |
| `entries` | entry状態[] | ✗ | 論理削除されていないentry |

### entry状態

物理名: `PlayerAdminInventoryEntryResponse`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `inventoryEntryId` | GUID | ✗ | entry ID。item IDや個体IDと区別 |
| `slotIndex` | int | ✓ | DB論理slot。通常BAGは1始まり |
| `itemCategory` | string | ✗ | マスタカテゴリ |
| `itemId` | string | ✓ | マスタitem ID |
| `resolvedItemId / displayName` | string | ✓ | 個体参照から解決したマスタID・表示名。解決不能ならnull |
| `instanceType / instanceId` | string / GUID | ✓ | 装備等の個体種別・ID |
| `quantity` | int64 | ✗ | 保有数量 |
| `metadataJson` | string | ✓ | 個体・保護情報 |
| `updatedAt` | UTC日時 | ✗ | entry確認版 |

### 付与候補

物理名: `PlayerAdminItemResponse`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `itemId / name / category` | string | ✗ | ID・表示名・カテゴリ |
| `maxStack` | int | ✗ | 通常アイテムのstack上限 |

### クラス候補

物理名: `PlayerAdminClassResponse`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `classId / name` | string | ✗ | ID・表示名 |
| `maxLevel` | int | ✗ | クラスレベル上限 |

### サーバー登録要求

物理名: `PlayerAdminRuntimeRegistrationRequest`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `serverSessionId` | GUID | ✗ | プロセス起動ごとに固定するboot ID |
| `role` | string | ✗ | RPG / LOBBY / PROXY |
| `itemCatalogHash / classCatalogHash` | SHA256 hex | ✓ | RPGでは必須。ロード済み詳細定義から算出 |

### サーバー登録結果

物理名: `PlayerAdminRuntimeRegistrationResponse`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `serverId` | string | ✗ | 必須一覧と一致するサーバーID |
| `serverSessionId` | GUID | ✗ | 登録boot ID |
| `role` | string | ✗ | 登録役割 |

### 退避要求

物理名: `PlayerAdminDrainResponse`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `editSessionId / accountId / userUuid` | GUID | ✗ | 編集・対象アカウント・制限対象ユーザー |
| `status` | string | ✗ | 未完了状態 |
| `revision` | int64 | ✗ | 編集版 |
| `safeToDisconnect` | bool | ✗ | 全RPGの保存・退出確認済み。Proxy/Lobby切断の条件 |

### 退避確認要求

物理名: `PlayerAdminDrainAckRequest`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `serverId` | string | ✗ | 応答元サーバーID |
| `serverSessionId` | GUID | ✗ | captureされたboot ID |
| `accountId / userUuid` | GUID | ✗ | 編集対象identity |
| `saved / offline` | bool | ✗ | 双方trueの明示的証明のみ受付 |
| `ackId` | GUID | ✗ | 同じ退避確認を再送する固定ID |

## マスタ版

RPGはAPIのitem/class詳細JSONを受信した時点のUTF-8本文SHA256を保持する。APIも同じWeb JSON規則で詳細を直列化する。IDをordinal順に並べた`id<TAB>詳細SHA256<LF>`のSHA256をitemとclassで算出し、開始時に両方を固定する。Pluginが内部で追加する仮想定義はAPIカタログの対象に含めない。設定・JSON形式変更で版が一致しない場合も反映を拒否する。
