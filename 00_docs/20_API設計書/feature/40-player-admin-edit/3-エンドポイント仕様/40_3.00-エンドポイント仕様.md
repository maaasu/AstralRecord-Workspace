# 40_player-admin-edit エンドポイント仕様

## 共通リクエストと認可

| 種別 | 名前 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| Header | `X-Api-Key` | string | ✓ | 既存共通APIキー。全経路でmiddleware検証 |
| Header | `X-Player-Admin-Web-Key` | string | 管理経路 | `PlayerAdmin:WebKey`。共通キーと別の専用キー |
| Query | `actor_user_uuid` | GUID | 管理経路 | WebがCookie claimsから設定。ManagementのWebAdminを再検証 |
| Path | `accountId` | GUID | 対応経路 | 編集対象アカウント |
| Path | `editSessionId` | GUID | 対応経路 | 操作者を固定した編集ID |
| Path | `serverId` | string | runtime経路 | 64文字以内のASCII英数字・`-`・`_` |
| Query | `server_session_id` | GUID | 退避一覧 | 現プロセスboot ID |

管理経路は`runtime/`以外とする。他操作者の編集は403。runtime経路は既存の共通APIキーだけで認証し、任意のWeb操作者として扱わない。サーバー起動ID・編集対象・保存と退出の確認条件は維持する。

共通エラーは[[40_5.00-例外・ログ・運用]]を参照する。Bodyは[[40_1.00-モデル定義]]のモデル定義に従う。

### 編集開始

HTTPメソッド: `POST`
パス: `/api/player-admin/accounts/{accountId}/edit-sessions`
コントローラ: `PlayerAdminController`
アクション物理名: `Start`

リクエスト:

| 種別 | 名前 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| Header / Path / Query | 共通項目 | 共通表参照 | ✓ | 上記の経路別条件 |
| Body | 要求 | [[40_1.00-モデル定義]].編集開始要求 | ✓ | 本文モデル |

レスポンス:

| ステータス | 内容 | ボディ |
|---|---|---|
| 201 Created / 200 OK | 成功または同一開始の照会 | [[40_1.00-モデル定義]].編集セッション |
| 400 / 401 / 403 / 404 / 409 | 入力・認証・所有者・未存在・安全条件エラー | [[40_5.00-例外・ログ・運用]] |

処理内容:

1. ユーザー→対象アカウントの順にロックし、所有者と必須boot・マスタ版を検証して参加制限と退避一覧を永続化する。開始IDの再利用は元の対象・理由と照合する。
