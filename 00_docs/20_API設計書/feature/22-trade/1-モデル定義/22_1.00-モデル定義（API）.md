# 22_1.00-モデル定義（API）

## トレード確定要求

物理名: `TradeCommitRequest`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `operationId` | GUID | ✗ | session 単位の冪等キー |
| `playerAAccountId` | GUID | ✗ | 参加者 A の account |
| `playerBAccountId` | GUID | ✗ | 参加者 B の account |
| `playerAItems` | 明細配列 | ✗ | A から B へ移す item |
| `playerBItems` | 明細配列 | ✗ | B から A へ移す item |
| `playerAGold` | long | ✗ | A が B へ支払う Gold（0 以上） |
| `playerBGold` | long | ✗ | B が A へ支払う Gold（0 以上） |
| `updatedBy` | GUID | ✗ | 監査更新者 |

## トレード item 明細

物理名: `TradeCommitItemRequest`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `sourceInventoryEntryId` | GUID | ✗ | 提示元の GAME BAG/HOTBAR entry |
| `quantity` | long | ✗ | 通常 item は移管個数、個体 item は 1 |

## トレード確定応答

物理名: `TradeCommitResponse`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `operationId` | GUID | ✗ | 確定済み冪等キー |
| `playerAAffectedInventoryEntryIds` | GUID 配列 | ✗ | A の Plugin state が再同期する entry ID |
| `playerBAffectedInventoryEntryIds` | GUID 配列 | ✗ | B の Plugin state が再同期する entry ID |
| `completedAt` | datetime | ✗ | DB 確定日時 |
