# リリースノート ユースケース

## Web起動時同期

1. Web が `status: published` かつ公開日時到来済みの Markdown を列挙する。
2. front matter と公開URLを検証し、内容ハッシュを計算する。
3. Web がAPIへリリースノート公開リクエストを送信する。
4. API がメタデータをupsertし、Discord通知対象ならOutboxを一度だけ作成する。

## Discord通知

1. APIワーカーが送信可能なOutboxをリース付きで取得する。
2. `token.txt` からBotトークンを読み、指定チャンネルへURLを送信する。
3. 成功時は `Sent`、再試行可能な失敗時は指数バックオフ付き `Failed`、恒久的な失敗時は長期保留へ更新する。
