# リリースノート 統合フロー

```text
00_docs/70_リリースノート/*.md
        │ Web publish output: release-notes/
        ▼
Web ReleaseNoteCatalog
        │ POST /api/release-notes/publish + X-Api-Key
        ▼
ReleaseNoteController
        │ transaction
        ├─ release_note upsert
        └─ release_notification_outbox Pending
                │
                ▼
ReleaseNotificationHostedService
        │ token.txt + Discord REST API v10
        ▼
Discord channel 1261962785026343043
```

Webの再起動・再デプロイ時は同じslugとチャネルのOutboxを再利用するため、Sent済みノートを重複送信しない。Discord Create Message APIにはOutbox ID由来の安定nonceと `enforce_nonce=true` を指定し、送信後のプロセス停止時もDiscord側の短時間nonce重複排除を利用する。ネットワーク障害でDiscord側の受理結果が不明な場合は、Discordのnonce保持期間外に再送される可能性があるため、配送保証はat-least-onceとする。API停止中の同期はWebが30秒間隔で再試行する。
