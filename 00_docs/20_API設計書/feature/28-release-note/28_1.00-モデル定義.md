# リリースノート モデル定義

## リリースノート公開リクエスト

物理名: `ReleaseNotePublishRequest`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `slug` | string | ✗ | 小文字英数字とハイフンで構成するURL識別子 |
| `version` | string | ✗ | バージョン表示文字列 |
| `title` | string | ✗ | リリースノートタイトル |
| `summary` | string | null | ✓ | 一覧表示用概要。`null` は空文字へ正規化 |
| `publishedAt` | DateTimeOffset | ✗ | 公開日時。未来日時の場合、Outboxは公開日時まで待機 |
| `releaseUrl` | string | ✗ | `https://astralrecord.com/releases/{slug}` |
| `sourcePath` | string | ✗ | リポジトリ相対のMarkdownパス |
| `contentSha256` | string | ✗ | 内容のSHA-256（16進64文字） |
| `notifyDiscord` | bool | ✗ | Discord通知をOutboxへ登録するか |

## リリースノート公開レスポンス

物理名: `ReleaseNotePublishResponse`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `slug` | string | ✗ | 登録したslug |
| `releaseUrl` | string | ✗ | 公開URL |
| `created` | bool | ✗ | 新規登録か |
| `notificationQueued` | bool | ✗ | 新規通知Outboxを登録したか |

## Discord通知再試行レスポンス

物理名: `ReleaseNotificationRetryResponse`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `slug` | string | ✗ | 対象slug |
| `notificationQueued` | bool | ✗ | Pendingへ戻したか |
