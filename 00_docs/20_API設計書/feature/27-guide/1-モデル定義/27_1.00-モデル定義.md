# Guide API モデル定義

## GuideResponse

`40_filebase/09.features.guide` のガイド定義を MasterDataDB 経由で返す。

| フィールド | 型 | 必須 | 説明 |
|:--|:--|:--:|:--|
| `schemaVersion` | int | ✓ | スキーマバージョン |
| `id` | string | ✓ | ガイド ID |
| `category` | string | ✓ | 分類。表示順の一次キー |
| `displayOrder` | int | ✓ | 同一分類内の表示順 |
| `title` | string | ✓ | GUI 表示タイトル |
| `iconMaterial` | string |  | Bukkit `Material` 名 |
| `summary` | string |  | 一覧表示用の短い説明 |
| `steps` | GuideStepResponse[] | ✓ | GUI に表示する手順。配列順は表示順だけを決め、達成順を強制しない |

## GuideStepResponse

| フィールド | 型 | 必須 | 説明 |
|:--|:--|:--:|:--|
| `id` | string | ✓ | Guide内で一意なstep ID |
| `text` | string | ✓ | 手順の表示文 |
| `details` | string[] |  | 具体的な操作方法。Plugin は灰色で表示する |
| `condition` | GuideConditionResponse | ✓ | 達成条件 |
| `action` | GuideActionResponse |  | クリック時の案内アクション |

## GuideActionResponse

| フィールド | 型 | 必須 | 説明 |
|:--|:--|:--:|:--|
| `type` | string | ✓ | `NAVIGATE_NPC` または `OPEN_MENU` |
| `description` | string |  | クリック時に行う動作の表示説明 |
| `npcId` | string |  | `NAVIGATE_NPC` の対象 NPC マスタ ID |
| `menuId` | string |  | `OPEN_MENU` の対象メニュー ID。現状は `mail` |

## GuideConditionResponse

| フィールド | 型 | 必須 | 説明 |
|:--|:--|:--:|:--|
| `type` | string | ✓ | Pluginが解釈する条件種別 |
| `targetId` | string |  | 条件対象ID。未指定時は同種イベントの全対象 |
| `level` | int |  | `MOB_DEFEATED` の対象Mobレベル。未指定時は全レベル |

## AccountGuideProgressResponse

| フィールド | 型 | 必須 | 説明 |
|:--|:--|:--:|:--|
| `accountId` | UUID | ✓ | アカウントID |
| `completedSteps` | AccountGuideStepProgressResponse[] | ✓ | 完了済みstep一覧 |

## AccountGuideStepProgressResponse

| フィールド | 型 | 必須 | 説明 |
|:--|:--|:--:|:--|
| `accountGuideStepProgressId` | UUID | ✓ | 進行行ID |
| `accountId` | UUID | ✓ | アカウントID |
| `guideId` | string | ✓ | Guide ID |
| `stepId` | string | ✓ | step ID |
| `completedAt` | datetime | ✓ | 初回達成日時 |
| `createdAt` | datetime | ✓ | 作成日時 |
| `createdBy` | UUID | ✓ | 達成したuser ID |
