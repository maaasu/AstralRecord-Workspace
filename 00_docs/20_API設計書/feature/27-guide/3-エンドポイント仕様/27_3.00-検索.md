# Guide API エンドポイント仕様

## GET `/api/guide`

ゲーム内ガイドの一覧を取得する。

### レスポンス

| Status | Body | 説明 |
|:--|:--|:--|
| 200 | `GuideResponse[]` | ガイド一覧 |

### 並び順

1. `category` の既定順
2. `displayOrder` 昇順
3. `id` 昇順

`category` の既定順は `beginner`、`equipment`、`skill`、`world`、その他の順とする。

## GET `/api/guide/{guideId}`

指定したガイドを取得する。

### パスパラメータ

| 名前 | 型 | 必須 | 説明 |
|:--|:--|:--:|:--|
| `guideId` | string | ✓ | ガイド ID |

### レスポンス

| Status | Body | 説明 |
|:--|:--|:--|
| 200 | `GuideResponse` | ガイド詳細 |
| 404 | なし | 指定 ID のガイドが存在しない |
