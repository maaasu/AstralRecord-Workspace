# Guide API エンドポイント仕様

## GET `/api/guide`

ゲーム内ガイドの一覧を取得する。

### レスポンス

| Status | Body | 説明 |
|:--|:--|:--|
| 200 | `GuideResponse[]` | ガイド一覧 |

### 並び順

1. `category` の既定順
2. `displayOrder` 昇順
3. `id` 昇順

`category` の既定順は `beginner`、`equipment`、`skill`、`world`、その他の順とする。

## GET `/api/guide/{guideId}`

指定したガイドを取得する。

### パスパラメータ

| 名前 | 型 | 必須 | 説明 |
|:--|:--|:--:|:--|
| `guideId` | string | ✓ | ガイド ID |

### レスポンス

| Status | Body | 説明 |
|:--|:--|:--|
| 200 | `GuideResponse` | ガイド詳細 |
| 404 | なし | 指定 ID のガイドが存在しない |

## GET `/api/account-guide/{accountId}`

アカウントの完了済みガイド手順を取得する。

| Status | Body | 説明 |
|:--|:--|:--|
| 200 | `AccountGuideProgressResponse` | 取得成功。未達成時は空配列 |
| 404 | なし | アカウントが存在しない |

## POST `/api/account-guide/{accountId}/steps/complete`

指定stepを完了済みとして冪等登録する。

### リクエスト

| フィールド | 型 | 必須 | 説明 |
|:--|:--|:--:|:--|
| `guideId` | string | ✓ | Guide ID |
| `stepId` | string | ✓ | step ID |
| `updatedBy` | UUID | ✓ | 達成したuser ID |

| Status | Body | 説明 |
|:--|:--|:--|
| 200 | `AccountGuideStepProgressResponse` | 登録成功、または既に登録済み |
| 400 | 文字列 | IDが空、または100文字超過 |
| 404 | なし | アカウントが存在しない |
