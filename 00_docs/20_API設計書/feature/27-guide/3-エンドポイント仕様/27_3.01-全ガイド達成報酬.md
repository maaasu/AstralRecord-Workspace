# 全ガイド達成報酬

アカウント単位で一度だけ、全ガイド達成報酬を既存のメール受取経路に配信する。

## 設定

API の `GuideCompletionReward:Rewards` に既存メール報酬と同じ `ItemId`、`Category`、`Amount` を列挙する。空配列にすると受取不可となり、受取権は消費しない。空配列、空 ID / Category、非正数、個体 ID 指定、有効なアイテムマスターまたは組込Gold額面と一致しない品目は未設定として扱い、受取記録を作らない。PET / PET_EGG は既存の所有個体 ID がないとメールで受け取れないため、この設定では扱わない。

既定の添付は次の4行。bundle は追加しない。

| 品目 | ItemId | Category | Amount |
|---|---|---|---:|
| ルーンの金片（合計3,000 Gold） | `99a00001` | `currency` | 3000 |
| シンドリのオーブ | `40a00011` | `orb` | 10 |
| ヴェルディアHP回復ポーション【中】 | `30a00032` | `consumable` | 10 |
| ヴェルディアMP回復ポーション【中】 | `30a00035` | `consumable` | 10 |

`99a00001` は1個=1 GoldのPlugin組込通貨であり、YAMLや通常アイテムマスター行を必要としない。検証は既存 `GoldCurrencyBalanceSupport` の正規額面IDと `currency` カテゴリの組み合わせだけを例外として受理する。IDの接頭辞だけでは受理せず、不明IDやカテゴリ違いは拒否する。メール受取は既存の通貨・所持品保存経路を利用する。

## GET `/api/account-guide/{accountId}/completion-reward`

`200 OK` は `{ accountId, configured, allCompleted, claimed, canClaim, mailId }`。`mailId` はこのアカウントで配信した場合はそのメール ID、未受取またはアカウント複製で受取済み状態を継承した場合は null。存在しない、または削除済みアカウントは `404`。

`allCompleted` は現在の Guide マスターに一つ以上のガイドがあり、各ガイドに一つ以上の手順があり、そのすべての `(guideId, stepId)` がアカウントの完了記録にある場合のみ true。追加されたガイドが未完了なら false に戻る。`claimed` は別の永続記録で、一度 true になると新しいガイドの追加で false に戻らない。`canClaim` は設定済み、全達成、未受取のすべてを満たす場合だけ true。

## POST `/api/account-guide/{accountId}/completion-reward/claim`

要求 `{ "updatedBy": "<user UUID>" }`。受取時に現行ガイド全手順と設定を再確認する。成功時 `200 OK` で GET と同じ応答。再送や二重クリックで既に受取済みの場合も `200 OK` と `claimed=true` を返す。未設定、未達成、操作 UUID 欠落は `409 Conflict`。アカウントなしは `404`。

ゲーム DB のアカウント行ロックの下で、`account_guide_completion_reward` の一意な受取記録と `player_mail_delivery` を同じトランザクションで作成する。メール ID は `guide-completion-{accountId:N}` に固定する。通信結果不明の再送は受取記録を読み直して同じ結果に収束させる。アイテムの実際の受取は従来どおりメール画面で行い、満杯時の処理は既存メール受取経路に従う。報酬メールの配信だけでガイド手順を変更しない。

アカウント複製では複製元または上書き先が受取済みなら、新アカウントへ受取済み記録だけを継承する。複製で報酬メールを再配信しない。複製先の記録には `inherited_from_account_id` を記録し、`mailId` は null とする。
