# 16_3.01-取得系

## 1. 取得系エンドポイント仕様

### Mob 一覧取得

HTTPメソッド: `GET`
パス: `/api/mob`
コントローラ: `MobController`
アクション物理名: `GetAll`

責務:

MasterDataDB の `dbo.master_data_entry`（`master_type IN ('mob.boss', 'mob.enemy', 'mob.npc')`）から有効レコードを取得し、主要項目のみ返却する。

リクエスト:

| 種別 | 名前 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| Header | `X-Api-Key` | string | ✓ | API キー |
| Query | `category` | string | × | フィルタ。`BOSS` / `ENEMY` / `NPC` のいずれか。大小区別なし。未指定なら全カテゴリ |

レスポンス:

| ステータス | 内容 | ボディ |
|---|---|---|
| 200 OK | 取得成功 | [[16_1.00-モデル定義]].Mob 一覧レスポンス要素 の配列 |
| 400 Bad Request | `category` 値が不正 | `ProblemDetails` |
| 401 Unauthorized | API キー未指定/無効 | なし |

処理内容:

1. 認証パイプラインで `X-Api-Key` を検証する
2. `category` クエリの妥当性を判定する
    | 値 | 取得対象 master_type |
    |---|---|
    | 未指定 | `mob.boss`, `mob.enemy`, `mob.npc` の全件 |
    | `BOSS` | `mob.boss` のみ |
    | `ENEMY` | `mob.enemy` のみ |
    | `NPC` | `mob.npc` のみ |
    | その他 | 400 を返す |
3. MasterDataDB から該当 mob を取得し、`payload_json` を [[16_1.00-モデル定義]].Mob 詳細レスポンス へデシリアライズしてから主要項目へ射影する

    | 項目 | 内容 |
    |---|---|
    | 取得対象 | `master_type` 該当 かつ `is_deleted = 0` |
    | デシリアライザ | `System.Text.Json`（CamelCase / 大小区別なし） |
    | 並び順 | `master_type` ASC, `master_id` ASC |

4. 200 で配列を返す
5. 例外時は [[16_5.00-例外・ログ・運用]] のログを記録し 500 を返す

---

### Mob 詳細取得

HTTPメソッド: `GET`
パス: `/api/mob/{mobId}`
コントローラ: `MobController`
アクション物理名: `GetById`

責務:

`mobId` をキーに MasterDataDB から有効レコードを取得し、`payload_json` をデシリアライズした [[16_1.00-モデル定義]].Mob 詳細レスポンス を返す。

リクエスト:

| 種別 | 名前 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| Header | `X-Api-Key` | string | ✓ | API キー |
| Path | `mobId` | string | ✓ | Mob テンプレート ID |

レスポンス:

| ステータス | 内容 | ボディ |
|---|---|---|
| 200 OK | 取得成功 | [[16_1.00-モデル定義]].Mob 詳細レスポンス |
| 401 Unauthorized | API キー未指定/無効 | なし |
| 404 Not Found | 未定義 mobId | なし |

処理内容:

1. 認証パイプラインで `X-Api-Key` を検証する
2. MasterDataDB から `master_type IN ('mob.boss', 'mob.enemy', 'mob.npc')` かつ `master_id = mobId` で検索する

    | 項目 | 内容 |
    |---|---|
    | 取得対象 | `payload_json`（`is_deleted = 0` のみ） |
    | 取得失敗 | 404 を返す |

3. `payload_json` を [[16_1.00-モデル定義]].Mob 詳細レスポンス へデシリアライズし 200 を返す
4. 例外時は [[16_5.00-例外・ログ・運用]] のログを記録し 500 を返す
