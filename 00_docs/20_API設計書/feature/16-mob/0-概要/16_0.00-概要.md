# 16_0.00-概要

## 1. 目的

MasterDataDB に投入済みの `mob` マスタから、Mob テンプレート定義を取得する読み取り専用 API。

## 2. コンテキスト

- 通常リクエスト時に filebase を直接読まず、MasterDataDB を参照する。
- 全件常時メモリ保持は行わず、必要に応じて ID 単位の短時間キャッシュのみ許容する。
- 一覧取得は主要項目のみ返却し、詳細は ID 指定で取得する設計。
- Mob のソースは `40_filebase/40.features.mob/{boss,enemy,npc}` の 3 ディレクトリに分かれ、`MasterDataSeeder` の Split 構造により以下の `master_type` で MasterDataDB に格納される。
  - `mob.boss`
  - `mob.enemy`
  - `mob.npc`
- API は 3 つの `master_type` を透過的に統合し、`/api/mob` 配下に単一のエンドポイント群として提供する。

## 3. 構成要素

- `Controllers/MobController`
- `Repositories/MobRepository`（MasterDataDB 参照）
- `Models/MobResponse`, `MobSummaryResponse`
