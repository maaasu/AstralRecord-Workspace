# 16_1.00-モデル定義

## 1. Mob 一覧レスポンス要素

物理名: `MobSummaryResponse`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `id` | string | ✗ | Mob テンプレート ID |
| `category` | string | ✗ | `BOSS` / `ENEMY` / `NPC` |
| `name` | string | ✗ | 表示名（Minecraft カラーコード含む） |
| `level` | int | ✗ | Mob の既定レベル。`levels` がある場合は最小レベル |
| `entityType` | string | ✗ | Bukkit EntityType（例: `ZOMBIE`） |
| `icon` | string | ✓ | アイコン（Minecraft マテリアル名） |
| `tags` | string[] | ✗ | 検索・分類用タグ |

## 2. Mob 詳細レスポンス

物理名: `MobResponse`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `schemaVersion` | int | ✗ | YAML スキーマバージョン |
| `id` | string | ✗ | Mob テンプレート ID |
| `type` | string | ✗ | マスタ種別（`MOB`） |
| `category` | string | ✗ | `BOSS` / `ENEMY` / `NPC` |
| `name` | string | ✗ | 表示名 |
| `title` | string | ✓ | 二つ名・称号 |
| `level` | int | ✗ | Mob の既定レベル。未指定または不一致時のフォールバックは最小レベル |
| `levels` | object[] | ✗ | 同一 Mob マスタ内のレベル別部分プロファイル。定義がない場合は空配列。各要素の `level` は必須で、未指定フィールドは親定義から継承 |
| `entityType` | string | ✗ | Bukkit EntityType |
| `nameVisible` | bool | ✗ | ネームタグ表示有無 |
| `damageImmune` | bool | ✓ | ダメージ無効化。未指定時はクライアント側のカテゴリ既定値を使用 |
| `icon` | string | ✓ | アイコン |
| `lore` | string[] | ✗ | 説明文 |
| `tags` | string[] | ✗ | 検索・分類用タグ |
| `skin` | object | ✓ | スキン設定（[[16_1.00-モデル定義]].Mob スキン） |
| `variant` | object | ✓ | バニラ外見差分設定（[[16_1.00-モデル定義]].Mob 外見差分）。未定義の場合は `null` |
| `equipment` | object | ✓ | 装備設定（[[16_1.00-モデル定義]].Mob 装備） |
| `baseStats` | object[] | ✗ | ステータスリスト（[[16_1.00-モデル定義]].Mob ベースステータス） |
| `ai` | object | ✗ | AI 設定（[[16_1.00-モデル定義]].Mob AI 設定） |
| `interactions` | object | ✓ | NPC クリックインタラクション設定（[[16_1.00-モデル定義]].Mob インタラクション設定）。`category = NPC` で使用 |
| `drops` | object | ✓ | ドロップ設定（[[16_1.00-モデル定義]].Mob ドロップ設定）。`category = NPC` の場合は `null` |
| `challenge` | object | ✓ | ボス挑戦設定。`category = BOSS` の場合に使用 |

## 3. Mob スキン

物理名: `MobSkinResponse`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `texture` | string | ✓ | Base64 エンコード済みスキンテクスチャ |
| `signature` | string | ✓ | テクスチャ署名値 |

## Mob 外見差分

物理名: `MobVariantResponse`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `age` | string | ✓ | 年齢表現。`ADULT` / `BABY`。未指定時は Plugin が `ADULT` として扱う |
| `kind` | string | ✓ | Cat / Rabbit / Fox / Frog / Axolotl / Parrot / Mooshroom など、Bukkit 側の variant/type setter に渡す値名 |
| `color` | string | ✓ | Sheep / Horse / Llama など、Bukkit 側の color setter に渡す値名 |
| `style` | string | ✓ | Horse など、Bukkit 側の style setter に渡す値名 |
| `profession` | string | ✓ | Villager / ZombieVillager の職業。Bukkit `Villager.Profession` 名 |
| `villagerType` | string | ✓ | Villager のバイオーム種別。Bukkit `Villager.Type` 名 |
| `villagerLevel` | int | ✓ | Villager の取引レベル。Plugin が `1` - `5` に丸めて適用する |
| `pattern` | string | ✓ | TropicalFish など、Bukkit 側の pattern setter に渡す値名 |
| `bodyColor` | string | ✓ | TropicalFish などの体色。Bukkit `DyeColor` 名 |
| `patternColor` | string | ✓ | TropicalFish などの模様色。Bukkit `DyeColor` 名 |
| `mainGene` | string | ✓ | Panda の主遺伝子。Bukkit `Panda.Gene` 名 |
| `hiddenGene` | string | ✓ | Panda の隠し遺伝子。Bukkit `Panda.Gene` 名 |

API は filebase の値を返し、Plugin は名前付きの値を大文字・小文字を区別せず解決する。未対応の `entityType` に指定されたフィールドや未知の値名は、Plugin 側でその差分だけを無視する。

## 4. Mob 装備

物理名: `MobEquipmentResponse`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `mainHand` | string | ✓ | Bukkit/Paper の標準 Material 名（例: `IRON_SWORD`） |
| `offHand` | string | ✓ | Bukkit/Paper の標準 Material 名 |
| `helmet` | string | ✓ | Bukkit/Paper の標準 Material 名 |
| `chestplate` | string | ✓ | Bukkit/Paper の標準 Material 名 |
| `leggings` | string | ✓ | Bukkit/Paper の標準 Material 名 |
| `boots` | string | ✓ | Bukkit/Paper の標準 Material 名 |

YAML 上は標準 Material 名を文字列で指定する。API レスポンスも Material 名をそのまま返す。
Material 名の解決はクライアント（プラグイン）側で行う。

## 5. Mob ベースステータス

物理名: `MobBaseStatResponse`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `status` | string | ✗ | 共有ステータスカタログのID（例: `MAX_HEALTH`） |
| `value` | number | ✗ | ステータス値 |

## 6. Mob AI 設定

物理名: `MobAiResponse`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `idle` | object | ✗ | 待機行動設定（[[16_1.00-モデル定義]].Mob 待機設定） |
| `targeting` | object | ✓ | ターゲット選定設定（`category = NPC` の場合は `null`） |
| `combat` | object | ✓ | 戦闘設定（`category = NPC` の場合は `null`） |

## 7. Mob 待機設定

物理名: `MobIdleResponse`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `behavior` | string | ✗ | `STATIONARY` / `WANDER` / `PATROL` |
| `wanderRadius` | number | ✗ | 徘徊半径（デフォルト 10.0） |
| `speed` | number | ✗ | 待機時の移動速度倍率（デフォルト 1.0） |

## 8. Mob ターゲット設定

物理名: `MobTargetingResponse`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `strategy` | string | ✗ | `NEAREST` / `HIGHEST_THREAT` / `RANDOM` / `LOWEST_HP` |
| `aggroRange` | number | ✗ | 敵対検知範囲 |
| `deaggroRange` | number | ✗ | 敵対解除距離（デフォルト `aggroRange * 2`） |
| `leashRange` | number | ✗ | スポーン地点からの最大追跡距離（デフォルト 30.0） |
| `retaliateOnly` | boolean | ✗ | 攻撃を受けた後のみターゲット選定を行うか（デフォルト false） |

## 9. Mob 戦闘設定

物理名: `MobCombatResponse`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `style` | string | ✗ | `MELEE` / `RANGED` / `MAGIC` |
| `preferredRange` | number | ✗ | 戦闘時の理想距離（デフォルト 1.0） |
| `attackIntervalTicks` | int | ✗ | 通常攻撃の間隔（tick。デフォルト 20） |

## 10. Mob インタラクション設定

物理名: `MobInteractionsResponse`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `leftClick` | object[] | ✗ | 左クリック時に実行するアクション一覧。未指定時は空配列 |
| `rightClick` | object[] | ✗ | 右クリック時に実行するアクション一覧。未指定時は空配列 |

`category = NPC` の Mob で使用する。API は filebase YAML の `interactions` をそのまま返し、実行可否や GUI 種別の解決はクライアント（プラグイン）側で行う。

## 11. Mob インタラクションアクション

物理名: `MobInteractionActionResponse`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `id` | string | ✗ | アクション ID。初期定義は `message` / `gui` / `command` |
| `params` | object | ✗ | アクションごとのパラメータ。値は文字列として返す |

初期定義:

| `id` | `params` | 説明 |
|---|---|---|
| `message` | `message` | プレイヤーに送るメッセージ本文 |
| `gui` | `type` | 開く GUI の種類（例: `SHOP`, `QUEST`, `MENU`） |
| `command` | `command` | プレイヤーとして実行するコマンド文字列。先頭の `/` は任意 |

## 12. Mob ドロップ設定

物理名: `MobDropsResponse`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `exp` | int | ✗ | 撃破時獲得経験値 |
| `money` | object | ✓ | 金銭ドロップ（[[16_1.00-モデル定義]].Mob 金銭ドロップ） |
| `items` | object[] | ✗ | ドロップアイテム一覧（[[16_1.00-モデル定義]].Mob ドロップアイテム） |
| `lootTable` | string | ✓ | 既存 LootTable の参照値（例: `loot_table:windwait_field_table`） |

## 13. Mob 金銭ドロップ

物理名: `MobMoneyDropResponse`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `min` | int | ✗ | 最小値（両端含む） |
| `max` | int | ✗ | 最大値（両端含む） |

## 14. Mob ドロップアイテム

物理名: `MobDropItemResponse`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `itemId` | string | ✗ | item 参照値（例: `item:glowstone_shard`） |
| `rate` | number | ✗ | ドロップ確率（0.00〜100.00） |
| `amount` | string | ✗ | 数量。固定値（`"1"`）または範囲（`"1~3"`） |
| `luckAffected` | bool | ✗ | `true` の場合、幸運補正の影響を受ける |
| `hidden` | bool | ✗ | `true` の場合、図鑑表示しない |

## Mob シールド設定

物理名: `MobShieldResponse`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `enabled` | bool | ✗ | シールドを有効化するか |
| `max` | number | ✗ | 最大シールド値 |
| `rechargeTimeSeconds` | number | ✓ | シールド破壊から一括回復までの基礎秒数。未設定時はリチャージしない |
| `rechargeAmount` | number | ✓ | 完了時の回復量。未設定時は `max`。`max` を超える値も許可する |

`MobResponse.shield` は filebase の `shield` 定義をそのまま返す。未定義の場合は `null`。
# 実装同期メモ

2026-06-24 時点で `MobResponse.challenge` を追加した。`category = BOSS` の Mob は、filebase の `challenge` を `MobChallengeResponse` として返す。主なフィールドは `fieldWorldId`, `entryLocation`, `entryRadius`, `playerSpawnLocation`, `bossSpawnLocation`, `partyMin`, `partyMax`, `timeLimitSeconds`, `deathLimit`, `reviveDelaySeconds`, `scaling` である。`deathLimit` の既定値は 5、`reviveDelaySeconds` の既定値は 5 秒とする。
