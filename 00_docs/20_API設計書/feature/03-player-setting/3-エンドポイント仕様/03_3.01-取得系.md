# 03_3.01-取得系

### 設定一覧取得

HTTPメソッド: `GET`
パス: `/api/player-setting?user_id={userId}`
コントローラ: `PlayerSettingController`
アクション: `GetByUserId`

レスポンス:
- `200 OK`: `PlayerSettingResponse[]`

### 設定1件取得

HTTPメソッド: `GET`
パス: `/api/player-setting/{userSettingId}`
コントローラ: `PlayerSettingController`
アクション: `GetById`

レスポンス:
- `200 OK`: `PlayerSettingResponse`
- `404 Not Found`: 対象が存在しない
