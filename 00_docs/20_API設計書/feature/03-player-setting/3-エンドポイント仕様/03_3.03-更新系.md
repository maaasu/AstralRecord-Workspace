# 03_3.03-更新系

### 設定更新（楽観ロック）

HTTPメソッド: `PUT`
パス: `/api/player-setting/{userSettingId}`
コントローラ: `PlayerSettingController`
アクション: `Update`

リクエストDTO: `PlayerSettingUpdateRequest`
レスポンスDTO: `PlayerSettingResponse`

レスポンス:
- `200 OK`: 更新成功
- `404 Not Found`: 対象が存在しない
- `409 Conflict`: `expectedVersion` と現在 `version` が不一致
