# 03_1.00-モデル定義

## 1. 登録リクエスト
DTO: `PlayerSettingCreateRequest`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `userId` | GUID | いいえ | 対象ユーザUUID（`dbo.user.uuid`） |
| `settingKey` | string | いいえ | 設定キー |
| `settingValueJson` | string | いいえ | 設定値JSON |
| `createdBy` | GUID | いいえ | 作成者UUID |

## 2. 更新リクエスト
DTO: `PlayerSettingUpdateRequest`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `settingValueJson` | string | いいえ | 更新する設定値JSON |
| `expectedVersion` | int | いいえ | 競合検知用バージョン |
| `updatedBy` | GUID | いいえ | 更新者UUID |

## 3. レスポンス
DTO: `PlayerSettingResponse`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `userSettingId` | GUID | いいえ | 設定レコードUUID |
| `userId` | GUID | いいえ | 対象ユーザUUID |
| `settingKey` | string | いいえ | 設定キー |
| `settingValueJson` | string | いいえ | 設定値JSON |
| `version` | int | いいえ | 現在バージョン |
| `createdAt` | DateTime | いいえ | 作成日時 |
| `updatedAt` | DateTime | いいえ | 更新日時 |
| `createdBy` | GUID | いいえ | 作成者UUID |
| `updatedBy` | GUID | いいえ | 更新者UUID |
| `isDeleted` | bool | いいえ | 論理削除フラグ |
