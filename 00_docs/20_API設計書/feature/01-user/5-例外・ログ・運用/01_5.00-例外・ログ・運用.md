# 01_5.00-例外・ログ・運用

API `user` 機能の例外応答、ログ、運用上の注意点を集約する。  
本機能のログ・メッセージはコード上にハードコーディングする。LogId は使用しない。

## 1. 共通エラーレスポンス

すべてのエンドポイントで以下が発生し得る。

| ステータス             | 発生条件                          | ボディ                                |
| ----------------- | ----------------------------- | ---------------------------------- |
| 401 Unauthorized  | `X-Api-Key` 欠落 / 不一致           | なし                                 |
| 400 Bad Request   | Body のバリデーション失敗               | `ProblemDetails` 互換のエラーオブジェクト      |
| 500 Internal Server Error | 上記以外の例外                  | `ProblemDetails` 互換のエラーオブジェクト      |

## 2. ログ一覧

### 2.1 取得系（[[01_3.01-取得系]].ユーザ取得）

| 項目     | 内容                              |
| ------ | ------------------------------- |
| レベル    | Error                           |
| テンプレート | `Failed to get user {Uuid}`     |
| 出力条件   | リポジトリ呼び出しで例外発生時                 |
| 引数     | `{Uuid}` = 対象UUID                |
| 出力例外   | キャッチした例外を `_logger.LogError(ex, ...)` で添付 |

### 2.2 登録系（[[01_3.02-登録系]].ユーザ登録）

| 項目     | 内容                              |
| ------ | ------------------------------- |
| レベル    | Error                           |
| テンプレート | `Failed to create user {Uuid}`  |
| 出力条件   | リポジトリ呼び出しで例外発生時                 |
| 引数     | `{Uuid}` = リクエストの `uuid`         |
| 出力例外   | キャッチした例外を `_logger.LogError(ex, ...)` で添付 |

### 2.3 更新系（[[01_3.03-更新系]].ユーザ更新）

| 項目     | 内容                              |
| ------ | ------------------------------- |
| レベル    | Error                           |
| テンプレート | `Failed to update user {Uuid}`  |
| 出力条件   | リポジトリ呼び出しで例外発生時                 |
| 引数     | `{Uuid}` = 更新対象UUID              |
| 出力例外   | キャッチした例外を `_logger.LogError(ex, ...)` で添付 |

## 3. エラーレスポンスメッセージ

クライアント（プラグイン）向けに返すエラーボディの代表例。
いずれも ASP.NET Core の `ProblemDetails` の `detail` フィールドへ格納する想定。

| ステータス | テンプレート                          | 出力条件                                             |
| ----- | ------------------------------- | ------------------------------------------------ |
| 400   | `Validation failed: {Errors}`   | バリデーションエラー時、`{Errors}` は失敗フィールド一覧                |
| 404   | -                               | ボディなし                                            |
| 409   | `User already exists: {Uuid}`   | [[01_3.02-登録系]].ユーザ登録 で UUID 重複時、`{Uuid}` は対象UUID |
| 500   | `Internal server error`         | 想定外例外時                                           |

## 4. 運用上の注意

- 本機能のログ・メッセージはコード上にハードコーディングされる。
  文言を変更する場合はソースと本ファイル / 各エンドポイント仕様を必ず同時に更新する。
- 401 はミドルウェアで発生するため本機能側ではログ出力しない（認証側で集約）。
- 論理削除済みレコードへの操作は常に 404 として扱う。`is_deleted` を意識した検索はリポジトリ側に閉じ込める。
- BAN 解除日時 (`banDate`) の運用は未確定項目あり。[[01_9.00-未決事項]] を参照。
