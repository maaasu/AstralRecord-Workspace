# 01_4.00-統合フロー

## 1. ユーザー登録/更新フロー

```text
Plugin (UserRepository)
   -> HTTP + X-Api-Key
ApiKeyAuthenticationHandler
   -> 認証
UserController
   -> IUserRepository
UserRepository
   -> EF Core
SQL Server (dbo.user)
```

## 2. ログイン時ユーザー確保フロー

1. Plugin が `GET /api/user/{uuid}` でユーザーを取得する。
2. BAN状態が有効でない場合、Plugin が `GET /api/user/by-ip?globalIp={globalIp}&excludeUuid={uuid}` で参加者本人以外の同一IP未削除ユーザーの有無だけを確認し、接続UUIDごとに一時保持する。
3. 404 の場合は `POST /api/user` で新規登録する。
4. 既存ユーザーの場合は `PUT /api/user/{uuid}` で `lastJoinDate` / `globalIp` / `accountId` を更新する。
5. Plugin は参加データ反映完了後、一時保持した他ユーザーが存在する場合だけ本人へ監視案内を表示する。API障害時はログインを継続し、案内を表示しない。

## 3. ログイン/ログアウト履歴フロー

1. Plugin がログイン時に `POST /api/user/history` を呼び出す（`eventType=PLAYER_LOGIN`）。
2. Plugin がログアウト時に `POST /api/user/history` を呼び出す（`eventType=PLAYER_LOGOUT`）。
3. API は `userUuid` が指定されている場合のみ `dbo.user` の存在確認を行う。
4. API は `HistoryDB.dbo.user_history` に履歴を登録して `201` を返す。

## 4. DB 関連

- ユーザー本体: `dbo.user`
- ユーザー履歴: `HistoryDB.dbo.user_history`
- 同一IP照合は既存の `dbo.user.global_ip` を検索し、新しいDB項目やテーブルを追加しない。
