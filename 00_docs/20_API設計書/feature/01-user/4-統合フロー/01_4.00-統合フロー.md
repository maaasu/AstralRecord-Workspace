# 01_4.00-統合フロー

## 1. ユーザー登録/更新フロー

```text
Plugin (UserRepository)
   -> HTTP + X-Api-Key
ApiKeyAuthenticationHandler
   -> 認証
UserController
   -> IUserRepository
UserRepository
   -> EF Core
SQL Server (dbo.user)
```

## 2. ログイン時ユーザー確保フロー

1. Plugin が `GET /api/user/{uuid}` でユーザーを取得する。
2. 404 の場合は `POST /api/user` で新規登録する。
3. 既存ユーザーの場合は `PUT /api/user/{uuid}` で `lastJoinDate` / `globalIp` / `accountId` を更新する。

## 3. ログイン/ログアウト履歴フロー

1. Plugin がログイン時に `POST /api/user/history` を呼び出す（`eventType=PLAYER_LOGIN`）。
2. Plugin がログアウト時に `POST /api/user/history` を呼び出す（`eventType=PLAYER_LOGOUT`）。
3. API は `userUuid` が指定されている場合のみ `dbo.user` の存在確認を行う。
4. API は `HistoryDB.dbo.user_history` に履歴を登録して `201` を返す。

## 4. DB 関連

- ユーザー本体: `dbo.user`
- ユーザー履歴: `HistoryDB.dbo.user_history`
