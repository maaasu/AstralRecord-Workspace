# 01_3.02-登録系

## 1. ユーザー登録

HTTPメソッド: `POST`  
パス: `/api/user`  
コントローラ: `UserController`  
アクション: `Create`

### 概要

`dbo.user` に新規ユーザーを登録する。  
同一 UUID が既に存在する場合は登録せず `409 Conflict` を返す。

### リクエスト

| 種別 | 名前 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| Header | `X-Api-Key` | string | 必須 | API キー |
| Header | `Content-Type` | string | 必須 | `application/json` |
| Body | (全体) | [[01_1.00-モデル定義]].ユーザー登録リクエスト | 必須 | 登録内容 |

### レスポンス

| ステータス | 内容 | ボディ |
|---|---|---|
| 201 Created | 登録成功 | [[01_1.00-モデル定義]].ユーザーレスポンス |
| 401 Unauthorized | API キー不正 | なし |
| 409 Conflict | 同一 UUID が既に存在 | なし |
| 500 Internal Server Error | 予期しない例外 | 標準エラーレスポンス |

### 処理フロー

1. API キーを認証する。
2. リクエストの UUID で既存ユーザーを確認する。
3. 既存ユーザーがある場合は `409` を返す。
4. `dbo.user` に新規レコードを登録する。
5. 登録結果を返却する。
