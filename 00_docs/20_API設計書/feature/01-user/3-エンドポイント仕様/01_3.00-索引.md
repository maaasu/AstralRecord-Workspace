## エンドポイント一覧（要約）

| HTTPメソッド | パス | 概要 | 詳細仕様 |
|---|---|---|---|
| GET | `/api/user/{uuid}` | ユーザー取得 | [[01_3.01-取得系]] |
| GET | `/api/user/mcid/{mcid}` | Minecraft ID 指定ユーザー取得 | [[01_3.01-取得系]] |
| GET | `/api/user/mcids?prefix={prefix}` | 参加履歴のある Minecraft ID 一覧取得 | [[01_3.01-取得系]] |
| GET | `/api/user/by-ip?globalIp={globalIp}&excludeUuid={uuid}` | 同一グローバルIPの別登録済みユーザー有無取得 | [[01_3.01-取得系]] |
| POST | `/api/user` | ユーザー登録 | [[01_3.02-登録系]] |
| PUT | `/api/user/{uuid}` | ユーザー更新 | [[01_3.03-更新系]] |
| POST | `/api/user/history` | ユーザー履歴登録 | [[01_3.04-履歴登録系]] |
