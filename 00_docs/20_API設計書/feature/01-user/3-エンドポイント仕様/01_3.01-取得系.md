# 01_3.01-取得系

## 1. 取得系エンドポイント仕様

### ユーザ取得

HTTPメソッド: `GET`
パス: `/api/user/{uuid}`
コントローラ: `UserController`
アクション物理名: `GetUser`

責務:

UUID をキーに `dbo.user` からユーザを取得し、[[01_1.00-モデル定義]].ユーザレスポンス を返す。
論理削除済みは取得対象外とする。

リクエスト:

| 種別 | 名前 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| Header | `X-Api-Key` | string | ✓ | API キー |
| Path | `uuid` | GUID | ✓ | 対象プレイヤーUUID |

レスポンス:

| ステータス | 内容 | ボディ |
|---|---|---|
| 200 OK | 取得成功 | [[01_1.00-モデル定義]].ユーザレスポンス |
| 401 Unauthorized | API キー未指定または無効 | なし（[[01_5.00-例外・ログ・運用]] 共通エラー参照） |
| 404 Not Found | 未登録または論理削除済み | なし |

処理内容:

1. 認証パイプラインで `X-Api-Key` を検証する

    | 項目 | 内容 |
    |---|---|
    | 検証主体 | `ApiKeyAuthenticationHandler` |
    | 失敗時 | 401 を返し、本処理は実行しない |

2. リポジトリでユーザを取得する

    | 項目 | 内容 |
    |---|---|
    | 検索キー | `uuid` |
    | 取得対象 | `dbo.user` のうち `is_deleted = 0` |
    | 取得成功 | [[01_1.00-モデル定義]].ユーザレスポンス へマッピングして 200 を返す |
    | 取得失敗（該当なし / 論理削除済み） | 404 を返す |

3. 例外発生時は以下ログを記録して 500 を返す

    | 項目 | 内容 |
    |---|---|
    | レベル | Error |
    | テンプレート | `Failed to get user {Uuid}` |
    | 出力条件 | リポジトリ呼び出しで例外発生時 |
    | 引数 | `{Uuid}` = 対象UUID |
    | 出力例外 | キャッチした例外を `_logger.LogError(ex, ...)` で添付 |

入力:

- `uuid`: 対象プレイヤーUUID

出力:

- [[01_1.00-モデル定義]].ユーザレスポンス（取得成功時）

例外時挙動:

- 認証失敗時は 401 のみ返す
- 該当レコードなし / 論理削除時は 404 のみ返す
- それ以外の例外は Error ログを記録し 500 を返す

### Minecraft ID 指定ユーザ取得

HTTPメソッド: `GET`
パス: `/api/user/mcid/{mcid}`

`dbo.user.mcid` を完全一致で検索し、未削除ユーザをユーザレスポンスとして返す。管理コマンドがオフラインプレイヤーを名前とアカウントスロットで指定するときの UUID 解決に使用する。

| ステータス | 内容 | ボディ |
|---|---|---|
| 200 OK | 取得成功 | [[01_1.00-モデル定義]].ユーザレスポンス |
| 401 Unauthorized | API キー未指定または無効 | なし |
| 404 Not Found | 未登録または論理削除済み | なし |

### Minecraft ID 一覧取得

HTTPメソッド: `GET`
パス: `/api/user/mcids?prefix={prefix}`

`dbo.user` のうち論理削除されていない、参加履歴のあるユーザーの `mcid` を前方一致で検索し、昇順で返す。`prefix` を省略または空文字にした場合は全件を返す。BAN対象のユーザーも参加履歴があれば候補に含める。

リクエスト:

| 種別 | 名前 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| Header | `X-Api-Key` | string | ✓ | API キー |
| Query | `prefix` | string |  | `mcid` の前方一致検索文字列 |

レスポンス:

| ステータス | 内容 | ボディ |
|---|---|---|
| 200 OK | 取得成功 | Minecraft ID の JSON 配列 |
| 401 Unauthorized | API キー未指定または無効 | なし |

処理内容:

1. 認証パイプラインで `X-Api-Key` を検証する。
2. `is_deleted = 0` のユーザーだけを対象に `prefix` を前方一致させる。
3. `mcid` 昇順で文字列配列を返す。

### 同一グローバルIPの別ユーザー有無取得

HTTPメソッド: `GET`
パス: `/api/user/by-ip?globalIp={globalIp}&excludeUuid={uuid}`
コントローラ: `UserController`
アクション物理名: `HasOtherByGlobalIp`

`dbo.user` のうち論理削除されていない、`global_ip` が完全一致し、`uuid` が参加者UUIDと異なるユーザーの有無だけを返す。Plugin の接続前処理が、参加者本人以外の同一IP登録ユーザーを検出するために使用する。DBの列・テーブルは追加しない。

リクエスト:

| 種別 | 名前 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| Header | `X-Api-Key` | string | ✓ | API キー |
| Query | `globalIp` | string | ✓ | 完全一致検索するグローバルIP。空文字は不正 |
| Query | `excludeUuid` | GUID | ✓ | 検索結果から除外する参加者UUID |

レスポンス:

| ステータス | 内容 | ボディ |
|---|---|---|
| 200 OK | 確認成功 | boolean（別ユーザーありなら `true`） |
| 400 Bad Request | `globalIp` または `excludeUuid` が未指定 | なし |
| 401 Unauthorized | API キー未指定または無効 | なし |

処理内容:

1. 認証パイプラインで `X-Api-Key` を検証する。
2. `globalIp` を trim し、空の場合は 400 を返す。
3. `excludeUuid` が未指定の場合は 400 を返す。
4. `is_deleted = 0`、`uuid <> excludeUuid`、`global_ip = globalIp` のユーザーの有無を検索する。
5. 別ユーザーが存在する場合は `true`、該当しない場合は `false` を返す。
