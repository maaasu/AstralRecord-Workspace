# 01_3.04-履歴登録系

## 1. ユーザー履歴登録

HTTPメソッド: `POST`  
パス: `/api/user/history`  
コントローラ: `UserController`  
アクション: `CreateHistory`

### 概要

プレイヤーのログイン/ログアウトなどのイベント履歴を `HistoryDB.dbo.user_history` に登録する。  
`userUuid` が指定された場合は対象ユーザーの存在確認を行い、存在しない場合は `404 Not Found` を返す。

### リクエスト

| 種別 | 名前 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| Header | `X-Api-Key` | string | 必須 | API キー |
| Header | `Content-Type` | string | 必須 | `application/json` |
| Body | (全体) | [[01_1.00-モデル定義]].ユーザー履歴登録リクエスト | 必須 | 履歴登録内容 |

### レスポンス

| ステータス | 内容 | ボディ |
|---|---|---|
| 201 Created | 登録成功 | [[01_1.00-モデル定義]].ユーザー履歴レスポンス |
| 400 Bad Request | `eventTime` / `eventType` / `message` 不正 | なし |
| 401 Unauthorized | API キー不正 | なし |
| 404 Not Found | `userUuid` 指定時に対象ユーザーが存在しない | なし |
| 500 Internal Server Error | 予期しない例外 | 標準エラーレスポンス |

### 処理フロー

1. API キーを認証する。
2. 必須項目（`eventTime`, `eventType`, `message`）を検証する。
3. `userUuid` 指定時は `dbo.user` で存在確認する。
4. `HistoryDB.dbo.user_history` にレコードを登録する。
5. 登録結果を返却する。

### 代表値（Plugin 連携）

| 項目 | 代表値 |
|---|---|
| `eventType` | `PLAYER_LOGIN` / `PLAYER_LOGOUT` |
| `source` | `PLUGIN` |
| `message` | `Player login: <name>` / `Player logout: <name>` |
