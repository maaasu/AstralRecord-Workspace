# 01_1.00-モデル定義

## 1. ドメインモデル

API `user` 機能の主要モデルは以下 3 種類。

- ユーザ登録リクエスト
- ユーザ更新リクエスト
- ユーザレスポンス

DB Entity `User` は本ファイルでは扱わない。`40_database/AstralRecord/dbo.user/user.md` を参照する。
プラグイン側のドメインモデルは [[01_1.00-モデル定義]].ユーザモデル（プラグイン設計書）を参照する。

## 2. ユーザ登録リクエスト

物理名: `UserCreateRequest`

`POST /api/user` の Body として受け取る。

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `uuid` | GUID | ✗ | プレイヤーUUID |
| `mcid` | string | ✗ | Minecraft ID |
| `joinDate` | DateTime (ISO 8601) | ✗ | 初回参加日時 |
| `lastJoinDate` | DateTime (ISO 8601) | ✗ | 最終参加日時 |
| `globalIp` | string | ✗ | 接続元グローバルIP |
| `createdBy` | GUID | ✗ | 作成者UUID（システム更新は nil UUID） |

## 3. ユーザ更新リクエスト

物理名: `UserUpdateRequest`

`PUT /api/user/{uuid}` の Body として受け取る。  
`null` フィールドは「更新しない」を意味する。

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `mcid` | string | ✓ | Minecraft ID |
| `lastJoinDate` | DateTime (ISO 8601) | ✓ | 最終参加日時 |
| `globalIp` | string | ✓ | 接続元グローバルIP |
| `accountId` | GUID | ✓ | 選択中アカウントUUID |
| `banIndefinite` | bool | ✓ | 無期限BANフラグ |
| `banDate` | DateTime (ISO 8601) | ✓ | BAN解除日時 |
| `kickIp` | bool | ✓ | IPキックフラグ |
| `permission` | int | ✓ | 権限レベル |
| `updatedBy` | GUID | ✗ | 更新者UUID（必須） |

## 4. ユーザレスポンス

物理名: `UserResponse`

`GET` / `POST` / `PUT` のレスポンス Body として返す。

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `uuid` | GUID | ✗ | プレイヤーUUID |
| `mcid` | string | ✗ | Minecraft ID |
| `joinDate` | DateTime (ISO 8601) | ✗ | 初回参加日時 |
| `lastJoinDate` | DateTime (ISO 8601) | ✗ | 最終参加日時 |
| `globalIp` | string | ✗ | 最終ログインIP |
| `accountId` | GUID | ✓ | 選択中アカウントUUID |
| `banIndefinite` | bool | ✗ | 無期限BANフラグ |
| `banDate` | DateTime (ISO 8601) | ✓ | BAN解除日時 |
| `kickIp` | bool | ✗ | IPキックフラグ |
| `permission` | int | ✗ | 権限レベル |
| `createdAt` | DateTime (ISO 8601) | ✗ | レコード作成日時 |
| `updatedAt` | DateTime (ISO 8601) | ✗ | レコード更新日時 |
| `createdBy` | GUID | ✗ | 作成者UUID |
| `updatedBy` | GUID | ✗ | 更新者UUID |
| `isDeleted` | bool | ✗ | 論理削除フラグ |

## 5. 関連 feature とのモデル関係

- プラグイン: ユーザレスポンスはプラグイン側 [[01_1.00-モデル定義]].ユーザモデル へマッピングされる。
- account API: ユーザ更新リクエストの `accountId` は account feature が発行した UUID を渡す。
  account 自体の作成は本 API の責務外。
