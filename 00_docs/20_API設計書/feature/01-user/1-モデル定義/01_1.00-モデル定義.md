# 01_1.00-モデル定義

## 1. 概要

API `user` では以下のモデルを扱う。

- ユーザー登録リクエスト
- ユーザー更新リクエスト
- ユーザーレスポンス
- ユーザー履歴登録リクエスト
- ユーザー履歴レスポンス

ユーザー本体の永続化定義は `00_docs/40_Database設計書/table-definitions/AstralRecord/dbo.user.md` を参照する。  
履歴の永続化定義は `00_docs/40_Database設計書/table-definitions/HistoryDB/dbo.user_history.md` を参照する。

## 2. ユーザー登録リクエスト

対象: `POST /api/user`  
型: `UserCreateRequest`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `uuid` | GUID | 不可 | プレイヤー UUID |
| `mcid` | string | 不可 | Minecraft ID |
| `joinDate` | DateTime (ISO 8601) | 不可 | 初回参加日時 |
| `lastJoinDate` | DateTime (ISO 8601) | 不可 | 最終参加日時 |
| `globalIp` | string | 不可 | グローバルIP |
| `createdBy` | GUID | 不可 | 作成者 UUID |

## 3. ユーザー更新リクエスト

対象: `PUT /api/user/{uuid}`  
型: `UserUpdateRequest`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `mcid` | string | 可 | Minecraft ID |
| `lastJoinDate` | DateTime (ISO 8601) | 可 | 最終参加日時 |
| `globalIp` | string | 可 | グローバルIP |
| `accountId` | GUID | 可 | 選択アカウント UUID |
| `banIndefinite` | bool | 可 | 無期限 BAN フラグ |
| `banDate` | DateTime (ISO 8601) | 可 | BAN 解除日時 |
| `kickIp` | bool | 可 | IP キックフラグ |
| `permission` | int | 可 | 権限レベル（0:プレイヤー / 99:管理者）。API はこの 2 値以外を受理しない。 |
| `updatedBy` | GUID | 不可 | 更新者 UUID |

## 4. ユーザーレスポンス

対象: `GET /api/user/{uuid}`, `POST /api/user`, `PUT /api/user/{uuid}`  
型: `UserResponse`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `uuid` | GUID | 不可 | プレイヤー UUID |
| `mcid` | string | 不可 | Minecraft ID |
| `joinDate` | DateTime (ISO 8601) | 不可 | 初回参加日時 |
| `lastJoinDate` | DateTime (ISO 8601) | 不可 | 最終参加日時 |
| `globalIp` | string | 不可 | グローバルIP |
| `accountId` | GUID | 可 | 選択アカウント UUID |
| `banIndefinite` | bool | 不可 | 無期限 BAN フラグ |
| `banDate` | DateTime (ISO 8601) | 可 | BAN 解除日時 |
| `kickIp` | bool | 不可 | IP キックフラグ |
| `permission` | int | 不可 | 権限レベル（0:プレイヤー / 99:管理者） |
| `createdAt` | DateTime (ISO 8601) | 不可 | 作成日時 |
| `updatedAt` | DateTime (ISO 8601) | 不可 | 更新日時 |
| `createdBy` | GUID | 不可 | 作成者 UUID |
| `updatedBy` | GUID | 不可 | 更新者 UUID |
| `isDeleted` | bool | 不可 | 論理削除フラグ |

## 5. ユーザー履歴登録リクエスト

対象: `POST /api/user/history`  
型: `UserHistoryCreateRequest`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `userUuid` | GUID | 可 | 対象ユーザー UUID |
| `eventTime` | DateTime (ISO 8601) | 不可 | イベント発生日時 |
| `eventType` | string | 不可 | イベント種別。例: `PLAYER_LOGIN`, `PLAYER_LOGOUT`, `PARTY_CREATED`, `PARTY_JOINED`, `PARTY_LEFT_LOGOUT` |
| `source` | string | 不可 | 発生元（例: `PLUGIN`） |
| `message` | string | 不可 | イベントメッセージ |
| `payloadJson` | string | 可 | 追加情報(JSON文字列) |

## 6. ユーザー履歴レスポンス

対象: `POST /api/user/history`  
型: `UserHistoryResponse`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `historyId` | long | 不可 | 履歴ID |
| `userUuid` | GUID | 可 | 対象ユーザー UUID |
| `eventTime` | DateTime (ISO 8601) | 不可 | イベント発生日時 |
| `eventType` | string | 不可 | イベント種別 |
| `source` | string | 不可 | 発生元 |
| `message` | string | 不可 | イベントメッセージ |
| `payloadJson` | string | 可 | 追加情報(JSON文字列) |
| `createdAt` | DateTime (ISO 8601) | 不可 | 登録日時 |
