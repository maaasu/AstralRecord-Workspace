# 20_3.00-索引

`account-skilltree` API のエンドポイント仕様をまとめる。

## 一覧

| HTTPメソッド | パス | 概要 |
|:--|:--|:--|
| GET | `/api/account-skilltree/{accountId}` | アカウント単位のスキルツリー進行取得 |
| PUT | `/api/account-skilltree/{accountId}` | アカウント単位のスキルツリー進行保存 |

## レスポンスモデル

- `accountSkillTreeStateId`: 保存済み行 ID。未保存状態は `null`
- `accountId`: 対象アカウント UUID
- `skillPoints`: 現在の未使用スキルポイント
- `unlockedNodeIds`: 解放済みノード ID 一覧
- `isSaved`: DB 保存済みなら `true`
- `version`: 保存済み行の更新バージョン。未保存状態は `0`

## 保存リクエスト

- `skillPoints`: 保存する未使用スキルポイント
- `unlockedNodeIds`: 保存する解放済みノード ID 一覧
- `updatedBy`: 監査用 UUID

## 補足

- スキルツリーノード定義は filebase `40_filebase/35.features.skilltree/*.yml` を正本とする。
- `skilltree_structure.yml` はサーバローカルの plugin ファイルであり、この API では扱わない。
- plugin は `GET` 結果をアカウント単位でメモリキャッシュし、ノード解放・解除クリックごとに同期通信しない。
- plugin は進行状態の変更を dirty として保持し、`PUT` には現在の `skillPoints` と `unlockedNodeIds` をまとめて非同期保存する。
