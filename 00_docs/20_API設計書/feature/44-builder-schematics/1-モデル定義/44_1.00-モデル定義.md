# ビルダースキーマティック API モデル定義

### チケット発行リクエスト

物理名: `BuilderSchematicTicketRequest`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `userUuid` | GUID | ✗ | Dev サーバーが取得した発行先ユーザー UUID |

### チケット発行レスポンス

物理名: `BuilderSchematicTicketResponse`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `token` | string | ✗ | 32 バイトの乱数をパディングなしの Base64URL にした、5 分間有効な単回使用トークン |

### アップロードリクエスト

物理名: `BuilderSchematicUploadRequest`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `userUuid` | GUID | ✗ | Web セッションから取得したユーザー UUID |
| `token` | string | ✗ | 同じユーザーに発行されたトークン |
| `file` | file | ✗ | 1 MiB 以下の gzip 圧縮 `.schem` ファイル |

### アップロード受付レスポンス

物理名: `BuilderSchematicUploadReceipt`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `id` | GUID | ✗ | API が生成した受付 ID |
| `status` | string | ✗ | `pending` |

### スキーマティックレスポンス

物理名: `BuilderSchematicResponse`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `id` | GUID | ✗ | 受付 ID |
| `name` | string | ✗ | アップロード時の表示名 |
| `status` | string | ✗ | `pending`（保留）、`registered`（承認済み）、`rejected`（拒否） |
| `error` | string | ○ | 拒否理由コード。保留・承認済みは `null` |

### 判定リクエスト

物理名: `BuilderSchematicDecisionRequest`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `accepted` | boolean | ✗ | Dev サーバーでの検証結果 |
| `error` | string | ○ | 拒否時は `invalid_schematic`、`unsupported_format`、`too_large`、`unsafe_content`、`incompatible_schematic` のいずれか。未指定と未知の値は `invalid_schematic` に変換する |
