# ビルダースキーマティック API エンドポイント仕様

全操作のコントローラは `BuilderSchematicsController`。全操作で `X-Api-Key` を要求し、Dev 専用操作は `X-Builder-Dev-Key` も要求する。キーが無効または欠落している場合は 401、機能が無効の場合は 503 を返す。

### アップロードチケット発行

HTTPメソッド: `POST`<br>
パス: `/api/builder-schematics/tickets`<br>
コントローラ: `BuilderSchematicsController`<br>
アクション物理名: `IssueTicket`

Dev 専用。JSON の [[44_1.00-モデル定義]].チケット発行リクエストを受け付け、201 と [[44_1.00-モデル定義]].チケット発行レスポンスを返す。チケットはユーザーにつき 1 件とし、新規発行で前のチケットを失効させる。有効なチケットが全体で 256 件あり、発行先ユーザーに有効なチケットがない場合は 429。

### スキーマティック受付

HTTPメソッド: `POST`<br>
パス: `/api/builder-schematics/uploads`<br>
コントローラ: `BuilderSchematicsController`<br>
アクション物理名: `Upload`

`multipart/form-data` の [[44_1.00-モデル定義]].アップロードリクエストを受け付ける。ファイル名はUTF-16 で最大 120 コードユニットの安全な単一の表示名に限定し、大文字小文字を区別せず `.schem` を要求する。gzip の先頭バイトを確認する。チケットの期限と所有者を検証し、保留レコード・ファイル保存とチケット消費を同じトランザクションで確定する。

| ステータス | 内容 | ボディ |
|---|---|---|
| 202 | 保留として受付 | [[44_1.00-モデル定義]].アップロード受付レスポンス |
| 400 | フォーム、名前、または gzip ヘッダーが不正 | |
| 403 | チケットが無効、期限切れ、使用済み、または所有者不一致 | |
| 413 | サイズ上限超過 | |
| 429 | 受付件数上限 | |

### アップロード状態取得

HTTPメソッド: `GET`<br>
パス: `/api/builder-schematics/uploads/{id}?userUuid={userUuid}`<br>
コントローラ: `BuilderSchematicsController`<br>
アクション物理名: `GetUpload`

受付 ID と Web セッションのユーザー UUID が一致する場合、200 と [[44_1.00-モデル定義]].スキーマティックレスポンスを返す。該当受付がない場合は 404。

### 本人アップロード一覧取得

HTTPメソッド: `GET`<br>
パス: `/api/builder-schematics/uploads?userUuid={userUuid}`<br>
コントローラ: `BuilderSchematicsController`<br>
アクション物理名: `GetUploads`

Web セッションのユーザー UUID に一致する保留・承認済みレコードを受付日時の降順で最大 32 件取得する。200 と [[44_1.00-モデル定義]].スキーマティックレスポンスの配列を返す。

### 本人アップロード削除

HTTPメソッド: `DELETE`<br>
パス: `/api/builder-schematics/uploads/{id}?userUuid={userUuid}`<br>
コントローラ: `BuilderSchematicsController`<br>
アクション物理名: `DeleteUpload`

受付 ID と Web セッションのユーザー UUID が一致する受付とファイル本体を削除し、204 を返す。該当受付がない場合は 404。削除済みの受付 ID へ Dev 検証結果を送ると 404 となる。

### 保留アップロード一覧取得

HTTPメソッド: `GET`<br>
パス: `/api/builder-schematics/pending`<br>
コントローラ: `BuilderSchematicsController`<br>
アクション物理名: `GetPending`

Dev 専用。保留レコードのみを受付日時の昇順で 200 と [[44_1.00-モデル定義]].スキーマティックレスポンスの配列として返す。

### 承認済みスキーマティック一覧取得

HTTPメソッド: `GET`<br>
パス: `/api/builder-schematics/registered?userUuid={userUuid}`<br>
コントローラ: `BuilderSchematicsController`<br>
アクション物理名: `GetRegistered`

Dev 専用。指定ユーザーの承認済みレコードのみを受付日時の昇順で 200 と [[44_1.00-モデル定義]].スキーマティックレスポンスの配列として返す。

### スキーマティックファイル取得

HTTPメソッド: `GET`<br>
パス: `/api/builder-schematics/files/{id}`<br>
コントローラ: `BuilderSchematicsController`<br>
アクション物理名: `GetFile`

Dev 専用。クエリの `userUuid` を省略した場合は保留レコードを返す。`userUuid` を指定した場合はそのユーザーの承認済みレコードのみを返す。成功時は 200 と `application/octet-stream` のファイル本体。該当受付がない場合は 404。

### 検証結果登録

HTTPメソッド: `POST`<br>
パス: `/api/builder-schematics/decisions/{id}`<br>
コントローラ: `BuilderSchematicsController`<br>
アクション物理名: `Decide`

Dev 専用。Dev サーバーが形式・安全性・WorldEdit 互換性を検証し、JSON の [[44_1.00-モデル定義]].判定リクエストで結果を送る。保留を承認済みまたは拒否へ更新し、204 を返す。該当受付がなければ 404。同じ判定の再送は 204、反対の判定は 409。
