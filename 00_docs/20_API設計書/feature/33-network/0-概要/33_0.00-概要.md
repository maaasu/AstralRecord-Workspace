# 33_0.00-概要

## 目的

LobbyとVelocity Proxyへ、ユーザー参加可否および複数Minecraftサーバーの実行時共有状態を提供する。

## 永続化境界

admissionは`01-user`の永続ユーザーと、Proxyが同期する最高権限UUIDを入力とする。プレイヤー所在、サーバー状態、最高権限UUID、チャットは単一APIプロセスのメモリだけに保持し、DBへ永続化しない。所在・サーバー状態・最高権限UUIDは最終heartbeatから30秒で失効し、チャットは新しい2,000件を保持する。

API再起動時は実行時状態が空になり、各pluginのheartbeat、Proxyの最高権限UUID再送、チャットpollで再構築する。
