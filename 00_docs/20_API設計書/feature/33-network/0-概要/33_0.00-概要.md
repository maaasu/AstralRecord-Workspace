# 33_0.00-概要

## 目的

LobbyとVelocity Proxyへ、ユーザー参加可否および複数Minecraftサーバーの実行時共有状態を提供する。

## 永続化境界

admissionは`01-user`のユーザーとManagementDBのネットワーク設定・ユーザーBANを入力とする。設定、最高権限UUID、チャンネル別debug/whitelist、BANと更新監査はManagementDBへ永続化する。Proxy YAMLのAPI接続設定・秘密値は移行しない。初回bootstrapだけが旧YAMLを取り込み、以後の管理者更新を上書きしない。

プレイヤー所在、サーバー状態、チャットは単一APIプロセスのメモリだけに保持する。所在とサーバー状態は最終heartbeatから30秒で失効し、チャットは新しい2,000件を保持する。API再起動時はこれらの実行時状態だけが空になり、heartbeatとpollで再構築する。永続設定とBANはAPI再起動後も維持する。

Webの管理操作は共通API認証に加えて毎回ManagementDBの`web_admin`を検証する。ゲーム内`/ban`の更新はRPG専用ModerationKeyと実行者権限を検証する。WebAdminとゲーム内permission=99は別の権限である。
