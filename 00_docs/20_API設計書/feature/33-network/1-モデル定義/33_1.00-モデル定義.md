# 33_1.00-モデル定義

## Admissionレスポンス

物理名: `NetworkAdmissionResponse`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `uuid` | GUID | ✗ | プレイヤーUUID |
| `mcid` | string | ✗ | 未登録時は空文字 |
| `registered` | bool | ✗ | 永続ユーザーの存在 |
| `admitted` | bool | ✗ | Lobby参加可否 |
| `denyReason` | string | ✓ | BAN時は`banned` |
| `permission` | int | ✗ | 未登録時は0。Proxy最高権限UUIDは永続値にかかわらず99 |
| `banIndefinite` | bool | ✗ | 無期限BAN |
| `banDate` | datetime | ✓ | 有期限BAN終了日時 |
| `accountId` | GUID | ✓ | 選択アカウント |
| `serverTimeUtc` | datetime | ✗ | API応答時刻 |

## プレイヤー所在

物理名: `NetworkPlayerHeartbeatRequest` / `NetworkPlayerPresenceResponse`

UUID、MCID、serverId、channel、表示アカウント、レベル、クラス名、AFK状態を持つ。レスポンスは`lastSeenUtc`を追加する。

## サーバー状態

物理名: `NetworkServerHeartbeatRequest` / `NetworkServerPresenceResponse`

serverId、表示名、state、onlineCount、一般プレイヤーの基本上限`capacity`、寄付者追加枠`donorExtraPlayers`、管理者追加枠`adminExtraPlayers`を持つ。レスポンスは`lastSeenUtc`を追加する。管理者が利用できる追加枠は寄付者追加枠と管理者追加枠の合計とする。

## チャット

物理名: `NetworkChatPublishRequest` / `NetworkChatMessageResponse` / `NetworkChatBatchResponse`

messageId、source（`minecraft`または`discord`）、sourceServerId、authorName、message、kind（`chat`または`lifecycle`、省略時`chat`）を持つ。メッセージレスポンスはsequenceとcreatedAtUtcを追加する。差分取得はAPIプロセス起動ごとに変わるgenerationId、全source共通のlatestSequence、messagesを持つbatchを返す。クライアントは初回接続時にlatestSequenceをカーソルとして過去の中継履歴を再送せず、generationId変更時はcursorを0へ戻す。latestSequenceを返さない旧APIは中継開始条件を満たさないため、LobbyはDiscord送信を停止してAPI更新を待つ。

## サーバー最高権限

物理名: `NetworkAuthorityUpdateRequest`

`uuids`にProxy設定を正本とする最高権限UUID一覧を持つ。PUTごとに全置換し、空GUIDを拒否する。重複UUIDは一件へ正規化する。
