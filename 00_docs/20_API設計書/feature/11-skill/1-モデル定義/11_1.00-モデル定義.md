# 11_1.00-モデル定義

## 1. スキル一覧レスポンス要素

物理名: `SkillListItem`

| フィールド | 型 | 説明 |
|---|---|---|
| `id` | string | スキル ID |
| `name` | string | スキル名 |
| `implementationId` | string | プラグイン実装クラスの紐付けキー |

## 2. スキル詳細レスポンス

物理名: `SkillResponse`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `schemaVersion` | int | ✗ | YAML スキーマバージョン |
| `id` | string | ✗ | スキル ID |
| `type` | string | ✗ | `SKILL` |
| `implementationId` | string | ✗ | プラグイン実装クラスの紐付けキー |
| `name` | string | ✗ | スキル名 |
| `description` | string | ✓ | 説明文 |
| `icon` | string | ✓ | 表示用アイコン |
| `lore` | string[] | ✗ | 説明文（色コード使用可） |
| `cooldownTicks` | long | ✗ | クールダウン時間（tick） |
| `manaCost` | double | ✗ | MP 消費量 |
| `castTimeTicks` | long | ✗ | 詠唱時間（tick） |
| `requiredLevel` | int | ✗ | 習得必要レベル |
| `onCast.sound` | string | ✓ | 発動時サウンド |
| `params` | object | ✗ | プラグイン実装が読み取るカスタムパラメータ（自由形式 Map） |
| `tags` | string[] | ✗ | 検索・分類用タグ |
