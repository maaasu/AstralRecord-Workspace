# 11_1.00-モデル定義

## 1. スキル一覧レスポンス

型名: `SkillListItem`

| フィールド | 型 | 説明 |
|---|---|---|
| `id` | string | スキル ID |
| `name` | string | スキル名 |
| `implementationId` | string | プラグイン実装クラスの紐付けキー |
| `icon` | string | 一覧表示用アイコン |
| `tags` | string[] | 分類タグ |

## 2. スキル詳細レスポンス

型名: `SkillResponse`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `schemaVersion` | int | ✗ | YAML スキーマバージョン |
| `id` | string | ✗ | スキル ID |
| `type` | string | ✗ | `SKILL` |
| `implementationId` | string | ✗ | プラグイン実装クラスの紐付けキー |
| `name` | string | ✗ | スキル名 |
| `description` | string | ✓ | 説明文 |
| `icon` | string | ✓ | 表示用アイコン |
| `lore` | string[] | ✗ | 説明文（複数行利用可） |
| `cooldownTicks` | long | ✗ | クールダウン時間（tick） |
| `manaCost` | double | ✗ | MP 消費量 |
| `castTimeTicks` | long | ✗ | 詠唱時間（tick） |
| `requiredLevel` | int | ✗ | 要求レベル |
| `onCast` | object | ✓ | 共通発動演出。未指定時は `null` |
| `onCast.sound` | string | ✓ | 発動サウンド |
| `params` | object | ✗ | プラグイン実装が読み取るカスタムパラメータ（自由形式 Map） |
| `tags` | string[] | ✗ | 分類・検索用タグ |

## 3. 補足

- `implementationId` は API で文字列として返すだけであり、対応する Plugin 実装クラスの存在確認は行わない。
- `params` は API で透過的に返す自由形式オブジェクトであり、項目名・型・必須条件は `implementationId` ごとの実装契約に委ねる。
- `description` / `icon` / `onCast` は YAML 上で省略可能なため `nullable` を許容する。
