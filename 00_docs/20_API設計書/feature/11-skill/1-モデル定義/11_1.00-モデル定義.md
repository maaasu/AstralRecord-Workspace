# 11_1.00 モデル定義

## 1. SkillResponse

`GET /api/skill/{skillId}` のレスポンス。

| フィールド | 型 | 説明 |
|---|---|---|
| `id`, `implementationId`, `name` | string | スキルID、Plugin実装ID、表示名 |
| `description`, `icon`, `lore`, `tags` | 各表示型 | 表示・分類情報 |
| `cooldownTicks`, `castTimeTicks`, `requiredLevel` | number | Lv.1共通発動値 |
| `resourceType`, `resourceCost`, `manaCost` | 各リソース型 | 消費リソース。`manaCost` は互換入力 |
| `cooldownId` | string? | cooldown共有ID。未指定時はskill ID |
| `maxLevel` | int | 個体の最大レベル。1以上 |
| `levels[]` | object[] | 前レベルからの差分 |
| `levels[].level` | int | 適用レベル |
| `levels[].cooldownTicksDelta` | long | cooldown差分 |
| `levels[].resourceCostDelta` | double | 消費量差分 |
| `levels[].castTimeTicksDelta` | long | 詠唱時間差分 |
| `levels[].paramDeltas` | map<string,double> | params数値差分 |
| `levels[].statusModifiers` | object[] | skill-local status加算 |
| `sigilSlotsByLevel[]` | object[] | levelと装着可能数 |
| `allowedSigilIds` | string[] | 装着可能シジルID |
| `learnRequiredItems[]` | object[] | 初回習得時に消費する `itemId` と `amount`。未指定なら無条件 |
| `levelUpRequiredItems[]` | object[] | レベルアップ時に消費する `itemId` と `amount`。未指定なら無条件 |
| `passive.bindRequired` | bool | passive枠を発動条件にするか |
| `params` | object | executor固有パラメータ |

`maxLevel` と `levels` は習得済み個体へ適用する。スキルジェムは生成しない。

## 2. AccountLearnedSkillResponse

| フィールド | 型 | 説明 |
|---|---|---|
| `learnedSkillId` | Guid | 個体UUID |
| `accountId` | Guid | 所有アカウント |
| `skillId` | string | スキルマスタID |
| `level` | int | 現在レベル |
| `sigils[]` | object[] | 装着済みシジル |
| `sigils[].learnedSkillSigilId` | Guid | 装着行UUID |
| `sigils[].sigilId` | string | シジルitem ID |
| `sigils[].equipGroupId` | string | 同一個体で重複不可のgroup |
| `sigils[].slotIndex` | int | 装着位置 |
| `version`, `createdAt`, `updatedAt` | 監査型 | 競合・監査情報 |

同一`skillId`の個体を複数返せる。

## 3. 習得・合成リクエスト

| モデル | 主なフィールド |
|---|---|
| `AccountLearnedSkillLearnRequest` | `skillId`, `updatedBy` |
| `AccountLearnedSkillLevelUpRequest` | `updatedBy` |
| `AccountLearnedSkillAttachSigilRequest` | `sigilId`, `sigilInventoryEntryId`, `orbInventoryEntryId`, `updatedBy` |
| `AccountLearnedSkillDetachSigilRequest` | `orbInventoryEntryId`, `updatedBy` |

`orbInventoryEntryId` と `sigilInventoryEntryId` は、Pluginが操作確定時に通常アイテム共通消費順で解決したentry UUIDを受け取る。APIは受信したUUIDの所有状態・item種別をtransaction内で検証し、受信IDを消費対象として扱う。

mutation結果は成功時の個体、失敗時の列挙理由を返す。代表理由は個体・skill・sigil不在、不正素材、最大Lv、空き枠なし、非許可sigil、group重複。

## 4. SkillBindPresetResponse

1プリセットは`activeSkillSlots` 6要素、`leftClickSkillId` 1値、`passiveSkillSlots` 9要素を持つ。通常の値は`learnedSkillId`文字列で、`activeSkillSlots`と`leftClickSkillId`は`__weapon_normal_attack__`も許可する。`passiveSkillSlots`は通常攻撃予約値を許可しない。プリセット番号は1..6。`isSelected`は現在選択中のプリセットだけtrueになる。
