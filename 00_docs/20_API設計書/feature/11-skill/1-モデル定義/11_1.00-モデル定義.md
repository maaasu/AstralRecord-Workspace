# 11_1.00 モデル定義

## SkillResponse

`GET /api/skill/{skillId}` のレスポンス。

| フィールド | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `schemaVersion` | int | 必須 | filebase schema version |
| `id` | string | 必須 | スキル ID |
| `type` | string | 必須 | `SKILL` |
| `implementationId` | string | 必須 | plugin 側実装 ID |
| `name` | string | 必須 | 表示名 |
| `description` | string? | 任意 | 説明 |
| `icon` | string? | 任意 | Material 名 |
| `lore` | string[] | 必須 | lore 一覧 |
| `cooldownTicks` | long | 必須 | クールダウン |
| `manaCost` | double | 必須 | 旧定義との互換用消費 MP。新規定義は `resourceCost` を使用する |
| `resourceType` | string? | 任意 | 共通消費リソース。`MANA` / `ENERGY` |
| `resourceCost` | double? | 任意 | 共通消費量 |
| `castTimeTicks` | long | 必須 | 詠唱時間 |
| `requiredLevel` | int | 必須 | 必要レベル |
| `onCast` | object? | 任意 | 発動演出設定 |
| `onCast.sound` | string? | 任意 | sound key |
| `passive` | object? | 任意 | パッシブ補助設定 |
| `passive.bindRequired` | bool | 任意 | `true` の場合はパッシブ枠への設定が必要 |
| `params` | object | 必須 | 実装固有パラメータ |
| `tags` | string[] | 必須 | 分類タグ |

## SkillSummaryResponse

`GET /api/skill` の一覧要素。

| フィールド | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `id` | string | 必須 | スキル ID |
| `name` | string | 必須 | 表示名 |
| `implementationId` | string | 必須 | plugin 側実装 ID |
| `icon` | string? | 任意 | Material 名 |
| `tags` | string[] | 必須 | 分類タグ |

## 補足

- 発動スキルかパッシブスキルかの最終判定は plugin 側の `SkillExecutor.kind()` が正本です。
- API は `passive.bindRequired` をそのまま返します。
- API は top-level `resourceType` / `resourceCost` をそのまま返します。未指定時の旧 `params` / `manaCost` 互換解決は plugin が行います。
- `params` はネストを保持したまま返却します。
