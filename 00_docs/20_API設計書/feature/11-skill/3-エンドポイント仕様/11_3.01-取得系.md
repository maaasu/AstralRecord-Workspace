# 11_3.01 取得系

## GET `/api/skill`

スキル一覧を返します。

- Controller: `SkillController`
- Action: `GetAll`
- Header: `X-Api-Key` 必須

### 返却

- `200 OK`
  - `SkillSummaryResponse[]`
- `401 Unauthorized`
  - API キー不正

### 備考

- `dbo.master_data_entry` の `master_type = 'skill'` かつ `is_deleted = 0` を対象にします。
- `payload_json` を逆シリアライズし、一覧では `id / name / implementationId / icon / tags` を返します。

## GET `/api/skill/{skillId}`

スキル詳細を返します。

- Controller: `SkillController`
- Action: `GetById`
- Header: `X-Api-Key` 必須
- Path: `skillId`

### 返却

- `200 OK`
  - `SkillResponse`
- `401 Unauthorized`
  - API キー不正
- `404 Not Found`
  - 対象スキルなし

### 備考

- top-level `resourceType` / `resourceCost` を `SkillResponse` として返却します。
- 旧 `params.resourceType` / `params.resourceCost` / `manaCost` からの互換解決は plugin 側の責務です。
- `params` はネストを保持したまま返します。
- `passive.bindRequired` を返却し、plugin 側はこれをパッシブ発動条件判定に使用します。
- スキル種別そのものは plugin 側実装が正本です。
