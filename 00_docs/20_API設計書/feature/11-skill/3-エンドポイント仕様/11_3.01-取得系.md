# 11_3.01-取得系

## 1. 取得系エンドポイント仕様

### スキル一覧取得
HTTPメソッド: `GET`
パス: `/api/skill`
コントローラ: `SkillController`
アクション型名: `GetAll`

概要

MasterDataDB の `dbo.master_data_entry`（`master_type = 'skill'`）から有効レコードを取得し、filebase 正本由来の `payload_json` をデシリアライズして主要項目を返す。

リクエスト

| 区分 | 名前 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| Header | `X-Api-Key` | string | ✓ | API キー |

レスポンス:

| ステータス | 概要 | ボディ |
|---|---|---|
| 200 OK | 取得成功 | [[11_1.00-モデル定義]].スキル一覧レスポンス の配列 |
| 401 Unauthorized | API キー不正または不足 | なし |

処理方針:

1. 認証パイプラインで `X-Api-Key` を検証する
2. MasterDataDB から `master_type = 'skill'` かつ `is_deleted = 0` の `payload_json` を取得する
3. 各 `payload_json` を [[11_1.00-モデル定義]].スキル詳細レスポンス へデシリアライズし、主要項目（`id` / `name` / `implementationId` / `icon` / `tags`）に射影して 200 で配列を返す
4. 例外時は [[11_5.00-例外・ログ・運用]] のログを記録し 500 を返す

### スキル詳細取得
HTTPメソッド: `GET`
パス: `/api/skill/{skillId}`
コントローラ: `SkillController`
アクション型名: `GetById`

リクエスト

| 区分 | 名前 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| Header | `X-Api-Key` | string | ✓ | API キー |
| Path | `skillId` | string | ✓ | スキル ID |

レスポンス:

| ステータス | 概要 | ボディ |
|---|---|---|
| 200 OK | 取得成功 | [[11_1.00-モデル定義]].スキル詳細レスポンス |
| 401 Unauthorized | API キー不正または不足 | なし |
| 404 Not Found | 未定義 skillId | なし |

処理方針:

1. 認証パイプラインで `X-Api-Key` を検証する
2. MasterDataDB から `master_type = 'skill'` かつ `master_id = skillId` で検索する（取得失敗時は 404）
3. `payload_json` を [[11_1.00-モデル定義]].スキル詳細レスポンス へデシリアライズし 200 で返す
4. `params` は型固定せず、そのまま返却する
5. 例外時は [[11_5.00-例外・ログ・運用]] のログを記録し 500 を返す
