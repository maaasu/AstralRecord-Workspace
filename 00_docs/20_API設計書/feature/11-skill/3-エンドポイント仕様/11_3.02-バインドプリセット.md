# 11_3.02 スキルバインドプリセット API

## GET /api/skill-bind-presets

アカウントのスキルバインドプリセット 1 から 9 を取得する。

### Query

| 名前 | 型 | 必須 | 説明 |
|:--|:--|:--|:--|
| `account_id` | Guid | ○ | 対象アカウント ID |

### Response 200

- `presetIndex`: 1 から 9
- `activeSkillSlots`: 発動系スキル 8 スロット。空きは `null`
- `passiveSkillSlots`: パッシブ系スキル 8 スロット。空きは `null`
- `isUnlocked`: 解放済み判定。1 から 3 は常に解放済みとして返す
- `isSaved`: 保存済み行が存在する場合 `true`

## PUT /api/skill-bind-presets/{accountId}/{presetIndex}

指定プリセットへ現在のバインド状態を保存する。

### Path

| 名前 | 型 | 必須 | 説明 |
|:--|:--|:--|:--|
| `accountId` | Guid | ○ | 対象アカウント ID |
| `presetIndex` | int | ○ | 1 から 9 のプリセット番号 |

### Request

```json
{
  "activeSkillSlots": ["fire_boost", null, null, null, null, null, null, null],
  "passiveSkillSlots": [null, null, null, null, null, null, null, null],
  "updatedBy": "00000000-0000-0000-0000-000000000000"
}
```

### Response 200

保存後の `SkillBindPresetResponse` を返す。

### Response 400

`presetIndex` が 1 から 9 の範囲外の場合。

## 補足

- 未保存プリセットは保存ボタン押下まで DB 行を作成しない。
- 未所持スキルが保存済みスロットに残っていても API は自動削除しない。発動可否は発動時の所持判定で制御する。
