# 11_3.02 スキルバインドプリセット API

## GET `/api/skill-bind-presets?account_id={accountId}`

アカウントのプリセット1..6を返す。DB行がない番号も空の6 action枠・9 passive枠として補完する。既存仕様どおり1..3を初期解放し、4..6は`isUnlocked`で解放状態を保持する。選択保存済みの場合は選択中の1件だけ`isSelected=true`を返し、選択保存がない場合はPluginがプリセット1を既定選択として扱う。

`leftClickSkillId`の`__weapon_normal_attack__`は武器タグ通常攻撃、`null`は未設定を表す。

個体ID導入前に保存された通常バインド値がraw `skillId` の場合、GETは対象accountが所有する同skill IDの最古の`learnedSkillId`へ正規化して返す。対応する習得個体がない旧値、および現在は対象accountが所有しないUUIDは`null`へ正規化する。Pluginはこの応答を次回PUTで保存し、UUID正本へ移行する。

## PUT `/api/skill-bind-presets/{accountId}/{presetIndex}`

指定プリセットを保存する。`presetIndex`は1..6。

```json
{
  "activeSkillSlots": ["3ccdb749-dc77-4f99-b33c-bcf2dd3567fb", null, null, null, null, null],
  "leftClickSkillId": "__weapon_normal_attack__",
  "passiveSkillSlots": [null, null, null, null, null, null, null, null, null],
  "updatedBy": "00000000-0000-0000-0000-000000000000"
}
```

action / left-click / passiveの通常バインド値は対象accountが所有する有効な`learnedSkillId`でなければならない。通常攻撃予約値`__weapon_normal_attack__`はactionとleft-clickに許可し、passiveには許可しない。通常攻撃予約値は所持済みスキル個体としての検証対象外とする。使用許可の有無は保存条件にせず、発動時に判定する。

9枠すべてを永続化するため、現在の有効passive枠数が5などへ減っても超過位置の値は削除しない。

## PUT `/api/skill-bind-presets/{accountId}/selected`

現在選択中のプリセット番号だけを保存する。スキルバインド内容は変更しない。`presetIndex`は1..6。
選択更新はアカウント単位のトランザクションとして実行し、既存の選択を解除してから新しい選択を保存する。保存完了後の`isSelected=true`は最大1件とする。

```json
{
  "presetIndex": 2,
  "updatedBy": "00000000-0000-0000-0000-000000000000"
}
```

保存成功時は `204 No Content` を返す。

## ステータス

| Status | 条件 |
|---|---|
| `200` | 取得・保存成功 |
| `400` | preset範囲外、account不在、未所持UUID、不正な通常攻撃予約値 |
| `401` | APIキー不正 |
