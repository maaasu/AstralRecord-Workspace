# 11_3.02 スキルバインドプリセット API

## GET `/api/skill-bind-presets?account_id={accountId}`

アカウントのプリセット1..9を返す。DB行がない番号も空の12 active枠・12 passive枠として補完する。1..3を初期解放し、4..9は`isUnlocked`で解放状態を保持する。選択保存済みの場合は選択中の1件だけ`isSelected=true`を返し、選択保存がない場合はPluginがプリセット1を既定選択として扱う。

既存の短い配列は割り当てを保持して末尾をnullで補完する。Pluginの初期有効枠はactive 1..9・passive 1..5、アクションリングの表示対象はactive 1..8とする。9..12はリングに含めず、利用可能な枠を別のキャスト手段から使用する。枠数変更はPluginとAPIを同時に反映し、既存DBには `20260921_skill_bind_capacity.sql` を事前適用する。

`leftClickSkillId`の`__weapon_normal_attack__`は武器タグ通常攻撃、`null`は未設定を表す。

個体ID導入前に保存された通常バインド値がraw `skillId` の場合、GETは対象accountが所有する同skill IDの最古の有効な`learnedSkillId`へ正規化して返す。対応する習得個体がない旧値、および対象accountに属した履歴がないUUIDは`null`へ正規化する。対象accountで忘却済みの`learnedSkillId`は同じバインド位置に保持して返し、Pluginが未習得表示・発動拒否できるようにする。Pluginはraw `skillId`の正規化結果を次回PUTで保存し、UUID正本へ移行する。

## PUT `/api/skill-bind-presets/{accountId}/{presetIndex}`

指定プリセットを保存する。`presetIndex`は1..9。

```json
{
  "activeSkillSlots": ["3ccdb749-dc77-4f99-b33c-bcf2dd3567fb", null, null, null, null, null, null, null, null, null, null, null],
  "leftClickSkillId": "__weapon_normal_attack__",
  "passiveSkillSlots": [null, null, null, null, null, null, null, null, null, null, null, null],
  "updatedBy": "00000000-0000-0000-0000-000000000000"
}
```

action / left-click / passiveへ新規設定または移動する通常バインド値は、対象accountが所有する有効な`learnedSkillId`でなければならない。忘却前から同じプリセット・同じslotに保存されていた対象accountの`learnedSkillId`は、その位置に保持する更新、または手動で空にする更新だけを許可し、別slotへの移動や再設定は拒否する。通常攻撃予約値`__weapon_normal_attack__`はactionとleft-clickに許可し、passiveには許可しない。通常攻撃予約値は所持済みスキル個体としての検証対象外とする。passive slotには`passive.bindRequired=true`のpassive個体だけを許可し、同一プリセット内のpassive slotへ同じ`learnedSkillId`を重複設定してはならない。使用許可の有無は保存条件にせず、発動時に判定する。

`learnedSkillId` がUUIDとして解釈できる場合、保存・返却時はハイフン付き小文字の標準UUID表記へ正規化する。

12枠すべてを永続化するため、現在の有効枠数を超える位置の値も削除しない。

## PUT `/api/skill-bind-presets/{accountId}/selected`

現在選択中のプリセット番号だけを保存する。スキルバインド内容は変更しない。`presetIndex`は1..9。
選択更新はアカウント単位のトランザクションとして実行し、既存の選択を解除してから新しい選択を保存する。保存完了後の`isSelected=true`は最大1件とする。

```json
{
  "presetIndex": 2,
  "updatedBy": "00000000-0000-0000-0000-000000000000"
}
```

保存成功時は `204 No Content` を返す。

## ステータス

| Status | 条件 |
|---|---|
| `200` | 取得・保存成功 |
| `400` | preset範囲外、account不在、未所持UUID（忘却前から同じslotに保持された対象accountのIDを除く）、削除済みIDの新規設定・移動、passive.bindRequired=falseのpassive、同一プリセット内のpassive重複、不正な通常攻撃予約値 |
| `401` | APIキー不正 |
