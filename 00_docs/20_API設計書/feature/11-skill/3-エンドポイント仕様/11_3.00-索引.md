# 11_3.00-索引

## エンドポイント一覧

| HTTPメソッド | パス | 論理名 |
|---|---|---|
| GET | `/api/skill` | スキル一覧取得 |
| GET | `/api/skill/{skillId}` | スキル詳細取得 |

---

## 1. スキル一覧取得

HTTPメソッド: `GET`
パス: `/api/skill`
コントローラ: `SkillController`
アクション物理名: `ListSkills`

リクエスト:

| 種別 | 名前 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| Header | `X-Api-Key` | string | ✓ | API キー |

レスポンス:

| ステータス | 内容 | ボディ |
|---|---|---|
| 200 OK | 取得成功 | [[11_1.00-モデル定義]].スキル一覧レスポンス要素 の配列 |
| 401 Unauthorized | API キー未指定/無効 | なし |

---

## 2. スキル詳細取得

HTTPメソッド: `GET`
パス: `/api/skill/{skillId}`
コントローラ: `SkillController`
アクション物理名: `GetSkill`

リクエスト:

| 種別 | 名前 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| Header | `X-Api-Key` | string | ✓ | API キー |
| Path | `skillId` | string | ✓ | スキル ID |

レスポンス:

| ステータス | 内容 | ボディ |
|---|---|---|
| 200 OK | 取得成功 | [[11_1.00-モデル定義]].スキル詳細レスポンス |
| 401 Unauthorized | API キー未指定/無効 | なし |
| 404 Not Found | 未定義 skillId | なし |

処理内容:

1. 認証パイプラインで `X-Api-Key` を検証する
2. MasterDataDB から `master_type = skill` かつ `master_id = skillId` で検索する（取得失敗時は 404）
3. 200 で詳細を返す
4. 例外時は [[11_5.00-例外・ログ・運用]] のログを記録し 500 を返す
