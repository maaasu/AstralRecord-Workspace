## 4. 責務分担

- filebase:
  - スキルの表示項目、top-level `resourceType` / `resourceCost`、`implementationId`、実装固有 `params` を定義する正本。
- API:
  - 定義を返し、全skillから `00_skill_gem_<skillId>` の仮想itemを生成する。
  - ジェム消費による新規個体、指定個体のレベルアップ、シジルと対応オーブの消費装着・オーブ消費脱着をtransactionで永続化する。
  - load時に削除済みskill/gemと不正シジルを整合し、不正シジルは動的メールで返却する。
- Plugin:
  - `implementationId` と実装クラスの紐付け、共通項目と `params` の詳細検証、発動ロジックを担当する。
  - 旧定義は `params.resourceType` / `params.resourceCost`、`manaCost` の順で互換解決する。
  - 所持個体と、クラスまたはスキルツリーから得る使用許可を分離して発動判定する。
