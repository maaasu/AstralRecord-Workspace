# 11_5.00-例外・ログ・運用

ログ・メッセージはハードコーディング。LogId は使用しない。

## 1. 共通エラーレスポンス

| ステータス | 発生条件 | ボディ |
|---|---|---|
| 401 Unauthorized | API キー未指定/無効 | なし |
| 404 Not Found | skillId 未定義 | なし |
| 500 Internal Server Error | 上記以外の例外 | `ProblemDetails` 互換 |

## 2. ログ一覧

| 項目 | 内容 |
|---|---|
| レベル | Information |
| テンプレート | `Loaded {Count} skills from filebase` |
| 出力条件 | アプリ起動時に YAML ロード完了 |
| 引数 | `{Count}` = 読み込まれたスキル数 |

| 項目 | 内容 |
|---|---|
| レベル | Error |
| テンプレート | `Failed to load skill YAML: {Path}` |
| 出力条件 | YAML パース失敗時 |
| 引数 | `{Path}` = 該当ファイルパス |
| 出力例外 | `_logger.LogError(ex, ...)` で添付 |

| 項目 | 内容 |
|---|---|
| レベル | Error |
| テンプレート | `Failed to get skill {SkillId}` |
| 出力条件 | 例外発生時 |
| 引数 | `{SkillId}` = スキル ID |
| 出力例外 | `_logger.LogError(ex, ...)` で添付 |

## 3. 運用上の注意

- `implementationId` に対応するプラグイン側実装クラスの存在は API 単体では検証しない。
