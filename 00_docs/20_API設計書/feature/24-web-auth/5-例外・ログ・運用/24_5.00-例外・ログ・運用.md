# 24_5.00-例外・ログ・運用

| 応答 | 条件 |
|---|---|
| `400 Bad Request` | 必須項目不足、コード不正、期限切れ、失効済み、消費済み |
| `404 Not Found` | 発行対象ユーザーが存在しない |
| `201 Created` | チャレンジ発行成功 |
| `200 OK` | チャレンジ消費成功 |
| `409 Conflict` | コンソール用MCID解決で同じMCIDが複数ある |

## セキュリティ・運用

- 平文ログインコードを DB やログへ保存しない。
- 有効期限は `WebAuth:ChallengeMinutes`（最小 1 分）で管理する。
- ログイン URL は `WebAuth:LoginUrl` から返す。
- 同一ユーザーの有効チャレンジは常に最新 1 件へ集約する。
- `ConnectionStrings:WebSite` を設定できる。未設定時は `ConnectionStrings:SqlServer` の接続先DB名だけを `WebSiteDB` に置換する。
- `WebSiteDB/init.sql` は初回配置時に適用する。既存3DB固定のDB移行・再構築ツールはWebSiteDBを操作しない。
- `WebAuth:LoginUrl` の既定値は `https://astralrecord.com/Login`。
- Web管理認可はWebSiteDBを要求ごとに照会し、API障害時は拒否する。
