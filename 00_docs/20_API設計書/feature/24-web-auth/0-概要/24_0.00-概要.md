# 24_0.00-概要

## 1. 目的

Minecraft で本人確認済みのプレイヤーに Web ログイン用コードを発行し、Web からの入力時に一度だけ消費してログイン主体を確定します。本人確認後は、ManagementDBに保持する固定ログインID・パスワードを任意で有効化できます。

## 2. 責務

- 発行要求のユーザー存在確認。
- 既存の有効チャレンジの失効。
- 8 文字コードの生成、SHA-256 ハッシュ化、DB 保存。
- 有効期限、消費済み、失効済みの検証。
- 消費成功時の user UUID、MCID、権限、アカウント ID、Cookie失効用sessionVersion返却。
- 固定ログインID・パスワードの有効化、変更、無効化と、ID単位の永続ログイン試行制限。
- ゲームDBリセット後もManagementDBの本人識別情報・Web認証情報を保持する。
