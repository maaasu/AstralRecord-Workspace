# 24_3.02-登録系

## ログインチャレンジ発行

- HTTP メソッド: `POST`
- パス: `/api/web-auth/challenges`
- 要求: `WebLoginChallengeCreateRequest`
- 応答: `201 Created` と `WebLoginChallengeCreateResponse`

必須項目が不足する場合は `400 Bad Request`、対象ユーザーが存在しない場合は `404 Not Found` を返します。有効な既存チャレンジは新規発行時に `revokedAt` を設定して失効します。

コードは `ABCDEFGHJKLMNPQRSTUVWXYZ23456789` から 8 文字を生成し、表示時は `XXXX-XXXX` 形式とします。DB には正規化後の SHA-256 ハッシュだけを保存します。
