# 24_3.03-消費系

## ログインチャレンジ消費

- HTTP メソッド: `POST`
- パス: `/api/web-auth/challenges/consume`
- 要求: `WebLoginChallengeConsumeRequest`
- 応答: `200 OK` と `WebLoginChallengeConsumeResponse`

空のコード、未知のコード、期限切れ、失効済み、消費済みは `400 Bad Request` とします。期限切れ等の既知チャレンジでは `failedAttempts` を増加させます。成功時は `consumedAt` を設定し、ユーザー情報と削除されていないアカウント ID をスロット順で返します。
