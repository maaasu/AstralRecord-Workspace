# 24_2.00-ユースケース

## 1. Plugin からチャレンジを発行する

1. 必須項目と user UUID を検証する。
2. 対象ユーザーが存在し、削除されていないことを確認する。
3. 同じユーザーの未消費・未失効・期限内チャレンジを失効する。
4. 新しいコードを生成し、ハッシュだけを DB に保存する。
5. 平文コード、有効期限、ログイン URL を Plugin へ返す。

## 2. Web からチャレンジを消費する

1. コードから空白とハイフンを除去し、大文字へ正規化する。
2. SHA-256 ハッシュでチャレンジを検索する。
3. 未消費・未失効・期限内であることを検証する。
4. 消費時刻を記録し、ユーザーとアカウント情報を返す。
