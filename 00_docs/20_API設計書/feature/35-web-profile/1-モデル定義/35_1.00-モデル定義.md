# Webプロフィールモデル

`WebPlayerProfileResponse` は`userUuid`、`mcid`、`permission`、`isPublic`、選択中の`currentAccount`、閲覧可能な非削除アカウント概要`accounts[]`を返す。`currentAccount`は`accountId`、`accountName`、`slotIndex`、`playerLevel`、`classId`、`className`、`classLevel`、全クラス進行`classProgresses[]`、所持金`gold`、総討伐数`totalMobDefeats`、最終保存時刻`updatedAt`、`skillTree`を持つ。`accounts[]`は`accountId`、`accountName`、`slotIndex`、`playerLevel`、`classId`、`className`を持つ。

`skillTree`は`structureId`、`name`、`rootNodeId`、表示対象`nodes[]`、両端が表示対象の`edges[]`を返す。nodeはID、名前、アイコン、lore、tags、point種別・コスト、条件、効果、表示用効果文、相対座標、解放状態、CP消費クラスを含む。

一覧レスポンスは`profiles[]`、クラスフィルタ候補`classes[]`、`page`、`pageSize`、`totalCount`を返す。`pageSize`既定値は20、上限は100である。

公開詳細の`permission`はnull。本人または明示的な管理者閲覧にのみ値を返す。

一覧の`profiles[]`はアカウント単位の`WebPlayerProfileSummaryResponse`で、user UUID・MCID・公開設定・アカウント概要（ID・名前・slot・レベル・クラスID・クラス名）のみを含む。所持金・スキルツリーの偽の0値は返さない。

nodeの`isConditionMet`は現在の職業/レベル条件の成立、`requirementText`は必要条件の日本語表示文を表す。`SCALAR`の0.10は10%と表示する。

本人の`currentAccount.connection`は、検証済みruntime viewから`status`、`channelName`、`worldName`、`x/y/z`、`observedAtUtc`を返す。公開詳細と管理者による他人の閲覧ではnullとし、場所の情報を公開しない。`status`はonline/offline/stale/unknownを区別する。通信途絶や世代不明をofflineと読み替えない。

スキン画像取得にはMinecraftプレイヤーの`userUuid`を利用する。ゲーム内スロットを表す`accountId`をスキンUUIDとして用いない。
