# Webプロフィールモデル

`WebPlayerProfileResponse` は`userUuid`、`mcid`、`permission`、`isPublic`、`currentAccount`を返す。`currentAccount`は`accountId`、`accountName`、`playerLevel`、`classId`、`className`、`classLevel`、全クラス進行`classProgresses[]`、所持金`gold`、最終保存時刻`updatedAt`、`skillTree`を持つ。

`skillTree`は`structureId`、`name`、`rootNodeId`、表示対象`nodes[]`、両端が表示対象の`edges[]`を返す。nodeはID、名前、アイコン、lore、tags、point種別・コスト、条件、効果、表示用効果文、相対座標、解放状態、CP消費クラスを含む。

一覧レスポンスは`profiles[]`、クラスフィルタ候補`classes[]`、`page`、`pageSize`、`totalCount`を返す。`pageSize`既定値は20、上限は100である。
