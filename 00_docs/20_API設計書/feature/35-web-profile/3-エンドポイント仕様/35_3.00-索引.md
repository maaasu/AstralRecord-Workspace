# Webプロフィール エンドポイント

| HTTP | パス | 内容 |
|---|---|---|
| GET | `/api/web-profiles/me?viewer_user_uuid=` | 本人の完全プロフィール |
| PUT | `/api/web-profiles/me/visibility?viewer_user_uuid=` | 本人の公開設定更新。bodyは`{isPublic}` |
| GET | `/api/web-profiles/{userUuid}?viewer_user_uuid=&include_private=&account_id=` | 公開済み、本人、またはWeb管理者の詳細。`account_id`は対象user所有の非削除アカウントだけを選択可能 |
| GET | `/api/web-profiles?viewer_user_uuid=&mcid=&class_id=&sort=level_desc|level_asc&page=1&page_size=20&include_private=` | MCID・クラスフィルタ、アカウントレベル順、アカウント単位ページング一覧 |
| GET | `/api/web-bestiary?viewer_user_uuid=&account_id=` | ログイン中の本人だけの討伐済みMob一覧。`account_id`省略時は現在選択中アカウント |
| GET | `/api/web-bestiary/{mobId}?viewer_user_uuid=&account_id=` | ログイン中の本人が討伐済みのMob詳細。未討伐または他人のアカウントは404 |

すべて既存の`X-Api-Key`が必要である。APIキーなしの任意閲覧はできない。公開一覧・公開詳細では`viewer_user_uuid`を省略できる。指定する場合の信頼境界はWebの認証済みセッションclaimsであり、APIはそのUUIDに対する`web_admin`だけをManagementDBで毎回再照会する。

`include_private=true` はManagementDBのWebAdminを要求し、非管理者の場合は一覧・詳細のどちらも403を返す。所有者でも管理者専用モードは利用できず、本人閲覧は通常モードで行う。

図鑑は管理者権限による他者閲覧を提供しない。Webの認証済みCookieから取得した`viewer_user_uuid`に対して、非削除userとaccountの所有を照合する。対象userがない場合・他人や削除済みaccount指定は404。account省略時に現在選択中accountがなければ一覧は`currentAccount: null`と空の`mobs`、本人所有の`accounts`を返し、詳細は404とする。Webページは一覧・詳細ともログイン必須。Webページと図鑑API応答の双方を`Cache-Control: no-store`で配信する。

一覧レスポンスは`currentAccount`、`accounts`、`mobs`、`totalDefeats`。詳細は同じアカウント情報と`mob`を返し、`mob`内に`defeatCount`、`firstDefeatedAt`、`lastDefeatedAt`を含む。日時はUTC。`drops.items[].rate`はマスタ定義の百分率（通常0～100）、`baseStats[].displayValue`は共通ステータスカタログの桁数・単位で整形する。`hidden: true`のアイテムは除外し、LootTableのIDや内訳は返さない。`hasAdditionalDrops`で追加抽選の有無を表す。
