# 12_1.00-モデル定義

## 1. レシピ一覧レスポンス要素

物理名: `RecipeListItem`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `id` | string | ✗ | レシピ ID |
| `type` | string | ✗ | リソース種別（`RECIPE`） |
| `category` | string | ✗ | レシピカテゴリ（`CRAFT` 等） |
| `name` | string | ✓ | 表示名 |

## 2. レシピ詳細レスポンス

物理名: `RecipeResponse`

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| `schemaVersion` | int | ✗ | YAML スキーマバージョン |
| `id` | string | ✗ | レシピ ID |
| `type` | string | ✗ | リソース種別 |
| `category` | string | ✗ | レシピカテゴリ |
| `name` | string | ✓ | 表示名 |
| `lore` | string[] | ✗ | 説明文 |
| `tags` | string[] | ✗ | タグ |
| `result` | object | ✓ | 生成結果 |
| `result.itemId` | string | ✗ | 生成アイテム ID |
| `result.amount` | int | ✗ | 生成数 |
| `ingredients` | object[] | ✗ | 必要素材 |
| `ingredients[].itemId` | string | ✗ | 素材アイテム ID |
| `ingredients[].amount` | int | ✗ | 必要数 |
| `requiredLevel` | int | ✗ | 必要レベル |
| `requiredClasses` | string[] | ✗ | 使用可能クラス |
| `requiredCurrency` | int | ✗ | 必要通貨 |
| `stationId` | string | ✓ | 必要施設 ID |
| `successRate` | number | ✗ | 成功率 |
| `failAction` | string | ✗ | 失敗時の挙動（`NONE` 等） |
| `cooldownTicks` | long | ✗ | クールダウン |
| `onSuccess.sound` | string | ✓ | 成功時サウンド |
| `onSuccess.particle` | string | ✓ | 成功時パーティクル |
| `onFail.sound` | string | ✓ | 失敗時サウンド |
| `onFail.particle` | string | ✓ | 失敗時パーティクル |
