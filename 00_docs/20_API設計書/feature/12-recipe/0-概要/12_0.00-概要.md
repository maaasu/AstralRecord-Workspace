# 12_0.00-概要

## 1. 目的

MasterDataDB に投入済みの `recipe` マスタから、レシピ定義を取得する読み取り専用 API。
クラフト・強化・状態変化など、装備関連のレシピを参照する `recipeId` の解決に使用される。

## 2. 構成要素

- `Controllers/RecipeController`
- `Repositories/RecipeRepository`（MasterDataDB 参照）
- `Models/RecipeResponse`
