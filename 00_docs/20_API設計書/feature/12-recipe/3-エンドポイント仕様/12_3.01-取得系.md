# 12_3.01-取得系

## 1. 取得系エンドポイント仕様

### レシピ一覧取得

HTTPメソッド: `GET`
パス: `/api/recipe`
コントローラ: `RecipeController`
アクション物理名: `GetAll`

責務:

MasterDataDB の `dbo.master_data_entry`（`master_type = 'recipe'`）から有効レコードを取得し、`master_id` / `type` / `category` / `display_name` の主要項目で返す。

リクエスト:

| 種別 | 名前 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| Header | `X-Api-Key` | string | ✓ | API キー |

レスポンス:

| ステータス | 内容 | ボディ |
|---|---|---|
| 200 OK | 取得成功 | [[12_1.00-モデル定義]].レシピ一覧レスポンス要素 の配列 |
| 401 Unauthorized | API キー未指定/無効 | なし |

処理内容:

1. 認証パイプラインで `X-Api-Key` を検証する
2. MasterDataDB から `master_type = 'recipe'` かつ `is_deleted = 0` のレコードを取得し、`master_id` → `id` / `type` / `category` / `display_name` → `name` に射影する
3. 200 で配列を返す
4. 例外時は [[12_5.00-例外・ログ・運用]] のログを記録し 500 を返す

---

### レシピ詳細取得

HTTPメソッド: `GET`
パス: `/api/recipe/{recipeId}`
コントローラ: `RecipeController`
アクション物理名: `GetById`

リクエスト:

| 種別 | 名前 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| Header | `X-Api-Key` | string | ✓ | API キー |
| Path | `recipeId` | string | ✓ | レシピ ID |

レスポンス:

| ステータス | 内容 | ボディ |
|---|---|---|
| 200 OK | 取得成功 | [[12_1.00-モデル定義]].レシピ詳細レスポンス |
| 401 Unauthorized | API キー未指定/無効 | なし |
| 404 Not Found | 未定義 recipeId | なし |

処理内容:

1. 認証パイプラインで `X-Api-Key` を検証する
2. MasterDataDB から `master_type = 'recipe'` かつ `master_id = recipeId` で検索する（取得失敗時は 404）
3. `payload_json` を [[12_1.00-モデル定義]].レシピ詳細レスポンス へデシリアライズし 200 で返す
4. 例外時は [[12_5.00-例外・ログ・運用]] のログを記録し 500 を返す
