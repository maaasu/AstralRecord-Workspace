# ペットモデル定義

## ペット個体レスポンス

物理名: PetInstanceResponse

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| instanceId/accountId | GUID | ✗ | 個体ID・現在所有者 |
| speciesId/itemId | string | ✗ | 種類ID・現在itemID |
| isEgg | bool | ✗ | 孵化前 |
| origin | string | ✗ | WILD/BRED |
| tradeAllowed | bool | ✗ | WILDのみtrue |
| version | long | ✗ | progressの楽観ロック |
| createdAt/updatedAt | datetime | ✗ | UTC |
| details | PetDetailsResponse | ✓ | 卵ではプロパティそのものを出力しない |

## 孵化後個体詳細

物理名: PetDetailsResponse

| フィールド | 型 | nullable | 説明 |
|---|---|---|---|
| name/sex | string | ✗ | 名前、MALE/FEMALE |
| size | double | ✗ | 種類ごとの範囲内倍率 |
| level/experience | int/long | ✗ | 成長度とレベル内EXP、最大LvでEXP0 |
| healthRatio/isDead | double/bool | ✗ | HP比率0〜1・死亡 |
| breedAvailableAt | datetime | ✓ | UTC配合CD終了 |
| stats | dictionary | ✗ | 五項目のPetStatResponse〈tier,baseValue,potential,currentValue〉 |
| skills | PetSkillResponse[] | ✗ | 最大3件〈id,tier,slotIndex0〜2〉 |
| cooldowns | dictionary<string,long> | ✗ | 次回発動時刻epoch milliseconds |

## 変更要求

全要求はPetOperationRequestの `operationId GUID`、`updatedBy GUID` を含み、非空UUIDが必須。

| 物理名 | 追加フィールド | 契約 |
|---|---|---|
| PetEggCreateRequest | speciesId string | 種類指定 |
| PetFacilityRequest | facilityId string | 許可施設ID |
| PetBreedRequest | maleId/femaleId GUID | 同種・異性・生存・成長済みの親 |
| PetProgressRequest | expectedVersion long、experience long、healthRatio double、isDead bool、cooldowns map nullable | 選択中個体のEXP加算。CD省略は維持 |
| PetReviveRequest | orbInventoryEntryId GUID nullable、facilityId string | オーブ指定または施設 |
| PetEquipRequest | petId GUID nullable | nullで解除 |
| PetRenameRequest | name string | 1〜24文字 |

## 応答

PetAccountResponseは `accountId GUID/equippedPetId GUID nullable/instances PetInstanceResponse[]`。PetMutationResponseは `instance PetInstanceResponse nullable/equippedPetId GUID nullable/inventorySnapshot InventoryOperationSnapshotResponse nullable`。操作のHTTP200本文はPetMutationResponse、失敗は `{failure:string}`。不正要求はmutation慣例に合わせ409、存在しないaccount/pet/egg/masterは404。詳細フローとエンドポイントは [[39_3.00-ペットAPI]]。
