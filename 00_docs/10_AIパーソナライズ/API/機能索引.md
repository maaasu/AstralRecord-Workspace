# APIの機能索引

機能名から入口を探すときに参照します。Controllerは [Controllers](../../../20_api/AstralRecordApi/AstralRecordApi/Controllers) にあります。

| 用途 | Controllerの入口例 |
|---|---|
| プレイヤー・所持品・保存 | `UserController`、`AccountController`、`PlayerStateController`、`InventoryController`、`PetController` |
| マスターとワールド | `MasterDataController`、`ItemController`、`MobController`、`SkillController`、`WorldController`、`WorldPlacementsController` |
| スキルツリーと進行 | `AccountSkillTreeController`、`SkillTreeEditorController`、`AccountQuestController`、`AdventureRecordController`、`DefenseController` |
| 取引・メール・報酬 | `TradeController`、`MarketController`、`MailController`、`LoginBonusController`、`AccountBenefitsController` |
| Webでの認証・表示・運営 | `WebAuthController`、`WebPlayerProfileController`、`WebBestiaryController`、`PlayerAdminController`、`DonationController`、`AstraldShopController` |
| サーバーの接続・素材配信 | `NetworkController`、`NetworkManagementController`、`GeyserController`、`ResourcePacksController`、`BuilderSchematicsController` |

DB接続とテーブル対応は [DbContext](../../../20_api/AstralRecordApi/AstralRecordApi/Data) と [DB定義](../../../00_docs/40_Database設計書/README.md)、マスター投入は [MasterDataSeeder](../../../20_api/AstralRecordApi/AstralRecordApi/Services/MasterDataSeeder.cs) と [Filebaseの定義](../../../00_docs/50_Filebase設計書/README.md) を確認します。配置は [運用ツール](../../../60_tool/README.md)、API変更とテストは [APIの実装規約](../../../.codex/skills/astralrecord-code/references/api-code.md) を参照します。
