# AstralRecordのAIパーソナライズ

次の依頼でも判断に使う要望や理由を、適用対象ごとの日本語のメモに保存します。

## 今回の依頼で読む項目を選ぶ

索引の「読む場面」と依頼の対象・操作を照合し、該当するメモだけを読みます。共通の項目も、今回の判断に関係するものを選びます。既読の索引・メモは、内容が変わったときに読み直します。

| 対象 | 読む場面 | メモ |
|---|---|---|
| 共通 | 現行仕様の根拠を調べる | [仕様の確認先](共通/仕様の確認先.md) |
| 共通 | 変更をレビューする、指摘を修正する | [レビューの判断](共通/レビューの判断.md) |
| Plugin・API | プレイヤー状態の保存、外部取引、再送・復旧を変更する | [プレイヤー状態の保存](プラグイン/プレイヤー状態の保存.md) |
| API・利用側 | Controller、ルート、DTO、呼び出し元を探す | [APIの探し方](API/README.md) |
| 開発ツール | マスタデータエディタをビルド・配布する | [マスタデータエディタの配布](ツール/マスタデータエディタの配布.md) |
| 開発ツール | マスタデータエディタのファイル表示、習得ノードの選択、予測変換を変更する | [マスタデータエディタの編集操作](ツール/マスタデータエディタの編集操作.md) |
| ゲームデザイン | モブ・装備・スキル・ペットの数値を調整する | [DPS指標](ゲームデザイン/DPS指標.md) |
| ゲームデザイン | ゲームデザイン設計書のHTMLを作成・修正する | [HTML資料のデザイン](ゲームデザイン/HTML資料のデザイン.md) |

下位索引がある領域では、その「読む場面」から対象メモを絞ります。索引で見つからない場合は、対象領域を語句で検索して候補のファイル名を確認します。現在の動作や具体的な条件は、選んだメモの参照先で確かめます。今回の依頼で明示された条件を優先します。

## 記録・整理をするとき

メモを追加・更新・移動するときは [記録と整理](記録と整理.md) を確認し、対象領域の重複・分量・索引を一緒に整えます。
