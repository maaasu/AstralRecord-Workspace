# リソースパックの描画の確認

`50_resourcepack/` に関わるモブ・ギミックの動作や、変更したアセットの見た目を確認するときに参照します。

動作を伴うモブ・ギミックは、両版で通常経路の状態遷移を確認する。ボスでは待機・移動・予兆・発動・復帰を時系列で比べ、該当する場合は被弾・無敵の入りと解除も確認する。専用モデルが表示されている接続では、元のエンティティの描画や発光輪郭が出ないことを確かめる。非対応パックの接続では代替表示を確認する。静止画や通信だけの確認は、実クライアントの動作確認と分けて記録する。

地面に沿う攻撃演出は、上からの視点と地面に近い水平視点の両方で確認する。実際の表示倍率を反映し、予兆中は高さのある境界から危険範囲と安全範囲を区別できること、発動中は代表フレームを通して立体形状の動きが読めることを両版で確かめる。

見た目を変更した場合は、AI が自身の実行環境で独立して再現できる方法で、変更対象を画像に出力して確認する。ユーザーのデスクトップや既存セッションの画面取得・操作など、コンピュータユースによる描画確認は行わない。

- テクスチャ・アイコン・GUI・HUD は、配布用 PNG や描画定義を使い、Python の画像処理やヘッドレス Chromium の Canvas で確認用 PNG を作る。用途に応じて実寸での視認性、透過、重なり、配置を確認する。既存の GUI アイコン・パネルには、[パックの README](../../../50_resourcepack/README.md) にある生成スクリプトの `--check --preview <PNGパス>` を使う。
- 立体モデルやアニメーションは、独立したヘッドレス Chromium 上の Blockbench Web や、対象形式を読み込めるオフスクリーンレンダラーで PNG を出力する。対象の版・視点・表示状態ごとに形状、テクスチャ、向きを確認し、アニメーションは代表フレームを並べて確認する。
- 手持ちの武器・道具は、柄軸まわりの反転を拾うため、両版で握り位置、柄の軸、刃先や作業面の向きを個別に確認する。
- アイテムのインベントリとホットバーは、両版の配布パックが選ぶ表示を枠込みの実寸で比較し、絵柄の片寄り、輪郭、余白を確認する。
- 実クライアント固有の描画は、隔離環境で対象クライアントを起動し、対象シーンとフレームをスクリプトで再現・取得できる場合に確認する。

検証結果は、プレビュー、静的検査・パケット検査、実クライアントの描画に分けて記録する。描画は対象の版・表示状態、入力（編集元または配布データ）、再現方法、確認できた範囲を記録する。確認手段がない描画や表示状態は、理由とともに未確認として記録する。

装備の原画・手持ち・着用の表示を制作・改修するときは、[装備の見た目](装備の見た目.md) の該当する判定条件も確認します。
