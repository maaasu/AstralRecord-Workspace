# 装備の見た目

`50_resourcepack/` の装備について、スロットの原画、手持ちモデル、着用防具を制作・改修し、見た目を判定するときに参照します。

- スロットの原画は Java 版の論理 16 px と統合版で使う表示寸法で確認する。部位や武器種が輪郭で分かり、開口、主素材、その装備を区別する意匠が順に読めること。所持品・装備欄・ホットバーの背景に重ね、隣に並ぶ同部位や同系統の品とも見比べる。防具のスロットには両版で共用する専用アイコンを使い、手持ちと着用のモデルには同じ素材と識別点を反映する。
- 弓のスロットは、実際の3Dモデルの GUI 姿勢と専用原画を同じ論理寸法で比べる。弦が途切れず、弓の内側の開口と弓身の明暗が読める表示を採用する。側面光で細い輪郭が沈む場合は正面光も同じ背景で比べる。通常のアイテムと長押し用の仮想トライデントで、同じスロット表示を使う。
- 着用防具は素体に装備し、単品と組み合わせた姿を正面・斜め・背面から確認する。頭は両目と頬の開口、胴は首元と肩、脚は腰と膝、足は靴口とつま先を見て、体の向きと各部位が読めること。明るい縁、宝石、紋章が複数部位で競合する場合は、主役となる部位を定め、他の面を同系統の素材色に戻す。明暗の異なる素体でも顔と輪郭の区別を確かめる。
- 着用防具の奥行きは素材に合わせて作る。金属や骨の当て板には傾いた面と接合部に落ちる影、革には厚い帯と沈んだ継ぎ目、布には立体の襞と暗い谷を付ける。Java 版の頭装備には頭に追従する着用専用モデルを使い、胴・脚・足は標準の装備面にこれらを描く。統合版は識別点となる当て板や留め具を着用骨に沿う立体にする。頭装備は正面で両目が見える開口と、斜め・背面で外殻や縁の厚みを確認する。混成装備と関節を曲げた姿でも、開口と各部位の動きが読めることを確認する。
- 着用を改修したら、閲覧者の「防具表示」ONとOFFで本人と他プレイヤーの4部位を確認する。ONで当て板を含む着用全体が出て、OFFで素体が見えること。どちらの設定でも同じアイコンと手持ちを参照することを、パックと表示経路の両方で確かめる。
- 手持ちモデルでは武器の刃・弦・石などの主材と、握り・接合部の副材を斜めから見分けられること。細かな彫刻は広い面と影が読める範囲に絞り、握りや接合部の奥行きが分かる箇所へ置く。一人称は手の位置と画角を再現し、待機・使用中に先端と主材の面が画面内に入り、照準周辺に余白があることを確認する。
- 一人称の構えは、柄の傾き、武器の先端、装飾面の向きを左右の手で確認する。待機時は握り側を画面の下端や側面に寄せ、手元から武器が伸びるように見せる。柄尻が自然に画面端で見切れる範囲を許容する。ハンマーは打面と厚み、スタッフは柄と先端、弓は引いたときの両端と弦を読み取れるようにする。待機・攻撃・使用中で、照準と下部・側面の HUD との間隔を確かめる。弓の引き段階、クロスボウの装填、盾の防御、仮想トライデントも対象に含める。
- 副手の道具は対応する手で表示し、主手との同時装備で照準と HUD との間隔を確認する。三人称は横と背面から、握り点と持ち物の向きが読み取れることを確認する。
- 画面の指摘を受けた改修では、確認できる場合は添付時のクライアントと適用済みパックのハッシュを照合する。配布パックを使う比較では画角、表示寸法、手、使用状態、再現した HUD を記録する。画像が切り抜かれている場合は照準を基準に描画領域を合わせ、実際に描画した HUD と位置を再現したガイドを区別する。
- 釣り竿はスロット実寸で、竿先、そこから垂れる糸、リールやウキが別々に読めることを確認する。手持ちの拡大は握り点を基準に行い、投げる前と使用中の構えを比較する。
- 装備の一括改修では、各 ID のスロットと該当する手持ち・着用を旧版と同じ倍率・視点で見比べる。描画画像に加えて、各 ID の識別点、修正した問題、確認した状態を残す。
