# Item 設計

## 役割

Item は、プレイヤーが所持・移動・参照できるマスタの共通土台です。個別の用途は material、consumable、equipment などのカテゴリで定義します。

## 設計方針

- ID、表示名、カテゴリ、レアリティ、見た目、説明文の共通情報を持たせます。
- item 単体には、用途カテゴリで定義すべき性能を重複させません。
- レアリティは希少性と入手難度を表し、進行度そのものとして使用しません。
- 同じ進行度でも、用途と入手難度に応じて複数レアリティを許容します。

## progression

標準入手段階を記載します。素材・装備・消耗品などの派生カテゴリでは、そのカテゴリ文書の基準を優先します。
