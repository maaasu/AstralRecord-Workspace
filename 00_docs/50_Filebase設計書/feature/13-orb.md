# Orb 設計

## 役割

Orb は、通常プレイヤーインベントリからクリックして装備加工または習得済みスキルのシジル操作を開始する item です。

## 設計方針

- `category` は `orb` とし、1 itemの `orb.effect.type` には1種類の操作だけを指定します。
- 強化は `targetSlots`, `rank`, `rankMode` で対象を絞ります。武器、防具、アクセサリの用途が分かれる場合は別オーブにします。
- 修理は正の `repairAmount` または `repairFull: true` のどちらかを指定します。
- 状態変化の `rank` は `rankBasis` で比較基準を指定します。既定 `TARGET` は即時次状態の目標rank、`CURRENT` は使用前の現在rankです。プロメテウスは `CURRENT` とし、無印は現在0、中級は1以下、上級は2以下で使用できます。
- エンチャントは共通 `enchantMasterId` を `enchant:<id>` 形式の必須参照で指定し、`OVERWRITE_RANDOM` / `FILL_ONE_EMPTY` / `FILL_ALL_EMPTY` のいずれかを指定します。
- 成立した装備強化・修理・状態変化・エンチャントは成功・強化失敗を問わず必ず1個消費します。`FILL_ALL_EMPTY` も全空き枠に対して1個です。
- ルーンの装着・脱着オーブは正本再照合に使う操作キーであり、オーブ自体は消費しません。装着時は対象のルーンを1個消費します。
- シジルの装着・脱着オーブは操作成立時にそれぞれ1個消費します。装着時は対象シジルも1個消費し、脱着時は対象シジルを1個返却します。
- 中級以上の強化・修理・状態変化オーブは `chargeSaleValue: true` とし、成立した操作1回につき売り値と同額のゴールドを消費します。状態変化は装備マスタの必要素材・通貨へ加算します。残高不足では装備・オーブ・ゴールドを変更しません。強化失敗は成立した試行として消費し、複数回使用でも各回で残高を再確認します。
- lore には対象ランク・用途などオーブ自体の条件を記載し、対象装備のステータスを動的に列挙しません。

## シジル操作オーブ

| ID | 名称・モチーフ | progression | rarity | 操作 |
|:--|:--|--:|:--|:--|
| `40a00006` (`bragi_orb`) | ブラギのオーブ（北欧神話・詩歌） | `1` | `UNCOMMON` | シジル装着 |
| `40a00010` (`mimir_orb`) | ミーミルのオーブ（北欧神話・知恵の泉） | `1` | `RARE` | シジル脱着・返却 |

返却を伴う脱着オーブは装着オーブより高いrarityとします。

ブラギのオーブは転生の自然完了時に1個付与し、`rebirth_sigil_shop` でも100EXPポイントで交換できます。ミーミルのオーブは転生完了報酬へ含めず、同shopで1500EXPポイントと交換します。

## ランク別オーブ

イージス（防具）・テュール（武器）・フレイヤ（アクセサリ）は、無印で現在ランク0、中級で1以下、上級で2以下、神級で3以下を1段階ずつ強化します。中級と神級は `iconGlint: true` で光沢を表示します。中級のヘッドは無印と同じものを使用します。

| 用途 | 無印ID | 中級ID / 売り値・消費Gold | 上級ID / 売り値・消費Gold | 神級ID / 売り値・消費Gold |
|:--|:--|:--|:--|:--|
| 防具強化（イージス） | `40a00001` | `40a00021` / 160 | `40a00022` / 320 | `40a00023` / 640 |
| 武器強化（テュール） | `40a00003` | `40a00024` / 160 | `40a00025` / 320 | `40a00026` / 640 |
| アクセサリ強化（フレイヤ） | `40a00002` | `40a00027` / 160 | `40a00028` / 320 | `40a00029` / 640 |
| 状態変化（プロメテウス） | `40a00012` | `40a00030` / 300 | `40a00031` / 600 | — |

売り値は無印から各段階で2倍としています。シンドリの中級・上級も既存売り値の120 / 240 Goldを消費します。`40a00016`（上位状態変化）と `40a00017`（上位テュール）は削除し、IDを再利用しません。ペット復活用 `40a00020` は北欧神話の生命・若返りをモチーフに「イズンのオーブ」とし、用途と参照IDを維持します。

## progression

対象装備と同じ段階から、用途の希少性に応じて1段階後までを基準とします。上位rank用オーブは、そのrankへ進める装備より先に大量供給しません。
