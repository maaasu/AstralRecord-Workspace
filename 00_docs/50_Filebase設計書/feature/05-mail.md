# Mail 設計

## 役割

Mail は、公開期間を持つ告知と、既読時に受け取る報酬をプレイヤーへ届ける定義です。

## 設計方針

- 件名と本文だけで目的と受取条件を理解できるようにします。
- 進行必須品を、期間限定 mail だけに依存させません。
- 報酬を持たせる場合、対象 item の progression と公開時期が矛盾しないことを確認します。
- プレイヤーごとの既読・削除状態はマスタへ持たせません。
- `firstLoginOnly: true` のメールは、ユーザーの初回ログイン時だけ配信します。
- `skilltree_structure_reset_compensation` は、スキルツリー構造不整合をロード時に全解除したユーザーへだけ動的配信する補償テンプレートです。本文・アイコン・既読時報酬はこのマスタで管理し、配信の重複防止は API が構造キーごとに行います。

## progression

報酬がある場合は、その報酬を標準的に受け取らせる段階を基準にします。告知のみの場合は `0` とします。
