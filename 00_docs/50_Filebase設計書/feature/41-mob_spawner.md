# Mob Spawner 設計

## 役割

Mob Spawner は、mob をワールド内の指定条件で出現・再出現させる定義です。

## 設計方針

- 出現対象、範囲、上限、間隔、再出現条件を組み合わせて密度を制御します。
- spawner 自体で対象マスタの役割や強さを変更しません。
- 複数の mob を混ぜる場合、同じ進行帯と戦闘目的に揃えます。
- world の配置条件が決まっていない spawner を先行して量産しません。
- `region` は任意項目とし、同じ地域を担当する複数スポナーには同一の表示名を設定します。未設定スポナーはプレイヤー地域の判定に使用しません。
- オーバーワールドでは、プレイヤーが地域付きスポナーの `radiusMeters` 内へ入ると最も近いスポナーの `region` を現在地域とします。範囲外は「オーバーワールド」を既定地域とします。

## ID とファイル名

- スポナー ID は `<対象ID>_lv<レベル>_spawner`、ファイル名は `v1.<スポナーID>.yml` に揃えます。
- 単一 Mob のスポナーは対象 Mob の ID を使い、レベルは `spawnMobs[].level` と一致させます。
- 同じレベルの複数 Mob を抽選するスポナーは、対象群を表す ID を使います。`eriva_great_forest_lv15_spawner` は2種類の Lv.15 Mob を抽選します。
- ID を変更して実行環境へ反映する場合は、プラグインデータフォルダの `mob_spawners.yml` に保存した配置 ID も新 ID へ移行します。旧 ID を持つ設置アイテムは新 ID のアイテムへ交換します。

## progression

出現対象のうち、標準遭遇段階が最も高いものを基準にします。出現密度によって実質難度が上がる場合は `+1` を検討します。
