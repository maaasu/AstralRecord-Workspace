# Pet 設計

## 役割

Pet は、装備して主人と行動し、長期育成・配合・スキル継承を通じて個体差を伸ばす支援コンテンツです。種類ごとのルールは単一ペットマスター、所有・個体・卵の状態はAPIの個体データで管理します。

## 設計方針

- 卵は敵討伐の共通抽選から低確率で取得し、孵化施設で採集素材を消費して個体を解放します。
- 卵の能力・性別・名前・サイズ・スキル・潜在能力は公開せず、孵化した個体だけが表示対象です。
- 成長度はペットレベルと同じ値とし、主人のプレイヤーレベルと同等の必要経験値曲線を使います。装備中・生存中の実活動で成長し、放置時間は経験値になりません。
- ステータスのティアはそれぞれ独立します。野生抽選の上限と配合の上限を分け、低ティアとティア内の低数値を高い重みで抽選します。
- 配合は同種のオス・メス、必要成長度、生存、クールダウンを検証します。ステータスごとに高い親の基礎個体値を継承し、低確率で上位ティアへ変異します。
- 潜在能力はステータス別の隠しフラグです。成長増分だけに倍率を適用し、該当ステータスを金色に表示します。基礎個体値は倍率の対象にしません。
- スキルは種類ごと8個、各ティア2個、最大3枠とします。野生の1枠目はT0、配合の1枠目は親の習得済みスキルから継承します。
- 2枠目の通常候補はT0〜T1、3枠目はT0〜T2です。1枠目にT2/T3を継承した個体の後続枠ではT0〜T3が候補となり、野生だけではT3へ到達しません。同じスキルは重複習得しません。
- 能力は主人のステータスを飽和式の継承係数で参照します。ペット自身の支援補正を参照元へ含めず、循環増幅を防ぎます。
- 野生由来の卵・個体は譲渡可能、配合由来の卵・個体は他アカウントへ譲渡できません。
- 死亡状態は永続保存し、装備変更では復活しません。施設の素材消費または専用オーブによって復活します。

## progression

孵化素材と施設を利用できる標準段階を基準にします。低確率の卵を早く取得しても、孵化素材によって解放の進行段階を維持します。ペットレベルは `progression` と一致させません。
