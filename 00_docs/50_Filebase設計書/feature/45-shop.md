# Shop 設計

## 役割

Shop は、通貨や item を対価として、購入、売却、交換を提供する定義です。

## 設計方針

- 初期供給、救済、素材消費、交換のどの役割を持つか明確にします。
- loot や recipe の価値を失わせる常時販売を避けます。
- 買値、売値、交換比率は、同じ progression の入手時間と比較します。
- NPC や導線から参照されない shop を作りません。

`astrald_shop` は、1行目のslot 0でストレージ拡張トークンを100アストラルド、slot 1でストレージ遠隔アクセストークンを300アストラルドで販売します。2行目のslot 7〜10にはマーケット拡張トークンα／β／γ／δをそれぞれ50／100／150／200アストラルドで配置します。いずれもGoldを対価に使用しません。

3行目のslot 14〜16には、スキルプリセット解放トークン、パッシブスロット解放トークン、アクティブスロット解放トークンを左から順に配置し、価格は300／500／500アストラルドです。

`skill_gem_raw_exchange` は、初級から神級までの上位原石1個を直下位原石3個へ変換する7段階を扱います。逆方向の交換は持ちません。スキルジェムとスキルジェム交換所は廃止し、スキルマネージャーが各 skill master の `learnRequiredItems` / `levelUpRequiredItems` を正本として原石を消費します。

`rebirth_sigil_shop` は転生NPCの左クリックから開くNPC専用のEXPポイント交換所です。1ページ目はクールダウン短縮を1～2行目、詠唱時間短縮を3行目、ブラギ／ミーミルのオーブを4行目の左右へ配置します。2ページ目は高価格帯のスキルダメージ増加を1～2行目へ配置します。

| 商品系統 | 段階別EXPポイント価格 |
|:--|:--|
| クールダウン短縮 5～50% | `100 / 250 / 500 / 900 / 1500 / 2200 / 3200 / 4500 / 6000 / 8000` |
| 詠唱時間短縮 10～50% | `150 / 700 / 1800 / 4000 / 8000` |
| スキルダメージ増加 10～100% | `2000 / 5000 / 9000 / 14000 / 20000 / 28000 / 38000 / 50000 / 65000 / 80000` |
| ブラギのオーブ | `100` |
| ミーミルのオーブ | `1500` |

### 廃止した skill_gem_exchange

旧 `skill_gem_exchange` の職業別価格は各 skill master へ移行済みです。

## progression

shop を最初に利用可能になる段階を記載します。商品ごとの progression は維持し、shop の progression だけで商品価値を上書きしません。

## アストラルドショップのVIP商品

2ページ目に有償アストラルド (`99a00021`) 専用商品を配置します。優先接続券は5/11/35/60/150回を500/1000/3000/5000/10000個、DONER15日券は1500個、ASTRALDER20日券は3000個です。全商品は使用中アカウントへ適用され、売却・トレードはできません。

## チャンネルブースト商品

3ページ目のslot 0〜4へEXP、slot 7〜11へドロップ、slot 17へスペシャルを配置します。対価はすべて有償アストラルド (`99a00021`) です。

| 種類 | 倍率 | 効果時間 | 価格 |
|:--|:--|:--|:--|
| EXP | 1.1 / 1.2 / 1.3 / 1.4 / 1.5 | 各1時間 | 500 / 600 / 700 / 800 / 1000 |
| ドロップ | 1.1 / 1.2 / 1.3 / 1.4 / 1.5 | 各1時間 | 1000 / 1200 / 1400 / 1600 / 2000 |
| スペシャル | EXP 2・ドロップ 2 | 1時間 | 10000 |

ゲーム内購入ではチケットを受け取り、使用したチャンネルに発動します。Webの有償ショップは同じ商品・価格定義を読み、現在のアカウントの有償アストラルドを消費して選択したチャンネルへ直接発動します。同種ブースト中は追加使用できず、スペシャルはEXP・ドロップの両方が無効な場合に限ります。詳細は消耗品スキーマを正本とします。


## 6職の装備交換

通常装備を先行して供給する公開素材交換所を以下のIDで定義します。`mode: EXCHANGE` / `access: PUBLIC` とし、通常プレイ中の `/shop <ID>` を入手導線にします。防具はLv15以上、武器・補助・アクセサリはLv40以上を対象とし、既存の入手可能な素材とGoldを消費します。新しい敵・ダンジョンの報酬はここでは定義しません。

| 対象 | 交換所ID |
|:--|:--|
| ウィザード | `wizard_equipment_exchange` |
| アークメイジ | `archmage_equipment_exchange` |
| ソードマスター | `sword_master_equipment_exchange` |
| パラディン | `paladin_equipment_exchange` |
| シャープシューター | `sharpshooter_equipment_exchange` |
| ファントムアーチャー | `phantom_archer_equipment_exchange` |

最終装備の状態変化素材も各交換所で供給します。育成用オーブは `/shop equipment_growth_exchange` に集約します。装備は固定能力で販売し、売却によって交換費用を回収できる設定にしません。
