# Shop 設計

## 役割

Shop は、通貨や item を対価として、購入、売却、交換を提供する定義です。

## 設計方針

- 初期供給、救済、素材消費、交換のどの役割を持つか明確にします。
- loot や recipe の価値を失わせる常時販売を避けます。
- 買値、売値、交換比率は、同じ progression の入手時間と比較します。
- NPC や導線から参照されない shop を作りません。

`astrald_shop` は、マーケット拡張トークンに加えて、ストレージクラウドアクセストークン1個を300アストラルドで販売します。いずれもGoldを対価に使用しません。

`skill_gem_raw_exchange` は、初級から神級までの上位原石1個を直下位原石3個へ変換する7段階を扱います。逆方向の交換は持ちません。`skill_gem_exchange` は、使用許可の区分に応じて、冒険者で使用できるスキル（冒険者スキルツリーの解放を含む）は無印原石1個、上位職で最初から使用できるスキルは無印原石2個、上位職のスキルツリー解放が必要なスキルは無印原石3個から各自動生成スキルジェム1個へ交換します。`administrator_shield_recharge` と `swordsman_shield_activate` はソードマンのスキルツリー解放対象として、無印原石3個からジェム1個へ交換します。初級原石からジェムへの交換は持ちません。

### skill_gem_exchange の職業別配置

`skill_gem_exchange` は1ページ目の7列×4行へ、左上を slot 0 として左から右、上から下の順に配置します。職業ごとの配置は次のとおりです。

- 1行目（slot 0〜6）: メディテーション、アストラルエッジ、スマッシュ、ブラストアロー、クイックショット、ライトニングボルト、マナバースト
- 2行目（slot 7〜13）: シールドドレイン、チャレンジングロア、フレイムラッシュ、バスティオンストライク、シールドリチャージ、ラストシールド、シールドアクティベート
- 3行目（slot 14〜20）: アローレイン、フェイドショット、ヒールアロー、クラッシュアロー、スペルステップ、空き、空き
- 4行目（slot 21〜27）: ファイアーボール、ヒールオーラ、スパーキング、フロストブリザード、アーケインフロー、フロストボール、空き

## progression

shop を最初に利用可能になる段階を記載します。商品ごとの progression は維持し、shop の progression だけで商品価値を上書きしません。
