# Currency 設計

## 役割

Currency は、交換、通行、討伐証明などに使用する item 形式の通貨・証です。

## 設計方針

- 入手元と主な消費先を少なくとも1つずつ成立させます。
- 同じ用途の currency を別名で重複させません。
- 期限を設ける場合、失効日時と交換終了の運用を同時に確認します。
- 通常 item と異なる管理挙動は Plugin の実装済み範囲だけを使用します。

ストレージ遠隔アクセストークンは、所持している間、ショップの必要素材が通常インベントリになくてもストレージから直接使用できることを表すシステム用の証として、`astrald_shop` から300アストラルドで入手します。ストレージ拡張トークンは、`CURRENCY` inventory の所持数1個につきストレージの最大ページ数を1ページ拡張する証として、同ショップから100アストラルドで入手します。ストレージの基礎上限は5ページです。

スキルプリセット解放トークンは、`CURRENCY` inventory の所持数1個につき未解放プリセットを1つ解放し、最大6個分まで反映します。パッシブスロット解放トークンとアクティブスロット解放トークンは、所持数1個につき対応する使用可能枠を1つ増やし、合計12枠を上限とします。3種とも所持中に効果を発揮し、`astrald_shop` からそれぞれ300 / 500 / 500アストラルドで入手します。

## progression

最初に標準入手できる段階を基準にします。複数進行帯で使う場合も値を都度変更しません。
