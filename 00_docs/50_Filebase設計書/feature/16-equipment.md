# Equipment 設計

## 役割

Equipment は、装備中のステータス、武器タグに応じた通常攻撃、操作、採集能力などを変化させる item です。装備ごとに主役となる用途を明確にします。`SKILLBOOK` だけは装備中にマスタ指定スキルの使用許可を与えます。

## 装備カテゴリ

| カテゴリ  | 主な役割                | 主に想定するステータス                     |
| :---- | :------------------ | :------------------------------ |
| 近接武器  | 近距離の通常攻撃・近接 skill   | `MELEE_ATTACK` を中心とする近接系        |
| 遠隔武器  | 距離を保った通常攻撃・遠隔 skill | `RANGED_ATTACK` を中心とする遠隔系       |
| 魔法武器  | 魔法 skill とリソース運用    | `MAGIC_ATTACK`、`MAX_MANA` など    |
| 補助装備  | 主武器の補助、防御、操作追加      | 主武器を補完する防御・補助系                  |
| 防具    | 被ダメージ抑制と生存方針        | `DEFENSE`、`MAGIC_DEFENSE`、リソース系 |
| アクセサリ | ビルドの補強・特化           | 装備種別の役割に応じた少数のステータス             |
| ツール   | 採集など戦闘外の機能          | Plugin が対応する用途タグと関連能力           |
| スキルブック | 指定スキルの使用許可 | スキルの習得・バインド条件は従来どおり |

使用可能な slot、hand type、accessory slot、tool/accessory tag は本書へ複製せず、正本参照先を確認します。

## 装備可能数

- 通常装備の slot と装着動作は Plugin の `ItemEquipmentSlot` と inventory 実装を正とします。
- アクセサリの種類別装備可能数は Plugin の `AccessorySlotType` を正とします。
- 装備可能数が多いカテゴリほど、1個あたりの性能配分を小さくします。

## ステータス

- 主役となるステータスは1〜2種類を基本とします。
- 近接武器は `MELEE_ATTACK`、遠隔武器は `RANGED_ATTACK`、魔法武器は `MAGIC_ATTACK` を主攻撃力として設計します。共通の `ATTACK` を追加する場合は、全攻撃種別へ影響させる意図を明示します。
- 特定ステータスへ触れることはできますが、使用可能な一覧は `StatusType.kt` を正とします。
- 固定値とランダム範囲は、同じ進行度・レアリティの装備間で期待値を比較できるようにします。

近接防具は、Shield破壊後の生存を `DEFENSE` / `MELEE_DEFENSE` で支え、`MP_REGEN` は魔法防具より控えめな副性能として配分します。`MOVEMENT_SPEED` は装備・アクセサリともに過剰な上昇を避け、職業別の `MOVEMENT_SPEED_CAP` で実速度を制限します。

### 今後作成する装備の個体差

今後新規に作成する戦闘用 equipment は、同じマスタから得た個体にも選択の余地が生まれるよう、基礎ステータスのランダム値とエンチャント可能枠を標準とします。武器・戦闘用補助装備ではルーン枠も標準とします。防具・アクセサリにも基礎ステータスのランダム値とエンチャント可能枠を適用し、複数部位で成立するシリーズにはセット効果を設計します。防具・アクセサリのルーン枠は必須ではなく、他の個体差やセット効果との役割を見て省略することが多いものとします。この方針は新規マスタの作成判断に使い、既存マスタを一律に書き換える指示ではありません。

| 対象 | 新規作成時の判断 |
|:--|:--|
| 武器・戦闘用補助装備 | 主役となる基礎ステータスに個体差を持たせ、エンチャント可能枠とルーン枠を設けることを基本とする。 |
| 防具 | 防御・生存上の役割に沿って基礎ステータスをランダム化し、エンチャント可能枠を設ける。組み合わせて装備するシリーズならセット効果を設ける。ルーン枠は他の成長・選択要素を見て判断する。 |
| アクセサリ | 装備可能数と用途を踏まえて基礎ステータスをランダム化し、エンチャント可能枠を設ける。組み合わせて装備するシリーズならセット効果を設ける。ルーン枠は用途上の理由がある場合に設ける。 |

- ランダムな基礎ステータスは、マスタの `equipment.stats[].value` に定義した範囲から装備個体の生成時に確定する値です。ステータスの種類や行数を抽選する追加効果（affix）ではありません。固定したい補正は同じ `stats[]` に固定値で残せます。対応する記法と個体ごとの確定方法は [equipment YAML スキーマ定義](../../../40_filebase/10.features.item/20.equipment/docs.equipment.YAMLスキーマ定義.md) を正とします。
- エンチャントは基礎ステータスの抽選と別の仕組みです。装備の `enchant.maxSlots` は後から付与できる枠数を定め、付与候補・重みは装備種別ごとの共通 enchant マスタ、付与操作は enchant orb が定めます。`enchant` を書くだけで生成時に効果が自動付与されるわけではありません。対象装備種別に有効な共通候補と入手機会も確認します。
- ルーンは装備の `rune.maxSlots` で装着可能数を定めます。個体ごとに枠数も変えたい場合だけ、スキーマが認めるランダム範囲を使います。ルーン自体の適合条件・入手機会を確認し、装着できない枠を形式的に付けません。
- セット効果は同じ `setId` を持つ複数の装備と set effect マスタで構成します。成立可能な部位・入手段階を確認し、段階効果の累積を含めて単品性能、ランダム値、エンチャントとの合計を評価します。単品で完結する装備に架空のセットを作りません。
- 固定値または各枠の省略は、支給・チュートリアル装備、機能優先のツール、スキル使用許可が目的のスキルブック、性能を一定にする理由のある固有品などで選べます。理由はその装備の役割・入手経路・Plugin の対応機能から判断し、単に既存の固定値マスタを写すことを理由にしません。ノクスの初回武器更新など、既に定めた個別条件を優先します。
- 値や範囲、枠数、セット効果量は一律の予算で決めず、同じ progression・レアリティの代替装備、最も早い入手経路、装備可能数、強化後の性能と合わせて戦闘バランス設計書で検証します。

### ノクスの初回武器更新

ノクスソード・ノクスボウ・ノクススタッフは、プレイヤー Lv.2 相当を目標とする初回武器更新です。主攻撃力は3種とも固定 `17` とし、ランダム値を持たせません。強化上限は Lv.10、各強化段階の主攻撃力増加は `+1` 固定です。したがって最大強化時の主攻撃力は `27` となります。副ステータスは武器種別の役割を維持するため、各マスタの既存値を使用します。

## レアリティと progression

- progression は標準入手段階、レアリティは同段階内の希少性と性能配分を表します。
- 攻略前に得る標準装備は対象コンテンツの `P-1` から `P` とします。
- 対象コンテンツから得る更新装備は `P` から `P+1` とします。
- レアリティだけを理由に、複数段階先の装備性能を与えません。

## 強化・セット効果・特殊効果

- 強化は同じ装備を継続利用する手段とし、無強化時の役割を変えません。
- 状態変化は現在状態の強化上限到達後に状態変化オーブから確認画面を開き、`requiredEnhanceLevel`、必要素材、必要通貨を満たした即時次 rank へ進めます。
- `requiredLevel` はプレイヤーレベル、`requiredClasses[].level` は現在選択中クラスのクラスレベルとして判定します。条件未達装備は装備由来性能を発揮しません。
- セット効果は複数部位を固定するコストに見合う効果とし、単品装備の主役を残します。
- 装備の `enchant` は `maxSlots` だけを持ち、抽選候補は `12.features.enchant` の共通マスタへ定義します。装備個別のプール・素材・通貨は定義しません。
- 強化レベルは `successRate` と `failAction`（`NONE` / `SET_LEVEL` / `DECREASE_ONE`）を持ちます。強化素材・通貨は定義せず、試行に使うオーブ1個だけを消費します。

### 強化成功率の標準値（状態変化前 / rank 0）

`levels[].successRate` は、現在の強化値からそのレベルへ強化する試行の成功確率を、`0.0` から `1.0` の小数で指定します。ノクス装備を除く `slot: WEAPON` と通常防具（`HEAD` / `CHEST` / `LEGS` / `FEET`）では、状態変化前の rank 0 に次の標準値を適用します。

| 強化先レベル | `successRate` | 成功率 |
|:--:|--:|--:|
| `+1` | `1.0` | 100% |
| `+2` ～ `+4` | `0.75` | 75% |
| `+5` ～ `+6` | `0.50` | 50% |
| `+7` ～ `+8` | `0.35` | 35% |
| `+9` | `0.20` | 20% |
| `+10` 以上 | `0.05` | 5% |

今後追加する強化対応の武器・防具も、ノクス装備を除き、状態変化前（rank 0）の各強化レベルで少なくともこの基準を満たす値を明記します。状態変化後（rank 1 以上）で追加される強化レベルの値は、状態変化後の個別設計として定義します。

- enchant、rune、transcendence は、Plugin と各スキーマに存在する仕組みだけを使用します。`SKILLBOOK` の `usableSkills` 以外の装備・rune・セット効果には skill 使用許可を定義しません。
- 特殊効果を持たせる場合、発動条件、対象、頻度、代替できない理由を明確にします。

## カルトグラフ

`20a00042` (`cartograph`) は共有equipment tag `CARTOGRAPH` を持つ、1スタックの再利用可能な `TOOL` です。最大耐久は300、`durability.consume` は75です。今回、loot・shop・quest・recipe等の入手経路は追加しません。

- ダンジョン内のmain hand右クリックは、装備instanceへ現在のdungeon session mapをメモリ登録してGUIを開きます。
- 新規session登録時だけ現在耐久75以上を要求して固定75を消費します。同じsessionの再表示は消費せず、残耐久0でも可能です。同じmasterでもsessionが異なれば新規登録です。
- session離脱・終了・失敗・logoutで登録を削除します。登録情報をitem PDCへ永続化しません。
- ダンジョン外ではaccountの踏破済みdungeonと設定報酬・数量・確率を表示します。
- 耐久は既存の装備instance耐久として管理し、generic repair orbで回復できます。将来の状態変化による最大耐久拡張は今回定義しません。

## フックショット

`20a00043` (`hookshot`) は共有equipment tag `HOOKSHOT` を持つ、crossbow iconの1スタック `TOOL` です。最大耐久は200、`durability.consume` は1です。今回、loot・shop・quest・recipe等の入手経路は追加しません。

- 未装填のmain hand左クリックは1.5秒（30 tick）の装填を開始する。装填中は通常移動速度を50%低下させ、ActionBarへ残り時間と進捗を表示する。右クリックは何も発動しない。装填開始・中断では素材も耐久も消費しない。
- 装填完了時だけ `10a00057` materialを1個消費し、個体のinventory entry metadataへ装填済み状態を保存する。装填済みのフックは取り外せず、通常の持ち替え・収納・再ログイン後も状態を保持する。
- 装填完了時に現在の照準が最大24 block先までの最初の固体blockへ命中する場合は自動発射する。発射時だけinstance耐久を1消費して装填状態を外す。照準失敗・耐久不足では装填状態と耐久を保持し、次のmain hand左クリックで発射を再試行する。
- プレイヤーをteleportせず、現在velocityの前方成分を維持し横方向だけを減衰しながら、距離比例のアンカー方向加速を加える。衝突・重力・落下はゲーム物理に従う。牽引は最大44 tick、速度上限は2.05である。
- 命中面には短命の金属格子型BlockDisplay、プレイヤーとアンカーの間にはparticle tetherを表示します。素材 `10a00057` のiconは `TRIPWIRE_HOOK` ですが、アイテム専用MaterialのためBlockDisplayには使いません。
- 耐久は既存の装備instance耐久として管理し、generic repair orbで回復できます。

## 不死鳥との共鳴のスキルブック

`20a00070` は `ENCHANTED_BOOK` をアイコンに使う `SKILLBOOK` 装備です。プレイヤーLv.25以上、現在クラスが `archmage` または `arc_sage` の場合に装備でき、装備中は `skill:archmage_phoenix_resonance` の習得・使用を許可します。習得時の初級原石15個、レベルアップ時の中級原石1個、パッシブバインドはスキルの定義どおり必要です。強化・エンチャント・ステータス補正は持ちません。

## 入手方法の確認

- 入手前に攻略が必要な対象と、その装備で攻略させたい対象が逆転していないこと。
- loot、recipe、shop、quest の複数経路を設ける場合、最も早い経路を progression の基準にすること。
- オーブやセット構成品が、装備本体より大きく後の段階に偏っていないこと。

## Mob/Bossドロップ方針

- 武器は Mob ドロップ対象とし、ドロップ時は武器専用 Bundle に梱包する。
- 防具は通常 Enemy からドロップさせず、Boss からのドロップは例外として許可する。供給は素材交換ショップを基本とする。新規防具の基礎ステータスは、ショップ・Boss のどちらから得る場合も前述の個体差方針を基準にし、固定値にする場合は装備の役割から判断する。
- アクセサリは Enemy / Boss からドロップ可能とする。新規アクセサリの基礎ステータスは入手元だけで固定値にせず、前述の個体差方針を基準にする。Boss ドロップ時のみ専用 Bundle に梱包する。
