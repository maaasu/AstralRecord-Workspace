# チャプターガイド設計

## 画面と操作

メニューの「ガイド」と `/guide` はチャプター一覧を開きます。第1章「グラスボアを1体倒そう」を選ぶと、次の操作と6手順の達成状態を確認できます。

| 手順 | 次の操作 |
|:--|:--|
| 1 | 案内具でメインメニューを開く |
| 2 | メールから初ログイン記念の贈り物を受け取る |
| 3 | 持ち物の初ログインバンドルをホットバーに入れ、手に持って開封する |
| 4 | 雑貨商ミナから簡素な武器を購入する |
| 5 | 簡素な武器を主手に装備する |
| 6 | ミズガルズの緑野でグラスボアを1体倒す |

一覧のタイトルに章名と達成数、詳細のタイトルに章番号・達成数・次の操作を表示します。詳細の6枠は手順の順番に並び、緑の染料は完了、星は現在、灰色の染料は今後の手順を表します。現在の星と中央のボタンは同じ操作に進みます。6手順が揃うと「チャプター完了」を表示します。

## 進行と報酬

- マスターは `beginner_onboarding` です。保存はSQL Serverのアカウント別・ガイドID別・手順ID別の記録を使います。先に武器を購入するなど順番を前後して達成しても、分子は実際の達成数で、現在の案内は最初の未達成手順です。
- APIとPluginは公開中の第1章を読み込みます。廃止されたテーマ別ガイドのDB行は一覧・完了・報酬の条件から外れます。過去の達成履歴と請求済み報酬の受領記録は引き継ぎます。
- 6手順の完了後、報酬設定と受領可否を確認できた場合に一覧・詳細の宝箱から請求できます。既存のアカウント別請求記録を使い、報酬をメールで受け取ります。
- 旧導入の21手順をすべて終えたアカウントは、新旧で共通のIDと追加2手順の補完によって完了扱いになります。初回メール対象外・受取済みの場合の補完は、参加時に `GET /api/mail/welcome-tutorial-status` の結果と所持品を照合します。
