# Guide 設計

## 役割

Guide は、ゲーム内 GUI で操作手順と達成状態を案内する順序付きチェックリストです。

## 設計方針

- 1つの guide は1つの操作または判断目的に絞ります。例外として、冒険開始から最初の戦闘準備までを一貫して案内する導入ガイドは、連続した1つの目的として扱います。
- 1つのguideは1つ以上のstepを持ち、記載順に達成します。
- 各stepはPluginが解釈する宣言的なconditionを1つ持ちます。
- マスタ名は参照記法を使い、表示名を本文へ固定しません。
- Plugin の画面配置やページングを YAML 側へ重複定義しません。
- 実装済みの機能と参照先だけを案内します。
- プレイヤーごとの達成状態はSQL Serverへ保存し、マスターには保持しません。
- 導入ガイドのように連続した体験を扱う場合も、ログイン、受取、購入、戦闘、採集などの達成判定は実際に成功した操作だけを使用します。

## progression

説明対象を初めて利用する直前の段階を基準にします。進行に依存しない常設ヘルプは `0` とします。
