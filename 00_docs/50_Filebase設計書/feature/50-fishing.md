# 釣りマスタ設計

釣りは魚（`44.features.fishing.fish`）、ワールドと竿の釣りレベル別抽選（`46.features.fishing.area`）、共通挙動（`47.features.fishing.rules`）に分ける。ファイル構造と数値境界は各カテゴリの JSON Schema と YAML スキーマ定義を正とする。

初期釣果は川ダラ、川サケ、彩りの熱帯魚の素材アイテムで、各魚が保証釣果 1 個を付与する。開始時のルールは `default` で、探索半径 10、周囲の魚 4～6、待機 1200 tick、食いつき 45 / 35 / 25％（魚別）。ゲーム内の追加用途が定まるまでは売却可能素材として扱う。

初期釣り場は `verdia`、`midgard_greenfields`、`vanaheim_supercontinent` の冒険用オーバーワールド 3 つ。有効釣り場を各 world に 1 件配置し、レベル帯 0～2147483647 に魚 3 種を割り当てる。開始時の出現抽選率は順に、ヴェルディア 70/25/5、ミズガルズ 55/35/10、エリヴァ 40/40/20％。最終釣果率は食いつき確率と釣り操作にも左右される。拠点、ボス、作業用ワールドは釣り場に含めない。これらの値は初期バランスであり、後続の釣りレベル帯調整は levelRanges で行う。
