# アカウント進行プリセット

開発環境で、プレイヤーレベル1〜50の戦闘状態を職業・ビルドごとに再現します。適用先は管理者権限を持つ実行者が選択中の通常プレイヤーアカウントです。

- 職業の成長と装備の更新は既存の成長曲線、装備条件、職業ごとの戦闘設計を基準にする。
- 上位職もレベル1から検証できるように、プリセットで選択し、前提職の進行を用意する。
- スキルツリーの接続、必要ポイント、装備条件、発動可能なスキルを同じ構成内で満たす。
- アクションリングの1番枠には適用直後に試せるアクティブスキルを登録する。

マスターデータエディタの「アカウント進行プリセット」で構成を編集します。定義形式は [YAMLスキーマ定義](../../../40_filebase/36.features.progression_preset/docs.progression_preset.YAMLスキーマ定義.md) を参照してください。
