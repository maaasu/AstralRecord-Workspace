# アカウント進行プリセット

開発環境で、プレイヤーレベル1〜50の戦闘状態を職業・ビルドごとに再現します。適用先は管理者権限を持つ実行者が選択中の通常プレイヤーアカウントです。

- 職業の成長と装備の更新は既存の成長曲線、装備条件、職業ごとの戦闘設計を基準にする。
- 上位職もレベル1から検証できるように、プリセットで選択し、前提職の進行を用意する。
- スキルツリーの接続、必要ポイント、装備条件、発動可能なスキルを同じ構成内で満たす。
- アクションリングの1番枠には適用直後に試せるアクティブスキルを登録する。Java版では適用後の最初の武器右クリックで発動する。
- 強化値とシジルは個体に適用する。装備の入手順と、渡航・転生を仮定する段階は [ゲーム進行順と装備の入手](../../60_戦闘バランス設計書/06-ゲーム進行順.md) に従う。

マスターデータエディタの「装備・入手経路」で、選択した職業・ビルド・適用開始レベルの装備とアカウント進行を一緒に編集します。職業レベル、習得ノード、アクティブ・パッシブの割り当て、スキルレベル、装着シジルは同じチェックポイントへ保存します。「マスターデータ」の「アカウント進行プリセット」カテゴリでもフォーム・原稿編集を利用できます。定義形式は [YAMLスキーマ定義](../../../40_filebase/36.features.progression_preset/docs.progression_preset.YAMLスキーマ定義.md) を参照してください。

保存先は `40_filebase/36.features.progression_preset` です。プリセットはアカウント進行機能が適用する構成全体を所有し、アイテム・スキル・ノードなどの個別マスターを参照します。複数機能が部品として参照する共有の報酬表やレシピとは用途が異なるため、`shared` 配下には配置しません。APIとプラグインのruntime-filebase、およびエディタはこの機能カテゴリを同じパスで読み込みます。

強化値・シジルを含む定義を配備するときは、それらを読めるプラグインと同じ更新で反映します。
