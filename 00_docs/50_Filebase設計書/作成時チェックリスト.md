# Filebase マスタ作成時チェックリスト

## 作成前

- [ ] `README.md` と対象の `feature/<number>-<category>.md` を読んだ。
- [ ] 対象カテゴリの `YAMLスキーマ定義.md` を読んだ。
- [ ] feature 文書に記載された Plugin ソースと Plugin 設計書を確認した。
- [ ] 近い用途の既存 YAML を確認した。
- [ ] ID が既存マスタと重複していない。
- [ ] マスタの役割を一文で説明できる。
- [ ] モチーフを、変更されにくい題材分類と核へ絞った。
- [ ] 進行度を、入手元・攻略対象・消費先・報酬先との関係から決めた。

## 作成中

- [ ] YAML 先頭に `motif` と `progression` の設計コメントがある。
- [ ] コメントに現在の配置場所、将来予定、調整履歴を書いていない。
- [ ] 使用する列挙値とステータスが Plugin ソースに存在する。
- [ ] スキーマにない項目を追加していない。
- [ ] 参照先 ID が存在し、参照方向が循環していない。
- [ ] 数値は進行度、カテゴリの役割、レアリティ、入手難度から説明できる。
- [ ] 複数の主役を持たせず、カテゴリ文書で定めた役割へ寄せている。
- [ ] プレイヤー表示文は日本語で、ゲーム内 UI に収まる長さになっている。

## 進行度の確認

- [ ] 攻略前に必要な装備・消耗品は、対象モブやコンテンツ以下の進行度になっている。
- [ ] 通常素材は、主な入手元と同程度の進行度になっている。
- [ ] 更新装備や希少報酬は、入手元と同値から `+1` を基準にしている。
- [ ] recipe 出力が入力素材より大きく先へ飛んでいない。
- [ ] shop、quest、loot が本来の攻略順を迂回させていない。
- [ ] 標準関係から外す場合、その理由をマスタの役割として説明できる。

## 作成後

- [ ] YAML を再読し、ID、表示名、参照、数値、コメントを確認した。
- [ ] 関連する loot / recipe / shop / quest / spawner から参照可能である。
- [ ] 未実装の Plugin 機能や未定義スキーマを前提にしていない。
- [ ] 個別ワールド設定を共通設計書へ追記していない。
- [ ] Plugin/API/Resource Pack の変更が必要な場合、filebase 変更と分けて残事項へ記載した。
