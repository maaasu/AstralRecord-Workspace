# モチーフ選定ガイド

## 1. 目的

マスタデータへ一貫した着想を与えつつ、個別ワールド設定や変更されやすい用途説明を設計コメントへ持ち込まないための情報選定ルールです。

## 2. 題材の候補

- 神話・伝承: 北欧神話、日本神話、民間伝承など
- 世界遺産・建築・地形: 遺跡、都市、庭園、山岳、洞窟など
- 都市伝説・怪談・未確認現象
- 天体・気象・鉱物・植物・動物
- 工芸・航海・交易・音楽・記録媒体

題材の分類そのものをゲーム内設定にはしません。マスタを考えるための入口として使用します。

## 3. 情報の絞り方

題材から採用する情報は、次の3点までに絞ります。

1. 固有の核: 樹木、狼、塔、霧、鐘など、題材を識別できる短い要素
2. 性質: 成長、反響、循環、守護、浸食など、性能へ変換できる性質
3. 視覚要素: 色、材質、輪郭、光り方など、名称や Resource Pack の方向性に使える要素

原典の筋書き、人物関係、結末、長い説明は持ち込みません。既存作品の固有表現や文章を複製せず、一般的な題材として再構成します。

## 4. motif コメント

`motif` には題材分類と核だけを記載します。

```yaml
# design:
#   motif: "北欧神話 / 世界樹"
#   progression: 12
```

良い例:

- `北欧神話 / 世界樹`
- `世界遺産 / 石造水道橋`
- `都市伝説 / 消える乗客`
- `鉱物 / 蛍石`

避ける例:

- `第2ワールドの森でドロップする予定`
- `将来は強化素材にする`
- `現在は序盤向けだが後で調整する`
- `○○を倒すために必要`

用途や実装が変わり得る文は、モチーフコメントには記載しません。

## 5. マスタへの変換

- item / material: 核となる物質、形状、由来を名前と見た目へ使います。
- equipment: 題材の性質を、装備の役割や主ステータスへ1つだけ対応させます。
- skill / buff: 題材の動きや性質を、効果の方向へ変換します。
- mob / boss: 題材の輪郭、行動、象徴を戦闘上の役割へ変換します。
- world / dungeon: 複数マスタを束ねられる景観・環境要素だけを採用します。

題材を採用したことだけを根拠に、カテゴリの役割や進行度から外れた強さを与えません。
