## 個体差・属性確率

武器は対応主攻撃 `180 + [-9,9]` を1刻み（19候補、171〜189、期待180）、STR/DEX/INTの対応能力 `14 + [-2,2]` を1刻み（5候補、12〜16、期待14）。主値・副値・属性は、既存実装の装備生成時に一度だけ確定する。装備個体の再読込や戦闘ごとの再抽選を定義していない。

| 武器 | 属性候補2種 |
|---|---|
| ソード/ハンマー/スピア | 火・雷 |
| ショートボウ/ロングボウ | 氷・雷 |
| ワンド/スタッフ | 火・氷 |

各属性行は `value: 0`、`offsetMin: 0.1`、`offsetMax: 7`、`step: 0.1`、`zeroChance: 0.96`。96%で0、残り4%で0.1〜7.0%の70候補を等確率で選ぶ。各非0候補の無条件確率は `0.04/70 = 約0.0571429%`、1行の期待値は `0.04 × 3.55 = 0.142` ポイント。内部値7は7%、10なら10%を意味する。属性2種は別属性の攻撃成分へ作用し、一つの属性へ最大14%を足す構成ではない。

独立2行の確率は両方0が92.16%、ちょうど1行非0が7.68%、両行非0が0.16%、少なくとも1行非0が7.84%。候補属性が生成時に常時付くわけではない。

## 強化・進化と総合性能

通常強化上限+15、進化rank1の条件も+15。進化は上限+30と表示名だけを変更し、エンチャント3枠・ルーン1枠を増やさない。

- 防具DEF: +1〜15の頭/胸/脚/足は毎段階+2/+3/+2/+1、+16〜30は+1/+2/+1/+1。系列合計の加算は+15で120、+30で195。近接DEFは+15で484〜516、+30で559〜591。遠隔は449〜481/524〜556、魔法は424〜456/499〜531。副リソース・回復は強化しない。
- 強化成功率: +1=100%、+2〜4=75%、+5〜6=50%、+7〜8=35%、+9=20%、+10〜30=5%。失敗動作NONE。強化費用を装備YAMLへ追加せず、既存の対応オーブを1試行1個消費する。
