# B02 平原の中位帯

共通基点 `e2058ade10a682118382e70aa01c7db758ac81c6`。所有はヒダマリウサギ、カゼトカゲ、素材 `10a00210` / `10a00211`、各専用 Executor、バッチ資料・専用検証のみ。中央登録、既存マスタ、共有 loot、buff、properties、POM、全 spawner、管理表は変更しない。

## 2種の対処

ヒダマリウサギは小型で速く、防御とHPが低い近接敵。通常攻撃は1.7m・28tick間隔。固有技「跳び蹴り」は12tick詠唱後に進路を10tick予告し、詠唱開始方向へ最大4mを8tickで跳ぶ。最高0.7mの弧に沿って実体を動かし、主対象のhitboxに一度だけ近接・無属性95%で攻撃する。命中拡張は0.2m、壁や崖で停止する。主対象へ追い直さず、横への回避で空振りする。再使用140tick・発動4.5m。

カゼトカゲは標準HPで、通常攻撃1.9m・32tick間隔の近接敵。固有技「風払い」は12tick詠唱後に120度・半径3.4mの扇を14tick予告する。詠唱開始方向を固定した扇と実hitboxの重なりで、プレイヤーと召喚ペットだけを一度ずつ近接・無属性80%で攻撃する。壁越しや上下1.25mを越えて体が離れた対象は命中しない。回避成功・ダメージ無効には押し戻しを与えず、移動可能な命中対象だけを外向き0.35、上向き最低0.1の速度で押す。横や背後へ回り込むと避けられる。再使用150tick・発動3.4m。風は演出と押し戻しを表し、存在しないWINDダメージ属性は追加しない。

両技とも標準 `MobSkillService` の詠唱・クールダウンを使用する。実効果の予告中は `scriptedAction` で通常AIを止め、pathfindingと水平移動を停止する。同じ個体の重複技は開始しない。毎tick、instance同一性、COMBAT、HP、実体、生存、標的資格・target UUID、同一world、AI・詠唱・攻撃・移動可否を確認する。外力で予告位置から0.75m超ずれた時も中断する。終了、空振り、失敗、例外でタスクと保持参照、AI停止を解除する。死亡・despawnはdestroy callback、Plugin停止はstop callbackの中央接続が必要。`registration_manifest.yml` に正確な呼び出しを記載した。

命中率は全個体95。種内の最大最小差は6、上限34。各種の低レベル共通定義とLv30/32/34のprofileを使う。全profileでHP/攻撃/防御/経験値を上げ、固有技、素材、役割を継承する。未定義レベルのfallbackを配置根拠に使わない。

数値の正本は `00_docs/60_戦闘バランス設計書/02-成長曲線.md` §4 と既存 `v1.eriva_camouflage_zombie.yml`。迷彩ゾンビはLv28 HP16600/攻撃3007/防御2896、Lv30 HP19000/攻撃3442/防御3318、通常30tick・移動95・回避3。ウサギは同基準のHP85%/攻撃85%/防御80%へ抑え、速さと回避へ役割を配る。トカゲはHP100%/攻撃95%/防御90%で、長い通常間隔と回避可能な範囲技を組み合わせる。

Lv30超の公式アンカーは未定義なので、迷彩ゾンビLv26→28→30のHP増分+2400とレベル幅2ごとの増分+200を延長し、Lv32を21600、34を24400とした。攻撃は直近+435/2Lv、防御は直近+422/2Lvを延長し、Lv32の基準3877/3740、34の基準4312/4162に種別倍率を適用して整数へ丸めた暫定値。HP/攻撃/防御を一律の成長係数にはしない。経験値は既存+40/2Lvを維持し、単体型は基準-10、範囲型は+10。

Lv30標準HP19000を6秒で削る実効DPS3167を仮置きすると、HPだけの参考TTKはウサギ5.10秒、トカゲ6.00秒（防御・回避・skill選択を含む実測ではない）。成長曲線の通常敵目標5〜7秒に置く。`01-戦闘計算.md` の防御減衰と `MobCombatService` の攻撃間隔を使う実戦DPS/耐久確認は親へ残す。既存棘牙狼は6m/120tick/詠唱16tick/85%の突進を持つ。ウサギは進路を短縮しCDと予告を増やしたうえで95%、トカゲは3.4mの扇と押し戻しに対し80%・CD150tick・合計26tick予告で強さを抑える。

Lv30プレイヤーのHP9500・有効防御D3442、回避3.5を仮置きし、命中率を95-3.5=91.5%とする。近接の減衰式は `F=(1-(D/R)/2.5)^G`、`G=log(0.5)/log(0.6)`（D/R<2.5）。会心・追加倍率なしで通常DPSを `R*F*0.915/(通常間隔/20)`、技DPSの上限を `R*技倍率*F*0.915/(CD/20)` として試算する。

RABBIT_HIDEは既存素材で使用済みだが、ウサギの毛という明確な題材に適しているため再利用する。TURTLE_SCUTEは作成時点の既存itemに未使用で、爬虫類の薄いウロコに合う。両素材とモブは相対的な遭遇段階progression20で揃える（Lvとは別概念）。ウサギはRABBIT/BROWN/scale1.25。トカゲは尾のある小型の地上モデルとしてSILVERFISH/scale2.0を使用し、専用Resource Packは追加しない。図鑑iconは対応するspawn egg。

## 専用検証

`verify_batch.py` は変更YAMLの重複キー、全filebaseのnamespace ID、8profile・level幅、stat/tag存在、素材参照、予約ID、manifest一致、所有diffを検証する。`WindTailGeometryCheck.java` は本番Executorから扇の幾何メソッドを読み出して一時コンパイルし、12個の命中境界と4個のPaper Materialを検証する。恒久の個別Mob JUnitは追加しない。
