# B01 クサハウンド・ヤブガニ

共通基点: `e2058ade10a682118382e70aa01c7db758ac81c6`。所有範囲は新規2種・素材3件・各種Executor・このB01資料だけ。中央登録は統合担当へ渡す。専用loot/buffは不要で、既存の直接drop形式を使う。既存Mob・共有lootは変更しない。

## クサハウンド

草色の猟犬。近接2m、通常36tick、速度120。「草走り突進」は5.25m以内で16tick詠唱、10tickの二列の直線予告後、詠唱開始時の方向へ0.75m/2tick、最大7区間（5.25m）。主対象の現在hitboxへ区間ごとに判定して、一度だけ近接・無属性90%を適用する。途中で追尾方向を更新しないため、予告線の横へ移動すると避けられる。通常ダメージ経路が命中・会心・防御・Shieldを処理する。

予告線16点は初回・4tick・8tickだけ、突進の残像は2区間ごと。共有粒子と唸り声を使う。hitboxの拡張は水平0.2m・垂直0.3m。前進全体の衝突形状を0.15m以下で刻んで確認し、壁、未読込chunk、world上下限・水平WorldBorder、足場欠落で停止する。標的の高低差1.25m超も中断する。CD140tickは詠唱開始から既存MobSkillServiceが管理する。

## ヤブガニ

草むらの小型甲殻類。カニのバニラモデルがないため、低いSILVERFISH実体を採用。近接1.8m、通常40tick、速度78。「横ばさみ」は3m以内で12tick詠唱、20tickのV字予告後に左右を同時に閉じる。予告開始時の足元と詠唱開始方向を固定し、左右1.5m・前方0.6mから前方2.7mへの二本の斜線で判定する。軌道の外や背後へ回ると回避できる。円形・距離だけの攻撃にはしない。

対象の現在hitboxを水平0.3m・垂直0.4m拡張し、有限線分と照合する。有効なプレイヤー・召喚ペットだけを候補とし、高低差1.25m超と壁越しを除く。命中候補を距離順・UUID順で最大4対象、各1回だけ近接・無属性105%で攻撃する。左右の交点にいても二重命中しない。CD160tick。予告14点は初回・5/10/15tickだけ、20tick時に一度衝撃を描画する。

## 共通の継続・解除

専用行動は個体UUIDごとに保持し、scriptedActionで通常AIと通常攻撃を止める。開始時はstopHorizontalMovementで旧経路・水平速度を停止する。予告位置からクサハウンドが0.4m超、ヤブガニが0.75m超移動させられた場合も中断し、離れた場所から攻撃しない。

各taskはMob登録同一性、COMBAT状態、独自HP、実体生存、対象UUID同一性、DamageService.isMobCombatTarget、同一world、行動可能・詠唱可能・攻撃可能を再検査する。クサハウンドは移動可能も必要。死亡/despawn/帰還/標的死亡・logout・変更/状態異常/world移動は次のtask tickまでに終了し、task・個体参照・scriptedActionを解除する。正常終了・空振り・例外も同じ解除経路。構築時にPluginDisableEvent listenerを登録し、所有Pluginの停止では残存taskとflagを即時解除する。別Plugin停止には反応しない。残る表示entityや一時buffは作らない。

標準のcastTimeTicksはMobSkillServiceの頭上詠唱表示。追加の固定予告はExecutor内部の有限時間で、バフによる詠唱時間補正の対象外。実戦での視認性・音・実体見た目は未確認。

## バランス根拠

`00_docs/60_戦闘バランス設計書/02-成長曲線.md` の標準TTK5〜7秒・耐久8〜10秒と、`01-戦闘計算.md` の防御式を基準にする。同レベルの `40_filebase/40.features.mob/enemy/v1.eriva_camouflage_zombie.yml` が直接の数値アンカー。クサハウンドはHP0.95 / 攻撃1.05 / 防御0.90倍、ヤブガニはHP1.08 / 攻撃0.85 / 防御1.05倍。Lv22〜28のアンカー間を用い、Lv50の未定義曲線を今回の低帯へ持ち込まない。

同格Playerの標準通常DPS×1.6、命中92%、最終倍率1.3、属性/会心/貫通なしの試算では、ゾンビ約6.0秒、猟犬約5.2秒、カニ約6.8秒。猟犬の技が必ず7秒ごとに命中する保守的な上限では、Lv22の期待被DPS約621、HP5000の耐久約8.0秒（Lv28も約8.1秒）。予告中に失う通常攻撃や回避・位置取りを除く上限。カニのEXPは同Lvゾンビ+20で、長めの撃破時間と通常素材率の差を補う。

素材率は `v1.eriva_grassboar.yml` のLv15肉40%・毛皮35%、`v1.midgard_forest_wolf.yml` の通常45〜55%・希少3〜5%を比較。カニの希少6%は計画初期案10%より抑え、耐久増と有限1個抽選を加味した。共有tier_2の低確率高進行報酬をコピーしない。
