# B12 コカゲハリネズミ

森林上位帯の3種目。1種だけを追加し、通常素材1種を落とす。既存バッチと同じ `field_` 命名を使用する。マスターIDは `field_shade_hedgehog`、技は `mob_field_shade_hedgehog_needle_ring`、素材は予約 `10a00410`。

| 項目 | 確定内容 |
|---|---|
| モデル | ARMADILLO、ADULT、scale 0.9、対応するスポーンエッグ |
| レベル | 36 / 38 / 40 / 42、同一IDの4 profile |
| 通常攻撃 | 近接2m、40tick間隔 |
| 針の輪 | 発動3m、予告開始位置へ半径3mの円を固定、頭上バーと地面の輪で30tick予告 |
| 防御姿勢 | 予告中1.5秒だけ既存の `MobInstance.defenseMultiplier` を1.35倍。開始時IDLEのArmadilloだけrollUpし、終了時rollOutする |
| 針放出 | 予告終了時の主対象1体だけへRANGED / NONE / 95%、`DamageService.attack`を一度使用 |
| 回避 | 予告中心から3mより外へ歩く。高低差1.25m超と遮蔽物の向こうは判定外。輪は追尾・拡大しない |
| 放出後 | 防御倍率を元へ戻し、20tickはAI停止を維持。次の開始は200tick以上後 |
| 素材 | 木陰の硬針、COMMON、35%、1個、幸運適用、売却540、取引可能 |
| 共通報酬 | Lv15以上の既存契約に従いnormal_enemy_common_table_tier_2を継承。固有素材は1種のまま |

輪の中へ接触しただけではダメージが発生しない。残留判定、反射、拘束、通常攻撃との同時発動を作らない。通行人や別プレイヤーを新たな標的にせず、既存の有効プレイヤー／召喚ペットの主対象だけを扱う。外部timingは発動0.5〜3m、再使用200tick以上、castTimeTicks=0、params空に限定する。予告の30tickはExecutor内で固定される。

死亡・破棄・帰還・主対象変更／無効化・world変更・行動不能・0.6m超のノックバック・地形chunk喪失・例外で中断する。保存した防御倍率、頭上バー、AI停止、taskを同じcleanupで返却する。destroy listenerとonDisableの中央接続はmanifestへ記載し、統合担当が直列で行う。中央ファイル、共有particles、properties、POM、管理表、スポナーは本担当で変更しない。

描画は予告28点×開始および5tick間隔（計6回）、放出48点×1回。既存共通の橙色予告粒子とCRITの針状火花を使い、1描画単位で閲覧者を一括解決する。新しいパーティクル種類／既定値の共有契約は追加しない。音は開始・放出各1回。未読込chunkをロードせず、ray trace前に線分を確認する。

数値根拠は `02-成長曲線.md` のLv30基準と、先行バッチの同帯Mob尺度。Lv36/38の霜猪（HP31800/34800、ATTACK4329/4743、DEFENSE4883/5355）よりHPと通常防御を抑え、短い防御姿勢に役割を寄せた。Lv40/42へHP+3000、ATTACK+414、DEFENSE+240、EXP+44を延長する。progression36は森林上位の遭遇段階、素材も同値とする。素材は売却へ接続し、レシピ等の未依頼経路は増やさない。POINTED_DRIPSTONEは硬い針の形を示す未使用アイコンとして選択した。

事前試算は `STATIC_RESULTS.json`。B07〜B10と同じ比較用の仮想Player R/HP/D（Lv32で3750/10700/3890、2Lvごと+450/+1200/+460）、通常期待命中92%、Player最終倍率130%、標準実戦DPS1.6倍を使用する。防御曲線は既存 `max(0,1-D/R/2.5)^1.35691545`。予告中防御を最初の1.5秒へ適用したTTKも併記する。これは正式なLv31以降のアンカー、実class・装備・skilltree育成、実戦ローテーションの確認ではない。

針の1hitは仮想HPの約14%（防御後）で、実戦生存・TTK、起伏地形、予告視認性、複数個体の密度、モデル／音量、Geyserでの受入は統合後に確認する。無防御・低レベル・既に瀕死の対象まで非致死を保証するものではなく、共通戦闘計算に従う。現在の低い代表解決攻撃力R416.58では当帯Mobが完全防御になり得るため、Lv31以降の正式育成基準が整うまで本番バランス受入済みとはしない。

通常素材1種という依頼は、固有素材の追加数を制約する。共通報酬の明示除外はないため、`04-レベル帯コンテンツ設計.md` のLv15以上ENEMYの既存規則を適用する。共通table/pool/item自体は変更しない。素材売却期待値189Gは固有素材だけの値で、共通報酬の売却や価値を含まない。

停止時の姿勢解除が例外を投げても、B12全個体の防御・詠唱・AI状態を回収する。中央onDisableではmanifestのdisable_codeで例外を捕捉して保持し、既存の全サービスcleanup完了後にだけdisable_after_cleanup_codeで再送出する。B12停止呼び出し直後に例外を再送出して後続のProjectile/Spawner等の停止を妨げない。

world名／座標が指定されていないため生息スポナーは作成せず、配置と中央登録・cleanup、全体build/test、版番号、develop統合は統合担当へ委任する。
