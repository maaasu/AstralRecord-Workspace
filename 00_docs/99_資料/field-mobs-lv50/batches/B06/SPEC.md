## ネッコガメ

- Mob: `field_root_turtle` / `TURTLE` / `TURTLE_SPAWN_EGG`。森林想定の低速・低火力の通常敵。通常近接2m・36tickを維持する。
- 技: `mob_field_root_turtle_root_snare` / 「根の足止め」。発動6m、高低差1.25m以内、CD160tick。`castTimeTicks: 0`としてExecutorが24tickの予告を担当する。
- 有効な通常プレイヤー1体を主対象にし、その足元の衝突面へ半径1.6mの輪を固定する。輪と4本の根筋を4tick間隔、最大36点で再表示し、予告中は通常AIを止める。地形やblockを変更しない。
- 24tick後、主対象が輪内・高低差1.25m以内・遮蔽物なしの場合だけ、間接・無属性の攻撃力40%を一回与える。独自DamageServiceの回避・shield・防御を通す。
- 実ダメージまたはshield damageがある命中にだけ`field_root_turtle_root_snare`を付与する。移動速度の最終倍率0.70を24tick（1.2秒）適用する。攻撃、スキル、ジャンプは封じない。凍結・長時間行動不能はない。
- ペットはプレイヤーバフの対象外なので、この技の`cast`を開始せず既存通常近接へ戻す。無効account・creative/spectator等は共通の`DamageService.isMobCombatTarget`で除外する。対象条件を狭くし、未対応のpet減速を捏造しない。
- 輪は追尾しないため予告中に外へ歩けば回避できる。壁も命中を防ぐ。発動前・予告中・命中直前に、caster/target/world/管理個体/COMBAT状態/行動可能性を確認する。移動不能だけは定置攻撃の中断条件にしない。
- 命中後に通常AIを戻し、減速の所有参照だけ最大24tick保持する。終了・対象変更・帰還・死亡・despawn・Plugin停止ではtaskと今回のActiveBuff個体を回収する。別個体が同IDを再付与した場合、その新しいbuffを旧casterのcleanupで消さない。減速管理中の終了は別のAI停止を解除しない。
- バフは`isDebuff: true`により持続時間増加の対象外、同ID/同stackGroupで非重複、挑戦開始時にも解除する。消費や恒久状態は作らない。

## ユキオオカミ

- Mob: `field_snow_wolf` / `WOLF` / `WOLF_SPAWN_EGG`。雪原想定の機動型通常敵。通常近接2m・36tickを維持する。
- 技: `mob_field_snow_wolf_ice_dash` / 「氷走り」。発動6m、高低差1.25m以内、CD140tick。`castTimeTicks: 0`、Executor内で24tick予告する。
- 有効なプレイヤーまたは召喚ペット1体への発動開始方向を固定する。通常AIを止め、幅1.6mの二本の氷筋と中央点で全6mの進路を4tick間隔、最大33点で示す。うなり→氷の割れる音→足元の雪粒子で段階を分ける。
- 予告後、0.6m/tickで最大10歩（6m）直進する。追尾・連続突進・瞬間的な対象位置への移動は行わない。発動時点で0.5m未満なら開始しない。
- 各区間で実体の幅と高さを0.15m以下の間隔でサンプルし、blockのcollision shape、足元の実衝突面、world border、読込済みchunkを確認する。壁、崖、水面、大きな段差では止まり、移動不能・行動不能・対象変更・帰還・world変更・外部移動でも中断する。`teleport`失敗時に内部座標だけ進めない。
- 主対象のhitboxを0.2m拡張して、区間rayと開始時の重なりで判定する。命中時にtaskを先に外し、近接・氷属性の攻撃力80%を一度だけ与えて終了する。他の通行人へ命中させず、凍結や減速を付けない。
- 進路から横へ外れる、遮蔽物を使う、地形を変えて空振りさせる対処がある。破棄listener・`stop()`・例外経路でtaskと通常AI停止を回収する。

両Executorはparamsを受け付けない。timing上書きは射程0.5〜6m、CD80tick以上、詠唱0tickだけを許可する。既存の通常AI・対象境界・攻撃力のfallback解決・共通粒子表示を変更しない。
