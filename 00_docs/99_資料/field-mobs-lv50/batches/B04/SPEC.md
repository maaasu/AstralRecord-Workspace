## 戦闘動作

| 項目 | イワセバイソン | アラシラプター |
|---|---|---|
| Mob ID | `field_stoneback_bison` | `field_storm_raptor` |
| モデル | ADULT COW、scale 1.15 | ADULT CHICKEN、scale 1.5 |
| 役割 | ボス未満の強い近接雑魚 | 移動する通常近接雑魚 |
| 技ID | `mob_field_stoneback_bison_earth_charge` | `mob_field_storm_raptor_diving_strike` |
| 技名 | 地鳴り突進 | 風切り急降下 |
| 予告 | 30tick、固定方向の幅付き2列18点 | 24tick、固定着地点の外接円16点 |
| 移動 | 最大8m、0.5m/tick、最大16tick | 最大6m、12tick、開始と着地を結ぶ高さ1.4mの弧 |
| 命中 | 実体幅・高さで主対象のhitboxを拡張し移動区間を連続判定 | 着地した実体hitboxを水平0.15mだけ拡張、着地時のみ判定 |
| 威力 | 近接・無属性110%、一度のみ | 近接・無属性90%、一度のみ |
| 硬直 | 命中／壁停止／距離満了後12tick | 着地後10tick |
| 再使用 | 240tick（12秒） | 180tick（9秒） |
| 通常攻撃 | 2.2m、48tick間隔 | 1.8m、36tick間隔 |
| 回避 | 予告の進路から横へ離れる、遮蔽物を使う | 予告の輪の外へ離れる、遮蔽物を使う |

固有技は主対象だけへ攻撃する。プレイヤー／有効な召喚ペットの判定、命中・回避・シールド処理は `DamageService` に委譲し、他のMobや非ゲームモードのプレイヤーへ広げない。土・風は現行 `DamageElement` にないため、技の題材だけに用いて `NONE` を使用する。状態異常・強制ノックバック・連続命中はない。

`castTimeTicks: 0` は内部予告の開始であり、即時ダメージではない。頭上の技名／残り時間はExecutor自身が管理し、予告は固定最低時間を確保する。paramsは受け付けず、外部詠唱時間の追加を拒否。射程はそれぞれ0超～8/6m、CDは120tick以上だけ許可する。別スキルの行動中・自種の行動重複は発動しない。

通常AIを `scriptedAction` で止め、開始時にpathfindingを停止する。対象が変わっても照準／着地点を追尾しない。予告の幅／半径は発動者だけでなく主対象のhitbox幅も含み、足元中心を線／輪の外へ出す回避を示す。移動中に対象が進路へ戻る場合は、現在の対象hitboxとの接触だけを判定する。ラプターは途中の空中接触では攻撃しない。技名は実際の動作が伝わる「風切り急降下」へ技案から具体化した。

## 地形とライフサイクル

バイソンは平坦な地面上だけを突進する。各0.5m区間を0.15m以下で刻み、全実体の衝突形状・液体・高さ・WorldBorder四隅・chunk読込を確認する。中央と四隅の支持を確認するため、崖・狭い縁・上り段差に入らない。平坦なslab上面は支持判定できるが、段差を登る処理は行わない。

ラプターの対象足元差は0.25m以内、水平距離0.5～6mに限定する。予告前に固定弧全体と開始／着地点の支持を検証し、予告後も毎区間と着地点を再検証する。低い天井、液体、壁、未読込chunk、WorldBorderで中断する。移動中のみ重力を停止し、正常着地・例外・中断・Plugin停止で元の値へ戻す。中断時は、同一Worldかつ現時点で安全な出発点へ復帰する。復帰地点が塞がれた場合は重力だけを戻し、強制的に壁内へ戻さない。外部テレポート／World変更を検知した場合は異Worldへ戻さない。

両者ともインスタンス一致、HP、生存、COMBAT状態、主対象ID／有効性、同一World、AI／詠唱／攻撃／移動可能性を各tick確認する。死亡・despawn・帰還・target喪失・行動阻害・外部移動では次tickまでに終了。正常終了／例外／停止はaction map、タスク、頭上バー、AI停止を回収する。constructorは自身の `PluginDisableEvent` Listenerを登録し、Bukkitの一括タスク取消時にも回収を保証する。`stop()` も冪等。同期メインスレッドでのみ構築・実行する。

予告粒子は5tick間隔で閲覧者を一括解決し、移動粒子は4tick間隔だけ描画する。既存の共有粒子定義を再利用し、粒子自体の色より予告の形・音・移動・命中段階で区別する。バイソンは低い牛の音／土煙、ラプターは鳥の声／風の粒子／着地の爪音。実機での見た目・音は未確認。

## レベルとバランス根拠

`levels[] = 42,44,46,48`、最小との差6。通常素材とenemyのprogressionは25、希少素材は26。既存progression15のエリヴァ草原・Lv30既存個体の先にある高帯での相対段階であり、progressionをレベル値として扱わない。

正本 `00_docs/60_戦闘バランス設計書/02-成長曲線.md` はLv30まで。Lv30 Player HP9500/R3318/D3442、標準Mob HP19000/R3442/D3318を、暫定的に `(Lv/30)^2` で延長して役割差を加えた。基点の既存Lv30迷彩ゾンビ、エリヴァ装備とclassを比較したが、31～50の装備込みPlayer基準は未定義。下表は暫定のコンテンツ定義であり、現行class／装備だけで同格性能を保証しない。

バイソンは初期強敵基準HP3/R1.15/D1.1からHP2.2へ抑えた。R/Dを上げるほど防御式の非線形効果もあり、HP3は理論TTK約19.7秒と長すぎるため。通常種ラプターはHP0.92/R1.12/D0.9で短い攻撃型にする。回避可能な単発技と硬直を合わせ、単純なHP倍率だけで強弱を決めない。

|---|---|---|
| 42 | 81928 / 7758 / 7153 / 1120 | 34261 / 7556 / 5853 / 560 |
| 44 | 89916 / 8515 / 7851 / 1160 | 37601 / 8292 / 6423 / 580 |

Lv42仮定上のPlayer HP18620/R6503/D6746、命中率92/91.5%、FINAL倍率1.3、skill込み攻撃DPSを通常攻撃の1.6倍として、正本の防御式 `(1 - D/(2.5R))^1.3569` で試算。バイソンTTK約14.5秒／通常攻撃だけの被弾耐久約11.2秒、ラプターTTK約5.0秒／被弾耐久約8.8秒。固有技は回避可能で予告／硬直が通常攻撃を止めるため、この耐久試算へ固有技を加算しない。技を毎回受ける場合の実戦耐久は要確認。

Lv30装備込みアンカーを据え置くと、Lv42バイソンTTK約190秒・被弾耐久約4.2秒、ラプターTTK約28秒・耐久約3.2秒。配置前にLv40帯装備・成長の実数から再計算し、必要ならB04値を統合担当が調整する。これを攻略可能と誤って報告しない。EXPは既存Lv30の440から2Lvごと+20を暫定延長し、バイソンは通常の2倍。仮定上のEXP/秒は約77対112で、強敵を最適周回だけの存在にしない。

抽選は独立、幸運補正あり、全素材を図鑑へ表示する。牛皮／羽の35%は既存グラスボア皮35%、通常素材40～55%を根拠に、追加素材供給を抑える初期値とした。角10%は強敵の長TTKを補い、大地の芯1%は角の10分の1で平均100撃破に1個。既存共通tier lootの極低確率装備は無条件コピーしない。期待素材売却額はバイソン263、ラプター91で、仮定TTKあたり約18.1対18.2。素材レシピは装備担当の所有範囲のため追加しないが、売却経路は成立する。

iconは使用済み素材を調査した。LEATHERとFEATHERはそれぞれ皮／羽そのもの、GOAT_HORNは角そのものを表すため採用。HEART_OF_THE_SEAは既存 `10a00085` 大地の命玉の核モチーフと共通で、別の素材に変えるより核として理解しやすいため再利用例外とした。名称・レアリティで既存素材と区別する。

## 中央引き渡し

完全修飾class、constructor依存と登録案は `registration-manifest.json`。中央登録前は2つとも未登録。新規Player skill YAMLは不要。properties/LogId/MsgId・共有基盤変更も不要。

生息想定はPLANの平原Cのみ。既存world `vanaheim_supercontinent` とエリヴァ大草原spawner参照は存在するが、平原Cの区域・座標・density根拠は未確認。スポナーを作成せず、統合担当が配置条件を確定する。実装済みと配置可能を分け、各spawnerのexact levelを検証する。
