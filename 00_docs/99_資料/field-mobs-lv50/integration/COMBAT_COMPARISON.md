# 統合済み8種の数値比較

B01/B02/B03/B04実マスタから32profileを抽出。COMBAT_COMPARISON.csvが全数値、generate_combat_comparison.pyが再計算元。実戦値ではない。

Player基準は既存迷彩ゾンビの同格HP/2、R=標準Mob DEFENSE、D=標準Mob ATTACK。Player通常1秒/命中95/最終130%/skill込みDPS1.6倍、Player回避3.5。Mobの実ATTACK/DEFENSE/EVASION/通常間隔/CDを使用。無属性・会心/貫通/盾/一時buffなし、防御倍率(1-D/R/2.5)^1.35691545、D/R>=2.5なら0。攻撃技倍率は防御比のRに含めない。

耐久下限は通常攻撃DPS+CDごとの技DPSを連続加算した保守的上限から算出。予告中の通常攻撃停止、回避、移動、ring操作、AoEの追加対象を含まない。TTKは通常DPS×1.6の仮定であり新装備/職業構成の実性能を保証しない。

Lv30超: 共通比較L=HP19000+1200×Δ/R3442+217.4×Δ/D3318+210.8×Δ。別比較C=B02 HP延長19000+2400n+100n(n+1), n=Δ/2、R/DはLと同じ。Q=B04のHP/R/Dを(Lv/30)^2で延長する案も別列に記録。正本未定義のため3案を保持し、マスタを一律修正しない。
