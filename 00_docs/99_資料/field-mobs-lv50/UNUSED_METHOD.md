# 用途なしアイテム資料の判定

UNUSED_CURRENT_MATERIALS.csvは2026-10-14/bc7877ae3のmaterial101件を40_filebase内で調査した17件の消費先なしスナップショット。

定義自身とdrop/採集/釣獲/報酬の参照は入手であり用途に数えない。recipe入力、quest提出、equipment.requiredMaterials（transcendence含む）、pet孵化、shopの入力/交換/販売を消費・経済用途として別分類する。18候補から10a00085大地の命玉はpet孵化消費があるため除外した。

CSVのdungeon reward only表記は機械抽出時の仮分類。今回確定できたのはdungeon item refであり、役割は参照先で再読する。全体の用途なし判定は「現行filebaseに消費先参照がない」で、コード内の動的ID/実サーバ設定/将来予定まで不存在を保証しない。

新規追加予定素材: PLAN.md記載の新規種通常23+希少8+強め低確率2=33件、およびE01〜E13既存種25件。現時点では予約で未実装。素材用途はモブ側で実装しないため、装備タスクが消費先を作るまでは追加後の用途なしに入る。PLAN.mdの全ID/名称を追加予定一覧として参照する。

素材実装後、装備タスク完了後、統合後の3時点で全YAML参照を再抽出しこのCSVを更新。新規IDだけでなく現在17件も再判定する。装備タスクの20a予約はモブ側と独立、10a素材の追加/命名/入手値はモブ側を正本とする。
