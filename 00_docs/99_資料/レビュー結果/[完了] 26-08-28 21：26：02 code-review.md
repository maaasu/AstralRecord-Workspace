### AR-CODE-001 [中] 実衝突境界の恒久テストが不足
- 種別: `テスト不足`
- 対象: `10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/skill/active/service/SkillProjectileServiceTest.java:141`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/active/service/SkillProjectileService.java:90`
- 根拠: `00_docs/10_Plugin設計書/feature/13-skill/13_6-発動スキル追加ガイド.md` の `## 16. ヒールアローの実装契約`、`### 16.2 演出・入手・テスト契約` は、Mob／Block／RANGEの終端、重力、回復エリア非生成、実回復、task lifecycleを恒久テストで検証する契約です。
- 問題: 追加テストは `SkillProjectileService` と終端 callback をモックし、`SkillTargetingService` の実 `blockImpact`・`inLineBeforeBlock`・`inLine` を通した projectile と衝突境界の組み合わせを検証していません。既存の共通サービス単体テストだけでは、今回の弾道処理からの呼び出し分岐を回帰検知できません。
- 影響: Block先着時のMob除外、Mob先着時のEntity終端、Block衝突地点の通知が実際の弾道処理と一致しなくても、ヒールアローのテストが成功する可能性があります。
- 修正方針: 恒久テストに実 `SkillTargetingService` を接続し、Mobのfallback bounding boxとBlock ray traceを使ったMob先着／Block先着の両方を弾道サービスから検証します。既存の `ActiveSkillLifecycleServiceTest` によるcaster単位task破棄の契約も対象として明示します。
- 修正対象候補: `10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/skill/active/service/SkillProjectileServiceTest.java`
- 修正可否: `自動修正可`
