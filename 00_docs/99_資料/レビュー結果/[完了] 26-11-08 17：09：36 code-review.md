- 種別: `ドキュメント不整合`
- 対象: `.codex/skills/astralrecord-git-worktree-develop/SKILL.md:47`
- 関連箇所: `.codex/skills/astralrecord-git-worktree-develop/references/worktree-management.md`
- 根拠: ルート AGENTS.md は外部配置先に実行環境の設定を使うよう定めている。
- 問題: 準備と管理ファイル更新の手順が E ドライブを指定している。この環境では既存の作業ツリーと管理ファイルは C ドライブにある。

- 修正方針: 実行環境の作業ツリー配置と管理ファイルを確定し、管理スクリプトへ明示する手順に揃える。
- 修正対象候補: `複数`

- 関連箇所: `.codex/skills/astralrecord-git-worktree-develop/SKILL.md`
- 根拠: 安全な整理の対象はローカル作業ツリーと作業ブランチを含み、リモート枝は存在する場合に整理する。
