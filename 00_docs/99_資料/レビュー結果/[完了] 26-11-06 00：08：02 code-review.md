### AR-CODE-001 [中] 読み取れないキャッシュが毎回の再取得を起こす
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecordGeyserExtension/src/main/java/io/github/maaasu/astralrecordgeyser/PlayerHeadCache.java:37`
- 関連箇所: `10_plugin/AstralRecordGeyserExtension/src/main/java/io/github/maaasu/astralrecordgeyser/PlayerHeadCache.java:117`
- 根拠: 読み込み失敗時も Mojang への取得を続け、取得結果の保存は抑止する。
- 問題: JSON全体の破損や読み取り障害が残ると、各起動で保存済みだった UUID を再取得する。
- 影響: 接続受付が繰り返し遅れ、起動ごとにヘッドの取得結果が変わり得る。
- 修正方針: 読み込み失敗時は元ファイルを保全してプレイヤー分の取得を見送り、復旧手順を記載する。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-002 [中] 起動上限で同じ UUID が後回しになる
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecordGeyserExtension/src/main/java/io/github/maaasu/astralrecordgeyser/PlayerHeadCache.java:50`
- 関連箇所: `10_plugin/AstralRecordGeyserExtension/src/main/java/io/github/maaasu/astralrecordgeyser/PlayerHeadCache.java:37`
- 根拠: UUID順の API 結果を毎回同じ順で問い合わせ、処理時間に上限を設ける。
- 問題: 前半に時間のかかる未解決 UUID が多いと、後半の UUID の取得が毎回見送られる。
- 影響: 取得可能なヘッドが再起動後も表示に加わらない場合がある。
- 修正方針: 起動ごとに未取得 UUID の問い合わせ順を変える。
- 修正対象候補: `10_plugin/AstralRecordGeyserExtension/src/main/java/io/github/maaasu/astralrecordgeyser/PlayerHeadCache.java`
- 修正可否: `自動修正可`
