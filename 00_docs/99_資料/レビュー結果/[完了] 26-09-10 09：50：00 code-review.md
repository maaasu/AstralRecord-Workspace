### AR-CODE-001 [高] 期限切れディスク受付が通常ドッジを抑止する
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/item/castdisk/CastDiskUseService.java:100`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/player/event/PlayerSneakEventHandler.java:82`
- 根拠: ディスク受付が250msを超えた場合でも `tryTriggerDodgeOnSneakRelease` が true を返し、通常ドッジ経路へ制御が渡らない。
- 問題: 右クリック後に受付期限を過ぎてスニークを解除すると、通常ドッジも発動しない。
- 影響: ドッジキャストディスクを使ったプレイヤーが、期限切れ後に通常ドッジを失う。
- 修正方針: 有効期限切れまたは無効な受付では false を返し、通常のドッジ判定へ委譲する。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/item/castdisk/CastDiskUseService.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
