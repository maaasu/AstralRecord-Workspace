## 指摘一覧

### AR-CODE-001 [高] 非同期ログインイベントからBukkitのオンライン一覧を参照している
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/player/service/PlayerCapacityService.java:32`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/player/event/PlayerCapacityEventHandler.java:53`
- 根拠: `AsyncPlayerPreLoginEvent` は非メインスレッドで発火する。Paper API 1.21.11 の `Bukkit.getOnlinePlayers()` は非同期処理から安全に利用できない。
- 問題: 接続前予約の上限判定が、非同期イベントから取得したBukkitのオンラインプレイヤー一覧のサイズに依存している。
- 影響: 同時接続時にオンライン人数の読み取りがAPIのスレッド制約に反し、30/5/1の権限別接続上限を正確に適用できない可能性がある。
- 修正方針: オンライン人数をメインスレッドで初期取得した内部カウンターで管理し、参加・退出のカウンター更新と予約解放を予約ロック内で行う。非同期接続前処理ではBukkitのオンライン一覧を参照しない。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/player/service/PlayerCapacityService.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-002 [中] ワールド参加前の接続切断で予約が残る
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/player/event/PlayerCapacityEventHandler.java:70`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/player/service/PlayerCapacityService.java:111`
- 根拠: 現在の予約解放契機は `PlayerLoginEvent` の拒否、`PlayerJoinEvent`、`PlayerQuitEvent` だけである。Paper の `PlayerConnectionCloseEvent` はワールド参加前の接続切断も通知できる。
- 問題: `AsyncPlayerPreLoginEvent` 通過後、`PlayerLoginEvent` または `PlayerJoinEvent` に到達する前に接続が切断された場合、UUID予約を解放するイベントを登録していない。
- 影響: 途中切断された接続の予約がPlugin停止まで残り、追加枠や全体の接続枠を実際には使用していない接続が占有し、後続の正常な接続を拒否する可能性がある。
- 修正方針: Paper の `PlayerConnectionCloseEvent` を登録し、通知されたUUIDの接続前予約を解放する。解放処理は既存のスレッドセーフな予約サービス経路を利用する。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/player/event/PlayerCapacityEventHandler.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
