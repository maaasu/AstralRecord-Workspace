### AR-CODE-001 [低] スキルloreが1受付1hitの仕様と矛盾する
- 種別: `ドキュメント不整合`
- 対象: `40_filebase/30.features.skill/v1.swordsman_blade_counter.yml:14`
- 関連箇所: `00_docs/10_Plugin設計書/feature/13-skill/13_6-発動スキル追加ガイド.md:153 / 10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/executor/active/swordsman/SwordsmanBladeCounterRuntimeService.java:160`
- 根拠: 実装と設計書は通常攻撃1回で1枠を消費し、受付中の最初の直接hitだけをカウンター試行と定義している。一方、skill YAMLのloreは受付中に連続攻撃へ反撃すると記載している。
- 問題: プレイヤー向けのスキル説明が実際の受付回数・反撃条件と一致しない。
- 影響: 連続hitを受けると複数回反撃できると誤認し、残数表示や実際の挙動と異なる期待を持つ。
- 修正方針: YAMLのloreを「受付中の最初の一撃だけ」へ更新する。
- 修正対象候補: `40_filebase/30.features.skill/v1.swordsman_blade_counter.yml`
