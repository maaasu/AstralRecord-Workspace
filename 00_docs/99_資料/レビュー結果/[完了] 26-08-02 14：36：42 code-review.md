### AR-CODE-001 [高] 切断時に合成素材の一時非表示が解除されない
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/event/SkillBindGuiEventHandler.java:188`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/player/event/PlayerJoinEventHandler.java:195`
- 根拠: `NORMAL` 優先度の PlayerJoinEventHandler が先に AstPlayerCache を削除し、`MONITOR` 優先度の当該ハンドラでは accountId を取得できない。
- 問題: 合成中にログアウトすると、素材 entry の一時非表示予約が InventoryService に残る。
- 影響: 同一プラグイン稼働中に再接続すると、未消費の合成素材が BAG/HOTBAR に表示されない。
- 修正方針: 合成選択に accountId を保持し、ログアウト時はキャッシュに依存せず一時非表示予約を解除する。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/event/SkillBindGuiEventHandler.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-002 [中] 習得失敗後に確認画面の所持品表示を再同期しない
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/event/SkillGemLearnEventHandler.java:131`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/service/LearnedSkillService.java:198`
- 根拠: mutation 失敗時は API 正本から所持品と習得状態を再同期する一方、確認 GUI の failure callback はメッセージとサウンドのみを実行する。
- 問題: 再同期された所持品状態を開いたままの確認画面へ反映しない。
- 影響: 通信結果の境界事例で、実際の所持状態と確認画面下部の表示が不一致になる。
- 修正方針: failure callback でも現行 AstPlayer の managed inventory 表示を再適用してクライアント表示を同期する。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/event/SkillGemLearnEventHandler.java`
- 修正可否: `自動修正可`

- 修正状態: `修正済み`
