### AR-CODE-001 [高] シジル操作成功時の ORB_USED 通知がない
- 種別: `仕様不整合`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/service/SkillSigilOrbService.java:465`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/AstralRecord.java:1178`
- 根拠: `SkillSigilOrbService.complete` はシジル装着・脱着の成功後にインベントリ更新と画面終了を行うが、成功通知 listener を呼び出していない。一方、`AstralRecord` の `ORB_USED` 記録は現状 `OrbService` の成功通知へ接続されている。
- 問題: 新しいシジル装着・脱着ガイドは `ORB_USED` とオーブ ID を達成条件にしているため、実際に操作が成功しても進捗が記録されない。
- 影響: `bragi_orb` と `mimir_orb` の使用ガイドをプレイヤーが完了できない。
- 修正方針: シジル操作サービスに成功通知 listener を追加し、`AstralRecord` の初期化で成功したオーブ ID を既存の `GuideService.recordCondition(..., ORB_USED, ...)` へ接続する。失敗時は通知しない。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
