### AR-CODE-001 [中] Java版の透過補間が途中で明滅する
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/shared/display/DisplayTextService.java:651`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/shared/display/DisplayTextService.java:667`
- 根拠: Java 1.21.11 の TextDisplay は不透明度のメタデータを符号付きbyteとして読み、整数へ拡張して補間する。
- 問題: 97から201への透過指定は補間中に97から負の55へ変化し、表示の途中で0付近を通る。退場時にも逆方向に同じ境界を通る。
- 影響: 登場や退場で枠と本文が一瞬消えたり、急に濃くなったりする。
- 修正方針: 登場と退場の間だけサーバー側で毎tickの姿勢と不透明度を計算し、補間なしで枠と本文へ適用する。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/shared/display/DisplayTextService.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
