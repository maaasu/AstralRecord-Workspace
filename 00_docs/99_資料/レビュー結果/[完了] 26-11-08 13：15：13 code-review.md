### AR-CODE-001 [中] スポナー集計で同期 HTTP が発生し得る

- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/spawner/service/MobSpawnerService.java:680`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/mob/service/MobService.java:281`
- 根拠: マスター公開時の集計が全定義を対象にし、テンプレートがキャッシュにないと `findTemplate` が同期で API へ問い合わせる。
- 問題: 地域名が未設定の定義にも同期問い合わせが発生し得る。
- 影響: 欠損した Mob 定義がある場合、マスターや配置の再読込でメインスレッドを待たせる。
- 修正方針: エリアレベル集計はロード済みのテンプレートを参照し、未解決の項目を除外する。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/spawner/service/MobSpawnerService.java`

### AR-CODE-003 [低] 非数の出現半径が全域に一致する
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/spawner/service/MobSpawnerService.java:642`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/spawner/service/MobSpawnerService.java:783`
- 根拠: 配置範囲の判定は距離が半径より大きい場合を除外する。スポーンの起動判定は距離が半径以下の場合だけ起動する。半径が NaN ならどちらの比較も偽になる。
- 問題: 地域名のない NaN 半径の配置は、実際の出現範囲が空でも集計に加わる。
- 影響: 不正な設定があると同一ワールド全域の表示レベルが変わる。
- 修正方針: スポーンと同じ包含条件を満たす配置だけ集計する。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/spawner/service/MobSpawnerService.java`
- 修正可否: `自動修正可`
