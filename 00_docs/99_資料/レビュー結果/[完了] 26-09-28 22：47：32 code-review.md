### AR-CODE-001 [中] 表示可能な管理モードのプレイヤーが表示設定を変更できない
- 種別: `仕様不整合`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/mob/command/MobCommand.java:51`
- 関連箇所: `00_docs/10_Plugin設計書/feature/12-mob/3-メソッド仕様/12_3-サービス.md:434`
- 根拠: 設計書は表示設定の適用対象を `AccountMode.ADMIN` 本人と定め、モデル定義ではスポナー可視条件を `user.permission` 非依存とする。一方、`MobCommand` は `/mob` 全体に `UserPermission.ADMIN` を要求し、`AstCommand.onCommand` はサブコマンド実行前に権限不足を拒否する。
- 問題: `AccountMode.ADMIN` で実効 permission が 99 未満のプレイヤーはスポナーを表示できても `/mob spawner display` に到達できない。
- 影響: そのプレイヤーは FPS 低下時に `light` または `off` を選べない。
- 修正方針: 表示設定だけを `AccountMode.ADMIN` で利用できるようにし、その他の `/mob` 管理操作に必要な permission 判定を維持する。
- 修正対象候補: `複数`
- 修正可否: `要確認`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-002 [低] 表示モードのタブ候補が enum と重複している
- 種別: `コーディングルール違反`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/mob/command/MobTabCompleter.java:58`
- 関連箇所: `PLUGIN_GUIDE.md:63`
- 根拠: `PLUGIN_GUIDE.md` は enum 管理済みの値の文字列ハードコーディングを禁止する。タブ候補 `normal`、`light`、`off` は追加した `MobSpawnerVisualMode` の enum 値を重複定義している。
- 問題: enum の値を変更した際に補完候補とコマンド受理値が乖離する。
- 影響: タブ補完から実行できない値が提示される可能性がある。
- 修正方針: `MobSpawnerVisualMode.values()` からコマンド入力用の候補を生成する。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/mob/command/MobTabCompleter.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
