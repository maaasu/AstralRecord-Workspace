- 根拠: 通常の詠唱は技名と24文字の進捗バーを既定フォントで送る。Minecraft はこの本文の実幅を基準にアクションバーを中央揃えする。
- 問題: 状態異常行の開始位置を決める幅計算が、回避・詠唱などで使う既定フォントの文字をすべて幅ゼロとして扱う。状態異常行の右端が意図する位置よりも本文幅の半分だけ左に寄る。
- 影響: 通常戦闘から詠唱・回避へ切り替えると状態異常の表示位置が大きく動く。長い詠唱本文と複数の状態異常が重なる場合は状態異常行の一部が画面中央より左に入り、右上で確認できなくなる。
- 修正方針: 通常の回避・詠唱本文で使う既定フォントの既知の字送りを位置計算へ含める。未知の字形は画面右端を超えない見積もりとする。
