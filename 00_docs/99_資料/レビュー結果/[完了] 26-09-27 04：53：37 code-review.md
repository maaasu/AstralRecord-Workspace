### AR-CODE-001 [中] 店売り価格以下をおすすめ価格として表示する
- 種別: `バグ/アルゴリズム`
- 対象: `30_web/AstralRecordWeb/AstralRecordWeb/Models/MarketModels.cs:76`
- 関連箇所: `20_api/AstralRecordApi/AstralRecordApi/Services/MarketPriceService.cs:28`
- 根拠: API は履歴なし・品質補正なしでは `SuggestedUnitPrice = SellPrice` とし、`MarketRepository.cs:409` でその quote を出品に保存する。一方、出品時の単価は `SellPrice` 以下なら同サービスの `ResolveJudgement` とリポジトリで拒否される。Web は履歴のない出品で snapshot の `SuggestedUnitPrice` を検証せず返す。
- 問題: `saleValue=100`、履歴なし、出品価格101の有効な出品に「おすすめ価格 100 Gold」と表示する。`saleValue=0` のアイテムなら出品価格1に対し「おすすめ価格 0 Gold」となる。
- 影響: Web のおすすめ価格を参考にした利用者が、その値を設定すると出品を拒否される。Plugin の新しい初期値補正後も、既存の snapshot は Web でそのまま表示される。
- 修正方針: snapshot から得た価格が出品下限 `PriceFloor` 以下の場合は、出品可能な最小単価へ補正するか「データなし」として扱い、カードと詳細に同じ結果を表示する。仕様に合わせて表示条件を設計書にも反映する。
- 修正対象候補: `複数`
- 修正可否: `要確認`
- 確信度: `高`
- 修正状態: `修正済み`
