## 指摘一覧

### AR-CODE-001 [中] 数字の片面モデルを公式例から反転している
- 種別: `バグ/アルゴリズム`
- 対象: `50_resourcepack/bedrock/animations/damage_number.animation.json`
- 関連箇所: `50_resourcepack/bedrock/models/entity/damage_number.geo.json`
- 根拠: 数字モデルは北面だけを持つ。最初の実装は [Microsoft のビルボード例](https://learn.microsoft.com/en-us/minecraft/creator/documents/custom_projectiles?view=minecraft-bedrock-stable) の回転に対して yaw を180度ずらし、pitchの符号を反転していた。
- 問題: 面の向きとカメラへの追従を反転する根拠がなく、片面表示が読めない可能性がある。
- 影響: 統合版で数字が描画されない、または鏡像となる可能性がある。
- 修正方針: 公式例と同じビルボードの角度規則を使う。
- 修正対象候補: `50_resourcepack/bedrock/animations/damage_number.animation.json`
- 修正可否: `自動修正可`
- 確信度: `中`
- 修正状態: `修正済み`
