### AR-CODE-001 [高] 装備報酬の生成を inventory state lock 内へ移す
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/dungeon/service/DungeonService.java:2889`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/dungeon/service/DungeonService.java:2942`
- 根拠: `createLocalEquipmentInstance` は装備個体を cache・pending creation・dirty state へ即時登録する一方、`addPreparedRewardsToNormalInventory` が state lock を取得するのは後段です。`InventoryPersistence.hasPendingChanges` は entry の dirty 有無にかかわらず dirty equipment を保存対象にし、capture 時に装備と inventory entry を同じ snapshot へ収集します。
- 問題: 一括受取が装備個体を生成してから entry を追加するまでの間に autosave／save lane が state lock を取得すると、生成済み装備だけを含み entry を含まない完成スナップショットを保存できます。
- 影響: 容量不足などで受取を取り消しても、DB に inventory entry を持たない装備個体が残り得ます。全件原子的付与および失敗時の equipment cache 補償契約を破ります。
- 修正方針: account の inventory state lock を取得した内部操作で、装備個体の rollback snapshot、生成、全 entry の追加可否判定・追加を一体で実行し、その lock の外から autosave が中間状態を capture できないようにする。失敗時は inventory と equipment cache を同じ補償点へ戻す。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/dungeon/service/DungeonService.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-002 [低] 失敗時に新規作成した inventory 親行も補償する
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/inventory/service/InventoryService.java:1852`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/inventory/service/InventoryService.java:2022`
- 根拠: `addPreparedRewardsToNormalInventory` は entry の補償スナップショット作成前に `ensureInventory` を呼び、未存在の inventory を state へ追加して dirty 化します。失敗時の `restoreImmediateGrantState` は current inventories の entry と表示種別だけを復元し、追加した `InventoryModel` を除去しません。
- 問題: たとえば未作成の CURRENCY inventory を含む報酬群で後続の BAG 容量不足が起きると、報酬entryは戻っても空の CURRENCY inventory 親行だけが残り、後続 autosave で永続化されます。
- 影響: 全件受取の失敗時に inventory state が操作前と一致せず、設計書の「inventory と装備個体cacheを操作前へ戻す」契約を満たしません。
- 修正方針: 原子的付与の補償点を `ensureInventory` より前に取得し、失敗時は新規作成した inventory 親行を含めて state を復元する。既存 helper を使う場合も、作成前の inventory 集合を復元対象へ含める。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/inventory/service/InventoryService.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
