### AR-CODE-001 [中] チャージ完了後もボスが上空に残る
- 種別: `仕様不整合`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/boss/service/BossMechanicService.java:795`
- 関連箇所: `00_docs/10_Plugin設計書/feature/26-boss/3-メソッド仕様/26_3-サービス.md:271`
- 根拠: 既存仕様はバードメテオを `MobInstance.spawnLocation` を中心に開始し、ボスを中央で静止させる契約です。チャージ実装はチャージ位置をスポーン地点のY+5へ設定した後、チャージ完了時にスポーン地点へ戻さず、その位置のままバードメテオを開始しています。
- 問題: `startBirdMeteor` の攻撃中心と安全地帯はスポーン地点ですが、ボス Entity はチャージ用のY+5位置に残ります。
- 影響: バードメテオの攻撃範囲とボスの見た目の位置が上下にずれ、既存の「中央で静止する」仕様と異なる体験になります。
- 修正方針: チャージ完了時に `mobService.resetPosition(boss, boss.spawnLocation())` を実行してから、既存のBossBar・安全地帯・バードメテオ予兆を開始します。Y+5位置は5秒のチャージ中だけ使用します。
