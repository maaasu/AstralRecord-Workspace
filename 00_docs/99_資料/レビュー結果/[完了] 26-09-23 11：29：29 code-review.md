### AR-CODE-001 [中] 属性矢継承の継続消費を関連ファイルへ同期する
- 種別: `ドキュメント不整合`
- 対象: `00_docs/50_Filebase設計書/feature/30-skill.md:80`
- 関連箇所: `40_filebase/70.shared.buff/v1.sharpshooter_fire_arrow_inheritance.yml:9, 40_filebase/70.shared.buff/v1.sharpshooter_ice_arrow_inheritance.yml:9, 40_filebase/30.features.skill/v1.sharpshooter_fire_arrow.yml:19, 40_filebase/30.features.skill/v1.sharpshooter_ice_arrow.yml:20`
- 根拠: 今回の `40_filebase/30.features.skill/v1.sharpshooter_inheritance_mastery.yml:49` と `:53` は消費量を600tickへ変更し、`00_docs/60_戦闘バランス設計書/03-クラス別戦闘バランス/07-シャープシューター.md:65` も着弾ごとの30秒消費を定義している。`InheritanceBuffService.prepareAttack()` は消費後に残存する同じバフを追跡し直すため、残り時間がある限り後続の通常攻撃にも効果を適用する（`10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/service/InheritanceBuffService.java:186`〜`:191`）。
- 問題: filebase機能設計書は「次の通常攻撃1回」と全量消費の旧仕様を記載したままであり、属性矢のconditional loreとバフloreも「次の通常攻撃」と表示する。実際には149秒の残り時間を30秒ずつ消費して複数回の通常攻撃へ属性効果を適用するため、設計とゲーム内説明が挙動と一致しない。
- 影響: プレイヤーは継承効果が1回限りだと誤認し、将来のfilebase変更時にも属性矢だけが全量消費という旧仕様として扱われる。
- 修正方針: `30-skill.md` の属性矢継承説明を149秒・通常攻撃着弾ごとの600tick消費・残り時間未満時の失効まで含めて更新し、火・氷のスキルconditional lore、バフlore、および該当behaviorコメントを複数回適用できる仕様へ同期する。
