- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/item/executor/WeaponAttackPackDisplay.java`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/resourcepack/service/ResourcePackService.java:228`
- 根拠: パック適用フラグは接続時の固定 ID の成功通知を保持する。
- 問題: 新しいフォントが含まれる版のパックを適用したかは適用フラグから識別できない。

- 修正方針: 字形を翻訳引数として渡し、翻訳を含まない旧パックにはバニラフォントの星を表示する。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
