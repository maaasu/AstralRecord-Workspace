## 指摘一覧

### AR-CODE-001 [中] 処理中の戻る操作が直前の履歴を上書きする
- 種別: `バグ/アルゴリズム`
- 対象: `30_web/AstralRecordControl/src/AstralRecordControl.Web/wwwroot/js/control-navigation.js`
- 関連箇所: `30_web/AstralRecordControl/tests/WebScript.Tests/navigation.test.cjs`
- 根拠: 05-画面と機能の戻る・進むはGETで再取得する契約。
- 問題: popstateで移動を拒否した場合にreplaceStateで移動先のエントリを現在URLへ書き換える。
- 影響: 転送中に戻ると、その後も直前のPC台帳等へ戻れなくなる。
- 修正方針: 履歴に位置を記録し、拒否時はhistory.goで現在位置へ戻す。移動先のURLを上書きしない。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-002 [低] 動的に生成した行のイベント参照が更新後も残る
- 種別: `パフォーマンス`
- 対象: `30_web/AstralRecordControl/src/AstralRecordControl.Web/wwwroot/js/p2-control.js`
- 関連箇所: `なし`
- 根拠: 一般的なブラウザ資源管理として、破棄したDOMを長寿命の配列から参照し続けない。
- 問題: listeners配列がファイル・転送一覧の行ボタンを保持し、replaceChildren後も古い行と閉包が解放されない。
- 影響: 同じ画面で一覧を繰り返し更新すると不要なメモリを保持する。
- 修正方針: 動的行のlistenerを長寿命配列へ登録せず、DOMの破棄とともに回収可能にする。
- 修正対象候補: `30_web/AstralRecordControl/src/AstralRecordControl.Web/wwwroot/js/p2-control.js`
- 修正可否: `自動修正可`

### AR-CODE-003 [中] 配備をまたいだPOST応答が一度限りのtokenを表示せず破棄される
- 種別: `バグ/アルゴリズム`
- 対象: `30_web/AstralRecordControl/src/AstralRecordControl.Web/wwwroot/js/control-navigation.js`
- 関連箇所: `30_web/AstralRecordControl/src/AstralRecordControl.Web/Pages/Hosts/Index.cshtml.cs`
- 根拠: Agent tokenは発行応答で一度だけ表示し、履歴やcacheから復元しない。
- 問題: 共通資産の版差異があるPOST直接応答も通常GETへ即移動し、発行済みtokenを含むHTMLを捨てる。
- 影響: 古いタブを開いたまま更新された場合、Agent tokenは作成済みでも値を取得できなくなる。
- 修正方針: POSTの直接応答を先に表示し、次のGET遷移で新しい共通資産を読み直す。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

- 対象: `30_web/AstralRecordControl/src/AstralRecordControl.Web/wwwroot/js/control-navigation.js`

- 根拠: 画面内処理中の戻る操作は現在位置へ復帰させ、処理中の画面を保持する。

- 修正方針: 現在のhistory.stateがControlの有効な位置番号を持つ場合は、その番号を引き継ぐ。

- 修正可否: `自動修正可`
