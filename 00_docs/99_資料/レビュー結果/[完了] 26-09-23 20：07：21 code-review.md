## 指摘一覧

### AR-CODE-001 [高] 既存の習得済みスキルIDを移行する必要がある
- 種別: `仕様不整合`
- 対象: `40_filebase/30.features.skill/v1.archer_air_shift.yml:5`
- 関連箇所: `20_api/AstralRecordApi/AstralRecordApi/Repositories/AccountLearnedSkillRepository.cs:796`
- 根拠: `00_docs/40_Database設計書/table-definitions/AstralRecord/dbo.account_learned_skill.md:11` は `skill_id` にスキルマスタIDを保持すると定義している。APIの `ReconcileInTransactionAsync` は現在のスキルマスタに存在しないIDの習得個体を論理削除し、関連バインドを除去する。
- 問題: filebaseとPluginのIDだけを `hunter_air_shift` / `hunter_heal_arrow_alpha` から `archer_air_shift` / `archer_heal_arrow_alpha` に変更すると、保存済みの習得個体は旧IDのままで新しいマスタを解決できない。
- 影響: 次回のAPI整合処理で習得状態が論理削除され、スキルバインドも外れる。既存プレイヤーのレベルや習得状態を失う。
- 修正方針: 既存の `dbo.account_learned_skill.skill_id` を2つの旧IDから新IDへ更新する冪等なDB移行を追加し、新マスタのseed後、API整合処理を再開する前に適用する。
- 修正対象候補: `00_docs/40_Database設計書/table-definitions/AstralRecord/migrations/20260923_rename_archer_shared_skill_ids.sql`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-002 [高] DB migration を実行manifestへ登録する
- 種別: `コーディングルール違反`
- 対象: `00_docs/40_Database設計書/table-definitions/AstralRecord/migrations/20260923_rename_archer_shared_skill_ids.sql:1`
- 関連箇所: `60_tool/db-migrate/db-migrate.config.json, 60_tool/db-migrate/Program.cs:188`
- 根拠: `60_tool/db-migrate/README.md` は新しい本番SQLを同じ変更で対象DBのmanifestへ登録するよう定める。`ValidateMigrationManifest` はディレクトリ内の未登録SQLを検出すると例外終了する。
- 問題: 追加した移行SQLが `db-migrate.config.json` に登録されていない。
- 影響: DB migration runner が停止し、既存習得スキルIDの移行を実行できない。
- 修正方針: SQLを `migrations` へ登録し、対象となる `account_learned_skill` と `skill_bind_preset` の必要スキーマ expectation を追加する。
- 修正対象候補: `60_tool/db-migrate/db-migrate.config.json`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
