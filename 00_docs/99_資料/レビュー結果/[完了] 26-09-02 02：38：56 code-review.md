### AR-CODE-001 [中] サンバードの専用フェーズ遷移でシールド再展開が抜ける
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/boss/service/BossMechanicService.java:417`
- 関連箇所: `00_docs/10_Plugin設計書/feature/26-boss/3-メソッド仕様/26_3-サービス.md:91`
- 根拠: `handlePhaseTransition` はサンバードの専用フェーズ処理で先に `return` し、共通の `boss.currentShield(boss.shieldDisplayCapacity(), ...)` に到達しない。今回サンバードへシールドと再充填を追加し、設計書はフェーズ移行時に現在の表示容量まで再展開すると定義している。
- 問題: サンバードのシールドを破壊した後にHP30%以下へ到達して専用フェーズへ移行すると、参加人数補正後のシールド容量があっても現在シールドが0のままになる。
- 影響: サンバードだけがフェーズ移行時にシールドを再展開せず、他のBOSSとシールド状態の挙動が一致しない。
- 修正方針: サンバード専用分岐で `return` する前に `boss.currentShield(boss.shieldDisplayCapacity(), System.currentTimeMillis())` を実行する。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/boss/service/BossMechanicService.java`
- 修正可否: `自動修正可`
