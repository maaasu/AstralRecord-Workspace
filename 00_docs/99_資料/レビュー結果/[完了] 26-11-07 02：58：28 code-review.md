### AR-CODE-001 [中] アカウント削除後の再ロード失敗で操作制限が残る
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/player/service/PlayerService.java:140`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/account/command/AccountDeleteCommand.java:135`
- 根拠: 削除後の代替アカウント読込が例外で終了すると、非同期処理の結果は null になり、失敗分岐が復旧処理を呼ばない。
- 問題: 追加した先行保存の待機期限に達すると、削除前に設定した操作制限が解除されない。
- 影響: 選択中アカウントを削除したプレイヤーが操作できなくなる。
- 修正方針: 参加データ一括取得で先行保存の待機失敗を記録し、取得不能を示す null を返して、削除コマンドの既存の失敗処理へ渡す。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/player/service/PlayerService.java`
