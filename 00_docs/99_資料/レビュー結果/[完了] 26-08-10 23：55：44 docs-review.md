### AR-DOC-001 [中] 能力再利用の判定条件が文書間で一致しない
- 種別: `矛盾`
- 対象: `00_docs/50_Filebase設計書/feature/35-skilltree.md:54`
- 関連箇所: `00_docs/50_Filebase設計書/feature/35-skilltree-node-catalog.md:11-18`
- 根拠: スキルツリー設計書は、効果種別・対象・補正種別・数値・効果の組合せが同じならカタログの表示定義を流用すると定める一方、カタログはこれらに加えて「プレイヤーへ提示する役割」の一致を必要とし、役割が変わる場合は別ノードを許容しています。
- 問題: 役割だけが異なる同一効果について、同じ表示定義を必ず流用するのか、別名・別アイコンを許容するのかを一意に判断できません。

- 修正方針: 役割差のみで別の表示定義を許容するかを設計判断し、両文書の再利用条件を同じ内容へ統一します。
- 修正対象候補: `複数`
- 修正可否: `設計判断待ち`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-DOC-002 [中] カタログに再利用必須の表示定義が記録されていない
- 種別: `不足`
- 対象: `00_docs/50_Filebase設計書/feature/35-skilltree-node-catalog.md:22-29`
- 関連箇所: `複数`
- 根拠: 設計書は同じ能力で表示名・アイコン・lore・タグを流用すると定め、JSON 契約も `name`、`icon`、`lore`、`tags` を必須としています。しかしカタログ表は表示名とアイコンのみで、lore とタグを持ちません。既存 node JSON の表示名には色コードも含まれますが、表には記録されていません。
- 問題: カタログだけでは完全な表示定義を流用できず、作成者が node JSON を都度解釈しなければなりません。
- 影響: lore、タグ、色コード付き表示名の流用漏れにより、同一能力のノード表現が不統一になります。
- 修正方針: カタログ表へ色コードを含む表示名、lore、タグを追加し、既存 node JSON と一致させます。
- 修正対象候補: `00_docs/50_Filebase設計書/feature/35-skilltree-node-catalog.md`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-DOC-003 [中] 複数効果ノードの再利用判定がカタログで定義されていない
- 種別: `矛盾`
- 対象: `00_docs/50_Filebase設計書/feature/35-skilltree-node-catalog.md:11-17`
- 関連箇所: `00_docs/50_Filebase設計書/feature/35-skilltree.md:54-55`
- 根拠: Skilltree 設計書は、効果の組合せが同じ場合にだけ表示定義を流用し、組合せが異なる場合は新しいカタログ項目を作れると定めています。一方、カタログの再利用条件は単一の効果種別・対象・補正種別・数値・skill ID だけを列挙しており、`effects[]` が複数要素である場合の組合せを条件に含めていません。
- 問題: 既存の単一ステータス効果と、その効果に別のステータス効果またはスキル使用許可を加えたノードについて、既存の表示定義を流用するか、新しいカタログ項目とするかをカタログだけでは一意に判断できません。
- 影響: AI または作成者が、効果内容の異なる複数効果ノードへ既存の単一効果ノードの名称・アイコン・lore・タグを流用し、表示と実効果の対応を誤らせるおそれがあります。
- 修正方針: カタログの再利用条件へ `effects[]` 全体の効果種別・対象・補正種別・数値・skill ID の組合せ一致を追加し、組合せが異なる場合は別項目とすることを Skilltree 設計書と同じ内容で明記します。
- 修正対象候補: `00_docs/50_Filebase設計書/feature/35-skilltree-node-catalog.md`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
