### AR-CODE-001 [中] 一人称で釣り糸の始点が竿先から離れる
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/fishing/service/FishingVisuals.java:52`
- 関連箇所: `50_resourcepack/assets/astralrecord/models/item/custom/wooden_fishing_rod.json`
- 根拠: 1280×720 の Java 版の比較で、竿先の高さが旧版の約506 pxから候補の約190 pxに移る。釣り演出の始点のオフセットは旧版で表示する位置を使っている。
- 問題: 新しい一人称の竿を表示しても、RPGの釣り糸の始点が旧モデルの位置に残る。
- 影響: 投げた後の糸が竿先から大きく離れて見える。
- 修正方針: 対応パックを適用した本人向けの始点を、添付時の視野角で竿先に合わせる。糸の補正を竿先から滑らかに減らし、残りの表示と釣りの判定には既存経路を使う。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
