- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/shop/gui/ShopGui.java`

### AR-CODE-003 [中] 未選択時のアクティブ自動バインドが有効枠9を超える
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/model/SkillBindSession.java:215`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/event/SkillBindGuiEventHandler.java:451`
- 根拠: 未選択時のactive割当は`findNextFreeSlot(activeDraft)`を呼び、12枠全体を探索します。一方、選択済み枠はhandler側で初期有効枠9に制限されています。
- 問題: 先頭9枠と左クリック枠が埋まると、10〜12番へ新規バインドできます。
- 影響: 初期アクティブ有効枠は1〜9という要件と保存内容が一致しません。
- 修正方針: 未選択時のactive自動探索を`DEFAULT_ACTIVE_SLOT_COUNT`へ制限し、10〜12番は既存値の保存・ディスク利用だけにします。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/model/SkillBindSession.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-004 [高] インベントリ自動再描画がスキル設定overlayを上書きする
- 種別: `バグ/アルゴリズム`

### AR-CODE-007 [中] キャストディスク設定が発動不能な10〜12番枠を有効設定として保存する
- 種別: `バグ/アルゴリズム`

- 根拠: `CastDiskSettings.ACTION_SLOT_COUNT` は12のままで、10〜12番を`isComplete`かつ保存可能な設定として受理します。一方、発動側は`DEFAULT_ACTIVE_SLOT_COUNT`の9未満だけを許可します。

- 修正方針: ディスク設定の許容action slot数を初期有効枠9へ合わせ、GUI選択・metadata保存・isCompleteを同じ境界で制限します。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/item/castdisk/CastDiskSettings.java`
