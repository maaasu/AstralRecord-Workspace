### AR-CODE-001 [低] 視認距離外破棄の連携を実行しない回帰テスト
- 種別: `テスト不足`
- 対象: `10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/dungeon/service/DungeonServiceRoomLifecycleTest.java:150`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/dungeon/service/DungeonService.java:1040; 10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/mob/service/MobService.java:593; 10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/mob/service/MobAiService.java:241`
- 根拠: `00_docs/10_Plugin設計書/feature/32-dungeon/32_3-処理契約.md` は Dungeon Mob を `keepWhenUnobserved=true` にして視認距離外の自動破棄から除外し、セッション終了時に明示破棄する契約を定めている。`00_docs/10_Plugin設計書/feature/12-mob/3-メソッド仕様/12_3-サービス.md` では、視認距離外破棄は `MobAiService` の tick から `MobService.destroyEnemiesOutsideViewDistance` を呼び、`keepWhenUnobserved` を判定する連携として定義されている。
- 問題: 追加テストは `MobService` をモックし、private な `activateRoomContent` の後に生成した `MobInstance` のフラグを確認するだけで、`MobAiService.tick` または `MobService.destroyEnemiesOutsideViewDistance` を実行していない。そのため、`MobService` 側が維持指定を無視してもテストは成功する。また、セッション停止の直前に `session.instanceWorld` を `null` 化しているため、`DungeonInstanceWorldService.destroyNow`、ワールド登録解除、アンロード経路もこのテストでは検証されない。
- 影響: 視認距離外の Dungeon Mob が将来の Mob/AI 実装変更で自動破棄され、部屋の `liveMobsByRoom` に残った UUID と実体が不整合になる回帰を自動検知できない。ワールド破棄順序や回収失敗の回帰も同じテストでは検知できない。
- 修正方針: DungeonService のフラグ設定テストとは別に、視認距離外の ENEMY に `keepWhenUnobserved=true` を設定した `MobService.destroyEnemiesOutsideViewDistance` または `MobAiService.tick` の恒久テストを追加する。終了経路は InstanceWorld を `null` 化せず、ワールドの unload・runtime 登録解除・Mob 明示破棄を検証するテストへ分離する。
