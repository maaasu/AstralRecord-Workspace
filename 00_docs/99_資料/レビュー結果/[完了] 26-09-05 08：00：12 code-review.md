### AR-CODE-001 [低] 同一接触で Move と Teleport が連続するケースの恒久テスト不足
- 種別: `テスト不足`
- 対象: `10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/world/event/BaseWorldGatewayEventHandlerTest.java:36`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/world/event/BaseWorldGatewayEventHandler.java:63`
- 根拠: 設計書は `PlayerMoveEvent` と gateway 系 `PlayerTeleportEvent` を同じ GUI 起動要求へ統合し、gateway 内の連続 open を player UUID 単位で抑止する契約です。現在の恒久テストは移動イベントのみの連続と、移動イベントなしのテレポートを個別に検証しています。
- 問題: `PlayerMoveEvent` の直後に同一接触由来の gateway 系 `PlayerTeleportEvent` が発生する実際の競合順序を、テストが検証していません。
- 影響: `playersInGateway` と `pendingGuiOpen` の連携を変更しても、両イベントの連続発生時に GUI が二重起動する退行を検知できません。
- 修正方針: 同じプレイヤーで `onPlayerMove` の後に gateway 原因の `onPlayerTeleport` を呼び、1 tick 後の `guiEventHandler.open(player)` が 1 回だけであることを恒久テストで検証します。
- 修正対象候補: `10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/world/event/BaseWorldGatewayEventHandlerTest.java`
- 修正可否: `自動修正可`
