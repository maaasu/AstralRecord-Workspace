### AR-CODE-001 [中] 戦闘バランス設計書の命中式が旧仕様のまま
- 種別: `ドキュメント不整合`
- 対象: `00_docs/60_戦闘バランス設計書/01-戦闘計算.md:153`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/combat/service/DamageCalculator.java:154、10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/combat/service/DamageCalculator.java:166、00_docs/10_Plugin設計書/feature/14-combat/3-メソッド仕様/14_3-サービス.md:74`
- 根拠: 戦闘バランス設計書は `clamp(A_hit - E, 0, 100)` と常時の `random[0, 100) < H` を定義する一方、実装と feature/14-combat のメソッド仕様は下限を1%とし、100%時は乱数判定を省略して必中と定義している。
- 問題: 同じ命中・回避計算式の正本級設計書間で、最低命中率と100%命中時の振る舞いが矛盾している。
- 影響: 後続のバランス調整、実装変更、またはテスト追加時に、旧式を正として0%完全回避または100%時の非必中へ戻す判断を招く。
- 修正方針: 戦闘バランス設計書の命中式を `clamp(A_hit - E, 1, 100)` に更新し、100%では乱数を使わず必中、回避だけでは完全回避不能であることを明記する。
