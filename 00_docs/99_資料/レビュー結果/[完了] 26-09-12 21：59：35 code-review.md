## 指摘一覧

### AR-CODE-001 [低] 一時防御倍率のDamageService接続テストがない
- 種別: `テスト不足`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/combat/service/DamageService.java:970`
- 関連箇所: `10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/combat/service/DamageCalculatorDesignTest.java:268`
- 根拠: 一時防御倍率の純粋な防御曲線はテストされているが、`TemporarySkillEffectService` から `DamageService` を経て `DamageCalculator` へ渡る接続と、攻撃種別ごとの防御参照は直接検証されていない。
- 問題: `DamageService` の設定経路や対象防御の接続が将来変更された場合、ホーリースマッシュが付与したMob防御低下が実ダメージへ反映されない回帰を、既存の直接計算テストでは検出できない。
- 影響: ホーリースマッシュだけでなく、将来 `TemporarySkillEffectService` の防御倍率を利用する全スキルの戦闘結果が設計値と不一致になる可能性がある。
- 修正方針: 既存の共通 `DamageService` テストへ、Mobへ一時防御倍率を付与した状態で `MELEE`・`RANGED`・`MAGIC` の攻撃結果が倍率なしより増加する接続テストを追加する。
- 修正対象候補: `10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/combat/service/DamageServiceMobDesignTest.java`
- 修正可否: `自動修正可`
