- 対象: `40_filebase/30.features.skill/v1.adventurer_quick_shot.yml:12`

- 根拠: `00_docs/60_戦闘バランス設計書/02-成長曲線.md` の「skill の発動経路」は、標準経路であるアクションリングの単体攻撃 skill を初期150～180%とし、左クリック連打 skill だけを120～140%の別枠としている。`13_1-モデル定義.md` と `SkillBindSession` は active skill を action ring へ優先配置する。
- 問題: クイックショットはアクションリング標準の active skill であるにもかかわらず、Lv.1 110%（Lv.5 132%）である。低威力を選ぶ根拠や、左クリック連打 skill として扱う経路も仕様化されていない。

- 修正方針: 低消費・短CDという役割を保ったまま、アクションリング基準を満たす倍率／CDへ再計算するか、左クリック連打 skill とする発動経路と受入DPSを設計書・実装へ明記する。

### AR-CODE-002 [低] 発射音が二重に再生される

- 対象: `40_filebase/30.features.skill/v1.adventurer_quick_shot.yml:41`

- 根拠: `SkillService.executeSkillNow` は `definition.onCast.sound` を executor 実行前に再生する。クイックショットはYAMLで同じ矢発射音を指定し、executorでもpitch 1.25の同音を再生する。

- 修正方針: 高pitchのexecutor演出を正とし、YAMLの`onCast.sound`を削除する。併せて音を一度だけ再生するテストを追加する。
- 修正対象候補: `40_filebase/30.features.skill/v1.adventurer_quick_shot.yml`
