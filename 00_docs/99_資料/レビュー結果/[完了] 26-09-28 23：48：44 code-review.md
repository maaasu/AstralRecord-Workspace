### AR-CODE-001 [中] 再入した別プレイヤーの反撃が元スキルの耐久判定を消費する
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/combat/service/DamageService.java:1435`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/service/SeijakuIssenSkillRuntimeService.java:226`
- 根拠: `SkillCombatService.applyHit` はスキル攻撃全体を `withSkillAttackWear` で囲む。`DamageService.applyDamage` はその内側で `tryCounterDirectDamage` を呼び、ソードマスターの反撃 `firstHit` が共有の `combatService.hit` から同じ `DamageService` に再入する。反撃は別プレイヤーの攻撃だが `ThreadLocal` の発動状態をそのまま参照する。
- 問題: 反撃側の有効命中が元スキルの `SkillAttackWear.claim()` を実行する。元スキルの攻撃は反撃で無効化される一方、同じ発動の後続有効命中では攻撃側の武器・アクセサリー耐久抽選が抑止される。
- 影響: ソードマスターの構えに命中したパラディンの多段スキルで、反撃側の装備耐久が発動元の判定状態に混入し、元スキルの最初の有効命中でも耐久抽選が発生しない場合がある。
- 修正方針: 発動状態を発動者に紐付け、再入した別攻撃者の命中には適用しない。反撃の通常耐久判定は維持する。

- 修正可否: `自動修正可`
