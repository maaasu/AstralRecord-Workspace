### AR-CODE-001 [低] Hub到着抑止情報の期限切れエントリが残留する
- 種別: `パフォーマンス`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/shared/challenge/ChallengeWaitingHubArrivalGuard.java:15`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/boss/service/BossChallengeService.java:636`
- 根拠: `suppressedUntilNanosByPlayer` は Hub 到着時に UUID を登録し、期限切れ判定時には削除するが、プレイヤーが期限内に判定入力をせずログアウトした場合に削除する経路がない。
- 問題: 期限切れ後も入力判定されない UUID がプラグイン稼働中の map に残り続ける。
- 影響: プレイヤーの再接続・入れ替わりが繰り返されると、不要な UUID エントリが蓄積する。
- 修正方針: 到着抑止ガードに UUID 単位の削除操作を追加し、Boss／Dungeon の既存ログアウト処理から呼び出して、退出プレイヤーの状態を即時破棄する。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/shared/challenge/ChallengeWaitingHubArrivalGuard.java`
