### AR-CODE-001 [中] legacy RGB 色コードが一部露出する
- 種別: `バグ/アルゴリズム`
- 対象: `30_web/AstralRecordWeb/AstralRecordWeb/Pages/Admin/History/HistoryPageModel.cs:93`
- 関連箇所: `30_web/AstralRecordWeb/AstralRecordWeb/Pages/Admin/History/Mobs.cshtml:35`
- 根拠: Minecraft 1.16 以降の legacy RGB 表現は `&x&F&F&5&5&5&5` または `§x§F§F§5§5§5§5` の連続コードである。
- 問題: `x` を未知文字として出力し、後続の各桁を通常色として解釈するため、`&x` または `§x` が画面へ露出する。
- 影響: 未対応コードを非表示にする要件を満たさず、意図しない色でモブ名が表示される。
- 修正方針: RGB シーケンス全体を先に認識して消費し、既存 CSS で表現できないコードを表示しない。
- 修正対象候補: `30_web/AstralRecordWeb/AstralRecordWeb/Pages/Admin/History/HistoryPageModel.cs`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
