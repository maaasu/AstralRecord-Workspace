## 指摘一覧

### AR-CODE-001 [低] showitem tooltip の lore 除去条件が prefix 判定になっている
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/item/service/ItemChatShareService.java:87`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/item/service/ItemTransferSupport.java:98`
- 根拠: `ItemChatShareService.share` は showitem 用 clone の lore 除去に `ItemTransferSupport.stripDisplayLore` を使用し、同メソッドは指定された文字列を lore の prefix として判定する。現在の BAG 操作案内は完全一致の固定文言で生成される。
- 問題: `クリックでホットバースロットに設定（武器専用）` のように、正規のアイテム説明 lore が操作案内の文言で始まる場合、その説明まで showitem tooltip から削除される。設計が要求するのはインベントリ表示専用の操作案内の除去であり、同じ prefix を持つ別の説明文の除去ではない。
- 影響: 一部アイテムの共有 tooltip で、本来表示すべき説明 lore が欠落する。現行の固定文言だけでは発生しないが、filebase の説明追加や将来の操作案内拡張で再発し得る。
- 修正方針: showitem の除去対象を、現行の操作案内の完全一致（または操作案内を識別できる構造化 marker）に限定する。既存の `ItemTransferSupport` を他用途が prefix 前提で利用しているため、共通メソッドの意味を変える場合は全呼び出し元を確認する。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
