- 種別: `仕様不整合`
- 対象: `40_filebase/10.features.item/equipment/v1.melkor_plate.yml:3`
- 関連箇所: `40_filebase/65.features.dungeon/v1.iluvatar_sanctum.yml:3`
- 根拠: `00_docs/50_Filebase設計書/feature/16-equipment.md` と `00_docs/50_Filebase設計書/feature/65-dungeon.md` は、対象コンテンツから得る更新装備の progression を対象コンテンツの `P` から `P+1` とする。万象聖域の遺跡は progression 8、新規装備は progression 10 である。

- 修正方針: `melkor_plate` の progression を `9` に変更し、万象聖域の遺跡からの更新報酬として扱う。
