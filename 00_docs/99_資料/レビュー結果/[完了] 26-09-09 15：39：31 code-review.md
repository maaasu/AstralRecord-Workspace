- 根拠: 糸の拘束は8反復で各反復に最大39回の補正を行い、非ゼロ補正が毎回rayTraceImpactを呼ぶ。針・ノード・区間検査を含め最大353回のhelper呼び出しがあり、各helperはさらに最大33回の同期探索を行う。

- 影響: 同時キャスト数に比例してメインスレッドの照会量が増える。
- 修正方針: 拘束反復を減らして収束後は終了し、移動・衝突・糸長のテストと通常ケースの探索回数を確認する。
