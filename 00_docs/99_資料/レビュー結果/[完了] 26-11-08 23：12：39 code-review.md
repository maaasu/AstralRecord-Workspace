### AR-CODE-003 [中] Javaの描画順により白い背景で現在地の文字を読みにくい
- 種別: `バグ/アルゴリズム`
- 対象: `50_resourcepack/scripts/generate-quest-hud-java.py:233`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/hud/view/LocationHudGlyphs.java:230`
- 根拠: Java 26.2のGUIはパイプラインとテクスチャ順に字形を並べ、GUI_TEXTの深度テストは無効。
- 問題: パネルの背景と文字が別のテクスチャにあるため、半透明の塗りが明るい背景と白文字の両方の後に重なる場合がある。白地と白文字の境界がほとんど見えなくなる。
- 影響: 雪原や明るい空を背景にした場合、現在地や挑戦情報を読み取れないことがある。
- 修正方針: 文字と同じフォントで位置を1ピクセルずらした暗い影を先に描画し、テクスチャ順によらず輪郭を視認できるようにする。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
