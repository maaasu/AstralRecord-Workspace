### AR-CODE-001 [高] Java版プレートの背景が本文の手前に出る
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/shared/display/DisplayTextService.java:64`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/shared/display/DisplayTextService.java:620`
- 根拠: Java 1.21.11 の DisplayRenderer は CENTER billboard のローカル正のZをカメラ側へ向ける。
- 問題: 背景をローカル正のZへ移動すると本文を覆う。
- 影響: 討伐で獲得したアイテム名や数量が暗くなり、背景の不透明な箇所では隠れる。
- 修正方針: 背景をローカル負のZへ移動する。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/shared/display/DisplayTextService.java`
- 修正可否: `自動修正可`

- 修正状態: `修正済み`

### AR-CODE-002 [中] 統合版の枠に登場と退場の演出がない
- 種別: `仕様不整合`
- 対象: `50_resourcepack/bedrock/animations/combat_reward_plaque.animation.json`
- 関連箇所: `00_docs/10_Plugin設計書/feature/12-mob/3-メソッド仕様/12_3-戦闘.md:145`
- 根拠: 設計では統合版のプレートモデルにクライアント側の登場と退場を定義する。
- 問題: 行数に応じた変形と正面向きの制御だけがあり、表示開始と終了に演出がない。

- 修正方針: モデルを短く拡大して登場させ、6秒の表示寿命に合わせて退場をフェードさせる。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`

### AR-CODE-003 [中] Java版のレア点滅用画像が通常のレア枠と同じ
- 種別: `バグ/アルゴリズム`
- 対象: `50_resourcepack/scripts/generate-combat-reward-plaque.py:253`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/shared/display/DisplayTextService.java:602`
- 根拠: Java版のレア枠は異なる字形へ切り替えて星を点滅させる。
- 問題: 生成ループのスタイルは normal または rare で、点滅用の描画でも sparkle の条件が常に偽になる。
- 影響: 字形が切り替わっても表示が変わらず、レア枠の星が見えない。
- 修正方針: 点滅用だけ星を有効にし、全行数の差分を再生成する。
- 修正対象候補: `50_resourcepack/scripts/generate-combat-reward-plaque.py`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-004 [高] 実マスターの通常モブレア報酬が枠から外れる
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/mob/service/MobDropPresentationService.java`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/shared/display/CombatRewardPlaque.java`
- 根拠: 通常モブの当選率0.1%のメリアンのチャームなどは、数量・確率・レアの印を一行に入れると推定幅182pxになる。
- 問題: 一行に収まらない印のためにプレート全体が従来表示になる。
- 影響: 既存の通常モブを討伐してレアが当選しても、レアのプレートが表示されない。
- 修正方針: 確率と数量を保持し、アイテム行に入らない印はプレートの見出しに出す。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
