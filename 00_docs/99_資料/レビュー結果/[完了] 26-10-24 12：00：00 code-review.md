## 指摘一覧

### AR-CODE-001 [高] ignored ファイルをマージ前の保護対象から漏らしている
- 種別: `バグ/アルゴリズム`
- 対象: `.codex/skills/astralrecord-git-worktree-develop/scripts/merge_safety_check.py:20`
- 関連箇所: `.codex/skills/astralrecord-git-worktree-develop/references/unrelated-changes.md:3`
- 根拠: 分離手順は対象外の内容とステージ状態を維持し、すべての未追跡差分へ適用すると定めている。
- 問題: パス収集に使う git status --porcelain=v1 -z -uall は ignored ファイルを列挙しない。作業ブランチが同名ファイルを追跡すると、チェックは通るが早送りマージがローカル内容を上書きする。一時リポジトリで .gitignore に cache.txt を登録し、作業ブランチで git add -f したファイルと develop 側のローカルファイルを用意して再現した。
- 影響: 対象外のローカルファイルの内容が無警告で失われる。
- 修正方針: ignored ディレクトリ内部を個別ファイルとして列挙する --ignored=traditional を -uall と併用し、同名衝突と独立した ignored ファイル保持の回帰テストを追加する。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
