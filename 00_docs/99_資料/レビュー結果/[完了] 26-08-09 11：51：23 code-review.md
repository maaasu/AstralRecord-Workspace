### AR-CODE-001 [中] 開始部屋の座標選定が設計契約と一致しない
- 種別: `仕様不整合`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/dungeon/generation/DungeonLayoutPlanner.java:114`
- 関連箇所: `00_docs/10_Plugin設計書/feature/32-dungeon/32_1-モデル定義.md:19`
- 根拠: 設計書は X 座標が最小の部屋を開始部屋として一意に選ぶ契約だが、実装は部屋矩形の minX ではなく centerX、次に centerZ を比較している。
- 問題: 幅が異なる部屋では左端が最も小さい部屋と中心が最も小さい部屋が異なり、マスタと seed から得る開始部屋が設計契約から外れる。
- 影響: 同じ生成結果を設計書どおりに検算できず、開始部屋とそこから決まる距離、ボス部屋、進行順が想定と異なる可能性がある。
- 修正方針: 開始部屋比較を bounds.minX、bounds.minZ、room ID の順へ変更し、複数 seed でこの順序を固定する純粋計算テストを追加する。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-002 [中] 自主離脱の転送失敗時に参加者追跡を先に失う
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/dungeon/service/DungeonService.java:476`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/dungeon/service/DungeonService.java:543`
- 根拠: removeParticipant は participants、sessionIdByParticipant、returnLocations を削除した直後に非同期 teleportPlayerAsync を開始し、その Boolean 結果を確認せず離脱完了メッセージを送る。
- 問題: 転送が false または例外で失敗すると、プレイヤーはインスタンス内に残り得る一方でセッションからは未追跡となる。入場転送中の leave と競合した場合も、帰還後に保留中の入場転送で再びインスタンスへ入る余地がある。
- 影響: ブロック保護対象の一時 World にプレイヤーが取り残され、セッション終了・World 回収・再試行の対象から外れる可能性がある。
- 修正方針: 入場転送 Future と離脱中状態を参加者単位で保持し、保留中の入場転送完了後に帰還転送する。帰還成功または既にインスタンス外であることを確認してから参加状態を削除し、失敗時は追跡を維持して再試行可能なエラーを通知する。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-003 [低] ゲートの物理的な閉鎖・開放契約をテストしていない
- 種別: `テスト不足`
- 対象: `10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/dungeon/generation/DungeonBlockPlannerTest.java:20`
- 関連箇所: `00_docs/10_Plugin設計書/feature/32-dungeon/32_3-処理契約.md:14`
- 根拠: 既存テストは各ゲートの座標数と Material だけを検証し、生成済みブロック平面上で閉鎖時に親子部屋間を通れず、対象ゲートだけを AIR にした時に通れることを確認していない。
- 問題: 通路幅の拡張、部屋開口、ゲート面の向きが組み合わさった際の横抜けや、ゲート開放後も壁が残る回帰を検出できない。

- 修正方針: baseY + 1 の最終 Placement から通行可能セルを作り、各接続について全ゲート閉鎖時は親子の spawn point 間が不可達、当該ゲート座標だけを開放した時は到達可能であることを幅優先探索で検証する。
- 修正対象候補: `10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/dungeon/generation/DungeonBlockPlannerTest.java`
- 修正可否: `自動修正可`
