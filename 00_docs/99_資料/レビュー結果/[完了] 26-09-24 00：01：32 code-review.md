## 指摘一覧

### AR-CODE-001 [高] 通常ドロップ通知が付与されないアイテムを獲得したと報告する
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/mob/service/MobDropPresentationService.java:217`
- 関連箇所: `10_plugin/AstralRecord/src/main/resources/player.properties:218`
- 根拠: `presentAndGrant` は付与処理を開始する前に `announceDropLogs` を呼ぶ。後続処理では装備の BAG slot 予約失敗で付与を中止し、通常アイテムは `grantedAmount()` が要求数未満になり得るほか、退出や演出取消でも付与されない経路がある。
- 問題: `P_5732` の文言は抽選結果だけが確定した時点で「獲得しました」と伝えており、実際に付与されたかを表していない。
- 影響: 所持品へ追加されないアイテムをプレイヤーが獲得したと、オンライン閲覧者へ誤って伝える。
- 修正方針: 通知を付与成功の報告ではなく、ドロップ抽選で当選した結果の通知として明示する。既存のレアドロップ通知と同じ抽選結果の記録タイミングを維持し、関連設計書も同じ意味に合わせる。
- 修正対象候補: `10_plugin/AstralRecord/src/main/resources/player.properties`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-002 [低] 公開報酬表示 API の JavaDoc が通常ドロップ通知を説明していない
- 種別: `コーディングルール違反`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/mob/service/MobDropPresentationService.java:152`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/mob/service/MobDropPresentationService.java:190`
- 根拠: 3つの public `presentAndGrant` overload の JavaDoc は結果表示と付与を説明するが、Mob カテゴリなしの経路で通常ドロップを全体通知する副作用を示していない。カテゴリ付き overload もレア通知だけを記載する。機能変更に伴う JavaDoc の更新は Plugin ガイドの要件。

- 修正方針: 各 public overload と共通処理の JavaDoc を通常・レアドロップ通知の条件に合わせる。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/mob/service/MobDropPresentationService.java`
