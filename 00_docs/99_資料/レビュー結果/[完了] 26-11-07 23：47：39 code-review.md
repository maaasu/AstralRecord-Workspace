- 関連箇所: `60_tool/skilltree-editor/src/SkillTreeEditor.Server/Services/SpawnerPlanningService.cs:234`

- 修正方針: 一覧候補を集めてから、個別読込と同じ方法で解決できたワールドだけを返す。
- 修正対象候補: `60_tool/skilltree-editor/src/SkillTreeEditor.Server/Services/SpawnerPlanningService.cs`

### AR-CODE-002 [中] 公開先の列挙に失敗すると旧地図を選択できない
- 種別: `バグ/アルゴリズム`
- 対象: `60_tool/skilltree-editor/src/SkillTreeEditor.Server/Services/SpawnerPlanningService.cs:24`
- 関連箇所: `60_tool/skilltree-editor/src/SkillTreeEditor.Server/Services/SpawnerPlanningService.cs:27`
- 根拠: 公開先のリンク検査と列挙の例外を一覧処理が扱わない。
- 問題: リンクされた公開先や、列挙直前に消えた公開先があると一覧がエラーになる。
- 影響: 旧形式の正常な地図まで一覧から利用できなくなる。
- 修正方針: リンクを辿らず、利用可能な公開先を個別読込と同じ方法で判定する。列挙時に公開先が消えた場合は旧形式の候補で処理を続ける。
- 修正対象候補: `60_tool/skilltree-editor/src/SkillTreeEditor.Server/Services/SpawnerPlanningService.cs`
- 修正可否: `自動修正可`
