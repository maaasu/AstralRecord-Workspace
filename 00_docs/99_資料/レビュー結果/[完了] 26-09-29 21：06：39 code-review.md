### AR-CODE-001 [中] 跳躍中に倒されても着地攻撃が発動する
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/mob/skill/ryushel/RyushelFlowerLeapMobSkillExecutor.java:151`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/mob/service/MobAiService.java:263`
- 根拠: 跳躍中のtick処理がMob実体の存続だけを確認し、死亡状態を判定していなかった。跳躍中はscriptedActionが有効となる。
- 問題: HPが0になった後も跳躍を続け、着地時に攻撃と弱点効果を適用できる。
- 影響: 討伐後にプレイヤーが被弾し、死亡したボスの戦闘処理が継続する。
- 修正方針: 各跳躍tickでMobState.DEADを確認し、死亡時は重力とscriptedActionを戻して中断する。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/mob/skill/ryushel/RyushelFlowerLeapMobSkillExecutor.java`
