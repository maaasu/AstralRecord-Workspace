- 修正方針: scheduler mockで同期タスクの初回遅延0・周期20tick・停止時cancelを検証し、停止時のPLAYERリーチ0復帰を追加する。併せてBASE以外、spawn未解決、ray trace missの各拒否条件を恒久テストへ追加する。
