### AR-CODE-001 [低] 実 GUI 経路の両替アイコン状態に対する回帰テストが不足
- 種別: `テスト不足`
- 対象: `10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/currency/view/CurrencyGuiViewTest.java:31`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/menu/event/MenuOpenEventHandler.java:703-711,751-758,905-944`
- 根拠: `CurrencyGuiViewTest.rendersExchangeShortcutOnlyWhenUnlocked` は `CurrencyGuiView.render` へ `false -> true -> false` を直接渡し、slot 51 の pane/icon を確認している。一方、実際の通貨 GUI は初回表示、ページ移動、プレイヤーインベントリからの収納成功後に `MenuOpenEventHandler` が `exchangeUnlocked(player)` を再評価して `MenuView.openCurrency` へ渡す経路で状態を決める。これらの呼び出し元経路を通るテストは、今回の直接関連テストには追加されていない。
- 問題: View 単体テストが通っても、初回表示または各再描画経路で解除状態の引き渡しを忘れたり、古い状態を渡したりする回帰を検出できない。現行コードでは各経路が `exchangeUnlocked(player)` を渡しており、直ちに不具合が確認できるものではないが、今回の仕様変更が対象とする「表示状態の再描画」を実 GUI 経路として固定できていない。
- 影響: ページ移動や通貨収納後に、星核所持状態と異なる両替アイコンが表示される変更を将来導入しても、既存テストが見逃す可能性がある。
- 修正方針: `MenuOpenEventHandler` または `MenuView` を通るテストを追加し、条件未達の初回表示、解除済み表示、ページ移動または収納成功後の再描画で slot 51 がそれぞれ pane/icon になることを検証する。既存の `CurrencyGuiViewTest` の直接描画テストは補助として維持する。
