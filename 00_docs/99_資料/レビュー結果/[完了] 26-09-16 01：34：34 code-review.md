- 対象: `20_api/AstralRecordApi/AstralRecordApi/Controllers/WebPlayerProfileController.cs:50`
- 関連箇所: `20_api/AstralRecordApi/AstralRecordApi/Repositories/WebPlayerProfileRepository.cs:42`
