### AR-CODE-001 [中] 凍結時にアルダ巨神兵の露出状態が残る
- 種別: `仕様不整合`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/boss/service/BossMechanicService.java:260`
- 関連箇所: `00_docs/10_Plugin設計書/feature/26-boss/3-メソッド仕様/26_3-サービス.md:255`
- 根拠: 凍結中は予約済み通常ギミックを予兆・専用行動状態ごと取り消す設計だが、Shield破壊露出は pending 外の `BossRuntime.exposureUntilTick`、一時効果、Display、`scriptedAction` として管理されている。
- 問題: 凍結分岐では `processAldaExposure` を呼ばないだけで `cleanupAldaExposure` も呼ばれないため、露出中に凍結すると発光、被ダメージ倍率、Display、専用行動状態が凍結解除まで残る。
- 影響: アルダ巨神兵だけ凍結によるギミック取消が完了せず、実装と設計書の挙動が不一致になる。
- 修正方針: 凍結分岐で `cleanupAldaExposure(boss.instanceId(), runtime)` を呼び、サンバード30%必殺とは独立して露出状態を即時解放する。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/boss/service/BossMechanicService.java`
