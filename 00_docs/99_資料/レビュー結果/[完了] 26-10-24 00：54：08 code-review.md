### AR-CODE-001 [高] スキル効果の射程を判定せず遠距離の対象へ命中させる
- 種別: `バグ/アルゴリズム`
- 対象: `60_tool/skilltree-editor/src/SkillTreeEditor.Server/Services/BalanceCombatSimulation.cs:174`
- 関連箇所: `60_tool/skilltree-editor/src/SkillTreeEditor.Server/Services/BalanceSkillMeleeProfiles.cs:28`
- 根拠: Plugin の `SkillTargetingService.java:214` 以降は射程と当たり判定半径を使って対象を抽出する。初回の共通モデルではスキルの効果に射程が付かず、固定距離の対象を範囲外でも処理していた。
- 問題: 射程外の敵へのダメージや状態異常を有効命中として計上できる。
- 影響: 射程境界を超えた条件の DPS・撃破時間・状態異常寄与が Plugin の実戦闘より高くなる。
- 修正方針: executor ごとの対象選択に応じて Range と HitRadius を効果へ設定し、対象向け効果の実行前に固定距離と敵の当たり判定から射程内を確認する。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-002 [中] 0ダメージの会心を有効命中として後続効果へ渡す
- 種別: `バグ/アルゴリズム`
- 対象: `60_tool/skilltree-editor/src/SkillTreeEditor.Server/Services/BalanceCombatSimulation.cs:215`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/executor/active/swordmaster/SwordmasterSkillSupport.java:270`
- 根拠: Plugin の `Hit.landed()` は回避されず、HP または盾への実ダメージが正の場合だけ成立する。初回モデルは命中ロール成功をそのまま landed としていた。
- 問題: 防御・耐性などで最終ダメージが 0 の会心でも、会心時追撃や命中時状態異常を発動できる。
- 影響: 0ダメージ境界での追加ダメージ・条件付与・資源回復が過大になる。
- 修正方針: 敵 HP または盾への適用ダメージが正である場合だけ landed とし、critical はその landed に従属させる。
- 修正対象候補: `60_tool/skilltree-editor/src/SkillTreeEditor.Server/Services/BalanceCombatSimulation.cs`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-003 [中] 超星会心だけの命中で会心時効果が発動しない
- 種別: `バグ/アルゴリズム`
- 対象: `60_tool/skilltree-editor/src/SkillTreeEditor.Server/Services/BalanceSkillDamage.cs:54`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/executor/active/swordmaster/SwordmasterSkillSupport.java:275`
- 根拠: Plugin の `Hit.critical()` は有効命中時に `DamageResult.critical()` または `superStarCritical()` のどちらかで成立する。初回モデルでは通常会心の成否だけを会心時効果の判定へ渡していた。
- 問題: 通常会心は外れ、超星会心だけが成立した一撃で、会心依存の追撃を落とす。
- 影響: 超星会心率を持つ構成の期待ダメージとスキル寄与が過小になる。
- 修正方針: 通常会心と超星会心の論理和を会心結果として返し、有効命中後だけ会心トリガーへ渡す。
- 修正対象候補: `60_tool/skilltree-editor/src/SkillTreeEditor.Server/Services/BalanceSkillDamage.cs`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-004 [中] 近接スキルの状態異常を魔法攻撃力でスナップショットする
- 種別: `バグ/アルゴリズム`
- 対象: `60_tool/skilltree-editor/src/SkillTreeEditor.Server/Services/BalanceSkillMeleeProfiles.cs:161`
- 関連箇所: `60_tool/skilltree-editor/src/SkillTreeEditor.Server/Services/BalanceCombatSimulation.cs:270`
- 根拠: Plugin の `ConditionService.java:469` 以降は要求の attackType から状態異常の snapshotPower を計算する。初回の近接スキル状態効果は共通効果の既定 `MAGIC` を継承していた。
- 問題: 近接由来の BURNING や SHOCKED などの継続ダメージに魔法攻撃力を使う。
- 影響: 近接攻撃と魔法攻撃のステータス差が大きい構成で、DoT ダメージと撃破時間が実戦闘からずれる。
- 修正方針: 近接 executor の状態効果に `AttackType: "MELEE"` を明示し、実 Plugin が渡す攻撃種別と同じ snapshotPower を使う。
- 修正対象候補: `60_tool/skilltree-editor/src/SkillTreeEditor.Server/Services/BalanceSkillMeleeProfiles.cs`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
