### AR-CODE-001 [中] モバイルでプレイヤーメニューのボタン名が消える
- 種別: `バグ/アルゴリズム`
- 対象: `30_web/AstralRecordWeb/AstralRecordWeb/Pages/Shared/_Layout.cshtml:71`
- 関連箇所: `30_web/AstralRecordWeb/AstralRecordWeb/wwwroot/css/portal.css:209`
- 根拠: ログイン時のメニューボタンから明示的な `aria-label` が外れた。767px以下では `portal.css` が末尾の `span` を非表示にする。先頭のアイコンは `aria-hidden` が指定され、359px以下では `journal.css` でも非表示になる。
- 問題: 767px以下ではボタンの読み上げ名が空になり、359px以下では見える文字とアイコンの両方が消える。
- 影響: スクリーンリーダーでメニューボタンの用途を判別できない。320px幅では、図鑑・メール・管理画面などへの入口が中身のない小さなボタンになる。
- 修正方針: 共有ヘッダーでモバイル時もメニューの文字を表示し、320px幅と一般的なモバイル幅でボタン名と文字の視認性を確認する。
- 修正対象候補: `30_web/AstralRecordWeb/AstralRecordWeb/wwwroot/css/portal.css`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
