## 修正結果

- `AR-CODE-001`: 修正済み - `TeleporterService` に `accountId + waystoneId` 単位の解除中キーを追加し、解除 API 完了前の連打で Gold が複数回消費されないようにした。成功・失敗・例外・プレイヤー退出・停止時に解除中キーを破棄する。
- `AR-CODE-002`: 修正済み - `WaystoneDefinitionRepository` の保存キーを `worldName` に変更し、読み込みは `worldName` 優先、旧 `world` キーも互換として受け入れるようにした。
- `AR-CODE-003`: 修正済み - `TeleporterPlayerEventHandler` の Join 同期を固定 40 tick 一回実行から、AstPlayer 確定までの上限付きリトライへ変更した。解除状態 API 取得失敗時もロック表示フォールバックの packet 同期を実行する。
- `AR-CODE-004`: 修正済み - `/teleporter remove` の対象なしメッセージを専用 ID に変更し、`/teleporter list` の各行を `PlayerMsgId` / `player.properties` 経由にした。
