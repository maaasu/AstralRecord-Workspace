### AR-CODE-001 [中] 中断された跳躍で重力が復帰しない
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/mob/skill/clayguard/ClayGuardLeapMobSkillExecutor.java:140`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/mob/skill/clayguard/ClayGuardLeapMobSkillExecutor.java:154`
- 根拠: `startLeap` は開始時に `Entity#setGravity(false)` を設定する一方、Mob実体が無効化・別ワールド化した中断分岐では `cancel()` だけを実行する。
- 問題: 跳躍中に実体が残ったまま中断された場合、重力が false のまま残る。
- 影響: クレイガードが以後のAI移動・リセット時にも浮遊状態になる可能性がある。
- 修正方針: 中断分岐を含む終了処理を共通化し、有効な実体へ開始前の重力設定を必ず復元する。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/mob/skill/clayguard/ClayGuardLeapMobSkillExecutor.java`

### AR-CODE-002 [中] 甲羅打ちの実効射程がAI判定より短い
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/mob/skill/mossshell/MossShellShellBashMobSkillExecutor.java:58`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/mob/service/MobAiService.java:726`
- 根拠: AIとMobスキルの発動距離は水平二軸で判定するが、甲羅打ちだけは頭上の `origin` とプレイヤー足元位置の三次元距離で再判定している。
- 問題: 水平距離が約1.48mを超えると、設定値2mの発動距離内でも高さ1.35mの差で甲羅打ちが不発になる。
- 影響: モスシェルは意図した近接範囲の外側で詠唱だけを消費し、通常攻撃へ戻るまでの行動が不自然になる。
- 修正方針: 同一ワールド確認後、AIと同じ水平二軸の距離で射程を判定する。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/mob/skill/mossshell/MossShellShellBashMobSkillExecutor.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
