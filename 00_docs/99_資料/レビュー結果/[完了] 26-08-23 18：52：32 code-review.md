### AR-CODE-001 [高] PLAYER NPC の Mob TextDisplay が疑似 Player 表示と連動しない
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/shared/display/OverheadDisplayService.java:171`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/mob/service/NpcPlayerSkinPacketService.java:323`
- 根拠: 設計書は PLAYER NPC について実体 Entity を viewer ごとに隠し、同じ位置へ疑似 Player を送信すると定義している。一方、頭上表示は実体 Mob Entity に TextDisplay を passenger として接続する設計であり、実装も `mobDisplayAnchor` で実体 Entity をアンカーにしている。
- 問題: 疑似 Player 表示開始時に隠されるのは実体 Entity 本体だけで、実体 Entity に紐付いた Mob 用 TextDisplay の viewer 単位の非表示・疑似 Player 位置への置換がない。
- 影響: 添付画像の `Lv.1 ログインボーナス案内人` / `HP` 表示が疑似 Player の下側に残り、頭上表示が低い位置・不自然な位置に見える。これはランダムな別表示ではなく、通常の Mob 頭上表示が残ったもの。
- 修正方針: PLAYER NPC の疑似 Player 表示ルートで Mob 用 TextDisplay も viewer 単位に隠すか、疑似 Player をアンカーとする表示ルートへ統合し、表示対象・位置・破棄を同じライフサイクルで管理する。
- 修正対象候補: `複数`
- 修正可否: `設計判断待ち`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-002 [中] 疑似 Player の内部 Profile 名が通常の名前タグとして表示される
- 種別: `仕様不整合`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/mob/service/NpcPlayerSkinPacketService.java:543`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/mob/service/NpcPlayerSkinPacketService.java:327`
- 根拠: 疑似 Player の GameProfile 名を `npc_` + UUID 断片として生成し、その Profile を Player spawn packet でクライアントへ送信している。名前タグを非表示にする処理は確認できない。
- 問題: クライアントが Profile 名を Player の標準名前タグとして描画するため、添付画像上部に `npc_4d47c6e8bba2` が表示される。
- 影響: プレイヤー向け NPC 表示に内部的な生成 ID が露出し、想定している NPC 名表示と異なる不自然なテキストになる。
- 修正方針: 疑似 Player の名前タグをクライアント側で表示しない packet/team/metadata 経路を設計し、通常の NPC 表示名とは分離する。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/mob/service/NpcPlayerSkinPacketService.java`
- 修正可否: `要確認`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-003 [中] 疑似 Player の頭部向きが実体 Mob の lookAt と同期されない
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/mob/service/NpcPlayerSkinPacketService.java:364`
- 関連箇所: `複数`
- 根拠: stationary NPC の AI は実体 Mob に `lookAt` を実行しているが、疑似 Player の移動・頭部 packet は `instance.currentLocation().getYaw()` を使っている。実体 Mob の head yaw/head pitch、または `MobInstance` の headYaw/headPitch を疑似 Player の packet 送信へ渡す処理はない。
- 問題: 実体 Mob の視線変更が疑似 Player の頭部へ反映されず、疑似 Player は初期の body/location yaw のまま表示される。
- 影響: 添付画像のように、プレイヤーを見ているはずの NPC の頭が動かない。移動同期と視線同期が別の回転値を参照している。
- 修正方針: 実体 Mob の body yaw と head yaw/pitch を明確に取得・保持し、疑似 Player の teleport/look/head-rotation packet へそれぞれ同期する。5 tick の viewer 更新契約も維持する。
- 修正対象候補: `複数`
- 修正可否: `要確認`
- 確信度: `高`
- 修正状態: `修正済み`
