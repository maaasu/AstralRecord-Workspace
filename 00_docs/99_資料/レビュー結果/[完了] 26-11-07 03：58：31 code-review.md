### AR-CODE-001 [中] 統合版の武器通常攻撃が共有 CT と実行結果を反映しない
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/service/SkillActionRingService.java`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/item/service/ItemWeaponAttackService.java`
- 根拠: 武器通常攻撃の発動は WEAPON_NORMAL_ATTACK_COOLDOWN_ID を使用し、結果を返す発動経路が存在する。
- 問題: フォームは通常攻撃の定義から CT キーを選び、発動は戻り値が void の経路で呼び出していた。
- 影響: CT 中でも残り0秒と表示され、発動に失敗しても成功の通知が出る。
- 修正方針: 統合版では共有 CT キーで残り時間を取得し、発動の結果が成功の場合にだけ成功を通知する。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/service/SkillActionRingService.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
