## 指摘一覧

### AR-CODE-001 [中] 地形や戦闘対象への使用がスキル操作に届かない
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/shared/interaction/VanillaInteractionResolver.java`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/player/event/PlayerModeEventHandler.java`
- 根拠: 統合版の主手武器による使用はスキル候補を作る。Geyser はブロックやエンティティへの操作をそれぞれの Java 操作として送信できる。
- 問題: 汎用バニラ候補は通常の地形もワールド操作として取得する。エンティティへの使用はプレイヤーモードの汎用ガードにも取得される。
- 影響: 地面や戦闘対象に照準を合わせた状態で、スキル選択や発動が行われない。
- 修正方針: 統合版の主手武器操作に限り、非操作ブロックと汎用エンティティ操作の候補を除外し、スキル候補で処理する。NPC、装置、操作可能ブロックを優先する。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
