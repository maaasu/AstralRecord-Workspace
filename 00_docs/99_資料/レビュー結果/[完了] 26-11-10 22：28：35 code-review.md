### AR-CODE-001 [低] ノクス武器の編集原稿でパーティクル指定が欠落する

- 種別: `仕様不整合`
- 対象: `50_resourcepack/blockbench/items/nox_bow.java.bbmodel:1`
- 関連箇所: `50_resourcepack/assets/astralrecord/models/item/custom/nox_bow.json`
- 根拠: 配布モデルにはパーティクル用テクスチャがある。Blockbench Web 5.2.2 で剣・弓の待機と引き3段階・杖の編集原稿を開いて再書き出しすると、配布モデルにあるパーティクル用の参照が出力されない。
- 問題: Java 版の編集原稿6点で、テクスチャの particle 指定が無効になっている。
- 影響: 原稿から再書き出しすると配布モデルのパーティクル用テクスチャが失われる。
- 修正方針: 対象6点の particle 指定を有効にし、編集元台帳のハッシュを更新する。

- 修正可否: `自動修正可`
