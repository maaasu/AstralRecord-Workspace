### AR-CODE-001 [低] API 詳細レスポンス設計に variant 契約が反映されていない
- 種別: `ドキュメント不整合`
- 対象: `00_docs/20_API設計書/feature/16-mob/1-モデル定義/16_1.00-モデル定義.md:14`
- 関連箇所: `00_docs/10_Plugin設計書/feature/12-mob/12_1-モデル定義.md:33`
- 根拠: Plugin 設計は `MobTemplate.variant` を `GET /api/mob/{mobId}` 由来のモデルとして定義し、同文書の入出力モデルでは API 側レスポンス DTO 設計を正本として参照している。実装の `MobResponse` にも `MobVariantResponse? Variant` と全 variant フィールドが存在するが、API 設計の「Mob 詳細レスポンス」表には `variant` がなく、`MobVariantResponse` のモデル節も存在しない。
- 問題: 今回追加された `profession` / `villagerType` を含む variant 契約を、参照先である API 設計だけから確認できず、Plugin 設計・API 実装・API 設計の三者が一致していない。
- 影響: API 利用者や後続実装者が詳細レスポンスに `variant` が存在しないと判断し、DTO、fixture、互換性確認から外す可能性がある。実行時挙動には直ちに影響しない。
- 修正方針: API 設計の `MobResponse` 表へ nullable な `variant` を追加し、`MobVariantResponse` の各フィールド、型、nullable、値名の契約を Plugin/Filebase の現行仕様と一致する形で追記する。
- 修正対象候補: `00_docs/20_API設計書/feature/16-mob/1-モデル定義/16_1.00-モデル定義.md`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-002 [低] ZombieVillager の OldEnum profession 適用経路がテストされていない
- 種別: `テスト不足`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/mob/service/MobEntityController.java:400`
- 関連箇所: `10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/mob/service/MobEntityControllerTest.java:153`
- 根拠: モデル設計は `variant.profession` を Villager と ZombieVillager の双方へ適用する契約としており、実装も Villager の `setProfession` とは別に ZombieVillager 用の `setVillagerProfession` を名前指定で呼ぶ。追加テストは `Villager#setProfession` / `setVillagerType` と Java enum の Sheep だけを検証しており、test source 全体にも `ZombieVillager` / `setVillagerProfession` の検証がない。
- 問題: OldEnum 解決器は検証されているが、ZombieVillager 固有の setter 名への接続は未検証であり、`setVillagerProfession` 呼び出しの削除・名称誤り・引数取り違えがあっても今回の10テストは成功する。
- 影響: ZombieVillager を variant 付きで使用した際、職業だけが既定外見のまま無言で無視される回帰を自動検知できない。未知値を意図的に無視する実装のため、運用時にも原因を見つけにくい。
- 修正方針: `ZombieVillager` mock と小文字の `profession` を持つテンプレートを使い、`applyVariant` が `setVillagerProfession(Villager.Profession.*)` を呼ぶ恒久テストを同じ設計入力に紐付けて追加する。必要なら `setVillagerType` も同一契約内で併せて確認する。
- 修正対象候補: `10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/mob/service/MobEntityControllerTest.java`
- 修正可否: `自動修正可`
