### AR-CODE-001 [中] 空き枠の状態と枠数を判読しにくい

- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/item/service/ItemStackFactory.java:1532`

- 根拠: 両版の背景の中央色は RGB (21, 26, 40) で、濃い灰色の文字 RGB (85, 85, 85) とのコントラスト比は 2.33:1 でした。依頼ではコントラストを強めることと、付与状態による見え方の確認が指定されています。

- 修正方針: 空の見出し、枠数の上限、状態の説明に明るい中立色を使います。アイテム ID と装飾用の空き記号は濃い灰色のままとします。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/item/service/ItemStackFactory.java`
- 修正可否: `自動修正可`
