### AR-CODE-001 [高] 未割当のオーブ支払い予約を売却移動が無視する
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/inventory/service/InventoryService.java:5936`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/inventory/service/InventoryService.java:637`
- 根拠: `reserveOrbOperationPayment` は確定前に itemId 単位の `normalItemAmounts` と空の `normalEntryAmounts` を予約し、`takeOwnedMatchingItemAmount` は entry 単位の `reservedEntryAmount` だけを差し引いている。
- 問題: entry 割当前の予約素材も売却GUIから取り出せる。
- 影響: 後続のオーブ支払い確定時に、売却済み素材を支払える前提が崩れて不足・状態不整合になる。
- 修正方針: itemId 単位の未割当予約と entry 単位の割当済み予約の双方を共通可用数量から除外する。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/inventory/service/InventoryService.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-002 [高] ストレージ収納がオーブ支払い予約済み素材を移動する
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/inventory/service/InventoryService.java:2598`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/inventory/service/InventoryService.java:7345`
- 根拠: `moveOwnedItemToStorage` と `moveAllOwnedMatchingItemsToStorage` は batch の総数量をそのまま収納し、既定の `consumeOwnedItemBatch` は `respectReservations=false` で entry を消費する。
- 問題: 単一収納・全量収納の両方が予約済みの BAG/HOTBAR 素材をストレージへ移動・削除できる。
- 影響: オーブ支払い予約が保持する同一資産を別操作が先に移動し、予約と実 state の対応が崩れる。
- 修正方針: batch の可用数量を itemId・entry 予約後で計算し、ストレージ収納と全量収納も予約を尊重して未予約分だけを移動する。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/inventory/service/InventoryService.java`
- 修正可否: `自動修正可`

- 修正状態: `修正済み`
