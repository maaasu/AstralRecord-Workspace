### AR-CODE-001 [高] FLASH パーティクルへ不正な data を渡す
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/shared/effect/SharedParticleDefinitions.java:449`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/mob/skill/purpletree/PurpleTreeMobSkillExecutor.java:276`
- 根拠: 新規 FLASH 定義が Color を data に渡していた。Particle.FLASH の要求 data 型は Void で、ParticleDisplayService は data をそのまま表示 API へ渡す。
- 問題: 着弾時の表示で型不一致例外が生じる。
- 影響: 刈り払い、地砕き、呪域は着弾表示より後のダメージ判定へ進めない。
- 修正方針: FLASH 定義の data を省略する。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/shared/effect/SharedParticleDefinitions.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-002 [高] Mob API が Armor Trim を破棄する
- 種別: `仕様不整合`
- 対象: `20_api/AstralRecordApi/AstralRecordApi/Models/MobResponse.cs:132`
- 関連箇所: `40_filebase/40.features.mob/boss/v1.purple_tree_velg.yml:22`
- 根拠: Plugin は equipment.trim を解釈するが、API の MobEquipmentResponse に trim プロパティがなく、MobRepository が payload を同 DTO にデシリアライズして返す。

- 修正方針: API DTO と関連する Mob API モデル定義へ trim 契約を追加する。
- 修正対象候補: `20_api/AstralRecordApi/AstralRecordApi/Models/MobResponse.cs`
