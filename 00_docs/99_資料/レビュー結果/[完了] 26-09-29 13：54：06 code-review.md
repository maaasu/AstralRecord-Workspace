### AR-CODE-001 [高] FLASH パーティクルに必要な Color を渡さない
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/shared/effect/SharedParticleDefinitions.java:449`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/mob/skill/purpletree/PurpleTreeMobSkillExecutor.java:257`
- 根拠: 当初レビューは Void と誤認した。実際の Paper API 1.21.11 は `FLASH("flash", Color.class)` であり、data の省略で null が渡る。ParticleDisplayService はその値を表示 API へ渡す。
- 問題: 着弾エフェクトで data 不足の例外が生じ、攻撃タスクのキャンセルにも到達しない。
- 影響: 刈り払いのダメージと根縛りの鈍化に進まず、着弾パーティクルが繰り返し追加される。
- 修正方針: FLASH へ Color を渡し、着弾処理前に攻撃タスクを止め、ゲーム効果をエフェクト表示より先に適用する。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-002 [高] Mob API が Armor Trim を破棄する
- 種別: `仕様不整合`
- 対象: `20_api/AstralRecordApi/AstralRecordApi/Models/MobResponse.cs:132`
- 関連箇所: `40_filebase/40.features.mob/boss/v1.purple_tree_velg.yml:22`
- 根拠: Plugin は equipment.trim を解釈するが、API の MobEquipmentResponse に trim プロパティがなく、MobRepository が payload を同 DTO にデシリアライズして返す。
- 問題: filebase の装飾設定が API 応答から失われる。
- 影響: ヴェルグのネザライト防具へ指定した紫の装飾が表示されない。
- 修正方針: API DTO と関連する Mob API モデル定義へ trim 契約を追加する。
- 修正対象候補: `20_api/AstralRecordApi/AstralRecordApi/Models/MobResponse.cs`
- 修正可否: `自動修正可`
