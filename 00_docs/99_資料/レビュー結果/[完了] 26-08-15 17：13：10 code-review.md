### AR-CODE-002 [低] 不正な loaded 値でも装填を確定する
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/item/service/HookshotLoadState.java:49`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/item/service/HookshotLoadState.java:19、00_docs/10_Plugin設計書/feature/04-item/3-メソッド仕様/04_3-サービス.md:365`
- 根拠: 設計は不正な metadata で装填完了を確定しない契約です。しかし `isLoaded` は `hookshot.loaded` が boolean 以外なら未装填として扱う一方、`setLoaded(..., true)` は同じ object 内の既存値型を検証せず boolean で上書きします。
- 問題: 例えば `{"hookshot":{"loaded":"true"}}` は未装填として右クリック装填を開始でき、完了時に既存の不正値を上書きして hook を消費します。
- 影響: metadata 破損時に安全に拒否すべき装填が成立し、フック消費と状態変更が発生します。
- 修正方針: `hookshot.loaded` が存在する場合は boolean primitive だけを有効として、それ以外は `setLoaded` を拒否します。文字列・数値・null・配列などを拒否する回帰テストを追加します。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/item/service/HookshotLoadState.java、10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/item/service/HookshotLoadStateTest.java`
- 修正可否: `自動修正可`
- 確信度: `中`
- 修正状態: `修正済み`

### AR-CODE-003 [中] ストレージから取り出すと装填済み状態が失われる
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/inventory/service/InventoryService.java:1920`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/inventory/service/InventoryService.java:4703、10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/inventory/service/InventoryService.java:4807、10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/inventory/service/InventoryService.java:5160、00_docs/10_Plugin設計書/feature/04-item/3-メソッド仕様/04_3-サービス.md:363`
- 根拠: 設計は `hookshot.loaded` を持ち替え・storage移動・再ログイン後にも保持し、装填済みフックを有効発射以外で外さない契約です。storage格納時は `copyEntryToStorage` が `storageMetadataJson(entry)` を保存しますが、取出しは `returnItemToOwnedInventory(astPlayer, itemStack.clone())` を呼び、entry の `metadataJson` を渡しません。返却先の既存instance entry は `addExistingInstanceEntry` で metadata `null` として作成されます。
- 問題: 装填済みフックショットをstorageへ格納してから取り出すと、同じinstanceであっても `hookshot.loaded=true` が失われます。
- 影響: hookを消費して装填した状態をstorage往復で無消費に解除でき、状態永続化および「取り外し不可」の仕様に反します。
- 修正方針: storage取出しでは元の `InventoryEntryModel.metadataJson` を返却先entryへ引き継ぐ経路を設け、instance再作成時にmetadataを保持します。装填済みフックショットをstorageへ格納・取出しした後も `hookshot.loaded=true` が残る回帰テストを追加します。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/inventory/service/InventoryService.java、10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/inventory/service/InventoryServiceHookshotMetadataTest.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
