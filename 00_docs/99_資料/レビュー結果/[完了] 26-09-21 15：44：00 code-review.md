## 指摘一覧

### AR-CODE-001 [中] 戻り先情報未実装の GUI では旧来の戻る表示が残る
- 種別: `仕様不整合`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/shared/gui/navigation/GuiNavigationService.java:203`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/currency/view/CurrencyExchangeGuiView.java:140`
- 根拠: `updateNavigationButton` は履歴がある場合でも、直前 inventory の holder が `GuiNavigationDestination` を返すときだけ back slot を置換する。`CurrencyExchangeGuiView.Holder`、`BossChallengeCancelGui.Holder`、`OrbGuiHolder`、`DungeonRewardGui.Holder`、`LoginBonusGui.Holder`、`MarketGui.Holder`、`TeleporterGui.Holder`、`SkillSigilOrbGuiHolder` など、`HotbarShortcutGuiHolder` を実装する GUI の一部は既定の `null` を返すままである。
- 問題: これらの GUI から別の履歴対応 GUI を開くと、履歴は存在するにもかかわらず遷移先 GUI が初期描画した戻るアイテムを保持する。直前 GUI のアイコンと「&lt;画面名&gt;画面へ戻る」表示には置換されず、全 GUI を対象とする今回の戻る表示仕様を満たさない。
- 影響: プレイヤーは GUI の遷移経路によって旧来の固定アイコン・固定文言、または実際の戻り先と異なる表示を見る。
- 修正方針: 履歴に記録し得る各 `HotbarShortcutGuiHolder` に対応する `GuiNavigationDestination` を実装する。画面固有アイコンを保持できない holder は、画面を識別できる既定アイコンと名称を定義し、`GuiNavigationService` が `null` のまま既存 back item を残さないようにする。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
