### AR-CODE-001 [高] 統合パネルの片面描画による表示欠落
- 種別: `バグ/アルゴリズム`
- 対象: `50_resourcepack/scripts/action-ring-panel.ps1`
- 関連箇所: `50_resourcepack/scripts/generate-action-ring-assets.py`
- 根拠: 一体型のアイコンとゲージは南面だけを持ち、同じ姿勢定義を使う旧輪郭は北面を表面とする。片面の発光材質は裏面を描画しない。
- 問題: 既存の PNG と面構成に裏面カリングのある材質を割り当てている。
- 影響: 視点側から輪郭だけが表示されるおそれがある。
- 修正方針: 既存の材質へ戻し、二値アルファの輪郭テクスチャでノイズを除去する。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-002 [中] Java 版の衝突回避が補間で遅れる
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/service/SkillActionRingDisplay.java`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/service/SkillActionRingService.java`
- 根拠: Java 版の位置と変形に2 tickの補間を設定している。障害物に近づく場合は即時にリングを手前へ縮める仕様である。
- 問題: 衝突回避による縮小フレームにも通常追従と同じ補間が適用される。
- 影響: 補間中に輪郭やアイコンがブロックへ隠れるおそれがある。
- 修正方針: 縮小フレームでは補間時間を0にし、通常追従時は2 tickに戻す。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-003 [中] 統合版の一部の発動不可枠に視覚的な手掛かりがない
- 種別: `仕様不整合`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/service/SkillActionRingService.java`
- 関連箇所: `50_resourcepack/scripts/action-ring-panel.ps1`
- 根拠: MP・ENG不足や発動制限の枠は通常のアイコンを持ち、ゲージはクールダウン中だけ描画される。一体型パックでは色付きのフォールバック目印が抑止される。
- 問題: 枠ごとの文字を削除すると、発動不可の枠が使用可能な枠と同じ外観になる。
- 影響: プレイヤーが確定できる枠を区別しにくい。
- 修正方針: 既存の枠明度ビットに発動不可の枠を含め、ゲージの進捗は独立して維持する。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
