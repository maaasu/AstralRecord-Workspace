### AR-CODE-001 [中] 同一スキルの習得個体が統合一覧から欠落する
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/menu/player/PlayerDetailGui.java:626`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/event/SkillBindGuiEventHandler.java:823`
- 根拠: `LearnedSkillService#getLearnedSkills` とスキルマネージャーは習得個体 ID ごとに全個体を扱い、各個体は独立したレベルと装着シジルを持つ。
- 問題: 統合一覧の生成時に base skill ID で重複排除しているため、同じスキルを複数習得している場合に2個目以降の個体が表示されない。
- 影響: 表示から欠落した習得個体の現在レベルと装着シジルを確認できず、バインド表示に存在する個体と統合一覧の内容が一致しない。
- 修正方針: 習得済みは個体単位で全件追加し、使用許可だけの定義を追加するときに限って習得済み master ID を除外判定へ使う。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/menu/player/PlayerDetailGui.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
