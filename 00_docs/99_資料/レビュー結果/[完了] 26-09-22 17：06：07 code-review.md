### AR-CODE-001 [中] トレード履歴のマスター名解決が大量の個別 API 要求を送る
- 種別: `パフォーマンス`
- 対象: `30_web/AstralRecordWeb/AstralRecordWeb/Services/ItemMasterApiClient.cs:17`
- 関連箇所: `30_web/AstralRecordWeb/AstralRecordWeb/Pages/Admin/History/Trades.cshtml.cs:37`
- 根拠: `GetNamesAsync` はページ内の全ユニーク `itemId` に対して `/api/item/{id}` を制限なく `Task.WhenAll` で同時要求する。履歴は1ページ50件で、1トレードに最大45枠を含められる。
- 問題: 最悪時に最大2,250本の API/DB 要求を1回の画面表示から開始し、`ItemMasterApiClient` の既定100秒タイムアウトまで履歴保存名へのフォールバックに到達できない。
- 影響: API/DB の接続枯渇・負荷増加と、管理画面の長時間待機を招く。
- 修正方針: アイテム一覧 API の応答にマスター名を含め、トレード履歴は1回の一覧取得で ID と名称の対応を構築する。API 契約と対象テストも同期する。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
