### AR-CODE-001 [中] AccountMode変更後もパーティーチャットモードが有効になる
- 種別: `仕様不整合`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/party/service/PartyService.java:394`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/player/event/ManagedChatEventHandler.java:55`
- 根拠: パーティー操作は `AccountMode.PLAYER` を前提とし、管理者が例外的に実行できるのは `list` のみである。`isPartyChatEnabled` は有効フラグと所属だけを確認しており、現在の `AccountMode` を確認していない。
- 問題: パーティー所属中にアカウントモードを `ADMIN` へ切り替えたプレイヤーが通常チャットを送信すると、切替前に有効化したパーティーチャットモードが残り、全体チャットではなくパーティー配信になる。
- 影響: 管理者モードのプレイヤーの通常チャットが意図せずパーティーメンバーと管理者だけへ配信され、通常のチャットモードと不整合になる。
- 修正方針: 通常チャットのパーティー配信判定で、現在の Bukkit Player が `AccountModeGuard.isGameplayPlayer` を満たす場合だけ有効フラグを採用する。満たさない場合は全体チャットへ戻す。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/party/service/PartyService.java | 10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/player/event/ManagedChatEventHandler.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-002 [中] パーティーチャットモードのライフサイクル解除テストが不足している
- 種別: `テスト不足`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/party/service/PartyService.java:281`
- 関連箇所: `10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/party/service/PartyServiceTest.java`
- 根拠: パーティーチャットモードの解除処理は離脱・logout・追放・解散・`clearAll` の複数ライフサイクルへ分散しているが、既存テストはトグル、AccountMode 判定、配信を検証するだけで、各ライフサイクル後に stale な mode が残らないことを検証していない。
- 問題: いずれかのライフサイクルで mode の解除を取りこぼしても、再加入・再作成後の最初の `/party chat` が無効化扱いになる回帰をテストで検出できない。
- 影響: パーティーを作り直したプレイヤーの通常チャットが、意図せずパーティーチャットへ切り替わる可能性を恒久テストで防げない。
- 修正方針: mode を有効化した後に、離脱・logout・追放・解散・`clearAll` をそれぞれ実行し、再加入・再作成後の次回トグルが `P_5926`（有効化）になるテストを追加する。
- 修正対象候補: `10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/party/service/PartyServiceTest.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
