### AR-DOC-001 [高] `SkillRepository.findAll` の戻り値型が一覧用と詳細用で曖昧
- 種別: `矛盾`
- 対象: `00_docs/10_プラグイン設計書/feature/13-skill/3-メソッド仕様/13_3.04-リポジトリ.md:8`
- 関連箇所: `00_docs/10_プラグイン設計書/feature/13-skill/3-メソッド仕様/13_3.02-サービス.md:5`
- 根拠: `13_3.04-リポジトリ.md` 手順2 で「スキル一覧項目モデル または詳細レスポンス配列として受け取る」と記載。一方 `13_3.02-サービス.md` の `reloadDefinitions` は `findAll` の結果を `implementationId` 検証→`replaceDefinitions`（`definitionsById` 構築）へ渡しており、`SkillDefinition` 相当の情報が必要。`SkillSummary`（id/name/implementationId/icon/tags のみ）では `manaCost`・`cooldownTicks`・`params` 等が欠ける。
- 問題: `findAll` が `SkillSummary` 配列を返す場合、`reloadDefinitions` 以降の検証・実行に必要な共通制御値や `params` が取れず、設計上ロード経路が破綻する。
- 影響: 起動時同期処理を実装する際に、追加 API 呼び出しを暗黙に要求するか、`SkillSummary` を `SkillDefinition` として扱う不正実装を誘発する。
- 修正方針: `findAll` は `SkillDefinition` 配列を返す前提に統一し、`SkillSummary` 用途は別メソッドまたは API 別エンドポイントとして切り出すか、本設計書では言及しない。
- 修正対象候補: `00_docs/10_プラグイン設計書/feature/13-skill/3-メソッド仕様/13_3.04-リポジトリ.md`
- 修正可否: `自動修正可`

### AR-DOC-002 [高] `SkillCastContext.caster` の型が `AstPlayer または Mob 実体` のままで抽象が未定義

- 対象: `00_docs/10_プラグイン設計書/feature/13-skill/1-モデル定義/13_1.00-モデル定義.md:49`
