## 指摘一覧

### AR-CODE-001 [中] 配信済みキーで再発した不整合をリセットしない
- 種別: `バグ/アルゴリズム`
- 対象: `20_api/AstralRecordApi/AstralRecordApi/Repositories/AccountSkillTreeStateRepository.cs:61`
- 関連箇所: `20_api/AstralRecordApi/AstralRecordApi/Repositories/AccountSkillTreeStateRepository.cs:75`
- 根拠: 同一構造キーのメール配信は重複させない一方、検出した不整合は全ノード解除する仕様。
- 問題: 同じ `(userId, repairKey)` のdeliveryが既にある場合、状態が再び不正なnodeを含んでいても早期returnし、空状態への置換を実行しない。
- 影響: DB不整合の再発や補修後の状態書換えが起きた場合、Pluginが同じ不正状態を繰り返しロードしてログイン処理を再試行し続ける。
- 修正方針: 既存deliveryはメール作成だけを省略し、解放済みnodeが残る場合は状態を空へ置換する。すでに空状態なら状態更新もしない。
- 修正対象候補: `20_api/AstralRecordApi/AstralRecordApi/Repositories/AccountSkillTreeStateRepository.cs`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
