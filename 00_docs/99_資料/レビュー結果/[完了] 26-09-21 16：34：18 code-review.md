### AR-CODE-001 [中] カルトグラフ成功 callback の世代再検証不足
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/dungeon/service/DungeonService.java:2684`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/dungeon/service/DungeonService.java:2702 / 00_docs/10_Plugin設計書/feature/32-dungeon/32_3-処理契約.md:101`
- 根拠: `WorldService.teleportPlayerAsync` は実テレポート成功後に `onSuccess` を呼び出すが、現在の `notifyCartographTeleportSuccess` は成功時の `transferGeneration`、セッション終了状態、参加者所有権を再確認せず、ガイド条件通知を実行する。ダンジョン終了処理は実転送開始後・成功 callback 前にも実行され得る。
- 問題: 古いセッションのカルトグラフ転送が成功 callback へ到達した場合、終了済みまたは世代変更済みのセッションでも `CARTOGRAPH_ROOM_TELEPORTED` を記録する。
- 影響: プレイヤーが有効なダンジョン参加者でない状態の転送でも、初めてのダンジョンガイドの手順3が誤って達成済みになる可能性がある。
- 修正方針: callback へ転送世代を渡し、`isActiveTransferCallback`、現在の参加者所有権、オンライン状態を再検証してからガイド通知を行う。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/dungeon/service/DungeonService.java`
- 修正可否: `自動修正可`
