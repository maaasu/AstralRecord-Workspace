### AR-CODE-001 [中] Vanilla BUNDLE まで内容量 tooltip を非表示にしている
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/item/view/ItemStackPacketAdapter.java:366`
- 関連箇所: `10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/item/view/ItemStackPacketAdapterTest.java:194`
- 根拠: `SET_SLOT`、`WINDOW_ITEMS`、`ENTITY_EQUIPMENT` の送信経路で、PDCを持たない純粋な `Material.BUNDLE` も `replaceIcon` の変換対象になる。一方、既存のメソッド契約は非AstralRecordアイテムを `null` として書き換えない。
- 問題: 通常のVanilla BUNDLEまで送信コピーへ `BUNDLE_CONTENTS` 非表示設定が付与される。
- 影響: プレイヤーが使用する通常のBundle内容量tooltipも表示されなくなる。今回の対象であるGUI/CURRENCYアイコンと表示用cloneより適用範囲が広い。
- 修正方針: 純粋なVanilla BUNDLEをパケット変換対象へ追加する条件を削除し、通常のVanilla BUNDLEは従来どおり `null` でスキップする。プラグイン生成GUIアイコンは生成時に、表示用cloneは `asDisplayStack` で非表示設定を適用するテストを維持する。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/item/view/ItemStackPacketAdapter.java、10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/item/view/ItemStackPacketAdapterTest.java、00_docs/10_Plugin設計書/feature/04-item/3-メソッド仕様/04_3-アダプタ・リスナー.md`
