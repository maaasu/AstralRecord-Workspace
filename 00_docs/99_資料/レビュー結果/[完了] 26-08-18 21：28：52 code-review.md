### AR-CODE-001 [中] GUI再表示時に暗黒効果が解除される
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/world/event/OverworldTeleportGuiEventHandler.java:126`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/world/gui/OverworldTeleportGui.java:49`
- 根拠: `OverworldTeleportGuiEventHandler.open()` は GUI 表示要求後に暗黒効果を付与するが、`OverworldTeleportGui.open()` は既存のプラグイン GUI 上では 2 tick 後に実際の GUI を開く。共有 GUI セッション終了イベントは遷移元の close 後に確定する。
- 問題: 同じ転送 GUI を再表示する遷移では、遷移元のセッション終了時に `clearGuiDarkness()` が実行される一方、遅延された遷移先 GUI の表示成功後に暗黒効果を再付与する処理がない。
- 影響: GUI 再表示時に転送 GUI が表示中でも暗黒効果が消え、設計書の「GUI 表示中だけ GUI 用の暗黒エフェクトを付与する」契約を満たさない。
- 修正方針: GUI の実表示成功 callback で暗黒効果を付与し、表示失敗時は状態を解除する。遷移元の session close では既存の暗黒効果を解除し、遷移先の表示成功時に再付与できるよう GUI 表示 API と handler を接続する。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-002 [中] 別のプラグイン GUI への遷移で暗黒効果が残留する
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/world/event/OverworldTeleportGuiEventHandler.java`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/shared/gui/session/GuiSessionTransitionEventHandler.java`
- 根拠: 共有 GUI セッションは後続のプラグイン GUI が開くと active session を新しい GUI に置き換え、先行 GUI の `GuiSessionEndEvent` を発行しない。
- 問題: 転送 GUI の暗黒効果解除を `GuiSessionEndEvent` と切断だけに委譲すると、別のプラグイン GUI へ遷移したとき解除処理が実行されない。
- 影響: 転送 GUI を閉じた後も別 GUI の表示中に視界が暗いまま残留する。
- 修正方針: 転送 GUI 以外のインベントリ表示成功を監視し、転送 GUI の暗黒効果を解除する。別 GUI 遷移を再現する回帰テストを追加する。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
