### AR-CODE-001 [低] 小文字の検索クエリが購入先切替時に消える
- 種別: `バグ/アルゴリズム`
- 対象: `30_web/AstralRecordWeb/AstralRecordWeb/Pages/Market/Index.cshtml.cs:171`
- 関連箇所: `30_web/AstralRecordWeb/AstralRecordWeb/Pages/Market/Index.cshtml:32`
- 根拠: `Query` と `Sort` は GET のバインド対象だが、`PreservedSearchParameters()` は列挙した実際のクエリキーを `nameof(Query)` 等と大文字小文字を区別して比較する。設計書 `04_3.00-マーケット閲覧.md` はアカウント切替時の検索条件保持を規定する。
- 問題: `/Market?query=ore&sort=price_asc` のような小文字キーで検索すると、一覧には条件が適用されてもアカウント切替フォームの hidden 入力に条件が含まれない。
- 影響: 購入先を切り替えると検索条件と並び順が消え、表示していた出品を見失う。
- 修正方針: 許可する検索キーと `stat_` 接頭辞を大文字小文字を区別せず照合し、元のクエリ値を hidden 入力に保持する。
- 修正対象候補: `30_web/AstralRecordWeb/AstralRecordWeb/Pages/Market/Index.cshtml.cs`
- 修正可否: `自動修正可`
- 確信度: `高`
