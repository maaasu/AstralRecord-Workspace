## 指摘一覧

### AR-CODE-001 [中] オーブ一覧の画面切替 close 順序を検証するテストが不足
- 種別: `テスト不足`
- 対象: `10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/item/service/OrbServiceLifecycleTest.java:125`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/item/service/OrbService.java:440`
- 根拠: オーブ一覧追加では、旧 GUI の `InventoryCloseEvent` が新しい一覧・操作セッションを削除しないよう holder、token、inventory を照合する close 処理を追加している。画面切替は設計書の「インベントリ内オーブ一覧」およびイベント仕様に含まれる。
- 問題: 追加テストは集計表示と正常な一覧選択、操作 GUI から一覧への遷移を確認しているが、テスト用 opener が `openInventory` を直接呼ぶため実際の `InventoryCloseEvent` を発生させていない。したがって一覧→操作 GUI、操作 GUI→一覧、手動 close、ページング、空一覧、stale entry 時の session 保護を自動検証できていない。
- 影響: 画面切替時の古い close event による新しい GUI session の誤削除や、一覧状態の境界退行をテストで検出できない。
- 修正方針: 既存 Harness の opener / close 呼び出しを利用した最小の lifecycle テストを追加し、画面切替時は新しい holder の session が維持されること、一覧 close は一覧 session のみを終了すること、ページ・空一覧・stale entry の拒否と再描画を確認する。
- 修正対象候補: `10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/item/service/OrbServiceLifecycleTest.java`
