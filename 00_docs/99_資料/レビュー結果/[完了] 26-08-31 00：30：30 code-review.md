### AR-CODE-001 [低] 幸運補正の実行経路テスト不足
- 種別: `テスト不足`
- 対象: `10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/mob/service/MobDropServiceTest.java:112`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/mob/service/MobDropService.java:90`
- 根拠: `MobDropService.roll` は killer の `StatusSnapshot.LUCK` を取得して直接ドロップの抽選率へ反映する実行経路である。既存の変更後テストは `calculateEffectiveRate` の数式だけを検証している。
- 問題: `roll(drops, killer)` が最新の LUCK を取得し、`luckAffected=true` の直接ドロップだけへ補正を適用することを回帰テストで確認できない。`killer=null` を含む既存の実行経路の検証範囲も変更前より狭くなっている。
- 影響: 幸運値の取得・直接ドロップへの適用接続が壊れても、数式ヘルパーのテストだけでは検出できない。
- 修正方針: 固定値の `StatusSnapshot.LUCK=100` と設定率50%を用い、`roll` 経由で幸運補正対象の直接ドロップが確定し、対象外が当選しない決定的なテストを追加する。
- 修正対象候補: `10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/mob/service/MobDropServiceTest.java`
