### AR-CODE-002 [中] 頭アイコン台帳が利用できないワークスペースで編集が阻害される
- 種別: `バグ/アルゴリズム`
- 対象: `60_tool/05-master-data-editor/src/SkillTreeEditor.Server/Services/WorkspaceItemTextures.cs:40`
- 関連箇所: `60_tool/05-master-data-editor/src/SkillTreeEditor.Server/Services/MasterDataCatalog.cs`
- 根拠: 初版の GetMobHeadRoles は台帳が存在しない場合に空の列挙を返し、台帳読み込みのアクセス例外はカタログ呼び出しへ伝播していた。
- 問題: 任意のリソースパックがないワークスペースでも、有効なモブの iconModel が列挙制約に違反する扱いになる。台帳へのアクセス失敗は別カテゴリのカタログ取得も失敗させる。
- 影響: 有効なモブデータの保存や、無関係のマスター編集が阻害される。
- 修正方針: 台帳を利用できない状態と有効な空台帳を区別する。利用できない場合は構文だけを検証し、読み込み可能なときだけ列挙の存在検証を行う。台帳を取り除いた場合のカタログ・保存検証を追加する。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `未修正`
