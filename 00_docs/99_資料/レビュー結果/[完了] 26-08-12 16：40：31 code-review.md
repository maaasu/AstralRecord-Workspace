### AR-CODE-001 [中] 修正パス後に警告ゲートが再適用されない
- 種別: `バグ/アルゴリズム`
- 対象: `.codex/skills/astralrecord-code-version-commit-develop/SKILL.md:72`
- 関連箇所: `.codex/skills/astralrecord-code-fix/SKILL.md:81`
- 根拠: Standard gate はビルド警告を検証結果として扱い、タスク起因の警告を解消して同一コマンドを再実行することを要求している（`.codex/skills/astralrecord-code-version-commit-develop/SKILL.md:56-62`）。一方、Fix Pass 1 は通常の build/test/static check の再実行だけを指定し、fix skill も警告の標準エラー取得・分類・再確認を要求していない。
- 問題: review-driven fix が新たなコンパイラ等の警告を導入しても、終了コードが 0 であれば警告を検出・分類・解消せずに品質ゲートを通過できる。
- 影響: 今回追加する警告対策が修正パスでは効かず、警告を含む変更が develop へ merge される余地が残る。
- 修正方針: Fix Pass 1 と Fix Pass 2 の後に Build Warning Gate を明示的に再適用する。必要なら `.codex/skills/astralrecord-code-fix/SKILL.md` の Verify に同等の警告確認を追加し、統合スキルからもその実施を必須化する。
