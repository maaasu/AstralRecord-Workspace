## 指摘一覧

### AR-CODE-001 [中] DiscordSRV標準経路との二重送信を防止する
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/discord/service/DiscordSrvChatBridge.java:97`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/player/service/PlayerMessageService.java:175`
- 根拠: DiscordSRVのMinecraftチャット処理は、キャンセル済みのBukkitチャットでも設定によって標準のDiscord送信処理へ進む。AstralRecordはカスタム全体チャットをキャンセルしたうえで、明示的に`processChatMessage`を呼び出している。
- 問題: `RespectChatPlugins`が無効な環境では、カスタム全体チャット1件に対してDiscordSRVの標準経路とAstralRecordの明示経路が両方実行され、Discordへ同じメッセージが2回送信される可能性がある。
- 影響: MinecraftからDiscordへの全体チャットが重複表示され、運用設定によって再現条件が変わる。
- 修正方針: DiscordSRVの`GameChatMessagePreProcessEvent`で、元のBukkitイベントがキャンセル済みの場合は標準送信をキャンセルする。AstralRecordが明示的に呼び出す経路は`triggeringBukkitEvent`が`null`であるため許可する。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/discord/service/DiscordSrvChatBridge.java`
- 修正可否: `自動修正可`
