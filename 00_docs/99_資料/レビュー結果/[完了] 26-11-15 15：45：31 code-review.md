### AR-CODE-001 [低] 閲覧者を指定した Java 版の粒子に地点ごとの距離判定が掛からない

- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/shared/effect/ParticleDisplayService.java:867`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/active/service/SkillEffectService.java, PLUGIN_GUIDE.md`
- 根拠: 閲覧者の選択では演出中心から64mの距離を判定する。粒子送信では閲覧者の一覧が指定されると Java 版の地点ごとの距離判定を省略する。

- 修正方針: Java 版の一括送信でも、閲覧者の指定の有無にかかわらず地点ごとに距離を判定する。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/shared/effect/ParticleDisplayService.java`
