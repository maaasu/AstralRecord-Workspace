## 指摘一覧

### AR-CODE-001 [低] 閉じたパネルの aria-controls が存在しない要素を参照する
- 種別: `バグ/アルゴリズム`
- 対象: `60_tool/skilltree-editor/src/SkillTreeEditor.Client/src/components/WorldPlacementEditor.tsx:349`
- 関連箇所: `60_tool/skilltree-editor/src/SkillTreeEditor.Client/src/components/WorldPlacementEditor.tsx:354`
- 根拠: 3つの開閉ボタンは常に `aria-controls` に useId の値を出す一方、参照先の div は開状態のときだけマウントされる。初期状態では詳細条件と一括操作の参照先がなく、選択フォームを閉じたときも同様になる。WAI-ARIA の `aria-controls` は ID 参照リストで、開閉パターンでは制御対象の要素を参照する。
- 問題: 閉状態の `aria-controls` が DOM に存在しない ID を指し、支援技術へパネルとの関係を示せない。
- 影響: 支援技術を使う操作で、折りたたみボタンと内容領域の関連をたどれない可能性がある。
- 修正方針: 各内容コンテナを閉状態でも `hidden` で DOM に保持するか、閉状態では `aria-controls` を外して有効な ID だけを公開する。フォーム内の数値原稿と開閉時のフォーカス挙動を維持する。
- 修正対象候補: `60_tool/skilltree-editor/src/SkillTreeEditor.Client/src/components/WorldPlacementEditor.tsx`
