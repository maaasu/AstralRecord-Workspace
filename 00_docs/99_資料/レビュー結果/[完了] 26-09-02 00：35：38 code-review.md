### AR-CODE-001 [中] レベル不変時のTab更新
- 種別: `パフォーマンス`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/playerclass/PlayerClassService.kt:150`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/playerclass/PlayerClassService.kt:133-151`
- 根拠: `grantClassExperience` はモブ・採集・クエスト報酬から呼ばれるが、レベル不変の報酬でも `playerListName` を再構築して送信する。
- 問題: クラスレベルが変わらない経験値加算のたびにTab表示更新を行い、不要なパケット処理が発生する。
- 影響: 報酬処理の頻度に応じて、メインスレッド上の Component 構築とプレイヤーリスト更新の負荷が増える。
- 修正方針: `level != previousLevel` の場合だけ `updatePlayerListName` を呼び出す。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/playerclass/PlayerClassService.kt`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-002 [低] クエスト報酬ロールバック後のTab表示未復元
- 種別: `仕様不整合`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/quest/service/QuestService.java:1224-1235`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/playerclass/PlayerClassService.kt:150`
- 根拠: クエスト報酬の保存失敗時、`AstPlayer` のクラスレベルを直接復元するが、Tab表示の更新処理を呼び出していない。設計書はクラスレベル変更時の表示更新を要求している。
- 問題: ロールバック前に表示された高いクラスレベルが、復元後もTabに残る可能性がある。
- 影響: Tabのクラスレベル表示とゲーム内の復元済み状態が不一致になる。
- 修正方針: ロールバックでクラス進行を復元し、ステータスを更新した後に `playerClassService.updatePlayerListName(player)` を呼び出す。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/quest/service/QuestService.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

- 修正対象候補: `10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/playerclass/PlayerClassServiceTest.kt`

### AR-CODE-004 [低] 非現在クラス・レベル不変の設定時のTab再送

- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/player/model/AstPlayer.kt:185-200, 10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/playerclass/command/ClassCommand.java:103-121`

- 修正方針: 現在クラスで、かつ設定前後のレベルが異なる場合だけ `updatePlayerListName` を呼び出す。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/playerclass/PlayerClassService.kt`
- 修正可否: `自動修正可`

### AR-CODE-005 [低] 未解決クラスIDのTab表示
- 種別: `コーディングルール違反`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/playerclass/PlayerClassService.kt:69-71,91-95`
- 関連箇所: `PLUGIN_GUIDE.md: GUI名・GUI lore・プレイヤー向けメッセージの内部識別子表示規則`
- 根拠: `getDisplayName` はクラスマスター未解決時に内部 `classId` を返し、Tabタグ生成がその値をプレイヤーへ表示する。Plugin規則は、プレイヤー表示で内部IDを出さず、解決不能時は汎用表示へフォールバックすることを求めている。
- 問題: クラスマスターの未ロード・欠損時に内部クラスIDがTabへ表示される。
- 影響: プレイヤー向け表示へ内部識別子が露出し、表示体裁も崩れる。
- 修正方針: Tab表示専用に `未登録のクラス` へフォールバックし、未解決ケースをテストする。既存の `getDisplayName` の内部用途向けフォールバック契約は変更しない。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/playerclass/PlayerClassService.kt, 10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/player/PlayerMsgId.java, 10_plugin/AstralRecord/src/main/resources/player.properties, 10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/playerclass/PlayerClassServiceTest.kt`
