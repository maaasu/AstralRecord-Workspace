### AR-CODE-002 [低] レベルアイコンの実幅と相殺に使う幅が1ピクセルずれる
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/hud/view/JavaProfileHud.java:170`
- 関連箇所: `50_resourcepack/scripts/generate-gameplay-hud.py:73`
- 根拠: レベルアイコン U+E940 の右端不透明ピクセルは x=5 にあり、等倍の bitmap フォントでの送り幅は 7px。他の個人情報アイコンは 8px。
- 問題: 送り幅の相殺に使う `gameplayAdvance` は U+E940 も 8px として扱う。
- 影響: プレイヤー行がカーソルを1px左へ残すため、クラス行とプレイヤー行の左端がずれ、戦闘行の中央位置も変わる。
- 修正方針: U+E940 の送り幅を描画データに合わせるか、アイコンのシルエットを揃えて実幅を8pxにする。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/hud/view/JavaProfileHud.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-003 [中] Java 戦闘 HUD の状態異常名とアイコンが欠字になる
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/hud/view/PlayerHudView.java:345`
- 関連箇所: `50_resourcepack/assets/astralrecord/font/gameplay_hud.json`
- 根拠: GUARD の書体変換は表示が空の場合もルートへ専用フォントを設定する。専用フォントには日本語や状態異常の記号が収録されていない。
- 問題: GUARD の書体を設定した要素に状態異常と職業固有リソースを連結すると、書体を持たない子要素が専用フォントを継承する。
- 影響: Java 版で対応パックを使用しているプレイヤーは、通常戦闘中に日本語の状態異常名や識別記号を読めなくなる。
- 修正方針: 書体未指定の共通の親に各要素を追加し、専用書体の適用を変換対象の要素内に限定する。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/hud/view/PlayerHudView.java`
- 修正可否: `自動修正可`

- 修正状態: `修正済み`
