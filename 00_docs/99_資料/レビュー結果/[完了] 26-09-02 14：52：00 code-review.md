## 指摘一覧

### AR-CODE-001 [中] Plugin再有効化時にDiscordSRVランタイム値を誤復元する
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/discord/service/DiscordSrvChatBridge.java:135`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/AstralRecord.java:569`
- 根拠: whitelist 有効化時のDiscordSRVランタイム値の元値をstaticフィールドへ保存し、whitelist無効化時だけ元値へ復元している。一方、AstralRecordのonDisable()はbridgeの購読解除だけを行い、plugin reload時にランタイム値の復元を行っていない。
- 問題: whitelist 有効中にAstralRecordだけをdisableして再有効化すると、DiscordSRV側に残ったfalseを再有効化時の元値として保存する。その後whitelistを無効化しても、元々trueだったMinecraft→Discord設定をfalseへ戻してしまう。
- 影響: plugin reload後にwhitelistを解除しても、Minecraft→Discordの標準中継が復帰しない。
- 修正方針: サーバー停止ではないAstralRecordのdisable時に、DiscordSRVのランタイム上書きを解除して次回有効化が永続設定から元値を再取得できるようにする。サーバー停止時は停止通知抑制を維持する。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/AstralRecord.java`
- 修正可否: `自動修正可`
