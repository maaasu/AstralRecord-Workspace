### AR-DOC-001 [高] 0 ダメージが最低 1 のシールドダメージへ変換される
- 種別: `不適切なロジック`
- 対象: `00_docs/60_戦闘バランス設計書/01-戦闘計算.md:303`
- 関連箇所: `00_docs/10_Plugin設計書/feature/14-combat/14_4-統合フロー.md:79`
- 根拠: シールド式は `max(1, floor(...))` を無条件に適用する一方、統合フローは `0 damage` で終了すると定めている。戦闘計算のフローにも、最終補正後かつシールド変換前に 0 ダメージを終了させる分岐がない。
- 問題: 防御、属性耐性、倍率 0 などでシールド判定前ダメージが 0 になっても、式どおりならシールドへ 1 ダメージが入る。`R = 0` の攻撃や完全防御された攻撃でもシールドを削れるため、0 ダメージ終了契約と一致しない。
- 影響: 無効化済み攻撃の連打でシールドを破壊でき、完全防御・倍率 0・無効属性の意味が HP とシールドで変わる。
- 修正方針: シールド式の前に `シールド判定前ダメージ <= 0` なら 0 damage result で終了する条件を追加し、全体フローと処理契約にも同じ終了条件を明記する。正の微小ダメージだけを `max(1, ...)` の対象にする。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 修正状態: 修正済み

### AR-DOC-006 [中] `R = 0` のとき防御比 `Q` が未定義になる
- 種別: `不適切なロジック`
- 対象: `00_docs/10_Plugin設計書/feature/14-combat/3-メソッド仕様/14_3-サービス.md:18`
- 関連箇所: `00_docs/60_戦闘バランス設計書/01-戦闘計算.md:205`
- 根拠: 両文書とも先に `Q = D / R` を定義し、その後で `R <= 0` なら防御倍率 0 としている。
- 問題: `R = 0` では `Q` の除算が数学的に定義できない。実装言語の IEEE 754 挙動へ暗黙依存すると、`D = 0` では `NaN`、`D > 0` では正の無限大となり、後段の比較やログ値が実装順に依存する。
- 影響: 0 攻撃力、空・無効 component、倍率 0 の境界テストを文書どおり一意に作れない。
- 修正方針: `R <= 0` を `Q` 計算前の終了条件に移し、`R > 0` の場合だけ `Q = D / R` を計算する式へ書き換える。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 修正状態: 修正済み
