### AR-CODE-001 [中] 再送パケットの再入抑止が送信スレッドをまたいで維持されない
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/item/view/ItemStackPacketAdapter.java:114`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/item/view/ItemStackPacketAdapter.java:208, 10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/item/view/ItemStackPacketAdapter.java:335`
- 根拠: `04_5-例外・ログ・運用.md` は `onPacketSending` をネットワーク IO スレッドで動作させ、Bukkit API の状態変更を行わない契約としている。一方、元パケットの処理は `runTask` で Bukkit メインスレッドへ移し、再送抑止はメインスレッドで set/remove する `ThreadLocal` だけである。
- 問題: `Player#sendEquipmentChange` が生成した `ENTITY_EQUIPMENT` の listener 実行が元の `ThreadLocal` と同じスレッド・呼出スタックでない場合、フラグは観測されない。再送を再び cancel して次 tick に再送する循環となり、装備が届かないか、送信負荷を継続的に増やす。
- 影響: `ARMOR_DISPLAY` の状態にかかわらず AstralRecord 装備を他者へ送るたび、今回修正対象の装備表示が欠落または反復送信し得る。複数プレイヤー環境では再び切断・パケット異常の誘因となる。
- 修正方針: ProtocolLib と Paper の実際の dispatch thread に依存しない再送識別方法へ変更する。少なくとも受信者・entityId・再送内容を一回限りと識別できる状態を設計し、消費・期限切れ・ログアウト時の破棄を含める。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/item/view/ItemStackPacketAdapter.java`
- 修正可否: `設計判断待ち`
- 確信度: `中`
- 修正状態: `修正済み`

### AR-CODE-004 [中] cancel 後に再送対象を解決できない場合、元の装備更新が失われる
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/item/view/ItemStackPacketAdapter.java:219`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/item/view/ItemStackPacketAdapter.java:330`
- 根拠: `handleEntityEquipment` は元パケットを cancel して次 tick の task を予約する。予約先は `viewer.getWorld().getEntities()` から `entityId` を探索し、対象が見つからない場合はそのまま return する。
- 問題: 元パケットの cancel と `LivingEntity` 解決の間に viewer の world・追跡状態または対象 entity が変化すると、元の装備更新も Paper API の再送もクライアントへ到達しない。失敗時に元更新を通す、または次の正規同期を要求する fallback がない。
- 影響: テレポート、追跡開始・終了、entity の despawn と同時に起きた装備更新では、クライアントが古い手持ち・防具表示のまま残る。現在の設計書が定める「全 slot を再送して表示を維持する」契約も満たせない。
- 修正方針: ネットワークスレッドで元パケットを cancel する前に安全に対象を特定できる同期方式へ見直すか、解決失敗時に次回の正規 equipment 同期を必ず発行する fallback を設ける。追跡状態・world 変化を含む失敗系テストを追加する。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/item/view/ItemStackPacketAdapter.java`
