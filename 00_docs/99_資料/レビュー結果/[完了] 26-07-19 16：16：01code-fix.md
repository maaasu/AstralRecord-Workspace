### AR-CODE-001 [中] メニューアイコンの定義と ItemStack 生成が View ごとに分散している
- 修正状態: `修正済み`
- 修正内容: メインメニューとクラフト欄の項目の素材・表示名・色・基本説明を `MenuIconDefinition` へ集約し、`MenuShortcutAction` は共通定義を参照する形へ変更した。`MenuIconFactory` が `GuiItems.create` 経由で呼び出しごとに独立した `ItemStack` を生成し、Gold・装備・帰還費用の動的 lore を両表示で共通化した。クラフト欄固有の PDC は生成後に付与する。
- 種別: `可読性/保守性`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/menu/view/CraftShortcutView.java:142`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/menu/view/screen/MainMenuScreenView.java:41`、`10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/menu/model/MenuIconDefinition.java:10`
- 根拠: 一般的な保守性の観点。`PLUGIN_GUIDE.md` は GUI 共通挙動を shared 側へ寄せる方針を定めている。また `GuiItems` は共通生成処理を提供するが、メニュー項目の意味定義まで一元化していない。
- 問題: `EQUIPMENT`、`CURRENCY`、`RETURN_TO_BASE` などの意味上同じメニュー項目が、`MenuIconDefinition`／`MenuShortcutAction` に一部定義されている一方、メインメニューとクラフト欄で別々に `ItemStack` と表示名・lore を組み立てている。クラフト欄には `CraftShortcutView` 独自の `createItem` もあり、`GuiItems.create` と同等の処理が重複している。
- 影響: 素材・表示名・基本説明・PDC マーカー・装飾を変更した際に反映漏れや表示差分が起こりやすい。ただし、ゴールド量や現在装備のような表示先固有の動的 lore まで同じ `ItemStack` インスタンスを共有する必要はない。
- 修正方針: 「項目の意味・基本アイコン」を `MenuIconDefinition` または専用の定義モデルへ集約し、表示先ごとに動的 lore とクリック識別子を付与する renderer/factory を共通化する。Bukkit の `ItemStack` は配置先で変更されるため、定義から毎回 clone/生成する。
- 修正可否: `修正済み`
- 確信度: `高`

### AR-CODE-002 [中] クラフト欄の選択中インベントリ表示が設計書どおり機能していない
- 修正状態: `修正済み`
- 修正内容: インベントリ種別切替時代の残存仕様と確認できたため、`selectedType` の引数・取得経路、選択中 action の glow 処理、関連設計書記述を削除した。
- 種別: `仕様不整合`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/menu/view/CraftShortcutView.java:54`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/menu/view/CraftShortcutView.java:205`、`10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/menu/view/CraftShortcutView.java:293`、`00_docs/10_Plugin設計書/feature/09-menu/3-メソッド仕様/09_3.07-GUI・View.md:178`
- 根拠: `09_3.07-GUI・View.md` は「現在表示中インベントリと一致する action には glow を付ける」と定義している。
- 問題: `renderCraftShortcuts` に `selectedType` が渡されるが、メソッド内で参照されていない。`applySelectionGlow` は `STATUS` アイコン生成時にだけ呼ばれており、通貨・装備などの現在選択状態に応じた glow 判定がない。
- 影響: プレイヤーが現在どのインベントリ／導線を表示中かをクラフト欄から判断できず、状態表示と実際の状態が一致しない。関連する `selectedType` を含む描画引数も不要なまま残っている。
- 修正方針: action と `InventoryType` の対応を定義し、描画時に一致するアイコンだけへ glow を付与する。固定ショートカット仕様で不要になった状態なら、設計書・引数・関連テストを同時に整理する。
- 修正可否: `修正済み`
- 確信度: `高`

### AR-CODE-003 [低] プレイヤー依存の GUI 描画コンテキストが個別引数へ分解され、不要なデータも渡されている
- 修正状態: `修正済み`
- 修正内容: `PlayerGuiRenderContext` と `PlayerEquipmentSnapshot` を不変モデルとして追加し、`PlayerGuiRenderContextFactory` が `AstPlayer` からアカウント、ステータス、CP / PP、Gold、帰還費用、装備表示を 1 回だけ取得する形へ変更した。View の個別引数、直接の service / `AstPlayerCache` 参照、未使用だった account 一覧とそのキャッシュを削除し、Bukkit `Player` は inventory の open / update など API 境界に限定した。
- 種別: `可読性/保守性`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/menu/event/MenuOpenEventHandler.java:860`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/menu/view/CraftShortcutView.java:51`
- 根拠: `PLUGIN_GUIDE.md` および `plugin-code.md` は、プレイヤー表現に原則 `AstPlayer` を使い、`org.bukkit.entity.Player` の直接引き回しを最小限にする方針を示している。これは GUI 境界の Bukkit 操作まで禁止するものではなく、一般的な保守性の観点を含む指摘である。
- 問題: ハンドラは `AstPlayer` から account/status/class points/accounts を個別に取り出し、View には `Player`、`selectedType`、`StatusSnapshot`、`AccountModel`、各ポイント、`accounts` を別々に渡している。しかし `CraftShortcutView` では `selectedType` と `accounts` が使用されず、通貨額や装備表示は Bukkit `Player` から直接取得している。
- 影響: プレイヤー情報の取得元と描画に必要な情報の境界が分かりにくくなり、同じ表示項目を別 GUI へ展開する際に引数追加と取得経路の重複が発生しやすい。現時点でデータ不整合が確定しているわけではない。
- 修正方針: `AstPlayer` 自体へ全機能の状態を平坦に詰め込むのではなく、GUI 用の immutable な `PlayerGuiRenderContext` などに、AstPlayer のセッション情報と画面固有の表示スナップショットをまとめる。Bukkit `Player` は openInventory・現在装備など API 境界に限定し、未使用引数は削除する。
- 修正可否: `修正済み`
- 確信度: `高`
