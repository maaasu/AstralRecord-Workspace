### AR-CODE-001 [中] 報酬配送用のフィルタ付き索引の変質を検出できない
- 種別: `バグ/アルゴリズム`
- 対象: `60_tool/management-db-migrate/Program.cs:314`
- 関連箇所: `00_docs/40_Database設計書/table-definitions/ManagementDB/migrations/20261019_defense.sql:104`
- 根拠: 正本DDLの `IX_defense_reward_pending` は `WHERE delivered_at_utc IS NULL` を持つが、新設の `table.Indexes` 検査は `is_disabled=0 AND is_unique=0` だけを確認する。追加された統合テストは索引を削除する場合のみ検査する。
- 問題: 同名の無効でない通常索引に置き換わっても ManagementDB のスキーマ検査が成功する。
- 影響: 配送済み報酬も索引へ入り、保留報酬の周期的な取得に必要な索引の形が崩れても API 配置前検査が見逃す。
- 修正方針: フィルタ付き通常索引を manifest で区別し、少なくとも `has_filter=1` を確認する。統合テストで同名の非フィルタ索引への置換を拒否する。
- 修正対象候補: `60_tool/management-db-migrate/Program.cs`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-002 [中] 日付ハイフン形式の未登録 migration を見逃す
- 種別: `バグ/アルゴリズム`
- 対象: `60_tool/management-db-migrate/Program.cs:179`
- 関連箇所: `00_docs/40_Database設計書/table-definitions/ManagementDB/migrations/20260915-import-website.sql`
- 根拠: ManagementDB の既存 migration には日付直後がハイフンの `20260915-import-website.sql` があるが、新しい登録漏れ検出は日付直後をアンダースコアに限定する。さらにファイル名全体と `20260917_web_credentials.sql` を序数比較するため、同日付のハイフン形式も閾値より小さくなる。
- 問題: `20261020-defense.sql` のような日付ハイフン形式の新規 SQL は、manifest に登録されなくても検査が成功する。
- 影響: SQL ファイルが存在しても runner の登録漏れに気付かず API を配置でき、今回の障害原因が再発し得る。
- 修正方針: 既存の両命名形式を対象にし、対象期間の判定はファイル名全体でなく先頭8桁の日付で行う。両形式の未登録ファイルを拒否する DB なしテストを追加する。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
