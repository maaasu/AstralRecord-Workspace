### AR-CODE-001 [中] 武器を握り検証なしで登録できる
- 種別: `バグ/アルゴリズム`
- 対象: `50_resourcepack/scripts/item-models.ps1:66`
- 関連箇所: `50_resourcepack/scripts/item-models.ps1:279`
- 根拠: 台帳の仮想トライデント設定を省略すると grip は任意になり、統合版の合成対象にはすべてのモデルが入る。
- 問題: 新規武器が両版の握り検証を経ずに長押し用の表示に入る。

### AR-CODE-002 [中] 統合版の握り検証が無効な姿勢を許可する
- 種別: `バグ/アルゴリズム`
- 対象: `50_resourcepack/scripts/item-model-grips.ps1:149`
- 関連箇所: `50_resourcepack/bedrock/attachables/nox_bow.json`
- 根拠: ノクスボウの一人称アニメーション条件を 0.0 にした場合と grip の縮尺を 0 にした場合に検証が通った。

- 修正方針: 一・三人称の姿勢条件、握り位置と縮尺、一人称の腕の姿勢を含めた先端の向きを検証する。

- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/item/view/ItemStackPacketAdapter.java:669`
- 関連箇所: `10_plugin/AstralRecordGeyserExtension/src/main/java/io/github/maaasu/astralrecordgeyser/ItemModel.java:159`
- 根拠: 仮想トライデントにも元のモデル番号を書き込む。Geyser は基本素材とモデル番号が合致するとカスタム ID に変換する。

- 修正方針: 統合版向け仮想コピーだけ、カスタムモデルデータの先頭値を消す。表示は別経路のモデル番号通知で行う。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 確信度: `高`

### AR-CODE-004 [中] チャンネル切替で手持ち表示が残る
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecordGeyserExtension/src/main/java/io/github/maaasu/astralrecordgeyser/AstralRecordGeyserExtension.java:93`
- 関連箇所: `10_plugin/AstralRecordGeyserExtension/src/main/java/io/github/maaasu/astralrecordgeyser/HeldWeaponModelDisplay.java:15`
- 根拠: Geyser の ServerTransferEvent は外部移送パケットで発火する。同一 Velocity の backend 切替は同じ Geyser 接続を使う。
- 問題: 切替先が通知を送るまで、または通知が来ないまま期限切れになるまで以前のモデル番号が残る。
- 影響: 通常のトライデントを主手に持つと、最大約9秒前の武器に見える可能性がある。ホットバーの切替でも定期更新まで残る。
- 修正方針: Velocity の接続切替で Geyser のプロパティを戻し、切替先からの同じモデル番号も再適用する。ホットバー切替の通知はイベント時に送る。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-005 [中] 極端な縮尺と三人称の反転を許可する
- 種別: `バグ/アルゴリズム`
- 対象: `50_resourcepack/scripts/item-model-grips.ps1:189`
- 関連箇所: `50_resourcepack/scripts/item-model-grips.ps1:204`
- 根拠: 一人称の縮尺を 1e-9 または 1e9 にし、三人称の回転を [87, 0, 0] から [-93, 0, 0] にして、それぞれ検証が通ることを確認した。
- 問題: 正の縮尺であれば大きさの制限がなく、三人称で武器が後ろを向いても数値形式の検証を通る。

- 修正方針: 両視点で全軸の縮尺を 0.5～2.0 に制限し、三人称では手のローカル座標で前向きの成分を 0.8 以上にする。
- 修正対象候補: `50_resourcepack/scripts/item-model-grips.ps1`
- 修正可否: `自動修正可`
