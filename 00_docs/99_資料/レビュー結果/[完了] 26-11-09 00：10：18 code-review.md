## 指摘一覧

### AR-CODE-001 [低] 省略されたアイコンの素材 ID を詳細で確認できない
- 種別: `仕様不整合`
- 対象: `60_tool/skilltree-editor/src/SkillTreeEditor.Client/src/components/TeleporterList.tsx:175`
- 関連箇所: `60_tool/skilltree-editor/src/SkillTreeEditor.Client/src/components/spawnerPlanning.css:97`
- 根拠: ワールド配置計画は画像と素材 ID の表示を案内している。一覧はアイコンの素材 ID を1行で省略する。マウスを合わせたときの補足は非フォーカス要素の title にあり、行を開いた詳細には素材 ID がない。
- 問題: INFESTED_MOSSY_STONE_BRICKS のような長い素材 ID は既定の列幅でも途中で省略される。キーボードやタッチで閲覧するとき、展開した詳細でも省略前の素材 ID を読めない。
- 影響: 名前の似た素材を見分けるには列幅の調整や編集画面を開く操作が必要になる。編集操作が停止中の状態でも素材 ID を確認できる経路は、列幅調整に限られる。
- 修正方針: 表示名から開く詳細に、素材 ID 全文と既定値かどうかを表示する。素材 ID を長くしたケースで確認する。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-002 [中] 通常一覧で画面と表の縦スクロールが重なる
- 種別: `バグ/アルゴリズム`
- 対象: `60_tool/skilltree-editor/src/SkillTreeEditor.Client/src/components/spawnerPlanning.css:64`
- 関連箇所: `60_tool/skilltree-editor/src/SkillTreeEditor.Client/src/components/SpawnerPlanningWorkspace.tsx:349`
- 根拠: 表の高さ上限はビューポートから固定の 15rem を引く。見出し・ツールバー・アプリのナビゲーションは別に高さを取る。Chrome の 1440×900 で通常一覧を表示すると表上端が約314px、表の高さが約660pxとなり、表下端は画面外だった。画面右端と表右端の両方に縦スクロールバーが表示された。
- 問題: 表をスクロールしても画面に収まらない部分が残り、表下端や横スクロールを操作するには画面側もスクロールする必要がある。
- 影響: 一覧を読むだけの状態でも二つの縦スクロールを操作することになり、右側の列に移動するまでの操作が増える。
- 修正方針: 一覧の通常表示では、見出しとツールバーを配置した後の実際の残り高さに表を収める。編集や狭い画面では画面の縦スクロールで内容に届くことを確認する。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
