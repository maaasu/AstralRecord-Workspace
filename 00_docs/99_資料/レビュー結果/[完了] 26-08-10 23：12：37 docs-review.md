### AR-DOC-001 [中] 冒険者の序盤 HP が共通アンカー上限を超える
- 種別: `矛盾`
- 対象: `00_docs/60_戦闘バランス設計書/03-クラス別戦闘バランス/01-冒険者.md:77`
- 関連箇所: `00_docs/60_戦闘バランス設計書/02-成長曲線.md:90`
- 根拠: Player Lv.1 の共通基準 HP は50であり、最適構成を含む基礎実数系の上限は標準アンカーの130%程度である。一方、職業 Lv.1 / Player Lv.1 に対応するこの表の `MAX_HEALTH` は125である。
- 問題: 冒険者を平均的な生存力と定義しながら、Lv.1 の最終 HP が共通アンカーの250%となり、明示した設計上限を超える。
- 影響: 序盤の耐久時間が受入目標から外れ、専門職との比較および以降の equipment・skilltree 配分の基準として使えない。
- 修正方針: Player Lv.1 のアンカーを共通基準の130%以内へ再配分し、Player Lv.2〜6 の対応行も共通成長曲線と職業差の範囲で連続する値へ見直す。
- 修正対象候補: `00_docs/60_戦闘バランス設計書/03-クラス別戦闘バランス/01-冒険者.md`
- 修正可否: `自動修正可`

### AR-DOC-002 [中] 内訳例が宣言した獲得源の配分比と一致しない
- 種別: `矛盾`
- 対象: `00_docs/60_戦闘バランス設計書/03-クラス別戦闘バランス/01-冒険者.md:94`
- 関連箇所: `00_docs/60_戦闘バランス設計書/03-クラス別戦闘バランス/01-冒険者.md:109`
- 根拠: Lv.1→30 の `MAX_HEALTH` 増加分は1,365であるが、内訳から算出した class + Player Lv.成長は255（約19%）、skilltreeは30（約2%）、equipmentは1,080（約79%）となる。これは25% / 25% / 50%の出発点と大きく異なる。
- 問題: 「配分の判断基準」と「確認用内訳」が両立していないため、どちらを正として調整すべきか判断できない。
- 影響: 表の内訳を使って class・skilltree・equipment を実装へ配分すると、意図しない装備依存と skilltree の選択差不足を固定化する。
- 修正方針: 各 status の Lv.1 からの増加分を25% / 25% / 50%へ再計算して内訳を合わせる。例外を維持する status がある場合は、理由と適用する比率を明記する。
- 修正対象候補: `00_docs/60_戦闘バランス設計書/03-クラス別戦闘バランス/01-冒険者.md`
- 修正可否: `自動修正可`

### AR-DOC-003 [中] 装備更新帯が Player Level 基準の設計と食い違う
- 種別: `矛盾`
- 対象: `00_docs/60_戦闘バランス設計書/03-クラス別戦闘バランス/01-冒険者.md:63`
- 関連箇所: `00_docs/60_戦闘バランス設計書/02-成長曲線.md:118`
- 根拠: 成長曲線は Player Lv.5ごとに少なくとも1〜2部位の主力equipmentを更新可能にすると定める。一方、進行対応表は Player Lv.2で第1更新、Lv.4でも第1更新、Lv.6で第2更新としており、更新帯と到達基準の対応を示していない。
- 問題: 職業 Lv.を主軸にする補助対応表で、Player Lv.基準の更新帯を別の節目へ振り替えているため、入手導線と更新性能差の検証位置が不明確になる。
- 影響: Player Lv.5・10 の共通アンカーを基準にした equipment 更新およびTTK検証を、冒険者の表から再現できない。
- 修正方針: Player Lv.5ごとの共通更新帯を表へそのまま対応付けるか、冒険者の早いclass進行で先行して取得する別の更新を示すなら、入手時期・性能差・共通更新帯との関係を追記する。
- 修正対象候補: `00_docs/60_戦闘バランス設計書/03-クラス別戦闘バランス/01-冒険者.md`

### AR-DOC-004 [中] `ATTACK` を解決攻撃力 `R` と同一視している
- 種別: `矛盾`
- 対象: `00_docs/60_戦闘バランス設計書/03-クラス別戦闘バランス/01-冒険者.md:78`
- 関連箇所: `00_docs/60_戦闘バランス設計書/02-成長曲線.md:38`
- 根拠: 成長曲線は `R` を複数 status の合算結果と定め、`ATTACK`・主能力値・種別攻撃力を組み合わせて `R` に近づけるとしている。一方、この表は `ATTACK` を `R` の値348.00として配分し、Lv.30のDPS試算でも `ATTACK = R = 348.00` としている。
- 問題: `ATTACK` に `R` と同じ値を設定すると、基本能力値または種別攻撃力の派生分を加えた最終 `R` がアンカー348.00を超える。逆にそれらを常に0とする意図も記載されていない。
- 影響: skill DPS、TTK、equipment・skilltreeの各status配分が、成長曲線の共通アンカーと異なる実戦値で算出・実装される。
- 修正方針: 表とDPS試算の主語を解決攻撃力 `R` に変更して `ATTACK` の内訳を別に示すか、`ATTACK` と派生statusから `R` へ至る構成およびDPS計算に使う最終 `R` を明記する。
- 修正対象候補: `00_docs/60_戦闘バランス設計書/03-クラス別戦闘バランス/01-冒険者.md`
- 修正可否: `自動修正可`
