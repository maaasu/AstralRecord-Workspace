- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/account/command/AccountDeleteCommand.java`

- 根拠: セッション破棄より前に `TradeService.cancelTrade(player)` を呼ばないため、取引の相手側と予約状態が残る。
