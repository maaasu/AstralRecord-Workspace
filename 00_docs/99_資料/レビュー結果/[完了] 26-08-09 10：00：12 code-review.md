### AR-CODE-001 [中] 未習得スキル表示で倍率プレースホルダーが解決されない
- 種別: `バグ/アルゴリズム`
- 対象: `40_filebase/30.features.skill/v1.adventurer_lightning_bolt.yml:12`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/service/SkillPresentationUtil.java:151`
- 根拠: 未習得スキルの表示経路は基礎 `SkillDefinition` と空の解決情報を使うため、既存の effective 倍率生成を通らない。今回の YAML は `effectiveDamageRatio` と `effectiveChainDamageRatio` を lore で参照している。
- 問題: 未習得スキルを表示すると、主倍率と連鎖倍率の placeholder が `?` へ解決され、ライトニングボルトの性能を確認できない。
- 影響: 未習得状態のスキル一覧・詳細 GUI で、今回追加したスキルの表示品質と仕様理解を損なう。
- 修正方針: 基礎定義を表示する経路でも `damageRatio` と `chainDamageRatio` の effective 値を補正0%として生成し、未習得スキルの両 placeholder が基礎倍率へ解決される回帰テストを追加する。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/service/SkillPresentationUtil.java、10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/skill/service/SkillPresentationUtilTest.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-002 [低] JavaDoc不足（コーディングルール違反）

- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/active/service/SkillCombatService.java:80-84`
- 関連箇所: `PLUGIN_GUIDE.md:公開メソッドのJavaDoc要件`
- 根拠: 新規公開メソッド `hasCondition` に引数・戻り値を説明する日本語JavaDocがなく、公開メソッドのドキュメント要件を満たしていなかった。

- 修正方針: `@param target`、`@param type`、`@return` を含む日本語JavaDocを追加する。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/active/service/SkillCombatService.java`
