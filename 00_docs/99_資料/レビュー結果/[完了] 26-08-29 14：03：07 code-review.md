### AR-CODE-001 [中] 壁反射とBlock衝突順の恒久テストが不足
- 種別: `テスト不足`
- 対象: `10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/skill/executor/active/mage/MageSparkingExecutorTest.java:175`
- 関連箇所: `00_docs/10_Plugin設計書/feature/13-skill/13_6-発動スキル追加ガイド.md:371`
- 根拠: 設計書第23節は、現在方向と螺旋座標軸の反射、同tick残距離、Block手前のMob優先を恒久テスト対象としている。
- 問題: 新しい反射テストは `SparkState.reflectTrajectory` と次tickの差分だけを直接確認しており、実処理 `advanceSparks` を通らない。現在方向の反射、衝突後の残距離、0.05m offset、BlockとMobの距離比較は未検証で、以前の実処理を通す残距離テストも削除されている。
- 影響: `direction` の反射漏れや衝突順の退行が起きてもテストが成功し、壁へ潜る・壁越しに命中する可能性がある。
- 修正方針: 螺旋1tickを使って `blockHit` を壁、次に `null` と返す実処理テストを復元し、反射前後の線分と合計移動距離を確認する。Blockより手前のMobは命中し、同距離または奥のMobは命中しないケースも追加する。
- 修正対象候補: `10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/skill/executor/active/mage/MageSparkingExecutorTest.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-003 [低] 微小な有効値で螺旋の進行方向が更新されない
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/executor/active/mage/MageSparkingExecutor.java:270`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/executor/active/mage/MageSparkingExecutor.java:129`
- 根拠: `MOVEMENT_EPSILON` は残距離判定では線形距離 `1.0E-8` として使われるが、`advanceSpiral` では二乗長と直接比較している。
- 問題: `1.0E-8 < movement.length() <= 1.0E-4` の場合、移動処理は実行される一方で `direction` が更新されず、螺旋差分とは異なる古い方向へ進む。`spiralRadiusGrowth` は正数なら検証を通るため到達可能である。
- 影響: 現行本番値 `0.10` では発生しないが、将来の有効な微小パラメータ調整で軌道が崩れる。
- 修正方針: 二乗長を `MOVEMENT_EPSILON * MOVEMENT_EPSILON` と比較し、移動処理と進行方向更新の閾値を一致させる。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/executor/active/mage/MageSparkingExecutor.java`
- 修正可否: `自動修正可`
