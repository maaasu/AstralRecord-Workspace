## 指摘一覧

### AR-CODE-001 [低] 停止中の見積完了が無効な scheduler へ同期 task を登録する
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/market/event/MarketGuiEventHandler.java:598`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/market/event/MarketGuiEventHandler.java:211`
- 根拠: item 選択後の HTTP 見積は非同期 task 内で完了し、直後に無条件で `Bukkit.getScheduler().runTask(plugin, ...)` を呼ぶ。shutdown は `closing = true` と `sessions.clear()` を行うが、この登録前の `closing` 判定や登録失敗の処理はない。
- 問題: 同期 HTTP が Plugin 停止をまたいで完了すると、停止済み Plugin への task 登録が例外となり、非同期 task から未処理で流れる。
- 影響: 停止時に scheduler 例外が出る。session 照合は同期 task 内なので、この登録失敗を防げない。
- 修正方針: 非同期 HTTP 完了後に停止状態を確認し、同期 task 登録が停止競合で拒否された場合は結果を破棄する。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/market/event/MarketGuiEventHandler.java`
