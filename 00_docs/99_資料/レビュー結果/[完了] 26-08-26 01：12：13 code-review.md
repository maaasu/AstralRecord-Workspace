## 指摘一覧

### AR-CODE-001 [中] transform 毎 tick 化で非 transform 処理も毎 tick 実行される
- 種別: `パフォーマンス`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/mob/service/MobService.java:596`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/mob/service/NpcPlayerSkinPacketService.java:159`
- 根拠: `syncPlayerSkinPacketViews` は毎 tick、表示対象全インスタンスに既存の `sync` を呼ぶ。`sync` は transform 差分判定だけでなく、viewer 集合コピー、`Bukkit.getPlayer`、名前タグ team 更新、`ViewerTransform` 生成も行う。設計書は viewer 探索を 5 tick、既存 viewer への transform だけを毎 tick 差分同期すると定める。
- 問題: 移動していない NPC でも PLAYER 型 NPC と viewer の組み合わせごとに集合割り当てと scoreboard 操作が毎 tick 発生する。
- 影響: メインスレッド負荷が NPC 数と viewer 数に比例して増え、滑らかさ改善がサーバ tick の遅延要因になる可能性がある。
- 修正方針: viewer 参加・再表示時の処理と毎 tick transform 処理を分離し、毎 tick 経路は表示中 state に対する transform 差分判定と必要な packet 送信だけに限定する。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/mob/service/NpcPlayerSkinPacketService.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-002 [高] viewer lifecycle 同期が呼ばれず疑似 Player を表示開始できない
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/mob/service/MobService.java:797`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/mob/service/NpcPlayerSkinPacketService.java:141`
- 根拠: `updateViewers(instance)` から `playerSkinPacketService.sync(instance, currentViewers)` が削除され、`syncTransforms` は state が未作成なら終了するため、state 作成・viewer 追加削除・実体表示切替がどこからも実行されない。
- 問題: 新規 spawn、viewer の範囲内追加・範囲外削除、ProtocolLib 無効時の既存 state 破棄が機能しない。
- 影響: PLAYER 型 NPC が疑似 Player として表示開始されず、既存表示も停止・残留するため表示機能全体が壊れる。
- 修正方針: 5 tick の `updateViewers(instance)` 後に lifecycle 用 `playerSkinPacketService.sync(instance, currentViewers)` を維持し、毎 tick 経路だけ `syncTransforms(instance)` を使う。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/mob/service/MobService.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
