- 問題: 3テストとも `CreativeFlySpeedCommand#executeCommand` を直接呼び出しており、`AstCommand.onCommand` の permission ガード、コンソール省略時の拒否、`CommandRegister` から `flyspeed` が登録される経路を通っていない。そのため、必要権限の指定や登録呼出しが将来欠落してもテストは成功する。

- 修正方針: 低権限プレイヤーと permission `99` 以上の実行者について `onCommand` または `canUse` を通るテストを追加し、コンソールの対象省略拒否と `CommandManager` の `flyspeed` 登録を検証する。
