## 指摘一覧

### AR-CODE-001 [中] W_5753 の world 引数がワールド名ではなく filesystem パス
- 種別: `ドキュメント不整合`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/world/event/WorldJoinSpawnEventHandler.java:56`
- 関連箇所: `10_plugin/AstralRecord/src/main/resources/logger.properties:251`
- 根拠: `W_5753` は `world=%s` を記録する定義であり、他の呼出元は Bukkit `World#getName()` を渡す。一方、この箇所が渡す `WorldMasterData.baseWorldPath` は record の定義どおり「複製元ワールドパス」で、filebase では `plugins/AstralRecord/worlds/base/starlit_nox` のような filesystem パスである。
- 問題: ログの `world` 欄に実行時ワールド名ではなくパスが記録され、同じ `W_5753` の既存ログと値の意味が一致しない。
- 影響: 参加時スポーン転送の失敗時、運用者がログの `world` を実際の Bukkit world として検索・照合できず、障害調査を誤る可能性がある。
- 修正方針: `W_5753` の world 引数を実行時ワールド名として扱う既存契約を維持するなら、ロード成功後の Bukkit world 名を渡せる位置で失敗を記録する。ロード未達時にパスを記録する必要があるなら、文言を path として明示する別ログ ID を用いる。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/world/event/WorldJoinSpawnEventHandler.java`
- 修正可否: `要確認`
