### AR-CODE-001 [中] 破棄 packet の送信失敗後に表示 ID を見失う
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/spawner/service/SpawnerVisualizer.java:353`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/spawner/service/SpawnerPacketDisplay.java:213`
- 根拠: `SpawnerPacketDisplay.send` は送信失敗時に `false` を返すが、`PacketEntity.destroy` はその結果を捨てる。`SpawnerVisual.destroy` は送信結果に関係なく `spawned` と `text` を消し、範囲外・モード off・ラベル切替では追跡 map からも表示を除去する。
- 問題: オンライン viewer への `ENTITY_DESTROY` が一時的に失敗すると、クライアント上の旧 packet entity が残ったまま、サーバー側はその entity ID を再送対象から外す。
- 影響: 同じチャンク内で範囲外へ移動した場合や表示モードを `off` にした場合、旧ブロック・ラベルがチャンク解除または再接続まで残り得る。ラベル切替では旧ラベルと新ラベルが重なり得る。
- 修正方針: オンライン viewer の破棄送信結果を保持し、失敗した entity ID の destroy を後続周期で再試行する。送信成功または viewer の切断などクライアント状態が失われた時点で追跡を解除する。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-002 [低] 停止時の破棄失敗は再送されない
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/spawner/service/SpawnerVisualizer.java:113`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/AstralRecord.java:888`
- 根拠: `stop` は周期 task を停止し listener を解除してから `clearViewer` を一度だけ呼ぶ。`clearViewer` は破棄送信に失敗した表示を map に保持するが、停止後は周期同期も切断イベントも受けない。Mob・採集の両 service はプラグイン無効化時にこの `stop` を呼ぶ。
- 問題: viewer が接続したままプラグインだけ無効化され、`ENTITY_DESTROY` が失敗すると、保持した entity ID を再送する経路がない。
- 影響: クライアントのチャンク解除または切断まで、旧管理表示が残り得る。
- 修正方針: 停止時に破棄失敗した表示について、接続継続中の再送またはクライアント状態の確実な解除を行えるライフサイクル方針を決める。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/spawner/service/SpawnerVisualizer.java`
- 修正可否: `設計判断待ち`
- 確信度: `高`
- 修正状態: `未修正`
