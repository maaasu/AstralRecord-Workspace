## 指摘一覧

### AR-CODE-001 [中] whitelist 有効化通知の許可条件が古い
- 種別: `ドキュメント不整合`
- 対象: `10_plugin/AstralRecord/src/main/resources/player.properties:635`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/whitelist/command/WhitelistCommand.java`
- 根拠: `WhitelistService.isAllowed` は `debugUsers` と `whitelistUsers` のいずれかを許可し、`WhitelistCommand` は whitelist 有効化時に `PlayerMsgId.P_7110` を送信する。関連設計書も両方の設定を許可する契約へ更新されている。
- 問題: `P_7110` の文言が `debugUsers` に登録されたプレイヤーのみ参加可能と案内しており、`whitelistUsers` に登録されたプレイヤーも参加できる実装と一致しない。
- 影響: whitelist 有効化時に表示される運用案内が誤り、管理者が接続許可設定を誤認する可能性がある。
- 修正方針: `P_7110` の文言を `debugUsers` または `whitelistUsers` に登録されたプレイヤーが参加できる内容へ更新する。
- 修正対象候補: `10_plugin/AstralRecord/src/main/resources/player.properties`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-002 [低] whitelistUsers の実設定読込テストが不足している
- 種別: `テスト不足`
- 対象: `10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/whitelist/service/WhitelistServiceTest.java:35`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/infrastructure/config/ConfigProperties.java:87`
- 根拠: 追加されたサービステストは `ConfigProperties` をモックしており、`ConfigProperties.initialize` / `reload` が `plugin.whitelistUsers` を読み込む実処理を通過しない。
- 問題: 有効な UUID、前後空白、不正 UUID、空値・未設定、reload 後の設定置換が壊れても、設定ローダーのテストでは検出できない。
- 影響: 本番 config.yml の記述ミスや設定リロード時の whitelistUsers 反映不良を見逃す可能性がある。
- 修正方針: ConfigProperties の恒久テストを追加し、debugUsers と whitelistUsers の UUID解析、空白・不正値の無視、reload 後の値置換を検証する。
- 修正対象候補: `10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/infrastructure/config/ConfigPropertiesTest.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
