### AR-CODE-001 [低] マーケット GUI の遷移・表示更新に回帰テストがない
- 種別: `テスト不足`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/market/event/MarketGuiEventHandler.java:169`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/market/event/MarketGuiEventHandler.java:581`
- 根拠: MY_LISTINGS 下部インベントリ click の委譲先を変更し、出品・購入・取り下げ・売上受取の各非同期完了 callback に表示更新を追加している。一方、`10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/market/` に `MarketGuiEventHandler` のイベントテストはなく、既存 `MarketGuiTest` はレイアウトのみを検証している。
- 問題: 同じアイテムをクリックしても取り下げ確認へ遷移しないこと、および mutation 成功時だけ Bukkit 所持品表示を更新することを自動検証できない。
- 影響: 今回修正した二つのユーザー起因回帰が、将来の GUI 分岐・非同期 callback の変更で再発しても検知できない。
- 修正方針: MY_LISTINGS の PlayerInventory item click が出品設定へ遷移し取消確認へ進まないこと、4 種の mutation 成功 callback が表示更新を一度実行し、失敗時には実行しないことを検証するイベントテストを追加する。
- 修正対象候補: `10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/market/`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
