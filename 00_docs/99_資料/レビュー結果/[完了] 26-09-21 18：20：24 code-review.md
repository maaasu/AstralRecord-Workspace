- 種別: `ドキュメント不整合`
- 対象: `00_docs/20_API設計書/feature/11-skill/1-モデル定義/11_1.00-モデル定義.md:75`

- 根拠: 実装とエンドポイント仕様はプリセット1〜9、active/passive各12枠へ変更済みですが、モデル定義はプリセット1..6、active 6要素、passive 9要素と記載しています。

- 修正方針: `11_1.00-モデル定義.md` の該当記述を、プリセット1〜9とactive/passive各12要素の契約、短い既存配列は末尾null補完して位置を保持する仕様へ更新します。
