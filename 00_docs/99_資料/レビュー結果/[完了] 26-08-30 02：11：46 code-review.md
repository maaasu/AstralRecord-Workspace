### AR-CODE-001 [中] ENTITY_EQUIPMENT境界の回帰テストが不足している
- 種別: `テスト不足`
- 対象: `10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/item/view/ItemStackPacketAdapterTest.java:242`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/item/view/ItemStackPacketAdapter.java:318`
- 根拠: `OFF_HAND_DISPLAY` の条件判定と表示用コピー単体は検証されているが、`ENTITY_EQUIPMENT` の受信者判定から Paper API 再送までの経路、設定変更後の再同期、他プレイヤー表示の非回帰を検証するテストが不足している。
- 問題: 送信先が本人か他プレイヤーか、ProtocolLib の装備slotが OFFHAND か、設定変更後に再送されるかの組み合わせを壊しても、現在の単体テストでは検出できない。
- 影響: 本人だけを `STONE_BUTTON` にする契約や、他プレイヤーからは通常アイテムにする契約が将来の変更で破綻する可能性がある。
- 修正方針: 実装本体の Paper API 再送境界を通るテストを追加し、本人の OFFHAND 置換、他エンティティの通常アイコン維持、`refreshEquipmentView` の即時反映を検証する。ProtocolLib の生パケット初期化ができない単体環境では、装備更新生成と送信境界を分離して検証する。
- 修正対象候補: `10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/item/view/ItemStackPacketAdapterTest.java`
