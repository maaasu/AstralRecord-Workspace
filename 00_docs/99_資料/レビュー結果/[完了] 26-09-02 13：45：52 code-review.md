## 指摘一覧

### AR-CODE-001 [中] シジル操作テストが共通消費順を検証しない
- 種別: `テスト不足`
- 対象: `10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/skill/service/SkillSigilOrbServiceTest.java:87`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/inventory/service/InventoryService.java:2597`
- 根拠: 通常アイテムの消費元entryは、BAGをHOTBARより優先し、各inventoryではslotIndexの大きいentry、未指定slot、同slotではinventoryEntryId昇順で解決する。修正前のシジル装着・脱着テストはresolverの戻り値を単一entryへ固定しており、この順序を検証していなかった。
- 問題: 共通resolverの戻り値を誤ってクリックentryへ置き換える回帰が、シジル操作テストで検出できなかった。
- 影響: シジル装着・脱着で、クリックしたslotのentryや共通順でないentryがAPIへ渡される回帰を見逃す可能性がある。
- 修正方針: 複数のBAG/HOTBAR entry、後方slot、未指定slot、同slotのentry IDを用意し、共通消費順で選ばれるオーブ・シジルentry IDをAPI呼び出しへ渡すことを検証する。
- 修正対象候補: `10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/skill/service/SkillSigilOrbServiceTest.java`
- 修正可否: `自動修正可`
