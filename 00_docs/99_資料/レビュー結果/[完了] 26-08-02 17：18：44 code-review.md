### AR-CODE-001 [高] API成功後の再同期失敗で合成を失敗扱いにする
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/service/LearnedSkillService.java`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/event/SkillBindGuiEventHandler.java`
- 根拠: API mutation は成功していても素材entryの再同期例外が同じ失敗経路へ入っていた。
- 問題: 消費済みの素材を失敗時に復元表示し、二重消費に見える。
- 影響: ジェム・シジル合成の結果と表示インベントリが不整合になる。
- 修正方針: 再同期失敗は成功結果を維持し、ローカルstateへ一個消費を反映して警告を残す。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/service/LearnedSkillService.java`
- 修正可否: `自動修正可`
