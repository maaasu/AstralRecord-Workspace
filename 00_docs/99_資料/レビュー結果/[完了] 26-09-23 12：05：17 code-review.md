### AR-CODE-001 [中] 連撃バフの残り時間を通常攻撃一回で二重消費する
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/service/InheritanceBuffService.java:213`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/service/InheritanceBuffService.java:223, 40_filebase/30.features.skill/v1.sharpshooter_inheritance_mastery.yml:56`
- 根拠: `normalAttackExtraCount` を持つ連撃Ⅰは通常攻撃開始時に 600tick を消費して追撃を予約しますが、命中 callback は `onImpact` ではなく全ての `captured` を走査するため、同じ継承をもう一度 600tick 消費します。`BuffService#consumeDuration` は残り時間が 600tick 未満でもバフを解除して `true` を返すため、1・2回目の有効命中は各60秒を消費し、3回目の予約時に残り時間をすべて消費します。
- 問題: 継承バフ連撃Ⅰは通常攻撃一回につき30秒だけ消費する仕様ですが、149秒の付与時間が通常攻撃3回で尽きます。本来は4回消費後に残る時間を5回目で消費して、5回の通常攻撃に追撃を付与できます。
- 影響: 継承の心得を有効にしたファントムショットの連撃付与回数が仕様上の5回から3回へ減り、表示された持続時間と実際の使用回数が一致しません。
- 修正方針: 追撃を予約した `extraCount > 0` の継承は命中時の再消費と効果適用の対象から除外し、`onImpact` のみを走査するよう統一する。追撃予約に失敗した場合の継承効果も発動させない。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/service/InheritanceBuffService.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

- 修正方針: 箇条書きへファントムショット node `2258` を追加し、ファントムアーチャー側の未配置 skill node を両方明記する。

### AR-CODE-003 [中] 連撃の追加通常攻撃が有効な拡散継承を無視する
- 種別: `仕様不整合`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/service/InheritanceBuffService.java:196`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/item/executor/WeaponAttackSkillExecutor.java:320; 00_docs/60_戦闘バランス設計書/03-クラス別戦闘バランス/07-シャープシューター.md:47,79`
- 根拠: 拡散する野望の継承バフは有効中の遠距離通常攻撃を5方向へ散開させる仕様です。ファントムショットの連撃は同じ通常攻撃を5・10tick後に追加し、追加攻撃では継承バフを追加消費しないだけです。しかし追撃実行中は `bonusAttackInProgress` により `prepareAttack` が空の `PreparedAttack` を返すため、`hasActiveSourceSkill(sharpshooter_spreading_ambition)` が常にfalseとなり、追撃2回は1方向にしか発射されません。
- 問題: 拡散継承と連撃継承を併用しても、残り時間が有効な追撃へ拡散効果が適用されない。
- 影響: 継承バフの組み合わせで通常攻撃の性質を変えるクラス仕様と、拡散する野望の「バフ中の遠距離通常攻撃は5方向」という仕様に反する。プレイヤーは初撃だけ5方向、追撃2回は1方向となる。
- 修正方針: 追撃の再予約と継承時間の追加消費だけを抑止し、追撃でも有効な継承の発射時効果を参照できるようにする。少なくとも拡散する野望の方向判定は、追撃時にも有効バフから解決し、追撃では消費callbackを実行しない。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/service/InheritanceBuffService.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
