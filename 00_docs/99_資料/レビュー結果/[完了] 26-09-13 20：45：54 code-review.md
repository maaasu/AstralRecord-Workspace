### AR-CODE-001 [中] ドラッグ中の辺の接続ハンドルが更新されない
- 種別: `バグ/アルゴリズム`
- 対象: `60_tool/skilltree-editor/src/SkillTreeEditor.Client/src/components/SkillTreeCanvas.tsx:133`
- 関連箇所: `60_tool/skilltree-editor/src/SkillTreeEditor.Client/src/components/SkillTreeCanvas.tsx:154`
- 根拠: edge の接続ハンドルは `structure.nodes` から算出している一方、ドラッグ中の位置は `flowNodes` にだけ反映され、`structure` はドラッグ停止時まで更新されない。
- 問題: ノードを上下・左右へまたいで移動しても、ドラッグ中のedgeは移動前の向きで選んだハンドルに接続され続ける。
- 影響: 移動中に接続線が不自然な辺から出るか、停止時に急に切り替わる。
- 修正方針: edge のルーティングだけは現在の `flowNodes` の位置から導出し、構造と履歴の確定はドラッグ停止時のままにする。
- 修正対象候補: `60_tool/skilltree-editor/src/SkillTreeEditor.Client/src/components/SkillTreeCanvas.tsx`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-002 [中] 構造同期後に複数選択の表示と操作対象が乖離する
- 種別: `バグ/アルゴリズム`
- 対象: `60_tool/skilltree-editor/src/SkillTreeEditor.Client/src/components/SkillTreeCanvas.tsx:101`
- 関連箇所: `60_tool/skilltree-editor/src/SkillTreeEditor.Client/src/components/SkillTreeCanvas.tsx:278`
- 根拠: 構造変更時に `initialNodes` で `flowNodes` を置換するが、選択状態を反映しないと内部の `selectedIds` だけが維持される。
- 問題: 複数選択したノードをドラッグ後、画面上では選択が外れていても右クリック操作が古い複数選択に作用し得る。
- 影響: 意図しない複数ノードに削除などの操作が実行される。
- 修正方針: 外部同期用ノードに `selectedIds` を反映し、表示と操作対象を同じ選択集合へ同期する。
- 修正対象候補: `60_tool/skilltree-editor/src/SkillTreeEditor.Client/src/components/SkillTreeCanvas.tsx`
