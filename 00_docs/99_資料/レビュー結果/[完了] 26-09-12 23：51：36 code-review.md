### AR-CODE-001 [高] 再計算が一時シールドの実行時状態を破棄する
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/status/service/StatusService.java:206`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/combat/service/DamageService.java:1935`
- 根拠: `MAX_SHIELD` 非依存の一時Shieldを有効中でも、再計算の最大Shieldが0以下の分岐が `clearShieldRuntimeState` を実行し、付与状態と表示capacityを削除する。
- 問題: filebase再読込やステータス再計算直後に、一時Shieldが被ダメージを吸収できなくなる。
- 影響: タンクシールドアクティベート未所持または最大Shield 0の対象で、20秒間の付与契約が破綻する。
- 修正方針: 有効な一時Shield中は通常リチャージ状態だけを破棄し、一時付与状態と表示capacityを維持する。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/status/service/StatusService.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-002 [中] 一時シールド失効と通常リチャージ完了が同一周期に競合する
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/status/service/StatusService.java:557`
- 関連箇所: `00_docs/10_Plugin設計書/feature/07-status/3-メソッド仕様/07_3-サービス.md`
- 根拠: 一時Shield失効後も同じ `completeShieldRechargeIfReady` 呼出しで期限切れの通常リチャージstateを処理する。
- 問題: 期限時に一時Shieldを0へ戻しても、同一周期に通常Shieldが上書きする。
- 影響: 20秒の付与期限での失効状態を観測できない。
- 修正方針: 一時Shieldを失効した呼出しでは通常リチャージを処理せず、次回周期から既存stateを処理する。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/status/service/StatusService.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/executor/active/paladin/PaladinShieldExecutor.java`

### AR-CODE-004 [中] Shield runtime破棄時に一時シールド値が残る
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/status/service/StatusService.java:644`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/player/death/PlayerDeathService.java:160`
- 根拠: UUIDだけを受けるShield runtime破棄は一時付与の状態を削除するが、対象の現在Shield値を0へ更新できない。
- 問題: 死亡・ログアウト・明示破棄後に一時Shieldの現在値がセッションへ残る。
- 影響: 一時Shieldの終了契約と実際の現在Shield値が一致しない。
- 修正方針: プレイヤーを受ける破棄経路で一時Shield値を0へ戻してからruntime状態を削除し、死亡・ログアウトはこの経路を呼び出す。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/status/service/StatusService.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
