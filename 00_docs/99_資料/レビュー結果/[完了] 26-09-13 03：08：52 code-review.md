- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/service/SkillService.java:769`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/executor/active/paladin/PaladinHolyControlExecutor.java:102`
- 根拠: `failureWithCostAndCooldown` はリソース消費とクールダウンを要求するが、共通制御が失敗通知を成功以外の分岐で実行していない。

- 修正方針: 消費を伴う失敗でも通常の失敗通知を実行する。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/service/SkillService.java`

### AR-CODE-002 [中] 同じ聖柱への再発動で効果が累積する
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/executor/active/paladin/PaladinHolyControlExecutor.java:109`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/buff/service/BuffService.java:137`
- 根拠: 発動ごとに一意の scope をバフ・一時効果 ID に使用しており、同一聖柱を再度制御しても既存の task と効果を置換しない。
- 問題: 同じ柱への再発動後、複数の task が継続してスキル与ダメージと被ダメージ倍率を重複付与する。
- 影響: 同一の聖柱から +10%、+15% と意図しない累積が発生する。
- 修正方針: 聖柱単位で制御状態を一意に管理し、再発動時は既存の task と付与済み効果を置換する。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/executor/active/paladin/PaladinHolyControlExecutor.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
