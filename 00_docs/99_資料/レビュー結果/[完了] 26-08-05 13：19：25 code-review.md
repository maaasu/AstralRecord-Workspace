### AR-CODE-001 [中] コマンド直開きのスキルマネージャーに再生音がない
- 種別: `仕様不整合`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/event/SkillBindGuiEventHandler.java:102`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/command/SkillCommand.java:18`
- 根拠: `SkillCommand` は `/skill` と `/skill gui` で `SkillBindGuiEventHandler.open` を直接呼び出すが、この成功経路には `GuiSound` の再生がない。メニュー経由は `MenuOpenEventHandler` で `GuiSound.SELECT` を再生してから同じ `open` を呼ぶ。
- 問題: メニュー経由では音が鳴る一方、コマンドで同じスキルマネージャーを開くと無音である。今回の要求で対象となる GUI 表示のフィードバックが導線によって欠落する。
- 影響: `/skill` を使うプレイヤーは、スキルマネージャーを開いたことへの聴覚フィードバックを受けられない。
- 修正方針: 成功して GUI を開く `/skill` の直開き導線にも `GuiSound.OPEN` を一度だけ再生する。メニュー経由の既存 `SELECT` と二重再生にならない配置を確認する。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/command/SkillCommand.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-003 [低] 読み込み未完了時にもコマンドの OPEN 音が鳴る
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/command/SkillCommand.java:22`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/event/SkillBindGuiEventHandler.java:104`
- 根拠: `/skill` は `GuiSound.OPEN` を再生してから `SkillBindGuiEventHandler.open` を呼ぶが、後者は習得スキルまたはプリセットの未ロード時に GUI を開かず `GuiSound.DENY` と `P_5848` を返す。
- 問題: GUI を開けない状態でも OPEN 音が先に鳴り、直後に DENY 音が重なる。追加した `SkillCommandTest` も成功経路だけを確認しており、この不整合を検出できない。
- 影響: 読み込み直後などの拒否操作で、GUI が開いたかのような誤った聴覚フィードバックを与える。
- 修正方針: `SkillBindGuiEventHandler.open` の成功可否をコマンド側が判定できるようにし、成功して GUI を開いた場合だけ OPEN 音を一度再生する。未ロード拒否では DENY のみになることをテストし、コマンド設計書の再生タイミングも実装に合わせる。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
