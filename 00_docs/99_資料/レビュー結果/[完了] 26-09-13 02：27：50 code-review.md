## 指摘一覧

### AR-CODE-001 [高] 最高権限のRPG間接続が現在接続判定で拒否される
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecordProxy/src/main/java/io/github/maaasu/astralrecordproxy/AstralRecordProxyPlugin.java:338`
- 関連箇所: `00_docs/10_Plugin設計書/feature/33-network/33_4-統合フロー.md`
- 根拠: 保存完了後の`connect`を受け取る時点でもプレイヤーは移動元RPGへ接続中であり、`currentlyInGame`はtrueになる。
- 問題: 接続元と最高権限の検証を通過した後も、RPG接続中という理由だけで要求を拒否するため、`/server <gameServer>`によるRPG間移動が常に失敗する。
- 影響: 今回追加した最高権限ユーザー向け直接チャンネル移動を利用できない。
- 修正方針: `currentlyInGame`拒否を最高権限以外に限定し、通常プレイヤーの既存拒否を維持する。RPG間の保存後接続要求が許可される回帰テストを追加する。
- 修正対象候補: `10_plugin/AstralRecordProxy/src/main/java/io/github/maaasu/astralrecordproxy/AstralRecordProxyPlugin.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
