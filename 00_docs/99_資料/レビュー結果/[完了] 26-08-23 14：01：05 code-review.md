### AR-CODE-001 [高] ProtocolLib の初期化時期が早く packet 表示が無効化される
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/mob/service/NpcPlayerSkinPacketService.java:68`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/AstralRecord.java:428`
- 根拠: `AstralRecord#onLoad()` で `MobService` と `NpcPlayerSkinPacketService` が生成されるが、ProtocolLib は通常その後の enable フェーズで有効になる。既存のコンストラクタは生成時に `isPluginEnabled("ProtocolLib")` を確認していた。
- 問題: `onLoad()` 時点で ProtocolLib が未有効だと `protocolManager` が `null` のまま固定され、NPC の `sync` とテストコマンドの仮想 Player 表示が早期 return する。
- 影響: 既存の NPC Player スキン表示と今回の `/test <player>` が、サーバー起動後も常に表示できない。
- 修正方針: ProtocolLib の参照と USE_ENTITY remapper の登録を、実際の packet 表示処理が呼ばれる時点へ遅延し、登録は一度だけ行う。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/mob/service/NpcPlayerSkinPacketService.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-002 [中] 一時 packet 表示がプラグイン停止時に残る可能性
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/mob/service/NpcPlayerSkinPacketService.java:111`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/mob/service/MobService.java:546`
- 根拠: `/test` の表示はクライアント向け packet のみで生成され、10秒後の削除を Bukkit scheduler に依存する。プラグイン停止・リロード時には scheduler task がキャンセルされるが、既存の `removeAll()` が保持するのは NPC 状態だけだった。
- 問題: 表示中にプラグインが停止すると、仮想 Player の destroy packet が送られず、接続中クライアントに一時表示が残る可能性がある。
- 影響: プラグインの再読み込みまで、クライアント上にスキン表示の残像が残る。
- 修正方針: 一時表示状態を短時間管理し、`removeAll()` で destroy packet を送信する。通常の期限切れ処理とは状態削除を原子的に行い、二重破棄を避ける。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/mob/service/NpcPlayerSkinPacketService.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
