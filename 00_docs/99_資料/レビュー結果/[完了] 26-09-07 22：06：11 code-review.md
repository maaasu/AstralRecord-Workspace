## 指摘一覧

### AR-CODE-001 [中] Proxy内配信を維持してDiscord中継だけ止める契約の直接テスト不足
- 種別: `テスト不足`
- 対象: `10_plugin/AstralRecordProxy/src/main/java/io/github/maaasu/astralrecordproxy/AstralRecordProxyPlugin.java:204`
- 関連箇所: `10_plugin/AstralRecordProxy/src/test/java/io/github/maaasu/astralrecordproxy/ProxyConfigTest.java:45`
- 根拠: `onPluginMessage` のMinecraftチャット処理は、Proxy内の全プレイヤーへのbroadcastとDiscord中継用APIへのpublishを同じ受信経路で実行する。現在の追加テストは除外backendの設定値と判定だけを確認し、受信処理でbroadcastを維持しながらpublishだけを抑止する動作を直接確認していない。
- 問題: 除外設定の条件を誤ってチャット全体の破棄へ変更しても、設定テストだけでは検出できない。また、通常backendでProxy内配信後にAPI登録する順序も回帰検知できない。
- 影響: dev backendのチャットがProxy内から消える、または通常backendのDiscord中継が停止する回帰を恒久テストで検出できない。
- 修正方針: 受信処理の配信分岐をテスト可能な小さな処理へ分離し、除外backendではProxy内配信のみ、通常backendではProxy内配信後にDiscord中継が実行されることを確認する。
- 修正対象候補: `10_plugin/AstralRecordProxy/src/main/java/io/github/maaasu/astralrecordproxy/AstralRecordProxyPlugin.java, 10_plugin/AstralRecordProxy/src/test/java/io/github/maaasu/astralrecordproxy/AstralRecordProxyPluginTest.java`
