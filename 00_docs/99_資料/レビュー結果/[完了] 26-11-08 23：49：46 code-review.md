### AR-CODE-001 [高] 単件更新で保存済み道標の ID と種類を変更できる
- 種別: `セキュリティ`
- 対象: `60_tool/skilltree-editor/src/SkillTreeEditor.Server/Endpoints/WorldPlacementEndpoints.cs:15`
- 関連箇所: `20_api/AstralRecordApi/AstralRecordApi/Repositories/WorldPlacementRepository.cs:29`
- 根拠: ワールド配置計画の「保存済み Dev 配置」は解放履歴と結び付く保存済み道標の ID を変更不可としている。ローカルプロキシの新規単件 PUT は本文を専用 Dev API へ転送する。転送先の単件更新は既存の配置配列の要素を直接置き換えるため、更新前後が同じ配列を参照した状態で道標 ID の維持を検査する。
- 問題: ローカルの単件 PUT へ現在のリビジョンと同じ配置 ID を含む本文を送ると、別の道標 ID を設定するか別種類へ置き換えられる。ブラウザー上の入力制御はこの経路に適用されない。
- 影響: 保存済みの解放履歴と道標の対応が壊れる。新設したローカル経路から、一覧の既存道標編集が許容する操作を超える変更が可能になる。
- 修正方針: 既存 Dev スナップショットと同じリビジョンであることを確認し、同じ配置 ID の既存道標だけを転送対象にする。種類、道標 ID、ワールド、監査メタデータの維持を確認し、同じ期待リビジョンで既存 API の原子的な更新を使う。拒否する入力と競合をテストする。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-002 [中] 地図の追加地点を選択中に一覧から保存すると追加条件が消える
- 種別: `バグ/アルゴリズム`
- 対象: `60_tool/skilltree-editor/src/SkillTreeEditor.Client/src/components/SpawnerPlanningWorkspace.tsx:351`
- 関連箇所: `60_tool/skilltree-editor/src/SkillTreeEditor.Client/src/components/SpawnerPlanningWorkspace.tsx:391`
- 根拠: 一覧の編集可否は配置の原稿と処理中フラグで判定している。地図の追加・移動地点の選択状態は別に管理している。一覧から保存すると、地図の配置エディタが再マウントされる。
- 問題: 配置編集で種類とマスターを選び「地図で追加」を開始した直後に一覧へ移り、道標を保存できる。地点選択フラグが残ったまま種類・マスター・追加先の選択が初期化される。
- 影響: 配置編集に戻ると地点選択中の案内が出るが、地図を押しても予定していた配置を追加できない。
- 修正方針: 地図側の追加または移動地点を選択中は、一覧からの設定編集と保存を停止する。開始済みの地図操作は、一覧を見て配置編集に戻ったときに続けられることをテストする。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-003 [中] 固定ヘッダーがキーボードで選択した行を隠す
- 種別: `バグ/アルゴリズム`
- 対象: `60_tool/skilltree-editor/src/SkillTreeEditor.Client/src/components/resizableTable.css:19`
- 関連箇所: `60_tool/skilltree-editor/src/SkillTreeEditor.Client/src/components/ResizableTable.tsx:81`
- 根拠: 共通テーブルはスクロール領域内で見出しを固定する。Chrome の確認で、スクロール後に Shift+Tab で前行のボタンへ移動すると、固定見出しの Y 座標 1〜38.5 px がボタンの Y 座標 1.19〜35.98 px 全体に重なった。
- 問題: フォーカスの移動先が見出しの裏に隠れ、画面上から操作対象やフォーカスの位置を確認できない。
- 影響: キーボード操作で表の行を行き来するとき、どの配置や項目を操作するか視認できない場合がある。
- 修正方針: 表のフォーカス先と固定見出しが重ならないようにスクロールを調整するか、スクロール領域内の行を覆わない見出しにする。Chrome で下の行から Shift+Tab した直後に前行を視認できることを確認する。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
