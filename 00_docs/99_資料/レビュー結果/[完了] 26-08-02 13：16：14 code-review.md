### AR-CODE-001 [高] 未許可の action ring バインドが理由別通知へ到達しない
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/service/SkillActionRingService.java:448`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/service/SkillActionRingService.java:325`
- 根拠: `00_docs/10_Plugin設計書/feature/13-skill/3-メソッド仕様/13_3-イベント.md` の `## 3. action ring入力解決` は、使用許可を失った個体で `P_5863` を通知する契約である。
- 問題: 所持済みでも許可なしの枠を `UNAVAILABLE` として選択不可にすると、`SkillService` の使用許可検証と `P_5863` 通知へ到達しない。
- 影響: action ring の操作だけが左クリックバインドと異なり、プレイヤーは発動拒否の理由を確認できない。
- 修正方針: 表示上の使用不可状態を維持したまま、所持済み・定義済みの `UNAVAILABLE` 枠は選択可能にして発動時判定を `SkillService` へ委譲する。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/service/SkillActionRingService.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-002 [高] 素材消費後の前詰めが非同期インベントリ変更を上書きし得る
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/inventory/service/InventoryService.java:228`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/service/LearnedSkillService.java:181`
- 根拠: `00_docs/10_Plugin設計書/feature/13-skill/3-メソッド仕様/13_3-イベント.md` の `## 1. スキルマネージャー表示・操作` は、素材消費後も無関係 entry を保持して通常収納の前詰めを行う契約である。
- 問題: authoritative entry の反映と snapshot を用いる前詰めを別の同期区間で実行すると、その間のメインスレッド操作を古い snapshot の `replaceEntries` で失う可能性がある。
- 影響: 合成中に発生した無関係なアイテム追加または移動が消失するおそれがある。
- 修正方針: API取得後に state monitor を保持し、単一entry再同期と前詰めを同じ排他区間で完了させる。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/inventory/service/InventoryService.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
