### AR-CODE-001 [中] 混在状態の shortcut cleanup が不完全
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/menu/view/CraftShortcutView.java:113`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/menu/event/MenuOpenEventHandler.java:1036`
- 根拠: クラフト行列に通常アイテムが1つでもあると shortcut cleanup が即時に `false` を返し、結果枠の確認まで到達しない。さらに shortcut 行列と通常の結果アイテムが同時にある場合、行列を空にした後に結果枠も無条件で AIR へ置換する実装になっている。
- 問題: 通常アイテムを保持するための条件分岐が、残存 shortcut の除去漏れと通常の結果アイテムの消去を同時に引き起こす。
- 影響: BE の join / world-change / shortcut render cleanup で残存 shortcut が残り、必要な同期も実行されない。また通常のクラフト結果を失う可能性がある。
- 修正方針: クラフト行列と結果枠を独立して走査し、shortcut と判定できる要素だけを AIR に置換する。通常の入力・結果は保持し、1要素以上を変更した場合だけ変更済みを返す。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/menu/view/CraftShortcutView.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-002 [中] BE再描画で所持品・カーソルの shortcut cleanup が不足
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/menu/view/MenuView.java:407`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/menu/event/MenuOpenEventHandler.java:1006`
- 根拠: BE の再描画分岐は `clearCraftShortcuts(player)` だけを呼び、プレイヤーインベントリとカーソルを走査する `removeCraftShortcutItems(player)` を呼んでいない。設計書の cleanup 対象はクラフト枠・所持品・カーソルである。
- 問題: クラフト枠が空でも所持品またはカーソルに残存 shortcut があると、BE 再描画経路では残存したままになる。
- 影響: BE プレイヤーに Java版由来などの shortcut が所持品・カーソルへ残っている場合、操作制限と表示状態が不整合になり、残存 dummy が除去されない。
- 修正方針: BE 再描画でもクラフト枠と所持品・カーソルの cleanup 結果を集約し、1要素以上を変更した場合だけ `updateInventory()` を1回実行する。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-003 [低] 変更した MenuView 公開メソッドに JavaDoc がない

- 修正方針: 3つの公開メソッドに、shortcut除去の対象・通常アイテム保持・戻り値・同期を行わない契約を JavaDoc で明記する。
