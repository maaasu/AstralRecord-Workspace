### AR-CODE-001 [中] 交差ルーンの粒子が命中範囲の幅を示さない
- 種別: `仕様不整合`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/boss/service/BossMechanicService.java:644`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/boss/service/BossMechanicService.java:345 / 00_docs/10_Plugin設計書/feature/26-boss/3-メソッド仕様/26_3-サービス.md:252`
- 根拠: `damageCross` は半幅 `1.0D` の帯を命中範囲にする一方、`renderCross` は各腕の中心線だけを `appendLine` している。使用する `BOSS_MECHANIC_SPARK` は count 1、各軸の拡散 0.02D であり、中心線から離れた命中範囲の境界を視覚化しない。設計書は発動瞬間にも同じ実効範囲を再表示すると定めている。
- 問題: 交差ルーンの線分から横方向へ最大1.0ブロック離れて被弾するPlayerの足元・境界には、予兆時も発動時もパーティクルが出ない。
- 影響: 実際の攻撃範囲をパーティクルで分かりやすくする要求に対し、Playerが見た中心線より広い範囲で被弾する。
- 修正方針: `renderCross` に交差ルーンと同じ半幅を渡し、各壁制限済み線分について中心線と両端線、または帯を表せる同等の地点を同じバッチへ追加する。命中判定の `1.0D` と表示幅を共通化し、粒子地点を検証するテストを追加する。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-002 [中] 追加テストが壁衝突の実処理を検証していない
- 種別: `テスト不足`
- 対象: `10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/boss/service/BossMechanicServiceTest.java:84`

- 根拠: `runeLanesStopAtBlockingWallWithinSafeMaximumRange` は `cappedCrossArmLength` の数値丸めだけを確認し、壁を探索する `World#rayTraceBlocks`、ヒット位置からの距離計算、壁なし時の32ブロック復帰を行う `wallLimitedLength` を通らない。
- 問題: レイトレースの削除、誤った最大距離・衝突モード・方向の指定、または常に32を返す退行があっても、今回追加されたテストは成功する。
- 影響: 「壁に当たるまで延長し、32ブロックで上限」の主要契約を自動検証できず、予兆・発動時表示・命中判定で使う壁制限長の回帰を検出できない。
- 修正方針: `World` と `RayTraceResult` をモックし、壁ヒット時の距離、壁なし時の32ブロック、32超要求時の上限、および `rayTraceBlocks` に渡す最大距離・`FluidCollisionMode.NEVER`・passable block 無視を `wallLimitedLength` で検証する。
- 修正対象候補: `10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/boss/service/BossMechanicServiceTest.java`
