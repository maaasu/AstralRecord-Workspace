## 指摘一覧

### AR-CODE-001 [高] 一覧の Mob 名に最低レベルの接尾辞が残る
- 種別: `仕様不整合`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/adventurerecord/gui/AdventureRecordGui.java:537`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/mob/repository/MobRepository.java:164`
- 根拠: `MobRepository` は共通定義へ最初のレベルプロファイルを適用した `MobTemplate` を返す。`AdventureRecordGui` はその `displayName` を一覧 item 名へそのまま使う。`40_filebase/40.features.mob/enemy/v1.midgard_savanna_witch.yml` の最低プロファイル名は `サバナウィッチ Lv.7` である。
- 問題: 一覧 lore のレベル行を削除しても、一覧 item の名前に最低レベルの `Lv.7` が残るため、同一 Mob を共通名だけで1件表示する要件を満たさない。
- 影響: レベルプロファイル名にレベルを含む Mob は、冒険記録一覧で依然としてレベル表記付きで表示される。
- 修正方針: 共通定義の名前を一覧用に保持・解決し、一覧 item の表示名に使う。レベル選択後の詳細画面は選択プロファイルの名前を使う。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/adventurerecord/gui/AdventureRecordGui.java`
- 修正可否: `要確認`
