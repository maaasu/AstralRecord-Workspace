### AR-CODE-001 [中] 詠唱中をアクションリングの発動可否・色判定に反映していない
- 種別: `仕様不整合`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/service/SkillService.java:316`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/service/SkillActionRingService.java:428`
- 根拠: 設計書 `00_docs/10_Plugin設計書/feature/13-skill/3-メソッド仕様/13_3-サービス.md` は `canCast` が進行中 cast を検証すると定める。リングは `canCast` の結果で状態と色を決める一方、現実に詠唱中を拒否する処理は `SkillService.beginCast` の `P_5810` 判定だけに存在する。
- 問題: プレイヤーが詠唱中の場合、リングは当該スキルを `AVAILABLE`（緑）として表示し得るが、選択後の実発動は `P_5810` で拒否される。表示が「実際の発動可否」を表していない。
- 影響: 要件のスキル発動状態による文字色切替が、詠唱中の状態で適用されず、プレイヤーに誤った発動可否を示す。
- 修正方針: `canCast` がプレイヤーの進行中 cast を `P_5810` として返すよう共通化し、リングの `SlotAvailability` をその結果へ対応付ける。通常の発動経路との二重判定を同じ契約にそろえる。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/service/SkillService.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
