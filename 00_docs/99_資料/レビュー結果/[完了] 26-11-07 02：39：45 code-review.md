### AR-CODE-001 [高] Geyser の書式リセットでリング画像番号がずれる
- 種別: `バグ/アルゴリズム`
- 対象: `50_resourcepack/scripts/action-ring-hud-bedrock.ps1`
- 関連箇所: `50_resourcepack/bedrock/ui/hud_screen.json`
- 根拠: Geyser の JavaSetActionBarTextTranslator は MessageTranslator.convertMessage で ActionBar 文字列の先頭に書式リセットを付ける。
- 問題: 画像番号の位置を arw2 が先頭にある前提で計算すると、書式リセットの2文字ぶん読み取りがずれる。
- 影響: 配布パック内に画像があっても、固定 HUD から対応するスキルアイコンを表示できない。
- 修正方針: 画像番号を切り出す前に書式リセットを除き、リセットの有無を両方検証する。
- 修正対象候補: `50_resourcepack/scripts/action-ring-hud-bedrock.ps1`
- 修正可否: `自動修正可`
