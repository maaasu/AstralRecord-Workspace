### AR-CODE-001 [中] 旧形式のワールド指定で地図から受付地点を選べない
- 種別: `仕様不整合`
- 対象: `60_tool/skilltree-editor/src/SkillTreeEditor.Client/src/components/ChallengeLocationEditor.tsx:135`
- 関連箇所: `60_tool/skilltree-editor/src/SkillTreeEditor.Server/Services/MasterDataService.cs:88`
- 根拠: 一意の Bukkit ワールド名と設定済みの worldRef 接頭辞を受付一覧 API は解決するが、フォームは標準の文字列との一致だけで地図との対応を判定する。
- 問題: API が現在の地図に含めた受付をアイコンから開いても、別ワールドの受付として扱う。
- 影響: 対応する地図が表示されていても、旧形式の受付地点を地図上で設定できない。
- 修正方針: 対象マスターの保存済み参照文字列が現在の地図の受付一覧と一致する場合を同じ地図と見なす。編集中にワールドを変更した場合には適用しない。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
