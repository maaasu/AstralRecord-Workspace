### AR-CODE-001 [中] tick 間隔パラメータが整数・有限値として検証されず切り捨てられる
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/executor/MeditationSkillExecutor.java:107`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/service/MeditationSkillRuntimeService.java:188`
- 根拠: メディテーションの設計書は `activeSoundIntervalTicks` を tick 単位の間隔として定義している。既存の共通 `SkillParamReader.getInt` は有限値・整数性・int 範囲を検証してから返す契約を持つ。
- 問題: `requirePositiveInt` は `Number.intValue()` が0以下かどうかだけを確認するため、`40.5` のような小数を受け入れて 40 tick に切り捨てる。また `MeditationSkillRuntimeService.readPositiveInt` も同じ変換を行うため、検証を経ない経路でも値の意味が変わる。固定値検証の `requireFixedInt` も `100.5` を 100 とみなして受け入れる。
- 影響: 不正な master/API params が有効定義として通過し、設計上の tick 間隔・準備時間と実際の状態遷移／音再生頻度が一致しない。特に interval の設定を変更したとき、指定値と実効値が異なることを検出できない。
- 修正方針: interval と固定 tick 値の検証・読取を、有限値かつ整数であることを確認する共通処理（`SkillParamReader.getInt` 相当）へ統一し、範囲外や小数を拒否する。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/executor/MeditationSkillExecutor.java / 10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/service/MeditationSkillRuntimeService.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `未修正`

### AR-CODE-002 [低] 追加テストが activeSoundIntervalTicks の設定読取を検証していない
- 種別: `テスト不足`
- 対象: `10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/skill/service/MeditationSkillRuntimeServiceTest.java:83`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/service/MeditationSkillRuntimeService.java:66`
- 根拠: 設計書は環境音が `activeSoundIntervalTicks` に従うことを契約し、YAML の現行値を 40 tick としている。
- 問題: テストは 40 を params に設定し、100 tick 発動後の 140 tick で音が鳴ることだけを確認している。これは実装が設定キーを読まず既定値／ハードコードの 40 を使っていても通過するため、「configured interval」を検証できていない。`validateParams` についても新しい interval の欠落・0・小数値を拒否するケースがない。
- 影響: `activeSoundIntervalTicks` のキー名を誤る、設定値を無視する、境界値検証を壊す回帰を恒久テストで検出できない。
- 修正方針: テストでは YAML 現行値とは異なる正の整数（例: 20 tick）を設定して発動後 120 tickでの再生を検証し、executor の interval 検証に未定義・0・小数・正常値のケースを追加する。
- 修正対象候補: `10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/skill/service/MeditationSkillRuntimeServiceTest.java`
