## 指摘一覧

### AR-CODE-001 [中] スキルツリーの横幅操作で指定幅と実幅がずれる
- 種別: `バグ/アルゴリズム`
- 対象: `60_tool/skilltree-editor/src/SkillTreeEditor.Client/src/components/WorkspaceLayout.tsx:46`
- 関連箇所: `60_tool/skilltree-editor/src/SkillTreeEditor.Client/src/styles.css:69`
- 根拠: 左境界の上限は右ペインの最小幅290pxだけを予約し、右境界も左ペインの最小幅210pxだけを予約する。一方で左右ペインは `flex: 0 1 auto` で縮小でき、各 `flexBasis` には保存した希望幅を使う。幅1000pxで3ペインを表示すると、左境界の上限は416pxになるが、右の既定370pxと中央の最小280px、境界2本14pxを加えると1080pxとなり80px超過する。
- 問題: 境界を終端までドラッグまたはEndキーで動かすと、ブラウザーが左右ペインを自動縮小するため、操作した側の実幅が指定値に届かず、反対側の幅まで変わる。保存値とセパレーターの `aria-valuenow` も実幅と一致しなくなる。
- 影響: 980pxを超える比較的狭い画面で3ペインを使う際、希望した幅への調整ができず、再表示やウィンドウ幅変更後も境界の値と見た目がずれる。片側を広げる操作で他方のインスペクターや一覧が意図せず狭くなる。
- 修正方針: 境界の上限に反対側の現在の希望幅または実幅を含め、中央の最小幅を確保する。左右ペインの縮小と保存値の扱いを揃え、狭い状態から広い状態へ戻したときの希望幅復元を確認する。
- 修正対象候補: `60_tool/skilltree-editor/src/SkillTreeEditor.Client/src/components/WorkspaceLayout.tsx`
- 修正可否: `自動修正可`
