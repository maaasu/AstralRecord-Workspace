### AR-CODE-001 [中] TEMPワールドへ通常ワールド向け副作用が適用される
- 種別: `仕様不整合`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/world/service/WorldService.java:837`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/world/event/WorldNaturalSpawnBlockEventHandler.java:50`
- 根拠: `loadBukkitWorld` の既存・新規ワールド経路で `applyRpgGameRules` を呼び、`WorldNaturalSpawnBlockEventHandler` も `findByBukkitWorld` で解決できる全ワールドを管理対象として gamerule 適用と非 AstralRecord Mob の削除を行っている。
- 問題: マスターデータ外の TEMP ワールドも通常の RPG 管理ワールドとして扱われる。
- 影響: TEMP ワールドをロードしただけで gamerule が永続変更され、既存 Mob が削除される。ロードと管理者転送だけという要件を超える。
- 修正方針: `WorldType.TEMP` は `loadBukkitWorld` の RPG gamerule 適用と `WorldNaturalSpawnBlockEventHandler` の管理対象から除外する。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-002 [中] TEMPワールドの転送先が固定座標になる
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/world/service/WorldService.java:493`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/world/service/WorldService.java:977`
- 根拠: TEMP の合成定義は `(0.5, 64.0, 0.5, 0, 0)` を持ち、`resolveSpawnLocation` と `resolveOrLoadSpawnLocation` は常に `WorldMasterData.spawnLocation` を Location 化している。
- 問題: 実際の TEMP ワールドに保存された Bukkit spawn 地点を参照しない。
- 影響: spawn が別座標、空中、地下などに設定された TEMP ワールドへ `/world tp` または管理者 GUI から転送すると、不正または危険な地点へ移動する。
- 修正方針: TEMP はロード済み Bukkit world の `getSpawnLocation()` を返し、通常ワールドだけ master の spawn 座標を使う。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/world/service/WorldService.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-003 [中] master IDと同名のTEMPワールドが無言で除外される
- 種別: `仕様不整合`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/world/service/WorldService.java:123`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/world/service/WorldService.java:973`
- 根拠: `loadDefinitionSnapshot` は API/filebase の ID 集合に含まれるフォルダ名の TEMP 定義を追加しない。master ID と `_temp` 直下フォルダ名の衝突を禁止する契約は確認できない。
- 問題: `_temp/<worldName>` の名前が master ID と同じ場合、TEMP 定義が snapshot へ追加されない。
- 影響: 対象ワールドはロード、補完、GUI、`/world tp` の全経路から除外され、マスターデータ不要でロードする要件を満たさない。
- 修正方針: TEMP の内部 ID を通常 master ID と分離して一意化し、表示とコマンド入力は `[temp]<worldName>` として保持する。同名でも TEMP 定義を snapshot へ追加する。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/world/service/WorldService.java`
- 修正可否: `自動修正可`
- 確信度: `中`
- 修正状態: `修正済み`
