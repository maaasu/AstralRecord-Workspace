### AR-CODE-001 [低] 閉じた確認画面を購入完了時に再表示しない
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/shop/event/ShopGuiEventHandler.java:246`
- 関連箇所: `複数`
- 根拠: `購入開始時の top inventory を時計表示へ更新する一方、完了 callback は player.isOnline() だけを確認して shopGui.openConfirm(...) を実行します。Shop には InventoryCloseEvent 処理も現在の top inventory／開始時 inventory の照合もないため、プレイヤーが Esc で閉じる、または別 GUI へ遷移しても callback が旧 confirm GUI を強制的に開き直します。Trade GUI は refreshIfOpen で viewer、session、現在の holder を照合してから再描画しています。`
- 問題: `非同期保存の待機中に確認画面を閉じたプレイヤーの現在画面を、成功・失敗のどちらでも旧商品の確認画面で上書きします。`
- 影響: `購入結果と無関係な画面遷移が取り消され、完了時に開いていた別 GUI やプレイヤーインベントリが意図せず閉じられます。`
- 修正方針: `購入開始時の confirm inventory（必要なら操作トークン）を保持し、main thread callback では現在の top inventory が同じ ConfirmHolder／対象 inventory の場合にだけ confirm GUI を再描画する。画面が既に閉じられたか遷移済みでも in-flight ロックの解除と購入結果のデータ反映は必ず行う。`
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/shop/event/ShopGuiEventHandler.java`
