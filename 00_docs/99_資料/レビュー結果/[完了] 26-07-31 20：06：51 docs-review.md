### AR-DOC-003 [中] Lv.1 最終目標と既存基礎値・配分方針が両立しない
- 種別: `矛盾`
- 対象: `00_docs/60_戦闘バランス設計書/02-成長曲線.md:26`
- 関連箇所: `00_docs/60_戦闘バランス設計書/02-成長曲線.md:50`
- 根拠: `07_3-サービス.md` のプレイヤー基礎値と `07_1-モデル定義.md` の派生係数を合算すると、class・equipment 適用前でも最大 HP は `20 + VITALITY 5 × 2 = 30`、最大 MP は `10 + INTELLIGENCE 5 = 15`、最大 EN は100、近接・間接の `D` は `DEFENSE 5 + VITALITY 5 = 10` となり、Lv.1 表の最終目標へ既に到達する。魔法の `D` はさらに `MAGIC_DEFENSE 3 + VITALITY 5 = 8` を加えて18となり、目標10を超える。
- 問題: 本書は Lv.1 値を class・標準 equipment・恒常補正を含む最終目標とし、基礎値と class 成長で70～80%、equipment で20～30%を配分すると定めるが、既存の共通基礎値だけで複数項目が100%以上となる。
- 影響: class や標準 equipment に正の補正を配ると Lv.1 アンカーを超え、特に魔法防御では負補正を入れない限り攻撃種別ごとの `D = 10` を満たせないため、同一の基準から整合したマスタを作成できない。
- 修正方針: 共通基礎値の寄与を明示したうえで Lv.1 アンカーと70～80%／20～30%の配分を再設定し、必要なら攻撃種別ごとの `D` を分けて定める。
- 修正対象候補: `00_docs/60_戦闘バランス設計書/02-成長曲線.md`
- 修正可否: `設計判断待ち`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-DOC-004 [中] TTK と耐久時間を時間として再現できない
- 種別: `不足`
- 対象: `00_docs/60_戦闘バランス設計書/02-成長曲線.md:66`
- 関連箇所: `00_docs/60_戦闘バランス設計書/README.md:37`
- 根拠: README は TTK と耐久時間を秒数相当の時間として評価し、各アンカーで想定 DPS と目標時間を決めるよう要求する。`01-戦闘計算.md` では実際の攻撃間隔が基本攻撃間隔と `ATTACK_SPEED` から決まるが、本書の基準は成功命中回数だけで、プレイヤー通常攻撃と Mob 攻撃の基本間隔または目標時間を定めていない。
- 問題: 同じ6回の命中でも攻撃間隔によって TTK と耐久時間は変わるため、現在の基準手数から README が正本とする時間ベースの指標を導けない。
- 影響: class・武器・Mob ごとに異なる行動間隔を採用しても基準達成と判定でき、想定 DPS、TTK、耐久時間を一貫して比較・検証できない。
- 修正方針: 標準プレイヤーと標準 Mob の基準攻撃間隔、またはアンカーごとの目標 TTK・耐久時間を定め、命中・会心を含む期待値で確認するか成功命中回数を使うかも明記する。
- 修正対象候補: `00_docs/60_戦闘バランス設計書/02-成長曲線.md`
