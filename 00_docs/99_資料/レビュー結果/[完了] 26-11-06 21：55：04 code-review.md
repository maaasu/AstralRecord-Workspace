### AR-CODE-001 [中] Windows PowerShell でパックの生成が止まる
- 種別: `バグ/アルゴリズム`
- 対象: `50_resourcepack/scripts/build-resourcepack.ps1:162`
- 関連箇所: `50_resourcepack/README.md`

- 問題: GUI 用のチェスト定義を読み直すと NamedParameterNotFound が発生する。
- 影響: README の直接実行手順では両版の配布パックを作れない。
- 修正方針: 既存ビルドと同じ ConvertFrom-Json の戻り値を使い、Windows PowerShell 5.1 で生成する。
- 修正対象候補: `50_resourcepack/scripts/build-resourcepack.ps1`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-002 [中] 統合版の表示失敗が施設全体に波及する
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/mob/service/MobEntityController.java:368`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/mob/service/MobAiService.java:232`
- 根拠: Paper は表示実体の生成イベントが拒否された場合に spawnAt から false を返す。Mob の追跡では操作実体と表示実体の寿命が分かれる。
- 問題: 統合版モデル用の空表示だけが拒否されると施設の生成が失敗する。後から空表示だけが消えた場合には復元処理がない。
- 影響: 操作実体の生成や、対応パック適用時の施設の視認性が損なわれる。
- 修正方針: 初回の失敗時は操作実体と従来表示を使う。統合版モデルが単独で消えた場合は再生成し、失敗時は従来表示を送り直す。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
