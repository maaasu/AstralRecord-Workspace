## 指摘一覧

### AR-CODE-001 [低] 名前がない候補の非一致検索でIDを余分に解析する
- 種別: `パフォーマンス`
- 対象: `60_tool/skilltree-editor/src/SkillTreeEditor.Client/src/data/masterCandidateSearch.ts:19`
- 関連箇所: `60_tool/skilltree-editor/src/SkillTreeEditor.Server/Services/MasterDataService.cs:264`
- 根拠: `MasterDataService.DisplayName` は表示名のないマスターに `null` を返し、候補の `label` は任意である。非空検索時にIDが一致しない候補は `label(entry).search` へ進むが、`label` 欠損でも `stripMinecraftFormatting(entry.value)` を実行する。旧実装は同じ場合に空文字を渡していた。
- 問題: 表示名のない候補のIDだけを検索したい場合に、検索へ使わないIDをMinecraft文字列として解析する。
- 影響: 多数の名前なし候補を含む一覧で、初回の非一致検索ほど余分な文字列走査とキャッシュ用文字列の生成が増える。今回の候補検索の軽量化効果が下がる。
- 修正方針: `entry.label == null` なら検索用ラベルを空文字とし、表示用IDが必要な候補にだけ装飾除去を適用する。
