- 根拠: `PrepareAnvilEvent#setResult(null)` は結果スロットだけを空にし、`AnvilView` の repair cost は変更しません。変更前の同ハンドラは `AnvilView#setRepairCost(0)` と `setMaximumRepairCost(1)` を実行していましたが、この差分で削除されています。
- 問題: 入力紙の表示名を変更すると金床の通常計算で repair cost が設定されたままになり、結果スロットを空にしてもクライアントの経験値コスト表示が残ります。
- 影響: 「消費経験値などの表示をなくす」という修正目的を満たさず、プレイヤーへ経験値を消費する操作であるかのような表示を継続します。
- 修正方針: 結果を `null` にする処理と併せて `AnvilView` を取得し、repair cost を 0 に設定する。最大コストも既存実装と同じ値へ設定するか、0 コスト時に不要なことを確認する。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/party/event/PartyRecruitmentGuiEventHandler.java`
