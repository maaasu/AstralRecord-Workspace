### AR-DOC-001 [中] 増加分の配分基準が定義されていない
- 種別: `不足`
- 対象: `00_docs/60_戦闘バランス設計書/02-成長曲線.md:63`
- 関連箇所: `00_docs/60_戦闘バランス設計書/README.md`
- 根拠: README は class の基礎値・レベル成長、equipment の更新、skill の解放を合算してアンカーを満たす方針を示し、本書も Lv.1 からの増加分を class、equipment、skill tree へ分配するとしている。
- 問題: 3者へどの程度を割り当てるか、または何を優先して残差を割り当てるかの目安がなく、同じアンカーから大きく異なるマスタ予算を導ける。特に「共通基礎値と能力値派生を先に計上する」と「Lv.1からの増加分を3者へ分配する」の関係も明示されていない。
- 影響: class、装備、skill tree の各担当が独立に値を決めると、標準構成がアンカーを超過または未達になり、将来装備用の余地も一貫して確保できない。
- 修正方針: Lv.1 から各アンカーまでの増加分について、class・レベル成長、equipment、skill tree の標準的な配分比率または優先順位を1つ定め、共通基礎値・能力値派生をどの枠へ数えるかを短く明記する。
- 修正対象候補: `00_docs/60_戦闘バランス設計書/02-成長曲線.md`
- 修正可否: `設計判断待ち`
- 確信度: `高`
- 修正状態: `修正済み`

- 関連箇所: `00_docs/60_戦闘バランス設計書/02-成長曲線.md:46`

- 問題: 130%上限の対象 status が明記されておらず、`ACCURACY`、`CRITICAL_RATE`、`ATTACK_SPEED`、`FINAL_DAMAGE_MULTIPLIER` などの割合・速度系にも同じ余裕を設ける解釈が成立する。

- 修正方針: 130%上限は HP・`R`・`D` など基礎実数系だけに適用し、3.2 の割合系 status と MP / EN は対象外であることを明記する。
