### AR-CODE-001 [中] drop presentation 未接続時の部分報酬
- 種別: `仕様不整合`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/gathering/service/GatheringService.java:396`
- 関連箇所: `00_docs/10_Plugin設計書/feature/12-mob/12_4-統合フロー.md:247`
- 根拠: 採集報酬は recipient と drop presentation が揃った完了経路で処理する設計であり、Mob の item / exp / money の報酬経路も presentation と一体である。
- 問題: Round 1 時点の実装は drop presentation が null でも経験値反映と耐久値消費を先に実行し、item / money の付与と quest 通知だけを省略していた。
- 影響: 報酬表示・付与基盤が未接続または異常な場合、プレイヤーが item / money を受け取れないまま経験値とツール耐久値だけを失う。
- 修正方針: recipient と drop presentation が解決できた場合だけ、drop 抽選、経験値反映、耐久値消費、表示・付与、quest 通知を一連の完了処理として実行する。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/gathering/service/GatheringService.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
