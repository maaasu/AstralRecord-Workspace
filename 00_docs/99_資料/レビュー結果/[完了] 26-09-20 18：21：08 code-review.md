### AR-CODE-001 [高] Sharpshooter 表示時に祖先職・冒険者 edge と交差する
- 種別: `仕様不整合`
- 対象: `40_filebase/35.features.skilltree/structures/starter.json`
- 関連箇所: `00_docs/50_Filebase設計書/feature/35-skilltree.md:136`
- 根拠: 同設計書は、シャープシューター表示時に同時表示される共通領域・冒険者・ハンター・シャープシューターの edge と交差・重複を作らないことを必須としている。構造 JSON の x-z 平面を端点共有以外の線分交差で検査すると、シャープシューター edge と冒険者/ハンター edge の交差が17件ある。例として `2154-2155 × 1090-1091`、`2164-2165 × 1247-1248`、`2177-2178 × 1273-1355`、`2212-2213 × 1268-1271`、`2238-2239 × 1258-1259` を確認した。
- 問題: `unlockCondition.classId: sharpshooter` はハンターおよび冒険者を祖先として表示対象に含むため、これらの交差は実際のシャープシューター表示で残る。異職業専用 edge との交差のみを許容する標準円弧配置の例外条件に該当しない。
- 影響: プレイヤーに表示される進行経路が他の edge と交差し、設計書が要求する読みやすい開いた円弧と交差禁止契約を満たさない。
- 修正方針: 4主円弧の node 座標または同職業内部 edge を調整し、祖先職・冒険者・共通・シャープシューター edge との全交差を解消する。調整後、対象職業の可視 edge を使った交差検査を再実行する。
- 修正対象候補: `40_filebase/35.features.skilltree/structures/starter.json`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
