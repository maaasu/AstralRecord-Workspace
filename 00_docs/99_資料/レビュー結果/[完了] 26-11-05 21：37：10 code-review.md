### AR-CODE-001 [中] 検索候補が一致結果の操作を覆う
- 種別: `バグ/アルゴリズム`
- 対象: `30_web/AstralRecordWeb/AstralRecordWeb/wwwroot/css/skilltree.css:95`
- 関連箇所: `30_web/AstralRecordWeb/AstralRecordWeb/wwwroot/js/skilltree-viewer.js:410`
- 根拠: 画面仕様の検索は一致件数の表示、前後の一致ノードへの移動と強調解除を備える。Chromium の通常表示 1280×900 で、3件が一致する検索語を入力した後に Tab で「次へ」に移動すると、フォーカスは「次へ」にあったが中央座標のヒット判定は検索候補だった。
- 問題: 検索候補を絶対配置し、直下に追加した検索操作の上に重ねている。フォームから Tab で離れた後も候補が残る。
- 影響: マウスとタッチでは候補がクリックやタップを受け取り、キーボードではフォーカスした操作を画面上で確認できない。
- 修正方針: 通常表示でも検索候補をレイアウトの流れに含め、候補と前後移動・強調解除を同時に操作できるようにする。最大表示の候補表示と既存の Escape 操作を維持する。
