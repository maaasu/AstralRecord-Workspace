### AR-CODE-001 [中] 非同期レベルアップ完了後のセッション状態確認が不足
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/event/SkillBindGuiEventHandler.java:973`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/event/SkillBindGuiEventHandler.java:989`
- 根拠: レベルアップは非同期 callback で完了処理と GUI 再表示を行う。初回実装では callback 内に現在アカウントの確認はあったが、開始時の `SkillBindSession` がまだ現行セッションかを確認していなかった。
- 問題: プレイヤーが GUI を閉じる、または別セッションへ遷移した後に古いレベルアップが完了すると、古い処理の callback がスキルマネージャー GUI を再表示する可能性がある。
- 影響: 画面遷移後に意図しない GUI が開き、別セッションの表示・操作状態を上書きする可能性がある。
- 修正方針: 成功・失敗 callback の先頭で `sessions.get(playerId) == session` を確認し、開始時セッションでなければ表示更新を行わず終了する。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/event/SkillBindGuiEventHandler.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-002 [中] レベルアップ処理中の詳細画面表示が操作可能に見える
- 種別: `仕様不整合`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/gui/SkillBindGui.java:264`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/event/SkillBindGuiEventHandler.java:432`
- 根拠: `LearnedSkillService.hasMutationInProgress` により更新処理中の重複操作を拒否できる一方、初回実装の詳細画面は通常時と同じバインド・レベルアップ項目を表示していた。
- 問題: 更新中でもユーザーにはバインド・レベルアップ操作が可能に見え、クリックして初めて拒否音になるため、処理状態と表示が一致しない。
- 影響: 統合版を含む環境で連続クリックや再操作を誘発し、詳細画面の操作可否が分かりにくい。
- 修正方針: 更新処理中はバインド・レベルアップ項目を `処理中...` 表示へ置き換え、入力側でも重複操作を拒否する。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
