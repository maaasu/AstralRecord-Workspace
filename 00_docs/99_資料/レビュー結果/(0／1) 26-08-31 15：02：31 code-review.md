- 関連箇所: `20_api/AstralRecordApi/AstralRecordApi/Repositories/EquipmentOrbOperationRepository.cs:180`
- 根拠: `debug_sword` は状態変化の rank 1 で `maxLevel: 7`、rank 2 で `maxLevel: 9` を定義していますが、`enhance.levels` の定義はレベル 1～5 までです。API は現在値の次のレベルを `levels` から完全一致で取得し、定義がない場合または上限を超える場合は `NOT_ELIGIBLE` を返します。今回の差分は `successRate` の変更のみで、状態変化の上限やレベル定義は変更していません。
- 問題: rank 1 の +6/+7、および rank 2 の +8/+9 は、状態変化後の上限値までの `enhance.levels` が存在しないため強化できません。
- 影響: `debug_sword` の状態変化で表示上の強化上限と実際に強化可能なレベルが一致しません。
- 修正方針: `debug_sword` のレベル 6～9について状態変化後の個別成功率・ステータス上昇値を設計して `enhance.levels` に追加するか、状態変化による `maxLevel` 拡張を削除します。
