### AR-DOC-001 [高] プレイヤー被ダメージ反映経路が確定仕様と未決事項で衝突している
- 種別: `矛盾` / `未確定事項`
- 対象: `00_docs/10_プラグイン設計書/feature/12-mob/2-ユースケース/12_2.00-ユースケース.md:124`
- 関連箇所: `00_docs/10_プラグイン設計書/feature/12-mob/3-メソッド仕様/12_3.03-戦闘.md:55` / `00_docs/10_プラグイン設計書/feature/12-mob/9-未決事項/12_9.00-未決事項.md:44`
- 根拠: ユースケースと戦闘メソッド仕様では「プレイヤー側 feature の API 経由」で HP を減算すると確定仕様として書かれている一方、未決事項では `Player.damage` か `feature/player` 独自 API かが未確定とされている。
- 問題: 実装者がプレイヤー被ダメージ経路を確定仕様として実装すべきか、未決事項として保留すべきか判断できない。
- 影響: Mob からプレイヤーへの攻撃処理で、バニラ HP と独自 HP のどちらを正本にするかが分岐し、死亡判定・HUD・保存タイミングの設計が破綻する可能性がある。
- 修正方針: 被ダメージ反映経路を設計判断で確定し、確定するなら未決事項を閉じる。未確定のままならユースケースとメソッド仕様の「API 経由」断定を「未決事項参照」に戻す。
- 修正対象候補: `12_2.00-ユースケース.md` / `12_3.03-戦闘.md` / `12_9.00-未決事項.md`
- 修正可否: `設計判断待ち`
- 修正状態: `未修正`

### AR-DOC-002 [高] 致死処理のキラー決定とドロップ配布対象が文書間で一致していない
- 種別: `矛盾`
- 対象: `00_docs/10_プラグイン設計書/feature/12-mob/3-メソッド仕様/12_3.03-戦闘.md:167`
- 関連箇所: `00_docs/10_プラグイン設計書/feature/12-mob/2-ユースケース/12_2.00-ユースケース.md:172` / `00_docs/10_プラグイン設計書/feature/12-mob/3-メソッド仕様/12_3.03-戦闘.md:198` / `00_docs/10_プラグイン設計書/feature/12-mob/4-統合フロー/12_4.00-統合フロー.md:121`
- 根拠: ユースケースは「最後に致死ダメージを与えたプレイヤー」をキラーとし、統合フローは「脅威値最大」をキラーとし、戦闘仕様の致死処理は脅威値最大を優先する。一方で同じ戦闘仕様の「ドロップ配布対象と演出」では `lastAttackerUuid` を優先し、さらに脅威テーブル参加者とパーティーメンバーへ個別配布するとしている。
- 問題: キラー、ドロップ抽選者、報酬受取者の定義が 1 人なのか複数人なのか、また優先順位が `lastAttackerUuid` なのか脅威値最大なのか決まっていない。
- 影響: 撃破報酬・経験値・金銭・リザルト表示がプレイヤー間で不公平または重複し、パーティー配布やヘイト管理の実装境界も曖昧になる。
- 修正方針: 「キラー特定」「配布対象」「個別抽選」「パーティー配布」の正本ルールを 1 つに統一し、ユースケース・戦闘仕様・統合フローを同じ優先順位へ揃える。
- 修正対象候補: `12_2.00-ユースケース.md` / `12_3.03-戦闘.md` / `12_4.00-統合フロー.md`
- 修正可否: `設計判断待ち`
