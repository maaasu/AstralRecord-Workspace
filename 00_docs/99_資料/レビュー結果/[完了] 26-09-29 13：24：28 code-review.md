## 指摘一覧

### AR-CODE-001 [中] 掲載期限到来直後に通常取り下げとして案内される
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/market/gui/MarketGui.java:282`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/market/event/MarketGuiEventHandler.java:1422`
- 根拠: 期限切れ表示・受取文言・完了通知は取得済み listing の status が `EXPIRED` のときだけ選ばれる。一方、自分の出品一覧は `status=ALL` で取得し、API の `ALL` は `ACTIVE` の `expiresAt` を検査しない。API の期限切れ更新は5秒周期で、Plugin の一覧は15秒キャッシュする。取消 API は `ACTIVE` でも `expiresAt <= now` を期限切れとして扱う。
- 問題: 期限到来後、一覧や確認画面がまだ `ACTIVE` を保持する間にクリックすると、画面は通常の「出品を取り下げる」と案内し、成功時も通常の `P_6301` を送る。API 上の結果は期限切れ取消であり、ユーザーに示す取り下げ理由が事実と異なる。
- 影響: プレイヤーが自分で取り下げたと思うか、期限切れで保管された商品を手動受取したと認識できない。期限切れ理由の表示という今回の要件が時刻境界で満たされない。
- 修正方針: 自分の出品の表示・操作・完了通知では取得済み status だけでなく `expiresAt` と現在時刻で実効的な期限切れを判定し、取消 API の確定応答が期限切れを返した場合も案内を合わせる。通常の手動取り下げの経路は維持する。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
