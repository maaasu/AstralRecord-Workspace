### AR-CODE-001 [低] シールドブレイクの基準構成が再現できない
- 種別: `ドキュメント不整合`
- 対象: `00_docs/50_Filebase設計書/feature/40-mob.md:27`
- 関連箇所: `40_filebase/20.features.class/v1.swordsman.yml:22`
- 根拠: Mob 設計へ追加したルールは「標準 equipment・skilltree」の最大 `MAX_SHIELD` を使うと定めているが、既存の戦闘バランス設計と filebase には、基準装備の ID、強化段階、skilltree の取得構成が一意に定義されていない。ソードマンの class 基礎 `MAX_SHIELD` は5である一方、Lv.8 の `fang_shield` は `MAX_SHIELD +15`、skilltree には `MAX_SHIELD` を増やす複数 node がある。
- 問題: `SHIELD_BREAK: 5 / 9` の数値が、文書に記載されたソードマンのシールド量から一意に再現できない。
- 影響: 高レベルダンジョンの Mob を追加・再調整する際、担当者ごとに異なる最大シールドを基準にして値がぶれる。
- 修正方針: Mob 設計へ、対象レベルのソードマンの class、基準 equipment、強化段階、skilltree 選択を固定した再現用基準構成と、現行 Lv.8 の基準 `MAX_SHIELD` を明記する。
