### AR-CODE-001 [高] 攻撃後の帰還で不死鳥がテレポートする
- 種別: `仕様不整合`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/service/ArchmagePhoenixRuntimeService.java:268`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/service/ArchmagePhoenixRuntimeService.java:503`
- 根拠: レビュー時の差分では、攻撃終了後に通常の `follow()` を呼び、その復旧分岐が追従点から24m超で `parrot.teleport(anchor)` を実行していた。一方、攻撃対象は所有者から50mまで許容される。ユーザーは攻撃後にテレポートせず追従点へ戻ることを指定している。
- 問題: 所有者から離れた敵へ攻撃した後、追従への復帰時に距離による復旧テレポートが発動する。
- 影響: 約24～50m先の敵を攻撃した不死鳥が物理飛行で戻らず、プレイヤーの背後へ瞬時に移動する。
- 修正方針: 攻撃後の帰還状態を保持し、同一ワールドで帰還中は距離・停滞による復旧テレポートを抑止する。追従点へ十分近づいたら通常追従へ戻す。
