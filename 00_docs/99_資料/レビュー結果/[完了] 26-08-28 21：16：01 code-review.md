### AR-CODE-001 [低] クラッシュアローの発射音が二重再生される
- 種別: `仕様不整合`
- 対象: `40_filebase/30.features.skill/v1.hunter_crash_arrow.yml:45`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/service/SkillService.java:674`
- 根拠: 成功したスキル発動では `SkillService` が `definition.getOnCastSound()` を `playOnCastSound` へ渡して再生する。クラッシュアローは YAML の `onCast.sound: entity.arrow.shoot` に加えて executor でも `SkillEffectService.sound(..., Sound.ENTITY_ARROW_SHOOT, 1.15F, 0.75F)` を呼び出している。実装契約は発射音を1回としている。
- 問題: 同じ発動で共通処理と executor の両方から `ENTITY_ARROW_SHOOT` が再生され、発射音が2回鳴る。
- 影響: クラッシュアローの発動演出が設計書の1回という契約から外れ、音量・pitchの異なる音が重なって聞こえる。
- 修正方針: executor 側の音量・pitch指定を正本として残し、クラッシュアロー YAML の `onCast` 音設定を削除する。
- 修正対象候補: `40_filebase/30.features.skill/v1.hunter_crash_arrow.yml`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
