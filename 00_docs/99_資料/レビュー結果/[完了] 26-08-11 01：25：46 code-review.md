### AR-CODE-001 [高] 一次職の初期スキル使用許可が空になる
- 種別: `仕様不整合`
- 対象: `40_filebase/20.features.class/v1.swordsman.yml:62`
- 関連箇所: `40_filebase/20.features.class/v1.hunter.yml:62, 40_filebase/20.features.class/v1.mage.yml:62`
- 根拠: `00_docs/50_Filebase設計書/feature/20-class.md:16` と各クラス別戦闘バランス設計は、swordsman / hunter / mage の各クラスが冒険者から引き継ぐ初期攻撃 skill 2件を `usableSkills` で許可すると定めている。Plugin の `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/service/SkillPermissionService.kt:16` は現在クラスの `usableSkills` と有効な skilltree skill effect の和集だけを使用許可にする。
- 問題: 3つの class master に `usableSkills` が定義されておらず、スキーマ契約上は空リストとなる。さらに今回の164 nodeには skill effect が0件のため、転職後の3職に skill 使用許可の供給元がない。
- 影響: ソードマン、ハンター、メイジへ転職したプレイヤーは、対象の習得済み skill 個体を所持・バインド済みでも使用許可検査を通過できず、設計上の初期攻撃 skill を発動できない。
- 修正方針: 3つの class master へ設計書指定の2件ずつを既存参照形式 `skill:<skillId>` で `usableSkills` に追加する。ソードマンは `adventurer_astral_edge` / `adventurer_smash`、ハンターは `adventurer_blast_arrow` / `adventurer_quick_shot`、メイジは `adventurer_mana_burst` / `adventurer_lightning_bolt` とし、master reference validation と現在クラス別の許可集合を再検証する。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-002 [中] 0ポイント時に無料ノードを解放できない
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skilltree/event/SkillTreeEventHandler.java:135`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skilltree/service/SkillTreeService.java:509, 40_filebase/35.features.skilltree/nodes/1047.json:17, 00_docs/50_Filebase設計書/feature/35-skilltree.md:56`
- 根拠: `00_docs/50_Filebase設計書/feature/35-skilltree.md:56` と `:63` はroot直近の上下左右各2nodeをPP 0の無料nodeとして定義し、node `1047`～`1055`も `pointCost: 0` である。`SkillTreeService.canUnlockNode` / `hasRequiredPoints` は0-cost nodeを許可する一方、`SkillTreeEventHandler.unlockNode` はnodeのcostを確認する前に `hasAvailableUnlockPoint` がfalseなら一律拒否する。PP / CP獲得量はそれぞれ `max(0, level - 1)` なので、Player Lv.1・冒険者Lv.1では同判定がfalseになる。
- 問題: ポイント残高0のLv.1プレイヤーが左クリックすると、root `1047`と後続の無料PP node `1048`～`1055`が、コスト0であるにもかかわらずポイント不足として拒否される。
- 影響: 明示要件である「最初の上下左右2マスずつはポイントなしで解放」を開始レベルで利用できず、rootを含むskilltree進行がPlayer Lv.2まで開始できない。
- 修正方針: Event層の残高不足guardを `node.pointCost() > 0` の場合だけ適用し、最終可否は既存の `service.canUnlockNode` に委ねる。Player Lv.1・冒険者Lv.1相当の残高0でrootから無料PP nodeを解放でき、有料nodeは引き続き拒否されるevent testを追加する。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
