### AR-CODE-001 [中] ゲート材質に応じた破片パーティクルを表示していない
- 種別: `仕様不整合`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/dungeon/service/DungeonGateReleaseService.java:51`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/shared/effect/SharedParticleDefinitions.java:114`
- 根拠: `32_3-処理契約.md` の「表示ゲートの各ブロックに共有の破壊パーティクルを表示する」という契約、および利用者要求のブロック破壊パーティクル。
- 問題: 表示するのは固定の `Particle.POOF` だけで、除去対象の `gateMaterial` / `BlockData` を使う `Particle.BLOCK` の破片表示ではない。このため石やレンガなどへゲート材質を変更しても、破壊されたブロックの見た目にならない。
- 影響: 部屋クリア時の演出が要求したブロック破壊表現と一致せず、ゲート材質の設定が演出へ反映されない。
- 修正方針: AIR へ変更する前に各表示ゲートの `BlockData` を保持し、共有定義・`ParticleDisplayService` 経由で当該データを持つ `Particle.BLOCK` を各座標へ表示する。材質別データを扱う共有定義の API を追加し、テストで particle 種別と `BlockData` を検証する。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/dungeon/service/DungeonGateReleaseService.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-003 [中] 追加したゲート解除演出テストが Bukkit 未初期化で失敗する
- 種別: `テスト不足`
- 対象: `10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/dungeon/service/DungeonGateReleaseServiceTest.java:41`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/shared/effect/SharedParticleDefinitions.java:360`
- 根拠: Plugin Code のテスト追跡性ゲートはテストを最終 Maven 実行で検証することを要求する。`mvn -q '-Dtest=DungeonBlockPlannerTest,DungeonGateReleaseServiceTest' test` 後の Surefire レポートでは当該テストが `Errors: 1` となり、`Material.STONE_BRICKS.createBlockData()` が Bukkit server 未初期化のため `NullPointerException` を送出している。
- 問題: Mockito 単体テストで Bukkit のグローバル server を初期化せず `Material#createBlockData()` を実行しているため、ゲート解除時の BlockData 破片パーティクル、両面削除、音の検証まで到達しない。
- 影響: 今回追加した解除演出の回帰テストが常に失敗し、CI／最終検証を通過できない。また、BlockData を渡す仕様の回帰を自動検出できない。
- 修正方針: MockBukkit 等で Bukkit server を初期化して実 BlockData を取得するか、`BlockData` を Mockito でモックして Bukkit グローバル状態へ依存しない単体テストへ変更する。修正後に対象 Maven テストで成功を確認する。
- 修正対象候補: `10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/dungeon/service/DungeonGateReleaseServiceTest.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
