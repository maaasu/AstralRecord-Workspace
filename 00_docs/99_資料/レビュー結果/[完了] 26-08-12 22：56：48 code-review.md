### AR-CODE-001 [中] スキルタグが共有カタログの登録・適用対象契約に違反している
- 種別: `仕様不整合`
- 対象: `40_filebase/30.features.skill/v1.swordsman_shield_drain.yml:52`
- 関連箇所: `40_filebase/76.shared.tag/v1.tags.yml:400`
- 根拠: `00_docs/50_Filebase設計書/feature/76-tag.md` は、新規タグを共有カタログへ追加してから個別マスターで使い、`appliesTo[]` の対象外では使用しないことを要求している。`swordsman` は共有カタログに存在せず、`shield` は `SKILLTREE_NODE` と `MOB` だけを適用対象としている。`generate-tag-types.ps1 -Check` も両方をエラーとして列挙した。

### AR-CODE-002 [中] 吸収粒子が敵から使用者へ流れず瞬時に全線分へ表示される
- 種別: `仕様不整合`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/executor/active/swordsman/SwordsmanShieldDrainExecutor.java:153`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/active/service/SkillEffectService.java:57`
- 根拠: `00_docs/10_Plugin設計書/feature/13-skill/13_6-発動スキル追加ガイド.md` は、対象から発動者へ粒子が流れ、到達4 tick後に円形 Shield を表示する契約である。一方 `SkillEffectService.line` は線分上の全点を一括生成し、同一 tick に batch 表示する。
- 問題: `renderAbsorption` は命中直後に全線分を一度だけ表示し、4 tick 遅延するのは到達リングだけなので、エネルギー粒子の移動が表現されない。
- 影響: 依頼された「敵から使用者へ流れて到達する」吸収演出にならず、遅延リングとの視覚的な因果も読み取りにくい。
- 修正方針: 4 tick 程度の有界な反復処理で対象から発動者へ進む点または短い線分を tick ごとに1 batch表示し、最終 tick でリングを表示する。同一 scope のタスクとして既存 lifecycle で破棄可能にする。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/executor/active/swordsman/SwordsmanShieldDrainExecutor.java`
