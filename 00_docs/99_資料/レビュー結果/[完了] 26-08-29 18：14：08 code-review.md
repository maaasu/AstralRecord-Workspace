### AR-CODE-001 [低] クモ糸飛翔体の主要実行経路を検証するテストがない
- 種別: `テスト不足`
- 対象: `10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/mob/skill/forestspider/ForestSpiderWebShotMobSkillExecutorTest.java:26`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/mob/service/MobProjectileService.java:134`
- 根拠: 現在の恒久テストはスキルパラメーターの受理・拒否と既定 timing／垂直照準だけを確認している。今回追加した `launchWeb` は tick 単位の移動、プレイヤー hitbox とブロック ray trace の手前優先判定、遠隔ダメージ成立後の `WEAKNESS` 要求を実装しているが、その実行経路をテストしていない。
- 問題: クモ糸スキルの主要な命中・状態異常処理が将来の変更で壊れても、既存のテストでは検出できない。
- 影響: クモ糸がプレイヤーへ命中する条件、壁で停止する条件、ダメージ後に `ConditionService` へ衰弱を要求する条件の回帰を自動検出できない。
- 修正方針: MockBukkit または既存の Bukkit scheduler テスト基盤を使い、発射から tick 移動・プレイヤー命中までを実行して、`DamageService.attack` と `ConditionService.applyCondition` の呼び出しを検証する。可能なら壁遮蔽時に命中しないケースも追加する。
