### AR-CODE-001 [中] 再同期中のローカル通貨変更を上書きする
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/inventory/service/InventoryService.java:2205`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/market/event/MarketGuiEventHandler.java:707`
- 根拠: `refreshAuthoritativeCurrencyEntries` は API 取得前後で state 世代と currency inventory の有効性だけを確認し、取得中に entry が変わっていないことを確認せずに正本 snapshot を置換する。
- 問題: オンライン出品者が再同期中に別の通貨操作を行うと、取得完了した API snapshot がその未保存ローカル変更を上書きする。
- 影響: 売上通知と並行した Gold の増減が画面・次回保存から失われ、通貨整合性を損なう。
- 修正方針: API 取得前の currency entry snapshot を保持し、取得後も同一である場合だけ正本を反映する。差分があれば state を変更せず false を返し、売上通知もしない。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/inventory/service/InventoryService.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-002 [中] 購入者離脱時に出品者の通貨再同期が省略される
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/market/event/MarketGuiEventHandler.java:499`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/market/event/MarketGuiEventHandler.java:508`
- 根拠: 購入 API が成功した後の出品者通貨再同期は、購入者の `isCurrentSession` 判定の後に呼ばれる。購入者が GUI を閉じるか離脱すると `sessions` から削除され、この判定が false になる。
- 問題: API transaction 自体は確定済みでも、購入者セッションが無効ならオンライン出品者の `CURRENCY` 正本再同期が実行されない。
- 影響: 出品者のローカル通貨が古い `updatedAt` のまま残り、次回保存で同じ 409 Conflict を再発し得る。
- 修正方針: API 成功時の出品者再同期を購入者 GUI / セッション検査より前に実行し、購入者向け GUI 更新だけをセッション有効時に限定する。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/market/event/MarketGuiEventHandler.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
