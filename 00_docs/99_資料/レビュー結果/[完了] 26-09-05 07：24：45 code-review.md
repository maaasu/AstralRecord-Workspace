### AR-CODE-001 [中] 一時APIエラーの再送が無期限で継続する
- 種別: `パフォーマンス`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/service/LearnedSkillService.java:729`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/service/LearnedSkillService.java:39、00_docs/10_Plugin設計書/feature/13-skill/13_5-例外・ログ・運用.md:49`
- 根拠: `scheduleMutationRetry` は待機間隔を最大2000msに固定するだけで、試行回数または総再送時間の上限を持たない。今回の変更でHTTP 429と500台全体がこの経路に入る。API mutation開始後のoperationTimeoutは保留通知だけでlockを解放しない。
- 問題: APIがrate limit中または恒常障害中の場合、同一accountのmutation lockを保持したまま最大2秒間隔のPOST再送を無期限に継続する。
- 影響: 障害が長引くほどAPIへの追加負荷が発生し、対象プレイヤーは同じaccountで後続のスキル操作を受け付けられない。応答不明を避ける目的に対して再送量と保持時間の境界がない。
- 修正方針: 同一operationIdによる再送の安全性を維持しつつ、試行回数または総再送時間に上限を設ける。上限到達時は習得済みスキルと操作対象entryを正本へ再同期してから失敗完了し、mutation lockを解放する。変更した待機・終了条件を設計書へ反映する。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-002 [低] 一時HTTPステータス判定のテスト網羅性が不足する
- 種別: `テスト不足`
- 対象: `10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/skill/service/LearnedSkillServiceTest.java:47`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/service/LearnedSkillService.java:761`
- 根拠: 実装は408、425、429、500台を再送し、その他の4xxとstatusCodeなしを再送しないが、テストで再送を確認しているのは503、非再送を確認しているのは409だけである。
- 問題: HTTP statusの境界値やIOExceptionの既存再送が将来変更されても、テストで検出できない。
- 影響: 408／425／429や500／599の判定誤り、401／404の業務・認証エラーの誤再送、接続例外の再送漏れを見逃す可能性がある。
- 修正方針: 再送対象（408／425／429／500／503／599）と非再送対象（400／401／404／409）、IOExceptionを同一operationIdで検証するテストを追加する。
- 修正対象候補: `10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/skill/service/LearnedSkillServiceTest.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
