### AR-CODE-001 [中] 保護対象が混在する一括削除の禁止条件がない
- 種別: `ドキュメント不整合`
- 対象: `.codex/skills/astralrecord-git-worktree-develop/references/integrated-branch-cleanup.md`
- 関連箇所: `.codex/skills/astralrecord-prune-codex-worktrees/scripts/prune_codex_worktrees.py`
- 根拠: 削除前確認は PR head/base、他作業依存、保持指定のある枝を除外するが、既存ローカル一括スクリプトはこれらを検出しない。
- 問題: 一括整理へ誘導する参照に保護対象混在時の実行禁止がない。
- 影響: マージ済みでも PR 等で必要な枝を一括削除する可能性がある。
- 修正方針: 全削除候補の事前確認を必須とし、保護・未確認候補が混在する場合は一括削除を禁止して個別整理または保留とする。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-002 [中] 取り込み済み成果が完了処理の停止条件に入る
- 種別: `ドキュメント不整合`
- 対象: `.codex/skills/astralrecord-code-version-commit-develop/references/cloud-workflow.md`
- 関連箇所: `.codex/skills/astralrecord-git-worktree-develop/SKILL.md`
- 根拠: Cloud 往復手順は既に取り込み済みの成果にも後続完了処理を適用するが、Git 完了処理は差分も先行コミットもない場合に停止する。
- 問題: 既に develop に含まれる成果枝の整理へ到達できない。
- 影響: 取り込み済み枝が通常完了処理で残り続ける。
- 修正方針: 取り込み済みを証明した場合は不要な統合作業ツリー作成・リベース・マージを省略し、安全整理へ進む例外を Cloud 往復手順に明記する。
- 修正対象候補: `.codex/skills/astralrecord-code-version-commit-develop/references/cloud-workflow.md`
