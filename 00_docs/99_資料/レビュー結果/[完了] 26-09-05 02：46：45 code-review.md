### AR-CODE-001 [高] Proxy既定定員がRPG backendの既定定員と一致しない
- 種別: `仕様不整合`
- 対象: `10_plugin/AstralRecordProxy/src/main/resources/config.yml:17`
- 関連箇所: `10_plugin/AstralRecord/src/main/resources/config.yml:13`
- 根拠: Proxyのch1/ch2は基本40人、寄付者追加5人、管理者追加1人だが、RPG本体は基本30人、寄付者追加5人、管理者追加1人を既定値として接続前に拒否する。
- 問題: GUIとProxyは通常40人まで空きありと判断する一方、RPG backendは30人で満員として拒否する。
- 影響: 表示人数と実際の接続可否が一致せず、31人目以降がbackendからkickされる。
- 修正方針: Proxyのch1/ch2既定基本定員をRPG本体と同じ30人へ揃える。
- 修正対象候補: `10_plugin/AstralRecordProxy/src/main/resources/config.yml`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-002 [中] 管理者追加枠の加算でintオーバーフローする
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecordLobby/src/main/java/io/github/maaasu/astralrecordlobby/LobbyApiClient.java:225`
- 関連箇所: `20_api/AstralRecordApi/AstralRecordApi/Controllers/NetworkController.cs`
- 根拠: LobbyのextraForは管理者向けにdonorExtraPlayersとadminExtraPlayersをintのまま加算し、APIは各値が非負かだけを検証する。
- 問題: 大きな追加枠値の合計が負数へオーバーフローし、limitForとfullForが誤判定する。
- 影響: 管理者向け最大人数表示と満員判定がProxyの飽和加算結果と不一致になる。
- 修正方針: longで加算してInteger.MAX_VALUEへ飽和させ、境界値テストを追加する。
- 修正対象候補: `10_plugin/AstralRecordLobby/src/main/java/io/github/maaasu/astralrecordlobby/LobbyApiClient.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-003 [低] API取得失敗とbackend停止を同じ表示にしている
- 種別: `仕様不整合`
- 対象: `10_plugin/AstralRecordLobby/src/main/java/io/github/maaasu/astralrecordlobby/ServerSelector.java:118`
- 関連箇所: `00_docs/10_Plugin設計書/feature/33-network/33_5-例外・ログ・運用.md`
- 根拠: API例外時も空Mapとloaded=trueで更新するため、presence欠落として「現在は接続できません」と表示される。
- 問題: 設計書の「人数情報を利用不可」と異なり、API障害とbackend停止を区別できない。
- 影響: プレイヤーと運用者が接続不能の原因を誤認する。
- 修正方針: API取得成否を別状態で渡し、失敗時は「人数情報を利用できません」と表示して接続を抑止する。
- 修正対象候補: `10_plugin/AstralRecordLobby/src/main/java/io/github/maaasu/astralrecordlobby/ServerSelector.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-004 [高] 停止中backendをオンラインとして公開する
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecordProxy/src/main/java/io/github/maaasu/astralrecordproxy/AstralRecordProxyPlugin.java:361`
- 関連箇所: `10_plugin/AstralRecordProxy/src/main/java/io/github/maaasu/astralrecordproxy/NetworkApiClient.java:81`
- 根拠: Proxyは全RegisteredServerを到達確認せずstate=onlineとしてAPIへ送信し、Lobbyはそのstateを接続可否表示に使う。
- 問題: Velocityに登録済みでも停止中のbackendが、GUIではオンラインかつ接続可能と表示される。
- 影響: 停止サーバーへの接続要求が送られ、失敗するまでLobby側で抑止できない。
- 修正方針: backend pingを非同期実行し、成功時だけonline、失敗時はofflineとして人数0をheartbeatする。
- 修正対象候補: `10_plugin/AstralRecordProxy/src/main/java/io/github/maaasu/astralrecordproxy/AstralRecordProxyPlugin.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
