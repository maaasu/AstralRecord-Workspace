### AR-CODE-001 [中] DiscordSRV起動前に中継ハンドラが登録されない
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecordLobby/src/main/java/io/github/maaasu/astralrecordlobby/DiscordNetworkBridge.java:37`
- 関連箇所: `10_plugin/AstralRecordLobby/src/main/resources/plugin.yml:6`
- 根拠: `plugin.yml` は DiscordSRV を `softdepend` として宣言しており、依存プラグインが利用できない状態でLobbyが有効化される可能性がある。`start()` は DiscordSRV が未登録の場合に初期化タイマーを作成せずreturnする一方、`tryInitialize()` には未起動時の停止・再試行を想定した分岐がある。
- 問題: DiscordSRV がLobbyの有効化時点で未登録だと `DiscordSRV.api.subscribe(this)` に到達せず、後からDiscordSRVが有効化されても `GameChatMessagePreProcessEvent` の標準中継抑止ハンドラが登録されない。
- 影響: 起動順または依存プラグインの再有効化の状況によっては、今回の二重送信防止が機能せず、同一のMinecraft発言が標準経路とNetwork API経路からDiscordへ送信され続ける。
- 修正方針: `discord.enabled` が有効な場合はDiscordSRVの有無にかかわらず初期化タイマーを開始し、既存の `tryInitialize()` による有効化待ちと購読処理を利用する。
- 修正対象候補: `10_plugin/AstralRecordLobby/src/main/java/io/github/maaasu/astralrecordlobby/DiscordNetworkBridge.java`
