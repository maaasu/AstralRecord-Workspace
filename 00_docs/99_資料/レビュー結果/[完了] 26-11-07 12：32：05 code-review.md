## 指摘一覧

### AR-CODE-001 [中] 整数値を表す小数表記でエディタとプラグインの判定が異なる
- 種別: `仕様不整合`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/account/repository/ProgressionPresetRepository.java`
- 関連箇所: `60_tool/skilltree-editor/src/SkillTreeEditor.Server/Services/ProgressionPresetValidation.cs`
- 根拠: JSON Schemaの整数型は値が整数の1.0を受理する。YAMLの読込では数値型がIntegerとは限らず、エディタの文字列からの整数変換では小数点付き表記が既定値にフォールバックする。
- 問題: 原稿編集で強化値・スキルレベル・枠に1.0を指定すると、エディタが保存した原稿をプラグインのマスタ再読込が拒否することがある。
- 影響: 保存に成功したプリセットを反映できず、プラグインのマスタ読込が失敗する。
- 修正方針: エディタとプラグインの両方でint範囲内の整数値を扱い、実際の値で制約を検証する。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
