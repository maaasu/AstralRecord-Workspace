## 指摘一覧

### AR-CODE-001 [低] 共通報酬の進行度コメントが参照元の段階と一致しない
- 種別: `ドキュメント不整合`
- 対象: `40_filebase/80.shared.loot/table/v1.normal_enemy_common_table_tier_2.yml:3`
- 関連箇所: `40_filebase/80.shared.loot/pool/v1.normal_enemy_common_pool_tier_2.yml:3`
- 根拠: `00_docs/50_Filebase設計書/feature/80-loot.md` はtableのprogressionを主な参照元のprogressionに基づける。Tier2の適用開始はユーザー指定のLv.15であり、共通定義から参照するエリヴァ通常敵のprogressionは15である。
- 問題: 新しいtableとpoolのコメントはTier番号をそのままprogressionへ記載し、参照元の進行段階を表していない。
- 影響: 実行時の抽選には影響しないが、進行度の設計メタデータを参照する際に誤解を生む。
- 修正方針: 新しいtableとpoolのprogressionコメントを参照元の最初の段階である15に合わせる。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
