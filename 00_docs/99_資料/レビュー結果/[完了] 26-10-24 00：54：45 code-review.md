### AR-CODE-001 [中] 固定距離を敵の通常攻撃射程に適用していない
- 種別: `バグ/アルゴリズム`
- 対象: `60_tool/skilltree-editor/src/SkillTreeEditor.Server/Services/BalanceCombatSimulation.cs:116`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/mob/service/MobCombatService.java:308`
- 根拠: Plugin は対象との距離二乗が `normalAttack.range² + 4` を超えると攻撃せず AGGRO に戻る。実在 `midgard_grassboar` は `range: 2`、ラボ初期距離は3であり、`3² > 2² + 4` となる。
- 問題: ラボは固定距離をスキル飛翔と射程だけに使い、敵の通常攻撃を時間到達だけで実行する。
- 影響: 射程外に固定した戦闘でも敵のダメージ・死亡率を過大に見積もり、ビルド比較や必要回復量を誤る。
- 修正方針: 固定距離と Plugin の通常攻撃範囲判定を敵攻撃に適用し、敵の接近を行わない固定位置という前提を結果に明示する。
- 修正対象候補: `60_tool/skilltree-editor/src/SkillTreeEditor.Server/Services/BalanceCombatSimulation.cs`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-002 [中] 魔法スキルの既知パラメーターを Plugin より緩く受理する
- 種別: `バグ/アルゴリズム`
- 対象: `60_tool/skilltree-editor/src/SkillTreeEditor.Server/Services/BalanceSkillMagicProfiles.cs:242`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/executor/active/mage/MageFrostBallExecutor.java:37`
- 根拠: `MageFrostBallExecutor.validateParams` は `damageRatio` の正値、`freezeDurationTicks` の1以上、`freezeChance` の0～100を要求する。一方 `BalanceSkillMagicProfiles.Ready` の `ValidateGeometry` は射程・半径・速度・対象数だけを検査する。
- 問題: `mage_frost_ball` に `damageRatio: -1`、`freezeDurationTicks: 0`、`freezeChance: 120` のような値を設定しても `profile.Supported` が真になり得る。
- 影響: Plugin が不正として拒否するマスター調整案でもラボの厳密計算が成立し、効果比較が実稼働と乖離する。
- 修正方針: 対応魔法スキルの各 `validateParams` と同じ正値・確率・tick境界をアダプターで検証し、再現できない設定は厳密モードで停止する。
- 修正対象候補: `60_tool/skilltree-editor/src/SkillTreeEditor.Server/Services/BalanceSkillMagicProfiles.cs`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
