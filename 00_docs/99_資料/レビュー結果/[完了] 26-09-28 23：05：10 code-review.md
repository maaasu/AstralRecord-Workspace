### AR-CODE-001 [中] 星角の森守の攻撃頻度がLv.15の耐久目標に届かない
- 種別: `仕様不整合`
- 対象: `40_filebase/40.features.mob/enemy/v1.eriva_starhorn_guardian.yml:48`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/mob/skill/eriva/ErivaStarhornGroveCircleMobSkillExecutor.java:110`
- 根拠: `MobCombatService` は `normalAttack` 未設定時に通常攻撃せず、円陣は100 tickごとに20 tick詠唱と20 tick予告を経て攻撃する。`02-成長曲線.md` は同格プレイヤーの耐久時間を8～10秒とする。
- 問題: 星角の森守は円陣だけを使用するため、回避がなくても攻撃間隔が長く、同格プレイヤーへ十分な継続ダメージを与えない。
- 影響: 同じLv.15の既存通常敵と比べて戦闘上の脅威が極端に低くなる。
- 修正方針: 近接型へ寄せて30 tick間隔の通常攻撃を追加し、円陣を固有の回避可能な追加攻撃として維持する。
