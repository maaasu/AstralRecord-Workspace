### AR-CODE-001 [低] HUD更新経路のCP/PP受け渡しテスト不足
- 種別: `テスト不足`
- 対象: `10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/hud/view/PlayerHudViewTest.java:359`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/hud/service/PlayerHudService.java:228`
- 根拠: 追加テストは `PlayerHudView` へ CP / PP 表示値を直接渡した場合の描画だけを検証している。今回の要件の表示条件と値の受け渡しを実装する `PlayerHudService.updateAll` について、skilltree ワールド内で `SkillTreeService` の現在クラス CP / PP を渡すこと、および skilltree ワールド外で CP / PP を渡さないことを直接検証するテストがない。
- 問題: `isSkillTreeWorld` の判定や `currentClassPointLabel`、`availableClassPoints`、`availablePassivePoints` の受け渡しが将来変更されても、要件の入口である HUD 更新経路の回帰を検出できない。
- 影響: skilltree ワールド限定表示または CP / PP の値連携が壊れても、View 単体テストだけでは検知できない。
- 修正方針: `PlayerHudService` の更新経路を検証するテストを追加し、skilltree ワールド時は SkillTreeService の CP / PP 値が View へ渡され、通常ワールド時は CP 表示名が `null` になることを確認する。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
