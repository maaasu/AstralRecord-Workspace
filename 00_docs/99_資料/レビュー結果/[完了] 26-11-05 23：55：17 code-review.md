### AR-CODE-003 [低] JE で未登録の小数のモデル番号を拾う
- 種別: `仕様不整合`
- 対象: `50_resourcepack/scripts/item-models.ps1`
- 関連箇所: `50_resourcepack/item-models.json`
- 根拠: Java の range_dispatch は登録番号と次の整数の間でも同じモデルを選ぶ。
- 問題: 21001.5 のような値が JE で 21001 のモデルに割り当てられる。
- 影響: 登録外の番号に対するフォールバックが JE と BE で異なる。
- 修正方針: 登録番号の次に表現可能な float にフォールバックを設定し、直後の float も登録番号ならその登録を使う。
- 修正対象候補: `50_resourcepack/scripts/item-models.ps1`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
