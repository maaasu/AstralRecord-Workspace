## 指摘一覧

### AR-CODE-001 [中] 受信者の離脱後も保留された送信画面が開く
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/trade/service/TradeService.java:986`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/shared/gui/GuiOpenSupport.java:56`
- 根拠: 情報画面からの表示はGuiOpenSupportが2 tick保留する。受信者のquit・world離脱・account切替でcancelRelatedSessionsがsessionを中止しても、clearSessionはローカルの遷移トークンしか除去しない。
- 問題: 遷移元の情報画面はsession holderではなく閉じられないため、保留タスクのsource照合を通り、取消済みTradeGuiが開く。
- 影響: sessionが既に削除済みなので全クリックが拒否され、操作不能な送信画面が残る。
- 修正方針: GuiOpenSupportへ保留遷移の取消APIを追加し、TradeServiceで当該sessionの保留遷移がある場合に取消する。取消通知の二重実行を避ける。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
