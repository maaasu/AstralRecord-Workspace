- 対象: `60_tool/maintenance/UpdateWorkflow.ps1:257`
- 関連箇所: `60_tool/maintenance/Distribution.ps1:297`
- 根拠: 配布証跡を照合するのはDeploying/DeploymentFailedだけで、WaitingForStartupの再開時はdeployment.jsonがRestoredでも移行・完了へ進むことをmockで再現した。
