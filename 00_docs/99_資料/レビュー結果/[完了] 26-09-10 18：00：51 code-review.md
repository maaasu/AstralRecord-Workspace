### AR-CODE-001 [中] world 定義 overload が統合版非表示フラグを無視する
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/shared/effect/ParticleDisplayService.java:78`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/shared/effect/ParticleDisplayService.java:122`
- 根拠: `spawnWorld(World, Location, SharedParticleDefinition, double)` は定義の `hideForBedrock` を参照せず、`World#spawnParticle` へ直接到達する。定義受け取りの viewer 単位送信経路には統合版 viewer の除外処理があるが、この overload からは迂回できる。
- 問題: `hideForBedrock` が true の共通定義をこの public overload に渡した場合、統合版 viewer にもパーティクルが送信される。
- 影響: 現在の釣り竿糸は `spawnForNearbyViewers` を使うため影響を受けないが、共通定義を world overload で利用する将来・別経路では統合版非表示契約が破られる。
- 修正方針: `hideForBedrock=true` の定義だけ viewer 単位の送信へ分岐して統合版 viewer を除外し、`false` の既存 world 送信は維持する。該当経路の Bedrock/Java viewer テストを追加する。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/shared/effect/ParticleDisplayService.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-002 [低] 釣り竿実行経路の複数地点送信テストがない
- 種別: `テスト不足`
- 対象: `10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/shared/effect/ParticleDisplayServiceTest.java:34`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/item/service/DebugFishingRodUseService.java:583`
- 根拠: 現在のテストは単一点の `spawnForNearbyViewers(center, definition)` と world overload を検証している。実際の釣り竿糸は複数地点 overload を使用し、その経路にも統合版 viewer 除外処理があるが、専用テストがない。
- 問題: 複数地点送信へ引数を渡す経路や viewer ごとの送信回数が誤っても、釣り竿の実際の表示経路に対するテストで検出できない。
- 影響: 将来の共通パーティクル処理変更で、統合版 viewer に糸dustが送信される回帰を検出するまで遅れる。
- 修正方針: `spawnForNearbyViewers(center, List.of(...), FISHING_ROD_LINE)` を使い、統合版 viewer へ送信せず、Java版 viewer へ地点数分送信するテストを追加する。
- 修正対象候補: `10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/shared/effect/ParticleDisplayServiceTest.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
