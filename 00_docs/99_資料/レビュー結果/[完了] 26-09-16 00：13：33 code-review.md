## 指摘一覧

### AR-CODE-001 [中] ダンジョン表示名の色コードが待機ハブ本文へ継続する
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/resources/player.properties:681`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/dungeon/service/DungeonService.java:4581`
- 根拠: `P_7094` の第2置換値には直後の `&r` がない。呼び出し側は `session.loaded.definition().displayName()` を `{1}` へ渡しており、カラーコード付き表示名を受け取る同種の定義である。
- 問題: ダンジョン表示名に色・装飾コードが含まれる場合、`{1}` の後続にある「の待機ハブで待機中です。あなたを待っています。」がその色・装飾を引き継ぐ。
- 影響: ダンジョン待機中の案内文がダンジョン表示名の色・装飾で表示され、置換値の範囲を越えてメッセージの見た目が変わる。
- 修正方針: `P_7094` の第2 `{1}` の直後へ `&r&a` を追加し、続く待機ハブ本文を既定の緑へ戻す。カラーコード付きダンジョン名を使う回帰確認を追加する。
- 修正対象候補: `10_plugin/AstralRecord/src/main/resources/player.properties、10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/player/PlayerMsgResourceTest.java`
