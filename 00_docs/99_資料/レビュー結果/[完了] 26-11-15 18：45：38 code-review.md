## 指摘一覧

### AR-CODE-001 [低] チケット移動後にライブ画面の停止コマンドが失敗する
- 種別: `バグ/アルゴリズム`
- 対象: `.codex/skills/astralarchitect-builder/scripts/invoke_ticket_cli.py`
- 関連箇所: `10_plugin/AstralArchitect/tools/astralarchitect_ticket/cli.py:512`
- 根拠: 検証用チケットでライブ画面を起動し、プラグインのごみ箱に相当する別ディレクトリへチケットを移動した。元のパスで `live-stop` を呼ぶとパス検査が失敗し、画面への HTTP リクエストは引き続き成功した。
- 問題: 終了対象の識別にはセッションが保持するパスと認証情報を使えるが、停止コマンドはチケット本体を先に調査する。
- 影響: チケットを移動した後に自動化から停止できず、起動端末で停止するまでメモリ内のプレビューが残る。
- 修正方針: 停止時は元のチケットパスの位置とセッション認証を照合し、チケット本体が移動した場合の停止を回帰テストする。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
