### AR-CODE-001 [高] 中継対象外のDiscord発言までキャンセルされる
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecordLobby/src/main/java/io/github/maaasu/astralrecordlobby/DiscordNetworkBridge.java:77`
- 関連箇所: `10_plugin/AstralRecordLobby/src/main/java/io/github/maaasu/astralrecordlobby/DiscordNetworkBridge.java:78-84`
- 根拠: DiscordSRVの対象チャンネルを確認した直後に`event.setCancelled(true)`を実行し、その後でBot判定、Minecraftアカウント連携判定、本文空判定を行っている。設計書はMinecraftアカウント連携済みユーザーの発言だけをNetwork APIへ登録するフローとしている。
- 問題: Bot、未連携ユーザー、空本文の発言もDiscordSRV標準処理へ到達せず、Network APIにも登録されないまま破棄される。
- 影響: 中継対象外のDiscord発言がLobby側の標準DiscordSRV処理からも消失し、Discord側の発言が意図せず不可視になる。
- 修正方針: Bot判定、アカウント連携判定、本文検証を先に行い、実際にNetwork APIへ中継する発言だけ`event.setCancelled(true)`を実行する。アカウント連携必須の既存仕様は変更しない。
- 修正対象候補: `10_plugin/AstralRecordLobby/src/main/java/io/github/maaasu/astralrecordlobby/DiscordNetworkBridge.java`
- 修正可否: `自動修正可`

### AR-CODE-002 [中] DiscordSRVの再有効化後に中継が復旧しない
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecordLobby/src/main/java/io/github/maaasu/astralrecordlobby/DiscordNetworkBridge.java:40-60`
- 関連箇所: `10_plugin/AstralRecordLobby/src/main/java/io/github/maaasu/astralrecordlobby/DiscordNetworkBridge.java:94-115`
- 根拠: 初期化成功時に`subscribed=true`として初期化タスクを停止し、その後DiscordSRVが停止・再有効化されても`subscribed=false`へ戻す経路や再初期化を開始する経路がない。poll失敗時もログ出力だけである。
- 問題: Lobbyを再起動せずにDiscordSRVを再起動・再有効化した場合、Discord→Minecraft配信とMinecraft→Discord送信が停止したままになる。
- 影響: DiscordSRVの更新や一時停止後に、全チャンネルのチャット中継が復旧しない。
- 修正方針: DiscordSRVの無効化を検知して購読・pollを停止し、再有効化後にチャンネル解決・購読・poll再開を行う状態遷移を追加する。
- 修正対象候補: `10_plugin/AstralRecordLobby/src/main/java/io/github/maaasu/astralrecordlobby/DiscordNetworkBridge.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-003 [中] Lobby停止と非同期中継処理の競合で停止後の外部副作用が残る
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecordLobby/src/main/java/io/github/maaasu/astralrecordlobby/DiscordNetworkBridge.java:63-70`
- 関連箇所: `10_plugin/AstralRecordLobby/src/main/java/io/github/maaasu/astralrecordlobby/DiscordNetworkBridge.java:73-115`
- 根拠:`stop()`はtaskをcancelするが、すでに`pollMinecraft()`が購読状態を確認した後のHTTP取得やDiscord送信、または`onDiscordChat()`が投入した非同期API登録を取り消さない。停止開始を表す状態の再確認もない。
- 問題: Lobby停止中に進行済みのpollがDiscordへ投稿し、受信処理がNetwork APIへDiscord発言を登録する可能性がある。
- 影響: 停止・更新境界で停止後のチャットが外部へ流れ、停止状態とAPI/Discordの観測状態が一時的にずれる。
- 修正方針: 停止時に無効化する状態を先に設定し、Discord受信の非同期投入前、API取得後、Discord送信直前に有効状態を再確認して処理を中止する。
- 修正対象候補: `10_plugin/AstralRecordLobby/src/main/java/io/github/maaasu/astralrecordlobby/DiscordNetworkBridge.java`
- 修正可否: `自動修正可`
- 確信度: `中`
- 修正状態: `修正済み`

### AR-CODE-004 [中] DiscordSRV再有効化時にAPI購読が重複する
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecordLobby/src/main/java/io/github/maaasu/astralrecordlobby/DiscordNetworkBridge.java:77-85`
- 関連箇所: `10_plugin/AstralRecordLobby/src/main/java/io/github/maaasu/astralrecordlobby/DiscordNetworkBridge.java:54-60`
- 根拠: DiscordSRV 1.30.5の`ApiManager.subscribe`はリスナーを`CopyOnWriteArrayList.add`で追加し、重複排除しない。依存停止時に購読解除せず再有効化時に`subscribe(this)`を再実行すると、同じBridgeが複数回イベントを受ける。
- 問題: DiscordSRVの停止・再有効化を繰り返すと、1件のDiscord発言に対して同じLobby Bridgeの受信処理が複数回実行される。
- 影響: Discord発言のNetwork API登録が重複し、Proxyの全プレイヤー配信が重複する可能性がある。
- 修正方針: 依存停止を検知した時点でも既存Bridgeを`unsubscribe`し、再有効化時は1回だけ購読する。
- 修正対象候補: `10_plugin/AstralRecordLobby/src/main/java/io/github/maaasu/astralrecordlobby/DiscordNetworkBridge.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-005 [中] Lobby停止後の非同期外部副作用をライフサイクル状態だけでは原子的に抑止できない
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecordLobby/src/main/java/io/github/maaasu/astralrecordlobby/DiscordNetworkBridge.java:99-107`
- 関連箇所: `10_plugin/AstralRecordLobby/src/main/java/io/github/maaasu/astralrecordlobby/DiscordNetworkBridge.java:110-135`
- 根拠: `isActive(generation)`の確認直後に`api.publishDiscordChat`または`DiscordUtil.sendMessage`を呼ぶため、確認後に`stop()`が実行されるcheck-then-act競合が残る。
- 問題: 停止開始と外部API登録・Discord送信を排他していないため、停止後に進行済み非同期処理の外部副作用が発生し得る。
- 影響: Lobby停止・更新境界で、停止後のDiscord発言登録やMinecraft発言のDiscord投稿が残る可能性がある。
- 修正方針: ライフサイクル世代を使って旧処理を破棄し、非同期処理の状態確認を外部副作用直前にも行う。停止後に再初期化された世代の処理と混同しないようにする。
- 修正対象候補: `10_plugin/AstralRecordLobby/src/main/java/io/github/maaasu/astralrecordlobby/DiscordNetworkBridge.java`
- 修正可否: `自動修正可`
- 確信度: `中`
- 修正状態: `修正済み`

### AR-CODE-006 [中] DiscordSRV再起動をまたぐ旧pollが新世代の有効状態を誤認する
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecordLobby/src/main/java/io/github/maaasu/astralrecordlobby/DiscordNetworkBridge.java:110-130`
- 関連箇所: `10_plugin/AstralRecordLobby/src/main/java/io/github/maaasu/astralrecordlobby/DiscordNetworkBridge.java:77-85`
- 根拠: 旧pollがAPI応答待ちの間にDiscordSRVが停止・再有効化されると、booleanの`subscribed`だけでは旧処理と新処理を区別できない。旧pollが再有効化後の`subscribed=true`を読み、停止前に取得したbatchのcursor更新とDiscord送信を続け得る。
- 問題: 旧Discord接続向けに取得したbatchが新しいBridge世代へ持ち越され、送信失敗時にcursorだけが進んで再送されない可能性がある。
- 影響: DiscordSRV再起動境界でMinecraft発言のDiscord送信が欠落または順序不整合になる。
- 修正方針: poll開始時のライフサイクル世代を捕捉し、API応答後、cursor更新前、Discord送信前に現行世代と一致する場合だけ処理する。
- 修正対象候補: `10_plugin/AstralRecordLobby/src/main/java/io/github/maaasu/astralrecordlobby/DiscordNetworkBridge.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
