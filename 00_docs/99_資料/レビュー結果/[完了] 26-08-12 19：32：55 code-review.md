### AR-CODE-001 [低] クラス経験値バーの直下配置をテストで固定していない
- 種別: `テスト不足`
- 対象: `10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/hud/view/PlayerHudViewTest.java:167`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/hud/view/PlayerHudView.java:288`
- 根拠: `00_docs/10_Plugin設計書/feature/10-hud/3-メソッド仕様/10_3-View.md` の sidebar 契約は、クラス名・クラスレベルの直下へクラス経験値進捗バーを表示することを定めている。
- 問題: 追加テストはクラス行と経験値行が存在すること、経験値行が1行であることを確認しているが、両者の並び順を検証していない。そのため、経験値バーがクラス行から離れた位置へ移動してもテストが成功する。
- 影響: 依頼された「クラスの記載の下」という表示位置の回帰を自動検知できない。
- 修正方針: 捕捉した表示行からクラス行と経験値行の index を取得し、経験値行がクラス行の直後であることをアサートする。
- 修正対象候補: `10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/hud/view/PlayerHudViewTest.java`
