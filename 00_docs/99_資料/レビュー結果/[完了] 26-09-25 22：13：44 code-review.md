## 指摘一覧

### AR-CODE-001 [中] 再発動時に持続中の魔法陣が予定より早く消える
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/executor/active/archmage/ArchmageClearCircleExecutor.java:27`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/active/service/SkillTaskService.java:123`
- 根拠: このexecutorは発動ごとに同じ `TASK_SCOPE` を `repeat` へ渡す。`SkillTaskService.replace` は同一発動者・scopeの旧タスクを停止する。`SkillService` は `COOLDOWN_REDUCTION` を10秒の基礎クールタイムに適用し、スキルLv.5の魔法陣は10秒持続する。
- 問題: クールタイム短縮中に最初の魔法陣が解除対象を待っている間に再発動すると、新しいタスクの登録によって先の魔法陣の監視と描画が即時停止する。
- 影響: 指定された `5 + スキルLv` 秒の持続が成立せず、先の魔法陣に後から接触しても解除できない。
- 修正方針: ヒールサークルと同様、発動ごとに一意のscopeを生成し、その発動の解除成立時に同じscopeだけを停止する。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/executor/active/archmage/ArchmageClearCircleExecutor.java`
