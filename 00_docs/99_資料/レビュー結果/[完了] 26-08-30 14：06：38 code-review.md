### AR-CODE-001 [中] メイジ基礎幹を含む edge 交差が残っている
- 種別: `仕様不整合`
- 対象: `40_filebase/35.features.skilltree/structures/starter.json:1503`
- 関連箇所: `40_filebase/35.features.skilltree/docs.skilltree.JSONスキーマ定義.md:154`
- 根拠: x-z 平面で共通端点を持たない edge の交差・接触を検査すると、メイジ基礎幹を含む `1057-1058 × 1086-1300`、`1061-1062 × 1094-1307`、`1062-1081 × 1308-1309`、`1065-1066 × 1101-1314`、`1069-1070 × 1108-1321`、`1073-1081 × 1308-1309`、`1075-1084 × 1300-1301`、`1077-1082 × 1314-1315`、`1079-1083 × 1321-1322` の9組が残る。スキーマ説明は共通端点以外の edge 交差・重複を禁止している。
- 問題: 専門円環内の交差は解消されたが、メイジ基礎幹への接続とその近傍の edge が依然として交差または非共有端点で接触しており、追加した配置ルールとユーザー要件の「メイジのedge交差/重なりを修正」を満たさない。
- 影響: スキルツリー表示でメイジ領域の接続線が交差し、選択経路を判別しにくい。また、構造 JSON が明文化した配置制約に違反した状態で残る。
- 修正方針: メイジ4方向の基礎幹の起点・接続 edge を含めて座標または接続を再配置し、共通端点を持たない全 edge が x-z 平面で交差・接触・重複しないことを検査する。
- 修正対象候補: `40_filebase/35.features.skilltree/structures/starter.json`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-002 [中] 追加した edge 非交差ルールが既存構造と整合していない
- 種別: `仕様不整合`
- 対象: `40_filebase/35.features.skilltree/structures/starter.json:1503`
- 関連箇所: `40_filebase/35.features.skilltree/docs.skilltree.JSONスキーマ定義.md:154`
- 根拠: 追加した説明は、共通端点を持たない edge の x-z 平面上の交差または重複を例外なく禁止している。一方、`1096-1350`（`(18,-18)` から `(24,-18)`、冒険者）と、ハンターの `1267-1268`（`(21,-15)` から `(21,-18)`）および `1268-1271`（`(21,-18)` から `(24,-21)`）は端点を共有せず、いずれも `(21,-18)` で接触する。
- 問題: メイジの表示条件に限定した検査では交差しないが、文書化した配置制約は表示条件による限定を持たないため、同一 `starter.json` に残る上記2組が制約違反となる。
- 影響: エディター利用者が説明を全構造への制約として解釈した場合、現行データが契約違反に見える。将来の保存時検証へこの説明を実装した場合も、現行構造を受理できない。
- 修正方針: 非共有端点 edge の非交差を全構造へ適用するか、同時に表示される edge だけへ適用するかを確定し、前者なら該当座標/edgeを再配置し、後者ならスキーマ説明をその範囲に限定する。
- 修正対象候補: `複数`
- 修正可否: `設計判断待ち`
- 確信度: `高`
- 修正状態: `修正済み`
