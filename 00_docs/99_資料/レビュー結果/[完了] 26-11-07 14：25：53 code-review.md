- 関連箇所: `.codex/skills/astralrecord-code-version-commit-develop/SKILL.md:36`
- 根拠: Codex デスクトップの `create_thread` はユーザーが新しいタスクの作成を明示した場合だけ使える。変更前の手順は通常の変更を依頼ごとに新しい Cloud チャットへ委譲すると定めつつ、作成機能の利用を新規チャット作成が明示された依頼に限定していた。
