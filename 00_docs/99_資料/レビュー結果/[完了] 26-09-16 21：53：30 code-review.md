### AR-CODE-002 [低] 個体 Tooltip と安全側フォールバックのテストがない
- 種別: `テスト不足`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/market/gui/MarketGui.java:410`
- 関連箇所: `10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/market/repository/MarketRepositoryTest.java:38`
- 根拠: Plugin 設計書は通常装備 Tooltip への個体情報反映と identity 不一致時のマスタ表示フォールバックを要求するが、追加テストは API JSON からの復元までしか検証していない。
- 問題: `ItemStackFactory.create(model, equipmentInstance, 1)` を通る強化値・個体値表示と、instance ID または item ID 不一致時のフォールバックが自動検証されていない。
- 影響: 購入前 Tooltip が再びマスタ値だけになる、または別個体を描画する回帰を検出できない。
- 修正方針: MarketGui の一覧生成を通り、正常個体では強化値・ランダム値を含む Lore、identity 不一致では個体 Lore を採用しないことを検証する。
- 修正対象候補: `10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/market`
- 修正可否: `自動修正可`
