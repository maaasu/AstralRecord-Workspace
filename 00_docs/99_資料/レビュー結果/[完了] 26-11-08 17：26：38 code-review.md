### AR-CODE-001 [中] 同じ X・Z に重なる採集スポナーの詳細が欠落する
- 種別: `バグ/アルゴリズム`
- 対象: `60_tool/skilltree-editor/src/SkillTreeEditor.Client/src/components/SpawnerPlanningMap.tsx:229`
- 関連箇所: `00_docs/10_Plugin設計書/feature/12-mob/12_1-モデル定義.md:487`
- 根拠: 採集スポナーの一意キーに Y を含むため、X と Z が同じで高さの異なる配置を保存できる。エディタの地図は X と Z で点を投影する。
- 問題: ホバー判定で同じ距離の採集スポナーから最後の1件だけを返す。Dev 配置と同じ位置では Dev の判定が採集スポナーの詳細を隠す。AI 案の近くでは採集スポナーが AI 案の詳細を隠す。
- 影響: 重なる配置では、ズームしても保存済みの採集スポナーの ID と高さを確認できない場合がある。
- 修正方針: 同じ X・Z の採集スポナーをまとめて表示し、既存のマーカーと重なるときはホバーに詳細を併記する。既存の配置・地点のクリック操作を維持する。
- 修正対象候補: `60_tool/skilltree-editor/src/SkillTreeEditor.Client/src/components/SpawnerPlanningMap.tsx`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-002 [中] 受付アイコンが採集スポナーを覆う
- 種別: `バグ/アルゴリズム`
- 対象: `60_tool/skilltree-editor/src/SkillTreeEditor.Client/src/components/SpawnerPlanningMap.tsx:759`
- 関連箇所: `40_filebase/65.features.dungeon/v1.iluvatar_sanctum.yml:9`
- 根拠: 採集スポナーはブロック中心に描画し、受付アイコンは保存座標の中央に不透明なボタンを描画する。ミズガルズの受付 X=-449.5・Z=-684.5 は採集スポナー X=-450・Z=-685 の描画中心と一致する。
- 問題: 受付ボタンの表示領域が採集マーカーの描画とクリックの範囲を覆う。
- 影響: 重なった採集スポナーの ID や座標を地図から確認できない。
- 修正方針: 受付アイコンの衝突判定に採集マーカーを含め、重なったアイコンを既存の補助線で受付地点へ結ぶ。
- 修正対象候補: `60_tool/skilltree-editor/src/SkillTreeEditor.Client/src/components/SpawnerPlanningMap.tsx`
