### AR-CODE-001 [中] 返却不能な先頭出品が後続の期限切れ返却を止める
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/market/event/MarketGuiEventHandler.java:242`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/market/event/MarketGuiEventHandler.java:276`
- 根拠: 定期取得は `status=EXPIRED`、`listed_desc`、`page=1`、`pageSize=1` の固定条件で、取得した1件が容量不足なら API を呼ばず、アカウント単位の30秒待機へ進む。APIの `EXPIRED` 一覧は返却待ちの全件を降順に返すため、失敗した先頭は残り続ける。
- 問題: 先頭の出品を返却できない間、後続の期限切れ出品は一度も容量判定されない。
- 影響: 先頭品だけが容量不足でも、別の既存スタックへ収まる品を含む後続出品が自動返却されない。
- 修正方針: 同一アカウントの返却待ち出品を複数件調べ、返却可能なものを選ぶ。返却不能な出品は個別に再試行時刻を管理する。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/market/event/MarketGuiEventHandler.java`
