### AR-CODE-001 [中] 構え中の非Shift入力が通常攻撃にならない
- 種別: `仕様不整合`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/item/service/ItemWeaponAttackService.java:205`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/service/SeijakuIssenSkillRuntimeService.java:243`
- 根拠: 非Shift入力の冒頭でfinishForNormalAttackが構えを終了して共通通常攻撃CDを開始し、その直後のisOnCooldownが同じ入力を拒否する。ユーザーは非Shift時に通常攻撃を発生させるよう指定している。
- 問題: 構え中にShiftを離して左クリックしても通常攻撃を出せない。
- 影響: 追加クリックとCD待ちが必要になり、通常攻撃への切替が不自然になる。
- 修正方針: 構えのHUD・減速・期限タスクだけを解除し、同じ入力の通常攻撃成功経路が既存のCDを開始する。説明文と設計書を同期する。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 確信度: `高`
