- 根拠: 三波儀式は各波一撃で順番に進む契約、および第一回独立レビューの配置失敗・中断経路確認。
- 問題: 現在波を発動後、次波の安全床や視線を確保できず中断するとcompletedPhaseが未更新のまま第一波へ戻る。

- 修正方針: 個体に次の未発動波を保持し、中断・配置失敗後はその波を完全な予兆から再開する。最終波完了後に進行記録を解除する。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/boss/service/EmpusaSpellController.java`
