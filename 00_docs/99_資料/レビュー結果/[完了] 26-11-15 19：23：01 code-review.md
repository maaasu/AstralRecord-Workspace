## 指摘一覧

### AR-CODE-001 [中] 不正なモデル素材でライブ更新が部分反映される
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralArchitect/tools/astralarchitect_ticket/vanilla_assets.py:99`
- 関連箇所: `10_plugin/AstralArchitect/tools/astralarchitect_ticket/live.py:137`
- 根拠: 実物の Java 1.21.11 の素材を使い、オークの板材に規定外の状態回転角を指定した一時テスト JAR で `VanillaAssets.model()` が `StopIteration` を送出することを再現した。
- 問題: 不正なモデル素材を読み込む際に描画フォールバックから例外が漏れる。ライブ処理がモデルの解決とブロックの反映を同じループ内で行うため、例外の前に処理した変更がメモリ内に残る。
- 影響: 起動に失敗するか、送信済みの更新の一部がリビジョンを進めずに画面の再取得先へ反映され、操作の履歴とビューアーの表示が一致しなくなる。
- 修正方針: 対応する回転角と有限の座標を検証し、不正なモデルやテクスチャを簡易表示へ切り替える。新規モデルをすべて解決してからパレットとブロックの変更を反映し、ループ途中の失敗で表示状態が変化しないことを確認する。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
