### AR-CODE-002 [中] 選択したワークスペースのローカル設定を継承しない

- 修正対象候補: `60_tool/skilltree-editor/src/SkillTreeEditor.Server/Services/EditorHostOptions.cs`

### AR-CODE-003 [中] 動的ポートで画面設定の保存先が毎回変わる
- 種別: `バグ/アルゴリズム`
- 対象: `60_tool/skilltree-editor/src/SkillTreeEditor.Desktop/MainWindow.xaml.cs:98`
- 関連箇所: `60_tool/skilltree-editor/README.md`
- 根拠: 既存 README はペイン幅などをブラウザに記憶することを説明し、コードは localStorage を使う。

- 修正対象候補: `60_tool/skilltree-editor/src/SkillTreeEditor.Desktop/MainWindow.xaml.cs`
- 修正可否: `自動修正可`

### AR-CODE-005 [中] 非 PATH 配置の Node を子ビルドが参照できない
- 種別: `バグ/アルゴリズム`
- 対象: `60_tool/skilltree-editor/Publish-Desktop.ps1:57`
- 関連箇所: `60_tool/06-master-data-editor-build.bat`

- 修正対象候補: `60_tool/skilltree-editor/Publish-Desktop.ps1`
- 修正可否: `自動修正可`
