- 種別: `ドキュメント不整合`
- 対象: `00_docs/10_Plugin設計書/feature/19-party/19_0-概要.md:29`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/party/service/PartyService.java:119`
- 根拠: `PartyService` が `TradeService` の open session を参照して招待通知方式を切り替えるが、Party 概要の依存・連携表に trade がない。
- 問題: Party feature から Trade feature への依存境界と通知契約を概要から追跡できない。

- 修正方針: 依存・連携表に trade 行を追加し、open trade session 中の招待を非クリック式で通知する契約を記載する。
- 修正対象候補: `00_docs/10_Plugin設計書/feature/19-party/19_0-概要.md`
