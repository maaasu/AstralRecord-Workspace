### AR-CODE-001 [低] 2倍化した共有字形でクエストHUDのプレビューが崩れる
- 種別: `バグ/アルゴリズム`
- 対象: `50_resourcepack/scripts/generate-quest-hud-java.py:139`
- 関連箇所: `50_resourcepack/scripts/preview-quest-hud-bedrock.py:20`
- 根拠: 両版の既存クエストHUDプレビューが、今回1セル9×37から18×74へ拡大したクラス名用PNGを共有する。
- 問題: Java版プレビューは9×37の固定値で旧セル位置を切り出す。統合版プレビューは物理セルの上9ピクセルだけを切り出し、その物理幅で文字送りを行う。
- 影響: Java版の日本語サンプルに別字形や透明なセルの一部が混ざる。統合版のサンプルは字形が縦に切れ、行幅が本来のプレビューと合わない。
- 修正方針: PNGのグリッド寸法とJSONの論理heightからセルと倍率を求め、切り出した物理セルを論理寸法へ縮小して描画する。
