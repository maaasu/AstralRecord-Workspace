- 根拠: SQLはDBごとのトランザクション内でFK無効化とDELETEを行うだけで、アプリケーション接続を停止・排他しない。既存のDB再構築ツールは削除前に`SINGLE_USER WITH ROLLBACK IMMEDIATE`を設定する。

- 修正方針: 実行前に書き込み主体を停止することを必須化・検証するか、各DBを排他モードにする安全な実行手順を実装し、失敗時の復旧手順も明記する。
