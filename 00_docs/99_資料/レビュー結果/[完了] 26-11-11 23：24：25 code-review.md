### AR-CODE-001 [高] 有効化前に検証タスクが登録される
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/builder/service/BuilderSchematicImport.java`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/AstralRecord.java`
- 根拠: ビルダーのサービスは onLoad で生成される。Bukkit は無効状態のプラグインからのタスク登録を拒否する。
- 問題: 設定済みの dev でサービスの生成時に検証タスクを登録していた。
- 影響: プラグイン本体の起動処理が失敗する。
- 修正方針: API 初期化後の enableFeatures から検証タスクを開始する。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/builder/service/WorldEditGateway.java`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/builder/service/SchematicImportValidator.java`

- 修正方針: 移行結果を含めた ID とプロパティを稼働中のレジストリへ照合する。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`

### AR-CODE-005 [中] FAWE のパレット番号が切り詰められる
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/builder/service/WorldEditGateway.java`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/builder/service/SchematicImportValidator.java`
- 根拠: FAWE 2.15.2 の高速 reader はパレット番号を char に変換して、固定長のパレット配列へ格納する。
- 問題: パレット件数が reader の配列と16ビットの番号の範囲を超え得る。
- 影響: 値の衝突で別のブロックが読み込まれる。
- 修正方針: 稼働中の FAWE の配列長と16ビットの番号から上限を決め、読み込む前に確認する。
- 修正対象候補: `複数`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
