### AR-CODE-001 [中] 受領可能な空き枠まで受領枠案内で埋めている
- 種別: `仕様不整合`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/quest/gui/QuestGui.java:87`
- 関連箇所: `10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/quest/gui/QuestGuiTest.java:37`
- 根拠: 追加依頼は「受領できないスロット」に、受領枠の拡張方法と現在の受領枠を説明するダミーitemを置くことを求めている。`maxActiveQuests` は設計書 `29_3-メソッド仕様.md` の「受領上限」であり、active 件数がその上限に達していない間の論理スロットは受領可能枠である。
- 問題: 実装は active 件数から 28 件目までの全スロットへ案内itemを置く。そのため、例えば受領上限 5・active 0 件では、受領可能な先頭 5 枠も案内itemになり、「受領できないスロット」だけを示す表示にならない。
- 影響: 空き受領枠と上限超過枠を GUI 上で区別できず、受領枠を拡張する必要がある場所を誤って示す。
- 修正方針: active quest の直後から `maxActiveQuests - 1` までは空欄を維持し、`maxActiveQuests` 以降（表示上限 28 件まで）だけへ案内itemを配置する。active 件数が上限を超える既存データにも安全な開始位置を設定する。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/quest/gui/QuestGui.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
