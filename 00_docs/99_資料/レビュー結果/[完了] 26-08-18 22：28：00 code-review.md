- 問題: 現在のテストは表示名候補とアイテム解決だけを確認しており、`CONTROL_DROP` の AstralRecord item を共有したときに `InventoryClickEvent` を cancel してドロップを防ぐ契約と、対象外 item の通常ドロップ維持を確認していない。
