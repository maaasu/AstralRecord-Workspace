### AR-CODE-001 [中] クラスマスタ再読込後に通常攻撃劣化遅延が旧値のまま残る
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/AstralRecord.java:2457`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/playerclass/PlayerClassService.kt:62 | 10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/combat/service/NormalAttackDegradationService.java:366`
- 根拠: class Filebase 再読込時の公開処理は `playerClassService.replaceSnapshot(classSnapshot)` のみを行い、`PlayerClassService.replaceSnapshot` はオンラインプレイヤーのリスト名更新だけでStatusSnapshotを再計算しない。一方、通常攻撃劣化遅延は通常攻撃ごとに `StatusService.getStatus(player)` の既存スナップショットから読み取る。
- 問題: オンラインプレイヤーが `/masterdata reload` 後も再ログイン等でステータスが再計算されるまで、旧クラスマスタ由来の通常攻撃劣化遅延値を使用する。
- 影響: Hunter/Mageのクラスステータス変更や将来のクラスマスタ変更が、オンラインプレイヤーの通常攻撃劣化の発生回数へ即時反映されない。
- 修正方針: class snapshotの公開直後に、`AstPlayerCache` のオンラインプレイヤーのStatusSnapshotを `StatusService.refreshStatus` で再計算する。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/AstralRecord.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`

### AR-CODE-002 [低] 本番DI経路の通常攻撃劣化遅延統合テストがない
- 種別: `テスト不足`
- 対象: `10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/item/service/ItemWeaponAttackDegradationIntegrationTest.java:39`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/AstralRecord.java:1410 | 10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/combat/service/NormalAttackDegradationServiceTest.java:75`
- 根拠: 既存の `ItemWeaponAttackService` 統合テストは `NormalAttackDegradationService()` を生成しており、`StatusService` を持たない既定コンストラクタを通る。StatusService付きの単体テストは通常攻撃劣化遅延値を確認するが、武器通常攻撃からの呼出し経路との接続は確認していない。本番では `AstralRecord` がStatusService付きコンストラクタを使用する。
- 問題: 本番と同じStatusService注入経路で、空振りを含む通常攻撃castが新ステータスに応じた劣化段階へ進むことを自動検証できない。
- 影響: DI接続の変更や `ItemWeaponAttackService` 側の呼出し変更により、ステータス値が実際の通常攻撃処理へ伝播しなくなっても検知できない。
- 修正方針: 既存の武器通常攻撃統合テストをStatusService付きコンストラクタと遅延値で実行し、遅延回数を超えた攻撃で段階1へ到達することを確認する。
- 修正対象候補: `10_plugin/AstralRecord/src/test/java/io/github/maaasu/astralRecord/feature/item/service/ItemWeaponAttackDegradationIntegrationTest.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
