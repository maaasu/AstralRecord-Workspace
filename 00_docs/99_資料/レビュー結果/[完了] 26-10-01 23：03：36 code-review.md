### AR-CODE-001 [中] チャット共有ホバーで範囲行が既定非表示にならない
- 種別: `バグ/アルゴリズム`
- 対象: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/item/service/ItemChatShareService.java:105`
- 関連箇所: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/player/service/PlayerMessageService.java:368`
- 根拠: `ItemChatShareService.share` はサーバー側のアイテムを装飾行だけ除いたコピーとして `broadcastGlobalItemChat` に渡す。同サービスはその単一コピーを `asHoverEvent()` にして全受信者へ送る。範囲行の除去は `ItemStackPacketAdapter` の SET_SLOT/WINDOW_ITEMS/ENTITY_EQUIPMENT 送信処理内だけで行われる。
- 問題: `/showitem` で共有した装備のホバー ItemStack は受信者別の `RANDOM_STATUS_RANGE_DISPLAY` を適用しない。
- 影響: 既定値 `false` の受信者にも灰色の乱数範囲行が表示され、設定値 `true` と `false` の受信者が同じ表示を受け取る。
- 修正方針: チャット共有の送信先ごとにアイテムをコピーし、受信者の cache 設定が `false` の場合だけ `hideRandomStatusRangeLore` を適用してから hover event を組み立てる。
- 修正対象候補: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/player/service/PlayerMessageService.java`
- 修正可否: `自動修正可`
