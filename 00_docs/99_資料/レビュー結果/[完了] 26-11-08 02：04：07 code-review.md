### AR-CODE-001 [低] 紙で表示するポーションにも台帳のスタック上限を適用する
- 種別: `仕様不整合`
- 対象: `10_plugin/AstralRecordGeyserExtension/src/main/java/io/github/maaasu/astralrecordgeyser/ItemModel.java`
- 関連箇所: `50_resourcepack/scripts/item-models-generated.ps1`
- 根拠: 2Dポーションは地面表示のPOTIONとインベントリ・手持ちのPAPERで同じアイコンを使用する。台帳は1〜64の任意のスタック上限を受け付ける。
- 問題: 初稿では `max_stack_size` をPOTIONの定義にだけ適用し、PAPERの派生定義は既定の64を使っていた。
- 影響: 現行34点の上限は64で両経路が一致する。64未満のポーションを追加すると、経路によって統合版のスタック上限が異なる。
- 修正方針: PAPERの派生定義にも同じ `max_stack_size` を適用する。
- 修正対象候補: `10_plugin/AstralRecordGeyserExtension/src/main/java/io/github/maaasu/astralrecordgeyser/ItemModel.java`
- 修正可否: `自動修正可`
- 確信度: `高`
- 修正状態: `修正済み`
