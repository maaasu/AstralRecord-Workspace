# ゲームコンセプト

## 1. 目的

AstralRecord は Minecraft Java Edition 上で、育成、ビルド、探索、協力攻略を段階的に広げる RPG サーバーです。

本資料の目的は、強制的な物語進行を作ることではなく、本番向けマスタデータを増やすときの判断軸を揃えることです。

## 2. 既存情報から採用する軸

Web 側では次の表現が既に使われています。

- `Minecraft Java Edition MMO RPG`
- `星界を旅し、装備を鍛え、仲間と攻略を重ねる`
- `育成とビルド`
- `探索と攻略`
- `街・フィールド・戦闘コンテンツ`
- 画像: 空に浮かぶ島、温かい町、飛空艇、木造建築、発光する街灯、緑の多い拠点

このため、初期コンセプトは次のように置きます。

> 星界に点在する島と町を拠点に、プレイヤーが職業、装備、スキルを育てながら探索範囲を広げる Minecraft RPG。

## 3. 体験の柱

### 育成

- レベルアップ、装備更新、スキル習得により、短いプレイでも少し強くなった感覚を出す。
- 序盤は複雑な特殊効果より、HP、攻撃、防御、回復、移動速度などの読みやすい変化を優先する。

### ビルド

- クラスごとの得意ステータスを明確にする。
- 装備は「誰でも使える基本装備」と「クラス傾向に寄せた装備」を混ぜる。
- 序盤はビルド幅を広げすぎず、剣、弓、杖、防具、回復消耗品の基礎を揃える。

### 探索

- 町を安全圏、オーバーワールドを最初の危険圏として扱う。
- 初期フィールドは短時間で戻れる距離感を前提にする。
- 敵、素材、装備名にはエリアの軽いモチーフを反映する。

### 協力攻略

- 序盤はソロで成立させる。
- 少人数で少し楽になる敵配置、回復消耗品、ドロップ量を意識する。
- ボスや高難度は後続拡張で扱う。

## 4. ストーリーの扱い

このプロジェクトでは、ストーリーはマスタ作成の補助です。

- プレイヤーが必ず読む台本や連続シナリオは作らない。
- アイテムや敵を小説の一部として厳密に定義しない。
- 命名、地名、素材名、説明文に統一感を出すための背景だけ持つ。
- 元ネタを知っていると少し嬉しい程度の軽いモチーフは許容する。

## 5. 初期トーン

- 明るい空、浮遊島、町、星界、記録、古い航路、発光鉱石、風、木と石のクラフト感を中心にする。
- 暗黒、終末、過度な神話固有名、重い戦争設定は序盤では控えめにする。
- Minecraft の視認性を優先し、名前や lore は短く、ゲーム内 UI で読みやすくする。
