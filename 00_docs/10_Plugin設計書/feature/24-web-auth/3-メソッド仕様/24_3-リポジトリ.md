# 24_3-リポジトリ

## Web ログインチャレンジ作成

クラス名: `WebAuthRepository`
物理名: `createChallenge`

1. `userUuid`、`mcid`、`serverId`、現在時刻 `requestedAt` を JSON 化する。
2. `POST /api/web-auth/challenges` を呼び出す。
3. HTTP 200 または 201 を成功として扱う。
4. それ以外の HTTP status は `IOException` として失敗させる。
5. `challengeId`、`loginCode`、`expiresAt`、`loginUrl` を [[24_1-モデル定義]].Web ログインチャレンジ発行結果 へ変換する。
6. 割り込み時はスレッドの割り込み状態を復元する。割り込みと I/O 失敗は `RuntimeException` へ変換して呼び出し元へ伝播する。
