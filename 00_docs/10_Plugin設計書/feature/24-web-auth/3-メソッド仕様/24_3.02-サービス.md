# 24_3.02-サービス

## Web ログインチャレンジ発行

クラス名: `WebAuthService`
物理名: `issueLoginChallenge`

1. user UUID と MCID を引数として受け取る。
2. `ConfigProperties.getInstance().getApiServerId()` から発行元サーバー ID を取得する。
3. [[24_3.04-リポジトリ]].Web ログインチャレンジ作成 へ委譲する。
4. 成功時は [[24_1.00-モデル定義]].Web ログインチャレンジ発行結果 を返す。
5. 通信・解析失敗による `RuntimeException` は呼び出し元へ伝播する。
