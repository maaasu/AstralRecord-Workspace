# 24_3.02-サービス

クラス名: `WebAuthService`
物理名: `issueLoginChallenge`

## 1. `WebAuthService`

### `issueLoginChallenge(UUID userUuid, String mcid)`

- `ConfigProperties.getInstance().getApiServerId()` から発行元サーバー ID を取得する。
- `WebAuthRepository.createChallenge` へ処理を委譲する。
- 成功時は `WebLoginChallengeIssueResult` を返す。
- 通信失敗は `RuntimeException` として呼び出し元へ伝播する。
