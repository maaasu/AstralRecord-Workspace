# 24_3-コマンド

## Web ログインコード発行

クラス名: `WebAuthCommand`
物理名: `executePlayerCommand`

1. ゲーム内プレイヤーは `/web login` だけを受け付け、自身のUUIDとMCIDで発行する。`/web login <MCID>` はゲーム内の権限に関係なく `P_6403` で拒否する。
2. サーバーコンソールは `/web login <MCID>` だけを受け付ける。MCID省略の `/web login` は `P_5305` で拒否する。コンソール以外の非プレイヤー送信者も `P_6403` で拒否する。
3. コンソール指定時はAPIのMCID完全一致解決を先に呼び、未登録または複数一致なら `P_6404` で拒否する。アカウント名や部分一致は使用しない。
4. 発行対象のUUIDとMCIDを確定し、発行開始を通知する。

    | 項目 | 内容 |
    |---|---|
    | ID | `PlayerMsgId.P_6402` |
    | テンプレート | `Webログインコードを発行しています...` |
    | 出力条件 | 引数検証成功時 |
    | 引数 | なし |

5. Bukkit の非同期タスクで [[24_3-サービス]].Web ログインチャレンジ発行 を呼ぶ。
6. 成功時はメインスレッドへ戻り、ゲーム内実行では実行プレイヤーがオンラインの場合だけ結果を通知する。コンソール指定ではコンソールへ結果を通知する。有効期限は `Asia/Tokyo` の `yyyy-MM-dd HH:mm:ss z` 形式に変換する。

    | 項目 | 内容 |
    |---|---|
    | ID | `PlayerMsgId.P_6400` |
    | テンプレート | `Webログインコード: {0} （コードをクリックでコピー） 有効期限: {1} URL: {2}` |
    | 出力条件 | API 発行成功かつプレイヤーがオンライン |
    | 引数 | ログインコード、有効期限、ログイン URL |

7. `RuntimeException` の場合もメインスレッドへ戻り、実行者へ失敗を通知する。

    | 項目 | 内容 |
    |---|---|
    | ID | `PlayerMsgId.P_6401` |
    | テンプレート | `Webログインコードを発行できませんでした。しばらくしてからもう一度お試しください。` |
    | 出力条件 | 発行処理失敗かつプレイヤーがオンライン |
    | 引数 | なし |
