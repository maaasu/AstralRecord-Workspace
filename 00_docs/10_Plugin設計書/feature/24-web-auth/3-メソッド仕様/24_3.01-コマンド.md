# 24_3.01-コマンド

## Web ログインコード発行

クラス名: `WebAuthCommand`
物理名: `executePlayerCommand`

1. プレイヤー専用の `/web login` だけを受け付ける。引数が 1 個でない場合、または第 1 引数が大文字小文字を無視して `login` でない場合は使用方法を表示して終了する。
2. `AstPlayer` から user UUID と MCID を取得し、発行開始を通知する。

    | 項目 | 内容 |
    |---|---|
    | ID | `PlayerMsgId.P_6402` |
    | テンプレート | `Webログインコードを発行しています...` |
    | 出力条件 | 引数検証成功時 |
    | 引数 | なし |

3. Bukkit の非同期タスクで [[24_3.02-サービス]].Web ログインチャレンジ発行 を呼ぶ。
4. 成功時はメインスレッドへ戻り、コマンド実行時のプレイヤーがオンラインの場合だけ結果を通知する。有効期限は `Asia/Tokyo` の `yyyy-MM-dd HH:mm:ss z` 形式に変換する。

    | 項目 | 内容 |
    |---|---|
    | ID | `PlayerMsgId.P_6400` |
    | テンプレート | `Webログインコード: {0} （コードをクリックでコピー） 有効期限: {1} URL: {2}` |
    | 出力条件 | API 発行成功かつプレイヤーがオンライン |
    | 引数 | ログインコード、有効期限、ログイン URL |

5. `RuntimeException` の場合もメインスレッドへ戻り、オンラインの場合だけ失敗を通知する。

    | 項目 | 内容 |
    |---|---|
    | ID | `PlayerMsgId.P_6401` |
    | テンプレート | `Webログインコードを発行できませんでした。しばらくしてからもう一度お試しください。` |
    | 出力条件 | 発行処理失敗かつプレイヤーがオンライン |
    | 引数 | なし |
