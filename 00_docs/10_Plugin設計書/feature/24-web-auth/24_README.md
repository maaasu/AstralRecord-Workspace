# 24_README

Minecraft 内で本人確認済みのプレイヤーに、Web ログイン用の短時間・一回限りのコードを発行する機能です。

## 対象実装パス

- `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/webauth`

Plugin は `/web login` の受付、API への発行依頼、プレイヤーへのコード通知だけを担当します。コードの保存・検証と Cookie 認証は API / Web 側の責務です。

## 依存 feature

- `player`: user UUID、MCID、プレイヤーメッセージ
- `infrastructure`: API 通信と設定
- `00_docs/20_API設計書/feature/24-web-auth`: API 契約
