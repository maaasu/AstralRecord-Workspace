# 24_2-ユースケース

## 1. Web ログインコードを発行する

アクター: Minecraft へログイン済みのプレイヤー

1. プレイヤーが `/web login` を実行する。
2. Plugin が処理開始メッセージを返す。
3. Plugin が API へチャレンジ発行を非同期で依頼する。
4. 成功時はログインコード、有効期限、ログイン URL を表示する。
5. 失敗時は発行失敗メッセージを表示する。

## 2. 制約

- コンソール実行は受け付けない。
- 引数は `login` の 1 個だけを許可する。
- API 通信中に Bukkit API を非同期スレッドから操作しない。
