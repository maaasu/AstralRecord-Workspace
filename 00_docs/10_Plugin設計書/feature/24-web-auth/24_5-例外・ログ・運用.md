# 24_5-例外・ログ・運用

## 1. プレイヤーメッセージ

| ID | 条件 | 内容 |
|---|---|---|
| `P_6402` | 発行開始 | `Webログインコードを発行しています...` |
| `P_6400` | 発行成功 | `Webログインコード: {0} （コードをクリックでコピー） 有効期限: {1} URL: {2}` |
| `P_6401` | 発行失敗 | `Webログインコードを発行できませんでした。しばらくしてからもう一度お試しください。` |
| `P_6403` | ゲーム内でMCIDを指定、またはコンソール以外の非プレイヤー実行 | MCID指定発行はサーバーコンソール限定 |
| `P_6404` | コンソール指定MCIDが未登録または重複 | プレイヤーを一意に解決できない |
| `P_5305` | コンソールでMCIDを省略 | 対象プレイヤー指定を要求 |

## 2. 運用

- ログインコードや認証情報をログへ出力しない。
- API 呼び出しはメインスレッドをブロックしない。
- 有効期限は API の `WebAuth:ChallengeMinutes` を正とし、Plugin は返却値を表示するだけとする。
- 現行実装は発行失敗をプレイヤーメッセージへ集約し、専用 `LogId` を出力しない。
