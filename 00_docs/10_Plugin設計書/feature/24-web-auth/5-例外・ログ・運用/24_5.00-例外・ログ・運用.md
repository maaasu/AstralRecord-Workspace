# 24_5.00-例外・ログ・運用

## 1. プレイヤーメッセージ

| ID | 条件 | 内容 |
|---|---|---|
| `P_6402` | 発行開始 | API 問い合わせ中であることを通知する |
| `P_6400` | 発行成功 | コード、有効期限、ログイン URL を通知する |
| `P_6401` | 発行失敗 | 再試行を案内する |

## 2. 運用

- ログインコードや認証情報をログへ出力しない。
- API 呼び出しはメインスレッドをブロックしない。
- 有効期限は API の `WebAuth:ChallengeMinutes` を正とし、Plugin は返却値を表示するだけとする。
