# 24_0-概要

## 1. 目的

Minecraft サーバーへログイン済みのプレイヤーが、AstralRecord Web へ安全にログインする導線を提供します。Plugin はパスワードを扱わず、API が発行する短時間・一回限りのログインコードをプレイヤーへ通知します。

## 2. 責務

- ゲーム内プレイヤーの `/web login` を受け付け、実行者自身のコードを発行する。
- サーバーコンソールだけは `/web login <MCID>` を受け付け、登録済みプレイヤーをMCID完全一致で解決してコードをコンソールへ表示する。ゲーム内プレイヤーはMCID指定できない。
- `userUuid`、`mcid`、`serverId`、`requestedAt` を API へ送信する。
- 発行処理を非同期で実行し、メインスレッドで結果を通知する。
- ログインコード、有効期限、ログイン URL をプレイヤーへ表示する。
- コンソール指定時はコード、有効期限、ログイン URL をコンソールへ表示する。

## 3. 対象外

- ログインコードのハッシュ化、保存、失効、消費判定。
- Web の Cookie セッション発行とログアウト処理。

## 4. 依存・連携

- `player`: user UUID、MCID、プレイヤーメッセージ
- `infrastructure`: API 通信と設定
- `00_docs/20_API設計書/feature/24-web-auth`: API 契約
