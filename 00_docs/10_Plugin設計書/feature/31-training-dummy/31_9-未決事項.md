# 31_9-未決事項

## 1. Drop キー設定 GUI の編集権限

現行は `/dummy` コマンドだけを `UserPermission.ADMIN` で制限し、視線先カカシの Drop キー候補と設定 GUI では権限を検証しない。このため、配置済みカカシを視認できる全プレイヤーが共有ステータスを変更できる。

次のどちらを正式な利用者契約とするか未決である。

- 検証参加者全員が変更できる共有テスト対象として、現行の権限なし GUI を維持する。
- 配置・設定変更を管理操作として統一し、候補収集または GUI 実行直前に管理者権限を要求する。

決定時は [[31_0-概要]]、[[31_3-処理契約]]、[[31_5-例外・ログ・運用]] の権限記述を更新する。

## 2. 複数カカシの対象選択

現行 resolver は読み込み・登録順で視認可能な最初のカカシ一件だけを dispatcher へ返す。同じ視線上に複数のカカシがある場合、最短の対象が選ばれるとは限らない。

[[28_1-モデル定義]] の空間候補契約に合わせて resolver 内で全対象の命中距離を比較するか、登録順を検証用カカシ固有の優先規則として認めるか未決である。決定時は [[31_3-処理契約]] と player-interaction 側の対象選択契約を同時に更新する。
