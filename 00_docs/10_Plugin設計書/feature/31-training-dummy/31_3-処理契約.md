# 31_3-処理契約

## 1. 初期化と停止

1. Plugin 起動時に Mob 定義をロードした後、`training-dummies.yml` を読み込んで読み込み順を維持した定義キャッシュへ格納する。
2. Mob AI 開始後、メインスレッドで 20 tick 周期のカカシ管理タスクを開始する。
3. 各周期で、実体がない定義は実行時テンプレートから生成する。生成に失敗した ID は同じ読み込み状態では再試行せず、`place`、設定更新、または reload で失敗状態が解除された後に再試行する。実体がある場合は定義座標へ保持する。
4. 管理タスクの共通カウンタが各定義の `recoveryIntervalTicks` で割り切れる周期に、現在 HP を最大 HP へ戻し、shield が有効なら現在 shield を最大値へ戻す。この定期的な状態リセットは常時回復として扱い、回復数値の TextDisplay を表示しない。
5. Plugin 停止時は管理タスクを停止し、カカシとして追跡している全 Mob インスタンスを破棄する。

カカシの chunk ticket は chunk 単位で参照管理する。同じ chunk を使う複数カカシでは plugin ticket を一度だけ追加し、最後の利用者を破棄したときだけ ticket を解放する。

reload は既存実体を先に破棄し、定義キャッシュを YAML の内容で置換する。新しい実体は次の管理周期に生成する。

## 2. 管理コマンド

`/dummy <place|remove|reload|open> [id]` は `UserPermission.ADMIN` を持つプレイヤーだけが実行できる。

| 操作 | 処理契約 |
|:--|:--|
| `place <id>` | ID を trim・小文字化し、実行者の現在地、固定最大 HP `Integer.MAX_VALUE`、その他の既定ステータスで定義を新規作成または上書きする。全件保存、実体再生成の後に設定 GUI を開く |
| `remove <id>` | 完全一致する ID の定義を削除し、実体を破棄して残りの全件を保存する |
| `reload` | 既存実体を破棄し、YAML から定義を再読込する |
| `open <id>` | 完全一致する ID が存在する場合だけ設定 GUI を開く |

引数不足と未知のサブコマンドは共通 usage を表示する。存在しない ID、配置・削除・reload の成功件数は個別メッセージを返さない。`remove` と `open` は ID を小文字化しないため、手編集した YAML の大文字 ID は同じ表記で指定する。

## 3. 共有設定 GUI

GUI は 27 slot とし、holder に定義 ID を保持する。対象定義が操作前に消えていた場合は GUI を閉じる。

| 操作 | 変更量・結果 |
|:--|:--|
| 最大 HP 表示 | `Integer.MAX_VALUE` の固定値を表示し、GUI からは変更しない |
| 防御力減少 / 増加 | `-1.0` / `+1.0`。下限は `0.0` |
| 魔法防御減少 / 増加 | `-1.0` / `+1.0`。下限は `0.0` |
| shield 切替 | 有効・無効を反転する |
| shield 最大値 | 通常クリックで `+10.0`、Shift+クリックで `-10.0`。下限は `0.0` |
| 閉じる | GUI を閉じる |

設定を変更した場合は共有定義を保存し、対象実体を再生成して GUI を再描画する。GUI 内の click と drag はすべて cancel し、アイテムを移動させない。

## 4. Drop キー入力

1. `DROP_ITEM` family 以外では候補を返さない。
2. 配置 ID の保持順に出現中の Mob 実体を解決し、共通 ray と遮蔽距離から視認できる最初のカカシを一件だけ候補にする。
3. 候補は ID `training-dummy`、tier `WORLD_INTERACTION`、実際の命中距離、`stableOrder = 20`、target key は配置 ID、policy は `CLAIM_AND_CANCEL` とする。
4. 実行直前に対象定義が残っていることを再検証し、勝者になった場合だけ共有設定 GUI を開く。
5. 元の `PlayerDropItemEvent` を cancel し、通常の item drop は行わない。

同じ視線上に複数のカカシがある場合、現行 resolver は最短距離を比較せず定義の保持順で最初の一件を返す。返された候補と他 feature の候補との比較は [[28_3-サービス]] の共通規則に従う。
