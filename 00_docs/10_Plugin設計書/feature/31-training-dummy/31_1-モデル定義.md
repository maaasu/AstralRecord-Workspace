# 31_1-モデル定義

## 1. カカシ定義

物理名: `TrainingDummyDefinition`

| 項目 | 型 | 配置時の既定値 | 制約・用途 |
|:--|:--|:--|:--|
| `id` | `String` | コマンド引数 | 前後空白を除去する。`place` では小文字へ正規化する |
| `worldName` | `String` | 実行者の現在ワールド | 前後空白を除去する |
| `x`, `y`, `z` | `double` | 実行者の現在座標 | 実体の固定位置 |
| `yaw` | `float` | 実行者の現在 yaw | pitch は `0` 固定 |
| `maxHealth` | `double` | `2147483647.0` | `Integer.MAX_VALUE` に固定する。YAML の既存値や GUI 更新値は定義生成時に固定値へ正規化する |
| `defense` | `double` | `0.0` | 最小 `0.0` |
| `magicDefense` | `double` | `0.0` | 最小 `0.0` |
| `shieldEnabled` | `boolean` | `false` | `true` の場合だけ shield を有効化する |
| `shieldMax` | `double` | `10.0` | 最小 `0.0`。無効時も設定値は保持する |
| `recoveryIntervalTicks` | `long` | `40` | 最小 `20`。GUI からは変更しない |

定義生成時に数値下限を適用する。ワールドがロードされていない場合は座標を `Location` へ解決できず、定義は保持したまま実体生成を見送る。

## 2. training-dummies.yml

Plugin data folder 直下の `training-dummies.yml` を全件読み書きする。

```yaml
version: 1
dummies:
  - id: damage-check
    world: world
    x: 10.5
    y: 64.0
    z: -4.5
    yaw: 180.0
    maxHealth: 2147483647.0
    defense: 0.0
    magicDefense: 0.0
    shieldEnabled: false
    shieldMax: 10.0
    recoveryIntervalTicks: 40
```

- 保存時は常に `version: 1` と定義全件を出力する。現行の読み込み処理は `version` を分岐条件に使用しない。
- `id` または `world` が空・欠落した行は読み飛ばす。
- `maxHealth` は入力値にかかわらず `2147483647.0` へ正規化する。その他の数値型でない値は、`shieldMax=10.0`、`recoveryIntervalTicks=40`、残りを `0.0` へフォールバックする。
- boolean 型でない `shieldEnabled` は `false` とする。
- 同じ ID が複数行にある場合は、読み込み順で後の定義がメモリ上の正本になる。
- YAML から読み込む ID は前後空白だけを除去し、小文字化しない。

## 3. 実行時 Mob

定義ごとに次の実行時状態を構築する。

| 状態 | 内容 |
|:--|:--|
| テンプレート ID | `training_dummy:<id>` |
| category / level | `ENEMY` / `1` |
| 実体・表示 | 可視・通常サイズ・腕と台座ありの `ARMOR_STAND` 実体へカカシ用装備を設定する。重力と装備操作を無効化する |
| status | 最大 HP `Integer.MAX_VALUE`、定義の防御力・魔法防御、移動速度 `0.0`、ノックバック耐性 `100%` |
| shield | 定義の有効状態と最大値 |
| idle | `STATIONARY` |
| runtime flag | `nonLethal=true`、`keepWhenUnobserved=true` |

テンプレートは API / filebase の Mob キャッシュへ登録せず、定義から都度構築して `MobService` へ渡す。定義 ID と生成済み `MobInstance.instanceId` の対応はメモリだけに保持する。
