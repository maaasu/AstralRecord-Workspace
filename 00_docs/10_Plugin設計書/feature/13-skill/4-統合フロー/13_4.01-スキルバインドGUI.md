# 13_4.01 スキルバインドGUI

## 概要

プレイヤーが現在所持しているスキルを確認し、発動スキル用 8 枠へ設定するチェスト GUI。

## GUI レイアウト

54 スロットのチェスト GUI だけでスキル設定を完結させる。プレイヤーインベントリ側は
ダミーへ置き換えず、通常の所持アイテムとホットバーを表示する。ホットバー切替や BAG
ショートカットの操作は共通の `HotbarShortcutGuiHolder` / `HotbarShortcutClickSupport` を利用する。

- 上 4 行（0〜35）: 現在所持しているスキル一覧。36 スロット単位でページングする
- 5 行目（36〜44）: アクティブスキル設定 8 枠（36〜43）と保存（44）
- 最下行（45〜53）: 前ページ（45）、プリセット 1〜3（46〜48）、戻る（49）、プリセット 4〜6（50〜52）、次ページ（53）
- プリセット 7〜9 は本画面では廃止する。既存の保存データは互換のため削除せず、Plugin の通常操作では取得・選択対象にしない
- パッシブスキルは所持スキル一覧に表示するが、指定レイアウトに設定枠を設けない。既存のパッシブ設定値は保存時に保持する

## 所持スキル判定

GUI が扱う「所持スキル」は次の合算です。

- 職業スキル
- 装備本体の `skills`
- ルーン由来の `skills`
- セット効果由来の `skills`
- スキルツリー解放ノード由来の `skillIds`

スキルツリー由来の供給元:

- 解放済みノード集合は account 単位で API / DB 永続化する。未使用CP/PPは永続化せず、クラスレベル・プレイヤーレベルと解放済みノードの `pointType` / `pointCost` から算出する
- ノード定義本体は filebase `skilltree` を正本とする
- ノード座標レイアウトは `skilltree_structure.yml` をサーバローカル plugin ファイルとして管理する
- `skilltree_structure.yml` が未配置のサーバーでは、plugin 同梱の序盤用レイアウトを初回起動時に展開する
- マスタ変更により解放済みノードの必要CP/PPが現在所持量を超えた場合、解放済みノード ID の値が高い順に「解放済みだが効果停止中」として扱い、スキル一覧・ステータス反映から除外する

## スキル一覧の表示ルール

- 一覧には現在所持しているスキルだけを表示する
- 発動スキルかパッシブスキルかを各スキル情報に表示する
- パッシブスキルは `passive.bindRequired` の状態も表示する
- `passive.bindRequired: false` のパッシブスキルは、所持のみで常時発動するため一覧には表示しない

- パッシブスキルは情報表示のみとし、アクティブスキル設定枠への割当対象にしない

## バインドルール

- 発動スキルは発動スキル枠にだけ設定できる
- パッシブスキルはパッシブスキル枠にだけ設定できる
- 選択中スロットとスキル種別が一致しない場合は設定を拒否する
- スロット未選択時は、スキル種別に対応する側の空きスロットへ自動設定する

## パッシブスキルの発動ルール

- `passive.bindRequired: true`
  - 所持していて、かつパッシブ枠に設定されている時だけ発動
- `passive.bindRequired: false`
  - 所持しているだけで常時発動
  - バインド GUI の一覧には出さない

## 保存と切替

- プリセット一覧は account 単位でメモリキャッシュし、通常参照では API へ再取得しない
- Plugin が画面で扱うプリセットは 1〜6 とする
- プリセット保存に成功した場合は、保存済みプリセットでキャッシュを更新する
- プリセット保存時にパッシブスキルの有効状態を即時再計算する
- プリセット切替時も同様に即時再計算する
- 未所持スキルが古いプリセットに残っていても発動しない

## 2026-06 skilltree UI 補足

- SkillTree ノードの詳細は、浮遊ノードラベルを読むだけで把握できる状態にする。
- SkillTree 操作用にプレイヤーのホットバーを流用しない。
- スキルツリーへの移動は `/skilltree` を使用する。入口用 NPC を置く場合も同じ `/skilltree` を呼び出す導線に統一する。
- スキルツリーからの復帰は `/skilltree back` を使用する。
- 帰還用 NPC を置く場合も同じ `/skilltree back` を呼び出す導線に統一する。
- ノードの解放・解除は、注視中ノードへの左クリック・右クリックで行う。
