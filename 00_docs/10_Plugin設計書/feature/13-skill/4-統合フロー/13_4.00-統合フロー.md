# 13_4.00-統合フロー

## 1. 起動時ロード

1. Plugin 起動処理が `SkillRegistry` に実行クラスを登録する
2. `AstralRecord` が `SkillService` を生成し、非同期で API 定義を取得して `implementationId` と実行クラスの対応を検証する
3. 検証成功分を immutable snapshot として完成させる
4. メインスレッドへ戻してレジストリ参照を一括交換する
5. レジストリ交換完了後に skilltree の名称・説明・表示アイテム cache を再構築する

## 2. プレイヤー発動

1. コマンド / GUI / ショートカットが `skillId` を決定する
2. `SkillService.canCast` が MP・レベル・cooldown を確認する
3. `SkillService.castSkill` が `SkillCastContext` を構築する
4. `SkillRegistry.getExecutor(implementationId)` で個別ロジックを解決する
5. 実行成功後に共通 MP 消費と cooldown を適用する

## 3. Mob 発動

1. 共通制御層は `SkillCaster` 抽象で Mob へ拡張できる構造を持つ
2. ただし Mob 用 `SkillCaster` 実装と AI からの接続は未実装
3. Mob 発動の実装時はプレイヤー発動と同じ `SkillService.castSkill` 経路へ接続する
