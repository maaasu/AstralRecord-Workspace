## 3. 例外方針

- definition 1 件の executor / params 不正は `W_5801` で除外し、他 definition を有効化する。
- executor 例外は `E_5802` を記録して失敗 result とし、Bukkit scheduler へ伝播させない。
- skill bind GUI の click / drag / close 例外は `E_5601`、action ring quit と active skill lifecycle の quit / death / world 例外は operation 別 context 付き `E_3002` を使用し、skill executor 用 `E_5802` へ GUI / event context を渡さない。
- preset I/O は非同期で行い、callback は session generation と online state を確認する。
- active skill の scheduled task と temporary modifier は quit / death / world 変更 / plugin stop で破棄する。

## 4. TPS 運用

- executor ごとに独自 scheduler、Mob 全件探索、damage 経路を複製しない。
- target 検索は共通 service の range / line-of-sight / world / alive filter を利用する。
- repeat task は caster scope を付け、終了条件と cancel 経路を必ず定義する。
- particle 数は player setting の density scale と表示距離を尊重する。
