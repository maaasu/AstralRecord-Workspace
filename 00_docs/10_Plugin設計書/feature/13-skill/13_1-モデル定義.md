# 13_1-モデル定義

## 1. skill definition

物理名: `SkillDefinition`

| 項目 | 内容 |
|---|---|
| `id` | definition の一意 ID |
| `implementationId` | `SkillExecutor` 解決 key |
| `name`, `description`, `icon`, `lore`, `tags` | 表示・分類情報 |
| `cooldownTicks`, `castTimeTicks`, `requiredLevel` | 共通 cast 制御値 |
| `manaCost` | legacy MP cost。新規定義は resource 項目を使う |
| `onCastSound` | 共通発動 sound |
| `params` | executor 固有 `Map<String, Any>` |
| `kind` | `SkillKind.ACTIVE` / `PASSIVE` |
| `passiveBindRequired` | passive slot への bind が有効化条件か |
| `resourceType` | `SkillResourceType.MANA` / `ENERGY` / `NONE` |
| `resourceCost` | 共通 resource 消費量 |

## 2. skill summary

物理名: `SkillSummary`

一覧 API の ID、表示名、implementation ID、icon、tags などを保持する。`SkillRepository.findAll` は summary を返し、`SkillService.loadDefinitions` が ID ごとに詳細を取得する。

## 3. caster

物理名: `SkillCaster`、`PlayerSkillCaster`、`MobSkillCaster`

| 契約 | player | Mob |
|---|---|---|
| `casterId()` | Bukkit player UUID | `MobInstance.instanceId` |
| `level()` | 現行は `Integer.MAX_VALUE` | `Integer.MAX_VALUE` |
| `statusSnapshot()` | player snapshot | 空 snapshot |
| `currentMana()` / `currentEnergy()` | player 現在値 | `Double.MAX_VALUE` |
| `consumeMana()` / `consumeEnergy()` | player snapshot を減算 | no-op |
| `notify()` | player message | no-op |

`level()` は primitive `int` であり nullable ではない。両 caster とも現状は要求レベル検証を実質スキップする。player 側の正式な level 選択は [[13_9-未決事項]] とする。

## 4. cast context / trigger / result

物理名: `SkillCastContext`、`SkillCastTrigger`、`SkillCastResult`

context は definition、caster、trigger と発動時情報を executor へ渡す。trigger は player input、Mob AI など発動元を区別する。result は成功、必要レベル不足、resource 不足、cooldown、casting 中、definition / executor 不在、executor 失敗を表す。

## 5. executor

物理名: `SkillExecutor`

`implementationId()` と `execute(context)` を基本契約とし、passive 実装は params 検証、tick 要否・interval、tick callback、status modifier を提供する。active 実装は共通の targeting、combat、movement、projectile、effect、task service を再利用する。

## 6. bind preset

物理名: `SkillBindPreset`

account ID、preset index、active 8 slot、passive 8 slot、unlock / saved flag、version を保持する。両 slot 配列は常に 8 要素へ正規化し、空値を `null` とする。GUI は preset 1..6 を表示する。

## 7. bind session / holder

物理名: `SkillBindSession`、`SkillBindInventoryHolder`、`SkillBindScreen`、`SkillBindType`

session は 6 preset、選択 preset、active / passive draft、dirty、選択中 bind slot を保持する。holder は `MAIN` / `CONFIRM`、preset、page、確認 action を保持する。現行 GUI が編集するのは active slot だけで、passive draft は保存時に既存値を維持する。

## 8. registry

物理名: `SkillRegistry`

definition ID と executor implementation ID の map を保持する。executor の重複登録は後勝ちにせず拒否し、definition 一括置換時は executor 不在・不正 definition を除外する。

## 9. params reader

物理名: `SkillParamReader`

必須文字列、数値、参照 ID を型安全に読み、不正値は `SkillParameterException` とする。参照値は `type:id` から suffix ID を取り出す。
