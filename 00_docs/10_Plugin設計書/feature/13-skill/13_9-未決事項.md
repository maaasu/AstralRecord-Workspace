# 13_9-未決事項

## 1. player の required level 正本

`PlayerSkillCaster.level()` は現在 `Integer.MAX_VALUE` を返す。account level、class level、別の進行度のどれをrequired levelへ使うかは本改修の対象外とする。

## 2. 不要ジェムの追加用途

同一スキル個体の所持数に上限を設けないため、ジェムは常に新規習得へ使える。分解・交換などの追加用途は将来拡張として保留し、現時点では実装しない。

## 3. params / ロジック変更シジルの静的検証

status型シジルは共通加算処理を行う。ロジック変更型はexecutorがシジルIDを判定するため、相互矛盾は個別スキル実装とAIレビューで検出する。全implementationを横断する機械的競合解決は導入しない。

## 4. definition reload 中の継続状態

runtime reload時の既存cooldown、詠唱session、passive effectの引継ぎ方針と管理者操作面は別途決定する。

## 5. executor catalog の登録方式

現行はbuilt-in catalogの明示登録と重複禁止を採用する。class path自動探索や外部拡張APIは将来検討とする。
