# 13_3.04-リポジトリ

## 1. skill 一覧取得

クラス名: `SkillRepository`
物理名: `findAll`

`GET /api/skill` の `200` を `List<SkillSummary>` へ変換する。その他 status は `E_5801` を記録して例外化する。

## 2. skill 詳細取得

クラス名: `SkillRepository`
物理名: `findById`

`GET /api/skill/{skillId}` の `200` を `SkillDefinition` へ変換し、`404` は `W_5800` と `null`、その他 status は `E_5800` と例外にする。成功時は `D_5800` を記録する。

## 3. API definition 変換

クラス名: `SkillRepository`
物理名: `toDefinition`

表示項目、implementation ID、kind、passive bind 要否、cooldown、cast time、required level、resource type / cost、legacy mana cost、sound、params、tags を Plugin model へ正規化する。参照 prefix は必要な項目で suffix ID を保持する。

## 4. bind preset 一覧取得

クラス名: `SkillBindPresetRepository`
物理名: `findByAccountId`

`GET /api/skill-bind-presets?account_id={accountId}` の `200` 配列を preset へ変換する。異常 status は `E_5803` と `IOException`、interrupt は flag を復元して伝播する。

## 5. bind preset 保存

クラス名: `SkillBindPresetRepository`
物理名: `save`

`PUT /api/skill-bind-presets/{accountId}/{presetIndex}` へ active / passive 各 8 slot と更新者を送る。空 slot は JSON `null` とし、`200` の version 付き preset を返す。異常 status は `E_5804` とする。
