# 13_3-GUI・View

## 1. スキルマネージャー

クラス名: `SkillBindGui`
物理名: `open`

旧スキル設定画面の名称と機能を「スキルマネージャー」に統一する。54 slot GUI の配置は次のとおり。

| slot | 内容 |
|---:|---|
| 0 | 武器タグから解決する通常攻撃 |
| 1..26 | 習得済みスキル個体一覧（26件 / page） |
| 27..35 | パッシブスキルスロット1..9 |
| 37 | 左クリックバインド |
| 39..44 | action ringスロット1..6 |
| 45 | 前ページ |
| 46..48 | プリセット1..3 |
| 49 | 前画面へ戻る（直開き時は閉じる） |
| 50..52 | プリセット4..6 |
| 53 | 次ページ |

一覧の各項目は日本語マスター名と、最大レベル未満では `Lv.<現在>/<最大>`、最大レベル到達時は `&c&lmax`（赤色太字）、解決済みレベル・シジル補正を展開した説明、効果lore、消費リソース、クールダウン、タグ、種別、使用可否、シジル合成枠をセクション区切り線で分けて表示する。説明・効果loreの `{skill.<param>}` は `LearnedSkillResolver` 後の `params` を使い、倍率・範囲・最大対象数・命中順配列などの表示値を発動時と同じ計算結果へ揃える。展開されたプレースホルダー値は黄色で表示し、数値は小数第2位を四捨五入して小数第1位まで（末尾の0は除去）に整形する。旧 lore にある消費・クールダウンの一行表記は重複表示しない。タグはタグIDを表示せず、共有タグカタログに対応する日本語名（例: `lightning`→`雷`）を表示するが、種別と重複する `active` / `passive` はタグ欄から除く。シジル合成枠は空き・装着済みをスロットごとに表示し、装着済みシジルは表示名、ステータス補正、ロジック変更型シジルのitem loreまで表示する。個体IDは画面へ表示せず、PDCの `learnedSkillId` だけで内部識別する。使用可否は常に `現在のクラス／スキルツリーで使用可能` または `現在のクラス／スキルツリーでは使用不可` と表示する。後者は一覧の後ろへ並べ、アイコンを薄灰色の羊毛にする。左クリックは種別に合う空きバインド枠へ自動設定し、右クリックは合成画面を開く操作として別行で案内する。選択済み枠への優先設定は操作結果として扱い、説明文には表示しない。通常攻撃も予約バインドIDを PDC へ持ち、ジェム所持やスキル所有を要求しない。

選択中バインド枠がない場合は常時発動passiveを除く全習得個体を表示する。active / left-click枠を選択した場合はactiveだけ、passive枠なら `passiveBindRequired=true` のpassiveだけを表示する。常時発動passiveは設定候補へ表示しない。空の action / passive 枠は枠番号を item amount で示し、無効な passive 枠は鉄格子で表示する。無効枠の既存設定は解除だけを許可する。

設定済みのアクション・左クリック・パッシブ枠も、枠の状態と解除操作に加えて、一覧と同じ説明、消費リソース、クールダウン、タグ、種別、使用可否、シジル合成枠を表示する。使用不可の場合は一覧と同じ薄灰色の羊毛アイコンを表示する。

## 2. 合成画面

クラス名: `SkillBindGui`
物理名: `openSynthesis`

選択した習得済み個体をslot 20、インベントリから選んだ同スキルジェムまたは対応シジルをslot 22、合成後プレビューをslot 24へ表示する。素材未選択のslot 24はスキル結果を表示せず「素材をセットしてください」のプレースホルダーにする。プレビューはネザースターの汎用表示ではなく対象スキルのアイコン・名称・合成後に解決した説明を使い、スキル名のレベル表記は一覧と同じく、最大レベル到達時は `&c&lmax`（赤色太字）へ置き換える。ジェムではレベル変化、シジルでは装着先スロット・名称・`効果:` のステータス補正・`説明:` の固有効果、さらに合成後の全シジル枠を表示する。slot 24をクリックした時点で消費・合成し、追加確認画面は出さない。合成画面も footer の slot 49 だけをスキルマネージャーへ戻る専用操作に使い、共通戻るボタンとは別の文言を持たせる。

選択中の素材は消費確定まで永続インベントリを変更せず、表示上だけ一個を予約する。stack は残数を表示し、単品を予約して生じた BAG の隙間は通常の前詰め規則で画面上だけ詰める。slot 22 をクリックすると予約を解除できる。戻る・close・キャンセル・mutation失敗では元の表示へ復元し、成功時だけ API 正本の再同期結果を表示する。素材名・シジル名・説明・lore は共通表示 API 経由でカラーコードを Component 化し、シジルの StatusType は日本語名と suffix で表示する。シジルアイテム単体の lore にも、実際のステータス補正または固有効果を表示する。

最大レベル未満なら同スキルジェム、空きシジル枠があれば許可シジルを選択できる。非許可シジル、空き枠なし、同一系統のシジルは `P_5859` などの理由別メッセージを表示して選択・消費・合成 mutation を行わず、slot 24 にはバリアで理由と「素材は消費されません」を表示する。最大レベルならジェムを選べず、全シジル枠が埋まっていればシジルを選べない。どちらの操作もない個体は合成画面を開かない。

## 3. ジェム習得確認

クラス名: `SkillGemLearnEventHandler`、`ConfirmDialogView`

プレイヤーインベントリ上のスキルジェムを左クリックすると、色変換済みの短いスキル名と「ジェムを1個消費する」を複数行で表示する。同じskill IDを所持済みの場合も上書き・レベルアップせず別個体を作るが、確認GUIのタイトルを赤文字の「このスキルの習得は非推奨です。」へ変更し、すでに習得済みであることを表示する。確定ボタンの説明にも赤文字で、習得ではなく合成への使用を推奨する旨を表示する。表示開始時と習得成功時にはそれぞれ確認・習得サウンドを鳴らす。確認ダイアログ上部は操作対象外とし、下部プレイヤーインベントリは共通ホットバー／インベントリ操作を利用できる。キャンセル・画面closeではアイテムを維持する。右クリックは画面を開かない。

## 4. パッシブ超過枠

現在有効枠数を超える保存済みパッシブ枠は無効表示とする。設定済み値は自動削除せず、手動解除を許可する。無効枠への新規設定は拒否する。

## 5. 識別とページング

専用 holder とPDCの習得個体UUIDで操作対象を識別する。ページは循環せず、slot 45 で前、slot 53 で次へ移動する。バインド枠選択、プリセット切替、その他のメイン画面再描画では、再描画前のページを引き継ぐ。選択種別の絞り込みなどでそのページが存在しなくなった場合だけ、最後に存在するページへ補正する。プリセット切替確認画面も遷移元ページを保持する。プリセットはslot 46..48・50..52へ1..6の順で配置する。通常攻撃は1ページ目のslot 0だけに表示し、2ページ目以降には表示しない。メイン画面のslot 49は共通の太字「戻る」アイテムを使う。

## 6. マスター表示の共通化

`SkillPresentationUtil` を skill GUI / View のマスター表示用 API とし、`ItemModel` と `SkillDefinition` の name / description / lore をこの API で Component 化する。スキルタグは共有タグカタログから生成された `MasterTagIds` の表示名を使い、raw tag IDをGUIへ出さない。カラーコードの正規化は `ColorCodeUtil` だけが担い、GUI / View は raw master 文字列を `Component`、`displayName`、`lore` へ直接渡さない。リソース検査はこの禁止経路を `feature/skill/gui` と `feature/skill/view` の本番ソースで検出する。

## 7. スキルツリーノード解除確認GUI

解放済みノードの右クリック解除前に、100ゴールド消費を明示した確認GUIを表示する。確認省略設定はスキルツリーワールド離脱またはquitまでの一時状態とする。

## 8. スキル忘却 GUI

クラス名: `SkillForgetGui`、`SkillForgetGuiEventHandler`

NPC の `SKILL_FORGET` アクションからだけ開く、54 slot・45件/ページの一覧 GUI を提供する。メニューや共通戻る導線は持たず、所持中の習得済みスキル個体を表示する。一覧のスキルをクリックすると `ConfirmDialogView` に遷移し、確認画面の「一覧へ戻る」で元ページへ戻る。

- 「はい、忘却する」はスキル個体と装着中のシジルを削除するが、スキルジェム・シジルは返却しない。
- 「忘却の代償を払う」は100アストラルドを消費し、忘却したスキルのジェムを1個だけ返却する。個体のレベル差分や装着中のシジルは返却しない。
- 忘却した個体UUIDが既存バインドに残っている場合、バインドは自動削除しない。バインドGUIとアクションリングでは「未習得スキル」として表示し、発動時は未習得エラーを通知する。バインド解除操作を行った時点で空スロットになる。
