# 13_3-GUI・View

## 1. スキルマネージャー

クラス名: `SkillBindGui`
物理名: `open`

旧スキル設定画面の名称と機能を「スキルマネージャー」に統一する。54 slot GUI の配置は次のとおり。

| slot | 内容 |
|---:|---|
| 0 | 武器タグから解決する通常攻撃 |
| 1..26 | 習得済みスキル個体一覧（26件 / page） |
| 27..35 | パッシブスキルスロット1..9 |
| 37 | 左クリックバインド |
| 39..44 | action ringスロット1..6 |
| 45 | 前ページ |
| 46..48 | プリセット1..3 |
| 49 | 前画面へ戻る（直開き時は閉じる） |
| 50..52 | プリセット4..6 |
| 53 | 次ページ |

一覧の各項目は日本語マスター名と `Lv.<現在>/<最大>`、説明、効果lore、消費リソース、クールダウン、タグ、種別、使用可否、シジル合成枠をセクション区切り線で分けて表示する。旧 lore にある消費・クールダウンの一行表記は重複表示しない。タグはタグIDを表示せず、共有タグカタログに対応する日本語名（例: `lightning`→`雷`）を表示するが、種別と重複する `active` / `passive` はタグ欄から除く。シジル合成枠は空き・装着済みをスロットごとに表示し、装着済みシジルは表示名、ステータス補正、ロジック変更型シジルのitem loreまで表示する。個体IDは画面へ表示せず、PDCの `learnedSkillId` だけで内部識別する。使用可否は常に `現在のクラス／スキルツリーで使用可能` または `現在のクラス／スキルツリーでは使用不可` と表示する。後者は一覧の後ろへ並べ、アイコンを薄灰色の羊毛にする。左クリックは種別に合う空きバインド枠へ自動設定し、右クリックは合成画面を開く操作として別行で案内する。選択済み枠への優先設定は操作結果として扱い、説明文には表示しない。通常攻撃も予約バインドIDを PDC へ持ち、ジェム所持やスキル所有を要求しない。

選択中バインド枠がない場合は常時発動passiveを除く全習得個体を表示する。active / left-click枠を選択した場合はactiveだけ、passive枠なら `passiveBindRequired=true` のpassiveだけを表示する。常時発動passiveは設定候補へ表示しない。空の action / passive 枠は枠番号を item amount で示し、無効な passive 枠は鉄格子で表示する。無効枠の既存設定は解除だけを許可する。

## 2. 合成画面

クラス名: `SkillBindGui`
物理名: `openSynthesis`

選択した習得済み個体をslot 20、インベントリから選んだ同スキルジェムまたは対応シジルをslot 22、合成後プレビューをslot 24へ表示する。プレビューはネザースターの汎用表示ではなく対象スキルのアイコン・名称・説明を使い、ジェムではレベル変化、シジルでは装着先スロット・名称・ステータス補正・説明、さらに合成後の全シジル枠を表示する。slot 24をクリックした時点で消費・合成し、追加確認画面は出さない。合成画面も footer の slot 49 だけをスキルマネージャーへ戻る専用操作に使い、共通戻るボタンとは別の文言を持たせる。

選択中の素材は消費確定までプレイヤーインベントリから一時的に隠すだけである。戻る・close・キャンセル・mutation失敗では元の表示へ復元し、成功時だけ API 正本の再同期結果を表示する。素材名・シジル名・説明・lore は共通表示 API 経由でカラーコードを Component 化し、シジルの StatusType は日本語名と suffix で表示する。

最大レベル未満なら同スキルジェム、空きシジル枠があれば許可シジルを選択できる。非許可シジルは `P_5859` を表示して選択状態にせず、合成 mutation も開始しない。最大レベルならジェムを選べず、全シジル枠が埋まっていればシジルを選べない。どちらの操作もない個体は合成画面を開かない。

## 3. ジェム習得確認

クラス名: `SkillGemLearnEventHandler`、`ConfirmDialogView`

プレイヤーインベントリ上のスキルジェムを左クリックすると、色変換済みの短いスキル名と「ジェムを1個消費する」を複数行で表示する。同じskill IDを所持済みなら、上書き・レベルアップせず別個体を作る旨も表示する。表示開始時と習得成功時にはそれぞれ確認・習得サウンドを鳴らす。確認ダイアログ上部は操作対象外とし、下部プレイヤーインベントリは共通ホットバー／インベントリ操作を利用できる。キャンセル・画面closeではアイテムを維持する。右クリックは画面を開かない。

## 4. パッシブ超過枠

現在有効枠数を超える保存済みパッシブ枠は無効表示とする。設定済み値は自動削除せず、手動解除を許可する。無効枠への新規設定は拒否する。

## 5. 識別とページング

専用 holder とPDCの習得個体UUIDで操作対象を識別する。ページは循環せず、slot 45 で前、slot 53 で次へ移動する。プリセットはslot 46..48・50..52へ1..6の順で配置する。メイン画面のslot 49は共通の太字「戻る」アイテムを使う。

## 6. マスター表示の共通化

`SkillPresentationUtil` を skill GUI / View のマスター表示用 API とし、`ItemModel` と `SkillDefinition` の name / description / lore をこの API で Component 化する。スキルタグは共有タグカタログから生成された `MasterTagIds` の表示名を使い、raw tag IDをGUIへ出さない。カラーコードの正規化は `ColorCodeUtil` だけが担い、GUI / View は raw master 文字列を `Component`、`displayName`、`lore` へ直接渡さない。リソース検査はこの禁止経路を `feature/skill/gui` と `feature/skill/view` の本番ソースで検出する。

## 7. スキルツリーノード解除確認GUI

解放済みノードの右クリック解除前に、100ゴールド消費を明示した確認GUIを表示する。確認省略設定はスキルツリーワールド離脱またはquitまでの一時状態とする。
