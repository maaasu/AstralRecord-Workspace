# 13_3-モデル操作

## 必須文字列取得
クラス名: `SkillParamReader`
物理名: `requireString`

1. `params[key]` を取得する
2. 値が文字列であることを検証する
3. 未定義または型不一致時は `SkillParameterException` を送出する

## 数値取得
クラス名: `SkillParamReader`
物理名: `getDouble`

1. `params[key]` を取得する
2. `Number` 系であれば `double` へ変換する
3. 未定義時は `defaultValue` を返す

## 参照値取得
クラス名: `SkillParamReader`
物理名: `getRefId`

1. `params[key]` を文字列として取得する
2. `prefix` 付き参照値であることを検証する
3. `skill:` や `buff:` の prefix を除去した素の ID を返す

## `params` 検証
クラス名: `SkillExecutor`
物理名: `validateParams`

1. 実装ごとに必要キーと型を検証する
2. 検証失敗時は `skillId` と不足キーを含めて例外化する
3. 共通スキーマの更新は行わず、実装契約の範囲で完結させる

## パッシブ tick 要否判定
クラス名: `SkillExecutor`
物理名: `requiresPassiveTick`

1. 定期 tick 処理が必要なパッシブ executor だけ `true` を返す
2. ステータス補正のみのパッシブ executor は既定値 `false` のままにする
3. `false` の executor は `PassiveSkillService.tick` から毎 tick 呼び出さない

## パッシブ tick 間隔取得
クラス名: `SkillExecutor`
物理名: `passiveTickIntervalTicks`

1. `requiresPassiveTick` が `true` の場合だけ参照する
2. 1 未満の値は呼び出し側で 1 tick として扱う
3. 定期処理が不要な executor では既定値のままにする

## パッシブ定期処理
クラス名: `SkillExecutor`
物理名: `onTick`

1. `requiresPassiveTick` が `true` の有効パッシブだけを対象にする
2. `passiveTickIntervalTicks` で指定された間隔に到達した時だけ呼び出す
3. ステータス補正のみのパッシブはステータス再計算時に `passiveStatusModifiers` で反映し、定期処理では呼び出さない
