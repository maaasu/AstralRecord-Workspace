# 13_3.06-レジストリ・キャッシュ

## 実行クラス登録
クラス名: `SkillRegistry`
物理名: `registerExecutor`

1. `SkillExecutor.implementationId()` をキーとして登録する
2. 同一キーが既に存在する場合は起動失敗ではなく既存登録を維持（後勝ち禁止）し、以下ログを記録する

    | 項目 | 内容 |
    |---|---|
    | ID | LogId.W_5802 |
    | レベル | Warning |
    | テンプレート | 実行クラスが既に登録されています（後勝ち禁止）: implementationId=%s |
    | 出力条件 | `registerExecutor` に同一 `implementationId` を再登録した時 |
    | 引数 | implementationId |

## 実行クラス解決
クラス名: `SkillRegistry`
物理名: `getExecutor`

1. `implementationId` をキーに `executors` から取得する
2. 未登録時は `null` を返す

## スキル定義反映
クラス名: `SkillRegistry`
物理名: `replaceDefinitions`

1. `skillId` をキーにした変更不可の新しい `definitionsById` を構築する
2. `volatile` 参照を一括置換して、読み取り側へ完成済み snapshot だけを安全公開する
3. 更新後件数を以下ログで出力する

    | 項目 | 内容 |
    |---|---|
    | ID | LogId.I_5800 |
    | レベル | Information |
    | テンプレート | スキル定義を読み込みました: count=%s |
    | 出力条件 | 定義一括反映成功時 |
    | 引数 | 反映件数 |

## スキル定義解決
クラス名: `SkillRegistry`
物理名: `getDefinition`

1. `skillId` で `definitionsById` を参照する
2. 未登録時は呼び出し元へ未定義扱いを返す
