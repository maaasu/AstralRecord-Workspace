# 13_3-パラディン

## 1. 対象と発動

パラディンの6つの発動スキルはツリーで使用許可を得て、共通スキルマネージャーで習得・バインドする。数値・成長・素材・コストはfilebaseの `paladin_*` 定義を正本とする。個別executorは成功時だけ共通のコスト・クールダウンを開始する。

攻撃は近接・無属性、足元同士の高低差heightを対象数制限の前に判定し、視線を中心とする120度の扇形で、遮蔽越しのMob、NPC、死亡済みMob、別world、プレイヤーを含めない。支援は自分と現在同一パーティーの生存プレイヤーだけを円柱範囲と目線間の遮蔽で判定する。未所属では自分だけを対象とする。

## 2. 防御低下

アナテマは命中判定成功後に聖痕を付ける。防御による完全ブロックでも付与でき、回避時は付与しない。聖痕は全防御と攻撃種別防御の合計へ適用し、攻撃者ごとの防御貫通とは乗算する。元のMobマスタ・ステータスは変えない。味方を含む後続の攻撃へ適用する。

同じ低下率は期限を延長し、異なる低下率は各々期限を持つ。重複加算せず有効な最大低下率のみ採用する。強い聖痕の失効後は、まだ有効な弱い聖痕へ戻る。入力は有限な0超～50%で、失効後の防御倍率は1となる。ラストジャッジメントは有効な聖痕がある対象だけ倍率を増加する。

## 3. 時限シールドと聖歌

ヴェスパーは `wardBase + MAX_SHIELD × shieldRatio + SUPPORT_POWER × supportRatio` の時限シールドを付与する。通常のタンクシールド・有効化パッシブとは独立し、非タンクにも機能する。通常シールドの判定後に残ったHPダメージを残量まで吸収し、超過分だけHPへ通す。固定HPダメージも通常HP成分の後に吸収する。吸収分はシールド被弾数値として表示し、通常シールドの破壊・再充填は誘発しない。

時限シールドは加算せず、現在残量以上の付与で置換する。弱い付与は現在量や期限を変更しない。無効値・0以下・非有限値は付与しない。残量0、期限切れ、死亡・退出・world移動で破棄する。未参照の期限切れ状態も毎秒の保守で除去する。

聖歌は現存する時限シールドへ与ダメージ倍率を付ける。未付与の対象は支援できず、有効対象0なら発動失敗とする。聖歌は時限シールドの消費・破壊・失効・置換で終了し、再付与しても復活しない。倍率は重複せず、有効中の強い聖歌を弱い聖歌で上書きしない。持続は元シールドの期限を超えない。

## 4. 葬送と聖域

レクイエムは有効な扇形対象がある場合に限り、自分の現在時限シールドを全量消費する。通常シールドや味方の防護を消費しない。攻撃倍率は `damageRatio + min(bonusRatioCap, 実消費量 / wardPerRatio)`。対象0、または防護0なら失敗し、コスト・クールダウンを消費しない。攻撃が回避されても、発動済みの防護は戻さない。

ブラックサンクタムは周囲のMobを発動時に挑発し、一定時間自身の被ダメージ・与ダメージを同時に下げ、ノックバックを無効化する。通常シールドは最大量に対する指定率を既存回復規則で回復する。シールド有効化パッシブを持たない対象へ通常シールドを作らない。

## 5. 表示・運用

パーティクルは共通定義の金色の聖痕、白い光の聖柩、魂の炎の葬送を使う。発動時の魔法陣は24点の単発表示とし、毎tickの範囲探索・継続表示は行わない。入力範囲と整数tickを登録時に検証する。時限効果はゲームスレッドのセッション内状態で、APIやDBへ永続化しない。

ビルドの取得順・装備・成長根拠は [[05-パラディン]] を参照する。
