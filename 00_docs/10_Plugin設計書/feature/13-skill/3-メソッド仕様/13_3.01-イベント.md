# 13_3.01-イベント

## 1. bind GUI 表示・操作

クラス名: `SkillBindGuiEventHandler`
物理名: `open`, `onInventoryClick`, `onInventoryDrag`, `onInventoryClose`

- `open` は preset load 完了を確認し、選択 preset の session を作って GUI を開く。未 load 時は `P_5848` を通知する。
- click は hotbar shortcut、skill 一覧、active slot、save、preset 1..6、page、back、confirm を処理する。drag は常に cancel する。
- dirty な main GUI を close / back / preset switch する場合は破棄確認を開く。
- save 完了後は passive skill を再調停し、同じ session / snapshot の場合だけ GUI を更新する。
- GUI 終了時は inventory feature に player inventory の再描画を委譲する。
- click / drag / close の例外は shared GUI `E_5601` へ `player` と `skill_bind_<operation>` を渡し、Bukkit event loop へ送出しない。

## 2. action ring 入力解決

クラス名: `SkillActionRingEventHandler`
物理名: `resolve`, `onPlayerQuit`

player-interaction から HOTBAR / swap 等の入力 context を受け、action ring の開始・slot 選択・発動候補を返す。winner executor だけが ring state 変更または `SkillService.castSkill` を実行する。quit 時は player の ring session を破棄し、例外は shared event `E_3002` へ `skill_action_ring_quit:<player>` を context として渡す。

## 3. active skill lifecycle

クラス名: `ActiveSkillLifecycleEventHandler`
物理名: `onPlayerQuit`, `onPlayerDeath`, `onPlayerChangedWorld`

- quit / death は player の詠唱、cooldown を含む一時 skill state、scheduled task、temporary modifier を全消去する。
- world 変更は継続不能な詠唱・task・temporary effect を解除し、lifecycle service の方針に従って transient state を掃除する。
- 各 handler の例外は shared event `E_3002` へ `active_skill_quit:<player>`、`active_skill_death:<player>`、`active_skill_world:<player>` の context を渡す。
