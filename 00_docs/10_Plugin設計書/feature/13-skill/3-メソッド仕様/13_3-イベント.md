# 13_3-イベント

## 1. スキルマネージャー表示・操作

クラス名: `SkillBindGuiEventHandler`

`open` は習得個体と6プリセットのロード完了を確認してセッションを作る。メイン画面では一覧、passive 9枠、left-click、action 6枠、slot 0 の通常攻撃、プリセット、前後ページ、slot 49 の戻る／直開きcloseを処理する。

一覧の左クリックは選択済みで有効な種別適合バインド枠へだけ対象個体UUIDを設定し、即時保存する。選択枠なしの左クリックは合成を開かず、先にバインド先を選択する案内を表示する。右クリックだけが合成画面を開く。許可のない所持個体も設定できるが、発動時には未所持 (`P_5809`) と使用許可なし (`P_5863`) を分けて拒否する。パッシブ枠は一覧クリック直前と保存直前にも現在の有効枠数を再検証し、超過枠では既存バインドの維持・解除だけを許可する。

合成画面ではプレイヤーインベントリの対象ジェムまたはシジルを一つ選び、選択表示だけを一時的に隠して結果slotのクリックでAPI mutationを開始する。成功後は習得個体・インベントリ・パッシブ状態を更新し、通常収納と同じ前詰め規則で後続 entry を移動して、最大レベル・空き枠に応じて合成画面またはメインへ戻る。戻る・close・失敗時、およびコマンドなどによるスキルマネージャーの開き直し時には未消費素材を表示へ復元する。非許可シジル、空き枠なし、同一 `equipGroupId` はそれぞれ固有の player message を表示する。

dragは常にcancelし、保存中の二重操作を拒否する。非同期callbackはplayer online、session、account generationを再確認する。

## 2. スキルジェム習得

クラス名: `SkillGemLearnEventHandler`

通常インベントリのスキルジェム左クリックをcancelして確認GUIを開く。右クリックはcancelだけ行い、それ以外の動作をしない。確定時はentry UUIDを指定してAPIでジェムを1個消費し、Lv.1の新規習得個体を作る。既存個体へのレベルアップは行わない。習得・プリセット保存・合成の操作トークンはプレイヤー世代ごとに管理し、ログアウト時にGUIセッションとともに破棄する。古いcallbackは再ログイン後の新しい操作状態を解除しない。

成功時は習得キャッシュとインベントリGUIを即時更新する。失敗時は永続状態を再ロードし、消費されていない旨を通知する。キャンセル・closeではmutationを呼ばない。

## 3. action ring入力解決

クラス名: `SkillActionRingEventHandler`、`SkillActionRingService`

プリセットのバインド値を `learnedSkillId` として解決し、該当個体のレベル・シジル・使用許可・共有cooldownを表示と発動の両方へ使う。バインドが残っていても許可を失った個体は発動せず、`P_5863` でスキル名を通知する。

## 4. active skill lifecycle

world changeは詠唱・移動task・temporary effectを破棄しcooldownを維持する。death / quitはcooldownを含む全一時skill stateを破棄する。

## 5. 例外処理

GUI click / drag / close の例外は `E_5601`、action ringとactive lifecycleは `E_3002` へ操作context付きで記録し、Bukkit event loopへ再送出しない。
