# 13_3-イベント

## 1. スキルマネージャー表示・操作

クラス名: `SkillBindGuiEventHandler`

スキルマネージャーの表示・操作と下段設定の再描画は `AccountMode.PLAYER` の場合だけ実行する。`ADMIN` では `open` を `false` と `GuiSound.DENY` で拒否する。開いた後に `ADMIN` へ切り替えた場合はクリック操作を拒否して閉じ、保存待ちや未保存確認の再表示も行わない。共通オーバーレイ描画も同じモード境界を守り、管理者インベントリを設定アイコンで上書きしない。

習得・レベルアップ・保存などの非同期完了でも現在の `PLAYER` モードを再検証する。`ADMIN` へ切り替えた後はメイン・詳細・合成画面を再表示しない。開始時に確定した素材消費・習得個体更新の保存とACKは継続する。

シジル用オーブの子GUIも開始・クリック・保存待ちの再表示を `PLAYER` に限定する。`ADMIN` では保持中のオーブ・素材を新たに消費せず、GUIを閉じる。設定GUIとシジル子GUIの遅延遷移は `InventoryOpenEvent` でもモードを再検証し、予約後にモードが変わった場合は表示をキャンセルする。確定済みの保存・補償処理と表示予約解除は継続する。

スキル忘却GUIも開始・クリック・非同期完了後の一覧表示と遅延遷移を `PLAYER` に限定する。確認画面を開いた後に `ADMIN` へ切り替えた場合は忘却を拒否して閉じ、習得個体の削除、代償100 Astraldの消費、補填素材の付与を新たに開始しない。

`open` は習得個体と9プリセットのロード完了を確認してセッションを作る。未完了なら画面を開かず `false` と `GuiSound.DENY` を返し、完了してメイン画面を開いた場合だけ `true` を返す。上段GUIはslot 0..44の5行にスキル一覧を表示し、最下段のslot 45／49／53で前ページ／戻る（直開き時close）／次ページを処理する。下段インベントリではpassive・action各12枠の横スクロール、left-click、右上の通常攻撃STICK、hotbarのプリセットを操作する。

GUI 操作では、ページ移動に `GuiSound.PAGE`、通常攻撃設定・戻るに `GuiSound.SELECT`、シジル操作成功に `GuiSound.UPGRADE`、確認画面の表示と確定に `GuiSound.CONFIRM` を再生する。拒否操作は `GuiSound.DENY` を再生する。`GuiSessionTransitionService` が session token を次 tick に照合し、成功した画面遷移では source の `CLOSE` と feature 固有 cleanup を実行しない。未保存変更のある MAIN 画面を手動 close した場合も、`InventoryCloseEvent` 内で破棄確認画面への shared continuation を登録するため、確認画面表示まで `CLOSE`、navigation 履歴消去、SkillBind cleanup を実行しない。確認の cancel は MAIN へ戻り、確認画面の最終 close だけが `GuiSessionEndEvent` を一度発火して session とシジル操作の選択状態を後片付けする。Hotbar Shortcut GUI の `CLOSE` は共有基盤が再生し、SkillForget GUI も終了理由が無音の logout では `CLOSE` を再生しない。

未習得スキルの一覧左クリックは、詳細画面を開かず `learnRequiredItems` を消費して習得する。習得受付後は対象の一覧項目を時計アイコンの `処理中...` 表示へ置換し、完了まで同じセッションのスキル操作を拒否する。習得済みスキルは最大レベルならクリックでバインドし、最大レベル未満でもレベルアップに必要な素材を必要数所持していない場合は詳細画面を開かずクリックでバインドする。必要素材を所持している場合は27 slotの詳細画面を開く。詳細画面では「このスキルをバインド」と「レベルアップ」を個別に操作でき、一覧で選択済みだったバインド枠をセッションに保持してその枠へ設定する。詳細画面の戻る操作は遷移前の一覧ページへ戻る。最大レベル未満のレベルアップを受け付けた後は処理中表示にして二重操作を拒否し、成功時は更新後の詳細画面を保持する。最大レベル到達時は更新後個体を表示するスキルマネージャーへ戻る。選択済みで有効な種別適合バインド枠があればその枠へ、未選択なら種別に合う最初の空き枠へ対象個体UUIDを設定し、即時保存する。activeはaction ringの空き枠を優先して空のleft-click枠を最後に使い、passiveは現在有効なpassive枠だけを対象にする。空き枠がない場合は `P_5865` を表示する。シジル装着・脱着はシジル用オーブから専用GUIを開いて行う。許可のない所持個体も設定できるが、発動時には未所持 (`P_5809`) と使用許可なし (`P_5863`) を分けて拒否する。パッシブ枠は一覧クリック直前と保存直前にも現在の有効枠数を再検証し、超過枠では既存バインドの維持・解除だけを許可する。

シジル用オーブから開いた専用GUIでは、対象習得済み個体を選び、装着時はプレイヤーインベントリのシジルitem ID、脱着時は装着行UUIDを選択する。結果クリック直前に起点オーブと装着用シジルを通常アイテム共通消費順で再解決し、同じaccount state lock内でオーブ・シジル消費または返却と習得個体更新をローカル反映する。完成スナップショットのSQL ACK後に習得個体・インベントリ・パッシブ表示を更新し、保存失敗時はすべて操作前へ戻す。ログアウト時は選択時に保持したaccountIdで操作を無効化し、再接続後へ持ち越さない。非許可シジル、空き枠なし、同一 `equipGroupId` は確定前にそれぞれ固有のplayer messageを表示し、選択・消費を行わない。それ以外の保存失敗は `P_5864` を表示する。

API成功応答が `inventorySnapshot` を含む場合は、消費・返却entryをそのsnapshotで反映する。snapshotがない旧API応答だけは個別entry取得で再同期する。

dragは常にcancelし、保存中の二重操作を拒否する。非同期callbackはplayer online、session、account generationを再確認する。

active スキルを action ring へ設定した場合は、プリセット保存成功後に設定したスキル定義 ID を `SKILL_BOUND` としてガイドへ通知する。left-click 枠や passive 枠への設定、保存失敗、保存中断では通知しない。

## 2. スキルマネージャーの習得・レベルアップ

クラス名: `LearnedSkillService`、`SkillBindGuiEventHandler`

現在使用許可を持つ未習得スキルは「未習得」として表示し、左クリックで詳細画面を開かず習得する。使用許可がない習得済みスキルも一覧に表示し、専用の南京錠アイコンと使用不可の説明文で示す。習得済みスキルが最大レベル未満でレベルアップ素材を必要数所持している場合は、一覧クリックで詳細画面へ遷移する。必要素材を所持していない場合は詳細画面を開かず一覧クリックでバインドする。最大レベルの習得済みスキルも詳細画面を開かず、一覧クリックでバインドする。既存データに同じ skill ID の個体が複数ある場合は、API ロード順の先頭個体だけをレベルアップ対象とする。

クリック時に `LearnedSkillService` が `learnFromManagerAsync` またはレベルアップ用の重要操作入口を実行する。必要素材は BAG / HOTBAR の entry ごとの数量へ確定し、素材消費と習得個体の追加・レベル変更を同じ account lock 内で反映する。完成 player-state snapshot の SQL ACK 後だけ成功 callback を実行する。詳細画面の成功後は、更新後のレベルが最大未満なら詳細画面を再表示し、最大到達ならスキルマネージャーを再表示する。いずれの復帰でも更新後の習得個体を再取得して GUI を生成し、旧レベルを表示しない。必要素材は skill master の `learnRequiredItems` / `levelUpRequiredItems` を正本とし、未指定なら無条件で実行する。新規習得は `SKILL_LEARNED`、レベルアップは `SKILL_ENHANCED` として、現在の player session で ACK 後の成功 callback が有効な場合だけ通知なしでガイドへ記録する。

新規習得、レベルアップ、シジル操作、忘却の保存失敗時は inventory と習得個体 cache を操作前へ戻す。代償付き忘却では 100 Astrald の消費、補填素材の付与、習得個体削除を一つの重要操作 snapshot に含める。成功メッセージ、パッシブ再調停、GUI 更新は SQL ACK 後だけ行い、失敗時に別の返金保存を発生させない。

最大レベルでは習得・レベルアップ API を呼ばない。

## 3. action ring入力解決

クラス名: `SkillActionRingEventHandler`、`SkillActionRingHoldService`、`SkillActionRingService`、`SkillActionRingHud`

プリセットの先頭8枠のうち空でない値を設定済みとして数える。0件の場合は `P_5856` からスキルマネージャーを案内し、Java 版で1件の場合は右クリック1回で直接発動する。Java 版で2件以上の場合は1番を真上に置き、時計回りに8方向を45度間隔で表示する。空枠はアイコンのない輪郭で示し、輪郭が使えない場合は菱形で示す。視線方向に対応する選択可能な枠を強調する。該当個体のレベル・シジル・使用許可・共有クールダウンを表示と発動の両方へ使う。ホットバーの全9枠で、主手に持った武器から同じ選択操作を行える。発動候補の取得時と実行直前に主手武器の装備条件と耐久値を再確認する。バインドが残っていても許可を失った個体は発動せず、`P_5863` でスキル名を通知する。

Java 版の `ACTION_RING_HOLD_SELECT=false` は通常操作であり、設定済みスキルが2件以上なら右クリックでリングを開き、左クリックで選択、次の左クリックで発動する。`true` かつ設定済みスキルが2件以上の場合だけ、選択中 hotbar slot の主武器を事前にクライアントへ仮想 `TRIDENT` として送り、空中右クリックで長押しを開始する。0件または1件では仮想 `TRIDENT` 表示と長押し選択を無効にし、通常の右クリック入力として0件案内または単一スキル発動を行う。`RELEASE_USE_ITEM` を受けた時点で現在のリング選択を確定し、解除時に選択項目がなければ選択確定を行わずリングを閉じる。確定後は従来どおり次の左クリックで発動する。サーバー側の主武器は常に `PAPER` のまま保持し、解除時には開始時と同じ hotbar slot、item ID、equipment instance ID、および武器 PDC をメインスレッドで再確認する。

統合版は武器を持ってスニークしながら使用すると、候補が1件以上ある場合に標準フォームを開く。各ボタンに設定済みのスキル名、開いた時点の共有 CT の残り秒数、MP・ENG 不足などを表示し、現在の選択には選択中の印を付ける。未選択からスキルを選んだときだけ通常使用による発動を1回案内する。選択せずにフォームを閉じた場合や60秒経過した場合は、表示要求だけを解除する。応答時にアカウント、ワールド、開いたときの武器の枠と個体、現在のバインドを照合する。

スニークしていないときは武器を使うたびに選択済みスキルの発動を試みる。実行時の照準、主手武器の装備条件・耐久値、アカウント、現在のバインド、CT・リソース条件を検証する。使用の成否や持ち替えで選択は消費しない。通常使用時に現在のバインドと選択が一致しない場合、またはアカウント切り替え、退出、戦闘検証プリセット適用の際は選択を解除する。死亡・ワールド移動・他のインベントリ画面の表示では、フォームの応答待ちだけを破棄する。未選択時の通常使用では選択のしかたを10秒に1回まで案内する。通常の左クリック攻撃や、優先されるワールド操作は共通入力調停に従う。

統合版の主手武器による使用は、空中に加え、通常の地形や戦闘対象への右クリックも受け付ける。NPC・装置の個別操作や、操作可能なバニラのブロックは従来どおり優先する。

長押し中は hotbar 変更、offhand swap、drop、inventory open、world change、death、quit、リングの明示closeで待機を破棄する。取消入口ではリング表示 session の有無に依存せず長押し待機を先に破棄する。解除パケットは有効な待機 session にだけ cancel して選択確定へ振り替える。長押し中に新たな右・左クリックまたは hotbar 入力を受けた場合は、ワールド操作より優先する占有候補としてその入力を消費して長押し待機とリングを閉じ、次の入力から通常操作に戻す。選択確定後の発動待ちでは hotbar 入力を消費してリングを閉じる。未確定のリング表示中は従来どおり hotbar 変更をガードする。

視線判定の基準は開いたときの視線で初期化する。正面から約30度以内では基準を保持し、それを超えた視線には段階的に追従する。急旋回時も視線との角度を40度以内に収める。枠に視線を合わせるには中心から4度、中心へ戻って解除するには3度を境界とする。枠間の境界では、隣の枠へ3度入るまで現在の枠を維持する。

Java 版で対応パックの適用を確認した接続では、輪郭と8枠を画面中央に固定する。サーバーは枠の状態と視線の選択結果を送り、HUD はワールド座標や壁との距離に関係なく描画する。開くと輪郭が展開し、視線が移ると対象枠を短く光らせる。確定後は選んだアイコンを中央に拡大して発動を案内する。右クリックによる閉じる操作と選択時間切れでは短い終了演出を流し、発動・ワールド移動・退出などの終了処理では即時に解除する。

クールダウンは枠ごとのゲージと注視中の残り秒数で示す。MP不足、ENG不足、その他の発動制限は明度とそれぞれの記号で区別し、注視時に理由を表示する。Java 版は枠の注視中と確定後に、スキル名を残り時間、発動不可の理由、または操作案内とともにリング中央の字幕に表示する。台帳にないスキルは共通の代替アイコンを使う。

Java 版は専用フォントを Title に描画し、別の Title が来たらリングを終了する。HUD 対応を確認できない接続では、目の位置に追従する従来の Display 表示を使う。従来表示は障害物の手前で縮み、Java 版の通常追従は位置と変形を2 tickで補間する。

## 4. active skill lifecycle

world changeは詠唱・移動task・temporary effect・当該プレイヤーが発生させた一時挑発を破棄しcooldownを維持する。death / quitはcooldownを含む全一時skill stateと当該プレイヤーの一時挑発を破棄する。

## 5. メディテーション中断

クラス名: `MeditationSkillEventHandler`、`MeditationSkillRuntimeService`

- バインド済みパッシブの tick 中、プレイヤーがスニークしていない場合は準備・発動状態を破棄する。
- `EntityDamageEvent` と custom `DamageService` のプレイヤー実ダメージ通知、`PrePlayerAttackEntityEvent`、`SkillService` の検証済みskill-use通知を受けた場合は即時破棄する。
- runtime の短命状態は Bukkit Player UUID をキーにする。`PlayerToggleSneakEvent` の解除、`PlayerDeathEvent`、`PlayerQuitEvent`、`PlayerChangedWorldEvent`、クラス変更後のパッシブ再調停でも状態が残らないようにする。
- 3秒は60 tickとして管理し、開始後7秒に当たる140 tickの間、発動中のスニーク継続だけを条件に自然回復倍率を有効化する。開始時の倍率は2.0、以降20 tickごとに0.5ずつ加算し、最後は5.0とする。効果開始時に `buff:adventurer_meditation` を付与し、移動速度+120%を7秒適用する。中断時はこのバフを強制解除し、完了時はMP / ENGだけを最大値へ戻して全効果を終了する。HP自然回復とShield回復は倍率・全回復の対象外とする。発動時に円形 particle と控えめな音を一度だけ出し、維持中は低密度の周回 particle と環境音を間隔表示する。全回復時には `TOTEM_OF_UNDYING` / `END_ROD` の完了パーティクルを一度ずつ表示し、`ENTITY_PLAYER_LEVELUP` を一度再生する。環境音は `activeSoundIntervalTicks`（現行値40 tick）に従って再生し、`World#playSound` と `SoundCategory.PLAYERS` により音源位置の周囲にいるプレイヤーにも聞こえる。自然回復倍率の効果対象は自身のみとする。

## 6. 例外処理

GUI click / drag / close の例外は `E_5601`、action ringとactive lifecycleは `E_3002` へ操作context付きで記録し、Bukkit event loopへ再送出しない。
