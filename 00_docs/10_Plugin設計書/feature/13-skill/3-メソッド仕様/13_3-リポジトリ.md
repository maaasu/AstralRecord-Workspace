# 13_3-リポジトリ

## 1. skill 一覧取得

クラス名: `SkillRepository`
物理名: `findAll`

`GET /api/skill` の `200` を `List<SkillSummary>` へ変換する。その他 status は `E_5801` を記録して例外化する。

## 2. skill 詳細取得

クラス名: `SkillRepository`
物理名: `findById`

`GET /api/skill/{skillId}` の `200` を `SkillDefinition` へ変換し、`404` は `W_5800` と `null`、その他 status は `E_5800` と例外にする。成功時は `D_5800` を記録する。

## 3. API definition 変換

クラス名: `SkillRepository`
物理名: `toDefinition`

表示項目、implementation ID、kind、passive bind 要否、cooldown、cast time、required level、resource type / cost、legacy mana cost、sound、params、tags を Plugin model へ正規化する。参照 prefix は必要な項目で suffix ID を保持する。

## 4. bind preset 一覧取得

クラス名: `SkillBindPresetRepository`
物理名: `findByAccountId`

`GET /api/skill-bind-presets?account_id={accountId}` の `200` 配列を preset へ変換する。異常 status は `E_5803` と `IOException`、interrupt は flag を復元して伝播する。

## 5. bind preset 保存

クラス名: `SkillBindPresetRepository`
物理名: `save`

`PUT /api/skill-bind-presets/{accountId}/{presetIndex}` へ active / passive 各 8 slot と更新者を送る。空 slot は JSON `null` とし、`200` の version 付き preset を返す。異常 status は `E_5804` とする。

## 6. skill tree node 定義読込

クラス名: `SkillTreeNodeRepository`
物理名: `findAll`

- `35.features.skilltree/nodes` の schema v1 JSON を読み、skill / status の typed effect と任意の current class / player level 条件を model へ変換する。
- `nodeId` は `0` または先頭 0 のない数字文字列とし、ファイル間重複を拒否する。
- schema にない legacy property、先頭 0 付き ID、未知 effect / condition property、解決不能な Material は不正定義として全体読込を失敗させる。

## 7. skill tree structure 読込

クラス名: `SkillTreeStructureRepository`
物理名: `load`

- plugin config が選択した structure JSON を毎回読み、相対 node 座標を設定 center へ加算して絶対座標にする。
- edge は無向として両端 ID の正規順へ揃える。
- node ID / 座標の重複、自己 edge、同じ無向 edge の重複、未配置 node 参照、root から到達不能な node、座標加算 overflow を拒否する。

## 8. skill tree player state

クラス名: `SkillTreePlayerStateRepository`

account ごとの解放 node と class point 消費元を永続化する。読込結果は join generation に対応する state として service へ渡し、古い join callback が新しい session state を破棄しないよう、破棄時は state instance の一致を要求する。
