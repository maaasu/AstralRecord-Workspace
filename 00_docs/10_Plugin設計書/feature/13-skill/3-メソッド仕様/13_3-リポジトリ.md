# 13_3-リポジトリ

## 1. スキル定義

クラス名: `SkillRepository`

`GET /api/skill` と `GET /api/skill/{skillId}` を使用する。表示項目、発動制御、`cooldownId`、`maxLevel`、レベル差分、レベル別シジル枠、許可シジルを `SkillDefinition` へ変換する。

## 2. 習得済みスキル個体

クラス名: `LearnedSkillRepository`

`GET /api/account-skills/{accountId}` でログイン時の一覧だけを読み込む。習得・レベルアップ・シジル装着／脱着・忘却は `LearnedSkillService` がインベントリと習得個体を同じaccount state lock内で変更し、`PlayerStateRepository` の `learnedSkills` sectionを含む完成スナップショットで保存する。`LearnedSkillRepository` は更新POSTを持たない。

既存個体はロード時の`version`を`expectedVersion`に、新規個体は`expectedVersion=null`にする。削除は`deletedSkills`へ個体IDと期待versionを明示する。APIは同一transaction内でinventory・equipment・習得個体の楽観ロックを検証し、全件ACKを返す。

## 3. バインドプリセット

クラス名: `SkillBindPresetRepository`

`GET /api/skill-bind-presets?account_id={accountId}` で初期状態だけを読み込む。action 6枠、left-click、passive 9枠の変更と選択番号はローカルcacheへ即時反映し、`skillBindPresets` sectionを含む完成スナップショットで保存する。個別PUTは使用しない。

## 4. インベントリentry UUID

習得・レベルアップ・シジルmutationで素材を一意に指定できるよう、PluginからAPIへ保存するinventory draftは既存 `inventoryEntryId` を維持する。slot移動やGUI保存で別UUIDへ採番し直さない。既存entryには取得時の `updatedAt` を `expectedUpdatedAt` として送り、mutation後の古い一括保存を拒否する。保存成功応答は、送信後も内容が変化していないentryだけへ反映してAPI採番の新しい更新時刻を取り込み、待機中のローカル変更は上書きしない。

## 6. skill tree node 定義読込

`SkillTreeNodeRepository` はskill effectを使用許可IDとして読み込む。`lore` は任意項目であり、省略時は空の説明として読み込む。ノード全体のロード時、同じ `unlockCondition.classId`（条件なし同士を含む）に同じskill IDが複数定義されていた場合はマスタ不整合としてロードを失敗させる。`classId` が異なる場合だけ重複を許可し、`playerLevel` の違いは許可条件の区別に使わない。

`SkillTreePlayerStateRepository` はアカウント単位の解放ノード、class point消費元、versionを初期ロードする。更新は`skillTree` sectionを含む完成スナップショットへ集約する。現在クラス条件を満たさないノードは派生許可集合へ含めない。

## 7. skill tree structure 読込

クラス名: `SkillTreeStructureRepository`
物理名: `load`

- plugin configが選択したstructure JSONを毎回読み、0.1ブロック刻みの相対node座標を設定centerへ加算して絶対座標にする。
- edgeは無向として両端IDの正規順へ揃える。
- node ID / 座標の重複、自己edge、同じ無向edgeの重複、未配置node参照、rootから到達不能なnode、座標加算overflowを拒否する。

## 8. skill tree player state

クラス名: `SkillTreePlayerStateRepository`

accountごとの解放node、class point消費元、永続versionをGETで読み込む。読込結果はjoin generationに対応するstateとしてserviceへ渡し、古いjoin callbackが新しいsession stateを破棄しないよう、破棄時はstate instanceの一致を要求する。構造不整合はローカルで空状態へ置換し、読込versionを期待値とする完成スナップショットで保存する。
