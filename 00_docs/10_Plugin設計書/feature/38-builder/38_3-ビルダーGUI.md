# 38_3-ビルダーGUI

## 操作の流れ

`/builder` または `/bg` からホームを開き、範囲・素材を設定し、編集操作を選んで確認する。各画面に目的・前提・結果・次の操作を説明する。

| 画面 | 操作・設定 |
|:--|:--|
| 範囲 | 直方体モード、選択の斧、足元または見ているブロックの第1・第2地点、範囲情報、境界表示、指定方向への拡大・縮小 |
| 素材 | 定番パレット、全ブロックのページ一覧、プレイヤーインベントリのブロック、空気。配置先と置換元を別々に設定 |
| 範囲編集 | 塗りつぶし、指定素材の置換、四方の壁、箱の外側、消去、地面の起伏を一回なだらかにする |
| コピー | コピー、貼付、左右90度回転、東西・上下反転、空気を無視する設定 |
| 図形 | 球・中空球・円柱・中空円柱、半径1〜32、高さ1〜64 |
| 移動・繰返し | 指定方向への建築移動（選択範囲も追従）、繰返し複製。距離1〜64、複製回数1〜16、方角は固定の6方向 |
| 履歴 | 自分の直前のWorldEdit編集の取り消し、やり直し。手入力のWorldEdit編集も同じ履歴に含む |

空気を無視する設定は貼付・移動・繰返しに共通で、既定は有効。通常のブロック素材を選ぶため、階段・原木などの向きやブロック状態を指定する自由形式のWorldEditパターンは入力しない。

数値ボタンは左クリックで1、右クリックで最大10単位ずつ変更し、設定の上下限を超えない。

## 確認と実行

`BuilderService.prepare` はGUI利用権限・WorldEdit個別権限・WorldEditが所有するコマンド登録を確認する。範囲操作には完成した直方体と現在ワールドの一致を要求し、コピー操作にはセッションのコピー内容を要求する。別ワールドへのWorldEdit overrideやAPI非互換で状態を読めない場合は編集を拒否する。

確認画面には操作、素材・数値、実際の範囲のワールド・座標・体積、WorldEditの配置基準位置、対象規模、マスクの有無と履歴の案内を表示する。コピー・貼付・図形の基準位置はWorldEditセッションから読み、通常はプレイヤー位置、`pos1` 配置モードでは第1地点となる。

実行ボタンでGUIを閉じ、次tickに要求を一度だけ消費する。実行直前にワールド、必要な範囲・コピーと変換、マスク、配置基準、必要なプレイヤー位置、権限を再確認し、変わっていれば実行せず再確認を案内する。素材・数値は確認要求のコマンドに確定済みで、後続の設定変更から組み立て直さない。

コマンドはWorldEdit/FAWEを所有者とするBukkit登録名へ解決し、プレイヤーとして実行する。コンソール実行、OP付与、権限の一時付与、保護の解除は行わない。送信できたことと編集完了を区別し、実際の成功・変更数・拒否はWorldEditの通知で確認する。操作後はクリックでGUIを再開できる。

## 対象規模の上限

`builder.maxBlocks` とWorldEdit自身の制限を併用する。GUIの見積は実際の変更数ではなく、保守的な対象規模。

- 範囲操作・コピー: 選択体積。
- 繰返し: 選択体積 × 追加コピー回数。
- 移動: 選択体積 × 2（元と移動先）。
- 貼付・コピーの回転と反転: コピー体積。
- 球・中空球: `(半径 × 2 + 1)` の3乗。
- 円柱・中空円柱: `(半径 × 2 + 1)` の2乗 × 高さ。
- 取り消し・やり直し: GUIから履歴の変更数を断定せず、WorldEdit側の管理に任せる。

## インベントリと状態の保全

専用holderは所有者と画面操作を保持する。全クリックとドラッグによるアイテム移動を止め、通常クリックだけを操作として受け付ける。素材画面でインベントリのブロックを押しても取得・消費せず種類だけを選ぶ。画面遷移を待つ間は同じ画面の操作を再消費しない。

`PlayerQuitEvent`・`PlayerRuntimeDiscardEvent` で個人設定と未実行要求を破棄し、Plugin停止では全設定・要求を破棄する。

## メッセージとログ

プレイヤー通知の正本は `player.properties` の `P_7700`〜`P_7715`、連携例外の正本は `logger.properties` の `E_7700`・`E_7701`。状態読取失敗は提供元ごとに一度ログし、未選択とコピーなしの契約例外は通常状態として扱う。

FAWEのglobal transformが有効な場合はGUIの対象範囲と規模を保証できないため、準備と実行直前の両方で操作を拒否し、`//gtransform` で解除するよう案内する。通常WorldEditにないFAWE拡張APIは、メソッド自体が存在しない場合だけ未設定として扱う。

FAWEで複数コピーを保持している場合、コピー必須操作を準備・実行直前の両方で拒否する。コピーの変換も90度単位の軸直交回転・反転と整数移動だけを許容し、斜め回転・拡縮はGUIから再コピーするよう案内する。これにより確認画面と実際に選ばれるコピーの不一致、および変換による体積上限の過小見積を防ぐ。
