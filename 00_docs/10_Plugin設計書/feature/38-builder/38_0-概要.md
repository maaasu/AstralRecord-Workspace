# 38_0-概要

## 目的と責務

WorldEditを知らないビルダーが、日本語の説明を読みながら範囲・素材・数値を選び、建築を編集するためのインベントリGUIを提供する。入口は `/builder`、短縮は `/bg`。操作説明・素材選択・確認はGUI内で完結し、自由形式のコマンド入力やチャット入力を使用しない。

## 主要契約

- GUIの利用条件はAstralRecord管理者またはBukkit権限 `astralrecord.builder`。各操作にはWorldEditの個別権限も必要。
- WorldEditまたはFastAsyncWorldEditは任意依存。未導入時はGUI入口で案内し、本体の起動を妨げない。
- 選択範囲とコピー内容の正本はWorldEditのプレイヤーセッション。GUI内へ別の範囲を保持しない。
- 編集前に確認画面を出し、確定した操作をプレイヤー自身としてWorldEditの正規コマンドへ渡す。保護領域、履歴、WorldEdit側の制限と完了通知はWorldEditへ委譲する。
- GUI設定と未実行要求はメインスレッド上の一時状態。退出、プレイヤーruntime破棄、Plugin停止で破棄し、DB・API・filebaseへ保存しない。

## 依存・設定

`shared/gui` の開く処理とクリック制御、playerの権限・通知・runtime破棄を利用する。`config.yml` の `builder.maxBlocks` はGUIからの一回の対象規模の上限（既定100,000、最低1）。WorldEdit固有のセッション読取は任意依存の境界に閉じる。

操作と拒否条件は [ビルダーGUIの処理契約](38_3-ビルダーGUI.md) を参照する。所有パスは [FEATURE_CATALOG](../../FEATURE_CATALOG.md) を正本とする。
