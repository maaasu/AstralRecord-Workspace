# 04_3-コマンド

## 1. item コマンド振分

クラス名: `ItemCommand`
物理名: `executePlayerCommand`

入力:

- 引数なし
- `load <itemId>`
- `get <itemId> [amount]`

処理内容:

1. 引数なしの場合は [[04_3-コマンド]].管理者item GUI委譲 を実行する
2. 第1引数 `load` は [[04_3-コマンド]].アイテム単体再ロード へ委譲する
3. 第1引数 `get` は [[04_3-コマンド]].ロード済みアイテム付与 へ委譲する
4. その他は usage を返す

権限:

- `AstCommand` の player-only / `UserPermission.ADMIN(99)` ガードを使用する

## 2. 管理者item GUI委譲

クラス名: `ItemCommand`
物理名: `openAdminGui`

処理内容:

1. plugin から `ItemAdminGuiEventHandler` を取得する
2. 未初期化なら `PlayerMsgId.P_5063` を送信する
3. 初期化済みなら `ItemAdminGuiEventHandler.open(player)` を呼ぶ

## 3. アイテム単体再ロード

クラス名: `ItemCommand`
物理名: `handleLoad`

入力:

- `args[1]`: item ID

処理内容:

1. 引数不足なら usage を返す
2. `ItemService.loadItem(args[1])` で詳細 API から単体取得し、共有キャッシュへ反映する
3. 未検出なら `PlayerMsgId.P_5201` へ item ID 1 引数を渡して終了する
4. 成功時は `PlayerMsgId.P_5209` へ日本語カテゴリ名、ID、表示名を渡す

出力:

- なし

## 4. ロード済みアイテム付与

クラス名: `ItemCommand`
物理名: `handleGet`

入力:

- `args[1]`: item ID
- `args[2]`: 数量。省略または整数化失敗時 `1`、下限 `1`

処理内容:

1. 引数不足なら usage を返す
2. `ItemService.findLoadedById(args[1])` で共有キャッシュだけを参照する
3. 未ロードなら `PlayerMsgId.P_5213` を送信し、API 取得せず終了する
4. `InventoryService` 未初期化なら `PlayerMsgId.P_5063` を送信する
5. `InventoryService.addItemToNormalInventory` で付与する
6. 付与数が 0 以下なら `PlayerMsgId.P_5241` を送信する
7. 通貨以外は解決した `InventoryType` の GUI を反映する
8. `PlayerMsgId.P_5240` へ表示名と実付与数を渡す

出力:

- なし

## 5. item コマンド補完

クラス名: `ItemTabCompleter`
物理名: `getPlayerCompletions`

処理内容:

1. 第1引数位置では `load`, `get` を返す
2. 両サブコマンドの第2引数位置では `ItemService.getLoadedItemIds()` を返す
3. `get` の第3引数位置では `1`, `8`, `16`, `32`, `64` を返す
4. その他は空リストを返す

## 6. 管理者item GUI表示

クラス名: `ItemAdminGuiEventHandler`
物理名: `open`

処理内容:

1. `ADMIN(99)` 権限を防御的に再確認する
2. プレイヤー単位のカテゴリ・レア度・ページ状態を初期化する
3. `ItemService.getLoadedItems()` をフィルタし、`ItemAdminGuiView.open` へ渡す

終了条件:

- 権限不足は `PlayerMsgId.P_5707` を送信して終了する

## 7. 管理者item GUI描画

クラス名: `ItemAdminGuiView`
物理名: `open` / `render`

処理内容:

1. 54 slot inventory を作成し、slot `0..44` の内容領域へ最大 45 item を表示する
2. slot `45..53` に前後ページ、カテゴリ・レア度 filter、guide を描画する
3. item 表示は `ItemStackFactory.createShopDisplay` を使い、未確定 roll を範囲で表示する

## 8. 管理者item GUI操作

イベント物理名: `InventoryClickEvent` / `InventoryDragEvent` / `InventoryCloseEvent`
クラス名: `ItemAdminGuiEventHandler`
物理名: `onInventoryClick` / `onInventoryDrag` / `onInventoryClose`

処理内容:

1. 対象 GUI の click / drag は vanilla 操作をキャンセルする
2. filter 変更時はページを 0 に戻して再描画する
3. 前後ページ操作は filter 結果内でページを正規化する
4. 内容 item の左 click は 1、右 click は半 stack 切り上げ、Shift+左 click は 1 stack を要求する
5. `InventoryService.addItemToNormalInventory(..., "admin_gui")` で付与し、失敗時は `P_5241` と拒否音を返す
6. close 時はプレイヤー単位の GUI state を削除する

## 9. showitem コマンド

クラス名: `ItemChatShareCommand`

物理名: `executePlayerCommand`

入力:

- `/showitem <itemName>`
- `/si <itemName>`

処理内容:

1. `itemName` を空白結合し、実行プレイヤーの現在の所持品から同一の表示名を持つ AstralRecord item を先頭出現順で 1 件解決する。
2. 解決できない場合は `PlayerMsgId.P_5949` を送信して終了する。
3. 解決できた item はインベントリ表示専用のクリック操作案内を除いた clone を hover tooltip に使い、先頭の `◆` 装飾を除いた表示名を全体チャットの本文として送信する。
4. 本文へカーソルを合わせると item の表示名・lore を含む通常のアイテム tooltip を表示する。本文をクリックすると、`◆` と装飾コードを含まない表示名をクライアントのクリップボードへコピーする。

権限:

- `AstCommand` の player-only ガードを使用する。追加の権限は要求しない。

## 10. showitem 補完

クラス名: `ItemChatShareTabCompleter`

物理名: `getPlayerCompletions`

1. 実行プレイヤーの現在の所持品から、表示名を持つ AstralRecord item の名前を先頭出現順・重複なしで候補にする。
2. 表示名に空白が含まれる場合は、すでに入力済みの語を再挿入しない残り部分だけを候補にする。
