# 04_3.04-リポジトリ

## 1. ItemRepository メソッド仕様

### アイテム一覧取得

クラス名: `ItemRepository`  
物理名: `findAll`

責務:

全カテゴリのアイテムサマリを API から取得する。

処理内容:

1. `GET /api/item` を呼ぶ
2. `200` は [[04_1.00-モデル定義]].アイテム一覧サマリ のリストへ変換して返す
3. その他ステータスは `LogId.E_5201` を記録し例外化する

	| 項目 | 内容 |
	|---|---|
	| ID | `LogId.E_5201` |
	| レベル | `ERROR` |
	| テンプレート | `カテゴリのアイテム一括ロードに失敗しました: category=%s` |
	| 出力条件 | `GET /api/item` が `200` 以外 または 例外 |
	| 引数 | `HTTP <status> for GET /api/item` または例外メッセージ |

### カテゴリ別アイテム一括取得

クラス名: `ItemRepository`  
物理名: `findAllByCategory`

責務:

一覧 API でサマリを取得し、カテゴリ一致分のみ詳細 API で展開する。

処理内容:

1. 入力カテゴリを `trim` で正規化し、空文字なら空リストを返す
2. [[04_3.04-リポジトリ]].アイテム一覧取得 を呼び、カテゴリ一致分をフィルタする
3. 各サマリで [[04_3.04-リポジトリ]].アイテム詳細取得 を呼ぶ
4. 取得できたアイテムのみをリストに集約する
5. 件数を `LogId.D_5202` で記録する

	| 項目 | 内容 |
	|---|---|
	| ID | `LogId.D_5202` |
	| レベル | `DEBUG` |
	| テンプレート | `カテゴリのアイテム一覧を取得しました (API): カテゴリ=%s (%d件)` |
	| 出力条件 | カテゴリ別一括取得完了時 |
	| 引数 | カテゴリ, 件数 |

### アイテム詳細取得

クラス名: `ItemRepository`  
物理名: `findById`

責務:

ID 単位でアイテム詳細を API から取得する。

処理内容:

1. アイテム ID を URL エンコードする
2. `GET /api/item/{itemId}` を呼ぶ
3. `200` は [[04_1.00-モデル定義]].アイテムモデル へ変換して返す
4. `404` は `LogId.W_5200` を記録して `null` を返す

	| 項目 | 内容 |
	|---|---|
	| ID | `LogId.W_5200` |
	| レベル | `WARN` |
	| テンプレート | `アイテムが見つかりませんでした (API): カテゴリ=%s, ID=%s` |
	| 出力条件 | `GET /api/item/{itemId}` が `404` |
	| 引数 | カテゴリ, ID |

5. その他ステータスは `LogId.E_5200` を記録し例外化する

	| 項目 | 内容 |
	|---|---|
	| ID | `LogId.E_5200` |
	| レベル | `ERROR` |
	| テンプレート | `アイテム取得に失敗しました (API): %s` |
	| 出力条件 | `GET /api/item/{itemId}` が `200/404` 以外 または 例外 |
	| 引数 | APIエラーメッセージ or 例外メッセージ |

### 装備インスタンス生成

クラス名: `ItemRepository`  
物理名: `createEquipmentInstance`

責務:

API に装備インスタンスを新規作成させ、確定済みステータスロールを取得する。

処理内容:

1. リクエスト JSON を構築する（`equipmentId`, `accountId`, `source`, `createdBy`）
2. `POST /api/equipment/instances` を呼ぶ
3. `200/201` は [[04_1.00-モデル定義]].装備インスタンス へ変換して返す
4. その他ステータスは `LogId.E_5200` を記録し例外化する

### 装備インスタンス取得

クラス名: `ItemRepository`  
物理名: `findEquipmentInstanceById`

責務:

装備インスタンス ID で詳細を取得する。

処理内容:

1. `GET /api/equipment/instances/{instanceId}` を呼ぶ
2. `200` は [[04_1.00-モデル定義]].装備インスタンス を返す
3. `404` は `LogId.W_5200` に `"equipment"` と `instanceId` を渡して記録し `null` を返す
4. その他ステータスは `LogId.E_5200` を記録し例外化する

## 3. API エンドポイント一覧

- `GET /api/item`
- `GET /api/item/{itemId}`
- `POST /api/equipment/instances`
- `GET /api/equipment/instances/{instanceId}`
- `POST /api/rune/instances`
- `GET /api/rune/instances/{instanceId}`
- `GET /api/seteffect`
- `GET /api/seteffect/{setId}`

## 4. ステータスコード方針

- `GET`:
  - `200`: 正常
  - `404`: 用途に応じて `null` 返却（警告ありで吸収）
  - その他: 例外化
- `POST`:
  - `200/201`: 正常
  - その他: 例外化
