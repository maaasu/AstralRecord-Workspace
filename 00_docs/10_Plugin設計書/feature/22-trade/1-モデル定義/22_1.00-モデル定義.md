# 22_1.00-モデル定義

## TradeRequest

| 要素 | 型 | 意味 |
|:--|:--|:--|
| `requestId` | `UUID` | request ID |
| `senderUuid` / `targetUuid` | `UUID` | Bukkit player IDs |
| `senderName` / `targetName` | `String` | 作成時表示名 |
| `createdAt` / `expiresAt` | `Instant` | 作成・期限。期限は作成から 60 秒 |
| `status` | `TradeRequestStatus` | mutable status |

status は `PENDING`、`ACCEPTED`、`CANCELLED`、`EXPIRED`。

## TradeSession

| 要素 | 型 | 意味 |
|:--|:--|:--|
| `sessionId` | `UUID` | session ID |
| player A/B UUID | `UUID` | online player identity |
| player A/B account ID | `UUID` | inventory ownership identity |
| player A/B name | `String` | 表示名 |
| player A/B items | `List<ItemStack>` | clone 済み escrow |
| player A/B gold amount | `long` | 提示 gold。0 以上 |
| player A/B ready | `boolean` | 確定意思 |
| `status` | `TradeSessionStatus` | `OPEN`、`COMMITTING`、`COMPLETED`、`CANCELLED` |
| `openedAt` / `updatedAt` | `Instant` | 開始・最終更新 |

items または gold が変わると双方 ready を false にする。

## GUI holder

- `TradeGui.TradeHolder(sessionId, viewerUuid)`
- `TradeCancelConfirmGui.CancelHolder(sessionId, viewerUuid)`
- `GoldAmountSettingGui.GoldAmountHolder(sourceKey, sessionId, viewerUuid, ...)`

概念的な `TradeGuiState` ではなく、上記 physical holder を実装契約とする。
