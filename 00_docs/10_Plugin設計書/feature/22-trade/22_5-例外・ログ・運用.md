# 22_5-例外・ログ・運用

## 拒否と通知

空の送信は P_6202、対象不正・残高不足は P_6203、送信不可品は P_6204、確定準備失敗は P_6209、許可外worldは P_6210。正常確定後の通知は [[22_3-メソッド仕様]] の受信通知に従う。文言の正本は player.properties。

## ログと回復

GUI event の失敗は E_6200、予約・確定・再同期・描画失敗は E_6201 と Throwable を記録する。通信喪失時は同じ operation ID を再送し、確定不明の品を返却しない。通常終了では OPEN の予約だけ解除する。プロセスクラッシュ耐性はプロジェクト方針どおり対象外。
