# 22_9-未決事項

## 異常終了時の durable escrow recovery

現在の request、session、offered item は process memory にあり、正常 disable では `cancelAll()` が返却する。一方、process crash や snapshot rollback 自体の失敗に備えた durable journal／再起動時 recovery はない。

決定が必要な項目:

- commit intent と escrow の永続化単位
- item instance と stackable item の再送 idempotency key
- gold 移転の transaction 境界
- 起動時に `OPEN`／`COMMITTING` session を回復する規則
- rollback failure の管理者通知と修復 UI

この方針が確定するまでは、crash 後も自動復旧すると仕様へ記載しない。
