# 22_1-モデル定義

## 送信セッション

TradeSession は session ID、送受信者の player UUID・account UUID・表示名、送信品の clone・source entry ID・数量、Gold、状態を保持する。API の A/B 形式に対応するが A が送信者、B は受信者で提示なし・Gold 0 とする。申請モデル、ready 状態は持たない。

returnAction は情報画面への戻り先。コマンド起動は null。getOpenSession は送信者だけを索引とし、受信者の別 session を上書きしない。内容 clone は source entry と同順で保持し、同じ source entry を分割表示した場合は commit 時に一明細へ合算する。

## GUI 配置

TradeGui は54スロット。0〜44を送信アイテム、45を戻る（コマンド起動は閉じる）、48を金額設定、50を送信、53を閉じるに使用する。情報画面起動時は戻ると閉じるの両方がある。最下行の残りは操作不可のプレースホルダーとする。

TradeHolder は session ID・viewer UUID と HotbarShortcutGuiHolder を持つ。金額画面は共通 GoldAmountSettingGui を使い、sourceKey は send、contextId は session ID とする。
