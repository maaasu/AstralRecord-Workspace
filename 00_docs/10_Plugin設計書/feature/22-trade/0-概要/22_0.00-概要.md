# 22_0.00-概要

## 目的

両 player が提示内容を確認して ready にした場合だけ、item と gold の所有を交換する。offer 中の item は通常 inventory から取り除いて session に保持し、二重利用を防ぐ。

## 責務

- sender／target の招待を 60 秒保持し、`/trade accept` で session を開始する。
- player と account の対応を session 開始時に固定する。
- tradeable item を NORMAL inventory から offer へ移し、withdraw 時は戻す。
- gold offer を残高以内へ clamp し、提示変更時は双方の ready を解除する。
- 双方 ready 時に capacity、tradeability、gold、identity を再検証して commit する。
- cancel／quit／GUI close confirm で escrow を各所有者へ戻す。

## 責務外

- offline trade、server 間 trade、market listing。
- trade history の永続化、手数料、価格査定。
- world 移動による session 自動 cancel。現在は quit と GUI 操作を契機にする。

## 現在の契約

- request TTL は 60 秒。
- session は `OPEN -> COMMITTING -> COMPLETED|CANCELLED`。rollback 成功時は `OPEN` へ戻すことがある。
- `ItemModel.getUnTradeable()` が true の item は提示不可。
- offer item list は clone して保持・返却し、外部 mutation を共有しない。
- plugin disable 時は `cancelAll()` で全 open session を返却処理する。
