# 22_2-ユースケース

## UC-22-01 招待する

- `/trade <playerName>` で online target を指定する。
- 両者が gameplay mode、自己以外、open session なしであることを検証する。
- 60 秒後を期限に `PENDING` request を作成し双方へ通知する。

## UC-22-02 招待を承認する

- target が `/trade accept` を実行する。
- 最新 pending request の期限、sender online、両者の mode／session を再検証する。
- `ACCEPTED` にして account IDs を固定した `OPEN` session を作り、両者へ GUI を開く。

## UC-22-03 item を提示・取り下げる

- player inventory の owned item を自分側 offer slot へ提示する。
- `unTradeable`、amount、session、viewer、NORMAL inventory ownership を検証して escrow へ移す。
- offer 側 item click で NORMAL inventory に戻す。
- 内容変更後は双方の ready を解除し GUI を再描画する。

## UC-22-04 gold を提示する

- gold slot から共通 amount setting GUI を開く。
- 入力値を 0 以上かつ現在残高以内へ clamp して session へ反映する。
- amount GUI close は trade GUI を再度開く。

## UC-22-05 確定する

- ready slot で本人の ready を toggle する。
- 双方 ready になった時点で tradeability、残高、受取 capacity、account identity を再検証する。
- 検証後に item／gold を相互移転し、exact commit なら `COMPLETED`。

## UC-22-06 cancel する

- trade GUI close は次 tick に cancel confirm を開く。
- confirm の cancel で escrow を元 owner へ戻し `CANCELLED`。
- back は trade GUI へ戻る。confirm close、quit、disable も cancel 対象となる。
