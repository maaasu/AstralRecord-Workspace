# 07_1-モデル定義

## 1. ドメインモデル

`status` 機能の中心はステータススナップショット。
ステータス種別ごとの基礎値・補正値・合計値の最小値／最大値と、現在 HP / MP / EN / Shield を同時に保持する。

## 2. ステータススナップショット

物理名: `StatusSnapshot`

### 2.1 項目

| 項目              | 説明                                                     |
| --------------- | ------------------------------------------------------ |
| `values`        | [[07_1-モデル定義]].ステータス種別 ごとの [[07_1-モデル定義]].ステータス値 |
| `currentHp`     | 現在 HP                                                  |
| `currentMp`     | 現在 MP                                                  |
| `currentEnergy` | 現在 EN                                                  |
| `currentShield` | 現在 Shield                                              |
| `shieldChangedAtMs` | Shield 値が最後に変化した epoch milliseconds。再充填待機判定に使用 |
| `calculatedAt`  | 計算日時                                                   |

### 2.2 保持先

- [[03_1-モデル定義]].プレイヤーセッション.statusSnapshot に保持する。
- 空状態の場合は、[[07_3-サービス]].ステータス再計算 により初期化する。

## 3. ステータス値

物理名: `StatusValue`

| 項目 | 説明 |
|---|---|
| `baseMinValue` / `baseMaxValue` | 基礎値の下限／上限 |
| `bonusMinValue` / `bonusMaxValue` | アカウントモード・レベル・装備・バフによる補正値の下限／上限 |
| `minValue` / `maxValue` | 基礎値と補正値を合算した下限／上限 |
| `rollValue` | 下限と上限が異なる場合は範囲内からランダム取得し、同値ならその値を返す |

`MAX_HEALTH`、`MAX_MANA`、`MAX_ENERGY`、`MAX_SHIELD`、`INVENTORY_SLOTS`、`QUEST_LIMIT` は状態管理上の上限値として参照ごとに変動させないため、単一値で保持する。それ以外は装備等が範囲を持つ場合に最小値／最大値を維持する。

表示時は下限と上限が同値なら単一値へ畳み込み、異なる場合だけ range として表示する。percentage 種別の保存値は 0..1 の比率へ再変換せず percentage point として `%` 表示する。

## 4. ステータス種別

物理名: `StatusType`

ID・論理名・カテゴリ・表示単位・小数桁・範囲可否の正本は`40_filebase/75.shared.status/v1.status_types.yml`とし、`StatusType.kt`は`60_tool/generate-status-types.ps1`で生成する。Plugin固有のステータス計算と利用箇所は本設計書およびPluginソースを正本とする。

### 4.1 リソース系

| 物理名 | 論理名 | 用途 |
|---|---|---|
| `MAX_HEALTH` | 最大HP | HP 上限 |
| `MAX_MANA` | 最大MP | MP 上限 |
| `MAX_ENERGY` | 最大EN | EN 上限 |
| `MAX_SHIELD` | 最大シールド | Shield 上限 |

### 4.2 基本能力値

| 物理名 | 論理名 | 用途 |
|---|---|---|
| `STRENGTH` | 筋力 | 近接攻撃系の基礎能力 |
| `DEXTERITY` | 器用さ | 間接攻撃系の基礎能力 |
| `INTELLIGENCE` | 知力 | 魔法攻撃・MP 系の基礎能力 |
| `VITALITY` | 体力 | HP・防御・自然回復系の基礎能力 |
| `AGILITY` | 敏捷性 | 攻撃速度・移動速度・回避系の基礎能力 |
| `LUCK` | 幸運 | クリティカルやドロップ系の基礎能力 |

基本能力値は、装備・バフ・アカウントモード・レベルを反映した最終値から、以下の派生補正を加算する。直接指定された派生ステータスの補正とも加算される。基本能力値が範囲値の場合、範囲を許可する派生ステータスは対応する下限／上限を維持し、最大HP・最大MPは基本能力値の範囲平均を用いる。

| 基本能力値 | 派生先 | 基本能力値1あたりの補正 |
|---|---|---:|
| `INTELLIGENCE` | `MAX_MANA` | `+1` |
| `INTELLIGENCE` | `MP_REGEN` | `+0.1` |
| `VITALITY` | `MAX_HEALTH` | `+2` |
| `VITALITY` | `DEFENSE`, `MAGIC_DEFENSE` | 各 `+1` |
| `VITALITY` | `HP_REGEN` | `+0.1` |
| `AGILITY` | `ATTACK_SPEED`, `MOVEMENT_SPEED` | 各 `+1` |
| `AGILITY` | `EVASION` | `+0.1%` |
| `LUCK` | `CRITICAL_RATE` | `+0.1%` |

`LUCK` は加えて、`luckAffected = true` の直接ドロップ確率へ `LUCK × 0.05` ポイントを加算する。これはドロップ抽選時に適用する。

### 4.3 攻撃系

| 物理名 | 論理名 |
|---|---|
| `ATTACK` | 攻撃力 |
| `MELEE_ATTACK` | 近接攻撃力 |
| `RANGED_ATTACK` | 間接攻撃力 |
| `MAGIC_ATTACK` | 魔法攻撃力 |
| `CRITICAL_RATE` | 会心率 |
| `CRITICAL_DAMAGE` | 会心ダメージ |
| `SUPER_CRITICAL_RATE` | 超星会心率 |
| `SUPER_CRITICAL_DAMAGE` | 超星会心倍率 |
| `SKILL_DAMAGE_INCREASE` | スキルダメージ増加 |
| `NORMAL_ATTACK_DAMAGE_INCREASE` | 通常攻撃ダメージ増加 |
| `FINAL_DAMAGE_MULTIPLIER` | 最終ダメージ倍率（常時適用） |
| `ACCURACY` | 命中率 |
| `ATTACK_SPEED` | 攻撃速度（基準値100。通常攻撃・攻撃行動の間隔を `ceil(基本間隔 × 100 / 攻撃速度)` にする） |
| `SHIELD_BREAK` | シールド破壊力 |
| `DEFENSE_PENETRATION_RATE` | 防御力貫通率 |
| `MELEE_DEFENSE_PENETRATION_RATE` | 近接防御貫通率 |
| `RANGED_DEFENSE_PENETRATION_RATE` | 間接防御貫通率 |
| `MAGIC_DEFENSE_PENETRATION_RATE` | 魔法防御貫通率 |
| `LIFE_STEAL` | ライフスティール |

### 4.4 防御系

| 物理名 | 論理名 |
|---|---|
| `DEFENSE` | 防御力（全ダメージ共通） |
| `MELEE_DEFENSE` | 近接防御力 |
| `RANGED_DEFENSE` | 間接防御力 |
| `MAGIC_DEFENSE` | 魔法防御力 |
| `EVASION` | 回避率 |
| `KNOCKBACK_RESISTANCE` | ノックバック耐性 |

### 4.5 属性系

属性は `FIRE` / `ICE` / `LIGHTNING` ごとに以下のステータスを持つ。すべて単位は `%`。毒は属性ではなく状態異常として扱う。

| 接尾辞 | 用途 |
|---|---|
| `_DAMAGE_INCREASE` | 対応属性ダメージ増加 |
| `_RESISTANCE` | 対応属性耐性 |
| `_RESISTANCE_CAP` | 対応属性耐性として計算できる上限値（初期値 75%） |
| `_PENETRATION` | 対応属性耐性の相殺 |

### 4.6 状態異常系

燃焼、凍結、冷気、感電、毒状態、盲目、衰弱、回復阻害はそれぞれ付与確率増加と付与耐性を持つ。燃焼・感電・毒状態は追加でDoTダメージ増加、DoT耐性、DoT貫通を持つ。毒状態の物理名は `POISONED_` を使う。

### 4.7 回復・ユーティリティ系

| 物理名 | 論理名 |
|---|---|
| `HP_REGEN` | HP回復力 |
| `MP_REGEN` | MP回復力 |
| `ENERGY_REGEN` | EN回復力 |
| `MOVEMENT_SPEED` | 移動速度 |
| `COOLDOWN_REDUCTION` | クールダウン短縮率（`ceil(基本CD × max(0, 1 - 短縮率 / 100))`） |
| `CAST_TIME_REDUCTION` | 詠唱時間短縮率 |
| `MANA_COST_REDUCTION` | MP消費軽減率 |
| `ENERGY_COST_REDUCTION` | エネルギー消費軽減率 |
| `HEALING_INCREASE` | 回復量増加（自身のHP回復） |
| `CONDITION_DURATION_INCREASE` | 状態異常持続時間増加（自身が付与する状態異常） |
| `SHIELD_RECHARGE_REDUCTION` | シールドリチャージ待機短縮率 |
| `SHIELD_RECHARGE_RATE` | eligible tick ごとのシールド追加回復量 |
| `MINING_SPEED` | 採集速度（1回の採集判定で与える破壊力） |
| `INVENTORY_SLOTS` | インベントリスロット数。基礎値24、プレイヤーレベル5ごとに1増加し、最小実効値は0 |
| `QUEST_LIMIT` | クエスト受領上限。基礎値3 |

## 5. ステータスカテゴリ

物理名: `StatusType.Category`

| 物理名 | 論理名 | 対象 |
|---|---|---|
| `RESOURCE` | リソース | HP / MP / EN / Shield |
| `PRIMARY` | 基本能力値 | STR / DEX / INT / VIT / AGI / LUK |
| `OFFENSE` | 攻撃 | 攻撃力・会心・命中など |
| `ELEMENT` | 属性 | 属性ダメージ増加・耐性・貫通 |
| `CONDITION` | 状態異常 | 付与確率・付与耐性・DoT補正 |
| `DEFENSE` | 防御 | 防御・魔法防御・回避・ノックバック耐性 |
| `UTILITY` | ユーティリティ | 自然回復・移動速度・短縮率 |

## 6. 関連 feature とのモデル関係

- `player`
  - [[03_1-モデル定義]].プレイヤーセッション がステータススナップショットを保持する。
- `account`
  - [[02_1-モデル定義]].アカウントモード と `level` により補正値が変わる。
- `buff`
  - 有効バフはステータス種別ごとの補正値として合算される。
