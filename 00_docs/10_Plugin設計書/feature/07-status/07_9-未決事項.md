# 07_9-未決事項

## 1. ステータス計算式の拡張

現在の実装では、基礎値、アカウントモード補正、現在クラスの `baseStats` / `growthPerLevel` による職業補正、装備・セット効果補正、スキルツリー補正、パッシブスキル補正、バフ補正、基本能力値からの派生補正を扱う。プレイヤーレベルによる直接の戦闘ステータス補正はなく、レベル5ごとの `INVENTORY_SLOTS` 加算だけを行う。権限値はステータス補正に使用しない。
以下は未確定事項として扱う。

- 基本能力値から派生ステータスへの現在係数のバランス調整（現在値は [[07_1-モデル定義]].基本能力値 に定義）

近接 / 間接 / 魔法攻撃力の派生式は次のとおり採用済みである。

```text
種別攻撃力 = (ATTACK + 対応する種別攻撃力)
            × (1 + 対応する基本能力値 / 100)
```

武器の主攻撃力は、攻撃種別に対応する `MELEE_ATTACK` / `RANGED_ATTACK` / `MAGIC_ATTACK` で指定する。
