# 07_9-未決事項

## 1. ステータス計算式の拡張

現在の実装では、基礎値、アカウントモード補正、職業の Shield 系補正、装備・セット効果補正、スキルツリー補正、パッシブスキル補正、バフ補正、基本能力値からの派生補正を扱う。プレイヤーレベルによる直接の戦闘ステータス補正はなく、レベル5ごとの `INVENTORY_SLOTS` 加算だけを行う。権限値はステータス補正に使用しない。
以下は未確定事項として扱う。

- 近接 / 遠隔 / 魔法攻撃力の派生計算式
- 基本能力値から派生ステータスへの現在係数のバランス調整（現在値は [[07_1-モデル定義]].基本能力値 に定義）

## 2. 永続化方針

現在 HP / MP / EN / Shield と Shield 最終変更時刻はオンライン中のメモリ状態として扱う。
ログアウト時に保存対象とするかは未確定。

## 3. 表示名の管理

ステータス ID、表示名、カテゴリ、単位、小数桁、範囲可否の正本は `40_filebase/75.shared.status/v1.status_types.yml` であり、`StatusType.kt` は生成物である。
プレイヤーごとの言語切替を導入する場合、filebase を単一言語のまま維持するか、メッセージリソースへ表示名を移すかは未確定。

## 4. レベルアップ演出

- レベルアップ時に即時で HUD 演出、サウンド、メッセージを出すかは未確定。
- 再計算契機は account feature から発火するが、演出責務を `account` / `status` / `hud` のどこへ置くかは今後確定する。

## 5. Shield 再充填の時間基準

- `withCurrentShield` は Shield が実際に変化するたびに `shieldChangedAtMs` を更新する。このため現行実装は、再充填を1回行った後も再び短縮後の待機時間を経過するまで次の再充填を行わない。
- `refreshStatus` は新しいスナップショットを生成して現在値を移すため、ステータス再計算時にも Shield 再充填待機が現在時刻から再開する。
- 最初の待機後は毎秒連続回復させるのか、現行どおり回復ごとに待機させるのか、ステータス再計算で待機を再開するのかを確定する必要がある。

## 6. 現在 Shield のコマンド表示

`/status` は最大 Shield と Shield 関連ステータスを一覧へ表示する一方、`P_5105` / `P_5106` の現在リソース表示は HP / MP / EN のみである。現在 Shield 専用表示を追加するかは未確定。
