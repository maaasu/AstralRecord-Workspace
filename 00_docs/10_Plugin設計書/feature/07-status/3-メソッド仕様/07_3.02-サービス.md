# 07_3.02-サービス

## 1. StatusService メソッド仕様

### ステータス取得

クラス名: `StatusService`  
物理名: `getStatus`

処理内容:

1. [[03_1.00-モデル定義]].プレイヤーセッション から [[07_1.00-モデル定義]].ステータススナップショット を取得する。
2. ステータス値一覧が空の場合、[[07_3.02-サービス]].ステータス再計算 を実行して結果を返す。
3. ステータス値一覧が存在する場合、保持済みのステータススナップショットを返す。

### ステータス再計算

クラス名: `StatusService`  
物理名: `refreshStatus`

処理内容:

1. [[05_3.02-サービス]].期限切れバフ削除 を実行する。
2. 現在の [[07_1.00-モデル定義]].ステータススナップショット を退避する。
3. 全 [[07_1.00-モデル定義]].ステータス種別 について、基礎値・アカウントモード補正・レベル補正・装備補正・バフ補正を計算する。
   - 装備補正は、現在装備中の防具、オフハンド、拡張アクセサリ、メインハンド選択アイテムの equipment instance から取得する。
   - equipment の `FLAT` は加算、`SCALAR` は補正前値に対する倍率加算として扱う。
   - 装備に `setId` が設定されている場合は装備数を集計し、`/api/seteffect/{setId}` の `pieces[].count` 条件を満たすステータス補正を累積適用する。
4. 退避したステータス値一覧が空の場合、[[07_3.02-サービス]].全リソース最大値回復（内部） で HP / MP / EN を最大値まで回復した状態に初期化する。
5. 退避したステータス値一覧が存在する場合、現在 HP / MP / EN を維持しながら新しい最大値の範囲内へ丸める。
6. [[03_1.00-モデル定義]].プレイヤーセッション に再計算後のステータススナップショットを設定して返す。

### バフ適用

クラス名: `StatusService`  
物理名: `applyBuff`

処理内容:

1. [[05_3.02-サービス]].バフ付与 を実行する。
2. 適用結果が失敗の場合、[[07_3.02-サービス]].ステータス取得 を実行して現在状態を返す。
3. 適用結果が成功の場合、[[07_3.02-サービス]].ステータス再計算 を実行して結果を返す。

### バフ解除

クラス名: `StatusService`  
物理名: `removeBuff`

処理内容:

1. [[05_3.02-サービス]].バフ解除 を実行する。
2. [[07_3.02-サービス]].ステータス再計算 を実行して結果を返す。

クラス名: `StatusService`

処理内容:

### スナップショット生成

クラス名: `StatusService`  
物理名: `createSnapshot`

処理内容:

1. 全 [[07_1.00-モデル定義]].ステータス種別 を走査する。
2. [[07_3.02-サービス]].基礎値取得 でステータス種別ごとの基礎値を取得する。
3. [[07_3.02-サービス]].補正値取得 でアカウントモード・レベル・装備・スキル・バフを合算した補正値を取得する。
4. 基礎値と補正値から [[07_1.00-モデル定義]].ステータス値 を生成する。
5. 全ステータス値、現在 HP `0.0`、現在 MP `0.0`、現在 EN `0.0`、計算日時で [[07_1.00-モデル定義]].ステータススナップショット を生成する。

### 全リソース最大値回復（内部）

クラス名: `StatusService`  
物理名: `restoreAllInternal`

責務:

[[07_3.02-サービス]].全リソース全回復 と初回ステータス初期化からのみ呼び出す内部用補助メソッド。外部の feature やコマンドから直接呼び出さない。

処理内容:

1. 最大 HP / 最大 MP / 最大 EN を取得する。
2. [[07_3.09-モデル操作]].現在リソース更新 で現在 HP / MP / EN を最大値へ更新する。
3. 更新後のステータススナップショットを返す。

クラス名: `StatusService`

処理内容:

1. [[07_3.02-サービス]].アカウントモード補正取得 で [[02_1.00-モデル定義]].アカウントモード 補正を取得する。

### レベル補正取得

クラス名: `StatusService`
物理名: `getLevelBonus`

処理内容:

1. `level <= 1` の場合、補正値 `0.0` を返す。
2. `level >= 2` の場合、以下の補正を返す。

	以下に記載のない [[07_1.00-モデル定義]].ステータス種別 は補正値 `0.0` とする。

	| ステータス種別 | 補正値 |
	|---|---:|
	| 最大HP（`MAX_HEALTH`） | `(level * 2.0) + (floor(level / 5) * 3.0)` |
	| 最大MP（`MAX_MANA`） | `(level * 1.0) + (floor(level / 6) * 2.0)` |
	| 最大EN（`MAX_ENERGY`） | `(level * 3.0) + (floor(level / 4) * 2.0)` |
	| 筋力（`STRENGTH`）, 器用さ（`DEXTERITY`）, 知力（`INTELLIGENCE`）, 体力（`VITALITY`）, 敏捷性（`AGILITY`）, 幸運（`LUCK`） | `floor(level / 2.0)` |
	| 攻撃力（`ATTACK`）, 近接攻撃力（`MELEE_ATTACK`）, 遠隔攻撃力（`RANGED_ATTACK`）, 魔法攻撃力（`MAGIC_ATTACK`） | `floor(level * 0.7) + floor(level / 8.0)` |
	| 物理防御力（`DEFENSE`）, 魔法防御力（`MAGIC_DEFENSE`） | `floor(level * 0.6) + floor(level / 10.0)` |
	| 命中率（`ACCURACY`）, 回避率（`EVASION`） | `floor(level / 4.0)` |
	| 会心率（`CRITICAL_RATE`） | `floor(level / 15.0) * 0.5` |
	| HP回復力（`HP_REGEN`） | `floor(level / 10.0) * 0.5` |
	| MP回復力（`MP_REGEN`） | `floor(level / 12.0) * 0.4` |
	| EN回復力（`ENERGY_REGEN`） | `floor(level / 8.0) * 0.8` |
	| 移動速度（`MOVEMENT_SPEED`） | `floor(level / 20.0) * 1.0` |
