# 07_3.01-イベント

## 1. PlayerHeldItemStatusEventHandler メソッド仕様

### ホットバー選択変更

クラス名: `PlayerHeldItemStatusEventHandler`
物理名: `onPlayerItemHeld`

イベント:

- `PlayerItemHeldEvent`
- 優先度: `MONITOR`
- `ignoreCancelled = true`

処理内容:

1. `runSafely` の処理境界へ入る。
2. Bukkit プレイヤーに対応する [[03_1.00-モデル定義]].プレイヤーセッション をキャッシュから取得する。
3. セッションが存在しない場合は処理を終了する。
4. プラグインの同期 scheduler へ次 tick 実行を登録する。
5. 次 tick 時点でも Bukkit プレイヤーがオンラインの場合、[[07_3.02-サービス]].ステータス再計算 を実行する。

結果:

- 選択後の main hand item を装備補正へ含めたステータススナップショットへ更新する。
- [[28_README]] が定義する `HOTBAR_SLOT` の入力所有権や勝者選択には関与しない。

例外・終了条件:

- event が他処理でキャンセル済みの場合は Bukkit により呼び出されない。
- 未捕捉例外は `LogId.E_3002`、context `status_held_item:<playerName>` で記録し、イベント処理外へ送出しない。
