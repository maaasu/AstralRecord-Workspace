# 07_3.05-タスク

## 1. StatusRegenTask メソッド仕様

### 定期回復開始

クラス名: `StatusRegenTask`
物理名: `start`

処理内容:

1. 既にタスクが存在する場合は何もしない。
2. Bukkit Scheduler に `20tick` 間隔の同期定期タスクを登録する。
3. 登録したタスク参照を保持する。

### 定期回復停止

クラス名: `StatusRegenTask`
物理名: `stop`

処理内容:

1. タスクが存在しない場合は何もしない。
2. タスクが存在する場合はキャンセルする。
3. タスク参照を `null` に戻す。

### 定期回復処理

クラス名: `StatusRegenTask`
物理名: `tick`

処理内容:

1. [[03_1.00-モデル定義]].プレイヤーキャッシュ から全 [[03_1.00-モデル定義]].プレイヤーセッション を取得する。
2. Bukkit プレイヤーがオンラインではない、または死亡している場合は対象外とする。
3. 対象プレイヤーに対し、[[07_3.05-タスク]].単体回復処理 を実行する。

### 単体回復処理

クラス名: `StatusRegenTask`
物理名: `applyRegen`

処理内容:

1. [[07_3.02-サービス]].ステータス取得 で現在状態を取得する。
2. HP / MP / EN の 1 秒あたり回復量を、各自然回復ステータス値の `1/5` として計算する。範囲値は処理時に `rollValue` で確定する。

	| 項目 | 内容 |
	|---|---|
	| HP | HP回復量 = HP回復力（`HP_REGEN`） / `5.0` |
	| MP | MP回復量 = MP回復力（`MP_REGEN`） / `5.0` |
	| EN | EN回復量 = EN回復力（`ENERGY_REGEN`） / `5.0` |

3. 現在 HP が最大 HP 未満、かつ HP 回復量が `0` より大きい場合、[[07_3.02-サービス]].HP回復 を実行する。
4. 現在 MP が最大 MP 未満、かつ MP 回復量が `0` より大きい場合、[[07_3.02-サービス]].MP回復 を実行する。
5. 現在 EN が最大 EN 未満、かつ EN 回復量が `0` より大きい場合、[[07_3.02-サービス]].EN回復 を実行する。
6. [[07_3.05-タスク]].Shield再充填可否判定 が `true` の場合、`1.0 + SHIELD_RECHARGE_RATE` を回復量として [[07_3.02-サービス]].Shield回復 を実行する。`SHIELD_RECHARGE_RATE` が範囲値の場合は処理時に確定する。

### Shield再充填可否判定

クラス名: `StatusRegenTask`
物理名: `shouldRechargeShield`

処理内容:

1. 最大 Shield が `0` 以下、または現在 Shield が最大値以上の場合は `false` を返す。
2. `SHIELD_RECHARGE_REDUCTION` を処理時に確定し、`0.0` 以上 `95.0` 以下へ丸める。
3. 基準待機 `10,000ms` に `1 - reduction / 100` を乗算して四捨五入し、最短 `500ms` との大きい方を待機時間とする。
4. `shieldChangedAtMs` が `0` 以下の場合は `false` を返す。
5. 現在 epoch milliseconds と `shieldChangedAtMs` の差が待機時間以上なら `true`、未満なら `false` を返す。
