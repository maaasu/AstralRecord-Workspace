# 07_3.09-モデル操作

## 1. StatusSnapshot メソッド仕様

### ステータス値取得

クラス名: `StatusSnapshot`
物理名: `getValue`

処理内容:

1. 指定された [[07_1.00-モデル定義]].ステータス種別 に対応する [[07_1.00-モデル定義]].ステータス値 を取得する。
2. 対応する値が存在しない場合は `null` を返す。

### 最大値取得

クラス名: `StatusSnapshot`
物理名: `getMaxValue`

処理内容:

1. 指定された [[07_1.00-モデル定義]].ステータス種別 の [[07_1.00-モデル定義]].ステータス値 を取得する。
2. 対応する値が存在する場合は合計値の上限を返す。リソース上限系は単一値のため下限と上限が一致する。
3. 対応する値が存在しない場合は `0.0` を返す。

### ステータス値確定

クラス名: `StatusSnapshot`
物理名: `rollValue`

処理内容:

1. 指定された [[07_1.00-モデル定義]].ステータス種別 に対応する [[07_1.00-モデル定義]].ステータス値 を取得する。
2. 対応する値が存在する場合は、その値の下限以上・上限以下からランダムに1値を確定する。下限と上限が同値ならその値を返す。
3. 対応する値が存在しない場合は `0.0` を返す。

### 現在リソース丸め

クラス名: `StatusSnapshot`
物理名: `clampCurrentValues`

処理内容:

1. 最大 HP / 最大 MP / 最大 EN / 最大 Shield を取得する。
2. 現在 HP を `0` 以上、最大 HP 以下に丸める。
3. 現在 MP を `0` 以上、最大 MP 以下に丸める。
4. 現在 EN を `0` 以上、最大 EN 以下に丸める。
5. 現在 Shield を `0` 以上、最大 Shield 以下に丸める。
6. `shieldChangedAtMs` は変更せず、丸め後の新しい [[07_1.00-モデル定義]].ステータススナップショット を返す。

### 現在リソース更新

クラス名: `StatusSnapshot`
物理名: `withCurrentValues`

処理内容:

1. 指定された HP / MP（必要なら EN / Shield も含む）で新しいステータススナップショットを作成する。EN / Shield を指定しない場合は各現在値を維持する。
2. [[07_3.09-モデル操作]].現在リソース丸め を実行して有効範囲内へ丸める。
3. 丸め後の Shield が更新前の現在 Shield と異なる場合は `shieldChangedAtMs` を現在 epoch milliseconds に更新し、同値なら既存時刻を維持する。
4. 丸め後のステータススナップショットを返す。

### 現在Shield更新

クラス名: `StatusSnapshot`
物理名: `withCurrentShield`

処理内容:

1. HP / MP / EN は現在値を維持し、指定 Shield を使って [[07_3.09-モデル操作]].現在リソース更新 を実行する。
2. 有効範囲へ丸められ、実際に Shield が変化した場合は変更時刻も更新されたスナップショットを返す。

### 空スナップショット生成

クラス名: `StatusSnapshot`
物理名: `empty`

処理内容:

1. ステータス値一覧が空のステータススナップショットを作成する。
2. 現在 HP / MP / EN / Shield は `0.0`、`shieldChangedAtMs` は `0` とする。
3. 計算日時は `LocalDateTime.MIN` とする。

## 2. StatusType メソッド仕様

### 表示値整形

クラス名: `StatusType`
物理名: `formatValue`

処理内容:

1. [[07_1.00-モデル定義]].ステータス種別 に定義された小数桁数で数値を整形する。
2. [[07_1.00-モデル定義]].ステータス種別 に定義されたサフィックスを末尾へ付与する。
3. 整形後の文字列を返す。

### 符号付き表示値整形

クラス名: `StatusType`
物理名: `formatSignedValue`

処理内容:

1. 値が `0` より大きい場合は先頭に `+` を付与する。
2. [[07_3.09-モデル操作]].表示値整形 を実行する。
3. 符号付きの整形後文字列を返す。

### 範囲表示値整形

クラス名: `StatusType`
物理名: `formatRange`, `formatSignedRange`

処理内容:

1. 最小値と最大値が同値なら単一値として整形する。
2. 異なる場合は各値を整形し、`最小値 ～ 最大値` 形式で返す。

### カテゴリ別種別取得

クラス名: `StatusType`
物理名: `byCategory`

処理内容:

1. 全 [[07_1.00-モデル定義]].ステータス種別 を走査する。
2. 指定された [[07_1.00-モデル定義]].ステータスカテゴリ に一致する種別のみを抽出する。
3. 抽出したステータス種別一覧を返す。
