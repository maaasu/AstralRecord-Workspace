# 07_3-サービス

## 1. StatusService メソッド仕様

### ステータス取得

クラス名: `StatusService`
物理名: `getStatus`

処理内容:

1. [[03_1-モデル定義]].プレイヤーセッション から [[07_1-モデル定義]].ステータススナップショット を取得する。
2. [[05_3-サービス]].期限切れバフ削除 を実行する。
3. ステータス値一覧が空、または期限切れバフを1件以上削除した場合、[[07_3-サービス]].ステータス再計算 を実行して結果を返す。
4. `swordsman_shield_activate` の習得済み個体が使用許可済みでない場合、現在 Shield を `0` として状態を正規化し、シールドリチャージ状態を破棄する。タンクシールドアクティベートはパッシブスロット設定を要求しない。
5. それ以外の場合、保持済みのステータススナップショットを返す。

### ステータス再計算

クラス名: `StatusService`
物理名: `refreshStatus`

処理内容:

1. [[05_3-サービス]].期限切れバフ削除 を実行する。
2. 現在の [[07_1-モデル定義]].ステータススナップショット を退避する。
3. 全 [[07_1-モデル定義]].ステータス種別 について、基礎値・アカウントモード補正・プレイヤーレベル由来の `INVENTORY_SLOTS` 補正・現在クラスの職業補正・装備補正・スキルツリー補正・パッシブスキル補正・バフ補正を計算する。
   - 職業補正は、現在クラスの `baseStats` と `growthPerLevel × (classLevel - 1)` をステータス種別ごとに加算する。クラスレベルは現在クラスの `maxLevel` の範囲へ丸め、未ロードのクラスや未定義のステータスは `0.0` とする。
   - 装備補正は、現在装備中の防具、オフハンド、拡張アクセサリ、メインハンド選択アイテムの equipment instance から取得する。最大耐久値が正で現在耐久値が0以下の破損装備、`requiredLevel` または現在クラスの `requiredClasses[].level` を満たさない装備は、個別補正・セット効果数の双方から除外する。メインハンドの `slot=WEAPON` かつ `handType=TWO` の両手武器を装備中は、オフハンド装備とそのセット効果数を個別補正・セット効果の集計から除外するため、両手武器による攻撃時と被ダメージ時もオフハンド効果を参照しない。
   - equipment の `FLAT` は加算する。`SCALAR` は同一装備内に同じステータスの `FLAT` がある場合だけ、その装備のフラット値へ適用する。複数の `SCALAR` は装備単位で最後に定義された値を採用し、対応する `FLAT` がない `SCALAR` は無効とする。
   - 装備に `setId` が設定されている場合は装備数を集計し、`/api/seteffect/{setId}` の `pieces[].count` 条件を満たすステータス補正を累積適用する。
4. 基本能力値の最終値から派生ステータス補正を計算して加算する。派生先と係数は [[07_1-モデル定義]].基本能力値 を正本とする。
5. 退避したステータス値一覧が空の場合、[[07_3-サービス]].全リソース最大値回復（内部） で HP / MP / ENG を最大値まで回復する。タンクシールドアクティベートが有効な場合だけ Shield も最大値まで回復する。
6. 退避したステータス値一覧が存在する場合、現在 HP / MP / ENG を維持しながら新しい最大値の範囲内へ丸める。タンクシールドアクティベートが無効なら現在 Shield は `0` とし、有効なら現在 Shield を維持して新しい最大値へ丸める。既存セッションで無効から有効へ変化した場合、または `MAX_SHIELD` が0以下から正数へ変化した場合は即時付与せず、通常30秒リチャージを開始する。正数の `MAX_SHIELD` がさらに上昇した場合も増加を検知し、現在 Shield が正数かつ新しい最大値未満なら設定済み再充填パッシブの段階リチャージを開始し、現在 Shield が0なら通常リチャージを開始する。正数から `MAX_SHIELD` が0へ変化した場合は進行中の再充填状態と表示capacityを破棄する。
7. [[03_1-モデル定義]].プレイヤーセッション に再計算後のステータススナップショットを設定する。`MAX_SHIELD` の付け外し・上昇では即時満タンへ戻さない。`MOVEMENT_SPEED = 100` をバニラプレイヤーの標準速度 `0.1` とし、Bukkit プレイヤーの `Attribute.MOVEMENT_SPEED` には `0.1 × MOVEMENT_SPEED / 100` として反映する。`INVENTORY_SLOTS` は小数点以下を切り捨て、最小0として BAG の実効容量へ反映する。
8. 再計算後のステータススナップショットを返す。

### タンクシールドアクティベート

シールドの現在値を扱う前提条件は、`PassiveSkillService.isPassiveSkillActive` による `swordsman_shield_activate`（タンクシールドアクティベート）の有効判定とする。判定は習得済み個体とスキルの使用許可を満たす場合に `true` になる。`passive.bindRequired: false` のため現在のパッシブスロット設定は判定条件に含めない。判定サービスが未接続の場合も安全側に倒して無効とする。

`MAX_SHIELD` は class・equipment・skilltree・他のパッシブから上限候補として計算するが、タンクシールドアクティベートが無効な間は初期化・明示回復・通常リチャージ・段階リチャージのいずれも現在 Shield を増加させない。無効化を検知した時点で既存の現在 Shield とリチャージ進行を破棄する。有効化を既存セッション中に検知した場合は、現在 Shield を即時満タンにせず通常30秒リチャージを開始する。正数の `MAX_SHIELD` 上昇を既存セッション中に検知した場合は、現在 Shield が正数かつ新しい最大値未満なら設定済み再充填パッシブの段階リチャージを開始し、現在 Shield が0なら通常リチャージを開始する。

### 一時固定値バフ適用

クラス名: `StatusService`
物理名: `applyTemporaryFlatBuff`

処理内容:

1. 指定ステータス、正の上昇値、持続秒数からセッション内限定の `FLAT` バフを生成する。
2. 同一プレイヤー・同一ステータスの管理コマンド用一時バフがある場合は削除し、新しい値と失効時刻で置き換える。
3. [[07_3-サービス]].ステータス再計算 を実行する。
4. 付与した [[05_1-モデル定義]].アクティブバフを返す。

入力:

- `player`: 対象プレイヤー
- `statusType`: 上昇させる [[07_1-モデル定義]].ステータス種別
- `value`: 正の有限値
- `durationSeconds`: `1`〜`107374182` 秒

例外時挙動:

- 上昇値または持続秒数が有効範囲外の場合は `IllegalArgumentException` を送出する。

### HP回復

クラス名: `StatusService`
物理名: `recoverHp`

処理内容:

1. [[07_3-サービス]].ステータス取得 で現在状態を取得する。
2. 回復量が `0` 以下の場合、現在状態を変更せず返す。
3. 現在 HP に回復量を加算し、[[07_3-モデル操作]].現在リソース更新 で有効範囲内へ丸める。
4. [[03_1-モデル定義]].プレイヤーセッション に更新後のステータススナップショットを設定する。
5. 更新後の現在 HP が更新前より増加した場合だけ、上限・`HEALING_INCREASE` 適用後の実回復量を HP 回復通知へ渡す。回復阻害中または最大 HP 到達済みで増加がない場合は通知しない。
6. 更新後のステータススナップショットを返す。

2引数の `recoverHp` は自身による明示的な HP 回復として扱う。回復元プレイヤーと回復手段を持つ `HealthRecoveryContext` を渡す overload では、通知に対象プレイヤー、実回復量、回復元プレイヤー（いなければ `null`）、回復手段を含める。`context=null` は HP 自然回復などの常時回復を意味し、状態だけを更新して HP 回復通知を発生させない。

### Shield リチャージ

クラス名: `StatusService`

- `configureShieldRecharge` は有効なパッシブから、Shield残存時にだけ使う待機秒数と毎秒回復率を設定する。未設定時またはShield破壊時は従来の基礎30秒・一括回復設定を使う。設定だけが存在しても、タンクシールドアクティベートが無効なら現在 Shield は増加しない。
- `startShieldRecharge` はタンクシールドアクティベートが有効な Player のShieldが0になった実ダメージ後、またはセッション中の `MAX_SHIELD` 0 以下から正数への遷移時・正数の上昇時に現在Shieldが0の場合に呼び、パッシブ設定を参照せず開始時点の `SHIELD_RECHARGE_REDUCTION` を適用した通常全回復を設定する。無効時は状態を作成しない。
- `startShieldRechargeWhileRetained` はタンクシールドアクティベートと設定済みパッシブがあり、実ダメージ後、または正数の `MAX_SHIELD` 上昇を検知した時点で現在Shieldが正数かつ最大未満の場合だけ呼び、設定待機後の段階回復を設定する。
- `extendShieldRecharge` はタンクシールドアクティベートが有効な進行中状態だけ受理し、攻撃者の基礎追加秒数へ呼出時点の被ダメ側 `SHIELD_RECHARGE_REDUCTION` を適用して完了時刻へ加算する。
- `completeShieldRechargeIfReady` はタンクシールドアクティベートが有効な場合だけ状態の種別に応じて、通常全回復なら完了時に `MAX_SHIELD` を設定し、段階回復なら待機後の定期処理ごとに回復量を加算する。無効化を検知した状態は回復せず破棄する。段階回復は `MAX_SHIELD` 到達時、通常全回復は1回の適用後に状態を取り除く。
- `clearShieldRechargeConfiguration` は設定済みパッシブによる段階回復だけを解除し、既に始まっているShield破壊後の通常全回復は中断しない。
- `restoreAll`、ログアウト、死亡開始ではリチャージ状態を破棄する。タンクシールドアクティベートが有効な場合だけ Shield を最大値へ戻し、無効なら現在 Shield を `0` とする。
- リチャージ状態と表示capacityはセッション内だけで保持し、保存しない。

### 全リソース全回復

クラス名: `StatusService`
物理名: `restoreAll`

処理内容:

1. [[07_3-サービス]].ステータス取得 で現在状態を取得する。
2. [[07_3-サービス]].全リソース最大値回復（内部） で HP / MP / ENG を最大値まで回復する。タンクシールドアクティベートが有効な場合だけ Shield も最大値まで回復する。

### 有効セット効果一覧取得

クラス名: `StatusService`
物理名: `getActiveSetEffects`

処理内容:

1. `ItemService` が未設定の場合は空リストを返す。
2. 装備要件を満たし、破損していない装備から `setId` ごとの装備数を集計する。最大耐久値が正で現在耐久値が0以下の装備は、`/status detail` の装備数にも含めない。
3. `ItemService.findSetEffectById` でセット効果を取得し、装備数以上の正数 `pieces[].count` を発動段階として昇順で集計する。
4. 発動段階が1件以上あるセットだけを、set ID、set 名、装備数、発動段階一覧を持つ `ActiveSetEffect` として返す。

### スナップショット生成

クラス名: `StatusService`
物理名: `createSnapshot`

処理内容:

1. 全 [[07_1-モデル定義]].ステータス種別 を走査する。
2. [[07_3-サービス]].基礎値取得 でステータス種別ごとの基礎値を取得する。
3. [[07_3-サービス]].補正値取得 でアカウントモード・プレイヤーレベル・現在クラス・装備・スキル・バフを合算した補正値を取得する。
4. 基礎値と補正値から [[07_1-モデル定義]].ステータス値 を生成する。
5. 基本能力値から派生する補正を全ステータス値へ加算する。
6. 全ステータス値、現在 HP / MP / ENG / Shield `0.0`、Shield 変更時刻として現在 epoch milliseconds、計算日時で [[07_1-モデル定義]].ステータススナップショット を生成する。

### 全リソース最大値回復（内部）

1. 最大 HP / 最大 MP / 最大 ENG / 最大 Shield を取得する。
2. [[07_3-モデル操作]].現在リソース更新 で現在 HP / MP / ENG を最大値へ更新する。タンクシールドアクティベートが有効な場合だけ現在 Shield も最大値へ更新し、無効なら `0` へ更新する。
3. 更新後のステータススナップショットを返す。

### 基礎値取得

クラス名: `StatusService`
物理名: `getBaseValue`

処理内容:

1. 指定された [[07_1-モデル定義]].ステータス種別 に対応する基礎値を返す。

	| ステータス種別 | 基礎値 |
	|---|---:|
	| 最大HP（`MAX_HEALTH`） | `20.0` |
	| 最大MP（`MAX_MANA`） | `10.0` |
	| 最大ENG（`MAX_ENERGY`） | `100.0` |
	| 最大Shield（`MAX_SHIELD`） | `0.0` |
	| 筋力（`STRENGTH`） | `5.0` |
	| 器用さ（`DEXTERITY`） | `5.0` |
	| 知力（`INTELLIGENCE`） | `5.0` |
	| 体力（`VITALITY`） | `5.0` |

### 補正値取得

クラス名: `StatusService`
物理名: `getBonusValue`

処理内容:

1. [[07_3-サービス]].アカウントモード補正取得 で [[02_1-モデル定義]].アカウントモード 補正を取得する。
2. [[07_3-サービス]].レベル補正取得 で、`INVENTORY_SLOTS` にだけ [[02_1-モデル定義]].プレイヤーレベル進行 の `level` 補正を取得する。
3. 現在クラスの `baseStats` と `growthPerLevel × (classLevel - 1)` による職業補正を、対象のステータス種別へ加算する。
4. 装備補正を加算する。`FLAT` を先に加算し、`SCALAR` はその時点の基礎値と非バフ補正へ乗算する。
5. スキルツリー補正とパッシブスキル補正を順に加算する。
6. 基礎値と非バフ補正の合計を [[05_3-サービス]].バフ補正合計取得 へ渡し、バフ補正を取得する。
7. 非バフ補正とバフ補正を合算して返す。

## 状態異常との統合

`recoverHp`、`recoverMp`、`recoverEnergy`、`recoverShield` は回復阻害中なら現在値を変更しない。自然回復とポーションもこれらのメソッドを経由する。`restoreAll` は死亡後リスポーン、管理コマンド、NPC の `restore_status` action 用、`restoreMpAndEnergy` はメディテーション完了時の明示的MP / ENG全回復用の例外として回復阻害を無視する。

`applyMovementSpeed` は通常の移動速度へ `ConditionService.movementSpeedMultiplier` を掛け、冷気を0.5、凍結または感電の拘束中を0として反映する。
