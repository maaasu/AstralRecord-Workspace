# 07_3-コマンド

## 1. StatusCommand メソッド仕様

### ステータスコマンド実行

クラス名: `StatusCommand`  
物理名: `executePlayerCommand`

処理内容:

1. 引数なし、または第1引数が `show` の場合、ステータス表示を通常表示で実行する。
2. 第1引数が `detail` の場合、ステータス表示を詳細表示で実行する。
3. 第1引数が `refresh` の場合、[[07_3-サービス]].ステータス再計算 を実行し、以下メッセージを送信した後、ステータス表示を通常表示で実行する。

	| 項目 | 内容 |
	|---|---|
	| ID | `PlayerMsgId.P_5102` |
	| レベル | `INFO` |
	| テンプレート | `&aステータスを再計算しました。` |
	| 出力条件 | `/status refresh` 実行時 |
	| 引数 | - |

4. 対応外引数の場合、usage を送信する。

### ステータス表示

クラス名: `StatusCommand`  
物理名: `showStatus`

処理内容:

1. [[07_3-サービス]].ステータス取得 で [[07_1-モデル定義]].ステータススナップショット を取得する。
2. 最大 HP / 最大 MP / 最大 EN を取得する。
3. 見出しメッセージを送信する。

	| 項目 | 内容 |
	|---|---|
	| ID | `PlayerMsgId.P_5100` |
	| レベル | `INFO` |
	| テンプレート | `&6==== &eステータス: {0} &6====` |
	| 出力条件 | ステータス表示開始時 |
	| 引数 | アカウント名 |

4. 現在 HP / MP メッセージを送信する。

	| 項目 | 内容 |
	|---|---|
	| ID | `PlayerMsgId.P_5105` |
	| レベル | `INFO` |
	| テンプレート | `&c現在HP&7: &f{0}&7/&f{1} &8| &9現在MP&7: &f{2}&7/&f{3}` |
	| 出力条件 | ステータス表示時 |
	| 引数 | 現在HP, 最大HP, 現在MP, 最大MP |

5. 現在 EN メッセージを送信する。

	| 項目 | 内容 |
	|---|---|
	| ID | `PlayerMsgId.P_5106` |
	| レベル | `INFO` |
	| テンプレート | `&a現在EN&7: &f{0}&7/&f{1}` |
	| 出力条件 | ステータス表示時 |
	| 引数 | 現在EN, 最大EN |

6. 各 [[07_1-モデル定義]].ステータス種別 の値を走査し、通常表示の場合は合計値メッセージを送信する。最小値と最大値が異なる場合は `最小値 ～ 最大値`、同値の場合は単一値として整形する。

	| 項目 | 内容 |
	|---|---|
	| ID | `PlayerMsgId.P_5101` |
	| レベル | `INFO` |
	| テンプレート | `&e{0}&7: &f{1}` |
	| 出力条件 | 通常表示時 |
	| 引数 | ステータス表示名, 合計値 |

7. 各 [[07_1-モデル定義]].ステータス種別 の値を走査し、詳細表示の場合は基礎値・補正値・合計値メッセージを送信する。各値は通常表示と同じ範囲表記規則を用いる。

	| 項目 | 内容 |
	|---|---|
	| ID | `PlayerMsgId.P_5103` |
	| レベル | `INFO` |
	| テンプレート | `&e{0}&7: &f基礎 {1}&7 / &a補正 {2}&7 / &b合計 {3}` |
	| 出力条件 | 詳細表示時 |
	| 引数 | ステータス表示名, 基礎値, 補正値, 合計値 |

8. 詳細表示かつ有効なセット効果がある場合、セット効果見出しと発動中セット情報を送信する。

	| 項目 | 内容 |
	|---|---|
	| ID | `PlayerMsgId.P_5107`, `PlayerMsgId.P_5108` |
	| レベル | `INFO` |
	| テンプレート | `&6==== &eセット効果 &6====`, `&e{0}&7: &f装備数 {1}&7 / &a発動 {2}` |
	| 出力条件 | 詳細表示時かつ有効セット効果あり |
	| 引数 | セット名, 装備数, 発動段階（例 `2set, 4set`） |

9. 最終更新メッセージを送信する。

	| 項目 | 内容 |
	|---|---|
	| ID | `PlayerMsgId.P_5104` |
	| レベル | `INFO` |
	| テンプレート | `&7最終更新: &f{0}` |
	| 出力条件 | ステータス表示終了時 |
	| 引数 | 計算日時（`yyyy-MM-dd HH:mm:ss`） |

## 2. StatusBuffCommand メソッド仕様

### 管理者向け一時ステータスバフ付与

クラス名: `StatusBuffCommand`
物理名: `executePlayerCommand`

処理内容:

1. `/statusbuff <statusId> <value> <durationSeconds> [player]` を受け付ける。対象プレイヤー指定は最後に置き、省略時は実行者自身を対象とする。
2. 実行主体は `UserPermission.ADMIN` 以上のプレイヤーに限定する。コンソールを含むプレイヤー以外は実行できない。
3. `statusId` は共有ステータスカタログの英語 ID を大文字小文字・ハイフンとアンダースコアの差異を吸収して解決する。
4. `value` は正の有限値、`durationSeconds` は `1`〜`107374182` の整数秒のみ受け付ける。
5. 対象はオンラインかつ `AstPlayer` キャッシュ済みのプレイヤーのみ受け付ける。
6. [[07_3-サービス]].一時固定値バフ適用 を呼び出す。同一対象・同一ステータスの管理コマンド用バフが既にある場合は、値と残り時間を更新する。
7. 実行者へ `P_5109`、対象が実行者と異なる場合は対象へ `P_5113` を送信する。入力エラーと対象不在時は `P_5110`〜`P_5112` を送信する。

### 管理者向け一時ステータスバフ補完候補取得

クラス名: `StatusBuffTabCompleter`
物理名: `getPlayerCompletions`

処理内容:

1. 第1引数位置で共有ステータスカタログに定義された英語 ID を候補として返す。
2. 第4引数位置でオンラインプレイヤー名を候補として返す。
3. その他の位置では空リストを返す。

## 3. StatusTabCompleter メソッド仕様

### ステータス補完候補取得

クラス名: `StatusTabCompleter`  
物理名: `getPlayerCompletions`

処理内容:

1. 第1引数位置で `show`, `detail`, `refresh` を候補として返す。
2. それ以外の位置では空リストを返す。

## 4. コマンド仕様

- ルート: `/status`
- サブコマンド:
  - `/status show`
  - `/status detail`
  - `/status refresh`
- 実行主体: プレイヤーのみ

### 管理者向け一時ステータスバフ

- ルート: `/statusbuff`
- 使用方法: `/statusbuff <statusId> <value> <durationSeconds> [player]`
- 例: `/statusbuff ATTACK 25 60`, `/statusbuff CRITICAL_RATE 10.5 30 TargetPlayer`
- 実行主体: `UserPermission.ADMIN` 以上のプレイヤーのみ
- 持続時間: 秒。サーバ再起動または対象プレイヤーの切断時に失われる。
