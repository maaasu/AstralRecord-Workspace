# 07_3-タスク

## 1. StatusRegenTask メソッド仕様

### 定期回復開始

クラス名: `StatusRegenTask`
物理名: `start`

処理内容:

1. 既にタスクが存在する場合は何もしない。
2. Bukkit Scheduler に `20tick` 間隔の同期定期タスクを登録する。
3. 登録したタスク参照を保持する。

### 定期回復停止

クラス名: `StatusRegenTask`
物理名: `stop`

処理内容:

1. タスクが存在しない場合は何もしない。
2. タスクが存在する場合はキャンセルする。
3. タスク参照を `null` に戻す。

### 定期回復処理

クラス名: `StatusRegenTask`
物理名: `tick`

処理内容:

1. [[03_1-モデル定義]].プレイヤーキャッシュ から全 [[03_1-モデル定義]].プレイヤーセッション を取得する。
2. Bukkit プレイヤーがオンラインではない、または死亡している場合はセッション内のShieldリチャージ状態を破棄して対象外とする。
3. 対象プレイヤーに対し、[[07_3-タスク]].単体回復処理 を実行する。

### 単体回復処理

クラス名: `StatusRegenTask`
物理名: `applyRegen`

処理内容:

1. [[07_3-サービス]].ステータス取得 で現在状態を取得する。
2. HP / MP / ENG の 1 秒あたり回復量を、各自然回復ステータス値の `1/5` として計算する。MP / ENG は `StatusService.getNaturalRegenMultiplier` の条件付きパッシブ倍率を乗算し、範囲値は処理時に `rollValue` で確定する。

	| 項目 | 内容 |
	|---|---|
	| HP | HP回復量 = HP回復力（`HP_REGEN`） / `5.0` |
	| MP | MP回復量 = MP回復力（`MP_REGEN`） / `5.0` × 自然回復倍率 |
	| ENG | ENG回復量 = ENG回復力（`ENERGY_REGEN`） / `5.0` × 自然回復倍率 |

3. 現在 HP が最大 HP 未満、かつ HP 回復量が `0` より大きい場合、[[07_3-サービス]].HP回復 を回復コンテキストなしで実行する。HP は回復するが、常時回復として HP 回復数値・チャット通知は発生させない。
4. 現在 MP が最大 MP 未満、かつ MP 回復量が `0` より大きい場合、[[07_3-サービス]].MP回復 を実行する。
5. 現在 ENG が最大 ENG 未満、かつ ENG 回復量が `0` より大きい場合、[[07_3-サービス]].ENG回復 を実行する。
6. [[07_3-サービス]].Shield リチャージ完了判定を実行する。待機時刻に達していなければ何も変更せず、Shield残存時の段階回復状態なら達した後の各定期処理で毎秒回復量を加算し、最大値到達時に状態を破棄する。Shield破壊後の通常状態ならパッシブ設定にかかわらず待機完了後に一度だけShieldを一括回復する。
