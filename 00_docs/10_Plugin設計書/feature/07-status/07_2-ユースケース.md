# 07_2-ユースケース

## 1. ステータス表示

- 契機: プレイヤーが `/status`, `/status show`, `/status detail` を実行する。
- 処理: [[07_3-コマンド]].ステータスコマンド実行
- 結果: [[07_1-モデル定義]].ステータススナップショット の現在値・合計値・詳細値をプレイヤーへ表示する。

## 2. ステータス再計算

- 契機: プレイヤーが `/status refresh` を実行する、player feature のログイン反映で再計算が必要になる、または account feature のレベルアップが発生する。
- 処理: [[07_3-サービス]].ステータス再計算
- 結果: [[03_1-モデル定義]].プレイヤーセッション に最新の [[07_1-モデル定義]].ステータススナップショット を保持し、`INVENTORY_SLOTS` の確定値を BAG の実効容量へ即時反映する。既存セッションで `MAX_SHIELD` が 0 から正数へ変化した場合は即時満タンにせず Player 基礎30秒のリチャージを開始し、正数から 0 へ変化した場合は進行状態を破棄する。

## 3. リソース消費

- 契機: combat damage、player feature のドッジなど、HP / MP / EN / Shield を消費する処理。
- 処理: [[07_3-サービス]].HP消費, [[07_3-サービス]].MP消費, [[07_3-サービス]].EN消費, [[07_3-サービス]].Shield消費
- 結果: 現在値を下限 `0` 以上、最大値以下に丸めたステータススナップショットへ更新する。

## 4. リソース回復

- 契機: 定期回復タスク、回復効果、管理処理。
- 処理: [[07_3-サービス]].HP回復, [[07_3-サービス]].MP回復, [[07_3-サービス]].EN回復, [[07_3-サービス]].Shield回復
- 結果: 現在値を最大値以下に丸めたステータススナップショットへ更新する。

## 5. 定期自然回復・シールドリチャージ完了

- 契機: プラグイン起動後に開始される定期タスク。
- 処理: [[07_3-タスク]].定期回復処理
- 結果: オンラインかつ生存しているプレイヤーに HP / MP / EN の自然回復量を毎秒適用する。Shield は破壊時または既存セッションでの `MAX_SHIELD` 0 から正数への遷移時に通常リチャージを開始し、パッシブの有無にかかわらず基礎30秒後に `MAX_SHIELD` まで一括回復する。有効な再充填パッシブがある場合は、Shieldが残った状態でShieldまたはHPへの実ダメージを受けたときだけ設定待機後に毎秒 `MAX_SHIELD × rechargePercentPerSecond / 100` を加算し、最大値に達するまで state を保持する。旧来の一定時間ごとの `+1` 自動回復は行わない。

## 6. シールドリチャージ延長

- 契機: シールドを破壊した直接攻撃、またはリチャージ中に実HPダメージを与えた直接攻撃。
- 処理: 攻撃者の `SHIELD_RECHARGE_DELAY_CHANCE` で毎hit抽選し、成功時は `SHIELD_RECHARGE_DELAY_SECONDS × (1 - 被ダメ側SHIELD_RECHARGE_REDUCTION / 100)` 秒を残り時間へ追加する。
- 結果: 延長回数・総時間に上限を設けず、UIの残り時間と進捗へ即時反映する。回避・無効・0 damage・condition DoT は対象外。

## 7. 有効セット効果表示

- 契機: `/status detail`
- 処理: [[07_3-サービス]].有効セット効果一覧取得
- 結果: 装備条件を満たす set ID ごとに装備数と成立した piece 段階を `P_5107` / `P_5108` で表示する。
