# 07_5-例外・ログ・運用

## 1. 方針

`status` 機能はオンライン中のメモリ状態を扱うため、API や Repository の例外境界を持たない。
主な運用観点は、ステータス計算の整合性、定期回復タスクの重複起動防止、プレイヤー向けメッセージの表示内容である。

## 2. 主なメッセージポイント

- [[07_3-コマンド]].ステータス表示
  - `PlayerMsgId.P_5100`: ステータス見出し
  - `PlayerMsgId.P_5101`: 通常表示のステータス値
  - `PlayerMsgId.P_5103`: 詳細表示のステータス値
  - `PlayerMsgId.P_5104`: 最終更新日時
  - `PlayerMsgId.P_5105`: 現在 HP / MP
  - `PlayerMsgId.P_5106`: 現在 EN
  - `PlayerMsgId.P_5107`: セット効果見出し（detail 時）
  - `PlayerMsgId.P_5108`: 発動中セット効果（detail 時）
- [[07_3-コマンド]].ステータスコマンド実行
  - `PlayerMsgId.P_5102`: 再計算完了

## 3. イベントログ

- [[07_3-イベント]].ホットバー選択変更
  - `LogId.E_3002`: `イベント処理に失敗しました: context=%s`
  - context は `status_held_item:<playerName>` とする。
  - `runSafely` 内のキャッシュ参照、次 tick 登録、ステータス再計算で未捕捉例外が発生した場合に出力する。

## 4. タスク運用

- [[07_3-タスク]].定期回復開始 は重複起動を防止する。
- [[07_3-タスク]].定期回復停止 はプラグイン無効化時に呼び出し、BukkitTask をキャンセルする。
- 定期回復は `20tick` ごとに実行する。
- 回復量は HP回復力（`HP_REGEN`） / `5.0`, MP回復力（`MP_REGEN`） / `5.0`, EN回復力（`ENERGY_REGEN`） / `5.0` を 1 秒あたりの値として扱う。
- HP 自然回復は常時回復として扱い、HP 回復数値の TextDisplay と HP 回復チャット通知を表示しない。ポーション、スキル、ライフスティール、死亡復帰、NPC の全回復など、明示的な回復だけを表示対象とする。
- 設定済みのShield再充填パッシブは、Shield残存時の段階回復状態に限り、待機完了後の定期処理ごとに設定済みの毎秒回復量を加算し、最大値到達時に状態を破棄する。Shield破壊後はパッシブ設定にかかわらず、通常のリチャージ完了時刻が経過したtickに一括回復する。
- リチャージ状態はオンラインセッション限定で、ログアウト・死亡・全回復時に破棄する。

## 5. 注意点

- 現在 HP / MP / EN / Shield は [[07_3-モデル操作]].現在リソース丸め により `0` 以上、最大値以下へ丸める。
- ステータス再計算時、既存の現在 HP / MP / EN / Shield は維持される。ただし最大値変更により上限を超える場合は丸められる。
- 初回計算時は HP / MP / EN / Shield を最大値まで回復する。
- `/status` の専用現在値メッセージは HP / MP / EN のみで、現在 Shield は表示していない。最大 Shield と各 Shield 関連ステータスは通常のステータス一覧へ含まれる。
