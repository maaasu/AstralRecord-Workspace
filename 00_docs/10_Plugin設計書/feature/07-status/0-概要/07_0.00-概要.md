# 07_0.00-概要

## 1. 目的

`status` 機能は、オンライン中プレイヤーの戦闘・回復・表示に使うステータスを計算し、[[03_1.00-モデル定義]].プレイヤーセッション に保持する。
主目的は以下。

- 現在ステータスの取得・再計算
- HP / MP / EN / Shield の消費と回復
- アカウントモード・プレイヤーレベル・バフによる補正反映
- `/status` コマンドによるステータス表示
- オンライン中プレイヤーへの定期回復

## 2. コンテキスト

- 永続化は行わず、オンライン中の [[03_1.00-モデル定義]].プレイヤーセッション に [[07_1.00-モデル定義]].ステータススナップショット を保持する。
- [[02_1.00-モデル定義]].アカウントモード、[[02_1.00-モデル定義]].プレイヤーレベル進行 の `level` を補正条件として扱う。
- buff feature の有効バフを補正値へ加算する。
- player feature のログイン反映時に初回計算され、ドッジ処理では EN 消費に利用される。

## 3. 構成要素（実装単位）

- `service/StatusService`
  - ステータス取得、再計算、バフ適用、HP/MP/EN/Shield 消費・回復を制御する。
- `service/StatusRegenTask`
  - オンライン中プレイヤーを定期走査し、HP/MP/EN の自然回復と Shield 再充填を行う。
- `event/PlayerHeldItemStatusEventHandler`
  - 成立した hotbar slot 変更の次 tick に status を再計算する非競合 observer。
- `command/StatusCommand`, `StatusTabCompleter`
  - `/status` コマンドと補完候補を提供する。
- [[07_1.00-モデル定義]].ステータススナップショット, [[07_1.00-モデル定義]].ステータス値, [[07_1.00-モデル定義]].ステータス種別
  - ステータス計算結果と表示単位を定義する。
