# 07_2.00-ユースケース

## 1. ステータス表示

- 契機: プレイヤーが `/status`, `/status show`, `/status detail` を実行する。
- 処理: [[07_3.03-コマンド]].ステータスコマンド実行
- 結果: [[07_1.00-モデル定義]].ステータススナップショット の現在値・合計値・詳細値をプレイヤーへ表示する。

## 2. ステータス再計算

- 契機: プレイヤーが `/status refresh` を実行する、player feature のログイン反映で再計算が必要になる、または account feature のレベルアップが発生する。
- 処理: [[07_3.02-サービス]].ステータス再計算
- 結果: [[03_1.00-モデル定義]].プレイヤーセッション に最新の [[07_1.00-モデル定義]].ステータススナップショット を保持する。

## 3. リソース消費

- 契機: player feature のドッジなど、HP / MP / EN を消費する処理。
- 処理: [[07_3.02-サービス]].HP消費, [[07_3.02-サービス]].MP消費, [[07_3.02-サービス]].EN消費
- 結果: 現在値を下限 `0` 以上、最大値以下に丸めたステータススナップショットへ更新する。

## 4. リソース回復

- 契機: 定期回復タスク、回復効果、管理処理。
- 処理: [[07_3.02-サービス]].HP回復, [[07_3.02-サービス]].MP回復, [[07_3.02-サービス]].EN回復
- 結果: 現在値を最大値以下に丸めたステータススナップショットへ更新する。

## 5. 定期自然回復

- 契機: プラグイン起動後に開始される定期タスク。
- 処理: [[07_3.05-タスク]].定期回復処理
- 結果: オンラインかつ生存しているプレイヤーに対し、HP / MP / EN の自然回復量を毎秒適用する。
