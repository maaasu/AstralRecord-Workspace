# 07_0-概要

## 1. 目的

`status` 機能は、オンライン中プレイヤーの戦闘・回復・表示に使うステータスを計算し、[[03_1-モデル定義]].プレイヤーセッション に保持する。
主目的は以下。

- 現在ステータスの取得・再計算
- HP / MP / EN / Shield の消費と回復
- アカウントモード・職業・装備・スキル・バフによる補正反映
- `/status` コマンドによるステータス表示
- `/statusbuff` コマンドによる管理者向け一時ステータスバフ付与
- オンライン中プレイヤーへの定期回復

## 2. コンテキスト

- 永続化は行わず、オンライン中の [[03_1-モデル定義]].プレイヤーセッション に [[07_1-モデル定義]].ステータススナップショット を保持する。
- [[02_1-モデル定義]].アカウントモードを補正条件として扱う。プレイヤーレベルは戦闘ステータスへ直接補正せず、`INVENTORY_SLOTS` のみレベル5ごとに1増加させる。
- buff feature の有効バフを補正値へ加算する。
- player feature のログイン反映時に初回計算され、ドッジ処理では EN 消費に利用される。

## 3. 構成要素（実装単位）

- `service/StatusService`
  - ステータス取得、再計算、バフ適用、HP/MP/EN/Shield 消費・回復を制御する。
- `service/StatusRegenTask`
  - オンライン中プレイヤーを定期走査し、HP/MP/EN の自然回復と Shield 再充填を行う。
- `event/PlayerHeldItemStatusEventHandler`
  - 成立した hotbar slot 変更の次 tick に status を再計算する非競合 observer。
- `command/StatusCommand`, `StatusTabCompleter`
  - `/status` コマンドと補完候補を提供する。
- `command/StatusBuffCommand`, `StatusBuffTabCompleter`
  - 管理者がオンラインプレイヤーへ一時的な固定値ステータスバフを付与する `/statusbuff` コマンドと補完候補を提供する。
- [[07_1-モデル定義]].ステータススナップショット, [[07_1-モデル定義]].ステータス値, [[07_1-モデル定義]].ステータス種別
  - ステータス計算結果と表示単位を定義する。

## 6. 依存・連携

- `player`
  - [[03_1-モデル定義]].プレイヤーセッション に [[07_1-モデル定義]].ステータススナップショット を保持する。
  - [[03_1-モデル定義]].プレイヤーキャッシュ からオンラインプレイヤーを取得し、定期回復を行う。
- `account`
  - [[02_1-モデル定義]].アカウントモード に応じてステータス補正を加算する。
  - プレイヤーレベル進行の `level` は `INVENTORY_SLOTS` のみへ間接的に反映する。
- `buff`
  - 有効バフを削除・参照し、ステータス補正へ反映する。
- `hud`
  - HUD 表示は status の現在 HP/MP/EN/Shield を参照する。
  - HUD 側の責務分離（`service` / `view`）は [[10_0-概要]], [[10_3-索引]] を参照する。
- `player-interaction`
  - `HOTBAR_SLOT`の入力所有権は[[28_0-概要]]を正本とし、status側の再計算は非競合observerとして扱う。
