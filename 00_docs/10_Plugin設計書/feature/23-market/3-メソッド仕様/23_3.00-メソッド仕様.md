# 23_3.00-メソッド仕様

## 出品一覧取得

クラス名: `MarketRepository`
物理名: `findListings`

1. [[23_1.00-モデル定義]].出品一覧検索条件 を query string に変換する。
2. 同一 query string の有効キャッシュがあればそれを返す。
3. キャッシュがない場合、`GET /api/market/listings` を呼び出す。
4. `200` のレスポンスを `MarketListing` 一覧へ変換し、15 秒 TTL で保存する。

## 出品取得

クラス名: `MarketRepository`
物理名: `findListing`

1. `listingId` の有効キャッシュがあればそれを返す。
2. キャッシュがない場合、`GET /api/market/listings/{listingId}` を呼び出す。
3. `404` は `Optional.empty()` として扱う。
4. `200` のレスポンスを `MarketListing` へ変換し、30 秒 TTL で保存する。

## アカウント概要取得

クラス名: `MarketRepository`
物理名: `findAccountSummary`

1. `accountId` の有効キャッシュがあればそれを返す。
2. キャッシュがない場合、`GET /api/market/accounts/{accountId}/summary` を呼び出す。
3. `404` は `Optional.empty()` として扱う。
4. `200` のレスポンスを `MarketAccountSummary` へ変換し、15 秒 TTL で保存する。

## 相場見積取得

クラス名: `MarketRepository`
物理名: `createPriceQuote`

1. リクエスト内容からキャッシュキーを作る。
2. 有効キャッシュがあればそれを返す。
3. キャッシュがない場合、`POST /api/market/price-quote` を呼び出す。
4. `404` は `Optional.empty()` として扱う。
5. `200` のレスポンスを `MarketPriceQuote` へ変換し、5 秒 TTL で保存する。

## 出品作成

クラス名: `MarketRepository`
物理名: `createListing`

1. `POST /api/market/listings` を呼び出す。
2. `201` のレスポンスを `MarketListing` へ変換する。
3. 出品者概要、出品一覧、相場見積キャッシュを破棄する。
4. 作成済み出品を出品詳細キャッシュへ保存する。

## 購入

クラス名: `MarketRepository`
物理名: `purchase`

1. `POST /api/market/listings/{listingId}/purchase` を呼び出す。
2. `200` のレスポンスを `MarketTransaction` へ変換する。
3. 出品者概要、購入者概要、出品一覧、相場見積、対象出品詳細キャッシュを破棄する。

## キャンセル

クラス名: `MarketRepository`
物理名: `cancel`

1. `POST /api/market/listings/{listingId}/cancel` を呼び出す。
2. `200` のレスポンスを `MarketListing` へ変換する。
3. 出品者概要、出品一覧、相場見積キャッシュを破棄する。
4. 更新後出品を出品詳細キャッシュへ保存する。

## キャッシュ全破棄

クラス名: `MarketRepository`
物理名: `clearCache`

1. 出品一覧、出品詳細、アカウント概要、相場見積の全キャッシュを破棄する。
