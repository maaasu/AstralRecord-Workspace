# 23_5.00-例外・ログ・運用

## 1. 例外方針

- API 通信失敗は `RuntimeException` として呼び出し元へ伝播する。
- `404` を仕様上許容する取得系は `Optional.empty()` として扱う。
- 更新系で API が 2xx 以外を返した場合は、レスポンス本文を含む `IllegalStateException` を送出する。

## 2. ログ

現実装では `MarketRepository` はログを直接出力しない。
GUI / コマンド追加時にプレイヤー通知や運用ログが必要になった場合は、`PlayerMessageService` / `LogId` の既存ルールに従って追加する。

## 3. 運用

- キャッシュはメモリ上のみで保持し、Plugin 再起動で破棄される。
- 経済バランスに関わる最終判定は API 側で行う。
- 通貨残高の API 正本化が完了するまでは、購入 UI 追加時に API 側未決事項 `Q-MARKET-001` を確認する。
