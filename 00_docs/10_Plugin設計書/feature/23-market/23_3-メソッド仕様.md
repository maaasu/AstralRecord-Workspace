# 23_3-メソッド仕様

## 出品一覧・詳細

クラス名: `MarketRepository` / `MarketService`
物理名: `findListings` / `findListing`

- 引数: `MarketListingQuery query`、または `UUID listingId`
- 戻り値: `List<MarketListing>`、または `Optional<MarketListing>`
- endpoint: `GET /api/market/listings?...`、`GET /api/market/listings/{id}`
- 例外: 一覧は 200、詳細は 200／404 以外を例外とする。

一覧 cache は query string 単位で 15 秒。取得した各 listing を詳細 cache に 30 秒入れる。詳細 404 は cache を除去して empty。

## Account summary

クラス名: `MarketRepository` / `MarketService`
物理名: `findAccountSummary`

- 引数: `UUID accountId`
- 戻り値: `Optional<MarketAccountSummary>`
- endpoint: `GET /api/market/accounts/{accountId}/summary`
- 例外: 200／404 以外は例外。

summary は account ID 単位で 15 秒 cache する。404 は empty。

## 価格見積

クラス名: `MarketRepository` / `MarketService`
物理名: `createPriceQuote`

- 引数: `MarketPriceQuoteRequest request`
- 戻り値: `Optional<MarketPriceQuote>`
- endpoint: `POST /api/market/price-quote`
- 例外: 200／404 以外は例外。

全 request field を連結した key で 5 秒 cache する。404 は empty。

## 出品作成

クラス名: `MarketRepository` / `MarketService`
物理名: `createListing`

- 引数: `MarketListingCreateRequest request`
- 戻り値: 作成済み `MarketListing`
- endpoint: `POST /api/market/listings`
- 成功 status: 201
- 例外: 201 以外は例外。

成功後に seller summary、全一覧、全 quote cache を破棄し、作成済み listing を詳細 cache へ入れる。

## 購入

クラス名: `MarketRepository` / `MarketService`
物理名: `purchase`

- 引数: `UUID listingId`, `MarketPurchaseRequest request`
- 戻り値: `MarketTransaction`
- endpoint: `POST /api/market/listings/{id}/purchase`
- 成功 status: 200
- 例外: 200 以外は例外。

成功後に seller の一覧／quote／summary、buyer summary、対象 listing 詳細 cache を破棄する。

## Cancel

クラス名: `MarketRepository` / `MarketService`
物理名: `cancel`

- 引数: `UUID listingId`, `MarketCancelRequest request`
- 戻り値: 更新済み `MarketListing`
- endpoint: `POST /api/market/listings/{id}/cancel`
- 成功 status: 200
- 例外: 200 以外は例外。

成功後に seller 関連 cache を破棄し、cancel 後 listing を詳細 cache へ入れる。

## Cache 全破棄

クラス名: `MarketRepository` / `MarketService`
物理名: `clearCache`

- 引数: なし
- 戻り値: なし
- 例外: なし

一覧、詳細、summary、quote の全 map を clear する。
