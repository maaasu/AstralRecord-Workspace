# 23_3-メソッド仕様

## 出品一覧・詳細

クラス名: `MarketRepository` / `MarketService`
物理名: `findListings` / `findListing`

- 引数: `MarketListingQuery query`、または `UUID listingId`
- 戻り値: `List<MarketListing>`、または `Optional<MarketListing>`
- endpoint: `GET /api/market/listings?...`、`GET /api/market/listings/{id}`
- 例外: 一覧は 200、詳細は 200／404 以外を例外とする。

一覧 cache は query string 単位で 15 秒。取得した各 listing を詳細 cache に 30 秒入れる。詳細 404 は cache を除去して empty。

`MarketListing.sellerAccountName` は API の公開出品レスポンスから取得し、一覧アイテムの説明欄に `出品者: <アカウント名>` として表示する。値が空の場合は `不明な出品者` と表示し、`sellerAccountId` は画面へ出さない。

## Account summary

クラス名: `MarketRepository` / `MarketService`
物理名: `findAccountSummary`

- 引数: `UUID accountId`
- 戻り値: `Optional<MarketAccountSummary>`
- endpoint: `GET /api/market/accounts/{accountId}/summary`
- 例外: 200／404 以外は例外。

summary は account ID 単位で 15 秒 cache する。404 は empty。`astrald_shop` のマーケット拡張トークン購入では、inventory の `saveNow` 成功後に保存済み購入通知から全 market cache を破棄し、次回概要取得で API の最新所持数を反映する。

Market GUI の概要 item には次を表示する。

- 現在の使用済み枠／最大枠、出品中件数、Gold 残高
- API が返す累計成立取引数と現在 Tier
- `Tier基本枠 + 有効トークン枠 = 最大出品枠`
- トークンは 1 個につき 1 枠を加算し、種類ごとの反映上限は α `+6`、β `+9`、γ `+9`、δ `+9`
- トークンは NPC のアストラルドショップから購入でき、購入数自体に制限はない

最大枠は API の `maxListingSlotCount` を正とする。Plugin は Tier やトークンの枠数を再計算しない。

## 価格見積

クラス名: `MarketRepository` / `MarketService`
物理名: `createPriceQuote`

- 引数: `MarketPriceQuoteRequest request`
- 戻り値: `Optional<MarketPriceQuote>`
- endpoint: `POST /api/market/price-quote`
- 例外: 200／404 以外は例外。

全 request field を連結した key で 5 秒 cache する。404 は empty。

## 出品作成

クラス名: `MarketRepository` / `MarketService`
物理名: `createListing`

- 引数: `MarketListingCreateRequest request`
- 戻り値: 作成済み `MarketListing`
- endpoint: `POST /api/market/listings`
- 成功 status: 201
- 例外: 201 以外は例外。

成功後に seller summary、全一覧、全 quote cache を破棄し、作成済み listing を詳細 cache へ入れる。

## 購入

クラス名: `MarketRepository` / `MarketService`
物理名: `purchase`

- 引数: `UUID listingId`, `MarketPurchaseRequest request`
- 戻り値: `MarketTransaction`
- endpoint: `POST /api/market/listings/{id}/purchase`
- 成功 status: 200
- 例外: 200 以外は例外。

成功後に seller の一覧／quote／summary、buyer summary、対象 listing 詳細 cache を破棄する。

購入 request の `quantity` は `remainingQuantity` 以下で指定する。公開一覧・購入確認では自分の出品を選択できず、API も `market.self_purchase` で最終拒否する。購入時は seller Gold を再同期しない。売上は `SOLD` 出品への受取操作でだけ加算する。

## Cancel

クラス名: `MarketRepository` / `MarketService`
物理名: `cancel`

- 引数: `UUID listingId`, `MarketCancelRequest request`
- 戻り値: 更新済み `MarketListing`
- endpoint: `POST /api/market/listings/{id}/cancel`
- 成功 status: 200
- 例外: 200 以外は例外。

成功後に seller 関連 cache を破棄し、cancel 後 listing を詳細 cache へ入れる。

売上のない cancel は API が論理削除するため、詳細 cache に残さず一覧を再取得する。部分売却後の cancel は `SOLD` の売上受取待ちを返す。

## 売上受取

クラス名: `MarketRepository` / `MarketService`
物理名: `claimProceeds`

- 引数: `UUID listingId`, `MarketProceedsClaimRequest request`
- 戻り値: `MarketProceedsClaim`
- endpoint: `POST /api/market/listings/{id}/claim-proceeds`
- 成功 status: 200
- 例外: 200 以外は例外。

成功後に seller の一覧・summary・quote と対象 listing detail cache を破棄する。`SOLD` かつ `pendingProceeds > 0` だけが対象で、Plugin は出品 ID から安定導出した `idempotencyKey` を同じ値で再送し、出品者の通貨 entry を保存 lane 上で再同期する。

## Cache 全破棄

クラス名: `MarketRepository` / `MarketService`
物理名: `clearCache`

- 引数: なし
- 戻り値: なし
- 例外: なし

一覧、詳細、summary、quote の全 map を clear する。

## GUI 起動・プレイヤー操作

クラス名: `MarketGuiEventHandler`

| 物理名 | 起点 | 権限・条件 | 処理 |
|:--|:--|:--|:--|
| `openFromCommand` | `/market` | `UserPermission.ADMIN` と gameplay mode | 出品一覧を非同期取得して GUI を開く |
| `openFromNpc` | NPC `gui.type: MARKET` | gameplay mode | 通常プレイヤーを含めて GUI を開く |
| `submitListing` | 出品設定の確定 | BAG/HOTBAR の取引可能 item | account 保存 lane で API create と source entry の正本再同期を行う |
| `purchaseListing` | 購入確認の確定 | 自分の出品でなく、選択数の Gold が表示上不足していないこと | account 保存 lane で API purchase と購入者 Gold/取得 item の正本再同期を行う |
| `cancelListing` | 自分の出品の取り下げ | seller かつ `ACTIVE` / `SUSPENDED`、未売却残数を収容できること | 確認時と account 保存 lane 内の API 呼出直前に容量を再確認し、API cancel と全 source entry の正本再同期を行う |
| `claimProceeds` | 売却済み出品クリック | seller かつ売上受取待ち `SOLD` | account 保存 lane で API claim と出品者通貨の正本再同期を行い、出品枠を削除する |

- `/market` の権限不足は `AstCommand` が拒否するため、NPC action が通常プレイヤー向けの唯一の起動経路になる。
- `GoldAmountSettingGui` は source key `market-listing-price` の場合だけ market handler が処理する。trade handler は別 source key だけを処理する。
- 出品候補は `BAG` / `HOTBAR` の取引可能 item とする。Plugin は `unTradeable`、Goldを表す `CURRENCY`、不明カテゴリ、不正な stack / instance 形式を事前除外する。`unSellable` と売値 0 はマーケット対象外ではなく、API が `unitPrice > saleValue` の価格ガードで最終判定する。出品枠・escrow・所有権・装備中判定も API に委譲する。ルーンは stack 品であり、個体品の候補は `EQUIPMENT` だけとする。
- 出品選択画面では下部のバッグまたはホットバーをクリックし、stack 品は同じ item category / ID の BAG・HOTBAR 全 entry を出品候補として集計する。バッグ内の上下スクロール操作も有効にする。選択画面の出品枠表示は現在の Gold 残高を表示し、raw slot `49` に `自分の出品一覧へ戻る` を表示する。
- 自分の出品一覧でプレイヤー inventory の item をクリックすると、同じ item identity の `ACTIVE` 出品を検索して自動選択し、取り下げ確認へ進む。ページ外の出品も item 条件の API 検索で対象にする。BAG の上下スクロール操作は item 自動選択より先に共通 control へ委譲する。
- 購入成功通知 `P_6302` は API が確定した `transaction.totalPrice` を `（消費ゴールド: {0}）` として表示する。
- 購入確認は raw slot `10` / `16` で購入数を減増し、raw slot `11` に選択数量、raw slot `15` に選択数量の購入額を表示する。最大は `remainingQuantity` とする。
- 一覧画面は上段をヘッダーとし、公開中の出品一覧では raw slot `4` に `更新`、自分の出品一覧では raw slot `4` に `新しく出品する` を表示する。自分の出品一覧は raw slot `9` 以降の出品枠を使用中の出品、出品可能枠（`LIGHT_GRAY_STAINED_GLASS_PANE`）、未開放枠（`IRON_BARS`）で視覚的に区別する。
- 一覧の表示領域は raw slot `9`〜`44` の 36 枠とする。API は 37 件取得し、37 件目を次ページ有無の判定だけに使う。前ページ・次ページは存在する場合だけ表示し、アイコンは `PAPER`、クリック音は `GuiSound.PAGE` とする。閉じるボタンは一覧・出品選択画面に表示しない。
