# 23_4.00-統合フロー

## 1. 出品一覧参照

### シーケンス

```mermaid
sequenceDiagram
    participant Caller as 呼び出し元
    participant Service as MarketService
    participant Repo as MarketRepository
    participant API as Market API
    Caller->>Service: findListings(query)
    Service->>Repo: findListings(query)
    alt 15秒cache hit
        Repo-->>Service: cached list
    else miss / expired
        Repo->>API: GET /api/market/listings?query
        API-->>Repo: listings
        Repo->>Repo: list cache・各detail cache更新
    end
    Service-->>Caller: immutable list
```

### 処理要点

- query の nullable field は省略し、値は URL encode する。
- page／pageSize は query model で正規化する。

### 例外・終了条件

- cache miss 時の API／JSON failure は caller へ伝播する。

## 2. 詳細・summary・quote 参照

### シーケンス

```mermaid
sequenceDiagram
    participant Caller as 呼び出し元
    participant Repo as MarketRepository
    participant API as Market API
    Caller->>Repo: detail / summary / quote
    alt 対応cache hit
        Repo-->>Caller: cached Optional
    else miss
        Repo->>API: GET または POST
        alt 200
            API-->>Repo: response model
            Repo-->>Caller: Optional.of(value)
        else 404
            Repo-->>Caller: Optional.empty()
        end
    end
```

### 処理要点

- TTL は detail 30 秒、summary 15 秒、quote 5 秒。
- 404 の negative result 自体は cache しない。

### 例外・終了条件

- 200／404 以外は `IllegalStateException`。

## 3. 出品作成・cancel

### シーケンス

```mermaid
sequenceDiagram
    participant Caller as 呼び出し元
    participant Repo as MarketRepository
    participant API as Market API
    Caller->>Repo: createListing または cancel
    Repo->>API: POST request
    API-->>Repo: MarketListing
    Repo->>Repo: seller list・summary・quoteをinvalidate
    Repo->>Repo: listing detailを30秒cache
    Repo-->>Caller: updated listing
```

### 処理要点

- create は 201、cancel は 200 を成功とする。
- API が価格 guard・所有権・status transition を確定する。

### 例外・終了条件

- mutation failure 時は cache invalidation を行わない。

## 4. 購入

### シーケンス

```mermaid
sequenceDiagram
    participant Caller as 呼び出し元
    participant Repo as MarketRepository
    participant API as Market API
    Caller->>Repo: purchase(listingId, request)
    Repo->>API: POST /listings/{id}/purchase
    API-->>Repo: MarketTransaction
    Repo->>Repo: seller関連cache削除
    Repo->>Repo: buyer summary・listing detail削除
    Repo-->>Caller: transaction
```

### 処理要点

- caller が一意な `idempotencyKey` を request に含める。
- plugin は API transaction の結果を再計算しない。

### 例外・終了条件

- API が 200 以外を返した場合は transaction を返さず、cache も維持する。
