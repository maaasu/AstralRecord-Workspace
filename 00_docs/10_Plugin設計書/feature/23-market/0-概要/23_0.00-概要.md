# 23_0.00-概要

## 1. 目的

Plugin 側 `market` feature は、AstralRecord API の market エンドポイントをゲーム内機能から利用するための薄いアダプタを提供する。

Plugin は次を担当する。

- API 呼び出し
- API レスポンスの Java モデル化
- 一覧、詳細、アカウント概要、相場見積の短時間キャッシュ
- 出品、購入、キャンセル後の関連キャッシュ破棄

Plugin は次を担当しない。

- 出品数上限の最終判定
- 店売り価格下限チェック
- 相場乖離チェック
- 約定履歴作成
- アイテム所有権移転

## 2. キャッシュ方針

| 対象 | TTL | 破棄条件 |
|---|---:|---|
| 出品一覧 | 15 秒 | 出品作成、購入、キャンセル |
| 出品詳細 | 30 秒 | 対象出品の購入、キャンセル |
| アカウント概要 | 15 秒 | 対象アカウントの出品作成、購入、キャンセル |
| 相場見積 | 5 秒 | 出品作成、購入、キャンセル |

キャッシュは性能対策であり、正本ではない。
更新系操作では必ず API の戻り値を正として扱う。
