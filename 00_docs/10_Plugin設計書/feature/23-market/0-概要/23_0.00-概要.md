# 23_0.00-概要

## 目的

Market API の業務処理を plugin 内から一貫した Java model で呼び出し、GUI paging や価格入力で起きる短時間の連続参照を cache で抑える。

## 責務

- query を URL encode して出品一覧を取得する。
- 出品詳細、account summary、価格見積の未存在を `Optional.empty()` で表す。
- 出品作成、購入、cancel request を JSON 化して API へ送る。
- response を `MarketListing`、`MarketTransaction` 等へ変換する。
- 一覧 15 秒、詳細 30 秒、summary 15 秒、見積 5 秒で cache する。
- mutation 成功時に関連 seller／buyer／listing cache を無効化する。

## 責務外

- 出品可能性、価格 guard、手数料、残高・在庫移転、idempotency の業務判定。これらは API が正本。
- player GUI、command、inventory からの item 取り出し・返却。
- plugin 側の market 状態永続化。

## 現在の境界

`MarketService` は validation を追加しない薄い facade で、全公開 method を `MarketRepository` へ委譲する。repository は同期 HTTP を使うため、main thread からの呼出可否は将来の呼び出し側が管理する。
