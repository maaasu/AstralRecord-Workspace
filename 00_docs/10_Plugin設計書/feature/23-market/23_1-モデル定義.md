# 23_1-モデル定義

## MarketListing

API の出品状態を完全に表す response model。

| 分類 | フィールド |
|:--|:--|
| identity | `listingId`, `sellerAccountId`, nullable `buyerAccountId`, nullable互換 `sourceInventoryEntryId`, `sourceInventoryEntryIds` |
| seller | `sellerAccountName` |
| item | `itemCategory`, `itemId`, nullable `instanceType`, nullable `instanceId`, 出品時総数 `quantity`, 購入可能残数 `remainingQuantity` |
| price | `currencyId`, `unitPrice`, `totalPrice`, `priceFloor`, nullable `referenceUnitPrice`, nullable `priceDeviationRate`, `priceConfidence` |
| valuation | nullable `valuationSignature`, nullable `valuationSnapshotJson` |
| status | `status`, nullable `statusReason`, `listedAt`, `expiresAt`, nullable `soldAt`, nullable `canceledAt` |
| version | `version`, `createdAt`, `updatedAt`, 売上受取待ち `pendingProceeds` |

`sellerAccountName` は API のアカウント表示名で、公開出品の GUI に出品者として表示する。`sellerAccountId` は API 通信とキャッシュの内部識別に使用し、GUI には表示しない。`remainingQuantity` は公開購入の上限、`pendingProceeds` は `SOLD` の売上受取表示に使う。

## Query・request

### MarketListingQuery

nullable `sellerAccountId`、`itemCategory`、`itemId`、`status`、`minPrice`、`maxPrice`、`sort` と、`page`、`pageSize`。page は最低 1、pageSize は 1〜100 に正規化する。`activeFirstPage()` は `ACTIVE`、`listed_desc`、page 1、50 件。

### MarketListingCreateRequest

`sellerAccountId`、必須 `sourceEntries`、item category／ID、nullable instance type／ID、`quantity`、`currencyId`、`unitPrice`、nullable `expiresAt`、`createdBy`。`sourceEntries` は `MarketListingSource(inventoryEntryId, quantity)` の不変一覧で、合計は出品数量と一致する。Plugin GUI は `currencyId = gold` だけを送る。個体品も escrow entry を 1 件指定する。

### MarketPurchaseRequest

`buyerAccountId`、購入数量 `quantity`、`idempotencyKey`、`updatedBy`。

### MarketCancelRequest

`sellerAccountId`、nullable `reason`、`updatedBy`。

### MarketProceedsClaimRequest / MarketProceedsClaim

`MarketProceedsClaimRequest` は `sellerAccountId`、同一出品の再送でも変えない `idempotencyKey`、`updatedBy` を持つ。Plugin は `listingId` からこのキーを安定導出する。`MarketProceedsClaim` は受取済み `listingId`、`amount`、出品者通貨を再同期する `affectedInventoryEntryIds` を持つ。API は受取済み出品を論理削除した後も同じキーの receipt を再生する。

### MarketPriceQuoteRequest

nullable `accountId`、item category／ID、nullable instance type／ID、`quantity`、nullable `unitPrice`。

## Quote・summary・transaction

### MarketPriceQuote

item／instance identity、`sellPrice`、`suggestedUnitPrice`、nullable `referenceUnitPrice`、`sampleCount`、`referenceScope`、`confidence`、許容最小／最大単価、`judgement`、nullable valuation signature／roll quality、`evaluatedAt`。

### MarketAccountSummary

`accountId`、`activeListingCount`、互換用 `maxActiveListingCount`、`usedListingSlotCount`、`maxListingSlotCount`、`completedTradeCount`、`tier`、nullable `suspendedUntil`、`updatedAt`。使用済み枠は `ACTIVE` / `SUSPENDED` / 売上未受取 `SOLD` を数える。

### MarketTransaction

transaction／listing／seller／buyer identity、item／instance identity、quantity、currency、unit／total price、`feeAmount`、`sellerProceeds`、`affectedInventoryEntryIds`、`completedAt`。`affectedInventoryEntryIds` は購入者の Gold と取得品を API 正本へ再同期する対象。

### MarketListingDraft

GUI 内だけで保持する未確定出品。全候補 `sourceEntries`、item／instance identity、全同種 stack を集計した最大数量、選択数量、単価、price GUI の `contextId` を保持する。`selectedSources()` はクリックした stack を先頭として、選択数量を複数 source へ割り当てる。API 成功後に破棄する。DB・filebase へ永続化しない。

## Cache entry

package-private `MarketCacheEntry<T>(value, expiresAt)`。`isAlive()` は現在時刻が `expiresAt` より前の場合だけ true。

Plugin 設計内の model 参照はこの章を正とする。API 側の同名文書へ曖昧な wiki link を張らず、`00_docs/20_API設計書/feature/23-market/` を明示する。
