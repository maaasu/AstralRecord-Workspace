# 20_0.00-概要

## 目的

master data で定義した商品と複数種類の対価を GUI で提示し、player inventory の整合性を維持したまま一括購入させる。

## 責務

- shop と shop recipe を独立に読み込み、一つの `CacheSnapshot` として公開する。
- shop ID または色コードを除いた表示名で定義を検索する。
- command は `PUBLIC`、NPC は `PUBLIC`／`NPC_ONLY` を開く。
- direct cost と recipe cost を合算し、購入 preview を生成する。
- `AccountMode.PLAYER`、所持量、格納可能量を検証して購入する。
- 支払い・付与途中の失敗時に inventory snapshot を復元する。

## 責務外

- 市場相場、player 間販売、shop stock、販売回数、期間限定在庫。
- NPC の spawn／interaction 解決。
- 商品 item master／recipe master の編集。

## 現在の契約

- `/shop <shopId または表示名>` で開く。`/shop open ...` ではない。
- `ShopService` は購入 domain service であり GUI を開かない。open は `ShopGuiEventHandler` が担う。
- `amount` は 1 口あたりの商品数量、GUI の quantity は購入口数である。
- 価格は `priceGold + recipe.requiredCurrency` と、`requiredItems + recipe.ingredients` の合計。
- stock model は存在しないため、購入可能性は残高と inventory capacity だけで決まる。
