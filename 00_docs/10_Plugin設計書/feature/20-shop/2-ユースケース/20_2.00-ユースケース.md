# 20_2.00-ユースケース

## 1. NPC からショップを開く

1. mob feature の NPC interaction が shopId を解決する。
2. [[20_3.00-メソッド仕様]].ショップ表示 を呼び出す。
3. 商品一覧を GUI に表示する。

## 2. 商品購入

1. プレイヤーが商品をクリックする。
2. [[20_3.00-メソッド仕様]].購入実行 が価格と在庫を検証する。
3. currency feature で支払いを行う。
4. inventory feature で商品を付与する。

## 3. コマンドからショップを開く

1. 管理者または許可された導線が `/shop open <shopId>` を実行する。
2. [[20_3.00-メソッド仕様]].ショップ表示 を呼び出す。

`access=NPC_ONLY` のショップは ID・名称検索およびタブ補完から除外し、コマンドでは開かない。

## 4. 通貨両替

1. NPC interaction が `mode=EXCHANGE`、`access=NPC_ONLY` のショップを開く。
2. プレイヤーが交換方向と口数を選ぶ。
3. `category=currency` の必要通貨を CURRENCY から減算する。
4. 交換先の通貨を CURRENCY へ付与し、途中失敗時は開始前の状態へ復元する。
