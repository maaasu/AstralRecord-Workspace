# 20_1.00-モデル定義

## ShopDefinition

| フィールド | 型 | 意味 |
|:--|:--|:--|
| `id` | `String` | shop ID |
| `name` | `String` | GUI／検索用表示名 |
| `mode` | `ShopMode` | `SHOP` または `EXCHANGE` |
| `access` | `ShopAccess` | `PUBLIC` または `NPC_ONLY` |
| `entries` | `List<ShopEntry>` | 商品定義 |

## ShopEntry

| フィールド | 型 | 意味 |
|:--|:--|:--|
| `id` | `String` | shop 内 entry ID |
| `itemId` / `category` | `String` | 付与商品 model の解決キー |
| `amount` | `int` | 1 口あたりの商品数量 |
| `page` | `int` | GUI page |
| `slot` | `Integer?` | 直接 slot 指定 |
| `row` / `column` | `Integer?` | slot の代替配置指定 |
| `priceGold` | `int` | direct gold price |
| `requiredItems` | `List<ShopCostItem>` | direct item／currency costs |
| `recipeId` | `String?` | 追加 cost を持つ shop recipe |

## Cost・preview

### ShopCostItem

`itemId`、`category`、`amount`。category が `currency` の場合は CURRENCY、それ以外は NORMAL inventory から消費する。

### ShopRecipeCost

`recipeId`、`requiredCurrency`、`ingredients`。`requiredCurrency` は gold cost へ加算する。

### ShopPurchasePreview

`quantity`、`requiredGold`、`ownedGold`、`requiredItems`、`missingItems`、`canPurchase` を保持する。quantity は最低 1 へ正規化する。

## CacheSnapshot

`ShopService.CacheSnapshot` は `shops` と `recipes` の不変 list をまとめる。両 repository cache を同じ lifecycle step で置換する。

`Shop`、`ShopItem`、`ShopPrice`、`stockLimit` は現在の plugin model ではない。
