# 20_2-ユースケース

## UC-20-01 command から shop を開く

- `/shop <shopId または表示名>` を実行する。
- `findCommandAccessibleByIdOrName` で `PUBLIC` shop だけを解決する。
- 成功時は `ShopGuiEventHandler.openFromCommand`、未解決時は `P_5930` を通知する。

## UC-20-02 NPC から shop を開く

- NPC 定義が持つ shop ID を `openFromNpc` へ渡す。
- `NPC_ONLY` を含む既知 shop を開ける。
- `AccountMode.PLAYER` でない player は拒否する。

## UC-20-03 商品を preview する

- list の entry を選ぶと confirm GUI を開く。
- quantity、商品数量（`×N`）、Gold、必要な通貨／素材、missing item、購入可否を表示する。`astrald_shop` では「アストラルド ×N」として表示し、Gold 0 の行は表示しない。スキルの習得・レベルアップはスキルマネージャーに表示し、ショップ一覧と確認画面では扱わない。
- direct cost と recipe cost は同 category／item ID ごとに合算する。

## UC-20-04 商品を購入する

- confirm 操作時に preview を再計算する。
- NORMAL inventory の空きを確認し、全 inventory state を snapshot する。
- Gold、required currency／items の順で消費し、商品を exact amount 付与する。`astrald_shop` は `astrald` currency を消費する。
- 通常商品は account 別の重要操作 lane で支払いと商品付与を計算し、完成 player-state snapshot の SQL ACK 後だけ GUI、成功音、ガイド条件、market cache を更新する。保存失敗時は所持品と装備 cache を購入前へ戻し、失敗を表示する。
- スキルの習得・強化はスキルマネージャーが skill master の必要素材を検証し、素材消費と習得状態を同じ重要操作 snapshot で保存する。SQL ACK 後だけ対応するガイド条件を記録する。
- スキルが最大レベルなら `※ すでにレベルMAXのため購入できません。` を表示し、購入確定をcancelして支払い・商品付与・保存・習得APIを行わない。

## UC-20-05 quantity／page を変更する

- list page は master 配置と表示可能範囲で正規化する。
- confirm GUI の quantity 変更後は preview を再生成する。
- back 操作は元 shop と page へ戻す。

## UC-20-06 星晶錬成を利用する

- `skill_gem_raw_exchange` は、上位のスキルジェム原石1個を直下位の原石3個へ下位変換する7段階だけを表示する。無印から初級へ進む逆交換は定義しない。
- 個別スキルジェムの交換所は廃止する。使用許可済みの未習得スキルはスキルマネージャーに表示し、skill master の `learnRequiredItems` を消費して習得する。習得済みスキルのレベルアップは `levelUpRequiredItems` を消費する。未指定の段階は素材なしで実行できる。
