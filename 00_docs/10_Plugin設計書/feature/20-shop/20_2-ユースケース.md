# 20_2-ユースケース

## UC-20-01 command から shop を開く

- `/shop <shopId または表示名>` を実行する。
- `findCommandAccessibleByIdOrName` で `PUBLIC` shop だけを解決する。
- 成功時は `ShopGuiEventHandler.openFromCommand`、未解決時は `P_5930` を通知する。

## UC-20-02 NPC から shop を開く

- NPC 定義が持つ shop ID を `openFromNpc` へ渡す。
- `NPC_ONLY` を含む既知 shop を開ける。
- `AccountMode.PLAYER` でない player は拒否する。

## UC-20-03 商品を preview する

- list の entry を選ぶと confirm GUI を開く。
- quantity、商品数量（`×N`）、Gold、必要な通貨／素材、missing item、購入可否を表示する。`astrald_shop` では「アストラルド ×N」として表示し、Gold 0 の行は表示しない。スキルジェムは数量を1に固定し、未習得なら `次の購入: スキルを習得`、習得済みなら `次の購入: Lv.N → Lv.N+1` を一覧と確認画面へ表示する。
- direct cost と recipe cost は同 category／item ID ごとに合算する。

## UC-20-04 商品を購入する

- confirm 操作時に preview を再計算する。
- NORMAL inventory の空きを確認し、全 inventory state を snapshot する。
- Gold、required currency／items の順で消費し、商品を exact amount 付与する。`astrald_shop` は `astrald` currency を消費する。
- 通常商品は GUI state を反映して `saveNow` を登録し、購入成功のガイド条件は保存要求直後に記録する。マーケット拡張トークン購入に伴う market cache 破棄は保存 future が `true` で完了した場合だけ行う。支払い・付与途中の失敗時は snapshot を復元する。
- スキルジェムはローカル支払い・付与直後に専用保存境界を確保し、購入stateの保存、購入entryを素材とするAPI習得／強化、entry正本照合、操作後再保存を直列実行する。未習得ならLv.1を習得し、習得済みなら既存個体を1レベル上げる。習得・強化のガイド条件はAPI mutation成功時に記録する。APIが拒否した場合は購入entryだけを除去して支払いを全返却する。
- スキルが最大レベルなら `※ すでにレベルMAXのため購入できません。` を表示し、購入確定をcancelして支払い・商品付与・保存・習得APIを行わない。

## UC-20-05 quantity／page を変更する

- list page は master 配置と表示可能範囲で正規化する。
- confirm GUI の quantity 変更後は preview を再生成する。
- back 操作は元 shop と page へ戻す。

## UC-20-06 星晶錬成を利用する

- `skill_gem_raw_exchange` は、上位のスキルジェム原石1個を直下位の原石3個へ下位変換する7段階だけを表示する。無印から初級へ進む逆交換は定義しない。
- `skill_gem_exchange` は、skill masterから自動生成された各ジェムを、使用許可の区分に応じて交換する。冒険者で使用できるスキル（冒険者スキルツリーの解放を含む）は無印原石1個、上位職で最初から使用できるスキルは無印原石2個、上位職のスキルツリー解放が必要なスキルは無印原石3個からジェム1個へ交換する。タンクシールドアクティベート `swordsman_shield_activate` はソードマンのclass直接許可として無印原石2個、`administrator_shield_recharge` と `swordsman_shield_drain` はソードマンのスキルツリー解放対象として無印原石3個からジェム1個へ交換する。初級原石からジェムへ交換するentryは定義しない。
- `skill_gem_exchange` のジェムはインベントリへ保持する商品ではなく、購入時にそのまま習得またはレベルアップへ使用する。
- ソードマンの `swordsman_shield_drain` を含む自動生成ジェムも `skill_gem_exchange` に含める。

### skill_gem_exchange の職業別配置

`skill_gem_exchange` は1ページ目の7列×4行へ、左上を slot 0 として左から右、上から下の順に配置する。

- 1行目（slot 0〜6）: メディテーション、アストラルエッジ、スマッシュ、ブラストアロー、クイックショット、ライトニングボルト、マナバースト
- 2行目（slot 7〜13）: シールドドレイン、チャレンジングロア、フレイムラッシュ、バスティオンストライク、シールドリチャージ、空き、タンクシールドアクティベート
- 3行目（slot 14〜20）: アローレイン、フェイドショット、ヒールアロー、クラッシュアロー、スペルステップ、空き、空き
- 4行目（slot 21〜27）: ファイアーボール、ヒールオーラ、スパーキング、フロストブリザード、アーケインフロー、空き、空き
