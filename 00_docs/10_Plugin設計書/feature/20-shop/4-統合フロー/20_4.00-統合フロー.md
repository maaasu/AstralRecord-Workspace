# 20_4.00-統合フロー

## 1. NPC ショップ表示フロー

1. mob feature が NPC interaction で shopId を解決する。
2. [[20_3.00-メソッド仕様]].ショップ表示 を呼び出す。
3. shop feature が GUI を開く。

## 2. 購入フロー

1. GUI クリックで商品を選択する。
2. [[20_3.00-メソッド仕様]].購入実行 が支払いと商品付与を順に実行する。
3. 支払い失敗時は商品付与を行わない。
4. 商品付与成功後に GUI を再描画する。

## 3. 商品一覧ページングフロー

1. 商品一覧 GUI は `items[].page` が現在ページに一致する商品だけを表示する。
2. 左下 slot `45` の前ページボタンで 1 つ前のページを開く。
3. 右下 slot `53` の次ページボタンで 1 つ次のページを開く。
4. 購入確認 GUI から戻る場合は、商品を選択した一覧ページへ戻る。

## 4. NPC専用両替フロー

1. mob feature が専用NPCの shopId をNPC導線として解決する。
2. shop feature が `access=NPC_ONLY` を確認し、`mode=EXCHANGE` の共通GUIを開く。
3. 交換元の通貨を CURRENCY から減算し、交換先通貨を CURRENCY へ付与する。
4. `/shop` とタブ補完では同じ shopId を解決しない。
