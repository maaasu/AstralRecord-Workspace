# 20_3-メソッド仕様

## Cache 読み込み・置換

クラス名: `ShopService`
物理名: `loadCacheSnapshot` / `replaceCacheSnapshot` / `warmCaches`

- 引数: replace は `CacheSnapshot snapshot`
- 戻り値: snapshot、なし、または shop 件数
- 例外: repository／recipe 取得失敗を呼び出し元へ伝播する。

shop と recipe を先に読み、構築済み snapshot を両 repository へ置換する。

## Shop 検索

クラス名: `ShopService`
物理名: `findById` / `findByIdOrName` / `findCommandAccessibleByIdOrName`

- 引数: shop ID または検索文字列
- 戻り値: `ShopDefinition?`
- 例外: なし

表示名検索は色コードを除去し、trim、空白圧縮、小文字化する。command 用は `access.isCommandAccessible()` を追加検証する。

## 購入 preview

クラス名: `ShopService`
物理名: `preview`

- 引数: `AstPlayer player`, `ShopEntry entry`, `int quantity`
- 戻り値: `ShopPurchasePreview`
- 例外: なし

`AccountMode.PLAYER` でない場合は購入不可 preview。Gold と currency／item の不足分を `missingItems` に集める。category が `CURRENCY` かつ ID が `gold` の cost は組み込み全額面の Gold 換算残高で判定する。その他の `CURRENCY` cost（`astrald` を含む）は CURRENCY と STORAGE の同一 currency ID、通常 item cost は BAG・HOTBARの未予約数量と STORAGE の同一 item ID を合算して判定する。Gold が 0 で currency cost のみの場合、GUI は必要 Gold 行を表示せず、通貨名と必要数を表示する。

## 購入

クラス名: `ShopService`
物理名: `purchase`

- 引数: `AstPlayer player`, `ShopEntry entry`, `int quantity`
- 戻り値: 全支払いと exact 商品付与を完了した場合 `true`
- 例外: 途中失敗は `false` と snapshot restore へ変換する。

1. gameplay mode、商品 model、preview、NORMAL inventory capacity を検証する。
2. account inventory state を snapshot する。
3. Gold、required currency／item を category 別の残高から消費する。required currency は CURRENCY、通常 item は BAG・HOTBARを先に使い、不足分を STORAGE から消費する。オーブ操作で予約済みの BAG・HOTBAR数量は使用しない。`astrald_shop` では `astrald` を消費する。
4. `max(1, entry.amount) * quantity` を商品 category に対応する inventory へ付与する。`CURRENCY` 商品は `CURRENCY` へ付与し、通常 BAG へ混在させない。
5. cost 消費と商品付与は同じ snapshot 境界で扱う。exact amount でなければ restore、成功なら必要な GUI 反映と `saveNow` を行う。購入成功通知は保存完了を待たずに行い、保存成功後の通知は `saveNow` の成功 future に接続する。currency 間だけで完結する購入では BAG GUI を不要に更新しない。

## Cost 解決

クラス名: `ShopService`
物理名: `resolveGoldCost` / `resolveRequiredItems`

- 引数: `ShopEntry entry`
- 戻り値: 1 口の gold、または merged `List<ShopCostItem>`
- 例外: なし

direct cost と `recipeId` の cost を合算し、負の gold は 0 として扱う。

## GUI open・event

クラス名: `ShopGuiEventHandler`
物理名: `openFromCommand` / `openFromNpc` / `onInventoryClick` / `onInventoryDrag`

- 引数: player、shop ID、または inventory event
- 戻り値: なし
- 例外: event は `runSafely` で捕捉し `E_5601` に operation を渡す。

command open は `PUBLIC` のみ、NPC open は access 制限をかけず既知 ID を開く。click／drag は対象 GUI の標準操作を cancel する。

## `/shop` command

クラス名: `ShopCommand`
物理名: `executePlayerCommand`

- 構文: `/shop <shopId または表示名>`
- 実行者: gameplay player
- 戻り値: なし
- 例外: 未解決を `P_5930` へ変換する。
