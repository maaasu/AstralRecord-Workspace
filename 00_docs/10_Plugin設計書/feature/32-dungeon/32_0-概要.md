# 32_0-概要

## 1. 目的

ダンジョン機能は、専用の手作りワールドを要求せず、開始要求ごとに独立した void ワールドへ攻略空間を自動生成する。部屋数・形・テーマ・出現 Mob は filebase から調整でき、同じ定義と seed から同じ配置を再現できる。

## 2. 責務

- マスタ定義された受付ゲート内のスニークで、ソロまたはオンラインパーティーの参加者を確定し、待機ハブへ退避してインスタンスを非同期準備する。`/dungeon start <dungeonId>` は受付範囲内での開始 fallback として残す。
- 受付地点へ青緑色の門型フレーム、ポータル粒子、ダンジョン名とスニーク案内の TextDisplay を表示し、Boss の円環演出と区別する。
- BSP で指定範囲内に部屋を分散配置し、接続木、開始部屋、唯一のボス部屋を決定する。
- 部屋、直交折れ線通路、ゲート、任意の中央柱をマスタの重み付き Material から生成する。
- 部屋内 Mob の全滅で子部屋へのゲートを開き、解放済み部屋への進入時に次の戦闘を開始する。
- 初回の START 部屋転送後に10秒の開始カウントダウンを行い、開始演出後にだけ Mob を生成する。
- パーティー共有死亡回数、帰還ゲートからの自主離脱／再参加、リーダー中止、Dungeon Sidebar を管理する。
- ボス部屋クリア時に対象者ごとの報酬を確定し、実チェストからページング GUI で受け取らせ、30秒後に強制帰還・破棄する。
- 退出、全参加者不在、生成失敗、死亡許容回数超過、踏破後30秒、Plugin 停止時に Mob・表示・task・ワールド・フォルダを回収する。

## 3. 責務外

- 複数階、鍵アイテム、制限時間は扱わない。
- 部屋や通路を Schematic として手作業管理しない。
- 受付時点に含まれなかった真の途中参加、進行状態・未受取報酬の永続化、サーバー再起動後の復帰は扱わない。
- 個別ダンジョンのテーマ、攻略段階、Mob 構成そのものは本 feature のコードへ埋め込まない。

## 4. 主要境界と不変条件

- 1 開始要求につき一意な一時 `DUNGEON` ワールドを作り、他セッションと共有しない。
- 部屋数は固定値ではなく `roomCount.min` から `roomCount.max` の範囲で seed により決定する。
- 接続は全室を結ぶ閉路なしの木とし、開始部屋からグラフ距離が最大の葉を唯一のボス部屋とする。
- 開始部屋には通常 Mob だけを出現させ、`firstCombatRoomMaxMobLevel` を超える Mob は抽選候補から除外する。候補が一体もない定義は公開しない。
- ボス部屋には `bossMobId` の BOSS Mob を一体だけ出現させる。
- 通路は初期生成済みとし、未クリア側を表示ゲート Material とその奥の不可視 BARRIER で遮断する。親部屋全滅時は対応する両方を AIR に置換する。
- 受付後は参加者を Boss と同じ待機ハブへ移し、生成完了時にオンライン・通常プレイモード・待機ハブ滞在を再判定する。最少人数未満なら元地点へ戻して終了する。
- START 部屋へ初回転送した後は、10秒間 Mob を生成しない。参加者が一人以上残る限り受付時の最少人数は再判定せず、再参加者にはカウントダウンを繰り返さない。
- `deathLimit` は0を許容し、共有死亡回数が設定値以下の間は復帰可能、設定値を超えた死亡で終了する。
- 帰還ゲートから自主離脱した受付時参加者だけが同一インスタンスへ再参加できる。ログアウトで権利を失い、挑戦開始後に現パーティーへ加入したメンバーは参加できない。
- Dungeon Mob の死亡報酬受取人は死亡確定時、クリア報酬受取人はボス部屋クリア確定時に、当該 Dungeon world 内にいる現在参加者へ固定する。後補償しない。
- クリア報酬は受取人ごとに独立抽選し、未受取分はクリアから30秒後のセッション破棄と同時に破棄する。
- reload は新規開始へだけ反映し、進行中セッションは受付時の Dungeon、受付 World、Mob スナップショットを保持する。

## 5. データと依存

- Dungeon マスタ: `40_filebase/65.features.dungeon/*.yml`
- 受付 World 参照: `entry.worldRef` が示す既存 World マスタ
- 生成 World: DungeonService が安全な共通既定値から一時 `DUNGEON` World 定義を組み立てるため、ダンジョンごとの World マスタは不要
- Mob 参照: [[12_0-概要]] の ENEMY/BOSS Mob マスタ
- パーティー: [[19_0-概要]] の受付時オンラインメンバー一覧
- ワールド登録・転送: [[17_0-概要]] の実行時 World 登録とチャンク準備済み転送
- 死亡確定・報酬後通知: [[14_0-概要]] の Mob 死亡処理
- 死亡・復帰: PlayerDeathService
- クリア報酬抽選・付与: MobDropService、InventoryService、item feature
- 表示: DisplayTextService、共通 interaction gateway、hud feature
