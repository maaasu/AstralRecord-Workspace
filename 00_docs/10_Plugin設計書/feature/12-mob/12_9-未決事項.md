# 12_9-未決事項

## 1. boss 固有 mechanics の拡張点

phase 遷移、skill rotation、戦闘エリア、QTE などを boss feature へ集約するか、mob template / service に拡張点を置くかは未決。現行の boss challenge と個別実装を変更する時に境界を確定する。

## 2. knockback 方向の調整

現行は攻撃元から対象への水平 vector を基準とする。実プレイで違和感がある場合に、方向 jitter、攻撃種別、preferred range を考慮した補正値を決める。

## 3. AI・Pathfinder の負荷上限

1 tick task 内で探索・追跡・viewer・path 再要求を分散しているが、100 体超や複雑地形での許容 MSPT は確定していない。休眠条件、interval、spawn 上限を計測後に調整する。

## 4. custom hitbox

現行は Bukkit 実体の hitbox を使用する。巨大 boss など表示と判定が一致しない entity 向けに `hitboxRadius` / `hitboxHeight` を template へ追加するかは未決。

## 5. template hot reload の排他

`/mob load` は cache を全件置換するが、頻繁な再ロードや同時 spawn を想定した lock / snapshot policy は未決。現状は管理運用中だけ実行する。

## 6. Mob インスタンスの長期保持

現行の Mob インスタンスは永続化せず、サーバ再起動で消滅する。長期保持が必要になった場合の保存対象、復元境界、world 不在時の扱いは未決である。

## 7. Mob インスタンス数の上限

現行はインスタンス数の上限ガードを持たず、`/mob list` で件数を監視する。上限値と超過時の生成拒否・休眠方針は負荷計測後に決定する。
