# 12_6-Mobスキル追加ガイド

## 1. 分離方針

Mob スキルは player スキルと別の実行系である。`skill` master、skill gem、習得状態、player の
`SkillService` には登録しない。Mob master の `ai.combat.skills[].id` と、同じ ID を返す
`MobSkillExecutor` 実装を対にして追加する。

既存ファイルの互換用として `skills: [mob_example]` の文字列 ID も読めるが、timing と `params` を
定義できないため、新規・更新マスターでは必ず `- id: mob_example` の object 形式を使う。

通常攻撃をなくす変更ではない。接触時に即時ダメージを行う通常攻撃は `normalAttack`、矢・範囲技・
詠唱技など固有行動は `skills` へ定義する。両方を併用できる。

## 2. 追加手順

1. 共通契約の `MobSkillExecutor`、`MobSkillContext`、`MobSkillRegistry` は `feature/mob/skill` に置く。ID ごとの `...MobSkillExecutor` は `feature/mob/skill/<mob系統>` に追加する（例: スケルトン・アーチャーは `skill/skeletonarcher`、黄昏の巨像は `skill/twilightcolossus`）。`service` 直下へ個別 executor を追加しない。ID は `mob_` 接頭辞を使い、`id()` がその値を返す。
2. executor の JavaDoc に、`params` の必須・任意、既定値、許可範囲、ゲーム上の意味を記載する。パラメーターは通常 2〜3 個、上限 10 個とする。
3. `defaultTiming()` で発動距離、クールダウン、詠唱時間の既定値を定義し、`validate()` で固有パラメーターを検証する。
4. `AstralRecord` の `MobSkillRegistry` へ executor を登録する。player 用 executor や built-in `SkillDefinition` には追加しない。
5. 対象 Mob master の `ai.combat.skills[]` に ID と必要最小限の上書き値を定義する。詠唱表示が必要なら `castTimeTicks` を 1 以上にする。
6. 通常攻撃が必要なら `normalAttack.range` と `normalAttack.intervalTicks` を残す。スキルだけで攻撃させる Mob は `normalAttack` を省略する。
7. executor のパラメーター検証、registry、必要なら当たり判定をテストし、YAML と実装を同じ変更でレビューする。

## 3. 実行時の契約

`MobAiService` は距離と AI 状態を管理し、`MobSkillService` は詠唱、クールダウン、既存の Mob 頭上詠唱表示、
executor 呼び出しを管理する。ID 不明・パラメーター不正の binding は発動せず、通常攻撃があればそれだけを行う。

見える飛び道具は `MobProjectileService` を使用する。tick ごとの位置と player hitbox、block ray trace で判定するため、
発射後に移動して避けられ、壁にも遮られる。即時の `RANGED` 通常攻撃に置き換えてはならない。

## 4. ミドルアースの遺跡の専用契約

- `mob_middle_earth_piglin_rush` は30 tick（約1.5秒）の詠唱開始時に固定したターゲット位置へ突進する。詠唱後にターゲットが移動しても進行方向は変えない。
- `mob_all_things_el_ice_sphere` は同一 world の生存プレイヤー1人につき2個を発射する。各氷球はプレイヤー方向を基準に散らばり、壁面法線で反射し、命中時は氷属性ダメージと20 tickの凍結を与え、5秒で消滅する。
- `mob_all_things_el_charge` は各回の停止開始時にターゲット位置を固定し、20 tick停止後に突進する。総突進回数は `max(1, 10 - floor(残HP% / 10))` であり、HP80〜89%は2回、HP15%は9回となる。停止中または突進中に対象がoffline、死亡、world不一致になった場合は中断する。
- 専用スキルが停止・突進を制御している間は、`MobInstance.scriptedAction` により通常AIと経路探索を停止する。終了・Mob破棄後は次tickで通常AIへ復帰する。

## 5. フォレストスパイダーのクモ糸

- `mob_forest_spider_web_shot` は、フォレストスパイダーが近距離の対象へ発射する見える飛び道具である。`MobProjectileService` の tick 単位の移動、プレイヤー hitbox、ブロック ray trace を使い、発射後の移動で回避でき、壁で止まる。
- 命中時は `AttackType.RANGED` の無属性ダメージを攻撃力の `0.75` 倍で適用する。命中してダメージまたはシールドダメージが成立した場合、`ConditionService` へ `WEAKNESS` を基礎確率25%、100 tickで要求し、付与判定と耐性計算は状態異常サービスへ委譲する。
- 既定 timing は発動距離9m、cooldown40 tick、詠唱10 tickとする。`damageRatio`、`projectileSpeed`、`projectileHitRadius`、`weaknessChance`、`weaknessDurationTicks` は Mob master の `params` で上書きできる。
- 見た目は `SharedParticleDefinitions` の COBWEB item particle を使い、バニラの Weakness PotionEffect は使用しない。

## 6. 万象の聖域の専用契約

- `mob_ainua_bite_rush` は詠唱後に5回の噛みつきを行い、各回の直後に現在の対象へ最大0.9m前進する。噛みつきは2.2m以内だけへ近接・無属性の攻撃力28%ダメージを与え、6 tick間隔で繰り返す。壁、Mob消滅、対象死亡、world不一致では安全に終了する。
- `mob_ainurindale_fang_wave` は対象方向の前方へ3波を順番に発生させる。波のY座標は発動Mobの足元に固定する。各波は左右と中央の3地点を同時攻撃し、1波につき同じプレイヤーへ1回だけ魔法・無属性の攻撃力45%ダメージを与える。波は8 tick間隔、地点の三次元半径は1.25m、左右間隔は1.8mとする。
- `mob_iluvatar_fire_sphere` は `mob_all_things_el_ice_sphere` と対になる反射火球である。同一worldの生存プレイヤー1人につき2個を散開発射し、壁面法線で反射する。命中時は炎属性の攻撃力65%ダメージと60 tickの燃焼を与え、5秒で消滅する。
- `mob_iluvatar_flame_charge` は `mob_all_things_el_charge` と同じ残HP帯の回数式を使う。各回は16 tick停止して対象位置を固定した後、炎属性の攻撃力85%ダメージを伴う突進を行う。停止中または突進中に対象がoffline、死亡、world不一致になった場合は中断する。
- 噛みつき連撃、地走り魔法、連続炎突進の実行中は `MobInstance.scriptedAction` で通常AIと経路探索を停止し、正常完了と中断のどちらでも解除する。

## 7. アルダ始まりの遺跡の巨神兵跳躍

- `mob_clay_guard_leap` はクレイガードとボスで同じ executor を共有する。`radius` は通常の2mからボス用途の8mまで指定でき、`damageRatio` は呼び出し側の攻撃力倍率として扱う。
- 忘れられたアルダの巨神兵は `radius: 8.0`、`damageRatio: 1.50`、14 tickの跳躍、30 tickの詠唱、160 tickのcooldownで着地点を攻撃する。着地点の予告、着地演出、プレイヤーへの近接・無属性ダメージは既存executorの契約を再利用する。
- この段階ではフェーズ、追加攻撃、専用演出、追加のボスギミックは定義しない。
