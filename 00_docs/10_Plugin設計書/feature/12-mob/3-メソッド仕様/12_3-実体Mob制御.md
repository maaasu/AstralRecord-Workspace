# 12_3-実体Mob制御

Mob 本体は ProtocolLib のパケットエンティティではなく、Bukkit/Paper の実体 `Mob` として生成する。固定表示用の検証カカシに限り、実体 `ArmorStand` も管理対象とする。
本仕様は `MobEntityController` が担う実体 Mob 制御と、頭上 TextDisplay 追従表示の境界を定義する。

## 1. 実体 Mob 生成

クラス名: `MobEntityController`
物理名: `spawn`

責務:

指定された `MobInstance` と `Location` から Bukkit 実体 Mob を生成し、AstralRecord 管理状態へ初期化する。

処理内容:

1. `location.getWorld()` が `null` の場合は失敗として `null` を返す。
2. 通常の entity type は対応する `Mob` class を `World.spawn` へ渡す。`ARMOR_STAND` は `ArmorStand.class` を直接生成する。
3. `Mob` と `ArmorStand` 以外は失敗扱いとする。
4. `Mob` は [[12_3-実体Mob制御]].実体 Mob 初期化、`ArmorStand` は重力・衝突・装備操作を無効化する固定表示初期化を呼ぶ。
5. `MobInstance.bindEntity` で Bukkit Entity UUID / Entity ID / 初期位置を同期する。

## 2. 実体 Mob 初期化

クラス名: `MobEntityController`
物理名: `configure`

責務:

実体 Mob を「表示・当たり判定・Pathfinder だけを使う AstralRecord Mob」として構成する。

処理内容:

1. `Bukkit.getMobGoals().removeAllGoals(mob)` を呼び、vanilla goal を全削除する。
2. `setAI(true)` / `setAware(true)` を維持する。`setAI(false)` は Pathfinder も止め、`MobAiService` からの `lookAt` による首振りも失われるため使用しない。
3. `setInvulnerable(true)` を設定し、バニラダメージで実体 HP が減らないようにする。
4. `setPersistent(false)` / `setRemoveWhenFarAway(false)` を設定し、永続保存せず、距離だけで despawn しないようにする。
5. `setCanPickupItems(false)` / `setCollidable(false)` / `setSilent(true)` を設定し、不要な実体挙動を抑える。
7. `applyVariant` で `variant.age` を `Ageable` 実体へ適用し、`setAgeLock(true)` でランダムな大人 / 子供差分を固定する。その他の名前付き差分は、対応 setter の Java enum または Paper `OldEnum` の値名として大小文字を区別せず解決する。Paper 1.21.11 の `Villager.Profession` / `Villager.Type` も対象とし、未対応 setter や未知値はその差分だけを無視する。
8. PDC に `mob_instance_id` と `mob_template_id` を保持する。
9. Pathfinder の `setCanOpenDoors(false)` / `setCanPassDoors(true)` / `setCanFloat(true)` を設定する。

## 3. 実体 Mob 取得・同期

クラス名: `MobEntityController`
物理名: `getMob` / `syncLocation`

責務:

`MobInstance.bukkitEntityId` から Bukkit 実体を解決し、現在位置を `MobInstance.currentLocation` へ同期する。

`getMob` は無効な実体、死亡済み実体、`Mob` 以外の Entity を `null` 扱いとする。`syncLocation` は有効な管理 Entity を対象とするため、固定表示用 `ArmorStand` も現在位置を同期できる。`MobAiService.tick` は同期に失敗したインスタンスを破棄する。

## 4. Pathfinder 移動要求

クラス名: `MobEntityController`
物理名: `moveTo`

責務:

Paper Pathfinder へ目標位置を渡す。AI の意思決定は `MobAiService` が行い、`MobEntityController` は経路要求のレート制限を担う。

軽量化ルール:

- 目標まで 0.6 ブロック以内なら `stopPathfinding` する。
- 既存 path があり、目標地点の X/Z 変化が 1.5 ブロック未満で、再計算間隔未満なら `moveTo` を再発行しない。
- 再計算間隔は `10 tick` とする。
- Pathfinder speed は `MOVEMENT_SPEED / 100 * idle.speed * 0.9` から算出し、`0.05` から `2.5` の範囲へ丸める。`MOVEMENT_SPEED = 100` の mob は従来比 60% の速度となる。

### Vex 三次元経路

`VEX` は Paper Pathfinder の代わりに `VexFlightPathfinder` の有界三次元 A* を使用する。

- 1 block 格子の 26 近傍を探索し、斜め移動は直交中間位置もすべて通過可能な場合だけ許可する。
- Vex の実 AABB を候補位置へ平行移動し、block collision shape と重ならない位置だけを経路へ採用する。未ロードチャンク・ワールド高度外は閉塞扱いとする。
- 探索範囲は開始位置から水平 20 block、上下 10 block、最大 768 展開ノードとする。目標へ到達できない場合は、範囲内で目標に最も近い安全な部分経路を返す。
- 目標の X/Y/Z 変化が 1.5 block を超えた場合、保持経路を使い切った場合、または衝突で経路を破棄した場合に再計算する。再計算は 10 tick 以上、経路を得られなかった場合の再試行は 20 tick 以上空ける。
- `MobAiService` は意思決定間隔にかかわらず、保持中の Vex 経路を毎 tick 追従させる。次 tick の速度線分を 0.15 block 以下の間隔で検査し、実 AABB が衝突する場合は速度をゼロにして経路を破棄する。
- `MobEntityController.addVelocity` で Vex へ戦闘用直接移動またはノックバックを加算した場合は保持経路を解除し、その直接速度を次の経路追従 tick まで優先する。経路再計算待機中に経路がないことだけを理由として velocity をゼロにせず、直接速度の移動線分が衝突する場合だけ速度をゼロにする。
- 部分経路の完了、衝突、戦闘用直接移動では Vex の飛行経路だけを解除し、WANDER NPC の詰まり検知状態は維持する。明示停止または配置アンカーへの復帰では飛行経路と詰まり検知状態をまとめて消去する。
- 移動禁止、速度倍率 0、停止、到達時は velocity と Vex 経路状態を消去する。

## 5. 配置アンカーへの位置リセット

クラス名: `MobEntityController`
物理名: `resetPosition`

`NPC` の WANDER 徘徊を配置座標へ戻すため、管理 Entity を `anchor` の X/Y/Z へテレポートする。通常 Entity の現在の yaw / pitch は維持し、実体 Mob の velocity と Pathfinder を停止して、`MobInstance` のナビゲーション状態もクリアする。block NPC は既存の配置ルールに従って pitch を 0 とし、当たり判定用 `Interaction` と表示用 `BlockDisplay` / `ItemDisplay` を同じ anchor へ同期する。

## 6. 実体 Mob 破棄

クラス名: `MobEntityController`
物理名: `remove`

責務:

紐付く Bukkit 実体 Mob を `remove()` する。`MobService.destroy` / `destroyAll` から呼ばれる。

## 7. 頭上表示

Mob 本体の spawn / move / destroy は Bukkit/Paper の entity tracking に任せる。
Mob の頭上 HP 表示だけは `shared/display` の TextDisplay 共有層で扱う。

- `DisplayTextService`: 実体 TextDisplay の spawn / metadata / passenger attach / destroy を提供する。
- `OverheadDisplayService`: Mob の実体 Entity に TextDisplay を passenger として接続し、Mob の表示名、HP、シールド、詠唱中スキルの CAST バーを頭上へ表示する。Shield リチャージ中は Shield が存在しないため通常の Shield バーを隠し、経過割合が左から右へ増えるオレンジ色の `RC` バーと残り秒数を表示する。プレイヤーについても同じ共有層で、Shield を持つ場合は同じリチャージ表示を行う。passenger の基準位置が Mob 種別ごとの実体高を反映するため、ローカル Y 補正は実体高に依存させず固定の頭上余白とする。

`MobService.updateViewers` は Mob 本体の表示差分ではなく、頭上 TextDisplay の表示対象プレイヤー集合のみを管理する。
