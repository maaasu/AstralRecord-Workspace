# 12_3.05-実体Mob制御

Mob 本体は ProtocolLib のパケットエンティティではなく、Bukkit/Paper の実体 `Mob` として生成する。
本仕様は `MobEntityController` が担う実体 Mob 制御と、頭上 TextDisplay 追従表示の境界を定義する。

## 1. 実体 Mob 生成

クラス名: `MobEntityController`
物理名: `spawn`

責務:

指定された `MobInstance` と `Location` から Bukkit 実体 Mob を生成し、AstralRecord 管理状態へ初期化する。

処理内容:

1. `location.getWorld()` が `null` の場合は失敗として `null` を返す。
2. `World.spawnEntity(location, template.entityType())` を呼ぶ。
3. 生成結果が `org.bukkit.entity.Mob` でない場合は `remove()` して失敗扱いとする。
4. [[12_3.05-実体Mob制御]].実体 Mob 初期化 を呼ぶ。
5. `MobInstance.bindEntity` で Bukkit Entity UUID / Entity ID / 初期位置を同期する。

## 2. 実体 Mob 初期化

クラス名: `MobEntityController`
物理名: `configure`

責務:

実体 Mob を「表示・当たり判定・Pathfinder だけを使う AstralRecord Mob」として構成する。

処理内容:

1. `Bukkit.getMobGoals().removeAllGoals(mob)` を呼び、vanilla goal を全削除する。
2. `setAI(true)` / `setAware(true)` を維持する。`setAI(false)` は Pathfinder も止め、`MobAiService` からの `lookAt` による首振りも失われるため使用しない。
3. `setInvulnerable(true)` を設定し、バニラダメージで実体 HP が減らないようにする。
4. `setPersistent(false)` / `setRemoveWhenFarAway(false)` を設定し、永続保存せず、距離だけで despawn しないようにする。
5. `setCanPickupItems(false)` / `setCollidable(false)` / `setSilent(true)` を設定し、不要な実体挙動を抑える。
7. `applyVariant` で `variant.age` を `Ageable` 実体へ適用し、`setAgeLock(true)` でランダムな大人 / 子供差分を固定する。
8. PDC に `mob_instance_id` と `mob_template_id` を保持する。
9. Pathfinder の `setCanOpenDoors(false)` / `setCanPassDoors(true)` / `setCanFloat(true)` を設定する。

## 3. 実体 Mob 取得・同期

クラス名: `MobEntityController`
物理名: `getMob` / `syncLocation`

責務:

`MobInstance.bukkitEntityId` から Bukkit 実体を解決し、現在位置を `MobInstance.currentLocation` へ同期する。

無効な実体、死亡済み実体、`Mob` 以外の Entity は `null` 扱いとする。`MobAiService.tick` は同期に失敗したインスタンスを破棄する。

## 4. Pathfinder 移動要求

クラス名: `MobEntityController`
物理名: `moveTo`

責務:

Paper Pathfinder へ目標位置を渡す。AI の意思決定は `MobAiService` が行い、`MobEntityController` は経路要求のレート制限を担う。

軽量化ルール:

- 目標まで 0.6 ブロック以内なら `stopPathfinding` する。
- 既存 path があり、目標地点の X/Z 変化が 1.5 ブロック未満で、再計算間隔未満なら `moveTo` を再発行しない。
- 再計算間隔は `10 tick` とする。
- Pathfinder speed は `MOVEMENT_SPEED / 100 * idle.speed * 0.9` から算出し、`0.05` から `2.5` の範囲へ丸める。`MOVEMENT_SPEED = 100` の mob は従来比 60% の速度となる。

## 5. 実体 Mob 破棄

クラス名: `MobEntityController`
物理名: `remove`

責務:

紐付く Bukkit 実体 Mob を `remove()` する。`MobService.destroy` / `destroyAll` から呼ばれる。

## 6. 頭上表示

Mob 本体の spawn / move / destroy は Bukkit/Paper の entity tracking に任せる。
Mob の頭上 HP 表示だけは `shared/display` の TextDisplay 共有層で扱う。

- `DisplayTextService`: 実体 TextDisplay の spawn / metadata / passenger attach / destroy を提供する。
- `OverheadDisplayService`: Mob の実体 Entity に TextDisplay を passenger として接続し、Mob の表示名、HP、シールド、詠唱中スキルの CAST バーを頭上へ表示する。passenger の基準位置が Mob 種別ごとの実体高を反映するため、ローカル Y 補正は実体高に依存させず固定の頭上余白とする。

`MobService.updateViewers` は Mob 本体の表示差分ではなく、頭上 TextDisplay の表示対象プレイヤー集合のみを管理する。
