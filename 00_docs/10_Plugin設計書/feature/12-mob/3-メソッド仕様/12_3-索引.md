## 記載ルール

- 論理名（日本語）を主表記とする
- 物理名（メソッド名）とクラス名を併記する
- 処理内容は手順で記載する

## 責務マッピング

| クラス | 主な責務 | 定義ファイル |
|---|---|---|
| `MobCommand` | `/mob` サブコマンドの受け口 | [[12_3-コマンド]] |
| `MobTabCompleter` | `/mob` のサブコマンド・引数補完 | [[12_3-コマンド]] |
| `MobService` | テンプレート・インスタンス管理、外部 API のエントリポイント | [[12_3-サービス]] |
| `MobAiService` | tick 駆動の状態遷移、待機行動駆動、頭上表示用 viewer 同期 | [[12_3-サービス]] |
| `MobEntityController` | 実体 Mob 生成、vanilla goal 全削除、Pathfinder 移動要求、実体削除 | [[12_3-実体Mob制御]] |
| `MobVanillaDamageBlockEventHandler` | ENEMY / BOSS へのバニラダメージとバニラ燃焼をキャンセルし、バニラ由来の炎上表示を解除 | [[12_3-戦闘]] |
| `NpcPlacementWorldEventHandler` | world load 後の NPC 配置 spawn retry | [[12_3-イベント]] |
| `MobVanillaEffectProtectionService` | バニラ由来の可視状態とプラグインが明示的に付与した可視状態を区別 | [[12_3-戦闘]] |
| `MobCombatService` | 攻撃・被ダメージ・致死処理 | [[12_3-戦闘]] |
| `MobKnockbackService` | ノックバックベクトル算出と送出 | [[12_3-戦闘]] |
| `MobThreatTable` | プレイヤー単位の脅威値管理 | [[12_3-戦闘]] |
| `MobDropService` | ドロップ抽選と払い出し | [[12_3-戦闘]] |
| `MobRepository` | AstralRecord API への HTTP リクエスト | [[12_3-リポジトリ]] |
| `GatheringInteractionEventHandler` | 採集対象を world interaction 候補として解決 | [[12_3-イベント]] |
| `GatheringSpawnerBlockEventHandler` | 採集 spawner の左クリック・block mutation 候補を解決 | [[12_3-イベント]] |
| `GatheringService` | 採集定義・instance・session・報酬・quest 通知 | [[12_3-サービス]] |
| `GatheringSpawnerService` | 採集 spawner 定義・配置・出現判定・dirty 保存 | [[12_3-サービス]] |
| `GatheringVisualizer` / `GatheringPacketDisplay` | 採集 object と HP gauge の packet-only 表示 | [[12_3-サービス]] |
| `GatheringSpawnerVisualizer` | ADMIN mode 向け採集 spawner 表示 | [[12_3-サービス]] |
| `GatheringCommand` / `GatheringTabCompleter` | `/gathering` 管理コマンド・補完 | [[12_3-コマンド]] |
| `GatheringDefinitionRepository` | filebase 採集定義の読込 | [[12_3-リポジトリ]] |
| `GatheringSpawnerDefinitionRepository` / `GatheringSpawnerLocationRepository` | 採集 spawner 定義・配置の読書き | [[12_3-リポジトリ]] |
