# 12_3-コマンド

## 1. mob コマンド入口

クラス名: `MobCommand`
物理名: `executePlayerCommand`

`/mob <load|list|spawn|delete|spawner|npc> ...` を管理者権限で処理し、サブコマンドごとの `handle*` へ振り分ける。引数不足・不明 action は usage を表示する。

## 2. template load / list

クラス名: `MobCommand`
物理名: `handleLoad`, `handleList`

- `load`: `MobService.loadAll` で API template を全件再ロードし、件数を通知する。
- `list`: `MobService.getLoadedMobIds` の loaded ID 一覧を通知する。

## 3. enemy / boss spawn

クラス名: `MobCommand`
物理名: `handleSpawn`

`/mob spawn <templateId>` を実行者の現在地へ生成する。許可 category は `ENEMY` / `BOSS` だけとし、`NPC` は NPC 配置経路へ分離する。template 未解決または spawn 失敗時は `P_5703` を通知する。

## 4. instance 削除

クラス名: `MobCommand`
物理名: `handleDelete`

`/mob delete <instanceUuid|templateId|displayName>` を解決し、一致する instance を `MobService.destroyById` で削除する。template ID 以外は loaded template の表示名候補も解決する。

## 5. spawner 管理

クラス名: `MobCommand`
物理名: `handleSpawner`, `handleSpawnerItem`

- `spawner reload`: master と配置を再ロードする。
- `spawner list`: loaded spawner ID と登録座標数を表示する。
- `spawner item <spawnerId> [amount]`: admin mode の player に packet display 用の設置 item を付与する。amount は最小 1、不正値は 1 とする。

item lore は ID、種別、表示 block、半径、判定間隔、時間帯、spawn 対象と weight、各上限を含む。配置時に実 block は置かず、専用 item も消費しない。

## 6. NPC 配置管理

クラス名: `MobCommand`
物理名: `handleNpc`, `handleNpcPlace`, `handleNpcRemove`

- `npc place <npcId|displayName> [x y z]`: `NPC` category だけを現在 world の指定位置へ保存・生成する。座標省略時は実行者位置を使う。
- `npc remove <npcId|displayName>`: template に紐づく保存配置と出現中 instance を削除する。
- `npc list` / `npc reload`: 保存配置件数の表示・再読込を行う。
- place / remove は管理者権限に加えて `MobSpawnerService.isAdminMode` を満たすこと。

## 7. mob tab 補完

クラス名: `MobTabCompleter`
物理名: `getPlayerCompletions`

subcommand、category に合う template ID / 表示名、instance UUID、spawner ID を引数位置に応じて返す。`spawn` に NPC を混在させない。

## 8. 固定 TextDisplay 管理

クラス名: `TextDisplayCommand`
物理名: `executePlayerCommand`, `handlePlace`, `handleRemove`, `handleList`, `handleReload`

`/textdisplay <place|remove|list|reload>` を管理者権限で処理する。

- `place [id] <text...>` は現在地へ固定表示を保存する。ID 省略時は `textdisplay-<連番>`、指定時は半角英数字・`_`・`-` の 1〜64 文字とする。
- text の `\\n` は改行、`&` code は表示色として解釈する。同一 ID は上書きする。
- `remove <id>` は保存と表示を削除し、`list` は ID、`reload` は YAML を再読込して表示を再生成する。

## 9. gathering コマンド入口

クラス名: `GatheringCommand`
物理名: `executePlayerCommand`

`/gathering <load|list|spawn|spawner>` を管理者権限で処理する。

- `load`: `GatheringService.loadAll` と `GatheringSpawnerService.loadAll` を順に実行し、`P_5720` で両件数を通知する。
- `list`: loaded gathering ID と出現中 instance 数を `P_5721` で表示する。
- `spawn <gatheringId>`: 実行者の現在地へ instance を生成する。不明 ID は `P_5722`、成功は `P_5723`。
- `spawner reload`: 既存 gathering instance を全破棄してから spawner 定義・配置を再ロードし、`P_5724` を通知する。
- `spawner list`: loaded spawner ID と登録座標数を `P_5725` で表示する。
- `spawner item <spawnerId> [amount]`: `hasAdminPermission()` を検証し、PDC 付き設置 item を inventory 容量確認後に付与する。定義不在は `P_5708`、容量不足は `P_5241`、成功は `P_5714`。

amount は最低 1 とし、未指定・数値不正時は 1 を使う。

## 10. gathering tab 補完

クラス名: `GatheringTabCompleter`
物理名: `getCompletions`

- 第 1 引数: `load`, `list`, `spawn`, `spawner`
- `spawn` 第 2 引数: loaded gathering ID
- `spawner` 第 2 引数: `reload`, `list`, `item`
- `spawner item` 第 3 引数: loaded gathering spawner ID
