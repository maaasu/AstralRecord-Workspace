# 12_1.00-モデル定義

## 1. ドメインモデル

`mob` 機能は、API から取得する **テンプレート系** モデル群と、ワールド上の **実体系** モデル群、AI 駆動のための **状態系** モデル群で構成される。

| 区分 | モデル | 役割 |
|---|---|---|
| テンプレート系 | [[12_1.00-モデル定義]].Mob テンプレート 等 | API から取得する静的定義 |
| 実体系 | [[12_1.00-モデル定義]].Mob インスタンス | ワールド上に生成された実体 |
| 状態系 | [[12_1.00-モデル定義]].Mob 戦闘状態 / [[12_1.00-モデル定義]].脅威値テーブル | tick 単位で変動する AI 状態 |

## 2. Mob テンプレート

物理名: `MobTemplate`

API `GET /api/mob/{mobId}` から取得する Mob 定義の表現。

### 2.1 項目

- `schemaVersion`
- `id`
- `category`: [[12_1.00-モデル定義]].Mob カテゴリ
- `displayName`（API では `name`）
- `title`（任意）
- `level`: Mob の固定戦闘レベル。プレイヤーとのレベル差によるダメージ補正と撃破経験値補正、頭上表示に使用する。プレイヤー側はアカウントレベルのみを参照し、クラスレベルは参照しない。
- `entityType`: Bukkit `org.bukkit.entity.EntityType`。NPC の場合は Bukkit block `Material` 名も許容し、block 指定時は配置座標を中心にした `BlockDisplay` fakeblock として扱う。`CHEST` / `TRAPPED_CHEST` / `ENDER_CHEST` は表示用 Material を `BARREL` に正規化する
- `nameVisible`
- `icon`（任意）
- `lore`
- `tags`
- `skin`: [[12_1.00-モデル定義]].Mob スキン設定（任意。`entityType = PLAYER` の場合に主に使用）
- `variant`: `MobVariantConfig`。同一マスタから生まれる実体 Mob の見た目差分を固定する設定。未指定時は `age: ADULT`。
- `equipment`: [[12_1.00-モデル定義]].Mob 装備設定
- `baseStats`: [[12_1.00-モデル定義]].Mob ベースステータス のリスト
- `idle`: [[12_1.00-モデル定義]].Mob 待機設定
- `interactions`: [[12_1.00-モデル定義]].Mob インタラクション設定（NPC クリック定義。未指定時は空設定）
- `targeting`: [[12_1.00-モデル定義]].Mob ターゲット設定（`NPC` の場合は `null`）
- `combat`: [[12_1.00-モデル定義]].Mob 戦闘設定（`NPC` の場合は `null`）
- `drops`: [[12_1.00-モデル定義]].Mob ドロップ設定（`NPC` の場合は `null`）

## 3. Mob カテゴリ

物理名: `MobCategory`

| 値 | 意味 |
|---|---|
| `ENEMY` | 通常エネミー。`targeting` / `combat` / `drops` を持つ |
| `BOSS`  | ボスエネミー。`ENEMY` と同一構造だが、固有ギミックはプラグイン側で個別実装 |
| `NPC`   | 非戦闘 NPC。`targeting` / `combat` / `drops` は持たない（`null`） |

NPC は `interactions` により左クリック・右クリック時のアクションを宣言できる。実行系は `id` と `params` を見て、メッセージ送信や GUI 起動などの処理へ接続する。

文字列からのカテゴリ解決（物理名: `from`）は、大小区別なし・前後空白除去で判定し、未知値は `ENEMY` にフォールバックする。

## 4. Mob ベースステータス

物理名: `MobBaseStat`

| 項目 | 型 | 説明 |
|---|---|---|
| `status` | `String` | `StatusType` 名（例: `MAX_HEALTH`） |
| `value` | `double` | ステータス値。各 `StatusType` の単位定義に従う |

正本: [[07_1.00-モデル定義]].StatusType。`StatusType` に存在しない名前は読み込み時にスキップしてログ記録する。

## 5. Mob スキン設定

物理名: `MobSkin`

| 項目 | 型 | 説明 |
|---|---|---|
| `texture` | `String?` | Base64 エンコード済みスキンテクスチャ値 |
| `signature` | `String?` | テクスチャ署名値 |

`entityType = PLAYER` 以外では参照されない。両方が `null` の場合はバニラの当該エンティティのスキンが使用される。
現行プラグイン実装では `PLAYER` は直接 spawn せず、NPC は `VILLAGER`、それ以外は `ZOMBIE` に正規化しているため、このスキン設定は将来の player-like NPC 実装向けの予約フィールドとして保持される。

### MobVariantConfig

同一マスタの Mob がランダムな見た目差分を持たないようにするための設定。未指定時は `age: ADULT` として扱う。

| 項目 | 型 | 説明 |
|---|---|---|
| `age` | `ADULT` / `BABY` | Ageable Mob の大人 / 子供表現。spawn 時に設定し、age lock で固定する。 |

## 6. Mob 装備設定

物理名: `MobEquipmentConfig`

| 項目 | 型 | 説明 |
|---|---|---|
| `mainHand` | `String?` | item ID（例: `rusty_sword`） |
| `offHand` | `String?` | item ID |
| `helmet` | `String?` | item ID |
| `chestplate` | `String?` | item ID |
| `leggings` | `String?` | item ID |
| `boots` | `String?` | item ID |

API レスポンスは `item:rusty_sword` のような prefix 付き参照値で返ってくる。本モデルへの取り込み時に `MobRepository.parseTemplate` が prefix `item:` を除去して素の ID のみを保持する。  
装備は表示のみに使用し、ダメージや防御値には影響しない（独自ステータス計算のため）。

## 7. Mob 待機設定

物理名: `MobIdleConfig`

| 項目 | 型 | 説明 |
|---|---|---|
| `behavior` | [[12_1.00-モデル定義]].待機行動 | 待機時の行動パターン |
| `wanderRadius` | `double` | `WANDER` 時の徘徊半径 |
| `speed` | `double` | 待機時の移動速度倍率（1.0 = Paper Pathfinder に渡す標準倍率） |

## 8. 待機行動

物理名: `IdleBehavior`

| 値 | 意味 |
|---|---|
| `STATIONARY` | スポーン地点から動かない |
| `WANDER` | スポーン地点を中心にランダム徘徊 |
| `PATROL` | プラグイン側で定義された経路を巡回（経路定義は将来拡張） |

## 9. Mob ターゲット設定

物理名: `MobTargetingConfig`

| 項目 | 型 | 説明 |
|---|---|---|
| `strategy` | [[12_1.00-モデル定義]].ターゲット戦略 | ターゲット選定方式 |
| `aggroRange` | `double` | 敵対検知範囲（ブロック単位） |
| `deaggroRange` | `double` | 敵対解除距離。`aggroRange * 2` がデフォルト |
| `leashRange` | `double` | スポーン地点からの最大追跡距離。超えるとリセット |

## 10. ターゲット戦略

物理名: `TargetStrategy`

| 値 | 意味 |
|---|---|
| `NEAREST` | 最も近いプレイヤー |
| `HIGHEST_THREAT` | [[12_1.00-モデル定義]].脅威値テーブル の値が最大のプレイヤー |
| `RANDOM` | 範囲内のプレイヤーからランダム |
| `LOWEST_HP` | プレイヤー側 `AstPlayer` の現在 HP が最低のプレイヤー |

## 11. Mob 戦闘設定

物理名: `MobCombatConfig`

| 項目 | 型 | 説明 |
|---|---|---|
| `style` | [[12_1.00-モデル定義]].戦闘スタイル | 戦闘スタイル |
| `preferredRange` | `double` | 戦闘時に維持したい理想距離。スキル発動距離ではない |
| `attackIntervalTicks` | `long` | 通常攻撃の間隔（tick） |
| `skills` | `List<String>` | 使用スキル ID。`MobRepository.parseTemplate` で prefix `skill:` を除去した素の ID を保持 |

`skills` に設定された Mob AI スキルの発動距離は、次に使用する `SkillDefinition.params.activationRange` を優先し、未指定時は `params.hitRange`、それも未指定またはスキル定義未ロード時は `preferredRange` にフォールバックする。`preferredRange` は遠距離 / 魔法 Mob の後退・左右移動など、間合い維持の基準として扱う。

## 12. 戦闘スタイル

物理名: `CombatStyle`

| 値 | 意味 |
|---|---|
| `MELEE` | 近接戦闘。スキル発動距離まで接近して攻撃し、`preferredRange` は理想距離として扱う |
| `RANGED` | 遠距離戦闘。距離を保ちつつ攻撃。スケーリングは `DEXTERITY` |
| `MAGIC`  | 魔法戦闘。距離を保ちつつ攻撃。スケーリングは `INTELLIGENCE` |

## 13. Mob インタラクション設定

物理名: `MobInteractionsConfig`

| 項目 | 型 | 説明 |
|---|---|---|
| `leftClick` | `List<MobInteractionActionConfig>` | 左クリック時に実行するアクション一覧 |
| `rightClick` | `List<MobInteractionActionConfig>` | 右クリック時に実行するアクション一覧 |

未指定時は `MobInteractionsConfig.EMPTY` として空配列を保持する。NPC 以外のカテゴリでは現行実装上は空設定として扱う。

## 14. Mob インタラクションアクション

物理名: `MobInteractionActionConfig`

| 項目 | 型 | 説明 |
|---|---|---|
| `id` | `String` | アクション ID。初期定義は `message` / `gui` / `command` |
| `params` | `Map<String, String>` | アクションごとのパラメータ |

`MobRepository.parseTemplate` は API から返る `interactions.leftClick[]` / `interactions.rightClick[]` を読み取り、`params` のプリミティブ値を文字列として保持する。

初期定義:

| `id` | `params` | 説明 |
|---|---|---|
| `message` | `message` | プレイヤーに送るメッセージ本文 |
| `gui` | `type` | 開く GUI の種類（例: `SHOP`, `SELL`, `CLASS`, `STORAGE`, `EQUIPMENT_ENHANCE`, `EQUIPMENT_REPAIR`） |
| `command` | `command` | プレイヤーとして実行するコマンド文字列。先頭の `/` は任意 |

`gui.type=SHOP` は NPC interaction 専用の開き方として shop feature へ通知する。この導線では `access=NPC_ONLY` のショップを開けるが、同じショップは `/shop` やメニュー導線からは開けない。

## 15. Mob ドロップ設定

物理名: `MobDropConfig`

| 項目 | 型 | 説明 |
|---|---|---|
| `exp` | `int` | 撃破時の基礎経験値。受取人のプレイヤーレベルと Mob レベルの差に応じて補正する |
| `money` | [[12_1.00-モデル定義]].Mob 金銭ドロップ | 金銭ドロップ。`null` 許容 |
| `items` | `List<MobDropItem>` | ドロップアイテム一覧 |
| `lootTable` | `String?` | 既存 LootTable の ID。`MobRepository.parseTemplate` で prefix `loot_table:` を除去した素の ID を保持 |

`items` と `lootTable` は併用可能。両方指定時はそれぞれ独立に抽選する。

## 16. Mob 金銭ドロップ

物理名: `MobMoneyDrop`

| 項目 | 型 | 説明 |
|---|---|---|
| `min` | `int` | 最小値（両端含む） |
| `max` | `int` | 最大値（両端含む） |

撃破時に `[min, max]` の一様分布で 1 回抽選する。

## 17. Mob ドロップアイテム

物理名: `MobDropItem`

| 項目 | 型 | 説明 |
|---|---|---|
| `itemId` | `String` | item ID。`MobRepository.parseTemplate` で prefix `item:` を除去した素の ID を保持 |
| `rate` | `double` | ドロップ確率（0.00 〜 100.00） |
| `amount` | `String` | 数量。固定値（`1`）または範囲（`1~3`） |
| `luckAffected` | `boolean` | `true` の場合、幸運補正の影響を受ける |
| `hidden` | `boolean` | `true` の場合、図鑑表示しない |

### 17.1 Mob ドロップ結果アイテム

物理名: `MobDropResultItem`

| 項目 | 型 | 説明 |
|---|---|---|
| `itemId` | `String` | 当選した item ID |
| `amount` | `int` | 確定した数量 |
| `dropRate` | `double` | 当選元の `MobDropItem.rate`（%）。リザルト表示とレア判定に使用する |

通常 Mob（`ENEMY`）は `dropRate <= 0.1`、ボス（`BOSS`）は `dropRate <= 5.0` の当選アイテムをレアドロップとして扱う。

## 18. Mob インスタンス

物理名: `MobInstance`

ワールド上に生成された AstralRecord Mob の実行時状態。Bukkit/Paper の実体 `Mob` と紐付き、クライアントへの本体表示・当たり判定・経路探索は実体 Entity が担当する。

### 18.1 項目

- `instanceId`: `UUID`
- `bukkitEntityId`: `UUID?`（紐付く Bukkit Entity UUID。生成前または破棄後は `null`）
- `entityId`: `int`（紐付く Bukkit Entity ID。未紐付け時は `-1`）
- `template`: [[12_1.00-モデル定義]].Mob テンプレート
- `spawnLocation`: スポーン位置（leash 判定の基準）
- `currentLocation`: 現在位置
- `currentHealth`: `double`
- `state`: [[12_1.00-モデル定義]].Mob 戦闘状態
- `target`: 現ターゲット `AstPlayer`（`null` 許容）
- `lastAttackTick`: `long`（最終攻撃 tick）
- `lastAttackerUuid`: `UUID?`（最後にダメージを与えたプレイヤー UUID。致死処理のキラー特定フォールバックに使用）
- `threatTable`: [[12_1.00-モデル定義]].脅威値テーブル
- `navTargetX` / `navTargetZ`: 最後に Paper Pathfinder へ渡したターゲット座標
- `navRecomputeTick`: 最後に Paper Pathfinder へ目標を再設定した内部 tick
- `navPath` / `navPathIndex` / `navBlockedSinceTick`: 旧自前経路探索との互換用フィールド。現行実装では経路本体は Paper Pathfinder が保持する
- `wanderAnchor`: `WANDER` 時の中心座標（通常は `spawnLocation`）
- `wanderTarget`: `WANDER` 時の現在の目的地（未設定時は `null`）
- `wanderPauseUntilTick`: `WANDER` 時に次の目的地を選ぶ前の停止解除 tick
- `viewers`: `MobService` 側の内部キャッシュで保持する。Mob 本体ではなく頭上 packet display の表示対象プレイヤー UUID 集合として使用する

### 18.2 ライフサイクル

- 生成時: `currentHealth = MAX_HEALTH の baseStat 値`、`state = IDLE`、`threatTable` は空。`MobEntityController` が実体 Mob を生成した後、`bindEntity` で `bukkitEntityId` / `entityId` / `currentLocation` を同期する。
- 死亡時: `currentHealth <= 0` で `state = DEAD` に遷移し、ドロップ確定または AI tick の破棄処理で実体 Mob を remove する。

## 19. Mob 戦闘状態

物理名: `MobState`

| 値 | 意味 |
|---|---|
| `IDLE` | 非接敵。`idle.behavior` に従って動く |
| `AGGRO` | 接敵。`targeting` の選定に基づきターゲットを追跡 |
| `COMBAT` | 戦闘中。スキル発動距離内で `attackIntervalTicks` ごとに攻撃し、`preferredRange` を理想距離として維持 |
| `LEASHED` | `leashRange` を超えたためスポーン地点へ帰還中 |
| `DEAD` | 撃破済み。次 tick で完全消滅する |

状態遷移は [[12_4.00-統合フロー]] を参照。

## 20. 脅威値テーブル

物理名: `MobThreatTable`

`Map<UUID, Double>` をキャプセル化した内部構造。プレイヤー UUID をキーとし、脅威値を蓄積する。

| メソッド | 役割 |
|---|---|
| `add(playerId, amount)` | 既存値に加算 |
| `set(playerId, amount)` | 値を上書き |
| `remove(playerId)` | エントリ除去 |
| `top()` | 最大脅威値のプレイヤー UUID を返す（空なら `null`） |
| `decay(factor)` | 全エントリに `factor`（0.0〜1.0）を乗算（時間経過の減衰） |

脅威値の初期付与・加算量は [[12_3.03-戦闘]] で定義する。

## 21. Mob スポナー定義

物理名: `MobSpawnerDefinition`

filebase の `40.features.mob/spawner/*.yml` から読み込む静的定義。スポーン座標は含めず、プラグインデータフォルダ配下 `mob_spawners.yml` の `MobSpawnerLocation` で保持する。

| 項目 | 型 | 説明 |
|---|---|---|
| `id` | `String` | スポナー ID |
| `region` | `String?` | スポナー範囲の地域表示名。未設定時はプレイヤー地域判定に使用しない |
| `radiusMeters` | `double` | 登録座標を中心とした水平スポーン範囲。上方向の高さ上限にも使う |
| `spawnMobs` | `List<MobSpawnerEntry>` | スポーン対象 Mob と抽選重み |
| `timeWindows` | `List<MobSpawnerTimeWindow>` | スポーン可能なワールド時間帯 |
| `itemMaterial` | `Material` | `user.permission = 99` 向けスポナーアイテムの見た目。ブロック Material のみ |
| `spawnIntervalTicks` | `long` | スポーン判定間隔 |
| `maxAlivePerSpawner` | `int` | 当該スポナー由来の同時存在上限 |
| `maxNearbyMobs` | `int` | 他スポナー由来を含む周辺 Mob 上限 |
| `spawnPerPlayer` | `int` | 範囲内プレイヤー 1 人あたりの目標スポーン数。最大 6 人分まで加算 |

## 22. Mob スポナー座標

物理名: `MobSpawnerLocation`

| 項目 | 型 | 説明 |
|---|---|---|
| `spawnerId` | `String` | `MobSpawnerDefinition.id` |
| `worldName` | `String` | Bukkit ワールド名 |
| `x` / `y` / `z` | `int` | ブロック座標 |

座標キーは `worldName:x:y:z` とし、スポナー ID に関係なく同一座標の重複登録を拒否する。

## 23. 入出力モデル

- API 入力: なし（GET のみ）
- API 出力:
  - `GET /api/mob` -> [[12_1.00-モデル定義]].Mob テンプレート の主要項目配列（summary）
  - `GET /api/mob/{mobId}` -> [[12_1.00-モデル定義]].Mob テンプレート

API 側のレスポンス DTO は `00_docs/20_API設計書/feature/16-mob/1-モデル定義/16_1.00-モデル定義.md` を参照。

## 24. 関連 feature とのモデル関係

- `status`:
  - `StatusType` を `baseStats[].status` キーとして直接参照する。
  - `STRENGTH` / `DEXTERITY` / `INTELLIGENCE` / `ATTACK` / `DEFENSE` / `MAGIC_DEFENSE` などはダメージ計算に使用する。
- `player`:
  - `AstPlayer` がターゲット・ダメージ送付先・ドロップ受取先となる。
  - 永続化対象は Mob 側にはなく、`AstPlayer` のインベントリ・経験値・所持金更新は各 feature の API 経由で行う。
- `loot`:
  - `drops.lootTable` の参照解決で `LootTableResponse` を読み出す。
- `item`:
  - `drops.items[].itemId` の参照解決で `ItemResponse` を読み出す。
- `skill`:
  - `combat.skills` の参照解決で `SkillResponse` を読み出す。
## 追加補足

- `NPC` で `damageImmune = true` の場合は、Bukkit 側の無敵化だけでなく custom combat / built-in 通常攻撃 / 特殊攻撃からも HP を減算しない。
- NPC interaction を受け付けた入力では、hotbar-action feature の武器通常攻撃・特殊攻撃は同時発火させない。
- NPC interaction の受付距離は 3 ブロック、視線 ray size は 0.75 とし、近距離で対象を正面に捉えた場合のみ発火させる。

## 追記（2026-06-24）account mode による NPC interaction 制限

- NPC interaction は通常プレイ導線として扱い、`AccountMode.PLAYER` の場合のみアクションを実行する。
- `AccountMode.ADMIN` / `AccountMode.BUILDER` のプレイヤーが NPC をクリックした場合、対象 NPC の interaction event は cancel し、GUI 表示や通常プレイ処理は実行しない。
- `user.permission = ADMIN` は管理者権限の判定であり、account mode の通常プレイ許可とは別に扱う。
