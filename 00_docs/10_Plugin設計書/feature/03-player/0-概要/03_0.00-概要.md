# 03_0.00-概要

## 1. 目的

`player` 機能は、オンライン中のプレイヤー状態を [[03_1.00-モデル定義]].プレイヤーセッション として保持し、ログイン反映・ログアウト保存・プレイヤーモード制御・移動 action・地域・メッセージ・死亡状態を管理する。

## 2. コンテキスト

- ログイン時は user/account/inventory state のAPI取得を非同期かつ段階的に行い、Bukkit API 操作のみメインスレッドに戻す。
- ログインデータロード中はプレイヤーの座標移動をロックし、ロード完了後に解除する。
- オンライン中の他 feature は [[03_1.00-モデル定義]].プレイヤーキャッシュ 経由で状態を参照する。
- プレイヤーモードではインベントリ操作・ドロップ・ゲームモード変更を制限する。

## 3. 構成要素（実装単位）

- `event/PlayerJoinEventHandler`
  - ログイン・ログアウトイベントを受け、PlayerService に委譲する。
  - 参加時データロードの開始間隔と段階実行を制御し、ロード中の移動を抑止する。
- `event/PlayerModeEventHandler`
  - 通常プレイヤーモード中のインベントリクリック・ドラッグ・アイテムドロップ・ゲームモード変更の操作制限を行う。
- `event/PlayerSneakEventHandler`
  - しゃがみ操作からドッジ発動候補または壁張り付きを検出する。
- `event/PlayerInputEventHandler`
  - jump 入力の立ち上がりを検出し、二段ジャンプを委譲する。
- `event/ManagedChatEventHandler`, `command/DirectMessageCommand`
  - vanilla chat を管理形式へ置換し、`/message` のオンライン direct message を提供する。
- `event/PlayerVanillaDamageBlockEventHandler`
  - キャッシュ済みプレイヤーの vanilla damage を抑止し、custom combat 側へ被ダメージ責務を限定する。
- `death/PlayerDeathEventHandler`, `death/PlayerDeathService`
  - vanilla/custom combat の死亡を一時死亡状態へ統合し、固定・表示・経験値ペナルティ・復帰を管理する。
- `service/PlayerService`, `DodgeService`, `AirActionService`, `PlayerMessageService`, `PlayerRegionService`
  - プレイヤーセッション構築、保存、移動 action、メッセージ配信、地域更新を制御する。
- [[03_1.00-モデル定義]].プレイヤーキャッシュ
  - オンライン中のプレイヤーセッションを保持する。
  - 実装単位は `AstPlayerCache`。
- `save/*`
  - ログアウト・プラグイン停止時などの保存タスクを調整する。
- `shared/interaction/*`
  - Bukkit/Paper 入力を共通 token へ相関し、全 feature の候補から勝者一件だけを実行する。
