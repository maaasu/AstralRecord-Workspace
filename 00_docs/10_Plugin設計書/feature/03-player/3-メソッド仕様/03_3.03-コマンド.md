# 03_3.03-コマンド

## 1. ログイン報酬表示コマンド

クラス名: `LoginBonusCommand`
物理名: `executePlayerCommand`

処理内容:

1. プレイヤー専用コマンドとして `/loginbonus` を受け付ける
2. `AstralRecord.getInstance().getLoginBonusService()` で `LoginBonusService` を取得する
3. サービスが未初期化の場合は拒否音を再生して終了する
4. サービスが取得できた場合は開く音を再生し、[[03_3.02-サービス]].ログインボーナス表示 を実行する

## 2. コマンド仕様

- ルート: `/loginbonus`
- サブコマンド: なし
- 対象: プレイヤーのみ
- 権限値（`permission`）による個別制限は行わず、`AstCommand` 基底側の制御に委ねる
