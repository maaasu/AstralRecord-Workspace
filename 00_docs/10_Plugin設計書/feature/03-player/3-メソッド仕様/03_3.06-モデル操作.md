# 03_3.06-モデル操作

## 1. model メソッド仕様

### Bedrock判定

クラス名: `AstPlayer`
物理名: `isBedrock`

処理内容:

1. 設定値の Bedrock プレイヤー名prefix一覧を取得する
2. Bukkit プレイヤー名がいずれかのprefixで始まる場合は `true` を返す
3. prefix設定が無い場合、または一致しない場合は `false` を返す

### 権限反映

クラス名: `AstPlayer`
物理名: `applyPermission`

処理内容:

1. [[03_1.00-モデル定義]].プレイヤーセッション.user を更新する
2. permission が `99` 以上の場合、Bukkit OP 権限を付与する
3. OP 権限付与時は `LogId.I_5070` と `PlayerMsgId.P_5070` を出力する

	| 項目 | 内容 |
	|---|---|
	| ID | `LogId.I_5070` |
	| レベル | `INFO` |
	| テンプレート | `プレイヤーにOP権限を付与しました: %s (permission=%d)` |
	| 出力条件 | permission が `99` 以上 |
	| 引数 | プレイヤー名, permission |

	| 項目 | 内容 |
	|---|---|
	| ID | `PlayerMsgId.P_5070` |
	| レベル | `INFO` |
	| テンプレート | `permissionレベル{0}の管理者として認識されました。OP権限が付与されました。` |
	| 出力条件 | permission が `99` 以上 |
	| 引数 | permission |

4. permission が `99` 未満の場合、Bukkit OP 権限を解除する

### アカウントモード反映

クラス名: `AstPlayer`
物理名: `applyAccountMode`

処理内容:

1. [[03_1.00-モデル定義]].プレイヤーセッション.account を更新する
2. 通常プレイヤー以外の場合、エンティティ・ブロック操作範囲を管理用の値へ戻す
3. 通常プレイヤー以外へ切り替えた時点でゲームモードが ADVENTURE の場合、SURVIVAL に戻す
4. 通常プレイヤーの場合、ゲームモードを ADVENTURE にし、操作範囲を `0` にする

### プレイヤーメッセージ送信

クラス名: `AstPlayer`
物理名: `sendMessage`

処理内容:

1. `PlayerMessageService.send(this, msgId, args)` へ委譲する
2. 本メソッドは互換用の deprecated API とし、新規呼び出しは `PlayerMessageService` を使用する

### 現在クラス選択

クラス名: `AstPlayer`
物理名: `selectClass`

処理内容:

1. 入力を trim し、空なら `adventurer` へ正規化する
2. `classId` を更新する
3. 未経験クラスなら Lv.1 / EXP 0 の進行を生成する

### クラス進行取得

クラス名: `AstPlayer`
物理名: `getClassProgress`

処理内容:

1. class ID を正規化し、大小無視で既存進行を検索する
2. 未登録なら Lv.1 / EXP 0 の `ClassProgressModel` を map へ登録して返す

### 全クラス進行取得

クラス名: `AstPlayer`
物理名: `getAllClassProgresses`

処理内容:

1. セッション内の全 `ClassProgressModel` を class ID 順で返す

### クラス進行更新

クラス名: `AstPlayer`
物理名: `setClassProgress`

処理内容:

1. class ID を正規化し、大小だけが異なる既存 key を除去する
2. level を最低 `1`、experience を最低 `0` に clamp して登録する

### 権限レベル判定

クラス名: `AstPlayer`
物理名: `hasPermissionLevel` / `hasAdminPermission`

処理内容:

1. `hasPermissionLevel` は `user.permission >= requiredPermissionLevel` を返す
2. `hasAdminPermission` は要求値 `99` で同じ判定を行う

### スキル詠唱中判定

クラス名: `AstPlayer`
物理名: `isSkillCasting`

処理内容:

1. `skillCastingUntilMs > System.currentTimeMillis()` を返す
