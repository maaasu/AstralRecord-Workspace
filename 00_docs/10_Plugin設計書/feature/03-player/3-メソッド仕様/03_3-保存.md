# 03_3-保存

## 1. save メソッド仕様

### プレイヤー保存実行

クラス名: `PlayerSaveCoordinator`
物理名: `save`

処理内容:

1. 登録済み保存タスクを順に実行する
2. 個別タスクで例外が発生しても後続タスクは継続する
3. 例外時は `LogId.W_5071` を記録する

	| 項目 | 内容 |
	|---|---|
	| ID | `LogId.W_5071` |
	| レベル | `WARN` |
	| テンプレート | `プレイヤーデータ保存に失敗しました: タスク=%s, 契機=%s, プレイヤー=%s, 理由=%s` |
	| 出力条件 | 保存タスクで例外発生時 |
	| 引数 | タスク名, 保存契機, プレイヤー名, 例外メッセージ |

### 保存タスク名取得

クラス名: `PlayerSaveTask`
物理名: `getTaskName`

処理内容:

1. ログ出力や識別に使用する保存タスク名を返す

### 保存タスク実行

クラス名: `PlayerSaveTask`
物理名: `save`

処理内容:

1. 指定された [[03_1-モデル定義]].プレイヤーセッション と [[03_1-モデル定義]].保存契機 に応じて保存処理を実行する
