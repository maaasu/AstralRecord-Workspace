# 03_3-コマンド

## 1. ダイレクトメッセージ送信

クラス名: `DirectMessageCommand`
物理名: `executePlayerCommand`

入力:

- `args[0]`: 宛先オンラインプレイヤー名
- `args[1..]`: メッセージ本文

処理内容:

1. 引数が 2 個未満の場合は usage を返す
2. `Bukkit.getPlayerExact(args[0])` で宛先を完全一致検索する
3. 宛先が送信者自身でないことを確認する
4. 2 番目以降の引数を空白で結合・trim し、空でないことを確認する
5. `PlayerMessageService.sendDirectMessage` へ送受信者と本文を渡す

終了条件:

| 条件 | メッセージ |
|---|---|
| 宛先未検出 | `PlayerMsgId.P_5905` |
| 自分宛 | `PlayerMsgId.P_5947` |
| 本文が空 | `PlayerMsgId.P_5946` |

コマンド仕様:

- `/message <player> <message>`
- プレイヤー専用

バニラの `/msg`、`/tell`、`/w`、`/whisper` は同じ引数形式で `/message` へ変換し、同じダイレクトメッセージ送信処理を使用する。

`/say <message>` は `PlayerMessageService.broadcastGlobalChat` へ変換し、通常チャットと同じ管理全体チャット形式で配信する。

## 2. ダイレクトメッセージ補完

クラス名: `DirectMessageTabCompleter`
物理名: `getPlayerCompletions`

処理内容:

1. 第1引数位置では、実行者自身を除くオンラインプレイヤー名を返す
2. 第2引数以降は空リストを返す

## 3. クリエイティブ飛行速度設定

クラス名: `CreativeFlySpeedCommand`
物理名: `executeCommand`

- ルート: `/flyspeed <percentage> [<player>]`
- 実行者はコンソール、または permission `99` 以上のプレイヤーに限る。
- 対象プレイヤーを省略した場合は実行者自身を対象とし、コンソール実行時は `PlayerMsgId.P_5305` を返す。
- 対象プレイヤーを指定した場合は、オンラインプレイヤー名を完全一致で解決する。見つからない場合は `PlayerMsgId.P_5814` を返す。
- `<percentage>` は有限な数値の `0`〜`1000` とし、`100` を Bukkit の標準クリエイティブ飛行速度 `0.1` として、`percentage / 100 * 0.1` へ変換して `Player#setFlySpeed` に設定する。
- パーセンテージが数値でない場合は `PlayerMsgId.P_6922`、範囲外の場合は `PlayerMsgId.P_6921` を返す。
- 設定成功時は実行者へ `PlayerMsgId.P_6920` を表示する。速度はプレイヤーのオンラインセッションへ反映し、永続化しない。

## 4. ログイン報酬表示コマンド（廃止）

`LoginBonusCommand` と `/loginbonus` は廃止済みで、`plugin.yml` へ登録しない。

ログインボーナスは、NPC の `interactions.rightClick` に次の GUI action を定義して表示する。

```yaml
- id: gui
  params:
    type: LOGIN_BONUS
```

この action は [[03_3-サービス]].ログインボーナス表示 を実行する。
