# 03_1-モデル定義

## 1. ドメインモデル

`player` 機能の中心はプレイヤーセッション。  
Bukkit の `Player` と、[[01_1-モデル定義]].ユーザモデル、[[02_1-モデル定義]].アカウントモデル を結合し、オンライン中の状態として扱う。

## 2. プレイヤーセッション

物理名: `AstPlayer`

### 2.1 項目

- `bukkit`
- `user`
- `account`
- `classId`
- `classLevel`
- `classExperience`
- `classProgressById`
- `currentRegion`
- `currentRegionLevel`
- `statusSnapshot`
- `activeBuffs`
- `sneakStartedAtMs`
- `sneakStartedAtLocation`
- `sneakDodgeWindowExpiresAtMs`
- `isJumpInputPressed`
- `isAirJumpConsumed`
- `wallClingExpiresAtMs`
- `isWallClinging`
- `wallClingTowardWallDirection`
- `isDodging`

### 2.2 主要状態

| 状態 | 説明 |
|---|---|
| user | [[01_1-モデル定義]].ユーザモデル |
| account | [[02_1-モデル定義]].アカウントモデル |
| classId | 現在の職業 ID。未設定時は `adventurer` を既定値として扱う |
| classLevel | 現在の職業レベル。`classProgressById[classId]` を参照する派生プロパティ |
| classExperience | 現在職業の累計クラス経験値。`classProgressById[classId]` を参照する派生プロパティ |
| classProgressById | クラス ID ごとに独立したレベル・累計経験値を保持するセッション内マップ。転職時は転職先の保存値を復元し、未経験クラスは Lv.1 / EXP 0 とする |
| currentRegion | オンライン中の現在地域表示名。ワールド移動時はワールド種別の既定地域、オーバーワールドでは近接 Mob スポナーの任意 `region` を保持する |
| currentRegionLevel | オンライン中の現在地域レベル。オーバーワールドでは同じ地域を定義する全スポナーの出現 Mob レベル加重平均を保持し、ワールド移動時と地域未特定時は 0 に戻す |
| statusSnapshot | status feature が計算する現在ステータス |
| activeBuffs | オンライン中に有効なバフ一覧 |
| sneakDodgeWindowExpiresAtMs | ドッジ受付バーを非表示へ戻す終了時刻 |
| isJumpInputPressed | `PlayerInputEvent` の jump 押下立ち上がりを検出する直近入力状態 |
| isAirJumpConsumed | 現在の滞空中で二段ジャンプを使用済みかを表すフラグ |
| wallClingExpiresAtMs | 壁張り付きバーを非表示へ戻し、自然落下へ戻す終了時刻 |
| isWallClinging | 壁張り付き中かどうかを表すフラグ |
| wallClingTowardWallDirection | 壁張り付き開始時に正面にあった壁方向。壁キック判定に使用する |
| isDodging | ドッジ実行中かどうかを示すフラグ。ドッジ連動パッシブの発動は成功通知で処理する |

## 3. プレイヤーキャッシュ

物理名: `AstPlayerCache`

オンライン中のプレイヤーセッションを UUID キーで保持する。

## 4. プレイヤー参加データ

物理名: `PlayerJoinData`

ログイン反映前に非同期で取得した user/account の組。

| 項目 | 説明 |
|---|---|
| user | [[01_1-モデル定義]].ユーザモデル |
| account | [[02_1-モデル定義]].アカウントモデル |

## 5. 保存タスク

物理名: `PlayerSaveTask`

プレイヤーデータ保存処理の単位。保存タスク名と保存処理を持つ。

## 6. 保存契機

物理名: `PlayerSaveTrigger`

| 値 | 説明 |
|---|---|
| `LOGOUT` | ログアウト時 |
| `MANUAL` | 手動保存 |
| `AUTO` | 定期保存 |
| `PLUGIN_DISABLE` | プラグイン停止時 |

## 7. プレイヤーメッセージID

物理名: `PlayerMsgId`

プレイヤー向けメッセージキーを定義する enum。文言は `player.properties` で管理する。

## 8. プレイヤーメッセージリソース

物理名: `PlayerMsgResource`

`player.properties` を読み込み、カラーコード変換とメッセージ整形を行う。
プレイヤー名専用の整形では、オンライン状態に依存せず名前へ `/player info <playerName>` のクリックイベントと「クリックでプレイヤー情報を開く」の hover 案内を付与する。実際の GUI 表示は既存コマンドの仕様に従い、対象がオンラインで情報キャッシュを保持している場合に限る。

## 9. プレイヤーメッセージ送信サービス

物理名: `PlayerMessageService`

`PlayerMsgId` と `PlayerMsgResource` を用いて、プレイヤー向け通知を一元管理する。
システムメッセージには共通タグとタグ直後の半角1文字分の空白を付与し、全体チャット・パーティーチャット・ダイレクトメッセージも本サービス経由で送信する。GUI導線を持つ通知はクリックイベント付き Component として同じサービスから送信する。
Plugin 実装から `Player#sendMessage(...)` や `AstPlayer#sendMessage(...)` を直接使うことは新規禁止とする。
