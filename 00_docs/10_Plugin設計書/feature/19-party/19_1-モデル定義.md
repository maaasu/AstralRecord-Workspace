# 19_1-モデル定義

## Party

オンライン中だけ保持する mutable model。`PartyMember` という別 model は存在しない。

| 要素 | 型 | 意味 |
|:--|:--|:--|
| `partyId` | `UUID` | party ID |
| `leaderId` | `UUID` | leader の Bukkit player UUID |
| `members` | `LinkedHashSet<UUID>` | leader を含む加入順 member IDs |
| `createdAt` | `Instant` | 作成時刻 |
| `recruitmentMessage` | `String` | `/party recruit <募集内容>`で登録し、設定GUIと掲示板へ表示する募集内容。未設定は空文字列 |
| `recruitmentApprovalRequired` | `boolean` | 掲示板参加にleader承認が必要か。既定`true` |
| `recruitmentPublished` | `boolean` | 現在のサーバー内掲示板へ掲載中か |

`members()` は内部 set を公開せず、新しい `List<UUID>` を返す。online 状態や加入時刻は model に保持しない。

## PartyInvite

| フィールド | 型 | 意味 |
|:--|:--|:--|
| `partyId` | `UUID` | 招待元 party |
| `leaderId` | `UUID` | 招待時 leader |
| `targetId` | `UUID` | 招待対象 player |
| `createdAt` | `Instant` | 作成時刻 |

`expiresAt` は存在しない。同一 target・leader の新しい招待は map 上で置換する。承諾時は招待時のleaderが現在もleaderであることを確認し、不一致の招待を除去して拒否する。

## PartyActionResult

| フィールド | 型 | 意味 |
|:--|:--|:--|
| `success` | `boolean` | 操作成否 |
| `messageId` | `PlayerMsgId` | 実行者向け message ID |
| `args` | `Object[]` | message format 引数 |

command／GUI はこの結果を共通表示する。

## PartyJoinRequest

| フィールド | 型 | 意味 |
|:--|:--|:--|
| `partyId` | `UUID` | 申請先party |
| `requesterId` | `UUID` | 参加申請者 |
| `createdAt` | `Instant` | 申請作成日時 |

## Service 内索引

- `parties`: `partyId -> Party`
- `partyIdByMember`: `playerId -> partyId`
- `invitesByTarget`: `targetId -> (leaderId -> PartyInvite)`
- `partyChatEnabled`: 通常チャットをパーティーチャットとして送る player UUID の集合。party 脱退・追放・解散・logout・plugin disable で解除する。
- `joinRequestsByParty`: `partyId -> (requesterId -> PartyJoinRequest)`。掲載停止、満員、leader変更、party消滅、承認方式変更で対象申請を破棄する。

すべて process memory 上の状態であり、再起動後は復元しない。
