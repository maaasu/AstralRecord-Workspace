# 19_2.00-ユースケース

## 1. パーティー作成

1. プレイヤーが `/party create` または GUI 操作で作成する。
2. [[19_3.00-メソッド仕様]].パーティー作成 がリーダーを含むパーティーを作る。

## 2. 招待と参加

1. リーダーまたは権限を持つメンバーが対象プレイヤーを招待する。
2. 対象プレイヤーが承諾すると [[19_3.00-メソッド仕様]].招待承諾 がメンバーへ追加する。
3. 期限切れ招待は承諾できない。

## 3. 離脱と解散

1. メンバーが離脱するとパーティーから除外される。
2. リーダーが離脱した場合は新リーダーを選ぶ。
3. メンバーが 0 人になった場合、パーティーを解散する。

## 4. 報酬対象参照

1. mob feature が撃破時のとどめプレイヤーを特定する。
2. [[19_3.00-メソッド仕様]].近接パーティーメンバー取得 を呼び出す。
3. 同一ワールドかつ指定距離内のオンラインメンバーを返す。
