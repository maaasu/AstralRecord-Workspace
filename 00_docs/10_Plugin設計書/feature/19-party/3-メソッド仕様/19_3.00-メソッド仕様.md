# 19_3.00-メソッド仕様

## パーティー作成

クラス名: `PartyService`
物理名: `createParty`

1. プレイヤーが既にパーティー所属中でないことを確認する。
2. プレイヤーをリーダーとしてパーティーを作成する。
3. 作成後の [[19_1.00-モデル定義]].パーティー を返す。

## 招待承諾

クラス名: `PartyService`
物理名: `acceptInvite`

1. 招待が存在し、期限切れでないことを確認する。
2. 対象プレイヤーが未所属であることを確認する。
3. パーティーメンバーへ追加する。
4. 使用済み招待を削除する。

## 招待作成

クラス名: `PartyService`
物理名: `createInvite`

1. 招待者がパーティー所属中であることを確認する。
2. 招待者が対象プレイヤーを招待できる権限を持つことを確認する。
3. 対象プレイヤーが未所属であることを確認する。
4. 同一対象への未期限切れ招待がある場合は既存招待を返し、重複作成しない。
5. 招待 ID、招待者、対象プレイヤー、有効期限を持つ [[19_1.00-モデル定義]].パーティー招待 を作成する。
6. 作成した招待を対象プレイヤーへ通知する。

## 近接パーティーメンバー取得

クラス名: `PartyService`
物理名: `findNearbyMembers`

1. 基準プレイヤーの所属パーティーを取得する。
2. 入力距離が指定されている場合はその値を使う。未指定の場合は報酬共有距離 `60m` を使用する。
3. オンライン、同一ワールド、指定距離内のメンバーだけを抽出する。
4. 基準プレイヤーを含む重複なしの一覧を返す。

## パーティー GUI 表示

クラス名: `PartyGui`
物理名: `open`

1. 現在の所属状態を取得する。
2. 未所属の場合は作成・招待確認の導線を表示する。
3. 所属中の場合はリーダー、メンバー、招待、離脱・解散操作を表示する。
