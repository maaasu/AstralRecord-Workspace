# 19_3-メソッド仕様

## 作成・招待

クラス名: `PartyService`
物理名: `createParty` / `invite`

- 引数: `AstPlayer leader`、招待は `AstPlayer inviter`, Bukkit `Player target`
- 戻り値: `PartyActionResult`
- 例外: 公開操作は同期化され、業務不成立を failure result で返す。

招待時に inviter が未所属なら party を作成する。上限 6、leader 権限、target の状態を検証し、target map に `PartyInvite` を登録する。inviter または target が Dungeon／Boss の作成開始後の参加者なら `P_7024` で拒否する。待機ハブでメンバーを揃えている段階は招待制限の対象外とする。
target への招待通知はメッセージ全体をクリック可能にし、クリック時に `/party accept <招待者名>` を実行する。招待者名へのプレイヤー情報表示クリックは付与しない。target が送信 session を編集中の場合は、チャット画面を開くための inventory close が未送信内容の中止と競合しないよう、招待を保持したまま通知だけを非クリック式にする。

## 招待応答

クラス名: `PartyService`
物理名: `acceptInvite` / `declineInvite`

- 引数: `AstPlayer player`, `String leaderName`
- 戻り値: `PartyActionResult`
- 例外: 業務不成立を failure result で返す。

leader 名から online player を解決する。承認時は invite と party の関係、leader、満員を再検証して member／逆引きを更新する。leader または承認者が Dungeon／Boss の作成開始後の参加者なら `P_7024` で拒否する。期限判定は行わない。

## 脱退・切断・解散

クラス名: `PartyService`
物理名: `leave` / `leaveOnLogout` / `disband`

- 引数: `AstPlayer`、logout は `UUID playerId`, `String playerName`
- 戻り値: action result、logout はなし
- 例外: 業務不成立を result 化する。

leader 脱退時は残存 member の先頭へ leader を移譲する。party が空なら削除する。解散は leader のみ可能で、全逆引きを消す。

`leave`、`leaveOnLogout`、`kick`、`disband`、`acceptInvite` の構成変更後は `PartyMembershipChangeListener` へ party ID を通知する。挑戦待機中の Boss／Dungeon はこの通知で現在 member 一覧を同期し、全員が Hub に揃わない場合は作成待機列からメンバー待機へ戻す。全員が揃っている状態からの member 脱退で残りが全員 Hub にいる場合は、作成待機列の位置を維持する。

## member 管理

クラス名: `PartyService`
物理名: `kick` / `promote`

- 引数: `AstPlayer leader`, Bukkit `Player target`
- 戻り値: `PartyActionResult`
- 例外: 権限・所属・自己対象を failure result で返す。

## 参照・終了処理

クラス名: `PartyService`
物理名: `findParty` / `getInvites` / `clearAll`

- 引数: player UUID、またはなし
- 戻り値: `Party?`、`List<PartyInvite>`、`List<Party>`、またはなし
- 例外: なし

## `/party` command

クラス名: `PartyCommand`
物理名: `executePlayerCommand`

- 構文: `/party` または `/pt` `<gui|create|invite|accept|decline|leave|disband|kick|promote|list|chat [message]>`
- 実行者: `AccountMode.PLAYER` の player。ただし Admin の `list` は `AccountMode.ADMIN` でも実行できる
- 戻り値: なし
- 例外: service result を `PlayerMessageService` で表示する。

引数なしは GUI を開く。`chat <message>` は後続引数を message として現在 party の online member と、party 所属に関係なく `user.permission` が Admin の online player へ配信する。`chat` は通常チャットの送信先を party／全体でトグルする。
`list` は Admin の場合、全 party を作成順に一覧表示する。各行へカーソルを合わせると hover text に参加者一覧を表示する。Admin 以外は自身の party 一覧を表示する。

## パーティーチャット mode / 管理者一覧

クラス名: `PartyService`
物理名: `togglePartyChat` / `isPartyChatEnabled` / `broadcastPartyChat` / `getParties`

- `togglePartyChat` は party 所属を確認して player UUID 単位の mode を切り替え、`P_5926` または `P_5927` を返す。`isPartyChatEnabled` は所属・mode 有効に加えて現在の `AccountMode.PLAYER` も確認する。
- mode 有効中かつ `AccountMode.PLAYER` の `AsyncChatEvent` は main thread へ切り替えた後、`broadcastPartyChat` で配信する。mode 無効時または `AccountMode.PLAYER` 以外は `PlayerMessageService.broadcastGlobalChat` を使う。
- `broadcastPartyChat` の受信者は現在 party の online member と、party 所属に関係なく `hasAdminPermission()` が true の online player とする。
- `getParties` は全 party の変更不可スナップショットを返す。管理者一覧の各行は `P_5929` で整形し、`P_5909` / `P_5910` による参加者一覧を hover text として付与する。

## GUI event

クラス名: `PartyGuiEventHandler`
物理名: `onInventoryClick` / `onInventoryDrag`

対象 holder の標準操作を cancel し、create／invite／member action／back を処理する。例外時は `LogId.E_6100` に player と operation を渡す。
