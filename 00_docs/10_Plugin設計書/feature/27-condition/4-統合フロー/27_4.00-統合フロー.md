# 27_4.00-統合フロー

## スキル命中

```text
WeaponAttackSkillExecutor
  -> DamageService.attack(attackType, damageComponents)
  -> ConditionService.applyCondition(conditions[])
```

状態異常は属性ダメージの結果から自動発生せず、`conditions[]`に明示された場合だけ付与する。

## 状態異常DoT

```text
ConditionTickTask
  -> ConditionTickService.tickCondition
  -> ConditionService.conditionDamageMultiplier
  -> ConditionService.damageDealtMultiplier(source)
  -> DamageService.applyConditionDamage
  -> Shield / HP / death
```

## 横断接続

- `SkillService`: 冷気の詠唱時間倍率、凍結の発動禁止。
- `StatusService`: 冷気の移動倍率、回復阻害。
- `MobAiService`: 冷気の移動倍率、凍結・感電の停止。
- `ItemWeaponAttackEventHandler`: 凍結の通常攻撃禁止。
- `ConditionPlayerEventHandler`: 凍結・感電の移動とジャンプ禁止。
