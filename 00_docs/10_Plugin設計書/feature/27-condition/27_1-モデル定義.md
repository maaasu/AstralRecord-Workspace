# 27_1-モデル定義

## 1. `ConditionType`

| 値 | category | 既定時間 | 既定効果 | 表示 |
| --- | --- | ---: | --- | --- |
| `BURNING` | `DOT` | 100 tick | 20 tick ごとに付与元の解決攻撃力 × 0.20 | fire ticks、炎 particle |
| `FROZEN` | `CONTROL` | 40 tick | 移動・通常攻撃・スキル・Mob AI を禁止 | 氷 BlockDisplay、氷 particle |
| `CHILLED` | `CONTROL` | 100 tick | 移動速度 0.5 倍、詠唱時間 2 倍 | 氷 particle |
| `SHOCKED` | `DOT` | 100 tick | 20 tick ごとに付与元の解決攻撃力 × 0.10、16～32 tick 間隔で 6 tick 移動禁止 | 電撃 particle |
| `POISON` | `DOT` | 120 tick | 20 tick ごとに付与元の支援力 × 0.16。持続時間が長いほど総量が増え、HP 0 にできる | Poison PotionEffect、緑 particle、pulse 音 |
| `BLINDNESS` | `CONTROL` | 100 tick | condition 側の行動禁止なし | Blindness PotionEffect |
| `WEAKNESS` | `AMPLIFIER` | 100 tick | 与える最終ダメージ 0.5 倍 | 暗紫 particle |
| `HEALING_INHIBITION` | `AMPLIFIER` | 100 tick | HP / MP / EN / Shield 回復を禁止 | 赤 particle |

`SHOCKED` は category 上は `DOT` であるため、Boss の `CONTROL` 持続時間 25% 補正を受けません。

## 2. `ConditionEffect`

| フィールド | 意味 |
| --- | --- |
| `tickIntervalTicks` | DoT 間隔。0 は DoT なし |
| `healthRate` | 非 DoT 用の 1 pulse の HP 割合。DoT では 0 として扱い、対象 HP を参照しない |
| `currentHealthBased` | `true` は現在 HP、`false` は最大 HP を割合基準にする |
| `basePower` | 固定 DoT 値 |
| `sourcePowerCoefficient` | 付与元の基準能力値に対する係数。炎上・感電は解決攻撃力、毒は支援力を参照する |
| `movementSpeedMultiplier` | 移動速度倍率 |
| `castTimeMultiplier` | 詠唱時間倍率 |
| `damageDealtMultiplier` | 付与対象が与える最終ダメージ倍率 |
| `movementBlocked` / `attackBlocked` / `skillBlocked` / `aiBlocked` | 各行動の禁止 |
| `healingBlocked` | 通常回復の禁止 |
| `controlIntervalMinTicks` / `controlIntervalMaxTicks` | 間欠制御の次回発生間隔 |
| `controlDurationTicks` | 1 回の間欠制御時間 |

## 3. `ConditionApplyRequest`

| フィールド | 契約 |
| --- | --- |
| `target` | 付与対象。AstralRecord 管理 player / Mob のみ受理する |
| `source` | 付与元。環境由来は `null` |
| `type` | 状態異常種別 |
| `durationTicks` | 0 以下は `type.defaultDurationTicks` へ正規化する |
| `chance` | 基礎付与確率（%）。0～100へ clamp する |
| `strength` | 同種更新の第一比較値。0 未満は 0 へ clamp する |
| `basePower` | 固定 DoT 値の上書き。`null` は既定値 |
| `attackType` | 炎上・感電が参照する攻撃種別。スキルの攻撃種別を自動で渡し、環境由来などは `null` |
| `powerCoefficient` | 基準能力値係数の上書き。DoT は種別既定係数を上限とし、`null` は既定値 |
| `healthRate` | 非 DoT の HP 割合上書き。DoT では常に 0 として扱う |
| `tickIntervalTicks` | pulse 間隔の上書き。`null` は既定値、負数は 0 |
| `reason` | `SKILL` / `MOB_AI` / `COMMAND` / `ENVIRONMENT` / `SCRIPT` |

## 4. `ActiveCondition`

`ActiveCondition` は次の runtime 情報を保持します。

- 一意な `conditionId`、`ConditionType`、対象 ID / 種別 / `AstEntity`
- 付与元 ID / 種別 / `AstEntity`。環境由来は `null`
- 開始・終了時刻、直前 / 次回 DoT 時刻
- 次回間欠制御時刻と移動禁止終了時刻
- `strength`、付与時に解決した `snapshotPower`、`healthRate`、`tickIntervalTicks`

同じ対象・同じ `ConditionType` の active instance は 1 件だけです。付与元の基準能力値は付与・強化更新時に `snapshotPower` へ固定します。DoT は対象 HP を参照せず、`snapshotPower / tickIntervalTicks` で同種状態の強さを比較します。

## 5. 付与結果と拒否理由

`ConditionApplyResult` は `success`、既存更新を示す `updated`、成功時の `condition`、失敗時の `rejectReason` を返します。

| `ConditionRejectReason` | 意味 |
| --- | --- |
| `NONE` | 拒否なし |
| `UNMANAGED_TARGET` | 管理外 Bukkit entity |
| `DEAD_TARGET` | 死亡中 player または `MobState.DEAD` |
| `NPC_TARGET` | `MobCategory.NPC` |
| `RESISTED` | Boss 制御時間補正後に 1 tick 未満 |
| `CHANCE_FAILED` | 付与確率の乱数判定失敗 |
| `INVALID_DURATION` | 予約済み。現行 constructor は 0 以下を既定時間へ正規化するため通常到達しない |

## 6. 状態異常ステータス

全状態異常は `{TYPE}_APPLY_CHANCE` と `{TYPE}_RESISTANCE` を使います。毒だけは属性系 `POISON_*` と区別するため、状態異常系接頭辞を `POISONED_*` とします。`SUPPORT_POWER` は回復・支援系効果の基礎能力値で、毒 DoT はこの値を参照します。

燃焼・感電・毒はさらに次の DoT 専用ステータスを使い、単位はすべて `%` です。

- `{TYPE}_DAMAGE_INCREASE`
- `{TYPE}_DAMAGE_RESISTANCE`
- `{TYPE}_DAMAGE_PENETRATION`
