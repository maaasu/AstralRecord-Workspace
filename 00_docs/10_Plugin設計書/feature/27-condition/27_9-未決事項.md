# 27_9-未決事項

以下は現行実装の契約に含めず、実装する場合は個別に設計・テストを追加します。

## 1. バランス

- スキルごとの `strength` 基準値と上書き優先順位。
- Boss 以外の Mob category 固有の持続時間補正。
- 状態異常解除スキル、複数解除時の優先順位、解除耐性。
- `SHOCKED` を `DOT` のまま扱うか、Boss 持続時間補正対象の複合 category を導入するか。

## 2. 表示障害と孤立 entity

- `ConditionDisplayTask` の対象単位例外隔離、継続方針、専用ログ ID。
- plugin crash や map 不整合で残った `astralrecord_condition_frozen` BlockDisplay を起動時に全 world から回収するか。
- 対象 Bukkit entity を解決できない active condition を期限切れ前に解除するか。
- `MobVanillaEffectProtectionService` の plugin fire tracking に、消失 entity UUID が残った場合の掃除 API。

これらは `ConditionCleanupTask` の現行責務ではありません。実装前に探索範囲、1 run 上限、例外ログ、他 plugin の display を削除しない識別条件を決めます。

## 3. モデル整理

- constructor が 0 以下の duration を既定値へ正規化する現行仕様で、`ConditionRejectReason.INVALID_DURATION` を残すか削除するか。
- 状態異常を logout / restart を越えて永続化するか。現行は必ず runtime のみとする。
