# 27_3.01-イベント

## 1. `ConditionPlayerEventHandler`

プレイヤーに対する状態異常の行動制限と lifecycle cleanup を Bukkit イベントへ接続します。全メソッドは `AbstractEventHandler.runSafely` を使い、業務例外を `E_5902` へ記録します。

| 物理メソッド | Bukkit event | priority | 処理 | `operation` |
| --- | --- | --- | --- | --- |
| `onPlayerMove` | `PlayerMoveEvent` | `HIGH`, `ignoreCancelled=true` | `canMove=false` かつ同一 world 内で位置が変化した場合、移動先を移動元へ戻す | `player_move` |
| `onPlayerInteract` | `PlayerInteractEvent` | `HIGH`, `ignoreCancelled=true` | `canInteract=false` の操作を cancel | `player_interact` |
| `onPlayerInteractEntity` | `PlayerInteractEntityEvent` | `HIGH`, `ignoreCancelled=true` | `canInteract=false` の操作を cancel | `player_interact_entity` |
| `onInventoryClick` | `InventoryClickEvent` | `HIGH`, `ignoreCancelled=true` | player の inventory 操作を `canInteract` で判定し、不可なら cancel | `inventory_click` |
| `onInventoryDrag` | `InventoryDragEvent` | `HIGH`, `ignoreCancelled=true` | player の inventory drag を `canInteract` で判定し、不可なら cancel | `inventory_drag` |
| `onPlayerDropItem` | `PlayerDropItemEvent` | `HIGH`, `ignoreCancelled=true` | `canInteract=false` の drop を cancel | `player_drop_item` |
| `onPlayerSwapHandItems` | `PlayerSwapHandItemsEvent` | `HIGH`, `ignoreCancelled=true` | `canInteract=false` の hand swap を cancel | `player_swap_hand` |
| `onPlayerQuit` | `PlayerQuitEvent` | `MONITOR` | cache に対象があれば `clearAll` | `player_quit` |
| `onPlayerDeath` | `PlayerDeathEvent` | `MONITOR` | cache に対象があれば `clearAll` | `player_death` |

## 2. 行動制限の境界

- `canMove` は凍結と感電の間欠制御を対象とする。
- `canInteract` は、同じ状態が移動・通常攻撃・スキルをすべて禁止する場合に false となる。現行 `ConditionType` では凍結だけが該当する。
- `PlayerMoveEvent` は event 自体を cancel せず、同一 world 内の実移動だけを `setTo(from)` で差し戻す。視点変更だけは維持する。
- 管理 cache に `AstPlayer` がない場合は操作を変更しない。
- inventory event の操作者が player でない場合は処理対象外とする。
- 通常攻撃、スキル、Mob AI の制御は各 feature が `ConditionService` を照会するため、この handler の責務外である。

## 3. 例外ログ

例外時は次の引数契約でログを出し、例外を Bukkit へ再送出しません。

```text
E_5902(playerName, operation)
```

event ごとに異なる `operation` を固定し、戦闘ダメージ用 `E_5900` と混在させません。
