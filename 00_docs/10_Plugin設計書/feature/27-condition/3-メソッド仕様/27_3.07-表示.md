# 27_3.07-表示

`ConditionDisplayService` は状態異常の表示だけを担当し、状態異常の有効性や効果判定は `ConditionService` を正本とします。専用リソースパックは使わず、ActionBar、バニラ視覚効果、BlockDisplay、共通 particle を使用します。

## 1. 表示対応表

| 状態 | バニラ / entity 表示 | 共通 particle | pulse 固有処理 |
| --- | --- | --- | --- |
| `BURNING` | player は 30 fire ticks、Mob は `MobVanillaEffectProtectionService` 経由の fire ticks | `CONDITION_BURNING_FLAME` | particle |
| `FROZEN` | 対象ごとに ICE `BlockDisplay` 1 個 | `CONDITION_ICE_DUST` | particle |
| `CHILLED` | なし | `CONDITION_ICE_DUST` | particle |
| `SHOCKED` | なし | `CONDITION_SHOCKED_SPARK` | particle |
| `POISON` | Poison PotionEffect。effect particle は非表示、icon は表示 | `CONDITION_POISON_DUST` | particle と witch drink 音 |
| `BLINDNESS` | Blindness PotionEffect。effect particle は非表示、icon は表示 | なし | なし |
| `WEAKNESS` | なし | `CONDITION_WEAKNESS_DUST` | particle |
| `HEALING_INHIBITION` | なし | `CONDITION_HEALING_INHIBITION_DUST` | particle |

## 2. `showApplied` と `refreshTargetDisplay`

- `showApplied` は付与・更新直後に対象表示を更新し、対象 condition の pulse を 1 回表示する。
- `refreshTargetDisplay` は active list が空なら `clearAll` を呼ぶ。
- player には優先順位順の上位 3 件を `「icon 表示名 残り秒」` 形式で ActionBar 表示する。
- 優先順位は `FROZEN`、`SHOCKED`、`BURNING`、`POISON`、`CHILLED`、`BLINDNESS`、`WEAKNESS`、`HEALING_INHIBITION` の順である。残り時間順ではない。
- 各 active condition のバニラ表示、凍結 BlockDisplay、recurring particle を更新する。

## 3. 凍結 BlockDisplay

- `frozenDisplays` は target UUID から BlockDisplay UUID への対応を保持する。
- 登録済み display が有効なら対象位置へ teleport し、なければ新規生成する。
- material は `ICE`、teleport duration は 10、view range は 40、scoreboard tag は `astralrecord_condition_frozen` とする。
- 対象 entity の幅・高さを基準に transformation の scale を更新する。
- 凍結解除時は map から UUID を削除し、解決できた display entity を remove する。

## 4. particle と viewer

- `pulse` は対象位置の Y + 0.9、recurring particle は Y + 0.8 を基準にする。
- particle の生成と近傍 viewer 解決は `ParticleDisplayService.spawnForNearbyViewers` に委譲する。
- `ConditionDisplayService` 自身は viewer 一覧を保持しない。

## 5. 解除

- `clearCondition` は対象 type の fire ticks、PotionEffect、凍結 BlockDisplay を解除し、残存 condition の表示を再構築する。
- `clearAll` は燃焼、Poison / Blindness PotionEffect、凍結 BlockDisplay、player ActionBar を解除する。
- TextDisplay は生成しない。
- 現行実装は active map に登録された target 単位で display を解除し、全 world の孤立 BlockDisplay を検索しない。
