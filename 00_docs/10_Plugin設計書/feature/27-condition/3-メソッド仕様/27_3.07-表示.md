# 27_3.07-表示

## 状態異常表示開始

クラス名: `ConditionDisplayService`
物理名: `showApplied`

1. 対象の現在位置と高さを解決する。
2. 対象本人がプレイヤーの場合、画面右下またはアクションバーへ短い付与通知を出す。
3. 周囲 viewer へ付与瞬間の particle burst を表示する。
4. 対象頭上の状態異常 TextDisplay を作成または更新する。
5. `BURNING` / `FROZEN` / `INVULNERABLE` など専用表示が必要な condition は個別表示開始処理を呼ぶ。

TextDisplay 表示形式:

```text
状態アイコン 表示名 残り秒s
```

複数 condition がある場合は重要度順で最大 3 件まで表示する。
重要度は `FROZEN`、`STUNNED`、`INVULNERABLE`、`BURNING`、`POISON`、`BLEEDING`、`CHILLED`、`SILENCED`、`ATTACK_DISABLED`、`VULNERABLE` の順とする。

## 状態異常表示更新

クラス名: `ConditionDisplayService`
物理名: `refreshTargetDisplay`

1. 対象に active condition が無い場合は [[27_3.07-表示]].状態異常表示解除 を呼ぶ。
2. 対象位置に合わせて TextDisplay を頭上へ追従させる。
3. 残り時間とスタック数を表示文字列へ反映する。
4. condition ごとの recurring particle を表示する。
5. recurring particle は `ParticleDisplayService` 経由で表示し、`World#spawnParticle` / `Player#spawnParticle` を直接呼ばない。

## 状態異常表示解除

クラス名: `ConditionDisplayService`
物理名: `clearCondition`

1. 対象と condition に紐づく TextDisplay / BlockDisplay を検索する。
2. condition 専用表示を破棄する。
3. `BURNING` 解除時は `MobVanillaEffectProtectionService.applyPluginFireTicks(entity, 0)` または player の `setFireTicks(0)` を呼ぶ。
4. 対象に他 condition が残っている場合、頭上 TextDisplay は残り condition の表示へ更新する。
5. 対象に condition が残っていない場合、頭上 TextDisplay を破棄する。

## 炎上表示適用

クラス名: `ConditionDisplayService`
物理名: `applyBurningVisual`

1. 対象 Bukkit Entity を解決する。
2. 対象が Mob の場合、`MobVanillaEffectProtectionService.applyPluginFireTicks(entity, visualTicks)` を呼ぶ。
3. 対象が Player の場合、`Player#setFireTicks(visualTicks)` を呼ぶ。
4. `ParticleDisplayService` で対象胸元に `FLAME` / `SMOKE` 系粒子を表示する。
5. バニラ `FIRE_TICK` ダメージは引き続きキャンセル対象とし、DoT は custom combat のみで適用する。

## 凍結 BlockDisplay 表示

クラス名: `ConditionDisplayService`
物理名: `showFrozenBlockDisplay`

1. 対象位置と body height を解決する。
2. 対象の周囲に `ICE` または `PACKED_ICE` の BlockDisplay を 2-4 個生成する。
3. BlockDisplay は対象を完全に隠さないよう、半透明風の小型スケールで周囲に配置する。
4. 対象移動不可中も位置ずれ補正のため 10 tick ごとに追従更新する。
5. `FROZEN` 解除時にすべて破棄する。

## 無敵バリア表示

クラス名: `ConditionDisplayService`
物理名: `showInvulnerableBarrier`

1. 対象中心に金色/白色系のリング particle を表示する。
2. 必要に応じて `GLASS` または `LIGHT_BLUE_STAINED_GLASS` の BlockDisplay を短時間だけ点滅表示する。
3. 表示は viewer が近くにいる場合だけ更新する。
4. `INVULNERABLE` 解除時に表示生成物を破棄する。

## 状態異常別 recurring particle

| 種別 | particle 方針 |
|---|---|
| `BURNING` | `FLAME`, `SMOKE`, 小さめの上昇粒子 |
| `POISON` | 緑 Dust / `ENTITY_EFFECT` 風粒子 |
| `BLEEDING` | 赤 Dust を足元から少量 |
| `CHILLED` | `SNOWFLAKE`, 水色 Dust |
| `FROZEN` | `SNOWFLAKE`, 氷 BlockDisplay |
| `STUNNED` | 黄色 Dust / `ELECTRIC_SPARK` |
| `SILENCED` | 暗紫 Dust を口元/頭部付近 |
| `ATTACK_DISABLED` | 灰色 Dust と小さな封印風 TextDisplay |
| `INVULNERABLE` | 金色リング、白 Dust |
| `VULNERABLE` | 赤紫 Dust、ひび割れ風の短い pulse |
