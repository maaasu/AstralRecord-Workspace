# 27_3.07-表示

表示は`ConditionDisplayService`と共通`ParticleDisplayService`へ集約する。リソースパックは使用しない。

| 状態 | 表示 |
| --- | --- |
| 燃焼 | バニラ炎上表示を維持し、炎パーティクルを出す |
| 凍結 | ICEのBlockDisplayを対象位置へ追従させ、対象の幅・高さを覆う |
| 冷気 | 水色のカスタムパーティクル |
| 感電 | `ELECTRIC_SPARK`パーティクル |
| 毒 | 緑Dust、毒音、プレイヤーはバニラ毒アイコン |
| 盲目 | バニラ盲目のみ。追加パーティクルなし |
| 衰弱 | 暗紫Dust |
| 回復阻害 | 赤Dust |

プレイヤーには残り時間の短い状態一覧をActionBar表示する。状態解除時は対応するPotionEffect、炎上表示、凍結BlockDisplayを破棄する。
