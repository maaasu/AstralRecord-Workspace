# 27_3.02-サービス

## `ConditionService.applyCondition`

付与確率は次式で求め、0～100へ丸める。

```text
effectiveChance = clamp(
  baseChance
  * (1 + sourceApplyChanceIncrease / 100)
  * (1 - targetApplyResistance / 100),
  0,
  100
)
```

DoT貫通は付与判定へ影響しない。ボスへの制御状態は付与成功後の持続時間を25%へ短縮する。

同種が有効な場合:

1. `strength`が高い要求を強い効果とする。
2. 同じ`strength`なら固定DoT値＋HP割合をtick間隔で正規化し、DoT強度が高い方を残す。
3. 弱い要求では効果値を書き換えない。
4. どちらの場合も`expiresAt = max(existingExpiresAt, requestedExpiresAt)`とする。

## 行動制御

- `canMove`: 凍結または感電の間欠拘束中はfalse。
- `canAttack`: 凍結中はfalse。
- `canCastSkill`: 凍結中はfalse。
- `canRunAi`: 凍結中はfalse。
- `movementSpeedMultiplier`: 行動不能は0、冷気は0.5、それ以外は1。
- `castTimeMultiplier`: 冷気は2、それ以外は1。

## 最終補正

- `damageDealtMultiplier`: 衰弱中は0.5。通常攻撃と、そのエンティティを付与元とするDoTに適用する。
- `isHealingBlocked`: 回復阻害中はtrue。

## `conditionDamageMultiplier`

```text
effectiveResistance = max(0, dotResistance - dotPenetration)
multiplier = max(0, 1 + dotDamageIncrease / 100)
           * max(0, 1 - effectiveResistance / 100)
```

燃焼・感電・毒だけが専用DoTステータスを使う。属性増加・属性耐性・属性貫通は参照しない。

## `ConditionTickService.tickCondition`

固定値に最大HP割合または現在HP割合を加算し、`DamageService.applyConditionDamage`へ渡す。感電は16～32 tickのランダム間隔で6 tickの移動・ジャンプ禁止時間を設定する。
