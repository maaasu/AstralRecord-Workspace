# 27_0-概要

`feature/condition` は、燃焼、凍結、冷気、感電、毒、盲目、衰弱、回復阻害をメモリ上で管理し、プレイヤーと AstralRecord 管理 Mob へ同じ判定規則を提供します。

## 1. 責務

- `model`: 状態異常種別、既定効果、付与要求・結果、有効中インスタンスを定義する。
- `service`: 付与判定、同種更新、解除、行動可否、倍率合成、期限切れ掃除を正本として管理する。
- `task`: DoT / 間欠制御、表示、期限切れ掃除を同期 scheduler で定期実行する。
- `display`: バニラ視覚効果、凍結 BlockDisplay、共通 particle を更新する。プレイヤー ActionBar は hud feature が active condition を参照して描画する。
- `event`: プレイヤーの移動・操作制限と quit / death cleanup を Bukkit イベントへ接続する。

## 2. 正本と境界

- 状態異常の有効性と効果値の正本は `ConditionService` が保持する `ActiveCondition` である。
- バニラの fire ticks、PotionEffect、BlockDisplay は表示補助であり、効果判定の正本にしない。
- `DamageService` が DoT の HP 反映と死亡処理を担当し、condition feature は Bukkit health を直接減算しない。すべての DoT はシールドを貫通し、シールド残量を変更しない。
- `StatusService` がプレイヤー移動速度と回復 API へ補正を適用する。
- 属性ダメージだけでは状態異常を発生させず、呼び出し元が `ConditionApplyRequest` を明示した場合だけ付与する。
- 状態異常は永続化しない。quit、death、Mob 破棄、plugin disable で runtime 状態を破棄する。

## 3. 不変条件

- 異なる `ConditionType` は同時保持できる。
- 同じ対象・同じ `ConditionType` は最大 1 件で、強い効果値を保持しつつ終了時刻だけ後ろへ延長する。
- 冷気中に凍結しても冷気を削除しない。凍結解除後に冷気が有効なら移動 50%・詠唱 2 倍へ戻る。
- 付与確率増加と付与耐性は状態異常種別ごとに独立する。
- 燃焼・感電・毒の DoT 増加、耐性、貫通は属性ダメージ補正と独立する。
- DoT は会心せず、対象 HP の割合を参照しない。毒を含む condition damage は通常の死亡処理へ進み、HP 0 にできる。
- Boss に付与した `CONTROL` category の持続時間だけを要求値の 25% へ短縮する。

## 4. ライフサイクル

| 契機 | 現行処理 |
| --- | --- |
| plugin enable | service を構築し、event handler を登録して tick → display → cleanup task の順に開始する |
| 付与・更新 | active map を更新し、status 再計算、即時表示、pulse を行う |
| 明示解除・期限切れ | active map から削除し、表示解除と status 再計算を行う |
| player quit / death | 対象プレイヤーの全状態異常と表示を解除する |
| Mob 破棄 | mob feature から対象 Mob の全状態異常解除を呼ぶ |
| plugin disable | task を停止後、`clearAllRuntimeState` で全 runtime 状態と登録済み表示を破棄する |

## 5. 依存・連携

- `combat`: `AstEntity` を共通対象型として使い、`DamageService` がシールドを参照しない DoT の HP・死亡処理を担当する。
- `status`: 付与確率・耐性・DoT 補正値を提供し、移動速度と HP / MP / EN / Shield 回復へ状態異常効果を反映する。
- `skill`: スキル定義の `conditions` から付与要求を作り、発動可否と詠唱時間へ状態異常効果を反映する。
- `mob`: 管理 Mob、Boss / NPC 判定、AI 実行可否、Mob のバニラ炎上表示保護を提供する。
- `player`: `AstPlayerCache`、死亡判定、quit / death 時の状態破棄を提供する。
- `item` / `equipment`: 通常攻撃可否の確認元となる。
- `shared/effect`: 近傍 viewer 向けパーティクル表示を担当する。
- `hud`: HP / MP / EN と有効な状態異常を同じ ActionBar に合成し、最大3件を装飾表示する。
