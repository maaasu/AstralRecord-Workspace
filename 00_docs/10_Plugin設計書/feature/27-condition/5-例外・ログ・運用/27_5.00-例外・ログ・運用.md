# 27_5.00-例外・ログ・運用

## 1. 付与拒否条件

| 条件 | 結果 | 備考 |
|---|---|---|
| target が unmanaged Bukkit Entity | 付与不可 | custom combat 対象外 |
| target が死亡中プレイヤー | 付与不可 | 死亡状態を優先 |
| target が `MobCategory.NPC` | 付与不可 | 初期仕様では NPC へ状態異常を付与しない |
| target Mob が `DEAD` | 付与不可 | death/despawn 掃除対象 |
| duration が 1 tick 未満 | 付与不可 | 耐性適用後に 0 になった場合も含む |
| chance が乱数判定で失敗 | 付与なし | 正常系 |

## 2. ログ方針

- 状態異常の通常付与・期限切れ解除は高頻度のためログ出力しない。
- 例外、orphan display 掃除、想定外 target type、表示 entity 破棄失敗だけログ対象にする。
- 新規ログ追加時は `LogId` と `logger.properties` をセットで追加する。

想定ログ:

| ID 候補 | レベル | テンプレート | 出力条件 |
|---|---|---|---|
| `W_5901` | WARN | 状態異常対象を解決できませんでした: condition=%s target=%s | tick 時に対象 entity が消失 |
| `E_5901` | ERROR | 状態異常 tick 処理に失敗しました: condition=%s target=%s | `ConditionTickTask` の condition 単位例外 |
| `E_5902` | ERROR | 状態異常表示の更新に失敗しました: target=%s | `ConditionDisplayTask` の対象単位例外 |
| `W_5902` | WARN | 孤立した状態異常表示を破棄しました: entity=%s | cleanup task が orphan display を破棄 |

## 3. プレイヤー向け通知方針

- 付与/解除のたびにチャットへ流さない。
- 本人には短い画面内表示またはアクションバーで通知する。
- 行動制限で攻撃・スキルが中断された場合のみ、短いクールダウン付き通知を出す。
- 新規メッセージ ID が必要な場合は `PlayerMsgId` と `player.properties` をセットで追加する。

想定メッセージ:

| ID 候補 | 用途 | テンプレート |
|---|---|---|
| `P_5901` | 状態異常付与 | `%s になりました` |
| `P_5902` | 状態異常解除 | `%s が解除されました` |
| `P_5903` | 攻撃不可 | `現在は攻撃できません` |
| `P_5904` | スキル不可 | `現在はスキルを使用できません` |

## 4. パフォーマンス制約

- DoT 処理は 5 tick 間隔の batch で行い、毎 tick 全件走査しない。
- 表示更新は 10 tick 間隔を基準とし、viewer がいない対象の particle は省略する。
- TextDisplay / BlockDisplay は condition ごとに無制限生成せず、対象ごとに集約する。
- recurring particle は `ParticleDisplayService` を経由し、近傍 viewer 解決をまとめる。
- 1 対象に表示する頭上 condition は最大 3 件まで。
- 1 回の tick task で処理する condition 上限は 300 件。

## 5. バニラ状態との扱い

- `BURNING` の見た目だけ fire ticks を使う。
- fire ticks による `FIRE_TICK` ダメージは custom combat に入れない。
- PotionEffect の Poison、Slowness、Weakness、Glowing などを状態異常の正本にしない。
- 必要な見た目やクライアント挙動だけ補助的に使う場合も、効果判定は `ConditionService` を正本にする。

## 6. 起動・停止時の掃除

- plugin enable 時、古い display entity は原則残っていない前提とする。
- plugin disable 時、`ConditionService.clearAllRuntimeState` を呼び、全 condition と display entity を破棄する。
- task cancel 後に display entity が残らないよう、display service に一括破棄 API を用意する。
