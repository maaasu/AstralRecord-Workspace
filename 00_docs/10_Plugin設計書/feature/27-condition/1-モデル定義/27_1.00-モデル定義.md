# 27_1.00-モデル定義

## 1. 状態異常種別

物理名: `ConditionType`

| 値 | 表示名 | 分類 | 既定属性 | 主効果 | 視覚表示 |
|---|---|---|---|---|---|
| `BURNING` | 炎上 | `DOT` | `FIRE` | 一定間隔で火属性 DoT | fire ticks、炎パーティクル、赤橙 TextDisplay |
| `POISON` | 毒 | `DOT` | `POISON` | 一定間隔で毒属性 DoT、回復量低下 | 緑粒子、毒アイコン TextDisplay |
| `BLEEDING` | 出血 | `DOT` | `NEUTRAL` | 一定間隔で物理寄り DoT | 赤い滴粒子、赤 TextDisplay |
| `CHILLED` | 冷気 | `CONTROL` | `ICE` | 移動速度・攻撃速度低下 | 雪/氷粒子、薄青 TextDisplay |
| `FROZEN` | 凍結 | `CONTROL` | `ICE` | 移動不可、攻撃不可、スキル不可 | 氷 BlockDisplay、雪粒子、青 TextDisplay |
| `STUNNED` | スタン | `CONTROL` | `LIGHTNING` | 移動不可、攻撃不可、スキル不可 | 星/電撃粒子、黄 TextDisplay |
| `SILENCED` | 沈黙 | `CONTROL` | `DARK` | スキル不可 | 暗色粒子、紫 TextDisplay |
| `ATTACK_DISABLED` | 攻撃不可 | `CONTROL` | `NEUTRAL` | 通常攻撃不可 | 灰色 TextDisplay、武器封印風粒子 |
| `INVULNERABLE` | 無敵 | `PROTECTION` | `NEUTRAL` | HP/Shield ダメージ無効 | 金色リング、バリア BlockDisplay |
| `VULNERABLE` | 脆弱 | `AMPLIFIER` | `NEUTRAL` | 被ダメージ倍率増加 | ひび割れ風粒子、赤紫 TextDisplay |

初期実装ではこの 10 種を正本とし、ID は enum 名をそのまま使用する。
表示名・色・既定 duration は enum または `ConditionDefinition` で管理し、文字列直書きで分散させない。

## 2. 状態異常分類

物理名: `ConditionCategory`

| 値 | 説明 |
|---|---|
| `DOT` | 定期的にダメージや回復阻害を発生させる |
| `CONTROL` | 移動、通常攻撃、スキル、AI 行動を制限する |
| `PROTECTION` | ダメージ無効や保護を与える |
| `AMPLIFIER` | 被ダメージ、与ダメージ、回復量などの倍率を変える |
| `VISUAL_ONLY` | 将来用。効果なしの表示状態 |

## 3. アクティブ状態異常

物理名: `ActiveCondition`

| 項目 | 型 | 説明 |
|---|---|---|
| `conditionId` | `UUID` | 付与インスタンス ID |
| `type` | `ConditionType` | 状態異常種別 |
| `targetId` | `UUID` | 対象 `AstEntity.id()` |
| `targetType` | `AstEntityType` | `PLAYER` / `MOB` |
| `sourceId` | `UUID?` | 付与元。環境・ギミック由来なら `null` |
| `sourceType` | `AstEntityType?` | 付与元種別 |
| `startedAtMs` | `long` | 付与時刻 |
| `expiresAtMs` | `long` | 失効時刻。無期限は使わず、初期実装では必ず正値 |
| `lastTickAtMs` | `long` | periodic effect 最終処理時刻 |
| `nextTickAtMs` | `long` | 次回 periodic effect 処理予定時刻 |
| `stack` | `int` | スタック数 |
| `snapshotPower` | `double` | 付与時点で確定した効果強度 |
| `damageType` | `DamageType` | DoT の防御種別 |
| `damageElement` | `DamageElement` | DoT または状態属性 |
| `displayState` | `ConditionDisplayState` | 表示生成物の管理状態 |

`snapshotPower` は、付与時点の攻撃者ステータスやスキル係数から確定する。
装備変更や後続バフで過去に付与した DoT の威力が変わらないようにする。

## 4. 状態異常効果

物理名: `ConditionEffect`

| 項目 | 型 | 説明 |
|---|---|---|
| `tickIntervalTicks` | `int` | periodic effect の間隔。DoT なしなら 0 |
| `basePower` | `double` | 固定基礎値 |
| `sourceAttackCoefficient` | `double` | 付与元 `ATTACK` 係数 |
| `sourceTypedAttackCoefficient` | `double` | 付与元 `MELEE_ATTACK` / `RANGED_ATTACK` / `MAGIC_ATTACK` 係数 |
| `targetMaxHealthCoefficient` | `double` | 対象最大 HP 係数 |
| `maxTickDamage` | `double` | 1 tick 処理あたりの上限。0 以下なら上限なし |
| `healingReceivedMultiplier` | `double` | 受ける回復量倍率。`POISON` で使用 |
| `damageTakenMultiplier` | `double` | 被ダメージ倍率。`VULNERABLE` で使用 |
| `movementBlocked` | `boolean` | 移動不可 |
| `attackBlocked` | `boolean` | 通常攻撃不可 |
| `skillBlocked` | `boolean` | スキル不可 |
| `aiBlocked` | `boolean` | Mob AI 行動不可 |
| `damageImmune` | `boolean` | HP/Shield ダメージ無効 |

## 5. 付与要求

物理名: `ConditionApplyRequest`

| 項目 | 説明 |
|---|---|
| `target` | 対象 `AstEntity` |
| `source` | 付与元 `AstEntity`。環境由来は `null` |
| `type` | 付与する状態異常種別 |
| `durationTicks` | 効果時間 |
| `chance` | 付与確率。0-100 |
| `stack` | 付与スタック数。未指定は 1 |
| `basePower` | 固定効果値。未指定時は type 既定 |
| `powerCoefficient` | 攻撃者ステータス係数。未指定時は type 既定 |
| `damageType` | DoT の防御種別。未指定時は type 既定 |
| `damageElement` | 属性。未指定時は type 既定 |
| `reason` | `SKILL`, `MOB_AI`, `COMMAND`, `ENVIRONMENT`, `SCRIPT` |

## 6. 重複規則

物理名: `ConditionStackPolicy`

| ポリシー | 説明 | 初期適用 |
|---|---|---|
| `REFRESH_DURATION` | 既存状態の残り時間を延長/更新する | `STUNNED`, `SILENCED`, `ATTACK_DISABLED`, `INVULNERABLE` |
| `STACK_POWER_REFRESH_DURATION` | スタック上限まで増やし、時間を更新する | `BURNING`, `POISON`, `BLEEDING`, `CHILLED`, `VULNERABLE` |
| `REPLACE_IF_STRONGER` | 強い効果だけ上書きする | 将来用 |
| `IGNORE_IF_ACTIVE` | 既に有効なら無視する | 将来用 |

初期スタック上限は DoT 系と `VULNERABLE` が 3、`CHILLED` が 5、それ以外が 1。
`CHILLED` が 5 スタックに達した時、対象に `FROZEN` を付与して `CHILLED` を解除する。

## 7. 対象ポリシー

物理名: `ConditionTargetPolicy`

| 対象 | 付与可否 | 備考 |
|---|---|---|
| プレイヤー | 可 | 死亡中は付与不可。死亡開始時に全 condition を解除 |
| ENEMY Mob | 可 | despawn / death 時に全 condition を解除 |
| BOSS Mob | 可 | `CONTROL` は duration と効果を軽減する |
| NPC Mob | 不可 | 構造上は解決できるが、初期ポリシーで付与拒否 |
| unmanaged Bukkit Entity | 不可 | custom combat 対象外 |

## 8. ボス耐性

物理名: `ConditionResistanceProfile`

初期実装では filebase 拡張を待たず、コード既定値として以下を使う。

| 対象 | `DOT` | `CONTROL` | `PROTECTION` | `AMPLIFIER` |
|---|---:|---:|---:|---:|
| プレイヤー | 1.0 | 1.0 | 1.0 | 1.0 |
| ENEMY | 1.0 | 1.0 | 1.0 | 1.0 |
| BOSS | 1.0 | 0.25 | 1.0 | 0.5 |
| NPC | 0.0 | 0.0 | 0.0 | 0.0 |

`CONTROL` の倍率は duration と効果量に適用する。
例: 4 秒スタンを BOSS に付与する場合、実 duration は 1 秒とする。

## 9. 表示状態

物理名: `ConditionDisplayState`

| 項目 | 説明 |
|---|---|
| `textDisplayId` | 頭上状態異常表示の Entity UUID |
| `blockDisplayIds` | 凍結氷、無敵バリアなどの BlockDisplay UUID 一覧 |
| `lastVisualTickAtMs` | 最終表示更新時刻 |
| `pluginFireTicksActive` | `BURNING` の fire ticks をプラグイン由来として管理中か |

表示生成物は condition 解除、対象 death/despawn/logout、plugin disable 時に必ず破棄する。
