# 27_1.00-モデル定義

## `ConditionType`

| 値 | 既定時間 | 効果 | 表示 |
| --- | ---: | --- | --- |
| `BURNING` | 100 tick | 20 tickごとに最大HP1%の燃焼DoT | バニラ炎上、炎パーティクル |
| `FROZEN` | 40 tick | 移動・攻撃・スキル・Mob AIを禁止 | エンティティを覆う氷BlockDisplay |
| `CHILLED` | 100 tick | 移動速度50%、詠唱時間2倍 | 水色パーティクル |
| `SHOCKED` | 100 tick | 最大HP1%/秒、16～32 tick間隔で6 tick移動・ジャンプ禁止 | 電撃パーティクル |
| `POISON` | 120 tick | 現在HP3%/秒、HP1未満にしない | バニラ毒表示、緑パーティクル、音 |
| `BLINDNESS` | 100 tick | バニラ盲目 | 追加外観なし |
| `WEAKNESS` | 100 tick | 与える最終ダメージ50%。付与元DoTも対象 | 暗紫パーティクル |
| `HEALING_INHIBITION` | 100 tick | 通常のHP・MP・EN・シールド回復を無効化 | 赤パーティクル |

死亡後リスポーンと管理コマンドの全回復は、`restoreAll`を通る例外として回復阻害を無視する。

## `ConditionApplyRequest`

| フィールド | 説明 |
| --- | --- |
| `target` | 対象 |
| `source` | 付与元。環境由来はnull |
| `type` | 状態異常種別 |
| `durationTicks` | 0以下なら種別既定値 |
| `chance` | 基礎付与確率（%） |
| `strength` | 同種重複時の強さ比較値 |
| `basePower` | 固定DoT値の上書き |
| `powerCoefficient` | 付与元`ATTACK`係数の上書き |
| `healthRate` | HP割合の上書き。0.03は3% |
| `tickIntervalTicks` | DoT間隔の上書き |
| `reason` | 付与理由 |

## `ActiveCondition`

対象・付与元、開始時刻、終了時刻、次回DoT時刻、感電制御時刻、`strength`、固定DoTスナップショット、HP割合、DoT間隔を保持する。スタック数は常に1。

## 状態異常ステータス

全状態異常は `{TYPE}_APPLY_CHANCE` と `{TYPE}_RESISTANCE` を持つ。毒状態は属性の`POISON_*`と区別するため接頭辞を`POISONED_*`とする。

燃焼・感電・毒はさらに以下を持つ。

- `{TYPE}_DAMAGE_INCREASE`
- `{TYPE}_DAMAGE_RESISTANCE`
- `{TYPE}_DAMAGE_PENETRATION`

すべて単位は `%`。
