# 27_0.00-概要

`feature/condition` は燃焼、凍結、冷気、感電、毒、盲目、衰弱、回復阻害を管理する。

## 基本方針

- プレイヤーとカスタムMobの両方を対象にする。
- 異なる状態異常は同時保持できる。
- 同種は強い効果だけを保持し、終了時刻は後ろにだけ延長する。
- 冷気中に凍結しても冷気を削除しない。凍結中は移動不可を優先し、解除後に冷気が残っていれば移動50%へ戻す。
- 付与確率増加と付与耐性は状態異常ごとに独立する。
- 燃焼・感電・毒はDoT増加、DoT耐性、DoT貫通を個別に持つ。
- DoTは会心しない。
- 属性ダメージと状態異常DoTは別計算であり、関連属性の概念を計算には使わない。
- リソースパックは使わず、バニラ表示、BlockDisplay、共通パーティクルを使用する。
