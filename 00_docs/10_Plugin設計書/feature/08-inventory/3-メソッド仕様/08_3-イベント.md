# 08_3-イベント

## 1. インベントリクリック受付

クラス名: `InventoryEquipmentGuiEventHandler`
物理名: `onInventoryClick`
イベント: `InventoryClickEvent`

処理内容:

1. 装備画面では、通常プレイヤーモードを確認して画面固有処理へ振り分ける。削除済みの装備加工・旧強化・旧修理画面への分岐は持たない。
2. 通常の `CRAFTING` view ではホットバー `0..8`、オフハンド `40`、防具 `36..39`、管理 inventory `9..35` を所持品操作へ振り分ける。
3. 通常プレイヤーインベントリ内の `orb` entry クリックはオーブ操作側へ委譲し、Bukkit の移動操作をキャンセルする。
4. 装備条件、アクセサリ種別、BAG 容量を検証し、state、装備ロードアウト、ステータス、装備由来パッシブを同期する。
5. 操作種別ごとに [[08_3-サービス]].クリッククールタイム を取得できない場合は、イベントをキャンセルして終了する。

装備 GUI のプレイヤーヘッドは保存後にステータス画面を開き、`slot 49` は保存後にメインメニューへ戻る。メイン表示 `slot 19` と予約済みペット枠 `slot 16` は編集対象外とする。

## 2. インベントリクローズ受付

クラス名: `InventoryEquipmentGuiEventHandler`
物理名: `onInventoryClose`
イベント: `InventoryCloseEvent`

装備画面の終了時に画面固有の保存処理を実行する。防具、オフハンド、種類別アクセサリの `ItemStack` を読み取り、[[08_3-サービス]].装備 GUI 保存 へ委譲する。オーブ操作 GUI は装備を一時退避しない。通常時はsessionを終了するが、mutation・10tick演出・その後10tickの更新待機中は同じtokenのGUIを次tickに再表示し、上段・下段・held・dropを含む操作ロックを維持する。

## 3. ログアウト受付

クラス名: `InventoryEquipmentGuiEventHandler`
物理名: `onPlayerQuit`
イベント: `PlayerQuitEvent`

プレイヤー単位のクリッククールタイムを破棄し、次回ログインへ一時状態を持ち越さない。

## 4. ホットバースロット変更 observer

クラス名: `InventoryEquipmentGuiEventHandler`
物理名: `onPlayerItemHeld`
イベント: `PlayerItemHeldEvent`

`MONITOR`、`ignoreCancelled = true` の非競合 observer として、装備 GUI 表示中だけ次 tick にメイン表示 `slot 19` を変更後の選択アイテムで再描画する。入力所有権と競合順は [[28_3-イベント]] を正本とし、cancel 済みイベントは反映しない。

## 5. 手持ちアイテム入れ替え抑止

クラス名: `InventoryEquipmentGuiEventHandler`
物理名: `onPlayerSwapHandItems`
イベント: `PlayerSwapHandItemsEvent`

管理対象モードでは Bukkit 標準のメインハンド・オフハンド直接入れ替えをキャンセルし、state と表示の不整合を防ぐ。
