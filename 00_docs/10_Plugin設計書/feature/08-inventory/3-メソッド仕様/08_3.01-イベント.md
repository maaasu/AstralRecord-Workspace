# 08_3.01-イベント

## 1. 装備 GUI クリック

イベント物理名: `InventoryClickEvent`
クラス名: `InventoryEquipmentGuiEventHandler`
物理名: `onInventoryClick`

責務:

装備メニュー内の操作、または通常プレイヤーインベントリ上の装備・ホットバー操作へ振り分ける。

処理内容:

1. top inventory が menu feature の装備画面なら装備 GUI 操作へ委譲する
2. 装備画面でない場合はプレイヤーインベントリ操作へ委譲する
3. 例外時は runSafely で以下ログを記録する

    | 項目 | 内容 |
    |---|---|
    | ID | LogId.E_5600 |
    | レベル | ERROR |
    | テンプレート | インベントリ系イベント処理に失敗しました: %s |
    | 出力条件 | runSafely で例外発生時 |
    | 引数 | プレイヤー名 |

## 2. 装備 GUI クローズ

イベント物理名: `InventoryCloseEvent`
クラス名: `InventoryEquipmentGuiEventHandler`
物理名: `onInventoryClose`

責務:

装備 GUI を閉じたとき、画面上の装備スナップショットを保存する。

処理内容:

1. event player が Bukkit Player でなければ終了する
2. 閉じた inventory が装備 GUI でなければ終了する
3. [[08_3.01-イベント]].装備 GUI スナップショット保存 へ委譲する

## 3. 装備 GUI スナップショット保存

クラス名: `InventoryEquipmentGuiEventHandler`
物理名: `saveEquipmentMenuSnapshot`

責務:

装備 GUI の各装備スロットを読み取り、サービスへ保存を委譲する。

処理内容:

1. `AstPlayerCache` からプレイヤーセッションを取得する
2. セッションがない場合は終了する
3. `MenuView` から頭・胴・脚・足・オフハンド・種類別アクセサリ 2〜10 の ItemStack を取得する
4. [[08_3.02-サービス]].装備 GUI 保存 を呼び出す

## 3.1 装備 GUI の補助操作

- 左上 `slot 0` のプレイヤーヘッドをクリックした場合は、装備スナップショットを保存してステータス画面を開く。
- 共通位置 `slot 49` の戻るボタンをクリックした場合は、装備スナップショットを保存してメインメニューへ戻る。`slot 16` の鞍は将来用ペットスロットのため操作対象外とする。
- 装備 GUI を開いているプレイヤーの `PlayerItemHeldEvent` を`MONITOR`かつ`ignoreCancelled = true`で監視し、未cancelの通常変更だけを変更後の選択ホットバーアイテムでメインスロット `slot 19` へ再描画する。メインスロット自体は編集対象にしない。
- この処理は`HOTBAR_SLOT`の勝者候補ではなく非競合observerである。input lock、action ringのいずれかがeventをcancelした場合は実処理せず、変更要求先slotを表示へ先行反映しない。競合順は[[28_3.01-イベント]].ホットバースロット変更受付 を正本とする。
- アクセサリ枠へ配置できるのは `equipment.slot = ACCESSORY` かつ、`equipment.tag` が対象枠の `AMULET` / `TALISMAN` / `CHARM` / `CORE` / `RELIC` と一致するアイテムのみとする。

## 4. プレイヤーインベントリクリック

クラス名: `InventoryEquipmentGuiEventHandler`
物理名: `handlePlayerInventoryClick`

責務:

通常プレイヤーの Bukkit インベントリクリックを、ホットバー・オフハンド・防具・表示インベントリ操作へ振り分ける。

処理内容:

1. クリック者が Player でなければ終了する
2. view type が `CRAFTING` でなければ終了する
3. `AstPlayer` がない、またはアカウントモードが GUI 反映対象外なら終了する
4. slot `0`〜`8` はホットバークリックとして処理する
5. slot `40` はオフハンドクリックとして処理する
6. slot `36`〜`39` は防具スロットクリックとして処理する
7. slot `9`〜`35` の AstralRecord ItemStack は表示インベントリアイテムクリックとして処理する
8. 防具スロットを手動で書き換える場合はイベントをキャンセルし、Bukkit 標準処理との二重移動を防止する
9. ホットバースロット・オフハンド・防具スロット・BAG アイテム・BAG 制御列・装備 GUI スロットの各クリックは、対応する [[08_3.02-サービス]].クリッククールタイム の `tryAcquire` を呼び出し、取得に失敗した場合は音・メッセージを出さずにイベントをキャンセルして終了する
10. ホットバー空きスロットや空オフハンドスロットを「割当先選択」として選ぶだけの操作は装備音ではなくクリック音を再生する
11. `PlayerSwapHandItemsEvent` は常にキャンセルし、Bukkit 標準のメインハンド・オフハンド直接入れ替えで管理 state と表示を不整合にしない
