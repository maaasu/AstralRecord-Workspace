# 08_3.03-コマンド

## 1. インベントリ再描画

クラス名: `InventoryCommand`
物理名: `executePlayerCommand`

責務:

`/inventory` で統合所持品 BAG、装備スロット、アクセサリスロット、ホットバーを再描画する。

処理内容:

1. アカウントモードが GUI インベントリ反映対象外なら `PlayerMsgId.P_5250` を送信して終了する
2. `InventoryService` が未初期化なら `PlayerMsgId.P_5252` を送信して終了する
3. [[08_3.02-サービス]].インベントリ GUI 一括反映 を呼び出す

## 2. インベントリ補完候補取得

クラス名: `InventoryTabCompleter`
物理名: `getPlayerCompletions`

責務:

カテゴリ切替引数を廃止したため常に空リストを返す。

## 3. コマンド仕様

- ルート: `/inventory`
- 形式: `/inventory`
- コンソール実行: 不可（`isPlayerOnly = true`）
