# 26_3-ホロロギウム

## 1. 対象と挑戦

Lv.50の`horologium_clockwork_sovereign`（廻刻の機工王 ホロロギウム）は、針の向きと自分が残した足跡の両方を読み、回避後の隙に反撃するボス。`HorologiumEncounterController`が個体ごとの予兆・位置固定・衝突・反響・反撃時間を管理し、`BossMechanicService`の同期5tick更新と共通戦闘に接続する。

受付は登録済みの`BASE`または`HUB`からの`/boss horologium`に限定する。ダンジョン・他ボス会場・野外からは開始できない。コマンド専用のため入口円検索と入口演出から外し、拠点spawnのスニークで誤起動しない。終了・中断・失敗の帰還先は`starlit_nox`のマスタspawn(-75,-42,-576)。1～6人、制限900秒、死亡許容5回、復帰5秒。専用の`horologium_clockwork_field`は原本コピーを使わず、`HorologiumFieldGenerator`が中心(0.5,64,0.5)、床Y63の時計盤を作る。参加者は北端(0.5,64,-16.5)から始まる。挑戦の名簿、人数HP補正、退出、復活、結果と経験値は既存の共通処理を使う。専用worldだけ時刻18000の晴天に固定し、中心・環・歯車のシーランタンで夜の時計盤を照らす。外壁内側の北・東・南・西には光る常設の壁看板を目線の高さY65に付け、中央へ向ける。看板は半径21mの外壁内面、支持壁は半径22mの磨かれたブラックストーンレンガで、床や半径16m以内の歯車印・歩行路を占有しない。

## 2. 針と足跡

戦闘開始後80tick待ち、会場半径24m・高さ±6m以内の参加者から順番に一人を狙う。中心から対象への方向に、長さ24m、左右幅2.4mの針を固定する。第一段階は開始40tick後に足跡を固定し、さらに40tick後に針が通る。残HP70%以下で入る第二段階は、標的を見た初期方向から時計回り90度の最終線を予告し、足跡固定後30tickでその最終線に一度だけ衝突判定を出す。初期線から最終線へ動く琥珀色の針は見た目だけで、赤い最終危険線は開始時から表示する。残HP35%以下で入る第三段階は第二段階の回転を維持し、基本の固定猶予を30tickに縮め、最終線の衝突から35tick後に初期線を一度だけ逆再演する。逆再演の移動線は無害で、赤い危険線は初期角へ切り替わる。逆再演からさらに35tick後に足跡反響が来る。各波の段階、初期角・最終角、固定・衝突・逆再演・反響時刻、反響倍率は波開始時に確定し、途中でHPが変わっても変えない。HP閾値を一度に二つ越えても、新しい波ごとに段階を最大一つ進める。無敵やHPロックは付けない。

足跡固定では、その波の開始時に参加していた生存者の位置を保存する。第一・第二段階は針の衝突から35tick後、第三段階は逆再演から35tick後、保存された各位置の半径3mへ反響を発生させる。最終針の魔法攻撃倍率は0.50、第三段階の逆再演は0.30、反響は第一・第二段階0.55、第三段階0.65。同一波の二本の針は同じ人へ合計一回だけ攻撃を試みるため、針の上限は最終線0.50または逆再演0.30であり、合算0.80にはならない。反響は別判定で、第三段階の針と反響を両方避けなかった場合の倍率合計上限は1.15。倍率は実HP減少率を直接表さず、防御・命中・シールド処理を通る。通常AIの直接攻撃は定義しない。固定後に離れたプレイヤーは反響を避けられる。

時計盤には内環半径8mの東西南北4印、外環半径16mの8方位8印を床材で描く。印の中心から半径1.5m以内に中心がある床セルを塗り、そのセル全域を成功判定とする。プレイヤーの足元ブロック座標は時計盤中心ブロックとの差で求め、負座標・斜め印でも同じ塗りセル定義を使う。強調粒子は塗りセルの外周辺に沿って描き、足跡固定直後には緑輪郭と一時BlockDisplayを消す。固定時に標的本人へ印への記録成否を一度通知し、4ブロック以上の退避を促す。強化反撃の成否は反響時の退避条件を確認してから確定する。専用挑戦の各予兆で、標的一人から最も近い1印を選び、内外環と北から時計回りの角度を通知し、一時表示と緑の共通粒子で強調する。標的から印の内側までの歩行距離を3m/sで換算し、20tickの反応余白を加えて足跡固定時刻を延長する。標的の固定足跡が指定印の塗りセル内にあり、その標的が反響時にも有効な同会場参加者で、足跡から平面3.5m超離れていれば成功とする。仲間の足跡で代行できず、一波で成功は一度だけ。専用挑戦以外の直接召喚・ダンジョンでは、生成時計盤の歩行条件を保証できないため誘導を無効と通知する。

通常の反響後は120tick、ボスの被ダメージ倍率を1.25とし次の予兆を始めない。歯車誘導に成功した場合は180tickで1.35倍。BossBarは足跡固定前・最終針衝突前・反響前、第三段階だけはさらに逆再演前を加えた4段階に分け、各段階の実開始時刻から締切までを進捗と残秒へ反映する。固定前は標的・選定印・固定期限を優先し、固定後はその時点で危険な赤線の方位と次の期限に絞る。初期角・最終角・逆再演までの全予定は開始時のチャット通知へ分ける。第三段階の衝突後は初期角を逆再演の危険線として表示する。逆再演後は針の赤線を消し、足跡の反響円だけを示す。各段階で足跡から4ブロック以上離れるよう案内し、内部成功閾値の平面3.5m超には余裕を持たせる。針の左右の縁と中心、各足跡の反響円に、歯車印12点と回転装飾14点を合わせても最大96地点の共通粒子で描く。統合版のDUST変換と個人の粒子密度は`ParticleDisplayService`に委譲する。粒子OFFでも常設の四方位看板、標的と印、現在の赤い危険線の方位、段階別残秒を文字で伝える。音は段階の補助として鳴らす。

## 3. 対象と寿命

挑戦では確定名簿、ダンジョンでは同部屋の報酬対象、直接召喚では初撃所有者の固定パーティーを対象にする。攻撃所有者が同じ会場内にいなければボスへの攻撃を拒否する。見学者、死亡者、creative、spectator、別worldのプレイヤーはギミック対象から除外する。波の途中で復帰した者、または同じ波の途中で盤外へ出て戻った者は、その波の判定対象に加えない。対象外になった参加者には同じ波で一度だけ保護状態と次の波からの参加を通知する。

会場の16chunkを挑戦中は保持する。生成失敗・取消・終了後のworld破棄とticket解放は`BossFieldInstanceService`の共通処理を使う。参加者不在では現在の予兆とBossBarを解放する。生成盤の床はセル中心半径22mまでで壁もその内側にあり、セル角と壁上の跳躍まで含む半径24m・高さ±6mを参加資格・ボスへの攻撃許可・針の長さ・予兆表示に共通使用する。波の途中でこの領域から出た参加者の資格と足跡は破棄し、戻っても同じ波では被弾しない。ボス死亡・消失・帰還・Plugin停止でも個体UUIDの状態と表示を回収する。命中から挑戦終了が再入した場合は個体と詠唱の同一性を確認して後続処理を止める。進行例外では専用行動を解放し、挑戦は報酬なしの異常終了とする。任意の粒子・一時BlockDisplay・音だけの失敗は戦闘を止めず、種類ごとに個体内で一度だけ例外を記録し以後の該当演出を省く。初回の演出失敗は`P_8063`でBossBarとチャットの文字情報へ案内する。BossBarと判定等の進行失敗は異常終了の対象とする。直接召喚の個体は討伐を経由せず破棄する。異常終了でMob破棄が失敗しても、その失敗を記録し、参加者の退避とフィールド後片付けを続行する。

## 4. 数値と未確認事項

Lv50基礎職にアストラ武器と対応防具4部位を+10で装備し、ツリー・アクセサリー・エンチャントを外した比較では、有効攻撃Rが674～708、HPが368～1727、魔法防御が639～812。DEF500に設定して低装備ビルドでゼロダメージになる閾値を避ける。ボスHP100,000、攻撃500、経験値24,000。共通HP人数補正は二人目以降一人あたり50%。技能係数1.3～1.6、攻撃稼働75～85%を仮定したソロ3～5分は計算上の目標であり、実測ではない。

コマンドの実地到達性と帰還、Java版・統合版クライアントでの針と反響の視認性、1～6人の討伐時間、復活直後の公平性は実機で未確認。

## 5. 固有報酬と交換

`10a00411`「廻刻の時針」は、討伐時の抽選率100%、数量1、幸運補正なしとする。実受取には既存共通報酬資格が必要で、固定参加者がオンラインで同じ戦闘会場におり、非AFKかつBAGに空きまたは積める枠が必要。BAGが満杯で積めない場合は抽選済み素材も破棄する共通仕様である。受付成立時と待機後参加時に`P_8062`で条件を案内する。受け取った素材4個を `85.shared.recipe` の `SHOP` レシピ `horologium_pocket_watch_exchange` で消費し、公開 `EXCHANGE` ショップ `horologium_exchange` の商品一つから `20a00457`「巻戻しの懐中時計」1個へ交換する。ショップ商品には `recipeId` のみを指定し、`requiredItems` は重ねない。プレイヤーは `/shop 廻刻の交換所` で名前検索してGUIを開ける。

懐中時計はLv50のAMULETで、固定 `MAX_HEALTH +60` と `MOVEMENT_SPEED +6` を持つEPIC品。強化・エンチャント・ルーン・攻撃補正を持たない。既存Lv5アミュレットの攻撃・回避寄りの選択肢に対し、生存と位置取りへ特化する。比較したLv50構成のHP368～1727に対する固定HP60は約16.3～3.5%で、移動速度は職業上限に従う。確定周回品として個体抽選を付けず性能を一定にし、別の希少抽選も設けない。素材・装備・レシピ・ショップの `progression` は、ボスと同じ標準攻略段階50とする。
