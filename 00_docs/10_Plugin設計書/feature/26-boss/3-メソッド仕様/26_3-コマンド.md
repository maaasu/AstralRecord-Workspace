# 26_3-コマンド

## 1. ボスコマンド実行

クラス名: `BossCommand`
物理名: `executeCommand`

コマンド: `/boss <instances|list|stop|cancel|teleport> [partyId|partyKey|challengeIdPrefix|type instanceId]`

処理内容:

1. plugin または `BossChallengeService` が未初期化の場合、`P_6520` を error 表示する。
2. 引数なしは usage を表示する。
3. 第1引数 `cancel` は管理者判定より先にプレイヤー向け中止処理へ進む。
4. `cancel` 以外は、console または `UserPermission.ADMIN` 以上のオンライン `AstPlayer` だけ許可する。権限不足は `P_5061` を表示する。
5. `instances` / `list` は [[26_3-コマンド]].稼働中挑戦一覧 を実行する。
6. `stop` は [[26_3-コマンド]].管理者停止 を実行する。
7. `teleport` は [[26_3-コマンド]].管理者挑戦リーダー位置への転送 を実行する。
8. その他は usage を表示する。

## 2. 稼働中挑戦一覧

クラス名: `BossCommand`
物理名: `handleList`

コマンド: `/boss instances`, `/boss list`

処理内容:

1. `BossChallengeService.describeActiveForAdmin` と `DungeonService.describeActiveForAdmin` を取得し、ボス／ダンジョンの稼働中セッションを一つの一覧へまとめる。
2. 空の場合は `P_6538` を表示する。
3. 1件以上の場合は `P_6536` に件数を渡す。
4. プレイヤー実行時は各行を `P_6537` で表示し、`/boss teleport <boss|dungeon> <instanceId>` のクリックイベントを付ける。コンソール実行時は同じ内容をクリックなしで表示する。

## 3. 管理者挑戦リーダー位置への転送

クラス名: `BossCommand`
物理名: `handleTeleport`

コマンド: `/boss teleport <boss|dungeon> <instanceId>`

処理内容:

1. プレイヤー実行かつ `UserPermission.ADMIN` 以上であることを確認する。
2. 種別と UUID を検証し、Boss の場合は `BossChallengeService.teleportAdminToLeader`、Dungeon の場合は `DungeonService.teleportAdminToLeader` を呼び出す。
3. クリック時点で対象セッションが存在し、終了処理中でなく、現在のパーティーリーダーが対象参加者としてオンラインであることを再検証する。
4. リーダーの現在 `Location` を `PlayerTeleportService` へ渡し、管理者を転送する。対象が見つからない、リーダーがオフライン、または転送失敗の場合は `P_6539` を表示する。

## 4. 管理者停止

クラス名: `BossCommand`
物理名: `handleStop`

コマンド: `/boss stop <partyId|partyKey|challengeIdPrefix>`

処理内容:

1. 引数が2件でなければ usage を表示する。
2. `BossChallengeService.stopChallenge(args[1])` を呼ぶ。
3. 対象なしは `P_6519`、停止開始は `P_6518` を引数文字列付きで表示する。

`stopChallenge` は challenge UUID prefix の複数一致を検出せず、iteration 上で最初の一致を停止する。運用上の扱いは [[26_9-未決事項]] とする。

## 5. リーダー中止

クラス名: `BossCommand`
物理名: `handlePlayerCancel`

コマンド: `/boss cancel`

処理内容:

1. console からの実行は `P_5060` を error 表示する。
2. player の中止可能 challenge を検索し、現在の party leader 条件を確認する。
3. `STOPPED` は `P_6528`、`NOT_LEADER` は `P_6526`、`NO_CHALLENGE` は `P_6527` を表示する。
