## 実装境界

- `boss` feature は挑戦 session、参加者、結果、temporary world lifecycle を管理する。
- Mob の生成・破棄、通常戦闘、固定受取人への報酬処理は mob feature を利用する。
- 有効ダメージと HP 0 の検出は combat feature を入口とする。
- 通常 world と runtime world の登録・転送は world feature を入口とする。
- 入力 Event を直接競合処理せず、player-interaction の resolver として候補を提供する。
