# 26_3-水鏡の守り主

## 対象と実装境界

- Mob ID `eriva_pond_mirror_keeper` の固有戦闘は `PondEncounterController` が所有する。ボスのHP・攻撃・防御・モデルはMobマスタ、人数HP補正と確定参加者はDungeon/Boss挑戦サービスを正本とする。
- `BossMechanicService` の同期5tick時計で進み、Dungeonでは `resolveMobRewardRecipients` の確定名簿、挑戦では確定参加者、直接召喚では標的の戦闘所有者とそのパーティーを解決する。死亡・観戦・creative・別world・スポーン基準の半径18m外・戦闘階の高さ±2m外を除く。
- ボスへの攻撃も、攻撃者または召喚ペットの戦闘所有者が同じ会場の参加者である場合に限る。直接召喚の最初の接敵だけ会場内の初撃を許可する。

## 水鏡の記録と再演

- 初回60tickの案内後、移動を60tick記録、軌跡を40tick固定予告、60tick再演、60tick静水の反撃猶予、40tick通常AIの間隔を繰り返す。記録から静水終了までは通常AIと経路探索を停止し、通常攻撃が同時に重ならない。
- 記録するのは最大6人・1人13点。足元XZを浅水面または岸へ投影する。3m超の移動、通れない区間、転送は記録を切り直す。退出者の未確定記録を除く。予告後の軌跡は固定し、途中退出で危険範囲を突然変えない。
- HP70%より多い段階は元の移動順、70%以下は元の軌跡に20tick遅れた点対称の鏡軌跡を追加、35%以下は追加鏡軌跡を逆再生する。70%以下の再演全体は80tick。元の軌跡を消して鏡側だけにせず、ソロでも段階が進むほど判断が増える。観測したHP段階は回復しても逆戻りせず、次の記録開始に反映する。
- 予告は水色の記録点、薄紫の固定軌跡、緑の退避小円を使う。半透明のBlockDisplay鏡片が記録点の間を補間して動く。色に加え、足跡・小円・動く鏡片・進行バーの対処説明で区別する。
- 鏡片の5tick移動を水平線分で掃引し、幅0.85m・高さ差2m以内・壁に遮られない生存参加者へ魔法・氷属性の攻撃力75/85/95%を要求する。同じ再演全体で各参加者へのダメージ要求は一度だけで、複数軌跡や回避後でも連打しない。
- 静水では鏡片を回収し、甲羅を発光させ、固有一時効果で被ダメージ1.20倍を60tick適用する。無敵や即死は持たない。

## 安全域と地形

- `PondSurface` は読込済みchunkだけを調べる。基準階の上下2mにある、頭上2mが開いた衝突床か深さ1ブロックの水面を使い、深水・溶岩・マグマを採用しない。地形を変更しない。
- 点対称の鏡軌跡が成立しない地形ではその軌跡を採用しない。固定予告開始前に各生存参加者から3.4m以内で歩ける退避点を探索し、全軌跡から1.7m以上離れた小円を確保する。確保できない場合は軌跡を末尾から省き、何も残らなければ危険な攻撃を出さず静水へ進む。ソロでも他人の位置・同時操作を必要としない。
- 階外の人を高さ無制限の水平判定で攻撃しない。未読込chunkを読み込まず、壁越しや通れない場所へ鏡片を進めない。

## 回収と上限

- 死亡・Mob破棄・待機・帰還・走査から消えた個体・Plugin停止は `clear/clearAll/retain` で全状態を回収する。CC・拘束・詠唱不能・生存参加者喪失は `cancelCast` で攻撃を中断する。
- 完了・中断の共通経路で鏡片UUID、BossBar、記録・固定軌跡・退避点・命中済み集合、一時被ダメージ倍率、所有する通常AI停止を解放する。開始前の発光状態を復元する。
- 鏡片は最大12個。記録の粒子は最大78点、固定軌跡は点間の補間も含め最大444点、退避小円は12点/人で10tick間隔に一括描画し、対象走査を点ごとに繰り返さない。個別schedulerは持たず、共通サービス停止後に再開しない。
- リソースは `P_7740`〜`P_7746` と `E_6510`、共有粒子は `POND_RECORD/WARNING/SAFE/IMPACT` を使う。文言の正本はpropertiesにある。

## 検証境界

コンテンツ固有の倍率・軌跡・見た目を恒久JUnitへ固定しない。登録、リソース検査、コンパイル、実サーバーでのソロ・パーティー・転送・CC・退出・死亡・停止時の表示回収を確認する。クライアントの視認性と操作感はコンパイルだけでは確認できない。
