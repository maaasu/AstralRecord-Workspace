# 26_3.01-イベント

## ボス挑戦スニーク受付

入力family: `SNEAK`
クラス名: `BossEntryEventHandler`
物理名: `resolve`

1. `PlayerInteractionGatewayEventHandler.onPlayerToggleSneak`が生成した`SNEAK` contextかつ`PlayerToggleSneakEvent.isSneaking() == true`の場合だけ判定する。
2. 現在ワールドと座標から、ボス挑戦設定`entryLocation` / `entryRadiusMeters`内で最も近い入口を解決する。
3. 円内なら入口までの実距離を`hitDistance`に設定し、`WORLD_INTERACTION`、`stableOrder = 10`、`CLAIM`の`boss-entry`候補を返す。
4. 候補収集時は挑戦受付を行わず、本候補が勝った場合だけexecutorが[[26_3.02-サービス]].ボス挑戦受付 を呼び出す。
5. 同tierのworld spawn候補とは実距離を先に比較し、距離も同じ場合だけboss `10`、world `15`の順にする。敗者になった入口は実行しない。
6. boss候補が勝った場合、wall-cling / dodge player-controlは実行しない。
7. `CLAIM`は元eventをcancelせず、vanillaのスニーク姿勢変更を維持する。円外では候補を返さず通常スニークを変更しない。

## ボス中止controllerのドロップ受付

入力family: `DROP_ITEM`

クラス名: `BossChallengeCancelEventHandler`

物理名: `resolve`

1. `PlayerInteractionGatewayEventHandler.onPlayerDropItem`が生成した`DROP_ITEM` contextだけを対象にする。
2. プレイヤー近傍のボス挑戦中止controllerを副作用なしで検索し、存在しなければ候補を返さない。
3. 対象があれば`WORLD_INTERACTION`、`stableOrder = 10`、`CLAIM_AND_CANCEL`の`boss-cancel-drop`候補を返す。
4. input lockがなければ、本候補はmenu craft shortcutとplayer-mode normal drop guardより優先する。
5. 本候補が勝った場合だけ元eventをcancelし、executorがリーダー権限を検証して中止GUIを開く。権限不足では案内を返す。
6. executorが拒否・失敗しても下位drop候補へfallbackしない。候補がなければ通常ドロップを変更しない。

## ボス挑戦中ログアウト処理

イベント物理名: `PlayerQuitEvent`
クラス名: `BossPlayerSessionEventHandler`
物理名: `onPlayerQuit`

1. ログアウトしたプレイヤーの待機フラグを削除する。
2. プレイヤーがボス挑戦中の参加者でない場合は終了する。
3. 参加者を非アクティブ化し、`leftFieldAt` を記録する。
4. ボスフィールド内のアクティブ参加者が 0 人になった場合、[[26_3.02-サービス]].ボス挑戦終了 を `NO_PARTICIPANTS` で呼び出す。
5. 残り参加者がいる場合、挑戦状態は変更しない。

## ボス挑戦中死亡処理

イベント物理名: `BossPlayerDeathEvent`
クラス名: `BossPlayerDeathEventHandler`
物理名: `onBossPlayerDeath`

`BossPlayerDeathEvent` は `DamageService` または `PlayerDeathService` からボス挑戦中の死亡として通知される内部イベントとする。

1. 死亡プレイヤーが `IN_PROGRESS` の参加者であることを確認する。
2. `currentDeathCount` と参加者個人の `deathCount` を加算する。
3. `currentDeathCount >= challenge.deathLimit` の場合、[[26_3.02-サービス]].ボス挑戦終了 を `DEATH_LIMIT` で呼び出す。
4. 上限未満の場合、5 秒間の死亡状態を開始し、全回復後に `playerSpawnLocation` へ復帰させる。
5. 復帰待機中に討伐成功した場合、死亡参加者を報酬対象に残し、個別復帰を中止して結果待機へ移行する。

## ボス Mob 撃破処理

イベント物理名: `BossMobDefeatedEvent`
クラス名: `BossMobEventHandler`
物理名: `onBossMobDefeated`

`BossMobDefeatedEvent` は `MobCombatService` または `DamageService` から、ボス挑戦に紐づくボス Mob が撃破されたときに通知される内部イベントとする。

1. 撃破された Mob インスタンス ID から `BossChallengeInstance` を取得する。
2. 挑戦状態が `IN_PROGRESS` でない場合は何もしない。
3. [[26_3.02-サービス]].ボス挑戦終了 を `DEFEATED` で呼び出す。

## ボス挑戦中パーティー解散抑制

イベント物理名: `PartyDisbandRequestEvent`
クラス名: `BossPartyEventHandler`
物理名: `onPartyDisbandRequest`

1. 対象パーティーがボス挑戦中でなければ何もしない。
2. ボス挑戦中の場合、イベントをキャンセルする。
3. パーティー GUI またはコマンド実行元へ、ボス挑戦中は解散できない旨を表示する。

## ボス挑戦中パーティー離脱抑制

イベント物理名: `PartyLeaveRequestEvent`
クラス名: `BossPartyEventHandler`
物理名: `onPartyLeaveRequest`

1. 対象プレイヤーがボス挑戦中の参加者でなければ何もしない。
2. ボス挑戦中の参加者である場合、イベントをキャンセルする。
3. パーティー GUI またはコマンド実行元へ、ボス挑戦中は離脱できない旨を表示する。
