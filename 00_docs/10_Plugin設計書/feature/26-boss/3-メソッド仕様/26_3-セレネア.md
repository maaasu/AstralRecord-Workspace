# 26_3-セレネア

## 1. 役割と利用

`selenea_eclipse_witch`「月蝕の綴り魔女 セレネア」はLv30・1～6人用のWITCH型ボス。月の満ち欠けを書物へ綴り、封じた頁を開く魔女という独自モチーフを持つ。既存のRPGダメージ・報酬へ接続し、`SeleneaEncounterController` が `BossMechanicService` の5tick時計から全攻撃を直列に制御する。Skriptや外部Mobプラグインは使用しない。

登録後は `/mob spawn selenea_eclipse_witch` で生成する。既存ボスと同じく、未指定の実ワールド・受付座標は推測して `challenge` へ固定しない。受付を置く場合は既存のBOSS_FIELDと `challenge` に現地の入口・出現地点、`partyMin: 1` / `partyMax: 6` を設定する。挑戦・ダンジョンの制限時間、死亡回数、報酬配布、会場破棄は既存の管理へ委譲する。

会場は半径18mの連続した平坦な床、頭上4mの空間を推奨する。実装は同一world・出現高さ±3mを戦闘階とし、通常攻撃は18m以内、場外復帰予兆は32mまで扱う。壁の向こうへ攻撃しない。予兆時に各参加者から歩行可能な退避先を検査し、穴・液体・接触ダメージ床・未ロードchunkを除外する。地形上で成立しない攻撃は無害に待って再試行する。

## 2. 人数と基準値

Lv30通常Mob基準HP19,000・攻撃3,442・防御3,318にボス基準倍率8・1.2・1.15を適用し、HP152,000・攻撃4,130・防御3,816とする。恒常シールドはなく、封頁の儀だけ被ダメージ0.35倍、解呪成功後は1.45倍になる。高HPだけを完成度の指標にせず、読める予兆、役割分担、回避と反撃の循環を重視する。実プレイによる討伐時間の調整値とは区別する。

| 人数 | HP | 同時に狙う落款 / 必要封頁 |
|:--|--:|--:|
| 1 | 152,000 | 1 |
| 2 | 228,000 | 1 |
| 3 | 304,000 | 2 |
| 4 | 380,000 | 2 |
| 5 | 456,000 | 3 |
| 6 | 532,000 | 3 |

HPは共通 `BossMobScalingService` の `1 + 0.5 × (人数 - 1)`。挑戦・ダンジョンでは既存の生成時補正を使う。直接召喚では最初の有効な初撃または接敵時に、所有者と場内にいるパーティーメンバー最大6人をUUIDで固定し、一度だけ同じ補正を適用する。途中参加、脱退、死亡でHPを増減しない。別パーティー、見学者、クリエイティブ、スペクテイターは対象外。ペット攻撃も所有者の資格と場内位置を検査する。IDLE/LEASHEDへの帰還時は固定名簿を破棄する。

落款は詠唱開始時の生存する場内参加者数を用い、UUID順のカーソルを進めて対象を交代する。複数円が重なっても一波一人一回だけ命中する。封頁は開始時に1～3枚用意し、減員時には必要数を「解除済み枚数＋残存人数相当」まで減らす。増員・復帰では増やさない。一人が全封頁を順番に解除することも可能で、同時操作は必須にしない。

確定報酬は経験値12,000と「月蝕の綴り墨」`10a00101` ×1。素材は既存売却経路で1,500G。ドロップ個数はluck補正しない。これらは近い進行度の報酬から定めた初期値で、経済全体の実測値ではない。

## 3. 技と進行

| 技 | 予兆 / 持続 | 行動と回避 | 魔法倍率 |
|:--|--:|:--|--:|
| 導入 | 60tick | 危険印・緑白の退避輪・封頁操作を案内 | 0 |
| 墨の三叉 | 60tick | 固定された三方向の線（±30度・半幅1.25m）から横/後方へ | 0.75 |
| 墨の返し綴り | 60tick | 終章のみ。先の方向から90度回した三叉を再予告 | 0.75 |
| 呪頁の落款 | 65tick | 開始時の足元、半径2.5mの固定円から離れる | 0.80 |
| 月輪・満ち | 60tick | 中心6m以内から外へ | 0.85 |
| 月輪・欠け | 100tick | 満ちの後に別予兆。6mより外から内へ | 0.85 |
| 月蝕の行間 | 110tick | 中心を通る半幅3mの緑白通路へ | 0.90 |
| 月蝕の頁返し | 110tick | 終章のみ。通路を90度回して別予兆 | 0.90 |
| 封頁の儀 | 280tick | 半径約5.5mに配置した封頁の1.7m輪内で1.5秒連続スニーク | 0 |
| 解呪成功 | 100tick | 魔女の攻撃を止め、被ダメージ1.45倍で反撃 | 0 |
| 封頁失敗の月蝕 | 120tick | 半幅3mの通路へ退避。失敗しても即死させない | 1.10 |
| 月蝕の境界 | 120tick | 場外18～32mの参加者へ帰還を予告。場内への歩行経路も検査 | 0.90 |
| 反撃の好機 | 30tick | 呪文列の間の休止 | 0 |

第1章は三叉→落款→満ち/欠け→封頁。第2章は三叉→行間→落款→満ち/欠け→封頁。終章は三叉/返し綴り→落款→行間/頁返し→満ち/欠け→封頁。組技も一波ずつ完全な予兆を行い、別形状を重ねない。向き、落款位置は詠唱開始時から追尾しない。

組技の次波が地形・場内対象不在で開始できない場合は、技と固定方向を保持して再試行し、通常ローテーションへ飛ばさない。CC・拘束・有効参加者全員の喪失は明示的な中断とし、待機中の次波も破棄する。未完了のHP境界は保持し、儀式から完全にやり直す。外周18mからも退避できるよう、内戻りは5秒、通路は5.5秒以上の予兆とし、秒速3mの歩行距離と体幅の余白で成立を確認する。

HP65%以下・30%以下で章の儀式を順に予約する。一撃で両境界を跨いでも、一つ目の儀式とその結果の着弾/反撃窓が完了してから次へ進む。HP回復で完了済みの章を再実行しない。成功反撃窓は途中でHP境界を跨いでも5秒を保証する。CC・拘束・参加者喪失で中断した境界は未完了とし、再開時は完全な予兆からやり直す。

## 4. 操作・描画・寿命

解除保持は封頁ごと・個人ごとの開始tickを使う。輪外、スニーク解除、死亡、切断、資格喪失では未完了の保持を破棄する。他人の保持時間を合算せず、複数枚を一人で同時に進めない。解除済みの封頁はシーランタンに変わり音で通知する。BossBarに解除枚数・必要数・保持進捗を表示する。

危険面は全ボス共通の攻撃予見、退避輪は緑の輪郭と白い縦装飾を使う。紫の呪片、周回する3冊の魔導書、銀紫の着弾で魔女の外観を表す。粒子OFFでもBossBar、音、表示Entityを残す。安全通路には4個の白い灯の表示を両縁へ配置して向きを示す。予兆は10tick周期、危険最大144点、退避輪は最大6人分、境界は20tick・48点。1castの表示は攻撃呪片最大12個＋本3冊（通路では呪片8個＋白灯4個＋本3冊）、儀式時は封頁最大3個＋本3冊。実ブロックとプレイヤーの位置は変更しない。

全演出はcastまたは個体UUIDが所有する。中断、死亡、消失、帰還、Plugin停止でBossBar、ItemDisplay、BlockDisplay、保持状態、専用倍率、scriptedActionを解除する。専用遅延taskはなく、着弾による再入・死亡時はcast同一性を再確認して後続命中を止める。他会場の個体状態には触れない。文言は `P_7650`～`P_7664`、進行例外は `E_6509`。
