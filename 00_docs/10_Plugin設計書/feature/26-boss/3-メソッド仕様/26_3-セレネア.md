# 26_3-セレネア

## 1. 役割と利用

`selenea_eclipse_witch`「月蝕の綴り魔女 セレネア」はLv30・1～6人用のWITCH型ボス。月の満ち欠けを書物へ綴り、封じた頁を開く魔女という独自モチーフを持つ。既存のRPGダメージ・報酬へ接続し、`SeleneaEncounterController` が `BossMechanicService` の5tick時計から全攻撃を直列に制御する。Skriptや外部Mobプラグインは使用しない。

専用ワールドは `vanaheim_boss_selenea_field`。受付はエリヴァ超大陸の幽翠のトウヒ館の受付Xに3を加えた `(-742.5, 110, 1648.5)`、ボス出現位置は `(8.5, 64, 8.5)`、参加者出現位置は `(8.5, 64, -13.5)` とする。挑戦は1～6人で、制限時間、死亡回数、報酬配布、会場破棄は既存の管理へ委譲する。管理者は `/mob spawn selenea_eclipse_witch` でも生成できる。

専用フィールドの攻撃半径は48mとし、直下へ投影した安全な床が出現高さ±0.6mにある中央壇だけを本体への攻撃、詠唱対象、予兆、命中に共通で使う。中央壇からの跳躍中も水平の危険形状に当たる。下段や孤立した装飾床、外周足場は支援・移動の参加資格を維持するが、本体の通常戦闘対象にはしない。専用フィールド以外では同一world・出現高さ±3mを戦闘階とし、通常攻撃は18m以内、場外復帰予兆は32mまで扱う。壁の向こうへ攻撃しない。予兆時に各参加者から歩行可能な退避先を検査し、穴・液体・接触ダメージ床・未ロードchunkを除外する。地形上で成立しない攻撃は無害に待って再試行する。

2026-10-12のテンプレートregionの読み取りでは、足元Y64の中央壇は半径34mまで連続し、それより外側は装飾や足元Y52の下段を含む。名目半径48m全域が平坦な床ではない。外周の門の指定先Y67にはY66の床がなく、写本守の指定位置にはY66の床がある。下段のエメラルド床はY51（接地時の足元Y52）。これは保存地形から確認した事実であり、実クライアントの操作・描画・討伐時間は未確認。外周の門の着地床は後述の会場所有処理で補う。

## 2. 人数と基準値

Lv30通常Mob基準HP19,000・攻撃3,442・防御3,318にボス基準倍率8・1.2・1.15を適用し、HP152,000・攻撃4,130・防御3,816とする。恒常シールドはなく、封頁の儀だけ被ダメージ0.35倍、解呪成功後は1.45倍になる。高HPだけを完成度の指標にせず、読める予兆、役割分担、回避と反撃の循環を重視する。実プレイによる討伐時間の調整値とは区別する。

| 人数 | HP | 同時に狙う落款 / 必要封頁 |
|:--|--:|--:|
| 1 | 152,000 | 1 |
| 2 | 228,000 | 1 |
| 3 | 304,000 | 2 |
| 4 | 380,000 | 2 |
| 5 | 456,000 | 3 |
| 6 | 532,000 | 3 |

HPは共通 `BossMobScalingService` の `1 + 0.5 × (人数 - 1)`。挑戦・ダンジョンでは既存の生成時補正を使う。直接召喚では最初の有効な初撃または接敵時に、所有者と場内にいるパーティーメンバー最大6人をUUIDで固定し、一度だけ同じ補正を適用する。途中参加、脱退、死亡でHPを増減しない。別パーティー、見学者、クリエイティブ、スペクテイターは対象外。ペット攻撃も所有者の資格と場内位置を検査する。通常会場ではIDLE/LEASHEDへの帰還時に固定名簿を破棄する。専用フィールドでは外周への移動を通常AIの帰還扱いにしない。

落款は詠唱開始時の生存する場内参加者数を用い、UUID順のカーソルを進めて対象を交代する。複数円が重なっても一波一人一回だけ命中する。封頁は開始時に1～3枚用意し、減員時には必要数を「解除済み枚数＋残存人数相当」まで減らす。増員・復帰では増やさない。一人が全封頁を順番に解除することも可能で、同時操作は必須にしない。

確定報酬は経験値12,000と「月蝕の綴り墨」`10a00101` ×1。素材は既存売却経路で1,500G。ドロップ個数はluck補正しない。これらは近い進行度の報酬から定めた初期値で、経済全体の実測値ではない。

第1章は三叉→落款→満ち/欠け→封頁。第2章は三叉→行間→落款→満ち/欠け→封頁。終章は三叉/返し綴り→落款→行間/頁返し→満ち/欠け→封頁。組技も一波ずつ完全な予兆を行い、別形状を重ねない。向き、落款位置は詠唱開始時から追尾しない。

組技の次波が地形・場内対象不在で開始できない場合は、技と固定方向を保持して再試行し、通常ローテーションへ飛ばさない。CC・拘束・有効参加者全員の喪失は明示的な中断とし、待機中の次波も破棄する。未完了のHP境界は保持し、儀式から完全にやり直す。専用フィールドでは外周48mからも退避できるよう、内戻りは14秒、通路は16秒、封頁解除は22秒の予兆・操作時間とし、秒速3mの歩行距離と退避輪の余白を検査する。

HP65%以下・30%以下で章の儀式を順に予約する。一撃で両境界を跨いでも、一つ目の儀式とその結果の着弾/反撃窓が完了してから次へ進む。HP回復で完了済みの章を再実行しない。成功反撃窓は途中でHP境界を跨いでも5秒を保証する。CC・拘束・参加者喪失で中断した境界は未完了とし、再開時は完全な予兆からやり直す。

## 4. 操作・描画・寿命

解除保持は封頁ごと・個人ごとの開始tickを使う。輪外、スニーク解除、死亡、切断、資格喪失では未完了の保持を破棄し、中央の有効対象が全員いなくなった場合も破棄する。足元と床面の高さ差0.1m以内で接地を確認し、跳躍中のスニークは進捗に含めない。他人の保持時間を合算せず、複数枚を一人で同時に進めない。解除済みの封頁はシーランタンに変わり音で通知する。BossBarに解除枚数・必要数・保持進捗を表示する。

危険面は全ボス共通の攻撃予見を使う。入るだけの退避輪は半径1.5mの白い `END_ROD` と緑の補助輪、スニークが必要な封頁輪は半径3mの `ENCHANT` と紫の補助輪で、粒子の種類と色を分ける。白い輪の安全検査はプレイヤーの体幅を含めて半径1.85mまで行う。解除済み封頁は紫輪を消し、シーランタンの表示だけにする。

攻撃判定の発生時は、予兆と同じ危険形状へ最大24地点の爆発、最大256地点の火花と爆発音を一度表示する。実際の爆発やブロック破壊は発生させない。紫の呪片と周回する3冊の魔導書で魔女の外観を表す。本は遭遇が所有し、通常の波切替で再利用する。導入・詠唱・封頁・解呪成功・休止の五姿勢を共通の周回時計から算出し、生成時も同じ姿勢を設定する。呪片は各危険形状に沿って置き、最後の20tickに四段階で落下する。静止期間に同じ位置へのteleportを繰り返さない。

粒子OFFでもBossBar、音、表示Entityを残す。安全通路には4個の白い灯の表示を両縁へ配置して向きを示す。予兆は10tick周期、危険最大256点、退避輪は最大6人分、境界は20tick周期。危険点は輪郭と均等面積の有限サンプルから作り、半径に比例して床の格子走査を増やさない。攻撃中の表示は呪片最大12個＋本3冊（通路では呪片8個＋白灯4個＋本3冊）、儀式時は封頁最大3個＋本3冊。呪文演出は実ブロックとプレイヤーの位置を変更しない。必須の門・回復玉・支援爆発は最低粒子密度でも一地点一粒以上を送る。共有サービスの専用overloadで遠距離表示flagを付けるが、表示距離の送信上限64mとOFF・統合版の密度設定は維持する。実クライアントの補間、遠距離の可視性、描画負荷は別途確認する。

全演出はcastまたは個体UUIDが所有する。詠唱中断時は詠唱所有のBossBar、表示Entity、保持状態、専用倍率を解除する。専用フィールドの通常AI抑止は会場の管理中に維持し、会場終了時に解除する。死亡、消失、帰還、Plugin停止では遭遇所有の本も回収する。専用遅延taskはなく、着弾による再入・死亡時はcast同一性を再確認して後続命中を止める。他会場の個体状態には触れない。文言は `P_7650`～`P_7664` および支援・中央壇・転送案内の `P_7680`～`P_7689`、進行例外は `E_6509`。

## 5. 専用フィールドの写本守と転送門

`WorldService.findByBukkitWorld` で解決したマスタIDが `vanaheim_boss_selenea_field` と完全一致する場合だけ、`SeleneaSupportController` の追加ギミックを実行する。登録済みの挑戦インスタンスも元のマスタIDで判定し、他ワールドに召喚した魔女には追加しない。

魔女の残りHPが最大HPの50%以下になった時、次の5tick走査または被ダメージ倍率の確認時に四体を一度だけ召喚する。召喚前は写本守による支援・軽減を適用しない。召喚後にHPが50%を超えて回復しても生存個体の支援・軽減は継続し、再召喚せず、全滅後も再召喚しない。最大HPは各個体とも参加人数補正後の魔女最大HPの1/6（ソロでは約25,333）。人数補正が後から入る直接召喚では、現在HP割合を保持して最大HPを同期する。四体はWITHER_SKELETON型で移動・落下・通常攻撃をせず、ドロップや経験値を付与しない。

| 方向 / 色 | 写本守 / マスタID | 生存中の支援 | 中央の門 | 外周の門 | 召喚位置 |
|:--|:--|:--|:--|:--|:--|
| +X / 水色 | 封護 / `selenea_ward_page` | 魔女の防御3倍 | (34.5, 64, 8.5) | (66.5, 67, 8.5) | (80.5, 67, 8.5) |
| -X / 薄紫 | 月癒 / `selenea_lunar_page` | 魔女を回復 | (-17.5, 64, 8.5) | (-49.5, 67, 8.5) | (-63.5, 67, 8.5) |
| +Z / 赤 | 烈怒 / `selenea_wrath_page` | 魔女の与ダメージ2倍 | (8.5, 64, 34.5) | (8.5, 67, 66.5) | (8.5, 67, 80.5) |
| -Z / 緑 | 慈癒 / `selenea_mercy_page` | 自分を除く他三体を回復 | (8.5, 64, -17.5) | (8.5, 67, -49.5) | (8.5, 67, -63.5) |

座標は実際の魔女出現位置からX/Z方向へ26・58・72m、外周だけY+3として算出する。各門は半径3m・2.65mの二重縦リングに六本の回転放射線と白い光点を重ね、役割ごとの色で同色間を往復する。描画は10tick周期、役割ごとに二個の門の最大220色点と、八個の門の計96白点を一括で送る。接触判定は足元の水平半径3.2m・高さ-0.5〜6m。ゲートはHP50%に達する前から表示・転送を行い、再転送制限は2秒。写本守が死亡しても帰還用の門は残す。

外周の門の直下に各7×7、合計最大196ブロックの着地床を会場が所有する。AIR系またはLIGHTだけをDARK_OAK_PLANKSへ置き換え、元のBlockDataをworld PDCに記録する。既存建築は置き換えず、元の通路を使う。終了時は自分の配置と一致する床だけを復元し、他者の変更は保持する。同じ床を共有する会場は最後の所有者で復元する。保存済みの古いjournalがあれば初期化時に回収する。`World.save`は実行せず、PDCがまだ保存されていない強制終了からの復元は保証しない。転送直前に足元、体幅、頭上2mを検査し、不安全なら転送せず案内する。

中央、写本守、門、着地床の隅を含む最大29地点のchunkをPlugin ticketで保持する。指定座標では15chunkとなる。同じworld・chunkの複数会場は参照数で共有し、借用した既存ticketを勝手に解除しない。保持中に消えたticketは最大20tick間隔で補修する。終了時は床の復元を先に行い、最後の所有者で自分のticketを解放する。chunk読込callback再入と生成途中の失敗でも、取得済みの所有物を回収する。

回復玉は3秒ごとに発射し、2秒かけて最大12m持ち上がる放物線で対象へ進み、着弾時に対象最大HPの3%を `MobService.recoverHealth` で回復する。発射元または対象が死亡した玉は消える。魔女の被ダメージ軽減は生存写本守一体ごとに25%で、100%・75%・50%・25%・0%へ減少する。通常・スキル・状態異常・固定HP追加ダメージに適用し、既存の封頁・反撃倍率と乗算する。

召喚から180秒（3600tick）後、生存している各写本守はその位置を中心とする球形半径60mに一度だけ爆発する。範囲内の生存参加者の残HPを消費し、シールド・防御・回避を通さず共通の挑戦死亡・復帰処理へ渡す。地形を破壊せず、爆発後も写本守と支援は残る。爆発後は参加者を再取得し、カスタム死亡したプレイヤーを門へ転送しない。ボス死亡、消失、ワールド破棄、Plugin停止では写本守・玉・門・専用倍率を回収する。生成途中の例外では所有関係を先に外し、一個体の破棄が失敗しても全個体の破棄を試行する。

召喚時に四体の役割と本体の軽減を案内し、専用BossBarで生存数と爆発までの切り上げ残秒を表示する。30秒・10秒・5秒〜1秒の警告は一度ずつ送る。最後の10秒は一秒ごとに球形60mの三つの大円を描き、最大576地点/秒で危険範囲を示す。全滅時は支援・玉・専用BossBarを解除し、中央へ戻る案内を一度送る。生存個体がない場合は期限の爆発案内を送らない。

このフィールドでは参加資格を水平90m以内・出現高さとの差-16〜40mとし、外周足場を場外帰還予兆の対象にしない。本体への攻撃資格は所有者の位置を中央壇と48mの共通判定に限定し、設置スキルやペットも同じ資格を使う。写本守への攻撃資格は90mの参加範囲を使う。通常AIの敵対解除によるリセットを抑止し、管理中のボスはHP50%より前から無人回収から除外して終了時に元の保持設定へ戻す。通常呪文の判定・表示は専用フィールドの攻撃半径48mに揃える。

## 6. エメラルド床の跳躍

`SeleneaFieldJumpService` は同じ専用マスタIDのワールドだけで、エメラルドブロック上に接地しているプレイヤーへジャンプ力上昇21（Bukkit増幅値20）を付与する。Minecraft 1.21.11の通常重力・空気抵抗では約29.684mの上昇となる。頭上の障害物や他の移動効果を含む実クライアントの到達高度は別途確認する。

付与した効果は同フィールド内の離陸後から着地まで保持し、通常床への着地、別ワールドへの退出、死亡、ログアウト、Plugin停止で解除する。元のジャンプ効果は非表示チェーンの残り時間を保持して復元し、外部で同等以上の効果へ置換された場合は所有権を手放す。既存の落下ダメージ抑止を使用する。
