# 26_3-イベント

## 1. ボス入口候補解決

クラス名: `BossEntryEventHandler`
物理名: `resolve`

入力:

- family: `SNEAK`
- source snapshot event: `PlayerToggleSneakEvent`

処理内容:

1. `SNEAK`、`PlayerToggleSneakEvent`、`isSneaking() = true` を満たさない場合は空リストを返す。
2. [[26_3-サービス]].最寄り入口検索 を副作用なしで実行する。
3. 入口がなければ空リストを返す。
4. `boss-entry`、tier `WORLD_INTERACTION`、入口までの実距離、order `BOSS_ENTRY`、policy `CLAIM` の候補を返す。
5. 候補が勝った場合だけ `acceptChallenge(player, bossId)` を実行する。

例外・終了条件:

- executor の未捕捉例外は `LogId.E_6501`、引数 player name で記録する。
- `CLAIM` は元 Event を cancel せず、通常のスニーク姿勢を維持する。

## 2. ボス中止候補解決

クラス名: `BossChallengeCancelEventHandler`
物理名: `resolve`

### DROP_ITEM

1. 近傍3.5 block以内の中止 controller を検索する。
2. 対象があれば `boss-cancel-drop`、tier `WORLD_INTERACTION`、距離 `0.0`、order `BOSS_CONTROLLER`、policy `CLAIM_AND_CANCEL` の候補を返す。
3. 勝者 executor は現在のリーダーか確認し、成功時だけ GUI を開く。非リーダーへ `P_6526` を送る。

### RIGHT_CLICK

1. source が `PLAYER_INTERACT_ENTITY` または `PLAYER_INTERACT_AT_ENTITY`、main hand、スニーク中、target entity ありの場合だけ判定する。
2. target が controller の Interaction entity で、hit distance が取得でき visibility 条件を満たす場合だけ候補を返す。
3. `boss-cancel-controller`、実 hit distance、`WORLD_INTERACTION`、`BOSS_CONTROLLER`、`CLAIM_AND_CANCEL` を使用する。

両候補の executor 例外は `E_6501` で記録する。

## 3. 中止 GUI click

クラス名: `BossChallengeCancelEventHandler`
物理名: `onInventoryClick`

イベント:

- `InventoryClickEvent`
- 優先度: `HIGHEST`
- `ignoreCancelled = false`

処理内容:

1. top inventory が `BossChallengeCancelGui` でなければ何もしない。
2. 対象 GUI の click はすべて cancel する。
3. player が raw slot `13` を click した場合だけ challenge ID を取得する。
4. `stopChallengeForLeader` の結果に応じて `P_6528` / `P_6526` / `P_6527` を送り、inventory を閉じる。

## 4. プレイヤー logout

クラス名: `BossPlayerEventHandler`
物理名: `onPlayerQuit`

イベント:

- `PlayerQuitEvent`
- 優先度: `MONITOR`

処理内容:

1. `BossChallengeService.handleQuit(playerId)` を呼ぶ。
2. `handleQuit` は watchdog と同じ `tick` を即時実行し、フィールド内参加者が0人になった `IN_PROGRESS` 挑戦を終了する。

未捕捉例外は `E_6501`、引数 player name で記録する。

## 5. combat からの直接連携

専用 Bukkit Event class は持たない。

- プレイヤー HP が0以下: `DamageService` から `BossChallengeService.handleParticipantDeath` を呼ぶ。
- ボスへの有効ダメージ: `DamageService` から `recordBossDamage` を呼ぶ。
- ボス HP が0以下: 固定報酬対象を解決して Mob death 処理後、`handleBossDefeated` を呼ぶ。
