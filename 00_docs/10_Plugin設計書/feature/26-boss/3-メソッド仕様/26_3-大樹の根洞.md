# 26_3-大樹の根洞

## 1. 戦闘の責務と参加資格

`eriva_greatroot_heartwarden`「根脈の心守 オルディア」は、エリバのLv25ダンジョン `eriva_greatroot_hollow` のIRON_GOLEMボスです。静的ステータスと人数補正、配置、報酬、部屋の進行はMob/Dungeonの責務とします。シールド・通常攻撃・Mobスキルは使わず、`GreatrootEncounterController` が全攻撃を担当します。硬CC、即死、回復、地形破壊、プレイヤー強制移動は行いません。

`BossMechanicService` が同期5tick時計で進めます。攻撃は `DamageService` の `MELEE` / `NONE` / `SKILL` 経路へ委譲します。ダンジョンでは `resolveMobRewardRecipients` の現在参加者から、`DungeonService.canApplyCombatDamage` が許可する攻略中のボス部屋内の生存者だけを選びます。見学・別部屋・退出・終了中のセッションは対象外です。直接召喚では既存のクノッカーと同じ標的所有者・パーティー経路を使います。

会場はspawnLocationから水平14m、高さ差3m以内です。専用ボスと所有する芽へのダメージも同じ参加資格へ制限し、ペットによる攻撃は戦闘所有者から判定します。未登録の環境攻撃や部外者の攻撃で芽だけを破壊できません。

## 2. 予兆と通常攻撃

導入は50tickの無害な攻略案内です。一個体は同時に一つの予兆だけを持ち、開始時の中心・向き・標的位置を固定します。予兆中に対象を追尾しません。通常技は根線、扇、年輪、種、螺旋の順で進み、最終段階では六回ごとに息吹の循環を挟みます。

| 技 | 形状・対処 | 予兆 | 攻撃倍率 |
|:--|:--|--:|--:|
| 根走り | ボス中心から固定方向の線、前方14m・後方1m、半幅1.35m。横へ離れる | 45tick | 0.65 |
| 根枝の扇 | 半径11m・全角110度の前方扇。左右・背後へ移る | 45tick | 0.60 |
| 年輪波 | 固定標的地点の内半径4.5m・外半径9mの環、続いて半径5.5mの内側円。内外を交互に避ける | 各55tick、2段 | 各0.45 |
| 種の開花 | 開始時の参加者最大3地点へ半径2.2mの種印を固定。印から離れる | 60tick | 0.75 |
| 螺旋根脈 | 半径2〜10.5mに根を描き、固定方向の全角100度を安全角にする | 60tick | 0.70 |
| 息吹の循環 | 半径11mの危険面の中で半径2.8mの安全円を3回移す。次の白い案内を読んで緑の円へ進む | 各60tick、3段 | 各0.45 |

安全円の中心間移動は4mで、各候補の床・円周・頭上・直前地点からの歩行経路を確認します。成立しない大技は開始しません。年輪・循環の各波は直前の発動後に完全な予兆を持ち、一段ごとに同じプレイヤーへ一撃だけ適用します。安全円または技の外接範囲の外は命中しません。壁越し・別world・別階の命中も除外します。

通常技と導入の後は35tick、循環の後は70tickの無攻撃時間を置きます。専用行動中は通常AIを止め、速度をゼロにします。移動・詠唱禁止やバインド中は未発動の波を回収し、終了後にその波を完全な予兆から再開します。命中前に次波checkpointを進め、発動済み段の二重適用を避けます。

## 3. HP70%・35%の根脈接続

HP70%で2体、HP35%で3体の `eriva_greatroot_nourishing_bud` を各一度召喚します。一撃で両境界を跨いでも、最初の根脈接続と反撃時間を終えてから次の接続を開始します。閾値は回復によって巻き戻しません。

芽は中心から5〜7.5mの、中心から歩いて届く支持面へ配置し、互いに3m以上離します。静止する破壊対象で、通常AI・攻撃・報酬を持ちません。`keepWhenUnobserved(true)` と `rewardEligible(false)` を設定します。Dungeonの部屋Mob対応表には登録せず、Controllerの所有者対応表で追跡します。芽の討伐は共通の報酬抑止経路で破棄され、部屋のクリア数と報酬へ加算されません。

全ての芽の実体を生成できた時だけ、開始前のダメージ無効状態を保存し、`MobService.setDamageImmune` でRPG戦闘・Bukkit実体の双方を無敵にします。芽が一体以上生存する間、または接続から500tick（25秒）が経過するまで有効です。接続中は半幅0.85m・0.30倍の根走りだけを、45tickの予兆と100tickの予約間隔で使います。通常の大技を重ねません。残り芽数と期限をBarに表示し、中心から芽への根脈を描きます。

足場不足・一体でも生成失敗・生成後の実体不正は部分生成した芽を全回収し、無敵を開始せず接続を完了扱いにします。spawn中の外部callbackで所有ボスが終了した場合は、そのspawnから戻った芽も破棄して無敵を再取得しません。無敵開始直前に全芽の必要数と生存を再確認します。進行例外でも結界を解き、攻撃可能な状態へ戻します。

## 4. 無敵解除と反撃時間

最後の芽のdestroy通知は無敵を即時に復元します。次の同期走査で終了通知と反撃時間を一度だけ確定します。通知の無い実体消失も走査で検出し、残存Mobを回収します。

全芽消失で120tick（6秒）の無攻撃反撃時間と被ダメージ1.25倍を設定します。時間切れ・部分生成失敗も120tickの無攻撃時間を設けますが、被ダメージ倍率は付けません。次のHP境界を消化する前に、この時間を必ず挟みます。倍率は `TemporarySkillEffectService` の専用effect IDで管理し、満了・中断・帰還・停止で自分の効果だけを回収します。

結界解除は芽破棄より先に行い、所有者対応表と芽一覧を先に切り離してからdestroyを実行します。再入callbackで反撃を重複開始しません。元の無敵設定とtemplateの既定無敵を維持し、他の既定無敵を無条件に解除しません。

## 5. 終了と条件不能中の進行

CC・詠唱禁止・バインド中でも、生存芽と500tick期限、反撃満了、参加者不在を処理します。行動不能を理由に無敵期限を延長しません。

死亡・Mob破棄は既存destroy listenerへ連結し、芽・予兆・Display・Bar・一時倍率・所有した無敵を回収します。IDLE/LEASHED・全参加者退出・会場外退避・実体不正・有効個体一覧からの消失は5tick走査までに同じ回収を行います。再挑戦は新しい個体状態を使い、Plugin停止は `clearAll` で全所有物を回収します。Displayや個別芽の回収失敗は記録し、他の回収を継続します。

## 6. 表示・負荷・検証境界

`GreatrootArena` が読み込み済みchunkの地面・危険床・頭上2m・体幅・歩行経路を有限探索します。各参加者が7m以内に歩いて届く安全地点を確保してから予兆を予約します。

危険面・攻撃根線・螺旋は共通の `BOSS_ATTACK_WARNING`、安全面は `BossParticleEffect.safeArea` の緑粒子と白い縦装飾を使います。次の安全円は白い `BOSS_SAFE_BEACON` のみで示し、現在の緑円と区別します。無害な接続根はエリバの茶色い根粒子、発動衝撃はグランバルの爆発粒子を使用します。危険点・安全面は各波で最大192地点を計算して保持し、10tick周期で点群ごとに描画します。固定種印Displayは最大3個で、実ブロックを変更しません。

表示文言の正本は `P_6740`〜`P_6751`、異常進行と回収失敗は `E_6530`・`E_6531` と各propertiesです。

固有コンテンツを恒久JUnitへ固定しません。リソース・コンパイル・設計構造・トレーサビリティを検証します。実サーバーでは通常6種、HP境界の同時突破、全芽撃破・期限・部分失敗、CC中の期限、ペット・状態異常・直接攻撃の無敵と参加資格、退出・再挑戦・停止時の所有物回収を確認します。実クライアントでは床差・壁・粒子極低密度・粒子OFF・統合版のDisplayなしでの視認性を確認します。攻略難度と操作感の実測は自動検証の成功とは区別します。
