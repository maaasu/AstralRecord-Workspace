## 実装境界

- `boss` feature は挑戦状態と一時ワールド状態を管理する。
- Mob 生成、Mob HP、通常ドロップ抽選は `mob` feature の既存責務を再利用する。
- 有効ダメージ計算は `combat` feature の `DamageService` を入口にする。
- `WorldMasterData` の取得と通常ワールド解決は `world` feature を入口にする。
