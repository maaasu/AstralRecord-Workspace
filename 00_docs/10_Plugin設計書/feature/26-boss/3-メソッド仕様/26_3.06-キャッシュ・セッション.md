# 26_3.06-キャッシュ・セッション

## ボス挑戦キャッシュ

クラス名: `BossChallengeCache`
物理名: `BossChallengeCache`

`BossChallengeInstance` をメモリ上で保持する。ボス挑戦状態は一時的な実行状態であり、SQL Server へ永続化しない。

| メソッド | 役割 |
|---|---|
| `put(instance)` | 挑戦インスタンスを登録する |
| `getByChallengeId(challengeId)` | 挑戦 ID で取得する |
| `getByPartyId(partyId)` | パーティー ID で進行中挑戦を取得する |
| `getByBossMobInstanceId(mobInstanceId)` | ボス Mob インスタンス ID で取得する |
| `getByPlayerId(playerId)` | 参加者または待機者のプレイヤー ID で取得する |
| `activeInstances()` | `ENDED` 以外の挑戦一覧を返す |
| `remove(challengeId)` | 終了済み挑戦を削除する |

## ボス待機フラグキャッシュ

クラス名: `BossWaitingFlagCache`
物理名: `BossWaitingFlagCache`

`BossWaitingFlag` をプレイヤー単位で保持する。

| メソッド | 役割 |
|---|---|
| `put(flag)` | 待機フラグを登録する |
| `get(playerId)` | プレイヤーの待機フラグを取得する |
| `remove(playerId)` | プレイヤーの待機フラグを解除する |
| `removeByChallenge(challengeId)` | 挑戦終了時に関連フラグを一括解除する |
| `countReadyMembers(challenge, hubWorldId)` | ハブ集合済み人数を数える |

## ボスフィールドキャッシュ

クラス名: `BossFieldInstanceCache`
物理名: `BossFieldInstanceCache`

`BossFieldInstance` を一時ワールド名・挑戦 ID から参照できるよう保持する。

| メソッド | 役割 |
|---|---|
| `put(challengeId, fieldInstance)` | フィールドインスタンスを登録する |
| `getByChallengeId(challengeId)` | 挑戦 ID で取得する |
| `getByWorldName(worldName)` | Bukkit ワールド名で取得する |
| `remove(challengeId)` | 破棄後に削除する |

## キャッシュ破棄方針

- 挑戦成功/失敗の終了処理が完了したら、挑戦インスタンス、待機フラグ、フィールドインスタンスを削除する。
- フィールド破棄失敗時も挑戦状態は `ENDED` とし、残存フォルダは起動時掃除対象に回す。
- サーバー停止またはプラグイン無効化時は、未終了の挑戦を `PLUGIN_SHUTDOWN` として終了扱いにする。
