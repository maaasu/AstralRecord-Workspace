# 26_3-イグニヴォル

## 1. 戦闘の責務

`eriva_caldera_ignivor` は隕石落下地点の火山ダンジョンへ配置するボスです。基礎ステータス、参加人数補正、部屋生成と報酬はMob/Dungeon masterと共通サービスが担当します。`IgnivorEncounterController` はドロップを定義しません。

`BossMechanicService` から同期5tickで進行します。`AGGRO` / `COMBAT`、生存実体、実行可能なAI・スキルを前提とし、通常攻撃とMobスキルはマスタで無効にします。全攻撃を共通 `DamageService` の `MAGIC` / `FIRE` / `SKILL` 経路へ委譲します。HP割合減算・即死判定・実ブロック変更・プレイヤー強制移動を行いません。

参加者はダンジョンの報酬対象解決、ボス挑戦の確定参加者、直接召喚時の標的所有者とパーティーの順で既存経路から取得します。同world、spawn地点から32m以内、生存、戦闘可能、非CREATIVE・非SPECTATORのプレイヤーだけを対象とします。

## 2. 会場と地形

部屋境界の公開APIに依存せず、spawn近傍の床と壁を四方向各最大64mまで、幅9mの断面（横方向−4・−2・0・2・4m）で走査します。支持床がない・危険床・高さ2/3mの壁・未ロードchunkで走査を止め、向かい合う走査端の中点を会場中心として求めます。最小の半幅から3mの余白を引き、半径最大27mの内接円を採用します。半径7.5m未満、中心に歩行床がない、走査距離64mに達した、向かい合う距離の和が64mを超えた場合は攻撃を開始しません。幅7mの回廊は幅9mの断面の端で壁を検知します。COLLAPSEDの低い瓦礫を部屋境界とは扱わず、安全円・経路と命中時の床／遮蔽検査で除外します。高い装飾や瓦礫によって走査が止まる場合は会場が縮小します。実ブロックを書き換えたりchunkを強制ロードしたりしません。

会場円に加え、同world、高度差3m以内、支持床・頭上2ブロック、中心からの壁遮蔽を確認します。予兆と命中はこの会場条件を共有します。会場外からのボスへの攻撃も共通戦闘経路で拒否し、会場外から安全に攻撃を続けられないようにします。会場を確定できない場合も攻撃を拒否します。

安全円は半径2.2mです。円盤を0.75m格子と24点の輪郭で調べ、実際の歩行床、頭上、会場内、中心との高さ差0.6m以内、壁を確認します。危険床はMAGMA_BLOCK・LAVA・FIRE・SOUL_FIRE・CAMPFIRE・SOUL_CAMPFIRE・CACTUS・SWEET_BERRY_BUSH・WITHER_ROSE・POWDER_SNOWです。安全地点間は0.5m間隔で支持床・両肩幅・段差・視線を確認します。

## 3. 通常ローテーション

開始時に位置・向き・形状を固定し、予兆中に標的を追尾しません。最初の対象近くに歩いて6m以内で移れる危険域外の床を確保した場合だけ予約します。一個体の発動予兆は一つです。

| 技 | 固定した命中形状 | 予兆 | 魔法攻撃倍率 |
|:--|:--|--:|--:|
| 降星の刻印 | 対象地表を中心とする半径4.2mの円 | 65tick | 0.78 |
| 溶岩の放射裂け目 | ボスから対象方向へ0度・±30度、会場半径の0.9倍・最大22m・半幅0.9mの3本 | 60tick | 0.68 |
| 火口の脈動 | ボス地表の半径5.5mの円 | 60tick | 0.72 |
| 灼熱の外環 | ボス地表の内半径10.5m・外半径は会場半径−1mと22mの小さい方の環 | 80tick | 0.72 |

この順番で繰り返します。各技は各プレイヤーへ一回だけ命中します。発動後は35tickの反撃時間、続いて15tickの予約間隔を置きます。反撃時間中は所有している専用行動ロックを保ち、既存のMob詠唱名表示へ冷却名と残り時間を渡します。予約間隔では通常AIの移動へ戻ります。

## 4. HP70%・35%の隕石儀式

HP70%と35%を観測した場合、それぞれ一回だけ同じ4波の儀式を順番に実行します。一撃で両境界を跨いでも、70%儀式と最後の反撃時間を終えてから35%儀式を開始します。通常技の途中で境界を跨いだ場合はその技を完了してから儀式を開始します。

初波の対象近傍へ第1安全円を置き、5.5mの辺を持つ三角形の第2・第3安全円へ順次移動します。直径4.4mの円が重ならず、同じ位置に留まって全波を回避できません。第1地点へ6m以内で歩いて到達できること、三つの円と地点間経路を確認できた場合だけ開始します。候補は対象位置・対象から2.5/4.5mの各8地点・会場中心・中心周囲8地点、三角形の向き12通りの有限探索です。配置不能なら20tick後に再試行し、未検証地点を代用しません。

各噴火は70tickの予兆と0.55倍ダメージを持ち、会場内の安全円外だけへ一回命中します。各波の間に20tickの反撃と15tickの予約間隔を置きます。第4波は第3安全円を維持し、100tickの完全な予兆後、1.60倍の大隕石を同じ安全円外へ適用します。安全円の外であっても会場外・壁越し・高度差3m超には命中しません。最後に100tickの反撃時間と15tickの予約間隔を持ちます。

波の発動前に進行番号を進め、命中・演出で例外が起きても発動済み波を重複しません。CC・拘束・参加者喪失では現在の予兆を中断し、完了段階と発動済み波を保持します。再開時は三つの安全円を再取得し、未発動波へ完全な予兆を与えます。

## 5. 見た目と負荷

外殻16片と周回岩8個はBLACKSTONE・MAGMA_BLOCKのBlockDisplayで表現します。5tickごとに位置・回転を更新し、5tick補間を使います。赤い予告標識は命中条件から抽出した最大40地点へ置き、緑の安全円の輪郭には16個のLIME_STAINED_GLASSを置きます。Displayは判定・遮蔽・衝突に使用しません。

通常メテオと最後の大隕石はMAGMA_BLOCK・BLACKSTONE・GILDED_BLACKSTONEを使う15個の落下本体です。着弾地点上空の読込済み空間を最大16mまで走査して出発高さを決め、最後の40tickで落下します。着弾5tick前に最終位置へ更新して表示補間と命中時刻を合わせます。

発動時は実際の命中面へ最大16個の溶岩柱・岩片を作り、20tickで回収します。追加ダメージは発生しません。同時Display上限は112個で、全て非永続・無重力・無敵です。参加者が存在しない場合は全表示を回収し、繰り返し表示を進めません。

赤い予兆は共通 `BOSS_ATTACK_WARNING`、安全円は緑 `BOSS_SAFE_AREA` と白い縦標識 `BOSS_SAFE_BEACON` です。命中判定と同じ形状から地表へ投影した最大96地点を波の開始時に準備し、10tick間隔で `ParticleDisplayService` の一括近傍閲覧者経路へ渡します。発動には既存メテオの火炎・爆発音を用います。詠唱名は既存Mobの動的スキル名表示契約を利用します。

## 6. 中断と回収

独自BukkitTaskを作らず、共通5tick処理だけで進行します。非戦闘、AI停止、スキル禁止、バインド拘束、参加者喪失、会場外へ出た実体は現在の予兆・外殻・噴出表示と所有ロックを解放します。`LEASHED` / `IDLE`、死亡、Mob破棄、無効実体、Mob一覧からの消失、Plugin停止では遭遇進行も破棄します。

重力・無敵・プレイヤー座標を変更しません。既存の専用行動や詠唱があるときに新しい技を開始せず、自分が取得した専用行動ロックと詠唱だけを解除します。Displayの回収失敗は個別記録し、残りの回収とロック解除を継続します。例外ログは `E_6525`（遭遇進行）、`E_6526`（一人の命中処理）、`E_6527`（一つのDisplay回収）を使用します。文言はlogger.propertiesを正本とします。

## 7. 検証境界

外環の危険帯幅は最大11.5mであり、帯の中央から内外へ5.75m移動すれば退避できます。

個別ボスのID・倍率・形状は恒久JUnitへ固定しません。コンパイル、リソース検証、設計書構造、テストトレーサビリティと差分レビューで検証します。実サーバー／クライアントでの視認性、難度、64m部屋の実生成地形、床素材、全波回避、HP境界の連続突破、CC再開、帰還・死亡時の全表示回収、統合版のDisplay表示、粒子OFF/VERY_LOWは実機検証対象です。
