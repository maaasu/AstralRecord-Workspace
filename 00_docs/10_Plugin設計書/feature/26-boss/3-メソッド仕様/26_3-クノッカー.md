# 廃坑の鐘守 クノッカー

## 1. 役割と導入

`mine_bell_knocker` はLv25の小さな坑夫型ボス。コーンウォールの坑道に伝わる [Knocker](https://minearchive.co.uk/culture/folklore/knockers/) の打音を着想に、危険を告げる三打と鐘の鎮静を戦闘にした。鐘守という人物像、三段階の戦闘、各技はゲーム独自の創作であり、最高神・神話の最強格を消費しない。

`KnockerEncounterController` を `BossMechanicService` の5 tick同期処理から呼ぶ。SkriptやMythicMobsへの依存はない。通常攻撃とMob skillの並行予約を持たず、全攻撃は一つのcastで直列に管理する。ダメージは既存 `DamageService` の `MELEE` / `NONE` / `SKILL` 経路を通り、独自HP・防御・回避・シールド・報酬処理を使う。

本番マスタは `/mob spawn mine_bell_knocker` で利用する。受付座標と実ワールドが未指定のため `challenge` をマスタへ固定しない。直接生成では標的の戦闘所有者とその現在のパーティーだけがギミック対象となり、HPはソロ値。BossChallengeへ配置する場合は既存の `challenge` と `BOSS_FIELD` を現地に合わせて設定し、固定参加者・人数補正・制限時間・死亡回数・フィールド破棄を既存サービスに任せる。新しい設定キーは追加しない。

推奨会場は中心から半径18m以上の平坦で連続した床、2ブロック以上の頭上空間、同一高さ±3m以内。半径6mの三方向に鐘を置ける床と通路を用意する。半径32mまで境界からの復帰を案内する。上階・別world・死亡中・見学者・クリエイティブ・スペクテイターはギミックに参加できない。

## 2. 数値と報酬

| 設定 | 値 |
|:--|--:|
| レベル / progression | 25 / 25 |
| HP / 攻撃 / 防御 | 104,000 / 2,826 / 2,604 |
| 命中 / 回避 | 95 / 3 |
| 移動速度 / ノックバック耐性 | 90 / 100 |
| 撃破EXP | 10,000 |
| 確定報酬 | 煤けた鐘片 `10a00096` ×1 |
| 素材売却額 | 1,000 |

HP・攻撃・防御は [[02-成長曲線]] のLv25通常Mob 13,000 / 2,355 / 2,264とボス倍率8 / 1.2 / 1.15を基にする。HP人数補正はBossChallenge/Dungeonの既存処理だけに任せ、Java側で重ね掛けしない。1～4人の挑戦ならHPは104,000 / 156,000 / 208,000 / 260,000。EXPと売却額は既存Lv20～21報酬からの初期設定であり、経済全体の実測結果ではない。確定した討伐証の個数を変えないため、このドロップだけ `luckAffected: false` とする。

## 3. 予兆とローテーション

| 技 | 予兆 | 危険領域 | 攻撃倍率 |
|:--|--:|:--|--:|
| 導入 | 60 tick | 無害。色と三打を案内 | 0 |
| 三打の掘削線 | 60 tick | 出現地点から固定方向、前方18m・後方0.5m、半幅1.65m | 0.8 |
| 返り響き | 30 tick | 掘削線と同じ位置・方向 | 0.8 |
| 落盤のしるし | 50 tick | 開始時の各参加者の足元、半径2.6m | 0.9 |
| 坑底の震動・内 | 45 tick | 中心から6m以内 | 0.9 |
| 坑底の震動・外 | 45 tick | 6mより外、18m以内 | 0.9 |
| 坑道崩落 | 80 tick | 中心を通る半幅2.4mの青い避難路以外、18m以内 | 1.1 |
| 坑道の境界 | 60 tick | 18mより外、32m以内 | 1.1 |

橙は危険、青は安全・操作対象、灰は18mの境界。色だけに頼らずBossBarの技名・方向指示と音を併用する。予兆中は照準と落盤位置を追尾しない。落盤が重なっても同じ波で同じ参加者へ一度だけ命中する。壁・高低差を確認して着弾させる。内輪と外輪は必ず順番に行い、安全地帯を移す。

第1幕（HP65%より上）は線→落盤→内外輪。第2幕は線と反響→落盤→内外輪→鐘。第3幕は線→反響→落盤→内輪→外輪→鐘の固定連続技。通常技列の後は20 tick、鐘成功後は80 tickの反撃時間と20 tickの間隔を置く。誰かが18m外にいると、現在のcastが終わった次の通常予約で境界帰還を優先する。帰還予兆の再使用は200 tick間隔とし、境界往復で通常技を止め続けられない。強制即死やプレイヤーの強制転送は使わない。

## 4. 鎮めの鐘とフェーズ

全員が18m外にいる間は、境界帰還以外の技順と幕の告知を進めず、再入場を待つ。

HP65%・30%で次の幕へ移る鐘儀式を各一回処理する。一撃で両方を跨いでも、生存している限り一幕ずつ処理する。HP全回復はしない。

半径6mの三角形に三つの非永続 `BlockDisplay` の鐘を生成し、操作対象だけを発光させる。青い輪（半径1.8m）の中で一人が連続20 tickスニークすると鎮まる。輪の外へ出る、スニークを離す、死亡・切断・対象外化すると保持を破棄する。複数人の保持時間は合算しない。

制限240 tick。開始時の有効な会場内参加者が1～2人なら2回、3人以上なら3回、光る鐘を順番に鎮める。儀式中の被ダメージ倍率は0.35。成功するとその倍率を解除し、80 tickだけ被ダメージ1.5倍で行動を停止する。共有倍率の実時間期限はcast中に更新し、解除はcastのtick時計に合わせる。時間切れでも次の幕へ進み、最後に光っていた鐘を向く青い避難路を80 tick予告してから崩落する。床不備で三つの鐘を置けない場合は生成済み表示を回収し、その儀式を無害に終えて進行を継続する。

## 5. 対象選別と寿命

`BossChallengeService.participantIdsForBossMob` は `IN_PROGRESS` の確定参加者IDを不変集合で返す。未開始・終了中・挑戦外では空集合を返す。ギミックはこの集合に対し `DamageService.isMobCombatTarget`、同一world、ゲームモード、距離、高さを再確認する。報酬対象のAPIを攻撃対象に流用しない。

クノッカーへの被弾も `DamageService` から `BossMechanicService.canApplyCombatDamage` へ委譲し、有効な場内参加者の攻撃に限定する。ペットも戦闘所有者の現在位置を確認する。18m外、出現高さ±3m外、別world、参加者外、死亡・見学・クリエイティブ、所有者不明の環境攻撃は拒否する。直接召喚の未接敵時だけ、条件を満たすプレイヤーの初撃を許可する。他のMobの判定は変えない。

CC・バインド・標的喪失では現在のcast、BossBar、鐘、専用倍率を取り消し、完了済みの幕だけを保持する。再開時は完全な予兆を行う。`IDLE` / `LEASHED`、死亡、Mob破棄、一覧からの消失、Plugin停止では個体の全状態を回収する。専用の遅延taskは持たず、UUIDと現在castの同一性で古い着弾を防ぐ。場外へ押し出されたボスは共通Mob位置同期で出現地点へ戻し、予兆をやり直す。

粒子は共通表示サービス経由で10 tickごと、危険最大192点・安全最大48点、境界48点を20 tickごとに送る。同じ中心の点群ごとに閲覧者を一括解決する。予兆粒子count4により `VERY_LOW` でも点を残す。粒子OFFの設定は尊重する。鐘は最大3個、実体ブロックは変更しない。操作案内は `P_6580`～`P_6592`、進行失敗は `E_6507` で管理する。
