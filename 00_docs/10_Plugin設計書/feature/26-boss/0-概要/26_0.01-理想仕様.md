# ボス機能 理想仕様

## 目的

ボス機能は、`MobCategory.BOSS` の Mob マスタを通常 Mob と同じ戦闘基盤に載せつつ、挑戦受付、参加者固定、専用インスタンスワールド、制限時間、復帰、結果表示、報酬確定、運用停止をボス挑戦単位で管理する機能である。

通常 Mob と共有するものは、表示エンティティ、AI、ダメージ計算、ドロップ抽選、経験値付与、図鑑記録とする。ボス機能が上書きするものは、参加者、入場、戦闘開始、死亡/復帰、報酬対象、フィールド破棄、結果表示、運用ログである。

## スコープ

| 区分 | 理想仕様 |
|---|---|
| 挑戦受付 | 入口範囲でのスニーク、将来の GUI/コマンド受付、ソロ/パーティー受付 |
| 参加者 | 受付時点のオンライン参加者を固定し、途中参加と再入場は原則不可 |
| フィールド | `WorldType.BOSS_FIELD` かつ `instanceEnabled=true` のテンプレートから挑戦ごとにコピーして生成 |
| 戦闘 | 転送成功後にボスを spawn し、参加者数に応じて HP/攻撃を補正 |
| 死亡/復帰 | 参加者死亡を挑戦状態として管理し、復帰可能条件と全滅条件を明確に分ける |
| 報酬 | 討伐成功時のみ、討伐時に同一ボスフィールドへ残っている参加者へ確定付与 |
| 結果表示 | 成功/失敗理由、経過時間、総ダメージ、個人別ダメージ、死亡回数を表示 |
| 運用 | `/boss list`、`/boss stop`、挑戦リーダー用 `/boss cancel`、ボス出現地点の中止操作装置、残存フィールド掃除、ログ/メッセージによる追跡 |

## 非スコープ

- ボス固有フェーズや特殊ギミックの個別内容は、各ボスマスタまたはボス固有クラスの仕様で定義する。
- 報酬の重み、アイテム性能、ドロップ率そのものは filebase の mob / loot / item 側で定義する。
- DB 永続化が必要な戦績ランキングは将来拡張とし、現段階では挑戦セッション内集計を正とする。

## 現実装との差分

| 項目 | 現在 | 理想仕様 |
|---|---|---|
| フィールド検証 | `WorldMasterData` 存在確認中心 | `BOSS_FIELD` と `instanceEnabled=true` を必須検証 |
| テンプレート欠損 | 空ワールド生成の余地あり | 欠損/不正は挑戦失敗 |
| 転送 | Future を待たずに spawn する余地あり | 必須参加者全員の転送成功後に spawn |
| スケーリング | HP 中心 | HP と攻撃倍率を両方適用 |
| 報酬 | 通常 Mob 死亡処理に依存 | ボス挑戦参加者だけを対象に確定付与 |
| 復帰 | 未確定 | 死亡回数、復帰待機、全滅判定を挑戦で管理 |
| UI | メッセージと TextDisplay 中心 | Sidebar に挑戦情報を表示し、ボス出現地点の BlockDisplay＋Interaction から中止 GUI を開く |
