# 26_0.00-概要

## 1. 目的

`boss` feature は `MobCategory.BOSS` の Mob を通常の戦闘・報酬基盤へ載せながら、挑戦単位の受付、参加者固定、一時ワールド、制限時間、死亡・復帰、結果表示、運用停止を管理する。

## 2. 対象範囲

- ボス入口円と案内 TextDisplay の表示
- `SNEAK` 入力によるソロ／パーティー挑戦受付
- ハブ転送後の参加者再確認
- `BOSS_FIELD` テンプレートの非同期コピー、直列ロード、必要チャンク準備
- 実参加人数に応じたボス HP・攻撃倍率補正
- 制限時間、参加者不在、共有死亡上限、管理操作による終了
- 固定参加者の有効ダメージ・死亡回数集計
- 討伐時の固定受取人向け通常 Mob 報酬処理
- Sidebar、討伐後 TextDisplay、中止 controller／GUI
- 退場、ワールド破棄、起動時の残存フィールド掃除

## 3. 対象外

- ボス固有フェーズ、攻撃パターン、専用ギミック
- DB へ永続化する討伐履歴・ランキング
- 挑戦開始後の自動途中参加・自動再入場
- `/boss cleanup` による手動掃除

未実装または方針未確定の要件は [[26_9.00-未決事項]] に集約する。

## 4. 実装構成

| 構成 | 主な責務 |
|---|---|
| `BossChallengeService` | 受付、参加者確定、戦闘開始、死亡、集計、報酬対象、終了、中止、表示情報 |
| `BossFieldInstanceService` | コピー、world ロード、chunk ticket、アンロード、非同期削除、起動時掃除 |
| `BossEntryEventHandler` | `SNEAK` の入口候補提供 |
| `BossChallengeCancelEventHandler` | controller の右クリック／ドロップ候補と中止 GUI click |
| `BossPlayerEventHandler` | logout 後の参加者不在確認 |
| `BossCommand` | `/boss instances|list|stop|cancel` |
| `BossChallengeCancelGui` | リーダー用の挑戦中止確認 GUI |
| `BossChallengeCancelController` | ボス地点の BlockDisplay、Interaction、案内 TextDisplay |

独立した待機フラグ、専用 cache class、専用 tick task class は持たない。挑戦とフィールドの一時状態は各 service 内で保持する。

## 5. 正本と境界

| データ／処理 | 正本 |
|---|---|
| ボス戦闘定義、`challenge`、drops | ボス Mob master と `MobTemplate` |
| ハブ ID | `config.yml` の `boss.hubWorldId` |
| フィールド種別、コピー元／先 | `WorldMasterData` |
| 有効ダメージ、死亡検出 | `DamageService` |
| Mob 報酬抽選・付与 | `MobCombatService` と関連する drop service |
| HP / MP / EN / Shield 全回復 | `PlayerDeathService` 経由の `StatusService` |
| 挑戦中 Sidebar | hud feature |
