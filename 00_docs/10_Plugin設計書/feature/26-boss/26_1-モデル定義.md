# 26_1-モデル定義

## 1. ボス挑戦設定

物理名: `BossChallengeConfig`

`MobCategory.BOSS` の `MobTemplate.challenge` として保持する。`fieldWorldId` が欠落または空の場合、`MobRepository` は challenge 自体を `null` とする。

| 項目 | 型 | 読込既定値 | record の補正 | 説明 |
|---|---|---:|---:|---|
| `fieldWorldId` | `String` | 必須 | - | `BOSS_FIELD` かつ instance 有効な `WorldMasterData.id` |
| `entryLocation` | `BossLocation` | 座標既定値を使用 | - | 挑戦受付地点。world ID 必須 |
| `entryRadius` | `double` | `3.0` | 最小 `0.5` | 入口判定半径 |
| `playerSpawnLocation` | `BossLocation` | 座標既定値を使用 | - | 一時 world 内の参加者転送先 |
| `bossSpawnLocation` | `BossLocation` | 座標既定値を使用 | - | 一時 world 内のボス生成地点 |
| `partyMin` | `int` | `1` | 最小 `1` | 開始に必要な実参加人数 |
| `partyMax` | `int` | `6` | `partyMin` 以上 | 受付時点の現在パーティーメンバー数の上限 |
| `timeLimitSeconds` | `long` | `600` | 最小 `30` | `IN_PROGRESS` 開始からの制限時間 |
| `deathLimit` | `int` | `5` | 最小 `0` | パーティー共有の死亡許容回数。設定回数までは復帰可能で、次の死亡で終了 |
| `reviveDelaySeconds` | `long` | `5` | 最小 `1` | 許容回数内の死亡から復帰までの秒数 |
| `scaling` | `BossScalingConfig` | `EMPTY` | `null` は `EMPTY` | BossChallenge 固有の与ダメージ倍率設定 |

## 2. ボス位置

物理名: `BossLocation`

| 項目 | 型 | 欠落時 | 説明 |
|---|---|---:|---|
| `worldId` | `String?` | `null` | 入口では WorldMasterData ID または Bukkit world 名。フィールド内座標では使用しない |
| `x` / `y` / `z` | `double` | `0.5 / 64.0 / 0.5` | 座標 |
| `yaw` / `pitch` | `float` | `0.0 / 0.0` | 向き |

`toLocation(World)` は渡された Bukkit world と保持座標から `Location` を生成する。

## 3. BOSS Mob の参加人数補正

BossChallenge のフィールド、または Dungeon 内で `MobCategory.BOSS` を生成するとき、同じ固定補正を適用する（現行の Dungeon 定義では BOSS 部屋）。補正に使う参加者数は、BossChallenge では入場直前に確定した `participantIds`、Dungeon では開始時に確定した `originalParticipants` の件数とする。

```text
extraPlayers = max(0, participantCount - 1)
healthMultiplier = 1 + extraPlayers * 0.50
shieldMultiplier = 1 + extraPlayers * 0.30
```

HP 倍率は `MobInstance.maxHealth` と現在 HP に適用し、シールド倍率は初期 `currentShield`／`shieldDisplayCapacity` に適用する。シールド再充填量にも同じ倍率を適用し、フェーズ移行時は現在の表示容量まで再展開する。

`BossChallengeConfig.scaling` は既存の BossChallenge 固有の与ダメージ倍率設定であり、共通 HP／シールド補正の有効・無効を切り替えない。共通補正は `MobCategory.BOSS` 以外へ適用しない。

## 4. ボス挑戦インスタンス

物理名: `BossChallengeInstance`

| 項目 | 型 | 説明 |
|---|---|---|
| `challengeId` | `UUID` | 挑戦 ID |
| `partyKey` | `String` | `solo:<playerUuid>` または `party:<partyId>` |
| `initiatorId` | `UUID` | 受付プレイヤー |
| `bossTemplate` | `MobTemplate` | 受付時のボス template |
| `config` | `BossChallengeConfig` | 受付時の challenge 設定 |
| `expectedParticipantIds` | `List<UUID>` | 待機中に同期する現在パーティーメンバー。immutable copy |
| `waitingAbsentParticipantIds` | `Set<UUID>` | ハブ初期スポーンで待機離脱した現在メンバー。再到着まで列参加不可。本人は待機 Sidebar と拠点帰還制限の対象外 |
| `participantIds` | `List<UUID>` | 入場直前に確定した実参加者。初期値は空 |
| `participantsConfirmed` | `boolean` | 実参加者確定済みか |
| `createdAtMs` | `long` | 挑戦作成時刻 |
| `state` | `BossChallengeState` | 現在状態 |
| `field` | `BossFieldInstance?` | 準備済み一時 world |
| `bossMobInstanceId` | `UUID?` | 生成したボス Mob instance ID |
| `startedAtMs` | `long` | 戦闘開始時刻。未開始は `0` |
| `damageByPlayerId` | `Map<UUID, Double>` | 参加者別有効ダメージ |
| `deathsByPlayerId` | `Map<UUID, Integer>` | 参加者別死亡回数 |
| `deathCount` | `int` | パーティー共有死亡回数 |
| `resultWaitEndsAtMs` | `long` | 討伐結果表示の終了時刻 |
| `resultWaitTask` | `BukkitTask?` | 15秒待機後の終了 task |
| `resultDisplay` | `ManagedTextDisplay?` | 討伐結果 TextDisplay |
| `bossBar` | `BossBar?` | 戦闘中に参加者へ表示するボス HP BossBar |
| `startCountdownTask` | `BukkitTask?` | フィールド転送後、ボス生成前の10秒カウントダウン task |
| `reservedCreationSlot` | `boolean` | 現在パーティーのいずれかが `AstPlayer.user.permission >= UserPermission.DONOR(5)` で、寄付者予約枠を要求したか。`ADMIN(99)` も対象 |
| `creationQueueTicketId` | `UUID?` | `InstanceCreationQueue` の作成枠チケット ID |

`damageByPlayerId` と `deathsByPlayerId` は `ConcurrentHashMap`、取得 API は immutable snapshot を返す。

## 5. ボス挑戦状態

物理名: `BossChallengeState`

| 値 | 意味 |
|---|---|
| `PREPARING` | ハブ転送、作成枠待機、コピー、ロード、chunk 準備、フィールド転送、10秒開始カウントダウン中 |
| `IN_PROGRESS` | ボス生成済み、制限時間監視中 |
| `RESULT_WAITING` | 討伐成功後の結果表示15秒待機中 |
| `ENDING` | 退場・フィールド破棄の完了待ち |
| `ENDED` | 終了済み。通常は直後に cache から削除する |

## 6. 終了理由

物理名: `BossChallengeEndReason`

| 値 | 成功 | 表示名 |
|---|:---:|---|
| `DEFEATED` | ○ | 討伐完了 |
| `TIME_LIMIT` | - | 制限時間超過 |
| `DEATH_LIMIT` | - | 全滅回数上限 |
| `NO_PARTICIPANTS` | - | 参加者不在 |
| `PARTICIPANT_REQUIREMENT_NOT_MET` | - | 参加条件未達 |
| `FIELD_PREPARE_FAILED` | - | フィールド準備失敗 |
| `TRANSFER_FAILED` | - | 転送失敗 |
| `BOSS_SPAWN_FAILED` | - | ボス出現失敗 |
| `ADMIN_STOP` | - | 管理者による停止 |
| `PLUGIN_SHUTDOWN` | - | プラグイン停止 |

## 7. ボスフィールドインスタンス

物理名: `BossFieldInstance`

| 項目 | 型 | 説明 |
|---|---|---|
| `challengeId` | `UUID` | 所有挑戦 ID |
| `worldName` | `String` | Bukkit world 名 |
| `worldFolder` | `Path` | コピー先フォルダー |
| `world` | `World` | ロード済み Bukkit world |

フィールド固有の状態 enum は持たず、準備 Future と `BossChallengeState` で進行を表す。

## 8. Sidebar 表示モデル

物理名: `BossChallengeSidebarInfo`

`bossDisplayName`、非負へ丸めた `bossLevel`、共有死亡回数／上限、経過秒／制限秒、immutable な参加者表示名一覧を保持する。`PREPARING` または `IN_PROGRESS` の参加者に対してだけ生成する。

## 9. 補助モデル

- `BossChallengeService.BossEntryHit`: 最寄り入口の `bossId` と実距離。
- `BossChallengeService.PlayerCancelResult`: `STOPPED` / `NO_CHALLENGE` / `NOT_LEADER`。
