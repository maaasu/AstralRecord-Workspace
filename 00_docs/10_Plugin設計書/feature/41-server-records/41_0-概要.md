# 41_0-概要

## 目的と表示

サーバーレコードは、通常プレイの保存済み記録から集計した上位プレイヤーを共有TextDisplayへ表示する。種類はプレイヤーレベル、所持ゴールド、プレイ時間、ダンジョン攻略回数、ボス討伐回数、モブ討伐回数、踏破ダンジョン種類数、完了クエスト種類数の8種類。

API `GET /api/server-records?limit=10` を非同期で一括取得し、応答をメインスレッドで配置済み表示へ反映する。同じ種別を複数配置してもHTTP要求を増やさない。要求中の重複起動を抑止し、失敗時は最後の成功順位と集計時刻を保持して再試行表示を付ける。停止後の応答は反映しない。

金・銀・銅の上位3人、ゴールドと水色の見出し、暗い背景、文字の影、最大光量、値の桁区切りを用いる。表示は閲覧者へ向く。順位エンティティは非永続とし、位置だけを永続化してロード済みチャンクに再生成する。チャンク解放時は破棄し、表示のために未使用チャンクを常時保持しない。

## 設定とコマンド

`config.yml` の `serverRecord.refreshIntervalSeconds` は既定30秒。未設定でも動作し、5秒未満または86400秒超は30秒へ補正する。`serverRecord.limit` は既定10人、1～20へ補正する。プレイ時間の保存要求もこの間隔で起動する。DB反映前のローカル状態はランキングに含まれず、保存確定後の取得で表示される。

| コマンド | 権限・動作 |
|---|---|
| `/serverrecord` | 拠点から閲覧ワールドへ入場 |
| `/serverrecord back` | 閲覧ワールドから訪問前の位置へ帰還 |
| `/serverrecord <ranking>` | 管理者が現在位置へ自動IDで表示を配置 |
| `/serverrecord place <ranking> [id]` | 管理者が現在位置へ配置。同一IDは置換 |
| `/serverrecord remove <id>` | 管理者が配置を削除 |
| `/serverrecord list` | 管理者が配置ID・種別を確認 |
| `/serverrecord refresh` | 管理者が一括更新を要求 |
| `/serverrecord help` | 操作案内 |

`ranking` の補完候補は `level`, `gold`, `play_time`, `dungeon_clears`, `boss_defeats`, `mob_defeats`, `dungeon_types`, `quest_types`。一般プレイヤーには `back` と `help` を補完する。配置の保存は `plugins/AstralRecord/server_records.yml`。通信結果は保存しない。

## 閲覧ワールドと帰還

ワールドIDは `server_record`、種別は共有空間の `BASE`、インスタンスは使用しない。元ワールドを `plugins/AstralRecord/worlds/base/server_record` に用意して既存ワールド読込経路でロードする。初期スポーンは `(-46, 199, -82)`、yaw `90`、pitch `0`。NPCマスタ `server_record_guide` は指定されたPLAYERスキンを使用し、右クリックで `serverrecord` を実行する。管理者が `/mob npc place server_record_guide` で配置する。

別ワールドからの入場直前の位置をプレイヤーUUIDごとに `server_record_returns.yml` へ保存する。帰還時は座標・yaw・pitchを復元する。向き保持の共通テレポート規則に対し、指定入場方向と保存方向を明示する例外として共通サービスの専用経路を使用する。

閲覧ワールドの `SCULK` に足元または体の側面が触れた場合、次tickに帰還する。向きだけのイベントや他ワールドは走査しない。進行中と失敗後1秒の重複転送を抑止する。保存位置は再接続・再起動で維持し、帰還成功後に削除する。元ワールドが未ロードなら既存マスターのパスから読み込む。元の位置を利用できない場合は設定済み初期スポーンへ退避する。破損した配置・帰還YAMLは上書きしない。

## 依存境界と集計

表示基盤は共有 `DisplayTextService`、ワールド移動は `WorldService`、HTTPは共有 `ApiRequestUtil`、集計と権限除外はAPIが所有する。APIは通常モードの有効アカウントをユーザー単位で集約し、DB権限とネットワーク最高権限を持つプレイヤーをオフラインも含め除外する。

プレイ時間は導入後の通常プレイ区間を保存する。導入前Bukkit統計をアカウント別の時間に換算しない。計測・保存・ACKの正本は [プレイヤー保存](../03-player/3-メソッド仕様/03_3-保存.md)。API集計契約は `00_docs/20_API設計書/feature/41-server-records/`。
