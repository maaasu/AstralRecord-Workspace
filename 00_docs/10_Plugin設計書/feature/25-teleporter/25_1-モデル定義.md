# 25_1-モデル定義

## 1. ウェイストーン定義

物理名: `WaystoneDefinition`

Plugin data folder の `waystones.yml` から読み込むウェイストーンの静的定義。

| 項目 | 型 | 必須 | 説明 |
|:--|:--|:--|:--|
| `id` | `String` | 必須 | 内部ウェイストーン ID。Plugin が生成し、API / DB の `waystoneId` と一致させる |
| `name` | `String` | 必須 | 表示名。コマンド引数のウェイストーン名称 |
| `worldName` | `String` | 必須 | Bukkit ワールド名 |
| `x` | `double` | 必須 | テレポート先 X |
| `y` | `double` | 必須 | テレポート先 Y |
| `z` | `double` | 必須 | テレポート先 Z |
| `yaw` | `float` | 必須 | テレポート後の向き |
| `pitch` | `float` | 必須 | テレポート後の視線角度 |
| `lockEnabled` | `boolean` | 必須 | ロック機能の有無 |
| `unlockGold` | `long` | 必須 | 解除に必要なゴールド数。`lockEnabled=false` の場合は `0` として扱う |
| `createdAt` | `Instant` | 必須 | ISO-8601 形式で保存する作成日時 |
| `createdBy` | `String` | 必須 | 作成した管理者の user UUID 文字列。既定値は `system` |

制約:

- コマンド作成時の `id` は `ws-<UTC yyyyMMddHHmmss>-<name slug>` を基底とし、重複時は `-2` 以降の連番を付ける。最大長は 100 文字とする。
- コマンドは空の `name` と負数の `unlockGold` を拒否する。
- `lockEnabled=false` の場合、保存する `unlockGold` は `0` とする。
- `lockEnabled=true` かつ `unlockGold=0` は無料解除のロックとして扱う。
- 現行実装は同一座標の重複を検証しないため、管理時の注意点および [[25_9-未決事項]] として扱う。

## 2. waystones.yml

所有クラス: `WaystoneDefinitionRepository`
物理名: `loadAll`, `saveAll`

専用 DTO は置かず、`WaystoneDefinitionRepository` が `YamlConfiguration` と `Map` を使って次の形式を直接読み書きする。

```yaml
version: 1
waystones:
  - id: "ws_20260623_0001"
    name: "始まりの石碑"
    worldName: "world"
    x: 100.5
    y: 64.0
    z: 200.5
    yaw: 180.0
    pitch: 0.0
    lockEnabled: true
    unlockGold: 500
    createdAt: "2026-06-23T00:00:00+09:00"
    createdBy: "00000000-0000-0000-0000-000000000000"
```

`version` は YAML 形式の schema version であり、現行の初期値は `1` とする。
読み込み時に未知の `version` はエラー扱いにせず、対応できない場合はロード失敗として管理者向けログへ出す。

## 3. ウェイストーン解除状態

物理名: `WaystoneUnlockState`

選択中アカウントが解除済みのウェイストーン ID セット。
API `GET /api/account-waystone/{accountId}` の `unlockedWaystoneIds` をもとに作る。

| 項目 | 型 | 説明 |
|:--|:--|:--|
| `accountId` | `UUID` | 選択中アカウント ID |
| `unlockedWaystoneIds` | `Set<String>` | DB に登録済みの解除済み ID |

解除済み判定:

1. `WaystoneDefinition.lockEnabled=false` の場合は常に解除済み。
2. `lockEnabled=true` の場合は `unlockedWaystoneIds` に `id` が含まれると解除済み。
3. API 取得に失敗して状態が不明な場合はロック中として扱い、GUI 操作時に再取得を試みる。

## 4. ウェイストーン packet 表示要素

物理名: `WaystonePacketDisplay.PacketEntity`

`WaystonePacketView` はプレイヤー UUID ごとに `List<WaystonePacketDisplay.PacketEntity>` を保持する。各要素は packet-only Display entity の ID、UUID、種別、座標、metadata を内包し、対象プレイヤーへの spawn と destroy を担当する。

現行同期は既存要素をすべて destroy してから、同一ワールド内の全ウェイストーンを現在の解除状態で再生成する。距離による除外や metadata だけの差分更新は行わない。

## 5. テレポーター GUI 表示項目

物理名: `TeleporterGui.Entry`

| 項目 | 型 | 説明 |
|:--|:--|:--|
| `definition` | `WaystoneDefinition` | 表示対象ウェイストーン定義 |
| `unlocked` | `boolean` | GUI 表示者にとって解除済みか |

表示順:

1. 解除済みウェイストーンを表示名昇順で並べる。
2. 未解除ウェイストーンを表示名昇順で後続に並べる。
3. GUI を開いた起点ウェイストーンは一覧から除外する。
4. `worldName` が起点ウェイストーンと一致しないものは一覧から除外する。

### テレポーター GUI holder

物理名: `TeleporterGui.Holder`

| 項目 | 型 | 説明 |
|:--|:--|:--|
| `sourceWaystoneId` | `String` | 起点ウェイストーン ID |
| `pageIndex` | `int` | 0 始まりの表示ページ |
| `visibleWaystoneIds` | `List<String>` | 現在ページの slot 順に並べたウェイストーン ID |

`HotbarShortcutGuiHolder` を実装し、共通ホットバーショートカットの閉じる操作とインベントリ切替を利用する。

## 6. クリック判定領域

物理名: `WaystoneHitBoxResolver.WaystoneHit`

packet-onlyのBlockDisplay / TextDisplayはサーバー側の実体当たり判定を持たないため、[[28_1-モデル定義]].プレイヤー入力コンテキスト の共通ray snapshotとウェイストーン座標を使って対象形状への入口命中点を解決する。遮蔽距離より遠いhitboxは候補にせず、同一tierの候補間では入口命中点までの`hitDistance`を比較する。

| 項目 | 値 |
|:--|:--|
| 判定中心 | `WaystoneDefinition.centerLocation()` |
| 形状 | 半径 `0.85` ブロックの球 |
| 最大距離 | `5.0` ブロック |

判定対象は同一ワールド内のウェイストーンのみとする。
