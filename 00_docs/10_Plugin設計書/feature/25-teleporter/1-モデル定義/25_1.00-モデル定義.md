# テレポーターモデル定義

## 1. ウェイストーン定義

物理名: `WaystoneDefinition`

Plugin data folder の `waystones.yml` から読み込むウェイストーンの静的定義。

| 項目 | 型 | 必須 | 説明 |
|:--|:--|:--|:--|
| `id` | `String` | 必須 | 内部ウェイストーン ID。Plugin が生成し、API / DB の `waystoneId` と一致させる |
| `name` | `String` | 必須 | 表示名。コマンド引数のウェイストーン名称 |
| `worldName` | `String` | 必須 | Bukkit ワールド名 |
| `x` | `double` | 必須 | テレポート先 X |
| `y` | `double` | 必須 | テレポート先 Y |
| `z` | `double` | 必須 | テレポート先 Z |
| `yaw` | `float` | 必須 | テレポート後の向き |
| `pitch` | `float` | 必須 | テレポート後の視線角度 |
| `lockEnabled` | `boolean` | 必須 | ロック機能の有無 |
| `unlockGold` | `long` | 必須 | 解除に必要なゴールド数。`lockEnabled=false` の場合は `0` として扱う |
| `createdAt` | `String` | 必須 | ISO-8601 形式の作成日時 |
| `createdBy` | `UUID` | 必須 | 作成した管理者の user UUID |

制約:

- `id` は半角英数字、アンダースコア、ハイフンのみ許可する。
- `name` は空文字不可とする。
- `unlockGold` は `0` 以上とする。
- `lockEnabled=true` かつ `unlockGold=0` は、無料解除のロックとして扱う。
- 同一 `worldName` 内の同一ブロック座標に複数ウェイストーンを登録してはならない。

## 2. waystones.yml

物理名: `WaystoneYamlDocument`

```yaml
version: 1
waystones:
  - id: "ws_20260623_0001"
    name: "始まりの石碑"
    worldName: "world"
    x: 100.5
    y: 64.0
    z: 200.5
    yaw: 180.0
    pitch: 0.0
    lockEnabled: true
    unlockGold: 500
    createdAt: "2026-06-23T00:00:00+09:00"
    createdBy: "00000000-0000-0000-0000-000000000000"
```

`version` は YAML 形式の将来拡張用で、初期値は `1` とする。
読み込み時に未知の `version` はエラー扱いにせず、対応できない場合はロード失敗として管理者向けログへ出す。

## 3. ウェイストーン解除状態

物理名: `WaystoneUnlockState`

選択中アカウントが解除済みのウェイストーン ID セット。
API `GET /api/account-waystone/{accountId}` の `unlockedWaystoneIds` をもとに作る。

| 項目 | 型 | 説明 |
|:--|:--|:--|
| `accountId` | `UUID` | 選択中アカウント ID |
| `unlockedWaystoneIds` | `Set<String>` | DB に登録済みの解除済み ID |
| `loadedAt` | `Instant` | Plugin キャッシュへ反映した日時 |

解除済み判定:

1. `WaystoneDefinition.lockEnabled=false` の場合は常に解除済み。
2. `lockEnabled=true` の場合は `unlockedWaystoneIds` に `id` が含まれると解除済み。
3. API 取得に失敗して状態が不明な場合はロック中として扱い、GUI 操作時に再取得を試みる。

## 4. ウェイストーン表示状態

物理名: `WaystoneViewState`

プレイヤーごとに packet 表示するための表示状態。

| 項目 | 型 | 説明 |
|:--|:--|:--|
| `playerUuid` | `UUID` | 表示対象プレイヤー |
| `waystoneId` | `String` | 表示対象ウェイストーン ID |
| `displayState` | `WaystoneDisplayState` | `UNLOCKED` / `LOCKED` |
| `entityIds` | `List<Integer>` | packet-only display entity ID |
| `lastSentAt` | `Instant` | 最終送信日時 |

### ウェイストーン表示状態区分

物理名: `WaystoneDisplayState`

| 値 | 説明 |
|:--|:--|
| `UNLOCKED` | 解除済みまたは常時開放 |
| `LOCKED` | ロック中 |

## 5. テレポーター GUI 表示項目

物理名: `TeleporterGuiEntry`

| 項目 | 型 | 説明 |
|:--|:--|:--|
| `waystoneId` | `String` | 対象ウェイストーン ID |
| `name` | `String` | 表示名 |
| `worldName` | `String` | 対象ワールド |
| `unlocked` | `boolean` | GUI 表示者にとって解除済みか |
| `unlockGold` | `long` | 未解除時に表示する解除コスト |
| `targetLocation` | `Location` | 解除済みクリック時のテレポート先 |

表示順:

1. 解除済みウェイストーンを表示名昇順で並べる。
2. 未解除ウェイストーンを表示名昇順で後続に並べる。
3. GUI を開いた起点ウェイストーンは一覧から除外する。
4. `worldName` が起点ウェイストーンと一致しないものは一覧から除外する。

## 6. クリック判定領域

物理名: `WaystoneHitBox`

packet-onlyのBlockDisplay / TextDisplayはサーバー側の実体当たり判定を持たないため、[[28_1.00-モデル定義]].プレイヤー入力コンテキスト の共通ray snapshotとウェイストーン座標を使って対象形状への入口命中点を解決する。遮蔽距離より遠いhitboxは候補にせず、同一tierの候補間では入口命中点までの`hitDistance`を比較する。

| 項目 | 値 |
|:--|:--|
| 判定中心 | `WaystoneDefinition` のブロック中心 |
| 水平半径 | `0.9` ブロック |
| 高さ | `2.4` ブロック |
| 最大距離 | `4.0` ブロック |

判定対象は同一ワールド内のウェイストーンのみとする。
