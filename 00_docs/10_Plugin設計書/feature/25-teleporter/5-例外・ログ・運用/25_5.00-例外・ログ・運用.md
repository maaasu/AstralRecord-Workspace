# テレポーター例外・ログ・運用

## 1. プレイヤー向けメッセージ

| ID | テンプレート | 用途 |
|:--|:--|:--|
| `PlayerMsgId.P_5950` | `ウェイストーンを登録しました: {0} (id={1})` | 管理者配置成功 |
| `PlayerMsgId.P_5951` | `ウェイストーンを削除しました: {0}` | 管理者削除成功 |
| `PlayerMsgId.P_5952` | `ウェイストーン: {0}` | 管理者一覧表示 |
| `PlayerMsgId.P_5953` | `ウェイストーンが見つかりません: {0}` | 指定 ID 不存在 |
| `PlayerMsgId.P_5954` | `ウェイストーン定義を再読み込みしました: {0}件` | reload 成功 |
| `PlayerMsgId.P_5955` | `ウェイストーン解除には {0} ゴールド必要です。` | ゴールド不足 |
| `PlayerMsgId.P_5956` | `ウェイストーンを解除しました: {0}` | ロック解除成功 |
| `PlayerMsgId.P_5957` | `ウェイストーンへ移動しました: {0}` | テレポート成功 |
| `PlayerMsgId.P_5958` | `このウェイストーンは未解除です。現地のウェイストーンを右クリックして解除してください。` | GUI の未解除項目クリック |
| `PlayerMsgId.P_5959` | `ウェイストーンへ移動できませんでした: {0}` | テレポート失敗 |

実装時は `PlayerMessageService` を使用し、`Player#sendMessage` を直接呼ばない。

## 2. ログ

| ID | レベル | テンプレート | 用途 |
|:--|:--|:--|:--|
| `LogId.I_5950` | INFO | `ウェイストーン定義をロードしました: %d件` | 起動時 / reload 成功 |
| `LogId.E_5950` | ERROR | `テレポータークリック処理に失敗しました: player=%s, waystoneId=%s` | ワールドクリック処理例外 |
| `LogId.E_5951` | ERROR | `テレポーターGUIクリック処理に失敗しました: %s` | GUI クリック処理例外 |
| `LogId.E_5952` | ERROR | `ウェイストーン解除失敗後の返金に失敗しました: player=%s, waystoneId=%s, gold=%d` | ゴールド返金失敗 |
| `LogId.E_5953` | ERROR | `waystones.yml の保存に失敗しました: %s` | YAML 保存失敗 |
| `LogId.E_5954` | ERROR | `account-waystone API の呼び出しに失敗しました: %s` | 解除状態 API 失敗 |

実装時は `LogId` と `logger.properties` を同時に追加する。

## 3. エラー時の挙動

### waystones.yml 読み込み失敗

- 起動時に読み込み失敗した場合、テレポーター機能は無効化する。
- 他 feature の起動は妨げない。
- 管理者向けログに YAML パスと例外内容を記録する。

### account-waystone API 取得失敗

- GUI 表示時は再取得を試みる。
- 再取得にも失敗した場合、ロック有効ウェイストーンは未解除扱いで表示する。
- 常時開放ウェイストーンは API 取得失敗時も利用可能とする。

### 解除登録失敗

- ゴールド消費済みの場合は同額返金を試みる。
- 返金成功時は解除失敗メッセージを送信し、解除状態は更新しない。
- 返金失敗時は `LogId.E_5952` を記録し、運用で補填できるよう player、waystoneId、gold を残す。

### テレポート失敗

- GUI を閉じた後に失敗した場合は、失敗メッセージを送信する。
- プレイヤー位置を巻き戻す処理は行わない。
- ワールド未ロード、チャンク準備失敗、Bukkit teleport 失敗は同じ失敗メッセージへ集約する。

## 4. 運用

- `waystones.yml` は管理者コマンドで更新することを基本とし、手編集した場合は `/teleporter reload` を実行する。
- 同一座標へ誤って複数ウェイストーンを登録しないよう、Plugin 側で保存前に重複検証する。
- 削除したウェイストーンの `account_waystone_unlock` 行は削除しない。再利用しない ID として扱う。
- `waystoneId` は API / DB のキーであるため、手編集で変更しない。

## 5. 権限

- `/teleporter set`、`/teleporter remove`、`/teleporter list`、`/teleporter reload` は `permission >= 99` のプレイヤー、またはコンソールから実行できる。ただし `set` は現在地を使うためプレイヤーのみ許可する。
- 通常プレイヤーはウェイストーンの利用、解除、GUI 表示、GUI 内テレポートのみ可能とする。
