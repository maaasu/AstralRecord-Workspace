# 25_0.00-概要

テレポーター機能は、同一ワールド内に配置されたウェイストーン間をプレイヤーが移動するための機能である。
管理者がコマンドでウェイストーンを配置し、プレイヤーは解除済みウェイストーンから同一ワールド内の別ウェイストーンへテレポートできる。

## 目的

- 管理者がワールド内にウェイストーンを追加、削除、再読み込みできる。
- ウェイストーンの座標、表示名、ロック有無、解除コストは Plugin data folder の `waystones.yml` を正本とする。
- ロック機能が有効なウェイストーンは、選択中アカウント単位の解除状態を AstralRecord API / SQL Server で保持する。
- ロック機能が無効なウェイストーンは、DB 行がなくても常に解除済みとして扱う。
- ワールド上の表示はプレイヤーごとに状態が異なるため、packet 表示で BlockDisplay / TextDisplay 相当の見た目を送信する。
- 解除済みウェイストーンを左クリックまたは右クリックした場合、テレポーター GUI を開く。
- ロック中ウェイストーンを右クリックした場合、必要ゴールドを消費して解除する。

## 対象外

- ワールドをまたいだテレポート。
- ウェイストーン間の利用料金。ロック解除時の一回限りのゴールド消費のみ扱う。
- ウェイストーンのマスタデータを SQL Server または filebase に保持すること。
- メニュー GUI からの画面遷移。テレポーター GUI はメニュー GUI と独立するが、共通ホットバーショートカットの閉じる操作とインベントリ切替は使用する。

## 既存契約

- API: `GET /api/account-waystone/{accountId}` と `POST /api/account-waystone/{accountId}/unlock`
- API 設計: `00_docs/20_API設計書/feature/25-waystone`
- DB: `dbo.account_waystone_unlock`
- DB 設計: `00_docs/40_Database設計書/table-definitions/AstralRecord/dbo.account_waystone_unlock.md`

## 表示方針

ウェイストーンは複数の BlockDisplay を組み合わせた石碑状の見た目で表示する。
中央に石系ブロック、装飾として銅系またはアメジスト系ブロック、頂部に光源系ブロックを置き、有名な Waystones 系 mod のウェイストーンをモチーフにした形状とする。

ウェイストーン上部には TextDisplay を表示する。

| 状態 | TextDisplay 表示 |
|:--|:--|
| 解除済み | 水色でウェイストーン名を表示 |
| ロック中 | ロック中であること、解除に必要なゴールド数を表示 |
| 常時開放 | 解除済みと同じ扱いで水色表示 |

packet 表示はプレイヤーごとに保持する。同期時はいったん既存表示を destroy し、対象プレイヤーと同一ワールドの全ウェイストーンを解除状態に応じて再生成する。現行実装は表示距離による除外や metadata だけの差分更新を行わない。

## 操作方針

| 操作 | 条件 | 結果 |
|:--|:--|:--|
| 右クリック | ロック中、解除コストを所持 | ゴールドを消費し、API へ解除登録し、表示を解除済みに更新 |
| 右クリック | ロック中、解除コスト不足 | 解除できない旨のメッセージを送信 |
| 左クリック | 解除済み | テレポーター GUI を開く |
| 右クリック | 解除済み | テレポーター GUI を開く |
| GUI 内の解除済み項目クリック | 同一ワールド内、現在地点以外 | 対象ウェイストーン座標へ、移動直前のプレイヤーの yaw / pitch を保持してテレポート |
| GUI 内の未解除項目クリック | 未解除 | テレポートせず、未解除である旨を表示 |

## データ保持方針

| データ | 正本 | 備考 |
|:--|:--|:--|
| ウェイストーン ID | `waystones.yml` | コマンド作成時に Plugin が内部生成 |
| 表示名 | `waystones.yml` | コマンド引数の名称 |
| 座標、yaw、pitch | `waystones.yml` | コマンド実行者の現在地 |
| ロック有無 | `waystones.yml` | `false` の場合は常時開放 |
| 解除コスト | `waystones.yml` | ロック有効時のみ使用 |
| アカウント別解除状態 | `dbo.account_waystone_unlock` | API `account-waystone` 経由 |

## 初期化方針

Plugin 起動時に `waystones.yml` を読み込み、内部キャッシュを構築する。
オンラインプレイヤーの解除状態はログイン時、アカウント切替時、GUI 表示時、解除成功時に取得または更新する。
`/teleporter reload` 実行時は `waystones.yml` を再読み込みし、表示 packet を全オンラインプレイヤーへ再同期する。
