# 25_3.03-コマンド

## テレポーターコマンド受付

クラス名: `TeleporterCommand`
物理名: `executePlayerCommand`

1. 先頭引数でサブコマンドを判定する。
2. `set` の場合は [[#ウェイストーン設定実行]] へ委譲する。
3. `remove` の場合は [[#ウェイストーン削除実行]] へ委譲する。
4. `list` の場合は [[#ウェイストーン一覧表示]] へ委譲する。
5. `reload` の場合は [[#ウェイストーン再読み込み]] へ委譲する。
6. 未指定または不明な場合は usage を表示する。

## ウェイストーン設定実行

クラス名: `TeleporterCommand`
物理名: `handleSet`

コマンド:

```text
/teleporter set <name> <lockEnabled> <unlockGold>
```

1. 実行者がプレイヤーであることを検証する。
2. 実行者の `permission >= 99` を検証する。
3. 引数数が 3 であることを検証する。
4. `name` が空文字でないことを検証する。
5. `lockEnabled` を `true` / `false` として解析する。
6. `unlockGold` を `0` 以上の long として解析する。
7. [[25_3.02-サービス]].ウェイストーン登録 を呼び出す。
8. 戻り値の ID と表示名を `P_5959` で通知する。

    | 項目 | 内容 |
    |:--|:--|
    | ID | `PlayerMsgId.P_5959` |
    | テンプレート | `ウェイストーンを更新しました: {0} ({1})` |
    | 出力条件 | 作成成功時 |
    | 引数 | ウェイストーン ID、表示名 |

権限:

| 実行者 | 許可条件 |
|:--|:--|
| プレイヤー | [[03_1.00-モデル定義]].プレイヤーセッション の `permission` が `99` 以上 |
| コンソール | 不可。座標を実行者現在地から取得するため |

権限不足時メッセージ:

| 項目 | 内容 |
|:--|:--|
| ID | `PlayerMsgId.P_5060` |
| テンプレート | `このコマンドを実行する権限がありません。` |
| 出力条件 | `permission < 99` |
| 引数 | なし |

## ウェイストーン削除実行

クラス名: `TeleporterCommand`
物理名: `handleRemove`

コマンド:

```text
/teleporter remove <waystoneId>
```

1. 実行権限を検証する。
2. `waystoneId` が空文字でないことを検証する。
3. [[25_3.02-サービス]].ウェイストーン削除 を呼び出す。
4. 削除対象が存在しない場合は `P_5960`、成功時は `P_5959` を送る。

権限:

| 実行者 | 許可条件 |
|:--|:--|
| プレイヤー | [[03_1.00-モデル定義]].プレイヤーセッション の `permission` が `99` 以上 |
| コンソール | 不可。`TeleporterCommand` はプレイヤー専用 |

## ウェイストーン一覧表示

クラス名: `TeleporterCommand`
物理名: `handleList`

コマンド:

```text
/teleporter list
```

1. 実行権限を検証する。
2. キャッシュ済みウェイストーン定義を保持中の順序で取得する。
3. 実行者へ件数と一覧を送信する。

表示内容:

| 項目 | 内容 |
|:--|:--|
| ID | `PlayerMsgId.P_5958` |
| テンプレート | `ウェイストーン件数: {0}` |
| 出力条件 | 一覧表示時の件数 |
| 引数 | 件数 |

| 項目 | 内容 |
|:--|:--|
| ID | `PlayerMsgId.P_5961` |
| テンプレート | `{0} | {1} | {2} | lock={3} | gold={4}` |
| 出力条件 | 一覧表示時 |
| 引数 | `id`、`name`、`worldName`、`lockEnabled`、`unlockGold` |

## ウェイストーン再読み込み

クラス名: `TeleporterCommand`
物理名: `handleReload`

コマンド:

```text
/teleporter reload
```

1. 実行権限を検証する。
2. [[25_3.02-サービス]].ウェイストーン定義再読み込み を呼び出す。
3. 戻り値の件数を `P_5958` で通知する。例外はこのメソッド内では捕捉しない。

## 補完候補取得

クラス名: `TeleporterTabCompleter`
物理名: `getPlayerCompletions`

1. 第 1 引数位置では `set`、`remove`、`list`、`reload` を返す。
2. `set` の第 3 引数位置では `true`、`false` を返す。
3. `set` の第 4 引数位置では `0`、`100`、`500`、`1000` を返す。
4. `remove` の第 2 引数位置では登録済みウェイストーン ID を返す。
5. 権限不足のプレイヤーには補完候補を返さない。
