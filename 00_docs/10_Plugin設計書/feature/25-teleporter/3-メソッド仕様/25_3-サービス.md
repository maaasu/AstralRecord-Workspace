# 25_3-サービス

## ウェイストーン定義ロード

クラス名: `TeleporterService`
物理名: `loadAll`

1. [[25_3-リポジトリ]].ウェイストーン定義一覧取得 を呼び出す。
2. 取得結果を不変リストのスナップショットにする。
3. 現在の ID キャッシュを空にし、スナップショットを読み込み順に一括反映する。
4. キャッシュ件数を返す。

現行実装はサービス層で追加の値検証、座標重複検証、ソート、ロード成功ログを行わない。

## ウェイストーン定義再読み込み

クラス名: `TeleporterService`
物理名: `reload`

1. [[#ウェイストーン定義ロード]] を呼び出す。
2. 全オンラインプレイヤーに対して [[25_3-GUI・View]].ウェイストーン表示同期 を呼び出す。
3. ロード件数を返す。実行者への通知は `TeleporterCommand.handleReload` が行う。

    | 項目 | 内容 |
    |:--|:--|
    | ID | `PlayerMsgId.P_5958` |
    | テンプレート | `ウェイストーン件数: {0}` |
    | 出力条件 | reload 成功時 |
    | 引数 | ロード件数 |

## ウェイストーン登録

クラス名: `TeleporterService`
物理名: `createWaystone`

1. 実行者の現在ワールドと座標を取得する。
2. `ws-<UTC yyyyMMddHHmmss>-<name slug>` を基底に内部 ID を生成し、重複時は連番を付ける。
3. `lockEnabled=false` の場合は `unlockGold=0` に正規化し、省略可能な `icon` はそのまま定義へ保持する。
4. `WaystoneDefinition` を作成してキャッシュへ追加する。
5. [[25_3-リポジトリ]].ウェイストーン定義一覧保存 を呼び出す。保存失敗時は追加したキャッシュを削除し、例外を伝播する。
6. 保存成功後に全オンラインプレイヤーの表示を再同期する。
7. 作成内容をログへ記録し、定義を返す。

    | 項目 | 内容 |
    |:--|:--|
    | ID | `LogId.I_5950` |
    | レベル | INFO |
    | テンプレート | `ウェイストーンを作成しました: id=%s, name=%s, world=%s` |
    | 出力条件 | 登録成功時 |
    | 引数 | ウェイストーン ID、表示名、ワールド名 |

引数の個数、空の `name`、boolean、負数、アイテム表示できない `icon` は `TeleporterCommand.handleSet` が先に検証する。

## ウェイストーン削除

クラス名: `TeleporterService`
物理名: `removeWaystone`

1. 指定 ID の定義をキャッシュから取得する。
2. 存在しない場合は `false` を返す。
3. 現在のキャッシュをスナップショット化してから対象を削除し、残った定義の全件を [[25_3-リポジトリ]].ウェイストーン定義一覧保存 へ渡す。
4. 保存失敗時はスナップショットを復元し、例外を伝播する。
5. 保存成功後に全オンラインプレイヤーの表示を再同期し、`true` を返す。

プレイヤーメッセージは `TeleporterCommand.handleRemove` が戻り値に応じて送信する。

## 解除状態取得

クラス名: `TeleporterService`
物理名: `loadUnlockStateAsync`

1. `AstPlayer` から選択中アカウント ID を取得する。
2. `CompletableFuture.supplyAsync` から [[25_3-リポジトリ]].アカウント別解除状態取得 を呼び出す。
3. 戻り値を不変 Set にし、`WaystoneUnlockState` を作成する。
4. Bukkit メインスレッドへキャッシュ反映と表示同期を予約する。
5. API 取得失敗は Future を例外完了させる。クリック処理は `P_5964` を通知して終了する。

    | 項目 | 内容 |
    |:--|:--|
    | ID | `PlayerMsgId.P_5964` |
    | テンプレート | `ウェイストーンの解除状態を取得できませんでした。しばらくしてからもう一度お試しください。` |
    | 出力条件 | 解除状態 API の取得失敗時 |
    | 引数 | なし |

## ウェイストーン解除

クラス名: `TeleporterService`
物理名: `unlockWaystone`

1. 対象ウェイストーン定義を取得する。
2. `lockEnabled=false` の場合は解除済み扱いとして [[25_3-GUI・View]].テレポーター GUI 表示 を呼び出す。
3. 最新の解除状態を取得し、すでに解除済みの場合は GUI 表示へ進む。
4. 同一プレイヤー、同一ウェイストーンの解除処理が進行中の場合は二重実行を拒否する。
5. 実行時の `InventoryService` が未設定なら、次のメッセージを送って終了する。

    | 項目 | 内容 |
    |:--|:--|
    | ID | `PlayerMsgId.P_5963` |
    | テンプレート | `テレポーター機能を現在利用できません。しばらくしてからもう一度お試しください。` |
    | 出力条件 | `InventoryService` 未設定時 |
    | 引数 | なし |

6. `InventoryService.consumeGold` でゴールドを消費する。
7. ゴールド不足の場合、以下メッセージを送信して終了する。

    | 項目 | 内容 |
    |:--|:--|
    | ID | `PlayerMsgId.P_5955` |
    | テンプレート | `解除に必要なゴールドが不足しています。必要: {0}` |
    | 出力条件 | ゴールド不足時 |
    | 引数 | 必要ゴールド |

8. 消費後のインベントリを直ちに保存する。
9. 非同期で [[25_3-リポジトリ]].ウェイストーン解除登録 を呼び出す。
10. 解除状態キャッシュへ `waystoneId` を追加する。
11. 対象プレイヤーへ表示 packet を再送信する。
12. ウェイストーン中心に解除成功サウンドと共通パーティクル演出を再生する。
13. 以下メッセージを送信する。

    | 項目 | 内容 |
    |:--|:--|
    | ID | `PlayerMsgId.P_5952` |
    | テンプレート | `ウェイストーンを解除しました: {0}（消費ゴールド: {1}）` |
    | 出力条件 | 解除成功時 |
    | 引数 | 表示名、確定した消費ゴールド |

14. API 登録に失敗した場合、消費済みゴールドの返金と即時保存を試み、`P_5957` を送信する。
15. 返金にも失敗した場合は以下ログを記録する。

    | 項目 | 内容 |
    |:--|:--|
    | ID | `LogId.E_5952` |
    | レベル | ERROR |
    | テンプレート | `ウェイストーン解除失敗後の返金に失敗しました: player=%s, waystoneId=%s, gold=%d` |
    | 出力条件 | API 登録失敗後の返金失敗時 |
    | 引数 | プレイヤー名、ウェイストーン ID、返金額 |

## GUI 表示項目構築

クラス名: `TeleporterService`
物理名: `listGuiEntries`

1. 起点ウェイストーンを取得する。
2. 起点と同じ `worldName` のウェイストーンだけを抽出する。
3. 起点ウェイストーン自身を除外する。
4. 対象プレイヤーの解除状態を取得する。
5. [[25_1-モデル定義]].テレポーター GUI 表示項目 を作成する。
6. 解除済みを先頭、未解除を後続に並べる。

## ウェイストーンテレポート

クラス名: `TeleporterService`
物理名: `teleportToWaystone`

テレポート先の座標は対象ウェイストーン定義から解決するが、`yaw` / `pitch` は対象定義ではなく移動直前のプレイヤーの向きを保持する。実際の移動は `WorldService.teleportPlayerAsync` を経由し、共通テレポート処理で向きを反映する。

1. GUI 起点と対象ウェイストーンが同じ `worldName` であることを検証する。
2. 対象ウェイストーンが解除済みであることを検証する。
3. 対象ワールドがロード済みであることを `WorldService` で検証する。
4. GUI を閉じる。
5. `WorldService.teleportPlayerAsync` を使って対象座標へ非同期テレポートする。
6. `WorldService` の成功 callback から以下メッセージを送信する。

    | 項目 | 内容 |
    |:--|:--|
    | ID | `PlayerMsgId.P_5953` |
    | テンプレート | `テレポートしました: {0}` |
    | 出力条件 | テレポート成功時 |
    | 引数 | 表示名 |

7. 完了後 5 tick で対象プレイヤーの packet 表示を再同期する。
8. 事前検証で失敗した場合は次のメッセージを送信し、GUI は閉じない。

    | 項目 | 内容 |
    |:--|:--|
    | ID | `PlayerMsgId.P_5954` |
    | テンプレート | `対象ウェイストーンへテレポートできません。` |
    | 出力条件 | world service 未設定、ワールド不一致、未解除、Location 解決失敗 |
    | 引数 | なし |
