# テレポーターリポジトリ仕様

## ウェイストーン定義一覧取得

クラス名: `WaystoneDefinitionRepository`
物理名: `loadAll`

1. Plugin data folder の `waystones.yml` を読み込む。
2. ファイルが存在しない場合は `version: 1`、`waystones: []` の空ドキュメントとして扱う。
3. YAML を [[25_1.00-モデル定義]].waystones.yml 形式へ変換する。
4. 変換できない場合は例外を返し、呼び出し元がロード失敗として扱う。

## ウェイストーン定義保存

クラス名: `WaystoneDefinitionRepository`
物理名: `save`

1. 既存 `waystones.yml` を読み込む。
2. 同一 `id` が存在する場合は保存を拒否する。
3. 新しい定義を追加する。
4. `worldName`、`name`、`id` の順で安定ソートして YAML へ保存する。
5. 保存失敗時は以下ログを記録する。

    | 項目 | 内容 |
    |:--|:--|
    | ID | `LogId.E_5953` |
    | レベル | ERROR |
    | テンプレート | `waystones.yml の保存に失敗しました: %s` |
    | 出力条件 | YAML 保存失敗時 |
    | 引数 | 例外メッセージ |

## ウェイストーン定義削除

クラス名: `WaystoneDefinitionRepository`
物理名: `remove`

1. 既存 `waystones.yml` を読み込む。
2. 指定 `waystoneId` に一致する定義を削除する。
3. 削除対象が存在しない場合は `false` を返す。
4. 削除できた場合は YAML へ保存して `true` を返す。

## アカウント別解除状態取得

クラス名: `AccountWaystoneRepository`
物理名: `findByAccountId`

1. `GET /api/account-waystone/{accountId}` を呼び出す。
2. `200 OK` の場合、`AccountWaystoneStateResponse.unlockedWaystoneIds` を返す。
3. `404` は未登録ではなく API 契約外として失敗扱いにする。
4. 通信失敗、JSON 変換失敗、非 2xx は例外を返す。

参照 API:

- `00_docs/20_API設計書/feature/25-waystone/3-エンドポイント仕様/25_3.00-索引.md`

## ウェイストーン解除登録

クラス名: `AccountWaystoneRepository`
物理名: `unlock`

1. `POST /api/account-waystone/{accountId}/unlock` を呼び出す。
2. Body に `waystoneId` と `updatedBy` を設定する。
3. `200 OK` の場合、`AccountWaystoneUnlockResponse` を返す。
4. API 側はすでに解除済みの場合も既存行を返すため、Plugin 側は冪等成功として扱う。
5. 通信失敗、JSON 変換失敗、非 2xx は例外を返す。

参照 DB:

- `00_docs/40_Database設計書/table-definitions/AstralRecord/dbo.account_waystone_unlock.md`
