# 25_3.04-リポジトリ

## ウェイストーン定義一覧取得

クラス名: `WaystoneDefinitionRepository`
物理名: `loadAll`

1. Plugin data folder の `waystones.yml` を読み込む。
2. ファイルが存在しない場合は空リストを返し、ファイルは作成しない。
3. `waystones` の map list を [[25_1.00-モデル定義]].ウェイストーン定義 へ変換する。
4. `id`、`name`、`worldName`（旧キー `world` も許容）が空の行は読み飛ばす。
5. 数値・日時の変換に失敗した値は `0` / `Instant.EPOCH`、`createdBy` の欠落は `system` として読み込む。
6. 現行実装は `version` を検証しない。

## ウェイストーン定義保存

クラス名: `WaystoneDefinitionRepository`
物理名: `saveAll`

1. 新しい `YamlConfiguration` を作り、`version: 1` を設定する。
2. 引数の全定義を受け取った順序で map list に変換し、`waystones` へ設定する。
3. data folder が存在しない場合は作成し、`waystones.yml` 全体を保存する。
4. このメソッドは重複検証やソートを行わない。
5. 保存失敗時は以下ログを記録し、`IllegalStateException` を呼び出し元へ送出する。

    | 項目 | 内容 |
    |:--|:--|
    | ID | `LogId.E_5953` |
    | レベル | ERROR |
    | テンプレート | `waystones.yml の保存に失敗しました: %s` |
    | 出力条件 | YAML 保存失敗時 |
    | 引数 | `waystones.yml` の絶対パス。例外は `Throwable` として渡す |

## アカウント別解除状態取得

クラス名: `AccountWaystoneRepository`
物理名: `loadUnlockedWaystoneIds`

1. `GET /api/account-waystone/{accountId}` を呼び出す。
2. `200 OK` の場合、`AccountWaystoneStateResponse.unlockedWaystoneIds` を返す。
3. `404` は解除済み ID がない状態として空 Set を返す。
4. `unlockedWaystoneIds` が配列でない場合も空 Set とする。空文字の ID は除外する。
5. 通信失敗、JSON 変換失敗、200 / 404 以外は `LogId.E_5954` を記録し、`RuntimeException` を返す。

参照 API:

- `00_docs/20_API設計書/feature/25-waystone/3-エンドポイント仕様/25_3.00-索引.md`

## ウェイストーン解除登録

クラス名: `AccountWaystoneRepository`
物理名: `unlock`

1. `POST /api/account-waystone/{accountId}/unlock` を呼び出す。
2. Body に `waystoneId` と `updatedBy` を設定する。
3. `200 OK` の場合に正常終了する。response body は解析しない。
4. API 側がすでに解除済みを 200 とする限り、Plugin 側も冪等成功として扱う。
5. 通信失敗または 200 以外は `LogId.E_5954` を記録し、`RuntimeException` を返す。

参照 DB:

- `00_docs/40_Database設計書/table-definitions/AstralRecord/dbo.account_waystone_unlock.md`
