# テレポーターイベント仕様

## ウェイストーンクリック受付

イベント物理名: `PlayerInteractEvent` / `PlayerAnimationEvent`
クラス名: `TeleporterInteractEventHandler`
物理名: `onPlayerInteract` / `onPlayerAnimation`

1. 右クリックは `PlayerInteractEvent`、packet-only 表示への左クリックは `PlayerAnimationEvent` で受け付ける。
2. `WaystoneHitBoxResolver` でプレイヤー視線上のウェイストーンを解決する。
3. 対象ウェイストーンが見つからない場合は通常操作として終了する。
4. 対象ウェイストーンが見つかった場合はイベントをキャンセルする。
5. 右クリックかつ対象がロック中の場合、[[25_3.02-サービス]].ウェイストーン解除 を呼び出す。
6. 左クリックまたは右クリックで対象が解除済みの場合、[[25_3.07-GUI・View]].テレポーター GUI 表示 を呼び出す。
7. 処理中に例外が発生した場合は以下ログを記録する。

    | 項目 | 内容 |
    |:--|:--|
    | ID | `LogId.E_5950` |
    | レベル | ERROR |
    | テンプレート | `テレポータークリック処理に失敗しました: player=%s, waystoneId=%s` |
    | 出力条件 | クリック処理中に例外発生時 |
    | 引数 | プレイヤー名、解決済みの場合はウェイストーン ID |

## プレイヤー参加時表示同期

イベント物理名: `PlayerJoinEvent`
クラス名: `TeleporterPlayerEventHandler`
物理名: `onPlayerJoin`

1. プレイヤーの選択中アカウントが確定した後に処理する。
2. [[25_3.02-サービス]].解除状態取得 を呼び出す。
3. [[25_3.07-GUI・View]].ウェイストーン表示同期 を呼び出す。
4. API 取得に失敗した場合、表示同期は常時開放ウェイストーンのみ行い、ロック有効ウェイストーンはロック中として表示する。
5. 選択中アカウントが未確定の場合は、短い間隔で上限付きリトライを行う。

## プレイヤー退出時表示破棄

イベント物理名: `PlayerQuitEvent`
クラス名: `TeleporterPlayerEventHandler`
物理名: `onPlayerQuit`

1. [[25_3.07-GUI・View]].ウェイストーン表示破棄 を呼び出す。
2. プレイヤー別の `WaystoneViewState` と解除状態キャッシュを破棄する。

## ワールド移動後表示同期

イベント物理名: `PlayerChangedWorldEvent`
クラス名: `TeleporterPlayerEventHandler`
物理名: `onPlayerChangedWorld`

1. 移動前ワールドのウェイストーン表示 packet を破棄する。
2. 移動後ワールドのウェイストーン表示 packet を同期する。
3. `WorldService` のタイトル表示や passenger 再接続と競合しないよう、数 tick 遅延して同期する。

## GUI クリック受付

イベント物理名: `InventoryClickEvent`
クラス名: `TeleporterGuiEventHandler`
物理名: `onInventoryClick`

1. `TeleporterInventoryHolder` 以外のクリックは処理しない。
2. GUI 内クリックはイベントをキャンセルする。
3. ページ操作 slot の場合は現在ページを更新して再描画する。
4. 解除済みウェイストーン項目の場合は [[25_3.02-サービス]].ウェイストーンテレポート を呼び出す。
5. 未解除ウェイストーン項目の場合はテレポートせず、以下メッセージを送信する。

    | 項目 | 内容 |
    |:--|:--|
    | ID | `PlayerMsgId.P_5962` |
    | テンプレート | `このウェイストーンは未解除です。現地のウェイストーンを右クリックして解除してください。` |
    | 出力条件 | 未解除項目クリック時 |
    | 引数 | なし |

6. 処理中に例外が発生した場合は以下ログを記録する。

    | 項目 | 内容 |
    |:--|:--|
    | ID | `LogId.E_5951` |
    | レベル | ERROR |
    | テンプレート | `テレポーターGUIクリック処理に失敗しました: %s` |
    | 出力条件 | GUI クリック処理中に例外発生時 |
    | 引数 | プレイヤー名 |

## GUI クローズ受付

イベント物理名: `InventoryCloseEvent`
クラス名: `TeleporterGuiEventHandler`
物理名: `onInventoryClose`

1. `TeleporterInventoryHolder` 以外の close は処理しない。
2. GUI 用ホットバー表示を閉じ、通常ホットバーへ復元する。

## 追記（2026-07-09）インタラクト消費と武器スキル抑止

- `TeleporterInteractEventHandler` が `PlayerInteractEvent` でウェイストーンを解決した場合、event cancel に加えて `PlayerInteractionConsumeService` へ処理済みインタラクトとして記録する。
- `ItemWeaponAttackEventHandler` は `PlayerInteractionConsumeService` で消費済みの `PlayerInteractEvent` では左クリック攻撃・右クリックスキルを発動しない。
- 新しい右クリックインタラクト系コンテンツを追加する場合も、コンテンツ側で処理した `PlayerInteractEvent` は `PlayerInteractionConsumeService#consume` を通して消費し、武器右クリックスキルとの同時発火を避ける。
