# 25_3-イベント

## ウェイストーンクリック受付

イベント物理名: `PlayerInteractEvent` / `PrePlayerAttackEntityEvent` / `PlayerArmSwingEvent`
クラス名: `TeleporterInteractEventHandler`
物理名: `resolve`

1. 右クリックは`PlayerInteractEvent`、左クリックは`PlayerInteractEvent`または`PrePlayerAttackEntityEvent`をsemantic inputとして受け付ける。`PlayerArmSwingEvent`だけの場合は次tick fallbackとする。
2. teleporter resolverは共通ray snapshotを`WaystoneHitBoxResolver`へ渡し、視線上かつ遮蔽距離以下のウェイストーンを`PlayerInputCandidate`として返す。
3. 候補はworld interaction tierとし、他のNPC・skilltree・gathering・spawner候補と同tierの場合はray入口までの`hitDistance`が短い対象を優先する。複数ウェイストーンが同じ入口距離ならwaystone IDの昇順で一件に決定し、定義の走査順へ依存しない。
4. 候補収集時はevent cancel、ゴールド消費、GUI表示を行わない。
5. 候補 executor は右・左の種別を保持し、勝者になった場合だけ `TeleporterService.handleWaystoneClick` を呼ぶ。
6. `handleWaystoneClick` は解除状態に応じて [[25_3-サービス]].ウェイストーン解除 または [[25_3-GUI・View]].テレポーター GUI 受付 へ分岐する。
7. 勝者の`InputClaimPolicy`をgatewayがeventへ反映する。解除拒否・失敗・例外時も別候補へfallbackしない。
8. 候補 executor の例外処理は共通 gateway の入力調停ログへ集約する。teleporter 固有のクリックログ ID は持たない。

## プレイヤー参加時表示同期

イベント物理名: `PlayerJoinEvent`
クラス名: `TeleporterPlayerEventHandler`
物理名: `onPlayerJoin`

1. プレイヤーの選択中アカウントが確定した後に処理する。
2. [[25_3-サービス]].解除状態取得 を呼び出す。
3. [[25_3-GUI・View]].ウェイストーン表示同期 を呼び出す。
4. API 取得に失敗した場合、表示同期は常時開放ウェイストーンのみ行い、ロック有効ウェイストーンはロック中として表示する。
5. 選択中アカウントが未確定の場合は、短い間隔で上限付きリトライを行う。

## プレイヤー退出時表示破棄

イベント物理名: `PlayerQuitEvent`
クラス名: `TeleporterPlayerEventHandler`
物理名: `onPlayerQuit`

1. [[25_3-GUI・View]].ウェイストーン表示破棄 を呼び出す。
2. プレイヤー別の `List<WaystonePacketDisplay.PacketEntity>` と、選択中アカウントの解除状態キャッシュを破棄する。

## ワールド移動後表示同期

イベント物理名: `PlayerChangedWorldEvent`
クラス名: `TeleporterPlayerEventHandler`
物理名: `onPlayerChangedWorld`

1. 移動前ワールドのウェイストーン表示 packet を破棄する。
2. 移動後ワールドのウェイストーン表示 packet を同期する。
3. イベント処理中に同期を実行し、追加の遅延は設けない。

## GUI クリック受付

イベント物理名: `InventoryClickEvent`
クラス名: `TeleporterGuiEventHandler`
物理名: `onInventoryClick`

1. `TeleporterGui.Holder` 以外のクリックは処理しない。
2. GUI 内クリックはイベントをキャンセルする。
3. ページ操作 slot の場合は現在ページを更新して再描画する。
4. 解除済みウェイストーン項目の場合は [[25_3-サービス]].ウェイストーンテレポート を呼び出す。
5. 未解除ウェイストーン項目の場合はテレポートせず、以下メッセージを送信する。

    | 項目 | 内容 |
    |:--|:--|
    | ID | `PlayerMsgId.P_5962` |
    | テンプレート | `このウェイストーンは未解除です。現地のウェイストーンを右クリックして解除してください。` |
    | 出力条件 | 未解除項目クリック時 |
    | 引数 | なし |

6. 処理中に例外が発生した場合は以下ログを記録する。

    | 項目 | 内容 |
    |:--|:--|
    | ID | `LogId.E_5951` |
    | レベル | ERROR |
    | テンプレート | `テレポーターGUIクリック処理に失敗しました: %s` |
    | 出力条件 | GUI クリック処理中に例外発生時 |
    | 引数 | プレイヤー名 |

## GUI クローズ受付

イベント物理名: `InventoryCloseEvent`
クラス名: `TeleporterGuiEventHandler`
物理名: `onInventoryClose`

1. `TeleporterInventoryHolder` 以外の close は処理しない。
2. GUI 用ホットバー表示を閉じ、通常ホットバーへ復元する。

## プレイヤーライフサイクル同期の例外

参加、ワールド移動、退出の同期処理で例外が発生した場合は次を記録する。

| 項目 | 内容 |
|:--|:--|
| ID | `LogId.E_5955` |
| レベル | ERROR |
| テンプレート | `ウェイストーン表示同期処理に失敗しました: player=%s, trigger=%s` |
| 出力条件 | join / world / quit の同期処理例外 |
| 引数 | プレイヤー名、`join` / `world` / `quit` |

## クリック入力の共通仲裁

- ウェイストーンはworld interaction候補としてitem use、action ring、weapon / combatより優先する。
- 同一入力のmain/offhand、semantic event、arm swingはtick tokenへ相関し、勝者executorを一回だけ呼ぶ。
- event経過時間を使うconsume/debounceは使用しない。
- gateway、候補比較、event抑止の詳細は[[28_3-イベント]]と[[28_3-サービス]]を正本とする。
