# 25_0-概要

テレポーター機能は、同一ワールド内に配置されたウェイストーン間をプレイヤーが移動するための機能である。
管理者がコマンドでウェイストーンを配置し、プレイヤーは解除済みウェイストーンから同一ワールド内の別ウェイストーンへテレポートできる。

## 目的

- 管理者がワールド内にウェイストーンを追加、削除、再読み込みできる。
- ウェイストーンの座標、表示名、ロック有無、解除コスト、省略可能な表示アイコンは Plugin data folder の `waystones.yml` を正本とする。
- ロック機能が有効なウェイストーンは、選択中アカウント単位の解除状態を Plugin のローカル確定状態として保持し、所持品と同じ player-state snapshot で AstralRecord API / SQL Server へ非同期保存する。
- ロック機能が無効なウェイストーンは、DB 行がなくても常に解除済みとして扱う。
- ワールド上の表示はプレイヤーごとに状態が異なるため、解除状態に応じた本体モデルと名称を packet で送信する。
- 解除済みウェイストーンを左クリックまたは右クリックした場合、テレポーター GUI を開く。
- ロック中ウェイストーンを右クリックした場合、必要ゴールドを消費して解除する。

## 対象外

- ワールドをまたいだテレポート。
- ウェイストーン間の利用料金。ロック解除時の一回限りのゴールド消費のみ扱う。
- ウェイストーンのマスタデータを SQL Server または filebase に保持すること。
- メニュー GUI からの画面遷移。テレポーター GUI はメニュー GUI と独立するが、共通ホットバーショートカットの閉じる操作とインベントリ切替は使用する。

## 既存ロードと保存契約

- 既存ロード API: `GET /api/account-waystone/{accountId}`。ログイン時などに既存解除状態を初期 cache として取得する。
- 保存 API: player-state の `waystones` section。payload / ACK は `clientRevision` と、`waystones.yml` の内部 ID を要素とする `unlockedWaystoneIds` を持つ。
- `unlockedWaystoneIds` は空白なし・100文字以下の文字列を送信順で保持する。API は集合追加だけを行い、解除取消は扱わない。
- API 設計: `00_docs/20_API設計書/feature/25-waystone`
- DB: `dbo.account_waystone_unlock`
- DB 設計: `00_docs/40_Database設計書/table-definitions/AstralRecord/dbo.account_waystone_unlock.md`

## 表示方針

ウェイストーンは石造の台座、紋章を刻んだ柱、頂部の結晶を持つリソースパックモデルで表示する。解除済みと常時開放は青緑色、ロック中は赤橙色の結晶と紋章を表示する。Java 版は専用 ItemDisplay を使い、統合版は AstralRecordGeyserExtension が表示用 TextDisplay を専用モデルへ変換する。

ウェイストーン上部には TextDisplay を表示する。

| 状態 | TextDisplay 表示 |
|:--|:--|
| 解除済み | 水色でウェイストーン名を表示 |
| ロック中 | ロック中であること、解除に必要なゴールド数を表示 |
| 常時開放 | 解除済みと同じ扱いで水色表示 |

Java 版では TextDisplay のさらに上に、GUI と共通のアイコンをドロップアイテム風の ItemDisplay として表示する。`icon` が未設定の場合は `BEACON` を表示する。

packet 表示はプレイヤー・ウェイストーンごとに保持し、同一ワールドかつ基準座標から64 block以内だけを表示する。10 tick周期と解除・定義変更時に差分同期し、新規・表示状態変更・範囲外の石碑だけを更新する。変更のない石碑の entity は維持し、表示状態変更時は対象石碑の一式を再生成する。

## 操作方針

| 操作 | 条件 | 結果 |
|:--|:--|:--|
| 右クリック | ロック中、解除コストを所持 | ゴールド消費と解除状態追加を同じローカル確定処理で完了し、保存キュー登録後に表示を解除済みに更新 |
| 右クリック | ロック中、解除コスト不足 | 解除できない旨のメッセージを送信 |
| 左クリック | 解除済み | テレポーター GUI を開く |
| 右クリック | 解除済み | テレポーター GUI を開く |
| GUI 内の解除済み項目クリック | 同一ワールド内、現在地点以外 | 対象ウェイストーン座標へ、移動直前のプレイヤーの yaw / pitch を保持してテレポート |
| GUI 内の未解除項目クリック | 未解除 | テレポートせず、未解除である旨を表示 |

## データ保持方針

| データ | 正本 | 備考 |
|:--|:--|:--|
| ウェイストーン ID | `waystones.yml` | コマンド作成時に Plugin が内部生成 |
| 表示名 | `waystones.yml` | コマンド引数の名称 |
| 座標、yaw、pitch | `waystones.yml` | コマンド実行者の現在地 |
| ロック有無 | `waystones.yml` | `false` の場合は常時開放 |
| 解除コスト | `waystones.yml` | ロック有効時のみ使用 |
| 表示アイコン | `waystones.yml` | 省略可能。未設定または無効な Material 名は `BEACON` |
| アカウント別解除状態 | gameplay 中は Plugin のローカル確定 cache | API 既存ロードと player-state `waystones` section で SQL Server へ同期 |

## 初期化方針

Plugin 起動時に `waystones.yml` を読み込み、内部キャッシュを構築する。
オンラインプレイヤーの解除状態はログイン時、アカウント切替時、GUI 表示時に既存 API から取得する。未受領のローカル解除がある場合、再ロード結果へその解除を和集合で重ねて巻き戻さない。
`/teleporter reload` 実行時は `waystones.yml` を再読み込みし、表示 packet を全オンラインプレイヤーへ再同期する。

## 依存・連携

- `player`: オンラインプレイヤー、選択中アカウント、権限 `permission`
- `account`: ウェイストーン解除状態のアカウント単位管理
- `currency`: ロック解除時のゴールド残高確認と消費
- `world`: 同一ワールド判定と共通テレポート処理
- `menu`: GUI 共通のインベントリ終了仕様
- `player-interaction`: ウェイストーン左右クリック候補、距離比較、勝者一件実行は[[28_0-概要]]を正本とする
- API `account-waystone`: `00_docs/20_API設計書/feature/25-waystone`
- DB `dbo.account_waystone_unlock`: `00_docs/40_Database設計書/table-definitions/AstralRecord/dbo.account_waystone_unlock.md`

## 正本境界

- ウェイストーン定義は Plugin data folder の `waystones.yml`、gameplay 中の解除状態は選択中アカウント単位のローカル確定 cache を正本とする。API / DB は player-state snapshot の ACK により反映済みになる。
- Minecraft ユーザー内の複数アカウントで解除状態を共有する案は [[25_9-未決事項]] で扱う。
