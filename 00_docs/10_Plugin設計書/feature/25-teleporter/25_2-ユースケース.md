# 25_2-ユースケース

## 1. 管理者がウェイストーンを配置する

前提:

- 実行者はプレイヤーである。
- 実行者の `user.permission` は `99` 以上である。

手順:

1. 管理者が配置したい座標に立つ。
2. `/teleporter set <name> <lockEnabled> <unlockGold> [icon]` を実行する。`icon` は Bukkit Material 名で、省略時は `BEACON` を使用する。
3. Plugin は `ws-<UTC yyyyMMddHHmmss>-<name slug>` を基底に、重複時の連番を含む内部ウェイストーン ID を生成する。
4. 現在ワールド、座標、yaw、pitch、表示名、ロック設定と、指定された場合はアイコンを `waystones.yml` へ保存する。
5. オンラインプレイヤーへ新しいウェイストーン表示 packet を同期する。

事後条件:

- `waystones.yml` にウェイストーン定義が追加される。
- `lockEnabled=false` の場合は全プレイヤーから解除済み表示になる。
- `lockEnabled=true` の場合は解除済みアカウント以外からロック中表示になる。

## 2. プレイヤーがロック中ウェイストーンを解除する

前提:

- プレイヤーは選択中アカウントを持つ。
- 対象ウェイストーンは `lockEnabled=true` である。
- 対象ウェイストーンは対象アカウントで未解除である。

手順:

1. プレイヤーがロック中ウェイストーンを右クリックする。
2. Plugin は現在の解除状態を確認する。
3. Plugin は必要ゴールド数を表示定義から取得する。
4. `InventoryService.executeLocalPlayerMutation` の同一 state lock 内で、最新の解除状態を再確認する。
5. 未解除かつゴールドが足りる場合だけ、ゴールド消費、解除状態 cache 追加、未受領 revision 記録を同時に確定する。
6. ゴールドが不足している場合、解除できない旨のメッセージを送信して終了する。
7. 確定後に player-state 保存キューへ登録し、対象ウェイストーン表示を解除済みに差し替える。API 応答を待たない。

事後条件:

- player-state `waystones` section の ACK 後、`dbo.account_waystone_unlock` に解除済み行が存在する。
- プレイヤーから対象ウェイストーン名が水色で表示される。

例外:

- 保存失敗または ACK 不正時は、確定済みゴールドと解除 cache を巻き戻さない。保存キューが同一スナップショットを再試行する。
- 連打、再ロード、セッション退出中に追加された解除は、すでに送信中の snapshot ACK で dirty を失わない。

## 3. プレイヤーが解除済みウェイストーンから GUI を開く

前提:

- プレイヤーは選択中アカウントを持つ。
- 対象ウェイストーンは解除済みまたは常時開放である。

手順:

1. プレイヤーが解除済みウェイストーンを左クリックまたは右クリックする。
2. Plugin は対象ウェイストーンと同一ワールド内のウェイストーン一覧を取得する。
3. 起点ウェイストーンを一覧から除外する。
4. 解除済みウェイストーンを先頭に、未解除ウェイストーンを後続に並べる。
5. テレポーター GUI を開く。
6. `HotbarShortcutGuiHolder` の共通動作を有効にし、ホットバーの閉じる操作とインベントリ切替を提供する。

事後条件:

- テレポーター GUI が表示される。
- GUI 本体には戻るボタンを表示しない。終了とインベントリ切替は共通ホットバーショートカットで扱う。

## 4. プレイヤーが GUI からテレポートする

前提:

- プレイヤーはテレポーター GUI を開いている。
- クリック対象は解除済みウェイストーン項目である。

手順:

1. プレイヤーが解除済みウェイストーン項目をクリックする。
2. Plugin は GUI を閉じる。
3. `WorldService.teleportPlayerAsync` 経由で対象ウェイストーン座標へ移動する。
4. 実際のテレポート成功後、`WAYSTONE_TELEPORTED` と対象ウェイストーン ID をガイド進捗へ記録する。
5. テレポート完了後、周辺ウェイストーン表示 packet を再同期する。

事後条件:

- プレイヤーは対象ウェイストーン座標へ移動する。
- 成功した場合だけ、対象ウェイストーン ID のガイド達成条件が記録される。

## 5. プレイヤーが GUI 内の未解除項目をクリックする

前提:

- プレイヤーはテレポーター GUI を開いている。
- クリック対象は未解除ウェイストーン項目である。

手順:

1. プレイヤーが未解除ウェイストーン項目をクリックする。
2. Plugin はテレポートを実行しない。
3. 未解除である旨と、解除するには現地ウェイストーンを右クリックする必要がある旨をメッセージ表示する。

事後条件:

- プレイヤーの位置は変わらない。
- GUI は開いたままとする。

## 6. 管理者がウェイストーンを削除する

前提:

- 実行者は `user.permission` が `99` 以上のプレイヤーである。

手順:

1. `/teleporter remove <waystoneId>` を実行する。
2. Plugin は `waystones.yml` から対象定義を削除する。
3. オンラインプレイヤーから対象ウェイストーンの packet 表示を破棄する。

事後条件:

- `waystones.yml` から対象ウェイストーンが削除される。
- DB の解除済み行は物理削除しない。再度同じ ID を使わない限り参照されない履歴扱いとする。
