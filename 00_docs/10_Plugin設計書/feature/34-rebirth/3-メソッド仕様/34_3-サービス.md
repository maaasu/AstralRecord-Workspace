# 34_3-サービス

## AccountService 転生進行

### 転生開始

`startRebirthCached` はレベル2以上かつ非転生中のアカウントだけを受理し、現在レベルを転生前レベル・最高到達レベルへ反映したうえでLv.1 / EXP 0 / 端数0へ遷移する。

### 転生中EXP加算

`grantExperienceCached` は転生中のみ通常の各レベル必要EXPを3で除した切り上げ値を用いる。EXPポイントは転生前レベルへ到達するまでに消費される実EXPだけを対象に100EXP単位で算出する。到達時の超過EXPは通常累計EXPへ変換して保持する。

### 転生終了

`endRebirthCached` は転生中だけを受理し、転生前レベルの通常開始累計EXPへ復帰して転生状態と端数を解除する。

## RebirthService 原子操作

### 転生開始操作

`start` は現在レベル × 10,000 Goldの消費と`startRebirthCached`の結果をresponsive local player-state mutationで一体確定する。完成stateはwrite-behind保存し、保存待機の外部操作境界を保持しない。

### 有償終了操作

`endEarly` は100アストラルド消費と`endRebirthCached`の結果をresponsive local player-state mutationで一体確定し、完成stateをwrite-behind保存する。

### EXPポイント付与

`grantExperience` はアカウントEXP進行と、結果が示すEXPポイント数量を同じローカルplayer-state変更境界で通貨inventoryへ反映する。通貨付与失敗時は双方を操作前へ戻す。
