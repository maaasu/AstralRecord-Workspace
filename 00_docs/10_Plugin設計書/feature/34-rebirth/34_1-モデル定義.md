# 34-rebirth モデル定義

## AccountModel 拡張

| 項目 | 型 | 説明 |
|:--|:--|:--|
| `highestLevel` | int | 過去最高プレイヤーレベル。常に現在レベル以上 |
| `rebirthOriginalLevel` | int? | 転生前レベル。転生中だけ現在レベルより大きい値 |
| `rebirthExperienceRemainder` | int | EXPポイントへ未変換の経験値端数。0～9 |

`rebirthOriginalLevel > level` を転生中と判定する。転生完了または有償終了では `rebirthOriginalLevel=null`、端数0へ戻す。

## EXPポイント

- item ID: `99a00017`
- category: `currency`
- icon: `EXPERIENCE_BOTTLE`
- 通貨inventoryへ数量として保存する。
