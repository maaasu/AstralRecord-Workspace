# 34-rebirth ユースケース

## 転生開始

1. NPCの`REBIRTH`アクションから転生GUIを開く。
2. 現在レベルと必要Goldを表示し、転生ボタンから確認GUIへ進む。
3. 確定時にレベル2以上、非転生中、Gold残高を再検証する。
4. 現在レベル × 10,000 Goldを消費し、転生前レベルと最高到達レベルを保持してLv.1 / EXP 0へ変更する。
5. ローカル一体確定後に成功通知を表示してwrite-behind保存を要求する。ローカル処理失敗時はGoldと進行を復元する。

## 転生中の経験値獲得

1. Mob、採集、クエストで確定した実獲得EXPを受け取る。
2. 現在レベルに対応する通常必要EXPを3で除し、端数切り上げした値をレベルアップ判定に使う。
3. 獲得EXPと保存済み端数を10で除し、商の分だけEXPポイントを通貨inventoryへ追加する。
4. 転生前レベルへ到達した場合は通常累計EXP基準へ変換し、超過EXPを保持して転生状態を解除する。

## 有償終了

1. 転生中GUIから終了確認へ進む。
2. 100アストラルドを消費して転生前レベルの開始累計EXPへ戻す。
3. 未変換端数を破棄し、転生状態を解除してwrite-behind保存を要求する。
