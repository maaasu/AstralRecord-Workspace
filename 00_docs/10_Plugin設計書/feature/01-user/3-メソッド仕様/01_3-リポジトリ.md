# 01_3-リポジトリ

## 1. repository メソッド仕様

### ユーザ取得

クラス名: `UserRepository`
物理名: `findByUuid`

責務:

UUID でユーザーを取得し、404 時は警告ログを記録して `null` を返す。

処理内容:

1. `GET /api/user/{uuid}` を呼ぶ
2. `200` は [[01_1-モデル定義]].ユーザモデル へ変換して返し、`LogId.D_5055` を記録する

	| 項目 | 内容 |
	|---|---|
	| ID | `LogId.D_5055` |
	| レベル | `DEBUG` |
	| テンプレート | `ユーザーを取得しました (API): %s` |
	| 出力条件 | `GET /api/user/{uuid}` が `200` |
	| 引数 | `uuid` |

3. `404` は `LogId.W_5055` を記録して `null` を返す

	| 項目 | 内容 |
	|---|---|
	| ID | `LogId.W_5055` |
	| レベル | `WARN` |
	| テンプレート | `ユーザーが見つかりませんでした (API): %s` |
	| 出力条件 | `GET /api/user/{uuid}` が `404` |
	| 引数 | `uuid` |

4. その他ステータスは `LogId.E_5055` を記録し例外化する

	| 項目 | 内容 |
	|---|---|
	| ID | `LogId.E_5055` |
	| レベル | `ERROR` |
	| テンプレート | `ユーザーの取得に失敗しました (API): %s` |
	| 出力条件 | `GET /api/user/{uuid}` が `200/404` 以外 または 例外 |
	| 引数 | APIエラーメッセージ or 例外メッセージ |

### MCID一覧取得

クラス名: `UserRepository`
物理名: `findMcids`

`GET /api/user/mcids?prefix={prefix}` を呼び、APIが返した参加履歴ユーザーの MCID 配列を返す。第1引数補完から利用するため、prefix は URLエンコードする。非 `2xx` または JSON 変換失敗は `LogId.E_5061` を記録し例外化する。

### 同一IPユーザー有無取得

クラス名: `UserRepository`
物理名: `hasOtherByGlobalIp`

`GET /api/user/by-ip?globalIp={globalIp}&excludeUuid={uuid}` を呼び、論理削除されていない参加者本人以外の同一グローバルIPユーザーの有無だけを取得する。IPはURLエンコードし、ユーザー属性はPluginへ返さない。非 `2xx` または JSON 変換失敗はIPを含まない `LogId.E_5064` を記録し例外化する。API障害時のログイン継続と通知抑止は `UserService` が担当する。

### BAN情報更新

クラス名: `UserRepository`
物理名: `updateBan`

`PUT /api/user/{uuid}` へ `banIndefinite`, `banDate`, `updatedBy` を送信し、更新後の JSON を `UserModel` へ変換して返す。無期限時は `banDate: null` を送信する。非 `2xx` または通信・JSON変換失敗は `LogId.E_5062` を記録し例外化する。

## 2. API エンドポイント一覧

- `GET /api/user/{uuid}`
- `GET /api/user/mcids?prefix={prefix}`
- `GET /api/user/by-ip?globalIp={globalIp}&excludeUuid={uuid}`
- `POST /api/user`
- `PUT /api/user/{uuid}`
- `POST /api/user/history`

## 3. ステータスコード方針

- `GET`:
  - `200`: 正常
  - `404`: 用途に応じて `null` 返却（警告あり/なし）
  - その他: 例外
- `POST/PUT`:
  - `2xx`: 正常
  - その他: 例外

## 4. DTO/永続化対応

- 永続化相当: `dbo.user`
- 更新主体: プレイヤー UUID または [[01_1-モデル定義]].システムユーザ
