# 01_3-イベント

## 1. イベント仕様

### ログイン前イベント受付

イベント物理名: `AsyncPlayerPreLoginEvent`  
クラス名: `UserLoginEventHandler`  
物理名: `onAsyncPreLogin`

責務:

ユーザーがサーバへ参加した際の処理を実施する。

処理内容:

1. プレイヤー情報を取得する
2. 接続元IPを取得する
3. [[01_3-サービス]].ログイン前検証を実行する

	| 項目 | 内容 |
	|---|---|
	| プレイヤーUUID | `event.getUniqueId()` |
	| プレイヤー名 | `event.getName()` |
	| 接続元IP | `event.getAddress().getHostAddress()` |
| 検証内容 | BAN判定、ユーザ存在確認、未登録時の新規登録、登録済みユーザの最終参加情報更新 |

4. サービスが `BANNED` を返した場合は接続を拒否する

	| 項目 | 内容 |
	|---|---|
	| 判定 | `banIndefinite == true` または `banDate` が現在日時より未来 |
	| イベント結果 | `AsyncPlayerPreLoginEvent.Result.KICK_OTHER` |
	| メッセージ | `PlayerMsgId.P_5307`。利用規約違反による BAN と、公式Discordの問い合わせ窓口案内を含む |

5. サービスが `INITIALIZATION_FAILED` を返した場合は接続を拒否する

	| 項目 | 内容 |
	|---|---|
	| 判定 | ユーザーまたは初期アカウントの作成・補完に失敗 |
	| イベント結果 | `AsyncPlayerPreLoginEvent.Result.KICK_OTHER` |
	| メッセージ | `PlayerMsgId.P_5313`。時間をおいた再接続と、解消しない場合の問い合わせを案内する |

6. 予期しない例外時は以下ログを記録する

	| 項目 | 内容 |
	|---|---|
	| ID | `LogId.E_5000` |
	| レベル | `ERROR` |
	| テンプレート | `ユーザーのログイン前処理に失敗しました: %s` |
| 出力条件 | イベントハンドラの `try/catch` で例外発生時 |
	| 引数 | プレイヤー名（`event.getName()`） |
