# 18_1-モデル定義

## MailEntry

API の表示用メール。`MailMessage` ではなく物理名 `MailEntry` を正とする。

| フィールド | 型 | 意味 |
|:--|:--|:--|
| `id` | `String` | mail ID |
| `icon` | `String` | GUI icon material |
| `title` | `String` | 件名 |
| `body` | `String` | 本文 |
| `publishFrom` | `LocalDateTime` | 公開開始 |
| `publishTo` | `LocalDateTime?` | 公開終了 |
| `receiveOnRead` | `boolean` | 初回既読時に reward を受け取るか |
| `rewards` | `List<MailReward>` | 添付報酬 |
| `read` | `boolean` | 対象アカウントの既読状態。JSON field は `isRead` |
| `readAt` | `LocalDateTime?` | 既読日時 |

## MailReward

| フィールド | 型 | 意味 |
|:--|:--|:--|
| `itemId` | `String` | item master ID |
| `category` | `String` | item category。未指定 fallback は `material` |
| `amount` | `int` | 付与数量。0 以下は無視する |

## MailFilter

| 値 | API value | 表示 |
|:--|:--|:--|
| `ALL` | `all` | すべて |
| `UNREAD` | `unread` | 未読 |
| `READ` | `read` | 既読 |

`next()` は `ALL -> UNREAD -> READ -> ALL`。未知 API value は `ALL` に fallback する。

## 内部整合モデル

- `MailClaimKey(accountId, mailId)`: 受取の排他キー。
- `PreparedClaimRewards`: inventory へ渡す報酬と、事前生成した instance の不変組。
- `PendingOpenRequest(requestId, expectedInventory)`: GUI 非同期応答が現在の request かを検証する holder。

`claimedAt`、`templateId`、`MailGuiState` は現在の plugin model には存在しない。
