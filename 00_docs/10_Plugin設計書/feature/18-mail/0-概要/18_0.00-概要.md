# 18_0.00-概要

## 目的

ログイン中ユーザーに対して、公開期間とユーザー状態を API が判定したメール一覧を表示する。未読メールを開いたときだけ任意の報酬を NORMAL inventory へ付与し、API の既読状態とローカル付与結果を補償可能な順序で整合させる。

## 責務

- `ALL`、`UNREAD`、`READ` filter で利用可能メールを取得する。
- GUI request ごとに user ID、account ID、開いている inventory を再検証し、古い非同期応答を破棄する。
- 未読メールの reward model／instance を非同期で準備し、main thread で一括付与する。
- 付与後に API を既読化し、失敗時は inventory rollback または reconciliation を行う。
- DROP 操作で API 上のユーザー別削除状態へ更新する。

## 責務外

- メール本文・配信対象・公開期間の作成。
- welcome mail の作成や重複防止。プラグインには `createWelcomeMailIfAbsent` 相当の処理はなく、API／master data 側の責務である。
- 添付報酬以外の arbitrary command 実行。

## 整合性原則

- user ID はメール可視性・既読・削除の主体、account ID は inventory 付与先として扱う。
- 同一 `(userId, mailId)` の受取を in-flight／completed set で二重実行しない。
- API 既読化が失敗したまま報酬だけ残る状態を許容せず、rollback できない場合は 100 tick 後に再調停する。
