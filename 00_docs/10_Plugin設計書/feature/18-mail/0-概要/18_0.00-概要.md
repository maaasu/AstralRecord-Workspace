# 18_0.00-概要

## 1. 目的

`mail` feature は、プレイヤー向けメールの一覧表示、本文表示、既読化、報酬受け取りを管理する。

## 2. コンテキスト

- 初回参加者向け `welcome_mail` は mail filebase マスタで提供する。
- 既読化と報酬受け取りは同一メールで二重実行しない。
- account feature は初回導線を持つだけで、メール本文・既読・報酬の正本は本 feature とする。

## 3. 構成要素（実装単位）

- `service/MailService`
  - メール一覧取得、既読化、報酬受け取りを担う。
- `event/MailGuiEventHandler`
  - メール GUI のクリック・クローズを処理する。
- `gui/MailGuiView`
  - メール一覧・詳細 GUI を構築する。
- `model/MailMessage`, `MailReward`
  - メール本文、既読状態、報酬を表す。
