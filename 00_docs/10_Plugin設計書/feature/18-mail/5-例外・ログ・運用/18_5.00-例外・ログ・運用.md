# 18_5.00-例外・ログ・運用

## 1. 例外方針

- メール一覧取得失敗時は GUI を開かず、呼び出し元へ失敗を返す。
- 報酬配布の一部が失敗した場合、成功分だけを受け取り済みにし、失敗分は再受け取り可能な状態を維持する。
- 宛先 account と操作 account が一致しない場合は既読化・報酬受け取りを拒否する。

## 2. 運用上の注意

- `welcome_mail` の本文・報酬を変える場合は mail filebase マスタと本 feature の報酬フローを同時に確認する。
- 報酬の重複付与を避けるため、既読状態と報酬受け取り状態は別項目として扱う。
