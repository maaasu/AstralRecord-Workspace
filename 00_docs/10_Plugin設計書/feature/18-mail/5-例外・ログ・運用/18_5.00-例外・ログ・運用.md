# 18_5.00-例外・ログ・運用

## 1. 例外方針

- メール一覧取得失敗時は GUI を開かず、呼び出し元へ失敗を返す。
- 報酬モデル未解決、容量不足、部分付与、API 既読化失敗のいずれかが発生した場合は inventory snapshot へ全量ロールバックし、メールを未読のまま保つ。
- 操作開始時の user または選択 account と完了時の状態が一致しない場合は、既読化・報酬受け取りを拒否する。
- 同一 `(userId, mailId)` の受け取り処理は in-flight guard により同時実行しない。

## 2. 運用上の注意

- `welcome_mail` の本文・報酬を変える場合は mail filebase マスタと本 feature の報酬フローを同時に確認する。
- `receiveOnRead` メールでは、全報酬の exact reservation 成功後だけ既読化し、API の既読化成功を受け取り確定点とする。
