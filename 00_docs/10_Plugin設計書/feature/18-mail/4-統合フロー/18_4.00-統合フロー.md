# 18_4.00-統合フロー

## 1. 初回メール配布フロー

1. account feature が初回参加者を確定する。
2. [[18_3.00-メソッド仕様]].初回メール作成 を呼び出す。
3. `welcome_mail` が存在しない場合だけ作成する。

## 2. メール GUI フロー

1. menu feature がメール GUI を開く。
2. [[18_3.00-メソッド仕様]].メール一覧取得 を呼び出す。
3. 左クリックで [[18_3.00-メソッド仕様]].メール既読化 と [[18_3.00-メソッド仕様]].報酬受け取り を実行し、ドロップキー（通常または Ctrl 併用）でメールを一覧から削除する。右クリックや Shift+右クリックでは削除しない。
4. 戻る操作は menu feature の GUI セッション履歴にある直前画面へ戻す。履歴がない場合は戻るボタンを表示しない。

## 3. 報酬配布フロー

1. 未受け取り報酬を種類ごとに分ける。
2. 通貨は currency feature、item は inventory feature へ委譲する。
3. 成功した報酬だけを受け取り済みにする。
