# 18_3.00-メソッド仕様

## メール一覧取得

クラス名: `MailService`
物理名: `listMails`

1. accountId を検証する。
2. 対象 account のメールを取得する。
3. 期限切れを表示対象に含めるかは GUI の表示条件で判断する。

## メール既読化

クラス名: `MailService`
物理名: `markAsRead`

1. 対象メールを取得する。
2. 宛先 account と操作 account が一致することを確認する。
3. 未読の場合だけ `readAt` を設定する。
4. 既読済みの場合は成功扱いで現在状態を返す。

## 報酬受け取り

クラス名: `MailService`
物理名: `claimRewards`

1. 対象メールを取得し、未受け取り報酬を抽出する。
2. 通貨報酬は currency feature の通貨加算へ委譲する。
3. item 報酬は inventory feature の通常インベントリ付与へ委譲する。
4. 成功した報酬へ `claimedAt` を設定する。

## 初回メール作成

クラス名: `MailService`
物理名: `createWelcomeMailIfAbsent`

1. 対象 account に `welcome_mail` が存在するか確認する。
2. 存在する場合は作成せず終了する。
3. mail filebase マスタから `welcome_mail` を解決し、対象 account 宛に作成する。

## メール GUI クリック

クラス名: `MailGuiEventHandler`
物理名: `onInventoryClick`

1. メール項目の左クリックまたは Shift+左クリックは、既読化と未受け取り報酬の受け取りを実行する。
2. メール項目上でドロップキーを押した `ClickType.DROP`、または Ctrl+ドロップキーの `ClickType.CONTROL_DROP` は、`MailService.delete` を呼び出して一覧から削除する。
3. 右クリックや Shift+右クリックでは削除しない。
4. 削除または受け取り後は、同じフィルターとページ位置でメール GUI を再描画する。
