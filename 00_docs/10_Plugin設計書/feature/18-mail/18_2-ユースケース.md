# 18_2-ユースケース

## UC-18-01 一覧を開く

- 事前条件: `AstPlayer` が cache に存在する。
- 基本フロー: account ID と filter で一覧を非同期取得し、報酬 model を preload 後、同一 player／ログインセッション／account／expected inventory の場合だけ GUI を開く。
- 代替: 取得中に別 GUI へ移動した、account が変わった、切断した場合は応答を捨てる。

## UC-18-02 filter・page を切り替える

- filter slot で `ALL`、`UNREAD`、`READ` を循環し、page を 0 へ戻して再取得する。
- page 移動は holder が保持する取得済み一覧を再描画し、API を再取得しない。

## UC-18-03 メールを読む／報酬を受け取る

- LEFT または SHIFT_LEFT で `readAndReceive` を実行する。
- 既読メールは報酬を付与せず成功扱いにする。
- 未読かつ `receiveOnRead=true` なら報酬を準備・付与してから API を既読化する。
- 今回の操作で報酬が inventory に残った成功時は `GuiSound.ITEM_RECEIVE`、既読メールのクリックなど報酬を付与しない成功時は `GuiSound.SELECT` を再生する。
- 成功後は同じ filter と page で再取得する。

## UC-18-04 メールを削除する

- DROP または CONTROL_DROP で `/api/mail/{id}/delete` を呼ぶ。
- API 204 を成功、404／通信失敗を失敗として扱い、成功時に一覧を再取得する。

## UC-18-05 未読数を通知する

`countUnread(accountId)` は `UNREAD` 一覧件数を返す。呼び出し側は必要に応じて `PlayerMsgId.P_5624` を表示する。
