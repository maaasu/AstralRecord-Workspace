# 05_3-サービス

## 1. BuffService メソッド仕様

### バフ付与

クラス名: `BuffService`
物理名: `apply`

責務:

指定 `buffId` のバフをプレイヤーへ付与する。同一 `buffId` の重複保持はせず、再付与は時間更新として扱う。

処理内容:

1. [[05_3-サービス]].キャッシュ付きバフ取得 でバフタイプを取得する

	| 項目 | 内容 |
	|---|---|
	| 取得失敗 | `false` を返して終了する |
	| 取得成功 | 次手順へ進む（キャッシュ登録・ログ記録の責務は [[05_3-サービス]].キャッシュ付きバフ取得 側に委譲する） |

2. プレイヤーの期限切れバフを [[05_3-サービス]].期限切れバフ削除 で除去する
3. 同一 `buffId` のアクティブバフを [[05_3-サービス]].バフ解除 で除去する
4. 現在時刻と失効時刻を計算する

	| 項目 | 内容 |
	|---|---|
	| `now` | `LocalDateTime.now()` |
	| `durationSeconds` | `Math.max(0L, durationTicks / 20L)` |
	| `expiresAt` | `now.plusSeconds(durationSeconds)` |

5. `AstPlayer.activeBuffs` へ新規 [[05_1-モデル定義]].アクティブバフ を追加する

入力:

- `player`: 対象プレイヤー
- `buffId`: 付与するバフ ID

出力:

- `boolean`: バフを取得できて付与できた場合 `true`

例外時挙動:

- リポジトリ層の例外は `BuffRepository` 側で `RuntimeException` として伝播するため、呼び出し側で必要に応じて捕捉する。

### バフ解除

クラス名: `BuffService`
物理名: `remove`

責務:

指定 `buffId` のアクティブバフを `AstPlayer.activeBuffs` から削除する。

処理内容:

1. `AstPlayer.activeBuffs` から、`type.id` が `buffId` と一致するエントリをすべて除去する

入力:

- `player`: 対象プレイヤー
- `buffId`: 解除するバフ ID

出力:

- `boolean`: 1 件以上削除できた場合 `true`

### 期限切れバフ削除

クラス名: `BuffService`
物理名: `purgeExpired`

責務:

`AstPlayer.activeBuffs` から失効済みエントリを除去する。

処理内容:

1. 現在時刻を取得する
2. 削除前件数を保持する
3. `AstPlayer.activeBuffs` から、[[05_1-モデル定義]].アクティブバフ の失効判定が真となるエントリをすべて除去する
4. 削除前件数と現在件数の差分を削除件数として返す

入力:

- `player`: 対象プレイヤー

出力:

- `int`: 削除した件数

### バフ補正合計取得

クラス名: `BuffService`
物理名: `getTotalBonus`

責務:

指定ステータスに対するバフ補正の合計値を返す。

処理内容:

1. [[05_3-サービス]].期限切れバフ削除 を実行する
2. `flat`, `scalar` を `0.0` で初期化する
3. アクティブバフごとに [[05_1-モデル定義]].バフ補正 を走査し、対象ステータスに一致するものを集計する

	| 判定 | 集計先 |
	|---|---|
	| 対象ステータスと一致しない補正 | スキップ |
	| 補正タイプが SCALAR の補正 | scalar 合算へ加算 |
	| それ以外（FLAT 扱い） | flat 合算へ加算 |

4. 最終値「FLAT 合算 ＋ 基準値 × SCALAR 合算」を返す

入力:

- `player`: 対象プレイヤー
- `statusType`: 対象ステータス
- `baseValue`: SCALAR 補正の基準値

出力:

- `double`: バフ補正合計（FLAT 加算 + 基準値に対する SCALAR 補正）

### 有効バフ一覧取得

クラス名: `BuffService`
物理名: `getActiveBuffs`

責務:

期限切れを除去したうえで、`AstPlayer.activeBuffs` の不変コピーを返す。

処理内容:

1. [[05_3-サービス]].期限切れバフ削除 を実行する
2. `List.copyOf(player.getActiveBuffs())` を返す

入力:

- `player`: 対象プレイヤー

出力:

- `List<ActiveBuff>`: 失効除去済みのバフ一覧（変更不可）

### キャッシュ付きバフ取得

クラス名: `BuffService`
物理名: `getOrLoad`

責務:

キャッシュ優先でバフタイプを返す。未キャッシュなら API から取得してキャッシュへ登録する。

処理内容:

1. `buffCache.get(buffId)` を返す（ヒット時はそのまま返却）
2. 未ヒット時は [[05_3-リポジトリ]].バフ取得 を呼ぶ
3. 取得成功なら `buffCache.put(buffId, loaded)` し、`LogId.D_5451` を記録する

	| 項目 | 内容 |
	|---|---|
	| ID | `LogId.D_5451` |
	| レベル | `DEBUG` |
	| テンプレート | `バフ詳細をロードしました: %s` |
	| 出力条件 | API 取得成功でキャッシュ登録時 |
	| 引数 | 取得した [[05_1-モデル定義]].バフタイプ |

4. API が `404` の場合は `null`、取得成功時は取得結果を返す

入力:

- `buffId`: バフ ID

出力:

- [[05_1-モデル定義]].バフタイプ（API `404` 時は `null`）

例外時挙動:

- リポジトリ層からの例外はそのまま伝播する。

## 2. バフ獲得表示サービス

### バフ獲得通知表示

クラス名: `BuffAcquisitionDisplayService`
物理名: `show`

入力:

- 表示対象 Bukkit `Player`
- 表示対象 [[05_1-モデル定義]].アクティブバフ

処理内容:

1. 同一プレイヤーの既存 `ManagedTextDisplay` があれば破棄する
2. `BuffType.displayName`、残り `mm:ss`、先頭 modifier の status 表示名・符号付き値を組み立てる
3. `DisplayAnchor.view` でプレイヤー視界右下へ TextDisplay を生成する
4. slide-in、`54 tick` 保持、`10 tick` fade の animation を実行する
5. dynamic text で表示中の残時間を更新する

出力:

- なし
