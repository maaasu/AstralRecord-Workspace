# 05_4.00-統合フロー

## 1. バフ付与

### シーケンス

```mermaid
sequenceDiagram
    participant C as 呼び出し側
    participant S as BuffService
    participant R as BuffRepository
    participant AP as AstPlayer
    participant D as BuffAcquisitionDisplayService

    C->>S: apply(astPlayer, buffId)
    alt BuffType キャッシュ未登録
        S->>R: findById(buffId)
        R-->>S: BuffType / null
    end
    alt BuffType あり
        S->>S: purgeExpired(astPlayer)
        S->>S: remove(astPlayer, buffId)
        S->>AP: ActiveBuff を activeBuffs へ追加
        S-->>C: true
        opt item 使用側の獲得通知
            C->>D: show(player, activeBuff)
        end
    else 404 / 未検出
        S-->>C: false
    end
```

### 処理要点

- 同一 `buffId` は重複保持せず、既存エントリを削除して開始・終了時刻を更新する。
- BUFF consumable は `PotionUseService` から `StatusService.applyBuff` を経由して付与し、成功時に獲得通知を表示する。
- `BuffAcquisitionDisplayService.show` は既存通知を破棄し、視界右下へ残時間と先頭 modifier を表示する。

### 例外・終了条件

- API の 404 は未検出として `false` を返す。
- 404 以外の API 例外は呼び出し元へ伝播する。

## 2. ステータス再計算時のバフ反映

### シーケンス

```mermaid
sequenceDiagram
    participant SS as StatusService
    participant BS as BuffService
    participant AP as AstPlayer

    SS->>BS: purgeExpired(astPlayer)
    loop StatusType ごと
        SS->>SS: preBuffTotal を計算
        SS->>BS: getTotalBonus(astPlayer, type, preBuffTotal)
        BS->>AP: activeBuffs を走査
        BS-->>SS: FLAT + SCALAR 補正合計
        SS->>SS: 最終値を確定
    end
    SS-->>AP: StatusSnapshot 更新
```

### 処理要点

- `FLAT` は定数加算、`SCALAR` は `preBuffTotal * value` として加算する。
- 期限切れエントリを除外してから全有効バフの対象 `StatusType` を合算する。

## 3. バフ解除

### シーケンス

```mermaid
sequenceDiagram
    participant C as 呼び出し側
    participant S as BuffService
    participant AP as AstPlayer

    C->>S: remove(astPlayer, buffId)
    S->>AP: activeBuffs.removeIf
    AP-->>S: 削除有無
    S-->>C: boolean
```

### 処理要点

- `buffId` が一致するアクティブバフをすべて削除する。
- 戻り値は 1 件以上削除した場合だけ `true` とする。
