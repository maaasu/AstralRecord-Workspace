# 05_1-モデル定義

## 1. ドメインモデル

`buff` 機能はバフマスタを表す `BuffType` と、プレイヤーへ実際に付与されている `ActiveBuff` を中心に構成される。
補正単位は `BuffModifier`（`BuffModifierType` と `StatusType` の組合せ）で表現する。

## 2. バフタイプ

物理名: `BuffType`

`/api/buff/{buffId}` から取得するバフ定義。`file/70.shared.buff` の内容を API 経由で取り込み、本モデルへマッピングする。

### 2.1 項目

- `id`
- `type`
- `displayName`（API では `name`）
- `durationTicks`
- `isDebuff`
- `stackGroup`: 同じ値のバフを排他的に扱う重複グループ。未指定時は `id` を重複判定に使用する
- `modifiers`: [[05_1-モデル定義]].バフ補正 のリスト

## 3. バフ補正

物理名: `BuffModifier`

バフが及ぼす単一補正を表す。

### 3.1 項目

- `status`: `StatusType`
- `type`: [[05_1-モデル定義]].バフ補正タイプ
- `value`

## 4. バフ補正タイプ

物理名: `BuffModifierType`

`FLAT` / `SCALAR` の 2 種を持つ列挙体。

| 値 | 意味 |
|---|---|
| `FLAT` | 値をそのまま加算する固定補正 |
| `SCALAR` | 基準値に対する割合補正（例: `0.1` = +10%） |

API 文字列から補正タイプへの変換（物理名: `fromApiValue`）を提供する。未知の値は安全側で `FLAT` として扱う。

## 5. アクティブバフ

物理名: `ActiveBuff`

プレイヤーへ付与されているバフのセッション中状態。

### 5.1 項目

- `type`: [[05_1-モデル定義]].バフタイプ
- `startedAt`
- `expiresAt`

### 5.2 失効判定

失効判定（物理名: `isExpired`）は、判定時刻が `expiresAt` 以降であれば失効扱いとし、それより前であれば有効扱いとする。

## 6. 入出力モデル

- API 入力: なし（GET のみ）
- API 出力:
  - `GET /api/buff/{buffId}` -> [[05_1-モデル定義]].バフタイプ

## 7. 関連 feature とのモデル関係

- `player`:
  - `AstPlayer.activeBuffs: MutableList<ActiveBuff>` をセッション内で保持する。
  - 永続化はせず、サーバ再起動・プレイヤー切断などで初期化される。
- `status`:
  - `StatusType` 単位の補正合算は [[05_3-サービス]].バフ補正合計取得 を経由する。
- `item`:
  - `PotionUseService` が `ItemConsumableEffect.buffId` を `StatusService.applyBuff` へ渡す実装済み導線を持つ。
  - 付与成功時は `BuffAcquisitionDisplayService` が [[05_1-モデル定義]].アクティブバフ を表示する。
