# 05_9-未決事項

## 1. 失効バフのログ整備

`LogId` は `5450-5499` の範囲で予約されているが、現状は `D_5451` のみ定義されている。
バフ付与・解除・失効削除の各イベントをログ出力すべきかは未確定。

## 2. バフ補正の重複付与方針

`apply` は同一 `buffId` を 1 件に正規化する設計だが、`displayName` や `type` が同じで `buffId` が異なるバフの重複制御は行わない。
将来的に「同種バフは最大強度のみ残す」「累積上限を設ける」などの方針を取る場合は、`BuffType` 側に区分キーを追加する必要がある。

## 3. アクティブバフの永続化

`AstPlayer.activeBuffs` はサーバ再起動・プレイヤー切断で初期化される。
長時間バフや日次バフを扱う場合、`expiresAt` を含めた永続化方針（API / DB / ファイル）を定義する必要がある。

## 4. バフ表示の残事項

現在付与中のバフ一覧は menu feature の `PlayerDetailGui` に概要を表示し、「現在のバフ」クリックで `BuffScreenView` の詳細を表示する。
バフ獲得時の短時間通知は buff feature の `BuffAcquisitionDisplayService` が `DisplayTextService` を使って表示する。
常時 HUD への表示、`isDebuff` の見せ分け詳細、アイコン化ルールは引き続き未定義。
