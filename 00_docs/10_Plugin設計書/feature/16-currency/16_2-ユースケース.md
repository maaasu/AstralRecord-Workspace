# 16_2-ユースケース

## 1. 通貨一覧表示

1. menu feature が対象 account ID で通貨表示一覧取得を呼び出す。
2. inventory feature が `CURRENCY` entry を表示用 `ItemStack` に変換する。
3. `gold` / `ast_gold` が未所持なら 0 個の `gold` 表示を補完する。
4. `CurrencyGuiView` が一覧をページング描画し、`yggdrasil_star_core` の所持条件を満たす場合だけ slot 51 に両替アイコンを配置する。条件未達時はダミー pane を配置する。

## 2. 通貨一覧と通常インベントリ間の境界

1. 通貨一覧の上部 item は残高表示専用であり、クリックしても `CURRENCY` から通常 BAG へ移動しない。
2. 下部のプレイヤーインベントリにある通貨 item は、左クリック 1、右クリック半分、Shift+左クリック 1 スタック、Shift+右クリック全量の規則で `CURRENCY` へ戻す。
3. 下部で Shift+右クリックした場合は、基準 slot と同じ item ID を BAG・ホットバー全体から戻す。
4. 収納失敗時は snapshot を復元し、残高と通常インベントリを片側だけ変更しない。

## 3. 両替

1. NPC interaction `CURRENCY_EXCHANGE`、または解除済みの通貨一覧アイコンから両替 GUI を開く。
2. 左クリックは選択額面を 1 段階上へまとめ、右クリックは 1 段階下へ崩す。
3. Shift 付きクリックは交換可能な全口数を対象にする。
4. `InventoryService.exchangeCurrency` が交換前後のゴールド価値を検証し、同一 snapshot 内で元額面を減算して先額面を加算する。

## 4. ゴールド支払い

1. shop、trade、world、teleporter などの呼び出し元が基本ゴールド値を確定する。
2. `InventoryService.consumeGold` が全額面と互換 ID の合計を検証する。
3. 低額面から消費し、不足分だけ上位額面を崩す。
4. 失敗時は通貨 state を変更せず `false` を返し、呼び出し元は後続処理を行わない。

## 5. 通貨報酬

1. mob / mail などが item ID、カテゴリ、数量を持つ報酬を inventory feature へ渡す。
2. item カテゴリが `currency` の場合、inventory feature が付与先を `CURRENCY` に解決する。
3. `gold` 値を直接加算する経路では `InventoryService.addGold` が額面へ分解して加算する。
