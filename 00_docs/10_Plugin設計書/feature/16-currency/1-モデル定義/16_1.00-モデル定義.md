# 16_1.00-モデル定義

## 1. 通貨残高

物理名: `CurrencyBalance`

| 項目 | 説明 |
|---|---|
| `accountId` | 対象アカウント UUID |
| `currencyId` | 通貨 ID。例: `gold`, `astrald` |
| `amount` | 残高。0 以上の整数 |
| `updatedAt` | 最終更新日時 |

## 2. 通貨変更要求

物理名: `CurrencyChangeRequest`

| 項目 | 説明 |
|---|---|
| `accountId` | 対象アカウント UUID |
| `currencyId` | 対象通貨 ID |
| `amount` | 加算または減算する数量 |
| `reason` | 変更理由。例: `mob_drop`, `mail_reward`, `shop_purchase` |
| `sourceId` | 参照元イベントや取引の ID。任意 |

## 3. 通貨表示項目

物理名: `CurrencyDisplayItem`

| 項目 | 説明 |
|---|---|
| `currencyId` | 通貨 ID |
| `amount` | 表示残高 |
| `itemStack` | GUI 表示用 ItemStack |

## 4. 通貨種別

| 通貨 ID | 表示方針 |
|---|---|
| `gold` | 1ゴールド相当の「ルーンの金片」 |
| `gold_coin` | 10ゴールド相当の「ヴァルハラの金貨」 |
| `gold_ingot` | 100ゴールド相当の「ミズガルズの黄金インゴット」 |
| `gold_block` | 1,000ゴールド相当の「アースガルズの黄金ブロック」 |
| `gold_diamond` | 10,000ゴールド相当の「ビフレストのダイヤ」 |
| `gold_diamond_block` | 100,000ゴールド相当の「神域のダイヤ結晶」 |
| `yggdrasil_star_core` | 1,000,000ゴールド相当の「ユグドラシルの星核」 |
| `astrald` | 所持または報酬導線がある場合に表示する |

ゴールド系7額面はすべて `currency.type=gold`、`currency.group=denomination` の組み込みアイテムとし、プレイヤー間取引へ出せる。売却はできない。
