# 16_1.00-モデル定義

## 1. ゴールド額面

物理名: `GoldDenomination`

| 項目 | 説明 |
|:--|:--|
| `itemId` | `CURRENCY` entry と item マスタで使う ID |
| `displayName` | 両替 GUI の表示名 |
| `icon` | Bukkit `Material` 名。解決不能時は `GOLD_NUGGET` |
| `goldValue` | 基本額面 `gold` に換算した 1 個の価値 |

列挙順は低額面から高額面である。`lower()` / `higher()` は隣接額面、`lowerExchangeRatio()` は 1 個を直下へ崩す個数、`highest()` は `YGGDRASIL_STAR_CORE` を返す。

## 2. 通貨残高

独立した `CurrencyBalance` は存在しない。物理的な正本は inventory feature の `InventoryModel` と `InventoryEntryModel` である。

| 項目 | 説明 |
|:--|:--|
| `InventoryModel.inventoryType` | `CURRENCY` |
| `InventoryModel.accountId` | 所有アカウント UUID |
| `InventoryEntryModel.itemId` | 通貨 item ID |
| `InventoryEntryModel.quantity` | 0 より大きい所持数量 |

同一 item ID の entry は `InventoryService.normalizeCurrencyEntries` で集約する。API 保存用の inventory / entry モデルと dirty state は inventory feature の設計に従う。

## 3. 通貨表示 item

物理名: `ItemStack`

通貨一覧は専用 `CurrencyDisplayItem` を持たず、`CurrencyService.getCurrencyItemStacks` が表示用 `ItemStack` の一覧を返す。item ID とカテゴリは `ItemReferenceResolver` で再解決する。

## 4. ゴールド計算結果

`GoldCurrencyCalculator.decompose` と `spendSmallestFirst` は `Map<GoldDenomination, Long>` を返す。支払い不足、負数、釣り銭加算の桁あふれでは `spendSmallestFirst` が `null` を返す。
