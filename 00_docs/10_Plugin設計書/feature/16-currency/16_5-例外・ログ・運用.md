# 16_5-例外・ログ・運用

## 1. 例外・補償方針

- `CurrencyService` は API I/O を行わず、ロード済み inventory state を参照する。
- 通貨収納、消費、額面交換は inventory feature の snapshot / restore を補償境界とする。`CURRENCY` から通常 BAG への取り出し経路は提供しない。
- 残高不足、item 未解決、state 未ロード、等価でない交換、桁あふれは戻り値で失敗を返し、部分更新を残さない。
- 呼び出し元 feature は支払い失敗時に商品付与、転送、成立処理などを続行しない。

## 2. プレイヤー向けメッセージ

| ID | 内容 | 出力条件 |
|:--|:--|:--|
| `PlayerMsgId.P_6800` | ユグドラシルの星核を所持していないため、ここからは両替できません。両替商を利用してください。 | 通貨一覧のロック中両替アイコンをクリック |

両替そのものの不成立は現行実装では拒否音だけで通知する。

## 3. ログ

| ID | レベル | テンプレート | 出力条件 | 引数 |
|:--|:--|:--|:--|:--|
| `LogId.E_5601` | ERROR | `GUI イベント処理に失敗しました: player=%s, operation=%s` | 両替 GUI click / drag の `runSafely` で例外 | プレイヤー名、`currency_exchange_click` / `currency_exchange_drag` |

## 4. 運用

- 額面 ID、表示名、icon、換算値は現行 `GoldDenomination` の組み込み定義である。変更時は item 定義と既存 `CURRENCY` entry の互換性を確認する。
- `ast_gold` は移行互換 ID であり、新規表示の正本は `gold` とする。
- 両替商の NPC 定義と配置は mob filebase / placement 運用に従う。shop master は使わない。
- 通貨の永続化タイミングは inventory feature の autosave、logout、disable、明示保存に従う。
