# 16_2.00-ユースケース

## 1. 通貨一覧表示

1. menu feature が通貨 GUI を開く。
2. [[16_3.00-メソッド仕様]].通貨表示一覧取得 が account の通貨残高を取得する。
3. item feature の表示ルールを使い、通貨 ItemStack 一覧へ変換する。
4. メニューのカレンシーアイコンは「合計ゴールド」を先頭に表示し、仕切りの後へ所持通貨種別を最大10件表示する。11件以上は `…` で省略する。

## 2. 通貨 GUI からの取り出し

1. プレイヤーが通貨 GUI の通貨 ItemStack をクリックする。
2. 左クリックは1個、右クリックは半分（切り上げ）、Shift+左クリックは1スタック、Shift+右クリックは全量を取り出し数量とする。
3. currency feature が対象通貨を CURRENCY から減算し、inventory feature が通常 BAG へ通貨アイテムを追加する。
4. BAG に空きがない場合は CURRENCY と BAG の変更を行わない。

## 3. 通貨 GUI への収納

1. 通貨 GUI 下部のプレイヤーインベントリにある通貨アイテムをクリックする。
2. 左クリックは1個、右クリックはクリックしたスタックの半分（切り上げ）、Shift+左クリックはクリックした1スタック、Shift+右クリックは BAG・ホットバー全体の同一通貨を収納数量とする。
3. inventory feature が通常 BAG／ホットバーから通貨アイテムを取り出し、CURRENCY へ無制限スタックで戻す。

## 4. 通貨アイテムクリックによる GUI 起動

1. 通貨 GUI 以外でプレイヤーインベントリの通貨アイテムをクリックする。
2. 通常のアイテム移動を行わず、通貨 GUI を自動で開く。

## 5. Mob 撃破報酬

1. mob feature が撃破処理で金銭報酬を確定する。
2. [[16_3.00-メソッド仕様]].通貨加算 を呼び出す。
3. 加算成功後、必要に応じて対象プレイヤーへ報酬表示を返す。

## 6. メール報酬

1. mail feature が既読化時に報酬通貨を解決する。
2. [[16_3.00-メソッド仕様]].通貨加算 を呼び出す。
3. 同一メールを二重に既読処理しないよう、mail feature 側の既読状態を正本とする。

## 7. ショップ購入

1. shop feature が購入価格を検証する。
2. [[16_3.00-メソッド仕様]].ゴールド自動減算 を呼び出す。
3. 全ゴールド額面の合計値で支払い可否を判定する。
4. 支払後残高を最上位額面から順に再構成し、shop feature が商品付与を行う。

## 8. NPC両替所

1. プレイヤーが専用NPC `currency_exchange_clerk` を右クリックする。
2. mob feature が Plugin 独自の両替GUIを開く。filebase の shop master は使用しない。
3. プレイヤーは対象額面を左クリックして上位額面へまとめ、右クリックして下位額面へ崩す。Shift付き操作は交換可能な全量を対象にする。
4. currency / inventory feature が交換元通貨を CURRENCY から減算し、等価な交換先通貨を CURRENCY へ加算する。
5. 途中失敗時は交換前の inventory state へ復元する。
6. カレンシーGUIには両替アイコンを常設し、`yggdrasil_star_core` を1個以上所持する場合だけ両替GUIを開く。未所持時は利用条件をメッセージ表示する。
