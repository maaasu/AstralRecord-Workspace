# 16_3-メソッド仕様

## 通貨表示一覧取得

クラス名: `CurrencyService`
物理名: `getCurrencyItemStacks`

- 引数: `UUID accountId`
- 戻り値: 表示用 `List<ItemStack>`。state 未ロード時も `gold` 0 個表示を返し得る。
- 例外: 独自に捕捉しない。

1. `InventoryService.getInventoryItemStacks(accountId, InventoryType.CURRENCY)` へ委譲する。
2. inventory feature が entry を正規化し、表示 item を生成する。

## ゴールド残高取得

クラス名: `CurrencyService`
物理名: `getGoldAmount`

- 引数: `UUID accountId` または `Player player`
- 戻り値: 全額面を基本ゴールドへ換算した `long`。プレイヤーデータ未ロード時は 0。
- 例外: なし

1. `InventoryService.getGoldAmount` へ委譲する。
2. 7 額面と `ast_gold` を合算し、桁あふれ時は `Long.MAX_VALUE` へ飽和する。

## 通貨残高取得

クラス名: `CurrencyService`
物理名: `getCurrencyAmount`

- 引数: `UUID accountId`, `String itemId`
- 戻り値: 同一 item ID の合計数量。未ロード・未所持時は 0。
- 例外: なし

`getDisplayCurrencyAmount` は基本額面 `gold` のときだけ `ast_gold` を加算する。

## 上位額面交換

クラス名: `CurrencyService`
物理名: `exchangeUp`

- 引数: `UUID accountId`, `GoldDenomination source`, `boolean all`
- 戻り値: 1 口以上の等価交換が完了した場合 `true`
- 例外: 独自に捕捉しない。

1. `source.higher()` と交換比率を解決し、上位額面がなければ `false` を返す。
2. 所持量から 1 口または全口数を計算する。
3. `InventoryService.exchangeCurrency` へ交換元・先の数量を渡す。

## 下位額面交換

クラス名: `CurrencyService`
物理名: `exchangeDown`

- 引数: `UUID accountId`, `GoldDenomination source`, `boolean all`
- 戻り値: 1 口以上の等価交換が完了した場合 `true`
- 例外: 独自に捕捉しない。

1. `source.lower()` と `lowerExchangeRatio()` を解決し、下位額面がなければ `false` を返す。
2. 全量交換時の乗算が `long` を超える場合は `false` を返す。
3. `InventoryService.exchangeCurrency` へ委譲する。

## 通貨 item ID 解決

クラス名: `CurrencyService`
物理名: `getCurrencyItemId`

- 引数: `ItemStack itemStack`（`null` 可）
- 戻り値: 通貨 item ID。AstralRecord item でない、またはカテゴリが `CURRENCY` でない場合は `null`。
- 例外: なし

## 両替 GUI 表示

クラス名: `CurrencyExchangeGuiEventHandler`
物理名: `open`

- 引数: `Player player`
- 戻り値: なし
- 例外: なし

1. `AstPlayer` と `AccountMode.PLAYER` を検証し、不成立なら拒否音で終了する。
2. `CurrencyExchangeGuiView.open` へ account ID と `CurrencyService` を渡す。

## 両替 GUI クリック

イベント物理名: `InventoryClickEvent`
クラス名: `CurrencyExchangeGuiEventHandler`
物理名: `onInventoryClick`

- 引数: `InventoryClickEvent event`
- 戻り値: なし
- 例外: `runSafely` が捕捉する。

1. holder が両替 GUI でなければ終了し、対象 GUI なら標準クリックを cancel する。vanilla item 移動によって受信前から cancel 済みの場合も、対象 holder の両替操作は処理する。
2. close slot は GUI を閉じる。
3. 額面 slot の左 / 右クリックを上位 / 下位額面交換へ振り分け、Shift 状態を `all` に渡す。
4. 成功時は同じ account の残高で GUI を再描画し、失敗時は拒否音を鳴らす。
5. 例外時は `LogId.E_5601`（`GUI イベント処理に失敗しました: player=%s, operation=%s`）へプレイヤー名と `currency_exchange_click` を渡す。

## ゴールド消費（inventory 委譲）

クラス名: `InventoryService`
物理名: `consumeGold`

- 引数: `UUID accountId`, `long amount`
- 戻り値: 全量を消費できた場合 `true`。0 以下は変更せず `true`。
- 例外: 独自に捕捉しない。

全額面を一度取り除いて計算後残高を再構築する。再構築に失敗した場合は取得済み snapshot を復元する。

## 等価交換（inventory 委譲）

クラス名: `InventoryService`
物理名: `exchangeCurrency`

- 引数: account ID、交換元 item ID / 数量、交換先 item ID / 数量
- 戻り値: 価値が等しい交換を完了した場合 `true`
- 例外: 独自に捕捉しない。

組み込み額面、正の数量、同値の総価値、所持量を検証し、途中失敗時は snapshot を復元する。
