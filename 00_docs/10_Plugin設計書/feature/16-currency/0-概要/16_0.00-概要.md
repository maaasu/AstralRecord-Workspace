# 16_0.00-概要

## 1. 目的

`currency` feature は、アカウント単位の通貨残高を取得・加算・減算し、GUI 表示用の通貨 ItemStack 一覧を提供する。

## 2. コンテキスト

- 通貨の所持状態は account に紐づく。
- ゴールド系通貨は `gold`（1）、`gold_coin`（10）、`gold_ingot`（100）、`gold_block`（1,000）の4額面とする。
- `gold` は未所持でも `0` 表示対象に含める。
- `astrald` は所持エントリ、初回メール報酬、または運用で明示された場合に表示対象へ含める。
- item feature は通貨カテゴリの見た目を持つが、残高の正本は本 feature とする。
- モブ報酬、メール報酬、NPC報酬などシステムからの通貨付与は、通貨 ItemStack を通常インベントリへ生成せず CURRENCY へ直接加算する。
- 通貨 GUI のクリック操作だけが、通貨を通常 BAG へアイテムとして取り出す経路となる。通常 BAG の通貨アイテムは通貨 GUI へ戻せる。
- CURRENCY の通貨 entry は通常のスタック上限を持たず、通貨種別ごとに数量を集約する。所持上限は設けない。
- ゴールド系額面の相互交換は専用NPCから開く両替GUIで行い、コマンドおよびメニューから両替GUIを開かない。

## 3. 構成要素（実装単位）

- `service/CurrencyService`
  - 残高取得、通貨加算、通貨減算、表示用 ItemStack 一覧の生成を担う。
- `model/CurrencyBalance`
  - account 単位の通貨残高を表す。
- `repository/CurrencyRepository`
  - API または永続化層との通信を担う。
- `gui/CurrencyGuiView`
  - 通貨一覧 GUI の表示を担う場合の View。
