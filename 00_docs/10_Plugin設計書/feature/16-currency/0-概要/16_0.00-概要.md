# 16_0.00-概要

## 1. 目的

`currency` feature は、アカウントの `CURRENCY` インベントリを通貨 GUI へ表示し、組み込みゴールド額面の合計・交換を提供する。残高モデル、API repository、独立した永続化処理は持たず、実行中の正本と保存境界は inventory feature に委譲する。

## 2. 通貨の保持方針

- 通貨は `PlayerInventoryState` 内の `InventoryType.CURRENCY` に item ID ごとの entry として保持する。
- `CURRENCY` は同一 item ID を集約し、通常のスタック上限を適用しない。
- `gold` entry がない場合も通貨一覧には 0 個の表示 item を補完する。
- 基本額面 `gold` は互換 ID `ast_gold` を残高取得・消費・表示で合算する。
- 報酬 item のカテゴリが `currency` の場合、inventory feature が通常 BAG ではなく `CURRENCY` を付与先に選ぶ。

## 3. 組み込みゴールド

`GoldDenomination` は次の 7 額面を低額面順に定義する。

| item ID | 表示名 | ゴールド換算値 |
|:--|:--|--:|
| `gold` | ルーンの金片 | 1 |
| `gold_coin` | ヴァルハラの金貨 | 10 |
| `gold_ingot` | ミズガルズの黄金インゴット | 100 |
| `gold_block` | アースガルズの黄金ブロック | 1,000 |
| `gold_diamond` | ビフレストのダイヤ | 10,000 |
| `gold_diamond_block` | 神域のダイヤ結晶 | 100,000 |
| `yggdrasil_star_core` | ユグドラシルの星核 | 1,000,000 |

支払いは低額面を優先し、不足する場合だけ所持中の上位額面を 1 個崩して釣り銭を生成する。合計値や中間演算が `long` 上限を超える場合は飽和または失敗として扱う。

## 4. GUI

- 通貨一覧は menu feature の 54 slot ページング GUI で表示する。
- 通貨 item のクリックで `CURRENCY` から通常 BAG へ取り出し、下部のプレイヤーインベントリからは `CURRENCY` へ戻す。
- 通貨一覧の slot 51 に両替アイコンを表示する。`yggdrasil_star_core` を 1 個以上所持する場合だけ同アイコンから両替 GUI を開ける。
- NPC interaction `CURRENCY_EXCHANGE` からは所持条件なしで両替 GUI を開く。
- 両替 GUI は隣接額面間の等価交換だけを行う。

## 5. 構成要素

| 物理名 | 責務 |
|:--|:--|
| `CurrencyService` | 通貨表示、残高参照、額面交換、通貨 item 判定 |
| `GoldDenomination` | 組み込み額面、表示情報、隣接額面 |
| `GoldCurrencyCalculator` | 合計、分解、低額面優先支払い |
| `CurrencyGuiView` | 通貨一覧のページング描画と両替アイコン |
| `CurrencyExchangeGuiView` | 両替 GUI 描画 |
| `CurrencyExchangeGuiEventHandler` | 両替 GUI の open / click / drag |
