# 16_3.00-メソッド仕様

## 通貨表示一覧取得

クラス名: `CurrencyService`
物理名: `getDisplayItems`

1. accountId から残高一覧を取得する。
2. `gold` が存在しない場合は `0` の表示項目を補完する。
3. item feature の通貨カテゴリ定義を使って ItemStack を生成する。
4. 表示順に並べた [[16_1.00-モデル定義]].通貨表示項目 を返す。

## 通貨 GUI から通常 BAG への取り出し

クラス名: `InventoryService`
物理名: `withdrawCurrencyToNormalInventory`

1. 通貨 ItemStack から通貨カテゴリと item ID を解決する。
2. 指定数量を CURRENCY の対象通貨残高以内に制限する。
3. 通常 BAG へアイテムを追加し、追加できた数量だけ CURRENCY から減算する。
4. BAG に追加できない場合、CURRENCY の残高を変更せず 0 を返す。

## 通常 BAG から CURRENCY への収納

クラス名: `InventoryService`
物理名: `moveOwnedCurrencyToCurrency`, `moveAllOwnedMatchingCurrencyToCurrency`

1. 指定された BAG またはホットバーの entry が通貨カテゴリであることを検証する。
2. 指定数量を通常インベントリから取り出す。
3. 取り出した通貨 ItemStack を CURRENCY へ集約する。
4. CURRENCY への追加に失敗した場合は元の state へ復元する。
5. Shift+右クリック時は `moveAllOwnedMatchingCurrencyToCurrency` を使い、基準 slot と同一 itemId の通貨を BAG・ホットバー全体から一括で戻す。

## 通貨加算

クラス名: `CurrencyService`
物理名: `add`

1. [[16_1.00-モデル定義]].通貨変更要求 の `amount` が 1 以上であることを検証する。
2. 対象残高を取得し、存在しない場合は 0 から開始する。
3. 残高へ `amount` を加算する。
4. 更新結果を永続化し、更新後残高を返す。

## 通貨減算

クラス名: `CurrencyService`
物理名: `subtract`

1. [[16_1.00-モデル定義]].通貨変更要求 の `amount` が 1 以上であることを検証する。
2. 対象残高を取得し、不足する場合は失敗を返す。
3. 残高から `amount` を減算する。
4. 更新結果を永続化し、更新後残高を返す。

## 指定通貨の減算

クラス名: `InventoryService`
物理名: `consumeCurrency`

1. accountId、通貨 item ID、数量を受け取る。
2. CURRENCY の同一 item ID の残高を検証する。
3. 全量を減算できる場合だけ通貨 entry を更新する。
4. `gold` の場合は互換 ID `ast_gold` も合算して消費する。
5. 両替所では交換開始時の inventory snapshot と組み合わせ、交換先付与失敗時に復元する。

## 通貨残高取得

クラス名: `CurrencyRepository`
物理名: `findByAccountId`

1. accountId に紐づく通貨残高を取得する。
2. 取得失敗時は呼び出し元へ例外を返し、表示側でフォールバックを判断する。
