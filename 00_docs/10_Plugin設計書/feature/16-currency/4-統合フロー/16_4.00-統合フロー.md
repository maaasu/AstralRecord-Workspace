# 16_4.00-統合フロー

## 1. 通貨 GUI 表示フロー

1. menu feature が通貨 GUI 導線を受け付ける。
2. [[16_3.00-メソッド仕様]].通貨表示一覧取得 を呼び出す。
3. 取得した表示項目を GUI に配置する。
4. 通貨 GUI の通貨 ItemStack は左クリック1個、右クリック半分、Shift+左クリック1スタック、Shift+右クリック全量で通常 BAG へ取り出せる。全量指定でも BAG の空き容量までを移動する。
5. GUI 下部のプレイヤーインベントリにある通貨 ItemStack は同じ数量規則で CURRENCY へ戻せる。Shift+右クリックでは BAG・ホットバー全体の同一通貨を一括で戻す。
6. GUI の戻る操作は menu feature の遷移仕様へ戻す。
7. 戻るボタンから1枠空けた slot 51 にエメラルドの両替アイコンを常時表示する。`yggdrasil_star_core` 所持時は両替GUIを開き、未所持時は利用できない理由をメッセージ表示する。

## 2. 報酬加算フロー

1. mob / mail などの呼び出し元 feature が報酬金額を確定する。
2. [[16_1.00-モデル定義]].通貨変更要求 を組み立てる。
3. [[16_3.00-メソッド仕様]].通貨加算 を呼び出す。
4. 失敗時は呼び出し元 feature の報酬処理方針に従い、必要なログを残す。

## 3. 支払いフロー

1. shop feature が購入価格を確定する。
2. [[16_3.00-メソッド仕様]].ゴールド自動減算 を呼び出す。
3. 全額面の合計値で支払い可否を判定し、低額面から優先して消費する。不足時だけ上位額面を崩して釣り銭を作る。
4. 減算成功後に shop feature が商品付与を行う。減算失敗時は商品付与を行わない。

## 4. NPC両替フロー

1. `currency_exchange_clerk` の右クリック interaction `type=CURRENCY_EXCHANGE` が Plugin 独自の両替GUIを開く。
2. プレイヤーはクリックした額面を隣接する上位または下位額面へ交換する。
3. GUI保護処理でクリックイベントがキャンセル済みでも、専用ハンドラーは額面スロットの操作を受け取り、アイテム移動を禁止したまま両替処理だけを実行する。
4. inventory snapshot を取得し、指定額面の減算、交換先額面の加算を順に行う。
5. 途中失敗時は snapshot を復元する。
6. shop master、`/shop`、ショップ補完には依存しない。
