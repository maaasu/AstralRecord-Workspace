# 21_0-概要

## 目的

player が倒した ENEMY／BOSS の回数と初回・最終時刻を account 単位で蓄積し、魔物録、厄災録、drop item 逆引きとして閲覧できるようにする。

## 責務

- 討伐確定後に API へ `accountId`、`mobId`、category、`userId` を非同期送信する。
- account の討伐記録一覧とロード済み `MobTemplate` を結合する。
- `ALL`、`ENEMY`、`BOSS`、`SEARCH` の一覧を生成する。
- 冒険記録一覧のカテゴリフィルター候補（すべて／エネミーのみ／ボスのみ）を表示する。
- 検索 slot に置かれた AstralRecord item ID と、hidden でない Mob drop item ID を照合する。
- player setting の super mode が有効なら未討伐のロード済み Mob も表示する。
- 非同期 GUI request の request ID と player／account 状態を検証し、GUI close 時に request を無効化して古い応答を破棄する。

## 責務外

- 他 player の冒険記録閲覧。現在は viewer 自身の account だけを対象とする。
- drop chance の再計算や hidden drop の開示。

## 現在の契約

- 保存対象 category は `ENEMY` と `BOSS` のみ。
- 冒険記録を開いた直後は `ALL`（ENEMY／BOSS 横断）の一覧を表示し、カテゴリフィルターで `ENEMY` または `BOSS` に限定できる。
- 通常 mode は API に記録がある Mob のみ、super mode はロード済み未討伐 Mob を追加する。
- SEARCH は ENEMY／BOSS を横断し、選択 item のいずれかを visible drop に持つ Mob を返す。
- page 移動は holder の entry snapshot を使い、API を再取得しない。

## 依存・連携

| feature | 依存内容 |
|:--|:--|
| infrastructure / API | Mob 討伐記録の取得・加算 |
| mob | MobTemplate、category、drop 定義、討伐確定 |
| player / player-setting | account／user identity、super mode |
| item / menu | drop item 検索 slot と GUI navigation |

## 変更影響

- API record schema／endpoint を変更した場合は [[21_1-モデル定義]]、[[21_3-メソッド仕様]] と API 設計書を更新する。
- 一覧種別、検索、super mode を変更した場合は [[21_2-ユースケース]] と [[21_4-統合フロー]]を更新する。
- 討伐記録の対象・呼出位置を変更した場合は mob feature と [[21_3-メソッド仕様]]を更新する。
