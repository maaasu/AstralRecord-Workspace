# 21_4.00-統合フロー

## 1. GUI 表示フロー

1. menu feature などの導線から冒険記録 GUI を開く。
2. [[21_3.00-メソッド仕様]].冒険記録取得 を呼び出す。
3. [[21_3.00-メソッド仕様]].冒険記録 GUI 表示 がサマリを描画する。
4. 戻る操作は呼び出し元導線へ戻す。

## 2. 記録更新フロー

1. 呼び出し元 feature が記録対象イベントを確定する。
2. [[21_3.00-メソッド仕様]].記録イベント反映 を呼び出す。
3. 失敗時は呼び出し元 feature の処理を継続するか、運用ログで検知する。
