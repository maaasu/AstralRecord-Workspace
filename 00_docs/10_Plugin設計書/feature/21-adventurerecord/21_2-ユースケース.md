# 21_2-ユースケース

## UC-21-01 討伐を記録する

- `MobCombatService` が報酬 recipient ごとに `recordDefeatAsync` を呼ぶ。
- Mob category が ENEMY／BOSS の場合だけ API の defeat endpoint へ送る。
- API 側が account・mob の記録を作成または count 加算する。

## UC-21-02 冒険記録一覧を開く

- main GUI の冒険記録アイコンを選ぶと `ALL` 一覧を開く。
- account ID とカテゴリ未指定で record を非同期取得する。
- record の mob ID をロード済み template へ結合し、holder snapshot で list GUI を開く。
- 一覧下部のカテゴリフィルターから `すべて`、`エネミーのみ`、`ボスのみ` を選ぶと、選択カテゴリの一覧を再取得する。

## UC-21-03 drop item から Mob を検索する

- SEARCH 画面の専用 slot に最大 slot 数まで item を置く。
- search button で AstralRecord item IDs を収集する。
- ENEMY／BOSS template の hidden でない直接 drop、またはロード済み lootTable の候補のいずれかに一致する Mob を表示する。
- player inventory の AstralRecord item を click すると clone を検索条件へ追加する。drag とその他の標準操作は cancel する。

## UC-21-04 super mode で未討伐を表示する

- user setting `ADVENTURE_RECORD_SUPER_MODE=true` の場合に有効。
- API record に加え、条件一致するロード済み template の未収録分を mob ID 順で追加する。
- 未討伐 entry は討伐情報を持たない表示にする。

## UC-21-05 page・back 操作

- page は holder の entry snapshot を再利用する。
- 通常一覧の戻る操作は menu navigation、search result の戻る操作は search 条件画面に戻る。

## UC-21-06 Mob のステータスを確認する

- Mob 一覧の item を click すると、選択した `Entry` の Mob 情報画面を開く。
- Mob 情報画面は player 情報画面と同じく、リソース／基本能力値／攻撃／防御／属性／状態異常／ユーティリティのカテゴリ項目を表示する。
- カテゴリ項目を click すると、`MobTemplate.baseStats` の認識済みかつ非ゼロの基礎ステータスを `StatusType` の表示定義で詳細表示する。
- 詳細画面の page／戻る操作は GUI navigation と `PagedGuiView` を使う。表示値は静的テンプレート値であり、ワールド上の MobInstance の現在値ではない。
