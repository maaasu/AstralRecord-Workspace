# 21_4-統合フロー

## 1. 討伐保存

### シーケンス

```mermaid
sequenceDiagram
    participant Combat as MobCombatService
    participant Record as AdventureRecordService
    participant Repo as AdventureRecordRepository
    participant API as Adventure Record API
    Combat->>Record: recordDefeatAsync(recipient, template)
    alt ENEMY または BOSS
        Record->>Repo: recordMobDefeat(...)(async)
        Repo->>API: POST /api/adventure-record/mob/defeat
    else 対象外category
        Record-->>Combat: 何もしない
    end
```

### 処理要点

- party 報酬 recipient ごとに各 account の記録を加算する。
- API 通信は Bukkit main thread 外で行う。

### 例外・終了条件

- 保存失敗は gameplay を rollback せず `LogId.E_6550` に mob ID と例外を記録する。

## 2. 冒険記録一覧表示

### シーケンス

```mermaid
sequenceDiagram
    actor Player as プレイヤー
    participant Handler as AdventureRecordGuiEventHandler
    participant Service as AdventureRecordService
    participant Repo as AdventureRecordRepository
    participant Mob as MobService
    Player->>Handler: 冒険記録を開く（ALL）またはカテゴリを選択
    Handler->>Service: buildEntriesAsync(...)
    Service->>Repo: findMobRecords(accountId, category)
    Service->>Mob: record.mobIdのtemplate解決
    opt super mode
        Service->>Mob: getLoadedMobIds()
    end
    Service-->>Handler: EntryResult(main thread)
    Handler->>Handler: request ID・player・account再検証
    Handler-->>Player: list GUI
```

### 処理要点

- API record に対応する template が未ロードなら表示しない。
- page 移動は取得済み entries を holder に保持して再描画する。

### 例外・終了条件

- API 失敗、古い request、account 変更、GUI close 後は response を表示しない。

## 3. Drop item 検索

### シーケンス

```mermaid
sequenceDiagram
    actor Player as プレイヤー
    participant GUI as AdventureRecordGui
    participant Handler as AdventureRecordGuiEventHandler
    participant Service as AdventureRecordService
    Player->>GUI: search slotへitem配置
    Player->>Handler: 検索実行
    Handler->>GUI: selectedItemIds()
    Handler->>Service: buildEntriesAsync(SEARCH, ids)
    Service->>Service: ENEMY/BOSS・visible dropsを照合
    Service-->>Player: 検索結果
```

### 処理要点

- hidden drop は検索対象外。
- 複数 item は OR 条件。
- empty IDs は ENEMY／BOSS 全件条件となる。

### 例外・終了条件

- AstralRecord item ID を解決できない item は検索条件にならない。

## 4. GUI event 保護

### シーケンス

```mermaid
sequenceDiagram
    actor Player as プレイヤー
    participant Handler as AdventureRecordGuiEventHandler
    participant GUI as AdventureRecordGui
    Player->>Handler: click / drag / close
    Handler->>GUI: holderとscreen確認
    alt SEARCH item slot
        Handler->>GUI: 選択itemを更新
    else filter
        Handler->>Handler: カテゴリ候補を表示
    else navigation
        Handler->>GUI: list/search/pageへ遷移
    end
```

### 処理要点

- click、drag、close はそれぞれ `E_5601` の固有 operation を持つ。

### 例外・終了条件

- holder が対象外なら event を変更しない。
