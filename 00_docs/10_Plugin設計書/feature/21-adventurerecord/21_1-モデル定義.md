# 21_1-モデル定義

## AdventureMobRecord

| フィールド | 型 | 意味 |
|:--|:--|:--|
| `recordId` | `UUID` | record ID |
| `accountId` | `UUID` | 所有 account |
| `mobId` | `String` | Mob master ID |
| `category` | `MobCategory` | `ENEMY` または `BOSS` |
| `defeatCount` | `long` | 討伐回数 |
| `firstDefeatedAt` | `Instant` | 初回討伐時刻 |
| `lastDefeatedAt` | `Instant` | 最新討伐時刻 |

## AdventureRecordListType

| 値 | title | category filter |
|:--|:--|:--|
| `ALL` | 冒険記録 | `ENEMY`／`BOSS` |
| `ENEMY` | 魔物録 | `MobCategory.ENEMY` |
| `BOSS` | 厄災録 | `MobCategory.BOSS` |
| `SEARCH` | モブ検索結果 | category なし。ENEMY／BOSS を service 側で許可 |

`ALL` は冒険記録を開いた直後の初期一覧であり、ENEMY と BOSS を横断する。`ENEMY`／`BOSS` は一覧下部のカテゴリフィルターから選択する。

## 表示用内部モデル

### AdventureRecordService.Entry

- `MobTemplate template`
- `AdventureMobRecord? record`
- `boolean defeated`

super mode の未討伐 entry は `record=null`、`defeated=false`。

### AdventureRecordService.EntryResult

非同期一覧生成結果の `entries` と `superMode`。entries は constructor で不変 list 化する。

### AdventureRecordGui.Holder

screen、list type、page、検索 item IDs、entry snapshot、super mode を保持する実 GUI holder。Mob 詳細画面では選択した `Entry` と `StatusType.Category` も保持する。`AdventureRecordSummary` や公開 `AdventureRecordGuiState` は存在しない。

### Mob 詳細表示

- 一覧の item click は現在ページの `Entry` を holder の entry snapshot から解決する。
- Mob 情報画面は `MobTemplate` の表示名・カテゴリ・レベル・討伐情報と、7カテゴリの基礎ステータス概要を表示する。
- ステータス詳細画面は、選択カテゴリの `baseStats` に定義された認識済みかつ非ゼロの `StatusType` をページ表示する。
- MobInstance はサーバーセッション内の実体であり、冒険記録 GUI の表示モデルには含めないため、現在 HP／現在 Shield は対象外とする。
