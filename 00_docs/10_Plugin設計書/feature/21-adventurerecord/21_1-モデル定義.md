# 21_1-モデル定義

## AdventureMobRecord

| フィールド | 型 | 意味 |
|:--|:--|:--|
| `recordId` | `UUID` | record ID |
| `accountId` | `UUID` | 所有 account |
| `mobId` | `String` | Mob master ID |
| `category` | `MobCategory` | `ENEMY` または `BOSS` |
| `defeatCount` | `long` | 討伐回数 |
| `firstDefeatedAt` | `Instant` | 初回討伐時刻 |
| `lastDefeatedAt` | `Instant` | 最新討伐時刻 |

## AdventureRecordListType

| 値 | title | category filter |
|:--|:--|:--|
| `ENEMY` | 魔物録 | `MobCategory.ENEMY` |
| `BOSS` | 厄災録 | `MobCategory.BOSS` |
| `SEARCH` | モブ検索結果 | category なし。ENEMY／BOSS を service 側で許可 |

## 表示用内部モデル

### AdventureRecordService.Entry

- `MobTemplate template`
- `AdventureMobRecord? record`
- `boolean defeated`

super mode の未討伐 entry は `record=null`、`defeated=false`。

### AdventureRecordService.EntryResult

非同期一覧生成結果の `entries` と `superMode`。entries は constructor で不変 list 化する。

### AdventureRecordGui.Holder

screen、list type、page、検索 item IDs、entry snapshot、super mode を保持する実 GUI holder。`AdventureRecordSummary` や公開 `AdventureRecordGuiState` は存在しない。
