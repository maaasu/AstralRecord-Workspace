# 21_3-メソッド仕様

## Mob 記録取得

クラス名: `AdventureRecordRepository`
物理名: `findMobRecords`

- 引数: `UUID accountId`, nullable `MobCategory category`
- 戻り値: `List<AdventureMobRecord>`
- 例外: 通信、非期待 status、JSON 変換失敗は runtime exception。

`GET /api/adventure-record/mob?account_id=...` に category がある場合だけ query を加える。

## 討伐加算

クラス名: `AdventureRecordRepository`
物理名: `recordMobDefeat`

- 引数: account ID、mob ID、category、updated user ID
- 戻り値: なし
- 例外: 通信、非期待 status は runtime exception。

`POST /api/adventure-record/mob/defeat` へ送る。

## 表示 entry 生成

クラス名: `AdventureRecordService`
物理名: `buildEntries` / `buildEntriesAsync`

- 引数: `AstPlayer player`, `AdventureRecordListType listType`, `Set<String> searchItemIds`。async 版は completion／failure を追加。
- 戻り値: 同期版 `List<Entry>`、async 版はなし
- 例外: async 版は worker exception を main thread の `failure` に変換する。

record を一度取得し、template、category、visible drop と結合する。visible drop は hidden でない直接 drop と、`LootService.getLoaded` で解決できた lootTable の `LootModel.flattenedEntries` を含む。`ALL` は ENEMY／BOSS を横断し、`ENEMY`／`BOSS` は指定カテゴリに限定する。super mode では未討伐のロード済み template を追加する。

list GUI の Mob item lore は、既存のレベル・討伐情報・説明・ドロップ情報を維持し、直接 drop とロード済み lootTable の平坦化候補を同じドロップアイテムリストへ表示する。lootTable は GUI 描画中に API I/O せず、cache 未解決なら直接 drop だけを表示する。説明がある場合は説明とドロップの間に共通区切り線 `◈───────────◈` を表示し、経験値またはゴールドと表示対象アイテムの両方がある場合は固定報酬と獲得アイテムの間にも同じ区切り線を表示する。ドロップ未設定、または表示対象報酬がない場合の既存表記は変更しない。

### Mob 詳細・ステータス表示

クラス名: `AdventureRecordGui` / `AdventureRecordGuiEventHandler`

物理名: `openMobDetail` / `openMobStatusDetail` / `getEntryAtSlot`

- Mob 一覧の content slot は holder の page index と `PagedGuiView.CONTENT_SLOT_COUNT` から `Entry` を解決し、クリック時に Mob 情報画面へ遷移する。
- Mob 情報画面は player 情報画面と同じ7カテゴリの slot 配置、カテゴリ名、区切り線、カテゴリ概要を使う。
- カテゴリ概要と詳細項目は `MobTemplate.baseStats` を `StatusType.fromId` で解決し、未定義 ID を表示対象外とする。値が `0` の項目も表示対象外とする。
- 詳細項目は `StatusType.description` と `StatusType.formatValue` を用い、`基礎値` として表示する。MobInstance の現在値・補正値は生成しない。
- 詳細画面の page 移動は同じ `Entry` とカテゴリを holder に保持して再描画し、戻る操作は GUI navigation の履歴を使用する。

## 討伐記録非同期保存

クラス名: `AdventureRecordService`
物理名: `recordDefeatAsync`

- 引数: `AstPlayer recipient`, `MobTemplate template`
- 戻り値: なし
- 例外: API failure を async worker 内で捕捉して log する。

ENEMY／BOSS 以外は送信しない。recipient 自身の account と user を request に使う。

## Super mode 判定

クラス名: `AdventureRecordService`
物理名: `isSuperMode`

- 引数: `AstPlayer player`
- 戻り値: setting value が Boolean true の場合だけ `true`
- 例外: setting service の契約に従う。

## GUI open・event

クラス名: `AdventureRecordGuiEventHandler`
物理名: `open` / `onInventoryClick` / `onInventoryDrag` / `onInventoryClose`

- 引数: player または Bukkit inventory event
- 戻り値: なし
- 例外: `runSafely` が捕捉し `LogId.E_5601` へ player と operation を渡す。

list open は request ID、player、account を非同期応答時に検証し、GUI close 時に request ID を破棄する。SEARCH 画面の player inventory click だけを検索条件追加として扱い、drag を含むその他の標準操作は cancel する。
