# 21_3-メソッド仕様

## Mob 記録取得

クラス名: `AdventureRecordRepository`
物理名: `findMobRecords`

- 引数: `UUID accountId`, nullable `MobCategory category`
- 戻り値: `List<AdventureMobRecord>`
- 例外: 通信、非期待 status、JSON 変換失敗は runtime exception。

`GET /api/adventure-record/mob?account_id=...` に category がある場合だけ query を加える。

## 討伐加算

クラス名: `AdventureRecordRepository`
物理名: `recordMobDefeat`

- 引数: account ID、mob ID、category、updated user ID
- 戻り値: なし
- 例外: 通信、非期待 status は runtime exception。

`POST /api/adventure-record/mob/defeat` へ送る。

## 表示 entry 生成

クラス名: `AdventureRecordService`
物理名: `buildEntries` / `buildEntriesAsync`

- 引数: `AstPlayer player`, `AdventureRecordListType listType`, `Set<String> searchItemIds`。async 版は completion／failure を追加。
- 戻り値: 同期版 `List<Entry>`、async 版はなし
- 例外: async 版は worker exception を main thread の `failure` に変換する。

record を一度取得し、template、category、visible drop と結合する。super mode では未討伐のロード済み template を追加する。

## 討伐記録非同期保存

クラス名: `AdventureRecordService`
物理名: `recordDefeatAsync`

- 引数: `AstPlayer recipient`, `MobTemplate template`
- 戻り値: なし
- 例外: API failure を async worker 内で捕捉して log する。

ENEMY／BOSS 以外は送信しない。recipient 自身の account と user を request に使う。

## Super mode 判定

クラス名: `AdventureRecordService`
物理名: `isSuperMode`

- 引数: `AstPlayer player`
- 戻り値: setting value が Boolean true の場合だけ `true`
- 例外: setting service の契約に従う。

## GUI open・event

クラス名: `AdventureRecordGuiEventHandler`
物理名: `open` / `onInventoryClick` / `onInventoryDrag` / `onInventoryClose`

- 引数: player または Bukkit inventory event
- 戻り値: なし
- 例外: `runSafely` が捕捉し `LogId.E_5601` へ player と operation を渡す。

list open は request ID、player、account を非同期応答時に検証し、GUI close 時に request ID を破棄する。SEARCH 画面の player inventory click だけを検索条件追加として扱い、drag を含むその他の標準操作は cancel する。
