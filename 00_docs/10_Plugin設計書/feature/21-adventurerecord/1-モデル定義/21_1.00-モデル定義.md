# 21_1.00-モデル定義

## 1. 冒険記録サマリ

物理名: `AdventureRecordSummary`

| 項目 | 説明 |
|---|---|
| `accountId` | 対象アカウント UUID |
| `playerName` | 表示名 |
| `level` | 現在レベル |
| `classId` | 現在の職業 ID |
| `totalPlayTimeSeconds` | 総プレイ時間 |
| `mobKillCount` | Mob 撃破数 |
| `deathCount` | 死亡回数 |
| `updatedAt` | 集計日時 |

## 2. 冒険記録表示状態

物理名: `AdventureRecordGuiState`

| 項目 | 説明 |
|---|---|
| `viewerUuid` | 閲覧者 UUID |
| `targetAccountId` | 表示対象 account UUID |
| `pageIndex` | 表示ページ |
