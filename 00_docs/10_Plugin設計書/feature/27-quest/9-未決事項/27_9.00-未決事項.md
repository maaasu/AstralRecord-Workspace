## 1. プレイヤークエスト状態の本番永続化

クエスト状態は `account-quest` API 経由で SQL Server に保存する。既存の `quest-states/<accountUuid>.yml` は初回移行用に限り使用する。

報酬付与と状態更新のトランザクション境界、およびサーバー多重起動時の二重報酬防止は、報酬処理の API/DB トランザクション化を行う際の残課題とする。
