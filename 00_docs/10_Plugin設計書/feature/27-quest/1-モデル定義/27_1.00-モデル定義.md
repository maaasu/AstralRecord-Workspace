# 27_1.00-モデル定義

## 1. クエスト定義

物理名: `QuestDefinition`

| 項目 | 説明 |
|---|---|
| `id` | クエストID |
| `name` | GUI表示名 |
| `description` | GUI lore 説明 |
| `icon` | GUI表示アイコン。基本は `PAPER` |
| `repeatMode` | `ONCE` / `REPEATABLE` / `COOLDOWN` |
| `cooldownSeconds` | 再受領までの秒数。完了/報酬受取時から開始 |
| `completionMode` | `AUTO` / `NPC` |
| `turnInNpcId` | 報告先NPC ID。未指定時は運用上、受領元NPCを報告先にする |
| `objectives` | [[27_1.00-モデル定義]].クエスト目標 の一覧 |
| `requirements` | [[27_1.00-モデル定義]].受領条件 の一覧 |
| `rewards` | [[27_1.00-モデル定義]].クエスト報酬 |

## 2. クエスト目標

物理名: `QuestObjectiveDefinition`

| 項目 | 説明 |
|---|---|
| `id` | クエスト内で一意な目標ID |
| `type` | `KILL_MOB` または `GATHERING` |
| `targetId` | 対象Mob IDまたは採取定義ID |
| `label` | GUI表示名 |
| `amount` | 必要数 |

## 3. 受領条件

物理名: `QuestRequirementDefinition`

| 項目 | 説明 |
|---|---|
| `item` | 必要アイテム |
| `consume` | `true` の場合、受領時に消費する。`false` は所持確認のみ |

## 4. クエスト報酬

物理名: `QuestRewardDefinition`

| 項目 | 説明 |
|---|---|
| `exp` | AstralRecordアカウント/クラスEXP |
| `gold` | 既存Gold通貨 |
| `items` | 報酬アイテム一覧 |

## 5. プレイヤークエスト状態

物理名: `QuestPlayerState`

| 項目 | 説明 |
|---|---|
| `accountId` | アカウントUUID |
| `activeQuests` | 受領中または報告可能なクエスト |
| `completedAt` | 完了済みクエストの完了時刻 |
| `cooldownUntil` | クールタイム終了時刻 |

## 6. クエスト進行

物理名: `QuestProgress`

| 項目 | 説明 |
|---|---|
| `questId` | クエストID |
| `acceptedAtEpochMillis` | 受領時刻 |
| `acceptedNpcId` | 受領元NPC ID。`turnInNpcId` 未指定のNPC報告クエストで報告先として使う |
| `objectiveProgress` | 目標IDごとの進行数 |
| `readyToTurnIn` | NPC報告可能状態 |

## 7. クエストボード

物理名: `QuestBoardDefinition`

| 項目 | 説明 |
|---|---|
| `id` | ボードID |
| `name` | GUIタイトル |
| `entries` | 表示するクエストと配置 |
