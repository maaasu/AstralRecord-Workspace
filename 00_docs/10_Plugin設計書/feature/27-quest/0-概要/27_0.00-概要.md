# 27_0.00-概要

## 1. 目的

クエスト機能は、NPCから受領した任務をプレイヤー単位で保持し、Mob討伐またはギャザリング採取の進行度を記録して、達成時にEXP、Gold、アイテムを報酬として付与する。

## 2. 初期実装範囲

- Minecraft内インベントリGUIのみを提供する。
- プレイヤーの同時受領数は `StatusType.QUEST_LIMIT` の合計値を使う。基礎値は3。
- クエスト条件は `KILL_MOB` と `GATHERING` の2種類。
- 報酬受取はクエスト単位で `AUTO` または `NPC` を選択する。
- 繰り返しは `ONCE`、`REPEATABLE`、`COOLDOWN` を選択する。
- 破棄はクエスト一覧GUIからいつでも実行でき、進行度はリセットされる。

## 3. マスターデータ

- クエスト単体は `40_filebase/47.features.quest` に定義する。
- NPCから開くクエスト受領GUIは `40_filebase/48.features.quest_board` に定義する。
- NPC側は interaction の `gui` action に `type: QUEST` と `boardId` を指定する。

## 4. プレイヤー状態

プレイヤー状態はアカウントUUID単位で管理し、AstralRecord API 経由で SQL Server に保存する。既存の `quest-states/<accountUuid>.yml` は移行時だけ読み込み、API 保存成功後に削除する。
