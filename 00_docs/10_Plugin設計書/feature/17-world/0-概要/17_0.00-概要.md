# World システム概要

World システムは、filebase の `60.features.world` に定義された `WorldMasterData` を AstralRecord API から取得し、Plugin 側でキャッシュして扱う。

## 現在の実装対象

- `WorldType` と `WorldMasterData` のモデル管理
- API からの `WorldMasterData` 取得
- 管理用 `/world` コマンド
- `baseWorldPath` に対応する実ワールドフォルダの解決と `/world reload` 時の再ロード
- `config.yml` の `joinSpawn.world` と `WorldMasterData.spawnLocation` による初期スポーン
- 初期スポーン、`/world tp`、スキルツリー入口、メニューの `帰還` は `WorldService` の共通テレポートを通し、プレイヤー騎乗中の `TextDisplay` passenger を一度解除してから移動し、移動完了後に数 tick 遅らせて再開する
- `PlayerChangedWorldEvent` 発火時は遷移先 `WorldMasterData.displayName` をタイトル表示し、未登録ワールドのみ Bukkit ワールド名をそのまま表示する
- `WorldMasterData.spawnLocation` での `END_ROD` 常時リングパーティクル表示と、スニーク導線を示す TextDisplay 表示
- AstralRecord 管理ワールドのロード時に RPG 向け gamerule を適用し、バニラ Mob スポーンイベントをキャンセルする
- AstralRecord 管理ワールド上の Bukkit `Mob` は削除する。管理対象外ワールドではこの制御を行わない
- 管理ワールド判定は事前登録した Bukkit ワールド UUID または生成中の一時ワールド名をキャッシュから逆引きし、Creature / World / ChunkLoad イベント中にパス探索や同期ファイル I/O を行わない

## 拠点ワールドのオーバーワールド転送 GUI

- `WorldType = BASE` のワールドでは、`END_GATEWAY` / `END_PORTAL` / `NETHER_PORTAL` ブロックへ入った瞬間に、いったんそのワールドの Bukkit 既定スポーンへ退避させてからオーバーワールド転送 GUI を開く
- `WorldType = BASE` のワールドでは、`WorldMasterData.spawnLocation` の半径 2 メートル以内でスニークを押し込んだ瞬間に`SNEAK`のworld interaction候補を提供し、その候補が勝った場合だけ同じオーバーワールド転送 GUI を開く
- `WorldType = BASE` の `spawnLocation` には、`showSpawnParticle = true` の場合のみ「スニークでオーバーワールドへ移動」できる旨の TextDisplay を表示する
- GUI を開いたトリガー中は、プレイヤーが対象ブロック帯から離れるまで同じゲートウェイでの再オープンを抑止する
- バニラの `END_GATEWAY` / `END_PORTAL` / `NETHER_PORTAL` テレポートは拠点ワールド内では常にキャンセルし、移動は GUI 選択に一本化する
- GUI の候補は `WorldType = OVERWORLD` かつ `overworldTeleportGui.slot` に 0 以上 44 以下が指定された `WorldMasterData` だけを対象とする。設定オブジェクトまたは `slot` が未指定の場合は表示しない
- 候補は `overworldTeleportGui.slot` で指定されたチェスト GUI の絶対スロットへ配置し、表示名順の自動詰めやページングは行わない
- スロットが重複した場合は Plugin ロード時に警告し、ワールド ID の昇順で先の1件だけを表示する。範囲外のスロットも警告して表示しない
- GUI の表示内容は `displayName` / `description` / `guiIconMaterial` / `adventureGuide` を利用し、`baseWorldPath` のようなサーバーパスは表示しない
- GUI を開いている間はプレイヤーへ `DARKNESS` を付与して周囲を見えなくし、GUI を閉じた時点で解除する
- `guiIconMaterial` 未指定時は `GRASS_BLOCK` を既定アイコンとして使う

## オーバーワールドから拠点への帰還

- `WorldType = OVERWORLD` のワールドでは、初期スポーン地点の半径 2 メートル以内でスニークを押し込んだ瞬間に`SNEAK`のworld interaction候補を提供し、その候補が勝った場合だけ拠点ワールドへ即時帰還できる
- `WorldType = OVERWORLD` の `spawnLocation` には、`showSpawnParticle = true` の場合のみ「スニークで拠点に帰還」できる旨の TextDisplay を表示する
- この帰還はゴールドを消費せず、待機演出も発生しない
- 判定はスニーク押下イベントの瞬間だけ行い、押しっぱなし中の継続判定は行わない
- スポーン地点は `WorldMasterData.spawnLocation` を優先し、未管理ワールドでは Bukkit の既定スポーンを用いる

## SNEAK入力調停

- `PlayerToggleSneakEvent`の共通入口は`PlayerInteractionGatewayEventHandler.onPlayerToggleSneak`とし、world event handlerを直接listener登録しない。
- base / overworld spawn actionは`WORLD_INTERACTION`、`stableOrder = 15`、処理成立時`CLAIM`の候補とする。
- トリガー成立可否はプレイヤーからトリガー中心までの水平距離2メートル以内で判定する。成立した候補の`hitDistance`は高低差を含む3D実距離とし、同じ`WORLD_INTERACTION`のboss entry等では先に距離が近い候補を選び、同距離の場合だけ`stableOrder`を比較する。
- world候補が勝った場合、wall-cling / dodgeなどのplayer-control fallbackは実行しない。
- `CLAIM`は入力を所有するが元eventをcancelせず、vanillaのスニーク姿勢変更を維持する。world候補がなければ通常スニークを変更しない。

## コマンド

| Command | Description |
|---|---|
| `/world list` | ロード済み `WorldMasterData` 一覧を表示する。 |
| `/world info <worldId>` | `WorldMasterData` 詳細を表示する。 |
| `/world tp <worldId>` | `WorldMasterData.spawnLocation` へ移動する。 |
| `/world loaded` | Bukkit にロード済みのワールド名一覧を表示する。 |
| `/world reload` | MasterData Seeder API で filebase YAML を反映してから `WorldMasterData` を再取得する。 |

`/world` は `ADMIN(99)` 以上のプレイヤー向けコマンドとする。
