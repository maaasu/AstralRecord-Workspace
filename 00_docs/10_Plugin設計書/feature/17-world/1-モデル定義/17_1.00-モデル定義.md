# 17_1.00-モデル定義

## WorldMasterData

API から受け取るワールド定義。物理名は `WorldMasterData`。

| フィールド | 型 | 意味 |
|:--|:--|:--|
| `schemaVersion` | `int` | world schema version |
| `id` | `String` | 論理 world ID |
| `displayName` | `String` | プレイヤー向け表示名 |
| `worldType` | `WorldType` | `BASE`、`OVERWORLD`、`DUNGEON` 等の種別 |
| `baseWorldPath` | `String` | ロード元ワールドフォルダ |
| `instanceRootPath` | `String` | 将来の instance 配置ルート |
| `autoLoad` | `boolean` | 起動時ロード対象 |
| `instanceEnabled` | `boolean` | instance 対応フラグ |
| `maxPlayers` | `int` | 定義上の最大人数 |
| `allowBlockBreak` / `allowBlockPlace` | `boolean` | ブロック操作許可 |
| `allowMobSpawn` | `boolean` | master 上の Mob spawn 設定 |
| `showSpawnParticle` | `boolean` | スポーン地点演出の有効化 |
| `spawnLocation` | `WorldSpawnLocation` | x、y、z、yaw、pitch |
| `description` | `String` | 説明 |
| `guiIconMaterial` | `String?` | OVERWORLD 選択アイコン |
| `adventureGuide` | `WorldAdventureGuide?` | 推奨レベル・人数・notes |
| `overworldTeleportGui` | `OverworldTeleportGuiSetting?` | GUI slot |

## 補助モデル

### WorldSpawnLocation

`x`、`y`、`z`、`yaw`、`pitch` を保持する。欠落時の既定値は `(0.5, 64.0, 0.5, 0, 0)`。

### WorldAdventureGuide

`recommendedLevelMin/Max`、`recommendedPartySizeMin/Max`、`notes` を保持する。空の note は constructor で除外し、不変リスト化する。

### OverworldTeleportGuiSetting

nullable な `slot` を保持する。GUI の有効 slot と判定できる定義だけ転送先一覧へ採用する。同一 slot は world ID 順で先に評価された定義を採用する。

### WorldType

world の用途を表す enum。未知値は enum の fallback 規則に従って解決し、表示名は `getRegionDisplayName` から取得する。

### WorldService.DefinitionSnapshot

reload 中に構築する不変 snapshot。world ID 索引と runtime 解決用索引をまとめて置換し、中途半端な cache 状態を公開しない。
