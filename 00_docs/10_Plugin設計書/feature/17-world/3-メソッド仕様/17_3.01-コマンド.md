# World コマンド仕様

## `/world list`

`WorldService.getAll()` の結果を一覧表示する。ロード済み定義がない場合はメッセージを返す。

## `/world info <worldId>`

`WorldService.getById(worldId)` の詳細を表示する。未登録 ID の場合はエラーを返す。

## `/world tp <worldId>`

指定 `WorldMasterData` に対応する Bukkit ロード済みワールドを解決し、`WorldMasterData.spawnLocation` へ実行者を移動する。未ロードの場合はエラーを返す。

## `/wtp <worldId>`

`/world tp <worldId>` の短縮ルート。実行権限、ワールド ID 補完、移動処理は `/world tp` と同じものを使用する。

## `/world loaded`

`Bukkit.getWorlds()` のワールド名一覧を表示する。

## `/world reload`

`WorldService.reloadFromYaml()` を実行し、filebase YAML を MasterDataDB に同期してから `WorldMasterData` を再取得する。
