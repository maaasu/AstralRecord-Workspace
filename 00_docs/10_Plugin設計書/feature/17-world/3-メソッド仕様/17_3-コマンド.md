# 17_3-コマンド

## `/world`

クラス名: `WorldCommand`
物理名: `executePlayerCommand`

- 実行者: プレイヤー
- 権限: `ADMIN`
- 構文: `/world <list|info|tp|loaded|reload> ...`
- 戻り値: なし
- 例外: command 基盤の安全実行とメッセージ契約に従う。

| subcommand | 引数 | 処理 |
|:--|:--|:--|
| `list` | なし | 読み込み済み定義を一覧表示する。 |
| `info` | `worldId` または `[temp]worldName` | master と runtime 状態を表示する。一時ワールドはタグなしフォルダ名も受け付ける。 |
| `tp` | `worldId` または `[temp]worldName` | `resolveOrLoadSpawnLocation` を使い、未ロードなら必要時ロードして転送する。一時ワールドはタグなしフォルダ名も受け付ける。 |
| `loaded` | なし | Bukkit のロード済み world を表示する。 |
| `reload` | なし | filebase seed 後に world 定義を再読込する。 |

## `/wtp`

クラス名: `WorldTeleportCommand`
物理名: `executePlayerCommand`

- 実行者: プレイヤー
- 権限: `ADMIN`
- 構文: `/wtp <worldId>`
- 処理: `WorldCommand.teleport` へ委譲する。

## `/adminitem`

クラス名: `AdminWorldTeleportItemCommand`
物理名: `executePlayerCommand`

- 実行者: プレイヤー
- 権限: `ADMIN`
- 構文: `/adminitem`
- 処理: 管理者用ワールドテレポート用の `NETHER_STAR` を1個、実行者のインベントリへ付与する。空きがない場合は付与しない。
- 使用: 専用 PDC マーカーを持つ `NETHER_STAR` の右クリックで `AdminWorldTeleportGui` を開く。右クリックは外部のアイテムツールより先に抑止してから `PlayerInteractionGatewayEventHandler` の `INPUT_LOCK` 候補として処理する。左クリックは管理者用処理で捕捉しない。

## 補完と登録

- `WorldTabCompleter` と `WorldTeleportTabCompleter` は subcommand と world ID を補完する。一時ワールドは `[temp]worldName` を表示し、実行時はタグ付き・タグなしのどちらも解決する。
- command は lifecycle で動的登録する。`plugin.yml` への重複定義は追加しない。
