# 17_3-コマンド

## `/world`

クラス名: `WorldCommand`
物理名: `executePlayerCommand`

- 実行者: プレイヤー
- 権限: `ADMIN`
- 構文: `/world <list|info|tp|loaded|reload> ...`
- 戻り値: なし
- 例外: command 基盤の安全実行とメッセージ契約に従う。

| subcommand | 引数 | 処理 |
|:--|:--|:--|
| `list` | なし | 読み込み済み定義を一覧表示する。 |
| `info` | `worldId` または `[temp]worldName` | master と runtime 状態を表示する。一時ワールドはタグなしフォルダ名も受け付ける。 |
| `tp` | `worldId` または `[temp]worldName` | `resolveOrLoadSpawnLocation` を使い、未ロードなら必要時ロードして転送する。一時ワールドはタグなしフォルダ名も受け付ける。 |
| `loaded` | なし | Bukkit のロード済み world を表示する。 |
| `reload` | なし | filebase seed 後に world 定義を再読込する。 |

## `/wtp`

クラス名: `WorldTeleportCommand`
物理名: `executePlayerCommand`

- 実行者: プレイヤー
- 権限: `ADMIN`
- 構文: `/wtp <worldId>`
- 処理: `WorldCommand.teleport` へ委譲する。

## `/adminitem`

クラス名: `AdminWorldTeleportItemCommand`
物理名: `executePlayerCommand`

- 実行者: プレイヤー
- 権限: `ADMIN`
- 構文: `/adminitem`
- 処理: 管理者用ワールドテレポート用の `NETHER_STAR` を1個、実行者のインベントリへ付与する。空きがない場合は付与しない。
- 使用: 専用 PDC マーカーを持つ `NETHER_STAR` の右クリックで `AdminWorldTeleportGui` を開く。右クリックは外部のアイテムツールより先に抑止してから `PlayerInteractionGatewayEventHandler` の `INPUT_LOCK` 候補として処理する。左クリックは管理者用処理で捕捉しない。

## `/bosstp`・`/dungeontp`・`/instancetp`

クラス名: `InstanceTeleportCommand`
物理名: `executePlayerCommand`

- 実行者: `UserPermission.ADMIN` 以上のプレイヤー。account mode は制限せず、管理者モードからも実行できる。
- 構文: `/bosstp`、`/dungeontp`、`/instancetp`。引数なし。
- 処理: 同じ `InstanceTeleportGui` を開く。初期種別は順に `BOSS`、`DUNGEON`、`ALL` とし、`/instancetp` は種別フィルターなしで表示する。
- 一覧: `MobService` の読込済み `BOSS` のうち `challenge` があるマスタと、`DungeonService.getLoadedDefinitions()` の検証済み定義を使用する。クリック時に API や filebase を再読込しない。表示レベル、表示名、種別、ID の順に整列するが、内部 ID は GUI に表示しない。
- 表示情報: ボスは表示名・`lore`・ボス自身の `level`、ダンジョンは表示名・`recommendedLevel`・生成部屋数・同じスナップショットの最深部ボス表示名。両方に参加人数、制限時間、パーティー共有の復帰可能死亡回数を表示する。ボスレベルを推奨レベルとは表示しない。
- GUI 操作: 45件単位のページ移動、現在値付き種別候補一覧、フィルター解除を持つ。候補選択は先頭ページへ戻り、選択取消は元の種別・ページへ戻る。共通の閉じる操作とホットバー操作を使用する。
- 転送先: ボスは `challenge.entryLocation`、ダンジョンは `entry` と検証済み `entryWorldData` の組を使う。`playerSpawnLocation`、`bossSpawnLocation`、一時ダンジョンワールドには転送しない。受付 World は論理 ID から `WorldService.resolveOrLoadWorld` で解決する。
- 利用条件: 管理者の直接転送のため、通常プレイモード、挑戦参加状態、受付ワールドの必要アイテム所持は条件にしない。
- 拒否: 管理者権限不足、account が切り替わった画面操作、二重転送、受付定義欠損、内部戦場への受付定義を拒否する。権限不足は `P_5061`、未初期化は `P_5794`、二重転送は `P_5793`、受付欠損・転送失敗は `P_5791` を通知する。
- 非同期転送: 実転送直前はオンライン状態、同じ account、管理者権限だけを確認する。`WorldService.teleportPlayerAsync` を使用して移動直前の yaw / pitch を保持し、成功時だけ `P_5790` を表示する。

## 補完と登録

- `WorldTabCompleter` と `WorldTeleportTabCompleter` は subcommand と world ID を補完する。一時ワールドは `[temp]worldName` を表示し、実行時はタグ付き・タグなしのどちらも解決する。
- command は lifecycle で動的登録する。`plugin.yml` への重複定義は追加しない。
