# 17_3-サービス

## 定義一覧取得

クラス名: `WorldRepository`
物理名: `findAll`

- 引数: なし
- 戻り値: 完全な `List<WorldMasterData>`
- 例外: API 通信・JSON 変換失敗を runtime exception として通知する。

1. `/api/world` を取得する。
2. 一覧要素が完全定義ならそのまま変換し、概要行なら `/api/world/{id}` で詳細化する。
3. 概要行の詳細が 404 の場合は `IllegalStateException` とし、不完全な一覧を返さない。

## 定義 snapshot 読み込み・反映

クラス名: `WorldService`
物理名: `loadDefinitionSnapshot` / `replaceDefinitionSnapshot` / `activateDefinitionSnapshot`

- 引数: 反映系は `DefinitionSnapshot snapshot`
- 戻り値: 読み込みは snapshot、反映系はなし
- 例外: repository の取得失敗を呼び出し元へ伝播する。

`activateDefinitionSnapshot` は cache を置換した後、`autoLoad` 定義をロードし runtime 索引へ登録する。`reloadFromYaml` は master seed と再読込を同期的に実行する管理操作である。

## Bukkit world 解決

クラス名: `WorldService`
物理名: `resolveLoadedWorld` / `resolveOrLoadWorld` / `findByBukkitWorld`

- 引数: `WorldMasterData data`、または Bukkit `World world`
- 戻り値: 解決結果。未解決時は `null`
- 例外: world 生成失敗を独自には捕捉しない。

ロード済み解決は UUID、名前、フォルダ対応を使う。`resolveOrLoadWorld` は未ロード時に `baseWorldPath` を Bukkit world としてロードし、成功後に runtime cache と RPG gamerule を更新する。

## スポーン地点解決・転送

クラス名: `WorldService`
物理名: `resolveSpawnLocation` / `resolveOrLoadSpawnLocation` / `teleportToSpawnAsync`

- 引数: `WorldMasterData data`、転送は `Player player` と必要に応じて teleport cause
- 戻り値: `Location?`、または `CompletableFuture<Boolean>`
- 例外: 非同期転送の失敗は future を exceptional completion にし得る。

`resolveSpawnLocation` はロード済み world のみ、`resolveOrLoadSpawnLocation` は必要時ロードを許可する。転送先には master の yaw / pitch を適用する。

## OVERWORLD 転送先一覧・転送

クラス名: `OverworldTeleportService`
物理名: `listDestinations` / `teleportToDestination`

- 引数: 転送は `Player player`, `AstPlayer astPlayer`, `String worldId`
- 戻り値: 一覧、またはなし
- 例外: 転送結果の throwable を main thread で失敗メッセージへ変換する。

一覧は `OVERWORLD` かつ有効 GUI slot の定義だけを slot 順に返す。転送先 ID が不正、種別違い、転送失敗の場合は `PlayerMsgId.P_5766` を通知する。

## 拠点帰還

クラス名: `ReturnToBaseService`
物理名: `calculateGoldCost` / `beginReturn` / `beginImmediateReturn` / `cancelAll`

- 引数: level、または `AstPlayer`
- 戻り値: 費用、または開始可否
- 例外: 非同期転送失敗は callback 内で補償・通知する。

通常帰還費用は `100 * max(1, level)`。通常帰還は 60 tick 静止後に消費・保存・転送し、転送失敗時は同額を戻して保存する。即時帰還は待機と費用を使わない。

## 管理外 Mob 抑止

クラス名: `WorldNaturalSpawnBlockEventHandler`
物理名: `onCreatureSpawn` / `onWorldLoad` / `onChunkLoad`

管理 world 内で instance ID を持たない Mob を cancel・削除する。`CUSTOM` spawn は他 plugin が識別子を付与する猶予として次 tick に再検証する。
