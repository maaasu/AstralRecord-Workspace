# 17_4-統合フロー

## 1. 定義ロード

### シーケンス

```mermaid
sequenceDiagram
    participant Lifecycle as PluginLifecycle
    participant World as WorldService
    participant Repo as WorldRepository
    participant API as World API
    Lifecycle->>World: loadDefinitionSnapshot()
    World->>Repo: findAll()
    Repo->>API: GET /api/world
    opt 概要行
        Repo->>API: GET /api/world/{id}
    end
    Repo-->>World: 完全な定義一覧
    Lifecycle->>World: activateDefinitionSnapshot(snapshot)
    World->>World: cache置換・autoLoad・runtime登録
```

### 処理要点

- 一覧と詳細を組み合わせ、完全な `WorldMasterData` だけを snapshot に入れる。
- cache 置換と runtime 有効化を段階化し、reload 中の中間索引を公開しない。

### 例外・終了条件

- API または変換失敗時は旧 snapshot を維持したまま lifecycle 側へ失敗を返す。
- auto load に失敗した world は runtime 解決できない。

## 2. BASE から OVERWORLD へ移動

### シーケンス

```mermaid
sequenceDiagram
    actor Player as プレイヤー
    participant Gateway as BaseWorldGatewayEventHandler
    participant GUI as OverworldTeleportGuiEventHandler
    participant Select as OverworldTeleportService
    participant World as WorldService
    Player->>Gateway: gatewayへ進入
    Gateway->>Gateway: vanilla teleport取消・spawnへ退避
    Gateway->>GUI: open(player)
    GUI->>Select: listDestinations()
    Player->>GUI: 転送先を選択
    GUI->>Select: teleportToDestination(...)
    Select->>World: teleportToSpawnAsync(...)
    World-->>Player: OVERWORLD spawn
```

### 処理要点

- portal 系 Bukkit teleport を BASE 内だけ cancel する。
- gateway 内の連続 open を player UUID 単位で抑止する。
- BASE spawn 近傍の sneak 入力候補からも同じ GUI を開ける。
- 転送 GUI の表示中だけ GUI 用の暗黒エフェクトを付与し、GUI を閉じる、別 GUI へ遷移するか切断すると解除する。GUI 表示前の暗黒エフェクトがある場合は元の状態へ戻す。

### 例外・終了条件

- 無効 world ID、OVERWORLD 以外、転送失敗は `P_5766` を通知する。
- GUI slot 重複・不正値は先着採用または除外し、警告ログを記録する。

## 3. OVERWORLD から BASE へ帰還

### シーケンス

```mermaid
sequenceDiagram
    actor Player as プレイヤー
    participant Entry as SpawnHandler / MenuOpenEventHandler
    participant Return as ReturnToBaseService
    participant Inventory as InventoryService
    participant World as WorldService
    alt spawn近傍でsneak
        Player->>Entry: 即時帰還入力
        Entry->>Return: beginImmediateReturn(astPlayer)
        Return->>World: teleportToSpawnAsync(BASE)
    else menuから通常帰還
        Player->>Entry: 帰還操作
        Entry->>Return: beginReturn(astPlayer)
        Return-->>Player: 3秒の待機・演出
        alt 静止完了
            Return->>Inventory: consumeGold(accountId, cost)
            Return->>Inventory: saveNow(accountId)
            Return->>World: teleportToSpawnAsync(BASE)
        else 待機中に移動
            Return-->>Player: 帰還取消
        end
    end
```

### 処理要点

- spawn の水平半径 2 block 以内を候補とし、interaction resolver の `WORLD_INTERACTION` tier から即時帰還する。
- menu の通常帰還は待機完了時に残高を再検証し、転送失敗時はゴールドを返して保存する。

### 例外・終了条件

- BASE 定義／spawn 不在、offline では開始または完了しない。通常帰還は残高不足でも開始しない。
- spawn の即時帰還は待機・費用なしで同じ BASE spawn へ送る。
- ダンジョンセッション参加中、またはボス挑戦の準備中・進行中・結果待ち・終了処理中は、通常帰還と即時帰還を拒否する。

## 4. 参加時の拠点スポーン転送

### シーケンス

```mermaid
sequenceDiagram
    actor Player as プレイヤー
    participant Join as WorldJoinSpawnEventHandler
    participant World as WorldService
    Player->>Join: PlayerJoinEvent
    Join->>World: getById(configured joinSpawn world)
    Join->>World: teleportToSpawnAsync(player, world)
    World->>World: 未ロードならbaseWorldPathからロード
    World-->>Player: BASE spawn
```

### 処理要点

- 参加・再参加のたびに `plugin.joinSpawn.world` のスポーン地点へ転送する。
- 参加時ハンドラーはロード済み判定で中断せず、`teleportToSpawnAsync` にオンデマンド world 読込と転送を委譲する。

### 例外・終了条件

- 設定 ID に対応する world master がない、または world の読込・転送に失敗した場合は警告ログを記録し、Bukkit teleport は実行しない。

## 5. 管理ワールドの Mob 抑止

### シーケンス

```mermaid
sequenceDiagram
    participant Bukkit as Bukkit Event
    participant Handler as WorldNaturalSpawnBlockEventHandler
    participant World as WorldService
    participant Mob as MobService
    Bukkit->>Handler: world/chunk load または creature spawn
    Handler->>World: findByBukkitWorld(world)
    Handler->>Mob: instanceId確認
    alt 管理外Mob
        Handler-->>Bukkit: spawn取消・entity削除
    else AstralRecord Mob
        Handler-->>Bukkit: 維持
    end
```

### 処理要点

- world load 時に RPG gamerule も適用する。
- `CUSTOM` spawn は次 tick に識別子を再確認する。

### 例外・終了条件

- world master に対応しない Bukkit world は対象外。
