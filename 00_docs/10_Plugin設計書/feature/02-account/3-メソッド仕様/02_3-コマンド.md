# 02_3-コマンド

## 1. command メソッド仕様

### 管理者EXP付与

`/exp <value> [player]` は管理者がプレイヤーEXPだけを付与する。対象は最後の引数で、省略時は実行者自身、コンソールからの省略は拒否する。転生中も同じEXP付与経路を使い、100EXPごとのEXPポイント変換を適用する。

### アカウントルート振分

クラス名: `AccountCommand`
物理名: `executeCommand`

実行者はコンソール、または permission `99` 以上（`UserPermission.ADMIN`）のプレイヤーに限る。通常プレイヤーは引数なしを含めて `/account` 系コマンドを実行できない。

処理内容:

1. 引数なしの場合は usage を返す
2. 第一引数が `create` の場合、アカウント作成へ委譲する
3. 第一引数が `rename` の場合、アカウント名変更へ委譲する
4. 第一引数が `mode` の場合、アカウントモード変更へ委譲する
5. 第一引数が `delete` の場合、アカウント削除へ委譲する
6. 第一引数が `switch` の場合、アカウントスロット切替へ委譲する
7. 第一引数が `uuid`、`clone`、`confirm` の場合、それぞれUUID照会、複製、複製確認へ委譲する
8. 対応外サブコマンドは usage を返す

### アカウント作成

- `AccountCreateCommand.executeCommand` は `/account create [player]` を管理者またはコンソールから受け付け、登録済みユーザーへ新しいアカウントを追加する。選択中アカウントは切り替えない。
- APIへの作成要求でslotを省略し、APIが0〜99の最小空きスロットを原子的に決める。
- 同じユーザーUUIDの作成が処理中なら、後続要求は作成APIを呼ばず拒否する。先行要求が成功または失敗して完了した後は、次の明示的な作成要求を受け付ける。
- 対象ユーザーの解決とAPI呼出しは非同期で実行し、通知とオンライン状態の参照はメインスレッドで行う。

### アカウント名変更

クラス名: `AccountRenameCommand`
物理名: `executeCommand`

- ルート: `/account rename <accountName>`
- 実行者は permission `99` 以上（`UserPermission.ADMIN`）のプレイヤーに限る。コンソールは使用できない。
- プレイヤー自身の選択中アカウントだけを変更対象とする。
- `<accountName>` は ASCII 英数字（`A-Z` / `a-z` / `0-9`）またはアンダースコア（`_`）のみ、3〜50文字で検証する。
- API は未削除アカウント間の大文字小文字を区別しない重複を 409 として返す。重複時は現在名を保持する。
- 成功時はアカウント名とスロット番号を `{accountName}#{slotIndex}` として表示し、`#slotIndex` を灰色で描画する。

### アカウントスロット切替

クラス名: `AccountSwitchCommand`
物理名: `executeCommand`

処理内容:

1. コンソール、または permission `99` 以上のプレイヤーだけを許可する
2. `/account switch [<player>] <slot|name>` として、対象省略時はプレイヤー実行者自身を対象にする。コンソールからの対象省略は `PlayerMsgId.P_5305` を返す
3. オンライン対象はキャッシュ済みのプレイヤーセッションを検証し、カーソル上にアイテムがある場合は保持したまま切替を拒否する。オフライン対象は API 登録済み Minecraft ID として非同期に解決する
4. 対象ユーザーのアカウント一覧から、1〜2桁の数値は `slotIndex`、それ以外は大文字小文字を区別しないアカウント名として検索する。未作成のslotまたは未検出名は切替を行わず拒否する
5. 作成は `/account create [player]` だけが行う。API へ `slotIndex` を送らず、API が 0〜99 の最小空きslotを原子的に採番する
6. 切替要求を対象 Minecraft ID 単位で直列化する。オンライン対象ではプレイヤー単位の共通セッション遷移ゲートを取得し、同じ対象の切替またはチャンネル移動が進行中なら拒否する
7. オンライン対象は旧アカウントの取引・入力を停止し、退出時と同じ feature の解放および保存キュー登録を行う
8. オンライン対象の旧アカウント保存完了後、またはオフライン対象では直ちに、[[02_3-サービス]].アカウント切替を `updatedBy` とともに非同期で実行する
9. オンライン対象は切替後アカウントのユーザー、インベントリ、スキル、スキルツリー、クエスト、バインドをロードし、メインスレッドで反映する。オフライン対象は次回ログイン時に反映する
10. 切替成功時は実行者へ対象アカウント表示名（`{accountName}#{slotIndex}`）を含む成功メッセージを送信する。オンライン対象にも本人向けメッセージを送信する。切替再ロードではログインボーナス付与とログイン履歴登録を行わない

例外時挙動:

- API切替または再ロードに失敗した場合は旧アカウントの選択状態を復元して再ロードする
- 旧アカウントの復元にも失敗した場合は `PlayerMsgId.P_5339` でプレイヤーを切断する
- 切替中は `PlayerMsgId.P_5341`、チャンネル移動中は `PlayerMsgId.P_7151`、サービス未初期化またはセッション不在は `PlayerMsgId.P_5340`、その他の失敗は `PlayerMsgId.P_5062` を使用する

### アカウントモード変更

クラス名: `AccountModeCommand`
物理名: `executeCommand`

処理内容:

1. 実行者権限を検証する

	| 項目 | 内容 |
	|---|---|
	| コンソール | 許可 |
	| プレイヤー | [[03_1-モデル定義]].プレイヤーキャッシュ から取得した [[03_1-モデル定義]].プレイヤーセッション の permission が `99` 以上なら許可 |
	| 拒否時メッセージ | `PlayerMsgId.P_5061`: `このコマンドを実行する権限がありません。` |

2. `AccountService` / `UserService` / `AccountModeApplicationService` の初期化状態を確認する

	| 項目 | 内容 |
	|---|---|
	| 拒否条件 | いずれかが `null` |
	| 拒否時メッセージ | `PlayerMsgId.P_5330`: `アカウントモード変更サービスが初期化されていません。` |

3. mode 値を [[02_1-モデル定義]].アカウントモード へ変換する

	| 項目 | 内容 |
	|---|---|
	| 入力 | `args[0]` |
| 名称指定 | 英語ID（`PLAYER` / `ADMIN`）と大小無視で一致した場合に採用する |
| 数値指定 | 整数として解析でき、列挙値（`0`/`2`）と一致する場合に採用する |
| 拒否時メッセージ | `PlayerMsgId.P_5331`: `mode は名称（PLAYER/ADMIN）または 0 または 2 のいずれかで指定してください。` |

4. 対象アカウントを解決する

	| 項目 | 内容 |
	|---|---|
	| 入力 | `args[1]`（省略可） |
	| 省略時（プレイヤー実行） | 実行者の選択中アカウント UUID を対象とする |
	| 省略時（コンソール実行） | エラーメッセージ（`PlayerMsgId.P_5305`）を返して終了する |
	| プレイヤー名指定 | オンラインプレイヤーの [[03_1-モデル定義]].プレイヤーセッション.account.uuid を使用する |
	| アカウントUUID指定 | [[02_3-サービス]].アカウント取得 で存在確認する |
	| ユーザUUID指定 | [[01_3-サービス]].ユーザ取得 後、[[02_3-サービス]].選択アカウント取得 で解決する |
	| 拒否時メッセージ | `PlayerMsgId.P_5333`: `対象アカウントが見つかりません: %s` |

5. 解決要求の account UUID または UUID 入力を key に `pendingTargets` へ登録する

	| 項目 | 内容 |
	|---|---|
	| 重複時メッセージ | `PlayerMsgId.P_5334`: `対象アカウントのモードを更新中です。完了までお待ちください。` |
	| 解放 | オンライン対象はローカル確定開始前、offline対象はAPI保存完了後のメインスレッド処理で削除する |

6. 非同期タスクで対象 UUID をアカウント UUID として先に照会し、未検出ならユーザ UUID として選択アカウントを解決する
7. オンライン対象はメインスレッドで [[02_3-サービス]].モードローカル確定 を実行する。offline対象は非同期タスクで [[02_3-サービス]].offlineモードAPI保存 を完了させる
8. [[02_3-サービス]].ローカルモードオンライン反映 をメインスレッドで実行する。offline API待機中に対象がログインした場合は、現在の進行を保持して保存済みmodeだけを反映する

	| 項目 | 内容 |
	|---|---|
	| 世代条件 | 完了結果が同一アカウントの最新永続化世代と一致 |
	| 一致条件 | 更新後アカウントUUIDとオンラインプレイヤーのアカウントUUIDが一致 |
| 管理者 → 別 mode 時 | 反映前に inventory feature のツールモード用スナップショット保存を依頼する |
| 通常プレイヤー | inventory feature へGUIインベントリ反映を依頼する |
| 管理者 | inventory feature へ ADMIN 用スナップショット復元を依頼する |
	| その他 | GUIインベントリをクリアする |

9. 最新世代を反映できた場合だけ成功メッセージを返す。offline対象ではAPI保存が成功するまで成功メッセージを送信しない

	| 項目 | 内容 |
	|---|---|
	| ID | `PlayerMsgId.P_5332` |
	| レベル | `INFO` |
	| テンプレート | `アカウントモードを更新しました: %s = %s` |
	| 出力条件 | モード更新成功時 |
	| 引数 | `AccountDisplayNameFormatter.toLegacy(updated)`, `updated.getMode().getDisplayName()`（表示名） |

例外時挙動:

- 非同期解決または永続化失敗時は `LogId.E_5154` を記録し、`PlayerMsgId.P_5062` を送信する
- 完了結果が古い世代の場合はオンライン反映も成功メッセージも行わず終了する

### アカウント補完候補取得

クラス名: `AccountTabCompleter`
物理名: `getCompletions`

処理内容:

1. 第1引数位置では管理権限保持者に `create`、`rename`、`mode`、`delete`、`switch`、`uuid`、`clone`、`confirm` を返し、通常プレイヤーには候補を返さない
2. `switch` の第1引数位置ではオンラインプレイヤー名を返す
3. `switch` と `delete` の選択子位置では対象プレイヤーのロード済みアカウント一覧から作成したメモリキャッシュにあるアカウント名だけを返す。補完処理で API 同期通信を行わない
4. 候補に未作成slotを含めない
5. `mode` サブコマンド時はアカウントモード補完候補取得へ委譲する
6. `delete` サブコマンド時はアカウント削除補完候補取得へ委譲する
7. それ以外は空リストを返す

### アカウント切替

クラス名: `AccountSwitchCommand`
物理名: `executeCommand`

- ルート: `/account switch [<player>] <slot|name>`
- 実行者はコンソール、または permission `99` 以上のプレイヤーに限る。
- `<player>` は対象 Minecraft ID。対象がオンラインなら即時再ロードし、オフラインなら API の選択アカウントだけを更新する。
- `<slot>` は1〜2桁の数値、`<name>` は大文字小文字を区別しない既存アカウント名として解決する。未作成slotまたは未検出名を作成せず拒否する。
- API 更新時の `updatedBy` はコマンド実行者 UUID とする。

### アカウント削除

クラス名: `AccountDeleteCommand`
物理名: `executeCommand`

1. コンソール、または permission `99` 以上のプレイヤーだけを許可する。
2. `/account delete <accountUuid>` はアカウント UUID を、`/account delete <player> <slot|name>` は API の Minecraft ID 指定ユーザー取得からユーザーを、続けてslotまたは大文字小文字を区別しない名前を解決する。後者は対象のオンライン状態を問わない。
3. 同一 account UUID の削除要求を直列化し、進行中の要求は拒否する。
4. 対象ユーザーが削除対象アカウントを使用中なら、まず開いている取引を明示中止して提示品を元の所有者へ戻す。続けて移動・インベントリ操作・ドロップ・拾得・各種操作を停止し、Bukkit インベントリと runtime state を破棄する。既にキュー投入済みの保存が完了してから API 削除を行う。
5. API 削除後、対象が削除アカウントを使用中だった場合だけ選択先を非同期ロードしてメインスレッドで反映する。ロード不能時は対象をキックする。
6. 対象ユーザーがオンラインなら、削除対象が非選択スロットでも `PlayerMsgId.P_5335` を送信する。実行者には `PlayerMsgId.P_5336` を送信する。

### アカウント複製

クラス名: `AccountCloneCommand`
物理名: `executeCommand`

- ルートは `/account clone <sourceUuid|sourceName|sourceSlot> <targetPlayer> <targetSlot>`、または `/account clone <sourcePlayer> <sourceName|sourceSlot> <targetPlayer> <targetSlot>` とする。slot は 0〜99、名前は大文字小文字を区別せず解決する。
- source と target がこのサーバーで使用中なら、account switch と同じ準備経路で操作を停止し、両側の保存キューとruntime session終了を待ってからAPI複製を実行する。他サーバーの有効sessionなどが残る場合はAPIが拒否する。
- 未作成の複製先slotは確認を要求せず直ちに複製する。既存先を上書きする場合だけ、同じ実行者が2分以内に `/account confirm <token>` を一度実行する。期限切れ・別実行者・使用済みtokenでは書き込まず、APIも確認時の複製先UUIDが一致することを検証する。
- API 成功・失敗・結果不明のいずれでも、複製のため切り離した全オンラインsessionをDB上の現在選択accountから再ロードしてから処理を終了する。再ロード失敗時は既存の安全な切断経路で切断する。
- API結果不明時は自動再送せず、管理者が `/account uuid` で状態を照会して判断する。

### アカウント UUID 照会

クラス名: `AccountUuidCommand`
物理名: `executeCommand`

- ルートは `/account uuid [uuid|name|slot|player]` と `/account uuid <player> <name|slot>`。引数なしは実行者自身の選択中accountを表示する。
- `/account` ルートが許可する実行者（permission `99` 以上のプレイヤーまたはコンソール）だけに許可する。
- 単独の文字列は、実在するMinecraft IDを最優先してそのuserの現在選択accountを解決する。該当MCIDがない場合だけ、グローバルなaccount UUIDまたはaccount名として解決する。明示した `<player> <name|slot>` はそのplayer所有accountだけを解決する。
- API照会は非同期で実行し、結果として名前・slot・account UUIDを表示する。

### アカウント削除補完候補取得

クラス名: `AccountDeleteTabCompleter`
物理名: `getCompletions`

1. 第1引数位置ではオンラインプレイヤー名を返す。
2. 第2引数位置ではキャッシュ済みアカウント名を返す。補完で API 通信を行わない。

### アカウントモード補完候補取得

クラス名: `AccountModeTabCompleter`
物理名: `getCompletions`

処理内容:

1. 第1引数位置ではモード名称（`PLAYER`, `ADMIN`）だけを返す。数値入力は実行時に受理するが補完候補には含めない
2. 第2引数位置ではオンラインプレイヤー名を返す
3. それ以外は空リストを返す

## 2. コマンド仕様

- ルート: `/account`
- 実行者はコンソール、または permission `99` 以上（`UserPermission.ADMIN`）のプレイヤーに限る。通常プレイヤーは引数なしを含めて実行できない。
- サブコマンド: `/account rename <accountName>`
  - 実行者は permission `99` 以上（`UserPermission.ADMIN`）のプレイヤーに限る。コンソールは使用できない。
  - 実行者自身の選択中アカウント名を変更する。
  - `<accountName>` は ASCII 英数字（`A-Z` / `a-z` / `0-9`）またはアンダースコア（`_`）のみ、3〜50文字。
  - 大文字小文字を区別しない重複名は拒否する。
- サブコマンド: `/account mode <mode> [<player|accountUuid|userUuid>]`
  - `<mode>` は名称（`PLAYER`/`ADMIN`）または数値（`0`/`2`）
  - 対象指定省略時はプレイヤー実行者の選択中アカウント。コンソール実行で省略した場合はエラー。
- サブコマンド: `/account create [<player>]`
  - API が0〜99の最小空きslotを原子的に採番して新規アカウントを作成する。
- サブコマンド: `/account delete ((<player> <slot|name>)|<accountUuid>)`
  - 実行者はコンソール、または permission `99` 以上のプレイヤーに限る。
  - `<player> <slot>` はオフラインプレイヤーも API 登録済み Minecraft ID で指定できる。
- サブコマンド: `/account switch [<player>] <slot|name>`
  - 実行者はコンソール、または permission `99` 以上のプレイヤーに限る。
  - `<player>` はオンライン・オフラインの対象 Minecraft IDで、省略時は実行者自身を対象とする。
  - `<slot>` または既存名を選択する。未作成slotは作成しない。
  - 補完候補は対象プレイヤーのキャッシュ済みアカウント名だけを表示する。
- 短縮ルート: `/am <mode> [<player|accountUuid|userUuid>]`
  - `/account mode` と同じ権限・入力・補完・処理を使用する。

## 3. プレイヤーレベル設定

クラス名: `LevelCommand`
物理名: `executeCommand`

- ルート: `/level <level|+delta|-delta> [<player>]`
- 実行者はコンソール、または permission `99` 以上のプレイヤーに限る。
- 対象プレイヤーを省略した場合は実行者自身を対象とし、コンソール実行時は `PlayerMsgId.P_5305` を返す。
- `<level>` は整数の絶対値、`+delta` / `-delta` は現在レベルからの相対値として解釈する。
- 設定値は `AccountService` のプレイヤーレベル範囲（`1`〜`100`）へ補正し、設定レベルの累計必要経験値を同時に保存予約する。
- 設定後はスキルツリー派生状態とステータスを再計算し、対象指定時は実行者と対象の双方へ `PlayerMsgId.P_5852` を送信する。

### プレイヤーレベル補完

クラス名: `LevelTabCompleter`
物理名: `getCompletions`

1. 第1引数位置では `1`、`10`、`100`、`+1`、`-1` を返す
2. 第2引数位置ではオンラインプレイヤー名を返す
3. 管理権限がない場合、またはそれ以外の位置では空リストを返す
