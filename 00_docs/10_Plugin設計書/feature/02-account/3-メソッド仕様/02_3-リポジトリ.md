# 02_3-リポジトリ

## 1. repository メソッド仕様

### ユーザ別アカウント一覧取得

クラス名: `AccountRepository`
物理名: `findByUserId`

処理内容:

1. `GET /api/account?user_id={userId}` を呼ぶ
2. `200` は [[02_1-モデル定義]].アカウントモデル の一覧を返す。成功ログは記録しない
3. `404` は空リストを返し、`LogId.W_5150` を記録する

	| 項目 | 内容 |
	|---|---|
	| ID | `LogId.W_5150` |
	| レベル | `WARN` |
	| テンプレート | `アカウントが見つかりませんでした (API): ユーザーID=%s` |
	| 出力条件 | API が `404` |
	| 引数 | `userId` |

4. その他ステータスは `LogId.E_5150` を記録し例外化する

	| 項目 | 内容 |
	|---|---|
	| ID | `LogId.E_5150` |
	| レベル | `ERROR` |
	| テンプレート | `アカウント一覧の取得に失敗しました (API): %s` |
	| 出力条件 | API が `200/404` 以外 または 例外 |
	| 引数 | APIエラーメッセージ or 例外 |

### クラス進行更新

クラス名: `AccountRepository`
物理名: `updateClassProgress`

入力:

- `targetUuid`: 更新対象 account UUID
- `classId` / `classLevel` / `classExperience`: 選択中クラスの互換ミラー
- `classProgresses`: クラス別進行の正本一覧
- `updatedBy`: 更新者 UUID

処理内容:

1. `PUT /api/account/{targetUuid}` を呼ぶ
2. body に `classId`, `classLevel`, `classExperience`, `classProgresses`, `updatedBy` を設定する
3. `2xx` は更新後の [[02_1-モデル定義]].アカウントモデル を返す
4. 非 `2xx`、I/O 例外は `LogId.E_5155` を記録して例外化する
5. `InterruptedException` は interrupt flag を再設定して `RuntimeException` 化する

## 2. API エンドポイント一覧

- `GET /api/account?user_id={userId}`
- `GET /api/account/{uuid}`
- `POST /api/account`
- `PUT /api/account/{uuid}`
- `DELETE /api/account/{uuid}`
- `GET /api/account/resolve?selector=...&user_mcid=...`
- `POST /api/account/{sourceUuid}/clone`

## 3. 管理APIの応答契約

- `AccountManagementRepository.resolve` は200応答の直下にある `uuid` からアカウントを取得する。404は未登録として返す。
- `AccountManagementRepository.cloneAccount` は201応答の `account.uuid` から複製後アカウントを取得する。APIの応答は `{ "account": { ... }, "replacedAccountId": null }` 形式であり、アカウント本体を直下から読まない。
- 409などの失敗応答は成功として処理せず、機械判定用の `code` を保持した例外で呼出元へ返す。失敗応答からアカウントの再取得を行わず、複製POSTの自動再送もしない。
- 複製先slotが0〜99の範囲外なら、HTTP通信前に拒否する。
