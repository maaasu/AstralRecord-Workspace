# 02_3.02-コマンド

## 1. command メソッド仕様

### アカウントルート振分

クラス名: `AccountCommand`
物理名: `executeCommand`

処理内容:

1. 引数なしの場合は usage を返す
2. 第一引数が `mode` の場合、アカウントモード変更へ委譲する
3. 対応外サブコマンドは usage を返す

### アカウントモード変更

クラス名: `AccountModeCommand`
物理名: `executeCommand`

処理内容:

1. 実行者権限を検証する

	| 項目 | 内容 |
	|---|---|
	| コンソール | 許可 |
	| プレイヤー | [[03_1.00-モデル定義]].プレイヤーキャッシュ から取得した [[03_1.00-モデル定義]].プレイヤーセッション の permission が `99` 以上なら許可 |
	| 拒否時メッセージ | `PlayerMsgId.P_5061`: `このコマンドを実行する権限がありません。` |

2. `AccountService` / `UserService` / `AccountModeApplicationService` の初期化状態を確認する

	| 項目 | 内容 |
	|---|---|
	| 拒否条件 | いずれかが `null` |
	| 拒否時メッセージ | `PlayerMsgId.P_5330`: `アカウントモード変更サービスが初期化されていません。` |

3. mode 値を [[02_1.00-モデル定義]].アカウントモード へ変換する

	| 項目 | 内容 |
	|---|---|
	| 入力 | `args[0]` |
	| 名称指定 | 英語ID（`PLAYER` / `BUILDER` / `ADMIN`）と大小無視で一致した場合に採用する |
	| 数値指定 | 整数として解析でき、列挙値（`0`/`1`/`2`）と一致する場合に採用する |
	| 拒否時メッセージ | `PlayerMsgId.P_5331`: `mode は名称（PLAYER/BUILDER/ADMIN）または 0, 1, 2 のいずれかで指定してください。` |

4. 対象アカウントを解決する

	| 項目 | 内容 |
	|---|---|
	| 入力 | `args[1]`（省略可） |
	| 省略時（プレイヤー実行） | 実行者の選択中アカウント UUID を対象とする |
	| 省略時（コンソール実行） | エラーメッセージ（`PlayerMsgId.P_5305`）を返して終了する |
	| プレイヤー名指定 | オンラインプレイヤーの [[03_1.00-モデル定義]].プレイヤーセッション.account.uuid を使用する |
	| アカウントUUID指定 | [[02_3.01-サービス]].アカウント取得 で存在確認する |
	| ユーザUUID指定 | [[01_3.02-サービス]].ユーザ取得 後、[[02_3.01-サービス]].選択アカウント取得 で解決する |
	| 拒否時メッセージ | `PlayerMsgId.P_5333`: `対象アカウントが見つかりません: %s` |

5. [[02_3.01-サービス]].アカウントモード更新を実行する
6. オンライン中の [[03_1.00-モデル定義]].プレイヤーセッション へ反映する

	| 項目 | 内容 |
	|---|---|
	| 一致条件 | 更新後アカウントUUIDとオンラインプレイヤーのアカウントUUIDが一致 |
	| ビルダー / 管理者 → 別 mode 時 | 反映前に inventory feature のツールモード用スナップショット保存を依頼する |
	| 通常プレイヤー | inventory feature へGUIインベントリ反映を依頼する |
	| ビルダー | inventory feature へ BUILDER 用スナップショット復元を依頼する |
	| 管理者 | inventory feature へ ADMIN 用スナップショット復元を依頼する |
	| その他 | GUIインベントリをクリアする |

7. 成功メッセージを返す

	| 項目 | 内容 |
	|---|---|
	| ID | `PlayerMsgId.P_5332` |
	| レベル | `INFO` |
	| テンプレート | `アカウントモードを更新しました: %s = %s` |
	| 出力条件 | モード更新成功時 |
	| 引数 | `updated.getAccountName()`, `updated.getMode().name()`（英語ID） |

### アカウント補完候補取得

クラス名: `AccountTabCompleter`
物理名: `getCompletions`

処理内容:

1. 第1引数位置では `mode` を返す
2. `mode` サブコマンド時はアカウントモード補完候補取得へ委譲する
3. それ以外は空リストを返す

### アカウントモード補完候補取得

クラス名: `AccountModeTabCompleter`
物理名: `getCompletions`

処理内容:

1. 第1引数位置ではモード名称（`PLAYER`, `BUILDER`, `ADMIN`）とモード値（`0`, `1`, `2`）を返す
2. 第2引数位置ではオンラインプレイヤー名を返す
3. それ以外は空リストを返す

## 2. コマンド仕様

- ルート: `/account`
- サブコマンド: `/account mode <mode> [<player|accountUuid>]`
  - `<mode>` は名称（`PLAYER`/`BUILDER`/`ADMIN`）または数値（`0`/`1`/`2`）
  - 対象指定省略時はプレイヤー実行者の選択中アカウント。コンソール実行で省略した場合はエラー。
- 短縮ルート: `/am <mode> [<player|accountUuid>]`
  - `/account mode` と同じ権限・入力・補完・処理を使用する。
