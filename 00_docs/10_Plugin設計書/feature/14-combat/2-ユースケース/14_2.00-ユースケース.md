# 14_2.00-ユースケース

## 属性付き魔法攻撃

1. スキルが `attackType: MAGIC` と火属性倍率0.8を渡す。
2. `DamageCalculator` が魔法攻撃値を解決し0.8倍する。
3. `MAGIC_DEFENSE`、レベル差、会心を適用する。
4. 攻撃者の火属性ダメージ増加と火属性貫通、対象の火属性耐性を適用する。
5. 衰弱による与ダメージ補正後、シールドまたはHPへ反映する。

## 複数属性攻撃

1. スキルが氷0.3と雷0.3を渡す。
2. 合計倍率0.6で攻撃種別共通の計算を行う。
3. 算出値を1:1で氷成分と雷成分に配分する。
4. 氷・雷それぞれの増加、耐性、貫通を適用して合算する。

## 無属性攻撃

`damageComponents` 未指定は `NONE` 1.0とする。無属性には属性ダメージ増加、属性耐性、属性貫通を適用しない。

## 状態異常DoT

1. `ConditionTickService` が状態異常固有の固定値・HP割合を計算する。
2. `DamageService.applyConditionDamage` が専用DoT増加・耐性・貫通を適用する。
3. 付与元が衰弱中なら最終ダメージを半減する。
4. 会心・命中判定なしでシールドまたはHPへ反映する。
5. 毒は現在HP割合を参照し、HP1で停止する。
