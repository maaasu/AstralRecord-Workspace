# 14_4-統合フロー

## 1. Bukkit damage event 変換

### シーケンス

```mermaid
sequenceDiagram
    participant Bukkit as EntityDamageByEntityEvent
    participant Event as CombatDamageEventHandler
    participant Ring as SkillActionRingService
    participant Damage as DamageService
    participant Resolver as resolveEntity

    Bukkit->>Event: onEntityDamageByEntity
    Event->>Ring: player attack suppressed?
    alt action ring が抑止
        Event->>Bukkit: cancel / damage=0
    else 通常
        Event->>Damage: handleEntityDamage
        Damage->>Resolver: attacker / victim 解決
        alt 両者 unmanaged
            Damage-->>Bukkit: event を変更しない
        else managed を含む
            Damage->>Bukkit: cancel / damage=0
            Damage->>Damage: attack または fixed applyDamage
        end
    end
```

### 処理要点

- player semantic input の winner selection は event 発生前の player-interaction を正本とする。
- Mob -> player は AI / skill の直接呼び出しを正本とし、Bukkit event 経路では再適用しない。

### 例外・終了条件

- damage-immune Mob、managed victim でない event は custom HP を変更しない。
- handler 例外は `E_5900` を記録して event loop へ伝播しない。

## 2. damage 計算・shield / HP 反映

### シーケンス

```mermaid
sequenceDiagram
    participant Source as attack / skill / fixed effect
    participant Service as DamageService
    participant Calc as DamageCalculator
    participant Shield as Status / Mob shield
    participant HP as StatusService / MobInstance
    participant Side as threat / durability / display / log

    Source->>Service: attack / applyDamage
    Service->>Calc: calculate(context)
    Calc-->>Service: DamageResult（通常会心 / 超星会心）
    Service->>Service: condition / temporary multiplier
    alt active shield
        Service->>Shield: shield damage
    else no shield
        Service->>HP: HP damage
    end
    Service->>Side: knockback・threat・durability・会心演出・表示・message
    opt プレイヤーから Mob への超星会心
        Service->>Service: 追尾弾を7個生成
        Service->>Service: 各命中先へ FORCE モードで再計算
    end
```

### 処理要点

- 1 hit は shield または HP のどちらか一方へ適用する。
- hit / 通常会心 / 超星会心情報は shield result にも保持し、表示・durability 判定で共有する。
- damage または shield damage が成立した会心は、共通 particle definition / display service と会心種別ごとの sound で被弾中心へ演出する。両会心の同時成立時は両演出を重ねる。
- 追尾弾の再計算は超星会心倍率を強制適用するが、超星会心判定と追加弾生成は行わない。
- damage number と詳細 message は player setting を確認する。

### 例外・終了条件

- evade、0 damage、dead player、damage immune、condition immunity は副作用を最小化して終了する。

## 3. lethal damage

### シーケンス

```mermaid
sequenceDiagram
    participant Damage as DamageService
    participant Status as StatusService
    participant PlayerDeath as PlayerDeathService
    participant Mob as MobInstance
    participant MobDeath as MobCombatService
    participant Boss as BossChallengeService

    alt victim player
        Damage->>Status: consumeHp
        alt HP <= 0
            Damage->>Boss: handleParticipantDeath
            opt boss が処理しない
                Damage->>PlayerDeath: startDeath
            end
        end
    else victim Mob
        Damage->>Mob: currentHealth 減算・DEAD
        alt boss Mob
            Damage->>MobDeath: handleDeath(recipients)
            Damage->>Boss: handleBossDefeated
        else normal Mob
            Damage->>MobDeath: handleDeath
        end
    end
```

### 処理要点

- player 独自 HP 反映は実装済みで、Bukkit health damage の将来対応ではない。
- boss は participant death / reward recipient / defeated lifecycle を通常 death と分岐する。

### 例外・終了条件

- death flow 中 player は `resolveEntity` で managed player に戻さず、重複 death を防ぐ。
