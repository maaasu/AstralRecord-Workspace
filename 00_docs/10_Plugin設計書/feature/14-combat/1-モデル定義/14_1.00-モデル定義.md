# 14_1.00-モデル定義

## 1. 攻撃種別

物理名: `AttackType`

攻撃力の系統を表す列挙。武器種別・スキル種別・Mob 攻撃などの発生経路に依らず、ダメージ計算で参照する攻撃力種別を識別する。

| 値 | 説明 |
|---|---|
| `MELEE` | 近接攻撃。`STRENGTH` スケーリング |
| `RANGED` | 間接攻撃（弓・投擲等）。`DEXTERITY` スケーリング |
| `MAGIC` | 魔法攻撃。`INTELLIGENCE` スケーリング |

## 2. ダメージ種別

物理名: `DamageType`

防御計算の分岐に用いるダメージ系統。

| 値 | 説明 |
|---|---|
| `PHYSICAL` | 物理ダメージ。物理防御で軽減される |
| `MAGIC` | 魔法ダメージ。魔法防御で軽減される |
| `TRUE` | 純粋ダメージ。防御計算をスキップし最終ダメージへ直接適用される |

## 3. 属性種別

物理名: `DamageElement`

ダメージの属性を表す列挙。`DamageType` が防御計算の分岐を表すのに対し、`DamageElement` は属性耐性、弱点、表示色、状態異常連携のために使用する。

| 値 | 説明 | 主な用途 |
|---|---|---|
| `NEUTRAL` | 無属性。既存ダメージの既定値 | 既存 skill / 通常攻撃 |
| `FIRE` | 火属性 | 炎上、火球、燃焼系スキル |
| `ICE` | 氷属性 | 冷気、凍結、氷魔法 |
| `POISON` | 毒属性 | 毒 DoT、毒罠 |
| `LIGHTNING` | 雷属性 | スタン、雷撃 |
| `HOLY` | 聖属性 | 回復反転、聖属性攻撃 |
| `DARK` | 闇属性 | 沈黙、呪い、闇属性攻撃 |

既存 filebase の `damageElement` 未指定値は `NEUTRAL` とする。
`DamageElement` は `DamageType` と直交するため、`DamageType.MAGIC + DamageElement.FIRE` や `DamageType.TRUE + DamageElement.POISON` のように組み合わせる。

## 4. 属性補正プロファイル

物理名: `DamageElementProfile`

攻撃者の属性与ダメージ倍率と、被弾者の属性被ダメージ倍率を解決するためのモデル。
初期実装では `StatusType` に属性攻撃・属性耐性を追加せず、全属性 1.0 を返す。
将来、装備・Mob・class・buff から属性補正を読み込む場合も、`DamageCalculator` はこのプロファイル経由で参照する。

| 項目 | 説明 |
|---|---|
| `element` | 対象属性 |
| `attackMultiplier` | 攻撃者側の属性与ダメージ倍率 |
| `defenseMultiplier` | 被弾者側の属性被ダメージ倍率 |
| `finalMultiplier` | `attackMultiplier * defenseMultiplier` |

## 5. ダメージコンテキスト

物理名: `DamageContext`

ダメージ計算に必要な入力情報を集約したモデル。攻撃者・被弾者は `AstEntity` として保持し、攻撃種別／ダメージ種別の判定結果を併せて保持する。

| 項目 | 説明 |
|---|---|
| `attacker` | 攻撃者エンティティ。環境ダメージ等で不在の場合は `null` |
| `victim` | 被弾者エンティティ |
| `baseDamage` | Bukkit イベント、スキル、Mob 攻撃などの呼び出し元から渡される基礎ダメージ |
| `attackType` | [[14_1.00-モデル定義]].攻撃種別 |
| `damageType` | [[14_1.00-モデル定義]].ダメージ種別 |
| `damageElement` | [[14_1.00-モデル定義]].属性種別。未指定時は `NEUTRAL` |
| `sourceConditionType` | 状態異常 DoT 由来の場合の `ConditionType`。通常ダメージでは `null` |
| `scaling` | `DamageScaling`。攻撃者ステータス依存か固定値かを表す |

`from(EntityDamageByEntityEvent)` ファクトリで Bukkit のエンティティ間ダメージイベントからも構築できる。実運用では `DamageService` が `AstPlayer` 解決済みの `AstEntity` を渡して構築する。

## 6. AstEntity

物理名: `AstEntity`

ダメージ処理で扱うプレイヤー / Mob / Bukkit エンティティの共通モデル。

| 項目 | 説明 |
|---|---|
| `type` | [[14_1.00-モデル定義]].AstEntityType |
| `player` | `AstPlayer`。`type = PLAYER` の場合のみ保持 |
| `mob` | `MobInstance`。`type = MOB` の場合のみ保持 |
| `bukkitEntity` | Bukkit `Entity`。`type = BUKKIT`、または `PLAYER` の Bukkit 実体として保持 |

`statValue(StatusType)` はプレイヤーでは `StatusSnapshot`、Mob では `MobTemplate.baseStats` を参照する。`currentHealth()` / `maxHealth()` はダメージ反映・致死判定の入力として使用する。

## 7. AstEntityType

物理名: `AstEntityType`

| 値 | 説明 |
|---|---|
| `PLAYER` | `AstPlayer` として管理されるプレイヤー |
| `MOB` | `MobInstance` として管理される独自 Mob |
| `BUKKIT` | AstPlayer / MobInstance へ解決できない Bukkit エンティティ |

## 8. ダメージ計算結果

物理名: `DamageResult`

ダメージ計算の出力モデル。`finalDamage` は防御・補正適用後の値であり、必ず 0 以上であることを呼び出し側で保証する。

| 項目 | 説明 |
|---|---|
| `finalDamage` | 最終ダメージ（0 以上） |
| `shieldDamage` | シールドへ適用したダメージ（0 以上） |
| `shieldBroken` | この結果でシールドを破壊したか |
| `critical` | 会心 / 超会心が成立したダメージ結果か。ダメージログ表示と会心ヒット音に使用する |
| `evaded` | 命中判定で回避されたか |
| `hitChance` | 命中判定に使用した最終命中率（%） |
| `accuracy` | 攻撃者の命中率（%） |
| `evasion` | 被弾者の回避率（%） |
