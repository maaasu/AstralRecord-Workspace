# 14_1.00-モデル定義

## `AttackType`

| 値 | 攻撃値 | 主能力値 | 防御値 |
| --- | --- | --- | --- |
| `MELEE` | `MELEE_ATTACK` | `STRENGTH` | `DEFENSE` |
| `RANGED` | `RANGED_ATTACK` | `DEXTERITY` | `DEFENSE` |
| `MAGIC` | `MAGIC_ATTACK` | `INTELLIGENCE` | `MAGIC_DEFENSE` |

## `DamageElement`

| 値 | 論理名 |
| --- | --- |
| `NONE` | 無属性 |
| `FIRE` | 火 |
| `ICE` | 氷 |
| `LIGHTNING` | 雷 |
| `POISON` | 毒 |
| `LIGHT` | 光 |
| `DARK` | 闇 |

属性と攻撃種別は独立する。近接・間接・魔法のいずれも全属性を持てる。

## `DamageComponent`

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `element` | `DamageElement` | 属性 |
| `ratio` | `double` | 攻撃値へ掛ける倍率。0.8は80% |

空の成分リストは `NONE` 1.0へ補正する。火0.6と氷0.3＋雷0.3は、属性補正がなければ同じ基礎ダメージになる。

## `DamageContext`

| フィールド | 説明 |
| --- | --- |
| `attacker` | 攻撃者。環境由来はnull |
| `victim` | 被弾者 |
| `baseDamage` | 固定値または最低基礎値 |
| `attackType` | 攻撃種別 |
| `components` | 属性別倍率一覧 |
| `scaling` | `ATTACKER_STATUS` / `FIXED` |

## `DamageResult`

HPダメージ、シールドダメージ、シールド破壊、会心、回避、命中率の結果を保持する。状態異常DoTは常に非会心・非回避とする。

## `AstEntity`

`AstPlayer`、`MobInstance`、Bukkit Entityの差を吸収し、ステータス・HP・レベル・位置を共通参照する。属性・状態異常ステータスも `statValue(StatusType)` から取得する。
