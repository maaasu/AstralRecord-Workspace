# 14_3.02-サービス

## `DamageCalculator.calculate`

`ATTACKER_STATUS` の攻撃値は次式で解決する。

```text
resolvedAttack = ATTACK * (1 + primary / 100) + typedAttack
ratioTotal = sum(component.ratio)
preDefense = max(baseDamage, resolvedAttack) * ratioTotal
postDefense = max(1, criticalApplied - defense * 0.5)
postLevel = postDefense * levelDifferenceMultiplier
```

各属性成分は次式で計算する。

```text
share = postLevel * component.ratio / ratioTotal
effectiveResistance = max(0, resistance - penetration)
elementMultiplier = max(0, 1 + damageIncrease / 100)
                  * max(0, 1 - effectiveResistance / 100)
componentDamage = share * elementMultiplier
finalDamage = sum(componentDamage)
```

`MELEE`と`RANGED`は`DEFENSE`、`MAGIC`は`MAGIC_DEFENSE`を参照する。別のダメージ分類は使用しない。

## `DamageService.attack`

攻撃者・対象・攻撃種別・属性成分を受け、`ATTACKER_STATUS`として計算する。属性成分省略時は無属性100%。計算後に攻撃元の衰弱倍率を掛け、シールド、HP、死亡、脅威値、表示を処理する。

## `DamageService.applyDamage`

固定基礎ダメージを攻撃種別と無属性100%で処理する。命中・回避判定は行わないが、通常ダメージとして防御と属性以外の最終補正は適用する。

## `DamageService.applyConditionDamage`

状態異常DoT専用経路。状態異常ごとのダメージ増加・耐性・貫通と、付与元の衰弱を適用する。属性ステータス、防御、会心、回避は参照しない。毒は対象のHPを1未満にしない。
