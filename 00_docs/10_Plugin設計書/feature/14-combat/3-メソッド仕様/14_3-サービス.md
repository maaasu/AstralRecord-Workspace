# 14_3-サービス

## 1. damage 計算

クラス名: `DamageCalculator`
物理名: `calculate`

`ATTACKER_STATUS` の基礎 attack は次式とする。

```text
statusAttack = ATTACK * (1 + primary / 100) + typedAttack
resolvedAttack = max(baseDamage, statusAttack)  // ATTACKER_STATUS
resolvedAttack = baseDamage                     // FIXED
R = max(0, resolvedAttack)
preDefense = R * sum(positive component ratios)
           * sourceDamageMultiplier * attackerDamageMultiplier

D = effectiveGeneralDefense + effectiveTypedDefense
Q = D / R
B = 2.5
G = log(0.5) / log(1 - 1 / B)

defenseMultiplier = 0                         // R <= 0 または Q >= B
defenseMultiplier = (1 - Q / B) ^ G           // 上記以外
postDefense = criticalApplied * defenseMultiplier  // managed victim
```

`R` は component ratio、発生元倍率、攻撃者固有倍率、会心より前の解決攻撃力である。`D` は共通防御と攻撃種別防御へ各貫通率を適用した後の合計である。攻防が同値なら50%軽減し、防御が攻撃の2.5倍以上ならダメージを0にする。防御倍率を会心後ダメージ全体へ掛けるため、skill 倍率や会心倍率が上がっても同じ攻防比率の軽減率は変わらない。

element component ごとは次式とする。

```text
share = postDefense * component.ratio / ratioTotal
effectiveResistance = min(resistance, resistanceCap) - penetration
elementMultiplier = max(0, 1 + increase / 100)
                  * max(0, 1 - effectiveResistance / 100)
finalDamage = sum(share * elementMultiplier)
```

`ATTACKER_STATUS` の managed attacker だけ hit 判定を行う。通常会心は scaling を問わず managed attacker に適用する。超星会心はプレイヤーから攻撃可能 Mob への攻撃だけを対象に通常会心とは独立して判定し、成立時は主攻撃へ `SUPER_CRITICAL_DAMAGE / 100`（未設定時30%）を乗算する。

命中時の `DamageResult.breakdown` には、解決攻撃力、貫通前後の defense、非 `NONE` 属性ごとの上限・貫通適用前後の resistance を同じ計算内で保存する。damage log はこの snapshot を使用し、表示時に status を再取得しない。

## 2. 超星会心追尾弾

クラス名: `SuperStarCriticalProjectileService`
物理名: `spawn`

超星会心が成立した主攻撃ごとに、被弾 Mob の身体中央からネザースターの `ItemDisplay` を7個生成する。各追尾弾は水平面のランダムな方位、上向き25～65度の仰角、毎秒3.2～4.8 block の速度を個別に抽選し、10～20 tick（1.6～4.8 block）直進する。その後は半径24 block 内の最寄りの攻撃可能 Mob を毎 tick 再選択し、毎秒7 block で追尾する。対象不在時はその場で再索敵し、生成から100 tick（5秒）で消滅する。

Mob の当たり判定へ接触した追尾弾は消滅し、元攻撃と同じ attack type、element component、scaling、source でダメージを再計算する。命中、通常会心、対象防御、属性補正、最終補正を再評価し、超星会心は発生率を再抽選せず `SUPER_CRITICAL_DAMAGE / 100` を強制適用する。追尾弾から追加の追尾弾は生成せず、装備耐久消費とノックバックも発生させない。

## 3. hit chance 計算

クラス名: `DamageCalculator`
物理名: `calculateHitChance`

`clamp(accuracy - evasion, 0, 100)` を返す。Mob の configured accuracy が 0 以下の場合は 100 を既定値にする。

## 4. Bukkit damage 変換

クラス名: `DamageService`
物理名: `handleEntityDamage`

projectile shooter を含め attacker / victim を解決する。両者 unmanaged は event を維持する。一方でも managed なら event を cancel / 0 damage とし、victim unmanaged、damage-immune Mob、Mob -> player の event 経路は終了する。managed attacker は `attack`、unmanaged attacker は event damage の `applyDamage` へ接続する。Mob -> player は AI の直接呼び出しを正本とし、event から二重適用しない。

## 5. status scaling attack

クラス名: `DamageService`
物理名: `attack`

attacker / victim、attack type、任意の component list を `DamageScaling.ATTACKER_STATUS` で共通処理へ渡す。component 省略時は無属性 1.0。

## 6. fixed / effect damage

クラス名: `DamageService`
物理名: `applyDamage`, `applyEffectDamage`

外部 base を `DamageScaling.FIXED` で処理する。`applyDamage` は指定 attack type、`applyEffectDamage` は `MAGIC` / 無属性を使用する。hit は省略するが managed attacker の critical、victim defense、最終 modifier は適用する。

## 7. condition damage

クラス名: `DamageService`
物理名: `applyConditionDamage`

dead player、damage-immune Mob を除外し、condition 固有 multiplier、dealt multiplier、temporary effect を base に掛ける。poison は `currentHealth - 1` を上限とし、shield、HP、表示へ反映する。通常 calculator と damage log は通さない。

## 8. Bukkit entity 解決

クラス名: `DamageService`
物理名: `resolveEntity`

projectile shooter、alive `AstPlayer`、`MobService` の entity index の順に解決し、該当しなければ `AstEntity.bukkit` を返す。death flow 中 player は managed player として再解決しない。

## 9. result 反映（内部）

クラス名: `DamageService`
物理名: `applyDamageResult`

- shield damage は shield threat と break / hit effect を反映し、同 hit の HP damage は 0 とする。
- evade と 0 damage を除き、通常会心は `CRITICAL_HIT_CRIT` と `ENTITY_PLAYER_ATTACK_CRIT`、超星会心は `SUPER_STAR_CRITICAL_BURST_END_ROD` / `SUPER_STAR_CRITICAL_IMPACT` と `ENTITY_FIREWORK_ROCKET_TWINKLE` を被弾対象の身体中央へ反映する。shield damage でも会心情報を維持して表示し、両会心が成立した場合は両演出を重ねる。パーティクル表示は `ParticleDisplayService` を経由する。
- player HP は `StatusService.consumeHp` で減算し、HP 0 なら boss participant death または `PlayerDeathService.startDeath` を呼ぶ。
- Mob HP は `MobInstance.currentHealth` へ反映し、player threat / aggro / boss damage を更新する。通常個体は HP 0 なら Mob / boss death を呼ぶ。`nonLethal=true` の個体は実効 HP damage を `min(max(0, currentHealth - 1), finalDamage)` とし、更新後 HP を 1 以上に保って死亡処理を呼ばない。
- HP damage 時だけ attack type に応じた knockback を適用する。

## 10. level difference

クラス名: `LevelDifferenceCalculator`
物理名: `damageMultiplier`, `experienceMultiplier`, `scaleExperience`

レベル差を Mob 撃破経験値の倍率へ変換する。ダメージ計算には使用しない。
