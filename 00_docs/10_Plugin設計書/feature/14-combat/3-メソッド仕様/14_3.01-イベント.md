# 14_3.01-イベント

## 1. Entity 間 damage 受信

クラス名: `CombatDamageEventHandler`
物理名: `onEntityDamageByEntity`
イベント: `EntityDamageByEntityEvent`
priority: `NORMAL`、`ignoreCancelled = true`

1. damager が player かつ action ring service が attack を抑止中なら、event を cancel して damage を 0 にする。
2. その他は `DamageService.handleEntityDamage` へ委譲する。
3. 例外は `runSafely` で捕捉し、victim entity 名を引数に `E_5900` を記録する。

player 起点 semantic input の候補収集・winner selection は [[28_3.01-イベント]] と [[28_3.02-サービス]] を正本とし、本 handler は同じ入力を再調停しない。
