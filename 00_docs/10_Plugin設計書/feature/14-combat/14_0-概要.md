# 14_0-概要

## 1. 目的

combat feature は player と custom Mob の damage 計算、shield / HP 反映、threat・death・表示への副作用を一元管理する。Bukkit の damage 値は custom combat への入口に限定し、managed entity の状態正本にはしない。

## 2. 分類

- attack type は `MELEE`、`RANGED`、`MAGIC`。
- element は `NONE`、`FIRE`、`ICE`、`LIGHTNING`。
- scaling は attacker status から基礎値を作る `ATTACKER_STATUS` と、外部の基礎値を使う `FIXED`。
- attack type と element は独立し、1 attack に複数 element ratio を指定できる。

## 3. 計算順序

1. `ATTACKER_STATUS` だけ accuracy - evasion で hit 判定する。
2. scaling に応じて基礎 damage を解決し、element ratio 合計を掛ける。
3. managed attacker は scaling に関係なく通常会心を判定する。プレイヤーから攻撃可能 Mob への攻撃では、通常会心と独立して超星会心も判定する。
4. managed victim の有効 defense と解決攻撃力の比率から防御倍率を求め、会心後ダメージへ1回だけ乗算する。
5. damage を element ratio で配分し、element increase / resistance / penetration を成分ごとに適用する。
6. condition / temporary skill の最終 multiplier、shield、HP の順に反映する。有効shieldがなければ直接攻撃へ `FIXED_HEALTH_DAMAGE` を加算する。非致死 Mob は HP 1 を下限とする。
7. threat、durability、会心・hurt / death effect、damage number、詳細 message を反映する。

通常判定 `ROLL` で超星会心が成立した主攻撃は `1 + SUPER_CRITICAL_DAMAGE / 100` を乗算し、被弾 Mob を起点として7個の追尾弾を生成する。各追尾弾はランダムな曲率軸・位相により初期飛行と追尾の両方で曲線軌道を描く。命中時は元攻撃と同じ attack type、element component、scaling、source で計算をやり直し、命中・通常会心・防御・属性補正を再評価する。追尾弾の `FORCE` は超星会心を再抽選せず `SUPER_CRITICAL_DAMAGE / 100` だけを強制適用し、追加の追尾弾を生成しない。

damage または shield damage が成立した通常会心は `CRIT` パーティクルと critical attack sound、超星会心は `END_ROD` / `FLASH` の重ね合わせと firework twinkle sound を被弾対象の身体中央へ表示する。両方が独立して成立した hit は両演出を重ねる。パーティクルは `SharedParticleDefinitions` の共通定義を `ParticleDisplayService` で表示し、viewer ごとの particle density 設定を反映する。

## 4. condition damage

condition damage は専用 multiplier と temporary modifier を適用し、hit、critical、defense、element status、shield を参照しない。すべての condition damage は shield 残量を変更せず HP へ直接適用し、HP 0 に到達した場合は通常の死亡処理へ進む。

## 5. 固定HPダメージとShield

`FIXED_HEALTH_DAMAGE` は `DamageScaling.FIXED` と別の攻撃者ステータスである。`NORMAL_ATTACK` / `SKILL` の命中ごとに通常HPダメージへ加算し、防御・会心・属性・一時/condition/最終倍率・ライフスティール算出元の影響を受けない。回避・無効・condition DoT・有効shield中は発生せず、shieldを破壊したhitでもHPへ通さない。

有効shieldは一撃のHPダメージを完全に遮断し、破壊時の余剰も同hitでHPへ通さない。シールドが破壊された場合は、シールド再充填パッシブの有無にかかわらず基礎30秒後に最大値まで一括回復する。シールド再充填パッシブが有効なプレイヤーは、シールドを保持した状態でシールドまたはHPへの実ダメージを受けたとき、または既存セッションで正数の最大シールドが上昇して現在Shieldが新しい最大値未満のときに設定した待機を開始し、待機後は毎秒定義値ずつ最大値まで段階回復する。再充填中は修復を示す共有パーティクルを表示する。シールドリチャージは最大シールド30、待機8秒、毎秒2%回復とし、ソードマンのskilltree node `1202` とAdministratorの `usableSkills` から使用許可を与える。

`MobInstance.nonLethal=true` の victim は damage 種別にかかわらず実効 HP damage を残 HP 1 までに制限し、death / drop へ進めない。現在この runtime flag は [[31_0-概要]] の検証用カカシが使用する。

## 6. 入力境界

player の左クリック通常攻撃は [[28_4-統合フロー]] の winner executor から `DamageService.attack` へ到達する。`CombatDamageEventHandler` は発生済み `EntityDamageByEntityEvent` の変換だけを担当し、入力候補を選び直さない。Mob AI は skill / built-in attack から直接 `DamageService` を呼ぶ。

player モードの通常攻撃 cast は、空振りを含めて `NormalAttackDegradationService` が成功した連続回数を一時保持し、`NORMAL_ATTACK_DEGRADATION_DELAY` の現在値の非負整数部を既定の猶予回数へ加算した回数から、段階的な通常攻撃倍率・攻撃速度補正を適用する。1ポイントにつき劣化が発生しない回数を1回追加する。ただし、現在クラスが `adventurer` のプレイヤーは通常攻撃劣化の対象外とし、常に通常攻撃を等倍で処理する。劣化ダメージは既存のPvE標的選別を通った Mob だけへ適用する。通常攻撃失敗時は状態を更新前へ戻し、成功した通常攻撃以外のスキル発動または10秒間の通常攻撃停止で解除する。劣化段階は専用の赤色6分割BossBarへ表示し、PvPには適用しない。

## 7. 依存・連携

- `status`: 攻撃・防御・属性・状態異常 status と player HP / shield 更新を扱う。
- `player`: `AstPlayer` 解決、死亡中判定、独自 death flow を扱う。
- `mob` / `boss`: `MobInstance`、threat、drop、boss damage / death を扱う。
- `skill` / `condition`: active skill、temporary modifier、condition damage の発生元となる。
- `item`: 攻撃命中・被弾時の equipment durability を扱う。
- `player-setting` / `display`: damage number と詳細 message の表示可否・描画を扱う。
- `player-interaction`: player 起点の通常攻撃と他 action の入力排他を正本とする。
