# 14_0.00-概要

`feature/combat` はプレイヤーとカスタムMobの独自ダメージ計算を一元管理する。

## 方針

- 攻撃種別は `MELEE`（近接）、`RANGED`（間接）、`MAGIC`（魔法）の3種類だけとする。
- `PHYSICAL` / `MAGIC` / `TRUE` のような別のダメージ分類は持たない。
- 攻撃種別は攻撃力・能力値・防御力の参照元を決める。
- 属性は `NONE` / `FIRE` / `ICE` / `LIGHTNING` / `POISON` / `LIGHT` / `DARK` とする。
- スキルは属性ごとのダメージ倍率を複数保持できる。属性未指定は無属性100%とする。
- 属性ダメージ増加、属性耐性、属性貫通はすべて%値として扱う。
- 状態異常DoTは属性ダメージとは独立し、状態異常専用の増加・耐性・貫通を使う。

## 計算の責務

1. `AttackType` から攻撃力と防御力を解決する。
2. 属性成分の倍率合計を基礎ダメージへ掛ける。
3. 通常攻撃だけ命中・会心を判定する。
4. 防御力とレベル差を適用する。
5. ダメージを属性倍率の比率で配分する。
6. 属性成分ごとにダメージ増加・耐性・貫通を適用して合算する。
7. 衰弱などの最終補正、シールド、HPの順に反映する。

DoTは会心・命中判定を行わない。毒状態のDoTだけはHPを1未満にしない。
