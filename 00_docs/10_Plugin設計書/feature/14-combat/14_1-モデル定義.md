# 14_1-モデル定義

## 1. attack type

物理名: `AttackType`

| 値 | typed attack | primary status | defense |
|---|---|---|---|
| `MELEE` | `MELEE_ATTACK` | `STRENGTH` | `DEFENSE` |
| `RANGED` | `RANGED_ATTACK` | `DEXTERITY` | `DEFENSE` |
| `MAGIC` | `MAGIC_ATTACK` | `INTELLIGENCE` | `MAGIC_DEFENSE` |

## 2. element / component

物理名: `DamageElement`、`DamageComponent`

element は `NONE`、`FIRE`、`ICE`、`LIGHTNING`、`POISON`、`LIGHT`、`DARK`。component は element と非負の ratio を持つ。空 component list は `NONE` / `1.0` へ補正し、計算時は ratio 0 以下を除外する。

## 3. scaling

物理名: `DamageScaling`

- `ATTACKER_STATUS`: `ATTACK * (1 + primary / 100) + typedAttack` と外部 base の大きい方を使い、hit 判定を行う。
- `FIXED`: 外部 base をそのまま使い、hit 判定を省略する。managed attacker の critical は省略しない。

## 4. damage context

物理名: `DamageContext`

nullable attacker、必須 victim、base damage、attack type、component list、scaling を保持する。`from(EntityDamageByEntityEvent)` は Bukkit entity、event damage、`MELEE`、無属性 1.0、`ATTACKER_STATUS` の既定 context を作る。

## 5. damage result

物理名: `DamageResult`

| 項目 | 内容 |
|---|---|
| `finalDamage` | HP に反映する damage |
| `shieldDamage` | shield に反映する damage |
| `shieldBroken` | この hit で shield が 0 になったか |
| `critical` | critical または super critical が成立したか |
| `evaded` | hit 判定で回避されたか |
| `hitChance`, `accuracy`, `evasion` | 判定と詳細 log 用の値 |

shield が有効な hit は HP へ貫通せず、命中・critical 情報を保った shield-only result へ変換する。

## 6. unified entity

物理名: `AstEntity`、`AstEntityType`

`PLAYER`、`MOB`、管理外 `BUKKIT` を統一し、ID、名前、位置、level、status、現在 / 最大 HP、元 `AstPlayer` / `MobInstance` / Bukkit entity を参照する。projectile は shooter entity を再帰解決する。

## 7. level difference

物理名: `LevelDifferenceCalculator`

`damageMultiplier` は attacker / defender level 差を damage 補正へ、`experienceMultiplier` / `scaleExperience` は reward 補正へ変換する。具体式は同クラスを正本とし、変更時は combat と mob reward の双方を更新する。
