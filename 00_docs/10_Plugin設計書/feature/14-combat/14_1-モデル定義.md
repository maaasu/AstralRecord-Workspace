# 14_1-モデル定義

## 1. attack type

物理名: `AttackType`

| 値 | typed attack | primary status | defense |
|---|---|---|---|
| `MELEE` | `MELEE_ATTACK` | `STRENGTH` | `DEFENSE` |
| `RANGED` | `RANGED_ATTACK` | `DEXTERITY` | `DEFENSE` |
| `MAGIC` | `MAGIC_ATTACK` | `INTELLIGENCE` | `MAGIC_DEFENSE` |

## 2. element / component

物理名: `DamageElement`、`DamageComponent`

element は `NONE`、`FIRE`、`ICE`、`LIGHTNING`、`POISON`、`LIGHT`、`DARK`。component は element と非負の ratio を持つ。空 component list は `NONE` / `1.0` へ補正し、計算時は ratio 0 以下を除外する。

## 3. scaling

物理名: `DamageScaling`

- `ATTACKER_STATUS`: `ATTACK * (1 + primary / 100) + typedAttack` と外部 base の大きい方を使い、hit 判定を行う。
- `FIXED`: 外部 base をそのまま使い、hit 判定を省略する。managed attacker の通常会心は省略せず、プレイヤーから攻撃可能 Mob への攻撃では超星会心も判定する。

## 4. damage context

物理名: `DamageContext`

nullable attacker、必須 victim、base damage、attack type、component list、scaling、source、超星会心モードを保持する。超星会心モードは発生率を判定する `ROLL`、倍率を強制適用する `FORCE`、無効化する `DISABLED` で構成する。`from(EntityDamageByEntityEvent)` は Bukkit entity、event damage、`MELEE`、無属性 1.0、`ATTACKER_STATUS`、`ROLL` の既定 context を作る。

## 5. damage result

物理名: `DamageResult`

| 項目 | 内容 |
|---|---|
| `finalDamage` | HP に反映する damage |
| `shieldDamage` | shield に反映する damage |
| `shieldBroken` | この hit で shield が 0 になったか |
| `critical` | 通常会心が成立したか |
| `superStarCritical` | 超星会心が成立したか |
| `evaded` | hit 判定で回避されたか |
| `hitChance`, `accuracy`, `evasion` | 判定と詳細 log 用の値 |
| `breakdown` | 同じ hit の計算時点で確定した攻撃力・防御力・属性耐性 |

shield が有効な hit は HP へ貫通せず、命中・通常会心・超星会心情報を保った shield-only result へ変換する。

## 6. damage breakdown

物理名: `DamageBreakdown`、`DamageBreakdown.ElementResistance`

| 項目 | 内容 |
|---|---|
| `resolvedAttackPower` | scaling と外部 base を解決した攻撃力 |
| `rawDefense` | 貫通適用前の全体防御力と攻撃種別防御力の合計 |
| `effectiveDefense` | 対応する貫通率を各防御力へ適用した後の合計 |
| `elementResistances` | 使用した非 `NONE` 属性ごとの元耐性と実効耐性 |

`ElementResistance` は element、上限・貫通適用前の `rawResistance`、耐性上限と属性貫通を適用した `effectiveResistance` を保持する。表示処理で status を読み直さず、計算に実際に使った値を damage log へ渡すための snapshot とする。

## 7. unified entity

物理名: `AstEntity`、`AstEntityType`

`PLAYER`、`MOB`、管理外 `BUKKIT` を統一し、ID、名前、位置、level、status、現在 / 最大 HP、元 `AstPlayer` / `MobInstance` / Bukkit entity を参照する。projectile は shooter entity を再帰解決する。

## 8. level difference（経験値のみ）

物理名: `LevelDifferenceCalculator`

`experienceMultiplier` / `scaleExperience` は reward 補正へ変換する。ダメージ計算にレベル差補正は使用しない。具体式は同クラスを正本とし、変更時は mob reward を更新する。
