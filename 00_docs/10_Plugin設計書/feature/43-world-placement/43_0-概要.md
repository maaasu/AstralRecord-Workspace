# ワールド配置

## 目的と境界

Mob スポナー、固定 NPC、ウェイストーンの設置情報をサーバー環境単位で読み込み、ゲーム実行時へ公開する。`worldPlacements.mode` が `local` の既存サーバーは各 YAML を従来どおり正本とする。移行済みサーバーだけ `api` に切り替え、配置専用 API の `dev` または `channels` 環境を正本とする。

API モードでは `worldPlacements.baseUrl` から全種別・単一 revision のスナップショットを起動時に非同期取得する。`worldId` は論理ワールドの安定 ID、`worldName` は Bukkit の物理名であり、プラグインは物理名を変更せず実行時座標へ渡す。未ロードワールドの配置もスナップショット内に保持し、ワールドが使える時に出現・表示する。API 障害時に旧 YAML へフォールバックしない。

既存のスポナー・NPC・ウェイストーンのゲーム内設置と削除は API モードで読み取り専用として拒否する。配置の編集は World Placement Editor で行い、ゲーム実行時への反映は管理者が `/worldplacements reload` を実行する。マスターデータの health 自動再読込は配置 API の revision を更新しない。ウェイストーンのプレイヤー別解放状態は従来の保存境界を維持する。

詳細な取得・公開契約は [[43_3-配置スナップショット]] を参照する。
