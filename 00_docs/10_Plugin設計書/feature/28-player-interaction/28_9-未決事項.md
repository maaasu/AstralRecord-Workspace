# 28_9-未決事項

## 1. entity 内クリック位置

`PlayerInteractAtEntityEvent` の entity 内クリック位置は、現行の `PlayerInteractionSnapshot` へ保持していない。現在の候補は直接対象 entity、共通 ray、AABB 入口距離、安定 ID だけで決定できるため、業務判定には使用しない。

将来、entity 上の部位別操作を追加する場合は、クリック位置を不変値として snapshot へ追加し、通常の `PlayerInteractEntityEvent` との相関・優先順位・遅延 guard を同時に定義する。

## 2. 入力 family の追加

jump、swap-hand、chat、GUI 内操作は現行 dispatcher の対象外である。新しい family を追加する場合は、ingress、token 相関単位、cancel 方針、他 family と競合させない根拠を先に定義する。

## 3. 明示的な全状態破棄 API

quit 時は player 単位で ledger と pending arm swing を破棄する。plugin disable 時は listener と scheduler の廃棄に追従して gateway 自体が破棄されるため、現行クラスに `clearAll` はない。gateway を plugin lifecycle より長く保持する運用を導入する場合は、全 token と pending fallback を明示破棄する API を追加する。
