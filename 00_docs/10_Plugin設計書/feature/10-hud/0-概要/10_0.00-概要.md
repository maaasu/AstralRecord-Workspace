# 10_0.00-概要

## 1. 目的

`hud` 機能は、オンライン中プレイヤーの表示情報（ActionBar / Sidebar / TabList / バー表示）を定期更新する。
Sidebar はサーバー情報、現在ワールド・地域・地域レベル、プレイヤー情報、クラス情報を表示し、ボス挑戦中はボス情報をクラス情報の下へ追加する。
ただしゲーム中処理として扱う ActionBar / Sidebar / ドッジ受付バー / 壁張り付きバーは `AccountMode.PLAYER` のみを対象とし、`BUILDER` / `ADMIN` では更新しない。
ドッジ入力中は、しゃがみ開始から短時間だけ ActionBar をドッジ受付バーへ一時切り替えし、実行または受付切れで通常のリソース表示へ即時復帰させる。
壁張り付き中は、自然落下へ戻るまでの残り時間を表す壁張り付きバーへ一時切り替えし、解除または時間切れで通常のリソース表示へ即時復帰させる。

## 2. コンテキスト

- ステータス値は `status` feature から取得し、HUD は表示責務に限定する。
- 更新トリガーは `service/PlayerHudService` の定期タスクとする。
- ドッジ受付バーと壁張り付きバーは `service/PlayerHudService` が `1 tick` 間隔の短命タスクで補助描画する。
- 実際の描画処理は `view/PlayerHudView` に集約し、表示ロジックをサービスから分離する。
- Sidebar のクラス情報はクラス名の右にクラスレベルを表示し、クラスEXPバーは表示しない。
- Sidebar の地域レベルは、通常地域ではスポナー出現 Mob の加重平均レベル、拠点では 0、ボスフィールドでは挑戦中ボスのレベルを表示する。
- ボス挑戦中はボス名、共有死亡回数、経過時間、挑戦参加者名を表示する。挑戦していない場合はボス情報を表示しない。
- MSPT・Ping は `PERFORMANCE_INFO_DISPLAY` プレイヤー設定で切り替え、既定値は非表示とする。

## 3. 構成要素（実装単位）

- `service/PlayerHudService`
  - プレイヤー走査、ステータス取得、表示更新呼び出しを行う。
- `view/PlayerHudView`
  - ActionBar / Sidebar / TabList / 各種バーへの描画処理を行う。
