# 10_0.00-概要

## 1. 目的

hud feature は、online player の RPG 状態を ActionBar、vanilla bar、sidebar、tab list へ周期描画する。状態計算は行わず、各 feature の snapshot を表示へ変換する。

## 2. 表示面

| 表示面 | 内容 |
|---|---|
| ActionBar | HP / MP / EN、最大 shield がある場合は SH。dodge / wall / primary renderer が一時上書きする |
| health bar | HP 比率を vanilla 20 health へ写像 |
| food bar | EN 比率を 0..20 へ写像。saturation は 0 |
| experience bar | MP 比率を 0..1 へ写像 |
| armor bar | shield 比率を armor attribute 0..20 へ写像 |
| sidebar | online 数、任意の MSPT / ping、world、region、region level、player level / EXP、class、挑戦中 boss |
| tab list | タイトル。performance 表示が有効な場合は MSPT / ping |

## 3. 更新境界

`PlayerHudService.start` が 10 tick 後から 10 tick 間隔で同期 task を実行する。gameplay mode では全表示面を更新し、非 gameplay mode では sidebar と ActionBar override を解除する。ただし vanilla bar と tab list は online session 全体へ更新する。

## 4. ActionBar 優先順位

1. wall cling window
2. dodge window
3. player UUID ごとの primary renderer
4. status ActionBar
