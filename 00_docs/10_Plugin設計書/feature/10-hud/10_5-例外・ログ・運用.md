# 10_5-例外・ログ・運用

## 1. feature 固有 ID

hud feature は通常 HUD に専用の `LogId` を定義しない。管理者メッセージ BossBar の入力結果には `PlayerMsgId.P_6910`〜`P_6912` を使用する。イベント処理の例外は共通 event ログ `LogId.E_3002` へ記録する。

## 2. 運用方針

- HUD task はメインスレッドで動作するため、renderer と依存値取得にブロッキング I/O を追加しない。
- `setPrimaryActionBarRenderer` を利用する feature は、終了・quit・death・world 変更など自 feature の lifecycle で必ず解除する。
- sidebar の解除は `astral_info` objective だけを対象とし、他 plugin の objective を変更しない。
- health は死亡表現を Bukkit 側へ直接委ねず、RPG HP 比率を最小 0.5 health へ写像する。死亡判定は combat / player death feature を正本とする。
- performance 表示設定は sidebar と tab list で同じ値を使用する。
- 管理者メッセージは最大86400秒で、表示中のメッセージは1件だけ保持する。プラグイン停止時は BossBar と同期更新 task を必ず破棄する。
