# 10_0-概要

## 1. 目的

hud feature は、online player の RPG 状態を ActionBar、vanilla bar、sidebar、tab list へ周期描画する。状態計算は行わず、各 feature の snapshot を表示へ変換する。また、管理者が全プレイヤーへ一時的なメッセージを通知する BossBar を管理する。

## 2. 表示面

| 表示面 | 内容 |
|---|---|
| ActionBar | HP / MP / EN、最大 shield がある場合は SH。Shield リチャージ中も現在値 / 最大値を維持し、SH の括弧内へオレンジ色の `RC` と残り秒数を併記する。通常表示には有効な状態異常を色・太字・識別記号付きで最大3件併記する。dodge / wall / primary renderer が一時上書きする |
| health bar | HP 比率を vanilla 20 health へ写像。赤ハートは最大10個 |
| food bar | EN 比率を 0..20 へ写像。saturation は 0 |
| absorption hearts | MP 比率を vanilla absorption 0..20 へ写像。最大10個の黄色いハートとして表示。独自HP / Shieldダメージでは消費せず、MP更新時に再設定 |
| experience bar / level | アカウント経験値のレベル内進捗とプレイヤーレベルを表示。表示パケットのみを送信し、vanilla経験値の実値は変更しない |
| armor bar | shield 比率を armor attribute 0..20 へ写像 |
| sidebar | online 数、任意の MSPT / ping、world、region、region level、player level、class 名 / level / EXP、設定が有効な場合の有効バフ、挑戦中 boss |
| tab list | タイトル。performance 表示が有効な場合は MSPT / ping |
| BossBar | 管理者メッセージを全 online player へ表示。指定秒数に応じて進捗を減少させ、終了時に削除 |

## 3. 更新境界

`PlayerHudService.start` が 10 tick 後から 10 tick 間隔で同期 task を実行する。gameplay mode では全表示面を更新し、非 gameplay mode では sidebar と ActionBar override を解除する。ただし vanilla bar と tab list は online session 全体へ更新する。

## 4. ActionBar 優先順位

1. wall cling window
2. dodge window
3. player UUID ごとの primary renderer
4. status ActionBar

## 5. 依存・連携

- `player` / `account`: online session、アカウントモード、レベル、経験値を参照する。
- `status`: HP / MP / EN / shield の現在値と最大値、および Shield リチャージ状態を参照する。
- `class`: 現在クラスの表示名、クラスレベル、レベル内経験値進捗を参照する。
- `player-setting`: performance 情報の表示可否を参照する。
- `player-setting`: `BUFF_SIDEBAR_DISPLAY` によりバフ欄の表示可否を参照する。
- `buff`: 獲得順の有効バフ、表示名、残り時間、buff / debuff 区分を参照する。
- `condition`: 有効な状態異常を通常 ActionBar へ合成する。
- `world`: ワールド表示名、地域名、地域レベルを解決する。
- `boss`: 挑戦中ボスの sidebar 情報を参照する。
- `player` の dodge / air action と、primary action bar を差し替える feature は ActionBar の優先順位を共有する。
- `command/AdminMessageCommand`, `service/AdminMessageBossBarService`, `event/AdminMessageBossBarEventHandler`
  - `/adminmessage` と短縮形 `/adminmsg` を管理者専用で提供し、指定メッセージを全プレイヤーへ BossBar 表示する。
