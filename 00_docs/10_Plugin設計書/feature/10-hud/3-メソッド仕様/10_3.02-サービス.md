# 10_3.02-サービス

## 1. HUD更新タスク開始

クラス名: `PlayerHudService`

### 論理名

HUD更新タスク開始

### 物理名

`start(AstralRecord plugin)`

### 概要

HUD更新タスクが未起動の場合のみ、10 tick 間隔で定期更新タスクを起動する。

## 2. HUD更新タスク停止

クラス名: `PlayerHudService`

### 論理名

HUD更新タスク停止

### 物理名

`stop()`

### 概要

起動中タスクを停止し、再起動可能な状態に戻す。

## 3. 全プレイヤーHUD更新

クラス名: `PlayerHudService`

### 論理名

全プレイヤーHUD更新

### 物理名

`updateAll()`

### 概要

オンラインプレイヤーを走査し、`status` から取得したスナップショットを使って `PlayerHudView` の描画メソッドを呼び出す。
`AstPlayer.classId` から `PlayerClassService.getDisplayName()` で職業表示名を取得し、サイドバーに渡す。`WorldService` から現在ワールドの表示名・種別を取得し、`AstPlayer.currentRegion` とともに現在地情報として渡す。地域レベルは通常地域では `AstPlayer.currentRegionLevel`、拠点では 0、ボスフィールドでは `BossChallengeService.findSidebarInfo()` が返すボスレベルを使用する。`PlayerSettingService` から `PERFORMANCE_INFO_DISPLAY` を取得し、MSPT・Ping の表示を個人ごとに切り替える。参加中ボス情報はボスセクションにも渡す。
壁張り付き終了時刻が未来の場合は壁張り付きバーを優先し、次にドッジ受付終了時刻が未来の場合は通常のリソース表示の代わりにドッジ受付バーを描画する。
ゲーム中 HUD として扱う ActionBar / Sidebar は `AccountMode.PLAYER` のときだけ更新し、`BUILDER` / `ADMIN` では描画しない。
権限レベルは Sidebar に表示しない。

### サイドバー表示項目（score 順）

| score | 表示内容 |
|:--:|:--|
| 14 | オンライン人数 |
| 13 | MSPT（`PERFORMANCE_INFO_DISPLAY=true` の場合） |
| 12 | Ping（`PERFORMANCE_INFO_DISPLAY=true` の場合） |
| 11 | 現在ワールド |
| 10 | 現在地域 |
| 9 | 地域レベル |
| 8 | `PLAYER` 区切り線 |
| 7 | プレイヤーレベル |
| 6 | プレイヤーEXP進捗バー |
| 5 | 職業名とクラスレベル（`AstPlayer.classId` / `AstPlayer.classLevel`） |
| 4 | `BOSS` 区切り線（挑戦中のみ） |
| 3 | ボス名（挑戦中のみ） |
| 2 | 共有死亡回数（挑戦中のみ） |
| 1 | 経過時間 / 制限時間（挑戦中のみ） |
| 0 | 挑戦参加者名（挑戦中のみ） |

## 4. ドッジ受付バー表示開始

クラス名: `PlayerHudService`

### 論理名

ドッジ受付バー表示開始

### 物理名

`showDodgeWindow(AstPlayer astPlayer)`

### 概要

対象プレイヤーの ActionBar を即時にドッジ受付バーへ切り替え、`1 tick` 間隔の短命タスクで残り時間バーを更新する。
対象は `AccountMode.PLAYER` のみとする。

## 5. 壁張り付きバー表示開始

クラス名: `PlayerHudService`

### 論理名

壁張り付きバー表示開始

### 物理名

`showWallClingWindow(AstPlayer astPlayer)`

### 概要

対象プレイヤーの ActionBar を即時に壁張り付きバーへ切り替え、`1 tick` 間隔の短命タスクで残り時間バーを更新する。
対象は `AccountMode.PLAYER` のみとする。

## 6. 通常ActionBar復帰

クラス名: `PlayerHudService`

### 論理名

通常ActionBar復帰

### 物理名

`restoreStatusActionBar(AstPlayer astPlayer)`

### 概要

ドッジ受付バー / 壁張り付きバー更新タスクを停止し、ActionBar を通常の HP/MP/ENG リソース表示へ即時に戻す。
対象が `AccountMode.PLAYER` 以外の場合は通常 ActionBar への復帰描画も行わない。
