# 10_3-サービス

## 1. 周期更新開始

クラス名: `PlayerHudService`
物理名: `start`

未起動の場合だけ、10 tick 後から 10 tick 間隔で `updateAll` を実行する同期 task を登録する。二重起動要求は無視する。

## 2. 周期更新停止

クラス名: `PlayerHudService`
物理名: `stop`

主 task と player ごとの一時 ActionBar task を cancel し、task map と plugin 参照を破棄する。primary renderer は呼び出し元が player lifecycle に合わせて解除する。

## 3. dodge window 表示

クラス名: `PlayerHudService`
物理名: `showDodgeWindow`

plugin 起動済みかつ gameplay mode の場合、既存の一時 task を置換し、1 tick ごとに dodge 受付時間の残り割合を描画する。

## 4. wall cling window 表示

クラス名: `PlayerHudService`
物理名: `showWallClingWindow`

plugin 起動済みかつ gameplay mode の場合、既存の一時 task を置換し、1 tick ごとに wall cling 残り割合を描画する。

## 5. status ActionBar 復帰

クラス名: `PlayerHudService`
物理名: `restoreStatusActionBar`

一時 task を cancel し、dodge / wall の期限を 0 にした後、現在の primary renderer または status 表示を即時描画する。

## 6. primary renderer 登録・解除

クラス名: `PlayerHudService`
物理名: `setPrimaryActionBarRenderer`, `clearPrimaryActionBarRenderer`

player UUID ごとの ActionBar 描画関数を登録・解除する。登録関数はメインスレッドの HUD 更新中に呼ばれるため、長時間処理や Bukkit 非同期操作を含めない。

## 7. ActionBar 即時更新

クラス名: `PlayerHudService`
物理名: `refreshActionBar`

wall、dodge、primary renderer、status の順に有効な描画を選び、周期更新を待たずに表示する。

## 8. 全 player 更新（内部）

クラス名: `PlayerHudService`
物理名: `updateAll`

online session を走査し、[[10_0-概要]].表示面 と ActionBar 優先順位に従って `PlayerHudView` を呼ぶ。アカウントのプレイヤーレベルとレベル内経験値進捗を解決し、vanilla HUD には経験値表示パケットとして渡す。現在クラスのレベル内経験値進捗と `CurrencyService` から所持 Gold を解決し、sidebar にはプレイヤーレベルを値のみ、クラス経験値をクラス行直下のブロック形式バー、所持金をその直下の `Gold: {値}G` として渡す。`SkillTreeService.isSkillTreeWorld` が true の場合は、同サービスの `currentClassPointLabel`、`availableClassPoints`、`availablePassivePoints` から現在クラスの CP / PP 残高を解決し、skilltree ワールド用の表示値として渡す。world / region / boss field から sidebar のエリアレベルを解決し、performance 設定を sidebar と tab list の両方へ適用する。

## 9. 管理者メッセージ BossBar 表示

クラス名: `AdminMessageBossBarService`
物理名: `show`

1. 既存の管理者メッセージ BossBar と更新 task があれば破棄する。
2. メッセージを legacy color code 変換し、指定秒数を20倍した総tick数で一時 BossBar を作成する。
3. 実行時点で online の全プレイヤーを表示対象へ追加し、進捗1.0から同期 task を開始する。
4. 同時に保持する管理者メッセージは1件だけとする。

## 10. 管理者メッセージ BossBar 更新

クラス名: `AdminMessageBossBarService`
物理名: `update`

1. 1 tickごとに残りtick数を1減らす。
2. 残りtick数を総tick数で割った値を0.0〜1.0へ制限して BossBar の進捗へ設定する。
3. 残りtick数が0以下になった場合は BossBar を非表示にし、表示対象と task を破棄する。

## 11. 管理者メッセージ BossBar の表示対象更新

クラス名: `AdminMessageBossBarService`
物理名: `addPlayer`, `removePlayer`

表示中の `PlayerJoinEvent` では参加プレイヤーを BossBar へ追加し、`PlayerQuitEvent` では退出プレイヤーを削除する。表示終了後の呼び出しは何もしない。

## 12. 管理者メッセージ BossBar 停止

クラス名: `AdminMessageBossBarService`
物理名: `stop`

プラグイン停止時に更新 task を cancel し、BossBar を全対象から外して非表示にする。
