# 10_3-イベント

## 1. 管理者メッセージ表示中の参加

イベント物理名: `PlayerJoinEvent`
クラス名: `AdminMessageBossBarEventHandler`
物理名: `onPlayerJoin`

表示中の `AdminMessageBossBarService` へ参加プレイヤーを追加する。表示が終了している場合は何もしない。

## 2. 管理者メッセージ表示中の退出

イベント物理名: `PlayerQuitEvent`
クラス名: `AdminMessageBossBarEventHandler`
物理名: `onPlayerQuit`

表示中の `AdminMessageBossBarService` から退出プレイヤーを削除する。表示が終了している場合は何もしない。

## 3. ライフサイクル

`AdminMessageBossBarService.stop` はプラグイン停止時に呼び出し、BossBar と同期更新 task を破棄する。
