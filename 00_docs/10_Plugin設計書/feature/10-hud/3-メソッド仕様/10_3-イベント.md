# 10_3-イベント

## 1. 管理者メッセージ表示中の参加

イベント物理名: `PlayerJoinEvent`
クラス名: `AdminMessageBossBarEventHandler`
物理名: `onPlayerJoin`

表示中の `AdminMessageBossBarService` へ参加プレイヤーを追加する。表示が終了している場合は何もしない。

## 2. 管理者メッセージ表示中の退出

イベント物理名: `PlayerQuitEvent`
クラス名: `AdminMessageBossBarEventHandler`
物理名: `onPlayerQuit`

表示中の `AdminMessageBossBarService` から退出プレイヤーを削除する。表示が終了している場合は何もしない。

## 3. ライフサイクル

`AdminMessageBossBarService.stop` はプラグイン停止時に呼び出し、BossBar と同期更新 task を破棄する。

## 4. サイドバー効果のページ入力と破棄

クラス名: `SidebarBuffPagingEventHandler`
イベント物理名: `PlayerSwapHandItemsEvent` / `PlayerQuitEvent` / `PlayerChangedWorldEvent` / `PlayerRuntimeDiscardEvent`

手の持ち替え入力はLOW優先度・cancel済みも受け付け、実際の持ち替えは禁止したまま、通常画面のF／スニーク＋Fを `PlayerHudService.changeSidebarBuffPage` へ委譲する。ロード等の入力停止・スキルリング表示中は同サービスが拒否する。退出・ワールド変更・runtime復旧では `clearSidebarBuffPage` を呼ぶ。同じイベントで `clearProgressHud` も呼び、本人用の2行を解除する。
