# 10_3.07-View

## 1. ActionBar描画

クラス名: `PlayerHudView`

### 論理名

ActionBar描画

### 物理名

`renderActionBar(Player player, StatusSnapshot snapshot)`

### 概要

HP/MP/ENG の現在値と最大値を ActionBar へ描画する。

## 2. ドッジ受付ActionBar描画

クラス名: `PlayerHudView`

### 論理名

ドッジ受付ActionBar描画

### 物理名

`renderDodgeWindowActionBar(Player player, double progressRemaining)`

### 概要

しゃがみ開始から `250ms` の間だけ、残り受付時間を表す長尺バー付きの `DODGE` 表示を ActionBar へ描画する。

## 3. 壁張り付きActionBar描画

クラス名: `PlayerHudView`

### 論理名

壁張り付きActionBar描画

### 物理名

`renderWallClingActionBar(Player player, double progressRemaining)`

### 概要

壁張り付き中だけ、自然落下へ戻るまでの残り時間を表す長尺バー付きの `WALL` 表示を ActionBar へ描画する。

## 4. バー描画

クラス名: `PlayerHudView`

### 論理名

バー描画

### 物理名

`renderBars(Player player, StatusSnapshot snapshot)`

### 概要

HP をヘルスバー、EN を満腹度、MP を経験値バーへ反映する。

## 5. Sidebar描画

クラス名: `PlayerHudView`

### 論理名

Sidebar描画

### 物理名

`renderSidebar(Player player, double mspt, int playerLevel, double experienceProgress, int classLevel, String className, String worldName, String regionName, int regionLevel, boolean showPerformanceInfo, BossChallengeSidebarInfo bossInfo)`

### 概要

Sidebar 上部にオンライン数などのサーバー情報と現在ワールド・地域・地域レベルを表示し、その下にプレイヤー情報とクラス情報を表示する。挑戦中はクラス情報の下にボス情報を表示する。全項目表示時も Minecraft の上限内となる 15 行に収める。
プレイヤー情報にはプレイヤーレベルとEXPバー、クラス情報にはクラス名の右にクラスレベルを表示する。EXPバーは40文字幅（従来の80%）とし、進捗部分と未進捗部分を通常の縦棒記号 `|` で表示する。クラスEXPバーは表示しない。
権限レベルとクラスEXPバーは表示しない。MSPT・Ping はプレイヤー設定で非表示にできる。

## 6. TabList描画

クラス名: `PlayerHudView`

### 論理名

TabList描画

### 物理名

`renderTabList(Player player, double mspt, boolean showPerformanceInfo)`

### 概要

TabList のヘッダー/フッターに MSPT と Ping を表示する。`showPerformanceInfo=false` の場合は診断値を表示しない。
