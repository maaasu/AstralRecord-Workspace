# 10_2-ユースケース

## 1. 通常 HUD を表示する

1. plugin 起動時に HUD task を開始する。
2. 10 tick ごとに online `AstPlayer` を走査する。
3. gameplay player には ActionBar、個人情報HUD、sidebar を同時に描画する。
4. 全 online session に vanilla bar と tab list を描画する。
5. 通常 ActionBar では HP / MP / ENG、バインド中のGuard、Shield、有効な状態異常要約、設定が有効な場合のDPSを同時表示する。Java 版は管理配布パックの適用後に HP / MP / ENG をアイコンとゲージで表示し、アイコンと現在値の間に半角空白を入れる。統合版は配布パックで ActionBar に装飾プレートを表示する。DPS表示の既定値は有効で、プレイヤー設定から省略できる。Shield リチャージ中は SH の値を置き換えず、同じ囲み内へ `RC` と残り秒数を追加する。
6. 有効なデバフは `BUFF_SIDEBAR_DISPLAY` の設定にかかわらずサイドバーへ優先表示する。通常バフは設定が有効な場合だけ表示し、同じ区分内では獲得順を保つ。1ページ最大5件とし、現在確保できる効果行数でページを区切る。表示対象の総件数と現在ページ／総ページ数を表示する。

7. 画面上部に本人用の2行を表示する。プレイヤー行にはレベルと所持Gold、クラス行にはクラス名・クラスレベル・EXP進捗を表示する。クラスレベルは最大到達時に `Lv.max` とし、スキルツリーワールドではクラス行に未使用CP / PPを追加する。戦闘ActionBarやサイドバーの効果ページとは独立して表示する。ボスフィールド、ダンジョン、防衛戦参加中、および通常攻撃劣化・スキルクールダウン・管理者通知のBossBar表示中は戦闘・通知用のBossBarを優先する。個人情報の2行は通常表示に戻った周期更新で再表示する。

サイドバーの基本項目はオンライン人数、ワールド、エリア、エリアレベルと、設定有効時の MSPT / PING とする。効果とボス・ダンジョンの挑戦情報を含めて15行以内とし、挑戦情報がある場合は必須行を確保して効果件数と挑戦の任意情報を残り行数に合わせる。効果に1行しか使えない場合は件数とページ案内を効果行へ併記する。

## 2. 一時 ActionBar を表示する

1. dodge または wall cling 成立時に対応する `show*Window` を呼ぶ。
2. 1 tick ごとにHP、残り時間を示す短いprogress bar、優先順位付きの状態異常要約を同時表示する。
3. 期間終了時に task を破棄し、現在の優先順位に従う ActionBar へ戻す。

## 3. 他 feature が primary ActionBar を表示する

1. feature が player UUID と描画関数を `setPrimaryActionBarRenderer` へ登録する。
2. dodge / wall がない間、周期更新と即時更新は登録関数の `Component` を表示する。
3. 終了時に `clearPrimaryActionBarRenderer` を呼び、`refreshActionBar` で通常表示へ戻す。

## 4. 管理者メッセージを BossBar で表示する

1. `UserPermission.ADMIN` のプレイヤーまたはコンソールが `/adminmessage <seconds> <message...>` を実行する。`/adminmsg` は同じ処理への短縮形である。
2. `seconds` は1〜86400秒の整数として検証し、メッセージ本文は残りの引数を空白で結合する。本文の `&` 形式 legacy color code は表示前に変換する。
3. 実行時点の全 online player を同一 BossBar の表示対象へ追加する。表示中に参加した player は参加イベントで追加し、退出時に削除する。
4. 表示開始時の進捗を1.0とし、1 tickごとに残り時間の割合へ更新する。指定秒数が経過した tick で BossBar と更新 task を削除する。
5. 表示中に別の管理者メッセージを実行した場合、既存 BossBar を削除して新しいメッセージを1件だけ表示する。

## 5. サイドバーの効果ページを切り替える

1. 通常プレイ中のF（手の持ち替え入力）で次ページ、スニーク中のFで前ページへ移動する。末尾の次は先頭、先頭の前は末尾へ循環する。実際の手の持ち替えは引き続き禁止する。
2. Java版・統合版とも、メインメニューの「表示効果：前へ／次へ」から自分のサイドバーを同じように操作できる。
3. ページ切替で即時再描画し、以後も10tick更新で残り時間を更新する。効果の減少や表示枠の縮小でページが範囲外になった場合は最終有効ページへ補正する。
4. 新しいデバフの付与（バフ種別IDと付与時刻で識別）を検出した場合は先頭ページへ戻す。同じ描画でページ移動が予約されていても新規デバフを優先する。
5. ロード中・管理編集の入力停止中・セッション遷移中・スキルリング表示中・死亡中は切替しない。F操作は通常画面でのみ受け付け、GUI内のFは流用しない。
6. ページ状態は保存せず、退出、復旧、ワールド移動、アカウント切替、非gameplay mode、plugin停止で破棄する。効果量・重複ルールは変更しない。
