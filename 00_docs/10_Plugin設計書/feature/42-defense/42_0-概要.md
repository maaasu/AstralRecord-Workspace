# 42_0-概要

## 目的と境界

防衛戦は、チャンネルごとの既存ワールドで固定参加者が中央の防衛対象を守り、到達した防衛レベルに応じてオーブを得る耐久戦である。開始予定・即時開始・設定・開催台帳・報酬確定はWeb/APIが担当し、Pluginは受付、入場、戦闘、死亡、帰還、API報告を担当する。開催単位はチャンネルごとに独立し、同一チャンネルで同時に戦闘を重ねない。

防衛対象の破壊が通常の終了条件であり、時間切れの勝利条件はない。防衛戦専用Mobマスタは作らず、既存のENEMYで `defenseEligible: true` のものから選ぶ。防衛戦個体だけ通常Mob報酬を抑止し、フィールド個体の挙動と報酬には影響させない。

Pluginのゲーム状態はメインスレッドで処理し、API通信は非同期で行う。API受理とゲーム内開始を区別し、開始・進行・中断・終了を開催IDと起動世代で報告する。PluginからDBへ直接書き込まない。

## 主要な不変条件

- 防衛レベルは全チャンネル共通でLv.1から始まり、戦闘開始から30秒ごとに+1する。受付・準備時間を含まない。
- 最大30人を開始時に固定する。途中参加・枠の譲渡は認めず、切断後の同一本人・同一アカウントの復帰だけを設定された猶予内で認める。
- 1～10人では出現量・敵HP/シールド・与ダメージの人数倍率を1とし、11～30人は設定係数で増やす。開始後の切断・脱落で倍率を下げない。
- 防衛対象HP/防御、座標、召喚数と上限、各係数、復帰・報酬条件、オーブID/数量など運営調整値はWeb設定必須とし、不足や不正があれば開催を始めない。値は [[42_9-未決事項]] に列挙し、設計書では任意の数値を決めない。
- 到達段階の報酬は既存メールへ永続・冪等に配送する。報告失敗時はPluginの保存済みoutboxから再送する。
