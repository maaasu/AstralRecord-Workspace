# 42_0-概要

## 設計の状態

防衛戦は未実装であり、本 feature は設計を固めるための入口である。現行の Plugin・API・Web・DB・Filebase に防衛戦の契約を追加した状態ではない。

- 採用した機能方針と将来の受入条件は [[42_8-防衛戦の実装予定]] に置く。
- 仮置き数値、比較案、実装前に必要な判断は [[42_9-未決事項]] に置く。仮置き値を確定したバランスや実測結果として扱わない。
- 実装着手は本設計書作成の対象外とし、未決事項の判断と別途の実装依頼を経て行う。カテゴリ8の記載を現行動作や恒久テストの採用済み入力として扱わない。

## 目的と責務の境界

防衛戦の対象範囲は、チャンネルごとの独立した開催、中央の防衛対象、既存Mobの選出と進軍、参加者の生存管理、到達段階に応じたオーブ報酬である。Webで設定する開始予定とゲーム内の開催を、一つの開催として対応付ける。

敵として使うMobの別マスタ作成、既存フィールドのAI・報酬変更、既存Dungeon・Bossの参加規則変更は対象に含めない。防衛対象は敵Mobとは別の役割として扱い、外見・戦闘モデルの詳細は未決である。

## 横断設計の扱い

本 feature のカテゴリ8を、設計検討中の防衛戦全体の方針の入口とする。既存API・Web・DB・Filebaseの現行契約は書き換えず、将来同期が必要な領域を [[42_8-防衛戦の実装予定]] にまとめる。APIパス、テーブル名、マスタの物理配置、実装packageの割当はこの段階では確定しない。

設計featureの登録は [[FEATURE_CATALOG]] を正本とする。実装所有パスは未割当である。
