# 06_1.00-モデル定義

## 1. ドメインモデル

`loot` 機能はルートテーブル、参照解決済みプール、プール内候補、抽選結果で構成される。

## 2. ルートテーブル

物理名: `LootModel`

`/api/loot/table` および `/api/loot/table/{tableId}` から取得するドロップ定義。

### 2.1 項目

| 項目 | 型 | 説明 |
|---|---|---|
| `schemaVersion` | `int` | スキーマバージョン |
| `id` | `String` | ルートテーブル ID |
| `name` | `String` | 表示名。API 取得時は ID と同値 |
| `minRolls` | `int` | テーブル全体の最小抽選回数。降順範囲は正規化済み |
| `maxRolls` | `int` | テーブル全体の最大抽選回数。実行ごとに `minRolls` との閉区間で抽選 |
| `pools` | `List<LootPoolModel>` | 参照解決済みプール一覧 |

## 3. ルートプール

物理名: `LootPoolModel`

### 3.1 項目

| 項目 | 型 | 説明 |
|---|---|---|
| `id` | `String` | プール ID |
| `minPick` | `int` | 1 roll 内の最小採用上限。降順範囲は正規化済み |
| `maxPick` | `int` | 1 roll 内の最大採用上限。実行ごとに `minPick` との閉区間で抽選 |
| `contents` | `List<LootContent>` | 抽選候補一覧 |

API の `pick` が未指定または null の場合は `contents.size` を min/max の両方へ設定する。空 pool は `0` となり結果を生成しない。

## 4. ルート候補

物理名: `LootContent`

| 項目 | 型 | 説明 |
|---|---|---|
| `itemId` | `String` | item prefix 除去済み ID |
| `minAmount` | `int` | 最小数量 |
| `maxAmount` | `int` | 最大数量 |
| `rate` | `double` | content ごとの独立ドロップ率（0〜100%） |

## 5. Lore 表示用ルートエントリ

物理名: `LootEntry`

`LootModel.flattenedEntries` が pool を平坦化して生成する表示用モデル。`itemId`、`minAmount`、`maxAmount`、`weight` を持ち、bundle の Lore 候補表示に使用する。`weight` は互換上の物理名であり、値の意味は content の設定ドロップ率である。

## 6. ルート抽選結果

物理名: `LootRollResult`

| 項目 | 型 | 説明 |
|---|---|---|
| `itemId` | `String` | 選択されたアイテム ID |
| `amount` | `int` | 範囲内で確定した数量 |
| `configuredRate` | `double` | 選択元候補の独立ドロップ率（%） |

### 6.1 補足

- 同一 item が複数回選択された場合、`LootRollResult` は選択ごとに保持する。bundle 付与時だけ item ID ごとに数量を集約する。
- `configuredRate` は content 1 回の独立判定に使用した設定率であり、複数 roll を通した「1 回以上取得する確率」へ換算しない。

## 7. 入出力モデル

- API 入力: なし（GET のみ）
- API 出力:
  - `GET /api/loot/table` -> [[06_1.00-モデル定義]].ルートテーブル のリスト
  - `GET /api/loot/table/{tableId}` -> [[06_1.00-モデル定義]].ルートテーブル

## 8. 関連 feature とのモデル関係

- `item`:
  - `ItemBundle.lootTableId` がルートテーブル `id` を参照する。
  - bundle 開封は抽選結果を item ID ごとに集約して付与する。
- `mob` / `gathering`:
  - `MobDropConfig.lootTable` がルートテーブル `id` を参照し、抽選結果を直接ドロップへ結合する。
