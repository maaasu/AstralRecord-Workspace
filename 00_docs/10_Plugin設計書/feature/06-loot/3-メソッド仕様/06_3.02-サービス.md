# 06_3.02-サービス

## 1. LootService

### 全ルートテーブルロード

クラス名: `LootService`
物理名: `loadAll`

処理内容:

1. [[06_3.02-サービス]].ルートスナップショット構築 を実行する
2. [[06_3.02-サービス]].ルートスナップショット置換 を実行する
3. snapshot 件数を返す

例外時挙動:

- 例外は `LogId.E_5301` へ `loadAll` を付けて記録する
- 公開中 snapshot は変更せず `0` を返す

### ルートスナップショット構築

クラス名: `LootService`
物理名: `loadSnapshot`

処理内容:

1. `LootRepository.findAll` で table / pool 結合済み `LootModel` 一覧を取得する
2. 各 ID を trim、最初の `:` より前の接頭辞除去、小文字化する
3. 正規化 ID key の `LinkedHashMap` を構築し、各詳細を `LogId.D_5301` で記録する
4. copy 済みの変更不能 map を返す

出力:

- 正規化 ID key の `Map<String, LootModel>`

例外時挙動:

- repository 例外は捕捉せず呼び出し元へ伝播する

### ルートスナップショット置換

クラス名: `LootService`
物理名: `replaceSnapshot`

入力:

- 準備済み `Map<String, LootModel>`

処理内容:

1. `cacheLock` 内で入力を再 copy・変更不能化する
2. `volatile loadedLoots` を新 snapshot へ一回で置換する
3. `LogId.I_5300` へ件数を記録する

出力:

- なし

### ロード済みルート取得

クラス名: `LootService`
物理名: `getLoaded`

入力:

- loot table ID または `loot_table:<id>` 等の参照値

処理内容:

1. 入力を正規化する
2. 現在の不変 snapshot から一致する `LootModel`、未登録なら `null` を返す

### ロード済み優先ルート取得

クラス名: `LootService`
物理名: `getLoadedOrFetch`

処理内容:

1. [[06_3.02-サービス]].ロード済みルート取得 の hit を即時返却する
2. miss 時は `LootRepository.findById` で単体取得する
3. 取得成功時は `cacheLock` 内で現在 snapshot を copy し、正規化 ID key を追加した新 snapshot へ置換する
4. 取得結果を返す

例外時挙動:

- API・変換例外は `LogId.E_5301` を loot ID 付きで記録し、`null` を返す

### ロード済みルート一覧取得

クラス名: `LootService`
物理名: `getLoadedLoots`

処理内容:

1. 現在 snapshot の value を順序維持した変更不能 list として返す

### キャッシュクリア

クラス名: `LootService`
物理名: `clearCache`

処理内容:

1. `cacheLock` 内で `loadedLoots` を空の不変 map へ置換する

## 2. LootRollService

### ルートテーブル抽選

クラス名: `LootRollService`
物理名: `roll`

入力:

- 参照解決済み `LootModel`

処理内容:

1. `minRolls` / `maxRolls` を非負へ正規化し、閉区間から roll 回数を決める
2. 各 roll で全 pool を順に評価する
3. pool ごとに `minPick` / `maxPick` の閉区間から最大採用件数を決める
4. 各 content の rate を `0..100` に clamp し、互いに独立判定する
5. 成功候補が pick 上限を超えた場合だけ部分 shuffle で無作為に絞る
6. amount の min / max を並べ替えた閉区間から数量を決め、正の結果だけを追加する
7. item ID、確定数量、clamp 済み設定 rate の `LootRollResult` を選択順で返す

出力:

- 変更不能 `List<LootRollResult>`

終了条件:

- rolls / pick が 0、空 pool、全 rate 判定失敗、amount 最大値が 0 以下の場合は該当結果を生成しない

補足:

- 本サービスはステートレスで、bundle・Mob・採集から共通利用する。
