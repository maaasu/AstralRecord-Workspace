# 30_5-例外・ログ・運用

## 1. プレイヤー向けメッセージ

| ID | 内容 | 条件 |
|:--|:--|:--|
| `P_5550` | ダウンロード失敗。通信確認と再接続を案内 | `FAILED_DOWNLOAD` |
| `P_5551` | URL 不正。管理者への連絡を案内 | `INVALID_URL` |
| `P_5552` | クライアント再読み込み失敗。再接続を案内 | `FAILED_RELOAD` |
| `P_5553` | 拒否により一部表示が欠ける可能性を警告 | `DECLINED` |

## 2. ログ

| ID | レベル | 条件 |
|:--|:--|:--|
| `W_5550` | WARN | 設定 SHA-1 が 40 桁の 16 進文字列でない |
| `I_5550` | INFO | Java 用要求の送信完了 |
| `I_5551` | INFO | Bedrock 判定による送信除外 |
| `I_5552` | INFO | `ACCEPTED` |
| `I_5553` | INFO | `DOWNLOADED` |
| `I_5554` | INFO | `SUCCESSFULLY_LOADED` |
| `W_5551` | WARN | `DISCARDED` |
| `W_5552` | WARN | `DECLINED` |
| `D_5550` | DEBUG | 個別分岐のない status |
| `E_5550` | ERROR | event handler 内の例外 |

物理テンプレートの正本は `logger.properties`、プレイヤー文言の正本は `player.properties` とし、ID enum と同時に更新する。

## 3. 設定・配布運用

- 本番 URL は HTTPS で、Minecraft クライアントから直接取得できる場所を指定する。
- `sha1` は配布 ZIP の内容を変更するたびに更新する。空値も許容されるが、キャッシュ整合性のため本番では正しい値を設定する。
- `force=true` の拒否・切断挙動はサーバーとクライアントの契約に従う。本機能は拒否後の kick を独自実装しない。
- `bedrockNamePrefixes` は Geyser/Floodgate 側の設定と一致させる。prefix に空文字列を設定しても判定から除外される。
- `enabled=false` または URL が空の場合、2 つの event handler は登録対象外となる。

## 4. 障害切り分け

1. `W_5550` がある場合は ZIP の SHA-1 を再計算する。
2. `P_5551` が出る場合は URL の構文と配布先応答を確認する。
3. `P_5550` が出る場合はクライアントから配布 URL へ到達できるか確認する。
4. `I_5550` がなく `I_5551` がある場合は Bedrock prefix 設定を確認する。
