# 30_3.00-メソッド仕様

## 1. 参加時要求

イベント物理名: `PlayerJoinEvent`

クラス名: `ResourcePackJoinEventHandler`

物理名: `onPlayerJoin`

1. ハンドラはサービスが有効な場合だけ登録される。
2. NORMAL priority で参加プレイヤーをリソースパック適用へ委譲する。
3. 例外時は `runSafely` で `LogId.E_5550` をプレイヤー名付きで記録する。

## 2. status 受信

イベント物理名: `PlayerResourcePackStatusEvent`

クラス名: `ResourcePackStatusEventHandler`

物理名: `onStatus`

1. event の pack ID が管理対象でなければ終了する。
2. 管理対象 status を状態処理へ委譲する。
3. 例外時は `runSafely` で `LogId.E_5550` をプレイヤー名付きで記録する。

## 3. 機能有効判定

クラス名: `ResourcePackService`

物理名: `isEnabled`

`resourcePack.enabled=true` かつ trim 済み URL が空でない場合に `true` を返す。

## 4. リソースパック適用

クラス名: `ResourcePackService`

物理名: `applyTo`

1. 無効設定なら何もせず終了する。
2. Bedrock 除外対象なら `I_5551` を記録して終了する。
3. URL 由来 UUID、URL、任意 SHA-1、任意 prompt、force で `Player#setResourcePack` を呼ぶ。
4. SHA-1 の形式が不正なら `W_5550` を記録し、SHA-1 なしで送信する。
5. 送信後に `I_5550` を記録する。

## 5. 管理対象判定

クラス名: `ResourcePackService`

物理名: `isManagedPack`

event の pack ID と現在の URL から導出した UUID が等しい場合に `true` を返す。

## 6. status 処理

クラス名: `ResourcePackService`

物理名: `handleStatus`

`PlayerResourcePackStatusEvent.Status` を [[30_1.00-モデル定義]].クライアント状態 の表どおりにログまたはプレイヤーメッセージへ変換する。

## 7. Bedrock prefix 判定

クラス名: `BedrockPlayerDetector`

物理名: `isBedrock`

prefix リストが `null` または空なら `false` を返す。それ以外は有効な prefix とプレイヤー名の先頭一致を判定する。
