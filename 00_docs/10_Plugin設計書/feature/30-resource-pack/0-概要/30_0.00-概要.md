# 30_0.00-概要

## 1. 目的

設定された URL の Java Edition 用リソースパックをプレイヤー参加時に要求し、クライアントが返す適用状況をログとプレイヤーメッセージへ反映する。

## 2. 責務

- `resourcePack.enabled=true` かつ URL が空でない場合だけイベントハンドラを有効化する。
- URL から決定的な pack UUID を生成し、この機能が送信した status だけを処理する。
- 設定に従って Bedrock Edition とみなすプレイヤーを Java 用要求から除外する。
- SHA-1、表示プロンプト、強制適用フラグを Paper の `Player#setResourcePack` へ渡す。
- クライアント結果をログへ記録し、利用者が対処できる失敗はメッセージで通知する。

## 3. 責務外

- リソースパック ZIP の生成、配布、バージョン管理は行わない。
- URL の疎通確認、ファイル取得、SHA-1 の自動計算は行わない。
- Bedrock Edition 向けパックの変換・配布は行わない。
- status を永続化して再接続時の適用状態を復元しない。

## 4. 実装境界

`ResourcePackJoinEventHandler` と `ResourcePackStatusEventHandler` が Bukkit event を受け、判断と通知を `ResourcePackService` へ委譲する。設定値は起動時に読み込まれた `ConfigProperties` を参照する。
