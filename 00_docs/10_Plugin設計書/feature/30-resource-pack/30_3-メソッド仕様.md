# 30_3-メソッド仕様

## 1. 参加時要求

イベント物理名: `PlayerJoinEvent`

クラス名: `ResourcePackJoinEventHandler`

物理名: `onPlayerJoin`

1. ハンドラはサービスが有効な場合だけ登録される。
2. NORMAL priority で参加プレイヤーをリソースパック適用へ委譲する。
3. 例外時は `runSafely` で `LogId.E_5550` をプレイヤー名付きで記録する。

## 2. status 受信

イベント物理名: `PlayerResourcePackStatusEvent`

クラス名: `ResourcePackStatusEventHandler`

物理名: `onStatus`

1. event の pack ID が管理対象でなければ終了する。
2. 管理対象 status を状態処理へ委譲する。
3. 例外時は `runSafely` で `LogId.E_5550` をプレイヤー名付きで記録する。

## 3. 機能有効判定

クラス名: `ResourcePackService`

物理名: `isEnabled`

`resourcePack.managed.enabled=true`、または固定URL方式が有効かつ trim 済みURLが空でない場合に `true` を返す。

## 4. リソースパック適用

クラス名: `ResourcePackService`

物理名: `applyTo`

1. 管理配布が有効なJava接続は、`ResourcePackRepository` で `GET /api/resource-packs/manifest` を非同期に取得する。同時に待機する接続は一度の要求にまとめる。
2. 配布情報の `java.sha1` が小文字16進40桁なら、公開Webの `/resource-packs/java/{sha1}.zip` を要求する。送信前に現在の接続であることを確認する。
3. 管理配布の対象外、未配布、取得失敗、公開URL不正時は固定URL方式を確認する。有効で除外対象でない場合は、設定URL・任意SHA-1・prompt・forceで要求する。固定SHA-1の形式不正時は `W_5550` を記録し、SHA-1を省略する。
4. 送信後に `I_5550` を記録する。

## 5. 管理対象判定

クラス名: `ResourcePackService`

物理名: `isManagedPack`

event のpack IDが、有効な管理配布の固定UUIDまたは固定URLから導出したUUIDに一致する場合に `true` を返す。

## 6. status 処理

クラス名: `ResourcePackService`

物理名: `handleStatus`

`PlayerResourcePackStatusEvent.Status` を [[30_1-モデル定義]].クライアント状態 の表どおりにログまたはプレイヤーメッセージへ変換する。

管理配布の `SUCCESSFULLY_LOADED` は閲覧者ごとの専用フォントを有効にする。失敗、拒否、破棄、退出で適用状態を解除する。

## 7. Bedrock prefix 判定

クラス名: `BedrockPlayerDetector`

物理名: `isBedrock(String, List<String>)`

prefix リストが `null` または空なら `false` を返し、それ以外は有効なprefixとプレイヤー名の先頭一致を判定する。パック配布とダメージ数値の送信先切り替えがこの判定を共有する。`AstPlayer.isBedrock` の user.mcid 判定とは用途を分ける。
