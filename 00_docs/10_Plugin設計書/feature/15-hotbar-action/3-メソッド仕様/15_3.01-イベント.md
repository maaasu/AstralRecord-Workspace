# 15_3.01-イベント

このファイルは移行後の責務境界を示す。新しい入力調停仕様は player-interaction、武器業務処理は item、skill 実行は skill feature を正本とする。

## 入力候補解決

クラス名: `ItemWeaponAttackEventHandler`
物理名: `resolve`

- 引数: `PlayerInputContext<PlayerInteractionSnapshot> context`
- 戻り値: `Collection<PlayerInputCandidate>`
- 例外: 独自に捕捉せず、入力 gateway の例外処理へ伝播する。

1. `InputFamily.LEFT_CLICK` かつメインハンド入力でなければ空一覧を返す。
2. skilltree 編集中、アクションリング表示中、または攻撃抑止中なら空一覧を返す。
3. `AstPlayer` 未ロード、`AccountMode.PLAYER` 以外、または左クリック武器アクションなしなら空一覧を返す。
4. `ConditionService.canAttack` が `false` の場合は `weapon-attack-condition-guard` を返す。
5. 実行可能な場合は `weapon-left-click-action` を返し、executor から左クリック武器アクション実行を呼び出す。
6. executor 実行直前にも mode、skilltree、action ring、武器アクション、攻撃可否を再検証する。

## 左クリック武器アクション有無判定

クラス名: `ItemWeaponAttackService`
物理名: `hasLeftClickAction`

- 引数: `AstPlayer player`
- 戻り値: 左クリック skill ID を持つ武器なら `true`
- 例外: なし

1. `InventoryService.getItemModelInHand(player, EquipmentSlot.HAND)` でメインハンド item を解決する。
2. `equipment`、`equipment.onUse`、`equipment.slot == WEAPON` を検証する。
3. `leftClickSkillId` が `null` または空白なら `false`、それ以外は `true` を返す。

## 左クリック武器アクション実行

クラス名: `ItemWeaponAttackService`
物理名: `handleLeftClick`

- 引数: `AstPlayer player`, `Location castLocation`
- 戻り値: なし
- 例外: 独自に捕捉しない。

1. メインハンド item、武器 slot、装備要件、耐久値、`onUse.leftClickSkillId` を再検証し、不成立なら何もせず終了する。
2. `leftClickCooldownTicks > 0` かつ skill がクールダウン中なら終了する。
3. `SkillService.castSkill` を `SkillCastTrigger.AUTO_ATTACK`、指定発動位置、対象なしで呼び出す。
4. 発動成功時だけ、正の `leftClickCooldownTicks` を `SkillService.startCooldown` へ渡す。

入力相関、候補比較、claim の詳細は [[28_3.01-イベント]]、[[28_3.02-サービス]]、[[28_4.00-統合フロー]]を参照する。
