# 11_1-モデル定義

## 1. プレイヤー設定モデル

物理名: `PlayerSettingModel`

`userSettingId`、`userId`、`settingKey`、JSON 文字列 `settingValueJson`、optimistic lock 用 `version`、作成・更新日時、作成者・更新者、論理削除 flag を保持する API model。

## 2. snapshot と entry

物理名: `PlayerSettingSnapshot`、`PlayerSettingEntry`

snapshot は user UUID と `Map<PlayerSettingKey, PlayerSettingEntry>` の不変な時点値を保持する。entry は API ID、型変換済み value、version を保持する。API に行がない key は ID / version を持たない既定値 entry とする。

## 3. 設定 key

物理名: `PlayerSettingKey`

| key | 型 | 既定値 | GUI slot |
|---|---|---|---:|
| `DAMAGE_LOG_DISPLAY` | boolean | `true` | 20 |
| `DAMAGE_LOG_MESSAGE` | boolean | `false` | 21 |
| `PARTICLE_DENSITY` | `ParticleDensity` | `NORMAL` | 22 |
| `PERFORMANCE_INFO_DISPLAY` | boolean | `false` | 23 |
| `DROP_LOG_DISPLAY` | boolean | `true` | 24 |
| `AUTO_SAVE_MESSAGE` | boolean | `false` | 25 |
| `TEMP_DROP_DISPLAY` | boolean | `true` | GUI なし |
| `TEMP_BLOCK_DISPLAY` | boolean | `true` | GUI なし |
| `ADVENTURE_RECORD_SUPER_MODE` | boolean | `false` | 管理者用 secret slot 53 |

boolean の入力は `on` / `true`、`off` / `false` を受理する。key 入力は `-` を `_` へ正規化して大文字比較する。

## 4. particle 密度

物理名: `ParticleDensity`

| 値 | 表示名 | scale |
|---|---|---:|
| `OFF` | 非表示 | 0.0 |
| `VERY_LOW` | とても少ない | 0.25 |
| `LOW` | 少ない | 0.5 |
| `NORMAL` | 標準 | 1.0 |
| `HIGH` | 多い | 1.5 |
| `VERY_HIGH` | とても多い | 2.0 |

## 5. 変更要求と更新結果

物理名: `PlayerSettingChangeRequest`、`PlayerSettingService.UpdateResult`

変更要求は `userId`、key、型変換済み value、更新者 UUID を保持する。更新結果は成功、optimistic lock conflict、stale session を区別し、conflict 時は最新 model と通知メッセージを保持する。

## 6. 既定値と cache

物理名: `PlayerSettingDefaults`、`PlayerSettingCache`

既定値は `PlayerSettingKey.getDefaultValue()` を正本とする。cache は user UUID ごとの `PlayerSettingSnapshot` を保持し、mutable model を外部へ公開しない。
