# 11_0.00-概要

## 1. 目的

`player-setting` 機能は、ユーザー単位のプレイヤー設定（ダメージログ表示・パーティクル密度・ドロップログ表示など）を、
AstralRecord API (`/api/player-setting`) 経由で永続化しつつ、オンライン中はメモリ上にキャッシュして他 feature から低コストで参照可能にする。

## 2. コンテキスト

- 設定は `account` ではなく `user` に紐づく（複数アカウントで共通の操作体験を維持するため）。
- 永続化は AstralRecord API。プラグインから DB へ直接アクセスしない。
- API には key/JSON value 形式（[[03_1.00-モデル定義]].登録リクエスト ほか）で 1 レコード = 1 設定キーとして保存する。
- オンライン中はログイン時に一括取得して [[11_1.00-モデル定義]].プレイヤー設定キャッシュ に格納する。
- プレイヤーは [[11_3.03-コマンド]]、または [[11_3.07-GUI・View]].プレイヤー設定 GUI から変更できる。
- ダメージログ・ドロップログ・パーティクル密度などの「表示」は本 feature では出力しない。本 feature はあくまで設定値の取得・更新・参照点を提供し、各表示 feature が参照側として呼び出す。

## 3. 構成要素（実装単位）

- `service/PlayerSettingService`
  - ログイン時の API 一括取得、キャッシュ構築、設定変更時の API 更新を担う。
- `service/PlayerSettingDefaults`
  - 未登録キーに対する初期値解決を担う。
- `repository/PlayerSettingRepository`
  - AstralRecord API (`/api/player-setting`) との HTTP 通信を担う。
- `cache/PlayerSettingCache`
  - オンライン中の [[11_1.00-モデル定義]].プレイヤー設定スナップショット を UUID キーで保持する。
- `command/PlayerSettingCommand`
  - `/setting` コマンドによる確認・変更操作を提供する。
- `gui/PlayerSettingGui`
  - チェスト型 GUI による設定変更操作を提供する。
- `model/PlayerSettingKey`, `model/ParticleDensity`, `model/PlayerSettingSnapshot`
  - 設定キー・列挙値・スナップショットのデータ定義。
