# 11_9.00-未決事項

## 1. 既定値へ戻す操作

現行 GUI / command は明示値への更新だけを提供し、API row の削除または「既定値を継承する」状態へ戻す操作を持たない。導入時は API の delete / reset 契約と optimistic lock の扱いを決める。

## 2. GUI 非表示 key の扱い

`TEMP_DROP_DISPLAY`、`TEMP_BLOCK_DISPLAY` は command のみ、`ADVENTURE_RECORD_SUPER_MODE` は管理者 secret 操作のみで変更できる。通常 GUI へ公開するかは各表示機能の運用方針と合わせて決める。
