# 11_3-リポジトリ

## 1. user 設定一覧取得

クラス名: `PlayerSettingRepository`
物理名: `findByUserId`

`GET /api/player-setting?user_id={userId}` を送信し、`200` の JSON 配列を `PlayerSettingModel` 一覧へ変換する。その他 status は `E_5310` を記録して `IOException` とする。

## 2. 設定作成

クラス名: `PlayerSettingRepository`
物理名: `create`

`POST /api/player-setting` へ `userId`、`settingKey`、`settingValueJson`、`createdBy` を送る。`200` / `201` の model を返し、その他 status は `E_5311` を記録して `IOException` とする。

## 3. 設定更新

クラス名: `PlayerSettingRepository`
物理名: `update`

`PUT /api/player-setting/{userSettingId}` へ JSON value、`expectedVersion`、`updatedBy` を送る。`200` は更新 model、`404` は `null`、`409` は response の最新 model を持つ `OptimisticLockConflictException`、その他 status は `E_5312` を記録した `IOException` とする。

`findById` は実装されていない。service は user 一覧から key entry を構築する。
