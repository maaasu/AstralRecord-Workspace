# 11_3-リポジトリ

## 1. user 設定一覧取得

クラス名: `PlayerSettingRepository`
物理名: `findByUserId`

`GET /api/player-setting?user_id={userId}` を送信し、`200` の JSON 配列を `PlayerSettingModel` 一覧へ変換する。その他 status は `E_5310` を記録して `IOException` とする。

設定の作成・更新は本 repository から送信しない。`PlayerSettingService` が `playerSettings` 完成 section を作り、共通の `PlayerStateRepository` が `POST /api/player-state/snapshots` で保存する。
