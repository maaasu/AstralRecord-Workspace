# 11_3.06-キャッシュ

## 1. snapshot 登録・取得

クラス名: `PlayerSettingCache`
物理名: `put`, `find`

user UUID を key に `PlayerSettingSnapshot` を登録し、存在しない場合は `null` を返す。snapshot / entry 自体を不変値として扱う。

## 2. snapshot 破棄

クラス名: `PlayerSettingCache`
物理名: `remove`, `clear`

`remove` は quit user、`clear` は plugin 停止時の全 user を対象とする。
