# 11_3-コマンド

## 1. setting コマンド

クラス名: `PlayerSettingCommand`
物理名: `executePlayerCommand`

`/setting [gui|<key> <value>]` を処理する。

- 引数なし: 従来の権限制限に加え、旧 `PERFORMANCE_INFO_DISPLAY` を一覧から外し、分離したMSPT・Pingを表示する。統合版で非対応の画面UI項目は現在値の代わりに赤字「非対応」と表示する。
- `gui`: `PlayerSettingGui.open` を呼ぶ。
- `<key> <value>`: key と値を検証し、session token 付きで `updatePlayerSetting` からキャッシュへ直ちに反映し、集約保存を予約する。統合版で非対応の画面UI項目は変更を拒否する。互換用の `/setting performance_info_display <on|off>` はMSPTとPingをまとめて更新する。
- super mode のコマンド更新は管理者だけ許可する。
- `NIGHT_VISION` の更新成功時は、設定値に応じて無期限・粒子なしの暗視効果を付与または除去する。
- 画面UI設定の更新成功時は現在のHUD表示を同期する。stale session では反映も通知も行わない。

一覧表示と設定更新は補助 command へ分離せず、公開入口 `executePlayerCommand` 内で引数に応じて分岐する。

## 2. tab 補完

クラス名: `PlayerSettingTabCompleter`
物理名: `getPlayerCompletions`

第1引数は現在のクライアントに対応する key の小文字 code と `gui`（旧MSPT・Ping一括キーは補完しない）、第2引数は選択可能な key の有効値を返す。boolean は `on` / `off`、particle は全 density の小文字 code とする。
