# 11_3.05-リポジトリ

## 1. repository メソッド仕様

`PlayerSettingRepository` は AstralRecord API (`/api/player-setting`) との HTTP 通信を担う。  
DB への直接アクセスは行わない。

### 設定一覧取得

クラス名: `PlayerSettingRepository`  
物理名: `findByUserId`

処理内容:

1. `GET /api/player-setting?user_id={userId}` を呼び出す（API: [[03_3.01-取得系]].設定一覧取得）
2. レスポンスを `PlayerSettingResponse[]` として受信し、[[11_1.00-モデル定義]].プレイヤー設定モデル 一覧に変換する
3. 通信失敗・パース失敗時は例外を伝播する

### 設定1件取得

クラス名: `PlayerSettingRepository`  
物理名: `findById`

処理内容:

1. `GET /api/player-setting/{userSettingId}` を呼び出す（API: [[03_3.01-取得系]].設定1件取得）
2. `404 Not Found` の場合は `null` を返す
3. 成功時は [[11_1.00-モデル定義]].プレイヤー設定モデル に変換して返す

### 設定登録

クラス名: `PlayerSettingRepository`  
物理名: `create`

処理内容:

1. [[03_1.00-モデル定義]].登録リクエスト を組み立てる（`userId`, `settingKey`, `settingValueJson`, `createdBy`）
2. `POST /api/player-setting` を呼び出す（API: [[03_3.02-登録系]].設定登録）
3. レスポンス（`PlayerSettingResponse`）を [[11_1.00-モデル定義]].プレイヤー設定モデル に変換して返す

### 設定更新

クラス名: `PlayerSettingRepository`  
物理名: `update`

処理内容:

1. [[03_1.00-モデル定義]].更新リクエスト を組み立てる（`settingValueJson`, `expectedVersion`, `updatedBy`）
2. `PUT /api/player-setting/{userSettingId}` を呼び出す（API: [[03_3.03-更新系]].設定更新（楽観ロック））
3. `409 Conflict` の場合は `OptimisticLockConflictException`（共通基盤の楽観ロック例外）を投げる
4. `404 Not Found` の場合は `null` を返す
5. 成功時は [[11_1.00-モデル定義]].プレイヤー設定モデル に変換して返す
