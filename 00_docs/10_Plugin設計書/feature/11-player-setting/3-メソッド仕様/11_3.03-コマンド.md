# 11_3.03-コマンド

## 1. setting コマンド

クラス名: `PlayerSettingCommand`
物理名: `executePlayerCommand`

`/setting [gui|<key> <value>]` を処理する。

- 引数なし: `ADVENTURE_RECORD_SUPER_MODE` を除く全 key の現在値を `P_5322` で表示する。
- `gui`: `PlayerSettingGui.open` を呼ぶ。
- `<key> <value>`: key と値を検証し、session token 付きで `updatePlayerSetting` を非同期実行する。
- super mode のコマンド更新は管理者だけ許可する。
- 完了 callback はメインスレッドへ戻し、offline / stale は通知せず、成功・競合・失敗を通知する。

一覧表示と設定更新は補助 command へ分離せず、公開入口 `executePlayerCommand` 内で引数に応じて分岐する。

## 2. tab 補完

クラス名: `PlayerSettingTabCompleter`
物理名: `getPlayerCompletions`

第1引数は全 key の小文字 code と `gui`、第2引数は選択 key の有効値を返す。boolean は `on` / `off`、particle は全 density の小文字 code とする。
