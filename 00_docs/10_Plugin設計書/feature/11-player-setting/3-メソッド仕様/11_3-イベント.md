# 11_3-イベント

## 1. login warmup

クラス名: `PlayerSettingJoinEventHandler`
物理名: `onPlayerJoin`
イベント: `PlayerJoinEvent`

`MONITOR` で user UUID の session を開始し、`warmup(userId, sessionToken)` を非同期実行する。完了時に同一 session で online ならメインスレッドで装備表示と `BASE_MUSIC` の再生状態を再同期する。例外は `E_5314` へ記録し、player の login 自体は継続する。

## 2. logout cleanup

クラス名: `PlayerSettingJoinEventHandler`
物理名: `onPlayerQuit`
イベント: `PlayerQuitEvent`

user UUID の cache と session token を `PlayerSettingService.clear` で破棄する。

## 3. GUI click / drag

クラス名: `PlayerSettingGuiEventHandler`
物理名: `onInventoryClick`, `onInventoryDrag`

- 対象 GUI の操作を cancel し、hotbar shortcut、戻る、設定 slot、secret slot を処理する。
- boolean は反転、particle は enum の次値へ進め、draft map を再描画する。
- secret slot は管理者だけ 5 連続 click で `ADVENTURE_RECORD_SUPER_MODE` を反転できる。他 slot の click で回数を reset する。

## 4. GUI close 保存

クラス名: `PlayerSettingGuiEventHandler`
物理名: `onInventoryClose`

draft を copy して session token とともに非同期保存する。変更前と同じ値は送信せず、stale session で打ち切る。完了通知は online player へメインスレッドで行い、元の draft と secret click count は close 時に破棄する。`ARMOR_DISPLAY` の成功または競合同期後は、受信者本人と追跡中プレイヤーの防具表示を再送し、`BASE_MUSIC` の成功または競合同期後は拠点音楽を確定値へ同期する。
