# 11_3.07-GUI・View

クラス名: `PlayerSettingGui`
物理名: `open`

## 1. GUI レイアウト

クラス: `PlayerSettingGui`

| スロット | 設定キー | 内容 |
|---:|---|---|
| `20` | `DAMAGE_LOG_DISPLAY` | ダメージログ表示の ON / OFF |
| `21` | `DAMAGE_LOG_MESSAGE` | ダメージログのチャット出力 ON / OFF |
| `22` | `PARTICLE_DENSITY` | パーティクル密度 |
| `24` | `DROP_LOG_DISPLAY` | ドロップログ表示の ON / OFF |
| `25` | `AUTO_SAVE_MESSAGE` | オートセーブ開始・完了メッセージの ON / OFF |
| `49` | 戻る | メインメニューへ戻る |
| プレイヤーホットバー `4` | 通常表示 | 専用の閉じるボタンは配置しない |

チェスト側に閉じるアイコンや不可視の閉じるクリック領域は配置しない。管理者向け隠し操作として `slot 53` を 5 回クリックした場合のみ `ADVENTURE_RECORD_SUPER_MODE` を反転する。

## 2. 操作

- `open`: 現在設定を読み込んで GUI を表示する。
- `onSlotClick`: 対象設定を更新し、表示を再描画する。
- `onClose`: 必要な保存処理を行う。

Boolean 設定は共通表示規則で ON / OFF を示し、個別 GUI に重複した保存ロジックを置きません。失敗時は既存 `LogId` とプレイヤーメッセージ経路を使用します。
