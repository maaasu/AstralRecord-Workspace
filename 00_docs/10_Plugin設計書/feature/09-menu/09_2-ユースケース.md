# 09_2-ユースケース

## 1. メインメニューを開く

1. gameplay player が `/menu` を実行する。
2. `PlayerGuiRenderContextFactory` がアカウント、ステータス、CP、通貨、装備を同一の描画コンテキストへ集約する。
3. `MenuView.open` がメイン画面を描画する。
4. 項目クリック時は menu が遷移先 feature の service / GUI へ委譲する。

メイン配置は `20` プレイヤー情報、`21` 装備、`22` スキルマネージャー、`23` クエスト、`24` プレイヤー設定、`29` 冒険記録、`30` メール、`31` party、`32` プレイヤー一覧、`38` 通貨、`39` ガイド、`40` 帰還、`41` ゴミ箱、`49` close とする。

クエスト項目をクリックした場合は、`QuestGuiEventHandler.openList`へ遷移し、受領中・報告可能クエストの確認と破棄を行う。

## 2. クラフトショートカットを使う

1. gameplay player の join、world 変更、inventory open / close、craft 更新時に 2×2 枠を再描画する。
2. プレイヤー情報 shortcut は、基礎値から合計値が変化したステータスだけをカタログ順に最大8件表示する。9件目以降は `… ほかN件` として省略する。
3. クリックまたは DROP 入力を action へ変換し、プレイヤー詳細・帰還・通貨・装備を開く。
4. shortcut item の drop / pickup / world item 化は抑止し、dummy item を残さない。

## 3. ゴミ箱を利用する

1. `/trash` またはメニューから編集画面を開く。
2. プレイヤーが捨てる item を内容枠へ移す。
3. 確認画面で確定した場合だけ item を破棄し、戻る・閉じる場合は保持 item をプレイヤーへ返す。
4. inventory に入りきらない返却 item は安全な位置へ drop する。

## 4. プレイヤー情報を参照する

1. メインメニューまたは `/player info <playerName>` から online player を選ぶ。
2. 自分または対象 player の詳細画面を表示する。
3. 詳細画面ではリソース、基本能力値、攻撃、防御、属性、状態異常、ユーティリティの全 status category を個別 icon から参照する。
   クラス情報の全クラスレベルは、class master の `order` 昇順（同値時は class ID 昇順）で表示する。
4. party 招待用途では対象選択後に party feature へ処理を委譲する。
