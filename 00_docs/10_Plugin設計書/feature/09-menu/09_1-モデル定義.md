# 09_1-モデル定義

## 1. 画面種別

物理名: `MenuScreen`

| 値 | 用途 |
|---|---|
| `MAIN` | メインメニュー |
| `BUFF` | 有効バフ |
| `CLASS` | クラス一覧 |
| `EQUIPMENT_GUI` | 装備編集 |
| `CURRENCY` | 通貨一覧 |
| `GUIDE` | ガイド一覧・詳細 |
| `TRASH` / `TRASH_CONFIRM` | ゴミ箱編集・破棄確認 |
| `SELL` / `SELL_CONFIRM` | 売却編集・確定確認 |
| `STORAGE` | ストレージ |

旧装備加工用の3画面種別と表示 state は削除する。オーブ候補一覧と状態変化確認は menu の画面種別へ登録せず、`OrbGuiHolder` がオーブ session とロック状態を保持する。

## 2. クラフトショートカット

物理名: `MenuShortcutAction`、`MenuShortcutSettings`

ショートカットは 4 枠固定で、既定値は次のとおりとする。

| index | action | 遷移先 |
|---:|---|---|
| 0 | `STATUS` | 自分のプレイヤー詳細 |
| 1 | `RETURN_TO_BASE` | 拠点帰還開始 |
| 2 | `INVENTORY_CURRENCY` | 通貨画面 |
| 3 | `EQUIPMENT_GUI` | 装備画面 |

action 候補は `NONE`、`MAIN_MENU`、`STATUS`、`RETURN_TO_BASE`、`INVENTORY_CURRENCY`、`EQUIPMENT_GUI`。不明コードは `NONE` として扱う。現行実装は `defaults()` のみ使用し、プレイヤー別永続化は行わない。

## 3. 共通アイコン

物理名: `MenuIconDefinition`

`UNSET`、`MAIN_MENU`、`ACCOUNT_INFO`、`QUEST`、`PLAYER_SETTING`、`EQUIPMENT`、`TRASH`、`GUIDE`、`RETURN_TO_BASE`、`ADVENTURE_RECORD`、`MAIL`、`SKILL_BIND`、`CURRENCY`、`PARTY`、`PLAYER_LIST` の material・表示名・色・説明を一元管理する。

メインメニューで用途を識別しやすくするため、各定義の Material は重複させない。`ACCOUNT_INFO` は描画対象プレイヤーのスキンを持つ `PLAYER_HEAD` とし、`QUEST` は `MAP`、`ADVENTURE_RECORD` は `SPYGLASS`、`MAIL` は `CHEST`、`SKILL_BIND` は `ENCHANTING_TABLE`、`PARTY` は `IRON_CHAIN`、`PLAYER_LIST` は `NAME_TAG` を使用する。`GUIDE` は `KNOWLEDGE_BOOK` とし、通常の本アイコンと区別する。

## 4. プレイヤー依存描画コンテキスト

物理名: `PlayerGuiRenderContext`

| 項目 | 型・内容 |
|---|---|
| `account` | 選択中 `AccountModel` |
| `statusSnapshot` | 描画時点の `StatusSnapshot` |
| `classPointLabel` | 現在職を含む CP 表示名 |
| `availableClassPoints` | 使用可能 CP |
| `availablePassivePoints` | 使用可能 passive point |
| `goldAmount` | 所持 gold |
| `returnToBaseGoldCost` | 帰還費用 |
| `equipment` | `PlayerEquipmentSnapshot`。頭・胴・脚・足の表示名 |
| `currencyBalances` | `CurrencyDisplayEntry` 一覧。ID、表示名、数量 |

## 5. GUI holder

物理名: `MenuInventoryHolder`

`screen`、`shortcutSlotIndex`、`pageIndex`、`contentId` を保持し、`HotbarShortcutGuiHolder` として navigation ID、戻る slot、直接戻り可否、常時 close 可否を公開する。`GuiNavigationHolder` はこれらの navigation metadata だけを公開し、プレイヤー別 navigation state の正本は `AstPlayer.guiNavigationState` が保持する `GuiNavigationState` とする。

## 6. プレイヤー一覧用途

物理名: `PlayerListPurpose`

- `PARTY_INVITE`: party 招待対象選択。
- `PLAYER_INFO`: プレイヤー詳細表示対象選択。
