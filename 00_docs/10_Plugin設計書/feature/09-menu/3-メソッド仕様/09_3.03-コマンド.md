# 09_3.03-コマンド

## 1. メニュー表示実行

クラス名: `MenuCommand`
物理名: `executePlayerCommand`

責務:

`/menu` および各サブコマンドを処理する。

処理内容:

1. `AstralRecord.getInstance()` から `MenuView` と `PlayerGuiRenderContextFactory` を取得する
2. 引数が空の場合は、コマンド基底から渡された `AstPlayer` の描画コンテキストを 1 回生成する
3. `MenuView.open(AstPlayer, PlayerGuiRenderContext)` を呼び出してメインメニューを開く
4. 引数の第 1 要素が `status` の場合は [[09_3.03-コマンド]].ステータスサブコマンド を呼び出す
5. 未対応サブコマンドの場合は使用方法を表示する

## 2. プレイヤー情報サブコマンド

クラス名: `MenuCommand`
物理名: `executePlayerCommand`

責務:

`/menu status` で統合プレイヤー情報画面を直接開く。`status` は既存コマンドとの互換用サブコマンド名とする。

処理内容:

1. `PlayerBrowserGuiEventHandler.openSelfDetail` を呼び出す
2. `StatusService.refreshStatus` でステータススナップショットを再計算し、`PlayerDetailGui` を開く
3. コマンドから直接開いた時点で GUI 履歴が存在しない場合、戻るボタンは表示しない

## 3. コマンド仕様

- ルート: `/menu`
- サブコマンド:
  - `status`: 統合プレイヤー情報画面を開く（互換名）
- コンソール実行: 不可（`isPlayerOnly = true`）
- 権限値（`permission`）による個別制限は行わず、`AstCommand` 基底側の制御に委ねる

## 追記（2026-05-27）trash コマンド

### trash表示実行
クラス名: `TrashCommand`
物理名: `executePlayerCommand`

処理内容:
1. `AstralRecord.getInstance().getTrashService()` で `TrashService` を取得する。
2. `TrashService.open(player.getBukkit())` を呼び、ゴミ箱GUIを1ページ目で開く。

### コマンド仕様追記
- ルート: `/trash`
- 引数: なし
- コンソール実行: 不可（`isPlayerOnly = true`）

## 追記（2026-06-02）sell コマンド

### sell表示実行
クラス名: `SellCommand`
物理名: `executePlayerCommand`

処理内容:
1. `AstralRecord.getInstance().getMenuView()` で `MenuView` を取得する。
2. `MenuView.openSell(player.getBukkit(), List.of(), 0)` を呼び、売却GUIを1ページ目で開く。

### コマンド仕様追記
- ルート: `/sell`
- 引数: なし
- コンソール実行: 不可（`isPlayerOnly = true`）
- permission: ADMIN 以上
- メニューには追加しない。通常プレイヤー導線は NPC 経由を想定する。

## 追記（2026-06-13）enhance コマンド

### enhance表示実行
クラス名: `EnhanceCommand`
物理名: `executePlayerCommand`

処理内容:
1. 引数なしのプレイヤー実行のみ受け付ける。余分な引数がある場合は使用方法を表示する。
2. `AstralRecord.getInstance().getEquipmentEnhancementService()` で `EquipmentEnhancementService` を取得する。
3. `GuiSound.OPEN` を再生し、`EquipmentEnhancementService.open(player.getBukkit())` で装備強化GUIを直接開く。
4. service が利用できない場合は `GuiSound.DENY` を再生し、自動遷移や代替GUI表示は行わない。

### コマンド仕様追記
- ルート: `/enhance`
- 引数: なし
- コンソール実行: 不可（`isPlayerOnly = true`）
- permission: 追加制限なし
