# 09_3-イベント

## 1. クラフトショートカット入力解決

クラス名: `MenuOpenEventHandler`
物理名: `resolve`

`DROP_ITEM` かつ craft shortcut item の場合だけ `menu-craft-shortcut-drop` 候補を返す。候補は `CLAIM_AND_CANCEL` で元入力を所有し、drop された dummy entity とプレイヤー inventory 内の shortcut item を除去して action を実行する。

## 2. クラフト枠・画面ライフサイクル

クラス名: `MenuOpenEventHandler`
物理名: `onPrepareItemCraft`, `onInventoryOpen`, `onInventoryClose`, `onPlayerJoin`, `onPlayerQuit`, `onPlayerChangedWorld`

- gameplay player のみ `MenuShortcutSettings.defaults()` をクラフト 2×2 枠へ描画する。
- menu / 共通 GUI を開くと player inventory に dummy を適用し、画面終了時は遷移フラグに従って復元する。
- quit と world 変更では shortcut / 遷移一時状態を除去する。

## 3. shortcut item の world 流出防止

クラス名: `MenuOpenEventHandler`
物理名: `onItemSpawn`, `onEntityPickupItem`

shortcut marker を持つ item entity を即時削除し、entity pickup をキャンセルする。

## 4. menu inventory 操作

クラス名: `MenuOpenEventHandler`
物理名: `onInventoryClick`, `onInventoryDrag`

画面種別と slot に応じて、プレイヤー情報、設定、装備、skill bind、通貨、ガイド、帰還、ゴミ箱、売却、ストレージなどへ委譲する。共通 GUI 外の通常 inventory 操作は inventory feature に残す。

## 5. craft shortcut 再描画

クラス名: `MenuOpenEventHandler`
物理名: `refreshCraftShortcuts`

現在の view が `CRAFTING` かつ gameplay player の場合に限り、craft 枠へ既定 shortcut を再描画する。`cleanup` は plugin 停止時に全 online player の shortcut と一時状態を破棄する。

## 6. プレイヤー一覧・詳細操作

クラス名: `PlayerBrowserGuiEventHandler`
物理名: `onInventoryClick`, `onInventoryDrag`, `openInfoList`, `openInviteList`, `openDetailFromCommand`, `openSelfDetail`

online player のページ移動、詳細表示、status category 詳細 GUI のページ移動、party 招待選択を処理する。status category 詳細 GUI は対象カテゴリの status だけを表示し、戻る操作でプレイヤー詳細へ復帰する。対象が離脱済みの場合は `P_5603` を通知して処理を終了する。
