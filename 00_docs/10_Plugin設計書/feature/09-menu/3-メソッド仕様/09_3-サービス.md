# 09_3-サービス

## 1. 描画コンテキスト生成

クラス名: `PlayerGuiRenderContextFactory`
物理名: `create`

`AstPlayer` からアカウント、現在 status、CP、gold、帰還費用、装備表示名、通貨残高を取得し、不変な `PlayerGuiRenderContext` を返す。

## 2. GUI 遷移

クラス名: `MenuGuiTransitionService`
物理名: `applyPlayerInventoryDummy`, `fillPlayerInventoryDummy`, `consumePlayerInventoryDummyApplied`, `consumeSuppressedPlayerInventoryRestore`, `shouldPlayCloseSoundOnClose`, `restorePlayerInventory`, `switchGuiWithoutInventoryReload`, `switchGuiWithInventoryRestore`

- menu 表示中の下部 inventory を dummy で保護する。
- GUI 間遷移では close event による不要な復元・close sound を一度だけ抑止する。
- 通常画面へ戻る遷移では inventory feature に実データの再描画を委譲する。

## 3. ゴミ箱

クラス名: `TrashService`
物理名: `open`, `handleClick`, `handleDrag`, `handleClose`

- `open` は保持中 item と page を引き継いで編集画面を開く。
- `handleClick` / `handleDrag` は内容枠、ページ、確認、戻る操作だけを許可する。
- 確認時は item を破棄して `P_5601`、戻る・close 時は item を返却して `P_5602` を通知する。
- private な確認処理を独立した public メソッドとしては扱わない。
