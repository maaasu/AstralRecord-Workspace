# 09_3-コマンド

## 1. menu コマンド

クラス名: `MenuCommand`
物理名: `executePlayerCommand`

`/menu [status|guide|mail]` を処理する。gameplay player 以外は拒否し、引数なしはメイン、`status` は自分の詳細、`guide` はガイド、`mail` はメールを開く。未対応引数は usage を返す。

## 2. player info コマンド

クラス名: `PlayerInfoCommand`
物理名: `executePlayerCommand`

`/player info <playerName>` の online exact match を解決し、対象の詳細を開く。対象不在時は `P_5603` を通知する。

クラス名: `PlayerInfoTabCompleter`
物理名: `getPlayerCompletions`

online player 名から prefix 一致候補を返す。

## 3. trash コマンド

クラス名: `TrashCommand`
物理名: `executePlayerCommand`

`/trash` を受け、引数なしの場合に `TrashService.open` を呼ぶ。

## 4. enhance コマンド

クラス名: `EnhanceCommand`
物理名: `executePlayerCommand`

`/enhance` を gameplay player かつ引数なしで受け、equipment enhancement service に画面表示を委譲する。

売却コマンドは menu feature に存在せず、sell feature を正本とする。各コマンドは `CommandRegister` が明示登録する。
