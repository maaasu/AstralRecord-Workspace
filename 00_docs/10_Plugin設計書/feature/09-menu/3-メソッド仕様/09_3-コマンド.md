# 09_3-コマンド

## 1. menu コマンド

クラス名: `MenuCommand`
物理名: `executePlayerCommand`

`/menu [status|guide|mail]` を処理する。gameplay player 以外は拒否し、引数なしはメイン、`status` は自分の詳細、`guide` はガイド、`mail` はメールを開く。未対応引数は usage を返す。

## 2. guide コマンド

クラス名: `GuideCommand`
物理名: `executePlayerCommand`

`/guide` を受け、引数なしでガイドGUIを開く。プレイヤー送信者であれば権限レベルにかかわらず利用できる。

## 3. player info コマンド

クラス名: `PlayerInfoCommand`
物理名: `executePlayerCommand`

`/player info [<playerName>]` の online exact match を解決し、対象の詳細を開く。プレイヤー名を省略した場合は実行者自身を対象にする。対象不在時は `P_5603` を通知する。

`/pi [<playerName>]` は `/player info [<playerName>]` の短縮形で、プレイヤー名を省略した場合は実行者自身を対象にする。

クラス名: `PlayerInfoTabCompleter`
物理名: `getPlayerCompletions`

online player 名から prefix 一致候補を返す。`/player` では `info` と対象名、`/pi` では対象名を補完する。

## 4. trash コマンド

クラス名: `TrashCommand`
物理名: `executePlayerCommand`

`/trash`、`/g`、`/gomi` を受け、引数なしの場合に `TrashService.open` を呼ぶ。いずれもプレイヤー送信者であれば権限レベルにかかわらず利用できる。

## 5. currency コマンド

クラス名: `CurrencyCommand`
物理名: `executePlayerCommand`

`/currency`、`/c`、`/gold` を受け、`MenuOpenEventHandler` 経由で通貨GUIを開く。いずれもプレイヤー送信者であれば権限レベルにかかわらず利用できる。

旧 `/enhance` コマンドは削除する。装備強化・修理・状態変化・エンチャントにコマンド入口は設けず、通常プレイヤーインベントリのオーブクリックから開始する。

売却コマンドは menu feature に存在せず、sell feature を正本とする。各コマンドは `CommandRegister` が明示登録する。
