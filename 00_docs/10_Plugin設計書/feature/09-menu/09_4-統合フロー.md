# 09_4-統合フロー

## 1. メインメニュー表示・画面遷移

### シーケンス

```mermaid
sequenceDiagram
    actor Player as プレイヤー
    participant Command as MenuCommand
    participant Context as PlayerGuiRenderContextFactory
    participant View as MenuView
    participant Transition as MenuGuiTransitionService
    participant Feature as 遷移先 feature

    Player->>Command: /menu
    Command->>Context: create(AstPlayer)
    Context-->>Command: PlayerGuiRenderContext
    Command->>Transition: inventory dummy 適用
    Command->>View: open(context)
    Player->>View: menu item click
    View->>Transition: GUI 遷移フラグ設定
    Transition->>Feature: 対象 service / GUI を開く
```

### 処理要点

- 画面は `MenuInventoryHolder.screen` で識別し、ページ・detail ID を holder へ保持する。
- 画面間遷移では close event による inventory 再ロードと close sound を一度だけ抑止する。
- 業務処理は遷移先 feature へ委譲し、menu は表示と navigation に限定する。

### 例外・終了条件

- gameplay player でなければ menu を開かない。
- menu open の例外は `E_5600`、shared GUI 操作の例外は `E_5601`（`player`, `operation`）として記録し、Bukkit event loop へ送出しない。

## 2. クラフトショートカット

### シーケンス

```mermaid
sequenceDiagram
    actor Player as プレイヤー
    participant Event as MenuOpenEventHandler
    participant View as MenuView
    participant Gateway as PlayerInteractionGateway
    participant Action as 遷移先処理

    Event->>View: refreshCraftShortcuts
    View->>Player: 2x2 枠へ既定4項目を描画
    Player->>Gateway: click / DROP_ITEM
    Gateway->>Event: resolve(input context)
    Event-->>Gateway: CLAIM_AND_CANCEL candidate
    Gateway->>Event: winner action
    Event->>View: dummy item 除去・再描画
    Event->>Action: status / return / currency / equipment
```

### 処理要点

- shortcut は gameplay player にだけ表示し、現行値は `MenuShortcutSettings.defaults()` 固定とする。
- DROP 入力は player-interaction の勝者選択を経由する。
- spawn / pickup された shortcut marker item は削除し、world item 化を防ぐ。

### 例外・終了条件

- `CRAFTING` view でない場合は再描画しない。
- quit・world 変更・plugin disable では shortcut と一時状態を除去する。

## 3. ゴミ箱確定・返却

### シーケンス

```mermaid
sequenceDiagram
    actor Player as プレイヤー
    participant Command as TrashCommand
    participant Trash as TrashService
    participant View as MenuView
    participant Inventory as Bukkit PlayerInventory

    Player->>Command: /trash
    Command->>Trash: open
    Trash->>View: openTrash(items, page)
    Player->>Trash: item 配置・確認
    Trash->>View: openTrashConfirm
    alt 破棄確定
        Trash->>Trash: 保持 item を破棄
        Trash-->>Player: P_5601
    else 戻る・close
        Trash->>Inventory: 保持 item を返却
        Trash-->>Player: P_5602
    end
```

### 処理要点

- 確認前の item は GUI が保持し、意図しない close では必ず返却する。
- page 移動と確認遷移でも保持 item を新しい inventory へ引き継ぐ。

### 例外・終了条件

- inventory に戻せない item はプレイヤー位置へ drop し、消失させない。
- content placeholder は item として扱わない。
