## 8. 拠点帰還

対象: プレイヤー

契機: メインメニューの `帰還` 項目クリック

正常系:

1. `AstPlayer` を取得する。未取得なら拒否音で終了する
2. world feature から `joinSpawn.world` に対応する `WorldMasterData` とスポーン地点を解決する
3. プレイヤーレベルに応じて `100 x Lv` の必要ゴールド量を算出し、所持ゴールド不足時はエラーメッセージを返して終了する
4. メニュー GUI を閉じ、タイトル・サブタイトル・ボスバーで帰還待機を案内する
5. 3 秒間移動しなければ、world feature の共通安全テレポートで参加時スポーン地点へ帰還する
6. 待機中はプレイヤー周囲へパーティクルとサウンドを出し続ける
7. 移動した場合は帰還をキャンセルし、キャンセルメッセージを表示する
