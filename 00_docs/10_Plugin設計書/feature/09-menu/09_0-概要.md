# 09_0-概要

## 1. 目的

menu feature は、プレイヤー向け機能への共通入口、クラフト 2×2 枠のショートカット、ゴミ箱、online プレイヤー参照 GUI を提供する。画面遷移と表示を集約し、遷移先 feature の業務処理は各 feature へ委譲する。

## 2. 責務

- メイン、バフ、クラス、装備、通貨、ガイド、ゴミ箱、売却確認、ストレージ画面の識別と描画。
- `/menu`、`/player info`、`/trash` の入口。装備操作は通常インベントリ内のオーブクリックを入口とする。
- gameplay player のクラフト枠へ固定ショートカットを描画し、クリック・DROP 入力を各機能へ転送する。
- GUI 間遷移時の Bukkit player inventory dummy 適用・復元と、共有 session token による終了・遷移の判定。
- online プレイヤー一覧・詳細画面の表示と party 招待への委譲。

## 3. 責務外

- 売却価格計算・売却確定は sell feature、ストレージ entry 更新は storage / inventory feature を正本とする。
- 装備、設定、ガイド、メール、party、冒険記録の業務処理は各 feature を正本とする。
- コマンドは `plugin.yml` ではなく `CommandRegister` が明示登録する。
- ショートカット専用 repository は持たない。現在のショートカットは `MenuShortcutSettings.defaults()` の固定値であり永続化しない。

## 4. スレッド境界

Bukkit inventory の作成・更新、イベント処理、プレイヤーへの画面表示はメインスレッドで行う。外部 feature が非同期で取得した値を画面へ反映する場合は、呼び出し元がメインスレッドへ戻してから `MenuView` を呼ぶ。

## 5. 依存・連携

- `player` / `account`: online セッション、アカウントモード、プレイヤー一覧を参照する。
- `status` / `class` / `currency`: メインメニューとプレイヤー詳細の描画値を取得する。
- `inventory`: 装備 GUI、Bukkit inventory の dummy 表示、ホットバー表示を連携する。
- `player-setting`: プレイヤー設定 GUI を開く。
- `guide` / `mail` / `party` / `adventure-record`: メニュー項目の遷移先を提供する。
- `sell` / `storage`: `MenuView` を共有するが、売却・保管の業務処理は各 feature を正本とする。
- `player-interaction`: クラフトショートカットの DROP 入力を調停する。
