# 09_5.00-例外・ログ・運用

## 1. ログ

| ID | レベル | テンプレート | 用途 |
|---|---|---|---|
| `LogId.E_5600` | ERROR | `メニューイベント処理に失敗しました: %s` | `MenuOpenEventHandler` の event 処理失敗 |
| `LogId.E_5601` | ERROR | `GUI イベント処理に失敗しました: player=%s, operation=%s` | feature をまたいで利用する shared GUI 操作失敗 |

## 2. プレイヤーメッセージ

| ID | 用途 |
|---|---|
| `PlayerMsgId.P_5601` | ゴミ箱内 item の破棄完了 |
| `PlayerMsgId.P_5602` | ゴミ箱内 item の返却 |
| `PlayerMsgId.P_5603` | 指定 player が online でない |

遷移先 feature で発生するメッセージは、その feature の設計書を正本とする。

## 3. 例外・運用方針

- Bukkit GUI event は `runSafely` で保護し、失敗した操作だけを中止する。shared GUI の失敗は menu 専用扱いにせず、`E_5601` へ `player` と `operation` を渡す。
- holder や marker を持たない inventory / item は menu 管理対象にしない。
- GUI を閉じる経路では、dummy inventory とゴミ箱保持 item の復元を優先する。
- shortcut marker item は drop、spawn、pickup の全経路で除去する。
- `MenuView` の sell / storage 描画 API は共有 view であり、データ更新の責務を menu へ移さない。
