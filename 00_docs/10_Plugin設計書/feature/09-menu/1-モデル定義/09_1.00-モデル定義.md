# 09_1.00-モデル定義

## 1. メニュー画面種別

物理名: `MenuScreen`

| 物理名 | 論理名 | 用途 |
|---|---|---|
| `MAIN` | メインメニュー | 主要画面への入口 |
| `BUFF` | バフ | 現在有効なバフ一覧を表示する |
| `EQUIPMENT_GUI` | 装備 GUI | 防具・オフハンド・種類別アクセサリを編集し、選択中メイン装備とペット・メモリー・ゲージの将来枠を表示する |
| `EQUIPMENT_ENHANCE` | 装備強化 GUI | 装備をセットし、必要素材を確認して強化を実行する |
| `EQUIPMENT_REPAIR` | 装備修理 GUI | 装備をセットし、ゴールドを消費して耐久値を最大まで回復する |
| `CURRENCY` | 通貨 | 通貨アイテムをページング表示する |

## 2. メニューショートカット項目

物理名: `MenuShortcutAction`

| 物理名 | 表示名 | 対象 |
|---|---|---|
| `NONE` | 未設定 | 未使用・範囲外 slot のフォールバック |
| `MAIN_MENU` | メニュー | メインメニューを開く |
| `STATUS` | プレイヤー情報 | 統合プレイヤー情報画面を開く。識別値は既存ショートカットとの互換用に維持する |
| `RETURN_TO_BASE` | 帰還 | `BEACON` アイコンで拠点へ帰還を開始する |
| `INVENTORY_CURRENCY` | 通貨 | 通貨 GUI |
| `EQUIPMENT_GUI` | 装備 | 装備 GUI を開く |

## 4.1 GUI ナビゲーション状態

物理名: `GuiNavigationState`

`AstPlayer` が、GUI を閉じずに遷移している間だけ現在の GUI と直前の GUI の履歴を保持する。ページ送りやフィルター変更など同一画面の再描画は現在位置を置換し、履歴へ積まない。GUI セッションを閉じた場合は現在位置と履歴をすべて破棄する。

## 5. 関連 feature とのモデル関係

- `inventory`: BAG スクロール、装備 GUI、カスタムGUI中の通常ホットバー操作で連携する。
- `account`: ショートカット永続設定は使用しない。`menuShortcutsJson` は参照・保存しない。
- `currency`: 通貨 GUI の表示アイテム一覧を取得する。
- `world`: `帰還` で参加時スポーン地点を拠点として利用し、共通安全テレポート経路へ委譲する。

## 追記（2026-06-13 装備強化GUI）
- `EQUIPMENT_ENHANCE`: NPC interaction など明示導線から開く 54 スロット GUI。装備 GUI からの遷移アイコンと装備強化 GUI の戻るボタンは持たない。装備は一旦セット可能とし、次強化段階が存在する場合のみ必要素材・必要ゴールド・成功率・失敗時挙動を表示する。強化不可理由は実行アイコンに表示する。

## 追記（2026-06-01 プレイヤー一覧・パーティーGUI）

### MenuScreen 追加
- `PLAYER_LIST`: サーバー参加中プレイヤーの一覧を表示する共通 GUI。
- `PLAYER_DETAIL`: 1 人のプレイヤー詳細情報を表示する GUI。
- `PARTY_MEMBER_ACTION`: パーティーリーダーが対象メンバーに対して昇格・キックを選択する GUI。

### PlayerListGui 共通パラメータ
- `purpose`: 一覧の用途。プレイヤー情報参照またはパーティー招待に使用する。
- `pageIndex`: ページ番号。54 スロット GUI の 0-44 を一覧領域として使用する。
- `filter`: 表示対象条件。用途に応じて「全オンライン」または「パーティー未所属」を適用する。
- 戻り先は固定値を持たず、`GuiNavigationState` が保持する直前の GUI を参照する。

### パーティー GUI 配置
- リーダー: 上段中央 `slot 13`
- 招待ボタン: `slot 15`
- メンバー: 下段中央から `slot 31, 30, 32, 29, 33`
- 戻る: `slot 49`
- 離脱/解散: `slot 51`

### PlayerDetailGui 表示項目
- `slot 4` のプレイヤーヘッドへ、プレイヤー名、レベル、アカウント、モード、累計経験値、クラス、クラス経験値、所持 Gold、プレイ時間、初回・最終ログインをまとめて表示する。
- 現在地は world master のプレイヤー向け表示名だけを表示し、world ID と座標は表示しない。
- `StatusType.Category` ごとのステータス一覧。各値は合計値の隣へ基礎値と補正値を色分けして数値だけ表示し、「基礎」「補正」のラベルは表示しない。
- 現在有効なバフ一覧
- 他者操作としてトレード申請とパーティー招待のアイコンを表示する。自分自身を対象にした場合は操作不可表示とする。

## 追記: 装備修理 GUI

- `MenuScreen.EQUIPMENT_REPAIR`: ゴールドを消費して装備インスタンスの耐久値を最大まで回復する 54 スロット GUI。
- メインメニューには `装備修理` 導線を置かない。修理は拠点などに配置された NPC interaction の `gui.type = EQUIPMENT_REPAIR` から `EquipmentRepairService.open` を実行する。
- 修理 GUI は下部の表示中装備インベントリから対象装備を選択し、対象 slot へ一時セットする。閉じた場合は選択中装備を元の所持品へ戻す。
- 修理費用は `ceil(回復耐久値 * (1 + max(0, 最大耐久値 - 300) / 1400))`。最大耐久値が小さい序盤装備は 1 耐久値あたり 1 Gold に近く、終盤装備は緩やかに上乗せする。
