    3計算方法

    計算例は近接標準構成の値。

    3.1現職の直接補正

    防御基本能力値
    現職補正=職業の初期補正+レベルごとの成長×職業Lv − 1

    Lv.25共通防御 7 + 0.8 × (16 − 1) = 19
    体力 8 + 1 × (16 − 1) = 23

    • 現在職のみ共有初期値へ加算。祖先職のCPはツリーの取得に使用。

    3.2防具の直接値

    防御
    防具の直接共通防御=目標共通防御−体力による派生−防具以外の直接値

    Lv.25235 − 30 − (5 + 0 + 19 + 4 + 0) = 177

    • 派生を引いた直接値は 205。防具以外の直接値は計 28。

    3.3共通防御の合計

    防御基本能力値
    共通防御=直接値の合計+体力の合計×1

    Lv.255 + 0 + 19 + 4 + 177 + 0 + 30 × 1 = 235

    • 体力の合計は 5 + 0 + 23 + 2 + 0 + 0 = 30。体力からの共通防御の派生は合算後に一度だけ適用。
