    3計算方法

    02の標準目標を使い、共有初期値と近接前衛の配分を求める。

    3.1共有初期値の逆算

    防御基本能力値
    初期体力=初期Lvの体力目標
    初期の直接共通防御=初期Lvの共通防御目標−初期体力×1

    Lv.1体力 5、直接共通防御 8 − 5 × 1 = 3

    3.2防具の直接値

    防御
    防具の直接共通防御=目標共通防御−体力による派生−防具以外の直接値

    Lv.25235 − 30 − (3 + 0 + 20 + 5 + 0) = 177

    • 派生を引いた直接値は 205。防具以外の直接値は計 28。

    3.3共通防御の合計

    防御基本能力値
    共通防御=直接値の合計+体力の合計×1

    Lv.253 + 0 + 20 + 5 + 177 + 0 + 30 × 1 = 235

    • 体力の合計は 5 + 0 + 20 + 5 + 0 + 0 = 30。体力からの共通防御の派生は合算後に一度だけ適用。
