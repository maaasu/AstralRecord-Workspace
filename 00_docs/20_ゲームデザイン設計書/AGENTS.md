# ゲームデザイン設計書のHTMLルール

このフォルダ以下でHTML資料を新規作成・修正するときに適用します。

## 統一する基準

- HTML資料のデザインは統一します。作成・修正前に、基準となる [DPS指標](01-DPS指標.html) のHTMLとCSSを確認してください。
- CSS変数、フォント、余白、パネル、表、操作部品のスタイルは基準HTMLから再利用します。資料ごとに別のテーマを作らず、追加要素も同じ変数と寸法に合わせます。
- 共通デザインを変更するときは、このルールと基準HTML、同じ部品を使う既存HTMLを揃えます。各資料の指標・数値・計算式は、その資料の仕様に従います。

## レイアウトと見た目

| 項目 | 共通ルール |
|---|---|
| 画面幅 | `main` は幅100%。PCでも狭い最大幅を設けず、画面全幅を使う |
| 外側の余白 | PCは上下28px・左右32px。760px以下は20px・16px、420px以下は18px・12pxを基準にする |
| 配色 | 基準HTMLの `:root` と `prefers-color-scheme: dark` のCSS変数を使い、ライト・ダークの両方に対応する。主系列は青、比較・上限はアンバーを使う |
| フォント | 基準HTMLと同じSegoe UI系・日本語フォールバックを使う。数値は `tabular-nums` で桁を揃える |
| 文字 | 大見出し28〜32px、小見出し18px、本文14〜16px、補足12〜13pxを目安にする。細すぎる文字を避け、背景とのコントラストを確保する |
| パネル | 面色・1pxの境界線・12〜16pxの角丸・控えめな影を基準HTMLに揃える |
| 情報の順序 | タイトルと短い目的説明の後に、主となる図表と操作・数値表示を置く。詳しい条件・計算方法・補助の数値表は、その下の `details` にまとめる |
| 表と操作 | 表の見出し・罫線・選択行、スライダー・数値表示・フォーカス枠は基準HTMLの表現を再利用する |

## グラフがある資料

- グラフは横幅を使い、高さは基準HTMLの `clamp(310px, 43svh, 460px)` を基準にします。画面高に合わせて縦へ引き伸ばしすぎず、軸・凡例・操作・数値を読み取れる配置にします。
- 軸ラベルは14px、主要線は約3〜3.5px、主要点の半径は約5.5〜6pxを基準にします。標準系列の実線、比較・上限系列の破線、明瞭な点と凡例を組み合わせます。
- 主要な軸ラベルに対応する点は、同じ大きさと強調方法で揃えます。DPS指標ではLv.75も主要点として表示します。
- カーソルとタップで値を確認できるようにし、キーボードでも同じ値を選択できる操作部品を用意します。選択値はグラフの近くにも表示し、ツールチップが画面外へはみ出さないようにします。

## 表示と確認

- 単一ファイルをブラウザで直接開いて利用できる構成を基本にし、外部CDNやWebフォントに依存しません。
- 760px前後で段組みを縦に切り替え、320px幅でもページ全体が横にはみ出さないようにします。幅が必要な表は、表の領域だけを横スクロールさせます。
- 入力にはラベル、図表には説明を付け、キーボード操作時のフォーカスを見える状態にします。色に加えて線種・文字・凡例でも情報を区別します。
- 印刷時は操作部品を隠し、条件・計算方法・数値表などの折りたたみ内容も読めるようにします。
- HTMLを変更したら、PC・スマホ幅とライト・ダークの両方で実際にブラウザ表示を確認します。図表や操作がある場合は、主要点、値の表示、タップ・キーボード操作も確認します。
