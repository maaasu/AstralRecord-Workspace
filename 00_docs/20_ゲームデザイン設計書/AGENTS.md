# ゲームデザイン設計書のHTMLルール

このフォルダ以下でHTML資料を新規作成・修正するときに適用します。

## 統一する基準

- HTML資料のデザインは統一します。作成・修正前に、基準となる [DPS指標](01-DPS指標.html) のHTMLとCSSを確認してください。
- CSS変数、フォント、余白、パネル、表、操作部品のスタイルは基準HTMLから再利用します。資料ごとに別のテーマを作らず、追加要素も同じ変数と寸法に合わせます。
- 共通デザインを変更するときは、このルールと基準HTML、同じ部品を使う既存HTMLを揃えます。各資料の指標・数値・計算式は、その資料の仕様に従います。

## レイアウトと見た目

| 項目 | 共通ルール |
|---|---|
| 画面幅 | `main` は幅100%。PCでも狭い最大幅を設けず、画面全幅を使う |
| 外側の余白 | PCは上下28px・左右32px。760px以下は20px・16px、420px以下は18px・12pxを基準にする |
| 配色 | マスターデータエディタの部品構造を使い、画面はエディタと同じチャコール系で統一する。背景は #21252b、パネルは #282c34、表見出しは #303640、本文は #cdd3de。選択には #323e50 の面と #8ab8eb のアクセントを使う |
| フォント | 基準HTMLと同じSegoe UI系・日本語フォールバックを使う。数値は `tabular-nums` で桁を揃える |
| 文字 | 大見出し28〜36px、小見出し18px。表と凡例は15px、表見出しと吹き出しは14px、軸目盛りは13pxを基準にする |
| 図表の枠 | 面に細い境界線と10px前後の角丸を付ける。セルは1pxの罫線で区切り、見出しと選択行に色を付ける |
| 情報の順序 | タイトルと短い目的説明、主となる図表と操作、主要な基準値の表の順に置く。表は必要なときに詳細な刻みへ展開し、条件・計算式を末尾の `details` にまとめる |
| 表と操作 | 表の見出し・罫線・選択行、スライダー・数値表示・フォーカス枠は基準HTMLの表現を再利用する |

## グラフがある資料

- 図表の部品は [マスターデータエディタの基本CSS](../../60_tool/05-master-data-editor/src/SkillTreeEditor.Client/src/styles.css) と [マスターデータ用CSS](../../60_tool/05-master-data-editor/src/SkillTreeEditor.Client/src/masterData.css) を参考にします。基準HTMLの配色を使い、左と下の軸に短い目盛りを置きます。
- 1.5〜2pxの線と各観測点の記号を組み合わせます。主系列は実線と丸、比較系列は破線とひし形。単位を軸に、系列名を図の直前に表示します。
- 比較する系列は最初から同じ図に重ね、率と実数など尺度が違う図は並べて表示します。各図の上の凡例にカーソルまたはキーボードフォーカスを合わせると他の線が薄くなり、離すと元の表示に戻ります。タップで固定、再タップで解除します。同じ数値の系列をまとめるときは対象を明記します。
- [DPS指標](01-DPS指標.html) に総DPSの目標・育成上限・測定条件、[ステータス指標](02-ステータス指標.html) にプレイヤーと標準モブのステータスを記載します。設計目標・現行値・仮案を区別し、各指標の正本を相互リンクで参照します。
- 主要な軸ラベルに対応する点は、同じ大きさと強調方法で揃えます。DPS指標ではLv.75も主要点として表示します。
- 吹き出しにはカーソル・タップ位置の線の名前、レベル、値を1項目だけ表示します。線が重なる場合は凡例で固定した系列を優先します。キーボードでも選べるようにし、吹き出しを図の中に収めます。

## 表示と確認

- 単一ファイルをブラウザで直接開いて利用できる構成を基本にし、外部CDNやWebフォントに依存しません。
- 760px前後で段組みを縦に切り替え、320px幅でもページ全体が横にはみ出さないようにします。幅が必要な表は、表の領域だけを横スクロールさせます。
- 入力にはラベル、図表には説明を付け、キーボード操作時のフォーカスを見える状態にします。色に加えて線種・文字・凡例でも情報を区別します。
- 印刷時は操作部品を隠し、条件・計算方法・数値表などの折りたたみ内容も読めるようにします。
- HTMLを変更したら、PC・スマホ幅で実際にブラウザ表示を確認し、OSのライト・ダーク設定のどちらでもエディタと同じダーク配色になることを確認します。図表や操作がある場合は、主要点、実数のツールチップ、タップ・キーボード操作も確認します。
