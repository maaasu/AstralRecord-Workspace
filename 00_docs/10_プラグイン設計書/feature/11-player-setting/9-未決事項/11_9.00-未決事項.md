# 11_9.00-未決事項

## 1. ダメージログの粒度

- 現状: `DAMAGE_LOG_DISPLAY` は ON/OFF の 2 値。
- 未決: 「与ダメージのみ表示」「被ダメージのみ表示」のような粒度分割を行うかどうか。
- 影響: 値型を `Boolean` から専用 enum に変更する必要がある。

## 2. ドロップログの対象範囲

- 現状: `DROP_LOG_DISPLAY` は Mob のレアドロップ全体通知を受信するかを切り替える ON/OFF の 2 値。通常 Mob は `0.1%以下`、ボスは `5%以下` を通知対象とする。
- 決定済み: 通知対象は自分・パーティーに限定せず、設定が ON の全オンラインプレイヤーとする。
- 未決: 通知対象範囲を将来さらに細分化するか。

## 3. パーティクル密度の表示倍率の最終値

- 現状: 6 段階の表示倍率を `0.0 / 0.25 / 0.5 / 1.0 / 1.5 / 2.0` で仮置きしている。
- 未決: 実機調整で適切な係数が変わる可能性がある。
- 影響: [[11_1.00-モデル定義]].パーティクル密度 の `表示倍率` 列のみ更新。enum 構成自体は変更不要の想定。

## 4. 設定変更の権限制御

- 現状: 設定変更は本人（オンラインの操作プレイヤー）からのみ可能とする想定。
- 未決: 管理者が他プレイヤーの設定を変更する運用ユースケースがあるか。
- 影響: コマンド引数規約と権限チェックを追加する必要がある。

## 5. GUI からの「既定値に戻す」操作

- 現状: GUI には個別キーの値循環のみを実装する想定。
- 未決: 「全設定を既定値に戻す」アクションスロットを設けるかどうか。
- 影響: [[11_3.07-GUI・View]] のレイアウトおよび [[11_3.02-サービス]] への新規メソッド追加。
