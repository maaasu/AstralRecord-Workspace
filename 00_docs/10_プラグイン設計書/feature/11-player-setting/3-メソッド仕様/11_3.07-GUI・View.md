# 11_3.07-GUI・View

クラス名: `PlayerSettingGui`
物理名: `open`

## 1. GUI レイアウト

クラス: `PlayerSettingGui`

| スロット | 設定キー | 内容 |
|---:|---|---|
| `11` | `DAMAGE_LOG_DISPLAY` | ダメージログ表示の ON / OFF |
| `13` | `PARTICLE_DENSITY` | パーティクル密度 |
| `15` | `DROP_LOG_DISPLAY` | ドロップログ表示の ON / OFF |
| `18` | 戻る | 前画面へ戻る |
| `26` | 閉じる | GUI を閉じる |

## 2. 操作

- `open`: 現在設定を読み込んで GUI を表示する。
- `onSlotClick`: 対象設定を更新し、表示を再描画する。
- `onClose`: 必要な保存処理を行う。

Boolean 設定は共通表示規則で ON / OFF を示し、個別 GUI に重複した保存ロジックを置きません。失敗時は既存 `LogId` とプレイヤーメッセージ経路を使用します。
