# 11_3.07-GUI・View

## 1. GUI レイアウト

物理名: `PlayerSettingGui`

チェスト型 GUI（27 スロット / 3 行）で構成する。  
各設定キーに 1 スロットを割り当て、クリックで値を循環させる。

| スロット | 設定キー | 表示内容 |
|---:|---|---|
| `11` | `DAMAGE_LOG_DISPLAY` | アイテム: 紙、`ON`/`OFF` を Lore に表示 |
| `13` | `PARTICLE_DENSITY` | アイテム: 花火の星、現在の [[11_1.00-モデル定義]].パーティクル密度 を Lore に表示 |
| `15` | `DROP_LOG_DISPLAY` | アイテム: チェスト、`ON`/`OFF` を Lore に表示 |
| `26` | （閉じる） | アイテム: バリア、クリックで GUI を閉じる |
| 上記以外 | （装飾） | アイテム: 黒色のステンドガラスペーン |

## 2. view メソッド仕様

### プレイヤー設定 GUI

クラス名: `PlayerSettingGui`  
物理名: `open`

処理内容:

1. [[03_3.04-キャッシュ]].プレイヤーキャッシュ取得 で [[03_1.00-モデル定義]].プレイヤーセッション を取得し、所属ユーザー UUID を解決する
2. [[11_3.04-キャッシュ]].プレイヤー設定キャッシュ取得 でスナップショットを取得する
3. スナップショットが存在しない場合は [[11_1.00-モデル定義]].プレイヤー設定既定値 のみで仮表示する
4. GUI のスロットを「1. GUI レイアウト」のとおり構築し、プレイヤーに開く

### スロットクリック処理

クラス名: `PlayerSettingGui`  
物理名: `onSlotClick`

処理内容:

1. クリックされたスロットから対応する [[11_1.00-モデル定義]].プレイヤー設定キー を解決する
2. `Boolean` 型のキーは現在値を反転して新しい値とする
3. 列挙型のキーは現在値の次の enum 定数を新しい値とする（最後の値の次は最初の値に戻す）
4. [[11_1.00-モデル定義]].プレイヤー設定変更要求 を組み立てる
5. [[11_3.02-サービス]].プレイヤー設定更新 を呼び出す
6. 更新成功後、該当スロットを再描画する

### GUI 閉鎖処理

クラス名: `PlayerSettingGui`  
物理名: `onClose`

処理内容:

1. プレイヤーが GUI を閉じた際の追加保存は行わない（変更時点で API に保存済みのため）
2. 開閉ログ用途で必要な場合のみ `LogId` 経由で記録する（必要時のみ）
