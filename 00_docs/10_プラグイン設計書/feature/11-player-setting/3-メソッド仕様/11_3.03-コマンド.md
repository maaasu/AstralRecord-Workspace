# 11_3.03-コマンド

## 1. command メソッド仕様

### 設定一覧コマンド

クラス名: `PlayerSettingCommand`  
物理名: `executeList`

コマンド形式: `/setting`

処理内容:

1. 実行者が `Player` であることを確認する。コンソール実行の場合は `PlayerMsgId.P_5305` を返す
2. [[03_3.04-キャッシュ]].プレイヤーキャッシュ取得 で [[03_1.00-モデル定義]].プレイヤーセッション を取得し、所属ユーザー UUID を解決する
3. [[11_3.04-キャッシュ]].プレイヤー設定キャッシュ取得 でスナップショットを取得する
4. [[11_1.00-モデル定義]].プレイヤー設定キー の全項目について、現在値（または既定値）を表示する

	| 項目 | 内容 |
	|---|---|
	| ID | `PlayerSettingMsgId.P_5322` |
	| レベル | - |
	| テンプレート | `現在の設定: %s = %s` |
	| 出力条件 | 一覧表示時、設定キーごとに 1 行 |
	| 引数 | 設定キー論理名, 値の表示文字列 |

### 設定変更コマンド

クラス名: `PlayerSettingCommand`  
物理名: `executeSet`

コマンド形式: `/setting <key> <value>`

処理内容:

1. 実行者が `Player` であることを確認する。コンソール実行の場合は `PlayerMsgId.P_5305` を返す
2. `<key>` を [[11_1.00-モデル定義]].プレイヤー設定キー のコードまたは番号として解釈する
	- 解釈失敗時は `PlayerSettingMsgId.P_5323` を返す

	| 項目 | 内容 |
	|---|---|
	| ID | `PlayerSettingMsgId.P_5323` |
	| レベル | - |
	| テンプレート | `不明な設定キーです: %s` |
	| 出力条件 | `<key>` を [[11_1.00-モデル定義]].プレイヤー設定キー に解決できない |
	| 引数 | 入力文字列 |

3. `<value>` を `<key>` の `値型` に従って解釈する
	- `Boolean` は `on`/`off`/`true`/`false`、列挙値はコード名で受け取る
	- 解釈失敗時は `PlayerSettingMsgId.P_5324` を返す

	| 項目 | 内容 |
	|---|---|
	| ID | `PlayerSettingMsgId.P_5324` |
	| レベル | - |
	| テンプレート | `設定値が不正です: key=%s, value=%s` |
	| 出力条件 | `<value>` を `値型` に変換できない |
	| 引数 | 設定キー論理名, 入力文字列 |

4. [[11_1.00-モデル定義]].プレイヤー設定変更要求 を組み立てる
5. [[11_3.02-サービス]].プレイヤー設定更新 を呼び出す

### 補完候補取得

クラス名: `PlayerSettingCommand`  
物理名: `tabComplete`

処理内容:

1. 第 1 引数では [[11_1.00-モデル定義]].プレイヤー設定キー のコード一覧を候補とする
2. 第 2 引数では、第 1 引数の `値型` に応じた候補を返す
	- `Boolean`: `on`, `off`
	- 列挙値: [[11_1.00-モデル定義]].パーティクル密度 等のコード一覧

備考: 引数規約は PLUGIN_GUIDE.md の「コマンド引数規約」に従い、設定キー・値ともに名称（英語 ID）の予測変換優先で受け取る。
