# 16_2.00-ユースケース

## 1. 通貨一覧表示

1. menu feature が通貨 GUI を開く。
2. [[16_3.00-メソッド仕様]].通貨表示一覧取得 が account の通貨残高を取得する。
3. item feature の表示ルールを使い、通貨 ItemStack 一覧へ変換する。
4. `gold` は未所持でも `0` 表示に含める。

## 2. Mob 撃破報酬

1. mob feature が撃破処理で金銭報酬を確定する。
2. [[16_3.00-メソッド仕様]].通貨加算 を呼び出す。
3. 加算成功後、必要に応じて対象プレイヤーへ報酬表示を返す。

## 3. メール報酬

1. mail feature が既読化時に報酬通貨を解決する。
2. [[16_3.00-メソッド仕様]].通貨加算 を呼び出す。
3. 同一メールを二重に既読処理しないよう、mail feature 側の既読状態を正本とする。

## 4. ショップ購入

1. shop feature が購入価格を検証する。
2. [[16_3.00-メソッド仕様]].通貨減算 を呼び出す。
3. 減算成功後に shop feature が商品付与を行う。
