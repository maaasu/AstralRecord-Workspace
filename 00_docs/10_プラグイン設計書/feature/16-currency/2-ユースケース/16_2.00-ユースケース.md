# 16_2.00-ユースケース

## 1. 通貨一覧表示

1. menu feature が通貨 GUI を開く。
2. [[16_3.00-メソッド仕様]].通貨表示一覧取得 が account の通貨残高を取得する。
3. item feature の表示ルールを使い、通貨 ItemStack 一覧へ変換する。
4. `gold` は未所持でも `0` 表示に含める。

## 2. 通貨 GUI からの取り出し

1. プレイヤーが通貨 GUI の通貨 ItemStack をクリックする。
2. 左クリックは 1 個、右クリックは半分（切り上げ）、Shift+左クリックは全量を取り出し数量とする。
3. currency feature が対象通貨を CURRENCY から減算し、inventory feature が通常 BAG へ通貨アイテムを追加する。
4. BAG に空きがない場合は CURRENCY と BAG の変更を行わない。

## 3. 通貨 GUI への収納

1. 通貨 GUI 下部のプレイヤーインベントリにある通貨アイテムをクリックする。
2. 左クリックは 1 個、右クリックは半分（切り上げ）、Shift+左クリックは全量を収納数量とする。
3. inventory feature が通常 BAG／ホットバーから通貨アイテムを取り出し、CURRENCY へ無制限スタックで戻す。

## 4. 通貨アイテムクリックによる GUI 起動

1. 通貨 GUI 以外でプレイヤーインベントリの通貨アイテムをクリックする。
2. 通常のアイテム移動を行わず、通貨 GUI を自動で開く。

## 5. Mob 撃破報酬

1. mob feature が撃破処理で金銭報酬を確定する。
2. [[16_3.00-メソッド仕様]].通貨加算 を呼び出す。
3. 加算成功後、必要に応じて対象プレイヤーへ報酬表示を返す。

## 6. メール報酬

1. mail feature が既読化時に報酬通貨を解決する。
2. [[16_3.00-メソッド仕様]].通貨加算 を呼び出す。
3. 同一メールを二重に既読処理しないよう、mail feature 側の既読状態を正本とする。

## 7. ショップ購入

1. shop feature が購入価格を検証する。
2. [[16_3.00-メソッド仕様]].通貨減算 を呼び出す。
3. 減算成功後に shop feature が商品付与を行う。
