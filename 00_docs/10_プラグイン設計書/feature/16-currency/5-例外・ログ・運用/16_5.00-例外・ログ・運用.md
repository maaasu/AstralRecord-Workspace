# 16_5.00-例外・ログ・運用

## 1. 例外方針

- 残高取得失敗時、GUI 表示は空一覧ではなくエラーとして扱う。
- 加算失敗時、呼び出し元 feature は報酬の再試行可否を自 feature の責務で判断する。
- 減算失敗時、商品付与や消費後処理は行わない。

## 2. 運用上の注意

- 通貨種別を追加する場合は [[16_1.00-モデル定義]].通貨種別 と item feature の通貨カテゴリ表示を同時に更新する。
- Mob 報酬、メール報酬、ショップ支払いは同じ加算・減算経路を使い、feature ごとに残高更新を重複実装しない。
- 残高補正を運用で行う場合は `reason` に補正理由を残す。
