# 08_4.00-統合フロー

## 1. `/inventory` 表示切替フロー（command -> service -> repository -> Bukkit GUI）

1. [[08_3.03-コマンド]].インベントリ切替実行 が引数とアカウントモードを検証する
2. [[08_1.00-モデル定義]].インベントリ種別 から切替可能な種別を解決する
3. [[08_3.02-サービス]].インベントリ GUI 反映 が表示中種別を accountId 単位で更新する
4. 必要に応じて [[08_3.04-リポジトリ]].インベントリ一覧取得 / [[08_3.04-リポジトリ]].インベントリエントリ一覧取得 で API データを取得する
5. [[08_3.05-タスク・補助]].ItemStack 解決 が entry から ItemStack を生成する
6. Bukkit PlayerInventory の管理対象スロットへ反映する
7. プレイヤーへ `PlayerMsgId.P_5253`（インベントリ切替成功メッセージ）を送信する

## 2. アイテム付与フロー（item -> inventory -> menu）

1. item feature が [[08_3.02-サービス]].通常インベントリアイテム追加 を呼び出す
2. inventory feature が item category から格納先種別を解決する
3. 装備・ルーンの場合は個体 ID を作成し、インベントリエントリへ保存する
4. 通常アイテムの場合はスタック加算または空きスロットへ保存する
5. 要求数量の一部または全てが追加できなかった場合、inventory feature が対象プレイヤーへ `PlayerMsgId.P_5241` を送信する
6. 格納先が現在表示中インベントリの場合は GUI を再描画する
7. 通貨カテゴリの場合は menu feature の通貨画面再表示へ接続する

## 3. 装備 GUI フロー（menu -> inventory -> API）

1. menu feature が装備 GUI を開く
2. [[08_3.01-イベント]].装備 GUI クリック が装備スロットクリックを処理する
3. インベントリサービスが配置可否を判定する
4. 装備解除時は所有インベントリへ戻す
5. GUI クローズまたは戻る操作時に [[08_3.02-サービス]].装備 GUI 保存 を呼び出す
6. EQUIP_SLOT / ACCESSORY_SLOT の entry と有効 loadout slot を API へ同期する
7. Bukkit 現在装備状態を更新する

## 4. menu 連携フロー

1. menu feature がクラフト欄または GUI からショートカット操作を受け取る
2. インベントリ切替系アクションは [[08_3.02-サービス]].インベントリ GUI 反映 へ委譲する
3. GUI 表示中は [[08_3.02-サービス]].ホットバーショートカットモード設定 を `on` で呼び、ホットバーをショートカット表示へ切り替える
4. GUI を閉じると [[08_3.02-サービス]].ホットバーショートカットモード設定 を `off` で呼び、通常ホットバー表示へ戻す
