# 08_4.00-統合フロー

## 1. `/inventory` 表示切替フロー（command -> service -> repository -> Bukkit GUI）

1. `InventoryCommand.executePlayerCommand` が引数とアカウントモードを検証する
2. `InventoryType.fromCommandInput` で切替可能な種別を解決する
3. `InventoryService.applyInventoryToGui` が表示中種別を accountId 単位で更新する
4. 必要に応じて `InventoryRepository.findByAccountId` / `findEntries` で API データを取得する
5. `InventoryItemStackResolver` が entry から ItemStack を生成する
6. Bukkit PlayerInventory の管理対象スロットへ反映する
7. プレイヤーへ `PlayerMsgId.P_5253` を送信する

## 2. アイテム付与フロー（item -> inventory -> menu）

1. item feature が `InventoryService.addItemToNormalInventory` を呼び出す
2. inventory feature が item category から格納先種別を解決する
3. 装備・ルーンの場合は個体 ID を作成し、インベントリエントリへ保存する
4. 通常アイテムの場合はスタック加算または空きスロットへ保存する
5. 格納先が現在表示中インベントリの場合は GUI を再描画する
6. 通貨カテゴリの場合は menu feature の通貨画面再表示へ接続する

## 3. 装備 GUI フロー（menu -> inventory -> API）

1. menu feature が装備 GUI を開く
2. `InventoryEquipmentGuiEventHandler` が装備スロットクリックを処理する
3. `InventoryService.canPlaceInEquipmentGuiSlot` で配置可否を判定する
4. 装備解除時は `returnItemToOwnedInventory` で所有インベントリへ戻す
5. GUI クローズまたは戻る操作時に `saveEquipmentGui` を呼び出す
6. EQUIP_SLOT / ACCESSORY_SLOT の entry と有効 loadout slot を API へ同期する
7. `syncCurrentEquipmentState` で Bukkit 装備状態を更新する

## 4. menu 連携フロー

1. menu feature がクラフト欄または GUI からショートカット操作を受け取る
2. インベントリ切替系アクションは `InventoryService.applyInventoryToGui` へ委譲する
3. GUI 表示中は `setHotbarShortcutMode(true)` でホットバーをショートカット表示へ切り替える
4. GUI を閉じると `setHotbarShortcutMode(false)` で通常ホットバー表示へ戻す
