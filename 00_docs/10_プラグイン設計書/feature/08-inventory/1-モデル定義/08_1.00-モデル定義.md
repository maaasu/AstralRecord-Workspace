# 08_1.00-モデル定義

## 1. インベントリモデル

物理名: `InventoryModel`

| 項目 | 説明 |
|---|---|
| `inventoryId` | インベントリ UUID |
| `accountId` | 所有アカウント UUID |
| `inventoryType` | [[08_1.00-モデル定義]].インベントリ種別 |
| `inventoryProfile` | [[08_1.00-モデル定義]].インベントリプロファイル のコード |
| `slotCapacity` | スロット上限。無制限または未設定の場合は `null` |
| `isEnabled` | 使用可能フラグ |
| `metadataJson` | スナップショット等の補助 JSON |
| `createdAt`, `updatedAt` | 作成・更新日時 |
| `createdBy`, `updatedBy` | 作成・更新者 UUID |
| `isDeleted` | 論理削除フラグ |

## 2. インベントリエントリモデル

物理名: `InventoryEntryModel`

| 項目 | 説明 |
|---|---|
| `inventoryEntryId` | エントリ UUID |
| `inventoryId` | 所属インベントリ UUID |
| `slotIndex` | スロット番号。未配置の場合は `null` |
| `itemCategory` | アイテムカテゴリ |
| `itemId` | マスタアイテム ID |
| `instanceType` | [[08_1.00-モデル定義]].インベントリ個体種別 のコード |
| `instanceId` | 装備・ルーン等の個体 UUID |
| `quantity` | 数量 |
| `metadataJson` | 追加メタデータ JSON |
| `createdAt`, `updatedAt` | 作成・更新日時 |
| `createdBy`, `updatedBy` | 作成・更新者 UUID |
| `isDeleted` | 論理削除フラグ |

## 3. インベントリ種別

物理名: `InventoryType`

| 物理名 | コード | 論理名 | スロット管理 | 個体管理 | コマンド切替 |
|---|---|---|---|---|---|
| `NORMAL` | `NORMAL` | ノーマル | あり | なし | 可 |
| `CURRENCY` | `CURRENCY` | 通貨 | あり | なし | 不可 |
| `EQUIPMENT` | `EQUIPMENT` | 装備 | あり | あり | 可 |
| `RUNE` | `RUNE` | ルーン | あり | あり | 可 |
| `EQUIP_SLOT` | `EQUIP_SLOT` | 装備スロット | あり | あり | 不可 |
| `HOTBAR` | `HOTBAR` | ホットバー | あり | なし | 不可 |
| `ACCESSORY_SLOT` | `ACCESSORY_SLOT` | アクセサリスロット | あり | あり | 不可 |

`/inventory` の入力では `NORMAL`, `EQUIPMENT`, `RUNE` のみ切り替え対象にする。

## 4. 装備種別

物理名: `EquipmentType`

| 物理名 | 用途 |
|---|---|
| `MAIN_HAND` | メインハンド |
| `HEAD` | 頭装備 |
| `CHEST` | 胴装備 |
| `LEGS` | 脚装備 |
| `FEET` | 足装備 |
| `OFF_HAND` | オフハンド |
| `UNSUPPORTED` | ItemStack や slot_index から装備種別を解決できなかった場合のフォールバック値。`applyTo` は何もせず、保存・反映処理ではこの値を持つ要素を読み飛ばす |

## 5. アクセサリスロット種別

物理名: `AccessorySlotType`

`ACCESSORY_SLOT` インベントリの slot_index 2〜7 を表す拡張アクセサリ種別。slot_index 1（オフハンド）は本種別に含めず、[[08_1.00-モデル定義]].装備種別 の `OFF_HAND` で表現する。
本種別の全スロットは Bukkit 装備欄ではなく、アクセサリ専用 GUI から表示・編集する。

| 物理名 | slotIndex | 論理名 |
|---|---:|---|
| `NECKLACE` | 2 | 首飾り |
| `RING` | 3 | 指輪 |
| `EARRING` | 4 | 耳飾り |
| `BRACELET` | 5 | 腕輪 |
| `BELT` | 6 | ベルト |
| `CHARM` | 7 | 護符 |

## 5.1 インベントリ個体種別

物理名: `InventoryInstanceType`

| 物理名 | コード | 論理名 | 用途 |
|---|---|---|---|
| `EQUIPMENT` | `EQUIPMENT` | 装備個体 | 装備個体 UUID を `instanceId` に持つエントリで使用 |
| `RUNE` | `RUNE` | ルーン個体 | ルーン個体 UUID を `instanceId` に持つエントリで使用 |

通常のスタック可能アイテムなど個体管理が不要なエントリでは `instanceType` を `null` とする。

## 5.2 インベントリプロファイル

物理名: `InventoryProfile`

| 物理名 | コード | 論理名 | 用途 |
|---|---|---|---|
| `GAME` | `GAME` | ゲームプロファイル | 通常プレイ用インベントリ |
| `BUILDER` | `BUILDER` | ビルダープロファイル | ビルダーモード切替時に保持する別系統インベントリ |

`ensureInventory` は accountId / inventoryType / profile の 3 項で照合する。

## 5.2.1 クリック種別

物理名: `InventoryClickGuard.ClickAction`

[[08_3.02-サービス]].クリッククールタイム で accountId と組み合わせてクールタイムを管理するキー。

| 物理名 | 用途 |
|---|---|
| `HOTBAR_SLOT` | ホットバースロット・オフハンドスロットの直接クリック |
| `HOTBAR_SHORTCUT` | GUI 表示中のホットバーショートカットアイコンクリック |
| `ARMOR_SLOT` | Bukkit 防具スロットのクリック |
| `DISPLAYED_ITEM` | 表示中インベントリ内のアイテムクリック・装備 GUI のプレイヤーインベントリ欄クリック |
| `EQUIPMENT_GUI_SLOT` | 装備 GUI の各装備スロットクリック |
| `INVENTORY_SWITCH` | クラフトショートカット等による表示インベントリ種別切替 |

既定クールタイムは 100ms。種別ごとに必要なら個別指定する。

## 5.3 インベントリエントリ下書き

物理名: `InventoryEntryDraft`

リポジトリ登録・更新・一括置換のリクエスト body を組み立てるためのデータ。

| 項目 | 型 | 必須 | 説明 |
|---|---|---|---|
| `slotIndex` | int? | 任意 | スロット番号。未配置は `null` |
| `itemCategory` | string | 必須 | アイテムカテゴリ |
| `itemId` | string? | 任意 | マスタアイテム ID |
| `instanceType` | string? | 任意 | [[08_1.00-モデル定義]].インベントリ個体種別 のコード |
| `instanceId` | UUID? | 任意 | 装備・ルーン等の個体 UUID |
| `quantity` | long | 必須 | 数量（既定 1） |
| `metadataJson` | string? | 任意 | 追加メタデータ JSON |

## 7. 装備プリセットスロットモデル

物理名: `EquipmentLoadoutSlotModel`

| 項目 | 説明 |
|---|---|
| `equipmentLoadoutId` | 所属プリセット UUID |
| `equipmentLoadoutSlotId` | プリセットスロット UUID |
| `slotType` | スロット種別。`HEAD` / `CHEST` / `LEGS` / `FEET` / `ACCESSORY` の文字列コード |
| `slotIndex` | スロット番号。`HEAD` / `CHEST` / `LEGS` / `FEET` は `0` 固定。`ACCESSORY` は [[08_1.00-モデル定義]].装備種別 `OFF_HAND` を `0`、[[08_1.00-モデル定義]].アクセサリスロット種別 を slotIndex（2〜7）で表現 |
| `equipmentInstanceId` | 装備インスタンス UUID |

## 8. 関連 feature とのモデル関係

- `item`: `itemId`、`itemCategory`、装備・ルーン個体 ID を参照し、ItemStack 生成に利用する。
- `account`: accountId とアカウントモードを表示反映条件として扱う。
- `menu`: インベントリ種別選択、装備 GUI、ショートカット表示の操作点を提供する。
