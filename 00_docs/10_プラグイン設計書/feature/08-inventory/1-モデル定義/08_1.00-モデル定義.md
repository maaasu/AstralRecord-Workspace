# 08_1.00-モデル定義

## 1. インベントリモデル

物理名: `InventoryModel`

| 項目 | 説明 |
|---|---|
| `inventoryId` | インベントリ UUID |
| `accountId` | 所有アカウント UUID |
| `inventoryType` | [[08_1.00-モデル定義]].インベントリ種別 |
| `inventoryProfile` | [[08_1.00-モデル定義]].インベントリプロファイル のコード |
| `slotCapacity` | スロット上限。無制限または未設定の場合は `null` |
| `isEnabled` | 使用可能フラグ |
| `metadataJson` | スナップショット等の補助 JSON |
| `createdAt`, `updatedAt` | 作成・更新日時 |
| `createdBy`, `updatedBy` | 作成・更新者 UUID |
| `isDeleted` | 論理削除フラグ |

## 2. インベントリエントリモデル

物理名: `InventoryEntryModel`

| 項目 | 説明 |
|---|---|
| `inventoryEntryId` | エントリ UUID |
| `inventoryId` | 所属インベントリ UUID |
| `slotIndex` | スロット番号。未配置の場合は `null` |
| `itemCategory` | アイテムカテゴリ |
| `itemId` | マスタアイテム ID |
| `instanceType` | [[08_1.00-モデル定義]].インベントリ個体種別 のコード |
| `instanceId` | 装備・ルーン等の個体 UUID |
| `quantity` | 数量 |
| `metadataJson` | 追加メタデータ JSON |
| `createdAt`, `updatedAt` | 作成・更新日時 |
| `createdBy`, `updatedBy` | 作成・更新者 UUID |
| `isDeleted` | 論理削除フラグ |

## 3. インベントリ種別

物理名: `InventoryType`

| 物理名 | コード | 論理名 | スロット管理 | 個体管理 | コマンド切替 |
|---|---|---|---|---|---|
| `NORMAL` | `NORMAL` | ノーマル | あり | なし | 可 |
| `CURRENCY` | `CURRENCY` | 通貨 | あり | なし | 不可 |
| `EQUIPMENT` | `EQUIPMENT` | 装備 | あり | あり | 可 |
| `RUNE` | `RUNE` | ルーン | あり | あり | 可 |
| `EQUIP_SLOT` | `EQUIP_SLOT` | 装備スロット | あり | あり | 不可 |
| `HOTBAR` | `HOTBAR` | ホットバー | あり | なし | 不可 |
| `ACCESSORY_SLOT` | `ACCESSORY_SLOT` | アクセサリスロット | あり | あり | 不可 |

`/inventory` の入力では `NORMAL`, `EQUIPMENT`, `RUNE` のみ切り替え対象にする。

## 4. 装備種別

物理名: `EquipmentType`

| 物理名 | 用途 |
|---|---|
| `MAIN_HAND` | メインハンド |
| `HEAD` | 頭装備 |
| `CHEST` | 胴装備 |
| `LEGS` | 脚装備 |
| `FEET` | 足装備 |
| `OFF_HAND` | オフハンド、アクセサリ 1 番 |
| `UNSUPPORTED` | 対応外 |

## 5. アクセサリスロット種別

物理名: `AccessorySlotType`

| 物理名 | slotIndex | 論理名 |
|---|---:|---|
| `OFF_HAND` | 1 | オフハンド |
| `NECKLACE` | 2 | 首飾り |
| `RING` | 3 | 指輪 |
| `EARRING` | 4 | 耳飾り |
| `BRACELET` | 5 | 腕輪 |
| `BELT` | 6 | ベルト |
| `CHARM` | 7 | 護符 |

## 6. 装備プリセットモデル

物理名: `EquipmentLoadoutModel`

| 項目 | 説明 |
|---|---|
| `equipmentLoadoutId` | 装備プリセット UUID |
| `accountId` | 所有アカウント UUID |
| `loadoutProfile` | プリセットプロファイル |
| `loadoutName` | 表示名 |
| `sortOrder` | 並び順 |
| `isActive` | 現在有効なプリセットか |
| `metadataJson` | 追加メタデータ JSON |
| `slots` | [[08_1.00-モデル定義]].装備プリセットスロットモデル一覧 |
| `createdAt`, `updatedAt` | 作成・更新日時 |
| `createdBy`, `updatedBy` | 作成・更新者 UUID |
| `isDeleted` | 論理削除フラグ |

## 7. 装備プリセットスロットモデル

物理名: `EquipmentLoadoutSlotModel`

| 項目 | 説明 |
|---|---|
| `equipmentLoadoutSlotId` | プリセットスロット UUID |
| `equipmentLoadoutId` | 所属プリセット UUID |
| `slotType` | スロット種別 |
| `slotIndex` | スロット番号 |
| `equipmentInstanceId` | 装備インスタンス UUID |

## 8. 関連 feature とのモデル関係

- `item`: `itemId`、`itemCategory`、装備・ルーン個体 ID を参照し、ItemStack 生成に利用する。
- `account`: accountId とアカウントモードを表示反映条件として扱う。
- `menu`: インベントリ種別選択、装備 GUI、ショートカット表示の操作点を提供する。
