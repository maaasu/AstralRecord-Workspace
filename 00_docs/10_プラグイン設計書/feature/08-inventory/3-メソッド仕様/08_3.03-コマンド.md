# 08_3.03-コマンド

## 1. インベントリ切替実行

クラス名: `InventoryCommand`
物理名: `executePlayerCommand`

責務:

`/inventory <type>` で表示中インベントリを切り替える。

処理内容:

1. 引数が 1 個未満なら usage を返す
2. アカウントモードが GUI インベントリ反映対象外なら以下メッセージを送信して終了する

    | 項目 | 内容 |
    |---|---|
    | ID | PlayerMsgId.P_5250 |
    | テンプレート | 現在の mode では AstralRecord インベントリを反映しません。 |
    | 出力条件 | アカウントモードが GUI 反映対象外 |
    | 引数 | なし |

3. 第1引数から [[08_1.00-モデル定義]].インベントリ種別 を解決する
4. 解決できない場合は以下メッセージを送信して終了する

    | 項目 | 内容 |
    |---|---|
    | ID | PlayerMsgId.P_5251 |
    | テンプレート | 無効なインベントリタイプです。指定可能: {0} |
    | 出力条件 | 第1引数が切替可能種別に解決できない |
    | 引数 | 切替可能種別の一覧 |

5. `InventoryService` が未初期化なら以下メッセージを送信して終了する

    | 項目 | 内容 |
    |---|---|
    | ID | PlayerMsgId.P_5252 |
    | テンプレート | InventoryService が初期化されていません。 |
    | 出力条件 | サービス未初期化 |
    | 引数 | なし |

6. [[08_3.02-サービス]].インベントリ GUI 反映 を呼び出す
7. 以下メッセージを送信して成功を通知する

    | 項目 | 内容 |
    |---|---|
    | ID | PlayerMsgId.P_5253 |
    | テンプレート | インベントリを切り替えました: {0} |
    | 出力条件 | 表示インベントリ切替成功 |
    | 引数 | 切替後のインベントリ種別 |

## 2. インベントリ補完候補取得

クラス名: `InventoryTabCompleter`
物理名: `getPlayerCompletions`

責務:

`/inventory` 第1引数の補完候補を返す。

処理内容:

1. args.length が 1 の場合、`InventoryType.commandSwitchableEntries()` を返す
2. 各候補は enum 名を小文字化する
3. それ以外の位置では空リストを返す

## 3. コマンド仕様

- ルート: `/inventory`
- 形式: `/inventory <type>`
- 指定可能 type: `normal`, `equipment`, `rune`
- コンソール実行: 不可（`isPlayerOnly = true`）
