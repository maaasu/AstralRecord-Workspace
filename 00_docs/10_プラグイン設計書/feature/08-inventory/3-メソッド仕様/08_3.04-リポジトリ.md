# 08_3.04-リポジトリ

## 1. インベントリ一覧取得

クラス名: `InventoryRepository`
物理名: `findByAccountId`

責務:

accountId に紐づくインベントリ一覧を API から取得する。

処理内容:

1. `GET /api/inventory?account_id={accountId}` を送信する
2. `200` は JSON 配列を [[08_1.00-モデル定義]].インベントリモデル一覧へ変換する
3. `404` / `500` は空リストとして扱う
4. その他ステータスは `IOException` を送出する

## 2. インベントリ作成

クラス名: `InventoryRepository`
物理名: `create`

責務:

指定 accountId / inventoryType / profile のインベントリ本体を API に作成する。

処理内容:

1. `POST /api/inventory` へ JSON body を送信する
2. body には `accountId`, `inventoryType`, `inventoryProfile`, `slotCapacity`, `isEnabled`, `metadataJson`, `createdBy` を含める
3. 成功レスポンスを [[08_1.00-モデル定義]].インベントリモデルへ変換して返す

## 3. インベントリエントリ作成・更新・削除

クラス名: `InventoryRepository`
物理名: `createEntry`, `updateEntry`, `deleteEntry`

責務:

インベントリエントリの作成、更新、削除を API へ伝搬する。

処理内容:

1. 作成は `POST /api/inventory/{inventoryId}/entries` を送信する
2. 更新は `PUT /api/inventory/entries/{inventoryEntryId}` を送信する
3. 削除は `DELETE /api/inventory/entries/{inventoryEntryId}?updated_by={updatedBy}` を送信する
4. 作成・更新の body は [[08_1.00-モデル定義]].インベントリエントリ下書き から組み立てる

## 4. 装備プリセット操作

クラス名: `EquipmentLoadoutRepository`
物理名: `findByAccountId`, `create`, `activate`, `upsertSlot`, `deleteSlot`

責務:

装備プリセット本体とスロット割当を API へ同期する。

処理内容:

1. 一覧は `GET /api/equipment/loadouts?account_id={accountId}&loadout_profile={profile}` を送信する
2. 作成は `POST /api/equipment/loadouts` を送信する
3. 有効化は `POST /api/equipment/loadouts/{loadoutId}/activate` を送信する
4. slot upsert は `PUT /api/equipment/loadouts/{loadoutId}/slots` を送信する
5. slot delete は `DELETE /api/equipment/loadouts/{loadoutId}/slots/{slotType}/{slotIndex}?updated_by={updatedBy}` を送信する
