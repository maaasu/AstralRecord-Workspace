# 08_3.05-タスク・補助

## 1. インベントリ保存

クラス名: `InventorySaveTask`
物理名: `save`

責務:

player feature の保存トリガーから、通常・装備・アクセサリ・ホットバーの 4 種スナップショットを順に保存する。

処理内容:

1. アカウントモードが `BUILDER` の場合は [[08_3.02-サービス]].ビルダーインベントリスナップショット保存 を呼び出して終了する
2. それ以外で GUI 反映対象モードでない場合は終了する
3. [[08_3.02-サービス]].装備スロットスナップショット保存 を呼び出す
4. [[08_3.02-サービス]].ホットバースナップショット保存 を呼び出す
5. [[08_3.02-サービス]].アクセサリスロットスナップショット保存 を呼び出す
6. 現在装備状態を装備プリセットへ同期する
7. 各メソッドは try/catch を設けず、例外は呼び出し元の `PlayerSaveTask` 基盤へ伝播させる。後続スナップショットの実行可否は基盤側の方針に委ねる

## 2. ItemStack 解決

クラス名: `InventoryItemStackResolver`
物理名: `resolve`

責務:

[[08_1.00-モデル定義]].インベントリエントリモデル から Bukkit ItemStack を生成する。

処理内容:

1. entry の itemId から item feature のロード済みモデルを取得する
2. instanceType が `EQUIPMENT` の場合は装備インスタンス付き ItemStack を生成する
3. instanceType が `RUNE` の場合はルーンインスタンス付き ItemStack を生成する
4. それ以外は数量を max stack size に丸めて通常 ItemStack を生成する
5. モデル未解決の場合は `null` を返す

## 3. スナップショットエンコード・デコード

クラス名: `InventorySnapshotCodec`
物理名: `encode`, `decode`

責務:

Bukkit ItemStack 配列と metadataJson 保存用文字列を相互変換する。

処理内容:

1. encode は ItemStack 配列を BukkitObjectOutputStream でシリアライズし Base64 文字列として JSON へ格納する
2. decode は JSON から contents 文字列を取り出し、Base64 + BukkitObjectInputStream で ItemStack 配列を復元する
3. 新形式に失敗した場合は legacy contents の復元を試みる
4. 復元不可の場合は `null` を返す
