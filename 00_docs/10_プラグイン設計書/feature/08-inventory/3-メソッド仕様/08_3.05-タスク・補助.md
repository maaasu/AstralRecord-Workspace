# 08_3.05-タスク・補助

## 1. インベントリ保存

クラス名: `InventorySaveTask`  
対象メソッド: `save`

説明

player feature の保存トリガから Bukkit 側の最新状態を `PlayerInventoryState` に取り込み、その state を API へ反映する。

処理手順:

1. `PlayerInventoryStateRegistry` から accountId の state を取得する。未登録なら何もしない
2. アカウントモードが `BUILDER` の場合は [[08_3.02-サービス]].ビルダーインベントリスナップショット保存 を呼ぶ
3. それ以外で GUI 反映対象モードの場合は [[08_3.02-サービス]].装備スロットスナップショット保存 / ホットバースナップショット保存 / アクセサリスロットスナップショット保存 / 現在装備同期 を行う
4. `InventoryPersistence.save(state, trigger)` を 1 回呼ぶ

## 2. インベントリオートセーブ

クラス名: `InventoryAutoSaveTask`  
対象メソッド: `start`, `runSaveAll`, `stop`

説明

online プレイヤーの dirty state を 60 秒間隔で保存する。

処理手順:

1. plugin 起動時に async timer を開始する
2. `PlayerInventoryStateRegistry.all()` で online 全 state を走査する
3. 各 state に対して `InventoryPersistence.save(state, AUTO)` を呼ぶ
4. 保存失敗時は `LogId.W_5252` を WARN 出力し、他プレイヤーの保存を継続する
5. plugin disable 時は timer を停止する

## 3. ItemStack 変換

クラス名: `InventoryItemStackResolver`  
対象メソッド: `resolve`

説明

[[08_1.00-モデル定義]].インベントリエントリモデル から Bukkit `ItemStack` を復元する。

処理手順:

1. entry の `itemId` から item feature の `ItemModel` を取得する
2. `instanceType=EQUIPMENT` の場合は装備インスタンス付き `ItemStack` を生成する
3. `instanceType=RUNE` の場合はルーンインスタンス付き `ItemStack` を生成する
4. 通常アイテムは数量を `maxStack` に収めて生成する
5. モデル解決不能時は `null` を返す

## 4. スナップショットエンコード・デコード

クラス名: `InventorySnapshotCodec`  
対象メソッド: `encode`, `decode`

説明

Bukkit `ItemStack[]` と `metadataJson` の相互変換を行う。

処理手順:

1. `encode` は `ItemStack[]` を `BukkitObjectOutputStream` で Base64 化し JSON へ格納する
2. `decode` は JSON から contents 配列を取り出し、Base64 + `BukkitObjectInputStream` で `ItemStack[]` を復元する
3. 新形式に失敗した場合は legacy contents の復元を試みる
4. 復元不能時は `null` を返す

## 5. 永続化制御

クラス名: `InventoryPersistence`  
対象メソッド: `load`, `save`, `saveNow`, `clearAccount`

説明

join 時ロードと dirty state 永続化を担う。

処理手順:

1. `load(accountId)` は inventory 一覧、各 inventory entry、equipment loadout を API から取得して `PlayerInventoryState` を構築する
2. `save(state, trigger)` は `dirty` が立っている場合だけ保存する
3. inventory は inventoryId 単位で `replaceEntries` を呼ぶ
4. loadout は前回保存スナップショットとの差分比較で changed slot だけ `upsertSlot` / `deleteSlot` を呼ぶ
5. 保存失敗時は WARN を出し、`state.restoreDirty()` で次回 save 対象へ戻す
6. `saveNow(state)` は即時整合性が必要な処理向けで、`dirty` を立てたうえで通常 save を流用する
