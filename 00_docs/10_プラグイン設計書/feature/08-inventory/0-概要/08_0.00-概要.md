# 08_0.00-概要

## 1. 目的

`inventory` 機能は、アカウントに紐づくゲーム内インベントリ、装備スロット、アクセサリスロット、ホットバー表示を管理する。

主目的は以下。

- API 管理のインベントリ本体・エントリを取得、作成、更新、削除する
- プレイヤーの GUI インベントリへ表示対象インベントリを反映する
- アイテム付与、装備、ホットバー割当、アクセサリ割当を扱う
- 装備プリセットを読み書きし、現在装備状態へ同期する
- player feature の保存契機から通常インベントリ・装備・ホットバー状態を保存する

## 2. コンテキスト

- 永続データは AstralRecord API の inventory / equipment loadout エンドポイントを通じて操作する。
- 表示対象は [[02_1.00-モデル定義]].アカウントモード が通常プレイヤーの場合のみ GUI に反映する。
- 表示アイテム生成は item feature の ItemStack 生成処理へ委譲する。
- menu feature からインベントリ選択・装備 GUI・ホットバーショートカットを起動される。

## 3. 構成要素（実装単位）

- `command/InventoryCommand`, `InventoryTabCompleter`
  - `/inventory <type>` による表示インベントリ切り替えと補完候補を提供する。
- `event/InventoryEquipmentGuiEventHandler`
  - 装備 GUI とプレイヤーインベントリ上のクリック・クローズを処理する。
- `service/InventoryService`
  - API 連携、キャッシュ、表示反映、保存、装備・ホットバー操作を制御する。
- `service/InventorySaveTask`
  - player feature の保存タスクから通常インベントリを保存する。
- `repository/InventoryRepository`, `EquipmentLoadoutRepository`
  - API エンドポイントとの通信と JSON 変換を担当する。
