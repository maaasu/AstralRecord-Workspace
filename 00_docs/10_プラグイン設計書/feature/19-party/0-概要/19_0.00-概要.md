# 19_0.00-概要

## 1. 目的

`party` feature は、プレイヤー同士のパーティー作成、招待、参加、離脱、解散、GUI 表示、パーティーチャットを管理する。

## 2. コンテキスト

- menu feature はパーティー GUI を開く導線を持つが、メンバー状態の正本は本 feature とする。
- パーティーリーダーはメンバー昇格・キックを行える。
- Mob 撃破時の報酬対象判定は、本 feature のメンバー情報を参照する。
- パーティーチャットは `PlayerMessageService` 経由で配信し、共通メッセージ管理配下のチャットとして扱う。

## 3. 構成要素（実装単位）

- `service/PartyService`
  - パーティー状態、招待、参加、離脱、解散を管理する。
- `gui/PartyGui`
  - パーティー GUI、メンバー一覧、招待一覧を表示する。
- `command/PartyCommand`
  - `/party` 系コマンドを受け付ける。`/party chat <message>` を含む。
- `model/Party`, `PartyMember`, `PartyInvite`
  - パーティー状態と招待状態を表す。

## 追記（2026-06-24）account mode によるパーティー導線制限

- party feature は通常プレイ導線として扱い、作成、招待、参加、脱退、解散、追放、リーダー移譲、GUI 操作は `AccountMode.PLAYER` のみ処理する。
- `AccountMode.ADMIN` / `AccountMode.BUILDER` のプレイヤーはパーティー状態へ参加させず、GUI 操作は cancel して閉じる。
- ログアウトや session cleanup など、既存状態を解消する処理は account mode に関係なく実行できる。
