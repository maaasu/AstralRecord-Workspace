# 19_1.00-モデル定義

## 1. パーティー

物理名: `Party`

| 項目 | 説明 |
|---|---|
| `partyId` | パーティー UUID |
| `leaderUuid` | リーダーのプレイヤー UUID |
| `members` | [[19_1.00-モデル定義]].パーティーメンバー の一覧 |
| `createdAt` | 作成日時 |

## 2. パーティーメンバー

物理名: `PartyMember`

| 項目 | 説明 |
|---|---|
| `playerUuid` | メンバー UUID |
| `joinedAt` | 参加日時 |
| `online` | オンライン状態 |

## 3. パーティー招待

物理名: `PartyInvite`

| 項目 | 説明 |
|---|---|
| `partyId` | 招待元パーティー UUID |
| `fromUuid` | 招待者 UUID |
| `toUuid` | 招待先 UUID |
| `expiresAt` | 招待期限 |
