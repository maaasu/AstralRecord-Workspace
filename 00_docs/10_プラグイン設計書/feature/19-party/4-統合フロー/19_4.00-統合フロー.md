# 19_4.00-統合フロー

## 1. GUI 表示フロー

1. menu feature がパーティー GUI を開く。
2. [[19_3.00-メソッド仕様]].パーティー GUI 表示 が現在状態を描画する。
3. slot 49 の戻る操作は menu feature のメインメニューへ戻す。

## 2. 招待フロー

1. 招待者が対象プレイヤーを選ぶ。
2. [[19_3.00-メソッド仕様]].招待承諾 で利用できる招待を作成する。
3. 対象プレイヤーが承諾するとメンバーへ追加する。

## 3. 報酬参照フロー

1. mob feature がとどめプレイヤーを特定する。
2. [[19_3.00-メソッド仕様]].近接パーティーメンバー取得 を呼び出す。
3. mob feature は返却されたメンバーを個別報酬対象へ加える。
