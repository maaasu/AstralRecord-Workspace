# 19_3.00-メソッド仕様

## パーティー作成

クラス名: `PartyService`
物理名: `createParty`

1. プレイヤーが既にパーティー所属中でないことを確認する。
2. プレイヤーをリーダーとしてパーティーを作成する。
3. 作成後の [[19_1.00-モデル定義]].パーティー を返す。

## 招待承諾

クラス名: `PartyService`
物理名: `acceptInvite`

1. 招待が存在し、期限切れでないことを確認する。
2. 対象プレイヤーが未所属であることを確認する。
3. パーティーメンバーへ追加する。
4. 使用済み招待を削除する。

## 近接パーティーメンバー取得

クラス名: `PartyService`
物理名: `findNearbyMembers`

1. 基準プレイヤーの所属パーティーを取得する。
2. オンライン、同一ワールド、指定距離内のメンバーだけを抽出する。
3. 基準プレイヤーを含む重複なしの一覧を返す。

## パーティー GUI 表示

クラス名: `PartyGui`
物理名: `open`

1. 現在の所属状態を取得する。
2. 未所属の場合は作成・招待確認の導線を表示する。
3. 所属中の場合はリーダー、メンバー、招待、離脱・解散操作を表示する。
