# 05_2.00-ユースケース

## 1. プレイヤーへバフを付与する

アクター:

- サーバー（ステータスサービス・将来的に消耗品サービス等）

事前条件:

- 対象 `buffId` が API 側に存在する

主シナリオ:

1. 呼び出し側が [[05_3.02-サービス]].バフ付与 を呼ぶ
2. サービスがキャッシュからバフタイプを取得する
3. 未キャッシュなら [[05_3.04-リポジトリ]].バフ取得 で API から取得し、キャッシュに登録する
4. プレイヤーの期限切れバフを削除する
5. 同一 `buffId` のアクティブバフがあれば削除する
6. 開始時刻・失効時刻（`durationTicks / 20` 秒後）を計算する
7. `AstPlayer.activeBuffs` へ新規 [[05_1.00-モデル定義]].アクティブバフ を追加する

代替シナリオ:

- バフタイプが API から取得できない場合は `false` を返して終了する

事後条件:

- プレイヤーの `activeBuffs` に対象バフが 1 件存在する
- 同一 `buffId` の旧バフは破棄される

## 2. プレイヤーからバフを解除する

アクター:

- サーバー

主シナリオ:

1. 呼び出し側が [[05_3.02-サービス]].バフ解除 を呼ぶ
2. `AstPlayer.activeBuffs` から `buffId` 一致のエントリを削除する

事後条件:

- 対象 `buffId` のアクティブバフが残っていない

## 3. 期限切れバフを掃除する

アクター:

- サーバー（ステータス再計算・補正合算・参照取得）

主シナリオ:

1. 呼び出し側が [[05_3.02-サービス]].期限切れバフ削除 を呼ぶ
2. 現在時刻と各 `ActiveBuff.expiresAt` を比較し、`isExpired` が `true` のエントリを除去する
3. 削除件数を返す

事後条件:

- `activeBuffs` には未失効のエントリのみが残る

## 4. ステータス補正にバフを反映する

アクター:

- `StatusService`

主シナリオ:

1. `StatusService` がステータス再計算時にプレイヤーの期限切れバフ削除を実行する
2. プレイヤーの非バフ補正を計算し、ベース値と合算する
3. [[05_3.02-サービス]].バフ補正合計取得 を呼び、FLAT 補正と SCALAR 補正の合計を取得する
4. SCALAR は手順2の合算結果を基準値として乗算される
5. `StatusType` 別に最終補正値が確定する

事後条件:

- 該当ステータスの補正値にアクティブバフの合計が反映される

## 5. 有効バフ一覧を取得する

アクター:

- サーバー（HUD 表示・コマンド情報表示など）

主シナリオ:

1. 呼び出し側が [[05_3.02-サービス]].有効バフ一覧取得 を呼ぶ
2. 期限切れバフを削除する
3. `activeBuffs` の不変リストコピーを返す

事後条件:

- 呼び出し側は失効済みエントリを含まないバフ一覧を取得する
