# 05_3.04-リポジトリ

## 1. BuffRepository メソッド仕様

### バフ取得

クラス名: `BuffRepository`  
物理名: `findById`

責務:

`buffId` を指定して API からバフ定義を取得する。

処理内容:

1. `buffId` を URL エンコードする
2. `GET /api/buff/{buffId}` を呼ぶ
3. ステータスに応じて以下を返す

	| ステータス | 戻り値 |
	|---|---|
	| `200` | [[05_1.00-モデル定義]].バフタイプ |
	| `404` | `null` |
	| その他 | `IOException("Unexpected status ... for GET ...")` を送出 |

4. `InterruptedException` は `Thread.currentThread().interrupt()` を実行のうえ `RuntimeException` でラップして送出する

入力:

- `buffId`: バフ ID

出力:

- [[05_1.00-モデル定義]].バフタイプ（存在しない場合は `null`）

例外時挙動:

- 200/404 以外のステータスは `IOException` として呼び出し元へ伝播する。

## 2. JSON パース

### バフタイプパース

クラス名: `BuffRepository`（private）  
物理名: `parseBuffType`

処理内容:

1. JSON から `id`, `type`, `name`, `durationTicks`, `isDebuff` を取り出す
2. `displayName` には JSON の `name` を割り当てる
3. `modifiers` 配列は [[05_3.04-リポジトリ]].バフ補正パース で変換する

### バフ補正パース

クラス名: `BuffRepository`（private）  
物理名: `parseModifiers`

処理内容:

1. 配列要素ごとに JSON オブジェクトを取り出す
2. `status` 文字列を `StatusType` へ解決する（解決失敗時はスキップ）
3. `type` を `BuffModifierType.fromApiValue` で解決する（未知値は `FLAT`）
4. `value` を `double` として取得し（未指定は `0.0`）、[[05_1.00-モデル定義]].バフ補正 を生成する

## 3. API エンドポイント一覧

- `GET /api/buff/{buffId}`

## 4. ステータスコード方針

- `GET`:
  - `200`: 正常
  - `404`: `null` 返却（ログ出力なし）
  - その他: 例外化
