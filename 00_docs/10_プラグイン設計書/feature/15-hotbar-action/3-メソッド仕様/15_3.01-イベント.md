# 15 ホットバーアクション メソッド仕様 - イベント

## ホットバーアイテム操作検知

イベント物理名: PlayerInteractEvent
クラス名: HotbarActionEventHandler
物理名: onPlayerInteract

優先度: EventPriority.LOWEST（ItemInteractionBlockEventHandler の HIGHEST キャンセル前に先行処理）

1. オフハンド操作は除外する
   - `event.getHand() != EquipmentSlot.HAND` の場合はリターン
2. PHYSICAL アクションは除外する
3. AstPlayerCache からプレイヤーを取得する
   - null または AccountMode が PLAYER 以外の場合はリターン
4. メインハンドのアイテムが AstralRecord アイテムか判定する
   - `ItemStackFactory.getAstralItemId` で null の場合はリターン
5. アクション種別に応じてデバッグメッセージを送信する

    | Action | メッセージ |
    |---|---|
    | LEFT_CLICK_AIR / LEFT_CLICK_BLOCK | P_6000（左クリック通知） |
    | RIGHT_CLICK_AIR / RIGHT_CLICK_BLOCK | P_6001（右クリック通知） |

    | 項目 | 内容 |
    |---|---|
    | ID | PlayerMsgId.P_6000 |
    | テンプレート | [DEBUG] ホットバー左クリック: {0} |
    | 引数 | AstralRecord アイテム ID |

    | 項目 | 内容 |
    |---|---|
    | ID | PlayerMsgId.P_6001 |
    | テンプレート | [DEBUG] ホットバー右クリック: {0} |
    | 引数 | AstralRecord アイテム ID |

6. 例外時は runSafely で以下ログを記録する

    | 項目 | 内容 |
    |---|---|
    | ID | LogId.E_6000 |
    | レベル | ERROR |
    | テンプレート | ホットバーアクション処理に失敗しました: %s |
    | 出力条件 | runSafely で例外発生時 |
    | 引数 | プレイヤー名 |
