# 15 ホットバーアクション メソッド仕様 - イベント

## 装備左クリック通常攻撃

イベント物理名: `PlayerInteractEvent`
クラス名: `EquipmentAttackEventHandler`
物理名: `onPlayerInteract`

優先度は `EventPriority.LOWEST` とする。item feature 側のブロック処理より後ではなく、装備通常攻撃の入力判定を早い段階で行う。

1. メインハンド入力のみを対象とする。
   - `event.getHand() != EquipmentSlot.HAND` の場合は処理を終了する。
2. 左クリック入力のみを対象とする。
   - `LEFT_CLICK_AIR` または `LEFT_CLICK_BLOCK` 以外は処理を終了する。
3. AstPlayer を取得する。
   - `AstPlayerCache` から取得できない場合は処理を終了する。
   - `AccountMode.PLAYER` 以外は処理を終了する。
4. メインハンドの AstralRecord アイテムを取得する。
   - AstralRecord アイテム ID を取得できない場合は処理を終了する。
5. [[15_3.01-イベント]].装備左クリック通常攻撃サービス呼び出し へ委譲する。
6. 例外時は `runSafely` で以下ログを記録する。

    | 項目 | 内容 |
    |---|---|
    | ID | `LogId.E_6000` |
    | レベル | ERROR |
    | テンプレート | ホットバーアクション処理に失敗しました: %s |
    | 出力条件 | `runSafely` で例外発生時 |
    | 引数 | プレイヤー名 |

## 装備左クリック通常攻撃サービス呼び出し

クラス名: `EquipmentAttackService`
物理名: `handleLeftClick`

1. item ID からアイテムモデルを取得する。
2. `equipment` が未設定、または `equipment.slot != WEAPON` の場合は処理を終了する。
3. `equipment.onUse.leftClickSkillId` を取得する。
   - 未設定の場合は処理を終了する。
   - `leftClickSkillId` には API スキル ID または built-in 通常攻撃 ID を指定できる。
4. `equipment.onUse.leftClickCooldownTicks` を取得する。
   - 未設定または 0 以下の場合は、スキル定義側クールダウンをそのまま使用する。
5. `SkillService.isOnCooldown` でクールダウン状態を確認する。
   - クールダウン中は以下メッセージを表示して処理を終了する。

    | 項目 | 内容 |
    |---|---|
    | ID | `PlayerMsgId.P_5802` |
    | テンプレート | スキルはクールダウン中です |
    | 出力条件 | `leftClickSkillId` がクールダウン中 |
    | 引数 | - |

6. `SkillCastTrigger.AUTO_ATTACK` を指定して [[13_3.02-サービス]].スキル起動 を呼び出す。
   - `castLocation` にはプレイヤー視点位置を渡す。
7. スキル起動成功時のみ `leftClickCooldownTicks > 0` であれば `SkillService.startCooldown` を呼び出す。
   - 装備側クールダウンは built-in 通常攻撃、API スキルのどちらに対しても同じ `skillId` 単位で適用する。
8. スキル起動失敗時はメッセージを追加せず、[[13_3.02-サービス]].スキル起動 の結果に従う。
