# 15 ホットバーアクション メソッド仕様 - イベント

## 武器左右クリック攻撃イベント `PlayerInteractEvent`
クラス名: `ItemWeaponAttackEventHandler`
対象メソッド: `onPlayerInteract`

優先度は `EventPriority.HIGHEST`、`ignoreCancelled = false` とする。item feature 側でイベントが cancel 済みでも、武器攻撃・特殊攻撃の委譲可否を最終判定できるようにする。

1. `event.getHand() != EquipmentSlot.HAND` の場合は処理を終了する。
2. `LEFT_CLICK_AIR` / `LEFT_CLICK_BLOCK` / `RIGHT_CLICK_AIR` / `RIGHT_CLICK_BLOCK` 以外は処理を終了する。
3. `SkillTreeService.isSkillTreeEditing(player)` が `true` の場合は `event.setCancelled(true)` して処理を終了する。
4. `SkillActionRingService.isAttackSuppressed(player)` が `true` の場合は処理を終了する。
5. `SkillActionRingService.isOpen(player)` が `true` の場合は処理を終了する。
6. `AstPlayerCache` からプレイヤーを解決できない場合、または `AccountMode.PLAYER` 以外の場合は処理を終了する。
7. 左クリックの場合は `ItemWeaponAttackService.handleLeftClick` に委譲する。
8. 右クリックの場合は `ItemWeaponAttackService.handleRightClick` に委譲する。
9. 例外時は `runSafely` で `LogId.E_6000` を記録する。

## 武器左クリック通常攻撃サービス呼び出し
クラス名: `ItemWeaponAttackService`
対象メソッド: `handleLeftClick`

1. メインハンドの item ID から AstralRecord アイテムを解決する。
2. `equipment` が未設定、または `equipment.slot != WEAPON` の場合は処理を終了する。
3. `equipment.onUse.leftClickSkillId` を解決する。
4. `leftClickSkillId` が未設定または空文字の場合は処理を終了する。
5. `equipment.onUse.leftClickCooldownTicks > 0` かつ `SkillService.isOnCooldown(...) == true` の場合は処理を終了する。
6. `SkillCastTrigger.AUTO_ATTACK` を指定して `SkillService.castSkill` を呼び出す。
7. 発動成功時のみ `leftClickCooldownTicks > 0` なら `SkillService.startCooldown` を呼び出す。

## 武器右クリック特殊攻撃サービス呼び出し
クラス名: `ItemWeaponAttackService`
対象メソッド: `handleRightClick`

1. メインハンドの item ID から AstralRecord アイテムを解決する。
2. `equipment` が未設定、または `equipment.slot != WEAPON` の場合は処理を終了する。
3. `equipment.onUse.rightClickSkillId` を解決する。
4. `rightClickSkillId` が未設定または空文字の場合は処理を終了する。
5. `equipment.onUse.rightClickCooldownTicks > 0` かつ `SkillService.isOnCooldown(...) == true` の場合は処理を終了する。
6. `SkillCastTrigger.AUTO_ATTACK` を指定して `SkillService.castSkill` を呼び出す。
7. 発動成功時のみ `rightClickCooldownTicks > 0` なら `SkillService.startCooldown` を呼び出す。

## アクションリングガード

- アクションリング表示中または選択後の発動待ち中の左クリック・右クリックは、`SkillActionRingService.isOpen` により武器攻撃サービスへ委譲しない。右クリック時のリング表示への復帰は skill feature 側の `SkillActionRingEventHandler` が処理する。

## スキルツリー編集中の補足

- `SkillTreeService.isSkillTreeEditing(player)` が `true` の間は、player の `skill_tree` 滞在中と ADMIN / BUILDER の設置アイテム操作中を含めて、`ItemWeaponAttackService.handleLeftClick` / `handleRightClick` へ委譲しない。
