# 15 ホットバーアクション メソッド仕様 - イベント

## 武器左右クリック攻撃
イベント種類: `PlayerInteractEvent`
クラス名: `ItemWeaponAttackEventHandler`
対象メソッド: `onPlayerInteract`

優先度は `EventPriority.HIGHEST`、`ignoreCancelled = false` とする。
item feature 側でイベントが cancel 済みでも、武器攻撃だけは同一イベント内で処理を継続できるようにする。

1. `event.getHand() != EquipmentSlot.HAND` の場合は処理を終了する。
2. `LEFT_CLICK_AIR` / `LEFT_CLICK_BLOCK` / `RIGHT_CLICK_AIR` / `RIGHT_CLICK_BLOCK` 以外は処理を終了する。
3. `AstPlayerCache` からプレイヤーを取得できない場合、または `AccountMode.PLAYER` 以外の場合は処理を終了する。
4. 発動対象アイテムは `event.getPlayer().getInventory().getItemInMainHand()` を使用する。
5. 左クリックの場合は `ItemWeaponAttackService.handleLeftClick` に委譲する。
6. 右クリックの場合は `ItemWeaponAttackService.handleRightClick` に委譲する。
7. 例外時は `runSafely` で `LogId.E_6000` を記録する。

## 武器左クリック通常攻撃サービス呼び出し
クラス名: `ItemWeaponAttackService`
対象メソッド: `handleLeftClick`

1. item ID からアイテムモデルを取得する。
2. `equipment` が未設定、または `equipment.slot != WEAPON` の場合は処理を終了する。
3. `equipment.onUse.leftClickSkillId` を取得する。
4. 未設定・空文字の場合は処理を終了する。
5. `equipment.onUse.leftClickCooldownTicks` が 0 より大きく、かつ `SkillService.isOnCooldown` が true の場合は `PlayerMsgId.P_5802` を表示して処理を終了する。
6. `SkillCastTrigger.AUTO_ATTACK` を指定して `SkillService.castSkill` を呼び出す。
7. 成功時のみ `leftClickCooldownTicks > 0` であれば `SkillService.startCooldown` を呼び出す。

## 武器右クリック特殊攻撃サービス呼び出し
クラス名: `ItemWeaponAttackService`
対象メソッド: `handleRightClick`

1. item ID からアイテムモデルを取得する。
2. `equipment` が未設定、または `equipment.slot != WEAPON` の場合は処理を終了する。
3. `equipment.onUse.rightClickSkillId` を取得する。
4. 未設定・空文字の場合は処理を終了する。
5. `equipment.onUse.rightClickCooldownTicks` が 0 より大きく、かつ `SkillService.isOnCooldown` が true の場合は `PlayerMsgId.P_5802` を表示して処理を終了する。
6. `SkillCastTrigger.AUTO_ATTACK` を指定して `SkillService.castSkill` を呼び出す。
7. 成功時のみ `rightClickCooldownTicks > 0` であれば `SkillService.startCooldown` を呼び出す。
