# 15 ホットバーアクション 概要

## 位置づけ

ホットバーアクションは、プレイヤー入力を装備やアイテムの使用処理へ橋渡しする機能である。
現時点で実装している対象は、武器をメインハンドに持った状態での左クリック通常攻撃のみとする。

## 対象アクション

| 入力 | 対象 | 連携先 |
|:--|:--|:--|
| 左クリック | 武器 (`equipment.slot = WEAPON`) | `equipment.onUse.leftClickSkillId` に紐づく通常攻撃 |
| 右クリック | 武器 (`equipment.slot = WEAPON`) | `equipment.onUse.rightClickSkillId` に紐づく特殊攻撃 |
| 右クリック | バンドル | item feature 側で使用 |
| 左クリック | 武器以外 | 対象外 |

## 現状仕様

- 左クリック通常攻撃のイベント入口は equipment feature 配下に置く。
- 通常攻撃に使う `skillId` は item マスタ上では `leftClickSkillId` として保持する。
- `leftClickSkillId` は API スキルマスタだけでなく、plugin 内で定義する built-in 通常攻撃 ID も指定できる。
- 特殊攻撃に使う `skillId` は item マスタ上では `rightClickSkillId` として保持する。
- `rightClickSkillId` は API スキルマスタだけでなく、plugin 内で定義する built-in 特殊攻撃 ID も指定できる。
- built-in 特殊攻撃 ID は `special_attack_melee` / `special_attack_bow` / `special_attack_magic` を使用する。
- built-in 通常攻撃は `normal_attack_melee`、`normal_attack_bow`、`normal_attack_magic` を用意する。
- 通常攻撃では、built-in 実装に応じてモブへの当たり判定と custom ダメージ適用まで行う。
- `normal_attack_melee` は前方範囲ヒット、`normal_attack_bow` は重力のある飛翔、`normal_attack_magic` は近傍モブへ弱ホーミングする飛翔として扱う。
- 魔法通常攻撃の演出は、外周エフェクトを控えめにしつつ、中心に紫のコアパーティクルを重ねて表示する。

## ガード条件

- メインハンド入力のみ対象とする。
- `AccountMode.PLAYER` のプレイヤーのみ対象とする。
- AstralRecord アイテムでない場合は対象外とする。
- `equipment.slot != WEAPON` の場合は対象外とする。
- `equipment.onUse.leftClickSkillId` が未設定の場合は対象外とする。
- `equipment.onUse.rightClickSkillId` が未設定の場合は右クリック特殊攻撃の対象外とする。
