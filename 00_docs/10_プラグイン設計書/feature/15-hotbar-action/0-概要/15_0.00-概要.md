# 15 ホットバーアクション 概要

## 目的

ホットバーに配置された AstralRecord アイテムへの左クリック・右クリック操作を検知し、アイテム種別に応じたアクションを実行する。

## 対象アクション（将来計画）

| 操作 | アイテム種別 | アクション |
|:--|:--|:--|
| 左クリック | 武器 | 通常攻撃 |
| 右クリック | 武器 | スキル発動 |
| 右クリック | ポーション | 使用 |
| 右クリック | バンドル | 開封 |

## 現状

イベント検知とデバッグメッセージ表示のみ実装。アクション委譲は未実装。

## ガード条件

- メインハンド操作のみ対象（オフハンドは除外）
- AccountMode が PLAYER のプレイヤーのみ対象
- AstralRecord アイテムを持っている場合のみ対象

## メッセージ・ログ ID

| ID | 種別 | 内容 |
|:--|:--|:--|
| P_6000 | PlayerMsgId | [DEBUG] ホットバー左クリック: {0} |
| P_6001 | PlayerMsgId | [DEBUG] ホットバー右クリック: {0} |
| E_6000 | LogId | ホットバーアクション処理に失敗しました: %s |
