# 18_2.00-ユースケース

## 1. メール一覧表示

1. menu feature などの導線からメール GUI を開く。
2. [[18_3.00-メソッド仕様]].メール一覧取得 が対象 account のメールを取得する。
3. 未読・既読・期限切れを区別して一覧表示する。

## 2. メール既読化

1. プレイヤーがメール詳細を開く。
2. 未読メールの場合、[[18_3.00-メソッド仕様]].メール既読化 を呼び出す。
3. 既読日時を保存し、GUI を再描画する。

## 3. 報酬受け取り

1. プレイヤーが報酬付きメールを開く。
2. 未受け取り報酬を抽出する。
3. 通貨報酬は currency feature、item 報酬は inventory feature へ委譲する。
4. すべて成功した報酬だけを受け取り済みにする。

## 4. welcome_mail 配布

1. account feature が初回参加導線を完了する。
2. [[18_3.00-メソッド仕様]].初回メール作成 が `welcome_mail` を対象 account へ作成する。
3. 既に作成済みの場合は重複作成しない。
