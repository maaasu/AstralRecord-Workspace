# 18_1.00-モデル定義

## 1. メール

物理名: `MailMessage`

| 項目 | 説明 |
|---|---|
| `mailId` | メール ID |
| `accountId` | 宛先アカウント UUID |
| `templateId` | filebase マスタ由来のテンプレート ID |
| `title` | 件名 |
| `body` | 本文 |
| `readAt` | 既読日時。未読時は `null` |
| `expiresAt` | 期限。期限なしは `null` |
| `rewards` | [[18_1.00-モデル定義]].メール報酬 の一覧 |

## 2. メール報酬

物理名: `MailReward`

| 項目 | 説明 |
|---|---|
| `rewardType` | `currency` / `item` |
| `rewardId` | 通貨 ID または item ID |
| `amount` | 数量 |
| `claimedAt` | 受け取り日時。未受け取り時は `null` |

## 3. メール表示状態

物理名: `MailGuiState`

| 項目 | 説明 |
|---|---|
| `accountId` | 表示対象アカウント UUID |
| `pageIndex` | 一覧ページ |
| `selectedMailId` | 詳細表示中のメール ID |
