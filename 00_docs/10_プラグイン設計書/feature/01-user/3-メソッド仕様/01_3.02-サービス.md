# 01_3.02-サービス

## 1.サービスメソッド仕様
### ログイン前検証

クラス名: `UserService`
物理名: `onAsyncPreLogin`

責務:

ユーザーの存在確認を行い、未登録なら新規登録、既存なら最終参加情報を更新する。

処理内容:

1. [[01_3.04-リポジトリ]].ユーザ存在確認でユーザー存在を確認する

	| 項目 | 内容 |
	|---|---|
	| 検索キー | `uuid` |
	| 登録済み | [[01_1.00-モデル定義]].ユーザモデル を取得する |
	| 未登録 | `null` として扱う |
	| API一時障害 | 例外として捕捉し、手順5のログを記録して終了する |

2. 未登録なら新規ユーザ登録を実行する

	| 項目 | 内容 |
	|---|---|
	| 判定条件 | 手順1の取得結果が `null` |
	| 入力 | `uuid`, `mcid`, `globalIp` |
	| 後続処理 | 新規ユーザ登録内で user 作成、初期 account 作成、選択アカウントID更新を行う |
	| 例外時 | 手順5のログを記録して終了する |

3. 登録済みなら選択アカウントを解決する

	| 項目 | 内容 |
	|---|---|
	| 判定条件 | 手順1の取得結果が [[01_1.00-モデル定義]].ユーザモデル |
	| 参照値 | `existing.getAccountId()` |
	| 解決方法 | `AccountService` で選択中アカウントを取得する |

4. 選択アカウントがある場合のみ [[01_3.04-リポジトリ]].最終参加情報更新を実行する

	| 項目 | 内容 |
	|---|---|
	| 判定条件 | 手順3の選択アカウントが `null` ではない |
	| 更新項目 | 最終参加日時、接続元IP、選択アカウントID、更新者 |
	| 更新者 | [[01_1.00-モデル定義]].システムユーザ |
	| 選択アカウントなし | 更新せず終了する |

5. 例外時は `LogId.W_5051` を記録して処理を終了する

	| 項目 | 内容 |
	|---|---|
	| ID | `LogId.W_5051` |
	| レベル | `WARN` |
	| テンプレート | `ログイン前処理をスキップしました（API一時障害）: %s (%s)` |
	| 出力条件 | ユーザ存在確認、新規ユーザ登録、最終参加情報更新で例外発生時 |
	| 引数 | `mcid`, `e.getMessage()` |

入力:

- `uuid`: プレイヤー UUID
- `mcid`: プレイヤー名
- `globalIp`: 接続元IP

出力:

- なし

例外時挙動:

- 例外を再送出せず警告ログを記録して終了する

### 新規ユーザ登録

クラス名: `UserService`
物理名: `registerNewUser`

責務:

`user` と初期 `account` を整合順序で作成し、`user.account_id` を確定する。

処理内容:

1. [[01_3.04-リポジトリ]].ユーザ登録で `account_id = null` のユーザを登録する

	| 項目 | 内容 |
	|---|---|
	| 登録対象 | [[01_1.00-モデル定義]].ユーザモデル |
	| `uuid` | プレイヤーUUID |
	| `mcid` | プレイヤー名 |
	| `joinDate` / `lastJoinDate` | 現在日時 |
	| `globalIp` | 接続元IP |
	| `accountId` | `null` |
	| `createdBy` / `updatedBy` | [[01_1.00-モデル定義]].システムユーザ |

2. 初期アカウントを作成する

	| 項目 | 内容 |
	|---|---|
	| 委譲先 | `AccountService` |
	| ユーザUUID | `uuid` |
	| アカウント名 | `mcid` |
	| slot | `0` |
	| 更新者 | [[01_1.00-モデル定義]].システムユーザ |

3. [[01_3.04-リポジトリ]].選択アカウントID更新で作成した `account.uuid` を `user.account_id` へ反映する

	| 項目 | 内容 |
	|---|---|
	| 対象ユーザ | `uuid` |
	| 選択アカウントID | 作成した `account.uuid` |
	| 更新者 | [[01_1.00-モデル定義]].システムユーザ |

4. 正常終了ログ `LogId.I_5050` を記録する

	| 項目 | 内容 |
	|---|---|
	| ID | `LogId.I_5050` |
	| レベル | `INFO` |
	| テンプレート | `新規ユーザーを登録しました: %s (%s)` |
	| 出力条件 | 新規ユーザ登録の正常終了時 |
	| 引数 | `mcid`, `uuid` |

入力:

- `uuid`: プレイヤー UUID
- `mcid`: プレイヤー名
- `globalIp`: 接続元IP

出力:

- なし

例外時挙動:

- 呼び出し元のログイン前検証で捕捉し、`LogId.W_5051` を記録する

### ユーザ取得

クラス名: `UserService`
物理名: `getUser`

責務:

UUID でユーザーを取得し、他 feature から参照できるユーザー状態を返す。

処理内容:

1. [[01_3.04-リポジトリ]].ユーザ取得を実行する

	| 項目 | 内容 |
	|---|---|
	| 取得キー | `uuid` |
	| 取得成功 | [[01_1.00-モデル定義]].ユーザモデル を返す |
	| 未存在 | `null` を返す |
	| API一時障害 | `null` を返し、以下ログを記録する |

	| 項目 | 内容 |
	|---|---|
	| ID | `LogId.W_5052` |
	| レベル | `WARN` |
	| テンプレート | `ユーザー取得をスキップしました（API一時障害）: %s (%s)` |
	| 出力条件 | ユーザー取得で例外発生時 |
	| 引数 | `uuid`, `e.getMessage()` |

2. 取得結果を呼び出し元へ返す

入力:

- `uuid`: 対象ユーザー UUID

出力:

- [[01_1.00-モデル定義]].ユーザモデル: 取得したユーザー（未存在または取得失敗時は `null`）

例外時挙動:

- 例外を再送出せず `LogId.W_5052` を記録し `null` を返す

### 権限更新

クラス名: `UserService`
物理名: `setPermission`

責務:

permission 値を更新し、更新後のユーザー状態を返す。

処理内容:

1. [[01_3.04-リポジトリ]].権限更新を実行する

	| 項目 | 内容 |
	|---|---|
	| 対象ユーザ | `uuid` |
	| 設定値 | `permission` |
	| 更新者 | `updatedBy` |

2. [[01_3.04-リポジトリ]].ユーザ取得で更新後ユーザーを再取得する

	| 項目 | 内容 |
	|---|---|
	| 取得キー | `uuid` |
	| 取得成功 | 更新後の [[01_1.00-モデル定義]].ユーザモデル を返す |
	| 取得失敗 | `null` を返し、以下ログを記録する |

	| 項目 | 内容 |
	|---|---|
	| ID | `LogId.W_5052` |
	| レベル | `WARN` |
	| テンプレート | `ユーザー取得をスキップしました（API一時障害）: %s (%s)` |
	| 出力条件 | 更新後ユーザーの再取得で例外発生時 |
	| 引数 | `uuid`, `e.getMessage()` |

3. 再取得結果を呼び出し元へ返す

入力:

- `uuid`: 対象ユーザー UUID
- `permission`: 設定する権限値
- `updatedBy`: 更新実行者 UUID

出力:

- [[01_1.00-モデル定義]].ユーザモデル: 更新後ユーザー（取得失敗時は `null`）

例外時挙動:

- 更新後取得失敗時は `LogId.W_5052` を記録し `null` を返す
