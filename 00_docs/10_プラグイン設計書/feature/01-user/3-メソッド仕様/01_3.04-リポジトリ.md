# 01_3.04-リポジトリ

## 1. repository メソッド仕様

### ユーザ取得

クラス名: `UserRepository`
物理名: `findByUuid`

責務:

UUID でユーザーを取得し、404 時は警告ログを記録して `null` を返す。

処理内容:

1. `GET /api/user/{uuid}` を呼ぶ
2. `200` は [[01_1.00-モデル定義]].ユーザモデル へ変換して返し、`LogId.D_5055` を記録する

	| 項目 | 内容 |
	|---|---|
	| ID | `LogId.D_5055` |
	| レベル | `DEBUG` |
	| テンプレート | `ユーザーを取得しました (API): %s` |
	| 出力条件 | `GET /api/user/{uuid}` が `200` |
	| 引数 | `uuid` |

3. `404` は `LogId.W_5055` を記録して `null` を返す

	| 項目 | 内容 |
	|---|---|
	| ID | `LogId.W_5055` |
	| レベル | `WARN` |
	| テンプレート | `ユーザーが見つかりませんでした (API): %s` |
	| 出力条件 | `GET /api/user/{uuid}` が `404` |
	| 引数 | `uuid` |

4. その他ステータスは `LogId.E_5055` を記録し例外化する

	| 項目 | 内容 |
	|---|---|
	| ID | `LogId.E_5055` |
	| レベル | `ERROR` |
	| テンプレート | `ユーザーの取得に失敗しました (API): %s` |
	| 出力条件 | `GET /api/user/{uuid}` が `200/404` 以外 または 例外 |
	| 引数 | APIエラーメッセージ or 例外メッセージ |

## 2. API エンドポイント一覧

- `GET /api/user/{uuid}`
- `POST /api/user`
- `PUT /api/user/{uuid}`

## 3. ステータスコード方針

- `GET`:
  - `200`: 正常
  - `404`: 用途に応じて `null` 返却（警告あり/なし）
  - その他: 例外
- `POST/PUT`:
  - `2xx`: 正常
  - その他: 例外

## 4. DTO/永続化対応

- DTO: [[01_1.00-モデル定義]].ユーザモデル（詳細は [[01_1.00-モデル定義]]）
- 永続化相当: `dbo.user`
- 更新主体: プレイヤー UUID または [[01_1.00-モデル定義]].システムユーザ
