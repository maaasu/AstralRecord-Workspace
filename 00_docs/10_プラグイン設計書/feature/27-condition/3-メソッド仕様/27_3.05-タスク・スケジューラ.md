# 27_3.05-タスク・スケジューラ

## 状態異常 tick タスク

クラス名: `ConditionTickTask`
物理名: `run`

1. 5 tick 間隔で実行する。
2. `ConditionService.snapshotAllActiveConditions` で処理対象を取得する。
3. 各 active condition に対して [[27_3.02-サービス]].状態異常 tick 処理 を呼ぶ。
4. 1 回の run で処理した condition 数が上限を超える場合、次 tick へ分割する。
   - 初期上限は 300 件。
5. 例外は対象 condition 単位で握りつぶさずログ化し、次 condition の処理を継続する。

## 状態異常表示タスク

クラス名: `ConditionDisplayTask`
物理名: `run`

1. 10 tick 間隔で実行する。
2. `ConditionService.snapshotVisibleTargets` で active condition を持つ対象一覧を取得する。
3. 各対象について `ConditionDisplayService.refreshTargetDisplay` を呼ぶ。
4. 周囲に viewer が存在しない対象は particle 更新を省略する。
5. TextDisplay / BlockDisplay の位置ずれ補正は対象ごとに 10 tick 間隔で行う。

## 状態異常掃除タスク

クラス名: `ConditionCleanupTask`
物理名: `run`

1. 100 tick 間隔で実行する。
2. 対象 entity が存在しない active condition を解除する。
3. 期限切れ condition を解除する。
4. orphan 化した TextDisplay / BlockDisplay を破棄する。
5. `MobVanillaEffectProtectionService` の plugin fire tracking に残った無効 entity ID を掃除する。
