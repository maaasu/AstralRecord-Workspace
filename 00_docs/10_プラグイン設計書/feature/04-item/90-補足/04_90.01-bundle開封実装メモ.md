# 04_90.01-bundle開封実装メモ

## 概要

- 2026-05-27 時点で `bundle` カテゴリの AstralRecord アイテムは右クリックで開封する。
- 右クリック判定は `PlayerInteractEvent` の `RIGHT_CLICK_AIR` / `RIGHT_CLICK_BLOCK` を使用する。
- 開封処理は `BundleUseService` が担当し、報酬抽選・バンドル消費・演出再生までを一括で実行する。

## loot 解決

- `bundle.lootTableId` は `loot_table:` プレフィックス付き参照値でも解決できる。
- Plugin 側の `LootRepository` は API の `table` / `pool` レスポンスを結合して、抽選可能な構造へ展開する。
- ルートテーブル未キャッシュ時は `LootService.getLoadedOrFetch(...)` で単体取得を試みる。

## 使用結果

- 報酬は AstralRecord の通常インベントリへ追加する。
- インベントリに入らなかった分は ItemStack 化してプレイヤー足元へドロップする。
- バニラの使用動作とブロック干渉は従来通り抑止する。
