# 04_90.01-bundle開封実装メモ

## 概要
- 2026-05-28 時点で `bundle` カテゴリの AstralRecord アイテムは右クリックで開封を開始する。
- 開封完了までに約 3 秒の待機時間を設ける。
- 待機中は subtitle で使用中表示を出し、BossBar の進捗バーで完了までを表現する。

## 開封フロー
- `PlayerInteractEvent` の `RIGHT_CLICK_AIR` / `RIGHT_CLICK_BLOCK` を契機に `BundleUseService.beginBundleUse(...)` を呼ぶ。
- 右クリックイベントが他要因で `cancelled` 済みでも、AstralRecord item の bundle 開封判定自体は継続して実行する。
- `BundleUseService` は `bundle.lootTableId` を `LootService.getLoadedOrFetch(...)` で解決し、解決失敗時のみ開封失敗を通知する。
- 開封完了時に bundle を 1 個消費し、ルート定義に従って報酬抽選・インベントリ格納・足元ドロップ・生成処理を実行する。
- `bundle.onUse.sound` / `bundle.onUse.particle` は raw の Minecraft Key ではなく bundle 用カスタム ID とし、filebase の専用マスタから解決する。

## キャンセル条件
- 開封中にホットバー選択を切り替えた場合は開封をキャンセルする。
- 開封中にプレイヤーが移動した場合も開封をキャンセルする。
- プレイヤー退出時も開封状態を破棄する。
- キャンセル時は BossBar と subtitle を閉じ、bundle 消費や報酬付与は行わない。

## Lore 表示
- bundle Lore にルート情報は表示しない。
- bundle Lore に item ID は表示しない。
