# 04_90.01-bundle開封実装メモ

## 概要
- `bundle` カテゴリの AstralRecord アイテムは右クリックで開封できる。
- 開封完了まで約3秒の待機時間を設ける。
- 待機中は subtitle と BossBar で進行状況を表示する。

## 開封フロー
- `PlayerInteractEvent` の `RIGHT_CLICK_AIR` / `RIGHT_CLICK_BLOCK` を起点に `BundleUseService.beginBundleUse(...)` を呼び出す。
- `BundleUseService` は `bundle.lootTableId` を `LootService.getLoadedOrFetch(...)` で解決し、解決に失敗した場合のみ開封失敗メッセージを返す。
- 開封完了時に bundle を 1 個消費し、ルートテーブルの結果に従って通常インベントリへ付与する。
- 開封完了メッセージでは獲得したアイテム名と個数を 1 行ずつ表示する。
- 通常インベントリに入り切らない報酬は足元へドロップする。
- `bundle.onUse.sound` / `bundle.onUse.particle` は filebase の定義を参照して再生する。

## キャンセル条件
- 待機中にホットバー選択を変えた場合は開封をキャンセルする。
- 待機中にプレイヤーが移動した場合も開封をキャンセルする。
- プレイヤー退出時も開封待機を解除する。
- キャンセル時は BossBar / subtitle を片付け、bundle 消費や報酬付与は行わない。

## Lore 表示
- bundle ItemStack の Lore には、`bundle.lootTableId` から解決したルートテーブルの報酬候補を表示する。
- Lore にはルート名や候補アイテム ID は表示せず、アイテム名・個数・必要時のみ weight% を表示する。
- ルートテーブルが未ロードでも `LootService.getLoadedOrFetch(...)` で解決を試み、取得できた報酬候補をその場で Lore に反映する。
- 報酬候補は `アイテム名 x最小数~最大数 / weight%` 形式で表示する。
- `weight` が 100% の要素は確率表記を省略する。
