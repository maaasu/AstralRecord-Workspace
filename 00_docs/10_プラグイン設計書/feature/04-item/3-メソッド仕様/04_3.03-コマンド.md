# 04_3.03-コマンド

## 1. command メソッド仕様

### アイテムルート振分

クラス名: `ItemCommand`  
物理名: `executePlayerCommand`

責務:

`/item` の第一引数を判定し、サブコマンドへ委譲する。

処理内容:

1. 引数なしの場合は usage を返す
2. 第一引数が `load` の場合、[[04_3.03-コマンド]].アイテム再ロード実行 へ委譲する
3. 第一引数が `get` の場合、[[04_3.03-コマンド]].アイテム付与実行 へ委譲する
4. 対応外サブコマンドは usage を返す

入力:

- `args[0]`: サブコマンド名

出力:

- なし

例外時挙動:

- 基底 `AstCommand` 側で例外を捕捉しエラーメッセージを返す

### アイテム再ロード実行

クラス名: `ItemCommand`  
物理名: `handleLoad`

責務:

指定 ID のアイテムを API から再取得し、キャッシュへ反映する。

処理内容:

1. 引数が 2 個未満なら usage を返す
2. [[04_3.02-サービス]].個別アイテムロード（ID のみ）を呼ぶ

	| 項目 | 内容 |
	|---|---|
	| 入力 | `args[1]` |
	| 取得失敗 | `PlayerMsgId.P_5201` を送信し終了する |

	| 項目 | 内容 |
	|---|---|
	| ID | `PlayerMsgId.P_5201` |
	| レベル | `-` |
	| テンプレート | `アイテムが見つかりません: category={0}, id={1}` |
	| 出力条件 | 個別アイテムロードの戻り値が `null` |
	| 引数 | `args[1]` |

3. 成功時はロード結果を実行者へ通知する

	| 項目 | 内容 |
	|---|---|
	| ID | `PlayerMsgId.P_5209` |
	| レベル | `-` |
	| テンプレート | `ロードしました: {0}/{1} ({2})` |
	| 出力条件 | 個別アイテムロード成功時 |
	| 引数 | `category`, `id`, `name` |

入力:

- `args[1]`: アイテム ID

出力:

- なし

### アイテム付与実行

クラス名: `ItemCommand`  
物理名: `handleGet`

責務:

指定 ID のアイテムを必要に応じて API から取得し、プレイヤーのインベントリへ付与する。付与後は必要に応じて GUI を再描画する。

処理内容:

1. 引数が 2 個未満なら usage を返す
2. [[04_3.02-サービス]].個別アイテムロード（ID のみ）を呼ぶ

	| 項目 | 内容 |
	|---|---|
	| 入力 | `args[1]` |
	| キャッシュ済み | キャッシュ済みアイテムを返す |
	| 未ロード | 詳細 API から取得し、ID 単位キャッシュへ登録する |
	| 取得失敗 | `PlayerMsgId.P_5201` を送信し終了する |

	| 項目 | 内容 |
	|---|---|
	| ID | `PlayerMsgId.P_5201` |
	| レベル | `-` |
	| テンプレート | `アイテムが見つかりません: category={0}, id={1}` |
	| 出力条件 | 個別アイテムロードの戻り値が `null` |
	| 引数 | `-`, `args[1]` |

3. `InventoryService` を取得する

	| 項目 | 内容 |
	|---|---|
	| 取得 | `AstralRecord.getInstance().getInventoryService()` |
	| 未初期化 | `PlayerMsgId.P_5063` を送信し終了する |

4. 数量を解決する

	| 項目 | 内容 |
	|---|---|
	| 入力 | `args[2]`（省略時は `1`） |
	| 整数解釈失敗 | デフォルト値 `1` |
	| 下限クランプ | `Math.max(1, parsed)` |

5. インベントリへ付与する

	| 項目 | 内容 |
	|---|---|
	| 呼び出し | `inventoryService.addItemToNormalInventory(player, model, amount)` |
	| 戻り値 | 付与に成功した個数 |
	| 0以下 | `PlayerMsgId.P_5241` を送信し終了する |

	| 項目 | 内容 |
	|---|---|
	| ID | `PlayerMsgId.P_5241` |
	| レベル | `-` |
	| テンプレート | `インベントリに空きがありません。` |
	| 出力条件 | 付与結果が 0 以下 |
	| 引数 | なし |

6. 付与カテゴリに応じて GUI を更新する

	| 項目 | 内容 |
	|---|---|
	| 解決方法 | `inventoryService.resolveInventoryType(model)` |
	| `CURRENCY` | GUI 更新は行わない（通貨アイテム取得時の GUI 自動表示は廃止） |
	| その他 | `inventoryService.applyInventoryToGui(player, inventoryType)` |

7. 実行者へ成功メッセージを送信する

	| 項目 | 内容 |
	|---|---|
	| ID | `PlayerMsgId.P_5240` |
	| レベル | `-` |
	| テンプレート | `アイテムを付与しました: {0} x{1}` |
	| 出力条件 | 付与成功時 |
	| 引数 | `model.name`, 付与数 |

入力:

- `args[1]`: アイテム ID
- `args[2]`: 数量（省略可、省略時は `1`）

出力:

- なし

### アイテム補完候補取得

クラス名: `ItemTabCompleter`  
物理名: `getPlayerCompletions`

責務:

`/item` 入力位置に応じた補完候補を返す。

処理内容:

1. 第1引数位置では `load`, `get` を返す
2. `load` / `get` の第2引数位置ではロード済みアイテム ID 一覧を候補として返す
3. `get` の第3引数位置では `1`, `8`, `16`, `32`, `64` を返す
4. それ以外は空リストを返す

## 2. コマンド仕様

- ルート: `/item`
- サブコマンド:
  - `/item load <itemId>` — 指定 ID のアイテムを API から再取得してキャッシュ更新する
  - `/item get <itemId> [amount]` — 指定 ID のアイテムを必要に応じて API から取得し、実行者のインベントリへ付与する

## 3. 実行権限仕様

- 送信者がコンソール: 実行不可（`isPlayerOnly = true`）
- 送信者がプレイヤー:
  - [[03_1.00-モデル定義]].プレイヤーキャッシュ 取得不可: 拒否
  - [[03_1.00-モデル定義]].プレイヤーセッション.user.permission < `99`: 拒否
  - それ以外: 実行可

`/item` は運用・検証向けにアイテム付与を行うため `ADMIN(99)` 以上を必須とする。権限不足時は `AstCommand` 基底側の実行時ガードで拒否し、Brigadier 登録時の可視性判定でも候補に表示しない。

## 4. 管理者GUI追記

### 管理者アイテムGUI表示

クラス名: `ItemCommand` / `ItemAdminGuiEventHandler`
処理名: `executePlayerCommand` / `open`

説明:

`/item` を引数なしで実行した場合、`ADMIN(99)` プレイヤー専用のアイテム一覧 GUI を開く。
一覧には `ItemService.getLoadedItems()` でロード済みのアイテムをすべて表示し、カテゴリ・レア度の簡易フィルタとページングを提供する。

処理方針:

1. `args.length == 0` の場合は usage を返さず GUI オープン処理へ委譲する
2. GUI は 45 スロット内容領域に現在フィルタ結果のアイテムを描画する
3. フィルタは `category` / `rarity` の 2 軸のみとし、各ボタンのクリックで `null -> 候補順巡回 -> null` を切り替える
4. 表示 ItemStack は `ItemStackFactory.createShopDisplay` 相当の表示を使い、equipment などランダム要素を持つアイテムでも shop 表示と同様に `min～max` を Lore 上へ表示する。カテゴリ表示は `ItemCategory.displayNameJa` の日本語名を使う
5. 内容領域クリック時の付与量は以下で決定する

| クリック | 付与量 |
|---|---|
| 左クリック | `1` |
| 右クリック | `1スタックの半分（切り上げ）` |
| Shift+左クリック | `1スタック分` |

6. `maxStack == 1` の equipment / rune / instance 系アイテムは、どの許可クリックでも結果として `1` 個付与になる
7. 付与実行は `InventoryService.addItemToNormalInventory(astPlayer, model, amount, "admin_gui")` を使う
8. 付与失敗時は `PlayerMsgId.P_5241` を再利用し、成功時は GUI を閉じずそのまま連続取得できるようにする

入出力:

- 入力: なし（`/item` 引数なし）
- 出力: なし
