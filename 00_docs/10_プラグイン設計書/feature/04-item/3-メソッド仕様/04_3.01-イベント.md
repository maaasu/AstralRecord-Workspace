# 04_3.01-イベント

クラス名: `ItemInteractionBlockEventHandler`
物理名: `onPlayerInteract`

## 1. アイテム操作イベント

| イベント | ハンドラ | 主な責務 |
|---|---|---|
| `PlayerInteractEvent` | `ItemInteractionBlockEventHandler.onPlayerInteract` | AstralRecord アイテムのブロック・空中操作を判定する |
| `PlayerInteractEntityEvent` | `onPlayerInteractEntity` | エンティティ右クリックを処理する |
| `PlayerInteractAtEntityEvent` | `onPlayerInteractAtEntity` | エンティティ位置指定クリックを処理する |
| `EntityDamageByEntityEvent` | `onEntityDamageByEntity` | プレイヤー武器攻撃をカスタム戦闘処理へ渡す |
| `PlayerItemConsumeEvent` | `onPlayerItemConsume` | 消耗品使用を処理する |

`Action.PHYSICAL` は対象外とし、`ItemStackFactory.getAstralItemId(item)` が `null` の場合は通常処理へ戻します。Plugin 管理対象では必要に応じて `setUseItemInHand(DENY)`、`setUseInteractedBlock(DENY)`、`setCancelled(true)` を設定します。

非同期の item 取得に失敗した場合は `LogId.E_5200` を使用し、イベントスレッドへ例外を漏らしません。メッセージテンプレートは `アイテム取得に失敗しました (API): %s` です。
