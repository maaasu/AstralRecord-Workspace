# 04_3.01-イベント

## 1. イベント仕様

### アイテム操作ブロック（ブロック・空中クリック）

イベント物理名: `PlayerInteractEvent`  
クラス名: `ItemInteractionBlockEventHandler`  
物理名: `onPlayerInteract`

責務:

AstralRecord アイテムを保持した状態でのバニラ右/左クリック動作を抑止する。

処理内容:

1. アクションが `Action.PHYSICAL` の場合は処理対象外として終了する
2. プレイヤーが PLAYER モードであることを判定する

	| 項目 | 内容 |
	|---|---|
	| 判定方法 | `AstPlayerCache.get(player)` から [[03_1.00-モデル定義]].プレイヤーキャッシュ を取得 |
	| 許可条件 | [[02_1.00-モデル定義]].アカウントモード が `PLAYER` |
	| 拒否条件 | キャッシュ未取得、または `PLAYER` 以外 |

3. 使用中アイテムが AstralRecord アイテムであることを判定する

	| 項目 | 内容 |
	|---|---|
	| 判定対象 | `event.getItem()` |
	| 判定方法 | `ItemStackFactory.getAstralItemId(item)` が `null` でない |

4. 条件成立時はバニラ動作をキャンセルする

	| 項目 | 内容 |
	|---|---|
	| `setUseItemInHand` | `DENY` |
	| `setUseInteractedBlock` | `DENY` |
	| `setCancelled` | `true` |

5. 例外時は `runSafely` で以下ログを記録する

	| 項目 | 内容 |
	|---|---|
	| ID | `LogId.E_5200` |
	| レベル | `ERROR` |
	| テンプレート | `アイテム取得に失敗しました (API): %s` |
	| 出力条件 | `runSafely` で例外発生時 |
	| 引数 | プレイヤー名（`event.getPlayer().getName()`） |

### アイテム操作ブロック（エンティティクリック）

イベント物理名: `PlayerInteractEntityEvent`  
クラス名: `ItemInteractionBlockEventHandler`  
物理名: `onPlayerInteractEntity`

責務:

AstralRecord アイテムを持った状態でのエンティティへの右クリック動作を抑止する。

処理内容:

1. 使用中の手（`event.getHand()`）からアイテムを取得し、AstralRecord アイテム判定を行う
2. プレイヤーが PLAYER モードであることを判定する
3. 条件成立時は `event.setCancelled(true)` を実行する
4. 例外時は `runSafely` で `LogId.E_5200` を記録する

	| 項目 | 内容 |
	|---|---|
	| ID | `LogId.E_5200` |
	| レベル | `ERROR` |
	| テンプレート | `アイテム取得に失敗しました (API): %s` |
	| 出力条件 | `runSafely` で例外発生時 |
	| 引数 | プレイヤー名（`event.getPlayer().getName()`） |

### アイテム攻撃ブロック

イベント物理名: `EntityDamageByEntityEvent`  
クラス名: `ItemInteractionBlockEventHandler`  
物理名: `onEntityDamageByEntity`

責務:

AstralRecord アイテムをメインハンドに持った状態のプレイヤーからの攻撃ダメージ発生を抑止する。

処理内容:

1. ダメージ実行者が `Player` であることを判定する
2. メインハンドの ItemStack が AstralRecord アイテムであることを判定する
3. プレイヤーが PLAYER モードであることを判定する
4. 条件成立時は `event.setCancelled(true)` を実行する
5. 例外時は `runSafely` で `LogId.E_5200` を記録する（引数はダメージ対象エンティティ名）

	| 項目 | 内容 |
	|---|---|
	| ID | `LogId.E_5200` |
	| レベル | `ERROR` |
	| テンプレート | `アイテム取得に失敗しました (API): %s` |
	| 出力条件 | `runSafely` で例外発生時 |
	| 引数 | ダメージ対象エンティティ名 |
