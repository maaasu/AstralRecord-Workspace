# 04_3.02-サービス

## 1. ItemService メソッド仕様

### 全アイテム一括ロード（廃止予定）

クラス名: `ItemService`  
物理名: `loadAll`

責務:

旧設計の互換メソッド。移行後は起動時呼び出しを行わず、管理用途でも原則使用しない。
必要なアイテムは [[04_3.02-サービス]].個別アイテムロード（ID のみ） で取得する。

処理内容:

1. [[04_3.04-リポジトリ]].アイテム一覧取得 でサマリ一覧を取得する

	| 項目 | 内容 |
	|---|---|
	| 取得 API | `GET /api/item` |
	| 取得項目 | [[04_1.00-モデル定義]].アイテム一覧サマリ のリスト |

2. サマリ単位で [[04_3.04-リポジトリ]].アイテム詳細取得 を呼び出す

	| 項目 | 内容 |
	|---|---|
	| 取得失敗 | `LogId.W_5200` を記録し当該アイテムをスキップする |

	| 項目 | 内容 |
	|---|---|
	| ID | `LogId.W_5200` |
	| レベル | `WARN` |
	| テンプレート | `アイテムが見つかりませんでした (API): カテゴリ=%s, ID=%s` |
	| 出力条件 | 個別アイテム取得結果が `null` |
	| 引数 | カテゴリ, ID |

3. 取得したアイテムをキャッシュへ登録し、カテゴリ別件数を集計する

	| 項目 | 内容 |
	|---|---|
	| キャッシュ | `loadedItems`（id 正規化キーで `ConcurrentHashMap`） |
	| デバッグログ | `LogId.D_5203` を記録 |

	| 項目 | 内容 |
	|---|---|
	| ID | `LogId.D_5203` |
	| レベル | `DEBUG` |
	| テンプレート | `アイテム詳細をロードしました: %s` |
	| 出力条件 | 個別アイテムキャッシュ登録時 |
	| 引数 | アイテムモデル |

4. カテゴリ別件数と合計件数を info ログに記録する

	| 項目 | 内容 |
	|---|---|
	| ID | `LogId.I_5202` |
	| レベル | `INFO` |
	| テンプレート | `カテゴリのアイテムを一括ロードしました (API): カテゴリ=%s (%d件)` |
	| 出力条件 | カテゴリ別集計ループ |
	| 引数 | カテゴリ, 件数 |

	| 項目 | 内容 |
	|---|---|
	| ID | `LogId.I_5203` |
	| レベル | `INFO` |
	| テンプレート | `全カテゴリのアイテムを初期ロードしました: 合計 %d件` |
	| 出力条件 | 全件ロード完了時 |
	| 引数 | 合計件数 |

5. 例外時は `LogId.E_5202` を記録し、ロード総数（現時点までの数）を返す

	| 項目 | 内容 |
	|---|---|
	| ID | `LogId.E_5202` |
	| レベル | `ERROR` |
	| テンプレート | `カテゴリのアイテム一括ロードに失敗しました (Service): category=%s` |
	| 出力条件 | 一括ロード中の例外発生時 |
	| 引数 | `"loadAll"` |

入力:

- なし

出力:

- `int`: ロードしたアイテムの総件数

例外時挙動:

- 例外を再送出せずログ記録のみ行い、その時点までのロード件数を返す

### カテゴリ別アイテム一括ロード

クラス名: `ItemService`  
物理名: `loadAllByCategory`

責務:

指定カテゴリのみ API から取得してキャッシュ更新する。

処理内容:

1. 入力カテゴリを正規化し、空文字なら `0` を返す
2. [[04_3.04-リポジトリ]].カテゴリ別アイテム一括取得 を呼ぶ
3. 取得した各アイテムをキャッシュへ登録する
4. `LogId.I_5202` を記録する
5. 例外時は `LogId.E_5202` を記録し `0` を返す

入力:

- `category`: カテゴリ

出力:

- `int`: ロード件数

### 個別アイテムロード（ID のみ）

クラス名: `ItemService`  
物理名: `loadItem(itemId)`

責務:

指定 ID のアイテムを API で取得し、ID 単位キャッシュへ登録する。

処理内容:

1. 入力 ID を正規化し、空文字なら `null` を返す
2. ID 単位キャッシュに有効な値があれば返す
3. [[04_3.04-リポジトリ]].アイテム詳細取得 を呼ぶ
4. 取得できた場合は ID 単位キャッシュへ登録する
5. 例外時は `LogId.E_5202` を記録し `null` を返す

入力:

- `itemId`: アイテム ID

出力:

- [[04_1.00-モデル定義]].アイテムモデル（取得失敗時は `null`）

### 個別アイテムロード（ID+カテゴリ）

クラス名: `ItemService`  
物理名: `loadItem(itemId, category)`

責務:

指定 ID とカテゴリで詳細を取得し、キャッシュへ登録する。

処理内容:

1. 入力 ID を正規化する
2. [[04_3.04-リポジトリ]].アイテム詳細取得 を呼ぶ
3. 取得結果を `cacheItem` でキャッシュへ登録する
4. 取得結果を返す

入力:

- `itemId`: アイテム ID
- `category`: アイテムカテゴリ

出力:

- [[04_1.00-モデル定義]].アイテムモデル（取得失敗時は `null`）

### ロード済みアイテム取得

クラス名: `ItemService`  
物理名: `findLoadedById` / `getLoadedItems` / `getLoadedItemsByCategory` / `getLoadedCategories` / `getLoadedItemIds`

責務:

ID 単位キャッシュからアイテム情報を返す参照系メソッド群。全 item の保持を前提にしない。

処理内容:

- `findLoadedById`: 正規化キーでキャッシュを引く
- `getLoadedItems`: 現在キャッシュ済みのアイテムだけを `category` → `id` でソートして返す
- `getLoadedItemsByCategory`: 現在キャッシュ済みのアイテムからカテゴリ一致のみを返す
- `getLoadedCategories`: ロード済みカテゴリの一覧を返す
- `getLoadedItemIds`: ロード済みアイテム ID の一覧を返す

### カテゴリサポート判定

クラス名: `ItemService`  
物理名: `isSupportedCategory` / `getSupportedCategories`

責務:

`ItemCategory` の `unknown` を除いたサポート対象カテゴリの判定と一覧を返す。

## 2. ItemStackFactory メソッド仕様

### 通常 ItemStack 生成

クラス名: `ItemStackFactory`  
物理名: `create(model)` / `create(model, amount)`

責務:

`ItemModel` から共通テンプレートを生成・キャッシュし、clone と数量設定のみで `ItemStack` を返す。

処理内容:

1. キャッシュキー `category:id` でテンプレートを取得する
2. 未キャッシュなら `buildTemplate` でプロトタイプ ItemStack を構築する
3. テンプレートを clone し、数量を `1 ～ maxStack` にクランプして返す

入力:

- `model`: アイテム定義
- `amount`: 個数（省略時 `1`）

出力:

- `ItemStack`: ベース Material は `PAPER` 固定

### 装備インスタンスから ItemStack 生成

クラス名: `ItemStackFactory`  
物理名: `create(model, instance, amount)`（`EquipmentInstance` 版）

責務:

`EquipmentInstance` 固有のステータスロール・強化レベル・エンチャント・ルーンスロット・状態変化を反映した `ItemStack` を生成する。キャッシュは使用しない。

処理内容:

1. レアリティに応じた表示名を組み立てる

	| 項目 | 内容 |
	|---|---|
	| 表示名解決 | `resolveEquipmentDisplayName` で `transcendence.overridesName` → `model.name` の優先順 |
	| 強化サフィックス | `enhanceLevel > 0` なら `+N` を白文字で連結 |

2. `buildLoreForEquipmentInstance` で Lore を構築する

	| 項目 | 内容 |
	|---|---|
	| 基本情報 | レアリティ、カテゴリ、フレーバー lore |
	| 装備情報 | スロット、ハンド、必要レベル、必要クラス、状態変化、強化レベル |
	| ステータス | base + enhance 累積（`statRollId` ごと） |
	| エンチャント | `instance.enchants` を 1 件ずつ表示（最大スロット数併記） |
	| ルーン | スロット番号順に装着済みルーン / 空きスロットを描画 |
	| 耐久値 | `durabilityValue / durabilityMax` を表示 |
	| フッター | アイテム ID、装備インスタンス ID、`unTradeable` / `unSellable` フラグ |

3. `customModelData` を `ItemMeta` に適用する
4. バニラの輝き表示を抑える `HIDE_*` ItemFlag を適用する
5. `instance.enchants` が空でない場合は `Enchantment.UNBREAKING` をエンチャント輝き目的で付与する
6. PDC へ AstralRecord メタ情報を書き込む

	| キー | 値 |
	|---|---|
	| `astralrecord:item_id` | `model.id` |
	| `astralrecord:icon` | `model.icon`（大文字） |
	| `astralrecord:custom_model_data` | `model.customModelData`（設定時のみ） |
	| `astralrecord:category` | `model.category` |
	| `astralrecord:rarity` | `model.rarity` |
	| `astralrecord:equipment_instance_id` | `instance.equipmentInstanceId` |

7. 数量を `1 ～ maxStack` にクランプして返す

入力:

- `model`: アイテム定義
- `instance`: [[04_1.00-モデル定義]].装備インスタンス
- `amount`: 個数

出力:

- `ItemStack`

### ルーンインスタンスから ItemStack 生成

クラス名: `ItemStackFactory`  
物理名: `create(model, instance, amount)`（`RuneInstance` 版）

責務:

`RuneInstance` の確定済みステータスロール（value）を Lore に反映した `ItemStack` を生成する。キャッシュは使用しない。

処理内容:

1. レアリティに応じた表示名を組み立てる
2. `buildLoreForRuneInstance` で Lore を構築する

	| 項目 | 内容 |
	|---|---|
	| ステータス補正 | `roll.value` を `type == SCALAR` で `×`、それ以外で `+` プレフィックス付き表示 |
	| フッター | アイテム ID、ルーンインスタンス ID、`unTradeable` / `unSellable` |

3. `customModelData` の適用とバニラ非表示フラグ適用を行う
4. PDC へ AstralRecord メタ情報（`item_id`, `icon`, `custom_model_data`, `category`, `rarity`, `rune_instance_id`）を書き込む
5. 数量を `1 ～ maxStack` にクランプして返す

入力:

- `model`: アイテム定義
- `instance`: [[04_1.00-モデル定義]].ルーンインスタンス
- `amount`: 個数

出力:

- `ItemStack`

### プロトタイプテンプレート構築

クラス名: `ItemStackFactory`  
物理名: `buildTemplate`

責務:

`ItemModel` 単体から共通テンプレート ItemStack を構築し、`create(model, amount)` から clone 元に使用される。

処理内容:

1. ベース Material `PAPER` で ItemStack を生成し、`ItemMeta` を取得する
2. レアリティに応じた表示名と装飾済みアイテム名を設定する
3. `buildLore` で Lore を構築する

	| 項目 | 内容 |
	|---|---|
	| ヘッダー | レアリティ・カテゴリ・星評価 |
	| フレーバー lore | `model.lore` を斜体グレーで表示 |
	| equipment セクション | 装備スロット・ハンド・必要条件・基本ステータス・耐久値 |
	| bundle セクション | `lootTableId` を [[06_3.02-サービス]].ロード済みルート取得 で解決し、Loot エントリを 1 件ずつ描画 |
	| フッター | アイテム ID、`unTradeable` / `unSellable` |

4. `customModelData` を `ItemMeta` に適用する
5. `HIDE_*` の ItemFlag を一括適用する
6. PDC へアイテム情報を書き込む（`item_id`, `icon`, `custom_model_data`, `category`, `rarity`）

### キャッシュ操作

クラス名: `ItemStackFactory`  
物理名: `clearCache` / `cacheSize`

責務:

テンプレートキャッシュのクリアと現在件数の参照を提供する。

処理内容:

- `clearCache`: `templateCache.clear()` 実行後 `LogId.D_5210` を記録する
- `cacheSize`: `templateCache.size()` を返す

	| 項目 | 内容 |
	|---|---|
	| ID | `LogId.D_5210` |
	| レベル | `DEBUG` |
	| テンプレート | `ItemStack テンプレートキャッシュをクリアしました` |
	| 出力条件 | `clearCache` 呼び出し時 |
	| 引数 | なし |

### PDC 読み取りユーティリティ

クラス名: `ItemStackFactory`（static メソッド群）  
物理名: `getAstralItemId` / `getIconName` / `getCustomModelData` / `getCategory` / `getEquipmentInstanceId` / `getRuneInstanceId`

責務:

`ItemStack` の `PersistentDataContainer` から AstralRecord メタ情報を読み取り、パケットアダプタ・イベントハンドラ・サービス層から共通利用する。

処理内容:

1. `item.hasItemMeta()` が `false` なら `null` を返す
2. PDC から該当キーの値を取得して返す（未設定時は `null`）
