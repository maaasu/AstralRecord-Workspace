# 04_3.02-サービス

クラス名: `ItemService`
物理名: `loadAll`

## 1. `ItemService`

- `loadAll`: 全カテゴリを API から読み込み、カテゴリ別キャッシュへ登録する。
- `loadAllByCategory`: 指定カテゴリを一括読み込みする。
- `loadItem`: ID、または ID とカテゴリから単件を読み込む。
- `findLoadedById`, `getLoadedItems`, `getLoadedItemsByCategory`: キャッシュを参照する。
- `getLoadedCategories`, `getLoadedItemIds`: 読み込み済みキーを返す。
- `isSupportedCategory`, `getSupportedCategories`: `ItemCategory` の対応範囲を返す。
- `clearCache`: item キャッシュと ItemStack テンプレートキャッシュを破棄する。

キャッシュは `ConcurrentHashMap` を使用します。読み込み失敗・未検出・成功件数は既存の `LogId.W_5200`, `D_5203`, `I_5202`, `I_5203`, `E_5202` を使用して記録します。

## 2. 所有インスタンス API

- `createEquipmentInstance`, `findEquipmentInstanceById`
- `createRuneInstance`, `findRuneInstanceById`

作成元は `command`, `loot_drop` 等の `source` と `createdBy` を明示します。

## 3. `ItemStackFactory`

`create(model, amount)` はカテゴリと最大スタック数を考慮して ItemStack を生成します。装備・ルーンでは所有インスタンス ID、強化値、超越名、エンチャント、ルーン、耐久値、ステータスロールを Lore と PDC へ反映します。耐久値は現在値/最大値の数値ではなく、白と灰色の中央寄りの短い縦棒 `╎` による20文字幅のバーで表示します。

## 4. 耐久値と修理

`EquipmentDurabilityService` は実ダメージまたはシールドダメージが発生した場合に耐久値を消費します。耐久値 0 の装備は破損表示とし、保存はインベントリと同じ save boundary で非同期に行います。

`EquipmentRepairService` は最大耐久値を上限に回復し、修理費は `ceil(回復耐久値 * (1 + max(0, 最大耐久値 - 300) / 1400))` を使用します。
