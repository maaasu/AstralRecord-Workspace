# 04_1.00-モデル定義

## 1. ドメインモデル

`item` 機能は、アイテムマスタを表す `ItemModel` を中心に、カテゴリ別の拡張定義（`ItemBundle` / `ItemCurrency` / `ItemEquipment` / `ItemConsumable` / `ItemRune`）と、プレイヤーが所有する装備/ルーンのインスタンス（`EquipmentInstance` / `RuneInstance`）、およびセット効果（`SetEffect`）を保持する。

## 2. アイテムカテゴリ

物理名: `ItemCategory`

API 値:

- `bundle`
- `currency`
- `equipment`
- `material`
- `consumable`
- `rune`
- `unknown`（未解決時のフォールバック）

API 値 / コマンド入力値から `ItemCategory.fromApiValue` / `fromInput` で解決する。`unknown` を除いたサポート対象は `supportedApiValues` から取得する。

## 3. アイテム一覧サマリ

物理名: `ItemSummary`

`/api/item` 一覧 API のレスポンス最小形を表現する。

- `id`
- `category`

## 4. アイテムモデル

物理名: `ItemModel`

`ItemModel` はアイテムマスタ（API のアイテム詳細）を表す。カテゴリ別拡張は `bundle / currency / equipment / consumable` を nullable で持つ。`rune` カテゴリの拡張定義はモデル内に組み込まれず、ルーン固有定義は `ItemRune` を別途参照する。

### 4.1 基本項目

- `schemaVersion`
- `id`
- `category`
- `name`
- `icon`
- `rarity`
- `maxStack`
- `saleValue`
- `customModelData`（nullable）
- `lore`（行リスト）
- `unTradeable`
- `unSellable`

### 4.2 カテゴリ別拡張

- `bundle`: [[04_1.00-モデル定義]].アイテムバンドル
- `currency`: [[04_1.00-モデル定義]].アイテム通貨
- `equipment`: [[04_1.00-モデル定義]].アイテム装備
- `consumable`: [[04_1.00-モデル定義]].アイテム消耗品

## 5. アイテムバンドル

物理名: `ItemBundle`

`bundle` カテゴリ拡張。Loot テーブル参照と使用時演出を保持する。

- `lootTableId`（nullable）
- `onUse`: [[04_1.00-モデル定義]].アイテムバンドル使用時演出

### 5.1 アイテムバンドル使用時演出

物理名: `ItemBundleOnUse`

- `sound`
- `effect`
- `particle`

## 6. アイテム通貨

物理名: `ItemCurrency`

`currency` カテゴリ拡張。通貨種別とグループ、失効日時を保持する。

- `type`
- `group`
- `expiresAt`

## 7. アイテム装備

物理名: `ItemEquipment`

`equipment` カテゴリ拡張。装備スロット、ハンドタイプ、装備条件、ステータス、強化・エンチャント・ルーン・状態変化（超越）定義を保持する。

### 7.1 装備本体

- `slot`: `ItemEquipmentSlot`（`WEAPON / HEAD / CHEST / LEGS / FEET / ACCESSORY / TOOL / UNKNOWN`）
- `handType`: `ItemEquipmentHandType`（`ONE / TWO`）
- `requiredLevel`
- `requiredClasses`
- `setId`（nullable）
- `stats`: [[04_1.00-モデル定義]].装備ステータス のリスト
- `durability`: [[04_1.00-モデル定義]].装備耐久値
- `onUse`: [[04_1.00-モデル定義]].装備使用時演出
- `skills`
- `enhance`: [[04_1.00-モデル定義]].強化定義（null なら強化不可）
- `enchant`: [[04_1.00-モデル定義]].エンチャント定義（null ならエンチャント不可）
- `rune`: [[04_1.00-モデル定義]].ルーンスロット定義（null ならルーン装着不可）
- `transcendence`: [[04_1.00-モデル定義]].状態変化定義 のリスト

### 7.2 装備ステータス

物理名: `ItemEquipmentStat`

- `status`
- `type`: `ItemEquipmentStatType`（`FLAT / SCALAR`）
- `min`
- `max`
- 取得時は `rollValue` で範囲内の乱数値、表示時は `displayValue` で `min~max` 表記を返す。

### 7.3 装備耐久値

物理名: `ItemEquipmentDurability`

- `max`
- `consume`

### 7.4 装備使用時演出

物理名: `ItemEquipmentOnUse`

- `leftClickCooldownTicks`（nullable）
- `leftClickSkillId`（nullable）
- `rightClickCooldownTicks`（nullable）
- `rightClickSkillId`（nullable）

### 7.5 強化定義

物理名: `ItemEquipmentEnhance`

- `maxLevel`
- `levels`: [[04_1.00-モデル定義]].強化レベル定義 のリスト

#### 7.5.1 強化レベル定義

物理名: `ItemEquipmentEnhanceLevel`

- `level`
- `statIncrease`: [[04_1.00-モデル定義]].強化ステータス増加 のリスト
- `durabilityBonus`（nullable）

#### 7.5.2 強化ステータス増加

物理名: `ItemEquipmentEnhanceStatIncrease`

- `status`
- `type`
- `min`
- `max`

### 7.6 エンチャント定義

物理名: `ItemEquipmentEnchantDef`

- `maxSlots`

### 7.7 ルーンスロット定義

物理名: `ItemEquipmentRuneDef`

- `maxSlotsRaw`（固定値 or `1~3` 形式のランダム表現）
- `allowedRuneIds`（空なら全許可）

### 7.8 状態変化定義

物理名: `ItemEquipmentTranscendence`

- `name`
- `rank`
- `overridesName`（nullable）
- `overridesEnhanceMaxLevel`（nullable）
- `overridesEnchantMaxSlots`（nullable）

## 8. アイテム消耗品

物理名: `ItemConsumable`

`consumable` カテゴリ拡張。使用時演出と効果リストを保持する。

- `onUse`: [[04_1.00-モデル定義]].消耗品使用時演出
- `effects`: [[04_1.00-モデル定義]].消耗品効果 のリスト

### 8.1 消耗品使用時演出

物理名: `ItemConsumableOnUse`

- `sound`
- `effect`
- `amount`

### 8.2 消耗品効果

物理名: `ItemConsumableEffect`

- `type`: `ItemConsumableEffectType`（`RECOVER / BUFF / UNKNOWN`）
- `rate`
- `value`（nullable）
- `status`（nullable）
- `isPercent`
- `buffId`（nullable）

## 9. アイテムルーン

物理名: `ItemRune`

`rune` カテゴリの単独定義。装着対象スロット、強化要件、ステータス、スキル付与を保持する。

- `targetSlots`
- `requiredEnhanceLevel`
- `stats`: [[04_1.00-モデル定義]].装備ステータス のリスト
- `skills`

## 10. 装備インスタンス

物理名: `EquipmentInstance`

`/api/equipment/instances` から取得する、装備の個別動的データ。アイテムマスタ（`ItemModel`）とは別に、DB に保存されたアカウント固有の装備情報を表す。

### 10.1 項目

- `equipmentInstanceId`
- `accountId`
- `itemId`
- `enhanceLevel`
- `runeMaxSlots`
- `transcendenceRank`
- `durabilityMax`
- `durabilityValue`
- `createdAt`
- `updatedAt`
- `statRolls`: [[04_1.00-モデル定義]].装備ステータスロール のリスト
- `enchants`: [[04_1.00-モデル定義]].装備エンチャント のリスト
- `runes`: [[04_1.00-モデル定義]].装備ルーン のリスト
- `enchantPools`: [[04_1.00-モデル定義]].エンチャントプール のリスト

### 10.2 装備ステータスロール

物理名: `EquipmentStatRoll`

作成時に確定した乱数範囲（min/max）を保持する。

- `statRollId`
- `status`
- `min`
- `max`
- `sortOrder`

### 10.3 装備エンチャント

物理名: `EquipmentEnchant`

- `enchantId`
- `equipmentInstanceId`
- `slotIndex`
- `poolIndex`
- `status`
- `type`
- `value`

### 10.4 装備ルーン

物理名: `EquipmentRune`

- `runeId`
- `equipmentInstanceId`
- `slotIndex`
- `itemId`

### 10.5 エンチャントプール

物理名: `EquipmentEnchantPool`

- `poolIndex`
- `recipeId`（nullable）
- `requiredMaterialItemId`
- `requiredMaterialAmount`
- `requiredCurrency`

## 11. ルーンインスタンス

物理名: `RuneInstance`

`/api/rune/instances` から取得する、ルーンの個別動的データ。`EquipmentInstance` と異なり、ステータスロールは確定した単一値（`value`）を保持する。

### 11.1 項目

- `runeInstanceId`
- `accountId`
- `itemId`
- `createdAt`
- `updatedAt`
- `statRolls`: [[04_1.00-モデル定義]].ルーンステータスロール のリスト

### 11.2 ルーンステータスロール

物理名: `RuneStatRoll`

- `statRollId`
- `status`
- `type`
- `value`
- `sortOrder`

## 12. セット効果

物理名: `SetEffect`

同じ `setId` を持つ装備を複数装着した際に発動する効果を表現する。

- `id`
- `name`
- `pieces`: [[04_1.00-モデル定義]].セット効果ピース のリスト

### 12.1 セット効果ピース

物理名: `SetEffectPiece`

装着数ごとの効果定義。

- `count`
- `stats`: [[04_1.00-モデル定義]].セット効果ステータス のリスト
- `skills`

### 12.2 セット効果ステータス

物理名: `SetEffectStat`

- `status`
- `type`: `ItemEquipmentStatType`
- `value`

## 13. ItemStack PDC

`ItemStackFactory` が生成する `ItemStack` の `PersistentDataContainer` には以下キーで AstralRecord メタ情報を埋め込む。

| キー（NamespacedKey） | 型 | 用途 |
|---|---|---|
| `astralrecord:item_id` | STRING | アイテム ID |
| `astralrecord:icon` | STRING | パケット書き換え対象 Material 名（大文字） |
| `astralrecord:custom_model_data` | INTEGER | カスタムモデルデータ |
| `astralrecord:category` | STRING | アイテムカテゴリ |
| `astralrecord:rarity` | STRING | レアリティ |
| `astralrecord:equipment_instance_id` | STRING | 装備インスタンス ID（装備のみ） |
| `astralrecord:rune_instance_id` | STRING | ルーンインスタンス ID（ルーンのみ） |

サーバ側のベース Material は `Material.PAPER` 固定で、icon は [[04_3.08-アダプタ・リスナー]].SET_SLOT書き換え / WINDOW_ITEMS書き換え により送信パケット上で差し替える。

## 14. 入出力モデル

- API 入力:
  - `POST /api/equipment/instances` 用 JSON（`equipmentId`, `accountId`, `source`, `createdBy`）
  - `POST /api/rune/instances` 用 JSON（`runeId`, `accountId`, `source`, `createdBy`）
- API 出力:
  - `GET /api/item` -> [[04_1.00-モデル定義]].アイテム一覧サマリ のリスト
  - `GET /api/item/{itemId}` -> [[04_1.00-モデル定義]].アイテムモデル
  - `POST/GET /api/equipment/instances` -> [[04_1.00-モデル定義]].装備インスタンス
  - `POST/GET /api/rune/instances` -> [[04_1.00-モデル定義]].ルーンインスタンス
  - `GET /api/seteffect`, `GET /api/seteffect/{setId}` -> [[04_1.00-モデル定義]].セット効果

## 15. 関連 feature とのモデル関係

- `loot`:
  - `ItemBundle.lootTableId` は [[06_1.00-モデル定義]].ルートテーブル を参照する。
- `inventory`:
  - `EquipmentInstance.equipmentInstanceId` / `RuneInstance.runeInstanceId` はインベントリ・装備プリセットからの参照キーとして利用される。
- `account`:
  - `EquipmentInstance.accountId` / `RuneInstance.accountId` は [[02_1.00-モデル定義]].アカウントモデル.uuid と一致する。
- `status`:
  - `ItemEquipmentStat.status`, `EquipmentStatRoll.status` などは `StatusType` に解決可能な識別子として扱う。
