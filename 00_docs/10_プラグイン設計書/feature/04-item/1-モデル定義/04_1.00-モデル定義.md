# 04_1.00-モデル定義

## 1. ドメイン構成

`item` 機能は `ItemModel` を中心に、カテゴリ別定義とプレイヤー所有インスタンスを分離します。

- カテゴリ別定義: `ItemBundle`, `ItemCurrency`, `ItemEquipment`, `ItemConsumable`, `ItemRune`
- 所有インスタンス: `EquipmentInstance`, `RuneInstance`
- セット効果: `SetEffect`

## 2. `ItemCategory`

`bundle`, `currency`, `equipment`, `material`, `consumable`, `rune`, `unknown` を扱います。API 値とコマンド入力は `fromApiValue` / `fromInput` で解決し、対応値は `supportedApiValues` を正とします。

## 3. `ItemModel`

共通項目は `schemaVersion`, `id`, `category`, `name`, `icon`, `rarity`, `maxStack`, `saleValue`, `customModelData`, `lore`, `unTradeable`, `unSellable` です。カテゴリ固有定義は対応する `bundle`, `currency`, `equipment`, `consumable`, `rune` に保持します。

## 4. カテゴリ固有定義

### 4.1 `ItemBundle`

`lootTableId` と `onUse`（`sound`, `effect`, `particle`）を持ちます。

### 4.2 `ItemCurrency`

`type`, `group`, `expiresAt` を持ちます。

ゴールド系の組み込み通貨は `type=gold`, `group=denomination` とし、`gold`（1）、`gold_coin`（10）、`gold_ingot`（100）、`gold_block`（1,000）の4額面を持ちます。

### 4.3 `ItemEquipment`

`slot`, `requiredLevel`, `requiredClasses`, `setId`, `stats`, `durability`, `skills`, `enhance`, `enchant`, `rune`, `transcendence` を持ちます。

- `ItemEquipmentStat`: `status`, `type`, `min`, `max`, `rollValue`, `displayValue`
- `ItemEquipmentDurability`: 最大耐久値と消費設定
- `ItemEquipmentOnUse`: 左右クリックの skill ID と cooldown tick
- `ItemEquipmentEnhance`: `maxLevel` とレベル別ステータス・耐久補正
- `ItemEquipmentEnchantDef`: `maxSlots`
- `ItemEquipmentRuneDef`: `maxSlotsRaw`, `allowedRuneIds`
- `ItemEquipmentTranscendence`: `rank` と名称・強化上限・スロット上限の上書き

武器の通常攻撃 implementation ID は `normal_attack_melee`, `normal_attack_bow`, `normal_attack_magic` を使用します。

### 4.4 `ItemConsumable`

`onUse` と `effects` を持ちます。効果は `type`, `value`, `isPercent`, `buffId` 等で表現します。

### 4.5 `ItemRune`

`targetSlots`, `requiredEnhanceLevel` を持ちます。

## 5. 所有インスタンス

### 5.1 `EquipmentInstance`

`equipmentInstanceId`, `accountId`, `itemId`, `enhanceLevel`, `runeMaxSlots`, `transcendenceRank`, `durabilityMax`, `durabilityValue`, `createdAt`, `updatedAt`, `statRolls`, `enchants`, `runes`, `enchantPools` を保持します。

### 5.2 `RuneInstance`

`runeInstanceId`, `accountId`, `itemId`, `createdAt`, `updatedAt` と確定済みの `RuneStatRoll` を保持します。

## 6. セット効果

`SetEffect` は必要装備数別の `SetEffectPiece` を持ち、各 piece が `SetEffectStat` を保持します。

## 7. ItemStack 永続キー

`ItemStackFactory` は `PersistentDataContainer` に次のキーを保存します。

- `astralrecord:item_id`
- `astralrecord:icon`
- `astralrecord:custom_model_data`
- `astralrecord:category`
- `astralrecord:rarity`
- `astralrecord:equipment_instance_id`
- `astralrecord:rune_instance_id`

## 8. API 契約

- `GET /api/item`, `GET /api/item/{itemId}`
- `POST/GET /api/equipment/instances`
- `POST/GET /api/rune/instances`
- `GET /api/seteffect`, `GET /api/seteffect/{setId}`

ステータス種別は `StatusType` と一致させ、item / equipment / rune / set effect 間で文字列を独自定義しません。
