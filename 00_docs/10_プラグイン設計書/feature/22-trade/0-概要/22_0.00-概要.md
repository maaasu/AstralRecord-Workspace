# 22_0.00-概要

## 1. 目的

トレード機能は、オンライン中の 2 人のプレイヤーが互いにアイテムを提示し、双方が取引準備完了を押した場合にアイテムを交換する機能である。

取引対象は取引 GUI に置かれたアイテムのみとし、取引不可アイテムは取引 GUI へ移動できない。取引中止時、取引 GUI 内のアイテムは元の所有者へ返却する。

## 2. 基本仕様

- プレイヤーはトレード申請を送信できる。
- 相手プレイヤーにはトレード申請が届いている旨のメッセージを送信する。
- 申請メッセージはクリックに対応し、クリック時は `/trade accept` と同等の承諾操作を行う。
- 相手プレイヤーが `/trade accept` を実行すると、2 人の取引 GUI を開く。
- GUI 名は `{相手プレイヤー名}とのトレード` とする。
- 取引 GUI は 54 スロットを使用する。
- 左側 4x6 は自分のアイテム設置スロットとする。
- 右側 4x6 は相手が設置しているアイテムの表示スロットとする。
- 左から 5 列目は 6 行目の取引準備完了ボタンを除き、ダミーアイテムのしきりとする。
- 他 GUI の戻るボタン位置である 6 行目の左から 5 列目を取引準備完了ボタンとする。
- ホットバー中央の閉じるボタン押下時は、即時中止せず取引中止確認 GUI を表示する。

## 3. 取引準備状態

取引準備完了ボタンは、押下したプレイヤーの準備状態を切り替える。

- 相手がすでに取引準備完了を押している場合、押下時に即時取引を成立させる。
- 相手がまだ取引準備完了を押していない場合、自分を準備中にし、相手の GUI には相手が取引準備中であることを示すボタンを表示する。
- 準備中のプレイヤーが再度クリックした場合、取引準備をキャンセルする。
- どちらかのプレイヤーが提示アイテムを変更した場合、双方の準備状態を未準備へ戻す。

## 4. 取引不可アイテム

取引不可アイテムは item feature が提供する取引可否判定で判定する。

- 取引不可アイテムを取引 GUI の自分側スロットへ移動しようとした場合、移動をキャンセルする。
- 取引不可アイテムは相手側表示スロット、しきり、取引準備完了ボタン、取引中止確認 GUI へ移動できない。
- 取引不可の理由はプレイヤー向けメッセージで通知する。

## 5. 対象外

- ゴールドや専用通貨の取引。
- オフラインプレイヤーとの取引。
- 3 人以上の同時取引。
- 取引履歴の永続保存。
