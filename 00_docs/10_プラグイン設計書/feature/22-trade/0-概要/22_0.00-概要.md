# 22_0.00-概要

## 1. 目的

トレード機能は、オンライン中の 2 人のプレイヤーが互いにアイテムまたは Gold を提示し、双方が取引準備完了を押した場合に提示内容を交換する機能である。

取引対象は取引 GUI に置かれたアイテムと、取引 GUI から設定した Gold 金額とする。取引不可アイテムは取引 GUI へ移動できない。取引中止時、取引 GUI 内のアイテムは元の所有者へ返却し、提示 Gold は消費しない。

## 2. 基本仕様

- プレイヤーはトレード申請を送信できる。
- 相手プレイヤーにはトレード申請が届いている旨のメッセージを送信する。
- 申請メッセージはクリックに対応し、クリック時は `/trade accept` と同等の承諾操作を行う。
- 相手プレイヤーが `/trade accept` を実行すると、2 人の取引 GUI を開く。
- GUI 名は `{相手プレイヤー名}とのトレード` とする。
- 取引 GUI は 54 スロットを使用する。
- 左側 4x6 は自分のアイテム設置スロットとする。
- 右側 4x6 は相手が設置しているアイテムの表示スロットとする。
- 左から 5 列目は 6 行目の取引準備完了ボタンを除き、ダミーアイテムのしきりとする。
- 左から 5 列目の中央には Gold 金額設定ボタンを置き、共通 Gold 金額設定 GUI へ遷移する。
- 他 GUI の戻るボタン位置である 6 行目の左から 5 列目を取引準備完了ボタンとする。
- 取引 GUI を直接閉じた時は、即時中止せず取引中止確認 GUI を表示する。専用の閉じるボタンは配置しない。

## 3. 取引準備状態

取引準備完了ボタンは、押下したプレイヤーの準備状態を切り替える。

- 相手がすでに取引準備完了を押している場合、押下時に即時取引を成立させる。
- 相手がまだ取引準備完了を押していない場合、自分を準備中にし、相手の GUI には相手が取引準備中であることを示すボタンを表示する。
- 準備中のプレイヤーが再度クリックした場合、取引準備をキャンセルする。
- どちらかのプレイヤーが提示アイテムまたは提示 Gold 金額を変更した場合、双方の準備状態を未準備へ戻す。

## 4. 取引不可アイテム

取引不可アイテムは item feature が提供する取引可否判定で判定する。

- 取引不可アイテムを取引 GUI の自分側スロットへ移動しようとした場合、移動をキャンセルする。
- 取引不可アイテムは相手側表示スロット、しきり、取引準備完了ボタン、取引中止確認 GUI へ移動できない。
- 取引不可の理由はプレイヤー向けメッセージで通知する。

## 5. Gold 取引

- Gold は取引 GUI の Gold 金額設定ボタンから設定する。
- Gold 金額設定 GUI は共通 GUI とし、今後のマーケット GUI でも再利用できる構造にする。
- 設定可能な Gold 上限は設定時点の所持 Gold とする。
- 成立時は双方の所持 Gold を再検証し、不足している場合は成立させず準備状態を未準備へ戻す。
- 提示アイテムと提示 Gold の両方が双方とも 0 の場合、取引成立メッセージを出さず取引を中止する。

## 6. 対象外

- オフラインプレイヤーとの取引。
- 3 人以上の同時取引。
- 取引履歴の永続保存。

## 追記（2026-06-24）account mode による取引導線制限

- trade feature は通常プレイ導線として扱い、申請、承諾、ready、Gold 設定、再表示、成立処理、GUI 操作は当事者双方が `AccountMode.PLAYER` の場合のみ処理する。
- `AccountMode.ADMIN` / `AccountMode.BUILDER` のプレイヤーが取引 GUI を操作した場合は event を cancel して GUI を閉じる。
- 取引キャンセル、close cleanup、ログアウト cleanup は、既存 session を安全に解消するため account mode に関係なく実行できる。
