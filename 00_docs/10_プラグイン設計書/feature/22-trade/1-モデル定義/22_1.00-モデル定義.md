# 22_1.00-モデル定義

## 1. トレード申請

物理名: `TradeRequest`

| 項目 | 説明 |
|---|---|
| `requestId` | 申請 ID |
| `senderUuid` | 申請者 UUID |
| `senderName` | 申請者表示名 |
| `targetUuid` | 相手プレイヤー UUID |
| `targetName` | 相手プレイヤー表示名 |
| `createdAt` | 申請作成日時 |
| `expiresAt` | 申請期限。作成から 60 秒後 |
| `status` | 申請状態。`PENDING` / `ACCEPTED` / `CANCELLED` / `EXPIRED` |

## 2. トレードセッション

物理名: `TradeSession`

| 項目 | 説明 |
|---|---|
| `sessionId` | セッション ID |
| `playerAUuid` | 参加プレイヤー A の UUID |
| `playerBUuid` | 参加プレイヤー B の UUID |
| `playerAName` | 参加プレイヤー A の表示名 |
| `playerBName` | 参加プレイヤー B の表示名 |
| `playerAItems` | プレイヤー A が提示した ItemStack 一覧 |
| `playerBItems` | プレイヤー B が提示した ItemStack 一覧 |
| `playerAGoldAmount` | プレイヤー A が提示した Gold 金額 |
| `playerBGoldAmount` | プレイヤー B が提示した Gold 金額 |
| `playerAReady` | プレイヤー A の取引準備完了状態 |
| `playerBReady` | プレイヤー B の取引準備完了状態 |
| `status` | セッション状態。`OPEN` / `COMMITTING` / `COMPLETED` / `CANCELLED`。`COMMITTING` 中は GUI close や再操作を受け付けない |
| `openedAt` | GUI 開始日時 |
| `updatedAt` | 最終更新日時 |

## 3. トレード GUI レイアウト

物理名: `TradeGuiLayout`

54 スロット GUI を使用する。スロット番号は Bukkit の 0 始まりに従う。

| 領域 | スロット | 説明 |
|---|---:|---|
| 自分側アイテム設置 | `0-3, 9-12, 18-21, 27-30, 36-39, 45-48` | 自分が取引に出すアイテムを置ける |
| Gold 金額設定 | `22` | 自分と相手の提示 Gold を表示し、クリックで共通 Gold 金額設定 GUI を開く |
| しきり | `4, 13, 31, 40` | ダミーアイテム。クリック移動不可 |
| 取引準備完了ボタン | `49` | 6 行目の左から 5 列目 |
| 相手側アイテム表示 | `5-8, 14-17, 23-26, 32-35, 41-44, 50-53` | 相手が置いているアイテムを表示する。クリック移動不可 |

表示タイトルは閲覧者から見た相手名を使い、`{相手プレイヤー名}とのトレード` とする。

## 4. トレード GUI 表示状態

物理名: `TradeGuiState`

| 項目 | 説明 |
|---|---|
| `viewerUuid` | GUI を見ているプレイヤー UUID |
| `partnerUuid` | 相手プレイヤー UUID |
| `sessionId` | トレードセッション ID |
| `viewerReady` | 閲覧者の準備状態 |
| `partnerReady` | 相手の準備状態 |
| `viewerItems` | 閲覧者側スロットの ItemStack 一覧 |
| `partnerItems` | 相手側表示スロットの ItemStack 一覧 |
| `viewerGoldAmount` | 閲覧者が提示している Gold 金額 |
| `partnerGoldAmount` | 相手が提示している Gold 金額 |

## 5. 取引中止確認 GUI 表示状態

物理名: `TradeCancelConfirmGuiState`

| 項目 | 説明 |
|---|---|
| `viewerUuid` | 確認 GUI を見ているプレイヤー UUID |
| `sessionId` | 中止対象のトレードセッション ID |
| `returnToTrade` | キャンセル選択時に取引 GUI へ戻すかどうか |

確認 GUI は取引中止の実行ボタンと取引 GUI へ戻るボタンを表示する。確認 GUI 上では取引アイテムを移動できない。

## 6. Gold 金額設定 GUI 表示状態

物理名: `GoldAmountSettingGui`

| 項目 | 説明 |
|---|---|
| `sourceKey` | 呼び出し元 GUI を識別するキー。トレードでは `trade` |
| `contextId` | 呼び出し元の対象 ID。トレードでは `sessionId` |
| `viewerUuid` | 設定 GUI を見ているプレイヤー UUID |
| `amount` | 現在設定中の Gold 金額 |
| `maxAmount` | 設定可能な最大 Gold 金額 |

Gold 金額設定 GUI は shared GUI として実装し、トレード以外のマーケット GUI でも同じ描画部品を使用できる。
