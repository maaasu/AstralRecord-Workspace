# 22_2.00-ユースケース

## 1. トレード申請

1. プレイヤーが相手プレイヤーを指定してトレード申請を送信する。
2. [[22_3.00-メソッド仕様]].トレード申請送信 が相手プレイヤーへ申請メッセージを送信する。
3. 申請メッセージはクリック可能にし、クリック時は `/trade accept` を実行する。

## 2. トレード承諾

1. 相手プレイヤーが `/trade accept` または申請メッセージのクリックで承諾する。
2. [[22_3.00-メソッド仕様]].トレード申請承諾 が申請状態と両者のオンライン状態を検証する。
3. 検証に成功した場合、2 人の取引 GUI を開く。

## 3. アイテム提示

1. プレイヤーが自分側アイテム設置スロットへアイテムを置く。
2. [[22_3.00-メソッド仕様]].トレード GUI クリック処理 が取引可否を検証する。
3. 取引可能なアイテムのみ自分側スロットへ移動できる。
4. 提示内容が変わった場合、双方の取引準備状態を未準備へ戻す。
5. 相手側 GUI には提示内容が表示専用として反映される。

## 4. 取引準備完了

1. プレイヤーが slot 49 の取引準備完了ボタンを押す。
2. 相手が未準備の場合、自分を準備中にし、双方の GUI を再描画する。
3. 準備中のプレイヤーが再度押した場合、自分の準備をキャンセルし、双方の GUI を再描画する。
4. 相手が準備中の場合、取引を即時成立させる。

## 5. 取引成立

1. 双方の準備状態が揃ったクリックを契機に取引成立処理を実行する。
2. [[22_3.00-メソッド仕様]].取引成立実行 が双方の提示アイテムとインベントリ空き容量を検証する。
3. 検証に成功した場合、互いの提示アイテムを相手へ付与する。
4. 成立後、取引 GUI を閉じ、双方へ成立メッセージを送信する。

## 6. 取引中止

1. プレイヤーがホットバー中央の閉じるボタンを押す。
2. [[22_3.00-メソッド仕様]].取引中止確認表示 が取引中止確認 GUI を開く。
3. 中止を確定した場合、取引セッションをキャンセルし、提示アイテムを元の所有者へ返却する。
4. 戻る操作を選んだ場合、取引 GUI に戻る。

## 7. 強制中止

1. どちらかのプレイヤーがログアウト、ワールド遷移不可状態、または取引 GUI を不正に閉じた場合、取引を中止する。
2. 提示アイテムは元の所有者へ返却する。
3. 相手プレイヤーへ中止メッセージを送信する。
