# 24_1.00-モデル定義

## 1. 発行要求

API `POST /api/web-auth/challenges` へ次を送信します。

| フィールド | 型 | 内容 |
|---|---|---|
| `userUuid` | UUID | プレイヤーの user UUID |
| `mcid` | String | プレイヤーの MCID |
| `serverId` | String | 発行元サーバー ID |
| `requestedAt` | Instant | Plugin が要求を作成した UTC 時刻 |

## 2. `WebLoginChallengeIssueResult`

| フィールド | 型 | 内容 |
|---|---|---|
| `challengeId` | UUID | API が採番したチャレンジ ID |
| `loginCode` | String | プレイヤーへ表示する一回限りのコード |
| `expiresAt` | Instant | コードの有効期限 |
| `loginUrl` | String | Web ログイン画面 URL |
