# 24_3.04-リポジトリ

クラス名: `WebAuthRepository`
物理名: `createChallenge`

## 1. `WebAuthRepository`

### `createChallenge(UUID userUuid, String mcid, String serverId)`

1. `userUuid`、`mcid`、`serverId`、現在時刻 `requestedAt` を JSON 化する。
2. `POST /api/web-auth/challenges` を呼び出す。
3. HTTP 200 または 201 を成功として扱う。
4. `challengeId`、`loginCode`、`expiresAt`、`loginUrl` を `WebLoginChallengeIssueResult` へ変換する。
5. 割り込み時は割り込み状態を復元し、通信例外とともに `RuntimeException` へ変換する。
