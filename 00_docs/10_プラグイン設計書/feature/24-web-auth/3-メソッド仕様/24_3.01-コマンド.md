# 24_3.01-コマンド

クラス名: `WebAuthCommand`
物理名: `executePlayerCommand`

## 1. `/web login`

クラス: `WebAuthCommand`

| 項目 | 内容 |
|---|---|
| 実行主体 | プレイヤーのみ |
| 引数 | `login` |
| 使用方法 | `/web login` |
| 開始通知 | `PlayerMsgId.P_6402` |
| 成功通知 | `PlayerMsgId.P_6400`（コード、有効期限、URL） |
| 失敗通知 | `PlayerMsgId.P_6401` |

`WebAuthService.issueLoginChallenge` は非同期タスクで呼び出し、プレイヤーへの通知はメインスレッドへ戻してから行います。通知前にプレイヤーがオンラインか確認します。
