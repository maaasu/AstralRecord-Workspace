# 14_3.02-サービス

## `DamageService.handleEntityDamage`
1. `event.getDamager()` / `event.getEntity()` を `resolveEntity(...)` で `AstEntity` に解決する
2. 攻撃者・被弾者の双方が unmanaged なら何もしない
3. どちらかが managed entity なら `event.setDamage(0)` と `event.setCancelled(true)` を行う
4. 被弾者が managed entity で、攻撃者も managed なら `attack(attacker, victim, MELEE, PHYSICAL)` を呼ぶ
5. 被弾者が managed entity で、攻撃者が unmanaged なら `applyDamage(attacker, victim, event.getDamage(), MELEE, PHYSICAL)` を呼ぶ

## `DamageService.attack`
1. 攻撃者ステータス依存の custom 通常ダメージ入口として使う
2. `DamageScaling.ATTACKER_STATUS` で `DamageContext` を構築する
3. `DamageCalculator.calculate(...)` で最終ダメージを確定する
4. custom player なら `StatusService.consumeHp(...)`、custom mob なら `MobInstance.currentHealth` へ反映する

5. custom mob へ有効ダメージを与えた場合は Bukkit 実体へ hurt effect を再生する
6. custom mob の HP が 0 以下になった場合は death effect / particle / sound を再生し、`MobCombatService.handleDeath(...)` でドロップ抽選と破棄を行う
7. 討伐後は `DisplayTextService.spawnResultText(...)` で mob 名、drop、exp、money を含むリザルト TextDisplay を短時間表示する

## `DamageService.applyDamage`
1. 外部で基礎値が確定している direct damage の入口として使う
2. `DamageScaling.FIXED` で `DamageContext` を構築する
3. 攻撃者が存在しても、基礎値へ攻撃者ステータスは上乗せしない
4. 最終ダメージだけ防御計算へ通して反映する

## `DamageService.applyEffectDamage`
1. DoT / デバフなど継続系ダメージ専用の簡易入口として使う
2. 内部では `applyDamage(..., FIXED)` を呼ぶ
3. 攻撃種別は damage 計算上のスケーリングに使わず、固定値ダメージとして扱う

## `DamageService.resolveEntity`
1. Bukkit `Player` で `AstPlayerCache` に存在するものは `AstEntity.player(...)` に解決する
2. `MobService.getInstanceByEntity(...)` で custom mob が引けるものは `AstEntity.mob(...)` に解決する
3. それ以外は `AstEntity.bukkit(...)` として扱う

## `DamageCalculator.calculate`
1. `DamageScaling.ATTACKER_STATUS` の場合は `ATTACK` と `AttackType` 対応ステータスから攻撃力を構成する
2. `DamageScaling.FIXED` の場合は `baseDamage` をそのまま採用する
3. `DamageType.TRUE` 以外では被弾者の `DEFENSE` / `MAGIC_DEFENSE` を用いて軽減する
4. 結果を `Math.max(0.0, damage)` で下限クランプする
