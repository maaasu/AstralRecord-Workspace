# 14_3.02-サービス

## エンティティ間ダメージ確定
クラス名: `DamageService`
物理名: `handleEntityDamage`

1. 引数の `EntityDamageByEntityEvent` の攻撃者・被弾者を [[14_1.00-モデル定義]].AstEntity に解決する
2. [[14_3.02-サービス]].ダメージ計算 を呼び出して [[14_1.00-モデル定義]].ダメージ計算結果 を取得する
3. 被弾者が `AstPlayer` / `MobInstance` の場合は AstralRecord 側の HP に最終ダメージを反映し、Bukkit イベントのダメージを `0.0` にしてキャンセルする
4. 被弾者が Bukkit エンティティのみの場合は `event.setDamage(...)` に最終ダメージを反映する
5. メインスレッドで動作する前提のため、本メソッド内で SQL/YAML 等の I/O は行わない
6. 必要なステータス・装備・バフ情報は事前にメモリへロード済みの値（[[07-status]] のキャッシュ等）を参照する

## 汎用ダメージ適用
クラス名: `DamageService`
物理名: `attack` / `applyDamage`

1. `attack(AstEntity attacker, AstEntity victim, AttackType attackType, DamageType damageType)` は攻撃者ステータスを基礎値としてダメージを確定する
2. `applyDamage(AstEntity? attacker, AstEntity victim, double baseDamage, AttackType attackType, DamageType damageType)` は外部指定の基礎ダメージを受け取りダメージを確定する
3. `AstPlayer` が関与する場合は `StatusService.getStatus` でステータスを解決してから計算する
4. 被弾者が `AstPlayer` の場合は `StatusService.consumeHp` で現在 HP を減算する
5. 被弾者が `MobInstance` の場合は `currentHealth` を減算し、0 以下で `MobState.DEAD` へ遷移する
6. 攻撃者が `AstPlayer` かつ被弾者が `MobInstance` の場合は脅威値を加算し、IDLE 状態なら AGGRO へ遷移する
7. Bukkit エンティティのみの場合は計算結果を返し、HP 反映は呼び出し元イベントに委ねる

## ダメージ計算
クラス名: `DamageCalculator`
物理名: `calculate`

1. 引数の [[14_1.00-モデル定義]].ダメージコンテキスト から `baseDamage` を取り出す
2. 攻撃者が管理対象エンティティの場合、`ATTACK * (1 + 攻撃種別に対応する主能力 / 100) + 攻撃種別別攻撃力` を攻撃力として算出し、`baseDamage` と比較して大きい方を使用する
3. 被弾者が管理対象エンティティで、ダメージ種別が `TRUE` 以外の場合、物理防御または魔法防御の `0.5` 倍を軽減値として差し引く
4. 管理対象エンティティへの防御適用後ダメージは最低 `1.0` とする
5. 結果を `Math.max(0.0, damage)` で下限クランプする
6. [[14_1.00-モデル定義]].ダメージ計算結果 を構築して返す
7. Bukkit API には依存せず、入力モデルの数値情報のみから計算を行う

## サービス初期化
クラス名: `DamageService`

`DamageService` は以下の依存を受け取って構築する。

| 物理名 | 役割 |
|---|---|
| `DamageService(StatusService)` | プレイヤーのステータス参照・HP 反映に使用するサービスを受け取る |

プレイヤー HP の実値更新は [[07-status]] 配下 `StatusService` の責務であり、`DamageService` は `StatusService.consumeHp` を経由して反映する。
