# 14_3.02-サービス

## エンティティ間ダメージ確定
クラス名: `DamageService`
物理名: `handleEntityDamage`

1. 引数の `EntityDamageByEntityEvent` から [[14_1.00-モデル定義]].ダメージコンテキスト を構築する
2. [[14_3.02-サービス]].ダメージ計算 を呼び出して [[14_1.00-モデル定義]].ダメージ計算結果 を取得する
3. `event.setDamage(...)` に最終ダメージを反映する
4. メインスレッドで動作する前提のため、本メソッド内で SQL/YAML 等の I/O は行わない
5. 必要なステータス・装備・バフ情報は事前にメモリへロード済みの値（[[07-status]] のキャッシュ等）を参照する

## ダメージ計算
クラス名: `DamageCalculator`
物理名: `calculate`

1. 引数の [[14_1.00-モデル定義]].ダメージコンテキスト から `baseDamage` を取り出す
2. 攻撃力 / 防御力 / クリティカル / 属性補正等を本メソッド内で適用する（現状は未実装で `baseDamage` をそのまま使用）
3. 結果を `Math.max(0.0, damage)` で下限クランプする
4. [[14_1.00-モデル定義]].ダメージ計算結果 を構築して返す
5. Bukkit API には依存せず、入力モデルの数値情報のみから計算を行う

## サービス初期化
クラス名: `DamageService`

`DamageService` は以下の依存を受け取って構築する。

| 物理名 | 役割 |
|---|---|
| `DamageService(StatusService)` | 被弾者の現在ステータス参照・将来の HP 反映に使用するサービスを受け取る |

HP/MP/エネルギーの実値更新は [[07-status]] 配下 `StatusService` の責務であり、本サービスから直接プレイヤーの内部状態を書き換えない。
