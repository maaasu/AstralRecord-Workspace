# 14_0.00-概要
## 1. 位置づけ
`combat` 機能は、AstralRecord 内の戦闘ダメージ確定を一元化する。
通常攻撃、Mob 攻撃、スキル直撃、DoT（継続ダメージ）など、ダメージを与える処理は原則 `DamageService` を入口にし、バニラの `EntityDamageByEntityEvent` / `Entity#damage(...)` を正本にしない。

## 2. 責務
- 攻撃者・被弾者を `AstEntity` に統一し、`AstPlayer` / `MobInstance` / Bukkit Entity を同一 API で扱う
- managed entity に対するダメージを `DamageCalculator` で計算し、プレイヤー HP または Mob HP に直接反映する
- 通常攻撃用の攻撃者ステータス依存ダメージと、DoT 用の固定値ダメージを両立させる
- バニラ接触ダメージイベントは managed entity が関わる場合のみ遮断し、custom combat として再適用する

## 3. 非責務
- SQL / YAML I/O
- バフ定義そのものの管理
- スキル選択 UI や Mob AI の意思決定
- プレイヤー死亡 / リスポーン / ドロップ配布の最終仕様

## 4. 実装構成
- `service/DamageService`
  - custom damage の単一入口
  - `attack(...)` で攻撃者ステータス依存ダメージを処理する
  - `applyDamage(...)` / `applyEffectDamage(...)` で固定値ダメージを処理する
  - `resolveEntity(...)` で Player / custom Mob / Bukkit Entity を解決する
- `service/DamageCalculator`
  - `DamageScaling` に応じて「攻撃者ステータス使用」か「固定値使用」かを切り替える
- `event/CombatDamageEventHandler`
  - `EntityDamageByEntityEvent` を受けて `DamageService.handleEntityDamage(...)` へ委譲する
- `feature/item/executor/WeaponAttackSkillExecutor`
  - 通常攻撃の見た目と当たり判定を処理し、範囲内の managed target へ `DamageService.attack(...)` を直接呼ぶ

## 5. 関連 feature
- `status`
  - プレイヤー HP の現在値更新に `StatusService.consumeHp(...)` を使う
- `mob`
  - `MobService.getInstanceByEntity(...)` で custom mob 解決を行う
  - Mob HP は `MobInstance.currentHealth` を直接更新する
- `skill`
  - executor から `DamageService` を呼ぶ
