# 14_9.00-未決事項

## 1. 攻撃種別 / ダメージ種別の判定方法

`DamageContext.from(EntityDamageByEntityEvent)` は現状、攻撃種別を `MELEE`、ダメージ種別を `PHYSICAL` に固定している。

- 武器カテゴリ・スキル文脈・Mob 攻撃定義から `AttackType` / `DamageType` を判定する仕組みは未整備。
- 将来 [[14_1.00-モデル定義]].攻撃種別 を判定するための入力（装備種別 / スキル定義 / Mob 攻撃定義）の正本所在を確定する必要がある。

## 2. ダメージ計算式の具体仕様

`DamageCalculator.calculate` は現状 `Math.max(0.0, baseDamage)` の下限クランプのみ実装。

- `ATTACK` / `MELEE_ATTACK` / `RANGED_ATTACK` / `MAGIC_ATTACK` の最終攻撃力算出ロジックは [[07-status]] 配下で未確定（`MELEE_ATTACK` 等は派生値）。
- 会心 / 超会心 / 最終ダメージ確率 / 命中・回避判定の発生順序と乗算順序は未確定。
- セット効果・バフ・装備強化の補正適用順序は [[07-status]] 側の集計と整合させる必要がある。

## 3. HP/MP/エネルギーへの反映経路

- 現状 `DamageService.handleEntityDamage` は `event.setDamage(...)` のみを行い、`AstPlayer` の `StatusSnapshot.currentHp` への反映は行わない。
- プレイヤー被弾時のバニラダメージは [[03-player]] 配下 `PlayerVanillaDamageBlockEventHandler` がキャンセルしているため、本機能から `StatusService.consumeHp` を呼び出して HP を反映する経路が必要。
- 呼び出し優先度・対象判定（プレイヤー / Mob）・致死判定との連動は未確定。

## 4. スキル / Mob 攻撃からの直接呼び出し

- `skill` feature の `SkillExecutor` 内で発生するダメージを `DamageService` 経由で確定するための API は未整備。
- `mob` feature の AI から行うダメージも同様。
- `DamageContext` のファクトリを Bukkit イベント以外（スキル発動コンテキスト / Mob 攻撃定義）からも構築できるよう拡張する必要がある。

## 5. modifier 階層の導入可否

- 補正項目（会心 / 防御 / バフ / 装備 / スキル）の増加に応じて `modifier/` パッケージへ分離する案がある。
- 現状は最小構成のため未導入。導入条件と単位粒度は要検討。
