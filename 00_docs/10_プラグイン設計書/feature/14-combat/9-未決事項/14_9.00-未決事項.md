# 14_9.00-未決事項

## 1. 攻撃種別 / ダメージ種別の判定方法

`DamageContext.from(EntityDamageByEntityEvent)` は現状、攻撃種別を `MELEE`、ダメージ種別を `PHYSICAL` に固定している。

- 武器カテゴリ・スキル文脈・Mob 攻撃定義から `AttackType` / `DamageType` を判定する仕組みは未整備。
- 将来 [[14_1.00-モデル定義]].攻撃種別 を判定するための入力（装備種別 / スキル定義 / Mob 攻撃定義）の正本所在を確定する必要がある。

## 2. ダメージ計算式の具体仕様

`DamageCalculator.calculate` は現状、攻撃者の `ATTACK` と主能力スケーリング、防御側の `DEFENSE` / `MAGIC_DEFENSE` による基本軽減までを実装している。

- `MELEE_ATTACK` / `RANGED_ATTACK` / `MAGIC_ATTACK` の派生値を [[07-status]] 側で算出するか、`combat` 側で算出し続けるかは未確定。
- 会心 / 超会心 / 最終ダメージ確率 / 命中・回避判定の発生順序と乗算順序は未確定。
- セット効果・バフ・装備強化の補正適用順序は [[07-status]] 側の集計と整合させる必要がある。

## 3. HP/MP/エネルギーへの反映経路

- `DamageService` は `AstPlayer` 被弾時に `StatusService.consumeHp` を呼び出し、`MobInstance` 被弾時に `currentHealth` を減算する。
- プレイヤー HP が 0 になった場合の死亡演出・リスポーン・デスペナルティは未確定。
- Mob 死亡時のドロップ確定と `DamageService` の連携範囲は未確定。

## 4. スキル / Mob 攻撃からの直接呼び出し

- `DamageService.attack` / `DamageService.applyDamage` により、`SkillExecutor` や `mob` feature から `AstEntity` を渡して直接ダメージを確定できる。
- 既存の weapon attack / Mob AI がどのタイミングで `DamageService` を呼ぶか、当たり判定・クールダウンとの接続仕様は未確定。

## 5. modifier 階層の導入可否

- 補正項目（会心 / 防御 / バフ / 装備 / スキル）の増加に応じて `modifier/` パッケージへ分離する案がある。
- 現状は最小構成のため未導入。導入条件と単位粒度は要検討。
