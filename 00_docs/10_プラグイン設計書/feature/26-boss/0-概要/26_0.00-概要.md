# ボス概要

ボス機能は、既存 `mob` feature の `MobCategory.BOSS` を対象に、通常 Mob とは別の挑戦管理、戦闘中状態、結果表示、報酬対象、インスタンスワールド生成・破棄を扱う機能である。

## 目的

- プレイヤーまたはパーティーが、ボスマスターに定義された挑戦地点からボス挑戦を開始できる。
- ボス挑戦ごとに制限時間、デスカウント上限、参加者、ボスフィールド、ボススポーン地点、プレイヤー入場地点を固定する。
- ボスフィールドは `WorldMasterData` を元にパーティー単位の一時ワールドとして生成し、挑戦終了後に破棄する。
- 挑戦中は残り時間、残りデスカウント、ボス HP、フェーズ、与ダメージを表示対象とする。
- 討伐成功時のみ、ボスマスターの `drops` を使用して参加者へ同条件の報酬を付与する。

## 対象範囲

| 区分 | 対象 |
|---|---|
| 挑戦受付 | ボス挑戦座標、スニーク受付、ソロ挑戦、パーティー挑戦 |
| 待機 | `boss.hubWorldId` への転送、待機フラグ、パーティーメンバー集合待ち |
| インスタンス | ボスフィールドコピー、ワールドロード、ボス・プレイヤー転送、破棄 |
| 戦闘 | ボス状態、制限時間、デスカウント、ダメージ集計、ログアウト制御 |
| 結果 | 成功/失敗理由、与ダメージ、死亡回数、報酬処理、退場 |
| 運用 | `/boss instances`、`/boss stop <partyId>`、起動時残存ワールド掃除 |

## 対象外

- ボス固有のフェーズ遷移、攻撃パターン、専用ギミックの詳細実装。
- 強制開始コマンド。
- 管理者コマンドによる残存ワールド掃除。
- ボス挑戦開始後の途中参加と再入場。
- 与ダメージ量、参加時間、職業、役割による報酬差。

## 構成方針

| 構成 | 主な責務 |
|---|---|
| プレイヤーロジック | 参加者固定、挑戦条件、待機フラグ、死亡制御、制限時間、結果表示、報酬対象 |
| ワールドロジック | ボスフィールドコピー、インスタンス生成、ワールドロード、転送、破棄、起動時掃除 |

プレイヤーロジックは「誰が、どの条件で、どの状態としてボスに挑戦しているか」を管理する。
ワールドロジックは「どのボスフィールドを、どのパーティー用に、どのように生成・破棄するか」を管理する。

## データ正本

| 値 | 正本 |
|---|---|
| ボス ID / 表示名 / 基礎 HP / 基礎攻撃力 / ドロップ / 経験値 | `40_filebase/40.features.mob/boss/*.yml` |
| 制限時間 / デスカウント上限 / 挑戦座標 / 入場座標 / スポーン座標 / スケーリング | ボスマスターの `challenge` |
| ボス待機ハブ | `config.yml` の `boss.hubWorldId` |
| インスタンス生成元 / 生成先 / 可否 | `WorldMasterData` |

## 表示方針

| 場面 | 表示 |
|---|---|
| 挑戦地点 | `challenge.entryLocation` と `entryRadiusMeters` の円をパーティクル表示 |
| ハブ待機中 | タイトルバーで `集合待ち: <集合済み>/<参加予定者数>` を表示 |
| 挑戦中 | ボスバーまたはタイトルで残り時間、残りデスカウント、ボス HP、現在フェーズを表示 |
| 結果 | ボス名、成功/失敗理由、討伐時間または経過時間、合計与ダメージ、個人別与ダメージ、死亡回数を表示 |
