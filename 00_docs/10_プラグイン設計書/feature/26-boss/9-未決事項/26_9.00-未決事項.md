# 26_9.00-未決事項

## 1. 復帰仕様

- ボス挑戦中に死亡した参加者を復帰させる場合の復帰待機時間。
- 復帰地点を `playerSpawnLocation` に固定するか、別の復帰地点を `challenge` に追加するか。
- 復帰時の HP / MP / EN / Shield の回復量。
- 復帰させない設計にする場合、観戦、退場、パーティー全体失敗のどれを採用するか。

## 2. 表示媒体

- 挑戦中表示にチャット、タイトル、ボスバー、GUI のどれを使うか。
- ボス HP と現在フェーズはボスバーに寄せるか、タイトル表示に含めるか。
- 結果表示をチャットだけで行うか、GUI またはタイトル演出を併用するか。

## 3. ボス固有ロジック

- フェーズ遷移、攻撃パターン、専用ギミックを `feature/boss` 配下のクラスで個別実装するか、`mob` / `skill` feature の定義で寄せるか。
- HP 閾値、行動クールダウン、ギミック状態のモデルを汎用化するか、ボスごとに専用クラス化するか。

## 4. 退場先

- 成功/失敗後の退場先を `boss.hubWorldId` にするか、参加前のワールド・座標へ戻すか。
- フィールド生成失敗時に、既にハブへ移動したプレイヤーをどこへ戻すか。

## 5. 報酬付与の詳細境界

- 通常 Mob と同じ報酬処理を再利用する際、ボス用の豪華演出をどのサービスで差し込むか。
- お金・経験値・アイテム付与の一部だけが失敗した場合の再試行または補填方針。

## 6. 管理者権限

- `/boss instances` と `/boss stop <partyId>` を実行できる `user.permission` の閾値。
- account mode が `ADMIN` / `BUILDER` の場合もボス挑戦に参加できるか。

本設計はボスマスターに `challenge` を追加する方針を定義しているが、`40_filebase/40.features.mob/boss/boss.YAMLスキーマ定義.md` はまだ更新していない。実装時は filebase schema と API DTO の同期要否を確認する。
