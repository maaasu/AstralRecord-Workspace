# ボス機能 理想モデル定義

## ボス挑戦設定

物理名: `BossChallengeConfig`

| フィールド | 型 | 必須 | 内容 |
|---|---:|:---:|---|
| `fieldWorldId` | String | ○ | `WorldType.BOSS_FIELD` かつ `instanceEnabled=true` の `WorldMasterData.id` |
| `entryLocation` | `BossLocation` | ○ | 受付地点。`worldId` は WorldMasterData ID または Bukkit world 名 |
| `entryRadius` | double | ○ | 受付半径。最小 0.5 |
| `playerSpawnLocation` | `BossLocation` | ○ | ボスフィールド内の参加者入場地点 |
| `bossSpawnLocation` | `BossLocation` | ○ | ボスフィールド内のボス spawn 地点 |
| `partyMin` | int | ○ | 最小参加人数。最小 1 |
| `partyMax` | int | ○ | 最大参加人数。`partyMin` 未満にはしない |
| `timeLimitSeconds` | long | ○ | 制限時間。最小 30 秒 |
| `deathLimit` | int | 将来 | 挑戦全体の死亡上限。未指定時は 0 で死亡上限なし |
| `reviveDelaySeconds` | int | 将来 | 復帰待機秒数。未指定時は 10 秒 |
| `scaling` | `BossScalingConfig` | ○ | 参加者数補正 |

## 参加者数補正

物理名: `BossScalingConfig`

| フィールド | 型 | 内容 |
|---|---:|---|
| `enabled` | boolean | 参加者数補正を使うか |
| `healthPerExtraPlayer` | double | 2 人目以降 1 人ごとの HP 増加率。単位は % |
| `attackPerExtraPlayer` | double | 2 人目以降 1 人ごとの攻撃倍率増加率。単位は % |

補正式:

```text
extraPlayers = max(0, participantCount - 1)
healthMultiplier = 1.0 + extraPlayers * healthPerExtraPlayer / 100
attackMultiplier = 1.0 + extraPlayers * attackPerExtraPlayer / 100
```

HP 補正はボス spawn 直後の現在 HP に適用する。攻撃補正は `MobInstance` のセッション内攻撃倍率として保持し、Mob がプレイヤーへ与えるダメージ計算時に `ATTACK` へ乗算する。

## ボス挑戦インスタンス

物理名: `BossChallengeInstance`

| フィールド | 内容 |
|---|---|
| `challengeId` | 挑戦ごとの UUID |
| `partyKey` | `solo:<playerUuid>` または `party:<partyId>` |
| `initiatorId` | 受付したプレイヤー UUID |
| `bossTemplate` | 対象ボスマスタ |
| `config` | 受付時点の挑戦設定 |
| `participantIds` | 受付時点のオンライン参加者 UUID 固定リスト |
| `state` | `PREPARING` / `IN_PROGRESS` / `RESULT_WAITING` / `ENDED` |
| `field` | 生成済みボスフィールド |
| `bossMobInstanceId` | spawn したボス Mob インスタンス ID |
| `damageByPlayerId` | 参加者別有効ダメージ |
| `deathCountByPlayerId` | 将来: 参加者別死亡回数 |
| `currentDeathCount` | 将来: 挑戦全体の死亡回数 |
| `resultWaitEndsAtMs` | 討伐結果表示終了時刻 |

## 終了理由

物理名: `BossChallengeEndReason`

| 値 | 成功 | 内容 |
|---|:---:|---|
| `DEFEATED` | ○ | ボス HP が 0 になった |
| `TIME_LIMIT` | - | 制限時間を超過した |
| `NO_PARTICIPANTS` | - | フィールド内に参加者がいなくなった |
| `FIELD_PREPARE_FAILED` | - | フィールド設定不正、コピー失敗、ロード失敗 |
| `TRANSFER_FAILED` | - | 必須参加者のフィールド転送に失敗 |
| `BOSS_SPAWN_FAILED` | - | ボス spawn に失敗 |
| `DEATH_LIMIT` | - | 将来: 死亡回数上限を超過 |
| `ADMIN_STOP` | - | 管理者が停止 |
| `PLUGIN_SHUTDOWN` | - | プラグイン停止 |

## 報酬対象モデル

物理名: `BossRewardRecipient`

将来追加するボス報酬専用モデル。討伐時点の参加者状態から、以下を満たすプレイヤーだけを報酬対象にする。

- `participantIds` に含まれる。
- オンラインである。
- 討伐時点でボスフィールドと同一 Bukkit world にいる。
- 管理者モード、観戦者、途中参加者ではない。

ダメージ量、参加時間、職業、役割による報酬差は付けない。
