# 26_1.00-モデル定義

## 1. ドメインモデル

`boss` feature は、ボスマスターを拡張して扱う **定義系**、挑戦ごとの **実行系**、ワールド生成の **インスタンス系**、集計表示の **統計系** で構成する。

| 区分 | モデル | 役割 |
|---|---|---|
| 定義系 | [[26_1.00-モデル定義]].ボス挑戦設定 | ボスマスターの `challenge` |
| 実行系 | [[26_1.00-モデル定義]].ボス挑戦インスタンス / [[26_1.00-モデル定義]].ボス参加者 | 挑戦中の状態 |
| インスタンス系 | [[26_1.00-モデル定義]].ボスフィールドインスタンス / [[26_1.00-モデル定義]].ボス待機フラグ | ハブ待機と一時ワールド |
| 統計系 | [[26_1.00-モデル定義]].ボス結果統計 | 結果表示と報酬対象判定 |

## 2. ボス挑戦設定

物理名: `BossChallengeConfig`

ボスマスター `40_filebase/40.features.mob/boss/*.yml` の `challenge` として定義する。`MobTemplate.category = BOSS` の場合だけ参照する。

| 項目 | 型 | 説明 |
|---|---|---|
| `entryLocation` | [[26_1.00-モデル定義]].ボス位置 | ボス挑戦受付地点。`worldId` 必須 |
| `entryRadiusMeters` | `double` | 受付判定半径。未指定時は `2.0` |
| `hubMessage` | `String?` | ハブ待機中タイトル表示の補助文言 |
| `battleWorldId` | `String` | `WorldMasterData.id`。`worldType = BOSS_FIELD` かつ `instanceEnabled = true` が必須 |
| `playerSpawnLocation` | [[26_1.00-モデル定義]].ボス位置 | ボスフィールド内の参加者転送先。`worldId` は `battleWorldId` から解決するため任意 |
| `bossSpawnLocation` | [[26_1.00-モデル定義]].ボス位置 | ボスフィールド内のボススポーン地点。`worldId` は `battleWorldId` から解決するため任意 |
| `timeLimitSeconds` | `long` | 制限時間。`IN_PROGRESS` 遷移時から計測 |
| `deathLimit` | `int` | パーティー共有デスカウント上限 |
| `reviveDelaySeconds` | `long` | 上限未満の死亡時にフィールドへ復帰するまでの秒数。既定値 5 |
| `scaling` | [[26_1.00-モデル定義]].ボススケーリング設定 | 参加人数補正 |

### YAML 例

```yaml
challenge:
  entryLocation:
    worldId: v1.central_base
    x: 100.5
    y: 64.0
    z: -32.5
    yaw: 0.0
    pitch: 0.0
  entryRadiusMeters: 2.0
  hubMessage: "&eパーティーメンバーの集合を待機しています"
  battleWorldId: v1.dark_dragon_field
  playerSpawnLocation:
    x: 0.5
    y: 80.0
    z: 0.5
    yaw: 180.0
    pitch: 0.0
  bossSpawnLocation:
    x: 0.5
    y: 80.0
    z: -20.5
    yaw: 0.0
    pitch: 0.0
  timeLimitSeconds: 600
  deathLimit: 5
  reviveDelaySeconds: 5
  scaling:
    hpPerAdditionalMemberRate: 0.45
    attackPerAdditionalMemberRate: 0.15
```

## 3. ボス位置

物理名: `BossLocation`

| 項目 | 型 | 説明 |
|---|---|---|
| `worldId` | `String?` | `WorldMasterData.id`。挑戦受付地点では必須 |
| `x` / `y` / `z` | `double` | 座標 |
| `yaw` / `pitch` | `float` | 向き |

## 4. ボススケーリング設定

物理名: `BossScalingConfig`

| 項目 | 型 | 初期値 | 説明 |
|---|---|---:|---|
| `hpPerAdditionalMemberRate` | `double` | `0.45` | 2 人目以降 1 人あたりの HP 増加率 |
| `attackPerAdditionalMemberRate` | `double` | `0.15` | 2 人目以降 1 人あたりの攻撃力増加率 |

計算式:

```text
補正HP = 基礎HP * (1 + max(0, 参加人数 - 1) * hpPerAdditionalMemberRate)
補正攻撃力 = 基礎攻撃力 * (1 + max(0, 参加人数 - 1) * attackPerAdditionalMemberRate)
```

基礎 HP は `baseStats[].status = MAX_HEALTH`、基礎攻撃力は `baseStats[].status = ATTACK` を使用する。途中参加を許可しないため、挑戦開始後に人数補正は変更しない。

## 5. ボス挑戦インスタンス

物理名: `BossChallengeInstance`

| 項目 | 型 | 説明 |
|---|---|---|
| `challengeId` | `UUID` | 挑戦インスタンス ID |
| `bossId` | `String` | ボスマスター ID |
| `partyId` | `String` | パーティー ID。ソロ挑戦時は一人パーティー相当の内部 ID |
| `leaderPlayerId` | `UUID` | 受付時のリーダー。ソロ挑戦時は本人 |
| `state` | [[26_1.00-モデル定義]].ボス挑戦状態 | 現在状態 |
| `expectedParticipantIds` | `Set<UUID>` | 受付時点の参加予定者 |
| `participants` | `Map<UUID, BossParticipant>` | 挑戦開始時にボスフィールドへ転送された参加者 |
| `fieldInstance` | [[26_1.00-モデル定義]].ボスフィールドインスタンス | 一時ワールド情報 |
| `bossMobInstanceId` | `UUID?` | 生成した [[12_1.00-モデル定義]].Mob インスタンス ID |
| `acceptedAt` | `Instant` | 挑戦受付時刻 |
| `startedAt` | `Instant?` | `IN_PROGRESS` 遷移時刻 |
| `endedAt` | `Instant?` | 終了時刻 |
| `currentDeathCount` | `int` | パーティー共有デスカウント |
| `endReason` | [[26_1.00-モデル定義]].ボス挑戦終了理由 `?` | 終了理由 |
| `statistics` | [[26_1.00-モデル定義]].ボス結果統計 | ダメージ・死亡回数 |

## 6. ボス挑戦状態

物理名: `BossChallengeState`

| 値 | 意味 |
|---|---|
| `ACCEPTED` | 挑戦受付済み。参加予定者と待機フラグを作成済み |
| `WAITING_IN_HUB` | 参加予定者のハブ集合待ち |
| `CREATING_FIELD` | ボスフィールドコピー・ロード中 |
| `READY_TO_ENTER` | フィールド生成完了、全員集合待ちまたは転送直前 |
| `IN_PROGRESS` | ボス戦進行中。制限時間カウント中 |
| `RESULT_WAITING` | 討伐成功後の結果確認待機中。15 秒間フィールドを保持する |
| `ENDING` | 結果表示、報酬、退場、破棄の処理中 |
| `ENDED` | 完了 |

## 7. ボス挑戦終了理由

物理名: `BossChallengeEndReason`

| 値 | 成否 | 意味 |
|---|---|---|
| `DEFEATED` | 成功 | ボスを討伐した |
| `TIME_LIMIT` | 失敗 | 残り時間が 0 以下になった |
| `DEATH_LIMIT` | 失敗 | `currentDeathCount >= deathLimit` に達した |
| `NO_PARTICIPANTS` | 失敗 | ボスフィールド内の参加者が 0 人になった |
| `ADMIN_STOP` | 失敗 | 管理者が強制終了した |
| `FIELD_CREATE_FAILED` | 失敗 | インスタンス生成に失敗した |
| `TRANSFER_FAILED` | 失敗 | 挑戦開始前の必須転送に失敗した |
| `PLUGIN_SHUTDOWN` | 失敗 | サーバー停止またはプラグイン無効化で終了した |

## 8. ボス参加者

物理名: `BossParticipant`

| 項目 | 型 | 説明 |
|---|---|---|
| `playerId` | `UUID` | プレイヤー UUID |
| `displayName` | `String` | 結果表示用の名前 |
| `joinedFieldAt` | `Instant` | ボスフィールド入場時刻 |
| `leftFieldAt` | `Instant?` | ログアウトまたは退場時刻 |
| `active` | `boolean` | ボスフィールドで挑戦中か |
| `damageDealt` | `double` | 有効与ダメージ |
| `deathCount` | `int` | 個人死亡回数 |
| `rewardEligible` | `boolean` | 報酬対象か |

ボス挑戦開始後にパーティーへ参加したプレイヤーは `expectedParticipantIds` と `participants` に含めない。
待機会場でログアウト、パーティー離脱、キック、または会場外へ移動した参加予定者は、フィールド入場時に `participants` から除外する。実参加人数が `partyMin` 未満の場合は挑戦を開始しない。

## 9. ボス待機フラグ

物理名: `BossWaitingFlag`

| 項目 | 型 | 説明 |
|---|---|---|
| `bossId` | `String` | 対象ボス ID |
| `partyId` | `String` | 対象パーティー ID |
| `playerId` | `UUID` | 対象プレイヤー |
| `acceptedAt` | `Instant` | 受付時刻 |
| `hubWorldId` | `String` | `config.yml` の `boss.hubWorldId` |

待機フラグがないプレイヤーは、同じハブワールドにいてもボス待機中とは判定しない。待機フラグは、ボスフィールド転送、挑戦キャンセル、ログアウト、挑戦終了時に解除する。

## 10. ボスフィールドインスタンス

物理名: `BossFieldInstance`

| 項目 | 型 | 説明 |
|---|---|---|
| `instanceId` | `UUID` | フィールドインスタンス ID |
| `worldMasterId` | `String` | 元 `WorldMasterData.id` |
| `baseWorldPath` | `Path` | コピー元 |
| `instanceRootPath` | `Path` | コピー先ルート |
| `worldName` | `String` | Bukkit ワールド名。例: `boss_<bossId>_<partyId>_<timestamp>` |
| `worldFolderPath` | `Path` | コピー先フォルダ |
| `loadedWorldName` | `String?` | ロード済み Bukkit ワールド名 |
| `createdAt` | `Instant` | 作成時刻 |
| `state` | [[26_1.00-モデル定義]].ボスフィールド状態 | 現在状態 |

## 11. ボスフィールド状態

物理名: `BossFieldState`

| 値 | 意味 |
|---|---|
| `COPYING` | テンプレートワールドコピー中 |
| `LOADING` | Bukkit ワールドロード中 |
| `READY` | 転送可能 |
| `IN_USE` | ボス戦で使用中 |
| `UNLOADING` | ワールドアンロード中 |
| `DELETING` | コピー先フォルダ削除中 |
| `FAILED` | 生成または破棄に失敗 |
| `DELETED` | 削除完了 |

## 12. ボス結果統計

物理名: `BossResultStatistics`

| 項目 | 型 | 説明 |
|---|---|---|
| `totalDamage` | `double` | パーティー合計有効与ダメージ |
| `playerDamages` | `Map<UUID, Double>` | プレイヤー別有効与ダメージ |
| `playerDeaths` | `Map<UUID, Integer>` | プレイヤー別死亡回数 |
| `startedAt` / `endedAt` | `Instant` | 経過時間表示に使用 |

与ダメージは `DamageService` で HP またはシールドへ実際に反映された値だけを集計する。オーバーキルは残り HP を上限に丸める。

## 13. config.yml `boss`

```yaml
boss:
  hubWorldId: "skyhaven_isle"
```

`hubWorldId` はボス挑戦受付後に集合待ちを行う、実ワールドをロード可能なハブ `WorldMasterData.id` とする。既定値は既存のハブワールド `skyhaven_isle` とする。
