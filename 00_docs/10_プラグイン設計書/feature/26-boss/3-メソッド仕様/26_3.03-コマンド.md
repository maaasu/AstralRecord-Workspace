# 26_3.03-コマンド

## ボスインスタンス一覧

クラス名: `BossCommand`
物理名: `instances`

コマンド: `/boss instances`

1. 実行者が管理者権限を持つことを確認する。
2. `BossChallengeCache` から `ENDED` 以外の挑戦インスタンスを取得する。
3. 各インスタンスについて `partyId`、`bossId`、状態、参加者数、ワールド名、開始時刻、残り時間を整形する。
4. 実行者へ一覧を表示する。
5. 稼働中インスタンスが 0 件の場合は、その旨を表示する。

## ボス強制終了

クラス名: `BossCommand`
物理名: `stop`

コマンド: `/boss stop <partyId>`

1. 実行者が管理者権限を持つことを確認する。
2. `<partyId>` に対応する `ENDING` / `ENDED` 以外の挑戦インスタンスを取得する。
3. 見つからない場合は、対象パーティーがボス挑戦中ではない旨を表示する。
4. 見つかった場合、[[26_3.02-サービス]].ボス挑戦終了 を `ADMIN_STOP` で呼び出す。
5. 強制終了を開始した旨を実行者へ表示する。
