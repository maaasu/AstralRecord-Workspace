# ボス機能 理想例外・ログ・運用

## 受付時エラー

| 条件 | 終了/応答 | メッセージ |
|---|---|---|
| 入口範囲外 | 受付しない | `P_6500` または `P_6502` |
| ボスマスタなし | 受付しない | `P_6501` |
| gameplay 対象外 | 受付しない | `P_5065` |
| パーティーリーダーでない | 受付しない | `P_6503` |
| 参加人数不正 | 受付しない | `P_6504` |
| 同一 partyKey が挑戦中 | 受付しない | `P_6505` |
| ハブ WorldMasterData なし | 受付しない | `P_6506` |
| フィールド WorldMasterData なし | 受付しない | `P_6507` |
| フィールド型不正 | 受付しない | `P_6522`, `W_6502` |

## 準備/開始時エラー

| 条件 | 終了理由 | 動作 |
|---|---|---|
| baseWorldPath 欠損 | `FIELD_PREPARE_FAILED` | 参加者通知、フィールド作成途中なら掃除 |
| Bukkit world ロード失敗 | `FIELD_PREPARE_FAILED` | 参加者通知、フォルダ削除 |
| 参加者転送失敗 | `TRANSFER_FAILED` | 成功済み参加者もハブへ戻す |
| ボス spawn 失敗 | `BOSS_SPAWN_FAILED` | フィールド破棄、報酬なし |

## 戦闘中エラー

| 条件 | 終了理由 | 動作 |
|---|---|---|
| 制限時間超過 | `TIME_LIMIT` | 報酬なし、結果表示、退場 |
| フィールド内参加者 0 | `NO_PARTICIPANTS` | 報酬なし、フィールド破棄 |
| 死亡上限超過 | `DEATH_LIMIT` | 報酬なし、結果表示、退場 |
| 管理者停止 | `ADMIN_STOP` | 報酬なし、フィールド破棄 |
| plugin disable | `PLUGIN_SHUTDOWN` | 報酬なし、可能な範囲で掃除 |

## ログ方針

| ID | レベル | 用途 |
|---|---|---|
| `I_6500` | INFO | 挑戦受付 |
| `I_6501` | INFO | 戦闘開始 |
| `I_6502` | INFO | 挑戦終了 |
| `W_6501` | WARN | テンプレート world 欠損/不正 |
| `W_6502` | WARN | WorldMasterData の型/instance 設定不正 |
| `E_6500` | ERROR | フィールド準備失敗 |
| `E_6501` | ERROR | boss event handler 例外 |
| `E_6502` | ERROR | フィールド削除失敗 |

## 運用コマンド

`/boss list` は進行中または結果待ちの挑戦を一覧表示する。表示項目は `challengeId`, `partyKey`, `bossId`, `state`, `participantCount`, `elapsedSeconds`, `fieldWorldName` とする。

`/boss stop <challengeId|partyKey>` は対象挑戦を `ADMIN_STOP` で終了する。前方一致で `challengeId` を受け付ける場合、複数一致時は停止せず候補を返す。

`/boss cleanup` は将来追加する。dry-run を既定にし、削除対象の `instanceRootPath` と world 名を表示する。`--execute` 指定時だけ unload/delete を行う。

## 報酬補償

討伐成功時の報酬は、演出より前に対象者と内容を確定する。付与処理が一部失敗した場合は、対象者 UUID、ボス ID、挑戦 ID、失敗カテゴリを ERROR ログへ出し、可能なら再付与キューへ積む。再付与キューが未実装の場合は未決事項へ残す。
