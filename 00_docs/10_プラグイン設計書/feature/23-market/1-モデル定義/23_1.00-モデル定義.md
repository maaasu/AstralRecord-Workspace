# 23_1.00-モデル定義

## 1. マーケット出品

物理名: `MarketListing`

API [[23_1.00-モデル定義]].マーケット出品レスポンス に対応する。

## 2. 相場見積

物理名: `MarketPriceQuote`

API [[23_1.00-モデル定義]].相場見積レスポンス に対応する。

## 3. アカウントマーケット概要

物理名: `MarketAccountSummary`

API [[23_1.00-モデル定義]].アカウントマーケット概要レスポンス に対応する。

## 4. マーケット取引

物理名: `MarketTransaction`

API [[23_1.00-モデル定義]].マーケット取引レスポンス に対応する。
