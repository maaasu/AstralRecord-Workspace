# 23_4.00-統合フロー

## 1. 参照フロー

1. GUI / コマンド / 他 feature が `MarketService` を呼び出す。
2. `MarketService` は `MarketRepository` へ委譲する。
3. `MarketRepository` はキャッシュを確認する。
4. キャッシュミス時のみ AstralRecord API を呼び出す。
5. API レスポンスをモデルへ変換し、TTL 付きで保存して返す。

## 2. 更新フロー

1. GUI / コマンド / 他 feature が出品作成、購入、キャンセルを要求する。
2. `MarketService` は `MarketRepository` へ委譲する。
3. `MarketRepository` は API 更新系エンドポイントを呼び出す。
4. API の成功レスポンスをモデルへ変換する。
5. 関連キャッシュを破棄し、必要な詳細キャッシュだけ最新レスポンスで上書きする。

## 3. API 正本ルール

Plugin は API の失敗レスポンスを独自に補正しない。
相場判定、出品制限、価格ガード、取引確定は API の戻り値を正とする。
