# 20_5.00-例外・ログ・運用

## 1. 例外方針

- shopId を解決できない場合は GUI を開かない。
- 通貨不足または支払い失敗時は商品付与を行わない。
- 支払い成功後の商品付与失敗は運用上の補償対象としてログを残す。

## 2. 運用上の注意

- 商品 item ID を変更する場合は item feature のマスタ表示と同時に確認する。
- NPC からの導線を変更する場合は mob feature の NPC interaction 記述も更新する。

## 3. 出力一覧

| 種別 | ID | レベル | テンプレート | 用途 |
|---|---|---|---|---|
| プレイヤー通知 | `PlayerMsgId.P_5930` | - | `Shopが見つかりません: {0}` | shopId 未解決 |
| プレイヤー通知 | `-` | - | `購入条件を満たしていません。` | 通貨不足、必要素材不足、在庫制限、数量不正 |
| プレイヤー通知 | `-` | - | `インベントリに空きがありません。` | 購入品付与前の空き不足 |
| ログ | `LogId.E_5200` | ERROR | `アイテム取得に失敗しました (API): %s` | ショップ GUI click / drag のイベント処理例外 |
| ログ | `-` | WARN | `ショップ購入品の付与に失敗しました: player=%s, shopId=%s, itemId=%s, amount=%s, reason=%s` | 支払い成功後の商品付与失敗 |
