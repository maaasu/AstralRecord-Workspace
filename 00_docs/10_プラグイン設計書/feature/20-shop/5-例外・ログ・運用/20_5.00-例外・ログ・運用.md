# 20_5.00-例外・ログ・運用

## 1. 例外方針

- shopId を解決できない場合は GUI を開かない。
- 通貨不足または支払い失敗時は商品付与を行わない。
- Gold・必要素材の減算前に補償用スナップショットを取得し、素材減算または商品全量付与に失敗した場合は state を復元する。
- 補償後は `LogId.W_6300` を残し、購入成功として保存・GUI反映しない。
- `access=NPC_ONLY` をコマンドから指定した場合はショップ未解決として扱い、GUIを開かない。

## 2. 運用上の注意

- 商品 item ID を変更する場合は item feature のマスタ表示と同時に確認する。
- NPC からの導線を変更する場合は mob feature の NPC interaction 記述も更新する。
