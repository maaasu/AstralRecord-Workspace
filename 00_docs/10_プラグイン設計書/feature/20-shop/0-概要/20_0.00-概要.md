# 20_0.00-概要

## 1. 目的

`shop` feature は、NPC やコマンドから開くショップ GUI、商品一覧、購入、支払い、購入品付与を管理する。

## 2. コンテキスト

- NPC interaction は mob feature からショップを開く導線として扱う。
- 通貨支払いは currency feature に委譲する。
- 商品表示と購入品付与は item / inventory feature に委譲する。

## 3. 構成要素（実装単位）

- `service/ShopService`
  - 商品一覧取得、購入可否検証、支払い、購入品付与を制御する。
- `gui/ShopGui`
  - ショップ GUI を構築する。
- `command/ShopCommand`
  - `/shop` 系コマンドを受け付ける。
- `model/Shop`, `ShopItem`, `ShopPrice`
  - 店舗、商品、価格を表す。
- 共通ショップGUIは `mode=EXCHANGE` の両替表示にも利用でき、`access=NPC_ONLY` の定義はNPC interactionからだけ開く。

## 追記（2026-06-24）account mode によるショップ導線制限

- shop feature は通常プレイ導線として扱い、NPC interaction、`/shop`、ショップ GUI クリック・ドラッグ、購入 preview / purchase は `AccountMode.PLAYER` のみ処理する。
- `AccountMode.ADMIN` / `AccountMode.BUILDER` ではショップ GUI を開かず、既に開いているショップ GUI の操作は cancel して閉じる。
- 管理者権限を持つプレイヤーがショップ動作を確認する場合も、`user.permission = ADMIN` かつ account mode は `PLAYER` とする。
