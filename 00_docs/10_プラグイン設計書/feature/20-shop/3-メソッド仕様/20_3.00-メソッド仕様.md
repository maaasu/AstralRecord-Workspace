# 20_3.00-メソッド仕様

## ショップ表示

クラス名: `ShopService`
物理名: `openShop`

1. shopId からショップ定義を取得する。
2. 商品 item ID を item feature で表示可能な ItemStack へ変換する。
3. [[20_1.00-モデル定義]].ショップ価格 を lore に含める。
4. `ShopGui` へ描画を委譲する。

## 購入実行

クラス名: `ShopService`
物理名: `purchase`

1. 対象ショップと商品を取得する。
2. 在庫制限と購入数量を検証する。
3. currency feature の通貨減算を呼び出す。
4. 減算成功後、inventory feature で購入品を付与する。
5. 付与失敗時の補償は [[20_5.00-例外・ログ・運用]] に従う。

## ショップコマンド

クラス名: `ShopCommand`
物理名: `onCommand`

1. `/shop open <shopId>` を受け付ける。
2. 権限と shopId を検証する。
3. [[20_3.00-メソッド仕様]].ショップ表示 を呼び出す。
