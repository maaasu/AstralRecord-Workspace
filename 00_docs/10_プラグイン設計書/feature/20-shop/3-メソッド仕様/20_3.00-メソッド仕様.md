# 20_3.00-メソッド仕様

## ショップ表示

クラス名: `ShopService`
物理名: `openShop`

1. shopId からショップ定義を取得する。
2. 商品 item ID を item feature で表示可能な ItemStack へ変換する。
3. 購入品・必要素材・不足素材の lore 表示は item ID ではなく item feature から解決したアイテム表示名を使う。解決できない場合のみ item ID にフォールバックする。
4. [[20_1.00-モデル定義]].ショップ価格 を lore に含める。
5. `items[].page` が未指定の商品は 1 ページ目に配置する。指定がある場合はその 1-based ページに配置する。
6. 商品一覧 GUI は左下 slot `45` を前ページ、右下 slot `53` を次ページとして扱い、前後ページが存在する場合だけボタンを表示する。
7. `ShopGui` へ描画を委譲する。
8. `mode=EXCHANGE` は購入文言を両替文言へ切り替える。
9. コマンド導線では `access=NPC_ONLY` を解決しない。NPC導線では開くことを許可する。

失敗時出力:

| 種別 | ID | レベル | テンプレート | 出力条件 | 引数 |
|---|---|---|---|---|---|
| プレイヤー通知 | `PlayerMsgId.P_5930` | - | `Shopが見つかりません: {0}` | shopId を解決できない場合 | `shopId` |
| ログ | `LogId.E_5200` | ERROR | `アイテム取得に失敗しました (API): %s` | ショップ GUI click / drag のイベント処理で例外が発生した場合 | `playerName` |

## 購入実行

クラス名: `ShopService`
物理名: `purchase`

1. 対象ショップと商品を取得する。
2. 在庫制限と購入数量を検証する。
3. inventory feature の補償用スナップショットを取得する。
4. currency feature の通貨減算と、必要素材の減算を順に呼び出す。
5. 減算成功後、inventory feature で購入品を全量付与する。
6. 素材減算または購入品付与が途中失敗した場合はスナップショットへ復元し、[[20_5.00-例外・ログ・運用]] の WARN を記録する。
7. 必要コストの `category=currency` は CURRENCY から指定 item ID を減算する。`gold` は互換 ID を含める。

失敗時出力:

| 種別 | ID | レベル | テンプレート | 出力条件 | 引数 |
|---|---|---|---|---|---|
| プレイヤー通知 | `-` | - | `購入条件を満たしていません。` | 通貨不足、必要素材不足、在庫制限、数量不正のいずれかで購入不可の場合 | なし |
| プレイヤー通知 | `-` | - | `インベントリに空きがありません。` | 購入品を追加できない場合 | なし |
| ログ | `LogId.W_6300` | WARN | `ショップ購入失敗を補償しました: player=%s, shopId=%s, itemId=%s, amount=%d, reason=%s` | 支払いまたは商品付与の途中失敗を補償した場合 | `player`, `shopId`, `itemId`, `amount`, `reason` |

## ショップコマンド

クラス名: `ShopCommand`
物理名: `onCommand`

1. `/shop open <shopId>` を受け付ける。
2. 権限と shopId を検証する。
3. [[20_3.00-メソッド仕様]].ショップ表示 を呼び出す。

失敗時出力:

| 種別 | ID | レベル | テンプレート | 出力条件 | 引数 |
|---|---|---|---|---|---|
| プレイヤー通知 | `PlayerMsgId.P_5305` | - | `プレイヤーを指定してください。` | コンソールなど player 以外の実行元で対象 player を解決できない場合 | なし |
| プレイヤー通知 | `PlayerMsgId.P_5930` | - | `Shopが見つかりません: {0}` | shopId を解決できない場合 | `shopId` |
| プレイヤー通知 | `-` | - | `ShopService が初期化されていません。` | service 未初期化の場合 | なし |
