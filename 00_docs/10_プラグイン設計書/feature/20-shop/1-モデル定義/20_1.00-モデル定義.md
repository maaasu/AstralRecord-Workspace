# 20_1.00-モデル定義

## 1. ショップ

物理名: `Shop`

| 項目 | 説明 |
|---|---|
| `shopId` | ショップ ID |
| `displayName` | 表示名 |
| `items` | [[20_1.00-モデル定義]].ショップ商品 の一覧 |

## 2. ショップ商品

物理名: `ShopItem`

| 項目 | 説明 |
|---|---|
| `itemId` | 商品 item ID |
| `amount` | 購入数量 |
| `price` | [[20_1.00-モデル定義]].ショップ価格 |
| `stockLimit` | 在庫上限。無制限は `null` |

## 3. ショップ価格

物理名: `ShopPrice`

| 項目 | 説明 |
|---|---|
| `currencyId` | 支払い通貨 ID |
| `amount` | 価格 |
