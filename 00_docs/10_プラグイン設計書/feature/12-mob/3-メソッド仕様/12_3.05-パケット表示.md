# 12_3.05-パケット表示

ProtocolLib を用いた Mob のパケット表示を担当する。バニラエンティティを `World.spawnEntity` で生成しないため、本ビューが「クライアントに見える Mob」を完全に制御する。

## 1. PacketMobView メソッド仕様

### Mob スポーンパケット送出

クラス名: `PacketMobView`  
物理名: `spawn`

責務:

指定プレイヤーへ Mob の出現パケットを送信する。

処理内容:

1. `PacketType.Play.Server.SPAWN_ENTITY` のパケットを生成する
2. 以下のフィールドを設定する
   | フィールド | 内容 |
   |---|---|
   | `Integers[0]` | `entityId`（仮想 Entity ID） |
   | `UUIDs[0]` | `instanceId` |
   | `EntityTypes[0]` | `template.entityType` |
   | `Doubles[0]/[1]/[2]` | `location.x` / `y` / `z` |
   | `Bytes[0]/[1]/[2]` | `pitch` / `yaw` / `headYaw`（`degrees * 256 / 360`） |
3. `ProtocolManager.sendServerPacket` で送出。例外が発生した場合は捕捉のうえ以下ログを記録する

    | 項目 | 内容 |
    |---|---|
    | ID | `LogId.W_5570` |
    | レベル | `WARN` |
    | テンプレート | `Mob スポーンパケットの送出に失敗しました instanceId={0} playerUuid={1}: {2}` |
    | 出力条件 | パケット送出で例外捕捉時 |
    | 引数 | インスタンス ID, プレイヤー UUID, 例外メッセージ |

4. 続けて [[12_3.05-パケット表示]].メタデータ更新 で表示名・ネームタグ可視性などを反映する

入力:

- `player`: 送信先プレイヤー
- `instance`: Mob インスタンス

出力:

- なし

例外時挙動:

- `RuntimeException` を捕捉し、上記 `LogId.W_5570` でログ出力する（プレイヤーには通知しない）

### メタデータ更新

クラス名: `PacketMobView`  
物理名: `updateMetadata`

責務:

カスタム表示名・ネームタグ可視性・装備（外見のみ）の更新パケットを送信する。

処理内容:

1. `PacketType.Play.Server.ENTITY_METADATA` のパケットを生成する
2. 表示名（`template.displayName` + `template.title`）を `Component` 化して載せる
3. `nameVisible` を反映する
4. 装備パケット `PacketType.Play.Server.ENTITY_EQUIPMENT` を別途送出する場合はここから呼び出す

入力:

- `player`: 送信先プレイヤー
- `instance`: Mob インスタンス

出力:

- なし

### 位置・回転更新

クラス名: `PacketMobView`  
物理名: `move`

責務:

`currentLocation` の更新差分を相対移動パケットとして送出する。

処理内容:

1. 前回送出位置と現在位置の差を算出
2. 差分が小さい場合は `ENTITY_LOOK` のみ送出
3. 差分が大きい場合は `ENTITY_TELEPORT` で絶対座標送出
4. 中間サイズは `REL_ENTITY_MOVE_LOOK` で送出
5. 上記いずれの送出でも例外が発生した場合は捕捉のうえ以下ログを記録する

    | 項目 | 内容 |
    |---|---|
    | ID | `LogId.W_5572` |
    | レベル | `WARN` |
    | テンプレート | `Mob 移動パケットの送出に失敗しました instanceId={0} playerUuid={1}: {2}` |
    | 出力条件 | パケット送出で例外捕捉時 |
    | 引数 | インスタンス ID, プレイヤー UUID, 例外メッセージ |

入力:

- `player`: 送信先プレイヤー
- `instance`: Mob インスタンス

### アニメーション送出

クラス名: `PacketMobView`  
物理名: `animate`

責務:

攻撃・被ダメージなどのアニメーションパケットを送出する。

処理内容:

1. `PacketType.Play.Server.ANIMATION` のパケットを生成
2. `animation`（0: swing main hand, 1: take damage 等）を指定
3. 送出

入力:

- `player`: 送信先プレイヤー
- `instance`: Mob インスタンス
- `animation`: アニメーションコード

### Mob 破棄パケット送出

クラス名: `PacketMobView`  
物理名: `destroy`

責務:

指定プレイヤーから Mob を消す（クライアント側から該当 entity を削除）。

処理内容:

1. `PacketType.Play.Server.ENTITY_DESTROY` のパケットを生成
2. `IntLists[0]` に `[instance.entityId]` を設定
3. 送出。例外が発生した場合は捕捉のうえ以下ログを記録する

    | 項目 | 内容 |
    |---|---|
    | ID | `LogId.W_5571` |
    | レベル | `WARN` |
    | テンプレート | `Mob 破棄パケットの送出に失敗しました instanceId={0} playerUuid={1}: {2}` |
    | 出力条件 | パケット送出で例外捕捉時 |
    | 引数 | インスタンス ID, プレイヤー UUID, 例外メッセージ |

入力:

- `player`: 送信先プレイヤー
- `instance`: Mob インスタンス

## 2. パケット種別と用途まとめ

| 用途 | パケット | 呼び出し元 |
|---|---|---|
| 出現 | `SPAWN_ENTITY` | `spawn` |
| メタ更新 | `ENTITY_METADATA` | `updateMetadata` |
| 装備更新 | `ENTITY_EQUIPMENT` | `updateMetadata`（必要時） |
| 移動（小） | `REL_ENTITY_MOVE_LOOK` | `move` |
| 移動（大） | `ENTITY_TELEPORT` | `move` |
| アニメ | `ANIMATION` | `animate` |
| 破棄 | `ENTITY_DESTROY` | `destroy` |

## 3. 設計上の制約

- すべてのパケット送出はメインスレッドからの呼び出しを推奨する。
- 当たり判定はバニラ EntityType のヒットボックスを参考に独自実装する（[[12_3.03-戦闘]].攻撃 tick 内で距離判定）。
- `entityId` 採番はプロセス内で衝突しないよう `AtomicInteger` で管理する。

## 4. 頭上表示

Mob の頭上テキストは `src/main/java/io/github/maaasu/astralRecord/shared/display/*` の packet display 共有層で扱う。

- `PacketDisplayService`: TextDisplay / ItemDisplay / ドロップアイテム型 packet entity の spawn・metadata 更新・teleport・destroy を提供する。
- `OverheadDisplayService`: Mob の `displayName` と現在 HP / 最大 HP を TextDisplay として頭上へ表示し、`MobService.getViewers(instanceId)` と同期して viewer ごとに spawn / teleport / destroy する。
- 実体 Entity は生成せず、Mob 本体と同様に ProtocolLib packet のみで表示する。
