# 12_3.04-リポジトリ

## 1. MobRepository メソッド仕様

### Mob 一覧取得

クラス名: `MobRepository`  
物理名: `findAllSummaries`

責務:

`/api/mob` から Mob 主要項目の配列を取得する。

処理内容:

1. `GET /api/mob` を呼ぶ
2. ステータスに応じて以下を返す
   | ステータス | 戻り値 |
   |---|---|
   | `200` | [[12_1.00-モデル定義]].Mob テンプレート の主要項目（`MobSummary`）リスト |
   | その他 | 以下ログを記録のうえ `IOException("Unexpected status ... for GET /api/mob")` を送出 |

    | 項目 | 内容 |
    |---|---|
    | ID | `LogId.E_5550` |
    | レベル | `ERROR` |
    | テンプレート | `GET /api/mob が想定外ステータスを返しました: status={0}` |
    | 出力条件 | 200 以外を受信した時（例外送出前） |
    | 引数 | HTTP ステータスコード |

3. `InterruptedException` は `Thread.currentThread().interrupt()` を実行のうえ `RuntimeException` でラップして送出

入力:

- なし

出力:

- `List<MobSummary>`

例外時挙動:

- 200 以外のステータスは `IOException` として呼び出し元へ伝播する。

### Mob 取得

クラス名: `MobRepository`  
物理名: `findById`

責務:

`mobId` を指定して API から Mob 定義を取得する。

処理内容:

1. `mobId` を URL エンコードする
2. `GET /api/mob/{mobId}` を呼ぶ
3. ステータスに応じて以下を返す
   | ステータス | 戻り値 |
   |---|---|
   | `200` | [[12_1.00-モデル定義]].Mob テンプレート |
   | `404` | `null`（ログ出力なし。WARN はサービス層で出力する） |
   | その他 | 以下ログを記録のうえ `IOException("Unexpected status ... for GET /api/mob/{mobId}")` を送出 |

    | 項目 | 内容 |
    |---|---|
    | ID | `LogId.E_5551` |
    | レベル | `ERROR` |
    | テンプレート | `GET /api/mob/{mobId} が想定外ステータスを返しました: status={0} mobId={1}` |
    | 出力条件 | 200/404 以外を受信した時（例外送出前） |
    | 引数 | HTTP ステータスコード, テンプレート ID |

4. `InterruptedException` は `Thread.currentThread().interrupt()` を実行のうえ `RuntimeException` でラップして送出

入力:

- `mobId`: テンプレート ID

出力:

- [[12_1.00-モデル定義]].Mob テンプレート（存在しない場合は `null`）

## 2. JSON パース

### Mob テンプレートパース（内部補助）

クラス名: `MobRepository`  
物理名: `parseTemplate`

外部公開しない内部補助メソッド。

処理内容:

1. JSON から `schemaVersion`, `id`, `category`, `name`, `title`, `level`, `entityType`, `nameVisible`, `icon`, `lore[]`, `tags[]` を取り出す
2. `entityType` は `org.bukkit.entity.EntityType` に解決する。`PLAYER` は Paper/Bukkit で直接 spawn できないため、NPC は `VILLAGER`、それ以外は `ZOMBIE` に正規化する。その他の未知値はテンプレート全体を `null` 扱いで破棄
3. `skin` オブジェクトを [[12_1.00-モデル定義]].Mob スキン設定 に変換（存在しなければ `null`）
4. `equipment` オブジェクトを [[12_1.00-モデル定義]].Mob 装備設定 に変換（API は `item:xxx` 形式で返却するため、`:` 区切りで分割し suffix 側を素の ID として保持）
5. `baseStats[]` を [[12_1.00-モデル定義]].Mob ベースステータス のリストに変換
   - `status` が `StatusType` で解決できないエントリはログ出力のうえスキップ
6. `ai.idle` を [[12_1.00-モデル定義]].Mob 待機設定 に変換
7. `ai.targeting` を [[12_1.00-モデル定義]].Mob ターゲット設定 に変換（`category = NPC` の場合は `null`）
8. `ai.combat` を [[12_1.00-モデル定義]].Mob 戦闘設定 に変換（`category = NPC` の場合は `null`）。`skills[]` は `skill:xxx` 形式から `xxx` を抽出して保持
9. `drops` を [[12_1.00-モデル定義]].Mob ドロップ設定 に変換（`category = NPC` の場合は `null`）。`items[].itemId` は `item:xxx`、`lootTable` は `loot_table:xxx` から suffix のみ抽出して保持

### Mob サマリーパース（内部補助）

クラス名: `MobRepository`  
物理名: `parseSummary`

外部公開しない内部補助メソッド。

処理内容:

1. JSON から `id`, `category`, `name`, `level`, `entityType`, `icon`, `tags` を取り出す
2. [[12_1.00-モデル定義]].Mob テンプレート の主要項目のみを保持する

## 3. API エンドポイント一覧

- `GET /api/mob`
- `GET /api/mob/{mobId}`

## 4. ステータスコード方針

- `GET`:
  - `200`: 正常
  - `404`: `null` 返却（ログ出力なし）
  - その他: 例外化
