# 12_3.01-コマンド

## 1. MobCommand メソッド仕様

### Mob テンプレートロード

クラス名: `MobCommand`  
物理名: `executeLoad`

責務:

`/mob load` の実行で、API から Mob テンプレート全件を再ロードする。

処理内容:

1. [[12_3.02-サービス]].テンプレート全件ロード を呼ぶ
2. ロード結果（件数）を実行者へチャットメッセージで返す

    | 項目 | 内容 |
    |---|---|
    | ID | - |
    | レベル | `INFO` |
    | テンプレート | `&aMob テンプレートを {0} 件ロードしました。` |
    | 出力条件 | ロード成功時 |
    | 引数 | 件数 |

3. リポジトリ層から例外が伝播した場合は、実行者へエラーメッセージを送信する。サーバログ側の記録はサービス層（[[12_3.02-サービス]].テンプレート全件ロード 内 `LogId.E_5502`）で行うため、ここでは追加ログを出力しない

    | 項目 | 内容 |
    |---|---|
    | ID | - |
    | レベル | `INFO` |
    | テンプレート | `&cMob テンプレートのロードに失敗しました。サーバログを確認してください。` |
    | 出力条件 | サービス層から例外捕捉時 |
    | 引数 | - |

入力:

- なし（サブコマンド `load` のみ）

出力:

- なし（副作用としてのチャットメッセージ送出のみ）

引数仕様:

- 引数なし。フィルタ・部分ロードは本バージョンでは未対応。

権限:

- 管理者向け。同期 HTTP のため、メインスレッドをブロックしうる（[[12_5.00-例外・ログ・運用]] 4 節参照）。

備考:

- 仮実装段階。再ロード中の他処理との競合制御は本バージョンでは行わない（[[12_9.00-未決事項]] 10 節）。

### Mob テンプレート一覧表示

クラス名: `MobCommand`  
物理名: `executeList`

責務:

`/mob list` の実行で、現在 `MobService.templates` に登録済みのテンプレート ID 一覧を出力する。  
インスタンス（`MobService.instances`）の一覧表示はここでは扱わない。

処理内容:

1. [[12_3.02-サービス]].全テンプレート ID 一覧 を呼び、登録済みテンプレート ID のコレクションを取得する
2. 件数を計上する
3. 件数 0 の場合は以下メッセージのみ出力する

    | 項目 | 内容 |
    |---|---|
    | ID | - |
    | レベル | `INFO` |
    | テンプレート | `&7Mob テンプレートはロードされていません。&8(/mob load で読み込み)` |
    | 出力条件 | テンプレート未ロード時 |
    | 引数 | - |

4. 件数 1 以上の場合は、件数見出しと続けて ID 列をスペース区切りで出力する

    | 項目 | 内容 |
    |---|---|
    | ID | - |
    | レベル | `INFO` |
    | テンプレート | `&eMob テンプレート ({0} 件)&7: &f{1}` |
    | 出力条件 | テンプレートが 1 件以上ロード済み時 |
    | 引数 | 件数, テンプレート ID 列（空白区切り） |

5. 出力は実行者へのチャットメッセージで返す

入力:

- なし（サブコマンド `list` のみ）

出力:

- なし（副作用としてのチャットメッセージ送出のみ）

引数仕様:

- 引数なし。フィルタ・ページングは本バージョンでは未対応。

権限:

- 管理者向け。

備考:

- 監視用途で件数のみが必要な運用シーンは、本コマンドの先頭行の件数表示で吸収する（[[12_5.00-例外・ログ・運用]] 6 節「`/mob list` で件数を監視すること」の対応窓口）。
- インスタンス一覧（`MobService.instances`）の表示は本コマンドの責務外。必要になった場合は別サブコマンド（例: `/mob instances`）として [[12_9.00-未決事項]] で扱う。

### Mob スポーン

クラス名: `MobCommand`  
物理名: `executeSpawn`

責務:

`/mob spawn <mobId>` の実行で、指定テンプレート ID の Mob を実行者の現在地に生成する。

処理内容:

1. 実行主体がプレイヤーであることを検証する。コンソール実行時は usage メッセージを返して終了する

    | 項目 | 内容 |
    |---|---|
    | ID | - |
    | レベル | `INFO` |
    | テンプレート | `&c/mob spawn はプレイヤーから実行してください。` |
    | 出力条件 | 実行主体がプレイヤーでない時 |
    | 引数 | - |

2. 引数 `<mobId>` が省略された場合は usage メッセージを返す

    | 項目 | 内容 |
    |---|---|
    | ID | - |
    | レベル | `INFO` |
    | テンプレート | `&7使い方: /mob spawn <mobId>` |
    | 出力条件 | 第 1 引数が欠落時 |
    | 引数 | - |

3. 実行者の現在地（`Player.getLocation()`）を取得する
4. [[12_3.02-サービス]].Mob スポーン を `(mobId, location)` で呼ぶ
5. 戻り値が `null`（テンプレート未取得）の場合は以下メッセージを返す。サーバログ側の WARN はサービス層（[[12_3.02-サービス]].Mob スポーン 内 `LogId.W_5504`）で記録済みのため、ここでは追加ログを出力しない

    | 項目 | 内容 |
    |---|---|
    | ID | - |
    | レベル | `INFO` |
    | テンプレート | `&cMob テンプレートが見つかりません: &f{0}` |
    | 出力条件 | サービスが `null` を返した時 |
    | 引数 | テンプレート ID |

6. 戻り値が非 `null` の場合は成功メッセージを返す

    | 項目 | 内容 |
    |---|---|
    | ID | - |
    | レベル | `INFO` |
    | テンプレート | `&aMob をスポーンしました: &f{0} &8(instanceId={1})` |
    | 出力条件 | スポーン成功時 |
    | 引数 | テンプレート ID, インスタンス ID |

入力:

- `mobId`: テンプレート ID（位置引数 1）

出力:

- なし（副作用としてのチャットメッセージ送出のみ）

引数仕様:

- 第 1 引数: テンプレート ID（必須）
- 数量・向きなどの追加引数は本バージョンでは未対応。

権限:

- 管理者向け。

備考:

- 仮実装段階。座標指定オプション・スポーン数指定は本バージョンでは未対応（必要になれば [[12_9.00-未決事項]] へ追加）。

### Mob 削除

クラス名: `MobCommand`
物理名: `executeDelete`

責務:

`/mob delete <id>` の実行で、指定 ID に一致する Mob インスタンスを破棄する。
`<id>` はインスタンス UUID として解釈できる場合は単一インスタンス ID、解釈できない場合はテンプレート ID として扱い、同テンプレートから生成されたインスタンスをすべて削除する。

処理内容:

1. 引数 `<id>` が省略された場合は usage メッセージを返す。
2. `MobService.destroyById(id)` を呼び、破棄件数を取得する。
3. 破棄件数が 0 の場合は、削除対象が見つからない旨を実行者へ返す。
4. 破棄件数が 1 以上の場合は、削除件数を実行者へ返す。

入力:

- `id`: インスタンス UUID またはテンプレート ID

出力:

- 実行者向けのチャットメッセージ送信のみ。

権限:

- 管理者向け。

備考:

- テンプレート ID 指定時は同 ID から生成されたインスタンスを一括削除する。個別削除が必要な場合は `/mob spawn` 成功時に表示される instance ID を指定する。

## 2. MobTabCompleter メソッド仕様

### コマンド補完候補取得

クラス名: `MobTabCompleter`  
物理名: `getCompletions`

責務:

`/mob` 配下の補完候補を返す。

処理内容:

1. 第 1 引数位置では `load`, `list`, `spawn`, `delete` を候補として返す
2. 第 1 引数が `spawn` のとき、第 2 引数位置では [[12_3.02-サービス]].全テンプレート ID 一覧 で取得した ID 列を候補として返す（前方一致でフィルタ）
3. 第 1 引数が `delete` のとき、第 2 引数位置ではロード済みテンプレート ID とスポーン中のインスタンス UUID を候補として返す。
4. それ以外の位置・サブコマンドでは空リストを返す

入力:

- `args`: 補完対象の引数配列

出力:

- `List<String>`: 補完候補

備考:

- `spawn` の候補がテンプレート未ロード時は空リストとなる。実装上はそれで構わない（usage は本体側で案内）。

## 3. コマンド仕様

- ルート: `/mob`
- サブコマンド:
  - `/mob load`: テンプレート全件再ロード（仮実装）
  - `/mob list`: テンプレートキャッシュ一覧表示
  - `/mob spawn <mobId>`: 実行者の現在地に Mob を生成（仮実装）
  - `/mob delete <id>`: インスタンス UUID またはテンプレート ID に一致する Mob を破棄
- 実行主体:
  - `/mob load` / `/mob list`: プレイヤー・コンソール双方
  - `/mob spawn`: プレイヤーのみ（現在地参照のため）
- 権限: 管理者向け運用とする。
## 追加補足

- `/mob spawn <mobId>` は `ENEMY` / `BOSS` のみを対象とし、`NPC` は `/mob npc place <mobId> [x] [y] [z]` 側で扱う。
- `spawn` の補完候補には `NPC` を含めず、`npc place` の補完候補には `NPC` のみを含める。

## 4. 固定 TextDisplay コマンド仕様

クラス名: `TextDisplayCommand`
物理名: `executePlayerCommand`

`/textdisplay` は NPC と同様にワールド上へ滞在する固定 TextDisplay を管理する管理者向けコマンドである。

### コマンド一覧

| コマンド | 内容 |
|---|---|
| `/textdisplay place <id> <text...>` | 実行者の現在地に固定 TextDisplay を配置し、`text_displays.yml` に保存する |
| `/textdisplay remove <id>` | 指定 ID の固定 TextDisplay を削除し、保存済み YAML からも除去する |
| `/textdisplay list` | 登録済み ID 一覧と件数を表示する |
| `/textdisplay reload` | `text_displays.yml` を再読込し、表示を作り直す |

### 配置

1. 実行主体はプレイヤーのみとする。
2. `<id>` は半角英数字、`_`、`-` の 1〜64 文字とする。
3. `<text...>` はスペースを含む可変長文字列として扱う。
4. テキスト中の `\n` は改行に置換して保存する。
5. `&a` などの legacy color code は表示時に `ColorCodeUtil` 経由で解釈する。
6. 同一 ID が既に存在する場合は、既存表示を破棄して現在地・テキストで上書きする。

権限:

- `UserPermission.ADMIN` 以上。

補完:

- 第 1 引数は `place`, `remove`, `list`, `reload`。
- `remove` の第 2 引数は登録済み TextDisplay ID。
