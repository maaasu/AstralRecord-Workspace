## 記載ルール

- 論理名（日本語）を主表記とする
- 物理名（メソッド名）とクラス名を併記する
- 処理内容は手順で記載する

## 責務マッピング

| クラス | 主な責務 | 定義ファイル |
|---|---|---|
| `MobCommand` | `/mob` サブコマンド（`load` / `list` / `spawn` / `delete`）の受け口 | [[12_3.01-コマンド]] |
| `MobTabCompleter` | `/mob` のサブコマンド・引数補完 | [[12_3.01-コマンド]] |
| `MobService` | テンプレート・インスタンス管理、外部 API のエントリポイント | [[12_3.02-サービス]] |
| `MobAiService` | tick 駆動の状態遷移、待機行動駆動、頭上表示用 viewer 同期 | [[12_3.02-サービス]] |
| `MobEntityController` | 実体 Mob 生成、vanilla goal 全削除、Pathfinder 移動要求、実体削除 | [[12_3.05-実体Mob制御]] |
| `MobCombatService` | 攻撃・被ダメージ・致死処理 | [[12_3.03-戦闘]] |
| `MobKnockbackService` | ノックバックベクトル算出と送出 | [[12_3.03-戦闘]] |
| `MobThreatTable` | プレイヤー単位の脅威値管理 | [[12_3.03-戦闘]] |
| `MobDropService` | ドロップ抽選と払い出し | [[12_3.03-戦闘]] |
| `MobRepository` | AstralRecord API への HTTP リクエスト | [[12_3.04-リポジトリ]] |
