# 12_9.00-未決事項

## 1. ボス固有ギミック

`category = BOSS` のフェーズ遷移・スキルローテーション・専用ギミック（戦闘エリア制限・QTE 等）は本機能のスコープ外。  
将来的に `feature/boss-mechanics` のような別 feature を立てるか、`mob` 内に `bossLogic` 拡張点を切るかは未定。  
当面は `dark_dragon` などのボス毎にハードコード実装する想定。

## 2. ノックバック耐性（解決済み）

`StatusType.KNOCKBACK_RESISTANCE` を追加し、`DamageService` のダメージ結果処理から `MobKnockbackService.apply` を呼ぶ共通経路で軽減する。

## 3. ノックバックの方向ジッタ

`MobKnockbackService.apply` は攻撃元・対象の単純な水平ベクトルを使用する。  
プレイヤー視点での違和感（後方への押し戻し過剰など）が発生した場合は、攻撃方向に対する微小なジッタ追加や、`preferredRange` を考慮した非対称ノックバックを検討する。

## 4. 経路探索（パスファインディング）

`WANDER` / `AGGRO` / `LEASHED` 時の移動は Paper Pathfinder を使用する。
AI は目標位置だけを決め、経路探索そのものは実体 Mob 側へ委譲する。
ダンジョン等の複雑な地形で性能や経路品質が不足する場合は、Pathfinder への再要求間隔、目標地点の丸め方、Mob 種別ごとの通行設定を調整する。

## 5. AI tick の負荷上限

`MobAiService.tick` は 1 tick 周期で動くが、IDLE 探索は 10 tick、AGGRO / LEASHED の追跡判断は 5 tick、viewer 更新は 5 tick に分散済み。
100体を超える規模で不足する場合、状態ごとの間隔拡大、遠距離 Mob の休眠、spawn 管理側の上限設定を検討する。

## 6. 当たり判定の精度

実体 Mob のヒットボックスを基準に扱うが、独自エンティティ（例: 巨大ボス）では期待サイズと不一致になる。
将来的に `MobTemplate` に `hitboxRadius` / `hitboxHeight` を追加することを検討する。

## 7. 経験値・金銭の付与経路

致死処理時の経験値加算は `account` feature のキャッシュ反映と定期 flush に委譲する。
金銭加算は `currency` feature の通貨加算経路へ委譲する。
本 feature では、経験値・金銭の永続化仕様を重複定義せず、呼び出し点と失敗時の扱いだけを保持する。

## 8. プレイヤーへの被ダメージ反映

`MobCombatService.tickCombat` 内でターゲットのプレイヤーへダメージを適用する経路（バニラ `Player.damage` か、`feature/player` の独自 API か）は未確定。  
プレイヤー側 HP がプロジェクト独自の値（`StatusType.MAX_HEALTH`）と乖離している可能性があるため、`feature/player` 側に「独自ダメージ適用 API」の整備が必要かを確認する。

## 9. テンプレートのホットリロード

`/mob load` は API から全件再ロードするが、ロード中の他処理との競合は考慮していない。  
頻繁な再ロードは想定しないため、当面はオペレーション側で運用注意とする。

## 10. ログ ID の整備

`LogId` の `5700-5799` を使用する。個別 ID の採番は [[12_5.00-例外・ログ・運用]] 第 2 節を正本とする。

## 11. Paper Pathfinder / MobGoals の保守

Mob 本体は Paper API の `MobGoals` と `Pathfinder` に依存する。
Paper / Minecraft のメジャー更新時には [[12_3.05-実体Mob制御]] の goal 全削除、Pathfinder `moveTo`、PDC 紐付けが期待通り動くか確認する。

## 12. config.yml の `mob` 有効化

`40_filebase/config.yml` の `mob` ソースは現状コメントアウトされている。  
理由: `ai.combat.skills` / `drops.items[].itemId` / `drops.lootTable` の参照先（skill / item / loot.table）が未充足のため、seeder の必須参照検証が失敗する。  
仮データ（`dragon_breath` 等）が揃った時点で `config.yml` の `mob` 行をコメントアウト解除する。
