# 12_4.00-統合フロー

## 1. Mob スポーン（command -> service -> entity）

```mermaid
sequenceDiagram
    participant C as MobCommand
    participant S as MobService
    participant R as MobRepository
    participant E as MobEntityController
    participant B as Bukkit/Paper Mob

    C->>S: spawn(templateId, location)
    alt キャッシュ未ヒット
        S->>R: findById(templateId)
        R-->>S: MobTemplate or null
    end
    alt テンプレートなし
        S-->>C: null
    else テンプレートあり
        S->>S: MobInstance 作成
        S->>E: spawn(instance, location)
        E->>B: World.spawnEntity
        E->>B: removeAllGoals / PDC / Pathfinder 設定
        E->>S: Bukkit Mob
        S->>S: instances / instanceByEntity / viewers 登録
        S-->>C: MobInstance
    end
```

物理名対応:

- Mob スポーン: `spawn`（`MobService`）
- Mob 取得: `findById`（`MobRepository`）
- 実体 Mob 生成・初期化: `spawn` / `configure`（`MobEntityController`）

## 2. AI tick 駆動と状態遷移

```mermaid
stateDiagram-v2
    [*] --> IDLE
    IDLE --> AGGRO: aggroRange 内のプレイヤー検知
    AGGRO --> COMBAT: preferredRange に到達
    COMBAT --> AGGRO: ターゲット範囲外
    AGGRO --> IDLE: deaggroRange 超過 / ターゲット失効
    COMBAT --> IDLE: ターゲット失効
    IDLE --> LEASHED: spawnLocation から leashRange 超過
    AGGRO --> LEASHED: spawnLocation から leashRange 超過
    COMBAT --> LEASHED: spawnLocation から leashRange 超過
    LEASHED --> IDLE: spawnLocation に到達
    IDLE --> DEAD: currentHealth <= 0
    AGGRO --> DEAD: currentHealth <= 0
    COMBAT --> DEAD: currentHealth <= 0
    LEASHED --> DEAD: currentHealth <= 0
    DEAD --> [*]
```

`MobAiService.tick` は 1 tick 周期で動くが、100体想定のため以下を分散する。

- `IDLE`: 10 tick 間隔でターゲット探索・徘徊判断
- `AGGRO` / `LEASHED`: 5 tick 間隔で追跡判断
- `COMBAT`: `RANGED` / `MAGIC` は近すぎる場合に後退補助を入れ、`preferredRange` 付近では左右移動で距離を維持
- `MobService.updateViewers`: 5 tick 間隔で頭上表示用 viewer を更新
- Paper Pathfinder の再要求: 10 tick 間隔、または目標 X/Z が 1.5 ブロック以上動いた場合

## 3. 移動要求（AI -> Paper Pathfinder）

```mermaid
sequenceDiagram
    participant A as MobAiService
    participant S as MobService
    participant E as MobEntityController
    participant P as Paper Pathfinder

    A->>S: moveToward(instance, target, speed, tick)
    S->>E: moveTo(instance, target, speed, tick)
    alt 目標付近
        E->>P: stopPathfinding
    else 再計算不要
        E-->>A: 何もしない
    else 再計算可能
        E->>P: moveTo(target, resolvedSpeed)
    end
```

AI は「どこへ行くか」だけを決める。段差、障害物、実際の経路探索は Paper Pathfinder に委譲する。

## 4. 被ダメージシーケンス（player/skill -> mob）

```mermaid
sequenceDiagram
    participant X as 外部呼び出し（戦闘 / スキル）
    participant CB as MobCombatService
    participant T as MobThreatTable
    participant KB as MobKnockbackService
    participant E as MobEntityController
    participant I as MobInstance

    X->>CB: applyDamage(instance, attacker, damage, type)
    CB->>I: currentHealth -= effectiveDamage
    CB->>T: 脅威値加算
    CB->>KB: applyToMob
    KB->>E: addVelocity
    alt currentHealth <= 0
        CB->>I: state = DEAD
    end
```

Mob 実体は `setInvulnerable(true)` のため、バニラダメージイベントは HP の正本にはしない。

## 5. 致死処理（drop -> destroy）

```mermaid
sequenceDiagram
    participant CB as MobCombatService
    participant D as MobDropService
    participant S as MobService
    participant E as MobEntityController

    CB->>CB: キラー決定（脅威値最大）
    CB->>D: ドロップ確定
    D-->>CB: MobDropResult
    CB->>S: destroy(instanceId)
    S->>E: remove(instance)
```

`MobService.destroy` は実体 Mob を remove し、`instances` / `instanceByEntity` / `viewers` を更新する。

## 6. 頭上表示

1. `MobAiService.tick` が 5 tick ごとに `MobService.updateViewers` を呼ぶ。
2. `MobService` は実体位置を同期し、64 ブロック以内のプレイヤー UUID を viewer として保持する。
3. `OverheadDisplayService` は Mob の実体 Entity に HP テキストの TextDisplay を passenger として接続し、テキスト更新 / destroy を行う。
4. Mob 本体の表示・移動・破棄は Bukkit/Paper の entity tracking に任せる。
