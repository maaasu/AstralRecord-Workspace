```mermaid

sequenceDiagram
    participant C as MobCommand
    participant S as MobService
    participant R as MobRepository
    participant V as PacketMobView

    C->>S: Mob スポーン
    alt キャッシュ未ヒット
        S->>R: Mob 取得
        R-->>S: テンプレート or null
    end
    alt テンプレートが null
        S-->>C: null
    else 取得成功
        S->>S: instanceId / entityId 採番
        S->>S: MobInstance を生成
        S->>S: instances に登録
        loop 範囲内プレイヤーごと
            S->>V: Mob スポーンパケット送出
            S->>V: メタデータ更新
        end
        S-->>C: MobInstance
    end
```

物理名対応:

- Mob スポーン: `spawn`（`MobService`）
- Mob 取得: `findById`（`MobRepository`）
- Mob スポーンパケット送出: `spawn`（`PacketMobView`）
- メタデータ更新: `updateMetadata`（`PacketMobView`）

## 2. AI tick 駆動と状態遷移

```mermaid
%%{init: {"theme": "base"}}%%
stateDiagram-v2
    [*] --> IDLE
    IDLE --> AGGRO: aggroRange 内のプレイヤー検知
    AGGRO --> COMBAT: preferredRange に到達
    COMBAT --> AGGRO: ターゲット範囲外
    AGGRO --> IDLE: deaggroRange 超過 / ターゲット失効
    COMBAT --> IDLE: deaggroRange 超過 / ターゲット失効
    IDLE --> LEASHED: spawnLocation から leashRange 超過
    AGGRO --> LEASHED: spawnLocation から leashRange 超過
    COMBAT --> LEASHED: spawnLocation から leashRange 超過
    LEASHED --> IDLE: spawnLocation に到達
    IDLE --> DEAD: currentHealth <= 0
    AGGRO --> DEAD: currentHealth <= 0
    COMBAT --> DEAD: currentHealth <= 0
    LEASHED --> DEAD: currentHealth <= 0
    DEAD --> [*]
```

各遷移は `MobAiService.tick` 内で 1 tick 単位に判定する。

物理名対応:

- tick 本体: `tick`（`MobAiService`）
- ターゲット選定: `selectTarget`（`MobCombatService`）
- 攻撃 tick: `tickCombat`（`MobCombatService`）

## 3. Mob 攻撃シーケンス（combat -> player）

```mermaid
sequenceDiagram
    participant A as MobAiService
    participant CB as MobCombatService
    participant KB as MobKnockbackService
    participant P as AstPlayer

    A->>CB: 攻撃 tick
    CB->>CB: 命中判定
    alt 命中
        CB->>CB: ダメージ計算
        CB->>CB: 会心判定
        CB->>P: ダメージ適用（feature/player API 経由）
        CB->>KB: ノックバック適用
        KB->>P: setVelocity
    else 不命中
        CB-->>A: 何もしない
    end
```

物理名対応:

- 攻撃 tick: `tickCombat`（`MobCombatService`）
- ダメージ計算: `computeDamage`（`MobCombatService`）
- 会心判定: `applyCriticalMultiplier`（`MobCombatService`）
- ノックバック適用: `apply`（`MobKnockbackService`）

## 4. 被ダメージシーケンス（player -> mob）

```mermaid
sequenceDiagram
    participant X as 外部呼び出し（戦闘 / スキル）
    participant CB as MobCombatService
    participant T as MobThreatTable
    participant KB as MobKnockbackService
    participant I as MobInstance

    X->>CB: 被ダメージ
    CB->>CB: 防御適用後ダメージ算出
    CB->>I: currentHealth -= effectiveDamage
    CB->>T: 脅威値加算
    CB->>KB: ノックバック適用
    KB->>I: 位置補正
    alt currentHealth <= 0
        CB->>I: state = DEAD
        Note over CB: 致死処理キューへ
    end
```

物理名対応:

- 被ダメージ: `applyDamage`（`MobCombatService`）
- 脅威値加算: `add`（`MobThreatTable`）
- ノックバック適用: `apply`（`MobKnockbackService`）

## 5. 致死処理（drop -> distribute -> destroy）

```mermaid
sequenceDiagram
    participant CB as MobCombatService
    participant D as MobDropService
    participant S as MobService
    participant V as PacketMobView
    participant P as AstPlayer

    CB->>CB: キラー決定（脅威値最大 -> 最終攻撃者）
    CB->>D: ドロップ確定
    D-->>CB: MobDropResult
    alt キラーが存在
        CB->>P: items 付与（inventory API）
        CB->>P: exp 加算（player API）
        CB->>P: money 加算（currency API）
    end
    CB->>S: 個別 Mob 破棄
    loop 表示中プレイヤーごと
        S->>V: Mob 破棄パケット送出
    end
```

物理名対応:

- 致死処理: `handleDeath`（`MobCombatService`）
- ドロップ確定: `roll`（`MobDropService`）
- 個別 Mob 破棄: `destroy`（`MobService`）
- Mob 破棄パケット送出: `destroy`（`PacketMobView`）

## 6. 表示範囲更新

1. `MobAiService.tick` が `MobService.updateViewers` を呼ぶ
2. インスタンスごとに「現在表示中のプレイヤー UUID 集合」と「現在範囲内のプレイヤー UUID 集合」の差分を算出
3. 新規プレイヤー集合へ `PacketMobView.spawn` を呼ぶ
4. 範囲外プレイヤー集合へ `PacketMobView.destroy` を呼ぶ
5. 範囲内継続プレイヤーへは `PacketMobView.move` を呼ぶ

物理名対応:

- 表示範囲更新: `updateViewers`（`MobService`）
- Mob スポーンパケット送出 / Mob 破棄パケット送出 / 位置・回転更新: `spawn` / `destroy` / `move`（`PacketMobView`）
