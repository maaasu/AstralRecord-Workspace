# 06_3.02-サービス

クラス名: `LootService`
物理名: `loadAll`

## 1. `LootService`

- `loadAll`: API から全 loot table を取得し、キャッシュへ登録して件数を返す。
- `getLoaded(lootId)`: 読み込み済み loot table を ID で取得する。未読み込み時は `null`。
- `getLoadedLoots`: 読み込み済み一覧のスナップショットを返す。
- `cacheLoot`: 取得した `LootModel` をキャッシュへ登録する。
- `clearCache`: 全キャッシュを破棄する。

詳細ロードは `LogId.D_5301`、全件成功は `LogId.I_5300`、一括ロード失敗は `LogId.E_5301` を使用します。`D_5301` のメッセージテンプレートは `ルートテーブル詳細をロードしました: %s` です。API 通信失敗時はキャッシュを中途半端な状態にせず、呼び出し元へ失敗を伝えます。
