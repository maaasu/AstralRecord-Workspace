# 06_3.02-サービス

## 1. LootService メソッド仕様

### 全ルートテーブル一括ロード

クラス名: `LootService`  
物理名: `loadAll`

責務:

API から全ルートテーブルを取得し、メモリキャッシュへ登録する。

処理内容:

1. [[06_3.04-リポジトリ]].ルートテーブル一覧取得 を呼ぶ
2. 取得した各 [[06_1.00-モデル定義]].ルートテーブル を `cacheLoot` でキャッシュへ登録する

	| 項目 | 内容 |
	|---|---|
	| キャッシュ | `loadedLoots`（id 正規化キーで `LinkedHashMap`） |
	| デバッグログ | `LogId.D_5301` を記録 |

	| 項目 | 内容 |
	|---|---|
	| ID | `LogId.D_5301` |
	| レベル | `DEBUG` |
	| テンプレート | `ルートテーブル詳細をロードしました: %s` |
	| 出力条件 | キャッシュ登録時 |
	| 引数 | ルートテーブル |

3. 件数を info ログに記録する

	| 項目 | 内容 |
	|---|---|
	| ID | `LogId.I_5300` |
	| レベル | `INFO` |
	| テンプレート | `全ルートテーブルをロードしました: %d件` |
	| 出力条件 | 全件ロード完了時 |
	| 引数 | 件数 |

4. ロード件数を返す
5. 例外時は `LogId.E_5301` を記録し `0` を返す

	| 項目 | 内容 |
	|---|---|
	| ID | `LogId.E_5301` |
	| レベル | `ERROR` |
	| テンプレート | `ルートテーブル一括ロードに失敗しました (Service): %s` |
	| 出力条件 | `loadAll` 内の例外発生時 |
	| 引数 | `"loadAll"` |

入力:

- なし

出力:

- `int`: ロード件数

例外時挙動:

- 例外を再送出せずログ記録のみ行い、`0` を返す

### ロード済みルート取得

クラス名: `LootService`  
物理名: `getLoaded`

責務:

正規化キー（`trim().toLowerCase(ROOT)`）でキャッシュからルートテーブルを取得する。

処理内容:

1. 入力 ID を正規化する
2. `loadedLoots.get(normalized)` を返す

入力:

- `lootId`: ルートテーブル ID

出力:

- [[06_1.00-モデル定義]].ルートテーブル（未ロード時は `null`）

### ロード済みルート一覧取得

クラス名: `LootService`  
物理名: `getLoadedLoots`

責務:

キャッシュ済みルートテーブルの不変リストコピーを返す。

処理内容:

1. `List.copyOf(loadedLoots.values())` を返す

入力:

- なし

出力:

- `List<LootModel>`: ロード順を保持するルートテーブル一覧（変更不可）

### キャッシュクリア

クラス名: `LootService`  
物理名: `clearCache`

責務:

`loadedLoots` を空にする。

処理内容:

1. `loadedLoots.clear()` を実行する

入力:

- なし

出力:

- なし

### キャッシュ登録（private）

クラス名: `LootService`  
物理名: `cacheLoot`

責務:

ルートテーブルをキャッシュへ登録し、登録内容を debug ログに記録する。

処理内容:

1. 正規化キー（`trim().toLowerCase(ROOT)`）で `loadedLoots` へ `put` する
2. `LogId.D_5301` で詳細をログ出力する
