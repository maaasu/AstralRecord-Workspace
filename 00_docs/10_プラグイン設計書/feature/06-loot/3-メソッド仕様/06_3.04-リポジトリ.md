# 06_3.04-リポジトリ

## 1. LootRepository メソッド仕様

### ルートテーブル一覧取得

クラス名: `LootRepository`  
物理名: `findAll`

責務:

API から全ルートテーブル一覧を取得する。

処理内容:

1. `GET /api/loot/table` を呼ぶ
2. `200` は [[06_1.00-モデル定義]].ルートテーブル のリストへ変換して返す
3. その他ステータスは `LogId.E_5300` を記録し例外化する

	| 項目 | 内容 |
	|---|---|
	| ID | `LogId.E_5300` |
	| レベル | `ERROR` |
	| テンプレート | `ルートテーブル取得に失敗しました (API): %s` |
	| 出力条件 | `GET /api/loot/table` が `200` 以外 または 例外 |
	| 引数 | APIエラーメッセージ or 例外メッセージ |

4. `InterruptedException` は `Thread.currentThread().interrupt()` を実行のうえ `LogId.E_5300` を記録し `RuntimeException` でラップして送出する

入力:

- なし

出力:

- `List<LootModel>`: ルートテーブル一覧

### ルートテーブル取得

クラス名: `LootRepository`  
物理名: `findById`

責務:

指定 ID のルートテーブルを API から取得する。

処理内容:

1. ルートテーブル ID を URL エンコードする
2. `GET /api/loot/table/{tableId}` を呼ぶ
3. `200` は [[06_1.00-モデル定義]].ルートテーブル へ変換して返し、`LogId.D_5300` を記録する

	| 項目 | 内容 |
	|---|---|
	| ID | `LogId.D_5300` |
	| レベル | `DEBUG` |
	| テンプレート | `ルートテーブルを取得しました (API): id=%s` |
	| 出力条件 | `GET /api/loot/table/{tableId}` が `200` |
	| 引数 | `lootId` |

4. `404` は `LogId.W_5300` を記録して `null` を返す

	| 項目 | 内容 |
	|---|---|
	| ID | `LogId.W_5300` |
	| レベル | `WARN` |
	| テンプレート | `ルートテーブルが見つかりませんでした (API): id=%s` |
	| 出力条件 | `GET /api/loot/table/{tableId}` が `404` |
	| 引数 | `lootId` |

5. その他ステータスは `LogId.E_5300` を記録し例外化する
6. `InterruptedException` / `IOException` は `LogId.E_5300` を記録し例外として再送出する

入力:

- `lootId`: ルートテーブル ID

出力:

- [[06_1.00-モデル定義]].ルートテーブル（存在しない場合は `null`）

## 2. JSON パース

### ルートテーブルオブジェクトパース

クラス名: `LootRepository`（private）  
物理名: `parseLootObject`

処理内容:

1. JSON から `schemaVersion`, `id`, `name` を取得する（`name` 欠落時は `id` で代用）
2. `entries` 配列を各エントリオブジェクトへ展開する
3. 各エントリは [[06_3.04-リポジトリ]].ルートエントリパース ロジックで [[06_1.00-モデル定義]].ルートエントリ を生成する

#### ルートエントリパース

`parseLootObject` 内で行うルートエントリ配列の変換処理。

処理内容:

1. `category`, `itemId` が `null` の場合は当該エントリをスキップする
2. `minAmount`, `maxAmount`, `weight` を JSON 値またはデフォルト値（`1`, `1`, `100.0`）で取得する

## 3. API エンドポイント一覧

- `GET /api/loot/table`
- `GET /api/loot/table/{tableId}`

## 4. ステータスコード方針

- `GET`:
  - `200`: 正常
  - `404`: `null` 返却（警告ログあり）
  - その他: 例外化

## 5. DTO/永続化対応

- DTO: [[06_1.00-モデル定義]].ルートテーブル
- 永続化相当: `file/loot/table/*`（API 経由で取得）
- 更新主体: なし（読み取り専用）
