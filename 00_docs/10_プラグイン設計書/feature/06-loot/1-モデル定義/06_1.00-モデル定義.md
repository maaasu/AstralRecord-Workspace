# 06_1.00-モデル定義

## 1. ドメインモデル

`loot` 機能はルートテーブルを表す `LootModel` と、その中の個別ドロップ定義を表す `LootEntry` で構成される。

## 2. ルートテーブル

物理名: `LootModel`

`/api/loot/table` および `/api/loot/table/{tableId}` から取得するドロップ定義。

### 2.1 項目

- `schemaVersion`
- `id`
- `name`
- `entries`: [[06_1.00-モデル定義]].ルートエントリ のリスト

## 3. ルートエントリ

物理名: `LootEntry`

ルートテーブル内の個別ドロップ定義。

### 3.1 項目

- `category`
- `itemId`
- `minAmount`（デフォルト `1`）
- `maxAmount`（デフォルト `1`）
- `weight`（デフォルト `100.0`、0.0 ～ 100.0 の確率）

### 3.2 補足

- 抽選アルゴリズム（重み付きランダム、合計補正など）は本モデルには含まない。
- 表示上 `minAmount == maxAmount` の場合は単一数値、異なる場合は `min~max` 形式で表記される（`ItemStackFactory#appendBundleLootLore` の挙動）。

## 4. 入出力モデル

- API 入力: なし（GET のみ）
- API 出力:
  - `GET /api/loot/table` -> [[06_1.00-モデル定義]].ルートテーブル のリスト
  - `GET /api/loot/table/{tableId}` -> [[06_1.00-モデル定義]].ルートテーブル

## 5. 関連 feature とのモデル関係

- `item`:
  - `ItemBundle.lootTableId` がルートテーブル `id` を参照する。
  - 装備/ルーン/通貨/消耗品/材料カテゴリは現状ルートテーブルから直接生成されない（テンプレート定義のみ）。
