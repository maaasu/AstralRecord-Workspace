# 03_1.00-モデル定義

## 1. ドメインモデル

`player` 機能の中心はプレイヤーセッション。  
Bukkit の `Player` と、[[01_1.00-モデル定義]].ユーザモデル、[[02_1.00-モデル定義]].アカウントモデル を結合し、オンライン中の状態として扱う。

## 2. プレイヤーセッション

物理名: `AstPlayer`

### 2.1 項目

- `bukkit`
- `user`
- `account`
- `classId`
- `classLevel`
- `classExperience`
- `statusSnapshot`
- `activeBuffs`
- `sneakStartedAtMs`
- `sneakStartedAtLocation`
- `sneakDodgeWindowExpiresAtMs`
- `isJumpInputPressed`
- `isAirJumpConsumed`
- `wallClingExpiresAtMs`
- `isWallClinging`
- `wallClingTowardWallDirection`
- `isDodging`

### 2.2 主要状態

| 状態 | 説明 |
|---|---|
| user | [[01_1.00-モデル定義]].ユーザモデル |
| account | [[02_1.00-モデル定義]].アカウントモデル |
| classId | 現在の職業 ID。未設定時は `adventurer` を既定値として扱う |
| classLevel | 現在の職業レベル |
| classExperience | 現在職業で獲得した累計クラス経験値。Sidebar の CEXP 進捗とクラスレベルアップ判定に使用する |
| statusSnapshot | status feature が計算する現在ステータス |
| activeBuffs | オンライン中に有効なバフ一覧 |
| sneakDodgeWindowExpiresAtMs | ドッジ受付バーを非表示へ戻す終了時刻 |
| isJumpInputPressed | `PlayerInputEvent` の jump 押下立ち上がりを検出する直近入力状態 |
| isAirJumpConsumed | 現在の滞空中で二段ジャンプを使用済みかを表すフラグ |
| wallClingExpiresAtMs | 壁張り付きバーを非表示へ戻し、自然落下へ戻す終了時刻 |
| isWallClinging | 壁張り付き中かどうかを表すフラグ |
| wallClingTowardWallDirection | 壁張り付き開始時に正面にあった壁方向。壁キック判定に使用する |
| isDodging | ジャスト回避判定に使用するドッジ中フラグ |

## 3. プレイヤーキャッシュ

物理名: `AstPlayerCache`

オンライン中のプレイヤーセッションを UUID キーで保持する。

## 4. プレイヤー参加データ

物理名: `PlayerJoinData`

ログイン反映前に非同期で取得した user/account の組。

| 項目 | 説明 |
|---|---|
| user | [[01_1.00-モデル定義]].ユーザモデル |
| account | [[02_1.00-モデル定義]].アカウントモデル |

## 5. 保存タスク

物理名: `PlayerSaveTask`

プレイヤーデータ保存処理の単位。保存タスク名と保存処理を持つ。

## 6. 保存契機

物理名: `PlayerSaveTrigger`

| 値 | 説明 |
|---|---|
| `LOGOUT` | ログアウト時 |
| `MANUAL` | 手動保存 |
| `AUTO` | 定期保存 |
| `PLUGIN_DISABLE` | プラグイン停止時 |

## 7. プレイヤーメッセージID

物理名: `PlayerMsgId`

プレイヤー向けメッセージキーを定義する enum。文言は `player.properties` で管理する。

## 8. プレイヤーメッセージリソース

物理名: `PlayerMsgResource`

`player.properties` を読み込み、カラーコード変換とメッセージ整形を行う。

## 9. プレイヤーメッセージ送信サービス

物理名: `PlayerMessageService`

`PlayerMsgId` と `PlayerMsgResource` を用いて、プレイヤー向け通知を一元管理する。
システムメッセージには共通タグとタグ直後の半角1文字分の空白を付与し、全体チャット・パーティーチャット・ダイレクトメッセージも本サービス経由で送信する。GUI導線を持つ通知はクリックイベント付き Component として同じサービスから送信する。
Plugin 実装から `Player#sendMessage(...)` や `AstPlayer#sendMessage(...)` を直接使うことは新規禁止とする。
