# 03_3.02-サービス

## 1. service メソッド仕様

### プレイヤー参加データ読込

クラス名: `PlayerService`
物理名: `loadPlayerJoinData`

処理内容:

1. [[01_3.02-サービス]].ユーザ取得 で [[01_1.00-モデル定義]].ユーザモデル を取得する
2. [[01_1.00-モデル定義]].ユーザモデル を取得できない場合は `LogId.W_5070` を記録して `null` を返す

	| 項目 | 内容 |
	|---|---|
	| ID | `LogId.W_5070` |
	| レベル | `WARN` |
	| テンプレート | `AstPlayerのキャッシュが見つかりませんでした。プレイヤー: %s` |
	| 出力条件 | ユーザ取得結果が `null` |
	| 引数 | プレイヤー名 |

3. [[02_3.01-サービス]].選択アカウント取得 で [[02_1.00-モデル定義]].アカウントモデル を取得する
4. [[02_1.00-モデル定義]].アカウントモデル を取得できない場合は `LogId.W_5070` を記録して `null` を返す

	| 項目 | 内容 |
	|---|---|
	| ID | `LogId.W_5070` |
	| レベル | `WARN` |
	| テンプレート | `AstPlayerのキャッシュが見つかりませんでした。プレイヤー: %s` |
	| 出力条件 | 選択アカウント取得結果が `null` |
	| 引数 | プレイヤー名 |

5. [[03_1.00-モデル定義]].プレイヤー参加データ を返す

### プレイヤー参加反映

クラス名: `PlayerService`
物理名: `applyPlayerJoin`

処理内容:

1. プレイヤーがオンラインかつ未キャッシュであることを確認する
2. [[03_1.00-モデル定義]].プレイヤーセッション を生成する
3. [[03_3.04-キャッシュ]].プレイヤーキャッシュ登録 を実行する
4. アカウントモードが通常プレイヤーの場合、inventory feature へGUIインベントリ反映を依頼する
5. status feature へステータス再計算を依頼する

### プレイヤー退出処理

クラス名: `PlayerService`
物理名: `onPlayerQuit`

処理内容:

1. [[03_3.04-キャッシュ]].プレイヤーキャッシュ取得で [[03_1.00-モデル定義]].プレイヤーセッション を取得する
2. セッションがある場合、[[03_3.05-保存]].プレイヤー保存実行 を実行する

	| 項目 | 内容 |
	|---|---|
	| 保存契機 | [[03_1.00-モデル定義]].保存契機 の `LOGOUT` |

3. [[03_3.04-キャッシュ]].プレイヤーキャッシュ削除を実行する

### 全オンラインプレイヤー保存

クラス名: `PlayerService`
物理名: `saveAllOnlinePlayersAndClear`

処理内容:

1. [[03_3.04-キャッシュ]].全プレイヤーキャッシュ取得で全セッションを取得する
2. 各セッションに対し [[03_3.05-保存]].プレイヤー保存実行 を実行する

	| 項目 | 内容 |
	|---|---|
	| 保存契機 | [[03_1.00-モデル定義]].保存契機 の `PLUGIN_DISABLE` |

3. [[03_3.04-キャッシュ]].プレイヤーキャッシュ全削除を実行する

### しゃがみ解除ドッジ判定

クラス名: `DodgeService`
物理名: `tryTriggerOnSneakRelease`

処理内容:

1. しゃがみ開始時刻が記録されているか確認する
2. しゃがみ時間が `250ms` 未満か確認する
3. プレイヤーがオンラインかつ生存しているか確認する
4. クールダウン中またはエネルギー不足の場合は失敗音を再生して終了する
5. 条件を満たす場合はドッジを実行する

### ドッジ実行

クラス名: `DodgeService`
物理名: `executeDodge`

処理内容:

1. status feature でエネルギーを `15` 消費する
2. プレイヤーの向きからドッジ方向を計算する
3. Bukkit プレイヤーへ速度を設定する
4. [[03_1.00-モデル定義]].プレイヤーセッション のドッジ中フラグとクールダウン終了時刻を更新する
5. 効果音・パーティクルを再生する
6. `8tick` 後にドッジ中フラグを解除する
