# 03_3.06-モデル操作

## 1. model メソッド仕様

### Bedrock判定

クラス名: `AstPlayer`
物理名: `isBedrock`

処理内容:

1. 設定値の Bedrock プレイヤー名prefix一覧を取得する
2. Bukkit プレイヤー名がいずれかのprefixで始まる場合は `true` を返す
3. prefix設定が無い場合、または一致しない場合は `false` を返す

### 権限反映

クラス名: `AstPlayer`
物理名: `applyPermission`

処理内容:

1. [[03_1.00-モデル定義]].プレイヤーセッション.user を更新する
2. permission が `99` 以上の場合、Bukkit OP 権限を付与する
3. OP 権限付与時は `LogId.I_5070` と `PlayerMsgId.P_5070` を出力する

	| 項目 | 内容 |
	|---|---|
	| ID | `LogId.I_5070` |
	| レベル | `INFO` |
	| テンプレート | `プレイヤーにOP権限を付与しました: %s (permission=%d)` |
	| 出力条件 | permission が `99` 以上 |
	| 引数 | プレイヤー名, permission |

	| 項目 | 内容 |
	|---|---|
	| ID | `PlayerMsgId.P_5070` |
	| レベル | `INFO` |
	| テンプレート | `permissionレベル{0}の管理者として認識されました。OP権限が付与されました。` |
	| 出力条件 | permission が `99` 以上 |
	| 引数 | permission |

4. permission が `99` 未満の場合、Bukkit OP 権限を解除する

### アカウントモード反映

クラス名: `AstPlayer`
物理名: `applyAccountMode`

処理内容:

1. [[03_1.00-モデル定義]].プレイヤーセッション.account を更新する
2. 通常プレイヤー以外の場合、エンティティ・ブロック操作範囲を管理用の値へ戻す
3. 通常プレイヤーの場合、ゲームモードを ADVENTURE にし、操作範囲を `0` にする

### プレイヤーメッセージ送信

クラス名: `AstPlayer`
物理名: `sendMessage`

処理内容:

1. プレイヤーがオンラインでない場合は送信しない
2. [[03_1.00-モデル定義]].プレイヤーメッセージリソース で文言を取得・整形する
3. Bukkit Player へメッセージを送信する

### 空中アクション状態

クラス名: `AstPlayer`
論理名: `空中アクション状態保持`

処理内容:

1. `isJumpInputPressed` は `PlayerInputEvent` の直近 jump 押下状態を保持し、立ち上がり検知に使う
2. `isAirJumpConsumed` は滞空中に一度だけ二段ジャンプを許可するための消費フラグとして使う
3. `wallClingExpiresAtMs` / `isWallClinging` / `wallClingTowardWallDirection` は壁張り付きの残り時間・有効状態・壁方向の保持に使う
4. 各状態は `DodgeService` / `AirActionService` が更新し、着地や解除時にリセットする
