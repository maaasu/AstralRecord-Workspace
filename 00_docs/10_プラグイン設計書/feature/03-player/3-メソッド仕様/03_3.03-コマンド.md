# 03_3.03-コマンド

## 1. command メソッド仕様

### テストコマンド実行

クラス名: `TestCommand`
物理名: `executePlayerCommand`

処理内容:

1. 引数なし、または `info` の場合はプレイヤー情報表示を実行する
2. `permission` の場合は権限表示を実行する
3. 対応外の場合は usage を返す

### プレイヤー情報表示

クラス名: `TestCommand`
物理名: `showPlayerInfo`

処理内容:

1. [[03_1.00-モデル定義]].プレイヤーセッション からプレイヤー名とUUIDを取得する
2. `PlayerMsgId.P_5050` でメッセージを送信する

	| 項目 | 内容 |
	|---|---|
	| ID | `PlayerMsgId.P_5050` |
	| レベル | `INFO` |
	| テンプレート | `[TEST] プレイヤー情報: 名前={0}, UUID={1}` |
	| 出力条件 | `/test` または `/test info` 実行時 |
	| 引数 | プレイヤー名, UUID |

### 権限表示

クラス名: `TestCommand`
物理名: `showPermission`

処理内容:

1. [[03_1.00-モデル定義]].プレイヤーセッション.user.permission を取得する
2. `PlayerMsgId.P_5051` でメッセージを送信する

	| 項目 | 内容 |
	|---|---|
	| ID | `PlayerMsgId.P_5051` |
	| レベル | `INFO` |
	| テンプレート | `[TEST] ユーザー権限レベル: {0}` |
	| 出力条件 | `/test permission` 実行時 |
	| 引数 | permission |

### テンポラリUI表示

クラス名: `TempCommand`
物理名: `executePlayerCommand`

処理内容:

1. 引数からUI種別を取得する
2. UI種別に対応する Bukkit Inventory を生成する
3. 生成できた場合、プレイヤーへインベントリを開く

### テスト補完候補取得

クラス名: `TestTabCompleter`
物理名: `getPlayerCompletions`

処理内容:

1. 第1引数位置では `info`, `permission` を返す

### テンポラリ補完候補取得

クラス名: `TempTabCompleter`
物理名: `getPlayerCompletions`

処理内容:

1. 第1引数位置では対応UI種別を返す
