# 03_3.01-イベント

## 1. event メソッド仕様

### プレイヤー参加イベント受付

イベント物理名: `PlayerJoinEvent`  
クラス名: `PlayerJoinEventHandler`  
物理名: `onPlayerJoin`

処理内容:

1. プレイヤーUUIDとプレイヤー名を取得する
2. ロード中プレイヤーとして登録し、現在座標を移動ロック位置として保持する
3. `PlayerMsgId.P_5071` を送信し、ロード中であることを通知する
4. サーバー全体で参加ロード開始間隔を予約し、非同期タスクで [[03_3.02-サービス]].プレイヤー参加ユーザ読込 を実行する
5. 一定 tick 後に [[03_3.02-サービス]].プレイヤー参加アカウント読込 を実行する
6. さらに一定 tick 後に [[03_3.02-サービス]].プレイヤー参加インベントリstate読込 を実行する
7. 参加データが取得できた場合、メインスレッドで [[03_3.02-サービス]].プレイヤー参加反映 を実行する
8. プレイヤー参加反映後、[[03_3.02-サービス]].ログインボーナス表示 を開始する。API取得は非同期、GUI描画だけをメインスレッドで行う
9. ロード中登録と移動ロックを解除し、`PlayerMsgId.P_5072` を送信する
10. 一定 tick 後の非同期タスクで [[03_3.02-サービス]].ログイン履歴登録 を実行する
11. 途中でデータ取得に失敗した場合はロード中登録と移動ロックを解除する
12. 例外時は `LogId.E_5070` を記録する

	| 項目 | 内容 |
	|---|---|
	| ID | `LogId.E_5070` |
	| レベル | `ERROR` |
	| テンプレート | `プレイヤーイベント処理に失敗しました: event=%s, player=%s, reason=%s` |
	| 出力条件 | 参加イベント処理で例外発生時 |
	| 引数 | `PlayerJoinEvent`, プレイヤー名, 例外メッセージ |

### プレイヤー参加ロード中移動抑止

イベント物理名: `PlayerMoveEvent`
クラス名: `PlayerJoinEventHandler`
物理名: `onPlayerMove`

処理内容:

1. 対象プレイヤーがロード中プレイヤーとして登録されているか判定する
2. ロード中でない場合は何もしない
3. `PlayerTeleportEvent` の場合はテレポートを許可し、移動先を新しいロック位置として保持する
4. 通常移動で移動先座標のワールドまたは X/Y/Z がロック位置と異なる場合、移動先をロック位置へ差し戻す
5. yaw/pitch は移動先の値を引き継ぎ、ロード中でも視点変更は許可する

### プレイヤー退出イベント受付

イベント物理名: `PlayerQuitEvent`  
クラス名: `PlayerJoinEventHandler`  
物理名: `onPlayerQuit`

処理内容:

1. [[03_3.02-サービス]].プレイヤー退出処理を実行する
2. ロード中登録と移動ロックが残っている場合は解除する
3. 非同期タスクで [[03_3.02-サービス]].ログアウト履歴登録 を実行する
4. 例外時は `LogId.E_5070` を記録する

	| 項目 | 内容 |
	|---|---|
	| ID | `LogId.E_5070` |
	| レベル | `ERROR` |
	| テンプレート | `プレイヤーイベント処理に失敗しました: event=%s, player=%s, reason=%s` |
	| 出力条件 | 退出イベント処理で例外発生時 |
	| 引数 | `PlayerQuitEvent`, プレイヤー名, 例外メッセージ |

### プレイヤーモード操作制限

イベント物理名: `InventoryClickEvent` / `InventoryDragEvent` / `PlayerDropItemEvent` / `PlayerGameModeChangeEvent`  
クラス名: `PlayerModeEventHandler`  
物理名: `onInventoryClick` / `onInventoryDrag` / `onPlayerDropItem` / `onGameModeChange`

処理内容:

1. 対象プレイヤーが通常プレイヤーモードか判定する
2. 通常プレイヤーモードの場合、対象操作をキャンセルする
3. 例外時は `LogId.E_5072` を記録する

	| 項目 | 内容 |
	|---|---|
	| ID | `LogId.E_5072` |
	| レベル | `ERROR` |
	| テンプレート | `プレイヤーモード操作制限処理に失敗しました: %s` |
	| 出力条件 | プレイヤーモード操作制限で例外発生時 |
	| 引数 | プレイヤー名 |

### バニラDMコマンド遮断

イベント物理名: `PlayerCommandPreprocessEvent`
クラス名: `ManagedChatEventHandler`
物理名: `onPlayerCommandPreprocess`

処理内容:

1. 入力コマンドの先頭 token を小文字化し、先頭 `/` と `minecraft:` などの namespace を除去して解決後 command 名を正規化する
2. command 名が `msg` / `tell` / `w` / `whisper` の場合は event をキャンセルする
3. `PlayerMsgId.P_5945` を送信し、管理対象の `/message <player> <text>` 利用を案内する

### しゃがみイベント受付

イベント物理名: `PlayerToggleSneakEvent`  
クラス名: `PlayerSneakEventHandler`  
物理名: `onPlayerToggleSneak`

処理内容:

1. [[03_1.00-モデル定義]].プレイヤーキャッシュ から [[03_1.00-モデル定義]].プレイヤーセッション を取得する
2. しゃがみ開始時は、空中かつ正面近距離に固体ブロックがある場合 [[03_3.02-サービス]].壁張り付き開始 を実行する
3. 壁張り付き開始条件を満たさない地上しゃがみ開始時は [[03_3.02-サービス]].地上ドッジ受付開始 を実行する
4. しゃがみ解除時は、壁張り付き中なら [[03_3.02-サービス]].壁張り付き解除 を実行し、そうでなければ [[03_3.02-サービス]].しゃがみ解除ドッジ判定 を実行する
5. 例外時は `LogId.E_5170` を記録する

### 入力イベント受付

イベント物理名: `PlayerInputEvent`
クラス名: `PlayerInputEventHandler`
物理名: `onPlayerInput`

処理内容:

1. [[03_1.00-モデル定義]].プレイヤーキャッシュ から [[03_1.00-モデル定義]].プレイヤーセッション を取得する
2. `event.input.jump` の押下状態を [[03_3.02-サービス]].jump入力処理 へ渡す
3. 例外時は `LogId.E_5171` を記録する
