# 03_3.01-イベント

## 1. event メソッド仕様

### プレイヤー参加イベント受付

イベント物理名: `PlayerJoinEvent`  
クラス名: `PlayerJoinEventHandler`  
物理名: `onPlayerJoin`

処理内容:

1. プレイヤーUUIDとプレイヤー名を取得する
2. 非同期タスクで [[03_3.02-サービス]].プレイヤー参加データ読込 を実行する
3. 参加データが取得できた場合、メインスレッドで [[03_3.02-サービス]].プレイヤー参加反映 を実行する
4. 非同期タスク内で [[03_3.02-サービス]].ログイン履歴登録 を実行する
5. 例外時は `LogId.E_5070` を記録する

	| 項目 | 内容 |
	|---|---|
	| ID | `LogId.E_5070` |
	| レベル | `ERROR` |
	| テンプレート | `プレイヤーイベント処理に失敗しました: event=%s, player=%s, reason=%s` |
	| 出力条件 | 参加イベント処理で例外発生時 |
	| 引数 | `PlayerJoinEvent`, プレイヤー名, 例外メッセージ |

### プレイヤー退出イベント受付

イベント物理名: `PlayerQuitEvent`  
クラス名: `PlayerJoinEventHandler`  
物理名: `onPlayerQuit`

処理内容:

1. [[03_3.02-サービス]].プレイヤー退出処理を実行する
2. 非同期タスクで [[03_3.02-サービス]].ログアウト履歴登録 を実行する
3. 例外時は `LogId.E_5070` を記録する

	| 項目 | 内容 |
	|---|---|
	| ID | `LogId.E_5070` |
	| レベル | `ERROR` |
	| テンプレート | `プレイヤーイベント処理に失敗しました: event=%s, player=%s, reason=%s` |
	| 出力条件 | 退出イベント処理で例外発生時 |
	| 引数 | `PlayerQuitEvent`, プレイヤー名, 例外メッセージ |

### プレイヤーモード操作制限

イベント物理名: `InventoryClickEvent` / `InventoryDragEvent` / `PlayerDropItemEvent` / `PlayerGameModeChangeEvent`  
クラス名: `PlayerModeEventHandler`  
物理名: `onInventoryClick` / `onInventoryDrag` / `onPlayerDropItem` / `onGameModeChange`

処理内容:

1. 対象プレイヤーが通常プレイヤーモードか判定する
2. 通常プレイヤーモードの場合、対象操作をキャンセルする
3. 例外時は `LogId.E_5072` を記録する

	| 項目 | 内容 |
	|---|---|
	| ID | `LogId.E_5072` |
	| レベル | `ERROR` |
	| テンプレート | `プレイヤーモード操作制限処理に失敗しました: %s` |
	| 出力条件 | プレイヤーモード操作制限で例外発生時 |
	| 引数 | プレイヤー名 |

### しゃがみイベント受付

イベント物理名: `PlayerToggleSneakEvent`  
クラス名: `PlayerSneakEventHandler`  
物理名: `onPlayerToggleSneak`

処理内容:

1. [[03_1.00-モデル定義]].プレイヤーキャッシュ から [[03_1.00-モデル定義]].プレイヤーセッション を取得する
2. しゃがみ開始時は開始時刻とプレイヤー座標を記録する
3. しゃがみ解除時は [[03_3.02-サービス]].しゃがみ解除ドッジ判定 を実行する
4. 例外時は `LogId.E_5170` を記録する
