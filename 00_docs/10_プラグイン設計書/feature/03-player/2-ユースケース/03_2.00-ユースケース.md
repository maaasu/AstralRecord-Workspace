# 03_2.00-ユースケース

## 1. ログイン反映

- 契機: `PlayerJoinEvent`
- 非同期処理: [[03_3.02-サービス]].プレイヤー参加データ読込
- メインスレッド処理: [[03_3.02-サービス]].プレイヤー参加反映
- 結果: [[03_1.00-モデル定義]].プレイヤーセッション を構築し、[[03_1.00-モデル定義]].プレイヤーキャッシュ へ登録する

## 2. ログアウト保存

- 契機: `PlayerQuitEvent`
- 処理: [[03_3.02-サービス]].プレイヤー退出処理
- 結果: 保存タスクを実行し、プレイヤーキャッシュから削除する

## 3. プレイヤーモード操作制限

- 契機: インベントリクリック、インベントリドラッグ、アイテムドロップ、ゲームモード変更
- 条件: [[03_1.00-モデル定義]].プレイヤーセッション.account.mode が通常プレイヤー
- 結果: 対象操作をキャンセルする

## 4. ドッジ発動

- 契機: しゃがみ開始後、短時間でしゃがみ解除
- 条件: オンライン、生存、エネルギー十分
- 結果: エネルギーを消費し、しゃがみ開始時座標から解除時座標へのベクトル（移動なしの場合は視線方向）を方向とした移動ベクトル・演出・ドッジ中フラグを反映する
