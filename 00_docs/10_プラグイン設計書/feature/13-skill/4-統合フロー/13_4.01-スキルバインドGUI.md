# 13_4.01 スキルバインドGUI

## 概要

プレイヤーが現在所持しているスキルを確認し、発動スキル用 8 枠とパッシブスキル用 8 枠へ設定する GUI。

## 所持スキル判定

GUI が扱う「所持スキル」は次の合算です。

- 職業スキル
- 装備本体の `skills`
- ルーン由来の `skills`
- セット効果由来の `skills`
- スキルツリー解放ノード由来の `skillIds`

スキルツリー由来の供給元:

- 解放済みノード集合と未使用スキルポイントは account 単位で API / DB 永続化する
- ノード定義本体は filebase `skilltree` を正本とする
- ノード座標レイアウトは `skilltree_structure.yml` をサーバローカル plugin ファイルとして管理する

## スキル一覧の表示ルール

- 一覧には現在所持しているスキルだけを表示する
- 発動スキルかパッシブスキルかを各スキル情報に表示する
- パッシブスキルは `passive.bindRequired` の状態も表示する
- `passive.bindRequired: false` のパッシブスキルは、所持のみで常時発動するため一覧には表示しない

## バインドルール

- 発動スキルは発動スキル枠にだけ設定できる
- パッシブスキルはパッシブスキル枠にだけ設定できる
- 選択中スロットとスキル種別が一致しない場合は設定を拒否する
- スロット未選択時は、スキル種別に対応する側の空きスロットへ自動設定する

## パッシブスキルの発動ルール

- `passive.bindRequired: true`
  - 所持していて、かつパッシブ枠に設定されている時だけ発動
- `passive.bindRequired: false`
  - 所持しているだけで常時発動
  - バインド GUI の一覧には出さない

## 保存と切替

- プリセット一覧は account 単位でメモリキャッシュし、通常参照では API へ再取得しない
- プリセット保存に成功した場合は、保存済みプリセットでキャッシュを更新する
- プリセット保存時にパッシブスキルの有効状態を即時再計算する
- プリセット切替時も同様に即時再計算する
- 未所持スキルが古いプリセットに残っていても発動しない

## 2026-06 skilltree UI 補足

- SkillTree ノードの詳細は、浮遊ノードラベルを読むだけで把握できる状態にする。
- SkillTree 操作用にプレイヤーのホットバーを流用しない。
- スキルツリーからの復帰は `/skilltree back` を使用する。
- ノードの解放・解除は、注視中ノードへの左クリック・右クリックで行う。
