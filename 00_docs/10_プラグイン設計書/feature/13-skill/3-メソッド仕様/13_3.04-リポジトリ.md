# 13_3.04-リポジトリ

## スキル全件取得
クラス名: `SkillRepository`
物理名: `findAll`

1. AstralRecord API `GET /api/skill` を呼び出す
2. 取得したレスポンスを [[13_1.00-モデル定義]].スキル一覧項目モデル配列として受け取る
3. 一覧用途で不足する項目がある場合は詳細 API を追加取得せず、サーバー側の一覧レスポンス拡張を優先する
4. 通信失敗時は例外として呼び出し元へ伝播する

## スキル詳細取得
クラス名: `SkillRepository`
物理名: `findById`

1. AstralRecord API `GET /api/skill/{skillId}` を呼び出す
2. レスポンスを [[13_1.00-モデル定義]].スキル定義モデル へ変換する
3. 404 は未定義スキルとして `null` へ変換する

## API レスポンス変換
クラス名: `SkillRepository`
物理名: `toDefinition`

1. API レスポンスの `implementationId` をそのまま保持する
2. `params` は `Map<String, Object>` として保持し、ここでは個別検証しない
3. `onCast.sound` は `onCastSound` へ射影する
4. `null` 許容項目は Plugin 側既定値へ補完せず、原則 API 値を尊重する
