# 13_3.09-モデル操作

## 必須文字列取得
クラス名: `SkillParamReader`
物理名: `requireString`

1. `params[key]` を取得する
2. 値が文字列であることを検証する
3. 未定義または型不一致時は `SkillParameterException` を送出する

## 数値取得
クラス名: `SkillParamReader`
物理名: `getDouble`

1. `params[key]` を取得する
2. `Number` 系であれば `double` へ変換する
3. 未定義時は `defaultValue` を返す

## 参照値取得
クラス名: `SkillParamReader`
物理名: `getRefId`

1. `params[key]` を文字列として取得する
2. `prefix` 付き参照値であることを検証する
3. `skill:` や `buff:` の prefix を除去した素の ID を返す

## `params` 検証
クラス名: `SkillExecutor`
物理名: `validateParams`

1. 実装ごとに必要キーと型を検証する
2. 検証失敗時は `skillId` と不足キーを含めて例外化する
3. 共通スキーマの更新は行わず、実装契約の範囲で完結させる
