# 13_3.02-サービス

## スキル定義同期
クラス名: `SkillService`
物理名: `reloadDefinitions`

1. [[13_3.04-リポジトリ]].スキル全件取得 を呼び出す
2. 一覧レスポンスの `id` ごとに [[13_3.04-リポジトリ]].スキル詳細取得 を呼び出す
3. 取得した各スキル定義について `implementationId` が空でないことを検証する
4. [[13_3.06-レジストリ・キャッシュ]].実行クラス解決 で `implementationId` に対応する実行クラスを確認する
5. `SkillExecutor.validateParams` を呼び出し、`params` 妥当性を検証する
6. 検証成功分だけを新しい定義一覧として構築し、[[13_3.06-レジストリ・キャッシュ]].スキル定義反映 でレジストリへ一括反映する
7. 一覧取得自体が失敗した場合は既存レジストリを保持したまま現在件数を返す
8. 未登録 `implementationId` または不正 `params` はスキップし、以下ログを記録する

    | 項目 | 内容 |
    |---|---|
    | ID | LogId.W_5801 |
    | レベル | Warning |
    | テンプレート | スキル定義を読み込みませんでした: skillId=%s, implementationId=%s, reason=%s |
    | 出力条件 | 実行クラス未登録または検証失敗時 |
    | 引数 | スキル ID、implementationId、理由 |

## スキル発動
クラス名: `SkillService`
物理名: `castSkill`

1. `skillId` で [[13_3.06-レジストリ・キャッシュ]].スキル定義解決 を行う
2. 発動者のステータスから `requiredLevel` / `manaCost` を検証する
3. 発動者の現在クールダウンを確認し、未終了なら失敗結果を返す
4. `castTimeTicks` はモデルとして保持するが、現実装では詠唱ハンドリングは未実装
5. `onCastSound` が定義されている場合は共通サウンドを再生する
6. [[13_3.06-レジストリ・キャッシュ]].実行クラス解決 で `implementationId` を解決する
7. `SkillCastContext` を構築し、実行クラスへ委譲する
8. 成功時は MP 消費と cooldown 開始を共通適用する
9. 失敗時は以下ログを記録する

    | 項目 | 内容 |
    |---|---|
    | ID | LogId.E_5802 |
    | レベル | Error |
    | テンプレート | スキル発動に失敗しました: skillId=%s, implementationId=%s |
    | 出力条件 | 実行クラスで例外発生時 |
    | 引数 | スキル ID、implementationId |

## 実行可否判定
クラス名: `SkillService`
物理名: `canCast`

1. `requiredLevel` を発動者レベルと比較する
2. `manaCost` を現在 MP と比較する
3. cooldown 状態を確認する
4. 判定結果を `SkillCastResult` で返す
