# 07_3.01-サービス

## 1. service メソッド仕様

### ステータス取得

クラス名: `StatusService`  
物理名: `getStatus`

処理内容:

1. [[03_1.00-モデル定義]].プレイヤーセッション から [[07_1.00-モデル定義]].ステータススナップショット を取得する。
2. ステータス値一覧が空の場合、[[07_3.01-サービス]].ステータス再計算 を実行して結果を返す。
3. ステータス値一覧が存在する場合、保持済みのステータススナップショットを返す。

### ステータス再計算

クラス名: `StatusService`  
物理名: `refreshStatus`

処理内容:

1. buff feature へ期限切れバフ削除を依頼する。
2. 現在の [[07_1.00-モデル定義]].ステータススナップショット を退避する。
3. 全 [[07_1.00-モデル定義]].ステータス種別 について、基礎値・アカウントモード補正・権限補正・バフ補正を計算する。
4. 退避したステータス値一覧が空の場合、HP / MP / EN を最大値まで回復した状態で初期化する。
5. 退避したステータス値一覧が存在する場合、現在 HP / MP / EN を維持しながら新しい最大値の範囲内へ丸める。
6. [[03_1.00-モデル定義]].プレイヤーセッション に再計算後のステータススナップショットを設定して返す。

### バフ適用

クラス名: `StatusService`  
物理名: `applyBuff`

処理内容:

1. buff feature へバフ適用を依頼する。
2. 適用結果が失敗の場合、[[07_3.01-サービス]].ステータス取得 を実行して現在状態を返す。
3. 適用結果が成功の場合、[[07_3.01-サービス]].ステータス再計算 を実行して結果を返す。

### バフ解除

クラス名: `StatusService`  
物理名: `removeBuff`

処理内容:

1. buff feature へ指定バフ解除を依頼する。
2. [[07_3.01-サービス]].ステータス再計算 を実行して結果を返す。

### 有効バフ一覧取得

クラス名: `StatusService`  
物理名: `getActiveBuffs`

処理内容:

1. buff feature から [[03_1.00-モデル定義]].プレイヤーセッション の有効バフ一覧を取得する。
2. 取得した有効バフ一覧を返す。

### スナップショット生成

クラス名: `StatusService`  
物理名: `createSnapshot`

処理内容:

1. 全 [[07_1.00-モデル定義]].ステータス種別 を走査する。
2. [[07_3.01-サービス]].基礎値取得 でステータス種別ごとの基礎値を取得する。
3. [[07_3.01-サービス]].補正値取得 でアカウントモード・権限・バフを合算した補正値を取得する。
4. 基礎値と補正値から [[07_1.00-モデル定義]].ステータス値 を生成する。
5. 全ステータス値、現在 HP `0.0`、現在 MP `0.0`、現在 EN `0.0`、計算日時で [[07_1.00-モデル定義]].ステータススナップショット を生成する。

### 全リソース最大値回復

クラス名: `StatusService`

3. 更新後のステータススナップショットを返す。

### 補正値取得

クラス名: `StatusService`  
物理名: `getBonusValue`

処理内容:

1. [[07_3.01-サービス]].アカウントモード補正取得 で [[02_1.00-モデル定義]].アカウントモード 補正を取得する。
2. [[07_3.01-サービス]].権限補正取得 で [[01_1.00-モデル定義]].ユーザモデル.permission 補正を取得する。
3. 基礎値と非バフ補正の合計を buff feature へ渡し、バフ補正を取得する。
4. 非バフ補正とバフ補正を合算して返す。

### 権限補正取得

クラス名: `StatusService`  
物理名: `getPermissionBonus`

処理内容:

1. `permission` が [[03_1.00-モデル定義]].プレイヤーセッション の OP 権限しきい値以上の場合、OP 権限補正を返す。
2. `permission` が `10` 以上かつ OP 権限しきい値未満の場合、運用権限補正を返す。
3. それ以外の場合、補正値 `0.0` を返す。

	| 権限条件 | 主な補正 |
	|---|---|
	| OP 権限しきい値以上 | 最大HP/MP/EN、基本能力値、攻撃・防御・回復系を広く補正する |
	| `10` 以上 | 最大MP/EN、基本能力値、攻撃・防御の一部を軽く補正する |
	| 上記以外 | 補正なし |
