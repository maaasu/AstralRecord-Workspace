# 07_5.00-例外・ログ・運用

## 1. 方針

`status` 機能はオンライン中のメモリ状態を扱うため、API や Repository の例外境界を持たない。  
主な運用観点は、ステータス計算の整合性、定期回復タスクの重複起動防止、プレイヤー向けメッセージの表示内容である。

## 2. 主なメッセージポイント

- [[07_3.03-コマンド]].ステータス表示
  - `PlayerMsgId.P_5100`: ステータス見出し
  - `PlayerMsgId.P_5101`: 通常表示のステータス値
  - `PlayerMsgId.P_5103`: 詳細表示のステータス値
  - `PlayerMsgId.P_5104`: 最終更新日時
  - `PlayerMsgId.P_5105`: 現在 HP / MP
  - `PlayerMsgId.P_5106`: 現在 EN
- [[07_3.03-コマンド]].ステータスコマンド実行
  - `PlayerMsgId.P_5102`: 再計算完了

## 3. タスク運用

- [[07_3.05-タスク]].定期回復開始 は重複起動を防止する。
- [[07_3.05-タスク]].定期回復停止 はプラグイン無効化時に呼び出し、BukkitTask をキャンセルする。
- 定期回復は `20tick` ごとに実行する。
- 回復量は HP回復力（`HP_REGEN`） / `5.0`, MP回復力（`MP_REGEN`） / `5.0`, EN回復力（`ENERGY_REGEN`） / `5.0` を 1 秒あたりの値として扱う。

## 4. 注意点

- 現在 HP / MP / EN は [[07_3.09-モデル操作]].現在リソース丸め により `0` 以上、最大値以下へ丸める。
- ステータス再計算時、既存の現在 HP / MP / EN は維持される。ただし最大値変更により上限を超える場合は丸められる。
- 初回計算時は HP / MP / EN を最大値まで回復する。
