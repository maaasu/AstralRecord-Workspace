# 07_1.00-モデル定義

## 1. ドメインモデル

`status` 機能の中心はステータススナップショット。  
ステータス種別ごとの基礎値・補正値・合計値と、現在 HP / MP / EN を同時に保持する。

## 2. ステータススナップショット

物理名: `StatusSnapshot`

### 2.1 項目

| 項目              | 説明                                                     |
| --------------- | ------------------------------------------------------ |
| `values`        | [[07_1.00-モデル定義]].ステータス種別 ごとの [[07_1.00-モデル定義]].ステータス値 |
| `currentHp`     | 現在 HP                                                  |
| `currentMp`     | 現在 MP                                                  |
| `currentEnergy` | 現在 EN                                                  |
| `calculatedAt`  | 計算日時                                                   |

### 2.2 保持先

- [[03_1.00-モデル定義]].プレイヤーセッション.statusSnapshot に保持する。
- 空状態の場合は、[[07_3.02-サービス]].ステータス再計算 により初期化する。

## 3. ステータス値

物理名: `StatusValue`

| 項目           | 説明                       |
| ------------ | ------------------------ |
| `baseValue`  | 基礎値                      |
| `bonusValue` | アカウントモード・レベル・権限・バフによる補正値 |
| `totalValue` | `baseValue + bonusValue` |

## 4. ステータス種別

物理名: `StatusType`

### 4.1 リソース系

| 物理名 | 論理名 | 用途 |
|---|---|---|
| `MAX_HEALTH` | 最大HP | HP 上限 |
| `MAX_MANA` | 最大MP | MP 上限 |
| `MAX_ENERGY` | 最大EN | EN 上限 |

### 4.2 基本能力値

| 物理名 | 論理名 | 用途 |
|---|---|---|
| `STRENGTH` | 筋力 | 近接攻撃系の基礎能力 |
| `DEXTERITY` | 器用さ | 遠隔攻撃系の基礎能力 |
| `INTELLIGENCE` | 知力 | 魔法攻撃・MP 系の基礎能力 |
| `VITALITY` | 体力 | HP・防御・自然回復系の基礎能力 |
| `AGILITY` | 敏捷性 | 攻撃速度・移動速度・回避系の基礎能力 |
| `LUCK` | 幸運 | クリティカルやドロップ系の基礎能力 |

### 4.3 攻撃系

| 物理名 | 論理名 |
|---|---|
| `ATTACK` | 攻撃力 |
| `MELEE_ATTACK` | 近接攻撃力 |
| `RANGED_ATTACK` | 遠隔攻撃力 |
| `MAGIC_ATTACK` | 魔法攻撃力 |
| `CRITICAL_RATE` | 会心率 |
| `CRITICAL_DAMAGE` | 会心ダメージ |
| `SUPER_CRITICAL_RATE` | 超会心率 |
| `SUPER_CRITICAL_DAMAGE` | 超会心ダメージ |
| `FINAL_DAMAGE_RATE` | 最終ダメージ発生率 |
| `FINAL_DAMAGE_MULTIPLIER` | 最終ダメージ倍率 |
| `ACCURACY` | 命中率 |
| `ATTACK_SPEED` | 攻撃速度 |

### 4.4 防御系

| 物理名 | 論理名 |
|---|---|
| `DEFENSE` | 物理防御力 |
| `MAGIC_DEFENSE` | 魔法防御力 |
| `EVASION` | 回避率 |

### 4.5 回復・ユーティリティ系

| 物理名 | 論理名 |
|---|---|
| `HP_REGEN` | HP回復力 |
| `MP_REGEN` | MP回復力 |
| `ENERGY_REGEN` | EN回復力 |
| `MOVEMENT_SPEED` | 移動速度 |
| `COOLDOWN_REDUCTION` | クールダウン短縮率 |

## 5. ステータスカテゴリ

物理名: `StatusType.Category`

| 物理名 | 論理名 | 対象 |
|---|---|---|
| `RESOURCE` | リソース | HP / MP / EN |
| `PRIMARY` | 基本能力値 | STR / DEX / INT / VIT / AGI / LUK |
| `OFFENSE` | 攻撃 | 攻撃力・会心・命中など |
| `DEFENSE` | 防御 | 防御・魔法防御・回避 |
| `UTILITY` | ユーティリティ | 自然回復・移動速度・短縮率 |

## 6. 関連 feature とのモデル関係

- `player`
  - [[03_1.00-モデル定義]].プレイヤーセッション がステータススナップショットを保持する。
- `account`
  - [[02_1.00-モデル定義]].アカウントモード と `level` により補正値が変わる。
- `buff`
  - 有効バフはステータス種別ごとの補正値として合算される。
