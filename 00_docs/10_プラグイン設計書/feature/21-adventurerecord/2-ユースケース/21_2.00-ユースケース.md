# 21_2.00-ユースケース

## 1. 自分の冒険記録表示

1. menu feature から冒険記録 GUI を開く。
2. [[21_3.00-メソッド仕様]].冒険記録取得 が自分の account を対象に集計する。
3. GUI にサマリを表示する。

## 2. 他プレイヤーの冒険記録表示

1. 許可された導線から対象プレイヤーを選ぶ。
2. [[21_3.00-メソッド仕様]].冒険記録取得 が対象 account を解決する。
3. 閲覧可能な項目だけを GUI に表示する。

## 3. 記録更新参照

1. mob / player などの feature が記録更新契約を必要とする。
2. 本 feature の更新契約に従い、集計対象イベントを追加する。
