# 21_0.00-概要

## 1. 目的

`adventurerecord` feature は、プレイヤーの冒険記録を参照・集計し、GUI で表示する。

## 2. コンテキスト

- menu feature は冒険記録 GUI の導線のみを持つ。
- 記録データの取得・集計・表示項目の正本は本 feature とする。
- 他 feature が記録値を更新する場合も、更新契約は本 feature で管理する。

## 3. 構成要素（実装単位）

- `service/AdventureRecordService`
  - 記録取得、集計、表示用モデル生成を担う。
- `gui/AdventureRecordGui`
  - 冒険記録 GUI を構築する。
- `model/AdventureRecordSummary`
  - 表示用の集計結果を表す。
