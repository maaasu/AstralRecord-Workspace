# 21_5.00-例外・ログ・運用

## 1. 例外方針

- 対象 account を解決できない場合は GUI を開かない。
- 記録集計に失敗した場合は部分表示ではなく取得失敗として扱う。
- 記録イベント反映の失敗は、呼び出し元 feature の主処理を失敗させるかどうかを呼び出し元で判断する。

## 2. 運用上の注意

- 集計項目を追加する場合は [[21_1.00-モデル定義]].冒険記録サマリ と GUI 表示を同時に更新する。
- 他 feature から記録更新を追加する場合は、呼び出し元 feature の README に依存関係を追記する。

## 3. 出力一覧

| 種別 | ID | レベル | テンプレート | 用途 |
|---|---|---|---|---|
| ログ | `LogId.E_5600` | ERROR | `メニューイベント処理に失敗しました: %s` | AdventureRecord GUI の click / drag / close 処理例外 |
| ログ | `LogId.E_5703` | ERROR | `Mob ドロップ抽選で例外が発生しました: mobId=%s` | 討伐記録の非同期保存失敗 |
