# 27_3.00-メソッド仕様

## 1. クエスト定義読込

クラス名: `QuestDefinitionRepository`  
物理名: `findAll`

1. `FileDatabaseManager` の root から `47.features.quest` を読む。
2. `.yml` ファイルを走査し、`QuestDefinition` に変換する。
3. `id` または `objectives` がない定義は読み飛ばす。

## 2. クエストボード読込

クラス名: `QuestBoardRepository`  
物理名: `findAll`

1. `FileDatabaseManager` の root から `48.features.quest_board` を読む。
2. `quests` 配列を `QuestBoardEntry` に変換する。
3. `questId` は `quest:<id>` 形式の prefix を除去して保持する。

## 3. クエスト受領

クラス名: `QuestService`  
物理名: `accept`

1. gameplay account mode を確認する。
2. クエスト表示状態が `AVAILABLE` か確認する。
3. `StatusType.QUEST_LIMIT` から最大受領数を取得し、受領数上限を確認する。
4. 受領条件アイテムの所持数を確認する。
5. `consume=true` の条件アイテムを消費する。
6. `QuestProgress.start` で進行状態を作成し、受領元NPC ID を `acceptedNpcId` として保存する。

## 4. 目標進行加算

クラス名: `QuestService`  
物理名: `recordObjective`

1. 対象プレイヤーの受領中クエストを走査する。
2. 目標種別と対象IDが一致した目標だけ進行数を加算する。
3. 全目標が必要数以上になった場合、`AUTO` クエストは報酬付与と完了処理へ進む。
4. `NPC` クエストは `readyToTurnIn=true` にして報告可能通知を行う。

## 5. 報告・完了

クラス名: `QuestService`  
物理名: `turnIn` / `complete`

1. `READY_TO_TURN_IN` のクエストだけ報告できる。
2. `turnInNpcId` が指定されている場合は、そのNPCからのみ報告できる。
3. `turnInNpcId` が未指定の場合は、`acceptedNpcId` のNPCからのみ報告できる。
4. 報酬アイテムを受け取る空きがない場合は、完了せず通知する。
5. 完了時は受領中クエストから削除し、完了時刻とクールタイムを保存する。

## 6. 報酬付与

クラス名: `QuestService`  
物理名: `grantRewards`

1. `AccountService.grantExperienceCached` でアカウントEXPを付与する。
2. `PlayerClassService.grantClassExperience` でクラスEXPを付与する。
3. `InventoryService.addGold` でGoldを付与する。
4. `InventoryService.addItemToNormalInventory` で報酬アイテムを付与する。
5. `InventoryService.saveNow` で即時保存する。

## 7. NPC interaction

イベント物理名: `PlayerInteractEntityEvent` / `PlayerInteractEvent` / `EntityDamageByEntityEvent`  
クラス名: `MobInteractionEventHandler`  
物理名: `openQuestBoard`

1. NPC interaction action の `id=gui`、`type=QUEST` または `QUEST_BOARD` を判定する。
2. `boardId` または `questBoardId` を読む。
3. `QuestGuiEventHandler.openBoard` にNPCのテンプレートIDを渡して開く。

## 8. クエストGUIクリック

イベント物理名: `InventoryClickEvent`  
クラス名: `QuestGuiEventHandler`  
物理名: `onInventoryClick`

1. クエストボードGUIではクリックをキャンセルする。
2. `AVAILABLE` のクエストは受領する。
3. `READY_TO_TURN_IN` のクエストは報告処理を行う。
4. クエスト一覧GUIではクリック対象のクエストを破棄する。
