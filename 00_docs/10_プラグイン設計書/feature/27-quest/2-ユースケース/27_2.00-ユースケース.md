# 27_2.00-ユースケース

## 1. NPCからクエストを受領する

1. プレイヤーがNPCを右クリックする。
2. NPC interaction の `type: QUEST` と `boardId` からクエストボードを開く。
3. クエストは状態付きで表示する。
4. `受領可能` のクエストをクリックすると受領条件を検証する。
5. 受領条件アイテムの消費設定がある場合は受領時に消費する。
6. 受領数が `QUEST_LIMIT` に達している場合は受領できない。

## 2. 進行度を確認する

1. `/quest` でクエスト一覧GUIを開く。
2. 受領中クエストの lore に `現在数 / 必要数` 形式で進行度を表示する。
3. 報告可能なクエストは状態を `報告可能` として表示する。

## 3. クエストを破棄する

1. クエスト一覧GUIで受領中クエストをクリックする。
2. 対象クエストを受領中リストから削除する。
3. 進行度は破棄される。
4. 破棄後の再受領制限は発生しない。

## 4. 自動完了クエストを完了する

1. 目標条件を満たす。
2. `completion.mode` が `AUTO` の場合、その場で報酬を付与する。
3. 受領中リストから削除する。
4. チャット、サウンド、パーティクルで完了を通知する。

## 5. NPC報告クエストを完了する

1. 目標条件を満たす。
2. 状態を `報告可能` にする。
3. プレイヤーが報告先NPCのクエストボードを開く。
4. 報告可能クエストをクリックすると報酬を付与する。
5. 受領中リストから削除する。
