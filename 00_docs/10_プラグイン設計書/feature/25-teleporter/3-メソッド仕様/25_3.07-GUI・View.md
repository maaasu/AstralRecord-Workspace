# テレポーター GUI・View 仕様

## ウェイストーン表示同期

クラス名: `WaystonePacketView`
物理名: `syncForPlayer`

責務:

プレイヤーの現在ワールド、表示距離、解除状態に応じて、ウェイストーンの BlockDisplay / TextDisplay 相当の packet 表示を同期する。

処理内容:

1. 対象プレイヤーの現在ワールドを取得する。
2. 同一ワールド内のウェイストーン定義だけを抽出する。
3. 対象プレイヤーの解除状態を使って `UNLOCKED` / `LOCKED` を判定する。
4. 未送信のウェイストーンは packet-only display entity を spawn する。
5. 表示状態が変わったウェイストーンは TextDisplay metadata を更新する。
6. ワールド移動、距離外、削除済みのウェイストーンは destroy packet を送信する。

表示構成:

| 部品 | 表示 |
|:--|:--|
| 台座 | `POLISHED_DEEPSLATE` 相当の BlockDisplay |
| 本体 | `CHISELED_STONE_BRICKS` 相当の BlockDisplay |
| 装飾 | `COPPER_BLOCK` または `AMETHYST_BLOCK` 相当の BlockDisplay |
| 頂部 | `SEA_LANTERN` 相当の BlockDisplay |
| 名称 | TextDisplay |

TextDisplay:

| 状態 | 文言 |
|:--|:--|
| 解除済み | `&b<name>` |
| ロック中 | `&c[LOCK] <name>\n&6解除: <unlockGold> Gold` |

## ウェイストーン表示破棄

クラス名: `WaystonePacketView`
物理名: `destroyForPlayer`

1. 対象プレイヤーに送信済みの packet-only entity ID を取得する。
2. destroy packet を送信する。
3. [[25_1.00-モデル定義]].ウェイストーン表示状態 をキャッシュから削除する。

## テレポーター GUI 表示

クラス名: `TeleporterGui`
物理名: `open`

責務:

起点ウェイストーンから移動可能な同一ワールド内ウェイストーン一覧を表示する。
この GUI は menu feature の画面遷移とは独立し、戻るボタンを持たない。

処理内容:

1. [[25_3.02-サービス]].GUI 表示項目構築 を呼び出す。
2. 54 slot inventory を作成する。
3. slot `0-44` を一覧表示領域とする。
4. slot `45` を前ページ、slot `53` を次ページとする。
5. slot `49` には戻るボタンを置かない。
6. GUI 表示中の下部 hotbar は他 GUI と同様に閉じるボタン付き hotbar へ切り替える。
7. プレイヤーへ inventory を開く。

ページング:

- 1 ページ最大 45 件。
- 前ページがない場合、slot `45` は無効表示にする。
- 次ページがない場合、slot `53` は無効表示にする。

## テレポーター GUI 再描画

クラス名: `TeleporterGui`
物理名: `render`

1. 現在ページの表示範囲を計算する。
2. 解除済み項目は `BEACON` で表示する。
3. 未解除項目は `CHAIN` で表示する。`BARRIER` は使用しない。
4. 解除済み項目の lore にはワールド名、座標、クリックで移動する旨を表示する。
5. 未解除項目の lore には未解除である旨、現地で解除が必要である旨、解除コストを表示する。
6. 空き slot は `GRAY_STAINED_GLASS_PANE` のプレースホルダーで埋める。

解除済み項目:

| 項目 | 内容 |
|:--|:--|
| Material | `BEACON` |
| 表示名 | `&b<name>` |
| lore | `クリックで移動`、`worldName`、座標 |

未解除項目:

| 項目 | 内容 |
|:--|:--|
| Material | `CHAIN` |
| 表示名 | `&7<name>` |
| lore | `未解除`、`現地ウェイストーンを右クリックで解除`、`必要ゴールド: <unlockGold>` |

## GUI 項目クリック解決

クラス名: `TeleporterGui`
物理名: `resolveEntry`

1. `TeleporterInventoryHolder` からページ番号と起点ウェイストーン ID を取得する。
2. slot から `TeleporterGuiEntry` を解決する。
3. ページ操作 slot の場合は page action を返す。
4. 空き slot または装飾 slot の場合は何も返さない。
