# World サービス仕様

## WorldRepository

API の `GET /api/world` と `GET /api/world/{worldId}` を呼び出し、`WorldMasterData` に変換する。

## WorldService

`WorldMasterData` の Plugin 内キャッシュとワールド解決を担当する。

| Method | Description |
|---|---|
| `loadAll()` | API から全 `WorldMasterData` を読み込み、ID 順でキャッシュ更新する。必要に応じて `baseWorldPath` を解決して Bukkit ワールドのロードも試行する。 |
| `reloadFromYaml()` | MasterData Seeder API で filebase YAML を MasterDataDB に同期したあと、`loadAll()` を再実行してキャッシュと Bukkit ワールド解決を更新する。 |
| `getAll()` | キャッシュ済み `WorldMasterData` 一覧を返す。 |
| `showWorldChangeTitle(player)` | `PlayerChangedWorldEvent` 後に現在ワールドの表示名をタイトル表示する。 |
| `getById(worldId)` | 指定 ID の `WorldMasterData` を返す。 |
| `resolveLoadedWorld(data)` | `baseWorldPath` や候補名から対応する Bukkit ワールドを解決する。 |
| `findByBukkitWorld(world)` | Bukkit ワールドに対応する `WorldMasterData` をキャッシュから逆引きする。 |
| `resolveSpawnLocation(data)` | `resolveLoadedWorld(data)` と `data.spawnLocation` を使って `Location` を返す。 |
| `teleportPlayerAsync(player, targetLocation, onSuccess)` | 必要な display passenger を外してチャンクを先読みし、`teleportAsync` 後に `onSuccess` を呼ぶ。 |
| `teleportToSpawnAsync(player, data)` | `resolveSpawnLocation(data)` を使って既定スポーンへ非同期テレポートする。参加時スポーンと `/world tp` で利用する。 |
| `applyRpgGameRules(world)` | RPG 用 gamerule を適用する。 |

`WorldSpawnParticleTask` は `WorldMasterData.showSpawnParticle` が `true` のワールドだけにスポーン地点リングパーティクルを表示する。`false` のワールドでも `spawnLocation` は参加時スポーンと `/world tp` に引き続き利用する。

## OverworldTeleportService

拠点ワールドからオーバーワールドへ移動する GUI の候補抽出と転送を担当する。

| Method | Description |
|---|---|
| `listDestinations()` | `WorldType = OVERWORLD` の `WorldMasterData` だけを抽出し、表示名順で返す。 |
| `isBaseWorld(world)` | Bukkit ワールドに対応する `WorldMasterData` が `BASE` か判定する。 |
| `teleportToDestination(player, astPlayer, worldId)` | 指定 `worldId` の `spawnLocation` へ非同期テレポートする。失敗時のみプレイヤーメッセージを返す。 |

## BaseWorldGatewayEventHandler

拠点ワールド内のゲートウェイ接触で GUI を開く。

1. `PlayerMoveEvent` で `END_GATEWAY` / `END_PORTAL` / `NETHER_PORTAL` ブロックへ入った瞬間を検知する。
2. すでに同じゲートウェイ帯から抜けていないプレイヤーは再オープンしない。
3. `OverworldTeleportGuiEventHandler.open(player)` を呼び、候補がなければエラーメッセージのみ返す。
4. `PlayerTeleportEvent` の `END_GATEWAY` / `END_PORTAL` / `NETHER_PORTAL` は拠点ワールド内では常に `cancel` する。

## OverworldTeleportGuiEventHandler

オーバーワールド転送 GUI の表示とクリック遷移を担当する。

1. GUI を開く前に `OverworldTeleportService.listDestinations()` を取得する。
2. 候補 0 件ならメッセージ `P_5769` を返して開かない。
3. クリックされた `worldId` を `OverworldTeleportService.teleportToDestination(...)` へ渡す。
4. `guiIconMaterial` は item icon、`displayName` / `description` / `adventureGuide` は lore/表示名に使う。

## ReturnToBaseService

`joinSpawn.world` を拠点として扱い、menu feature からの帰還処理を担う。

| Method | Description |
|---|---|
| `calculateGoldCost(playerLevel)` | 帰還コストを `100 x max(1, playerLevel)` で計算する。 |
| `beginReturn(astPlayer)` | 拠点スポーン `WorldMasterData` とスポーン座標を解決し、帰還確認と演出を開始する。 |
| `cancelAll()` | 実行中の帰還処理をすべて解除する。 |
