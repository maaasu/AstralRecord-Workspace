# World サービス仕様

## WorldRepository

API の `GET /api/world` と `GET /api/world/{worldId}` を呼び出し、`WorldMasterData` に変換する。

## WorldService

`WorldMasterData` の Plugin 内キャッシュを管理する。

| Method | Description |
|---|---|
| `loadAll()` | API から全 `WorldMasterData` を取得し、ID 順でキャッシュを更新する。その後、各定義の `baseWorldPath` に対応する既存ワールドフォルダを Bukkit にロードする。 |
| `reloadFromYaml()` | MasterData Seeder API で filebase YAML を MasterDataDB に同期し、その後 `loadAll()` を実行してキャッシュと Bukkit ロード済みワールドを更新する。 |
| `getAll()` | キャッシュ済み `WorldMasterData` 一覧を返す。 |
| `getById(worldId)` | 指定 ID の `WorldMasterData` を返す。 |
| `resolveLoadedWorld(data)` | `baseWorldPath`、その末尾名、ワールドフォルダ実体比較、`data.id` の順で Bukkit ロード済みワールドを解決する。 |
| `findByBukkitWorld(world)` | Bukkit ワールドに対応する `WorldMasterData` をキャッシュから引き当てる。 |
| `resolveSpawnLocation(data)` | `resolveLoadedWorld(data)` の結果と `data.spawnLocation` を組み合わせて `Location` を生成する。 |
| `applyRpgGameRules(world)` | Bukkit ワールドへ RPG マップ用 gamerule を適用する。Mob 自然スポーン、パトロール、行商人、ウォーデン、襲撃、Mob griefing、Mob loot、entity drop、火延焼、昼夜/天候サイクルを抑止し、keepInventory / immediateRespawn を有効化する。 |
