# World サービス仕様

## WorldRepository

API の `GET /api/world` と `GET /api/world/{worldId}` を呼び出し、`WorldMasterData` に変換する。

- 一覧 API は概要情報のみを返すため、各 ID に対して詳細 API を呼び、Plugin 側の完全なモデルへ変換する。
- API が `404` を返した場合は `null` として扱う。
- API 通信失敗は例外として上位へ伝搬し、コマンド基盤のエラーメッセージ対象にする。

## WorldService

WorldMasterData の Plugin 内キャッシュを管理する。

| Method | Description |
|---|---|
| `loadAll()` | API から全 WorldMasterData を取得し、ID 順でキャッシュを更新する。その後、各定義の `baseWorldPath` に対応する既存ワールドフォルダを Bukkit にロードする。 |
| `reloadFromYaml()` | MasterData Seeder API で filebase YAML を MasterDataDB に同期し、その後 `loadAll()` を実行して WorldMasterData キャッシュと Bukkit ロード済みワールドを更新する。 |
| `getAll()` | キャッシュ済み WorldMasterData 一覧を返す。 |
| `getById(worldId)` | 指定 ID のキャッシュ済み WorldMasterData を返す。 |
| `resolveLoadedWorld(data)` | `baseWorldPath`、`baseWorldPath` の末尾名、ワールドフォルダの実体パス、最後に `data.id` で Bukkit ロード済みワールドを解決する。 |
