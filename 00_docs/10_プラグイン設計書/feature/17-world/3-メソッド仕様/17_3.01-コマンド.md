# World コマンド仕様

## `/world list`

`WorldService.getAll()` の結果を一覧表示する。ロード済み定義がない場合は空メッセージを返す。

## `/world info <worldId>`

`WorldService.getById(worldId)` の詳細を表示する。未ロード ID の場合はエラーを返す。

## `/world tp <worldId>`

指定 WorldMasterData に対応する Bukkit ロード済みワールドを `WorldService.resolveLoadedWorld` で解決し、実行者を `spawnLocation` へ移動する。未ロードの場合はエラーを返す。

## `/world loaded`

`Bukkit.getWorlds()` のワールド名を表示する。

## `/world reload`

`WorldService.reloadFromYaml()` を実行し、filebase YAML を MasterDataDB に同期してから WorldMasterData を再取得する。
