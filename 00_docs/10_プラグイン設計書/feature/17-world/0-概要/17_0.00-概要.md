# World システム概要

World システムは、filebase の `60.features.world` で定義された WorldMasterData を AstralRecord API から取得し、Plugin 内でキャッシュする。

今回の実装範囲は以下に限定する。

- WorldType と WorldMasterData のモデル定義
- API からの WorldMasterData 取得
- 管理者用 `/world` コマンド
- `plugin.yml` の `joinSpawn` によるサーバー参加時の移動先ワールド・座標設定

ワールド複製、動的ロード、インスタンス削除は未実装。将来のインスタンス生成時は `worlds/` 配下を基準に `baseWorldPath` を複製元、`instanceRootPath` を複製先ルートとして使い、`{worldId}_{instanceType}_{ownerId}_{shortHash}` の生成名で作成する。

## コマンド

| Command | Description |
|---|---|
| `/world list` | ロード済み WorldMasterData 一覧を表示する。 |
| `/world info <worldId>` | WorldMasterData 詳細を表示する。 |
| `/world tp <worldId>` | 対応する Bukkit ロード済みワールドの spawnLocation へ移動する。 |
| `/world loaded` | Bukkit にロード済みのワールド名を表示する。 |
| `/world reload` | MasterData Seeder API で filebase YAML を同期してから WorldMasterData を再取得する。 |

`/world` は `ADMIN(99)` 以上の管理者プレイヤー向けコマンドとする。
