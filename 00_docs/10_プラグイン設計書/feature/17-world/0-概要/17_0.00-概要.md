# World システム概要

World システムは、filebase の `60.features.world` に定義された `WorldMasterData` を AstralRecord API から取得し、Plugin 内でキャッシュする。

## 現在の実装範囲

- `WorldType` と `WorldMasterData` のモデル定義
- API からの `WorldMasterData` 取得
- 管理者向け `/world` コマンド
- `baseWorldPath` に対応する既存ワールドフォルダの起動時 / `/world reload` 時ロード
- `config.yml` の `joinSpawn.world` と `WorldMasterData.spawnLocation` による参加時スポーン
- `allowMobSpawn` によるバニラ自然スポーン抑止

## コマンド

| Command | Description |
|---|---|
| `/world list` | ロード済み `WorldMasterData` 一覧を表示する。 |
| `/world info <worldId>` | `WorldMasterData` 詳細を表示する。 |
| `/world tp <worldId>` | `WorldMasterData.spawnLocation` へ移動する。 |
| `/world loaded` | Bukkit にロード済みのワールド名一覧を表示する。 |
| `/world reload` | MasterData Seeder API で filebase YAML を同期してから `WorldMasterData` を再取得する。 |

`/world` は `ADMIN(99)` 以上のプレイヤー向けコマンドとする。
