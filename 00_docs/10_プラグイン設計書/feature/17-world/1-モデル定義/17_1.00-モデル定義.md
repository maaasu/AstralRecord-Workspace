# 17_1.00-モデル定義

## WorldType

| Value | Description |
|---|---|
| `HUB` | ハブやロビー用途のワールド。 |
| `BASE` | 拠点ワールド。 |
| `OVERWORLD` | 探索向けフィールド。 |
| `DUNGEON` | ダンジョン用ワールド。 |
| `BOSS_FIELD` | ボス戦用ワールド。 |

## WorldMasterData

| Field | Description |
|---|---|
| `id` | ワールド定義 ID |
| `displayName` | 表示名 |
| `worldType` | WorldType |
| `baseWorldPath` | 元ワールドフォルダ |
| `instanceRootPath` | インスタンス生成先ルート |
| `autoLoad` | 起動時 / `/world reload` 時の自動ロード対象 |
| `instanceEnabled` | インスタンス対応フラグ |
| `maxPlayers` | 最大プレイヤー数 |
| `allowBlockBreak` | ブロック破壊許可 |
| `allowBlockPlace` | ブロック設置許可 |
| `allowMobSpawn` | 互換用フィールド。Plugin は管理ワールドでバニラ Mob スポーンを抑止する |
| `spawnLocation` | ワールド固有の既定スポーン地点。`x` `y` `z` `yaw` `pitch` を保持し、参加時スポーンと `/world tp` に使う。 |
| `description` | 説明 |

## config.yml `joinSpawn`

```yaml
joinSpawn:
  world: "world"
```

参加時スポーン先に使う `WorldMasterData` ID のみを保持する。実際の座標は各 `WorldMasterData.spawnLocation` で管理する。
