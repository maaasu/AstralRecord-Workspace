# 17_1.00-モデル定義

## WorldType

| Value | Description |
|---|---|
| `HUB` | ハブ・ロビー用途ワールド。 |
| `BASE` | 拠点ワールド。 |
| `OVERWORLD` | 探索フィールド。 |
| `DUNGEON` | ダンジョン用途ワールド。 |
| `BOSS_FIELD` | ボス戦用途ワールド。 |

## WorldMasterData

| Field | Description |
|---|---|
| `id` | ワールドマスタ ID |
| `displayName` | 表示名 |
| `worldType` | `WorldType` |
| `baseWorldPath` | 元ワールドフォルダ |
| `instanceRootPath` | インスタンス生成先ルート |
| `autoLoad` | 起動時 / `/world reload` 時の自動ロード対象 |
| `instanceEnabled` | インスタンス対応フラグ |
| `maxPlayers` | 最大プレイヤー数 |
| `allowBlockBreak` | ブロック破壊許可 |
| `allowBlockPlace` | ブロック設置許可 |
| `allowMobSpawn` | バニラ Mob スポーン許可の互換用フラグ |
| `showSpawnParticle` | ワールドスポーン地点の常時リングパーティクル表示有無。`false` の場合も `spawnLocation` はテレポート先として利用する。 |
| `spawnLocation` | ワールド既定スポーン地点。`x` `y` `z` `yaw` `pitch` を持ち、参加時スポーンと `/world tp` に利用する。 |
| `description` | 説明 |

## config.yml `joinSpawn`

```yaml
joinSpawn:
  world: "world"
```

参加時スポーン先には `WorldMasterData` ID のみを指定する。実際の座標は対応する `WorldMasterData.spawnLocation` で解決する。
