# World データモデル

## WorldType

| Value | Description |
|---|---|
| `HUB` | ダンジョンやボス挑戦前の待機所、マイスペース。プレイヤー単位またはパーティー単位でインスタンス化予定。 |
| `BASE` | NPC や他プレイヤーと交流する拠点。複製なし。 |
| `OVERWORLD` | 敵が湧く通常探索ワールド。チャンネル単位でインスタンス化予定。 |
| `DUNGEON` | 特定の敵が特定数湧くダンジョン。パーティー単位でインスタンス化予定。 |
| `BOSS_FIELD` | 特定ボスが湧くボス戦フィールド。パーティー単位でインスタンス化予定。 |

## WorldMasterData

| Field | Description |
|---|---|
| `id` | ワールド定義 ID。 |
| `displayName` | 表示名。 |
| `worldType` | WorldType。 |
| `baseWorldPath` | 複製元ワールドのパス。 |
| `instanceRootPath` | インスタンスワールド生成先ルート。 |
| `autoLoad` | 自動ロード対象フラグ。現時点では参照情報であり、登録済み WorldMasterData の `baseWorldPath` は起動時 / `/world reload` 時に Bukkit へロードする。 |
| `instanceEnabled` | インスタンス化対象か。 |
| `maxPlayers` | 最大参加人数。 |
| `allowBlockBreak` | ブロック破壊を許可するか。 |
| `allowBlockPlace` | ブロック設置を許可するか。 |
| `allowMobSpawn` | Mob スポーンを許可するか。 |
| `description` | 説明。 |

## plugin.yml `joinSpawn`

```yaml
joinSpawn:
  world: "world"
  x: 0.5
  y: 64.0
  z: 0.5
  yaw: 0.0
  pitch: 0.0
```

サーバー参加時は `joinSpawn.world` が Bukkit にロードされている場合のみ、指定座標へ移動する。`joinSpawn.world` は WorldMasterData の `id` または Bukkit ロード済みワールド名と一致させる。
