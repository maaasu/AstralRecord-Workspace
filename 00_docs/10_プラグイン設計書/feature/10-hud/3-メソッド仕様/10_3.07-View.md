# 10_3.07-View

## 1. ActionBar描画

クラス名: `PlayerHudView`

### 論理名

ActionBar描画

### 物理名

`renderActionBar(Player player, StatusSnapshot snapshot)`

### 概要

HP/MP/ENG の現在値と最大値を ActionBar へ描画する。

## 2. ドッジ受付ActionBar描画

クラス名: `PlayerHudView`

### 論理名

ドッジ受付ActionBar描画

### 物理名

`renderDodgeWindowActionBar(Player player, double progressRemaining)`

### 概要

しゃがみ開始から `250ms` の間だけ、残り受付時間を表す長尺バー付きの `DODGE` 表示を ActionBar へ描画する。

## 3. 壁張り付きActionBar描画

クラス名: `PlayerHudView`

### 論理名

壁張り付きActionBar描画

### 物理名

`renderWallClingActionBar(Player player, double progressRemaining)`

### 概要

壁張り付き中だけ、自然落下へ戻るまでの残り時間を表す長尺バー付きの `WALL` 表示を ActionBar へ描画する。

## 4. バー描画

クラス名: `PlayerHudView`

### 論理名

バー描画

### 物理名

`renderBars(Player player, StatusSnapshot snapshot)`

### 概要

HP をヘルスバー、EN を満腹度、MP を経験値バーへ反映する。

## 5. Sidebar描画

クラス名: `PlayerHudView`

### 論理名

Sidebar描画

### 物理名

`renderSidebar(Player player, String mode, double tps, int playerLevel, long totalExperience, int classLevel, String className, double classExperienceProgress)`

### 概要

Sidebar 上部にオンライン数などのサーバー情報を表示し、その下にプレイヤー情報とクラス情報を区切り線で分けて表示する。
プレイヤー情報にはプレイヤーレベルとEXPバー、クラス情報にはクラス名、クラスレベル、クラスEXPバーを表示する。
権限レベルは表示しない。クラスEXPバーは `classExperienceProgress` をもとに表示する。

## 6. TabList描画

クラス名: `PlayerHudView`

### 論理名

TabList描画

### 物理名

`renderTabList(Player player, double tps)`

### 概要

TabList のヘッダー/フッターに TPS と Ping を表示する。
