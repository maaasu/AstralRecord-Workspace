# 10_3.07-View

## 1. ActionBar描画

クラス名: `PlayerHudView`

### 論理名

ActionBar描画

### 物理名

`renderActionBar(Player player, StatusSnapshot snapshot)`

### 概要

HP/MP/ENG の現在値と最大値を ActionBar へ描画する。

## 2. バー描画

クラス名: `PlayerHudView`

### 論理名

バー描画

### 物理名

`renderBars(Player player, StatusSnapshot snapshot)`

### 概要

HP をヘルスバー、EN を満腹度、MP を経験値バーへ反映する。

## 3. Sidebar描画

クラス名: `PlayerHudView`

### 論理名

Sidebar描画

### 物理名

`renderSidebar(Player player, String mode, int permission, double tps, int level, long totalExperience)`

### 概要

オンライン数、TPS、Ping、プレイヤーレベル、レベル進行度バー、モードを Sidebar に表示する。
表示言語は日本語で統一し、見た目はおしゃれな区切り線とカラーコードで装飾する。

## 4. TabList描画

クラス名: `PlayerHudView`

### 論理名

TabList描画

### 物理名

`renderTabList(Player player, double tps)`

### 概要

TabList のヘッダー/フッターに TPS と Ping を表示する。
