# 10_3.02-サービス

## 1. HUD更新タスク開始

クラス名: `PlayerHudService`

### 論理名

HUD更新タスク開始

### 物理名

`start(AstralRecord plugin)`

### 概要

HUD更新タスクが未起動の場合のみ、10 tick 間隔で定期更新タスクを起動する。

## 2. HUD更新タスク停止

クラス名: `PlayerHudService`

### 論理名

HUD更新タスク停止

### 物理名

`stop()`

### 概要

起動中タスクを停止し、再起動可能な状態に戻す。

## 3. 全プレイヤーHUD更新

クラス名: `PlayerHudService`

### 論理名

全プレイヤーHUD更新

### 物理名

`updateAll()`

### 概要

オンラインプレイヤーを走査し、`status` から取得したスナップショットを使って `PlayerHudView` の描画メソッドを呼び出す。
`AstPlayer.classId` から `PlayerClassService.getDisplayName()` で職業表示名を取得し、サイドバーに渡す。
壁張り付き終了時刻が未来の場合は壁張り付きバーを優先し、次にドッジ受付終了時刻が未来の場合は通常のリソース表示の代わりにドッジ受付バーを描画する。
ゲーム中 HUD として扱う ActionBar / Sidebar は `AccountMode.PLAYER` のときだけ更新し、`BUILDER` / `ADMIN` では描画しない。

### サイドバー表示項目（score 順）

| score | 表示内容 |
|:--:|:--|
| 8 | 区切り線 |
| 7 | オンライン人数 |
| 6 | TPS |
| 5 | 遅延（ping） |
| 4 | 職業名（`AstPlayer.classId` → `PlayerClassService.getDisplayName()` で解決） |
| 3 | レベル（`AstPlayer.classLevel`） |
| 2 | 経験値進捗バー |
| 1 | 空白 |
| 0 | モード（`AccountMode`） |

## 4. ドッジ受付バー表示開始

クラス名: `PlayerHudService`

### 論理名

ドッジ受付バー表示開始

### 物理名

`showDodgeWindow(AstPlayer astPlayer)`

### 概要

対象プレイヤーの ActionBar を即時にドッジ受付バーへ切り替え、`1 tick` 間隔の短命タスクで残り時間バーを更新する。
対象は `AccountMode.PLAYER` のみとする。

## 5. 壁張り付きバー表示開始

クラス名: `PlayerHudService`

### 論理名

壁張り付きバー表示開始

### 物理名

`showWallClingWindow(AstPlayer astPlayer)`

### 概要

対象プレイヤーの ActionBar を即時に壁張り付きバーへ切り替え、`1 tick` 間隔の短命タスクで残り時間バーを更新する。
対象は `AccountMode.PLAYER` のみとする。

## 6. 通常ActionBar復帰

クラス名: `PlayerHudService`

### 論理名

通常ActionBar復帰

### 物理名

`restoreStatusActionBar(AstPlayer astPlayer)`

### 概要

ドッジ受付バー / 壁張り付きバー更新タスクを停止し、ActionBar を通常の HP/MP/ENG リソース表示へ即時に戻す。
対象が `AccountMode.PLAYER` 以外の場合は通常 ActionBar への復帰描画も行わない。
