# 10_0.00-概要

## 1. 目的

`hud` 機能は、オンライン中プレイヤーの表示情報（ActionBar / Sidebar / TabList / バー表示）を定期更新する。

## 2. コンテキスト

- ステータス値は `status` feature から取得し、HUD は表示責務に限定する。
- 更新トリガーは `service/PlayerHudService` の定期タスクとする。
- 実際の描画処理は `view/PlayerHudView` に集約し、表示ロジックをサービスから分離する。

## 3. 構成要素（実装単位）

- `service/PlayerHudService`
  - プレイヤー走査、ステータス取得、表示更新呼び出しを行う。
- `view/PlayerHudView`
  - ActionBar / Sidebar / TabList / 各種バーへの描画処理を行う。
