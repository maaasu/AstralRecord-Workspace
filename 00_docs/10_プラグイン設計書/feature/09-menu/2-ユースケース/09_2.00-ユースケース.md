# 09_2.00-ユースケース

## 1. メインメニュー表示

対象: プレイヤー

契機: `/menu` コマンド、クラフト成果物スロット、ショートカット `MAIN_MENU`

正常系:

1. [[09_3.07-GUI・View]].メインメニュー表示 が 3 行 GUI を作成する
2. [[09_1.00-モデル定義]].メニューインベントリホルダー に [[09_1.00-モデル定義]].メニュー画面種別 の `MAIN` を設定する
3. メインメニュー項目を描画する
4. プレイヤーへ GUI を開く

## 1.1 ステータス表示

対象: プレイヤー

契機: メインメニューのステータス項目クリック、`/menu status` コマンド

正常系:

1. `AstPlayer` を取得する。未取得なら拒否音で終了する
2. status feature でステータススナップショットを最新化する
3. [[09_3.07-GUI・View]].ステータス表示 で `MenuScreen.STATUS` の GUI を開く
4. back slot 操作でメインメニューへ戻れるようにする

## 2. クラフト欄ショートカット表示

対象: 通常プレイヤー

正常系:

1. プレイヤーセッションキャッシュからプレイヤーセッションを取得する
2. アカウントモードが `PLAYER` でなければ終了する
3. [[09_3.04-リポジトリ]].ショートカット設定取得 で設定を取得する
4. 現在表示中インベントリ種別を inventory feature から取得する
5. クラフト成果物スロットと 2x2 クラフトスロットへショートカットアイコンを描画する

## 3. インベントリ選択

対象: プレイヤー

正常系:

1. インベントリ選択画面を開く
2. 現在表示中の種別をハイライトする
3. プレイヤーが選択した種別を inventory feature へ渡す
4. GUI インベントリを切り替え、クラフト欄ショートカットを再描画する

## 4. 装備 GUI 表示

対象: プレイヤー

正常系:

1. inventory feature からアクセサリスナップショットを取得する
2. [[09_3.07-GUI・View]].装備 GUI 表示 で装備 GUI を開く
3. 実際の装備操作と保存は inventory feature のイベントへ委譲する

## 5. ショートカット設定

対象: プレイヤー

正常系:

1. ショートカットスロット選択画面を開く
2. 設定対象スロットを選ぶ
3. 割当可能な [[09_1.00-モデル定義]].メニューショートカット項目 を選ぶ
4. [[09_3.04-リポジトリ]].ショートカットスロット更新 で account API へ保存する
5. クラフト欄ショートカットを再描画する

## 6. 通貨 GUI 表示

対象: プレイヤー

正常系:

1. currency feature から通貨 ItemStack 一覧を取得する
2. [[09_3.07-GUI・View]].通貨 GUI 表示 でページング GUI を開く
3. 前後ページ、戻る、閉じるのクリックは [[09_3.01-イベント]].通貨 GUI クリック が処理する
