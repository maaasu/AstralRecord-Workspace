# 09_2.00-ユースケース

## 1. メインメニュー表示

対象: プレイヤー

契機: `/menu` コマンド、クラフト成果物スロット、ショートカット `MAIN_MENU`

正常系:

1. `MenuView.open` が 3 行 GUI を作成する
2. `MenuInventoryHolder` に `MenuScreen.MAIN` を設定する
3. メインメニュー項目を描画する
4. プレイヤーへ GUI を開く

## 2. クラフト欄ショートカット表示

対象: 通常プレイヤー

正常系:

1. `AstPlayerCache` からプレイヤーセッションを取得する
2. アカウントモードが `PLAYER` でなければ終了する
3. `MenuShortcutRepository.findByAccountId` で設定を取得する
4. 現在表示中インベントリ種別を inventory feature から取得する
5. クラフト成果物スロットと 2x2 クラフトスロットへショートカットアイコンを描画する

## 3. インベントリ選択

対象: プレイヤー

正常系:

1. インベントリ選択画面を開く
2. 現在表示中の種別をハイライトする
3. プレイヤーが選択した種別を inventory feature へ渡す
4. GUI インベントリを切り替え、クラフト欄ショートカットを再描画する

## 4. 装備 GUI 表示

対象: プレイヤー

正常系:

1. inventory feature からアクセサリスナップショットを取得する
2. `MenuView.openEquipmentGui` で装備 GUI を開く
3. 実際の装備操作と保存は inventory feature のイベントへ委譲する

## 5. ショートカット設定

対象: プレイヤー

正常系:

1. ショートカットスロット選択画面を開く
2. 設定対象スロットを選ぶ
3. 割当可能な [[09_1.00-モデル定義]].メニューショートカット項目 を選ぶ
4. `MenuShortcutRepository.updateSlot` で account API へ保存する
5. クラフト欄ショートカットを再描画する

## 6. 通貨 GUI 表示

対象: プレイヤー

正常系:

1. currency feature から通貨 ItemStack 一覧を取得する
2. `MenuView.openCurrency` でページング GUI を開く
3. 前後ページ、戻る、閉じるをクリックで処理する
