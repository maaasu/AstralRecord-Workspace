# 09_0.00-概要

## 1. 目的

`menu` 機能は、プレイヤーが AstralRecord の主要画面へアクセスするための GUI とショートカットを提供する。

主目的は以下。

- `/menu` コマンドからメインメニューを開く
- プレイヤーインベントリのクラフト欄へメニュー起動・ショートカットを描画する
- インベントリ選択、装備 GUI、通貨 GUI、ショートカット設定画面へ遷移する
- ショートカット設定をアカウントの `menuShortcutsJson` として保存する
- GUI 表示中のホットバーショートカットモードを inventory feature と連携する

## 2. コンテキスト

- 通常プレイヤーモードのプレイヤーだけがクラフト欄ショートカットの対象になる。
- 通貨表示は currency feature、インベントリ切替と装備 GUI 操作は inventory feature へ委譲する。
- ショートカット設定は account API の `menuShortcutsJson` を経由して保存する。
- GUI インベントリの識別には `MenuInventoryHolder` を使用する。

## 3. 構成要素（実装単位）

- `command/MenuCommand`
  - `/menu` コマンドを提供する。
- `event/MenuOpenEventHandler`
  - クラフト欄ショートカット描画、GUI クリック、ドラッグ抑止、参加時再描画を処理する。
- `view/MenuView`, `CraftShortcutView`, `screen/*`
  - GUI 作成、画面描画、slot 判定、通貨ページングを担当する。
- `repository/MenuShortcutRepository`
  - account API を通じてショートカット設定を取得・保存する。
