# 09_0.00-概要

## 1. 目的

`menu` 機能は、プレイヤーが AstralRecord の主要画面へアクセスするための GUI と、
プレイヤーインベントリのクラフト欄に表示する固定ショートカットを提供する。

主な機能:
- `/menu` コマンドからメインメニューを開く
- クラフト欄にメニュー起動と固定4スロットを描画する
- 装備GUI、通貨GUI、ステータス画面、バフ一覧GUI、パーティーGUI、およびゴミ箱GUIへ遷移する
- メインメニューの `帰還` アイコンから、参加時スポーン地点を拠点として 3 秒静止後に帰還する

## 2. 固定クラフト4スロット仕様

クラフト 2x2 スロットはプレイヤー設定を持たず、以下の固定割当とする。
- 左上: ステータスアイコン（メニューオープン時のステータス画面）
- 右上: インベントリ切り替え（クリック毎に `NORMAL -> EQUIPMENT -> RUNE -> NORMAL`）
- 左下: 通貨
- 右下: 装備（Java版/統合版の装備メニュー導線）

補足:
- ショートカット設定画面は廃止する
- `menuShortcutsJson` を用いたショートカット永続設定は使用しない

## 3. 主要コンポーネント

- `command/MenuCommand`
  - `/menu` のエントリポイント
- `event/MenuOpenEventHandler`
  - クラフト欄描画、GUIイベントの振り分け、開閉時再描画、固定4スロット実行
- `service/TrashService`, `feature/sell/service/SellService`
  - ゴミ箱GUI、売却GUIごとの状態管理と click/drag/close 処理
- `inventory` / `currency` / `party` / `shop` / `adventurerecord`
  - menu は導線と戻る遷移だけを担当し、各機能の状態管理・ドメイン処理は参照先 feature を正本とする。
- `view/MenuView`, `CraftShortcutView`, `screen/*`
  - GUI構築、クラフト欄描画、ページング表示

## 追記（2026-06-24）account mode によるメニュー導線制限

- `/menu`、装備 GUI、装備強化 GUI、メニュー内のストレージ・売却などの通常プレイ導線は `AccountMode.PLAYER` のみ処理する。
- `AccountMode.ADMIN` / `AccountMode.BUILDER` のプレイヤーが通常 GUI 内でクリック・ドラッグした場合は event を cancel し、必要に応じて GUI を閉じる。
- `/class gui` のように `user.permission = ADMIN` を要求する確認用コマンドでも、通常プレイ GUI を開く場合は account mode が `PLAYER` であることを別途要求する。
