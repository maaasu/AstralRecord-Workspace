# 09_5.00-例外・ログ・運用

## 1. ログ

| ID | レベル | テンプレート | 用途 |
|---|---|---|---|
| `LogId.E_5600` | ERROR | `メニューイベント処理に失敗しました: %s` | menu / inventory GUI 系イベント処理失敗 |

## 2. プレイヤー表示

menu feature は GUI アイコンとクリック音で状態を返す。

現時点で menu 専用の `PlayerMsgId` は持たない。

| 表現 | 用途 |
|---|---|
| `GuiSound.OPEN` | メニュー・通貨 GUI を開く |
| `GuiSound.SELECT` | 画面遷移、選択、ページ移動成功 |
| `GuiSound.CLOSE` | GUI 閉じる |
| `GuiSound.DENY` | 無効 slot、操作不可、対象セッションなし |
| アイコン glow | 現在選択中のインベントリ種別・ショートカット項目 |

## 3. 例外方針

- Bukkit イベントは `runSafely` で捕捉し、`LogId.E_5600` へ集約する。
- ショートカット設定取得に失敗した場合は default 設定を返し、プレイヤー操作を継続可能にする。
- ショートカット設定保存に失敗しても、ローカル cache は更新後設定へ差し替える。
- GUI クリックで対象 `AstPlayer` が見つからない場合は拒否音で終了する。

## 4. 運用注意

- ショートカット項目を追加する場合は、[[09_1.00-モデル定義]]、[[09_3.01-イベント]]、[[09_3.07-GUI・View]]、account API の `menuShortcutsJson` 互換性を同時確認する。
- GUI slot 配置を変更する場合は、view 側の slot 定数、event 側の rawSlot 判定、inventory feature の装備 GUI 判定を合わせる。
- menu 管理 GUI で実アイテム移動が起きないよう、クリック・ドラッグ抑止を維持する。
