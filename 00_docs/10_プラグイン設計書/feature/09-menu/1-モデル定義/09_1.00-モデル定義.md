# 09_1.00-モデル定義

## 1. メニュー画面種別

物理名: `MenuScreen`

| 物理名 | 論理名 | 用途 |
|---|---|---|
| `MAIN` | メインメニュー | 主要画面への入口 |
| `STATUS` | ステータス | 現在のプレイヤーステータスを表示する |
| `EQUIPMENT_GUI` | 装備 GUI | 装備・アクセサリを編集する |
| `CURRENCY` | 通貨 | 通貨アイテムをページング表示する |
| `SHORTCUT_SLOT_SELECTOR` | ショートカットスロット選択 | 2x2 クラフトスロットの設定対象を選ぶ |
| `SHORTCUT_ACTION_SELECTOR` | ショートカット項目選択 | 選択スロットへ割り当てる action を選ぶ |

## 2. メニューショートカット項目

物理名: `MenuShortcutAction`

| 物理名 | 表示名 | 対象 |
|---|---|---|
| `NONE` | 未設定 | 設定画面を開く |
| `MAIN_MENU` | メニュー | メインメニューを開く |
| `INVENTORY_NORMAL` | ノーマル | [[08_1.00-モデル定義]].インベントリ種別 `NORMAL` |
| `INVENTORY_CURRENCY` | 通貨 | 通貨 GUI |
| `INVENTORY_EQUIPMENT` | 装備 | [[08_1.00-モデル定義]].インベントリ種別 `EQUIPMENT` |
| `INVENTORY_RUNE` | ルーン | [[08_1.00-モデル定義]].インベントリ種別 `RUNE` |

### 2.1 初期割り当て

| slotIndex | 初期項目 |
|---:|---|
| 0 | `INVENTORY_NORMAL` |
| 1 | `INVENTORY_EQUIPMENT` |
| 2 | `INVENTORY_RUNE` |
| 3 | `INVENTORY_CURRENCY` |

## 3. メニューショートカット設定

物理名: `MenuShortcutSettings`

| 項目 | 説明 |
|---|---|
| `SLOT_COUNT` | `4`。2x2 クラフトスロット数 |
| `actions` | slotIndex 0〜3 の [[09_1.00-モデル定義]].メニューショートカット項目配列 |

## 4. メニューインベントリホルダー

物理名: `MenuInventoryHolder`

| 項目 | 説明 |
|---|---|
| `screen` | [[09_1.00-モデル定義]].メニュー画面種別 |
| `shortcutSlotIndex` | ショートカット設定対象スロット。対象外は `-1` |
| `pageIndex` | 通貨 GUI のページ番号 |

## 5. 関連 feature とのモデル関係

- `inventory`: 表示インベントリ切替、装備 GUI、ホットバーショートカットモードで連携する。
- `account`: `menuShortcutsJson` を保存先として使う。
- `currency`: 通貨 GUI の表示アイテム一覧を取得する。

## 追記（2026-06-01 プレイヤー一覧・パーティーGUI）

### MenuScreen 追加
- `PLAYER_LIST`: サーバー参加中プレイヤーの一覧を表示する共通 GUI。
- `PLAYER_DETAIL`: 1 人のプレイヤー詳細情報を表示する GUI。
- `PARTY_MEMBER_ACTION`: パーティーリーダーが対象メンバーに対して昇格・キックを選択する GUI。

### PlayerListGui 共通パラメータ
- `purpose`: 一覧の用途。プレイヤー情報参照またはパーティー招待に使用する。
- `pageIndex`: ページ番号。54 スロット GUI の 0-44 を一覧領域として使用する。
- `filter`: 表示対象条件。用途に応じて「全オンライン」または「パーティー未所属」を適用する。
- `backTarget`: 戻り先 GUI。メインメニューまたはパーティー GUI に戻す。

### パーティー GUI 配置
- リーダー: 上段中央 `slot 13`
- 招待ボタン: `slot 15`
- メンバー: 下段中央から `slot 31, 30, 32, 29, 33`
- 戻る: `slot 49`
- 離脱/解散: `slot 51`

### PlayerDetailGui 表示項目
- プレイヤー名、UUID、現在選択中アカウント名
- レベル、累計経験値、所持金
- HP / MP / EN の現在値と最大値
- ATTACK / MELEE_ATTACK / RANGED_ATTACK / MAGIC_ATTACK / DEFENSE / MAGIC_DEFENSE

## 追記（2026-06-02 売却GUI）

### MenuScreen 追加
- `SELL`: アイテム売却用 GUI。45 スロット内容領域に売却対象アイテムを移動できる。メインメニュー導線は持たない。
- `SELL_CONFIRM`: 売却確認 GUI。アイテム移動不可、確定で売却額をゴールドとして受け取る。

## 追記（2026-06-02 ストレージGUI）

### MenuScreen 追加
- `STORAGE`: アイテム収納用 GUI。45 スロット内容領域にストレージ内アイテムを表示し、カテゴリ・レア度フィルタと並び順変更を行う。
