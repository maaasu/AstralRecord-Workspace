# 09_4.00-統合フロー

## 1. `/menu` 表示フロー（command -> view）

1. `MenuCommand.executePlayerCommand` が `MenuView.open` を呼び出す
2. `MenuView` が `MenuScreen.MAIN` の inventory を生成する
3. `MainMenuScreenView` がメイン項目を配置する
4. プレイヤーへ GUI を開く

## 2. クラフト欄ショートカットフロー（event -> repository -> view）

1. join / open / craft prepare / close で `scheduleCraftShortcutRender` が呼ばれる
2. 次 tick に `renderCraftShortcuts` が実行される
3. `MenuShortcutRepository.findByAccountId` が設定を取得する
4. inventory feature から現在表示中インベントリ種別を取得する
5. `MenuView.renderCraftShortcuts` が成果物スロットと 2x2 スロットへアイコンを描画する

## 3. インベントリ選択フロー（menu -> inventory）

1. メインメニューのインベントリ選択 slot をクリックする
2. `MenuView.openInventorySelector` が選択画面を開く
3. 任意のインベントリ種別をクリックする
4. `MenuOpenEventHandler.applyInventoryShortcut` が inventory feature へ表示切替を委譲する
5. クラフト欄ショートカットを再描画する

## 4. 装備 GUI フロー（menu -> inventory）

1. メインメニューの装備 slot をクリックする
2. inventory feature からアクセサリスナップショットを取得する
3. `MenuView.openEquipmentGui` が装備 GUI を開く
4. 以降の装備配置・保存は inventory feature の `InventoryEquipmentGuiEventHandler` が処理する

## 5. ショートカット設定フロー（menu -> repository -> account API）

1. メインメニューのショートカット設定 slot をクリックする
2. 設定対象 slot を選ぶ
3. 割当 action を選ぶ
4. `MenuShortcutRepository.updateSlot` が account API へ `menuShortcutsJson` を保存する
5. クラフト欄ショートカットを再描画し、設定対象選択画面へ戻る
