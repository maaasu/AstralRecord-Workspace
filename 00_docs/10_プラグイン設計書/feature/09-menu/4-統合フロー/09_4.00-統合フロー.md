# 09_4.00-統合フロー

## 1. `/menu` 表示フロー（command -> view）

1. [[09_3.03-コマンド]].メニュー表示実行 が [[09_3.07-GUI・View]].メインメニュー表示 を呼び出す
2. [[09_3.07-GUI・View]].メインメニュー表示 が [[09_1.00-モデル定義]].メニュー画面種別 `MAIN` の inventory を生成する
3. メインメニュー画面ビューがメイン項目を配置する
4. プレイヤーへ GUI を開く

## 1.1 ステータス表示フロー（main menu / command -> status -> view）

1. メインメニューのステータス項目クリック、または [[09_3.03-コマンド]].ステータスサブコマンド実行 が起点になる
2. `AstPlayerCache` から `AstPlayer` を取得し、未取得時は拒否音で終了する
3. status feature の `StatusService.refreshStatus` でスナップショットを再計算する
4. [[09_3.07-GUI・View]].ステータス表示 が `MenuScreen.STATUS` の GUI を生成して開く
5. back slot 操作でメインメニューへ戻る

## 2. クラフト欄ショートカットフロー（event -> repository -> view）

1. join / open / craft prepare / close で [[09_3.01-イベント]].クラフトショートカット再描画予約 が呼ばれる
2. 次 tick に [[09_3.01-イベント]].クラフトショートカット描画 が実行される
3. [[09_3.04-リポジトリ]].ショートカット設定取得 が設定を取得する
4. inventory feature から現在表示中インベントリ種別を取得する
5. [[09_3.07-GUI・View]].クラフトショートカット描画 が成果物スロットと 2x2 スロットへアイコンを描画する

## 3. インベントリ選択フロー（menu -> inventory）

1. メインメニューのインベントリ選択 slot をクリックする
2. [[09_3.07-GUI・View]].インベントリ選択表示 が選択画面を開く
3. 任意のインベントリ種別をクリックする
4. [[09_3.01-イベント]].ショートカット項目実行 が inventory feature へ表示切替を委譲する
5. クラフト欄ショートカットを再描画する

## 4. 装備 GUI フロー（menu -> inventory）

1. メインメニューの装備 slot をクリックする
2. inventory feature からアクセサリスナップショットを取得する
3. [[09_3.07-GUI・View]].装備 GUI 表示 が装備 GUI を開く
4. 以降の装備配置・保存は inventory feature の装備 GUI イベントハンドラが処理する

## 4.1 通貨 GUI ページングフロー（event -> view）

1. 通貨 GUI で前後ページ・戻る・閉じる slot をクリックする
2. [[09_3.01-イベント]].通貨 GUI クリック がクリック種別を判定する
3. ページ送りの場合、`MenuInventoryHolder.pageIndex` を元に `±1` した番号で [[09_3.07-GUI・View]].通貨 GUI 表示 を再呼び出しする
4. 戻る・閉じるはメインメニューへ戻る／GUI を閉じる

## 5. ショートカット設定フロー（menu -> repository -> account API）

1. メインメニューのショートカット設定 slot をクリックする
2. 設定対象 slot を選ぶ
3. 割当 action を選ぶ
4. [[09_3.04-リポジトリ]].ショートカットスロット更新 が account API へ `menuShortcutsJson` を保存する
5. クラフト欄ショートカットを再描画し、設定対象選択画面へ戻る

## 追記（ゴミ箱GUIフロー）
1. インベントリ種別選択画面でゴミ箱アイコンを押下するとゴミ箱GUIを開く。
2. プレイヤーインベントリ側のアイテムを左クリックで1個、Shift+左クリックですべて、右クリックで半分の個数をゴミ箱GUIへ移動する。プレイヤー側のアイテムはその分だけ減る。
3. ゴミ箱GUI側のアイテムを左クリックで1個、Shift+左クリックですべて、右クリックで半分の個数をプレイヤーインベントリへ戻す。
4. ゴミ箱GUIで戻るを押した場合は廃棄せず種別選択へ戻り、ゴミ箱の内容は保持する（再度開いた際に復元される）。
5. ゴミ箱GUIを閉じた場合（ESC/X など）はゴミ箱内のアイテムをすべてプレイヤーインベントリへ戻し、保持データを破棄する。
6. ゴミ箱GUIで廃棄ボタン（旧 閉じる slot）を押下した場合はゴミ箱確認GUIを表示する。
7. ゴミ箱確認GUIで廃棄アイコン押下、またはGUIを閉じた場合は廃棄確定。
8. ゴミ箱確認GUIで「ゴミ箱GUIに戻る」押下時は廃棄せずゴミ箱GUIへ戻る。

## 追記（2026-05-27）trash起点フロー

1. TrashCommand.executePlayerCommand が MenuView.openTrash を呼び出す。
2. MenuOpenEventHandler.handleMainMenuClick でメインメニューのゴミ箱アイコン押下時に openTrash を呼び出す。
3. MenuOpenEventHandler.handleInventorySelectorClick でインベントリ種別選択画面のゴミ箱アイコン押下時に openTrash を呼び出す。
