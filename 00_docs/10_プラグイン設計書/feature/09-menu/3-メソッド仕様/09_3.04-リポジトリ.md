# 09_3.04-リポジトリ

## 1. ショートカット設定取得

クラス名: `MenuShortcutRepository`
物理名: `findByAccountId`

責務:

accountId に紐づくショートカット設定を取得する。

処理内容:

1. accountId のキャッシュを確認する
2. 未キャッシュの場合は [[09_3.04-リポジトリ]].ショートカット設定 API 取得 を呼び出す
3. 取得結果をキャッシュへ保存して返す

## 2. ショートカット設定 API 取得

クラス名: `MenuShortcutRepository`
物理名: `fetchByAccountId`

責務:

account API から `menuShortcutsJson` を取得し、設定モデルへ変換する。

処理内容:

1. `GET /api/account/{accountId}` を送信する
2. `200` の場合はレスポンス JSON の `menuShortcutsJson` を読む
3. JSON が未設定またはパース不可の場合は `MenuShortcutSettings.defaults()` を返す
4. `404` または取得失敗時も default を返す

## 3. ショートカットスロット更新

クラス名: `MenuShortcutRepository`
物理名: `updateSlot`

責務:

指定スロットのショートカット項目を更新し、account API へ保存する。

処理内容:

1. 現在設定を `findByAccountId` で取得する
2. `MenuShortcutSettings.withAction` で指定 slot のみ更新する
3. `menuShortcutsJson` を生成する
4. `PUT /api/account/{accountId}` へ JSON body を送信する
5. API 成功時・失敗時にかかわらず、ローカル cache は更新後設定へ差し替える
