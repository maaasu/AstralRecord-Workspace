# 09_3.04-リポジトリ

## 1. ショートカット設定取得（廃止済み互換）

クラス名: `MenuShortcutRepository`
物理名: `findByAccountId`

責務:

旧ショートカット永続設定向けの互換仕様。現行の固定 4 スロット仕様では repository を使わず、[[09_1.00-モデル定義]].固定メニューショートカット設定 の `defaults()` を使用する。

処理内容:

1. 新規実装では呼び出さない
2. 互換呼び出しが残る場合は `MenuShortcutSettings.defaults()` を返す

## 2. ショートカット設定 API 取得（廃止済み）

クラス名: `MenuShortcutRepository`
物理名: `fetchByAccountId`

責務:

旧 account API の `menuShortcutsJson` 取得仕様。現行仕様では使用しない。

処理内容:

1. 新規実装では `GET /api/account/{accountId}` によるショートカット設定取得を行わない
2. 互換呼び出しが残る場合は API レスポンスを読まず `MenuShortcutSettings.defaults()` を返す

## 3. ショートカットスロット更新（廃止済み）

クラス名: `MenuShortcutRepository`
物理名: `updateSlot`

責務:

旧プレイヤー別ショートカット設定の保存仕様。現行仕様では固定割当のため更新しない。

処理内容:

1. 新規実装では呼び出さない
2. account API へ `menuShortcutsJson` を保存しない
3. 固定割当の変更が必要な場合は [[09_1.00-モデル定義]].固定メニューショートカット設定 と実装の `MenuShortcutAction.defaultForSlot` を同時に更新する
