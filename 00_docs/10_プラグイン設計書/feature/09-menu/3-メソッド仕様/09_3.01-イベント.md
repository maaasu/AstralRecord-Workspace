# 09_3.01-イベント

## 1. クラフト準備ショートカット描画

イベント物理名: `PrepareItemCraftEvent`
クラス名: `MenuOpenEventHandler`
物理名: `onPrepareItemCraft`

責務:

プレイヤーインベントリのクラフト欄へメニューショートカットを描画する。

処理内容:

1. 対象 inventory がプレイヤークラフトインベントリでなければ終了する
2. view player が Player でなければ終了する
3. 対象プレイヤーが描画抑止中なら終了する
4. [[09_3.01-イベント]].クラフトショートカット再描画予約 を呼び出す
5. 例外時は `LogId.E_5600` を記録する

## 2. インベントリオープン

イベント物理名: `InventoryOpenEvent`
クラス名: `MenuOpenEventHandler`
物理名: `onInventoryOpen`

責務:

インベントリを開いた直後にクラフト欄ショートカットを再描画し、必要ならホットバーショートカットモードを有効化する。

処理内容:

1. event player が Player の場合、クラフトショートカット再描画を予約する
2. 開いた inventory が menu 管理 GUI または crafting view の場合、inventory feature の hotbar shortcut mode を有効化する

## 3. インベントリクリック

イベント物理名: `InventoryClickEvent`
クラス名: `MenuOpenEventHandler`
物理名: `onInventoryClick`

責務:

menu 管理 GUI、クラフト欄ショートカット、ホットバーショートカットのクリックを処理する。

処理内容:

1. top inventory が menu 管理 GUI の場合、ホットバーショートカットまたは menu 画面クリックへ委譲する
2. 装備 GUI の場合、装備操作は inventory feature 側へ委譲する
3. 通常プレイヤーモードでなければ終了する
4. クラフト欄への NUMBER_KEY / SWAP_OFFHAND は拒否する
5. クラフト成果物スロットならメインメニューを開く
6. 2x2 クラフトスロットなら対応ショートカット項目を実行する

## 4. ショートカット項目実行

クラス名: `MenuOpenEventHandler`
物理名: `executeShortcutAction`

責務:

[[09_1.00-モデル定義]].メニューショートカット項目 に対応する画面遷移またはインベントリ切替を実行する。

処理内容:

1. `NONE` はショートカット設定画面を開く
2. `MAIN_MENU` はメインメニューを開く
3. 通貨 action は通貨 GUI を開く
4. inventoryType を持つ action は inventory feature の表示切替へ委譲する
5. 未対応 action は拒否音を再生する

## 5. クラフトショートカット描画

クラス名: `MenuOpenEventHandler`
物理名: `renderCraftShortcuts`

責務:

現在の設定と表示インベントリ種別をもとにクラフト欄ショートカットを描画する。

処理内容:

1. 描画抑止中なら終了する
2. `AstPlayerCache` からセッションを取得し、アカウントモードが `PLAYER` でなければ終了する
3. accountId のショートカット設定を repository から取得する
4. inventory feature から現在表示中インベントリ種別を取得する
5. `MenuView.renderCraftShortcuts` を呼び出す
