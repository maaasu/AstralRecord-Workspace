# 09_3.01-イベント

## 1. クラフト準備ショートカット描画

イベント物理名: `PrepareItemCraftEvent`
クラス名: `MenuOpenEventHandler`
物理名: `onPrepareItemCraft`

責務:

プレイヤーインベントリのクラフト欄へメニューショートカットを描画する。

処理内容:

1. 対象 inventory がプレイヤークラフトインベントリでなければ終了する
2. view player が Player でなければ終了する
3. 対象プレイヤーが描画抑止中なら終了する
4. [[09_3.01-イベント]].クラフトショートカット再描画予約 を呼び出す
5. 例外時は runSafely で以下ログを記録する

    | 項目 | 内容 |
    |---|---|
    | ID | LogId.E_5700 |
    | レベル | ERROR |
    | テンプレート | メニュー系イベント処理に失敗しました: %s |
    | 出力条件 | runSafely で例外発生時 |
    | 引数 | プレイヤー名 |

## 2. インベントリオープン

イベント物理名: `InventoryOpenEvent`
クラス名: `MenuOpenEventHandler`
物理名: `onInventoryOpen`

責務:

インベントリを開いた直後にクラフト欄ショートカットを再描画し、必要ならホットバーショートカットモードを有効化する。

処理内容:

1. event player が Player の場合、クラフトショートカット再描画を予約する
2. 開いた inventory が menu 管理 GUI または crafting view の場合、inventory feature の hotbar shortcut mode を有効化する

## 3. インベントリクリック

イベント物理名: `InventoryClickEvent`
クラス名: `MenuOpenEventHandler`
物理名: `onInventoryClick`

責務:

menu 管理 GUI、クラフト欄ショートカット、メニュー表示中ホットバーショートカットのクリックを処理する。

処理内容:

1. クリック実行プレイヤーから `AstPlayerCache` 経由で `AstPlayer` を取得する。未取得の場合は `GuiSound.DENY` を再生して終了する
2. top inventory が menu 管理 GUI の場合、まず [[09_3.01-イベント]].メニュー表示中ホットバーショートカットクリック へ `AstPlayer` を渡して委譲する。処理済みなら終了する
3. menu 画面が `EQUIPMENT_GUI` の場合、装備操作は inventory feature 側へ委譲して終了する
4. menu 管理 GUI 内のその他クリックは menu 画面遷移処理へ `AstPlayer` を渡して委譲する
5. アカウントモードが `PLAYER` でなければ終了する
6. クラフト欄への NUMBER_KEY / SWAP_OFFHAND は拒否音で終了する
7. ビュー種別が CRAFTING でなければ終了する
8. クラフト成果物スロットならメインメニューを開く
9. 2x2 クラフトスロットなら対応ショートカット項目を実行する

備考:

- `AstPlayer` 取得は本メソッド先頭で一度だけ行い、以降の画面別ハンドラ・ショートカット実行・通貨 GUI クリック処理には引数で渡す。各ハンドラ内で再取得しない。

## 4. ショートカット項目実行

クラス名: `MenuOpenEventHandler`
物理名: `executeShortcutAction`

責務:

[[09_1.00-モデル定義]].メニューショートカット項目 に対応する画面遷移またはインベントリ切替を実行する。

処理内容:

1. `NONE` はショートカット設定画面を開く
2. `MAIN_MENU` はメインメニューを開く
3. 通貨 action は通貨 GUI を開く
4. inventoryType を持つ action は inventory feature の表示切替へ委譲する
5. 未対応 action は拒否音を再生する

## 5. クラフトショートカット再描画予約

クラス名: `MenuOpenEventHandler`
物理名: `scheduleCraftShortcutRender`

責務:

クラフト欄ショートカットの描画を次 tick へ予約する。

処理内容:

1. 対象プレイヤーが描画抑止中なら終了する
2. 次 tick に [[09_3.01-イベント]].クラフトショートカット描画 を実行するよう Bukkit scheduler へ予約する

## 6. プレイヤー参加

イベント物理名: `PlayerJoinEvent`
クラス名: `MenuOpenEventHandler`
物理名: `onPlayerJoin`

責務:

プレイヤー参加直後にクラフト欄ショートカットを描画する。

処理内容:

1. 2 tick 後に [[09_3.01-イベント]].クラフトショートカット再描画予約 を実行するよう Bukkit scheduler へ予約する
2. 例外時は runSafely で [[09_5.00-例外・ログ・運用]] のメニュー系イベント失敗ログを記録する

## 7. インベントリクローズ

イベント物理名: `InventoryCloseEvent`
クラス名: `MenuOpenEventHandler`
物理名: `onInventoryClose`

責務:

GUI を閉じた直後にクラフト欄ショートカットを再描画し、ホットバーショートカットモードを解除する。

処理内容:

1. 閉じた inventory がクラフトインベントリの場合、クラフト欄ショートカット表示を消去する
2. event player が Player の場合、`AstPlayer` を取得し inventory feature の hotbar shortcut mode を無効化する
3. クラフトショートカット再描画を予約する
4. 例外時は runSafely で [[09_5.00-例外・ログ・運用]] のメニュー系イベント失敗ログを記録する

## 8. インベントリドラッグ抑止

イベント物理名: `InventoryDragEvent`
クラス名: `MenuOpenEventHandler`
物理名: `onInventoryDrag`

責務:

menu 管理 GUI とクラフト欄ショートカット領域へのドラッグ操作を抑止する。

処理内容:

1. top inventory が menu 管理 GUI の場合、event をキャンセルし、操作プレイヤーへ拒否音を再生して終了する
2. 通常プレイヤーモードでなければ終了する
3. ドラッグ対象 raw slot にクラフト枠（成果物・2x2 ショートカット枠）が含まれる場合、クラフトショートカット再描画を予約する
4. 例外時は runSafely で [[09_5.00-例外・ログ・運用]] のメニュー系イベント失敗ログを記録する

## 9. メニュー表示中ホットバーショートカットクリック

クラス名: `MenuOpenEventHandler`
物理名: `handleMenuHotbarShortcutClick`

責務:

menu 管理 GUI を開いている間にプレイヤーがホットバー領域（slot 0〜8）をクリックした場合、inventory feature の hotbar shortcut click 処理へ委譲する。

処理内容:

1. クリック対象が `PlayerInventory` のホットバー領域（slot 0〜8）でなければ未処理を返す
2. `AstPlayer` を取得する。未取得、または hotbar shortcut mode が無効なら未処理を返す
3. event をキャンセルする
4. `InventoryService.handleHotbarShortcutClick` へ委譲する
5. 委譲結果が `true` の場合、slot 8 は `GuiSound.CLOSE`、それ以外は `GuiSound.SELECT` を再生する
6. 委譲結果が `false` の場合は `GuiSound.DENY` を再生する
7. 委譲した場合は処理済みを返す

備考:

- menu を開いていない状態のホットバーショートカットクリックは inventory feature 側で処理する。menu 側はメニュー表示中のみの分岐ルーティングに責務を限定する。

## 10. 通貨 GUI クリック

クラス名: `MenuOpenEventHandler`
物理名: `handleCurrencyClick`

責務:

通貨 GUI 上の前後ページ・戻る・閉じるクリックを処理する。

処理内容:

1. クリック raw slot が「閉じる」スロットの場合、`GuiSound.CLOSE` を再生し inventory を閉じて終了する
2. クリック raw slot が「戻る」スロットの場合、`GuiSound.SELECT` を再生しメインメニューを開いて終了する
3. 現在 inventory の `MenuInventoryHolder.pageIndex` と currency feature から取得した ItemStack 一覧を参照する
4. クリック raw slot が「前ページ」かつ前ページが存在するなら `GuiSound.SELECT` を再生し `MenuView.openCurrency(player, items, pageIndex - 1)` を呼ぶ
5. クリック raw slot が「次ページ」かつ次ページが存在するなら `GuiSound.SELECT` を再生し `MenuView.openCurrency(player, items, pageIndex + 1)` を呼ぶ
6. 上記いずれにも該当しない場合は `GuiSound.DENY` を再生する

備考:

- ページ番号の保持と再描画は `MenuInventoryHolder` と `MenuView.openCurrency` の責務とする。event handler はクリック種別を判定して再描画を依頼することに責務を限定する。

## 11. クラフトショートカット描画

クラス名: `MenuOpenEventHandler`
物理名: `renderCraftShortcuts`

責務:

現在の設定と表示インベントリ種別をもとにクラフト欄ショートカットを描画する。

処理内容:

1. 描画抑止フラグが立っているなら終了する
2. `AstPlayerCache` からセッションを取得し、アカウントモードが `PLAYER` でなければ終了する
3. 自プレイヤーの描画抑止フラグを一時的に立ててから以降の処理を実行し、`finally` で解除する
4. accountId のショートカット設定を repository から取得する
5. inventory feature から現在表示中インベントリ種別を取得する（アカウントモードが GUI 反映対象外の場合は `null` を渡す）
6. `MenuView.renderCraftShortcuts` を呼び出す

備考:

- 描画抑止フラグは `MenuOpenEventHandler` 内の `craftRenderSuppressed`（プレイヤー UUID 集合）で管理する。メインメニュー／通貨 GUI／インベントリ切替の遷移中は明示的に抑止し、遷移完了後に解除する。
- クラフト欄ショートカットはアイコン表示のみで、実際のクラフト処理は行わない。

## 追記（ゴミ箱GUIイベント）
### ゴミ箱GUIクリック
クラス名: MenuOpenEventHandler
物理名: handleTrashClick
- ゴミ箱GUIでは通常スロット（0-44）へのアイテム移動を許可する。
- 下段制御スロット（前ページ/ガイド/戻る/廃棄/次ページ）は移動不可。
- 戻る押下時は確認画面を出さず、メインメニューへ戻る（廃棄しない、ゴミ箱内容は dict に保持して次回開いた際に復元する）。
- ゴミ箱GUI下でホットバーショートカット（slot 0〜8）をクリックした場合は、通常の menu 管理 GUI と同じく `handleMenuHotbarShortcutClick` へ委譲する。
- 廃棄ボタン（slot 51）押下時は廃棄確認GUIを表示する。
- プレイヤーインベントリ側のアイテムクリックは、`ClickType` に応じて転送個数を決定する。
  - `LEFT`: 1 個をゴミ箱へ送る。
  - `SHIFT_LEFT`: 対象スタックすべてをゴミ箱へ送る。
  - `RIGHT`: 対象スタックの半分（端数切り上げ）をゴミ箱へ送る。
  - 装備・ルーンなどインスタンス系アイテムはクリック種別に関わらず常に 1 インスタンス全量を送る。
  - ゴミ箱側にスタッキング余地がある同一アイテムスロットへ優先的にマージし、無ければ最初の空スロットへ配置する。容量不足の場合は配置可能分のみ取り出す。
  - 受け側容量が 0 ならば取り出さず拒否音を再生する。
- ゴミ箱GUI内コンテンツスロットのクリックは、対象スロットの ItemStack 量に対し同じ `ClickType` ルール（LEFT=1 / SHIFT_LEFT=全量 / RIGHT=半分切り上げ）で個数を決定し、`InventoryService.returnItemToOwnedInventory` でプレイヤーインベントリへ返却する。残量がある場合は同スロットに残し、0 になったら AIR に設定する。
- カーソルにアイテムを持った状態でゴミ箱コンテンツスロットをクリックした場合は拒否音を再生して無視する。

### ゴミ箱確認GUIクリック
クラス名: MenuOpenEventHandler
物理名: handleTrashConfirmClick
- アイテム移動は常に不可。
- 廃棄アイコン押下で保持中アイテムを破棄する。
- ゴミ箱GUIに戻るアイコン押下で廃棄せず戻る。

### ゴミ箱系GUIクローズ
クラス名: MenuOpenEventHandler
物理名: handleTrashClose
- ゴミ箱GUIを閉じた場合（ESC / X など、戻る／廃棄ボタン以外の経路）はゴミ箱内のアイテムを全件 `InventoryService.returnItemToOwnedInventory` でプレイヤーインベントリへ戻し、保持データ（`trashItemsByPlayer`）をクリアする。
- ゴミ箱GUIを「戻る」ボタン経由で閉じた場合は、現在ページのアイテムスナップショットを `trashItemsByPlayer` に保存し、メインメニューへ遷移する。
- ゴミ箱GUIを「廃棄」ボタン経由で閉じた場合は、廃棄確認GUI への遷移として扱い、`suppressTrashConfirmOnClose` で返却処理を抑止する。
- ゴミ箱確認GUIを閉じた場合は廃棄アイコン押下と同等の破棄処理を行う。
- ページ跨ぎでアイテムが存在する状態で閉じた場合は、現在ページのスナップショットに加えて `trashItemsByPlayer` の他ページ分も合わせて返却対象に含める。
