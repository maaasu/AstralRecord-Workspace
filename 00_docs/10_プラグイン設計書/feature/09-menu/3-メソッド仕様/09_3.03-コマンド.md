# 09_3.03-コマンド

## 1. メニュー表示実行

クラス名: `MenuCommand`
物理名: `executePlayerCommand`

責務:

`/menu` および各サブコマンドを処理する。

処理内容:

1. `AstralRecord.getInstance().getMenuView()` を取得する
2. 引数が空の場合は `MenuView.open(player.getBukkit())` を呼び出してメインメニューを開く
3. 引数の第 1 要素が `status` の場合は [[09_3.03-コマンド]].ステータスサブコマンド を呼び出す
4. 未対応サブコマンドの場合は使用方法を表示する

## 2. ステータスサブコマンド

クラス名: `MenuCommand`
物理名: `executeStatusSubCommand`

責務:

`/menu status` でメニューのステータス画面を直接開く。

処理内容:

1. `StatusService.refreshStatus` でステータススナップショットを再計算する
2. `MenuView.openStatus(player.getBukkit(), player, snapshot)` を呼び出す

## 3. コマンド仕様

- ルート: `/menu`
- サブコマンド:
  - `status`: メニューのステータス画面を開く
- コンソール実行: 不可（`isPlayerOnly = true`）
- 権限値（`permission`）による個別制限は行わず、`AstCommand` 基底側の制御に委ねる

## 追記（2026-05-27）trash コマンド

### trash表示実行
クラス名: TrashCommand
物理名: executePlayerCommand

処理内容:
1. AstralRecord.getInstance().getTrashService() で TrashService を取得する。
2. TrashService.open(player.getBukkit()) を呼び、ゴミ箱GUIを1ページ目で開く。

### コマンド仕様追記
- ルート: /trash
- 引数: なし
- コンソール実行: 不可（isPlayerOnly = true）

## 追記（2026-06-02）sell コマンド

### sell表示実行
クラス名: SellCommand
物理名: executePlayerCommand

処理内容:
1. AstralRecord.getInstance().getMenuView() で MenuView を取得する。
2. MenuView.openSell(player.getBukkit(), List.of(), 0) を呼び、売却GUIを1ページ目で開く。

### コマンド仕様追記
- ルート: /sell
- 引数: なし
- コンソール実行: 不可（isPlayerOnly = true）
- permission: ADMIN 以上
- メニューには追加しない。通常プレイヤー導線は NPC 経由を想定する。
