# 09_3.03-コマンド

## 1. メニュー表示実行

クラス名: `MenuCommand`
物理名: `executePlayerCommand`

責務:

`/menu` でメインメニューを開く。

処理内容:

1. `AstralRecord.getInstance().getMenuView()` を取得する
2. `MenuView.open(player.getBukkit())` を呼び出す

## 2. コマンド仕様

- ルート: `/menu`
- サブコマンド: なし
- コンソール実行: 不可（`isPlayerOnly = true`）
- 権限値（`permission`）による個別制限は行わず、`AstCommand` 基底側の制御に委ねる
