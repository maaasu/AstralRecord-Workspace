# 09_3.07-GUI・View

## 1. メインメニュー表示

クラス名: `MenuView`
物理名: `open`

責務:

メインメニュー GUI を生成してプレイヤーへ開く。

処理内容:

1. `MenuInventoryHolder` に `MenuScreen.MAIN` を設定した inventory を作成する
2. `MainMenuScreenView.render` で画面を描画する
3. `player.openInventory` を呼び出す

## 2. ステータス表示

クラス名: `MenuView`
物理名: `openStatus`

責務:

現在の [[07_1.00-モデル定義]].ステータススナップショット を GUI で表示する。

処理内容:

1. `MenuScreen.STATUS` の inventory を作成する
2. `StatusScreenView.render` で現在 HP / MP / EN とカテゴリ別ステータスを描画する
3. back slot からメインメニューへ戻れるようにする

## 3. インベントリ選択表示

クラス名: `MenuView`
物理名: `openInventorySelector`

責務:

切替可能なインベントリ種別を選ぶ GUI を表示する。

処理内容:

1. `MenuScreen.INVENTORY_SELECTOR` の inventory を作成する
2. `InventorySelectorScreenView.render` へ現在選択中種別を渡す
3. 選択中の種別には glow を付与する

## 4. 装備 GUI 表示

クラス名: `MenuView`
物理名: `openEquipmentGui`

責務:

装備・アクセサリ編集用 GUI を表示する。

処理内容:

1. `MenuScreen.EQUIPMENT_GUI` の inventory を作成する
2. 頭・胴・脚・足・アクセサリ 1〜7 の slot に装備 ItemStack または placeholder を描画する
3. close / back slot を配置する
4. クリック時の保存・検証は inventory feature のイベントへ委譲する

## 5. 通貨 GUI 表示

クラス名: `MenuView`
物理名: `openCurrency`

責務:

通貨 ItemStack 一覧をページング GUI として表示する。

処理内容:

1. `MenuScreen.CURRENCY` の inventory を作成する
2. pageIndex に対応するアイテム範囲を描画する
3. 前ページ、次ページ、戻る、閉じるボタンを配置する

## 6. ショートカットスロット選択画面表示

クラス名: `MenuView`
物理名: `openShortcutSlotSelector`

責務:

ショートカット設定対象の 2x2 クラフトスロットを選ぶ GUI を表示する。

処理内容:

1. `MenuScreen.SHORTCUT_SLOT_SELECTOR` の inventory を作成する
2. `ShortcutSlotSelectorScreenView.render` で 4 スロット分の現在設定アイコンを描画する
3. close / back slot を配置する

## 7. ショートカット項目選択画面表示

クラス名: `MenuView`
物理名: `openShortcutActionSelector`

責務:

選択中ショートカットスロットへ割り当てる [[09_1.00-モデル定義]].メニューショートカット項目 を選ぶ GUI を表示する。

処理内容:

1. `MenuScreen.SHORTCUT_ACTION_SELECTOR` の inventory を作成する
2. `MenuInventoryHolder.shortcutSlotIndex` に対象スロットを保持する
3. `ShortcutActionSelectorScreenView.render` で割当可能な action アイコンを描画する
4. 現在割当中の action には glow を付与する
5. close / back slot を配置する

## 8. クラフトショートカット描画

クラス名: `MenuView`
物理名: `renderCraftShortcuts`

責務:

プレイヤーの 2x2 クラフト欄へショートカットアイコンを描画する。

処理内容:

1. `CraftShortcutView.createCraftResultIcon` で成果物スロットのメニューアイコンを作成する
2. `MenuShortcutSettings` の 4 action を 2x2 スロットへ配置する
3. 現在表示中インベントリと一致する action には glow を付ける
4. 描画抑止フラグが立っているプレイヤーは描画しない

備考:

- クラフト欄ショートカットは「アイコン表示のみ」であり、実クラフト処理は menu feature では行わない。クラフト欄からのアイテム生成・素材消費は発生しない前提とする。
- 描画抑止フラグはメインメニュー／通貨 GUI／インベントリ切替の遷移中に一時的に有効化し、遷移完了後に解除する（[[09_3.01-イベント]] 参照）。

## 追記（ゴミ箱GUI/View）
### ゴミ箱GUI表示
クラス名: MenuView
物理名: openTrash
- タイトル: ゴミ箱。
- ページングあり（0-44内容、45前ページ、53次ページ）。
- 戻るボタンあり（slot 49）。
- 下段左から3番目（slot 47）にゴミ箱ガイドアイテムを設置し、以下のクリック仕様と閉じる時の動作を記載する。
  - 左クリック: 1 個ゴミ箱へ
  - Shift+左クリック: すべてゴミ箱へ
  - 右クリック: 半分（端数切り上げ）ゴミ箱へ
  - ゴミ箱→インベントリ方向も同じクリック仕様
  - GUI を閉じるとゴミ箱内のアイテムはインベントリへ戻る
  - 廃棄ボタン（slot 51）で廃棄確認画面へ遷移する
- slot 51 は「廃棄」アイコン（Material.BARRIER, 赤文字）で、押下時に廃棄確認画面を開く。

### ゴミ箱確認GUI表示
クラス名: MenuView
物理名: openTrashConfirm
- タイトル: 本当に廃棄しますか？（赤文字）。
- ページングあり、内容閲覧のみ。
- 戻るボタン非表示。
- 非表示戻る枠の左右（slot 48/50）に廃棄アイコンとゴミ箱GUIに戻るアイコンを表示。
