# 02_0.00-概要

## 1. 目的

`account` 機能は、ユーザに紐づくゲーム内アカウント（キャラクター枠）を管理する。  
主目的は以下。

- 初回ユーザ登録時の初期アカウント作成
- 選択中アカウントの取得・切替
- アカウントモード（通常/ビルダー/管理者）の更新
- アカウント単位で保持するプレイヤーレベルと累計経験値の管理

## 2. コンテキスト

- データアクセスは直接 DB ではなく AstralRecord API (`/api/account/*`) 経由。
- [[01_1.00-モデル定義]].ユーザモデル の `accountId` と整合する必要がある。
- オンライン中の状態反映は [[03_1.00-モデル定義]].プレイヤーセッション に対して行う。
- プレイヤーレベルは [[02_1.00-モデル定義]].アカウントモデル に保持し、次レベル必要経験値は account UUID と現在レベルから内部算出する。
- 次レベル必要経験値の正確な数値はプレイヤーへ直接開示せず、進捗の概況のみ表示対象とする。

## 3. 構成要素（実装単位）

- `service/AccountService`
  - アカウント一覧取得、選択アカウント解決、作成、切替、モード更新、経験値加算を制御する。
- `repository/AccountRepository`
  - `/api/account` への HTTP リクエストを実行する。
- `command/AccountCommand`, `AccountModeCommand`
  - 管理者向けにアカウントモード変更を提供する。
- [[02_1.00-モデル定義]].アカウントモデル, [[02_1.00-モデル定義]].アカウントモード
  - アカウント実体とモードを定義する。
  - 実装単位は `model/AccountModel`, `AccountMode`。
