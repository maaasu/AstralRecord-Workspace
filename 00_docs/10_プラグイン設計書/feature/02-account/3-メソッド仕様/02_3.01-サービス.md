# 02_3.01-サービス

## 1. service メソッド仕様

### アカウント一覧取得

クラス名: `AccountService`
物理名: `getAccounts`

処理内容:

1. [[02_3.03-リポジトリ]].ユーザ別アカウント一覧取得を実行する

	| 項目 | 内容 |
	|---|---|
	| 入力 | ユーザUUID |
	| 出力 | [[02_1.00-モデル定義]].アカウントモデル の一覧 |

### 選択アカウント取得

クラス名: `AccountService`
物理名: `getSelectedAccount`

処理内容:

1. [[02_3.03-リポジトリ]].ユーザ別アカウント一覧取得を実行する

	| 項目 | 内容 |
	|---|---|
	| 検索キー | ユーザUUID |
	| 取得結果 | [[02_1.00-モデル定義]].アカウントモデル の一覧 |

2. [[01_1.00-モデル定義]].ユーザモデル.accountId と一致するアカウントを優先して返す

	| 項目 | 内容 |
	|---|---|
	| 優先条件 | `selectedAccountId` が `null` ではない |
	| 一致条件 | アカウントUUIDが `selectedAccountId` と一致 |

3. 一致しない場合は `isActive = true` のアカウントを返す

	| 項目 | 内容 |
	|---|---|
	| フォールバック条件 | 手順2で選択アカウントを取得できない |
	| 未取得時 | `null` を返す |

クラス名: `AccountService`

処理内容:

1. [[02_3.03-リポジトリ]].アカウント取得を実行する

### アカウント作成

クラス名: `AccountService`
物理名: `createAccount`

処理内容:

1. [[02_3.03-リポジトリ]].ユーザ別アカウント一覧取得で既存スロットを確認する

	| 項目 | 内容 |
	|---|---|
	| 検証対象 | `slotIndex` |
	| 使用済み | `IllegalArgumentException` を送出する |

2. [[02_1.00-モデル定義]].アカウントモデル を組み立てる

	| 項目 | 内容 |
	|---|---|
	| `uuid` | 新規UUID |
	| `userId` | ユーザUUID |
	| `accountName` | アカウント名 |
	| `slotIndex` | 入力スロット |
	| `isActive` | 既存アカウントが空なら `true` |
	| `mode` | [[02_1.00-モデル定義]].アカウントモード の通常プレイヤー |
	| `createdBy` / `updatedBy` | 入力された作成者UUID |

3. [[02_3.03-リポジトリ]].アカウント登録を実行する
4. 正常終了時は `LogId.I_5100` を記録する

	| 項目 | 内容 |
	|---|---|
	| ID | `LogId.I_5100` |
	| レベル | `INFO` |
	| テンプレート | `アカウントを作成しました: %s (slot=%d, user=%s)` |
	| 出力条件 | アカウント作成成功時 |
	| 引数 | `accountName`, `slotIndex`, `userId` |
