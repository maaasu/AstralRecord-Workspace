### 選択アカウント取得

クラス名: `AccountService`
物理名: `getSelectedAccount`

処理内容:

1. [[02_3.03-リポジトリ]].ユーザ別アカウント一覧取得を実行する

	| 項目 | 内容 |
	|---|---|
	| 検索キー | ユーザUUID |
	| 取得結果 | [[02_1.00-モデル定義]].アカウントモデル の一覧 |

2. [[01_1.00-モデル定義]].ユーザモデル.accountId と一致するアカウントを優先して返す

	| 項目 | 内容 |
	|---|---|
	| 優先条件 | `selectedAccountId` が `null` ではない |
	| 一致条件 | アカウントUUIDが `selectedAccountId` と一致 |

3. 一致しない場合は `isActive = true` のアカウントを返す

	| 項目 | 内容 |
	|---|---|
	| フォールバック条件 | 手順2で選択アカウントを取得できない |
	| 未取得時 | `null` を返す |

### アカウント作成

クラス名: `AccountService`
物理名: `createAccount`

処理内容:

1. [[02_3.03-リポジトリ]].ユーザ別アカウント一覧取得で既存スロットを確認する

	| 項目 | 内容 |
	|---|---|
	| 検証対象 | `slotIndex` |
	| 使用済み | `IllegalArgumentException` を送出する |

2. [[02_1.00-モデル定義]].アカウントモデル を組み立てる

	| 項目 | 内容 |
	|---|---|
	| `uuid` | 新規UUID |
	| `userId` | ユーザUUID |
	| `accountName` | アカウント名 |
	| `slotIndex` | 入力スロット |
	| `isActive` | 既存アカウントが空なら `true` |
	| `mode` | [[02_1.00-モデル定義]].アカウントモード の通常プレイヤー |
	| `level` | `1` |
	| `totalExperience` | `0` |
	| `createdBy` / `updatedBy` | 入力された作成者UUID |

3. [[02_3.03-リポジトリ]].アカウント登録を実行する
4. 初回参加者向けの `welcome_mail` 作成は [[18_3.00-メソッド仕様]].初回メール作成 へ委譲する。`welcome_mail` の本文・既読状態・既読時報酬は mail feature を正本とする
5. 正常終了時は `LogId.I_5100` を記録する

	| 項目 | 内容 |
	|---|---|
	| ID | `LogId.I_5100` |
	| レベル | `INFO` |
	| テンプレート | `アカウントを作成しました: %s (slot=%d, user=%s)` |
	| 出力条件 | アカウント作成成功時 |
	| 引数 | `accountName`, `slotIndex`, `userId` |

### 経験値加算

クラス名: `AccountService`
物理名: `grantExperienceCached`

処理内容:

1. 加算経験値が `0` 以下の場合、現在の [[02_1.00-モデル定義]].アカウントモデル を変更せず返す
2. 引数のアカウントモデルに、未 flush の経験値キャッシュがあればそれを優先して基準状態とする
3. `totalExperience` へ加算経験値を加える
4. [[02_1.00-モデル定義]].プレイヤーレベル進行 の式で次レベル必要経験値と累積必要経験値を算出し、到達済みの間は `level` を繰り上げる

	| 項目 | 内容 |
	|---|---|
	| 判定単位 | 1レベルずつ順に判定する |
	| 複数上昇 | 大量経験値で複数レベル到達した場合も同一処理内で反映する |
	| 表示方針 | exact な次レベル必要経験値はプレイヤーへ返さない |

5. 更新後の `level` / `totalExperience` を account 単位の経験値キャッシュへ保持する
6. 定期 flush タスクが一定間隔で [[02_3.03-リポジトリ]].アカウント進行更新を実行する
7. プラグイン停止時は `stop` で残存キャッシュを同期 flush する
8. Mob 撃破契機でレベルが変化した場合は、上昇レベル数と同数のスキルポイントを account-skilltree 永続状態へ付与できるよう結果へ含める
9. レベルが変化した場合は `LogId.I_5103` を記録する

	| 項目 | 内容 |
	|---|---|
	| ID | `LogId.I_5103` |
	| レベル | `INFO` |
	| テンプレート | `アカウントレベルが上がりました: %s (level=%d, totalExp=%d)` |
	| 出力条件 | 経験値加算でレベルが 1 以上上昇した場合 |
	| 引数 | `accountUuid`, 更新後 `level`, 更新後 `totalExperience` |
