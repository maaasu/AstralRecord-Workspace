# 02_3.02-コマンド

## 1. command メソッド仕様

### アカウントルート振分

クラス名: `AccountCommand`
物理名: `executeCommand`

処理内容:

1. 引数なしの場合は usage を返す
2. 第一引数が `mode` の場合、アカウントモード変更へ委譲する
3. 対応外サブコマンドは usage を返す

### アカウントモード変更

クラス名: `AccountModeCommand`
物理名: `executeCommand`

処理内容:

1. 実行者権限を検証する

	| 項目 | 内容 |
	|---|---|
	| コンソール | 許可 |
	| プレイヤー | [[03_1.00-モデル定義]].プレイヤーキャッシュ から取得した [[03_1.00-モデル定義]].プレイヤーセッション の permission が `99` 以上なら許可 |
	| 拒否時メッセージ | `このコマンドを実行する権限がありません。` |

2. AccountService / UserService の初期化状態を確認する

	| 項目 | 内容 |
	|---|---|
	| 拒否条件 | いずれかが `null` |
	| 拒否時メッセージ | `AccountService/UserService が初期化されていません。` |

3. mode 値を [[02_1.00-モデル定義]].アカウントモード へ変換する

	| 項目 | 内容 |
	|---|---|
	| 入力 | `args[1]` |
	| 許可値 | `0`, `1`, `2` |
	| 拒否時メッセージ | `mode は 0, 1, 2 のいずれかで指定してください。` |

4. 対象アカウントを解決する

	| 項目 | 内容 |
	|---|---|
	| 入力 | `args[0]` |
	| プレイヤー名指定 | オンラインプレイヤーの [[03_1.00-モデル定義]].プレイヤーセッション.account.uuid を使用する |
	| アカウントUUID指定 | [[02_3.01-サービス]].アカウント取得 で存在確認する |
	| ユーザUUID指定 | [[01_3.02-サービス]].ユーザ取得 後、[[02_3.01-サービス]].選択アカウント取得 で解決する |
	| 拒否時メッセージ | `対象アカウントが見つかりません: %s` |

5. [[02_3.01-サービス]].アカウントモード更新を実行する
6. オンライン中の [[03_1.00-モデル定義]].プレイヤーセッション へ反映する

	| 項目 | 内容 |
	|---|---|
	| 一致条件 | 更新後アカウントUUIDとオンラインプレイヤーのアカウントUUIDが一致 |
	| 通常プレイヤー | inventory feature へGUIインベントリ反映を依頼する |
	| 通常プレイヤー以外 | GUIインベントリをクリアする |

7. 成功メッセージを返す

	| 項目 | 内容 |
	|---|---|
	| ID | `-` |
	| レベル | `INFO` |
	| テンプレート | `account mode を更新しました: %s = %s` |
	| 出力条件 | モード更新成功時 |
	| 引数 | `updated.getAccountName()`, `updated.getMode().getValue()` |

### アカウント補完候補取得

クラス名: `AccountTabCompleter`
物理名: `getCompletions`

処理内容:

1. 第1引数位置では `mode` を返す
2. `mode` サブコマンド時はアカウントモード補完候補取得へ委譲する
3. それ以外は空リストを返す

### アカウントモード補完候補取得

クラス名: `AccountModeTabCompleter`
物理名: `getCompletions`

処理内容:

1. 第1引数位置ではオンラインプレイヤー名を返す
2. 第2引数位置では `0`, `1`, `2` を返す
3. それ以外は空リストを返す

## 2. コマンド仕様

- ルート: `/account`
- サブコマンド: `/account mode <player|accountUuid> <0|1|2>`
