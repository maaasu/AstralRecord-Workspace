# 02_1.00-モデル定義

## 1. ドメインモデル

`account` 機能の中心はアカウントモデル。  
[[01_1.00-モデル定義]].ユーザモデル に紐づくゲーム内アカウントを表し、選択状態、モード、メニューショートカット設定を保持する。

## 2. アカウントモデル

物理名: `AccountModel`

### 2.1 項目

#### 2.1.1 識別情報

- `uuid`
- `userId`
- `accountName`
- `slotIndex`

#### 2.1.2 選択・モード

- `isActive`
- `mode`
- `menuShortcutsJson`

#### 2.1.3 監査情報

- `createdAt`
- `updatedAt`
- `createdBy`
- `updatedBy`
- `isDeleted`

## 3. アカウントモード

物理名: `AccountMode`

| 値 | 論理名 | 説明 |
|---|---|---|
| `0` | 通常プレイヤー | 通常プレイ用。GUIインベントリへ反映する |
| `1` | ビルダー | ビルド権限向け。GUIインベントリ反映は行わない |
| `2` | 管理者 | 管理権限向け。GUIインベントリ反映は行わない |

## 4. 関連 feature とのモデル関係

- `user`
  - [[01_1.00-モデル定義]].ユーザモデル.accountId は選択中アカウントを指す。
- `player`
  - [[03_1.00-モデル定義]].プレイヤーセッション は現在のアカウントモデルを保持する。
- `inventory`
  - アカウントモードが通常プレイヤーの場合、GUIインベントリへ反映する。
