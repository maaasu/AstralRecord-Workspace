# 02_2.00-ユースケース

## 1. 初期アカウント作成

- 契機: [[01_3.02-サービス]].新規ユーザ登録
- 入力: ユーザUUID、アカウント名、slot `0`、作成者
- 結果: [[02_1.00-モデル定義]].アカウントモデル を作成し、user 側の選択アカウントIDへ反映する

## 2. 選択アカウント解決

- 契機: ログイン処理、オンライン状態構築、user の最終参加情報更新
- 優先: [[01_1.00-モデル定義]].ユーザモデル.accountId
- フォールバック: `isActive = true` のアカウント

## 3. アカウントモード変更

- 契機: `/account mode <player|accountUuid> <0|1|2>`
- 実行条件: コンソール、または permission `99` 以上のプレイヤー
- 結果: アカウントモードを更新し、オンライン中なら [[03_1.00-モデル定義]].プレイヤーセッション へ反映する

## 4. 経験値加算・レベルアップ

- 契機: 戦闘、クエスト、探索、クラフト等の gameplay 報酬
- 入力: 対象アカウントUUID、加算経験値
- 処理: [[02_3.01-サービス]].経験値加算 で累計経験値を更新し、必要に応じて複数レベル分のレベルアップ判定を行う
- 補足: Mob 撃破時はドロップ受取対象ごとに mob 定義の `exp` をそのまま加算する
- 結果: [[02_1.00-モデル定義]].アカウントモデル の `level` / `totalExperience` が更新され、レベルアップ数と同数のスキルポイントを skilltree へ付与する
