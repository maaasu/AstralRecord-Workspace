# 01_1.00-モデル定義

## 1. API 入出力

`WebLoginChallengeConsumeRequest`: `loginCode`

`WebLoginChallengeConsumeResponse`: `userUuid`, `mcid`, `permission`, `currentAccountId`, `accountIds`

## 2. Web 内部結果

`WebLoginChallengeConsumeStatus` は `Success`、`Invalid`、`ServiceUnavailable` を持ちます。`WebLoginChallengeConsumeResult` は状態と成功時レスポンスをまとめます。

## 3. Cookie Claim

- `ClaimTypes.NameIdentifier`: user UUID
- `ClaimTypes.Name`: MCID
- `permission`: 権限値
- `currentAccountId`: 現在のアカウント ID（存在時）
- `accountId`: 所有アカウント ID（複数）
