# 01_1.00-モデル定義

Webログインで使用するAPI入出力、内部結果、Cookie Claimを定義します。

## 1. API 入出力

`WebLoginChallengeConsumeRequest`: `loginCode`

`WebLoginChallengeConsumeResponse`: `userUuid`, `mcid`, `permission`, `webAdmin`, `currentAccountId`, `accountIds`

## 2. Web 内部結果

`WebLoginChallengeConsumeStatus` は `Success`、`Invalid`、`ServiceUnavailable` を持ちます。`WebLoginChallengeConsumeResult` は状態と成功時レスポンスをまとめます。

## 3. Cookie Claim

- `ClaimTypes.NameIdentifier`: user UUID
- `ClaimTypes.Name`: MCID
- `permission`: 権限値
- `currentAccountId`: 現在のアカウント ID（存在時）
- `accountId`: 所有アカウント ID（複数）

`webAdmin` はログイン応答に含まれるが、Web管理認可には利用しない。管理画面は要求ごとに `GET /api/web-auth/users/{userUuid}/authorization` を呼び、応答の `webAdmin` だけを使用する。
