# 01_5.00-例外・ログ・運用

| 状態 | 画面動作 |
|---|---|
| GET | Web ログイン未実装案内と操作不能フォームを表示する |
| 有効な CSRF トークン付き POST | 200 で同じ未実装案内を表示する |
| API 呼び出し | 停止中は行わない |
| Cookie 発行 | 停止中は行わない |

停止中は `WebAuthApiClient` を呼び出さないため、ログイン操作に起因する API 通信ログは発生しません。再開時は通信例外の Warning ログ、機密値の非出力、フォーム・POST・API・Cookie・テスト・設計書の同時更新を再確認します。
