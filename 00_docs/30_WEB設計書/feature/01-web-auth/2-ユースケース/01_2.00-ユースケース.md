# 01_2.00-ユースケース

## 1. ログイン画面でコードを消費する

1. プレイヤーがゲーム内で `/web login` を実行してコードを発行する。
2. プレイヤーが `/Login` を開き、コードを入力してCSRFトークン付きで送信する。
3. WebはAPIでコードを消費し、成功時に認証Cookieを発行して `/MyPage` へ遷移する。
4. 無効・期限切れ・使用済みコードは入力画面で拒否し、API障害は再試行案内を表示する。
5. 管理画面を要求した場合は、API照会時点の `web_admin` がtrueのプレイヤーだけを許可する。

## 2. ログアウトする

`/Logout` のPOSTは認証Cookieを破棄し、公開トップページへ遷移します。

## 3. Web管理機能を利用する

Web管理画面では、認証済みプレイヤーのUUIDをAPIへ送信し、ManagementDBの `web_admin=true` を確認できた場合だけ画面を表示します。ゲームpermissionやCookie内の過去の値では許可しません。
