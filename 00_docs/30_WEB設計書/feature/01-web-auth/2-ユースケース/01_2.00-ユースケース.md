# 01_2.00-ユースケース

## 1. 停止中のログイン画面を表示する

1. プレイヤーが `/Login` を開く。
2. Web は Web ログインが未実装であることを案内し、入力フォームを操作不能で表示する。
3. 有効な CSRF トークン付き POST を受けた場合も同じページを返し、API 呼び出し、Cookie 発行、`/MyPage` への遷移は行わない。

## 2. 保持中のログアウト処理

既存の `/Logout` POST は保持していますが、停止中の `/Login` から認証セッションは作成されません。

## 3. 再開する

再開時は Minecraft 内のコード発行、Web のコード入力・正規化、API 消費、Cookie 発行、`/MyPage` 遷移を一連の動作として再検証し、実装・画面・テスト・本設計書を同時に更新します。
