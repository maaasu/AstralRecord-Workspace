# 01_2.00-ユースケース

## 1. ログイン画面でコードを消費する

1. プレイヤーがゲーム内で `/web login` を実行してコードを発行する。
2. プレイヤーが `/Login` を開き、コードを入力してCSRFトークン付きで送信する。
3. WebはAPIでコードを消費し、成功時に認証Cookieを発行して `/MyPage` へ遷移する。
4. 無効・期限切れ・使用済みコードは入力画面で拒否し、API障害は再試行案内を表示する。
5. API照会時点の `web_admin` がtrueのプレイヤーには管理者専用メニューを表示する。メニューから管理画面を要求した場合は、コード認証から5分以内、または信頼済みブラウザの最終利用から7日以内のプレイヤーだけを許可する。コード入力時に信頼を選択したWeb管理者へは信頼済みブラウザを発行する。

## 2. ログアウトする

`/Logout` のPOSTは認証Cookieを破棄し、公開トップページへ遷移します。信頼済みブラウザCookieは、7日間の管理者モード継続を選択した端末のために保持します。

## 3. Web管理機能を利用する

共通メニューの管理者専用領域は、認証済みプレイヤーのUUIDをAPIへ送信してManagementDBの `web_admin=true` を確認できた場合に表示します。メニューから管理画面を開く場合は、さらに5分以内のコード認証または信頼済みブラウザの検証を確認できた場合だけ画面を表示します。ゲームpermissionやCookie内の過去の値では許可しません。信頼済みブラウザの検証成功時は最終利用日時を更新し、管理画面・操作全体に適用します。

## 4. ID・パスワードを管理する

初期状態は無効。初回のコードログイン後5分以内に `/LoginSettings` でパスワードを設定すると、UUID単位の固定IDを発行して同時に有効化する。次回はID・パスワードでログインできる。通常変更には現在のパスワード、忘れた場合には本人のコード再認証を使う。無効化時はハッシュを削除してIDを予約保持し、再有効化にも直近コード認証を要求する。保存・無効化時は世代を更新し、操作端末を更新後のCookieに替え、他端末を次の要求で失効させる。
