# 01_0.00-概要

## 1. 目的

Minecraft サーバー側のログインコード発行機能とは切り分けて、AstralRecord Web からのログインを停止しています。`/Login` は未実装案内を表示する公開ページとしてのみ提供します。

## 2. 責務

- `/Login` のフォームを操作不能にし、POST を受けても同じ未実装案内を返す。
- 停止中は API `POST /api/web-auth/challenges/consume` を呼び出さない。
- 停止中は認証 Cookie を発行せず、`/MyPage` へ遷移しない。

## 3. 再開条件

Web ログインを再開するときは、フォーム表示、POST の停止ガード、API 消費、Cookie 発行、関連テストと本 feature 設計書を同じ変更で有効な仕様へ更新します。
