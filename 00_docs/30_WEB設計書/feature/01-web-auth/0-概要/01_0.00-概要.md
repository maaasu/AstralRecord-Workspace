# 01_0.00-概要

## 1. 目的

Minecraftサーバー側で発行したログインコードを利用して、AstralRecord Webへ安全にログインする導線を提供します。`/Login` はコード入力フォームを公開し、成功時に `/MyPage` へ遷移します。

## 2. 責務

- `/Login` でログインコードを受け取り、API `POST /api/web-auth/challenges/consume` へ送る。
- 成功時に12時間有効のHTTPS専用認証Cookieを発行し、`/MyPage` へ遷移する。
- Web管理画面の要求ごとにAPIへWeb管理権限を照会し、WebSiteDBの `web_admin=true` の場合だけ許可する。
- ゲーム側permission、Cookieに残った過去の権限、API照会失敗ではWeb管理画面を許可しない。

## 3. 管理権限

Web管理者の初期指定は自動で行わない。ログイン成功後に作られた `web_user` に対し、運用担当者が明示的に `web_admin` を更新する。
