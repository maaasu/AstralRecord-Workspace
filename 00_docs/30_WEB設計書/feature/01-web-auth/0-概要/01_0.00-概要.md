# 01_0.00-概要

## 1. 目的

Minecraft サーバーで発行された一回限りのログインコードを使って、プレイヤーを AstralRecord Web へログインさせます。Web はパスワードを保持せず、API のチャレンジ消費結果を認証根拠とします。

## 2. 責務

- `/Login` でコードを受け付ける。
- API `POST /api/web-auth/challenges/consume` を呼び出す。
- 成功時に user UUID、MCID、権限、アカウント ID を Claim として Cookie を発行する。
- `/MyPage` を認証必須とし、`/Logout` で Cookie を破棄する。
