# 01_3.04-プレイヤー一覧・詳細

## プレイヤー一覧

- パス: `/players`。匿名閲覧可。API: `GET /api/web-profiles`。
- 公開済みのプレイヤーをMCID部分一致・現在クラスで検索し、プレイヤーレベルの昇順/降順に並べる。20件ずつページ表示する。
- 非公開・Web未ログインのプレイヤーは通常一覧に含めない。
- ログイン中のユーザーについてManagementDB `web_admin=true` を確認できた場合だけ「すべてのプレイヤーの情報を検索」トグルを表示する。
- トグルを有効にした場合は `include_private=true` をAPIへ渡す。Web側とAPI側の両方で管理権限を確認し、URLを直接改変した非管理者の要求は拒否する。
- クエリの `viewer_user_uuid` は受け入れず、認証済みCookieのUUIDだけをAPIへ渡す。

## プレイヤー詳細

- パス: `/players/{userUuid}`。API: `GET /api/web-profiles/{userUuid}`。
- 公開済みのプロフィール、本人自身、または明示的な管理者閲覧だけを許可する。
- マイページと共通の参照UIを使い、「プレイヤーのプロフィール」とMCIDを表示する。公開設定の変更ボタンは表示しない。
- 非公開プロフィールの管理者閲覧には `includePrivate=true` と要求時点の管理権限が必要。非公開状態を明示する。
- すべての一覧・詳細応答は `no-store`。公開取り消し後にサーバーや共有キャッシュから古いプロフィールを配信しない。

## 共通デザインと導線

PCとモバイルの双方で右側から開くハンバーガーメニューを利用する。公式Discordはヘッダーのメニューボタン左側に常設し、メニュー内には重複させない。

サイト案内、ログイン中のプレイヤー、管理者専用を区切り、プレイヤー領域は青緑、管理者領域は金色で区別する。サイト共通の星空、軌道、浮遊ブロック、スクロール出現演出を使用し、`prefers-reduced-motion` ではアニメーションを停止する。
