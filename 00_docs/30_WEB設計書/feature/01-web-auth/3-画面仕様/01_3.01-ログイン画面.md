# 01_3.01-ログイン画面

- パス: `/Login`
- Razor Page: `Pages/Login.cshtml`, `Pages/Login.cshtml.cs`
- 認証: `[AllowAnonymous]`

ゲーム内で `/web login` を実行して表示されたコードを入力します。有効なCSRFトークン付きPOSTではAPIでコードを消費し、成功時に認証Cookieを発行して `/MyPage` へリダイレクトします。入力不足、無効・期限切れ・使用済みコード、API接続失敗は同画面へエラーを表示します。

コード方式のフォームには「このブラウザを信頼する」チェックボックスを表示します。Web管理者が選択した場合、管理者モード用のトークンを発行し、このブラウザでは管理画面の最終利用から7日間Minecraft再認証を不要にします。共有端末での選択は推奨しません。ID・パスワード方式ではこのトークンを発行しません。

## 任意のID・パスワード認証

- コードとID・パスワードのフォームを別handlerで受け付ける。初回はコード方式を使う。
- ID・パスワードは `POST /api/web-auth/password/login` で照合し、成功時は同じCookie形式で `/MyPage` へ遷移する。コード認証日時は付与しない。
- 不存在・無効化済み・誤パスワード・試行制限は同じエラーを表示する。入力したパスワードを応答HTMLへ戻さない。
- IDやパスワードを忘れた場合はMinecraftのコードでログインし、ログイン設定から確認・再設定する。サーバー停止中のコード復旧は再開まで待つ。
- 全フォームはCSRF検証必須。接続元IPのPOST回数制限は再認証・ログイン設定と共通。
