# 01_3.01-ログイン画面

- パス: `/Login`
- Razor Page: `Pages/Login.cshtml`, `Pages/Login.cshtml.cs`
- 認証: `[AllowAnonymous]`

現在は「Webログインは現在未実装です」と案内し、ゲーム内のログインコード発行とは別に Web フォームが利用できないことを表示します。フォームは操作不能であり、有効な CSRF トークン付き POST を受けても 200 で同じ案内を返します。API のコード消費、認証 Cookie 発行、`/MyPage` 遷移は行いません。

再開時はフォーム表示と POST 停止ガードを解除するだけでなく、API 消費、Cookie 発行、画面案内、統合テストと本設計書を同じ変更で更新します。
