# 01_3.06-スキルツリー編集

- パス: `/skilltree/{accountId}`。
- Razor Page: `Pages/SkillTree/Index.cshtml` / `Index.cshtml.cs`。
- 本人のマイページから開く。認証必須、全応答は`no-store`。
- Webは変更要求を登録し、参加先Pluginが確定する。全置換保存APIを呼ばない。

## 表示と操作対象

対象アカウントを所有する認証済みユーザーのUUIDだけをAPIに渡す。フォーム、URL、JSONから送信された所有者UUIDや費用・条件判定を採用しない。POSTはRazor PagesのAnti-forgeryを必須とし、APIでも所有関係を再検証する。

参加先が実際にロードして公開した世代の定義と、そのプレイヤー状態に対応した評価情報を表示する。最新配置のJSONを参加先定義の代用にしない。必要な世代、評価または新鮮な稼働情報が得られない場合は編集不可とし、再取得や更新待ちを案内する。世代ハッシュや互換性の内部コードは画面文言に使わない。

接続領域にはゲームへのログイン中／オフライン／確認不能を区別し、オンライン時は接続チャンネル名、ワールド表示名、X/Y/Z、確認時刻を表示する。オンライン中の編集は拠点またはスキルツリーワールドだけで許可する。送信前にも最新状態を取得し、Pluginが確定直前に実際の現在地を再確認する。

## 変更要求

ノードを選ぶと解放または解除の内容を表示する。CP消費元を選べるノードでは候補クラス名と使用可能CPを提示する。「選択変更」は、この未確定の解放操作で消費元クラスを選び直す操作を指す。解放済みノードの消費元だけを付け替える新たなゲーム仕様は設けない。

変更内容と費用の確認後、操作ID、期待定義世代、期待プレイヤー状態更新番号、操作種別、ノードID、必要な場合のみCP消費元クラスを送る。送信直前の再取得で世代・状態・場所が変化していれば送らず再確認を求める。Webでの表示判定を、Pluginの検証結果の代用にしない。

編集中の変更は確定残高と分離する。PPと全利用可能クラスのCP、Goldを固定領域に表示し、詳細には消費・返還の差分を表示する。解除費用と返還先は取得したルールと保存済み消費元から表示する。APIの`balanceKind`が`LIVE`なら確定済み、`SAVED`ならオフライン・保存済み残高と明記する。`UNKNOWN`または再取得失敗時は残高を未確認として数値を消し、以前の残高を現在値として残さない。

| 状態 | 画面上の扱い |
|:--|:--|
| 編集中 | ノードとCP消費元を選択・確認中。まだ要求を登録していない |
| 適用待ち | APIに登録済み、またはPluginが確認中。残高を確定済みへ変更しない |
| 適用済み | APIから確定結果を受信した後だけ表示し、残高とノードを再取得 |
| 再確認が必要 | 世代・状態・条件・期限などが変化。再取得して内容を選び直す |
| 失敗 | 適用失敗の確定結果を表示 |

オフライン時は次回参加時に検証する編集案として保存する。アカウントにつき有効な要求は1件とし、新たな要求を作る前に既存要求を取り消す。取消済み・期限切れの要求は後から適用しない。確定済みの操作を取消済みに表示しない。

送信結果が不明な場合は同じ操作IDで照会する。まだAPIに届いていない場合の再送も元の操作IDと条件を保持し、新しい操作IDによる重複要求を作らない。操作IDはタブのセッション領域にも保存し、ページ再読込後の結果確認に使用する。APIの確定結果を取得するまでは次の変更を送信しない。

## 画面領域と入力

通常表示から「画面いっぱいに開く」で拡大表示へ切り替える。同じ編集状態を保持し、「通常表示に戻る」で戻る。Fullscreen APIは使用しない。ヘッダーと残高領域をコンパクトにし、中央のツリー領域を残りの高さまで広げる。

パン、ズーム、全体図、開始位置リセット、選択位置へ移動、検索、ミニマップを利用できる。ノード上からもドラッグでき、一定距離以上の移動をクリックとして扱わない。タッチでは1点でパン、2点でピンチ拡大縮小する。詳細パネルは閉じられ、ツリーを引き続き操作できる。

円形の外枠、中央アイコン、装飾は従来のデザインを維持する。名前、主要ステータス効果、スキル付与、コスト、CP対象クラス、状態は円形ノードの下のラベルに常時表示する。表示名・書式・値はPluginの評価情報を正本とし、内部IDで代用しない。長い文は折り返し、効果の行数に合わせてラベルと間隔を確保する。補足条件と保存済みの実消費元は詳細に表示する。

接続線はノードとラベルの背後へ描画し、実線・破線・太さ・枠・記号を併用する。縮小時も線幅を保ち、画面内に簡潔な凡例を表示する。キーボードの矢印、`+/-`、Home、Tab/Enterでも閲覧できる。

API・Plugin・DBの保存、処理権限、世代互換性、導入手順はスキルツリーAPIとPluginの設計を参照する。
