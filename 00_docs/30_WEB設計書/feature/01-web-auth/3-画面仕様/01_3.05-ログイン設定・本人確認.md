# 01_3.05-ログイン設定・本人確認

## ログイン設定

- パス: `/LoginSettings`。認証必須、no-store、CSRF必須。マイページから遷移する。
- 有効状態なら本人の固定ログインIDとコピーボタンを表示する。公開プロフィールには含めない。
- 有効化: 直近5分以内の本人コード認証と新パスワードの確認入力。API成功時にID発行と有効化を同時確定する。
- 変更: 現在のパスワード、または直近5分以内の本人コード認証。新パスワードを2回入力する。
- 無効化: 変更と同じ本人確認条件。新パスワードは不要。ハッシュを削除し、IDは予約保持する。
- いずれも世代更新で他端末を次の要求時に失効させ、操作端末には新Cookieを発行する。競合・古い世代は再ログインへ誘導する。
- パスワード入力は再表示しない。貼り付け・パスワードマネージャーを許可する。15〜128文字、一般的・単純なパスワードを拒否し、文字種の混在や定期変更は強制しない。

## 本人確認

- パス: `/Reauthenticate`。認証必須、no-store、CSRF必須。
- 現在のCookieのUUIDをExpectedUserUuidとしてコード消費APIへ渡す。他ユーザーへの切替は行わない。
- 成功時にコード認証日時とAPIが返したセッション世代を新Cookieに設定する。
- 戻り先はローカルURLのみ許可し、不正な戻り先はログイン設定へ戻す。POST操作は自動再送しない。
- 管理者専用メニューは最新のweb_adminがtrueの場合に表示する。管理画面は最新のweb_adminと直近コード認証の両方を要求し、コード認証期限切れはこの画面へ誘導する。
