# 01_3.02-ログアウト

- パス: `/Logout`
- Razor Page: `Pages/Logout.cshtml.cs`
- 認証: `[Authorize]`

GET は確認画面を表示し、POST で `CookieAuthenticationDefaults.AuthenticationScheme` をサインアウトして `/Index` へリダイレクトします。

ログイン済みプレイヤーのセッションを明示的に終了する画面です。

メニューのログアウトは確認ダイアログを開く。「キャンセル」およびEscapeではセッションを維持し、「ログアウトする」のAnti-forgery付きPOSTでのみ終了する。ダイアログ終了後は起動元へフォーカスを戻す。JavaScriptを利用できない場合は `/Logout` の確認画面へ移動する。
