# 01_3.03-マイページ

- パス: `/MyPage`
- Razor Page: `Pages/MyPage.cshtml`, `Pages/MyPage.cshtml.cs`
- 認証: `[Authorize]`

Cookie Claim から MCID、user UUID、権限、現在のアカウント ID を読み取り表示します。現在のアカウントがない場合は `-` を表示します。

認証Cookieを持つプレイヤーが到達できます。ここで表示するゲームpermissionはWeb管理権限を表さず、Web管理画面の可否はWebSiteDBの `web_admin` で別途判定します。
