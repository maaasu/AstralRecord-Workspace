# 01_3.03-マイページ

- パス: `/MyPage`
- Razor Page: `Pages/MyPage.cshtml`, `Pages/MyPage.cshtml.cs`
- 認証: `[Authorize]`。プロフィール応答は `Cache-Control: no-store`。

認証Cookieからは本人UUIDだけを識別し、ページ表示のたびに `/api/web-profiles/me` で保存済みの最新情報を取得する。ログイン時のMCID・選択アカウント・権限Claimを表示値の正本にしない。

## 表示内容

- MCID、UUID、権限レベル、現在選択中のアカウント名・UUID、クラス名。
- 選択アカウントのプレイヤーレベル、所持金、現在クラスレベル、クラス別成長記録、最終保存時刻（日本時間）。
- スキルツリーは同アカウントのゲーム内可視判定に従う。CPは現在クラス・祖先クラス・レベル条件に該当するノードのみ、PPは条件未達でも必要条件を示すため保持する。接続、解放状況、コスト、効果を表示し、未達条件を色分けする。
- X/Zの相対配置と距離比を保ち、両軸へ同じ倍率を適用する。標準のノード間隔は最低108、最も近い2点の軸方向距離と最も情報量の多いラベルの高さから、名前・効果・コスト・状態の表示に必要な間隔を確保する。表示倍率とは別にノード間隔を50～200%で調整でき、50%では全ノード間の表示距離が標準の半分になる。間隔を狭めるとラベルが重なる場合がある。初期表示は開始ノード周辺を読める倍率で表示し、全体図へ自動縮小しない。画面移動・ポインター位置基準の拡大縮小・全体図・ミニマップ・ノード検索・選択ノードへ戻る・テキスト一覧に対応する。配置と接続のマスター編集は行わない。
- 本人には「スキルツリーを編集する」リンクを表示し、専用の[安全編集画面](01_3.06-スキルツリー編集.md)へ移動する。他プレイヤーのプロフィールには編集導線を表示しない。
- 選択アカウントがなければ未選択を表示し、値を0で捏造しない。取得失敗は再読み込み案内を表示する。
- Pluginの非同期保存が反映されるまで遅延があるため「保存済みの最新情報」と明記する。

## 公開設定

既定は非公開。本人が公開ボタンを押したPOSTだけで公開し、いつでも非公開へ戻せる。このページのPOSTは公開設定だけを変更する。スキルツリーの変更要求は専用編集画面で扱う。

POST `/MyPage?handler=Visibility` はAnti-forgeryを要求し、閲覧者UUIDを認証Cookieから決定する。フォームのUUIDやアカウント指定は採用しない。公開される情報をボタン付近に説明する。

公開一覧・他プレイヤー詳細は [[01_3.04-プレイヤー一覧・詳細]] を参照する。Web管理権限はゲームpermissionとは別で、ManagementDBの `web_admin` を要求ごとに再照会する。

## スキルツリーの表示と検証

- ノードは従来の円形外枠・中央Materialアイコン・装飾を維持し、その下のラベルに名前、主要効果、クラス付きCPまたはPPコスト、状態を表示する。解放済みは金色の実線枠、解放可能は緑系の破線枠、未解放は灰紫の枠、選択中と隣接ノード・接続を強調する。解放可能状態は対象世代の評価が取得できる画面でのみ表示する。縮小した全体図では文字ラベルを隠し、ノード選択で読める倍率へ戻る。
- 通常表示と画面全体を使う拡大表示を切り替えられる。Fullscreen APIは使用せず、同じDOMと選択・カメラ状態を保持する。詳細パネルは閉じられ、次のノード選択で開く。
- 接続線は未解放を含む経路を明るい破線、解放済み同士を太い実線、選択ノードの接続をさらに太い実線で表示する。`vector-effect: non-scaling-stroke`でズームアウト時の線幅を維持し、ノードとラベルより後ろに描画する。
- ノード詳細は大きなMaterialアイコン、CP/PP、解放状態、コスト、効果一覧、必要条件、隣接ノードへの移動を表示する。解放済みでも条件未達なら無効と明示する。
- 現行73種類のアイコンを `wwwroot/images/minecraft` に同梱し、取得出典を同フォルダREADMEへ記録する。未収録のMaterialだけ既存 `assets.mcasset.cloud` のitem/block画像を順に参照し、取得できなければ記号を表示する。URLへ入れるMaterialは英小文字・数字・アンダースコアに制限する。
- マップ装飾・選択リングは `prefers-reduced-motion` でアニメーション停止。Tab/Enterによるノード詳細、矢印キーで移動、+/-による拡大縮小、テキスト一覧に対応する。
- 幾何計算の検証: `node --test 30_web/AstralRecordWeb/AstralRecordWeb.Tests/skilltree-geometry.test.mjs`。距離比・衝突回避用の余白・ズームの中心固定・安全なMaterial名を確認する。Webの既存 `dotnet test` も実行する。

## 接続情報とスキンアイコン

本人の現在アカウントには、対応Pluginが公開した接続状態（ログイン中・オフライン・確認不能）、チャンネル名、ワールド表示名、座標、確認時刻を表示する。公開プロフィールや管理者による他人の閲覧には座標・接続先を返さない。通信途絶をオフラインと推測しない。更新はページの再取得で行う。

本人のプロフィールアイコンはMinecraft user UUIDを使った[Crafatar Avatar API](https://crafatar.com/)の顔画像とする。アカウントUUIDやMCIDを画像識別子にしない。ブラウザーからUUIDを含む外部画像URLへアクセスし、referrerpolicy=no-referrerでページURLを送らない。画像取得失敗時は既存の頭文字表示へ戻す。ゲームサーバーへのスキン取得処理は追加しない。
