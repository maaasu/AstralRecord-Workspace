# リリースノート 例外・ログ・運用

- front matter不正のファイルはログへ記録し、他のノートの表示を継続する。
- `status: draft` は一覧・詳細・API同期の対象外とする。
- `publishedAt` が未来のノートは公開日時到来まで表示しない。
- API登録失敗時はWebが再試行し、Webページ自体はローカルMarkdownから表示を継続する。
- Markdownの生HTMLは無効化し、リンクの `javascript:`、`vbscript:`、`data:` スキームは無効化する。
- 本番Webの `appsettings.json` には `AstralRecordApi:BaseUrl` と `AstralRecordApi:ApiKey` を設定する。本番API接続先は `https://device_server:444` とする。APIキーはAPI側の `ApiKey:Key` と同じ値を使用し、リポジトリへ保存しない。
- リリース管理デプロイ前に、`token.txt` の存在・非空、本番API接続先、APIキーの一致、`ReleaseNotes:SyncOnStartup` が有効であることを検証する。トークンとAPIキーの値はログへ出力しない。
