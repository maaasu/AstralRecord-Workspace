# リリースノート 統合フロー

1. Webのpublish処理で `00_docs/70_リリースノート/**/*.md` を `release-notes/` に同梱する。
2. `ReleaseNoteCatalog` がfront matterを検証し、公開済みノートをMarkdigでHTML化する。
3. `/releases` と `/releases/{slug}` が同じカタログを参照する。
4. `ReleaseNotePublicationHostedService` がAPIへ同期する。
5. APIがDB登録とDiscord通知Outbox作成を行い、通知ワーカーがDiscordへ送信する。
