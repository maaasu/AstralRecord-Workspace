# リリースノート 画面モデル

## リリースノート一覧モデル

物理名: `IndexModel`

| 項目 | 型 | 説明 |
|---|---|---|
| `Releases` | `IReadOnlyList<ReleaseNoteDocument>` | 公開日時の降順で表示するノート |

## リリースノート詳細モデル

物理名: `DetailsModel`

| 項目 | 型 | 説明 |
|---|---|---|
| `ReleaseNote` | `ReleaseNoteDocument?` | slugに一致する公開ノート。未取得時は404 |

## Markdown front matter

| キー | 必須 | 説明 |
|---|---|---|
| `slug` | ✓ | URL識別子 |
| `version` | ✓ | バージョン |
| `title` | ✓ | タイトル |
| `summary` | ✓ | 一覧の概要 |
| `publishedAt` | ✓ | 公開日時 |
| `status` | ✓ | `draft` または `published` |
| `notifyDiscord` | ✓ | API通知Outboxの作成可否 |
