# 08 有償サービス画面

## 有償アストラルドショップ

- パス: `/AstraldShop`。ログイン必須、応答は `no-store`。
- `GET /api/web-profiles/me` の `CurrentAccount` を購入先とする。Cookieに残ったアカウント情報やスロット順では選ばない。購入POST直前にも現在アカウントを再取得し、表示時のアカウントIDと違えば送信しない。APIでも所有と現在アカウントを再検査する。
- `GET /api/web/astrald-shop/catalog` の商品名、商品ID、価格、チャンネル選択肢を表示する。有償残高・特典は本人限定の `GET /api/web/account-benefits` を使用する。取得失敗時は購入ボタンを無効にする。
- チャンネルブースト商品は対象チャンネルを選択し、購入確定と同時に発動する。同種が有効な場合は重複不可。EXP・DROP同時ブーストは両方とも無効な場合に限る。状態の参考表示は `GET /api/channel-boosts` から取得し、最終判定はAPIに任せる。
- 購入フォームはAnti-forgeryと操作IDを使い、送信後はボタンを無効化する。APIへはCookie由来の本人UUIDと商品、現在アカウント、操作ID、画面に表示した価格 `expectedPricePaidAstrald`、必要な場合だけチャンネルIDを渡す。APIの現行価格と違えば無課金で拒否する。POSTの409応答を含む結果を取得し、必要に応じ `GET /api/web/astrald-shop/purchases/{operationId}` で再照会する。`COMPLETED`、`PENDING`、`REJECTED` を区別し、拒否時は残高不足・同種ブースト有効・アカウント変更・チャンネル不正・価格変更などを具体的に案内する。効果は購入先アカウントへ直接適用し、メール受取は要らない。VIP券とインスタンス優先接続券はオフラインでも購入できる。

## マイページとメール

- マイページには現在アカウントのインスタンス優先接続残回数、VIP区分（なし/DONER/ASTRALDER）、期限と残日数を表示する。特典取得失敗を残回数0やVIPなしと見せない。
- メールパス: `/Mail`。ログイン必須、応答は `no-store`。`GET /api/web/mail` にCookie由来の本人UUIDと現在アカウントIDを渡す。APIの `canClaimCurrency` が真のメールだけWeb受取ボタンを表示する。混在メールでもAPIが通貨部分だけを安全に受け取れる場合に限りボタンを表示し、アイテム部分はゲーム内に残す。受取後は `currencyClaimed` と残りの報酬を表示する。
- 受取POST前にも現在アカウントとAPIの受取可否を再取得する。Anti-forgery、操作ID、二重送信防止を適用する。結果は `GET /api/web/mail/claims/{operationId}` で `COMPLETED`、`PENDING`、`REJECTED` を表示する。

## 管理者一覧

`/Players/Vip` は `WebAdminVisible` 認可を要求し、APIへ本人UUIDを渡す。一般ユーザーにはメニューのリンクを表示しない。APIも管理者権限を再検査する。
