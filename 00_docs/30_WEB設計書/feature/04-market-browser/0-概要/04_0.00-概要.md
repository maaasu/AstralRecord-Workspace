# 04_0.00 概要

## 目的

`/Market` はログイン済みユーザー向けの参照専用マーケット画面である。公開中の `ACTIVE` 出品を、既存 API の読取 endpoint だけで一覧・詳細表示する。

## データ取得

- `GET /api/market/listings?status=ACTIVE&page={n}&page_size=100` を終端ページ（100件未満）まで順に取得する。現行契約に総数はないため、途中ページが100件の場合は次ページも取得する。
- 出品に含まれる各 `itemId` に対し `GET /api/item/{itemId}` を取得し、名前、レアリティ、装備スロット、必要レベル、基礎 stat を補完する。
- item metadata が得られない場合も、出品レスポンスの `itemCategory` と `itemId` を表示して出品を除外しない。

## 参照専用の制約

- 購入と出品のボタンは「現在未公開」と表示した disabled button であり、フォーム、Page Model、API client に POST 操作を持たない。
- ページは `[Authorize]` を要求する。未ログイン利用者は既存の認証 challenge に従う。

検索候補は現在の絞り込みと独立した全ACTIVE出品から作り、カテゴリ・価格を切り替えても他候補を失わない。全条件を取得データへ適用する。出品時valuationの数値は検索だけでなくアイテム詳細にも表示する。Web購入・出品は無効で、ページから更新APIへ接続しない。

アイコンはスキルツリーと同じ同梱PNGを優先し、未収録のみ既存CDNへフォールバックする。共通 `minecraft-icons.mjs` でMaterial名の検証・取得・キャッシュを行う。
