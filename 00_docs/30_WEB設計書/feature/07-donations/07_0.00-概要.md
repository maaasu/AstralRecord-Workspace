# 寄付申請・Discord連携

## 画面と権限

- `/Donations` はログイン必須。本人の申請履歴と承認済み累計金額、Discord連携状況を表示する。メニューとマイページから遷移する。
- `/Donations/Discord` のPOSTでDiscord OAuth2を開始し、同ページのGETでcallbackを処理する。公式サーバー参加確認済みの連携がある場合に申請フォームを表示する。
- `/Admin/Donations` と `/Admin/Donations/Detail/{id}` は既存 `WebAdminOnly` ポリシーにより、管理権限と本人確認を毎回確認する。APIでも管理権限を確認する。
- 一覧は20件単位。一般ユーザーは本人分、管理者は全ユーザー分を確認する。番号・送金URLは一覧に表示せず、管理者の詳細ページにだけ表示する。

## 申請

明細はAmazonギフトカード番号または `https://pay.paypay.ne.jp/` の送金URLから選択し、1〜10件を追加・削除できる。明細ごとの申告金額と合計申告金額を入力し、合計一致・500〜1,000,000円・規約への同意を検証する。1,000,000円は入力・配布処理の上限として設ける。`operationId` をフォームに保持し、再送時にも同じIDをAPIへ渡す。APIがユーザー単位で未完了2件の制限とDiscord公式サーバーへの参加を再検証する。

状態はPending（申請中）、Reviewing（確認中）、Approved（承認）、Rejected（否認）、Cancelled（取消）。本人による取消しはPendingのみ。管理者が確認開始した後に受領を確認して承認する。承認額の入力欄は任意で、完全な空欄だけ申告金額へフォールバックする。入力ありの場合は1〜1,000,000円の整数のみ。承認フォームは実受領額の確認チェックを必要とする。否認は受領前のみ行い、1〜1,000文字の理由を必須とする。

受領済みの承認額が500円未満の場合は実額配布と次回500円以上の警告をAPIが処理する。未受領の500円未満は原則否認する。金額の相違と結果はWeb履歴に表示する。

## 配布・規約

寄付は見返りを約束しない任意の支援である旨と、現在の運用では承認額1円につきアストラルド(有償)1個を各アカウントへ配布する基準を併記する。ゲーム内メールで手動受取、オンライン時の即時通知、未受取添付の無期限保管、通貨・購入品のアカウント間移動不可を案内する。最低額、実受領額での処理、受領後の利用者都合の返金不可（法令上必要な場合を除く）を規約へ記載する。

ManagementDBに寄付履歴・累計・配布記録を保持する。ゲーム初期化後も新規アカウントに累計分を配布し、同じアカウントの復元で重複配布しない。ManagementDBも初期化した場合は完全リセット。規約同意版は `2026-09-26`。

## Discordと機密情報

Discord OAuth2 authorization codeフローに `identify guilds.members.read` を要求する。stateとPKCE verifierはData Protectionで保護したSecure・HttpOnly・SameSite=Laxの `__Host-AstralRecordDiscord` Cookieに、ログインユーザーUUIDと10分の期限を含めて保存する。callbackでUUID/state/期限を検証してCookieを削除する。redirect URIは構成から固定し、要求のHostから組み立てない。Discordの本人・公式サーバー所属確認とtoken暗号化保存はAPIで行う。自動DM送信は行わない。

Webは独自の永続DBを持たない。APIキーに加えて `X-Donation-Web-Key` を付け、ユーザーUUIDは認証Cookieのclaimからのみ取得する。POSTはRazor PagesのCSRF保護を使用する。寄付画面はno-store、詳細とcallbackはno-referrer。ギフト番号、送金URL、OAuth token、APIキーをログへ出力しない。秘密を含むリクエスト本文やcallback queryを、リバースプロキシ・APMのログにも収集しないこと。

## 配置設定

Webへ次の環境変数を設定する。秘密値はリポジトリに保存しない。

| 環境変数 | 用途 |
|---|---|
| `Donations__WebKey` | API側と一致する寄付専用共有キー |
| `Donations__DiscordClientId` | Discord Application Client ID |
| `Donations__DiscordClientSecret` | Discord Application Client Secret |
| `Donations__DiscordRedirectUri` | Discordへ登録した `https://<公開ホスト>/Donations/Discord` |

APIにも同じClient ID/Secret、WebKeyと、公式サーバーの `Donations__DiscordGuildId` を設定する。Discord Developer Portalでcallbackの完全一致登録と必要scopeを確認する。Discord未設定なら連携を開始せず、画面で運営への問い合わせを案内する。Data Protection鍵を既存Web認証と同様に永続化する。

公式契約参照: https://docs.discord.com/developers/topics/oauth2
