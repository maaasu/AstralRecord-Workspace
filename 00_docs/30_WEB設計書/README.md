# 30_WEB設計書

AstralRecord Web (`30_web/AstralRecordWeb`) の画面、認証、画面遷移を管理する設計書です。

## feature 一覧

| feature | 内容 |
|---|---|
| `feature/01-web-auth` | Minecraft で発行したコードを使用する Web ログイン、ログアウト、マイページ、プロフィール公開・検索 |
| `feature/02-release-note` | Markdownリリースノートの一覧・詳細表示とAPI同期 |
| `feature/04-market-browser` | ログイン限定の出品閲覧と取得データ由来の詳細検索 |
| `feature/05-network-management` | WebAdmin専用サーバー設定・MCID指定の管理ロール・ユーザーBAN |
| `feature/06-player-activity` | WebAdmin専用の同IP関連・トレード・ダンジョン攻略・モブによるプレイヤー撃破履歴 |
| `feature/07-donations` | Discord本人連携・公式サーバー参加確認、寄付申請・本人履歴、管理者の受領確認と承認・否認 |
| `feature/08-paid-services` | 有償アストラルドショップ、現在アカウントの特典・メール確認、通貨報酬のWeb受取 |
| `feature/09-player-admin-edit` | WebAdmin専用のプレイヤー保存退避とinventory/class/level訂正 |
| `feature/10-defense-management` | WebAdmin専用の防衛戦設定・即時開始・停止・状態と履歴 |

API 契約は `00_docs/20_API設計書`、DB 定義は `00_docs/40_Database設計書` を正として参照します。

## 独立した管理Web

[AstralRecordControl 設計書](AstralRecordControl/README.md) は、管理Webと各PCのAgent/RunnerによるMinecraft運用管理の採用済み・未実装設計です。Devを開発PC、チャンネルをMC用PCに配置し、Craftyに依存しません。既存AstralRecordWebとは別アプリ・別認証として、通信、保存モデル、運用、段階別の実装/受入条件を定義します。

## ホームのサーバー状況

参加情報と同じ `PublicSite:JavaServerAddress` / `JavaServerPort` へJava Edition Server List Pingを送り、公開中・参加人数・定員・最終確認時刻を表示する。接続拒否は閉鎖中、DNS/タイムアウト/不正応答など確認不能は別表示とし人数は「—」。ホーム初期表示でも取得し、表示中は30秒ごとに更新、サーバー側は15秒キャッシュを共有する。接続先はWebの要求パラメーターから変更できない。

ホーム以外ではヘッダーの公式Discord左側にホームリンクを表示する。プレイヤー一覧とマーケットはログイン中のメニューへ配置する。

## 共通の表示テーマ

通常のプレイヤー画面は、ページ固有CSSの後に `player.css` を読み、夜景の見出し背景、明朝の主見出し、深緑のパネル、明るい文字へ統一する。マイページ、プロフィール、プレイヤー一覧、図鑑、スキルツリー、マーケットと取引履歴、ショップ、メール、寄付、ログイン関連、エラー画面が対象。表やフォームの背景は不透明に保ち、アイテムのレアリティやスキル状態を表す色は維持する。

`/Admin/` 配下と `/Players/Vip` は管理画面として `admin.css` を読み込む。分類はRazorのページ経路に基づき、認可の判定とは分離する。背景画像や大きな装飾見出しを使わず、ゴシック体の見出し、明確な入力欄、行間と列間を確保した表を用いる。管理項目は「ネットワーク設定」「アイテム一覧」など機能を直接表す名称にする。

演出の操作はヒーロー右下の小さな丸い停止・再生アイコンにまとめる。見た目は30px、操作領域は44pxを確保し、読み上げ名・ツールチップを状態に応じて更新する。

`wwwroot/css/journal.css` を共通コンポーネントCSSの後、ページ固有CSSの前に読み込む。ホームは既存の飛行船画像を夜景に編集した背景、既存の街の夜景・冒険画像を使い、風景を大きく見せる導入、明るい紹介領域、Discord案内、参加情報の順に表示する。夜景素材の生成方法は `wwwroot/images/NIGHT-ASSETS.md` に記載する。サーバー状態の更新、参加アドレスのコピー、公開フェーズに応じた注意文、認証・認可によるメニュー分岐は維持する。ヘッダーの広い画面には特徴とお知らせへの直接リンクを置き、狭い画面では同じ導線を既存の右側メニューから利用する。未認証時はログインリンクだけを表示し、重複する「未ログイン」ラベルを置かない。画像は画面幅に応じたWebPを読み込み、ヒーロー以外は遅延読み込みする。フッターはワードマーク、サイト種別、折り返し可能なナビゲーションで構成する。

`astral-motion.css` と `astral-motion.js` はホーム・利用規約・プライバシーポリシーの装飾演出を担当する。回転する魔法陣、光、粒子、流星に加え、ホームの風景のパン・ズームとスクロール出現を使う。ヒーローの一時停止ボタンは同じタブのページ遷移後も選択を保持する。`prefers-reduced-motion` が有効なら静止表示とし、非表示タブや画面外の演出は停止する。粒子は描画を最大30fps、画素比を最大1.5に抑え、モバイルでは数を減らす。JavaScriptが無効でも内容と導線は表示する。利用規約・プライバシーポリシーのヒーロー下端は罫線を使わず、背景へグラデーションでつなぐ。

背景には同一オリジンの星雲動画を無音・インライン・ループで夜空へ薄く重ね、広がる光の輪とオーロラ状の光を添える。動画は表示領域に入り、動きを許可している場合だけソースを設定する。初回読込時の画面幅が768px未満なら640×360、それ以外は1280×720の15秒MP4を使い、リサイズ時に再取得しない。一時停止・画面外・非表示タブでは動画も停止し、`prefers-reduced-motion` は動画を隠す。再生拒否・読込失敗時は既存の静止画像を残し、明示的な演出再開まで自動再試行しない。素材の出典・加工内容は `wwwroot/media/README.md`、クレジットはフッターに記載する。
