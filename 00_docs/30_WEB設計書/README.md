# 30_WEB設計書

AstralRecord Web (`30_web/AstralRecordWeb`) の画面、認証、画面遷移を管理する設計書です。

## feature 一覧

| feature | 内容 |
|---|---|
| `feature/01-web-auth` | Minecraft で発行したコードを使用する Web ログイン、ログアウト、マイページ、プロフィール公開・検索 |
| `feature/02-release-note` | Markdownリリースノートの一覧・詳細表示とAPI同期 |
| `feature/04-market-browser` | ログイン限定の出品閲覧と取得データ由来の詳細検索 |
| `feature/05-network-management` | WebAdmin専用サーバー設定・MCID指定の管理ロール・ユーザーBAN |
| `feature/06-player-activity` | WebAdmin専用の同IP関連・トレード・ダンジョン攻略・モブによるプレイヤー撃破履歴 |
| `feature/07-donations` | Discord本人連携・公式サーバー参加確認、寄付申請・本人履歴、管理者の受領確認と承認・否認 |
| `feature/08-paid-services` | 有償アストラルドショップ、現在アカウントの特典・メール確認、通貨報酬のWeb受取 |
| `feature/09-player-admin-edit` | WebAdmin専用のプレイヤー保存退避とinventory/class/level訂正 |
| `feature/10-defense-management` | WebAdmin専用の防衛戦設定・即時開始・停止・状態と履歴 |

API 契約は `00_docs/20_API設計書`、DB 定義は `00_docs/40_Database設計書` を正として参照します。

## 独立した管理Web

[AstralRecordControl 設計書](AstralRecordControl/README.md) は、管理Webと各PCのAgent/RunnerによるMinecraft運用管理の採用済み・未実装設計です。Devを開発PC、チャンネルをMC用PCに配置し、Craftyに依存しません。既存AstralRecordWebとは別アプリ・別認証として、通信、保存モデル、運用、段階別の実装/受入条件を定義します。

## ホームのサーバー状況

参加情報と同じ `PublicSite:JavaServerAddress` / `JavaServerPort` へJava Edition Server List Pingを送り、公開中・参加人数・定員・最終確認時刻を表示する。接続拒否は閉鎖中、DNS/タイムアウト/不正応答など確認不能は別表示とし人数は「—」。ホーム初期表示でも取得し、表示中は30秒ごとに更新、サーバー側は15秒キャッシュを共有する。接続先はWebの要求パラメーターから変更できない。

ヘッダーはワードマークからホームに戻り、画面幅にかかわらずゲーム紹介・お知らせ・ログインまたはマイページ・参加方法へ直接移動できる。ログイン中のみプレイヤーメニューを表示し、図鑑・プレイヤー一覧・マーケット、メール・ショップ・寄付・ログイン設定を用途別に分ける。管理者リンクと寄付申請中の件数は既存の認可条件に従う。利用規約・プライバシーポリシー・公式Discordはフッターに置く。

## 共通の表示テーマ

`wwwroot/css/journal.css` が紙色の本文面、暗い木枠と真鍮色、見出し、ヘッダーとフッターを定義する。参加やログインの主操作には、飛行船の金具をモチーフにした段付きのボタンを使う。リンクは行き先を文言で示す。夜景は、飛行船をホーム・参加案内・規約類に、街をお知らせ・ログイン・フッターなどに使う。お知らせ一覧は日付、バージョン、タイトル、要約を行で並べ、記事へのリンクをタイトルにまとめる。

通常のプレイヤー画面はページ固有CSSの後に `player.css` を読み、写真付きの見出しと紙色の本文面を使う。マイページの主要な行き先はゲーム、受け取り・購入、アカウントに分ける。表やフォームは不透明な面に置き、アイテムのレアリティやスキル状態は色と文言で区別する。

スキルツリーのフレーム・マップ・残高・詳細は濃紺とチャコールを基調とする。金色の操作強調、ポイント種別やスキル状態の色は維持する。編集画面の外側は共通の紙色の本文面とする。

`/Admin/` 配下と `/Players/Vip` は管理画面として `admin.css` を読み込む。分類はRazorのページ経路に基づき、認可の判定とは分離する。本文の操作領域はゴシック体の見出し、明確な入力欄、行間と列間を確保した表を用いる。管理項目は「ネットワーク設定」「アイテム一覧」など機能を直接表す名称にする。

演出の操作はヒーロー右下の小さな丸い停止・再生アイコンにまとめる。見た目は26px、操作領域は44pxを確保し、読み上げ名・ツールチップを状態に応じて更新する。

ホームは `home.css` を読み、飛行船の導入、接続先とサーバー状況、ゲーム紹介、最新のお知らせ、Discord案内、参加方法の順に表示する。接続先はヒーロー直下と参加方法でコピーできる。参加方法はJava版と統合版を切り替え、該当するポートと手順を表示する。Java版で標準以外のポートを使うときは、ポートを付けた入力例を表示する。オープンアルファ中の停止とデータ引き継ぎに関する要点は常に表示し、その他の注意事項は展開して読める。JavaScriptが無効でも接続先・手順・エディション切替を使える。夜景素材の生成方法は `wwwroot/images/NIGHT-ASSETS.md` に記載する。

`astral-motion.css` と `astral-motion.js` はホーム・利用規約・プライバシーポリシーの装飾演出を担当する。回転する魔法陣、光、粒子、流星に加え、ホームの風景をパン・ズームし、紹介写真をスクロールに合わせて表示する。ホームの見出しと参加ボタンは初回表示から操作できる。ヒーローの一時停止ボタンは同じタブのページ遷移後も選択を保持する。`prefers-reduced-motion` が有効なら静止表示とし、非表示タブや画面外の演出は停止する。粒子は描画を最大30fps、画素比を最大1.5に抑え、モバイルでは数を減らす。

背景には同一オリジンの星雲動画を無音・インライン・ループで夜空へ薄く重ね、広がる光の輪とオーロラ状の光を添える。動画は表示領域に入り、動きを許可している場合だけソースを設定する。初回読込時の画面幅が768px未満なら640×360、それ以外は1280×720の15秒MP4を使い、リサイズ時に再取得しない。一時停止・画面外・非表示タブでは動画も停止し、`prefers-reduced-motion` は動画を隠す。再生拒否・読込失敗時は既存の静止画像を残し、明示的な演出再開まで自動再試行しない。素材の出典・加工内容は `wwwroot/media/README.md`、クレジットはフッターに記載する。
