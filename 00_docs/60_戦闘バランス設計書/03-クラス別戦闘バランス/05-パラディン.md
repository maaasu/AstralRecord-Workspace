# パラディンのクラス別戦闘バランス

## 1. クラス概要

| 項目 | 内容 |
| :-- | :-- |
| 親職 | [[02-ソードマン\|ソードマン]] |
| 職系統 | 赤職 |
| 役割 | 防御・タンク・サポート |

## 2. バランス方針

防御性能と敵の攻撃を引き受ける能力を主軸とし、味方を支援できる構成を目標とする。ソードマスターより攻撃成長を低くし、単独の常時DPSでは上回らない。高い瞬間火力は、防御低下、守護消費、ShieldとSUPPORT_POWERを持つ装備、CPの代償を揃えたときだけ得る。

## 3. クラス成長

| 項目 | Lv1補正 | Lvごとの補正 | Lv100のクラス補正 |
|:--|--:|--:|--:|
| MAX_HEALTH | 135 | 8 | 927 |
| MAX_SHIELD | 15 | 0 | 15 |
| VITALITY | 12 | 1.6 | 170.4 |
| DEFENSE / MAGIC_DEFENSE | 12 / 8 | 1.1 / 0.7 | 120.9 / 77.3 |
| STRENGTH / ATTACK | 6 / 8 | 0.8 / 0.8 | 85.2 / 87.2 |

クラス補正は `baseStats + growthPerLevel × (classLevel - 1)`。ソードマスターのSTR/ATTACK成長は各1.2のため、装備・ツリーなしのパラディンは近接攻撃力成長で優位にならない。

## 4. 6 skillと実ダメージ

近接の解決攻撃力は `A = (ATTACK + MELEE_ATTACK) × (1 + STRENGTH / 100)`。通常命中時は、各skillの倍率 `r` を先に掛け、発生元倍率・会心を適用する。その後、対象の全防御と近接防御へ貫通を適用した有効防御 `D` により `F(A,D) = (max(0, 1 - D / (2.5A)))^1.35` を掛け、属性耐性と最終与ダメージ補正を適用する。したがって、防御低下は攻撃倍率の後に効く。防御が攻撃力の2.5倍以上ならHPダメージは0になる。

| skill | Lv1 / 最大Lv | 実ダメージまたは守護式 | 役割 |
|:--|:--|:--|:--|
| アナテマ | 60%・防御-15% → 80%・-25% | `A×r×F(A,D×(1-低下率))` | 最大8体へ6秒の全防御低下。回避では付与しない。 |
| ラストジャッジメント | 100% → 140% | 防御低下対象のみ `A×r×1.6×F(...)` | 断罪枝の長CD追撃。 |
| ヴェスパー | 基礎30 → 50 | `W=基礎+MAX_SHIELD×0.3+SUPPORT_POWER×0.8` | self+同party、LOS内へ8秒のtemporary ward。 |
| セラフィム | 1.12 → 1.20倍 | wardがある受領者の最終与ダメージへ乗算 | ward消失と同時に終了し、再wardで復帰しない。 |
| レクイエム | 50% → 90% | `A×(r+min(2,Wcurrent/100))×F(A,D)` | 対象がいるときだけ自分のcurrent wardを全消費。 |
| ブラックサンクタム | 被ダメ0.65 → 0.55倍 | native Shieldを`MAX_SHIELD×0.15→0.25`回復 | 6秒間、与ダメ0.65倍・ノックバック0・LOS内挑発。 |

攻撃skillのDPSは、各命中対象について上表の実ダメージをクールダウン秒で割った値である。アナテマはLv5でも `0.8A×F/120`、ラストジャッジメントは防御低下成立時だけ `2.24A×F/240` であり、単独回転は低い。レクイエムはLv5で最大 `2.9A×F/300` だが、Wardを消費するため連打できない。複数対象の合計DPSは命中体数を掛けるが、単体ボス比較には用いない。

## 5. 3 buildとCP

共通幹は9CP、各枝は幹39CPとoptional passive 2CP。Lv80の79CPでは「共通9 + 断罪39 + 聖柩31」のように二枝までを選び、Lv100の99CPでも3枝132CPを全取得できない。各status nodeと6つのbind必須passiveはSCALARの利点と不利を併記するため、純粋な上積みだけの同一node連鎖にはしない。タンクシールドアクティベートは枠を使わないが、6 passiveは基礎5枠（statusで最大9枠）のうち1枠を使う。

| build | 主な選択 | 利点 | 代償 |
|:--|:--|:--|:--|
| 断罪 | アナテマ → ラストジャッジメント | 防御の高い対象への限定的な追撃 | DEFENSE、MAGIC_DEFENSEまたはMAX_SHIELDを落とす。 |
| 聖柩 | ヴェスパー → セラフィム | wardを保てるパーティの火力と安定性 | ATTACK、STRまたはATTACK_SPEEDを落とす。 |
| 黒聖域 | レクイエム → ブラックサンクタム | wardを犠牲にした瞬間打撃と危機耐性 | ATTACK、機動、MPまたはskill damageを落とす。 |

ソロの代表連携は `ヴェスパー → レクイエム`。Vesperで自分に作ったwardを、敵が前方cone内にいる時だけRequiemへ変換する。パーティ時はwardを消費するRequiemより、VesperとCovenantを維持する判断を優先する。

## 6. 装備の現状と将来条件

現行でwardを直接大きくするのはMAX_SHIELD装備だけで、`クウィンヤサバトン`（Lv3, Shield+2）、`ファングの盾`（Lv8, Shield+15と強化ごと+2）、`メルコールサバトン`（Lv10, Shield+4）、`始源遺跡の踏破甲`（Lv15, Shield+6）が確認できる。SUPPORT_POWERとShield recharge reductionを持つequipmentは現行filebaseにない。従ってSUPPORT_POWER特化や再充填短縮装備は将来の選択肢であり、現行性能としては扱わない。
