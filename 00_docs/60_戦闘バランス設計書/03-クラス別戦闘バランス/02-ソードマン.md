## 1. クラス概要

| 項目 | 内容 |
| :-- | :-- |
| クラス ID | `swordsman` |
| 役割 | 近接・防御型 |
| レベル上限 | Lv.100 |
| 解放条件 | 冒険者 Lv.10 |

## 2. バランス目標

同じ Player Lv.・同じ更新帯・標準装備で比較する。基準となる最終 HP・解決攻撃力 `R`・有効防御 `D`、TTK、耐久時間は [[../02-成長曲線|成長曲線]]と[[../01-戦闘計算|戦闘計算]]に従う。

| 指標 | ソードマンの方針 |
| :-- | :-- |
| 主力分野 | 近接単体・近接範囲攻撃 |
| 生存 | HP・物理防御を近接戦に必要な範囲で配分する |
| 弱み | 遠距離・魔法の直接 skill は class から許可しない |
| 構成差 | skilltree で追加する近接 skill と防御・反撃系の選択で作る |

## 3. 数値配分

| 方針 | 内容 |
| :-- | :-- |
| 基礎値 | HP・防御・攻撃を高めにする |
| 成長 | HP・攻撃・防御を優先する |
| 正本 | `40_filebase/20.features.class/v1.swordsman.yml` |

具体的な数値は、共通アンカーの130%程度を上限として、class・skilltree・equipment の増加分を **25% / 25% / 50%** の出発点で配分する。正式なステータス値はプレイテストで確定する。

### 現行skilltree基礎幹

現行の基礎幹は27node、各1ソードマンCPです。配分は `STRENGTH` 6、`VITALITY` 5、`ATTACK` 5、`MAX_HEALTH +10` 4、`DEFENSE` 4、`MAGIC_DEFENSE` 2、`AGILITY` 1とし、Class Lv.28の27CPで全取得できます。冒険者4方向の内側anchorから直接伸びる全員向けの幹であり、他職の非表示nodeを中継しません。予約leafのnode `1202` は、1ソードマンCPでシールドドレインの使用許可を与える実skill nodeへ置換済みです。

## 4. Skill / 装備

### class が許可する初期 skill

| ID | skill 名 | 役割 |
| :-- | :-- | :-- |
| `adventurer_astral_edge` | アストラルエッジ | 近接の主力範囲攻撃 |
| `adventurer_smash` | スマッシュ | 近接の単体高倍率攻撃 |

上記2個だけをソードマンの `usableSkills` に定義する。これ以外の skill は class に追加せず、skilltree の `skill` 効果で使用許可を与える。

### 単体・詠唱込み DPS の確認枠

個別 skill は主対象1体、命中100%、会心・防御・アクションリング操作時間なし、詠唱がある場合は `CD + 詠唱時間` を周期として確認する。既存の初期 skill はいずれも **Skill Lv.5** を前提とする。`R` はそのレベル・装備・skilltree構成で解決した値を使う。

| skill | Skill Lv. | 計算式 | DPS |
| :-- | :-- | :-- | :-- |
| アストラルエッジ | 5 | `R × (1.20 + 0.60) ÷ 2.5` | 構成ごとに試算 |
| スマッシュ | 5 | `R × 2.88 ÷ (7.5 + 0.6)` | 構成ごとに試算 |
### シールドドレイン

> [!note] 使用許可の境界
> `swordsman_shield_drain` はソードマンの skilltree node `1202` から使用許可を与え、Administrator の `usableSkills` には検証用許可を残す。ソードマンの `usableSkills` には追加しない。

シールドドレインは前方6mの単体へ基礎倍率65%を与え、Shield換算値と`SHIELD_BREAK`の合計だけを3倍する。実際に削った敵Shieldの50%を自身へ加算し、発動時に自身のShieldが最大なら基礎倍率を追加100%して吸収ではなく攻撃へ寄せる。

| 状態 | Skill Lv. | 1hit倍率 | CD基準DPS | `R=100`の比較値 |
| :-- | --: | --: | :-- | --: |
| Shield非最大 | 1 | 65% | `R × 0.65 ÷ 3.0` | 21.67 |
| Shield最大 | 1 | 130% | `R × 1.30 ÷ 3.0` | 43.33 |
| Shield非最大 | 5 | 78% | `R × 0.78 ÷ 3.0` | 26.00 |
| Shield最大 | 5 | 156% | `R × 1.56 ÷ 3.0` | 52.00 |

> [!info] 数値根拠
> 最大時Lv.5の1hit倍率156%を、標準単体skillのクイックショットLv.5 180%・ライトニングボルトLv.5 174%よりやや低く置く。通常時はHP火力を78%へ抑え、3倍のShield破壊と実消費量50%の耐久回復を主価値にする。DPS表は命中100%、会心・防御・最終倍率・操作時間なし、詠唱0秒、`R=100`の正規化比較であり、Shield吸収はダメージDPSへ加算しない。

### フレイムラッシュ

フレイムラッシュはskilltree node `1204` で解放する、前方最大5体向けの火属性二連撃である。初撃は対象を動かさない横薙ぎ、4 tick後の二撃目は縦斬りとし、Lv.8以降は二撃目だけに炎上判定を持たせる。

| 条件 | Skill Lv. | 横薙ぎ | 縦斬り | CD基準DPS | `R=100`の比較値 |
| :-- | --: | --: | --: | :-- | --: |
| 炎上なし | 1 | 65% | 75% | `R × 1.40 ÷ 4.0` | 35.00 |
| 炎上なし | 10 | 94.25% | 108.75% | `R × 2.03 ÷ 4.0` | 50.75 |
| 炎上期待値込み | 10 | 94.25% | 108.75% | `R × (2.03 + 0.20 × 4 × 0.35) ÷ 4.0` | 57.75 |

> [!info] 数値根拠
> Lv.2～10は各Lvで `SKILL_DAMAGE_INCREASE +5%` を積み、Lv.10の直接倍率合計を203%にする。炎上は35%・100 tick・20 tick間隔で、付与20 tick後から期限前までの4回を期待値へ換算しても、アストラルエッジLv.5の単体CD基準DPS `R × 0.72` を下回る。範囲上限5体と炎上は、近接を維持して集団へ使う価値に限定する。
