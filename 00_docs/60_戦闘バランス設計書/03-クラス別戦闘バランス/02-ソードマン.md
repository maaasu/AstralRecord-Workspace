## 1. クラス概要

| 項目 | 内容 |
| :-- | :-- |
| クラス ID | `swordsman` |
| 役割 | 近接・防御型 |
| レベル上限 | Lv.100 |
| 解放条件 | 冒険者 Lv.10 |

## 2. バランス目標

同じ Player Lv.・同じ更新帯・標準装備で比較する。基準となる最終 HP・解決攻撃力 `R`・有効防御 `D`、TTK、耐久時間は [[../02-成長曲線|成長曲線]]と[[../01-戦闘計算|戦闘計算]]に従う。

| 指標 | ソードマンの方針 |
| :-- | :-- |
| 主力分野 | 近接単体・近接範囲攻撃 |
| 生存 | HP・物理防御を近接戦に必要な範囲で配分する |
| 弱み | 遠距離・魔法の直接 skill は class から許可しない |
| 構成差 | skilltree で追加する近接 skill と防御・反撃系の選択で作る |

## 3. 数値配分

| 方針 | 内容 |
| :-- | :-- |
| 基礎値 | HP・防御・攻撃を高めにする |
| 成長 | HP・攻撃・防御を優先する |
| 正本 | `40_filebase/20.features.class/v1.swordsman.yml` |

具体的な数値は、共通アンカーの130%程度を上限として、class・skilltree・equipment の増加分を **25% / 25% / 50%** の出発点で配分する。正式なステータス値はプレイテストで確定する。

### 現行skilltree基礎幹

現行の基礎幹は27node、各1ソードマンCPです。配分は `STRENGTH` 6、`VITALITY` 5、`ATTACK` 5、`MAX_HEALTH +10` 4、`DEFENSE` 4、`MAGIC_DEFENSE` 2、`AGILITY` 1とし、Class Lv.28の27CPで全取得できます。冒険者4方向の内側anchorから直接伸びる全員向けの幹であり、他職の非表示nodeを中継しません。予約leafのnode `1202` は、1ソードマンCPでブレードカウンターの使用許可を与える実skill nodeへ置換済みです。

## 4. Skill / 装備

### class が許可する初期 skill

| ID | skill 名 | 役割 |
| :-- | :-- | :-- |
| `adventurer_astral_edge` | アストラルエッジ | 近接の主力範囲攻撃 |
| `adventurer_smash` | スマッシュ | 近接の単体高倍率攻撃 |

上記2個だけをソードマンの `usableSkills` に定義する。これ以外の skill は class に追加せず、skilltree の `skill` 効果で使用許可を与える。

### 単体・詠唱込み DPS の確認枠

個別 skill は主対象1体、命中100%、会心・防御・アクションリング操作時間なし、詠唱がある場合は `CD + 詠唱時間` を周期として確認する。既存の初期 skill はいずれも **Skill Lv.5** を前提とする。`R` はそのレベル・装備・skilltree構成で解決した値を使う。

| skill | Skill Lv. | 計算式 | DPS |
| :-- | :-- | :-- | :-- |
| アストラルエッジ | 5 | `R × (1.20 + 0.60) ÷ 2.5` | 構成ごとに試算 |
| スマッシュ | 5 | `R × 2.88 ÷ (7.5 + 0.6)` | 構成ごとに試算 |
| ブレードカウンター | 1 | `R × 1.00 × 3 ÷ (30 + 1)` | `約0.0968R`（3反撃成立時） |
| ブレードカウンター | 5 | `R × 1.00 × 5 ÷ (30 + 1)` | `約0.1613R`（5反撃成立時） |

> [!note] 反撃DPSの読み方
> ブレードカウンターは敵の攻撃回数に依存するため、表は20秒のバフ中に全反撃が成立した理論上限です。通常攻撃を止めずに受付を作れる一方、敵が攻撃しない時間、10 tick受付の失敗、対象消失ではDPSになりません。通常攻撃やほかの攻撃skillへ単純加算せず、実戦ローテーションで成立回数を記録します。

### ブレードカウンターの耐久性能

管理対象Mobの `NORMAL_ATTACK` / `SKILL` による直接hitだけを50%へ軽減し、condition DoT、環境damage、PvPは軽減しません。1バフあたりの軽減可能hitはLv.1で3回、Lv.5で5回です。

| Skill Lv. | 最大反撃回数 | 全受付成功時に防ぐdamage | 反撃総倍率 |
| :-- | --: | :-- | :-- |
| 1 | 3 | 対象3hitの合計damageの50% | `R × 3.00` |
| 5 | 5 | 対象5hitの合計damageの50% | `R × 5.00` |

> [!warning] 耐久試験の受入条件
> 同格Mobの直接攻撃間隔を固定し、受付成功率0%・50%・100%で「軽減前damage」「軽減後damage」「反撃成立回数」「通常攻撃を失った回数」を記録します。Lv.1の理論上限は3hit、Lv.5は5hitであり、20秒間の全被弾を常時半減する効果として評価しません。
