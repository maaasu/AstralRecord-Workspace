## 1. クラス概要

| 項目 | 内容 |
| :-- | :-- |
| クラス ID | `swordsman` |
| 役割 | 近接・防御型 |
| レベル上限 | Lv.100 |
| 解放条件 | 冒険者 Lv.10 |

## 2. バランス目標

同じ Player Lv.・同じ更新帯・標準装備で比較する。基準となる最終 HP・解決攻撃力 `R`・有効防御 `D`、TTK、耐久時間は [[../02-成長曲線|成長曲線]]と[[../01-戦闘計算|戦闘計算]]に従う。

| 指標 | ソードマンの方針 |
| :-- | :-- |
| 主力分野 | 近接単体・近接範囲攻撃 |
| 生存 | HP・物理防御を近接戦に必要な範囲で配分する |
| 弱み | 遠距離・魔法の直接 skill は class から許可しない |
| 構成差 | skilltree で追加する近接 skill と防御・反撃系の選択で作る |

## 3. 数値配分

| 方針 | 内容 |
| :-- | :-- |
| 基礎値 | HP・防御・攻撃を高めにする |
| 成長 | HP・攻撃・防御を優先する |
| 正本 | `40_filebase/20.features.class/v1.swordsman.yml` |

具体的な数値は、共通アンカーの130%程度を上限として、class・skilltree・equipment の増加分を **25% / 25% / 50%** の出発点で配分する。正式なステータス値はプレイテストで確定する。

### 現行skilltree基礎幹

現行の基礎幹は27node、各1ソードマンCPです。配分は `STRENGTH` 5、`VITALITY` 6、`ATTACK` 6、`MAX_HEALTH +10` 2、`DEFENSE` 5、`MAGIC_DEFENSE` 2、`AGILITY` 1、`ENERGY_REGEN` 1とし、Class Lv.28の27CPで全取得できます。`ENERGY_REGEN +1` は防御寄りの `1126` に付与し、基礎値5に対して毎秒回復量を0.2増やす初期検証値とします。各方向の主軸を残しつつ、途中に攻撃・耐久・リソースの副軸を混ぜ、単一方向へ伸ばしても複数の基礎能力を得られる構成にします。冒険者4方向の内側anchorから直接伸びる全員向けの幹であり、他職の非表示nodeを中継しません。

### 現行skilltree専門円環

基礎幹の中間から、通常会心、超星会心、Shield容量、Shield再充填の4円環を分岐します。各円環は1CPの小node4個と2CPのnotable1個で構成し、1円環6CP、合計24CPです。基礎幹27CP、専門円環24CP、skill解放5CPをすべて取得する場合は合計56ソードマンCPを消費します。

| 円環 | 小node合計 | notable | 円環の全取得合計 |
| :-- | :-- | :-- | :-- |
| 通常会心 | `CRITICAL_RATE +2` | `CRITICAL_RATE +3 / CRITICAL_DAMAGE +10` | 会心率+5pt、会心倍率+10pt |
| 超星会心 | `SUPER_CRITICAL_RATE +2` | `SUPER_CRITICAL_RATE +2 / SUPER_CRITICAL_DAMAGE +10` | 超星会心率+4pt、超星会心倍率+10pt |
| Shield容量 | `MAX_SHIELD +8` | `MAX_SHIELD +12 / DEFENSE +2` | 最大Shield+20、防御+2 |
| Shield再充填 | `SHIELD_RECHARGE_REDUCTION +10` | `SHIELD_RECHARGE_REDUCTION +10 / MAX_SHIELD +5` | 再充填短縮+20pt、最大Shield+5 |

通常会心率、超星会心率、会心倍率、超星会心倍率、再充填短縮は `FLAT` のパーセントポイント加算です。超星会心は通常会心と独立判定され、成立時に主撃と7個の追尾弾を生成するため、+4ptの実戦影響はプレイテストで確認します。Shield再充填短縮+20ptは、破壊後30秒を24秒、再充填パッシブの8秒を6.4秒にし、敵から受ける追加待機にも同じ比率を適用します。

追加skillのnode `1202` / `1203` / `1204` / `1211` / `1352` は、各1ソードマンCPで使用許可を与えます。skill nodeはnotableの先端に置かず、フレイムラッシュを通常会心、バスティオンストライクとラストシールドをShield容量、シールドリチャージとシールドアクティベートをShield再充填の小node途中から独立分岐します。シールドアクティベートはShield獲得の入口です。

## 4. Skill / 装備

### class が許可する初期 skill

| ID | skill 名 | 役割 |
| :-- | :-- | :-- |
| `adventurer_astral_edge` | アストラルエッジ | 近接の主力範囲攻撃 |
| `adventurer_smash` | スマッシュ | 近接の単体高倍率攻撃 |
| `swordsman_challenging_roar` | チャレンジングロア | 周囲の敵を一時挑発するタンク基礎行動 |
| `swordsman_shield_drain` | シールドドレイン | 敵Shieldを削り、自身のShieldを吸収回復する近接攻撃 |

上記4個をソードマンの `usableSkills` に定義する。これ以外の skill は class に追加せず、skilltree の `skill` 効果で使用許可を与える。

### 単体・詠唱込み DPS の確認枠

個別 skill は主対象1体、命中100%、会心・防御・アクションリング操作時間なし、詠唱がある場合は `CD + 詠唱時間` を周期として確認する。既存の初期 skill はいずれも **Skill Lv.5** を前提とする。`R` はそのレベル・装備・skilltree構成で解決した値を使う。

| skill | Skill Lv. | 計算式 | DPS |
| :-- | :-- | :-- | :-- |
| アストラルエッジ | 5 | `R × (1.44 + 0.72) ÷ 2.5` | 構成ごとに試算 |
| スマッシュ | 5 | `R × 4.32 ÷ (7.5 + 0.6)` | 構成ごとに試算 |

### チャレンジングロア

チャレンジングロアは半径8m・上下8m、遮蔽のない敵を最大24体まで1秒ごとに一時挑発する。挑発中は通常の脅威値と現在ターゲット維持より発動者を優先し、脅威値自体は変更しない。EN 25、cooldown 20秒、詠唱なしとし、持続はLv.1の4秒から1レベルごとに1秒増加してLv.5で8秒とする。

ダメージを持たないためDPSへは加算しない。ソードマンの標準配布スキルとして、集団戦でタンクが敵を引き受ける入口をクラス取得直後から保証する。複数の挑発が同じ敵へ重なった場合は後発を優先し、終了・退出・死亡・world変更後は通常の脅威選定へ戻す。

### シールドドレイン

> [!note] 使用許可の境界
> `swordsman_shield_drain` はソードマンの `usableSkills` から初期使用許可を与え、Administrator の `usableSkills` には検証用許可を残す。skilltree には配置しない。

シールドドレインは前方6mの単体へ基礎倍率97.5%を与え、Shield換算値と`SHIELD_BREAK`の合計だけを3倍する。実際に削った敵Shieldの50%を自身へ加算し、実際に回復した場合だけ対象から発動者への吸収演出を表示する。自身のShieldが最大でもダメージ倍率は変化しない。

| Skill Lv. | 1hit倍率 | CD基準DPS | `R=100`の比較値 |
| --: | --: | :-- | --: |
| 1 | 97.5% | `R × 0.975 ÷ 3.0` | 32.50 |
| 5 | 117% | `R × 1.17 ÷ 3.0` | 39.00 |

> [!info] 数値根拠
> Lv.5の1hit倍率は117%とし、3倍のShield破壊と実消費量50%の耐久回復を主価値にする。DPS表は命中100%、会心・防御・最終倍率・操作時間なし、詠唱0秒、`R=100`の正規化比較であり、Shield吸収はダメージDPSへ加算しない。

### シールドリチャージ

> [!note] 使用許可の境界
> `administrator_shield_recharge` はソードマンの skilltree node `1202` から使用許可を与え、Administrator の `usableSkills` には検証用許可を残す。ソードマンの `usableSkills` には追加しない。Shieldの獲得には別途 `swordsman_shield_activate` の使用許可とパッシブ設定が必要である。

シールドリチャージは最大Shieldを30増加し、シールド残存時の被弾後8秒から最大Shieldの毎秒2%を再充填する防御パッシブである。ただしシールドアクティベートが有効でない限り、最大Shield補正があってもShieldは獲得・再充填しない。再充填中に被弾すると待機をやり直し、シールド破壊時は通常の30秒後一括回復仕様に従う。バインド必須で、ダメージを与えないためDPS算出対象外とする。

### シールドアクティベート

シールドアクティベートは、ソードマンのShield獲得を許可するバインド必須パッシブである。使用許可とパッシブ設定の両方が有効な場合だけ、最大Shieldを実際に使用でき、初期化・明示回復・シールドドレイン・バスティオンストライク・通常／段階リチャージによる現在Shieldの増加を許可する。未設定または未許可の場合は現在Shieldを0として扱い、既存の最大Shield候補は表示・計算上の上限候補として残す。セッション中に有効化した場合は即時満タンにせず、通常30秒の再充填を開始する。直接発動操作は持たない。

### フレイムラッシュ

フレイムラッシュはskilltree node `1204` で解放する、前方最大5体向けの火属性二連撃である。初撃は対象を動かさない横薙ぎ、4 tick後の二撃目は縦斬りとし、二撃目の炎上率はLv.1〜7が0%、Lv.8/9/10が35%/40%/45%である。

| 条件 | Skill Lv. | 横薙ぎ | 縦斬り | CD基準DPS | `R=100`の比較値 |
| :-- | --: | --: | --: | :-- | --: |
| 炎上なし | 1 | 78% | 90% | `R × 1.68 ÷ 4.0` | 42.00 |
| 炎上なし | 10 | 113.1% | 130.5% | `R × 2.436 ÷ 4.0` | 60.90 |
| 炎上期待値込み | 10 | 113.1% | 130.5% | `R × (2.436 + 0.20 × 4 × 0.45) ÷ 4.0` | 69.90 |

> [!info] 数値根拠
> Lv.2～10は各Lvで `SKILL_DAMAGE_INCREASE +5%` を積み、Lv.10の直接倍率合計を243.6%にする。炎上はLv.1〜7が0%、Lv.8/9/10が35%/40%/45%・100 tick・20 tick間隔で、付与20 tick後から期限前までの4回を期待値へ換算しても、アストラルエッジLv.5の単体CD基準DPS `R × 0.864` を下回る。範囲上限5体と炎上は、近接を維持して集団へ使う価値に限定する。
### ラストシールド

> [!note] 使用許可の境界
> `swordsman_last_shield` はソードマンのskilltree node `1211` とAdministratorの `usableSkills` から使用許可を与える。ソードマンの `usableSkills` には追加しない。

ラストシールドは、シールドを破壊する通常攻撃または発動スキルを1回だけ無効化するバインド必須パッシブである。無効化時はシールド・HP・装備耐久を消費せず、状態異常DoTと環境ダメージは対象外とする。120秒のクールダウンを持ち、ダメージを与えないためDPS算出対象外である。

> [!info] 数値根拠
> ソードマンのShield容量円環から分岐する1CPの追加skillとして置き、長い120秒クールダウンにより継続的な無敵ではなく、シールド破壊が生む大きな被弾を一度だけ防ぐ緊急防御として扱う。

### バスティオンストライク

> [!note] 使用許可の境界
> `swordsman_bastion_strike` はソードマンの skilltree node `1203` から使用許可を与え、Administrator の `usableSkills` には検証用許可を残す。ソードマンの `usableSkills` には追加しない。

バスティオンストライクは前方6m・全角40度の最寄りMob 1体へ無属性の近接ダメージを与える。Lv.1〜4は現在MPが最大MPと一致するときだけ、Lv.5は最大MPの80%以上のときだけ発動できる。成功時は現在MPをすべて消費し、シールドアクティベートが有効な場合だけ、対象の有無や命中結果にかかわらず自身の現在Shieldを最大Shieldまで即時回復する。回復阻害中、最大Shieldが0、またはシールドアクティベートが無効の場合、ダメージは成立してもShieldは回復しない。シジル枠は全レベル0とする。

| Skill Lv. | 1hit倍率 | CD基準DPS | `R=100`の比較値 |
| --: | --: | :-- | --: |
| 1 | 187.5% | `R × 1.875 ÷ 150.0` | 1.25 |
| 5 | 225% | `R × 2.25 ÷ 110.0` | 2.05 |

> [!info] 数値根拠
> 自己Shield全回復と最大MPに近い現在MPの全量消費を主価値とし、Lv.1の150秒からレベルごとに10秒短縮してLv.5を110秒とする。シジルによる短縮は許可せず、長い再使用時間とMP条件により継続火力ではなく緊急の防壁再建へ役割を限定する。DPS表は命中100%、会心・防御・最終倍率・操作時間なし、詠唱0秒、`R=100`の正規化比較であり、Shield回復量はダメージDPSへ加算しない。
