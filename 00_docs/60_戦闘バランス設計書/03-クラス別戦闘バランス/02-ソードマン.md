## 1. クラス概要

| 項目 | 内容 |
| :-- | :-- |
| クラス ID | `swordsman` |
| 役割 | 近接・防御型 |
| レベル上限 | Lv.100 |
| 解放条件 | 冒険者 Lv.10 |

## 2. バランス目標

同じ Player Lv.・同じ更新帯・標準装備で比較する。基準となる最終 HP・解決攻撃力 `R`・有効防御 `D`、TTK、耐久時間は [[../02-成長曲線|成長曲線]]と[[../01-戦闘計算|戦闘計算]]に従う。

| 指標 | ソードマンの方針 |
| :-- | :-- |
| 主力分野 | 近接単体・近接範囲攻撃 |
| 生存 | HP・物理防御を近接戦に必要な範囲で配分する |
| 弱み | 遠距離・魔法の直接 skill は class から許可しない |
| 構成差 | skilltree で追加する近接 skill と防御・反撃系の選択で作る |

## 3. 数値配分

| 方針 | 内容 |
| :-- | :-- |
| 基礎値 | HP・防御・攻撃を高めにする |
| 成長 | HP・攻撃・防御を優先する |
| 正本 | `40_filebase/20.features.class/v1.swordsman.yml` |

具体的な数値は、共通アンカーの130%程度を上限として、class・skilltree・equipment の増加分を **25% / 25% / 50%** の出発点で配分する。正式なステータス値はプレイテストで確定する。

### 現行skilltree基礎幹

現行の基礎幹は27node、各1ソードマンCPです。配分は `STRENGTH` 5、`VITALITY` 6、`ATTACK` 6、`MAX_HEALTH +10` 2、`DEFENSE` 5、`MAGIC_DEFENSE` 2、`AGILITY` 1、`ENERGY_REGEN` 1とし、Class Lv.28の27CPで全取得できます。`ENERGY_REGEN +1` は防御寄りの `1126` に付与し、基礎値5に対して毎秒回復量を0.2増やす初期検証値とします。各方向の主軸を残しつつ、途中に攻撃・耐久・リソースの副軸を混ぜ、単一方向へ伸ばしても複数の基礎能力を得られる構成にします。冒険者4方向の内側anchorから直接伸びる全員向けの幹であり、他職の非表示nodeを中継しません。

### 現行skilltree専門円環

基礎幹の中間から、通常会心、超星会心、Shield容量、Shield再充填、破盾疾走の5円環を分岐します。各円環は1CPの小node4個と2CPのnotable1個で構成し、1円環6CP、合計30CPです。基礎幹27CP、専門円環30CP、skill解放6CPをすべて取得する場合は合計63ソードマンCPを消費します。

| 円環 | 小node合計 | notable | 円環の全取得合計 |
| :-- | :-- | :-- | :-- |
| 通常会心 | `CRITICAL_RATE +2` | `CRITICAL_RATE +3 / CRITICAL_DAMAGE +10` | 会心率+5pt、会心倍率+10pt |
| 超星会心 | `SUPER_CRITICAL_RATE +2` | `SUPER_CRITICAL_RATE +2 / SUPER_CRITICAL_DAMAGE +10` | 超星会心率+4pt、超星会心倍率+10pt |
| Shield容量 | `MAX_SHIELD +8` | `MAX_SHIELD +12 / DEFENSE +2` | 最大Shield+20、防御+2 |
| Shield再充填 | `SHIELD_RECHARGE_REDUCTION +10` | `SHIELD_RECHARGE_REDUCTION +10 / MAX_SHIELD +5` | 再充填短縮+20pt、最大Shield+5 |
| 破盾疾走 | `SHIELD_BREAK +4 / ATTACK_SPEED +4` | `SHIELD_BREAK +4 / ATTACK_SPEED +4` | シールドブレイク+8、攻撃速度+8 |

通常会心率、超星会心率、会心倍率、超星会心倍率、再充填短縮は `FLAT` のパーセントポイント加算です。超星会心は通常会心と独立判定され、成立時に主撃と7個の追尾弾を生成するため、+4ptの実戦影響はプレイテストで確認します。Shield再充填短縮+20ptは、破壊後30秒を24秒、再充填パッシブの8秒を6.4秒にし、敵から受ける追加待機にも同じ比率を適用します。

追加skillのnode `1202` / `1203` / `1204` / `1352` / `1361` は、各1ソードマンCPで使用許可を与えます。skill nodeはnotableの先端に置かず、フレイムラッシュとエクゼプトスタンプを通常会心、バスティオンストライク・シールドドレインをShield容量、シールドリチャージをShield再充填の小node途中から独立分岐します。エクゼプトスタンプは通常会心円環の小node `1217` から分岐します。タンクシールドアクティベートはソードマンの `usableSkills` から使用許可を与え、スキルツリーには配置しません。

## 4. Skill / 装備

### class が許可する初期 skill

| ID | skill 名 | 役割 |
| :-- | :-- | :-- |
| `adventurer_astral_edge` | アストラルエッジ | 近接の主力範囲攻撃 |
| `adventurer_smash` | スマッシュ | 近接の単体高倍率攻撃 |
| `swordsman_challenging_roar` | チャレンジングロア | 周囲の敵を一時挑発するタンク基礎行動 |
| `swordsman_shield_activate` | タンクシールドアクティベート | タンクのShield獲得を常時有効化する防御パッシブ |

上記4個をソードマンの `usableSkills` に定義する。これ以外の skill は class に追加せず、skilltree の `skill` 効果で使用許可を与える。

アストラルエッジは冒険者定義を引き継ぐ二段近接skillで、消費はMP 8とする。薙ぎ払いと4 tick後の突き刺しは独立した命中判定で、回避されずHPまたはShieldへ適用された各命中が最大ENGをLv.1で5%、レベルごとに2%ずつ回復する。Lv.5の回復率は13%であり、回復量はDPSへ加算しない。

### 単体・詠唱込み DPS の確認枠

個別 skill は主対象1体、命中100%、会心・防御・アクションリング操作時間なし、詠唱がある場合は `CD + 詠唱時間` を周期として確認する。既存の初期 skill はいずれも **Skill Lv.5** を前提とする。`R` はそのレベル・装備・skilltree構成で解決した値を使う。

| skill | Skill Lv. | 計算式 | DPS |
| :-- | :-- | :-- | :-- |
| アストラルエッジ | 5 | `R × (1.44 + 0.72) ÷ 2.5` | 構成ごとに試算 |
| スマッシュ | 5 | `R × 4.32 ÷ (7.5 + 0.6)` | 構成ごとに試算 |

### チャレンジングロア

チャレンジングロアは半径8m・上下8m、遮蔽のない敵を最大24体まで1秒ごとに一時挑発する。挑発中は通常の脅威値と現在ターゲット維持より発動者を優先し、脅威値自体は変更しない。ENG 25、cooldown 20秒、詠唱なしとし、持続はLv.1の4秒から1レベルごとに1秒増加してLv.5で8秒とする。

ダメージを持たないためDPSへは加算しない。ソードマンの標準配布スキルとして、集団戦でタンクが敵を引き受ける入口をクラス取得直後から保証する。複数の挑発が同じ敵へ重なった場合は後発を優先し、終了・退出・死亡・world変更後は通常の脅威選定へ戻す。

### シールドドレイン

> [!note] 使用許可の境界
> `swordsman_shield_drain` はソードマンの skilltree node `1352` から使用許可を与え、Administrator の `usableSkills` には検証用許可を残す。ソードマンの `usableSkills` には追加しない。

シールドドレインは前方8m・全角110度の遮蔽のないMobを距離順に最大8体まで選ぶ扇形範囲近接スキルである。各対象へ基礎倍率97.5%を与え、Shield換算値と`SHIELD_BREAK`の合計だけを3倍する。消費はMP10とする。各対象で実際に削った敵Shieldの50%を自身へ加算し、実際に回復した対象がある場合だけ、対象ごとの起点から発動者へ向かう吸収演出を表示する。自身のShieldが最大でもダメージ倍率は変化しない。

扇形の輪郭は発動者の手元を起点に、全角110度・射程8mの円弧を半径2m・4m・6m・8mへ青白い粒子で表示し、対象Shieldを実際に削った対象には破片粒子を表示する。対象ごとの吸収量が実際に自身へ反映された場合だけ、各対象から発動者へ4 tickで流れる粒子と到達時のShieldリング・効果音を表示する。

| Skill Lv. | 1hit倍率 | CD基準DPS | `R=100`の比較値 |
| --: | --: | :-- | --: |
| 1 | 97.5% | `R × 0.975 ÷ 3.0` | 32.50 |
| 5 | 117% | `R × 1.17 ÷ 3.0` | 39.00 |

上表のDPSは1体へ命中した場合のCD基準値であり、最大8体時の範囲総量は対象数と各対象の防御・Shield残量に応じて変動するため含めない。

> [!info] 数値根拠
> Lv.5の1hit倍率は117%とし、3倍のShield破壊と実消費量50%の耐久回復を主価値にする。DPS表は命中100%、会心・防御・最終倍率・操作時間なし、詠唱0秒、`R=100`の正規化比較であり、Shield吸収はダメージDPSへ加算しない。

### シールドリチャージ

> [!note] 使用許可の境界
> `administrator_shield_recharge` はソードマンの skilltree node `1202` から使用許可を与え、Administrator の `usableSkills` には検証用許可を残す。ソードマンの `usableSkills` には追加しない。Shieldの獲得には別途 `swordsman_shield_activate` の習得と使用許可が必要である。

シールドリチャージは最大Shieldを30増加し、シールド残存時の被弾後8秒から最大Shieldの毎秒2%を再充填する防御パッシブである。ただしタンクシールドアクティベートが有効でない限り、最大Shield補正があってもShieldは獲得・再充填しない。再充填中に被弾すると待機をやり直し、シールド破壊時は通常の30秒後一括回復仕様に従う。バインド必須で、ダメージを与えないためDPS算出対象外とする。

### タンクシールドアクティベート

タンクシールドアクティベートは、ソードマンのShield獲得を許可する非バインドパッシブである。習得済み個体と使用許可が有効な場合だけ、最大Shieldを実際に使用でき、初期化・明示回復・シールドドレイン・バスティオンストライク・通常／段階リチャージによる現在Shieldの増加を許可する。パッシブスロットへの設定は要求しない。未習得または未許可の場合は現在Shieldを0として扱い、既存の最大Shield候補は表示・計算上の上限候補として残す。セッション中に有効化した場合は即時満タンにせず、通常30秒の再充填を開始する。直接発動操作は持たない。

### フレイムラッシュ

フレイムラッシュはskilltree node `1204` で解放する、前方最大5体向けの火属性二連撃である。初撃は対象を動かさない横薙ぎ、4 tick後の二撃目は縦斬りとし、二撃目の炎上率はLv.1〜7が0%、Lv.8/9/10が35%/40%/45%である。

| 条件 | Skill Lv. | 横薙ぎ | 縦斬り | CD基準DPS | `R=100`の比較値 |
| :-- | --: | --: | --: | :-- | --: |
| 炎上なし | 1 | 78% | 90% | `R × 1.68 ÷ 4.0` | 42.00 |
| 炎上なし | 10 | 113.1% | 130.5% | `R × 2.436 ÷ 4.0` | 60.90 |
| 炎上期待値込み | 10 | 113.1% | 130.5% | `R × (2.436 + 0.20 × 4 × 0.45) ÷ 4.0` | 69.90 |

> [!info] 数値根拠
> Lv.2～10は各Lvで `SKILL_DAMAGE_INCREASE +5%` を積み、Lv.10の直接倍率合計を243.6%にする。炎上はLv.1〜7が0%、Lv.8/9/10が35%/40%/45%・100 tick・20 tick間隔で、付与20 tick後から期限前までの4回を期待値へ換算しても、アストラルエッジLv.5の単体CD基準DPS `R × 0.864` を下回る。範囲上限5体と炎上は、近接を維持して集団へ使う価値に限定する。
### エクゼプトスタンプ

> [!note] 使用許可の境界
> `swordsman_exept_stamp` はソードマンの skilltree node `1361` から使用許可を与え、Administrator の `usableSkills` には検証用許可を残す。ソードマンの `usableSkills` には追加しない。

エクゼプトスタンプは、水平前方velocity 1.30・上方向velocity 1.05で前方斜め上へ勢いよく飛び上がり、空中でスニーク入力を行ったときだけ急降下して着地点を攻撃する無属性近接範囲スキルである。着地までに空中スニーク入力がなければ攻撃を行わない。消費はENERGY20、cooldownは160tick（8秒）、詠唱なし、最大Lv.5とする。発動時のタイトル本文は空欄、subtitleは黄色の「スニークで急降下」とする。

| Skill Lv. | 着地半径 | ダメージ倍率 | 移動速度減少 | 減少時間 | CD基準DPS（単体） |
| --: | --: | --: | --: | --: | --: |
| 1 | 1m | 110% | -10 | 5秒 | `R × 1.10 ÷ 8.0`（13.75） |
| 2 | 2m | 120% | -20 | 5秒 | `R × 1.20 ÷ 8.0`（15.00） |
| 3 | 3m | 130% | -30 | 5秒 | `R × 1.30 ÷ 8.0`（16.25） |
| 4 | 4m | 140% | -40 | 5秒 | `R × 1.40 ÷ 8.0`（17.50） |
| 5 | 5m | 150% | -50 | 5秒 | `R × 1.50 ÷ 8.0`（18.75） |

飛翔中のスニーク開始時に強い下方向velocityを適用し、着地時に半径内の遮蔽のないMobへ近接攻撃を1回行う。実際にブロックは壊さず、着地点の地面材質を使った大量のブロック破片、crit、茶色のdustを重ねて着地を表示する。スニーク開始時と着地時に効果音を再生する。命中してHPまたはShieldへ実ダメージが適用された敵だけ、移動速度をスキルレベル×10だけ減少させる一時効果を5秒付与する。

> [!info] 数値根拠
> ユーザー指定の「半径=スキルレベルm」「100 + スキルレベル×10%」「5秒」「移動速度-10×スキルレベル」をLv.1〜5の基礎値・レベル差分へ展開した。ENERGY20、最大Lv.5、飛翔velocity、particle点数は初期バランス値として置き、プレイテストで確定する。単体CD基準DPSは操作時間・飛翔時間・会心・防御・最終倍率を含めず、範囲攻撃と5秒の移動速度減少を主な追加価値として評価する。

### バスティオンストライク

> [!note] 使用許可の境界
> `swordsman_bastion_strike` はソードマンの skilltree node `1203` から使用許可を与え、Administrator の `usableSkills` には検証用許可を残す。ソードマンの `usableSkills` には追加しない。

バスティオンストライクは、シールドを破壊する通常攻撃または発動スキルを受けたとき、プレイヤーの視点ラインに触れる半径6m以内の最寄りMob 1体へ無属性の近接反撃を行うバインド必須パッシブである。Lv.1〜4は現在MPが最大MPと一致するときだけ、Lv.5は最大MPの80%以上のときだけ反撃を試みる。MP不足、対象なし、反撃の回避・0ダメージ、またはクールダウン中は反撃せず、MPも消費しない。反撃が命中した場合だけ現在MPを全量消費し、受けた攻撃を無効化して不足Shieldを最大Shieldまで回復する。状態異常DoTと環境ダメージは対象外とし、シジル枠は全レベル0とする。

| Skill Lv. | 反撃倍率 | cooldown | 通常DPS |
| --: | --: | --: | :-- |
| 1 | 187.5% | 150秒 | 被弾時のみのため算出対象外 |
| 5 | 225% | 110秒 | 被弾時のみのため算出対象外 |

> [!info] 数値根拠
> 反撃倍率は既存値を維持し、Lv.1の150秒からレベルごとに10秒短縮してLv.5を110秒とする。シジルによる短縮は許可せず、シールド破壊を防ぐ反撃とShield再建を主価値にするため、通常の攻撃DPSには加算しない。反撃が成立した場合だけ、既存のShield回復阻害・上限・シールドアクティベート規則を適用する。

## 5. 検証
