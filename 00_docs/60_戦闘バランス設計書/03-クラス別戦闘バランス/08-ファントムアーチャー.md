# ファントムアーチャーのクラス別戦闘バランス

## 弓と幻影をつなぐ戦闘方針

親職は [[03-ハンター|ハンター]]。自分の弓と設置した幻影弓で同じ敵へ「霊印」を刻み、貫通矢でまとめて砕く。連射中の追い照準、設置弓との十字射線、後退からの幻影追撃を選び、[[07-シャープシューター|シャープシューター]]の通常射撃への継承バフとは別の手順で弓を使い込む。

従来は「専用攻撃は共有ファントムショットの単体火力を超えない」という制約を置いていた。専用5攻撃をすべてCDごとに全弾命中させても、Lv10で約3.3673 R/秒に留まり、共有ショット単独3.5 R/秒より低かった。今回の改訂ではこの制約を廃止し、専用技を組み合わせること自体に火力上の価値を持たせる。共有ショットとシャープシューターのマスタは変更しない。

> [!info] 戦闘規則
> 専用攻撃は `AttackType.RANGED` / `DamageElement.NONE`。管理対象MobへのPvE攻撃で、既存の地形遮蔽・回避・Shield・耐性計算を使う。闇属性、PvP、通常ドッジの無敵時間は追加しない。霊印は状態異常ではなく発動者別の専用状態。

通常弓は装備タグから `normal_attack_bow` / `normal_attack_shortbow` / `normal_attack_longbow` を実行する独自攻撃で、弓の引き絞り量は使わない。新しい大弓の準備時間はエクリプスショット内部の有限タスクで表現する。

## 霊印とコンボ

- 同じ発動者・同じMobの霊印は最大3層。最後の付与から120tick（6秒）で全層失効する。他プレイヤーの印を消費しない。
- ステッチ・ブルーム・セントリー・エコーは、回避されずHPまたはShieldへ正のダメージを与えたとき1層を刻む。
- スペクトラルアチューンメントのバインド中は、弓・短弓・長弓の通常攻撃も有効命中ごとに1層を刻む。印付与自体に追加リソース消費はない。
- ピアース・エクリプスは命中直前の自分の層数を使って倍率を加算する。同じ攻撃が有効命中した場合だけ、その対象の印を全層消費する。回避・無効化では消費しない。
- 印の付与と破裂を粒子で示す。印が残る敵の頭上へ、層数と同じ数の青緑の菱形を所有者だけに表示する。3層では淡色の外輪を加える。5tick間隔で敵の移動に追従し、消費・6秒の失効・敵の消滅・所有者の終了時に描画を停止する。表示距離は48m以内、1回の点数は最大48点で、共有の粒子設定を尊重する。セントリー設置中に通常射撃やエコーで素早く3層へ進め、ピアースを使い、長い射線にはエクリプスを合わせる。

> [!tip] 主な判断
> **刻む**：低コストの通常弓、衰弱付きステッチ、追い照準のエコー。**射線を作る**：セントリー設置とリトリート。**砕く**：回転の速いピアースか、準備時間を持つ大弓。ピアース直後にエクリプスを撃つと印が残っていないため、間に印を刻み直す。

## 専用アクティブスキル

専用アクティブは弓・短弓・長弓の装備を必要とする。倍率は間接攻撃の解決攻撃力 `R` に対する値。最大Lv10、共通の詠唱時間は0。MPは副消費、ENGは主消費。ノード・装備・パッシブの軽減前。

| スキル | Lv1 → Lv10 | 射程・範囲 | 基礎CD | ENG / MP | node |
|:--|:--|:--|--:|--:|:--|
| シャドウステッチ | 260% → 440%、衰弱70% → 88%、5秒、印+1 | 20m、1体 | 4秒 | 14 / 6 | `2424` |
| ソウルピアース | 基礎280% → 460%、印1層+65% → +110%、衰弱/盲目中は全体×1.40 → ×1.49 | 24m、最大4体貫通 | 5秒 | 21 / 12 | `2425` |
| ドレッドブルーム | 220% → 364%、盲目60% → 78%、4秒、印+1 | 20m、着弾半径3.5m、最大6体 | 7秒 | 22 / 14 | `2426` |
| スペクトラルセントリー | 1射115% → 205%、12tick間隔の8射撃枠、命中ごと印+1 | 設置16m、幻影から射程16m | 10秒 | 24 / 18 | `2427` |
| エコーボレー | 1射130% → 265%、4tick間隔で5射、命中ごと印+1 | 22m、1射につき最大3体貫通 | 5秒 | 24 / 15 | `2428` |
| ミストリトリート | 後退1.4、回避率×1.40 → ×1.76、3秒 | 自分 | 7秒 | 18 / 8 | `2429` |
| エクリプスショット | 基礎600% → 960%、印1層+120% → +192% | 28m、最大6体貫通、内部準備16tick | 10秒 | 30 / 24 | `2540` |

衰弱・盲目の付与率は基礎確率へ既存の攻撃側補正と対象耐性を適用する。`WEAKNESS_APPLY_CHANCE +15` は15ポイント加算ではなく、他補正なしなら基礎確率×1.15。ピアースの弱体特効は両方の状態があっても1回だけで、状態異常を消費しない。

ピアースの倍率は `(基礎 + 印の層数 × (印倍率 + 有効なカースの加算)) × 弱体特効`。エクリプスは `基礎 + 印の層数 × 印倍率` で、カース加算・弱体特効を持たない。印の加算にも、その攻撃の通常のスキル威力・防御等の計算が適用される。

セントリーは1人1体。弓の中心までの3D距離を設置射程内に収め、地表候補が射程外なら遮蔽確認済みの視線終点へ浮かべる。各射撃枠で設置地点から見える近距離のMobを狙い、対象不在の枠は消費する。再設置は旧発動を閉じ、旧幻影の表示・タスクと既発射弾の攻撃を無効化する。エコーは各射で現在の位置・照準を使い、敵を追って照準を動かせる。各矢は地形で止まる。

エクリプスは発動直後から消費・CDが始まり、16tick後の現在位置・照準から発射する。準備中も移動・照準変更が可能で、通常詠唱とは異なる。主手の持ち替え、死亡、転職等で中断しても消費・CDを返還しない。準備中は拡大する霊弓を示し、発射時の大きな弓・矢尻と着弾の破裂で段階を区別する。

## 専用パッシブスキル

3種とも既存ID・既存取得ノード・最大Lv1を維持し、固有executorへ変更する。習得に加えてパッシブ枠へのバインドが必要。既存のステータス補正を残したうえで、弓のコンボへ固有効果を足す。

| スキル | 既存補正と新しい弓の役割 | node |
|:--|:--|:--|
| カースウィービング | 衰弱・盲目付与率各+15%、状態異常持続+10%。ピアースの霊印1層の加算倍率へ+25%。エクリプスには適用しない | `2430` |
| スペクトラルアチューンメント | CD短縮+5%、MP消費軽減+8%。弓・短弓・長弓の通常攻撃の有効命中で印+1 | `2431` |
| レイスステップ | 回避率+5ポイント、ENG消費軽減+8%。リトリート後退成功後6秒以内の次の直射に、基礎倍率60%の幻影矢を1本追加 | `2432` |

レイスの対象はステッチ・ピアース・エクリプス。準備は1回分で再付与しても重ならず、発射元の基礎 `damageRatio` だけを参照する。印加算や弱体特効を複製せず、追加矢から印の付与・消費を行わない。後退できなかった場合は準備しない。

| 残す技能の役割 | 固有パッシブとの接続・変化しない部分の理由 |
|:--|:--|
| ステッチ：単体の始動と衰弱 | カースで付与・持続を伸ばし、レイスで一射を二重化。連射より低コストで弱体を準備する |
| ピアース：回転の速い印消費 | カースの印加算と弱体特効、レイスの追撃。通常弓の印が直接火力へつながる |
| ブルーム：群れへの始動 | カースの盲目補正と複数対象への印。レイスの対象外なのは、直射の二重化とは異なる範囲付与の役割を持たせるため |
| セントリー：設置地点から印を継続供給 | アチューンメントの回転・MP補正。レイスで設置数や射撃回数を増やさず、1人1体の配置判断を維持する |
| エコー：追い照準と急速な印蓄積 | アチューンメントの回転・MP補正。レイスの対象外とし、連射中の追撃増殖を避けて次の直射へ準備を残す |
| リトリート：射線を離して立て直す | レイスで次射の幻影矢を用意。印を増やさず、敵に当てる行動と位置取りを分ける |
| エクリプス：準備時間を払う長射程の一撃 | 通常弓の印とレイスの大きな追撃を利用。カースの追加破裂と弱体特効はピアースの強みとして残す |

シャープシューターの継承の心得はこの職業の固有ツリーへ追加しない。ファントム専用技は霊印・幻影弓・レイスで相互作用し、共有ショットの通常攻撃継承を複製しない。

印、準備、遅延射撃、設置弓は所有者単位に管理し、終了・死亡・ワールド移動・転職・成功したマスタ再読込・Plugin停止で後始末する。通常射撃の印はパッシブの現在の有効状態を確認する。追加矢を起点に再帰的な追加射撃を発生させない。

成立した主手のスロット変更・手の交換は、弓同士でも旧射撃と印を終了する。投棄は主手が空になる場合だけ解除し、弓を維持したまま別の素材を捨てる操作では消去しない。キャンセルされたリング入力や持ち替えイベントでは解除しない。敵への有効命中と地形衝突で固有の着弾演出・音を出し、射程切れへ命中音を重ねない。

## DPSとリソースの設計検算

単体・全段命中・会心/防御/耐性/消費軽減なしの `倍率合計 ÷ CD秒`。範囲の別対象を足さず、セントリーの空射・飛翔・移動・操作・resource枯渇を含まない。印3層の値は**各消費前に蓄積できた場合の上限**で、ピアースとエクリプスに同じ印を二重計上しない。

| スキル | Lv1 DPS / R | Lv10 DPS / R | 条件 |
|:--|--:|--:|:--|
| ステッチ | 0.6500 | 1.1000 | 単体1命中 |
| ピアース・印なし | 0.5600 | 0.9200 | 弱体なし |
| ピアース・3層 | 0.9500 | 1.5800 | 弱体なし、カースなし |
| ピアース・3層＋カース＋弱体 | 1.5400 | 2.5777 | 条件が全て維持された上限 |
| ブルーム | 0.3143 | 0.5200 | 範囲内1体だけを集計 |
| セントリー | 0.9200 | 1.6400 | 8射撃枠すべて同じ敵へ命中 |
| エコー | 1.3000 | 2.6500 | 5射とも同じ敵へ命中 |
| エクリプス・印なし / 3層 | 0.6000 / 0.9600 | 0.9600 / 1.5360 | 発動から着弾は別に16tick＋飛翔。CDは発動時開始 |
| リトリート | 0 | 0 | レイス追加矢は次の直射に依存するため別扱い |

> [!example] 通常弓を挟む専用3技の定常モデル（実測ではない）
> セントリー10秒周期、エコー5秒周期、ピアース5秒周期。先にセントリーとエコー・通常弓で印を作り、3層を見てピアースを撃つ。カース有効・弱体なしなら専用3技の上限はLv1で `0.92 + 1.30 + (2.8 + 3×0.90)/5 = 3.32 R/秒`、Lv10で `1.64 + 2.65 + (4.6 + 3×1.35)/5 = 6.02 R/秒`。通常攻撃や他スキルの分はこの数値に含めない。
> 印供給はエコー5命中/5秒とセントリー8命中/10秒で最大1.8層/秒、ピアース消費は3層/5秒で0.6層/秒。ただし供給のタイミング・3層上限・対象変更で余剰を失う。平均供給量だけで毎回3層を保証しない。各消費前に命中を確認して使う。
> 同じ3技の定常消費はENG11.4/秒、MP7.2/秒。スペクトラルアチューンメントのCD短縮とMP軽減を両方反映するとENG12.0/秒・MP約6.97/秒。さらにレイスを有効にすればENG11.04/秒。最大値や自然回復を超える場合は通常射撃へ戻す。無制限の連打を前提にしない。

[[../02-成長曲線]]のLv15アンカー `R=767`、敵防御767、HP4400、最終倍率1.3、命中0.92、会心なしを使うと、1.0 R/秒あたり期待ダメージ458.666。上のLv1モデルに通常攻撃1回/秒、1スキル操作で通常攻撃0.8回を失う仮定を加えると、係数は `3.32 + 1 - 0.8×(1/10+1/5+1/5) = 3.92`、約1798DPS、TTK約2.45秒。ただし3層と設置弓全弾の維持を仮定した定常換算で、開幕の印準備と有限HPへの過剰ダメージを含まず、実戦TTKの予測値として扱わない。既存の約6秒級という試算より強くなるため、同格敵・ボスの双方で実戦調整が必要。

シャープシューターと比較する際は、両職へ同じ共有ファントムショットを含め、通常攻撃の武器共有CD・劣化・継承の50%補正・追加2射・散開の実命中数を計測する。両職の基礎攻撃系クラス成長は同じだが、継承バフ・ツリー・resource回復の条件は違う。この資料の単体スキル値だけで「両職の実戦DPSが同じ」とは判断しない。

## 演出と取得経路

弓の弧・弦・矢尻を紫と青緑で描き、発射の螺旋、刻んだ層数、破裂の輪を区別する。ブルームは花弁状の放射、セントリーは敵へ向く弓と発射反応、エコーは各射の弓形、リトリートは後退前の幻影を示す。共有の表示サービスで閲覧者設定を尊重し、同期の点群を一括送信する。持続物とタスクは有限時間で破棄する。

既存9専用skillのノードを維持し、エクリプスショットの独立leafを追加する。専用10skillと共有7skillの計17skill、status120node、合計137node。新しいskillを除く既存配置・接続・CPを変えない。新規skillは既存と同じ初級スキルジェム原石3個で習得、強化ごとにも3個。使用許可と所持は別で、ツリー解放だけでは自動習得しない。ショップや一般転職の公開範囲は変更しない。

スキーマと日本語フォームの追加paramsは `40_filebase/30.features.skill/docs.skill.YAMLスキーマ定義.md` を正本とし、ローカル編集サイトが動的に読む。APIのMap転送形式とResource Packには新しい契約を要求しない。

> [!warning] 実測が必要な範囲
> 実クライアントの視認性、射線上の実命中率、操作時間、長期資源収支、シャープシューターとの同装備DPS・TTKは未確認。コード・マスタ・理論計算の検証と分けて扱う。

## スキルブック：スターウィーバー

[[07-シャープシューター#スキルブック：スターウィーバー|共用ブックの性能と演出]]を正本とする。`20a00084` を装備し、`archer_starweave_followup` をバインドすると、弓通常射撃の有効命中から六秒に一回、同じ敵一体へ0.3秒後の無属性間接追矢を放つ。基礎倍率はLv1の80%からLv5の120%。発生時に自分の霊印が残れば+40%で、合計120%から160%。30m以内、追加消費なし。Lv15/UNCOMMON/progression 1で、不死鳥のブックより前の段階に置く。習得は初級原石8個、強化ごと3個。

通常射撃への霊印付与を先に解決してから追矢の強化条件を判定するため、スペクトラルアチューンメントをバインドした通常命中は、その射撃で刻んだ印も利用できる。セントリー・エコー・ステッチ・ブルームが刻んだ自分の印も参照する。印を消費しないので、ピアース・エクリプスへ印を残したまま通常弓の小さな追撃を足せる。一方、追矢から印を増やさず、レイス準備も消費せず、設置弓や五連射を起点に追加矢を発生させない。

単体全命中の定常追加はLv1で基礎 `0.1333 R/秒`、霊印条件下 `0.2000 R/秒`、Lv5で基礎 `0.2000 R/秒`、条件下 `0.2667 R/秒`。専用三技のLv1定常上限 `3.32 R/秒` に対して霊印条件下で約6.0%、専用技Lv10とbook Lv5の `6.02 R/秒` に対して約4.4%の追加に留める。この比較は通常攻撃の火力を分母に含めず、実際の戦闘での上昇率を保証しない。bookのバインド枠を使うため、固有パッシブとの枠配分も選択になる。

> [!info] 追矢の終了条件
> 飛翔中にbook・バインド・現職の使用許可を再確認し、無効化と持ち替え・死亡・世界移動・マスタ公開・challenge終了では追撃を中止する。元通常矢の射出世代も照合し、旧武器・旧職業・旧公開世代の命中から追矢を再開しない。中断は再使用待機を返還しない。追矢から継承・霊印・他bookを再発動しない。視認性・音と実戦のDPS/TTKは未確認。
