# ファントムアーチャーのクラス別戦闘バランス

## 1. クラス概要

| 項目 | 内容 |
| :-- | :-- |
| 親職 | [[03-ハンター\|ハンター]] |
| 職系統 | 緑職 |
| 役割 | 属性攻撃・デバフ |

## 2. バランス方針

属性攻撃とデバフによる継続的な弱体化を主軸とし、敵の状態に応じて有利な攻撃を選ぶ構成を目標とする。

## 3. スキルツリー方針

ファントムアーチャーの専門領域は24CPの共通領域から、役割の異なる48CPの2系統へ分岐する。共通領域を含む各系統の全取得は72CPとし、両系統の全取得には120CPを必要とする。

| 系統 | 戦闘方針 | 主なステータス |
|:--|:--|:--|
| Shadow | 敵へマークに相当する弱体を重ね、まとまった対象への攻撃機会を作る | 衰弱・盲目付与、状態異常持続、スキルダメージ、間接防御貫通、会心 |
| Specter | 幻影の召喚と再展開を想定し、スキル回転と継続運用を伸ばす | クールダウン短縮、スキルダメージ、MP / ENG効率、器用さ・知力、移動・回避 |

> [!note]
> 現段階の専門枝はstatus nodeだけを定義する。共用回復skillのヒールアローα用に未配置node `2256`、ファントムショット用に未配置node `2259` をそれぞれ定義する。マーク処理、範囲攻撃、幻影召喚のskill masterとPlugin実装は含めず、存在しないskill IDも参照しない。

ノードID、個別効果量、配置とedgeは [[../../50_Filebase設計書/feature/35-skilltree|Skilltree 設計]] および `40_filebase/35.features.skilltree` を正本とする。

## 4. Skill / 装備

シャープシューターとファントムアーチャーの共用機動skillとして、`archer_air_shift`（エアーシフト）をクラスの `usableSkills` から配布する。パッシブスロットへのバインドは不要だが、使用には初級スキルジェム3個を消費してLv.1を習得する必要がある。最大Lvは1で、レベルアップは行わない。

エアーシフトは空中でスニークを押した瞬間に発動し、視線基準の前後左右入力を合成した方向へ水平1.45・上向き0.25のvelocityを設定する。方向入力がない場合は視線の後方へ移動する。通常ドッジと同じENG 15を消費する。クールダウンは設けないが、一度発動すると着地するまで再発動できない。ジャスト回避が有効なら通常ドッジと同じ判定を開始し、発動時には風圧音と空中移動パーティクルを再生する。攻撃・回復を行わないためDPSは0とする。

ヒールアローαはシャープシューターと共用する回復skillで、クラス別の未配置node `2256` から使用許可を得る。ヒールアローと同じ弾道・半径2m・3秒の回復エリアを持ち、各エリアで対象を1回だけ最大HPの `3.5% × skill level` 回復する。Lv.1は3.5%、Lv.10は35%。敵命中時の36%間接ダメージ、クールダウン8秒、ENG28と副MP12の消費を持つ。発動者には3秒間 `HEALING_INCREASE +1` の同名バフを付与し、その間に受ける後続のHP回復へ最大HPの20%を毎回加える。α自身の発動者への回復には加えない。単体理論DPSは36%間接攻撃が1対象へ1回命中する前提で `0.36R ÷ 8秒 = 0.045R/秒` とし、回復量はDPSに含めない。

ファントムショットはシャープシューターとの共用skillで、初回・5tick後・10tick後に広い判定半径1.1mの弾を放つ。各弾の無属性間接攻撃倍率は `150% + 20% × skill level`、Lv.1は170%、Lv.10は350%。3発全命中時の基礎倍率を3秒のクールダウンで平均すると、理論DPSは間接攻撃力の170%～350%/秒となる。主ENG20と副MP16を消費し、詠唱なし、初級スキルジェムは習得・各レベルアップに3個ずつ使う。Lv.10に限り2秒以内の再命中ごとに最大MPとENGを各10%回復する。継承バフ保有中は基礎クールダウン6秒。継承の心得が有効なら149秒の継承バフ連撃Ⅰを得て、通常攻撃1回ごと30秒を消費し、5tick後・10tick後に通常攻撃を追加する。追加分は通常攻撃列化に含めない。ファントムアーチャー専用の解放node `2259` を定義し、構造には配置しない。
