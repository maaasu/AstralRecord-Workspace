# ファントムアーチャーのクラス別戦闘バランス

## 1. クラス概要

| 項目 | 内容 |
| :-- | :-- |
| 親職 | [[03-ハンター\|ハンター]] |
| 職系統 | 緑職 |
| 役割 | 属性攻撃・デバフ |

## 2. バランス方針

属性攻撃とデバフによる継続的な弱体化を主軸とし、敵の状態に応じて有利な攻撃を選ぶ構成を目標とする。

## 3. スキルツリー方針

ファントムアーチャーの専門領域は24CPの共通領域から、役割の異なる48CPの2系統へ分岐する。共通領域を含む各系統の全取得は72CPとし、両系統の全取得には120CPを必要とする。

| 系統 | 戦闘方針 | 主なステータス |
|:--|:--|:--|
| Shadow | 敵へマークに相当する弱体を重ね、まとまった対象への攻撃機会を作る | 衰弱・盲目付与、状態異常持続、スキルダメージ、間接防御貫通、会心 |
| Specter | 幻影の召喚と再展開を想定し、スキル回転と継続運用を伸ばす | クールダウン短縮、スキルダメージ、MP / ENG効率、器用さ・知力、移動・回避 |

> [!note]
> 現段階のスキルツリーはstatus nodeだけを定義する。マーク処理、範囲攻撃、幻影召喚のskill masterとPlugin実装は含めず、存在しないskill IDも参照しない。

ノードID、個別効果量、配置とedgeは [[../../50_Filebase設計書/feature/35-skilltree|Skilltree 設計]] および `40_filebase/35.features.skilltree` を正本とする。

## 4. Skill / 装備

シャープシューターとファントムアーチャーの共用機動skillとして、`hunter_air_shift`（エアーシフト）をクラスの `usableSkills` から配布する。パッシブスロットへのバインドは不要だが、使用には初級スキルジェム3個を消費してLv.1を習得する必要がある。最大Lvは1で、レベルアップは行わない。

エアーシフトは空中でスニークを押した瞬間に発動し、視線基準の前後左右入力を合成した方向へ水平1.45・上向き0.25のvelocityを設定する。方向入力がない場合は視線の後方へ移動する。通常ドッジと同じENG 15を消費し、クールダウンは設けない。ジャスト回避が有効なら通常ドッジと同じ判定を開始し、発動時には風圧音と空中移動パーティクルを再生する。攻撃・回復を行わないためDPSは0とする。
