# シャープシューターのクラス別戦闘バランス

## 1. クラス概要

| 項目 | 内容 |
| :-- | :-- |
| 親職 | [[03-ハンター\|ハンター]] |
| 職系統 | 緑職 |
| 役割 | 通常攻撃・継承バフ・精密射撃・属性制御・散開連射 |

## 2. バランス方針

通常攻撃へ技を継承する弓職として、射線を揃える貫通、火氷の状態連携、散らばった敵への跳弾、遅延凍結による足止めを選ぶ。スキルの総数を他職と揃えることは目標にしない。

既存のファイアアロー・アイスアロー・拡散する野望・ファントムショットに加え、専用の追加4技も通常攻撃へ固有効果を継承する。継承バフを持つだけで倍率が増える単体射撃を増やさず、直接発動と通常弓の双方で技の特徴を使い分ける。

## 4. 「継承の心得」と継承バフ

根本パッシブskillとして `sharpshooter_inheritance_mastery`（継承の心得）を持つ。スキルツリーから使用許可を得て、初級スキルジェム1個でLv.1を習得し、パッシブスロットへバインドしている間だけ有効とする。このパッシブは通常攻撃倍率を50%低下させる代わりに、保有する継承バフの効果を通常攻撃で発揮できるようにする。継承によって発動するスキルのダメージ倍率も元スキルの50%とし、シールド破壊倍率、超星会心率、範囲、対象数などの非ダメージ性能は元スキルを維持する。最大Lvは1とし、レベルアップは行わない。

継承バフは、対応するskillの発動によって一定の残り時間を得る。同名のバフを再度得た場合は重複させず、残り時間を新しい付与時間へ再設定する。

プレイヤーが通常攻撃1回を発動した時点でバフが残っていれば、残り時間が1回分の消費時間に満たなくても効果を発揮する。効果発揮後に、各バフの残り時間を1回ずつ消費する。不足する場合は残り時間をすべて消費してバフが消滅する。

継承バフの効果発揮時に消費するリソース種別と量は、継承の心得のパラメータに継承バフごとに定義する。対応する定義がない継承バフはリソースを消費しない。通常攻撃1回によって使用した各継承バフの時間と対応リソースは1回ずつ消費し、継承効果が発生させた追加攻撃では追加消費しない。複数の継承バフは併用でき、各バフの効果、残り時間、リソース消費は個別に処理する。同じ通常攻撃で複数効果を処理する順序は継承の心得の `params.inheritanceBuffs` 記載順とし、先行効果の消費後にリソース不足となった後続効果は消費・発動せず保持する。

追加4技の継承バフは149秒で、通常攻撃が管理対象MobのHPまたはShieldへ有効命中した場合だけ30秒分を消費する。最後の30秒未満も1回分として発動する。回避、無効ダメージ、地形着弾では消費しない。通常攻撃で敵を倒した場合も着弾位置を連鎖・範囲の起点にできる。

元スキルの解決済み倍率へ心得の `inheritedSkillDamageMultiplier=0.5` を掛け、元スキルのリソースを再消費する。残量不足ならバフとリソースを両方保持する。継承から継承バフを再付与しない。同一バフは再使用で更新し、複数バフは心得マスタの記載順に個別処理する。付与時間には既存のバフ持続補正が適用される。

## 5. Skill / 装備

シャープシューターとファントムアーチャーの共用機動skillとして、`archer_air_shift`（エアーシフト）をクラスの `usableSkills` から配布する。パッシブスロットへのバインドは不要だが、使用には初級スキルジェム3個を消費してLv.1を習得する必要がある。最大Lvは1で、レベルアップは行わない。

エアーシフトは空中でスニークを押した瞬間に発動し、視線基準の前後左右入力を合成した方向へ水平1.45・上向き0.25のvelocityを設定する。方向入力がない場合は視線の後方へ移動する。通常ドッジと同じENG 15を消費する。クールダウンは設けないが、一度発動すると着地するまで再発動できない。ジャスト回避が有効なら通常ドッジと同じ判定を開始し、発動時には風圧音と空中移動パーティクルを再生する。攻撃・回復を行わないためDPSは0とする。

ヒールアローαはファントムアーチャーと共用する回復skillで、クラス別のnode `2255` から使用許可を得る。ヒールアローと同じ弾道・半径2m・3秒の回復エリアを持ち、各エリアで対象を1回だけ最大HPの `3.5% × skill level` 回復する。Lv.1は3.5%、Lv.10は35%。敵命中時の36%間接ダメージ、クールダウン8秒、ENG28と副MP12の消費を持つ。発動者には3秒間 `HEALING_INCREASE +1` の同名バフを付与し、その間に受ける後続のHP回復へ最大HPの20%を毎回加える。α自身の発動者への回復には加えない。単体理論DPSは36%間接攻撃が1対象へ1回命中する前提で `0.36R ÷ 8秒 = 0.045R/秒` とし、回復量はDPSに含めない。

ホライゾンブレイカーは直線貫通を通常弓へ継承する。継承元の発動時の向きではなく、通常弓の着弾時の進行方向へ続く射線を用いる。

ファイアアローとアイスアローは、射程16mを毎tick 1.6mで直進する重力なし・非貫通の高速矢とし、判定半径は0.6mとする。両skillの基礎倍率は `105% + 10% × skill level` で、Lv.1は115%、Lv.10は205%。クールダウンは5秒、主消費はMP 30、ENG消費は0とする。習得と各レベルアップには初級スキルジェム2個を消費する。ファイアアローは24.5%で5秒炎上、アイスアローは50%で2秒凍結を付与する。炎矢は炎粒子、氷矢は水色粒子と小型の氷BlockDisplayで飛翔位置を示す。

継承の心得が有効な間にファイアアローまたはアイスアローを発動すると、対応する「継承バフ火属性Ⅰ」「継承バフ氷属性Ⅰ」を149秒付与する。通常攻撃が最初に敵または地形へ着弾するごとに、残り時間を30秒分消費し、追加MPは消費しない。残り時間が30秒未満でも効果を発揮し、残り時間をすべて消費してバフが消滅する。敵へ有効ダメージを与えた場合、火は25%で炎上、氷は50%で凍結を判定する。継承属性のダメージ増加は通常攻撃の基礎ダメージへ属性ごとに個別加算する。基礎100、火属性増加10%、氷属性増加10%なら `100 + 10 + 10 = 120` とし、属性間で基礎値を分配しない。火・氷の加算分には対応する属性耐性と属性貫通を適用し、元の通常攻撃成分は維持する。

「継承の心得」が有効な間にアローレイン、ブラストアロー、クラッシュアローのいずれかを発動すると、対応する継承バフを30秒付与する。次の通常攻撃が敵または地形へ着弾すると、アローレインは着弾地点を中心に同じ雨矢、ブラストアローは同じ衝撃波を発生させ、残り時間を30秒分消費する。クラッシュアローは次の通常攻撃がMobへ命中した場合だけ、その対象へ同じ盾破壊攻撃を発生させて残り時間を30秒分消費し、地形着弾では発動・消費しない。各継承バフは1回で消滅し、多段・複数対象でも一攻撃につき1回だけ発動する。空振り、期限切れ、パッシブ無効化、消費リソース不足では追加効果と消費を行わない。付与後にダンジョン・ボスへ挑戦した場合はバフを解除する。

効果量は各バフ付与元のスキル個体のレベル・シジルを反映した発動値を使い、そのダメージ倍率だけを継承の心得により50%へ下げる。アローレインはLv.1で半径3m・45本、Lv.5で半径5m・81本を維持し、雨矢1本の基礎倍率は0.36から0.18となる。全弾が一対象へ当たる仮定の基礎倍率合計はLv.1で8.1、Lv.5で14.58（Lv補正前）だが、散布・遮蔽物・命中率に左右されるため実DPSとは区別する。ブラストアローは半径4.5m・最大6体を維持し、Lv.1基礎倍率は1.74から0.87となる。クラッシュアローはシールド破壊倍率3.0～5.0倍と超星会心率50%を維持し、Lv.1基礎倍率は0.45から0.225となる。追加の初弾・飛翔体、詠唱、クールダウン、継承バフ再付与は発生しない。消費は各元スキルの全消費リソースへ元スキル発動値の消費軽減を適用する。

継承についてのアローレイン、ブラストアロー、クラッシュアロー、ファイアアロー、アイスアロー、拡散する野望、ファントムショットの追加説明は、閲覧プレイヤーが継承の心得の使用許可を持つ場合だけ表示する。秒数、継承の心得、継承バフ名、元スキル名は各skillの `params` と `{skill.*}` プレースホルダーから表示し、固定文言へ複製しない。表示条件にパッシブの習得・バインドは要求しない。シャープシューター用の使用許可node `2240` は共通射撃node `2120` から独立leafとして `starter` に配置する。ファイアアローnode `2241`、アイスアローnode `2242`、ヒールアローαnode `2255`、拡散する野望node `2257`、ファントムショットnode `2258` は現行 `starter` に配置されている。専用ショップ販売は追加しない。冒険者・ハンターから継承する既存skillも維持する。

「拡散する野望」はスキルツリーのnode `2257` で使用許可を得るアクティブskillとする。Lv.1/2/3で矢を1/3/5本、照準方向を中心に全角20度へ等間隔で放つ。発射位置は視点の0.8m前方、射程24m、1 tickあたり1.6m、判定半径0.6m、重力なし・非貫通とする。各矢は敵または地形で止まり、その地点から半径3mの自然爆発を起こす。矢の直撃対象へ間接攻撃力200%を与え、爆発は直撃対象を除く周囲の最大6体へ100%を与える。同じ敵へ別の矢が命中することは許可する。いずれかの状態異常が有効な敵には、直撃と爆発の各ダメージ倍率を2倍にする。状態異常の種類は限定しない。射出中は緑の草花粒子、着弾時は爆発・苔ブロック片・緑の粒子輪と複数の効果音で示す。

クールダウンは10秒、発動時にENG20とMP12を同時消費する。最大Lvは3で、初回習得と各レベルアップに初級スキルジェム原石10個を消費する。直撃だけが全弾同一対象へ命中する理論上限はLv.1/2/3で1回あたり200%/600%/1000%、10秒ごとの基礎倍率DPSは20%/60%/100%相当とする。状態異常中はその2倍となる。散開角、遮蔽、各矢の着弾地点で実際の命中数は変動し、範囲爆発の別対象ダメージはこの単体DPSに加えない。

継承の心得が有効な発動では「継承バフ拡散する野望」を149秒付与する。バフ中の遠距離通常攻撃は発射時の照準を中心に5方向へ散開し、一攻撃で最初の矢が敵か地形に着弾したとき30秒分を一度だけ消費する。5本には同じ通常攻撃のダメージ計算を適用し、追加のENG・MPは消費しない。空振りと期限切れではバフ時間を消費しない。

ファントムショットはファントムアーチャーと共有する三連射skillとする。各弾は無属性の間接攻撃力 `150% + 20% × skill level` を持ち、初回・5tick後・10tick後に射程16m、判定半径1.1mで飛ぶ。Lv.1は170%×3発、Lv.10は350%×3発で、全弾命中・防御等を無視した基礎倍率の理論DPSはそれぞれ170%/秒、350%/秒となる。ENG20とMP16を同時消費し、クールダウン3秒、詠唱なしとする。Lv.10では2秒以内に次の弾も有効命中すると、2発目以降の各命中で最大MP・ENGを10%ずつ回復する。Lv.1～9は0%。継承バフを保有した発動は基礎クールダウンを6秒へ倍化する。

継承の心得が有効ならファントムショット発動時に継承バフ連撃Ⅰを149秒付与する。通常攻撃1回に30秒を消費し、5tick後と10tick後に同じ通常攻撃を追加する。追加攻撃は通常攻撃列化、武器共有クールダウン、継承バフ消費に含めない。習得と各レベルアップには初級スキルジェム3個を使い、解放node `2258` は現行 `starter` に配置されている。

## 6. 四つの継承射撃

固有スキルは既存4アクティブ＋継承の心得＋追加4アクティブの計9種類とする。祖先職・共用機動・回復スキルは別に数える。追加技は最大Lv.5、無詠唱、習得と各レベルアップに初級原石2個を消費する。既存の倍率・射程・クールダウン・消費を維持し、通常攻撃へ固有効果を持ち帰る機能と視聴覚を追加する。

| スキル / node | コンセプト・直接効果 | Lv.1 → Lv.5 | CD / 消費 | 継承時 |
|:--|:--|:--|:--|:--|
| ホライゾンブレイカー `2438` | 光の矢で23mの射線を最大3体貫通。命中ごとに0.8倍 | 150% → 190% | 10秒 / ENG20 | 通常弓の進行方向へ同じ貫通、倍率75% → 95%を起点に減衰 |
| パラドックスボルト `2443` | 射程18m。火氷を半分ずつ当て、炎上・凍結中の敵には合計+90% | 120% → 160%（特効210% → 250%） | 8秒 / MP26 | 命中した敵へ火氷の追撃60% → 80%（特効105% → 125%） |
| リフレインアロー `2446` | 射程19m。5m内の別の敵へ3tick間隔で最大2回跳弾、1回ごと0.7倍 | 120% → 152% | 10秒 / ENG22 | 命中位置から最大2回連鎖。初段60% → 76%、以後0.7倍 |
| フロストガーデン `2444` | 視線先16mへ氷晶の庭。12tick後、半径3m・最大5体を攻撃。35%で2秒凍結 | 90% → 122% | 12秒 / MP32 | 命中地点へ同じ予兆と凍結範囲、倍率45% → 61% |

継承の再消費はそれぞれENG20 / MP26 / ENG22 / MP32を基準に、解決済みのリソース軽減を適用する。直接発動のCDを短縮したり、継承効果から新たな通常攻撃を再帰生成したりしない。すべて既存の管理対象Mob・遮蔽判定・属性耐性・状態異常耐性を使用する。

### 専用パーティクルと音

| スキル | 視覚の核 | サウンドの段階 |
|:--|:--|:--|
| ホライゾンブレイカー | 金白の照準輪、光の射線、貫通ごとの輪郭衝撃 | 引き絞り、鋭い射出、貫通衝撃 |
| パラドックスボルト | 赤と青の対向螺旋、命中点の火氷交差 | 火と氷の発射、対になる破裂・氷割れ |
| リフレインアロー | 金緑の矢、敵から敵へ渡る軌跡と命中輪 | 発射、3tick間隔で音程を上げる反響 |
| フロストガーデン | 雪結晶の予兆を段階表示し、氷晶を立体的に開く | 設置、予兆、凍結範囲の開花 |

跳弾は各段で生存・未命中対象・遮蔽を再評価し、候補がなくなれば終了する。

直接発動と継承の双方から専用演出を呼び、汎用SOUL弾とREVERSE_PORTAL着弾への一律置換は行わない。粒子数・描画tick・音量には上限を設ける。派手さは常時大量の粒子ではなく、形・色の対比・予兆から命中への変化で示す。

### 整理した技能と例外

静眼狙撃・終局標的は条件付き単体倍率の水増し、破盾針はハンターのクラッシュアローと盾対策が重複、火華弾・霜貫矢は既存属性矢および採用した属性連携と重複するため撤去する。分岐矢・制圧雨・無尽連射も、拡散する野望・アローレイン・ファントムショットの範囲/連射の選択と重複するため撤去する。残した4技の内部IDは習得済み個体との対応を維持する。

共用エアーシフトは位置取り、ヒールアローαは味方への回復が主役であるため、通常攻撃への継承を追加しない。これらは攻撃の水増しではなく、弓射撃だけでは補えない移動と回復の役割を持つ。

### DPSとリソース前提

単体・全段命中・会心/防御/耐性/消費軽減なしで、直接発動の倍率をCD秒で割ると、ホライゾンは0.150→0.190 R/秒、パラドックスは0.150→0.200（特効0.2625→0.3125）、リフレインは0.120→0.152、ガーデンは0.075→0.1017となる。貫通先・跳弾先・範囲内の追加敵は単体DPSへ含めない。

継承はCDではなく有効な通常攻撃の命中回数とリソース残量に制約されるため、直接発動のDPSへ無条件加算しない。通常攻撃1回/秒かつ4種を維持・資源無制限なら、単体の追加倍率はLv.1で `0.75+0.60+0.60+0.45=2.40R/秒`、火氷特効中は2.85R/秒。ただし毎秒ENG42とMP58を消費し、元の通常攻撃は心得により0.5倍となる。この最大併用を定常運用の前提にはしない。

> [!example] 同格アンカーでの事前試算（実測ではない）
> [[../02-成長曲線]] のLv.15を使う。`R=767`、Mob防御767・HP4400、最終倍率1.3、命中率0.92、会心なしなら通常攻撃期待DPSは458.666。ホライゾンの継承だけを毎秒命中させる短時間の係数は `0.5+0.75=1.25` で約573.3、TTK約7.67秒。直接発動1回の初撃を加える単純近似では約6.47秒。継承5回でENG100、初動ENG20を別途使うため、自然回復を無視した継続運用はできない。Player HP2200・防御797、Mob攻撃797・1.5秒間隔・命中率0.915の基準耐久は約9.05秒で、今回の直接ステータス変更はない。

実サーバーでの操作・音量・粒子の視認性・最終TTKは別途確認する。コード上の呼び出し確認とビルド成功を実機確認として扱わない。

### 退役8技の展開とデータ移行

> [!warning] 展開前提
> この変更はローカル実装であり、本番のSeeder・master reload・アカウント移行を実行したものではない。実際の所持アカウント数は未確認。取得済みnodeを削除するため、単純な自動ログインパッチだけで展開してはならない。原石補償の判断が終わるまで本番展開を保留する。

退役nodeは `2437`、`2439`、`2440`、`2441`、`2442`、`2445`、`2447`、`2448`。対応skillは `sharpshooter_steady_sight`、`sharpshooter_shield_needle`、`sharpshooter_execution_mark`、`sharpshooter_ember_bloom`、`sharpshooter_frost_shard`、`sharpshooter_split_arrow`、`sharpshooter_suppressive_rain`、`sharpshooter_relentless_volley`。node IDは再利用しない。

1. 対象サーバーへの入場を止め、対象者のログアウトと保存を完了させる。旧世代定義とアカウント状態を確認可能な状態に保つ。
2. Plugin・Filebaseを一括配置し、Seeder完了と全対象サーバーの新定義ロードを確認して新世代パッチを公開する。新旧が混在したまま入場を再開しない。
3. 管理APIの `GET /api/skilltree/runtime/servers/{serverId}/migration-candidates` で全ページの候補を取得し、`runtime/definitions/{generationId}` と `runtime/accounts/{accountId}/migration-state` から旧新定義・保存node・消費クラスを確認する。`server_session_id` と `to_generation_id` は稼働中の値を取得し、固定の仮値を使用しない。
4. `POST /api/skilltree/runtime/servers/{serverId}/accounts/{accountId}/migrations` に `previewOnly: true` で送る。`removeNodeIds` はそのアカウントの保存済みnodeと退役8nodeの積集合だけにする。`operationId`、`expectedStateVersion`、`fromGenerationId`、`toGenerationId`、`legacyBaselineNodeIds` を実際の状態から設定する。世代付きの通常移行では `confirmLegacyBaseline: false` とし、保持CPノードの消費元が確定していれば `consumedClassAssignments: []` とする。保持CPノードの消費元が欠損している場合は旧定義の固定クラス条件を照合し、標準の安全編集手順に従い確認できた対象ノードだけ明示割当する。退役するノード自身の消費元が欠損している場合はこの割当で補えないため、移行を止めて個別調査する。旧世代が未確定のlegacyアカウントも標準のlegacy確認手順で個別に扱う。
5. previewの返還内容と保持nodeの接続を確認し、同じ対象の `previewOnly: false` をcommitする。commitの応答が不明なら同じ `operationId` と同じcommit本文で再照会・再試行する。全候補の成功を確認して入場を再開する。

CPは消費nodeを除去することで回復する。保持専用の `60_tool/player-patch-migration` はnode削除に使用しない。削除したskill masterを参照する習得個体は、既存の `AccountLearnedSkillRepository.ReconcileAsync` で論理削除され、bindが解除される。装着シジルは既存の補償メール対象だが、習得・レベルアップに消費した原石の自動返還処理はない。原石まで返還する場合は対象の確定と別途補償手順が必要となる。

正本手順は [[../../20_API設計書/feature/20-skilltree/20_5.00-安全編集の導入と検証|スキルツリー安全編集の導入と検証]]。実行結果と未対応アカウントを保存し、移行未完了を反映済みと扱わない。

## スキルブック：スターウィーバー

[[08-ファントムアーチャー|ファントムアーチャー]]と共用する `archer_starweave_followup` は、通常弓射撃の余韻を星糸の追矢にする装備限定パッシブ。`20a00084` の装備条件はプレイヤーLv15、シャープシューターまたはファントムアーチャーの現職Lv1。レアリティUNCOMMON、progression 1とし、不死鳥との共鳴のブック（Lv25、RARE、progression 2）より前の選択肢にする。習得は初級原石8個、各強化は同3個。バインドが必要で、解除中も習得個体は残る。クラス・ツリーへの常設許可と販売・ドロップは追加しない。

| 性能 | Lv1 | 最大Lv5 |
|:--|--:|--:|
| 基礎追矢倍率 / 間接攻撃力 `R` | 80% | 120% |
| 継承バフ保持中、または自分の霊印が残る敵への加算 | +40% | +40% |
| 条件成立時の合計倍率 | 120% | 160% |
| 再使用間隔 / 飛翔時間 / 射程 | 6秒 / 0.3秒 / 30m | 同左 |
| 追加MP・ENG消費 / シジル枠 | 0 / 0 | 同左 |

弓・短弓・長弓の通常攻撃が回避されずHPまたはShieldへ正のダメージを与えたとき、再使用可能なら同じ生存敵一体へ追矢を放つ。強化条件は発生時に判定し、両方成立しても加算一回。無属性間接の独立命中で、命中・回避・Shield・防御・耐性は共通ダメージ計算を使う。継承の心得の通常攻撃50%補正、継承技50%補正は追矢へ重ねない。追加矢は通常射撃ではなく、継承callback・霊印付与・霊印消費・他スキルブックの誘発を行わない。

> [!example] 上限検算（実測ではない）
> 同じ敵に6秒ごとに通常射撃が命中し、その0.3秒後の追矢も全弾命中する定常上限は、Lv1の基礎 `0.8/6 = 0.1333 R/秒`、継承中 `1.2/6 = 0.2000 R/秒`。Lv5は基礎 `1.2/6 = 0.2000 R/秒`、継承中 `1.6/6 = 0.2667 R/秒`。会心・防御・回避・操作損失は含まない。散開矢の別対象やファントムショットの追加射撃を足して発動数を増やさず、所有者につき6秒に一回へ制限する。追加操作と資源消費を要求せず、既存射撃の回転を小幅に補強する。

金と青緑の三本の糸を紡錘へ絞る始動、二重螺旋と矢尻の飛翔、四尖の星と内側の菱形の着弾を分ける。始動はアメジストの高音と矢の射出音、有効命中は短い矢の命中音とアメジストの破砕音。持続描画はせず、飛翔は2tick間隔で三回、各表示の点数は最大48。点群を共有表示サービスへまとめる。book解除、持ち替え、死亡、転職、ワールド移動、マスタ公開、challenge終了で飛翔を停止する。中断で再使用待機は返さず、別セッションへ状態を持ち越さない。元弾と追矢は攻撃側の耐久消費状態を共有する。

> [!warning] 未確認
> 実クライアントの星糸の視認性・音、同装備での実戦DPSとTTKは未確認。数値はマスタと実装の理論上限であり、販売・ドロップの入手経路は設定していない。
