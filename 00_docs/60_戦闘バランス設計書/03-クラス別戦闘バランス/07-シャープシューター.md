# シャープシューターのクラス別戦闘バランス

## 1. クラス概要

| 項目 | 内容 |
| :-- | :-- |
| 親職 | [[03-ハンター\|ハンター]] |
| 職系統 | 緑職 |
| 役割 | 通常攻撃・継承バフ・複合強化 |

## 2. バランス方針

シャープシューターに複数のビルド分岐は設けない。通常攻撃を主軸とし、skillで得た「継承バフ」を重ねることで、貫通、追撃、多方向化、会心強化、状態異常付与などを通常攻撃へ組み込む。

シャープシューター固有skillは単発の攻撃手段ではなく、その性質を以後の通常攻撃へ継承させる手段とする。複数の継承バフを組み合わせ、通常攻撃の性質を大きく変化させる立ち回りをクラスの核とする。

## 4. 「継承の心得」と継承バフ

根本パッシブskillとして `sharpshooter_inheritance_mastery`（継承の心得）を持つ。スキルツリーから使用許可を得て、初級スキルジェム1個でLv.1を習得し、パッシブスロットへバインドしている間だけ有効とする。このパッシブは通常攻撃倍率を50%低下させる代わりに、保有する継承バフの効果を通常攻撃で発揮できるようにする。継承によって発動するスキルのダメージ倍率も元スキルの50%とし、シールド破壊倍率、超星会心率、範囲、対象数などの非ダメージ性能は元スキルを維持する。最大Lvは1とし、レベルアップは行わない。

継承バフは、対応するskillの発動によって一定の残り時間を得る。同名のバフを再度得た場合は重複させず、残り時間を新しい付与時間へ再設定する。

プレイヤーが通常攻撃1回を発動した時点でバフが残っていれば、残り時間が1回分の消費時間に満たなくても効果を発揮する。効果発揮後に、各バフの残り時間を1回ずつ消費する。不足する場合は残り時間をすべて消費してバフが消滅する。

継承バフの効果発揮時に消費するリソース種別と量は、継承の心得のパラメータに継承バフごとに定義する。対応する定義がない継承バフはリソースを消費しない。通常攻撃1回によって使用した各継承バフの時間と対応リソースは1回ずつ消費し、継承効果が発生させた追加攻撃では追加消費しない。複数の継承バフは併用でき、各バフの効果、残り時間、リソース消費は個別に処理する。同じ通常攻撃で複数効果を処理する順序は継承の心得の `params.inheritanceBuffs` 記載順とし、先行効果の消費後にリソース不足となった後続効果は消費・発動せず保持する。

> [!example] 貫通の継承バフ
> 例として、貫通矢で継承バフ「貫通」を140秒得て、貫通する通常攻撃1回ごと30秒を消費するとする。短時間に4回発動すると120秒を消費し、5回目は残り20秒でも貫通効果を発揮する。その後に残り20秒をすべて消費し、バフが消滅する。
> 貫通矢、バフ名、付与時間、消費時間は仕組みを説明するための仮例であり、採用済みのskillや数値ではない。

将来的には、貫通、短い間隔で3回の追加通常攻撃、3方向への同時攻撃、会心倍率上昇、炎上付与などの継承バフを組み合わせられるようにする。

## 5. Skill / 装備

シャープシューターとファントムアーチャーの共用機動skillとして、`hunter_air_shift`（エアーシフト）をクラスの `usableSkills` から配布する。パッシブスロットへのバインドは不要だが、使用には初級スキルジェム3個を消費してLv.1を習得する必要がある。最大Lvは1で、レベルアップは行わない。

エアーシフトは空中でスニークを押した瞬間に発動し、視線基準の前後左右入力を合成した方向へ水平1.45・上向き0.25のvelocityを設定する。方向入力がない場合は視線の後方へ移動する。通常ドッジと同じENG 15を消費する。クールダウンは設けないが、一度発動すると着地するまで再発動できない。ジャスト回避が有効なら通常ドッジと同じ判定を開始し、発動時には風圧音と空中移動パーティクルを再生する。攻撃・回復を行わないためDPSは0とする。

シャープシューター固有skillは、原則として継承バフを付与する。貫通矢と継承バフ「貫通」は仕組みを説明するための例であり、現時点の実装対象には含めない。

ファイアアローとアイスアローは、射程16mを毎tick 1.6mで直進する重力なし・非貫通の高速矢とし、判定半径は0.6mとする。両skillの基礎倍率は `105% + 10% × skill level` で、Lv.1は115%、Lv.10は205%。クールダウンは5秒、主消費はMP 30、ENG消費は0とする。習得と各レベルアップには初級スキルジェム2個を消費する。ファイアアローは24.5%で5秒炎上、アイスアローは50%で2秒凍結を付与する。炎矢は炎粒子、氷矢は水色粒子と小型の氷BlockDisplayで飛翔位置を示す。

継承の心得が有効な間にファイアアローまたはアイスアローを発動すると、対応する「継承バフ火属性Ⅰ」「継承バフ氷属性Ⅰ」を149秒付与する。次の通常攻撃が最初に敵または地形へ着弾するとバフを全時間消費し、追加MPは消費しない。敵へ有効ダメージを与えた場合、火は25%で炎上、氷は50%で凍結を判定する。継承属性のダメージ増加は通常攻撃の基礎ダメージへ属性ごとに個別加算する。基礎100、火属性増加10%、氷属性増加10%なら `100 + 10 + 10 = 120` とし、属性間で基礎値を分配しない。火・氷の加算分には対応する属性耐性と属性貫通を適用し、元の通常攻撃成分は維持する。

「継承の心得」が有効な間にアローレイン、ブラストアロー、クラッシュアローのいずれかを発動すると、対応する継承バフを30秒付与する。次の通常攻撃が敵または地形へ着弾すると、アローレインは着弾地点を中心に同じ雨矢、ブラストアローは同じ衝撃波を発生させ、残り時間を30秒分消費する。クラッシュアローは次の通常攻撃がMobへ命中した場合だけ、その対象へ同じ盾破壊攻撃を発生させて残り時間を30秒分消費し、地形着弾では発動・消費しない。各継承バフは1回で消滅し、多段・複数対象でも一攻撃につき1回だけ発動する。空振り、期限切れ、パッシブ無効化、消費リソース不足では追加効果と消費を行わない。付与後にダンジョン・ボスへ挑戦した場合はバフを解除する。

効果量は各バフ付与元のスキル個体のレベル・シジルを反映した発動値を使い、そのダメージ倍率だけを継承の心得により50%へ下げる。アローレインはLv.1で半径3m・45本、Lv.5で半径5m・81本を維持し、雨矢1本の基礎倍率は0.36から0.18となる。全弾が一対象へ当たる仮定の基礎倍率合計はLv.1で8.1、Lv.5で14.58（Lv補正前）だが、散布・遮蔽物・命中率に左右されるため実DPSとは区別する。ブラストアローは半径4.5m・最大6体を維持し、Lv.1基礎倍率は1.74から0.87となる。クラッシュアローはシールド破壊倍率3.0～5.0倍と超星会心率50%を維持し、Lv.1基礎倍率は0.45から0.225となる。追加の初弾・飛翔体、詠唱、クールダウン、継承バフ再付与は発生しない。消費は各元スキルの全消費リソースへ元スキル発動値の消費軽減を適用する。

継承についてのアローレイン、ブラストアロー、クラッシュアロー、ファイアアロー、アイスアローの追加説明は、閲覧プレイヤーが継承の心得の使用許可を持つ場合だけ表示する。秒数、継承の心得、継承バフ名、元スキル名は各skillの `params` と `{skill.*}` プレースホルダーから表示し、固定文言へ複製しない。表示条件にパッシブの習得・バインドは要求しない。シャープシューター用の使用許可node `2240` は共通射撃node `2120` から独立leafとして `starter` に配置する。ファイアアローnode `2241` とアイスアローnode `2242` は定義だけを作成し、構造へは配置しない。専用ショップ販売は追加しない。冒険者・ハンターから継承する既存skillも維持する。
