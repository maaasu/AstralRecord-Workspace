# シャープシューターのクラス別戦闘バランス

## 1. クラス概要

| 項目 | 内容 |
| :-- | :-- |
| 親職 | [[03-ハンター\|ハンター]] |
| 職系統 | 緑職 |
| 役割 | 通常攻撃・継承バフ・複合強化 |

## 2. バランス方針

シャープシューターに複数のビルド分岐は設けない。通常攻撃を主軸とし、skillで得た「継承バフ」を重ねることで、貫通、追撃、多方向化、会心強化、状態異常付与などを通常攻撃へ組み込む。

シャープシューター固有skillは単発の攻撃手段ではなく、その性質を以後の通常攻撃へ継承させる手段とする。複数の継承バフを組み合わせ、通常攻撃の性質を大きく変化させる立ち回りをクラスの核とする。

## 3. クラス成長

| 項目 | Lv1補正 | Lvごとの補正 | Lv100のクラス補正 |
|:--|--:|--:|--:|
| MAX_ENERGY | 60 | 1 | 159 |
| DEXTERITY | 8 | 1.2 | 126.8 |
| AGILITY | 8 | 1 | 107 |
| LUCK | 6 | 0.4 | 45.6 |
| ATTACK | 7 | 0.9 | 96.1 |
| NORMAL_ATTACK_DEGRADATION_DELAY | 3 | 0.2 | 22.8 |

クラス補正は `baseStats + growthPerLevel × (classLevel - 1)`。`DEXTERITY`は間接攻撃力計算、`AGILITY`は攻撃速度・移動速度・回避率、`LUCK`は通常会心率へ派生する。正式な正本は `40_filebase/20.features.class/v1.23.sharpshooter.yml` とする。

## 4. 「継承の心得」と継承バフ

根本パッシブskillとして `sharpshooter_inheritance_mastery`（継承の心得）を持つ。スキルツリーから使用許可を得て、初級スキルジェム1個でLv.1を習得し、パッシブスロットへバインドしている間だけ有効とする。このパッシブは通常攻撃倍率を50%低下させる代わりに、保有する継承バフの効果を通常攻撃で発揮できるようにする。最大Lvは1とし、レベルアップは行わない。

継承バフは、対応するskillの発動によって一定の残り時間を得る。同名のバフを再度得た場合は重複させず、残り時間を新しい付与時間へ再設定する。

プレイヤーが通常攻撃1回を発動した時点でバフが残っていれば、残り時間が1回分の消費時間に満たなくても効果を発揮する。効果発揮後に、各バフの残り時間を1回ずつ消費する。不足する場合は残り時間をすべて消費してバフが消滅する。

継承バフの効果発揮時に消費するリソース種別と量は、継承の心得のパラメータに継承バフごとに定義する。対応する定義がない継承バフはリソースを消費しない。通常攻撃1回によって使用した各継承バフの時間と対応リソースは1回ずつ消費し、継承効果が発生させた追加攻撃では追加消費しない。複数の継承バフは併用でき、各バフの効果、残り時間、リソース消費は個別に処理する。

> [!example] 貫通の継承バフ
> 例として、貫通矢で継承バフ「貫通」を140秒得て、貫通する通常攻撃1回ごと30秒を消費するとする。短時間に4回発動すると120秒を消費し、5回目は残り20秒でも貫通効果を発揮する。その後に残り20秒をすべて消費し、バフが消滅する。
> 貫通矢、バフ名、付与時間、消費時間は仕組みを説明するための仮例であり、採用済みのskillや数値ではない。

将来的には、貫通、短い間隔で3回の追加通常攻撃、3方向への同時攻撃、会心倍率上昇、炎上付与などの継承バフを組み合わせられるようにする。

## 5. Skill / 装備

シャープシューターとファントムアーチャーの共用機動skillとして、`hunter_air_shift`（エアーシフト）をクラスの `usableSkills` から配布する。パッシブスロットへのバインドは不要だが、使用には初級スキルジェム3個を消費してLv.1を習得する必要がある。最大Lvは1で、レベルアップは行わない。

エアーシフトは空中でスニークを押した瞬間に発動し、視線基準の前後左右入力を合成した方向へ水平1.45・上向き0.25のvelocityを設定する。方向入力がない場合は視線の後方へ移動する。ENGは消費しない。クールダウンは設けないが、一度発動すると着地するまで再発動できない。ジャスト回避が有効なら通常ドッジと同じ判定を開始し、発動時には風圧音と空中移動パーティクルを再生する。攻撃・回復を行わないためDPSは0とする。

将来追加するシャープシューター固有skillは、原則として継承バフを付与する。貫通矢と継承バフ「貫通」は仕組みを説明するための例であり、現時点の実装対象には含めない。

今回は「継承の心得」のパッシブ定義と通常攻撃倍率低下だけを追加し、攻撃skill、継承バフ、skill node、スキルツリー上の配置、専用ショップ販売は追加しない。したがって、使用許可を与えるnodeが追加されるまでは通常プレイで有効化できない。冒険者・ハンターから継承する既存skillも維持する。
