# シャープシューターのクラス別戦闘バランス

## 1. クラス概要

| 項目 | 内容 |
| :-- | :-- |
| 親職 | [[03-ハンター\|ハンター]] |
| 職系統 | 緑職 |
| 役割 | クリティカル・高火力・単体 |

## 2. バランス方針

クリティカルと単体への高火力を主軸とし、対象を一体ずつ撃破する構成を目標とする。

防御力を積み上げるのではなく、命中・間接火力を維持したまま回避率と移動速度を伸ばして被弾を抑える。属性は雷へ統一し、スナイパーは雷属性貫通、ラピッドは感電付与を専門化する。共用機動skillとしてエアーシフトを配布し、攻撃skillは将来実装を前提としたstatus treeだけを定義する。

## 3. クラス成長

| 項目 | Lv1補正 | Lvごとの補正 | Lv100のクラス補正 |
|:--|--:|--:|--:|
| MAX_ENERGY | 60 | 1 | 159 |
| DEXTERITY | 8 | 1.2 | 126.8 |
| AGILITY | 8 | 1 | 107 |
| LUCK | 6 | 0.4 | 45.6 |
| ATTACK | 7 | 0.9 | 96.1 |
| NORMAL_ATTACK_DEGRADATION_DELAY | 3 | 0.2 | 22.8 |

クラス補正は `baseStats + growthPerLevel × (classLevel - 1)`。`DEXTERITY`は間接攻撃力計算、`AGILITY`は攻撃速度・移動速度・回避率、`LUCK`は通常会心率へ派生する。正式な正本は `40_filebase/20.features.class/v1.23.sharpshooter.yml` とする。

## 4. スナイパー / ラピッド（Sniper / Rapid）ビルドとCP

シャープシューターCP領域は、共通射撃24node、Sniper 48node、Rapid 48nodeの合計120 status node / 120CPで構成する。全nodeは1CPで、固有skillの使用許可は付与しない。

> [!important] ビルドの境界
> Sniperは高い命中、通常・超星会心、雷属性貫通、間接防御貫通を軸に、一撃の期待値を伸ばす。Rapidは攻撃速度、通常攻撃、通常攻撃劣化遅延、ENG循環、感電付与を軸に、攻撃を止めない継続DPSを伸ばす。両ビルドは共通して間接攻撃、雷属性、回避・移動を持つが、Rapidだけに直接の攻撃速度とENG効率を集中させる。

| 系統 | status node | 全取得時の主な合計 |
|:--|--:|:--|
| 共通射撃 | 24 | RANGED_ATTACK `FLAT +15`、ACCURACY `FLAT +11`、DEXTERITY `SCALAR +0.03`、EVASION `FLAT +4`、MOVEMENT_SPEED `FLAT +9`、MAX_ENERGY `FLAT +65`、ENERGY_REGEN `FLAT +3`、SUPER_CRITICAL_RATE `FLAT +1`、SUPER_CRITICAL_DAMAGE `FLAT +5` |
| Sniper | 48 | RANGED_ATTACK `FLAT +28`、DEXTERITY `SCALAR +0.08`、ACCURACY `FLAT +18`、NORMAL_ATTACK_DAMAGE_INCREASE `FLAT +9`、SKILL_DAMAGE_INCREASE `FLAT +12.5`、CRITICAL_RATE `FLAT +4`、CRITICAL_DAMAGE `FLAT +15`、SUPER_CRITICAL_RATE `FLAT +4`、SUPER_CRITICAL_DAMAGE `FLAT +10`、RANGED_DEFENSE_PENETRATION_RATE `FLAT +6`、LIGHTNING_DAMAGE_INCREASE `FLAT +18`、LIGHTNING_PENETRATION `FLAT +6`、EVASION `FLAT +4`、MOVEMENT_SPEED `FLAT +9` |
| Rapid | 48 | RANGED_ATTACK `FLAT +28`、DEXTERITY / AGILITY `SCALAR +0.08`、MAX_ENERGY `FLAT +60`、ATTACK_SPEED `FLAT +18`、CRITICAL_RATE `FLAT +3`、CRITICAL_DAMAGE `FLAT +10`、NORMAL_ATTACK_DAMAGE_INCREASE `FLAT +27`、NORMAL_ATTACK_DEGRADATION_DELAY `FLAT +5`、ENERGY_COST_REDUCTION `FLAT +9`、ENERGY_REGEN `FLAT +4`、LIGHTNING_DAMAGE_INCREASE `FLAT +18`、SHOCKED_APPLY_CHANCE `FLAT +20`、EVASION `FLAT +4`、MOVEMENT_SPEED `FLAT +9` |

共通射撃を含む各ビルドのstatus全取得は72CPである。シャープシューターLv80の79CPでは一方を完成して他方へ7CP、Lv100の99CPでは一方を完成して他方へ27CPまで配分できる。全120CPは取得できない。将来skill nodeを各系統へ追加する場合も、status nodeの合計は変更せず、パラディンと同様に関連する枝から独立leafとして分岐する。

共通射撃はハンターの間接攻撃notableから入口へ接続し、三つの円環を順に通過してSniperとRapidへ分岐する。Sniperは東側、Rapidは西側へ配置する。各系統は2nodeの星路と、5個の小node・1個のnotableからなる円環を6組配置する。

> [!note] 属性statusの適用範囲
> `LIGHTNING_DAMAGE_INCREASE`、`LIGHTNING_PENETRATION`、`SHOCKED_APPLY_CHANCE`は雷属性成分または感電付与を持つ攻撃へだけ作用する。現行の無属性通常攻撃へ雷属性を追加する効果はなく、将来の通常攻撃変化・固有skill実装時に利用する。固有skill実装前も円環全体が死値にならないよう、Sniperの雷円環は既存skillへ作用する `SKILL_DAMAGE_INCREASE`、Rapidの電導円環は既存通常攻撃へ作用する `NORMAL_ATTACK_DAMAGE_INCREASE` を同時に付与する。

## 5. Skill / 装備

シャープシューターとファントムアーチャーの共用機動skillとして、`hunter_air_shift`（エアーシフト）をクラスの `usableSkills` から配布する。パッシブスロットへのバインドは不要だが、使用には初級スキルジェム3個を消費してLv.1を習得する必要がある。最大Lvは1で、レベルアップは行わない。

エアーシフトは空中でスニークを押した瞬間に発動し、視線基準の前後左右入力を合成した方向へ水平1.45・上向き0.25のvelocityを設定する。方向入力がない場合は視線の後方へ移動する。通常ドッジと同じENG 15を消費し、クールダウンは設けない。ジャスト回避が有効なら通常ドッジと同じ判定を開始し、発動時には風圧音と空中移動パーティクルを再生する。攻撃・回復を行わないためDPSは0とする。

攻撃skill、skill node、専用ショップ販売は現時点では追加しない。冒険者・ハンターから継承する既存skillも維持する。
