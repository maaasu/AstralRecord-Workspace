# ウィザードのクラス別戦闘バランス

## 1. 役割とビルド

親職は[[04-メイジ|メイジ]]。属性攻撃・範囲・単体を使い分ける紫職で、固有スキルは17種類。共有のブリンクと親職スキルは固有数に含めない。射程による安全性と引き換えに、近接の[[06-ソードマスター|ソードマスター]]より通常の単体係数を抑え、詠唱、状態異常、MP残量、プリズムへの照準で火力を選ぶ。

- **元素連携**: シンダーランスで燃焼、ライムノヴァで熱衝撃と冷気、ストームチェインで感電を重ね、トライアドコンバージェンスで締める。エレメンタルボールは一種類の状態異常だけで増幅できる代替技。燃焼・感電追撃のパッシブは発動ごとにMPを消費するため、外す判断も含む。
- **アーケイン**: マナサイフォンでMPを確保し、詠唱を短縮してアーケインランスとアーケインオーバーロードを使う。オーバーロードは詠唱完了時・消費前の実MPが最大MPの60%以上なら1.4倍。MPを先に使うほど増幅を維持しにくくなる。
- **プリズムと継戦**: エレメンタルプリズムへプリズマティックダートや親職の対応魔法を当て、低い固定消費で屈折追撃を運用する。単体の敵に全弾を集めるか、直接狙って状態異常を付けるかを選ぶ。プリズムコンディションとマナサイフォンがMP供給、セルフヒールとマナヴェールが生存を支える。

## 2. CP配分

status領域は共通魔導24node、エレメンタル48node、アーケイン48nodeの計120node / 120CP。各専門枝の完成は共通込み72CPで、Lv100の99CPならもう一方へ27CPを配分できる。三つのスキル運用系統は既存の二つのstatus専門枝を組み合わせるビルドであり、status nodeは増やさない。

| 系統 | node数 | 専門枝の主な合計 |
|:--|--:|:--|
| 共通魔導 | 24 | MAGIC_ATTACK / INTELLIGENCE SCALAR +0.098、MAX_MANA +125、魔法防御貫通 / 詠唱短縮 +3、MP再生 +1.5 |
| エレメンタル | 48 | 火・氷・雷ダメージ各+22、属性貫通各+9 |
| アーケイン | 48 | MAX_MANA +256、MAGIC_ATTACK SCALAR +0.161、INTELLIGENCE SCALAR +0.125、スキルダメージ+14.6、魔法防御貫通+11、詠唱短縮+13.5 |

既存使用許可node `2260`〜`2267` は `starter` に配置済み。新規node `2449`〜`2457` は各1ウィザードCPで既存職業枝へ独立したleafとして接続する。スキルCPは上表の120CPに含めない。初期職業許可とショップ販売は追加せず、ノードの使用許可・習得素材消費を用いる。管理者クラスには検証用の使用許可を登録する。

## 3. 既存スキルの監査と調整

> [!important] 実値に基づく調整
> 調整前のSparkはYAMLで1弾15%からLv10の105%へ成長し、最大9弾が同じ敵へ命中していた。945%を1秒CD＋1tick詠唱で繰り返す単体上限は900%/秒。旧説明の115〜205%と12m/秒は実値と異なり、実速度は15m/秒だった。

### イミュレートスパーク

MP17、4秒CD、1tick詠唱。弾数はLv1〜2で1、Lv3〜4で3、Lv5〜6で5、Lv7〜8で7、Lv9〜10で9。一弾は75〜97.5%（レベルごと+2.5%）。同一敵への攻撃判定は一発動から最大4弾。回避・完全防御も一回に数え、上限後に触れた弾は消えて追加ダメージと状態異常を発生させない。別発動の上限は独立する。

全角30度へ散開し、水平15m/秒、地面で1.3mへ跳ね、壁で反射する。寿命はレベル×1.5秒、有効命中は各12%で5秒の感電を付与。AMETHYST_BLOCKの小型表示と紫の火花を使う。単体上限はLv1で75% / 4.05秒 = 18.52%/秒、Lv10で390% / 4.05秒 = 96.30%/秒。全9弾が複数敵へ分散命中した合計上限は216.67%/秒で、範囲散開の価値を残す。習得・強化は初級原石各2個。

### メテオ

MP80、1秒詠唱、8秒CD、着弾待ち3秒、射程16m・半径5m。420〜540%（レベルごと+30%）の火属性一撃を範囲内の管理Mobへ与え、25%で5秒の燃焼を付与。対象数上限は従来どおりなく、地形破壊とPvPはない。繰返し周期は詠唱込み9秒。着弾待ちは初弾の遅延として扱い、各発動でCDへ再加算しない。習得・強化は初級原石各3個。

バーンメテオストライクの小型追撃は別の固定150%。不死鳥の孵化が呼ぶ最大Lvメテオは同じYAMLを参照するため最大540%へ同期する。

### エレメンタルプリズム

MP19、1秒詠唱、1秒CDで3m先の地表へ一個設置し360秒持続。再設置で前の個体を置換。吸収一回で5発、一発は40〜60%、全弾200〜300%。範囲6〜10m、候補最大5体。敵一体なら全弾が集中し、複数なら候補から各弾の相手を抽選する。強化は初級原石各2個。

自分の `prism` タグ付き無・火・氷・雷の対応飛翔体だけを吸収。元の直撃を置き換えるので二重ダメージはない。吸収魔法の属性と攻撃者snapshotを使うが、倍率・弾数はプリズム設置時の解決値で、元魔法の状態異常は引き継がない。吸収ごとの追加MPと内部CDはなく、入力魔法のCD・詠唱・MPが頻度を制約する。Lv5プリズマティックダート入力なら300% / 5.3秒 = 56.60%/秒（設置コスト除外）。

### その他の既存5種

| スキル | 効果 | MP / CD / 詠唱 |
|:--|:--|:--|
| エレメンタルボール | 無245〜325%、状態異常中2倍。射程16m、着弾半径2.25m、最大4体。プリズムへ先に触れると直撃置換 | 40 / 7秒 / 0.5秒 |
| セルフヒール | 自分の最大HP25〜45%回復。回復阻害を適用、追加回復ボーナスなし | 33 / 5秒 / 0.2秒 |
| プリズムコンディション | 自分の攻撃による状態異常成功ごとにMP回復陣。半径1〜3m・持続3〜9秒。プレイヤー一人へ最大MP3%を固定回復し、実際に回復したら消える | 0 / なし / パッシブ |
| バーンメテオストライク | 30m内への燃焼成功ごとに1秒後、半径2.5mへ火150%。追撃は燃焼を付けない | 28 / 内部CDなし / パッシブ |
| ライトニングストライク | 30m内への感電成功ごとに同じ敵一体へ雷150%。追撃は感電を付けない | 56 / 内部CDなし / パッシブ |

パッシブ3種はバインド必須。追撃2種はMP不足なら発生せず、無償のダメージ乗算ではない。Spark最大4弾が全て命中した場合、感電成功の期待回数は0.48回、落雷の期待追加係数は0.72/発動、追加MPは26.88。状態異常耐性・MP不足を無視した期待値で、直接390%とは分ける。燃焼追撃は密集対象がそれぞれ燃焼すると複数発生するため、密集度とMP残量で総量が変わる。

ボールの強化は原石3個、セルフヒールの習得・強化は各3個、プリズムコンディションの初回無料・強化各2個、追撃パッシブ二種の習得は各30個。全て初級原石。コンディションは最大Lv3、追撃二種は最大Lv1、それ以外はSparkを除き最大Lv5。

## 5. 単体係数・収支・耐久

> [!note] 理論値の前提
> 解決魔法攻撃力は `(ATTACK + MAGIC_ATTACK) × (1 + INTELLIGENCE / 100)`。命中100%、シジル・status増幅・会心・防御・属性耐性・DoT・追撃・MP補給を除いた係数/秒。CDはexecutor成功後に始まるためCD＋詠唱で割る。実操作・飛翔・詠唱失敗・敵の移動は除外し、実測DPSを保証しない。

| スキル | Lv1 | 最大Lv | 最大Lvの条件成立時 |
|:--|--:|--:|:--|
| イミュレートスパーク | 0.185 | 0.963 | 同一敵最大4弾 |
| メテオ | 0.467 | 0.600 | 範囲の各敵へ同倍率 |
| エレメンタルボール | 0.327 | 0.433 | 状態異常中0.867 |
| シンダーランス | 0.344 | 0.469 | DoT・小型メテオは別 |
| ライムノヴァ | 0.240 | 0.347 | 燃焼中0.485 |
| ストームチェイン | 0.270 | 0.378 | 一体一回、落雷は別 |
| トライアドコンバージェンス | 0.333 | 0.444 | 三状態で0.778 |
| アーケインランス | 0.471 | 0.647 | 増幅なし |
| アーケインオーバーロード | 0.339 | 0.446 | 高MP時0.625 |
| マナサイフォン | 0.114 | 0.171 | 基礎消費後の差引MP回収10〜26 |
| プリズマティックダート | 0.264 | 0.377 | Lv5プリズム入力時0.566 |

ソードマスター通常能動技は約0.55〜1.04、条件時1.35〜1.49。新規ウィザード技は通常0.17〜0.65、準備した条件技は0.63〜0.87を目安にする。Sparkは散開・反射で到達を保証できない代わりに上限0.963を残す。攻撃力の単位が異なる職業間の倍率監査であり、装備・status差を含む実ダメージ比較ではない。

再生・軽減なしで元素四技一巡は128MP、追撃パッシブの消費は別。初期最大MP110だけでは一巡できず、MP育成か回復が必要。サイフォンLv5→ランス→オーバーロードは10−36＋32＋64 = 70MP純消費で、全回復できても永続循環ではない。プリズム設置＋ダート一発は39MP、以降一発20MP。

比較用fixtureを解決攻撃力100・有効防御100、会心/属性/最終倍率なしとすると、メテオLv5は270ダメージ、Spark全4弾は195（旧最大9弾472.5）。HP1000なら初回即時命中の仮定でメテオは4回目の27秒、Sparkは6回目の20.25秒で撃破。初回詠唱・飛翔とメテオ3秒待ちは別。Tier2職へTier1のLv1〜30アンカーを流用せず、同格の実TTKは別途測定する。

ヴェールLv5中は同じ継続被ダメージなら生存時間が約1.67倍だが3秒/18秒だけで、同時に火力20%低下とMP30を支払う。セルフヒールLv5は最大HP45%を5.2秒周期で回復するがMP33を消費。回復阻害、MP枯渇、詠唱中の移動速度低下を含まない上限比較である。

## 6. 演出・共有スキル・参照

火槍は赤橙線、冷気は青い同心円、連鎖雷は黄色の折線、三属性終撃は三色の同心円、アーケインは紫の細線と収束円、サイフォンは命中地点から戻る青線、ヴェールは青い薄円で区別する。共通particle経由の既存定義を使い、瞬間リングは持続魔法陣として数えない。新規iconは既存skill/itemの未使用Materialを選んだ。

共有 `mage_blink` はウィザードとアークメイジのバインド必須パッシブ。空中スニークから安全な視線方向へ最大10m移動し、成功時MP20・ENG20を消費。CDなし、着地後の次の空中移動で再使用できる。初級原石3個で習得し専用nodeは追加しない。

- マスタ: `40_filebase/30.features.skill/v1.wizard_*.yml`
- 職業: `40_filebase/20.features.class/v1.25.wizard.yml`
- 使用許可: `40_filebase/35.features.skilltree/nodes/2260.json`〜`2267.json`、`2449.json`〜`2457.json`
- 配置: `40_filebase/35.features.skilltree/structures/starter.json`
- 実行処理: `10_plugin/AstralRecord/src/main/java/io/github/maaasu/astralRecord/feature/skill/executor/active/wizard/WizardSkillExecutorCatalog.java`

自動検証はファイルベース参照、コンパイル、共通テスト、独立レビュー。視認性、命中率、実戦MP収支、TTKと耐久時間は実機検証として区別する。

シンダーランスとストームチェインは照準対象を発動時に固定し、次tickに命中させる。本体MP消費後に燃焼・感電の有償パッシブを判定し、残MPが追撃コストへ満たない場合は既存規則どおり追撃を起こさない。直線命中と演出は同じ遮蔽後射程を使用する。
