# ウィザードのクラス別戦闘バランス

## 1. 役割とビルド

親職は[[04-メイジ|メイジ]]。属性攻撃・範囲・単体を使い分ける紫職で、固有スキルは17種類。共有のブリンクと親職スキルは固有数に含めない。射程による安全性と引き換えに、近接の[[06-ソードマスター|ソードマスター]]より通常の単体係数を抑え、詠唱、状態異常、MP残量、プリズムへの照準で火力を選ぶ。

- **元素連携**: シンダーランスで燃焼、ライムノヴァで熱衝撃と冷気、ストームチェインで感電を重ね、トライアドコンバージェンスで締める。エレメンタルボールは一種類の状態異常だけで増幅できる代替技。燃焼・感電追撃のパッシブは発動ごとにMPを消費するため、外す判断も含む。
- **アーケイン**: マナサイフォンでMPを確保し、詠唱を短縮してアーケインランスとアーケインオーバーロードを使う。オーバーロードは詠唱完了時・消費前の実MPが最大MPの60%以上なら1.4倍。MPを先に使うほど増幅を維持しにくくなる。
- **プリズムと継戦**: エレメンタルプリズムへプリズマティックダートや親職の対応魔法を当て、低い固定消費で屈折追撃を運用する。単体の敵に全弾を集めるか、直接狙って状態異常を付けるかを選ぶ。プリズムコンディションとマナサイフォンがMP供給、セルフヒールとマナヴェールが生存を支える。

## 3. 既存スキルの監査と調整

> [!important] 実値に基づく調整
> 調整前のSparkはYAMLで1弾15%からLv10の105%へ成長し、最大9弾が同じ敵へ命中していた。945%を1秒CD＋1tick詠唱で繰り返す単体上限は900%/秒。旧説明の115〜205%と12m/秒は実値と異なり、実速度は15m/秒だった。

### イミュレートスパーク

MP17、4秒CD、1tick詠唱。弾数はLv1〜2で1、Lv3〜4で3、Lv5〜6で5、Lv7〜8で7、Lv9〜10で9。一弾は75〜97.5%（レベルごと+2.5%）。同一敵への攻撃判定は一発動から最大4弾。回避・完全防御も一回に数え、上限後に触れた弾は消えて追加ダメージと状態異常を発生させない。別発動の上限は独立する。

全角30度へ散開し、水平15m/秒、地面で1.3mへ跳ね、壁で反射する。寿命はレベル×1.5秒、有効命中は各12%で5秒の感電を付与。AMETHYST_BLOCKの小型表示と紫の火花を使う。単体上限はLv1で75% / 4.05秒 = 18.52%/秒、Lv10で390% / 4.05秒 = 96.30%/秒。全9弾が複数敵へ分散命中した合計上限は216.67%/秒で、範囲散開の価値を残す。習得・強化は初級原石各2個。

### メテオ

MP80、1秒詠唱、12秒CD、落下完了まで3秒、射程16m・最終半径8m。630〜810%（レベルごと+45%）の火属性ダメージを、中心半径3mの即時爆発から20tickかけて半径8mの外周へ広げる。波は2tickごとに前回半径より外側の新規到達帯を瞬間判定し、その時点で帯にいる管理対象Mobを各発動で1回だけ攻撃する。通過済みの内側と判定間の連続移動は攻撃判定の対象にしない。命中時25%で5秒の燃焼を付与する。対象数上限は従来どおりなく、地形破壊とPvPはない。60tickの落下完了時に中心のダメージが始まり、外側の対象は波の到達分だけ遅れる。繰返し周期は詠唱込み13秒で、落下と波の待ちは各発動のCDへ再加算しない。習得・強化は初級原石各3個。

バーンメテオストライクの小型追撃は従来どおり固定150%・落下20tick・半径2.5mの一括命中。不死鳥の孵化が呼ぶ最大Lvメテオは同じYAMLを参照するため最大810%・最終半径8m・20tickの拡大波へ同期する。

### エレメンタルプリズム

MP19、1秒詠唱、1秒CDで3m先の地表へ一個設置し360秒持続。再設置で前の個体を置換。吸収一回で5発、一発は40〜60%、全弾200〜300%。範囲6〜10m、候補最大5体。敵一体なら全弾が集中し、複数なら候補から各弾の相手を抽選する。強化は初級原石各2個。

自分の `prism` タグ付き無・火・氷・雷の対応飛翔体だけを吸収。元の直撃を置き換えるので二重ダメージはない。吸収魔法の属性と攻撃者snapshotを使うが、倍率・弾数はプリズム設置時の解決値で、元魔法の状態異常は引き継がない。吸収ごとの追加MPと内部CDはなく、入力魔法のCD・詠唱・MPが頻度を制約する。Lv5プリズマティックダート入力なら300% / 5.3秒 = 56.60%/秒（設置コスト除外）。

### ライムノヴァの距離確保と連携

半径4m・最大5体の即時攻撃から、発動地点に固定した半径8m・最大8体の氷波へ変更。詠唱4tick、発動後1/3/5/7/9tickに半径1.6/3.2/4.8/6.4/8mへ届く。波が届いた時点の管理Mob実body boundsと遮蔽を判定し、一体へ一発動一回だけ攻撃する。回避・完全防御も一回に数え、再攻撃しない。PvP・地形破壊はない。

有効命中へ基礎100%で凍結40tickと冷気120tickを別々に付与する。凍結は移動・攻撃・スキル・AIを止め、冷気は移動速度0.5倍・詠唱2倍。両状態は命中時から同時に始まり、耐性・状態異常持続時間補正を受ける。ボスは既存規則で制御時間が0.25倍（補正なしなら凍結0.5秒・冷気1.5秒）となる。

> [!tip] 距離を取りながら使う役割
> 接近中の集団を中距離で止め、後退してメテオの照準や次の詠唱へつなぐ。シンダーランス・メテオの燃焼中は308〜420%の熱衝撃を与え、冷気はエレメンタルボールの状態異常増幅とトライアドコンバージェンスの三状態連携へ使える。燃焼と他の状態は消費しない。制御は耐性次第であり、MP26・CD7秒で常時拘束はできない。

## 5. 単体係数・収支・耐久

> [!note] 理論値の前提
> 解決魔法攻撃力は `(ATTACK + MAGIC_ATTACK) × (1 + INTELLIGENCE / 100)`。命中100%、シジル・status増幅・会心・防御・属性耐性・DoT・追撃・MP補給を除いた係数/秒。CDはexecutor成功後に始まるためCD＋詠唱で割る。実操作・飛翔・詠唱失敗・敵の移動は除外し、実測DPSを保証しない。

ソードマスター通常能動技は約0.55〜1.04、条件時1.35〜1.49。新規ウィザード技は通常0.17〜0.65、準備した条件技は0.63〜0.87を目安にする。Sparkは散開・反射で到達を保証できない代わりに上限0.963を残す。攻撃力の単位が異なる職業間の倍率監査であり、装備・status差を含む実ダメージ比較ではない。

再生・軽減なしで元素四技一巡は128MP、追撃パッシブの消費は別。初期最大MP110だけでは一巡できず、MP育成か回復が必要。サイフォンLv5→ランス→オーバーロードは10−36＋32＋64 = 70MP純消費で、全回復できても永続循環ではない。プリズム設置＋ダート一発は39MP、以降一発20MP。

比較用fixtureを解決攻撃力100・有効防御100、会心/属性/最終倍率なしとすると、メテオLv5は270ダメージ、Spark全4弾は195（旧最大9弾472.5）。HP1000なら初回即時命中の仮定でメテオは4回目の27秒、Sparkは6回目の20.25秒で撃破。初回詠唱・飛翔とメテオ3秒待ちは別。Tier2職へTier1のLv1〜30アンカーを流用せず、同格の実TTKは別途測定する。

ヴェールLv5中は同じ継続被ダメージなら生存時間が約1.67倍。基礎5秒/18秒で、同時に火力20%低下とMP30を支払い、防御しながらMPを立て直す。追加MP回復力40〜60は5秒あたりの量なので、追加基礎回復は毎秒8〜12。基礎期間で5回回復できる場合は40〜60MP、消費との差引は+10〜30MPとなる上限比較であり、自然回復周期と失効時刻の境界では回数が減る。支援力・自然回復パッシブ・回復阻害・MP上限で実量は変動し、バフ持続時間増加は実際の持続と回復機会を増やす。攻撃命中で即時回収するサイフォンと、与ダメージを抑えつつ回復するヴェールを使い分ける。直接DPSは0。HP固定ダメージの別加算は与・被倍率の対象外。

セルフヒールLv5は最大HP45%を5.2秒周期で回復するがMP33を消費。回復阻害、MP枯渇、詠唱中の移動速度低下を含まない上限比較である。

## 6. 演出・共有スキル・参照

火槍は赤橙線、連鎖雷は黄色の折線、三属性終撃は三色の同心円、アーケインは紫の細線と収束円、サイフォンは命中地点から戻る青線、ヴェールは身体を囲う三段の青いリングと縦の円弧を回転させ、回復を示す光を上昇させる。5tickごとに殻60点・回復光8点を種類ごとに一括描画し、移動へ追従する。共通particleの表示設定と近傍viewer判定を維持する。失効時は縮小リングと小さなアメジスト音で終了を示し、死亡・退出・ワールド移動・挑戦開始・処理停止・再付与で前の描画を止める。魔力の殻は設置魔法陣として数えない。瞬間リングも持続魔法陣へ登録しない。ライムノヴァは足元の雪の結晶から青白い二層の氷波と雪片を広げ、六方向の氷柱BlockDisplayが伸びて砕ける。命中には氷片、燃焼対象の有効命中には蒸気と熱衝撃音を表示する。発動・波の拡張・到達を音で区別し、共通ParticleDisplayServiceを通す専用定義を使う。演出は17tickまでに終了し、非永続の氷柱は終了・死亡・退出・世界移動・例外で回収する。短い範囲表示は持続魔法陣として数えない。新規iconは既存skill/itemの未使用Materialを選んだ。

ストームチェインは実命中地点を固定し、白金の雷芯・金色の分岐・火花で敵同士の経路を表示する。各連鎖を2tick間隔で強調し、一つの雷は6tick後まで残光を表示する。HPまたはShieldに有効ダメージが出た地点には三方向の放電リングを重ね、終端のリングは大きくする。回避・完全防御の地点でも連鎖経路は表示するが、命中リング・命中音・雷鳴は出さない。発射時は蓄電音と風切り音、連鎖ごとは音程の上がる放電音と共鳴音、最後の敵には雷鳴を一度再生する。空振りの終点も発動時の照準と遮蔽で固定する。空振りは遮蔽後の射程までの放電だけで、命中リング・命中音・雷鳴は出さない。ダメージ・感電・有償パッシブは従来どおり消費後の次tickで全対象を処理し、以後の反復taskは描画だけを行う。雷芯は各区間最大128点、各区間の描画は最大4回、viewer探索は同種の点群で一括化する。演出taskは死亡・退出・ワールド移動時に停止し、表示Entityや持続魔法陣は生成しない。

アーケインオーバーロードは詠唱中4tickごとに三本の紫の螺旋を発動者の魔力核へ収束させ、開始音と8tick間隔の上昇する共鳴音を重ねる。詠唱完了時は従来どおり視線先の地表へ即時に一撃を適用し、発動者からの魔力線、六方向の放射線、核の紫白閃光、紫の爆発粒子と低音の爆発・魔術音を同じtickに表示する。以後2tick間隔で攻撃半径まで衝撃輪と上半球の弧を広げ、残留魔力と減衰する共鳴音で0.8秒以内に終える。この余韻に追加の攻撃判定はない。高MP増幅時は太い白紫の核と追加の衝撃輪、濃い爆発粒子と低い爆発音・増幅音を使い、攻撃範囲は拡大しない。予備演出は詠唱中断と同時に停止し、余韻は退出・死亡・world移動・Plugin停止の共通lifecycleで停止する。設置型魔法陣や表示Entityは生成しない。

アーケインランスは、発射口の光輪から紫・青紫・白の三条を編み込み、3mごとに射線上で交差させながら前進させる。先端は白い火花へ収束し、終端で射線に垂直な光輪が広がる。発動時の射線を固定し、2tick間隔の飛翔6frameと残光3frameだけを表示する。各frameの尾は最大5m、粒子間隔は0.18m。地形内部と未読込chunkの粒子を除外し、色ごとにviewer探索を一括化する。命中判定・ダメージは従来の発動時の一撃で、三条は追加の攻撃回数を表さない。マスタの説明は光槍の主目的、loreは射程・対象数とダメージに絞る。

ヴェールの与・被補正とMP回復力は一つのActiveBuffで保持し、レベル解決済みparamsから生成する。バフ一覧は残り時間と補正方式に対応した値を表示し、期限切れ時にはステータスも再計算する。パッシブ枠確認などで一覧から先に除去された場合も、次の演出更新で失効を確認し終了処理から再計算する。実機での視認性・演出の見栄えは未確認。

共有 `mage_blink` はウィザードとアークメイジのバインド必須パッシブ。空中スニークから安全な視線方向へ最大10m移動し、成功時MP20・ENG20を消費。CDなし、着地後の次の空中移動で再使用できる。初級原石3個で習得し専用nodeは追加しない。

## 7. 天球儀のスキルブック

`20a00085` はプレイヤーLv15以上・現在職ウィザードLv1以上で装備するUNCOMMONの魔導書。`wizard_spectral_orrery`（スペクトラルオーラリー）の習得・使用を装備中だけ許可する。progression1とし、不死鳥の魔導書（progression2、RARE、Lv25・上位職）より前の段階を担う。ENCHANTED_BOOKは魔導書という用途が明確なため既存ブックと共用し、スキルは既存未使用のWHITE_STAINED_GLASSを使う。初回習得は初級原石6個、各強化は2個、最大Lv5。シジル・装備status補正・初期職業許可・販売・ドロップは追加しない。

24m以内の管理MobのHPまたはShieldへ有効命中した火・氷・雷の魔法を、最初の属性から10秒以内に三種類揃えると最後の命中地点へ追撃する。異なる敵からも収集でき、同じ属性で期限は延長しない。トライアドコンバージェンスの三成分は一撃で成立し、プリズムの屈折も実際の入力属性で一種類として数える。無属性のダートやボール単独では蓄積しない。燃焼・感電パッシブなどの魔法命中も該当属性を蓄積するが、DoT・回避・完全防御・超星追加弾・スキルブック自身と他ブックの追撃は対象外。

| 性能 | Lv1 | Lv5 |
|:--|--:|--:|
| 火・氷・雷それぞれの魔法攻撃力倍率 | 40% | 60% |
| 一体への合計係数 | 120% | 180% |
| 内部CDだけを用いた係数/秒の上限 | 0.150 | 0.225 |
| 半径 / 最大対象数 | 2.5m / 3体 | 2.5m / 3体 |
| 成立時消費 / 内部CD | MP12 / 8秒 | MP12 / 8秒 |

追撃は三成分を一回の命中判定に集約し、状態異常・MP回復は付けない。本体MP消費後の次tickに現在のMPを確認し、対象が一体以上いてMP消費軽減後の実消費量を払えるときだけ消費とCDを開始する。基礎消費はMP12で、既存の共通計算を使う。軽減50%なら判定・消費ともMP6となる。MP不足・範囲内の対象不在なら集めた属性は消え、MPとCDは消費しない。追撃待機中とCD中は新しい連携を蓄積しない。同じパッシブの複数バインド個体は最高倍率だけを採用し、回数は増やさない。最後の装備・バインド解除、死亡、ワールド移動は連携と予約攻撃を破棄する。内部CDは同じログインセッション中の解除・再バインドで保持する。

> [!note] 上限と実戦値の区別
> 内部CD8秒ごとに三属性が必ず揃う仮定の単体上限であり、攻撃力・耐性・防御・会心・シジル・移動を含む実測DPSではない。Lv5トライアドを10秒CD＋0.8秒詠唱で回す場合の追加係数は1.8 / 10.8 = 0.1667/秒、追加MP12/回。元素三技の128MP一巡に一回成立させるなら140MPとなる。解決魔法攻撃力100・有効防御100・会心/属性/最終倍率なしのfixtureでは、追加HPダメージはLv1で60、Lv5で90。同格のTTK・MP収支は実機未確認。

属性取得時は肩に小さな三角結晶と段階的に上がる共鳴音、追撃地点は三色の傾斜軌道が交差する天球儀・放射線・結晶の破砕音で示す。有効命中した敵へだけ白紫の八面体とガラスの命中音を表示する。攻撃判定は一回だけで、以後2tick間隔・最大6回の軌道拡散は描画のみ。各属性は最大40点を一括表示し、同じ点群のviewer探索を重複させない。12tickで終了し、表示Entity・持続魔法陣登録を持たない。既存共有粒子を組み合わせるが、三次元の傾斜軌道と八面体で既存三属性の同心円と区別する。見た目と音の完成度は実クライアント未確認。
