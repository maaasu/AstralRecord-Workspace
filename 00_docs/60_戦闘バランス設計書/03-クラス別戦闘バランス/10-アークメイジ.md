# アークメイジのクラス別戦闘バランス

## 1. クラス概要

| 項目 | 内容 |
| :-- | :-- |
| 親職 | [[04-メイジ\|メイジ]] |
| 職系統 | 紫職 |
| 役割 | サポート・範囲 |

## 2. バランス方針

味方への支援と複数対象への範囲効果を主軸とし、集団戦を支える構成を目標とする。

## 3. 共有スキル：ブリンク

アークメイジはウィザードと共有する最大Lv.1のバインド必須パッシブ `mage_blink` を使用できる。空中でスニークを押すと、視点方向へ最大10m以内の安全な位置へ瞬間移動し、成功時にMP20とENG20を消費する。クールダウンはなく、着地した後の空中移動で再使用できる。詳しい経路・着地点の条件とYaw / Pitch保持条件は [[09-ウィザード#ブリンク|ウィザードのブリンク仕様]]を参照する。アークメイジの許可スキルとして登録し、スキルツリーnodeは作成しない。

## 4. 不死鳥との共鳴

`archmage_phoenix_resonance` は最大Lv.5のバインド必須パッシブ。敵モブとの戦闘開始時に不死鳥を召喚し、プレイヤーの背後上空を追従させる。

| 項目 | Lv.1〜5共通 |
| :-- | :-- |
| アイコン | `PARROT_SPAWN_EGG` |
| 召喚条件 | 自身の通常攻撃またはスキルの直接攻撃が敵モブに命中し、攻撃後も敵が生存している |
| リソース | 不死鳥のHPを表す `phoenix`。最大値500固定、召喚時の現在値500 |
| 消費・クールダウン・詠唱 | すべて0 |
| 習得素材 | スキルジェムの原石(初級)15個 |
| レベルアップ素材 | 1回につきスキルジェムの原石(中級)1個 |
| 使用許可 | スキルブック `20a00070` の装備中。アークメイジ用1CPノード `2268` も定義のみで未配置 |
| レベル成長・シジル | 今回の召喚機能にレベル差なし、シジル枠なし |
| 追加DPS | 0。不死鳥自身の攻撃効果なし |

HUDの `PHOENIX` は現在値が0より大きいときだけ表示する。未召喚・消滅後の現在値0では表示しない。

不死鳥の状態は現在選択中のアカウントUUIDとログイン中の `AstPlayer` に紐づける。アカウント切替時は他のパッシブの終了処理より先に破棄し、旧アカウントの遅れた有効化・解除・攻撃・更新は新アカウントへ適用しない。HUDと攻撃処理も所有アカウントを照合し、残っていた旧状態を参照して別クラスで召喚・表示しない。

最後に命中した敵を常に最新対象として記録する。最新対象が同じワールドの50m以内で生存している間は維持し、範囲外・死亡・消失で不在となってから30秒後に消滅する。待機中に対象が50m以内へ戻った場合は待機を解除する。召喚中は一撃で敵を倒した場合も最新対象と30秒の待機を更新する。空振り、回避、DoTは召喚・更新の対象外とする。

> [!note] 今回の実装範囲
> 不死鳥の召喚・追従・消滅とHPリソースの初期化を扱う。外見は赤いオウムに炎と金・橙・赤のDUSTを混ぜた翼と長い尾、火の粉と青炎を重ねる。不死鳥の攻撃、被ダメージ、蘇生などの追加効果は定義しない。

### 飛行と炎の演出

通常追従は毎tickの速度制御とし、最大速度0.65ブロック/tick、速度変化は最大0.065ブロック/tick、旋回は最大8度/tickに制限する。自律AIだけを `aware=false` で止め、物理移動を許可する。プレイヤーの視線の上下に影響されない背後1.9m・上方2.4mを基本位置とし、壁がある場合は手前へ補正する。移動時は追従の遅れと緩い上下動を持たせ、翼と尾はプレイヤー側の目標点ではなく実体の位置と向きに描画する。

通常移動ではテレポートせず、ワールド変更・24mを超える距離断絶・40tick以上追従点へ近づけない場合だけ復帰に使う。復帰の再試行は距離断絶時20tick、停滞時100tick以上空ける。

炎と小さい炎に金・橙・赤のDUSTを交ぜて左右5枚の羽根と3本の揺れる尾を作り、胸元の炎、翼端の火の粉と青炎を加える。羽ばたきは24tick周期。16m以内は2tickごとに74点、16〜32mは6tickごとに28点へ間引く。1回の閲覧者検索で近い最大16人を選び、閲覧者がいなければ形状を生成しない。各層は共有表示サービスで一括送信し、粒子数の丸めを含めて既存のプレイヤー粒子密度設定に従う。

### スキルブックによる習得

「不死鳥との共鳴のスキルブック」`20a00070` は、アイコン `ENCHANTED_BOOK` の `SKILLBOOK` 装備。装備条件はプレイヤーLv.25以上、現在クラスがアークメイジまたはアークセージであること。装備中に使用許可を得て、スキルマネージャーから初級原石15個を消費して習得する。習得後も使用許可とパッシブのバインドを必要とする。ブックを外しても習得個体は失わないが、他の有効な使用許可がなければ発動しない。

## 5. セレスティアルサークル

`archmage_celestial_circle` は最大Lv.10のバインド必須アクティブ。初級原石5個で習得し、各レベルアップで初級原石15個を消費する。消費MP30、詠唱20tick、クールタイム200tick。1CPのスキルツリーnode `2389` は定義のみで `starter` に配置しない。配置されるまではツリー経由の使用許可を得られない。

視点先24m以内の地表に水平の魔法陣を2秒かけて描く。参考画像の青・紫の同心円、八芒星、四方の星と月弧、赤いアクセントをDUST粒子で表現する。完成後30秒維持し、水平半径内かつ魔法陣の高さから上下2.5m以内の全プレイヤーに「セレスティアルサークル」を付与する。半径はLvと同じmで、Lv.1は1m、Lv.10は10m。範囲外に出ると解除し、戻ると再付与する。再発動時は発動者の旧魔法陣を直ちに消し、2秒の描画をやり直す。

| 効果 | Lv.1 | Lv.10 |
|:--|--:|--:|
| 最終ダメージ倍率 | +0.5ポイント | +5ポイント |
| ライフスティール | +1ポイント | +10ポイント |
| HP・MP・ENG回復力 | +1% | +10% |
| ドロップ増加率 | +1ポイント | +10ポイント |

同じバフは重複せず、複数の魔法陣が重なるときは対象ごとに最高レベルを一つ選ぶ。最終ダメージ倍率とドロップ増加率は基準値100%への加算、ライフスティールも割合値への加算とする。回復力は現在の基礎値への乗算補正とする。スキル自体にダメージはなく、直接DPSは0。攻撃・吸収・回復・ドロップへの間接的な効果は対象の行動と基礎能力に依存する。

バフの存続は魔法陣の範囲判定で管理し、挑戦開始時も魔法陣が残っている限り範囲内の対象へ維持する。魔法陣の終了、再発動、対象の退出時に明示的に解除する。
## 6. ヒールサークル

`archmage_heal_circle` は最大Lv.10のバインド必須アクティブスキル。5tick詠唱後、視点先16m以内の地面に半径3mの水平な魔法陣を置く。MP33を消費し、基礎クールタイムは5秒。魔法陣はレベルと同じ秒数だけ維持される。

最初に接触して実際にHPを回復したプレイヤー1人を、対象の最大HPの `10 + 4 × スキルLv` %を基礎量として回復する。Lv.1は14%、Lv.10は50%。対象は発動者を含む全プレイヤーとし、HP満タンなどで実回復量が0の場合は消費されない。回復成立時に魔法陣を消し、本スキルのクールタイムを解除する。回復阻害、支援力、被回復量増加、HP上限は共通のHP回復処理に従う。

演出は添付図の緑・水色・金色の同心円、葉、菱形と十字を地面と水平な粒子で描く。ダメージを与えないためDPSは0。初回習得にスキルジェムの原石（初級）5個、各レベルアップに15個を消費する。スキルツリーnode `2391` は定義のみで、`starter` には配置しない。

## 7. バインドサークル

`archmage_bind_circle` は最大Lv.1のバインド必須アクティブ。半径4mの設置型拘束で、ダメージは与えないためDPSは0。使用許可はアークメイジ用1CPノード `2392` で与える。ノードは定義のみで `starter` に配置・接続しない。

| 項目 | Lv.1 |
| :-- | :-- |
| アイコン | `NETHER_WART_BLOCK` |
| 射程 | 視線先の地面を探索する最大16m |
| 詠唱・消費・クールダウン | 5tick・MP100・300秒 |
| 設置 | 半径4mの水平な魔法陣。接触がなければ20秒後に消滅 |
| 接触後 | 接触した敵を速度によって中心へ引き寄せる。1秒後、中心に最も近い1体を現在位置で拘束 |
| 拘束 | 30秒間、移動と通常のMobスキル・ギミックを停止。発動済みの通常スキル詠唱も中断 |
| 必殺技の例外 | サンバードのバードメテオ開始時は拘束を解除して発動 |
| 習得素材 | スキルジェムの原石(初級)30個。最大Lv.1のため強化なし |

魔法陣は添付画像の同心円・四方星・魔眼・三色のルーンを地面と平行な粒子で描き、拘束開始時に再描画を止める。拘束中は対象の周囲にBlockDisplayと赤い粒子を表示し、解除時に除去する。引き寄せにはテレポートを使わず、壁との衝突判定を維持する。

## 8. クリアサークル

`archmage_clear_circle` は最大Lv.5のバインド必須アクティブスキル。MP60を消費して5tick詠唱し、クールタイムは10秒。視点先の地表へ半径3mの水平な魔法陣を設置する。設置射程は `11 + スキルLv` mで、Lv.1は12m、Lv.5は16m。接触がなければ `5 + スキルLv` 秒で消え、Lv.1は6秒、Lv.5は10秒維持する。

発動者を含む全プレイヤーのうち、最初に魔法陣へ接触して負の効果を解除できた1人を対象とする。解除対象は専用の状態異常8種、デバフ、Minecraftの有害ポーション効果、炎上。解除対象がない接触では魔法陣を残し、解除成立時に消す。HP回復やダメージはなく、直接DPSは0。解除後もクールタイムは維持する。

演出は添付図の水色と白の二重円、中央と四方の金色の星、菱形、周囲の小さな光をDUST粒子で水平面に描く。習得にスキルジェムの原石（初級）5個、各レベルアップに15個を消費する。1CPのアークメイジ用スキルツリーノード `2393` は定義のみで、`starter` へ配置・接続しない。
