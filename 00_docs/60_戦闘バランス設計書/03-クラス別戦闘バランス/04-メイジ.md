## 1. クラス概要

| 項目 | 内容 |
| :-- | :-- |
| クラス ID | `mage` |
| 役割 | 魔法・遠距離型 |
| レベル上限 | Lv.100 |
| 解放条件 | 冒険者 Lv.10 |

## 2. バランス目標

同じ Player Lv.・同じ更新帯・標準装備で比較する。基準となる最終 HP・解決攻撃力 `R`・有効防御 `D`、TTK、耐久時間は [[../02-成長曲線|成長曲線]]と[[../01-戦闘計算|戦闘計算]]に従う。

| 指標 | メイジの方針 |
| :-- | :-- |
| 主力分野 | 魔法単体・条件付き連鎖・前方範囲攻撃 |
| 生存 | MANAと射程で戦い、HP・物理防御へ偏らせない |
| 弱み | 近接・間接の直接 skill は class から許可しない |
| 構成差 | skilltree で追加する魔法 skill とresource・範囲系の選択で作る |

## 3. 数値配分

| 方針 | 内容 |
| :-- | :-- |
| 基礎値 | MANA・知力・魔法防御を高めにする |
| 成長 | 知力・魔法防御を優先し、MANAの成長は初期戦闘を保ったまま抑える |
| 正本 | `40_filebase/20.features.class/v1.mage.yml` |

具体的な数値は、共通アンカーの130%程度を上限として、class・skilltree・equipment の増加分を **25% / 25% / 50%** の出発点で配分する。正式なステータス値はプレイテストで確定する。

### リソース設計

Lv.1の最大MPと初期スキル消費は変更せず、クラスレベル上昇によるリソースの増加量だけを抑える。`v1.mage.yml` の `growthPerLevel` は `MAX_MANA +3`、`MP_REGEN +0.05` とし、魔法攻撃力へ直結する `INTELLIGENCE +1.4` は維持する。範囲・制圧系のskilltree解放スキルは、初期スキルより高い固定MPコストで選択的に負荷を作る。

### 現行skilltree基礎幹

現行の `starter` skilltreeにはメイジCP nodeを51個配置します。27node・27CPの汎用幹から、魔導、炎、雷、氷の4専門円環へ分岐します。各円環は4個の1CP小nodeと1個の2CP notableで、専門円環は合計20node・24CPです。アーケインフロー、スパーキング、フロストブリザード、フロストボール、ファイアーボールは関連する小nodeから独立した1CP leafとして分岐し、全取得は55メイジCPです。

## 4. Skill / 装備

### class が許可する初期 skill

| ID | skill 名 | 役割 |
| :-- | :-- | :-- |
| `adventurer_mana_burst` | マナバースト | 魔法の前方範囲攻撃 |
| `adventurer_lightning_bolt` | ライトニングボルト | 魔法の単体・条件付き連鎖攻撃 |
| `mage_heal_aura` | ヒールオーラ | 周囲プレイヤーの即時範囲回復 |

上記3個をメイジの `usableSkills` に定義する。アーケインフロー、スパーキング、フロストブリザード、フロストボール、ファイアーボールはclassへ追加せず、skilltree node `1347`～`1349` / `1351` / `1354` の `skill` 効果から許可する。Administratorの検証用 `usableSkills` は維持する。

### 単体・詠唱込み DPS の確認枠

個別 skill は主対象1体、命中100%、会心・防御・アクションリング操作時間なし、詠唱がある場合は `CD + 詠唱時間` を周期として確認する。初期 skill とskilltree解放 skill はいずれも **Skill Lv.5** を前提とする。`R` はそのレベル・装備・skilltree構成で解決した値を使う。

| skill | Skill Lv. | 計算式 | DPS |
| :-- | :-- | :-- | :-- |
| マナバースト | 5 | `R × 1.584 ÷ (3.0 + 0.1)` | 構成ごとに試算 |
| ライトニングボルト | 5 | `R × 2.088 ÷ (3.0 + 0.2)` | 構成ごとに試算 |
| ファイアーボール | 5 | `R × 1.584 ÷ (4.0 + 0.2)` | 構成ごとに試算 |
| フロストボール | 5 | `R × 0.54 ÷ (4.0 + 0.2)` | 構成ごとに試算 |
| スパーキング | 5 | `R × 1.20 ÷ (8.0 + 0.2)` | 構成ごとに試算 |
| フロストブリザード | 5 | `R × 0.288 × 20 ÷ (20.0 + 1.0)` | 構成ごとに試算 |

> [!note] 範囲攻撃の評価
> ファイアーボールはskilltree node `1354` から許可し、MP16とする。単体DPSをライトニングボルトより低く抑え、半径2.25mへ最大4体を巻き込めたときに価値が上がる。マナバーストの複数対象とライトニングボルトの連鎖も、単体 DPS とは別の戦闘シナリオで評価する。

> [!note] ヒールオーラ
> ダメージを発生させないためDPS算出対象外とする。Lv.1はMP 6・2.0秒ごと、Lv.5はMP 6・1.6秒ごとに発動し、各対象へ従来の固定値（Lv.1: 5、Lv.5: 9）を最低値として、対象の現在HPのスキルレベル%（Lv.1: 1%、Lv.5: 5%）との大きい方を回復する。範囲内の複数プレイヤーへ同時適用する。

> [!note] スパーキング
> `starter` node `1348` から使用許可を与える。MP18、Lv.1〜5の雷弾数は5 / 7 / 9 / 11 / 13、各対象は1発動につき1回だけ120%雷魔法ダメージを受ける。25%感電の期待DoTは別枠で評価し、複数雷弾を単体倍率へ加算しない。マナバーストの複数対象とライトニングボルトの連鎖も、単体 DPS とは別の戦闘シナリオで評価する。

> [!note] フロストブリザード
> `starter` node `1349` から使用許可を与える。MP50、持続10秒、20秒クールダウン、1秒詠唱とし、Lv.5は28.8%氷魔法ダメージを最大20回適用する。単体完走DPSは `R × 0.2743` を目安とし、半径2.75m・最大8体への同時攻撃とノックバック耐性依存の回転拘束は別の集団戦価値として評価する。

> [!note] フロストボール
> `starter` node `1351` から使用許可を与える。MP16、4秒クールダウン、0.2秒詠唱とし、基礎倍率45%へ下げ、Lv.2〜5の `SKILL_DAMAGE_INCREASE +5%` によりLv.5は54%氷魔法ダメージを半径2.25m・最大4体へ1回適用する。命中対象へ75%で `FROZEN` を付与し、設定持続時間はLv.1の2秒からLv.5の10秒までレベルごとに2秒増加する。Bossも対象だが、`FROZEN` は共通のCONTROL補正により実適用時間が設定値の25%（Lv.5で2.5秒）となる。凍結による拘束を主価値とし、ファイアーボールと同じ基礎性能にはそろえない。

> [!note] アーケインフロー
> `starter` node `1347` から使用許可を与えるバインド必須パッシブ。魔法タグ付きスキルの成功履歴をプレイヤー単位で保持し、直前と異なる魔法スキルの詠唱時間だけを追加短縮する。Lv.1は5%、Lv.5は10%で、初回・同一スキル・非魔法スキルでは短縮しない。短縮成立時は紫色のリング粒子を表示する。攻撃・回復・状態異常を追加しないためDPS算出対象外とし、詠唱短縮による実戦DPSへの影響は各スキルの詠唱込み周期へ別途反映する。

> [!note] MANA持続の受入条件
> Lv.1〜5の標準戦闘（通常敵1体・5〜7秒）では、初期スキルを2〜3回使ってもポーションやメディテーションを必須にしない。クラスLv.30以降の30秒継続戦闘では、解放済みの高コストskillを混ぜるとMPが明確に減少し、60秒の強敵戦では通常攻撃・ポーション・戦闘後のメディテーションを選べる状態を目標とする。
