## 2. バランス目標

同じ Player Lv.・同じ更新帯・標準装備で比較する。基準となる最終 HP・解決攻撃力 `R`・有効防御 `D`、TTK、耐久時間は [[../02-成長曲線|成長曲線]]と[[../01-戦闘計算|戦闘計算]]に従う。

| 指標 | メイジの方針 |
| :-- | :-- |
| 主力分野 | 魔法単体・条件付き連鎖・前方範囲攻撃 |
| 生存 | MANAと射程で戦い、HP・物理防御へ偏らせない |
| 弱み | 近接・間接の直接 skill は class から許可しない |
| 構成差 | skilltree で追加する魔法 skill とresource・範囲系の選択で作る |

## 3. 数値配分

| 方針 | 内容 |
| :-- | :-- |
| 基礎値 | MANA・知力・魔法防御を高めにする |
| 成長 | 知力・魔法防御を優先し、MANAの成長は初期戦闘を保ったまま抑える |
| 正本 | `40_filebase/20.features.class/v1.mage.yml` |

具体的な数値は、共通アンカーの130%程度を上限として、class・skilltree・equipment の増加分を **25% / 25% / 50%** の出発点で配分する。`NORMAL_ATTACK_DEGRADATION_DELAY` は初期値 `2`、クラスレベル1上昇ごとの増加量 `0.1` とし、通常攻撃劣化の開始を遅延させる。正式なステータス値はプレイテストで確定する。

### リソース設計

Lv.1の最大MPと初期スキル消費は変更せず、クラスレベル上昇によるリソースの増加量だけを抑える。`v1.mage.yml` の `growthPerLevel` は `MAX_MANA +3`、`MP_REGEN +0.05` とし、魔法攻撃力へ直結する `INTELLIGENCE +1.4` は維持する。範囲・制圧系のskilltree解放スキルは、初期スキルより高い固定MPコストで選択的に負荷を作る。

### 現行skilltree基礎幹

現行の `starter` skilltreeにはメイジCP nodeを51個配置します。27node・27CPの汎用幹から、魔導、炎、雷、氷の4専門円環へ分岐します。各円環は4個の1CP小nodeと1個の2CP notableで、専門円環は合計20node・24CPです。アーケインフロー、スパーキング、フロストブリザード、フロストボール、ファイアーボールは関連する小nodeから独立した1CP leafとして分岐し、全取得は55メイジCPです。
