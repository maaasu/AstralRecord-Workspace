## 1. クラス概要

| 項目 | 内容 |
| :-- | :-- |
| クラス ID | `mage` |
| 役割 | 魔法・遠距離型 |
| レベル上限 | Lv.100 |
| 解放条件 | 冒険者 Lv.10 |

## 2. バランス目標

同じ Player Lv.・同じ更新帯・標準装備で比較する。基準となる最終 HP・解決攻撃力 `R`・有効防御 `D`、TTK、耐久時間は [[../02-成長曲線|成長曲線]]と[[../01-戦闘計算|戦闘計算]]に従う。

| 指標 | メイジの方針 |
| :-- | :-- |
| 主力分野 | 魔法単体・条件付き連鎖・前方範囲攻撃 |
| 生存 | MANAと射程で戦い、HP・物理防御へ偏らせない |
| 弱み | 近接・間接の直接 skill は class から許可しない |
| 構成差 | skilltree で追加する魔法 skill とresource・範囲系の選択で作る |

## 3. 数値配分

| 方針 | 内容 |
| :-- | :-- |
| 基礎値 | MANA・知力・魔法防御を高めにする |
| 成長 | MANA・知力・魔法防御を優先する |
| 正本 | `40_filebase/20.features.class/v1.mage.yml` |

具体的な数値は、共通アンカーの130%程度を上限として、class・skilltree・equipment の増加分を **25% / 25% / 50%** の出発点で配分する。正式なステータス値はプレイテストで確定する。

### 現行skilltree基礎幹

現行の `starter` skilltreeにはメイジCP nodeを50個配置します。27node・27CPの汎用幹から、魔導、炎、雷、氷の4専門円環へ分岐します。各円環は4個の1CP小nodeと1個の2CP notableで、専門円環は合計20node・24CPです。アーケインフロー、スパーキング、フロストブリザードは関連する小nodeから独立した1CP leafとして分岐し、全取得は54メイジCPです。

## 4. Skill / 装備

### class が許可する初期 skill

| ID | skill 名 | 役割 |
| :-- | :-- | :-- |
| `adventurer_mana_burst` | マナバースト | 魔法の前方範囲攻撃 |
| `adventurer_lightning_bolt` | ライトニングボルト | 魔法の単体・条件付き連鎖攻撃 |
| `mage_fireball` | ファイアーボール | 遠距離から着弾範囲を攻撃する火属性魔法 |
| `mage_heal_aura` | ヒールオーラ | 周囲プレイヤーの即時範囲回復 |

上記4個をメイジの `usableSkills` に定義する。アーケインフロー、スパーキング、フロストブリザードはclassへ追加せず、skilltree node `1347`～`1349` の `skill` 効果から許可する。Administratorの検証用 `usableSkills` は維持する。

### 単体・詠唱込み DPS の確認枠

個別 skill は主対象1体、命中100%、会心・防御・アクションリング操作時間なし、詠唱がある場合は `CD + 詠唱時間` を周期として確認する。既存の初期 skill はいずれも **Skill Lv.5** を前提とする。`R` はそのレベル・装備・skilltree構成で解決した値を使う。

| skill | Skill Lv. | 計算式 | DPS |
| :-- | :-- | :-- | :-- |
| マナバースト | 5 | `R × 1.32 ÷ (3.0 + 0.1)` | 構成ごとに試算 |
| ライトニングボルト | 5 | `R × 1.74 ÷ (3.0 + 0.2)` | 構成ごとに試算 |
| ファイアーボール | 5 | `R × 1.32 ÷ (4.0 + 0.2)` | 構成ごとに試算 |
| スパーキング | 5 | `R × 1.00 ÷ (8.0 + 0.2)` | 構成ごとに試算 |
| フロストブリザード | 5 | `R × 0.24 × 20 ÷ (20.0 + 1.0)` | 構成ごとに試算 |

> [!note] 範囲攻撃の評価
> ファイアーボールは単体DPSをライトニングボルトより低く抑え、半径2.25mへ最大4体を巻き込めたときに価値が上がる。マナバーストの複数対象とライトニングボルトの連鎖も、単体 DPS とは別の戦闘シナリオで評価する。

> [!note] ヒールオーラ
> ダメージを発生させないためDPS算出対象外とする。Lv.1はMP 6・2.0秒ごとに各対象5回復、Lv.5はMP 6・1.6秒ごとに各対象9回復で、範囲内の複数プレイヤーへ同時適用する。

> [!note] スパーキング
> `starter` node `1348` から使用許可を与える。Lv.1〜5の雷弾数は5 / 7 / 9 / 11 / 13、各対象は1発動につき1回だけ100%雷魔法ダメージを受ける。25%感電の期待DoTは別枠で評価し、複数雷弾を単体倍率へ加算しない。マナバーストの複数対象とライトニングボルトの連鎖も、単体 DPS とは別の戦闘シナリオで評価する。

> [!note] フロストブリザード
> `starter` node `1349` から使用許可を与える。MP40、持続10秒、20秒クールダウン、1秒詠唱とし、Lv.5は24%氷魔法ダメージを最大20回適用する。単体完走DPSは `R × 0.2286` を目安とし、半径2.75m・最大8体への同時攻撃とノックバック耐性依存の回転拘束は別の集団戦価値として評価する。

> [!note] アーケインフロー
> `starter` node `1347` から使用許可を与えるバインド必須パッシブ。魔法タグ付きスキルの成功履歴をプレイヤー単位で保持し、直前と異なる魔法スキルの詠唱時間だけを追加短縮する。Lv.1は5%、Lv.5は10%で、初回・同一スキル・非魔法スキルでは短縮しない。短縮成立時は紫色のリング粒子を表示する。攻撃・回復・状態異常を追加しないためDPS算出対象外とし、詠唱短縮による実戦DPSへの影響は各スキルの詠唱込み周期へ別途反映する。
