## 1. クラス概要

| 項目       | 方針                                                                                   |
| :--------- | :------------------------------------------------------------------------------------- |
| クラス ID  | `adventurer`                                                                         |
| 役割       | 近接・間接・魔法を試せる初期クラス                                                     |
| レベル上限 | **Lv.30**                                                                        |
| expRate    | 58%                                                                                    |
| 攻撃軸     | 共通`ATTACK`。`MELEE_ATTACK` / `RANGED_ATTACK` / `MAGIC_ATTACK` は特化させない |
| 生存       | HP・防御・回避は平均。                                                                 |
| 強み       | 装備と skill を変えて、複数の戦い方に対応できる                                        |
| 弱み       | 単一分野の DPS・瞬間火力・生存力は専門職より低い                                       |
| 特徴       | 専門職の代わりになることではなく、転職先を試しながら選べることにある。                 |

## 2. バランス目標

同じ職業レベル、同じ更新帯、標準装備で専門職と比較する。

基準値:  [[../02-成長曲線|成長曲線]] から取り、実際の強さは [[../01-戦闘計算|戦闘計算]] で確認する。

| 指標                      | 冒険者の目標                                 |
| :------------------------ | :------------------------------------------- |
| 専門職の主力分野          | 標準実戦 DPS の 80～90% 程度                 |
| 非主力分野                | 装備・skill を寄せた場合に 70～85% 程度      |
| 同格 Mob への TTK         | 5～7 秒の範囲                                |
| 同格 Mob に対する耐久時間 | 8～10 秒を基準                               |
| 複数系統の構成            | 対応力は高いが、単一系統の最適構成より低火力 |

## 4. Skill / 装備

### 初期 skill

以下は職業 Lv.1 で使い始める攻撃 skill の基準値である。倍率は対応する攻撃力 `R` に掛ける値で、`100%` は `R × 1.00` を表す。

> [!note] ✏️ 発動経路の前提
> 下表は、アクションリングを開いて選択する操作コストを含めた値である。左クリックへ割り当てても倍率・コスト・CDは変えず、操作を短縮できる便利機能として扱う。単体攻撃 skill は、通常攻撃より明確に高い倍率を持たせる。

| ID                         | skill 名         | 効果                                          |   Lv.1倍率 |   Lv.5倍率 | コスト  | CD / 詠唱     |
| :------------------------- | :--------------- | :-------------------------------------------- | ---------: | ---------: | :------ | :------------ |
| `adventurer_astral_edge` | アストラルエッジ | 視点を基準に前方5.5mを右→左へ薙ぎ払い、進行位置で最大5体へ命中。命中後に突き刺し。 | 100% + 50% | 120% + 60% | EN 8    | 2.5秒 / なし  |
| `adventurer_blast_arrow` | ブラストアロー | 射程14mを飛翔し、最初の敵または地形への着弾地点から半径2.25mへ最大6体を巻き込む無属性の間接攻撃。 | 120% | 144% | EN 12 | 5.0秒 / 0.3秒 |

攻撃 skill は Lv.2～5 で `SKILL_DAMAGE_INCREASE +5%` を1回ずつ加算する。したがって、Lv.5 は Lv.1 の基礎倍率に対して20%増加する。skill は通常攻撃より高い倍率を持たせ、CD・コスト・詠唱・射程で強さを調整する。

### Lv.30 攻撃 skill DPS

職業 Lv.30、各攻撃 skill Lv.5、`ATTACK = R = 151.4`、命中100%、会心・防御・操作時間なし、各 skill の CD が常に回復している条件で、1体あたりを計算する。

| skill                                          | 計算式                            |              DPS |
| :--------------------------------------------- | :-------------------------------- | ---------------: |
| アストラルエッジ                               | `151.4 × (1.20 + 0.60) ÷ 2.5` |           109.01 |
| ブラストアロー（1体）                          | `151.4 × 1.44 ÷ 5.0`          |            43.60 |
| スマッシュ（主対象のみ）                       | `151.4 × 2.88 ÷ 7.5`          |            58.14 |
| クイックショット                               | `151.4 × 1.80 ÷ 2.0`          |           136.26 |
| ライトニングボルト（主対象のみ）               | `151.4 × 1.74 ÷ 3.0`          |            87.81 |
| 標準3 skill 合計（最終補正前）                 | `109.01 + 136.26 + 87.81`       |           333.08 |
| 標準3 skill 合計（`FINAL_DAMAGE_MULTIPLIER 130%`適用後） | `333.08 × 1.30`       | **433.00** |

```text
スキルDPS
= R × ((1.20 + 0.60) ÷ 2.5 + 1.80 ÷ 2.0 + 1.74 ÷ 3.0)
× 1.30
= 151.4 × 2.2 × 1.30
≒ 433.00
```

クイックショットは、旅人の射撃を置き換える軽量の間接攻撃である。射程12m、毎tick2.2m、当たり半径0.45mの非貫通仮想飛翔体で、最初のMob 1体だけへ命中する。PvPは対象外であり、ブロックで停止する一方、水は遮蔽として扱わない。`RANGED` / `NONE` を使用し、弓限定を新設せず既存の有効な主手`WEAPON`判定だけを必要とする。ジェムは星晶錬成の無印・初級原石交換で入手し、冒険者の`usableSkills`が使用を許可する。通常攻撃との追加GCD・キャンセルは持たない。

### ライトニングボルト

ライトニングボルトは、冒険者が扱う中距離・単体の雷属性魔法である。射程14m、速度2.8m/tick、当たり半径0.45mの非貫通仮想飛翔体が最初のMob 1体へ命中し、主対象へ `MAGIC` / `LIGHTNING` の145%（Lv.5で174%）を適用する。詠唱は4 tick、MP消費は10、CDは60 tickとし、通常時の単体性能を既存のクイックショットより抑える。

命中対象から水平半径5m・上下5m以内の候補を距離順・UUID順で確認し、別のMobが `ConditionType.SHOCKED` の有効状態を持つ場合だけ最大2体へ連鎖する。連鎖倍率は基礎40%（Lv.5で48%）で、非感電対象は飛ばして次の感電対象を選ぶ。主対象自身の感電有無は問わず、ライトニングボルト自身は感電を付与しない。連鎖は1段限りで、連鎖先からの再連鎖・同一対象への再命中・PvP/NPCへの命中はない。Lv.5で感電対象を2体満たす理想条件の合計は `151.4 × (1.74 + 0.48 × 2) ÷ 3.0 = 136.26 DPS`（最終補正前）であり、条件付き追加火力として扱う。

発動時は `SKILL_MAGE_LIGHTNING` の青白い収束と高速の雷光を表示し、通常命中は同粒子と雷撃音で示す。連鎖時は主対象から感電対象へ `CONDITION_SHOCKED_SPARK` を枝分かれさせ、通常命中と連鎖発生を区別する。ジェム交換と冒険者 / Administrator の使用許可は既存の冒険者 skill 方針へ追加する。

現行リポジトリには比較対象として挙げられた `mage_chain_lightning` の定義・executor は存在しない。将来それを無条件連鎖として追加する場合でも、ライトニングボルトは通常時の単体完結と `SHOCKED` 条件付き連鎖を差別化軸とする。

スマッシュは主対象への瞬間火力を評価するための skill であり、CDが長く副対象へのダメージが状況依存となるため、既存3 skill 合計へは加算しない。主対象だけを対象にした参考値は、Lv.5で `151.4 × 2.88 ÷ 7.5 = 58.14`、`FINAL_DAMAGE_MULTIPLIER 130%` 適用後で `75.58` となる。副対象へのダメージは、主対象の成立ダメージを基準にLv.1で48%、Lv.5で57.6%相当となる。副対象1体を含む2体条件では、Lv.5の追加分は最終補正前で `151.4 × 2.88 × 0.20 = 87.21`、CD基準で `+11.63 DPS` 相当となる。

### 補助パッシブ: メディテーション

`adventurer_meditation` / `implementationId: adventurer_meditation`、表示名「メディテーション」。冒険者が安全な場所へ退避して休息するための、バインド必須・自身のみ対象の条件付きパッシブである。

| 条件 | 固定値・仕様 |
| :--- | :--- |
| 発動準備 | バインド中にスニークを100 tick（5秒）連続継続 |
| 発動中 | スニーク継続中だけ有効。MP / EN の既存自然回復量へ `×3` を適用 |
| 中断 | スニーク解除、被ダメージ、通常攻撃、他スキル使用で即時終了し、準備カウントをリセット |
| コスト / CD | 消費なし。能動CDなし。再発動には再度100 tickの準備が必要 |
| その他 | 最大値、固定回復量、HP、防御、攻撃力は変更しない。Lv.1固定で、100 tickと`×3`は成長させない |

発動時は円形 particle と音を一度再生し、発動中は低密度の周回 particle と2秒間隔の環境音で、自然回復倍率が有効な状態をプレイヤーへ知らせる。環境音は `World#playSound` / `SoundCategory.PLAYERS` により音源位置の周囲にいるプレイヤーにも聞こえるが、自然回復倍率の効果対象は自身のみとする。

自然回復の基礎量は既存どおり `MP_REGEN / 5`、`ENERGY_REGEN / 5`（1秒ごとの処理）とし、発動中だけそれぞれへ3倍を掛ける。したがって5秒の無行動準備、被弾・攻撃による中断を含めた実戦の平均回復量で評価し、常時回復強化としてDPSやTTKへ加算しない。近接・間接・魔法のいずれでも利用できる共通の休息手段とする。

習得・ジェム交換・クラス使用許可は既存の冒険者スキル方針に従い、専用のスキルツリーノードは追加しない。利用には習得済み個体をパッシブ枠へバインドする必要がある。

### ブラストアロー

ブラストアローは単体高火力ではなく、密集時の着弾地点選択を学ぶための範囲 skill として既存3 skill 合計へ加算しない。Lv.5の1体命中は `151.4 × 1.44 ÷ 5.0 = 43.60 DPS`、`FINAL_DAMAGE_MULTIPLIER 130%` 適用後で `56.68 DPS` となり、旅人の射撃（最終補正前87.81 DPS）を下回る。2体を巻き込めた場合は合計 `87.21 DPS`（最終補正後 `113.37 DPS`）となる。倍率はLv.2～5の `SKILL_DAMAGE_INCREASE +5%` だけで伸ばし、半径2.25m・射程14m・最大6体はLvによらず固定とする。

### ブラストアローの命中規則と利用条件

- 発動時の照準へ毎tick 1.35m進む仮想矢を射出し、最初の敵または地形ブロックへの衝突地点でのみ一度爆発する。Mob の swept capsule 交差が Block 面より厳密に手前なら Mob 命中を優先し、同距離または Block 面が手前なら Block 着弾とする。最大射程14mまで無衝突の場合は爆発せず消滅する。
- 爆発は中心・外周を問わず同一倍率の無属性 `RANGED` ダメージを1回与える。持続エリア、追加攻撃、状態異常、ノックバックはない。
- 対象は現行プレイヤーskillのPvE Mob選択規則に従う。NPCを除外し、Bossを含む。プレイヤーは選択対象に含めずPvPでは命中しない。Block 着弾は正確な衝突地点へ演出を表示し、進行方向の手前側へ退避した範囲中心から遮蔽を判定する。爆発中心から対象へのブロック遮蔽がある敵は命中しない。
- 冒険者とAdministratorが `usableSkills` で使用できる。弓装備は既存の冒険者skill共通仕様に従って必須とせず、スキルジェムを `星晶錬成` で通常のskill gem原石1個、または初級原石1個から3個取得して習得する。
- 射出は短いCRIT軌跡と強めの矢音、着弾はELECTRIC_SPARKの拡散とCLOUDのリングで範囲を示す。炎・火薬の粒子を使わず、元素魔法と混同しない。

## 5. 検証

次の3構成を職業 Lv.1、10、20、30（対応する Player Lv.1、4、8、12を目安）で確認する。

| 構成            | 内容                           |
| :-------------- | :----------------------------- |
| 均等型          | 近接・間接・魔法を分散して取得 |
| 近接寄せ        | 近接装備・skill を優先         |
| 間接 / 魔法寄せ | 間接または魔法の一方を優先     |

各構成で次を記録する。

- TTK が 5～7 秒に収まるか
- 耐久時間が 8～10 秒に収まるか
- 通常攻撃と攻撃 skill の DPS 比率
- `MANA` / `ENERGY` の持続時間
- メディテーションの未発動（通常回復）、5秒準備中、発動中（3倍）、各中断直後のMP / EN回復量
- 被弾・通常攻撃・他スキル使用で準備カウントが0へ戻り、スニーク継続後にだけ再発動すること
- 攻撃距離を変えたときの性能差
- 専門職との差が「対応力」か「恒常 DPS」か
