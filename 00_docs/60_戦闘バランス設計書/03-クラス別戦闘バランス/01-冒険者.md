## 1. クラス概要

| 項目       | 方針                                                                                   |
| :--------- | :------------------------------------------------------------------------------------- |
| クラス ID  | `adventurer`                                                                         |
| 役割       | 近接・間接・魔法を試せる初期クラス                                                     |
| レベル上限 | **Lv.30**                                                                        |
| expRate    | 58%                                                                                    |
| 攻撃軸     | 共通`ATTACK`。`MELEE_ATTACK` / `RANGED_ATTACK` / `MAGIC_ATTACK` は特化させない |
| 生存       | HP・防御・回避は平均。                                                                 |
| 強み       | 装備と skill を変えて、複数の戦い方に対応できる                                        |
| 弱み       | 単一分野の DPS・瞬間火力・生存力は専門職より低い                                       |
| 特徴       | 専門職の代わりになることではなく、転職先を試しながら選べることにある。                 |

## 2. バランス目標

同じ職業レベル、同じ更新帯、標準装備で専門職と比較する。

基準値:  [[../02-成長曲線|成長曲線]] から取り、実際の強さは [[../01-戦闘計算|戦闘計算]] で確認する。

| 指標                      | 冒険者の目標                                 |
| :------------------------ | :------------------------------------------- |
| 専門職の主力分野          | 標準実戦 DPS の 80～90% 程度                 |
| 非主力分野                | 装備・skill を寄せた場合に 70～85% 程度      |
| 同格 Mob への TTK         | 5～7 秒の範囲                                |
| 同格 Mob に対する耐久時間 | 8～10 秒を基準                               |
| 複数系統の構成            | 対応力は高いが、単一系統の最適構成より低火力 |

## 4. Skill / 装備

### 初期 skill

以下は職業 Lv.1 で使い始める攻撃 skill の基準値である。倍率は対応する攻撃力 `R` に掛ける値で、`100%` は `R × 1.00` を表す。

> [!note] ✏️ 発動経路の前提
> 下表は、アクションリングを開いて選択する操作コストを含めた値である。左クリックへ割り当てても倍率・コスト・CDは変えず、操作を短縮できる便利機能として扱う。単体攻撃 skill は、通常攻撃より明確に高い倍率を持たせる。

| ID 案                      | skill 名         | 効果                                          |   Lv.1倍率 |   Lv.5倍率 | コスト  | CD / 詠唱     |
| :------------------------- | :--------------- | :-------------------------------------------- | ---------: | ---------: | :------ | :------------ |
| `adventurer_astral_edge` | アストラルエッジ | 視点を基準に前方5.5mを右→左へ薙ぎ払い、進行位置で最大5体へ命中。命中後に突き刺し。 | 100% + 50% | 120% + 60% | EN 8    | 2.5秒 / なし  |
| `adventurer_smash`      | スマッシュ       | 前方の主対象1体を上空から地面へ叩き落とす。着地点から半径2m以内に別の敵がいる場合、その敵へ主対象の成立ダメージ20%とノックバック。 |       240% |       288% | EN 16   | 7.5秒 / 0.6秒 |
| `adventurer_shot`        | 旅人の射撃       | 射程12mの単体・間接攻撃                       |       145% |       174% | EN 8    | 3.0秒 / なし  |
| `adventurer_arcane_bolt` | 旅人の魔弾       | 射程12m・半径1.5mの単体 / 小範囲・魔法攻撃    |       155% |       186% | MANA 10 | 3.5秒 / 0.4秒 |
| `adventurer_step`        | 旅人の退避       | 後方へ最大4m移動。ダメージなし                |         — |         — | EN 10   | 6.0秒 / なし  |

攻撃 skill は Lv.2～5 で `SKILL_DAMAGE_INCREASE +5%` を1回ずつ加算する。したがって、Lv.5 は Lv.1 の基礎倍率に対して20%増加する。skill は通常攻撃より高い倍率を持たせ、CD・コスト・詠唱・射程で強さを調整する。

#### スマッシュの追加効果

- 主対象は1体のみ。主対象が着地した地点を中心に、半径2m以内の「主対象以外」の敵を副対象とする。
- 副対象には、主対象への成立ダメージの20%を与える。副対象へのダメージは単体高火力の評価へ加算せず、2体条件での付加価値として扱う。
- 副対象には着地点から外向きのノックバックを与える。基準量は `baseKnockback × 1.0` とし、`KNOCKBACK_RESISTANCE` の通常補正を適用する。
- 主対象には上方向への打ち上げを行わず、上空から落下して地面へ叩き付ける演出とする。主対象の落下待機は `8 tick`、発動時の詠唱は `12 tick（0.6秒）` とする。追加のスタンは持たせない。
- 副対象は最大8体までとし、着地点から外向きのノックバックを与える。主対象へのダメージ倍率・CD・コストは変わらない。副対象がいない場合は単体高火力だけが成立する。

### Lv.30 攻撃 skill DPS

職業 Lv.30、各攻撃 skill Lv.5、`ATTACK = R = 151.4`、命中100%、会心・防御・操作時間なし、各 skill の CD が常に回復している条件で、1体あたりを計算する。

| skill                                          | 計算式                            |              DPS |
| :--------------------------------------------- | :-------------------------------- | ---------------: |
| アストラルエッジ                               | `151.4 × (1.20 + 0.60) ÷ 2.5` |           109.01 |
| スマッシュ（主対象のみ）                       | `151.4 × 2.88 ÷ 7.5`          |            58.14 |
| 旅人の射撃                                     | `151.4 × 1.74 ÷ 3.0`          |            87.81 |
| 旅人の魔弾                                     | `151.4 × 1.86 ÷ 3.5`          |            80.46 |
| 既存3 skill 合計（最終補正前）                 | `109.01 + 87.81 + 80.46`        |           277.28 |
| 既存3 skill 合計（`FINAL_DAMAGE_MULTIPLIER 130%`適用後） | `277.28 × 1.30`       | **360.46** |

```text
スキルDPS
= R × ((1.20 + 0.60) ÷ 2.5 + 1.74 ÷ 3.0 + 1.86 ÷ 3.5)
× 1.30
= 151.4 × 1.8314 × 1.30
≒ 360.46
```

スマッシュは主対象への瞬間火力を評価するための skill であり、CDが長く副対象へのダメージが状況依存となるため、既存3 skill 合計へは加算しない。主対象だけを対象にした参考値は、Lv.5で `151.4 × 2.88 ÷ 7.5 = 58.14`、`FINAL_DAMAGE_MULTIPLIER 130%` 適用後で `75.58` となる。副対象へのダメージは、主対象の成立ダメージを基準にLv.1で48%、Lv.5で57.6%相当となる。副対象1体を含む2体条件では、Lv.5の追加分は最終補正前で `151.4 × 2.88 × 0.20 = 87.21`、CD基準で `+11.63 DPS` 相当となる。

## 5. 検証

次の3構成を職業 Lv.1、10、20、30（対応する Player Lv.1、4、8、12を目安）で確認する。

| 構成            | 内容                           |
| :-------------- | :----------------------------- |
| 均等型          | 近接・間接・魔法を分散して取得 |
| 近接寄せ        | 近接装備・skill を優先         |
| 間接 / 魔法寄せ | 間接または魔法の一方を優先     |

各構成で次を記録する。

- TTK が 5～7 秒に収まるか
- 耐久時間が 8～10 秒に収まるか
- 通常攻撃と攻撃 skill の DPS 比率
- `MANA` / `ENERGY` の持続時間
- 攻撃距離を変えたときの性能差
- 専門職との差が「対応力」か「恒常 DPS」か
