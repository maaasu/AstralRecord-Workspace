## 1. クラス概要

| 項目       | 方針                                                                                   |
| :--------- | :------------------------------------------------------------------------------------- |
| クラス ID  | `adventurer`                                                                         |
| 役割       | 近接・間接・魔法を試せる初期クラス                                                     |
| レベル上限 | **Lv.30**                                                                        |
| expRate    | 58%                                                                                    |
| 攻撃軸     | 共通`ATTACK`。`MELEE_ATTACK` / `RANGED_ATTACK` / `MAGIC_ATTACK` は特化させない |
| 生存       | HP・防御・回避は平均。                                                                 |
| 強み       | 装備と skill を変えて、複数の戦い方に対応できる                                        |
| 弱み       | 単一分野の DPS・瞬間火力・生存力は専門職より低い                                       |
| 特徴       | 専門職の代わりになることではなく、転職先を試しながら選べることにある。                 |

## 2. バランス目標

同じ職業レベル、同じ更新帯、標準装備で専門職と比較する。

基準値:  [[../02-成長曲線|成長曲線]] から取り、実際の強さは [[../01-戦闘計算|戦闘計算]] で確認する。

| 指標                      | 冒険者の目標                                 |
| :------------------------ | :------------------------------------------- |
| 専門職の主力分野          | 標準実戦 DPS の 80～90% 程度                 |
| 非主力分野                | 装備・skill を寄せた場合に 70～85% 程度      |
| 同格 Mob への TTK         | 5～7 秒の範囲                                |
| 同格 Mob に対する耐久時間 | 8～10 秒を基準                               |
| 複数系統の構成            | 対応力は高いが、単一系統の最適構成より低火力 |

## 3. 数値配分

### 3.1 読み方

数値を確認するときは、まず「進行対応」と「最終ステータス」を見る。status 別の詳細内訳は、最終値が想定どおりに増えているか、どの獲得源を調整すべきかを確認するための補助情報である。

> [!important] ❗ この表の前提
> - `Player Lv.` は職業 Lv. と強制同期しない進行上の目安である。対応の考え方は [[../02-成長曲線#3.4 Player Level・Tier 1 class・equipment の進行|成長曲線]]を正本とする。
> - 「合計」は class・Player Lv. 成長・skilltree・標準 equipment を合算した、buff なしの例である。
> - `R` / `D` は `ATTACK` / `DEFENSE` そのものではなく、基本能力値・種別 status・各補正を [[../01-戦闘計算|戦闘計算]]で解決した実効結果である。この資料は実効結果の獲得源別寄与を示し、個々の raw status 値はマスタ設計で別途定める。

### 3.2 進行対応

| 職業 Lv. | Player Lv.目安 | 共通の装備更新帯 | この時点の確認対象 |
| -------: | -------------: | :--------------- | :----------------- |
|        1 |              1 | 初期装備         | 共通基礎値         |
|       15 |              5 | 第1更新          | 第1更新後の実戦値  |
|       30 |             10 | 第2更新          | 冒険者の上限値     |

職業 Lv.は Player Lv.より先行する目安であり、相互に設定する強制同期ではない。冒険者の職業 Lv.30 は Player Lv.10 到達時を受入目標とする。Player Lv.5 ごとの共通更新帯をそのまま示し、各更新帯で主力 equipment を1～2部位更新できることを確認する。

### 3.4 配分の判断基準

Lv.1 から各アンカーまでの増加分は、[[../02-成長曲線#3.3 class と equipment への配分|成長曲線]]の目安に従い、次の比率を出発点とする。各 status の例値は、プレイテストで TTK・耐久時間・resource 持続を確認してから正式値へ置き換える。

| 獲得源                  | 増加分の目安 | 担当する成長実感             |
| :---------------------- | -----------: | :--------------------------- |
| class + Player Lv. 成長 |          25% | 職業らしさと基礎成長         |
| skilltree               |          25% | 構成選択・分岐の手触り       |
| equipment               |          50% | 更新品を得たときの明確な上昇 |

> [!tip] 💡 調整の順序
> まずこの節の合計値を変えて目標 TTK・耐久時間を合わせる。次に詳細内訳を見て、職業らしさなら class、構成差なら skilltree、更新感なら equipment を調整する。合計値を変えずに内訳だけを動かす場合も、上の比率から大きく外れる理由を残す。

### 3.6 現行skilltree基礎幹

冒険者の現行基礎幹は29node、各1冒険者CPです。配分は `STRENGTH` 3、`DEXTERITY` 3、`INTELLIGENCE` 3、`VITALITY` 3、`AGILITY` 3、`LUCK` 2、`ATTACK` 3、`DEFENSE` 2、`MAGIC_DEFENSE` 2、`MAX_HEALTH +10` 2、`MAX_MANA +10` 1、`MAX_ENERGY +5` 2とします。

4方向の各2node目を一次職基礎幹の入口anchorとします。転職条件となる冒険者Lv.10では9CPを得ているため、4方向を2nodeずつ開く8CPでソードマン・ハンター・メイジの全入口へ到達できます。派生職でも祖先条件により表示と効果を維持し、消費元は冒険者CPです。敏捷枝から1冒険者CPの独立leaf `1350` を伸ばし、`administrator_just_dodge` の使用許可を与えます。

全職共通root `1047` は `adventurer_meditation` の使用許可nodeとします。旧rootの `MAX_HEALTH / MAX_MANA / MAX_ENERGY` 各10は命脈・循環・活風の無料nodeへ移し、無料領域全体のstatus総量を維持します。冒険者classからメディテーションの直接使用許可は外し、root解放を使用条件とします。

## 4. Skill / 装備

### 初の武器更新（ノクス）

ノクスソード・ノクスボウ・ノクススタッフは、Player Lv.2 の解決攻撃力 `R ≈ 35` を目標とする初回武器更新である。`02-成長曲線` の Player Lv.1 `R = 17` と Lv.5 `R = 87` の線形補間を基準にし、主攻撃力は固定 `17`、強化上限は Lv.10、各強化段階の主攻撃力増加は固定 `+1` とする。冒険者 Lv.1 の基礎値と各武器の副ステータスを含め、最大強化時の実効値がこの目標へ近づく構成とする。Player Lv.2 はバランス目標であり、装備の `requiredLevel` とは別の値である。

## 5. 検証

次の3構成を職業 Lv.1、10、20、30（対応する Player Lv.1、4、8、12を目安）で確認する。

| 構成            | 内容                           |
| :-------------- | :----------------------------- |
| 均等型          | 近接・間接・魔法を分散して取得 |
| 近接寄せ        | 近接装備・skill を優先         |
| 間接 / 魔法寄せ | 間接または魔法の一方を優先     |

各構成で次を記録する。

- TTK が 5～7 秒に収まるか
- 耐久時間が 8～10 秒に収まるか
- 通常攻撃と攻撃 skill の DPS 比率
- `MANA` / `ENERGY` の持続時間
- skill masterに定義された初期skillとskilltree解放skillの使用可否
- 攻撃距離を変えたときの性能差
- 専門職との差が「対応力」か「恒常 DPS」か
