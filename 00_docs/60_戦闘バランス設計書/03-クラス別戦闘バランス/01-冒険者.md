## 1. クラス概要

| 項目       | 方針                                                                                   |
| :--------- | :------------------------------------------------------------------------------------- |
| クラス ID  | `adventurer`                                                                         |
| 役割       | 近接・間接・魔法を試せる初期クラス                                                     |
| レベル上限 | **Lv.30**                                                                        |
| expRate    | 58%                                                                                    |
| 攻撃軸     | 共通`ATTACK`。`MELEE_ATTACK` / `RANGED_ATTACK` / `MAGIC_ATTACK` は特化させない |
| 生存       | HP・防御・回避は平均。                                                                 |
| 強み       | 装備と skill を変えて、複数の戦い方に対応できる                                        |
| 弱み       | 単一分野の DPS・瞬間火力・生存力は専門職より低い                                       |
| 特徴       | 専門職の代わりになることではなく、転職先を試しながら選べることにある。                 |

## 2. バランス目標

同じ職業レベル、同じ更新帯、標準装備で専門職と比較する。

基準値:  [[../02-成長曲線|成長曲線]] から取り、実際の強さは [[../01-戦闘計算|戦闘計算]] で確認する。

| 指標                      | 冒険者の目標                                 |
| :------------------------ | :------------------------------------------- |
| 専門職の主力分野          | 標準実戦 DPS の 80～90% 程度                 |
| 非主力分野                | 装備・skill を寄せた場合に 70～85% 程度      |
| 同格 Mob への TTK         | 5～7 秒の範囲                                |
| 同格 Mob に対する耐久時間 | 8～10 秒を基準                               |
| 複数系統の構成            | 対応力は高いが、単一系統の最適構成より低火力 |

## 4. Skill / 装備

### 初期 skill

以下は職業 Lv.1 で使い始める攻撃 skill の基準値である。倍率は対応する攻撃力 `R` に掛ける値で、`100%` は `R × 1.00` を表す。

> 下表は、アクションリングを開いて選択する操作コストを含めた値である。左クリックへ割り当てても倍率・コスト・CDは変えず、操作を短縮できる便利機能として扱う。単体攻撃 skill は、通常攻撃より明確に高い倍率を持たせる。

攻撃 skill は Lv.2～5 で `SKILL_DAMAGE_INCREASE +5%` を1回ずつ加算する。したがって、Lv.5 は Lv.1 の基礎倍率に対して20%増加する。skill は通常攻撃より高い倍率を持たせ、CD・コスト・詠唱・射程で強さを調整する。

### Lv.30 攻撃 skill DPS

職業 Lv.30、各攻撃 skill Lv.5、`ATTACK = R = 151.4`、命中100%、会心・防御・操作時間なし、各 skill の CD が常に回復している条件で、1体あたりを計算する。

| skill                                                      | 計算式                                |              DPS |
| :--------------------------------------------------------- | :------------------------------------ | ---------------: |
| アストラルエッジ                                           | `151.4 × (1.20 + 0.60) ÷ 2.5`     |           109.01 |
| ブラストアロー（1体）                                      | `151.4 × 1.44 ÷ 5.0`              |            43.60 |
| スマッシュ（主対象のみ）                                   | `151.4 × 2.88 ÷ 7.5`              |            58.14 |
| クイックショット                                           | `151.4 × 1.80 ÷ 2.0`              |           136.26 |
| ライトニングボルト（主対象のみ）                           | `151.4 × 1.74 ÷ 3.0`              |            87.81 |
| マナバースト（1体・CD基準）                                | `151.4 × 1.32 ÷ 3.0`              |            66.62 |
| マナバースト（2体・CD基準）                                | `151.4 × 1.32 × 2 ÷ 3.0`         |           133.23 |
| マナバースト（1体・詠唱込み）                              | `151.4 × 1.32 ÷ (3.0 + 0.1)`      |            64.47 |
| マナバースト（2体・詠唱込み）                              | `151.4 × 1.32 × 2 ÷ (3.0 + 0.1)` |           128.93 |
| 標準3 skill 合計（最終補正前）                             | `109.01 + 136.26 + 87.81`           |           333.08 |
| 標準3 skill 合計（`FINAL_DAMAGE_MULTIPLIER 130%`適用後） | `333.08 × 1.30`                    | **433.00** |

```text
スキルDPS
= R × ((1.20 + 0.60) ÷ 2.5 + 1.80 ÷ 2.0 + 1.74 ÷ 3.0)
× 1.30
= 151.4 × 2.2 × 1.30
≒ 433.00
```

## 5. 検証

次の3構成を職業 Lv.1、10、20、30（対応する Player Lv.1、4、8、12を目安）で確認する。

| 構成            | 内容                           |
| :-------------- | :----------------------------- |
| 均等型          | 近接・間接・魔法を分散して取得 |
| 近接寄せ        | 近接装備・skill を優先         |
| 間接 / 魔法寄せ | 間接または魔法の一方を優先     |

各構成で次を記録する。

- TTK が 5～7 秒に収まるか
- 耐久時間が 8～10 秒に収まるか
- 通常攻撃と攻撃 skill の DPS 比率
- `MANA` / `ENERGY` の持続時間
- メディテーションの未発動（通常回復）、5秒準備中、発動中（3倍）、各中断直後のMP / EN回復量
- 被弾・通常攻撃・他スキル使用で準備カウントが0へ戻り、スニーク継続後にだけ再発動すること
- 攻撃距離を変えたときの性能差
- 専門職との差が「対応力」か「恒常 DPS」か
