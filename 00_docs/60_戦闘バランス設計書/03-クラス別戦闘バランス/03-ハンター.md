## 1. クラス概要

| 項目 | 内容 |
| :-- | :-- |
| クラス ID | `hunter` |

| レベル上限 | Lv.100 |
| 解放条件 | 冒険者 Lv.10 |

## 2. バランス目標

同じ Player Lv.・同じ更新帯・標準装備で比較する。基準となる最終 HP・解決攻撃力 `R`・有効防御 `D`、TTK、耐久時間は [[../02-成長曲線|成長曲線]]と[[../01-戦闘計算|戦闘計算]]に従う。

| 指標 | ハンターの方針 |
| :-- | :-- |
| 主力分野 | 間接単体・安全距離からの範囲攻撃 |
| 生存 | 距離と移動で被弾を抑え、近接耐久へ偏らせない |
| 弱み | 近接・魔法の直接 skill は class から許可しない |
| 構成差 | skilltree で追加する間接 skill と機動・命中系の選択で作る |

## 3. 数値配分

| 方針 | 内容 |
| :-- | :-- |
| 基礎値 | ENERGY・敏捷・移動速度を高めにする |
| 成長 | 攻撃・敏捷・ENERGYを優先する |
| 正本 | `40_filebase/20.features.class/v1.hunter.yml` |

具体的な数値は、共通アンカーの130%程度を上限として、class・skilltree・equipment の増加分を **25% / 25% / 50%** の出発点で配分する。正式なステータス値はプレイテストで確定する。

### 現行skilltree基礎幹

現行の基礎幹は27node、各1ハンターCPです。配分は `DEXTERITY` 6、`AGILITY` 5、`ATTACK` 5、`MAX_ENERGY +5` 3、`MAX_HEALTH +10` 3、`LUCK` 2、`DEFENSE` 2、`MAGIC_DEFENSE` 1とし、Class Lv.28の27CPで全取得できます。冒険者4方向の内側anchorから直接伸びる全員向けの幹であり、他職の非表示nodeを中継しません。ビルド用status nodeと実skill nodeは今回未実装です。

## 4. Skill / 装備

### class が許可する配布 skill

| ID | skill 名 | 役割 |
| :-- | :-- | :-- |
| `adventurer_blast_arrow` | ブラストアロー | 間接の範囲攻撃 |
| `adventurer_quick_shot` | クイックショット | 間接の単体主力攻撃 |
| `hunter_fade_shot` | フェイドショット | 散弾と後退を組み合わせる機動射撃 |

上記3個だけをハンターの `usableSkills` に定義する。これ以外の skill は class に追加せず、skilltree の `skill` 効果で使用許可を与える。

### 単体・詠唱込み DPS の確認枠

個別 skill は主対象1体、命中100%、会心・防御・アクションリング操作時間なし、詠唱がある場合は `CD + 詠唱時間` を周期として確認する。既存の配布 skill はいずれも **Skill Lv.5** を前提とする。`R` はそのレベル・装備・skilltree構成で解決した値を使う。

| skill | Skill Lv. | 計算式 | DPS |
| :-- | :-- | :-- | :-- |
| ブラストアロー | 5 | `R × 1.44 ÷ (5.0 + 0.3)` | 構成ごとに試算 |
| クイックショット | 5 | `R × 1.80 ÷ 2.0` | 構成ごとに試算 |
| フェイドショット（5本全弾） | 5 | `R × 1.92 ÷ 4.0` | `R × 0.48` |

> [!note] フェイドショットの評価条件
> Lv.5で1本38.4%、5本すべてが同じ主対象へ命中する近距離条件を上限とする。実戦では距離と全角30度の拡散によって命中本数が減る一方、複数対象へ分散でき、発射後に最大3.5m後退する。ブラストアローの複数対象も単体 DPS とは別の戦闘シナリオで評価する。
