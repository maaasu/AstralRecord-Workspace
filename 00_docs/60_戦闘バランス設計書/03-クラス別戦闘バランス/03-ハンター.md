## 2. バランス目標

同じ Player Lv.・同じ更新帯・標準装備で比較する。基準となる最終 HP・解決攻撃力 `R`・有効防御 `D`、TTK、耐久時間は [[../02-成長曲線|成長曲線]]と[[../01-戦闘計算|戦闘計算]]に従う。

| 指標 | ハンターの方針 |
| :-- | :-- |
| 主力分野 | 間接単体・安全距離からの範囲攻撃 |
| 生存 | 距離と移動で被弾を抑え、近接耐久へ偏らせない |
| 弱み | 近接・魔法の直接 skill は class から許可しない |
| 構成差 | skilltree で追加する間接 skill と機動・命中系の選択で作る |

## 3. 数値配分

| 方針 | 内容 |
| :-- | :-- |
| 基礎値 | ENERGY・敏捷・移動速度を高めにする |
| 成長 | 攻撃・敏捷を優先し、ENERGYと補助用MANAの成長は初期戦闘を保ったまま抑える |
| 正本 | `40_filebase/20.features.class/v1.12.hunter.yml` |

具体的な数値は、共通アンカーの130%程度を上限として、class・skilltree・equipment の増加分を **25% / 25% / 50%** の出発点で配分する。`NORMAL_ATTACK_DEGRADATION_DELAY` は初期値 `3`、クラスレベル1上昇ごとの増加量 `0.2` とし、通常攻撃劣化の開始を遅延させる。正式なステータス値はプレイテストで確定する。

### リソース設計

Lv.1の最大MP・最大ENGと初期スキル消費は変更せず、クラスレベル上昇による補助用MANAとENGの増加量だけを抑える。`v1.12.hunter.yml` の `growthPerLevel` は `MAX_MANA +1`、`MAX_ENERGY +1` とする。アローレインの `ENG16 + MP8` は維持し、skilltree解放のクラッシュアロー、ヒールアロー、ビルドアップへ副MPを加えて、MPを選択的な補助リソースとして使う。

### 現行skilltree基礎幹

現行の `starter` skilltreeにはハンターCP nodeを52個配置します。27node・27CPの汎用幹から、間接攻撃、Shield破壊、機動、ENG効率の4専門円環へ分岐します。各円環は4個の1CP小nodeと1個の2CP notableで、専門円環は合計20node・24CPです。Shield破壊専門円環の全取得値は `SHIELD_BREAK +2` とし、ソードマンの `+8` より低く設定します。クラッシュアロー、ヒールアロー、スペルステップ、ビルドアップ、ジャスト回避は関連する小nodeから独立した1CP leafとして分岐し、全取得は56ハンターCPです。

## 5. 検証

- [ ] 職業 Lv.・Player Lv.・equipment 更新帯ごとに、同格 Mob への TTK と耐久時間を確認する。
- [ ] 通常攻撃と上記の初期 skill、skilltree で解放する skill の実戦 DPS 構成比を記録する。
- [ ] 射程・移動・命中率を変えたときのDPSと被弾機会の差を確認する。
- [ ] skill masterの定義とskilltree nodeによる使用許可が一致することを確認する。
- [ ] Lv.1〜5の標準戦闘（5〜7秒）で初期射撃を2〜3回使っても、ポーションやメディテーションを必須にしない。
