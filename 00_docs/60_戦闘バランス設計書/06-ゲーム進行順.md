# ゲーム進行順と装備の入手

戦闘検証プリセットの装備は、自力で攻略・交換する代表的な進行に沿って選びます。装備の必要プレイヤーレベル、現在の職業レベル、素材や通行証の取得は、それぞれ別の条件です。下のレベル帯はコンテンツの推奨レベルで、実際の取得時期には周回と素材集めが影響します。

## 渡航と装備の順序

| 段階 | 攻略・入手の流れ | 前提 |
| --- | --- | --- |
| 開始〜ミズガルズ | 初期装備からノクスの武器へ進み、Lv.5のミドルアースの遺跡、Lv.8の万象聖域の遺跡などで装備を更新する。Lv.10帯では太陽鳥の武器や既存の装備交換を使う。 | 既存マスターに定義済み |
| アルダ始まりの遺跡 | ミズガルズの推奨Lv.15ダンジョン。攻略と素材交換を経て始源遺跡の防具を揃える。既存のクリア報酬には始源の核がある。 | 既存マスターに定義済み |
| エリヴァ超大陸への渡航 | アルダ始まりの遺跡の低確率ドロップからエリヴァへの渡航を開く。既存のワールド定義はエリヴァの道標（`99a00015`）を要求する。 | 道標と要求は定義済み。アルダからの入手経路は計画段階 |
| エリヴァでの装備更新 | 野外敵の武器箱、グラスボアの毛皮と森の樹脂を使う職人交換でエリヴァ装備を得る。風切りの草原は推奨Lv.15。 | エリヴァへの渡航後 |
| ヴェルディアへの渡航 | エリヴァの花咲く古木の遺跡（推奨Lv.20）のクリア報酬から、ヴェルディアの道標（`99a00022`）を取得する。現在のマスター上の抽選率は5%。 | エリヴァへの渡航後。道標の報酬とワールド要求は定義済み |
| ラピス → ルミナ → アストラ | 職人交換で更新する。ラピスはヴェルディアの洞窟素材、ルミナ・アストラはさらにエリヴァの野外素材などを使う。必要プレイヤーレベルは順に20・25・30。 | 両地域の攻略・素材集めと交換費用 |

たとえばアストラソードは、プレイヤーLv.30の装備条件に加え、交換に100万G、こけ根岩のかけら48個、洞窟の石ころ96個、草色の毛皮20個が必要です。クラスLv.1への転職だけで入手が進むことはありません。

## プリセットでの扱い

- コマンドで指定する値はプレイヤーレベルです。各段階に設定する職業レベルは、転職時のLv.1と前提職の育成を起点にした代表値です。プレイ中は両方のレベルが独立して上昇します。
- Tier 1の継続プリセットはミズガルズ・アルダ段階を表します。Tier 2は転職直後に前段階の装備を引き継ぎ、その後、エリヴァに渡航できた検証状態から順に装備を更新します。Tier 3の転職直後も前段階の装備を引き継ぎます。
- 上位職は現行マスターで管理者切替専用です。通常の転職条件を満たす前のレベル帯でも選べるプリセットは、低レベルの戦闘検証用です。渡航後のプリセットは渡航や報酬入手を仮定した装備構成です。
- 装備強化は到達段階と装備マスターの上限に合わせます。新しい装備に更新した直後は低い強化値から始めます。シジルの標準購入には転生EXPポイントが必要です。プリセットではプレイヤーLv.25以降に低価格の短縮シジルを使い、威力シジルを設定する場合はLv.45以降の追加育成を済ませた構成に限ります。

| プレイヤーLv. | 代表的な職業とクラスLv. | 検証装備の目安 |
| --- | --- | --- |
| 15 | ソードマン・メイジなどのTier 1がクラスLv.50。Tier 2は転職直後のクラスLv.1 | ミズガルズで取得できる武器とアルダ攻略前の防具 |
| 20 | Tier 2がクラスLv.16 | エリヴァへ渡航し、現地で装備を入手した構成 |
| 25〜30 | Tier 2がクラスLv.32〜50 | ヴェルディアの素材を採集し、ラピス装備を交換した構成 |
| 35〜40 | Tier 2がクラスLv.65〜80。Lv.40のTier 3は転職直後のクラスLv.1 | ルミナ装備。Tier 3は前職の装備を引き継ぐ |
| 45〜50 | Tier 2の追加育成とTier 3の初期育成 | 素材と費用が揃った段階でアストラ装備。Tier 3のプリセットではLv.50で更新 |

ファントムアーチャーの転職直後の検証構成は、右クリックで使うスキルの習得経路に必要なCPを確保するためクラスLv.4から開始します。

## 進行を確定するために不足している情報

- アルダからエリヴァの道標を得る抽選対象、確率、周回数の目安。現行のドロップ・クリア報酬定義には道標の供給元がありません。
- Tier 2・3の通常転職の開放時期と、その時点の標準装備・資金・プレイ時間。
- 素材採集とダンジョン周回を含む、Lv.30〜50の標準取得時期と次の装備更新。既存の上位職・野外敵・装備マスターから、プレイヤーがその順番で取得できることまでは確定できません。

既存の装備条件と価格は、`40_filebase/10.features.item/20.equipment`、`40_filebase/45.features.shop` の各マスターを参照します。戦闘の数値目標は [成長曲線](02-成長曲線.md) と [レベル帯コンテンツ設計](04-レベル帯コンテンツ設計.md) に従います。
