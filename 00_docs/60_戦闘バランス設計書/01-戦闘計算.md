# 01-戦闘計算

## 目的

本書は、2026-07-28 時点で Plugin に実装されている計算式を記録する。ここに記載する式は現状把握用であり、目標とする戦闘バランスの決定ではない。

今後の調整では、本書の各式を起点に、成長曲線・職業差・敵の耐久・スキル係数を順に決める。

## 最初に読む概要

通常の AstralRecord プレイヤーが管理 Mob を攻撃するとき、Minecraft（Bukkit）側のダメージ値は使わない。ダメージイベントはキャンセルし、プレイヤーの現在の status と skill の倍率から Plugin が独自にダメージを計算し、Mob の独自 HP へ反映する。

通常プレイヤーの一撃は、次の順で決まる。

```text
命中判定
  ↓
攻撃力 × skill 倍率
  ↓
会心 / 超会心
  ↓
防御力による軽減
  ↓
レベル差補正
  ↓
属性ダメージ増加・耐性・貫通
  ↓
一時 skill 効果・状態異常の最終補正
  ↓
シールド または HP へ反映
```

通常攻撃の skill 倍率は `1.0`（100%）である。skill は `0.95`（95%）や `1.50`（150%）のような倍率を指定して、同じ計算式の威力だけを変える。属性がない通常攻撃は、無属性 `NONE` / `1.0` として扱う。

### まず見る status

| 役割 | 近接 | 遠距離 | 魔法 |
|:--|:--|:--|:--|
| 基本能力値 | `STRENGTH` | `DEXTERITY` | `INTELLIGENCE` |
| 種別攻撃力 | `MELEE_ATTACK` | `RANGED_ATTACK` | `MAGIC_ATTACK` |
| 防御に使う値 | `DEFENSE` | `DEFENSE` | `MAGIC_DEFENSE` |

このほか、`ACCURACY` / `EVASION` は命中、`CRITICAL_RATE` / `CRITICAL_DAMAGE` は会心、各属性の `*_DAMAGE_INCREASE` / `*_RESISTANCE` / `*_PENETRATION` は属性ダメージに影響する。

### 通常プレイヤー攻撃の見方

近接の通常攻撃なら、最初の攻撃力は次のように読む。

```text
攻撃力 = ATTACK × (1 + STR / 100) + MELEE_ATTACK
```

通常攻撃では `baseDamage = 0`、skill では上式の攻撃力へ skill 倍率を掛ける。つまり、通常プレイヤー攻撃は Bukkit の武器ダメージを下限として使わず、`ATTACK`、基本能力値、種別攻撃力から始まる。

例として、火属性 150% の近接 skill を使う場合を考える。

```text
ATTACK = 100
STR = 20
MELEE_ATTACK = 10
skill 倍率 = 1.50
相手 DEFENSE = 50
攻撃者が相手より 3 レベル高い
火ダメージ増加 = 20%
相手の火耐性 = 30%、火貫通 = 10%
```

会心・一時補正・シールドがない場合、計算は次のとおりである。

```text
攻撃力                 = 100 × 1.2 + 10 = 130
skill 倍率適用          = 130 × 1.50 = 195
防御後                  = 195 - 50 × 0.5 = 170
レベル差補正            = 170 × 1.09 = 185.3
実効火耐性              = 30 - 10 = 20%
火属性倍率              = 1.20 × 0.80 = 0.96
シールド適用前ダメージ  = 185.3 × 0.96 = 177.9
```

この例では、相手のシールドがなければ 177.9 が HP へ入る。シールドがあれば HP には入らず、後述のシールド専用計算でシールドだけを消費する。

### 属性成分と skill 倍率の読み方

属性成分の `ratio` は、属性の配分と skill 威力を兼ねる倍率である。

| 指定例 | 意味 |
|:--|:--|
| `NONE: 1.0` | 無属性の通常威力（100%） |
| `FIRE: 1.5` | 火属性の150%威力 |
| `FIRE: 0.7`, `ICE: 0.3` | 合計100%威力を火70%・氷30%に配分 |
| `FIRE: 1.0`, `ICE: 0.4` | 合計140%威力。そのうち火100%・氷40%に配分 |

複数属性では、まず `ratio` の合計で skill の全体威力を決め、防御を1回だけ適用した後に、各属性へ配分する。したがって属性ごとの耐性は配分後にそれぞれ効く。

### 現時点で計算に入らない status

`FINAL_DAMAGE_RATE` と `FINAL_DAMAGE_MULTIPLIER` は status として存在するが、2026-07-28 時点の `DamageCalculator` / `DamageService` では最終ダメージ計算に使われていない。`ATTACK_SPEED` も一撃のダメージ式には含まれない。これらをマスタへ配分する前に、実装へ反映するか、未実装のままとするかを決める。

## 計算経路

現在は、主に次の 3 経路がある。

| 経路 | 用途 | 実装上の特徴 |
|:--|:--|:--|
| 統合ダメージ | `DamageService.attack` / `applyDamage` | 属性、シールド、状態異常由来の最終補正を処理する |
| Mob 自律攻撃 | `MobCombatService` の AI 攻撃 | 独自の命中・攻撃・会心計算後、Bukkit の `Player#damage` へ渡す |
| 状態異常 DoT | `DamageService.applyConditionDamage` | 防御・会心・通常の属性計算を使わない専用経路 |

この 3 経路は完全には統一されていない。数式の変更時は、どの経路を対象にするかを先に決める。

## 統合ダメージ経路

### 攻撃力

攻撃種別ごとの基本能力値 `P` と種別攻撃力 `T` は次の対応とする。

| 攻撃種別 | 基本能力値 `P` | 種別攻撃力 `T` | 防御 `D` |
|:--|:--|:--|:--|
| `MELEE` | `STRENGTH` | `MELEE_ATTACK` | `DEFENSE` |
| `RANGED` | `DEXTERITY` | `RANGED_ATTACK` | `DEFENSE` |
| `MAGIC` | `INTELLIGENCE` | `MAGIC_ATTACK` | `MAGIC_DEFENSE` |

`ATTACKER_STATUS` のとき、解決攻撃力 `A` は次式となる。

```text
A = ATTACK × (1 + P / 100) + T
基礎ダメージ = max(baseDamage, A) × 属性倍率合計
```

`FIXED` のときは `baseDamage` をそのまま基礎値とする。属性倍率合計は、有効な属性成分の `ratio` の合計である。`ratio <= 0` の属性成分は除外され、合計が 0 以下ならダメージは 0 となる。

### 命中

命中判定は `ATTACKER_STATUS` かつ管理対象の攻撃者がいる場合だけ行う。

```text
命中率 = clamp(ACCURACY - EVASION, 0, 100)
命中 = random[0, 100) < 命中率
```

Mob の `ACCURACY` が 0 以下の場合だけ、統合ダメージ経路では `100` を既定値として使う。固定ダメージや未管理攻撃者は命中率 100% として扱う。

### 会心・超会心

管理対象の攻撃者がいて、基礎ダメージが正の場合に会心を判定する。

```text
会心成立時: ダメージ ×= CRITICAL_DAMAGE / 100
超会心成立時: ダメージ ×= SUPER_CRITICAL_DAMAGE / 100
```

`CRITICAL_DAMAGE <= 0` の場合は 150%、`SUPER_CRITICAL_DAMAGE <= 0` の場合は 100% を使う。会心率・超会心率は下限のみ 0 に補正し、上限 100 には丸めない。

### 防御・レベル差

被弾者が管理対象の場合、防御は会心後の合計ダメージに 1 回だけ適用する。

```text
防御後ダメージ = max(1, 会心後ダメージ - D × 0.5)
```

攻撃者と被弾者がともに管理対象の場合、続けてレベル差倍率を適用する。

```text
レベル差倍率 = clamp(1 + 0.03 × (攻撃者レベル - 被弾者レベル), 0.70, 1.30)
レベル差適用後ダメージ = 防御後ダメージ × レベル差倍率
```

### 属性

防御・レベル差を適用した後、属性成分の `ratio` に従ってダメージを配分する。無属性は常に倍率 1 である。

```text
属性配分 = レベル差適用後ダメージ × 属性 ratio / 属性倍率合計
実効耐性 = max(0, 属性耐性 - 属性貫通)
属性倍率 = max(0, 1 + 属性ダメージ増加 / 100)
         × max(0, 1 - 実効耐性 / 100)
属性ダメージ = 属性配分 × 属性倍率
最終属性ダメージ = 各属性ダメージの合計
```

### 最終補正・シールド・HP

属性計算後、次の倍率を掛ける。

```text
最終補正 = 一時 skill の与ダメージ倍率
         × 一時 skill の被ダメージ倍率
         × 状態異常の与ダメージ倍率
         × 状態異常の被ダメージ倍率
```

現状、`ConditionService.damageTakenMultiplier` は常に 1.0 である。与ダメージ倍率は、攻撃者に付与中の各状態異常の倍率を乗算する。

シールドが有効で最終ダメージが正の場合、HP へはダメージを通さず、次式でシールドを消費する。余剰ダメージの HP への貫通は行わない。

```text
基礎シールドダメージ = max(1, floor(シールド適用直前ダメージ / max(1, 最大HP × 0.1)))
シールドダメージ = min(現在シールド, 基礎シールドダメージ + max(0, SHIELD_BREAK))
```

シールドがない場合だけ、シールド適用直前ダメージをプレイヤーの HP または Mob の現在 HP から減算する。

## Mob 自律攻撃経路

Mob AI の通常攻撃は `DamageService` を使わず、`MobCombatService` 内で次式を使う。

```text
攻撃力 = ATTACK × outgoingDamageMultiplier
P = STRENGTH / DEXTERITY / INTELLIGENCE（戦闘スタイルごと）
攻撃値 = 攻撃力 × (1 + P / 100)
防御後ダメージ = max(1, 攻撃値 - 対象防御 × 0.5)
最終ダメージ = 防御後ダメージ × レベル差倍率
```

命中率は統合ダメージ経路と同じ `clamp(ACCURACY - EVASION, 0, 100)` を使う。会心・超会心も同じ倍率形式だが、Mob テンプレートの値を直接参照する。

この経路は、種別攻撃力、属性、属性耐性・貫通、統合経路の一時 skill 補正、シールド処理を `MobCombatService` 内では扱わない。計算後のダメージ適用は Bukkit の `Player#damage` に委譲する。

## 状態異常 DoT 経路

状態異常の DoT は次式となる。

```text
DoT = max(0, baseDamage)
    × 状態異常ダメージ倍率
    × 状態異常の与ダメージ倍率
    × 一時 skill の与ダメージ倍率
    × 一時 skill の被ダメージ倍率
```

状態異常ダメージ倍率は、属性ダメージと同じ形式で、状態異常ごとの増加・耐性・貫通を使う。

```text
実効耐性 = max(0, 状態異常耐性 - 状態異常貫通)
状態異常ダメージ倍率 = max(0, 1 + 状態異常ダメージ増加 / 100)
                     × max(0, 1 - 実効耐性 / 100)
```

DoT は防御、レベル差、命中、会心、通常の属性倍率を適用しない。毒 DoT は対象 HP が 1 未満にならない値に制限する。DoT もシールドは消費する。

## 基本能力値からの派生

プレイヤーの最終ステータス計算では、基本能力値から次の派生値を加算する。

| 基本能力値 | 派生先 | 1ポイントあたり |
|:--|:--|--:|
| `INTELLIGENCE` | `MAX_MANA` | 1.0 |
| `INTELLIGENCE` | `MP_REGEN` | 0.1 |
| `VITALITY` | `MAX_HEALTH` | 2.0 |
| `VITALITY` | `DEFENSE` | 1.0 |
| `VITALITY` | `MAGIC_DEFENSE` | 1.0 |
| `VITALITY` | `HP_REGEN` | 0.1 |
| `AGILITY` | `ATTACK_SPEED` | 1.0 |
| `AGILITY` | `MOVEMENT_SPEED` | 1.0 |
| `AGILITY` | `EVASION` | 0.1 |
| `LUCK` | `CRITICAL_RATE` | 0.1 |

`MELEE_ATTACK`、`RANGED_ATTACK`、`MAGIC_ATTACK` は統合ダメージ式の `T` として参照される。ただし、基本能力値からこれらへ自動で派生させる処理は現時点では実装されていない。

## 撃破経験値のレベル差補正

Mob を倒したプレイヤーが得る経験値は、プレイヤーレベルと Mob レベルの絶対差で減衰する。

```text
経験値倍率 = max(0.10, 1 - 0.05 × abs(プレイヤーレベル - Mobレベル))
獲得経験値 = max(1, round(基礎経験値 × 経験値倍率))
```

基礎経験値が 0 以下の場合、獲得経験値は 0 とする。
