# 01-戦闘計算

## 目的

本書は、2026-07-29 時点で Plugin に実装されている計算式を記録する。ここに記載する式は現状把握用であり、目標とする戦闘バランスの決定ではない。

今後の調整では、本書の各式を起点に、成長曲線・職業差・敵の耐久・スキル係数を順に決める。

## 最初に読む概要

通常の AstralRecord プレイヤーが管理 Mob を攻撃するとき、Minecraft（Bukkit）側のダメージ値は使わない。ダメージイベントはキャンセルし、プレイヤーの現在の status と skill の倍率から Plugin が独自にダメージを計算し、Mob の独自 HP へ反映する。

通常プレイヤーの一撃は、次の順で決まる。

```text
命中判定
  ↓
攻撃力 × skill 倍率
  ↓
通常会心 / 超星会心（主撃）
  ↓
防御力による軽減
  ↓
属性ダメージ増加・耐性・貫通
  ↓
一時 skill 効果・状態異常の最終補正
  ↓
最終ダメージ倍率
  ↓
シールド または HP へ反映
  ↓
超星会心が成立した主撃だけ、追尾弾を7個生成
```

通常攻撃の skill 倍率は `1.0`（100%）である。skill は `0.95`（95%）や `1.50`（150%）のような倍率を指定して、同じ計算式の威力だけを変える。属性がない通常攻撃は、無属性 `NONE` / `1.0` として扱う。

### まず見る status

| 役割 | 近接 | 遠距離 | 魔法 |
|:--|:--|:--|:--|
| 基本能力値 | `STRENGTH` | `DEXTERITY` | `INTELLIGENCE` |
| 種別攻撃力 | `MELEE_ATTACK` | `RANGED_ATTACK` | `MAGIC_ATTACK` |
| 防御に使う値 | `DEFENSE` + `MELEE_DEFENSE` | `DEFENSE` + `RANGED_DEFENSE` | `DEFENSE` + `MAGIC_DEFENSE` |

このほか、`ACCURACY` / `EVASION` は命中、`CRITICAL_RATE` / `CRITICAL_DAMAGE` は通常会心、`SUPER_CRITICAL_RATE` / `SUPER_CRITICAL_DAMAGE` は超星会心に影響する。各属性の `*_DAMAGE_INCREASE` / `*_RESISTANCE` / `*_PENETRATION` は属性ダメージに影響する。

### 通常プレイヤー攻撃の見方

近接の通常攻撃なら、最初の攻撃力は次のように読む。

```text
攻撃力 = ATTACK × (1 + STR / 100) + MELEE_ATTACK
```

通常攻撃では `baseDamage = 0`、skill では上式の攻撃力へ skill 倍率を掛ける。つまり、通常プレイヤー攻撃は Bukkit の武器ダメージを下限として使わず、`ATTACK`、基本能力値、種別攻撃力から始まる。

例として、火属性 150% の近接 skill を使う場合を考える。

```text
ATTACK = 100
STR = 20
MELEE_ATTACK = 10
skill 倍率 = 1.50
相手 DEFENSE = 50
火ダメージ増加 = 20%
相手の火耐性 = 30%、火貫通 = 10%
最終ダメージ倍率 = 130%
```

会心・一時補正・シールドがない場合、計算は次のとおりである。

```text
攻撃力                 = 100 × 1.2 + 10 = 130
skill 倍率適用          = 130 × 1.50 = 195
防御後                  = 195 - 50 × 0.5 = 170
実効火耐性              = 30 - 10 = 20%
火属性倍率              = 1.20 × 0.80 = 0.96
最終ダメージ倍率適用前  = 170 × 0.96 = 163.2
シールド適用前ダメージ  = 163.2 × 1.30 = 212.2
```

この例では、相手のシールドがなければ 212.2 が HP へ入る。シールドがあれば HP には入らず、後述のシールド専用計算でシールドだけを消費する。

### ダメージログの読み方

`DAMAGE_LOG_MESSAGE=true` のプレイヤーには、相手名を省略した計算トレース形式のログを表示する。以下の例では全システムメッセージへ付く共通タグ `[AstralRecord]` を省略している。

```text
→ HP125 MEL/FIR | AP180 DEF80>64 RES25>15 | H92(A95-E3) CRIT
← SHD3! RNG/ICE | AP90 DEF42>42 RES10>10 | H76(A82-E6)
→ MISS | H92(A95-E3)
```

| 表示 | 読み方 |
|:--|:--|
| `→` / `←` | 自分から相手への攻撃 / 相手から自分への攻撃 |
| `HP125` | HP に確定した 125 damage |
| `SHD3!` | shield に確定した 3 damage。`!` はこの hit での shield break |
| `MEL` / `RNG` / `MAG` | attack type の `MELEE` / `RANGED` / `MAGIC` |
| `NON` / `FIR` / `ICE` / `LTN` | element の `NONE` / `FIRE` / `ICE` / `LIGHTNING` |
| `AP180` | scaling と外部 base を解決した攻撃力。`ATTACKER_STATUS` は `max(baseDamage, A)`、`FIXED` は `baseDamage` |
| `DEF80>64` | victim の貫通適用前 defense 合計 80 → 対応する貫通率を各 defense へ適用した有効 defense 合計 64 |
| `RES25>15` | victim の元 element resistance 25 → 耐性上限と element penetration を適用した実効 resistance 15 |
| `H92(A95-E3)` | 最終 hit chance 92、attacker accuracy 95、victim evasion 3 |
| `CRIT` / `S-CRIT` | 通常会心 / 超星会心成立。両方成立時は `CRIT+S-CRIT`。超星会心の追尾弾も `S-CRIT` と表示する |
| `MISS` | hit 判定で回避され、damage 計算を終了 |

`AP` は常に attacker、`DEF` と `RES` は常に victim の値である。このため `→` では自分の `AP` と相手の `DEF` / `RES`、`←` では相手の `AP` と自分の `DEF` / `RES` を読む。

無属性では `RES` を表示しない。複数属性では `RES[F25>15/I10>5]` のように `F`（fire）、`I`（ice）、`L`（lightning）ごとに表示する。数値は小数第1位までとし、整数の `.0` は省略する。

### 属性成分と skill 倍率の読み方

属性成分の `ratio` は、属性の配分と skill 威力を兼ねる倍率である。

| 指定例 | 意味 |
|:--|:--|
| `NONE: 1.0` | 無属性の通常威力（100%） |
| `FIRE: 1.5` | 火属性の150%威力 |
| `FIRE: 0.7`, `ICE: 0.3` | 合計100%威力を火70%・氷30%に配分 |
| `FIRE: 1.0`, `ICE: 0.4` | 合計140%威力。そのうち火100%・氷40%に配分 |

複数属性では、まず `ratio` の合計で skill の全体威力を決め、防御を1回だけ適用した後に、各属性へ配分する。したがって属性ごとの耐性は配分後にそれぞれ効く。

### 一撃のダメージに入らない status

`ATTACK_SPEED` は一撃のダメージ式には含まれない。通常攻撃・Mob の built-in attack の間隔にだけ次式で適用する。攻撃速度の基準値は 100 であり、正の基本間隔は最短 1 tick とする。

```text
攻撃間隔 = max(1, ceil(基本攻撃間隔 × 100 / ATTACK_SPEED))
```

最終ダメージ確率は廃止し、最終ダメージ倍率は後述のとおり常時適用する。

## 計算経路

現在は、主に次の 3 経路がある。

| 経路 | 用途 | 実装上の特徴 |
|:--|:--|:--|
| 統合ダメージ | `DamageService.attack` / `applyDamage` | 属性、シールド、状態異常由来の最終補正を処理する |
| Mob 自律攻撃 | `MobCombatService` → `DamageService.attack` | 攻撃間隔・対象選定は Mob 側、命中から HP 反映までは統合経路 |
| 超星会心追尾弾 | `SuperStarCriticalProjectileService` → `DamageService.applyDamage` | 超星会心の主撃から7個生成し、命中した Mob ごとに統合経路を再計算する |
| 状態異常 DoT | `DamageService.applyConditionDamage` | 防御・会心・通常の属性計算を使わない専用経路 |

Mob 自律攻撃は通常攻撃として統合ダメージ経路を使う。DoT だけは、防御・会心・通常属性計算を使わない専用経路である。

## 統合ダメージ経路

### 攻撃力

攻撃種別ごとの基本能力値 `P` と種別攻撃力 `T` は次の対応とする。

| 攻撃種別 | 基本能力値 `P` | 種別攻撃力 `T` | 防御 `D` |
|:--|:--|:--|:--|
| `MELEE` | `STRENGTH` | `MELEE_ATTACK` | `DEFENSE + MELEE_DEFENSE` |
| `RANGED` | `DEXTERITY` | `RANGED_ATTACK` | `DEFENSE + RANGED_DEFENSE` |
| `MAGIC` | `INTELLIGENCE` | `MAGIC_ATTACK` | `DEFENSE + MAGIC_DEFENSE` |

`ATTACKER_STATUS` のとき、解決攻撃力 `A` は次式となる。

```text
A = ATTACK × (1 + P / 100) + T
会心適用前ダメージ = max(baseDamage, A)
                  × 属性倍率合計
                  × 発生元ダメージ倍率
                  × 攻撃者固有ダメージ倍率
```

`FIXED` のときは `baseDamage` をそのまま基礎値とする。属性倍率合計は、有効な属性成分の `ratio` の合計である。`ratio <= 0` の属性成分は除外され、合計が 0 以下ならダメージは 0 となる。

発生元ダメージ倍率は、通常攻撃なら `1 + 通常攻撃ダメージ増加 / 100`、発動スキルなら `1 + スキルダメージ増加 / 100`、それ以外の発生元なら 1 とする。`FIXED` でも発動スキル由来であればスキルダメージ増加を適用する。攻撃者固有ダメージ倍率は通常 1.0 であり、Mob 自律攻撃だけは `MobInstance.outgoingDamageMultiplier` をここへ掛ける。

### 命中

命中判定は `ATTACKER_STATUS` かつ管理対象の攻撃者がいる場合だけ行う。

```text
命中率 = clamp(ACCURACY - EVASION, 0, 100)
命中 = random[0, 100) < 命中率
```

Mob の `ACCURACY` が 0 以下の場合だけ、統合ダメージ経路では `100` を既定値として使う。固定ダメージや未管理攻撃者は命中率 100% として扱う。

### 通常会心・超星会心

管理対象の攻撃者がいて、会心適用前ダメージが正の場合に通常会心を判定する。プレイヤーから攻撃可能 Mob への攻撃では、通常会心とは独立して超星会心も判定する。

```text
会心成立時: ダメージ ×= CRITICAL_DAMAGE / 100
超星会心成立時: ダメージ ×= SUPER_CRITICAL_DAMAGE / 100
```

`CRITICAL_DAMAGE <= 0` の場合は150%、`SUPER_CRITICAL_DAMAGE <= 0` の場合は30%を使う。会心率・超星会心率は下限のみ0に補正し、上限100には丸めない。そのため100%以上は必ず成立する。両方が成立したときは、通常会心倍率と超星会心倍率を順に掛ける。

現在のプレイヤーの素の基礎値は、通常会心率5%、通常会心倍率150%、超星会心率0%、超星会心倍率30%である。装備・class・buff等の加算後の最終statusを使うため、`SUPER_CRITICAL_DAMAGE = 30` は「30%増加」ではなく、主撃・追尾弾ともにダメージへ `0.30` を掛ける設定である。

#### 超星会心の追尾弾

超星会心は、主撃の倍率補正に加えて追尾弾を発生させる追加攻撃である。発生条件は次のすべてを満たす場合に限る。

- 攻撃者が生存中のプレイヤーである。
- 被弾者が攻撃可能 Mob である。
- 主撃が命中し、超星会心が成立し、シールド適用直前のダメージが正である。

主撃の被弾 Mob の身体中央から、ネザースター表示の追尾弾を7個生成する。追尾弾はランダムな水平方位・上向き45度へ10～20 tick直進した後、同一world・半径24 block内にいる最寄りの攻撃可能 Mobを毎tick選び直して追尾する。生成から100 tickで消滅し、攻撃者の死亡・ログアウト、表示entityの消滅、Mobへの接触でも終了する。元の被弾Mobに限らず、条件を満たす最寄りMobへ向かう。

追尾弾がMobへ当たると、元攻撃の `baseDamage`、攻撃種別、属性成分、scaling、発生元、攻撃者固有ダメージ倍率を引き継いで統合ダメージ経路を最初から再実行する。命中、通常会心、防御、属性耐性、一時効果、状態異常、最終ダメージ倍率は命中時点の対象・statusで再評価する。一方、超星会心は再抽選せず、倍率だけを強制適用する。追尾弾からさらに追尾弾は生成しない。

追尾弾の命中も通常攻撃と同様にHP・シールド・ライフスティール・threat・表示・詳細ログへ反映する。ただし、追尾弾は装備耐久を消費せず、ノックバックも発生させない。主撃がシールドへ吸収されても、上の発生条件を満たしていれば追尾弾は生成される。

### 防御

被弾者が管理対象の場合、防御は会心後の合計ダメージに 1 回だけ適用する。全ダメージ防御力と攻撃種別防御力は、それぞれ対応する貫通率を適用してから合算する。

```text
有効全体防御 = max(0, DEFENSE) × max(0, 1 - 防御力貫通率 / 100)
有効種別防御 = max(0, 種別防御力) × max(0, 1 - 種別防御貫通率 / 100)
D = 有効全体防御 + 有効種別防御
防御後ダメージ = max(0, 会心後ダメージ - D × 0.5)
```

### 属性

防御を適用した後、属性成分の `ratio` に従ってダメージを配分する。使用できる属性は火 (`FIRE`)、氷 (`ICE`)、雷 (`LIGHTNING`) のみで、無属性 (`NONE`) は常に倍率 1 である。

```text
属性配分 = 防御後ダメージ × 属性 ratio / 属性倍率合計
耐性上限適用後 = min(属性耐性, 属性耐性上限値)
実効耐性 = 耐性上限適用後 - 属性貫通
属性倍率 = max(0, 1 + 属性ダメージ増加 / 100)
         × max(0, 1 - 実効耐性 / 100)
属性ダメージ = 属性配分 × 属性倍率
最終属性ダメージ = 各属性ダメージの合計
```

属性耐性上限値の初期値は 75% であり、上限を超える耐性は計算に使わない。耐性値には負の値を設定でき、負の実効耐性は属性倍率を 1 より大きくして弱点として扱う。

### 最終補正・シールド・HP

属性計算後、次の倍率を掛ける。

```text
最終補正 = 一時 skill の与ダメージ倍率
         × 一時 skill の被ダメージ倍率
         × 状態異常の与ダメージ倍率
         × 状態異常の被ダメージ倍率

シールド適用前ダメージ = 最終属性ダメージ
                     × 最終補正
                     × FINAL_DAMAGE_MULTIPLIER / 100
```

現状、`ConditionService.damageTakenMultiplier` は常に 1.0 である。与ダメージ倍率は、攻撃者に付与中の各状態異常の倍率を乗算する。`FINAL_DAMAGE_MULTIPLIER` は確率判定なしで常時適用する。プレイヤーの基礎値は 130%であり、明示的な 0 以下は 0% とする。Mob テンプレートは当該ステータスが未定義の場合だけ 100% を使い、明示的な 0 以下は 0% とする。

ライフスティールはシールドへ与えたダメージを含めず、実際に HP へ与えたダメージへ `LIFE_STEAL / 100` を掛けて攻撃プレイヤーの HP を回復する。HP回復には `HEALING_INCREASE` を適用する。

シールドが有効で最終ダメージが正の場合、HP へはダメージを通さず、次式でシールドを消費する。余剰ダメージの HP への貫通は行わない。

```text
基礎シールドダメージ = max(1, floor(シールド適用直前ダメージ / max(1, 最大HP × 0.1)))
シールドダメージ = min(現在シールド, 基礎シールドダメージ + max(0, SHIELD_BREAK))
```

シールドがない場合だけ、シールド適用直前ダメージをプレイヤーの HP または Mob の現在 HP から減算する。

## Mob 自律攻撃

Mob AI の built-in attack は、`MobCombatService` が対象選定・距離・攻撃間隔を確認した後、`DamageService.attack` を `NORMAL_ATTACK` として呼ぶ。攻撃種別は `combat.style`（`MELEE` / `RANGED` / `MAGIC`）から決める。

攻撃力、命中、通常会心、防御、属性、シールド、最終補正、HP 反映はすべて統合ダメージ経路と同じである。`MobInstance.outgoingDamageMultiplier` は、攻撃力解決後かつ会心・防御より前に乗算する。Mob のテンプレートに `ATTACK_SPEED` がない場合は基準値 100 として基本攻撃間隔をそのまま使う。超星会心はプレイヤーから攻撃可能 Mob への攻撃専用であり、Mob 自律攻撃では判定しない。

## 状態異常 DoT 経路

状態異常の DoT は次式となる。

```text
DoT = max(0, baseDamage)
    × 状態異常ダメージ倍率
    × 状態異常の与ダメージ倍率
    × 一時 skill の与ダメージ倍率
    × 一時 skill の被ダメージ倍率
    × FINAL_DAMAGE_MULTIPLIER / 100
```

状態異常ダメージ倍率は、属性ダメージと同じ形式で、状態異常ごとの増加・耐性・貫通を使う。

```text
実効耐性 = 状態異常耐性 - 状態異常貫通
状態異常ダメージ倍率 = max(0, 1 + 状態異常ダメージ増加 / 100)
                     × max(0, 1 - 実効耐性 / 100)
```

DoT は防御、レベル差、命中、会心、通常の属性倍率を適用しない。状態異常耐性にも負の値を設定でき、負の実効耐性は DoT ダメージを増やす弱点として扱う。毒 DoT は対象 HP が 1 未満にならない値に制限する。DoT もシールドは消費する。

## 基本能力値からの派生

プレイヤーの最終ステータス計算では、基本能力値から次の派生値を加算する。

| 基本能力値 | 派生先 | 1ポイントあたり |
|:--|:--|--:|
| `INTELLIGENCE` | `MAX_MANA` | 1.0 |
| `INTELLIGENCE` | `MP_REGEN` | 0.1 |
| `VITALITY` | `MAX_HEALTH` | 2.0 |
| `VITALITY` | `DEFENSE` | 1.0 |
| `VITALITY` | `MAGIC_DEFENSE` | 1.0 |
| `VITALITY` | `HP_REGEN` | 0.1 |
| `AGILITY` | `ATTACK_SPEED` | 1.0 |
| `AGILITY` | `MOVEMENT_SPEED` | 1.0 |
| `AGILITY` | `EVASION` | 0.1 |
| `LUCK` | `CRITICAL_RATE` | 0.1 |

`MELEE_ATTACK`、`RANGED_ATTACK`、`MAGIC_ATTACK` は統合ダメージ式の `T` として参照される。ただし、基本能力値からこれらへ自動で派生させる処理は現時点では実装されていない。

## 撃破経験値のレベル差補正

Mob を倒したプレイヤーが得る経験値は、プレイヤーレベルと Mob レベルの絶対差で減衰する。

```text
経験値倍率 = max(0.10, 1 - 0.05 × abs(プレイヤーレベル - Mobレベル))
獲得経験値 = max(1, round(基礎経験値 × 経験値倍率))
```

基礎経験値が 0 以下の場合、獲得経験値は 0 とする。
