# レベル帯コンテンツ設計

> [!abstract] この資料で決めること
> 現在 `40_filebase` に定義されているプレイヤー向けMobコンテンツと、その受入条件を記載する。

## 1. 共通ルール

- 表の `HP / R / D` は、マスタへ反映する最大HP・解決攻撃力・有効防御である。
- `R` は [[02-成長曲線]] のアンカーと役割倍率から求め、`ATTACK`・基本能力値・種別攻撃力へ配分する。
- `D` は対象の共通防御と攻撃種別防御の合計である。
- 受入条件は、同格装備における通常敵TTK 5〜7秒、プレイヤー耐久時間8〜10秒とする。
- マスタ反映前の計算では、整数HP・Dへの丸めと代表class差に限りTTK境界へ±0.1秒を許容する。配置後の実測平均は5〜7秒を満たすこと。

### 2.1 スケルトン・アーチャー Lv.3 の換算根拠

Lv.1とLv.5の標準Mobアンカーを直線補間したLv.3基準は、HP 300 / R 55 / D 52となる。高火力型の倍率（HP 0.8 / R 1.4 / D 0.8）を適用し、HP 240 / R 76 / D 42を目標値とした。

マスタでは、`ATTACK 48`、`RANGED_ATTACK 24`、`DEXTERITY 5`により、Pluginの計算式 `(ATTACK + RANGED_ATTACK) × (1 + DEXTERITY / 100)` から R 75.6（表示上76）となる。Dは`DEFENSE 42`で確保する。

### 2.2 ミッドガルズ・モスシェル Lv.2 の換算根拠

Lv.2 の標準 Mob 基準は、Lv.1 と Lv.5 のアンカーを直線補間して HP 200 / R 36 / D 35 とする。耐久型の倍率（HP 1.5 / R 0.8 / D 1.25）を適用し、HP 300 / R 29 / D 43 を目標値とした。`ATTACK 29` と `DEFENSE 43` でこの値を確保する。

### 2.3 クレイガード Lv.3 の換算根拠

Lv.3 の標準 Mob 基準は HP 300 / R 55 / D 52 とする。クレイガードは通常攻撃を主軸とし、長いクールダウンの `mob_clay_guard_leap` は半径2mの着地範囲へ攻撃力85%を与える回避可能な追加行動として扱う。`ATTACK 55` と `DEFENSE 52` で通常値を確保する。

### 2.4 ミドルアースの遺跡 Lv.5 の換算根拠

Lv.5の標準 Mob アンカーは HP 500 / R 87 / D 91 とする。近接スケルトンは標準値をそのまま用いる。遠隔スケルトンは高火力型（HP×0.8 / R×1.4 / D×0.8）として、`(ATTACK 76 + RANGED_ATTACK 40) × (1 + DEXTERITY 5 / 100) = 121.8`、表示上R122を得る。ピグリンは突進を持つ強敵としてHP750 / R100 / D100に留め、30 tickの予告後に詠唱開始時点の位置へ突進する。

万物のエルはソロ挑戦を基準に、現行値から20%削減した3200HP、Boss倍率のR104 / D105を採用する。`shield.max: 20` を初期シールドとする。氷球は命中時に20 tick凍結、突進は `max(1, 10 - floor(残HP% / 10))` 回とし、HP80〜89%で2回、15%で9回とする。

### 2.5 フォレストウルフ Lv.6〜8 の換算根拠

Lv.6〜8 は、現行shopのLv.5武器、Lv.3帯防具、Player Lv.7〜8で取得できる6〜7 PPのskilltreeを合算した実装値を基準にする。代表classの実装値はLv.7でHP 286〜372 / R 81〜87 / 物理D 45〜62、Lv.8でHP 293〜386 / R 87〜93 / 物理D 45〜65となる。現行skillの倍率とcooldownから、発動1回につき通常攻撃1回を失うモデルで通常攻撃比DPSをソードマン約1.67、ハンター約1.94、メイジ約1.43とする。フォレストウルフは通常型として、Lv.6〜8をHP 540 / 580 / 620、R 70 / 75 / 80、D 60 / 65 / 70とする。このうちLv.7 / 8の代表3職TTKは約4.9〜7.1秒となる。Lv.6は今回の主対象外だが、同一マスタ内でLv.7以降のプロファイルが基礎プロファイルより弱くならないよう連続して調整する。近接攻撃へ到達しやすい高速型として `MOVEMENT_SPEED` は115 / 120 / 125を維持し、攻撃は`NEAREST`の自動索敵と30 tick間隔の通常近接攻撃だけを持つ。

### 2.6 ミズガルズ・サバナ Lv.7〜8 の換算根拠

サバナハイエナは通常型として、Lv.7 / 8 のHP・R・Dをそれぞれ580 / 75 / 65、620 / 80 / 70とする。現行skillローテーションによる代表3職のTTKは約4.9〜7.1秒となる。30 tick間隔の通常近接攻撃と命中期待値を含めると、Lv.7の代表classは低耐久なメイジで約9秒、高防御なソードマンで約14秒の生存余地を持つ。通常敵の8〜10秒基準は低耐久classを下限として確認し、高防御classの生存時間は職業特性として長くする。

サバナウィッチは高火力遠隔型として、Lv.7をHP 500 / R 145 / D 50、Lv.8をHP 550 / R 150 / D 55とする。RはLv.7で`(ATTACK 110 + MAGIC_ATTACK 28) × (1 + INTELLIGENCE 5 / 100) = 144.9`、Lv.8で`(ATTACK 113 + MAGIC_ATTACK 30) × 1.05 = 150.15`となる。`mob_savanna_witch_ember_bolt`は48 tick間隔・攻撃力75%の追尾弾で、防御前の直接DPSを約45.3 / 46.9とし、通常型の50.0 / 53.3へ近づける。命中時に凍結18%・燃焼24%を独立判定するため、通常型より高いRと低いHP・Dを交換条件にする。

サバナガードキャメルは耐久型として、Lv.7をHP 750 / R 65 / D 80、Lv.8をHP 850 / R 70 / D 85とする。Shieldは最大HPの50%で、被攻撃時のみターゲットを取るため、通常型より低い攻撃力と引き換えに長い戦闘時間を持たせる。`mob_clay_guard_leap`は半径3m・攻撃力45%・150 tick間隔とし、標準のクレイガードより広範囲かつ低火力にする。

### 2.7 フォレストスパイダー Lv.7〜8 の換算根拠

Lv.7〜8はHP 550 / 600、R 100 / 110、D 55 / 60とする。`mob_forest_spider_web_shot`は攻撃力75%で40 tick間隔のため、一撃のRは通常型より高くしつつ、時間当たりの攻撃回数とHP・Dを抑える。`NEAREST`で近くのプレイヤーを索敵し、RANGEDの`preferredRange: 7`と発動距離9mでスケルトン・アーチャーより近い位置を保つ。

固有スキル `mob_forest_spider_web_shot` は、速度0.90、hitbox追加半径0.25、攻撃力倍率0.75、詠唱10 tick、cooldown40 tickでクモ糸を飛ばす。命中時は25%の基礎確率で100 tickの衰弱を要求する。Lv.7のヴェノムサックは45%、Lv.8は50%、毒した瞳は両レベルとも1%で、いずれも luck の影響を受ける。

### 2.7 陽冠のサンバード Lv.10 の換算根拠

Lv.10の標準Mobアンカー HP 2000 / R 362 / D 348へSolo Boss倍率を適用した基準をもとに、現行実装HP 52000から20%削減した41600、R 434、D 400とする。`shield.max: 70`、`rechargeTimeSeconds: 30`、`rechargeAmount: 70` を設定し、標準プレイヤーのLv.10帯で破壊と再展開の判断が発生する最終ボスShieldとする。参加人数補正は、BOSS共通仕様のHP 50%・Shield 30%を追加人数ごとに適用し、攻撃力は人数で増やさない。

天陽崩落は30%限定技から通常ローテーションへ移し、各6行動の先頭で1回発動する。残る5行動は太陽フレア、サンストライク、ソーラービームで構成する。発動時の位置から移動せずに60 tick予告した後、半径12mへ攻撃力145%の火属性ダメージを与える。命中判定には一撃だけ命中補正25ポイントを加算する。予兆円は内側4m・中間8m・外周12mをそれぞれ36・48・64地点で表示し、詠唱中のBlockDisplayは12個とする。通常段階は60 tick、HP30%以下は46 tick（いずれも従来値の約0.7倍）間隔で次の行動を予約する。12秒周期の陽炎転移はスポーン地点から水平7mの6地点を巡回し、専用行動中は延期する。

スポーン地点から水平18mを安全圏とし、中心高さより上方向へ0.5m間隔の8層、下方向へ2層の合計10層を、各円周64地点へ水平方向±0.12m・垂直方向±0.04mのランダムな位置揺らぎを加え、1秒周期で赤色の境界particleとして表示する。外側のPlayerは攻撃力18%の火属性ダメージを受ける。ボスが境界外へ出た場合は、内側の最寄りPlayerへ10 tick予告の帰還タックルを行い、攻撃力100%の火属性近接ダメージを与えて水平9m以内へ戻る。

HP30%到達時は一度だけ「バードメテオ」を発動する。スポーン地点へ帰還し、通常AI・他のボスギミックを停止して80 tick（8秒）静止する。詠唱中はBossBarを8秒で空にし、ボスは無敵となる。境界内の半径15m以内からランダムに選んだ地点へ、半径3m・高さ2.5mのEND_RODパーティクル円柱を表示し、安全判定は高さを問わず、その円柱の中心からX/Zの水平距離が半径3m以内を安全地帯とする。8秒後に安全地帯以外の境界内へ攻撃力3000%の火属性即死級ダメージを与える。命中判定にはこの一撃だけ命中補正1000ポイントを加算して必ず命中させ、範囲外へ爆発パーティクルを表示する。

討伐報酬はランダム値を持つ陽冠ソード、陽冠ボウ、陽冠スタッフの専用Bundleを各3%、攻撃のルーン【小】を0.5%、ヴェルザンディのオーブを1%で個別抽選する。陽冠の羽根は2〜4個を確定、陽炎の心核は12%で抽選する。

### 2.8 万象の聖域 Lv.8 の換算根拠

Lv.8の標準Mob基準は HP 1400 / R 254 / D 244とする。ヴァタールスケルトンは個別調整としてHP 1400を維持し、攻撃力を254から230、防御力を244から200へ下げる。Lv.15のステータス、報酬、ドロップ確率は変更しない。アイヌアは標準Mob基準値で攻撃力28%の噛みつきを5回行う。アイヌリンダレは高火力型の倍率を適用し、HP 1120 / R 305 / D 195とする。三方向の地走り魔法は1波につき攻撃力45%、最大3波だが、予兆地点から移動して回避できる。

万象のイルーヴァタールはソロ挑戦を基準に、HP 8064、R220、D281を採用する。`shield.max: 30` を初期シールドとする。反射火球は攻撃力35%と40 tickの燃焼、炎突進は攻撃力45%とし、突進回数は万物のエルと同じ残HP帯の式を使う。

### 2.9 アルダ始まりの遺跡 Lv.15 の換算根拠

Lv.15の標準Mobアンカーは HP 4400 / R 797 / D 767 とする。報告対応として、`alda_origin_ruins` の通常Mobとボスの攻撃力は、役割と耐久値を維持したまま約20%低下させる。`middle_earth_ruins_skeleton`、`vatar_skeleton`、`ainua` は R 638 とする。`middle_earth_ruins_skeleton_archer` は `ATTACK 579`、`RANGED_ATTACK 271`、`DEXTERITY 5` により `(579 + 271) × 1.05 = 892.5`、表示上R893とする。`middle_earth_ruins_piglin_charger` は突進役割を維持し、HP 6600 / R 734 / D 844とする。`ainurindale` は高火力魔法型の役割を維持し、`ATTACK 728 + MAGIC_ATTACK 37 = 765`とする。

`alda_origin_ruins` は推奨レベル15、受付地点を `midgard_greenfields` の `(-78.5, 9.0, -674.5)` とし、既存のダンジョンより広い144×144 block、10〜12部屋、1部屋5〜7体で生成する。通常Mob poolには上記6種をすべてLv.15で登録し、最初の戦闘部屋の上限もLv.15とする。通常Mobの `SHIELD_BREAK` は5を設定する。

`forgotten_alda_colossus` は IRON_GOLEM 型のソロ基準Bossとして、標準MobのBoss倍率からHP `4400 × 8.0 × 0.8 = 28160`、調整後のR 765、D `767 × 1.15 = 882.05`を整数化し、Shield 60と`SHIELD_BREAK: 9`を設定する。参加者が2人以上の場合のHP・Shield補正はBoss共通仕様に従う。フェーズ1は `mob_clay_guard_leap` のみとし、半径8m、攻撃力倍率150%、詠唱30 tick、cooldown160 tickで着地する。シールド破壊時は60 tickだけ通常AIを停止し、被ダメージを1.5倍にした露出状態とする。HP70%以下のフェーズ2では105 tick間隔で30 tick予兆の4方向衝撃波（最大22m、攻撃力倍率68%、ノックバック0.65）を、HP35%以下のフェーズ3では90 tick間隔で二地点の始源崩落（内円2.8m・外円7m、1地点目40 tick予兆、2地点目10 tick予兆、攻撃力倍率95%、ノックバック0.70）を発動する。跳躍・シールド破壊・各フェーズの予兆と発動にはParticleDisplayと一時BlockDisplayを使用し、地形ブロックは変更しない。これらは配置後に同格装備でTTK・耐久時間を実測し、必要なら個別調整する。

### 2.10 花咲く古木の遺跡 Lv.20 の換算根拠

Lv.20の標準Mobアンカーは HP 8000 / R 1449 / D 1394 とする。依頼された低攻撃力を、アルダ始まりの遺跡と同じく役割基準の攻撃だけ約20%下げる方針として扱い、耐久値は役割倍率どおり維持する。

苔の甲羅獣は耐久型のHP `8000 × 1.5 = 12000`、R `1449 × 0.8 × 0.8 = 927.36`、D `1394 × 1.25 = 1742.5` を整数化する。射手花スケルトンとツタクモは標準耐久のHP 8000 / D 1394とし、Rは `1449 × 0.8 = 1159.2` を整数化する。射手花スケルトンは `ATTACK 900`、`RANGED_ATTACK 204`、`DEXTERITY 5`により `(900 + 204) × 1.05 = 1159.2` とする。通常敵の `SHIELD_BREAK` は、基礎シールドダメージ1と未強化fang shieldを含む最大Shield 20を基準に9を設定する。

大樹の守り手グランバルは古代の種を守るSNIFFER型のソロ基準Bossとして、HP `8000 × 8.0 = 64000`、R `1449 × 1.2 × 0.8 = 1391.04`、D `1394 × 1.15 = 1603.1` を整数化し、Shield 80と`SHIELD_BREAK: 9`を設定する。根の扇払いは前方70度・16mへ攻撃力60%を与える。花形の種爆発は対象位置を花芯、周囲6地点を花弁とする半径2.4mの円を同時攻撃し、重複範囲でも1回だけ攻撃力75%を与える。両攻撃は発動時に実際の命中面全体へ爆発particleを表示する。個別ギミックを含む最終的な耐久時間は実サーバーで確認する。

### 2.11 冥河の渡し守カロン Lv.20 のギミック

`charon_ferryman` はアルダの巨神兵より耐久力を高めたLv20ボスとし、基礎HP192000 / R1391 / D1603、Shield120を設定する。HPは従来の3倍・アルダの約2.18倍、Shieldはアルダの2倍。共通の確定参加人数補正がさらに掛かり、4人ではHP480000・Shield228となる。Shield中はHPが減らず、HP増加でShield換算の分母も増えるため、最終的な討伐時間は実サーバーで確認する。攻撃力を維持し、広域の予兆を読んで動くことで対処できる設計とする。

HP50%・25%で通常ローテーションを105 / 90 / 75 tickへ切り替える。通常冥河は対象方向と左右28度の3河道（長さ22m・半幅2.8m）を2秒予兆して攻撃力68%で発動する。渡し賃は最大6個の半径4.8mの円を2.25秒後に発動し、その時点の対象位置を再捕捉して1.75秒予兆の追撃を行う。各波の倍率は62%。通常の魂灯は半径20mの危険円と半径4mの緑の安全円を6秒表示し、BossBarで残り秒数と避難先を案内して、安全円外へ攻撃力100%を適用する。通常AIの単体攻撃も設定射程4.2mへ広げ、30 tickの間隔を維持する。

魂柱は人数1〜6人に応じ6〜11本、HP50%以下では8〜13本とし、地形不足時は最低4本まで減らす。ボス挑戦・ダンジョンでは開始時の確定人数、直接召喚では攻撃対象のパーティー人数を使う。3秒の浮遊・無敵召喚後は30秒残り、辺と対角の2本、HP50%以下では3本を3.25秒間隔・1.75秒予兆で同時発射する。半幅1.1m、攻撃力65%の魔法・無属性で、交点でも1斉射1回だけ命中する。再召喚予約は38秒から人数ごとに2秒短縮するが、残柱が消える33秒より早く重複生成しない。

HP50%の「冥河の大渡航」は24隻の冥舟と6波の河道を召喚する。各波2本（全長40m・半幅3.2m）の向きと左右位置が変わり、中央に留まるだけでは全波を避けられない。初回3.5秒・以後2.5秒の予兆後、現波の範囲へ攻撃力100%を1回適用する。HP25%の「五魂灯の裁定」は半径30mを覆い、半径4mの安全灯を5回切り替える。次灯は約6m先の歩ける床へ置き、配置不能時は同じ位置を維持する。初回3.5秒・以後2.75秒で攻撃力110% / 120% / 130% / 140% / 150%を適用する。

> 通常冥河は三方向の間や背後へ退避し、渡し賃は初撃の後も追撃の輪を確認する。大渡航は怒った村人の粒子で示す現波とPORTALで示す次波を読み、裁定は緑の安全輪と白い光で示す次灯への経路を順に渡る。大技開始2秒は浮遊・無敵、その後は無敵を解除する。通常AIと柱ビームは大技中停止し、最終発動の0.5秒後から3秒の反撃時間を設ける。一撃で両HP境界を跨いでも順番に発動する。粒子・音・舟・柱・BossBarの演出と、予兆に一致する当たり判定を維持する。詳細は [[00_docs/10_Plugin設計書/feature/26-boss/3-メソッド仕様/26_3-サービス#18. ボス固有ギミック|ボス固有ギミック]] を参照する。

### 2.15 大樹の根洞 Lv.25

`eriva_greatroot_hollow` は推奨Lv.25、標準攻略段階25、1〜4人用とする。受付はエリヴァ超大陸の `spawnLocation` `(-1149.5, 107.0, 1480.5)` のXへ5を加えた `(-1144.5, 107.0, 1480.5)`。144×144 block、10〜12部屋という既存ダンジョンの規模を維持し、道中は各部屋4〜5体へ抑える。3種を各1体保証し、残りを樹皮衛兵2・胞子術師3・根潜り3の相対weightで抽選する。35〜39 blockのボス広場で、固定された予告から退避できる余地を確保する。

景観は屋内方式で、根土・苔の床、根と木の壁・天井、木の支柱と梁、菌光の照明を使用する。個別の曲がった巨大根や地上の大樹の建築生成までは追加しない。

[[02-成長曲線#3.1 レベル別の最終目標値|Lv.25 Playerアンカー]]のHP6,500 / R2,264 / D2,355を試算条件にする。現行のPlayer Levelは戦闘statusを直接加算せず、class・装備・skilltree等の合算が正本であり、アンカー到達を保証しない。既存Lv.20古木遺跡が通常敵のRを約20%抑えていることを踏まえ、専用技のある道中と複数段階のボスを次の初期値へ調整する。

| 対象 | HP | 解決攻撃力R | 有効防御D | 理論TTK | 100%攻撃の防御後HP被害 |
|:--|--:|--:|--:|--:|--:|
| 根洞の樹皮衛兵 | 16,000 | 1,600 | 2,300 | 約7.49秒 | 約479（7.37%） |
| 根洞の胞子術師 | 10,500 | 1,800 | 1,800 | 約4.07秒 | 約659（10.13%） |
| 根洞の根潜り | 10,500 | 1,800 | 1,900 | 約4.22秒 | 約659（10.13%） |
| 滋養の芽 | 4,500 | 1,100 | 1,000 | 約1.35秒 | 攻撃行動なし |
| 根脈の心守 オルディア | 100,000 | 2,100 | 2,300 | HP削りのみ約46.84秒 | 約936（14.41%） |

理論TTKは無属性、貫通・会心・Shieldなし、命中率92%、最終倍率130%、通常攻撃間隔1秒、skill込みDPSを通常攻撃期待DPSの1.6倍とする。`DamageCalculator.defenseDamageMultiplier` の `max(0, 1 - D / R / 2.5) ^ (log(0.5) / log(0.6))` を使い、技のratioを乗じる。移動・詠唱・回復・通常攻撃劣化による損失は含まない。

樹皮衛兵は低速の耐久役、胞子術師は通常攻撃を持たない設置攻撃役、根潜りは固定位置へ短距離移動する役とする。各専用技の予告・倍率・中断条件は[[00_docs/10_Plugin設計書/feature/12-mob/12_6-Mobスキル追加ガイド|Mobスキル追加ガイド]]を正本とする。静止した滋養の芽は道中poolへ入れず、ボス専用の破壊対象とする。

心守は通常攻撃とShieldを持たず、専用コントローラの6種の予告行動とHP70%・35%の根脈接続を使う。根脈接続は2体・3体の芽が生存する間のダメージ無効を伴い、25秒で解除する。全芽の撃破後は6秒間の反撃窓で与ダメージ1.25倍とする。HP回復、時間経過による攻撃強化、即死攻撃を設けない。通常技のratio0.45〜0.75は上記アンカーのHPに対して約421〜702（6.48〜10.80%）、接続中の弱い根走りのratio0.30は約281（4.32%）となる。正確な技の寸法・時間・倍率・中断契約は[[00_docs/10_Plugin設計書/feature/26-boss/3-メソッド仕様/26_3-大樹の根洞|心守の専用仕様]]へ記載する。

道中3種と心守の `SHIELD_BREAK: 9` は、ソードマン基礎 `MAX_SHIELD: 5` と未強化ファングの盾（`20a00035`）の15を合算した代表構成の最大Shield20を基準にする。基礎Shield換算1＋9で、正のダメージを伴う2命中を目安とする。ほかの防具・強化・skilltreeによるShield増加はこの試算に含めない。

> [!info] 報酬と検証の境界
> ユーザー指定に従い、アイテム・通貨・Loot table・Dungeonクリア報酬は追加しない。道中は経験値360、心守は9,000、召喚芽は経験値0で報酬対象外。以上は設計アンカーと実装式による事前試算であり、実機の攻略時間、実プレイヤーの装備・火力、地形上の受付、予告の視認性は未確認とする。

## 4. 実装境界

- ミドルアースの遺跡は `midgard_greenfields` の `(-327.3, 25.0, -517.4)` を受付地点とし、Dungeon masterから生成する。
- ミドルアースの遺跡の通常敵3種は固有`items`を持たず、共通Loot tableだけを参照する。万物のエルは経験値のみを持ち、遺跡素材・武器・アクセサリ・オーブ・売却用素材はダンジョンの `clearRewards.items` で各項目を独立抽選する。
- 万象の聖域は推奨Lv.8とし、通常敵3種が共通Loot tableを参照する。アイヌリンダレだけは共通報酬に加えて、攻撃種別ごとのチャーム3種を各15%で個別抽選する。ダンジョンクリア報酬には売却専用素材、間接攻撃・魔法攻撃のタリスマンに加え、バルログ・メリアン・サウロンのチャームを各10%で個別抽選する。
- Lv.15以上の通常敵（`category: ENEMY`）の共通報酬は `normal_enemy_common_table_tier_2` を使用する。共通報酬はテュール・イージス・フレイヤの中級オーブを各0.5%、シンドリの中級オーブを8%、上級オーブを1%、犬・猫・ニワトリが宿る魔法の卵をそれぞれ0.005%、エリヴァ武器箱を0.5%で独立抽選し、個数はすべて1個とする。テーブルは1回抽選、プールの採用上限は全9候補とし、成功候補を間引かない。確率は既存のドロップ増加率を適用する前の設定値とする。経験値のみを定義する個別コンテンツと、次項のアルダ始まりの遺跡はこの共通報酬の対象外とする。
- アルダ始まりの遺跡の通常敵6種は、Lv.15の `drops.lootTable: null` で共通報酬を明示解除する。対象は `middle_earth_ruins_skeleton`、`middle_earth_ruins_skeleton_archer`、`middle_earth_ruins_piglin_charger`、`vatar_skeleton`、`ainua`、`ainurindale`。経験値と固有アイテム報酬、および同じマスタを使うLv.5／8コンテンツのTier1共通報酬は維持する。
- エリヴァの野外スポナー対象であるグラスボア、星角の森守、下草の狩人、棘牙の森狼、胞子の茸獣、樹皮の番兵はTier2共通報酬を持つ。エリヴァ武器箱（`50a00003`）はこの共通報酬から入手し、グラスボアの固有4%報酬には重ねない。開封は10 tick、エリヴァソード・エリヴァハンマー・エリヴァスピア・エリヴァショートボウ・エリヴァガンボウ・エリヴァロッド・エリヴァスタッフの全7種から等確率（各1/7）で1本を得る。通常弓のエリヴァ武器は廃止する。

- 武器職人ショップの1ページ目・1行目（slot 0〜6）は、エリヴァソード・エリヴァスピア・エリヴァハンマー・エリヴァショートボウ・エリヴァガンボウ・エリヴァロッド・エリヴァスタッフの順とする。各武器1本の対価は500,000G、上質なグラスボアの毛皮（`10a00068`）45個、森の樹脂（`10a00100`）10個とする。武器職人の従来商品は置かない。防具職人ショップには、次項のエリヴァ防具12品を素材交換で供給する。

**エリヴァの育成防具**

エリヴァの獣角兜・獣骨鎧・獣骨腿甲・獣骨靴はバスティオン、風狩帽・風狩衣・風狩脚衣・風狩靴はストライド、霊樹冠・霊樹法衣・霊樹脚衣・霊樹靴はアルカナに属する。全品Player Lv.15、RARE、基礎DEFの下限・上限を個別抽選、エンチャント1枠とし、ルーン枠は設けない。

全系統は2部位で対応する近接・間接・魔法攻撃力をそれぞれ+6、4部位で命中を同じ+2%追加する。段階効果は累積し、2＋2混合では各系統の攻撃力+6を得られる。

防具職人の1ページ目は商品欄4行×7列とし、内側の2列目バスティオン・4列目ストライド・6列目アルカナを、それぞれ頭・胴・脚・足の順で上から配置する。間に空列を残し、外周・前後ページ操作には商品を置かない。logical slotは順に `1 / 8 / 15 / 22`、`3 / 10 / 17 / 24`、`5 / 12 / 19 / 26` とする。全系統共通の部位別価格は次のとおり。通常Enemyから防具本体はドロップさせない。

| 部位 | ゴールド | 上質なグラスボアの毛皮 `10a00068` | 森の樹脂 `10a00100` |

| 脚 | 140,000 | 9 | 1 |

頭・脚・足は毛皮9個・樹脂1個で揃え、胸だけ各素材を2倍の毛皮18個・樹脂2個とする。四部位で540,000G・毛皮45個・樹脂5個となり、既存エリヴァ武器1本の500,000G・毛皮45個・樹脂10個を費用の基準にする。毛皮は四部位合計45個を維持し、Goldは部位別価格を維持する。基礎DEFは始源遺跡のLv.15防具に近づけ、軽装・法衣は重装より控えめに配分する。

> [!note] 育成と回復の上限
> +15で毛皮20個・1,500Gとプロメテウスのオーブを使いrank 1へ進化し、強化上限を+30へ拡張する。強化成功率は既存エリヴァ武器と同じで、+1が100%、+2～4が75%、+5～6が50%、+7～8が35%、+9が20%、+10～30が5%。失敗時は強化値を維持する。rank 0では通常イージスも使え、rank 1では中級以上のイージスが必要。上位オーブは対応rankを広げ、成功率を変更しない。中級以上の有償使用オーブではオーブ自身の売り値分のGoldも加算される。
> 回復力は全強化段階で据え置き、四部位からのENG回復は5秒あたり5、MP回復は5秒あたり10とする。ENG回復で技能の継続コストを相殺しすぎないよう、進化後は最大ENGを伸ばす。

> [!info] 外観の対応範囲
> 現行の装備描画は革防具の単色指定までを使う。バスティオンはアイボリー・黒鉄色・暗赤、ストライドは深緑・焦茶、アルカナは白木色・紺・淡青緑を部位に配分する。独自の角・厚い肩・顔が見えるフード・短い上着・片肩の骨当て・枝冠・根模様・小さな青緑結晶・袖裾の発光は描画未対応。これらの意匠は名称・説明に留め、現クライアントで描画するアセットとしては追加しない。

- エリヴァ大森林のスポナー対象5種（星角の森守、下草の狩人、棘牙の森狼、胞子の茸獣、樹皮の番兵）は、森の樹脂を基礎確率5%・1個で独立抽選する。既存のTier2共通報酬と経験値は維持し、幸運・ドロップ増加率は通常素材と同じく適用する。

> [!note] エリヴァ武器の個体差
> 武器ID `20a00073`～`20a00075`・`20a00077`～`20a00080` は維持する。個体生成時の主攻撃力下限を `5～59`、上限を `60～115` から独立抽選し、従来の `50～59`／`60～70` と同じ期待中間値59.75を保つ。主能力値は下限 `0～4`、上限 `5～9` とし、従来の `3～4`／`5～6` と同じ期待中間値4.5を保つ。個体ごとの下限・上限の差を広げる調整であり、強化増加値、エンチャント枠、ルーン枠は維持する。通常攻撃ダメージ増加の装備補正は、エリヴァスピアの+37.25%を削除し、他の武器は維持する。取得済みスピア個体の保存済み補正値は、マスタ変更だけでは削除されない。期待ステータスの維持は実戦の平均TTKを保証しないため、低個体・高個体を含む実機の戦闘時間は未確認とする。

- 花咲く古木の遺跡は推奨Lv.20とし、通常敵3種は経験値とTier2共通Loot tableを持つ。直接item dropは定義せず、ボスは経験値だけを持つ。Dungeon clear rewardではヴェルディアの道標を5%で抽選する。

- 配置後は同格装備でTTK・耐久時間を実測し、必要なら個別Skill倍率と行動間隔を調整する。
