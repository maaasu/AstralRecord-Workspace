# レベル帯コンテンツ設計

> [!abstract] この資料で決めること
> 現在 `40_filebase` に定義されているプレイヤー向けMobコンテンツと、その受入条件を記載する。

## 1. 共通ルール

- 表の `HP / R / D` は、マスタへ反映する最大HP・解決攻撃力・有効防御である。
- `R` は [[02-成長曲線]] のアンカーと役割倍率から求め、`ATTACK`・基本能力値・種別攻撃力へ配分する。
- `D` は対象の共通防御と攻撃種別防御の合計である。
- 受入条件は、同格装備における通常敵TTK 5〜7秒、プレイヤー耐久時間8〜10秒とする。

### 2.1 スケルトン・アーチャー Lv.3 の換算根拠

Lv.1とLv.5の標準Mobアンカーを直線補間したLv.3基準は、HP 300 / R 55 / D 52となる。高火力型の倍率（HP 0.8 / R 1.4 / D 0.8）を適用し、HP 240 / R 76 / D 42を目標値とした。

マスタでは、`ATTACK 48`、`RANGED_ATTACK 24`、`DEXTERITY 5`により、Pluginの計算式 `(ATTACK + RANGED_ATTACK) × (1 + DEXTERITY / 100)` から R 75.6（表示上76）となる。Dは`DEFENSE 42`で確保する。

### 2.2 ミッドガルズ・モスシェル Lv.2 の換算根拠

Lv.2 の標準 Mob 基準は、Lv.1 と Lv.5 のアンカーを直線補間して HP 200 / R 36 / D 35 とする。耐久型の倍率（HP 1.5 / R 0.8 / D 1.25）を適用し、HP 300 / R 29 / D 43 を目標値とした。`ATTACK 29` と `DEFENSE 43` でこの値を確保する。

### 2.3 クレイガード Lv.3 の換算根拠

Lv.3 の標準 Mob 基準は HP 300 / R 55 / D 52 とする。クレイガードは通常攻撃を主軸とし、長いクールダウンの `mob_clay_guard_leap` は半径2mの着地範囲へ攻撃力85%を与える回避可能な追加行動として扱う。`ATTACK 55` と `DEFENSE 52` で通常値を確保する。

### 2.4 ミドルアースの遺跡 Lv.5 の換算根拠

Lv.5の標準 Mob アンカーは HP 500 / R 87 / D 91 とする。近接スケルトンは標準値をそのまま用いる。遠隔スケルトンは高火力型（HP×0.8 / R×1.4 / D×0.8）として、`(ATTACK 76 + RANGED_ATTACK 40) × (1 + DEXTERITY 5 / 100) = 121.8`、表示上R122を得る。ピグリンは突進を持つ強敵としてHP750 / R100 / D100に留め、30 tickの予告後に詠唱開始時点の位置へ突進する。

万物のエルはソロ挑戦を基準に、標準Mob HPの8倍である4000HP、Boss倍率のR104 / D105を採用する。`shield.max: 2` はMob最大HPの20%に相当する初期シールドである。氷球は命中時に20 tick凍結、突進は `max(1, 10 - floor(残HP% / 10))` 回とし、HP80〜89%で2回、15%で9回とする。

### 2.5 フォレストウルフ Lv.6〜8 の換算根拠

Lv.6〜8 は、Lv.5 と Lv.10 の標準Mobアンカーを直線補間した HP 800 / 1100 / 1400、R 145 / 199 / 254、D 139 / 191 / 244 を採用する。役割は通常敵のまま、近接攻撃へ到達しやすい高速型として `MOVEMENT_SPEED` を 115 / 120 / 125 に設定した。Lv.2 グラスボアの 102 を各レベルで上回る。攻撃は `NEAREST` の自動索敵と30 tick間隔の通常近接攻撃だけを持ち、固有スキルは定義しない。

### 2.6 ミズガルズ・サバナ Lv.7〜8 の換算根拠

サバナハイエナは標準 Mob として、Lv.7 / 8 の HP・R・D をそれぞれ 1100 / 199 / 191、1400 / 254 / 244 とした。通常近接攻撃のみを持つ。

サバナウィッチは高火力遠隔型の倍率（HP×0.8 / R×1.4 / D×0.8）を適用した。Lv.7 は HP 880 / R 238 / D 153、Lv.8 は HP 1120 / R 305 / D 195 とし、`mob_savanna_witch_ember_bolt` の 48 tick 間隔・攻撃力75%の追尾弾で、命中時に凍結18%・燃焼24%を独立判定する。

サバナガードキャメルは耐久型の倍率（HP×1.5 / R×0.8 / D×1.25）を適用した。Lv.7 は HP 1650 / R 160 / D 239、Lv.8 は HP 2100 / R 203 / D 305 とする。Shield は最大HPの50%で、被攻撃時のみターゲットを取る。`mob_clay_guard_leap` は半径3m・攻撃力45%・150 tick間隔とし、標準のクレイガードより広範囲かつ低火力にする。
### 2.7 フォレストスパイダー Lv.7〜8 の換算根拠

Lv.7〜8 は、Lv.5 と Lv.10 の標準Mobアンカーを直線補間した HP 1100 / 1400、R 199 / 254、D 191 / 244 を採用する。`RANGED_ATTACK` を 199 / 254、`DEFENSE` を 191 / 244 として、遠隔攻撃の解決値を基準へ合わせる。`NEAREST` で近くのプレイヤーを索敵し、RANGED の `preferredRange: 7` と発動距離9mでスケルトン・アーチャーより近い位置を保つ。

固有スキル `mob_forest_spider_web_shot` は、速度0.90、hitbox追加半径0.25、攻撃力倍率0.75、詠唱10 tick、cooldown40 tickでクモ糸を飛ばす。命中時は25%の基礎確率で100 tickの衰弱を要求する。Lv.7のヴェノムサックは45%、Lv.8は50%、毒した瞳は両レベルとも1%で、いずれも luck の影響を受ける。

### 2.7 陽冠のサンバード Lv.10 の換算根拠

Lv.10の標準Mobアンカー HP 2000 / R 362 / D 348へSolo Boss倍率を適用し、HP 16000、R 434、D 400とする。追加参加者1人ごとにHPを基礎値の100%加算し、攻撃力は人数で増やさない。通常ローテーションは回避可能な太陽フレア、サンストライク、ソーラービームで構成する。12秒周期の陽炎転移はスポーン地点から水平7mの6地点を巡回し、専用行動中は延期する。HP30%到達時の天陽崩落はスポーン地点へ帰還して60 tick予告し、半径12mへ攻撃力145%の火属性ダメージを与える一度限りの大技とする。

### 2.8 万象の聖域 Lv.8 の換算根拠

Lv.8の標準Mob基準は HP 1400 / R 254 / D 244とする。ヴァタールスケルトンは標準近接値を採用し、アイヌアは同じ基準値で攻撃力28%の噛みつきを5回行う。アイヌリンダレは高火力型の倍率を適用し、HP 1120 / R 305 / D 195とする。三方向の地走り魔法は1波につき攻撃力45%、最大3波だが、予兆地点から移動して回避できる。

万象のイルーヴァタールはソロ挑戦を基準に、標準Mob HPの8倍である11200HP、Boss倍率のR305 / D281を採用する。`shield.max: 3` はMob最大HPの30%に相当する。反射火球は攻撃力65%と60 tickの燃焼、炎突進は攻撃力85%とし、突進回数は万物のエルと同じ残HP帯の式を使う。

## 4. 実装境界

- ミドルアースの遺跡は `midgard_greenfields` の `(-327.3, 25.0, -517.4)` を受付地点とし、Dungeon masterから生成する。
- ミドルアースの遺跡の通常敵3種は固有`items`を持たず、共通Loot tableだけを参照する。万物のエルは経験値のみを持ち、遺跡素材・武器・アクセサリ・オーブ・売却用素材はダンジョンの `clearRewards.items` で各項目を独立抽選する。
- 万象の聖域は推奨Lv.8とし、通常敵3種が共通Loot tableを参照する。アイヌリンダレだけは共通報酬に加えて、攻撃種別ごとのチャーム3種を各0.1%で個別抽選する。万象のイルーヴァタールとダンジョンクリア報酬は今回定義しない。
- 新しいレベル帯のコンテンツは、対象マスタと受入条件を決めた別作業で追加する。
- 配置後は同格装備でTTK・耐久時間を実測し、必要なら個別Skill倍率と行動間隔を調整する。
