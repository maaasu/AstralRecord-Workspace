# Plugin Code Prompt

## 読むタイミング

- Plugin のコードを追加・修正するとき
- 配置先パッケージや言語選定で迷うとき

## 前提

- 規約（言語選定 / ディレクトリ構成 / コーディングルール / JavaDoc 規約）は [`../../README.md`](../../README.md) に記載されている。**先に README を読み、本プロンプトには規約を重複記載しない**。
- 本プロンプトは AI 作業時の **追加チェック項目** に限定する。

## AI 実装チェックリスト（README ルール適用後の最終確認）

1. 機能が `feature/<feature>/` 配下に閉じているか。
2. ゲームロジックを `infrastructure/` に入れていないか。
3. `core/` にコマンド・イベント登録の起点以外を書いていないか。
4. Bukkit / Paper API のスレッド制約を守っているか（メインスレッド要求の API を非同期から呼んでいないか等）。
5. プレイヤー表現が `AstPlayer` 経由になっているか。`org.bukkit.entity.Player` を不必要に引き回していないか。
6. DB アクセスが repository 層に閉じているか。
7. enum で管理済みの値を文字列ハードコーディングしていないか。
8. ログ・プレイヤーメッセージを直書きしていないか（→ 該当時は `logger.md` / `player_msg.md` を参照）。
9. **`public` で外部から呼び出されるメソッドに、引数・戻り値・例外・前提条件を含む日本語 JavaDoc / KDoc が記載されているか**。

## 言語選定の最終判断

- まず **既存ファイルの言語に合わせる**。
- 新ファイル作成時は、配置するディレクトリ内の既存ファイルの流儀を踏襲する。
- 詳細条件（Java を基本、Kotlin を許容する用途）は README の「実装方針 / 言語選定」を参照。
